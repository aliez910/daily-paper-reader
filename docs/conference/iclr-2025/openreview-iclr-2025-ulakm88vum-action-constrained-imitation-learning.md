## Abstract
Policy learning under action constraints plays a central role in ensuring safe behaviors in various robot control and resource allocation applications.
In this paper, we study a new problem setting termed Action-Constrained Imitation Learning (ACIL), where an action-constrained imitator aims to learn from a demonstrative expert with larger action space.
The fundamental challenge of ACIL lies in the unavoidable mismatch of occupancy measure between the expert and the imitator caused by the action constraints. We tackle this mismatch through $\textit{trajectory alignment}$ and propose DTWIL, which replaces the original expert demonstrations with a surrogate dataset that follows similar state trajectories while adhering to the action constraints. Specifically, we recast trajectory alignment as a planning problem and solve it via Model Predictive Control, which aligns the surrogate trajectories with the expert trajectories based on the Dynamic Time Warping (DTW) distance. Through extensive experiments, we demonstrate that learning from the dataset generated by DTWIL significantly enhances performance across multiple robot control tasks and outperforms various benchmark imitation learning algorithms in terms of sample efficiency.

# 论文总结：Action-Constrained Imitation Learning（动作受限的模仿学习）

## 1. 核心问题与整体含义

- **研究背景**：在许多机器人控制与资源分配任务中，对智能体的行为施加**动作约束**是保障安全的核心要求。例如某些方向、幅值或动作类型不允许执行，以保证硬件安全或满足任务限制。
- **核心问题（ACIL, Action-Constrained Imitation Learning）**：当一个**动作受限的模仿者（action-constrained imitator）**需要向一个**动作空间更大的专家（expert）**学习时，专家可以执行的动作模仿者未必能执行，由此产生不可避免的**占据度量（occupancy measure）不匹配**问题。
- **研究意义**：传统模仿学习（Behavioral Cloning、GAIL 等）通常假设模仿者与专家的动作空间一致，面对受限场景时直接模仿会导致状态分布偏离、数据利用率低下甚至不可行。本研究将"动作约束"与"模仿学习"显式地耦合在一起，填补了安全约束场景下模仿学习的空白。

## 2. 方法论

- **整体思路**：通过**轨迹对齐（trajectory alignment）**缓解专家与模仿者之间的占据度量不匹配。核心观察是：虽然受限模仿者无法执行专家的全部动作，但如果能找到一条**状态轨迹相似、且所有动作都在约束范围内**的替代轨迹，则可基于该替代轨迹做模仿学习。
- **核心方法 DTWIL（Dynamic Time Warping Imitation Learning）**：
  1. **构造代理数据集（surrogate dataset）**：不再直接使用原始专家示范，而是先生成满足动作约束、且与专家状态轨迹高度相似的替代轨迹。
  2. **轨迹对齐问题的规划化**：将轨迹对齐问题重新形式化为一个**规划（planning）问题**。
  3. **基于模型预测控制（MPC）的求解**：使用 Model Predictive Control 在已知（或可学习）环境动力学模型下搜索满足约束的轨迹，以**DTW 距离（Dynamic Time Warping distance）**作为对齐目标函数，量化替代轨迹与专家轨迹在时间轴上允许局部拉伸/压缩后的相似度。
  4. **再进行模仿学习**：在生成的代理数据集上运行标准模仿学习算法（如 BC、行为克隆类方法）训练策略。
- **关键技术细节**：
  - **DTW 对齐目标**：相比欧氏距离，DTW 能容忍两条轨迹在时间步上的错位，更适合长度可变或速率不同的轨迹匹配。
  - **MPC 滚动优化**：通过有限时域滚动优化保证每一步动作都在受限集合内，同时最小化与专家参考轨迹的 DTW 距离。
  - **通用性**：DTWIL 主要贡献在于"数据集替代"步骤，对下游模仿学习算法是**即插即用**的。

## 6. 主要结论与发现

- 在受限动作空间下，**直接模仿原始专家数据会因占据度量不匹配而导致性能显著下降**。
- 通过 DTWIL 生成"满足约束 + 状态轨迹相似"的代理数据集，可有效**缩小专家与模仿者之间的占据度量差距**。
- 在多个机器人控制任务中，基于 DTWIL 数据训练的策略在**累积回报**和**样本效率**上**优于多种基准模仿学习方法**。
- 表明**轨迹对齐（DTW）+ 规划（MPC）**是处理动作受限模仿学习的一种通用且有效的范式，可迁移到其他受约束控制场景。
