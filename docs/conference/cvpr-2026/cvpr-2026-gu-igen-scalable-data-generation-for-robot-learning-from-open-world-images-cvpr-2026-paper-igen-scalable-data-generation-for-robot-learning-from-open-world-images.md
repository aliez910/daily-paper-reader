## Abstract
The rise of generalist robotic policies has created an exponential demand for large-scale training data. However, on-robot data collection is labor-intensive and often limited to specific environments. In contrast, open-world images capture a vast diversity of real-world scenes that naturally align with robotic manipulation tasks, offering a promising avenue for low-cost, large-scale robot data acquisition. Despite this potential, the lack of associated robot actions hinders the practical use of open-world images for robot learning, leaving this rich visual resource largely unexploited. To bridge this gap, we propose IGen, a framework that scalably generates realistic visual observations and executable actions from open-world images. IGen first converts unstructured 2D pixels into structured 3D scene representations suitable for scene understanding and manipulation. It then leverages the reasoning capabilities of vision-language models to transform scene-specific task instructions into high-level plans and generate low-level actions as SE(3) end-effector pose sequences. From these poses, it synthesizes dynamic scene evolution and renders temporally coherent visual observations. Experiments validate the high quality of visuomotor data generated by IGen, and show that policies trained solely on IGen-synthesized data achieve performance comparable to those trained on real-world data. This highlights the potential of IGen to support scalable data generation from open-world images for generalist robotic policy training. Code for IGen will be made publicly available.

# IGen 论文总结

## 1. 核心问题与研究背景

- **核心问题**：通用机器人策略（generalist robotic policies）的训练需要大规模视觉-动作（visuomotor）配对数据，但真实机器人的数据采集存在以下瓶颈：
  - 劳动密集、成本高昂；
  - 受限于特定环境和任务，跨场景泛化能力差。
- **研究动机**：开放世界图像（来自互联网）数量庞大、场景多样，天然与现实操作任务对齐，是一种低成本、大规模的数据来源。但其**缺乏对应的机器人动作标签**，无法直接用于机器人学习。
- **目标**：弥合开放世界图像与机器人学习之间的鸿沟，提出一个能够从单张开放世界图像自动生成"配对的视觉观测 + 可执行动作"的框架，为通用机器人策略训练提供可扩展的数据基础设施。

## 2. 方法论

### 整体框架
IGen 由三大模块组成：**场景重建（Scene Reconstruction）→ 动作规划（Action Planning）→ 视觉合成（Observation Synthesis）**。

### 模块一：从像素到结构化 3D 表示
- 使用 **Metric3Dv2** 等单目几何基础模型估计图像的深度和几何结构。
- 使用 **Grounded-SAM** 提取任务相关物体的掩码 M。
- 用 **DINOv2** 提取场景特征，对特征嵌入和 3D 坐标分别做 **K-means 聚类**，得到 K 个空间关键点 K = {k_j ∈ ℝ³}。
- 用 **Inpaint Anything** 移除目标物体并修复背景，得到背景图 I_bg 与背景稠密点云 P_bg ∈ ℝ^{H×W×6}。
- 对被操作物体使用 **3D 生成式重建模型（TRELLIS）** 完成完整 3D 形状补全，再用 **Any6D** 进行 6D 位姿估计还原到原位姿。
- 在可操作平面上采样一组候选放置点，用于空间域随机化（spatial domain randomization）。

### 模块二：基于空间关键点的行为生成
- 将"图像 + 关键点 + 3D 坐标 + 任务指令"输入 **VLM（GPT-4o / Qwen-VL / GLM-4.5V）**，输出高层任务计划 S = {S_i} 与每阶段对应的关键点。
- 设计了一套基于 SE(3) 末端执行器位姿的可编程 Python 控制语言，将高层阶段转化为低级控制函数 F = {f_i}。
- 在**抓取前阶段**用 **GraspNet / GraspGen** 等抓取先验预测末端执行器位姿；夹爪开合由抓取主轴方向上的点云宽度决定。
- 在**操作阶段**，被操作物体的关键点被视为与末端执行器刚性绑定，其余关键点作为静态锚点。
- 运动规划器生成子目标 X̂ = {x̂_i}，并在仿真中执行得到动作序列 A = {a_t}^T_{t=1}（末端执行器位姿 + 关节位置）。

### 模块三：基于点云渲染的视觉合成
- 在仿真中将虚拟相机放在与图像生成时一致的位置 p_cam，机器人放在规划位姿 p_robot。
- 从动作序列 A 中得到末端执行器 SE(3) 位姿轨迹 T = {T_t}。
- 抓取确立时间 t_g 后，对所有 t ∈ T_grasp，被操作物体点云随末端执行器做刚体变换：
  - P_{obj,t} = T_t (T_{t_g})^{-1} T_{obj,t_g} P_{obj,t_g}
- 最终任务点云序列为：P_task = P_bg ∪ P_obj ∪ P_robot
- 通过虚拟相机逐帧渲染，得到与动作时间同步的视觉观测 O。
- 视觉观测与动作序列 A 共同构成机器人学习的视觉-动作配对数据。

## 3. 实验设计

### 数据集与场景
- **场景重建评估**：使用 **Simpler** 数据集的真实机器人操作场景。
- **行为生成评估**：使用 **DreamGen Bench**。
- **机器人真机评估**：自建三类任务——放置（"Place the bottle"）、场景-物体交互（"Water the flowers"）、物体-物体交互（"Hit Box"）。

### 对比方法
- **视觉保真度对比**：Simpler 中的 Real-to-Sim 数字孪生方法。
- **行为生成对比**：Cosmos-Predict2（基于 Cosmos-Predict2-2B-Video2World）、TesserAct（基于 CogVideoX-5B-I2V 微调）。
- **真机策略对比**：人工遥操作数据（10 / 100 条） vs. IGen 生成数据（100 / 1000 条）。
- **基准**：零样本 π0、10/100 条遥操作数据微调的 π0、100/1000 条 IGen 数据微调的 π0。

### 评估指标
- 视觉质量：PSNR、SSIM、LPIPS（三种 backbone：AlexNet / VGGNet / SqueezeNet）。
- 行为质量：Instruction Following 与 Physics Alignment（GPT-4o、Qwen-3-VL-Plus、GLM-4.5V 作为评判器）。
- 机器人真机：任务成功率。

## 6. 主要结论与发现

- IGen 生成的场景在 LPIPS 上比 Simpler 的 Real-to-Sim 方法最高提升 **5.13×** 相似度。
- 在 DreamGen Bench 上，IGen 在指令跟随和物理一致性上**全面优于 Cosmos-Predict2 和 TesserAct**；以 Qwen-3-VL-Plus 为评判时指令跟随成功率约为基线的 **2 倍**。
- 效率方面：单样本仅需约 18.6 秒、8.3 GB 显存，比视频生成式基线快一到两个数量级。
- **关键真机结论**：仅凭 100 / 1000 条 IGen 生成数据（**无任何人工遥操作**）微调 π0，平均成功率分别达到 **44.5% / 66.7%**，**超过同等时间预算下人工遥操作数据的 19.4% / 58.3%**。在"Place Bottle"任务上从 0% 跃升至 75.0%。

## 7. 优点与亮点

- **数据来源完全开放**：仅需一张网络图片即可生成可执行动作与视觉观测，极大降低数据获取门槛。
- **无物理仿真器依赖**：使用基于点云渲染的"无仿真（simulation-free）"合成方案，避开传统 Real-to-Sim 对物理重建的高成本要求。
- **结构化 3D 表示**：3D 关键点 + 点云作为中间表示，兼顾空间推理与渲染效率。
- **VLM + 程序化控制**：VLM 负责高层语义规划，可编程控制语言负责 SE(3) 位姿执行，模块化清晰。
- **效率与可扩展性突出**：相比视频生成模型，训练成本与显存开销大幅下降，适合大规模合成。
- **真机验证有力**：在 Franka 上进行三类真实任务且**完全脱离人工遥操作**，说服力较强。

## 8. 不足与局限

- **真机任务覆盖有限**：仅 3 类任务、1 台 Franka 机械臂，未验证双臂、移动操作、长时序任务。
- **空间随机化范围受限**：物体只能在支撑平面上随机放置，对物体姿态多样性、复杂遮挡、动力学变化建模较弱。
- **依赖多个强基础模型**：Metric3Dv2、Grounded-SAM、DINOv2、TRELLIS、Any6D、GraspNet 等任一环节出错都会影响最终数据质量，存在**误差累积风险**。
- **评估 VLM 的可靠性问题**：用 GPT-4o、Qwen-VL、GLM-4.5V 评判视频质量，存在评估偏差（不同 VLM 评判结果不一致）。
- **缺乏 VLM 消融与提示工程讨论**：未分析不同 VLM 对任务规划质量的影响。
- **未涉及安全/失败场景**：生成数据中失败与恢复样本是否充足未讨论，影响策略鲁棒性。
- **算力信息缺失**：训练阶段的硬件配置与训练时长未公开，复现成本难以预估。
- **没有泛化到训练图像之外的物体/场景**：本工作的"开放世界"更多指图像来源开放，而非物体类别或背景组合的真正开放。
