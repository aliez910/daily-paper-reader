## 摘要
机器人学习日益依赖于广泛且多样化的演示数据，然而机器人数据的采集成本高昂，难以覆盖真实世界任务的长尾分布。为解决这一瓶颈，我们提出了 RoboTok——一种互联网规模的数据引擎，给定查询的人类操作视频后，即可从网络视频中检索出与操作相关的人类演示，用于训练灵巧的机器人策略。具体而言，我们从以执行者为中心的估计参考系中所表达的 3D 手部轨迹学习一个潜在运动空间。该表征使得操作行为能够在相机视角、场景外观以及执行者遮挡等变化下进行跨场景比较，同时保持足够的紧凑性，以支持互联网规模视频集合上的高效搜索与持续索引。我们在检索基准和下游机器人策略性能上对 RoboTok 与现有机器人数据检索方法进行了对比评估。实验结果表明，RoboTok 能够检索到更具相关性的操作演示，并提升下游任务成功率，验证了将手部姿态轨迹感知检索作为一种使网络视频成为机器人学习可扩展且持续增长的监督来源的可行途径。

## Abstract
Robot learning increasingly depends on broad and diverse demonstrations, yet collecting robot data remains expensive and poorly suited to covering the long tail of real-world tasks. To address this bottleneck, we introduce RoboTok, an internet-scale data engine that, given a query human manipulation video, retrieves manipulation-relevant human demonstrations from web videos for training dexterous robot policies. Specifically, we learn a latent motion space from 3D hand trajectories expressed in estimated actor-centered reference frames. This representation enables manipulation behaviors to be compared across variations in camera viewpoint, scene appearance, and actor occlusions, while remaining compact enough for efficient search and continual indexing over internet-scale video collections. We evaluate RoboTok against existing robot-data retrieval approaches on retrieval benchmarks and downstream robot policy performance. Our results show that RoboTok retrieves more relevant manipulation demonstrations and improves downstream task success, establishing hand-pose trajectory-aware retrieval as a way to make web video a scalable and continuously growing source of supervision for robot learning.

# RoboTok 论文总结

## 1. 核心问题与研究动机

- **数据瓶颈**：机器人模仿学习严重依赖大规模、多样化的演示数据，但机器人数据的采集成本高昂、依赖专用遥操作设施，难以覆盖真实世界中"长尾"任务、物体与场景。
- **互联网视频的潜力与挑战**：互联网人类视频（HowTo100M、Action100M 等）蕴含海量、自然发生且持续增长的操作行为，对人形机器人与仿人手尤其相关。但其本身高度非结构化，存在任意视角、场景外观和人物遮挡。
- **关键观察**：视觉相似或语义相似并不等价于操作行为相似（Memmel et al., 2025; Hong et al., 2026; Papagiannis et al., 2025）。仅靠外观或文本标签检索，难以定位真正具有类似操作动作的视频。
- **本文定位**：构建一个面向互联网视频、以"手部轨迹行为"为核心的检索式数据引擎，缓解机器人数据采集瓶颈。

## 2. 方法论

### 2.1 核心思想
将网络视频中的**3D 手部轨迹**通过估计的**执行者躯干坐标系**进行视角无关的规范化，并在由 DTW（Dynamic Time Warping）诱导的相似度监督下学习一个紧凑的潜在运动嵌入空间，从而实现跨视角、跨外观、跨遮挡的可比、高效、可扩展的检索。

### 2.2 问题形式化
- 给定查询片段 $q$ 与人类演示集合 $D = \{x_1,\dots,x_N\}$，目标是从 $D$ 中检索出 $K$ 个手部运动最相似的片段。
- 用 DTW 计算 21 关节手部姿态序列 $x_i, x_j$ 之间的对齐代价，并定义归一化相似度：

$$s(i,j) = -\frac{\text{DTW}(x_i, x_j)}{\frac{1}{2}(L_i + L_j)}$$

- 直接计算 DTW 在互联网规模上不可行，因此用 DTW 作为**监督信号**，学习编码器 $\Gamma: \mathcal{X} \to \mathcal{S}^{d-1}$，使内积相似度能保持 DTW 诱导的排序：$s(i,j) > s(i,k) \Rightarrow \langle \Gamma(x_i),\Gamma(x_j)\rangle > \langle \Gamma(x_i),\Gamma(x_k)\rangle$。

### 2.3 数据处理流水线
- **源数据与筛选**：从 Action100M 中筛选 4–8 秒片段，要求近似静态相机（Lucas–Kanade）、双手可见（WiLoR）。
- **3D 手部姿态估计**：以 5 fps 用 WiLoR 提取手部关键点，MoGe-2 估计 metric 深度将其转为相机坐标系下 metric 3D 姿态，缺失帧用 HaWoR 填补。
- **自我中心轨迹表示**：训练一个轻量级人体躯干坐标系估计器，**仅以手腕轨迹作为输入**（不要求躯干可见），将相机坐标转换到执行者相对坐标系，得到 SMPL-H 兼容的规范化轨迹。

### 2.4 编码器与训练目标
- **编码器**：对每帧位置编码后用轻量 cross-attention 池化，得到 $\ell_2$ 归一化的 $d$ 维嵌入，供 cosine-similarity 检索。
- **批次构建**：基于 DTW 真实排序构造 anchor-centered 组——对每个 anchor $a$，选取 DTW 前 $K=20$ 个邻居中的 2 个正样本 + 1 个"边界负样本"，每批 49 组共 196 条轨迹。这种"边界负样本"采样显著提升训练信号质量。
- **损失函数**：$\mathcal{L} = \mathcal{L}_{\text{set}} + \lambda \mathcal{L}_{\text{rank}}$
  - Set 损失：使 oracle top-K 邻居在分数上高于边界/随机负样本。
  - Rank 损失：保持 DTW 诱导的相对排序。

### 2.5 检索流程
- **离线**：所有规范轨迹预先编码一次，存入内积索引。
- **在线**：查询片段编码后通过 cosine-similarity 快速检索最近邻，无需与全库重算 DTW；新增片段只需一次前向即可加入索引。

## 3. 实验设计

### 3.1 数据集与基准
- **检索评估**：
  - RoboTok 评测语料库：来自 Action100M 的 10K 留出片段（总 100K），伪 GT 由 DTW 给出，相关集大小 $K=20$。
  - AssemblyHands：831 个双手装配片段，具有传感器级 3D 手部真值，$K=5$，用于跨域评估。
- **下游策略评估**：VTDexManip（Liu et al., 2025）灵巧操作仿真基准。
  - 原始版本：6 个任务（瓶盖拧转、水龙头拧动、操纵杆滑动、桌面重定向、手内重定向、双手交接），Seen/Unseen 物体拆分。
  - 改进的"更难"版本：3 个任务（瓶盖拧转、水龙头拧动、操纵杆滑动），恢复手腕 3D 控制并去除人工设计的稠密奖励。

### 3.2 对比方法
- **检索基线**：Random、FlowRetrieval（Lin et al., 2024，光流）、HAND（Hong et al., 2026，2D 手/末端路径）、STRAP（Memmel et al., 2025，子轨迹 DTW）。

## 6. 主要结论与发现

- **检索质量显著领先**：在 RoboTok 评测集上 mAP@20=0.353、Recall@20≈0.996，最强基线 STRAP 仅 mAP@20=0.007；在 AssemblyHands 跨域集上同样全面领先（mAP@5=0.261 vs STRAP 0.133）。
- **检索排序正确性高**：Kendall τ=0.487（RoboTok 评测集）说明检索到的邻居不仅存在，且顺序与 DTW oracle 一致。
- **泛化能力**：仅在 $k=20$ 局部邻域训练，却在 $k$ 远大于 20 时仍保持高质量检索，说明学到的运动空间具备全局结构。
- **下游策略显著提升**：在原始 VTDexManip 6 个任务上，平均比最佳基线提升 7.45%（Seen）和 5.83%（Unseen）；在更难版本上提升更显著——例如 Lever Sliding Seen 79.3% 对比次优 HAND 19.5%（+59.8%），Faucet Screwing Seen 44.8% 对比 6.8%（+38.0%）。
- **核心论断**：手部轨迹感知检索能有效将互联网视频转化为机器人学习持续增长、可扩展的监督源。

## 7. 优点

- **表示设计精巧**：仅从手腕轨迹预测躯干坐标系，避免对执行者全身可见的依赖，覆盖大量常见演示视频。
- **DTW 监督无需语义标签**：避免了昂贵的人工标注，且行为定义明确、跨视角鲁棒。
- **检索与索引可扩展**：预先编码 + 嵌入索引支持高效最近邻搜索，新增数据无需重训，可作为"互联网规模数据引擎"持续运行。
- **检索与下游双验证**：不仅在检索指标上领先，也通过下游 PPO 策略的成功率实质性证明检索结果对机器人学习有用。
- **跨域评估**：在 AssemblyHands 这一独立、传感器级真值的数据集上验证迁移性，增强可信度。
- **批构建与损失设计**：使用 anchor 中心组 + 边界负样本，结合 set+rank 双损失，针对检索任务而非通用表征学习，贴合使用场景。

## 8. 不足与局限

- **伪 GT 限制**：在 RoboTok 评测集上以 DTW 作为伪 GT（缺乏传感器级手部真值），可能掩盖部分真正相关的演示，并受 DTW 对齐误差影响。
- **相机假设**：当前要求近似静态相机，许多真实网络视频（尤其是第一/第三人称移动镜头）被排除在外；作者承认"未来工作将扩展到移动相机"。
- **手部可见性要求**：依赖双手可见的筛选条件，可能过滤掉大量潜在相关演示。
- **下游评估局限于仿真**：未在真实机器人上验证检索结果的可执行性与泛化；真机迁移仍是开放问题。
- **缺少消融实验**：未对躯干坐标系估计、set/rank 损失权重 $\lambda$、边界负样本策略等进行系统性消融，难以判断各模块贡献。
- **下游奖励设计的耦合**：PPO 通过 k-NN 距离与潜在奖励塑形使用检索演示，但并未严格隔离"检索质量提升"与"奖励塑形设计"的贡献，方法间的差异部分可能来源于此。
- **数据来源单一**：训练数据完全来自 Action100M，未验证在更大或异质视频库（如 HowTo100M、EgoInfinity）上的可扩展性。
- **算力与代码细节缺失**：训练时长、硬件规模、推理延迟等关键工程信息未披露，复现成本不透明。
- **跨形态迁移未深入**：虽提到面向灵巧手与人形机器人，但仅评估了 VTDexManip 中的单一灵巧手形态，未验证多形态或人形全身操作场景。
