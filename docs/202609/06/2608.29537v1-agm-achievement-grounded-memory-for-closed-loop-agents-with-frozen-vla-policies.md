## 摘要
冻结的视觉-语言-动作（VLA）策略具备广泛的操控技能，但执行开环动作片段时无法跟踪任务进度，因此智能体难以可靠地判断是继续、重试还是终止。外部记忆是一种自然的解决方案，但当尝试执行的动作被视为已完成进度时，它可能产生危害，将局部执行错误转化为持续的任务状态错误。我们提出了成就驱动记忆（AGM），一种面向冻结 VLA 策略的轻量级闭环框架，它将任务表示为带有进度指针的子目标序列，并且仅在当前子目标被物理证据验证后才推进该记忆。本体感知交互线索决定何时进行验证，而源自冻结基础模型、经由一个仅 2.43M 参数的验证头获取的连贯点跟踪和语言条件跨视角比较，则决定达成了什么。AGM 因此将开环执行转变为执行-验证-进度的闭环，在保持策略冻结的同时无需测试时的大模型推理。在 RoboMME Counting 基准上，AGM 在 PickXTimes 和 BinFill 上分别达到相应成绩，平均超越最强的记忆增强基线相应百分点，并且该框架在物理机器人上也带来了同样显著的性能提升。因此，可靠的具身记忆更依赖于有纪律的状态更新，而非记忆容量。

## Abstract
Frozen vision-language-action (VLA) policies offer broad manipulation skills but execute open-loop action chunks without tracking task progress, so the agent cannot reliably decide whether to continue, retry, or terminate. External memory is a natural remedy, yet it can be harmful when attempted actions are treated as completed progress, turning local execution errors into persistent task-state errors. We propose Achievement-Grounded Memory (AGM), a lightweight closed-loop framework for frozen VLA policies that represents a task as a subgoal sequence with a progress pointer and advances this memory only after the current subgoal is verified by physical evidence. Proprioceptive interaction cues decide when to verify, while coherent point tracking and language-conditioned cross-view comparison, sourced from frozen foundation models through a single 2.43M-parameter verification head, decide what was achieved. AGM thereby converts open-loop execution into a closed loop of execution, verification, and progress, keeping the policy frozen without test-time large-model inference. On the RoboMME Counting benchmark, AGM reaches on PickXTimes and on BinFill, surpassing the strongest memory-augmented baseline by points on average, and the framework yields equally decisive gains on a physical robot. Reliable embodied memory thus depends more on disciplined state updates than on memory capacity.

## 1. 核心问题与研究动机

- **背景**：大规模预训练的视觉-语言-动作（VLA）模型（如 π0、π0.5、RT-2、OpenVLA 等）将视觉观测与语言指令直接映射为连续动作块，但执行过程是**开环的**，缺乏对任务进度的内部表征。
- **关键缺陷**：在**重复计数类操控任务**（如"将 5 个蓝色立方体放入箱中"）中，不同重复阶段在感知上几乎不可区分（perceptual aliasing）。抓取失败、滑落、放置偏移等瞬时执行错误一旦被当作"已完成"写进外部记忆，就会固化为持续的任务状态错误，导致整个回合计数出错。
- **核心洞察**：作者通过对照实验发现，使用"每次尝试都推进记忆"的朴素记忆机制，在 PickXTimes 任务上仅取得 32% 成功率，**甚至低于完全不使用进度记忆**的策略（36%）。因此，外部记忆的关键问题不是"**存什么**"，而是"**何时写入**"。
- **研究问题**：如何为冻结 VLA 策略设计一种轻量级闭环框架，使记忆写入严格以物理证据为锚，从而避免局部执行错误污染全局任务状态。

## 2. 方法论：Achievement-Grounded Memory (AGM)

### 2.1 整体框架

- **任务表示**：将任务指令确定性展开为有序的子目标序列 𝒢 = {(gₖ, cₖ)}，每个子目标带类型标签 cₖ ∈ {grasp, place-rev, place-irrev, other}，并维护一个进度指针 pₜ 构成任务记忆 ℳₜ = (𝒢, pₜ)。
- **类型决定可恢复性**：平面放置（recoverable）可通过重新抓取撤销；容器放置（irreversible）释放后不可撤销。这一区分直接决定验证阈值与回滚策略。
- **闭环结构**：执行（frozen VLA）→ 验证（物理证据）→ 进度推进（指针更新），三阶段严格闭环。

### 2.2 何时验证：本体感知事件触发

- **抓握-加载有限状态机（FSM）**：根据夹爪开度 wₜ 的迟滞阈值（仿真 0.030/0.035，需 5 帧确认）输出事件 eₜ ∈ {∅, G⁺, R⁺, R⁰}。
  - G⁺：稳定加载抓取；R⁺：从加载状态释放；R⁰：从空状态释放。
- **兼容性函数 χ**：仅允许 (G⁺, grasp) 和 (R⁺, place) 配对触发验证；空释放和不匹配事件被丢弃，不消耗验证预算。

### 2.3 验证什么：两类物理证据

#### 2.3.1 抓取验证——连贯运动点跟踪

- 抓取瞬间将末端执行器位置投影到前视图像，采样 6×6 查询点网格（仿真半宽 22 px，硬件 60 px）。
- 用冻结的 **CoTracker3** 跟踪末端提升片段（仿真 0.03 m 上升后停止累积）。
- 计算可见点（V ≥ η_vis = 0.5）中**上移位移最大**的 ρ = 1/3 点的**中位垂直位移** rⁿ_G：
  $$r^n_G = \text{Median}(\text{Top}_\rho\{d_{n,i} \mid i \in I^n_{vis}\})$$
- 接受条件：rⁿ_G ≥ δ_G（仿真 4 px，硬件 8 px），即确认物体与夹爪同步上移。

#### 2.3.2 放置验证——语言条件跨视角比对

- 释放事件前后，从前视和腕视各聚合 K = 4 帧窗口（容器放置后等待 40 帧，平面 30 帧）。
- 用冻结的 **SigLIP-base** 编码图像与文本子目标，得到嵌入向量。
- 特征拼接（Eq. 18）：前后前视嵌入、差分嵌入、前后腕视嵌入、本体感知摘要、子目标文本嵌入。
- 通过 2.43M 参数的 MLP 头 h_ψ 预测放置达成概率 sⁿ_P。

### 2.4 记忆推进规则（Eq. 20–21）

- **验证成功**：指针前移（min(p + 1, T)）。
- **抓取失败**：指针保持（保留当前状态等待重试）。
- **可恢复放置失败**：指针回滚到该重复的抓取子目标 B(p)。
- **不可恢复放置**：无回滚，使用更宽松阈值 κ_c = 0.05；连续拒绝上限 3 次后强制推进以防死锁。
- **终止前独立检查**：最后一步可恢复放置用视觉占据测试（不依赖学习头）再次确认。

### 2.5 训练数据与监督

- 788 个执行事件（抓取 384、平面放置 278、容器放置 126），来源于两个互补控制器（AGM 自身 + 尝试式无验证控制器）。
- 标签由环境谓词离线生成（物体抬升、目标区域包含、容器计数增加）。
- 仅训练验证头（AdamW，lr=1e-3，300 步，类别加权交叉熵），策略、跟踪器、编码器全部冻结。

## 6. 主要结论与发现

- **新 SOTA**：在 RoboMME Counting 上取得 55.96% 四任务平均成功率，超过最强记忆增强基线 MemER（48.83%）**7.1 个百分点**，几乎是冻结 π0.5（28.78%）的两倍。
- **抓取锚定任务绝对优势**：PickXTimes **100.0%**、BinFill **84.0%**（均为新 SOTA）。
- **真实机器人可迁移**：PickXTimes 全 N 保持 100%，BinFill 从 N=1/2 的 100% 平滑衰减至 N=5 的 60%。
- **跨骨干可迁移**：同一 AGM 配置使几乎不可用的 π0 提升至 PickXTimes 44%、BinFill 8%（说明收益源于接口而非特定策略）。
- **核心结论**：可靠的具身记忆**更依赖于有纪律的状态更新（写入时机），而非记忆容量或模型规模**。AGM 用 2.43M 训练参数击败 4B 外部 VLM 微调基线，验证了该论断。
- **不对称阈值必要性**：可恢复放置严格（κ_c = 0.5）、不可恢复放置宽松（κ_c = 0.05），移除该区分使 BinFill 掉 10 个百分点。

## 7. 优点与亮点

- **问题定位精准**：通过"尝试式记忆 vs 无记忆"的对照（Table 10）清晰揭示了朴素记忆的失败模式，为整个研究提供强动机。
- **零额外训练成本**：CoTracker3 + SigLIP 全部冻结，仅 2.43M 参数 MLP 头需训练；部署时无需任何自回归 VLM 推理。
- **物理证据与语义证据解耦**：抓取用点跟踪的**运动学证据**（物体是否与夹爪同步上移），放置用语言条件的**语义证据**（指定对象-目标关系是否建立），设计契合各自物理本质。
- **可恢复性感知设计**：将放置类型按可撤销性分类，验证阈值与回滚策略据此差异化，避免了不可逆操作的"假阳性"代价。
- **完整闭环工程化**：含 FSM 事件门控、兼容性过滤、死锁边界、终止前再验证、离线回放验证、部署-训练词汇对齐检查等工程细节，可直接复现。
- **跨骨干、跨平台一致**：同一框架在 π0/π0.5、仿真/真实机器人上均生效，仅需重新标定物理常数。
- **充分消融与归因**：抓取验证模态、阈值扁平化、子目标源、跨骨干、写入时机多维度消融，结论可信。

## 8. 不足与局限

- **验证词汇受夹爪交互约束**：AGM 仅覆盖由 G⁺/R⁺ 事件包围的子目标；推、滑、铰接物体操作、持工具操作等产生的事件不在兼容集内，只能回退到冻结策略。这是 SwingXTimes/StopCube 无法提升的根本原因。
- **任务结构限制为线性序列**：单指针 + 有序子目标无法表达分支规划、偏序子目标或乱序可满足子目标；回滚仅能到达当前重复的抓取。
- **可恢复性标签静态化**：类型在指令展开时即固定，无法根据场景动态判定"该物体是否仍可重抓"；若物体因意外不可达，重试会被强制推进到死锁边界。
- **有界拒绝的权衡**：死锁边界将"活性失败"转化为"潜在进度错误"，AGM 保证的是"未验证写入少且有界"，而非"永不发生"。
- **验证质量即性能上限**：假阳性记录虚假进度，假阴性消耗预算重复已完成子目标；不可恢复放置的判别性在 held-out 上不佳（仅 4 个失败样本），阈值策略只能缓解而非消除。
- **物理评估范围有限**：真实机器人仅 1 套 6-DoF 平台、单一夹爪几何、单一物体类别；标定阈值未声明跨平台可迁移性，需按 D.5 流程重新标定。
- **算力信息披露不足**：GPU 型号/数量、训练墙钟时间未给出；不利于完整复现成本评估。
- **跨计数深度零样本仅限 BinFill**：PickXTimes 演示覆盖到 N=5，BinFill N=5 完全在演示外；其他任务家族的分布外泛化未验证。
