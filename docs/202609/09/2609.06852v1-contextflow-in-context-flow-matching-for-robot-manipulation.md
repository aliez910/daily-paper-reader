## 摘要
尽管上下文学习在视觉和语言领域效果显著，但将其应用于机器人仍具挑战性。现有的自回归上下文模仿方法将连续动作离散化，并通过下一标记预测加剧了早期预测误差的累积，限制了对未见任务配置的泛化能力。与此同时，流匹配策略已被探索用于连续机器人控制，并能缓解误差累积；然而，在流匹配框架内的上下文模仿学习仍研究不足。为了解决这些局限性，我们提出了ContextFlow，一种用于上下文模仿学习的条件流匹配模型，能够学习连续动作分布。ContextFlow将基于流的动作预测条件化于示教和观测之上，从而能够从含噪声的动作分布中进行稳健生成。为了更好地编码多模态上下文示教，我们采用了感知器（perceiver）风格的多模态上下文压缩器，将视觉、本体感知和动作序列提炼为紧凑且与任务相关的潜在表示。在LIBERO基准上，ContextFlow在未见任务配置上的平均成功率比ICRT高出35个百分点，同时在未见任务上无需任何微调即可达到任务特定微调的VLA模型$π_0$的性能。在真实机器人实验中，它能够泛化到单臂和双臂任务的未见配置，在一个全新的开笔帽配置上取得了40%的成功率。项目页面：https://dingjiansw101.github.io/contextflow-page/。

## Abstract
Although highly effective in vision and language domains, applying in-context learning to robotics remains challenging. Existing autoregressive in-context imitation methods discretize continuous actions and exacerbate the accumulation of early prediction errors through next-token prediction, limiting their generalization on unseen task configurations. Meanwhile, flow-matching policies have been explored for continuous robot control and can help mitigate compounding errors; however, in-context imitation learning within a flow-matching framework remains underexplored. To address these limitations, we introduce ContextFlow, a conditional flow-matching model that learns continuous action distributions for in-context imitation learning. ContextFlow conditions flow-based action prediction on demonstrations and observations, enabling robust generation from noisy action distributions. To better encode multimodal in-context demonstrations, we adapt perceiver-style multimodal context compressors that distill visual, proprioceptive, and action sequences into compact, task-relevant latent representations. On LIBERO, ContextFlow outperforms ICRT by 35 percentage points in average success rate on unseen task configurations, while matching the performance of the task-specific fine-tuned VLA model $π_0$ without any fine-tuning on unseen tasks. On real robots, it generalizes to unseen configurations of both single-arm and bimanual tasks, achieving 40% success on a new pen-uncapping configuration. # ContextFlow: 面向机器人操作的上下文流匹配 — 论文总结

## 1. 核心问题与研究动机

- **核心问题**：如何让机器人像 LLM 那样，仅凭测试时给出的少量示教（in-context demonstrations）就能在不更新参数的情况下泛化到**未见任务配置**（例如未见物体或空间摆放），并同时保持连续动作的精确控制。
- **现有方法的两大瓶颈**：
  - **自回归（AR）上下文模仿学习**（如 ICRT、LipVQ-VAE、RICL）将连续动作离散化为 token，按 token 自回归生成。早期预测误差会沿着时间步**累积放大**（compounding error），在 train/test 任务分布不同的"未见配置"上尤其严重。
  - **流匹配（Flow Matching）策略**（如 π0）虽能建模连续动作、并行预测动作块，缓解累积误差，但**尚未被系统地用于上下文模仿学习**。
- **研究动机**：将条件流匹配引入上下文模仿学习框架，使模型既能利用示教信号，又能避免动作离散化和串行生成带来的误差放大。

## 2. 方法论

### 2.1 整体框架

- **建模目标**：学习条件分布 $\pi(a_t \mid o_t, d)$，其中 $a_t$ 为未来 $H$ 个连续动作块，$o_t$ 为当前观测（图像 + 本体状态），$d$ 为示教轨迹 $[T, X, Q, A]$（文本、图像序列、本体状态序列、动作序列）。
- **条件流匹配（CFM）**：
  - 构造中间分布 $p_s(a_t^s \mid a_t) = \mathcal{N}(a_t^s \mid s a_t, (1-s)^2 I)$，$s \in [0,1]$。
  - 闭式速度场：$u(a_t^s \mid a_t) = a_t - \epsilon$，即噪声到干净动作的直接位移。
  - 学习一个参数化向量场 $u_\theta(a_t^s, o_t, d, s)$，最小化 CFM 损失 $\mathcal{L}_{CFM} = \|u_\theta - u\|^2$。
  - 推理时从 $a_0 \sim \mathcal{N}(0,I)$ 用 Euler 积分 $K=10$ 步得到 $a_1$，作为动作块预测。
- **关键优势**：连续动作、并行预测动作块，从根本上规避 AR 的累积误差。

### 2.2 模型架构（Mixture-of-Experts）

- **Context Expert**：编码当前观测 + 文本 prompt + 经压缩的示教 token。
- **Action Expert**：处理本体状态 + 噪声动作 token，通过 cross-attention 与 Context Expert 交互，经 K 步流匹配迭代输出干净动作块。
- **权重初始化**：SigLIP 视觉编码器与 Action Expert 从 π0 初始化（Action Expert 使用 LoRA r=32 微调），Context Expert 随机初始化并全量训练。
- **块式因果注意力**：动作 token 可 attend 到 context token，反之不行，便于推理时缓存 context token、避免每步重算。

### 2.3 多模态上下文压缩器（核心创新）

- **问题**：单条示教可长达 800 步，多相机视角产生大量视觉 token，自注意力复杂度二次增长，计算不可承受。
- **解决方案**：采用 perceiver 风格的可压缩模块，对图像、本体状态、动作三类序列分别进行压缩：
  - **时间子采样**：图像 $N_1=8$ 帧、本体 $N_2=128$ 步、动作 $N_3=128$ 步。
  - **Perceiver 压缩器**：$N_q=32$ 个可学习 query token 经 $L$ 层交替 cross-attention / self-attention，蒸馏出固定大小的紧凑 latent。
  - 三个压缩器（Cimg、Cstate、Caction）输出拼接为 $T_{\text{context}}$，与当前观测 token、文本 token 一起送入 Context Expert。
- **作用**：在显著降低显存与计算开销的同时保留任务相关信息（注意力可视化显示 query 会随任务阶段聚焦到夹爪、物体、目标位置）。

### 2.4 训练与推理流程

- 训练：Context Expert 接收同任务（seen）的随机示教样本；推理：给定**新任务**（unseen）的一条示教，模型直接预测动作，**不更新任何参数**。

## 3. 实验设计

### 3.1 仿真 Benchmark：LIBERO

- 使用 LIBERO 的 **Spatial**、**Object** 两个核心任务套件，外加 **Goal**、**Long-horizon-10** 训练数据；评估在 Spatial/Object 各 2 个 unseen 配置（每任务 50 次）。
- 多模态输入：工作区相机 + 腕部相机 RGB、本体感知、文本指令。

### 3.2 真实世界 Benchmark：ALOHA

- 新构建的数据集：3 个任务套件、共 **21 个任务配置、1,064 条主任务示教** + 254 条额外双臂任务示教，总计 **1,318 条轨迹**：
  1. **Pick & Place**：单臂抓放（涉及 apple/corn/pen 等不同物体、不同左右手）；

### 3.3 对比方法

- **自回归上下文模仿基线**：ICRT、作者自实现的 ContextAR（与 ContextFlow 同样从 π0 初始化以保证公平）。

## 6. 主要结论与发现

1. **流匹配优于自回归**：在受控对比下（同样 backbone 与 π0 初始化），ContextFlow-Plain 比 ContextAR 在 unseen 任务上高 10.5 个百分点；引入压缩器后 ContextFlow 比 ContextAR 高 20 个百分点，比 ICRT 高 35 个百分点。
2. **示范 > 文本指令**：ContextAR 比仅用文本 prompt 的 OpenVLA-OFT 高 13.5 个百分点，证明多模态示教对 unseen 泛化关键。
3. **上下文学习 ≈ 任务专属微调**：ContextFlow（73.5%）与 π0 FT（72.5%）持平，但 ContextFlow **无需任何参数更新**，避免了微调带来的灾难性遗忘与额外开销。
4. **连续平行预测 > 离散串行预测**：MLP L1（58%）和 Flow Matching（73.5%）均超过 AR；Diffusion 在同等迭代下明显落后（33.5%），说明流匹配是当前最佳动作头选择。
5. **本体状态 + 动作**是最关键的示教模态，去除后 unseen 性能下降 44.5 个百分点；文本贡献相对较小但仍重要（−9.0）。
6. **累积误差更小**：ContextFlow-Plain MSE 3.0，ContextFlow 2.2，相比 ContextAR（4.7）显著降低。
7. **真实机器人**：单臂 unseen 平均 4/10，双臂 uncap-pen 4/10、put-egg-in-box 6/10；ICRT 在双臂精细任务上完全失败。
8. **扩大训练数据**可改善 Goal/Long-horizon-10 的 unseen 表现（平均从 36.8 提升到 43.0），但这两类任务仍接近 0%，说明当前方法的扩展性有限。

## 7. 方法与实验的亮点

- **首次将条件流匹配系统性地引入上下文模仿学习**，直接回避 AR 的两大固有问题（动作离散化 + 串行误差累积）。
- **perceiver 式多模态压缩器**针对机器人示教的高时空冗余定制，分别压缩图像、本体、动作三类流，是既降低计算量又提升性能的关键设计；可视化表明其学到任务相关、阶段自适应表征。
- **块式因果注意力 + 缓存**使推理时不必在每个流匹配步重算 context token，兼顾效率与精度。
- **公平对比设计**：构造 ContextAR 与 ContextFlow-Plain 两个 ablation 版本，控制 backbone、初始化、数据相同，专门隔离"AR vs Flow Matching"与"有无压缩器"两个变量。
- **真实机器人数据集贡献**：在 ALOHA 上同时覆盖单臂与高频率闭环双臂精细任务（uncap pen、put egg in box），弥补现有 in-context 模仿工作在此类设置下的不足。
- **鲁棒性测试**：主动扰动测试场景（物体位置、半截香蕉）证明模型对示教-测试状态差异具有鲁棒性。

## 8. 不足与局限

- **泛化范围有限**：作者明确指出当前方法只能在"共享相同原语"的 unseen 任务上泛化（如未见物体、空间摆放），**无法处理全新任务类型**；Goal 与 Long-horizon-10 unseen 任务成功率仍接近 0%。
- **未见任务多样性不足**：每套件仅 2 个 unseen 配置，每个 unseen 仅评估 50 次（仿真），统计强度有限。
- **真实机器人试验量小**：每配置 10 次试验，ICRT 真实实验数据有较多 0/10，难以得出统计显著结论；真实机器人评估未包含 π0 FT 这类微调基线（仅在仿真对比）。
- **未报告训练硬件配置**：仅给出 A100 GPU·小时，未说明 GPU 数量、并行策略等，实验可复现性受影响。
- **超参依赖性**：图像数从 4→8 提升 3 个百分点，但状态数 128 是经验最优值，缺乏敏感性曲线或更大范围扫描。
- **Diffusion 对比不充分**：仅跑了 100k 迭代，而 Flow Matching 在 20k 即可达更优性能，二者比较未控制总训练成本公平性。
- **模态贡献的解读**：本体+动作主导贡献（−44.5）远超其他模态，但未深入分析是状态序列还是动作序列在起作用，也未讨论是否与 π0 预训练数据分布有关。
- **风险与偏差**：仿真基于 LIBERO 标准划分（固定 unseen 配置），可能与现实分布差异较大；ICRT 在真实机器人上的全 0 失败可能部分源于实现细节而非方法本质，但论文未做消排。
- **应用限制**：依赖 π0 预训练权重与大规模机器人预训练数据，对小规模、低算力场景部署门槛较高；动作块长度 H=50 在更长 horizon 任务下是否仍有效未验证。
