## 摘要
长时序机器人操作任务在使用视觉-语言-动作（VLA）策略时仍然容易受到执行时偏差的影响，因为仅凭最终的任务成败难以诊断和修正由动作噪声、物体位移或目标错位引起的失败。我们提出了一种阶段感知的失败验证与提示恢复框架，能够在不更新参数或依赖特权仿真器状态的条件下对固定的VLA策略进行闭环纠错。该框架引入了一种基于可观测历史的习得验证器，通过时序建模多视角视觉观测、本体感知状态以及已执行动作，联合估计操作进度与执行风险。为了提供可解释的任务理解，我们将操作执行过程表示为语义进度阶段，包括接近、对齐、抓取、搬运和放置，并识别各阶段特有的失败模式。在检测到异常执行时，该框架保留原始指令并生成阶段条件化的恢复提示，使同一个冻结的VLA策略能够产生纠错动作。在LIBERO和LIBERO Plus上进行的广泛多轮评估表明，所提方法在多种扰动下显著提升了闭环可靠性。在不访问特权物体或目标坐标的情况下，习得验证器在所评估场景中取得了接近基于特权规则的验证器的恢复性能。这些结果表明，可观测的视觉-本体感知-动作历史足以推断潜在的任务状态，并使现有VLA策略实现切实可行的失败恢复。

## Abstract
Long-horizon robot manipulation with Vision-Language-Action (VLA) policies remains vulnerable to execution-time deviations, as final task success provides little information for diagnosing and correcting failures caused by action noise, object displacement, or goal misalignment. We introduce a stage-aware failure verification and Prompt Recovery framework that enables closed-loop correction of a fixed VLA policy without parameter updates or privileged simulator states. The framework introduces an observable-history-based Learned Verifier that jointly estimates manipulation progress and execution risk by temporally modeling multi-view visual observations, proprioceptive states, and executed actions. To provide interpretable task understanding, we represent manipulation execution through semantic progress stages, including approach, alignment, grasp, transport, and placement, and identify stage-specific failure patterns. Upon detecting abnormal execution, the framework preserves the original instruction and generates a stage-conditioned recovery prompt, allowing the same frozen VLA policy to produce corrective actions. Extensive multi-round evaluations on LIBERO and LIBERO Plus demonstrate that the proposed approach substantially improves closed-loop reliability under diverse perturbations. Without access to privileged object or goal coordinates, the Learned Verifier achieves recovery performance close to that of the privileged rule-based verifier in the evaluated settings. These results show that observable visual-proprioceptive-action history is sufficient to infer latent task states and enable practical failure recovery for existing VLA policies.

# VLA-Corrector 论文总结

## 1. 核心问题与研究动机

- **研究背景**：长时序机器人操控任务中，Vision-Language-Action（VLA）策略虽然能生成符合指令的动作，但缺乏对执行正确性的验证机制——"知道要做什么，却不知道做得对不对"。
- **关键痛点**：执行过程中，动作噪声、物体位移、抓取不完美、目标区域偏移等小偏差会逐渐累积，导致有效轨迹偏离；最终成败信号无法诊断具体失败原因，策略在不自知的情况下继续执行，往往无法自主恢复。
- **核心缺口**：现有VLA系统存在"动作生成"与"可靠具身智能"之间的鸿沟，缺少对**执行状态理解（execution-state understanding）** 的能力。
- **根本问题**：能否仅从**可观测交互历史**（而非特权仿真器状态）推断执行状态，并在不修改底层策略的情况下实现闭环纠错？

## 2. 方法论

### 2.1 整体框架
- **核心理念**：解耦"策略能力"与"执行可靠性"——VLA负责生成动作，验证器负责监控与恢复。
- **冻结基策略**：采用OpenPI的 `pi05_libero` 预训练策略，参数、视觉编码器、动作头均不更新。
- **双模块设计**：
  - **Learned Verifier**（可部署的执行状态理解模块）
  - **Prompt Recovery**（轻量闭环纠错接口）

### 2.2 关键公式与算法流程
- **观测定义**：`o_t = (I_a^t, I_w^t, s_t)`，其中 `I_a^t` 为代理视角图像、`I_w^t` 为腕部视角图像、`s_t ∈ R^8` 为本体感知状态。
- **历史定义**：`h_t = {(I_a^i, I_w^i, s_i, u_i)}_{i=0}^{t}`，严格按时间顺序，无未来信息泄露。
- **策略映射**：`U_t = π_θ(q, h_t)`，返回动作块，仅执行前5步后重新查询。
- **风险估计**：`p_t = Pr(f_t=1 | h_t)`，`f_t ∈ {0,1}` 为执行风险二值标签，`τ` 为阈值。
- **恢复提示**：`q_t^rec = q ⊕ r_t`，原始指令 `q` 保留，附加阶段路由恢复片段 `r_t`。

### 2.3 Learned Verifier 架构
- **视觉分支**：参数无关的空间统计特征器（3×4×4 adaptive-avg-pool + RGB均值/标准差），每视图54维，两视图拼接后投影至64维。
- **状态-动作分支**：15维向量（本体8维 + 动作7维）投影至32维。
- **时序融合**：GRU（隐藏维度64）整合8步窗口序列，每2个环境步采样一次。
- **双预测头**：
  - **风险头**：`p_t = σ(w_f^T z_t + b_f)`
  - **阶段头**：`ℓ_t^stage = W_stage z_t + b_stage`，输出5类非终止阶段（APPROACH, ALIGN, GRASP, MOVE, PLACE）。

### 2.4 教师监督与对齐
- 教师利用特权信息将执行进度转化为操作标签，而非直接回归特权坐标。
- 二值标签定义：`min|e - t| ≤ 10` 为正，`min|e - t| > 20` 为负，中间模糊区域排除训练。
- **关键设计**：阶段头仅作"路由"，非五类风险检测器。

### 2.5 在线触发门控
- 阈值 `τ = 0.40`，4帧连续确认，10步冷却。
- 低置信度（< 0.9625）回退至通用恢复提示（`UNKNOWN_FAILURE`）。
- 所有门控参数在验证集上确定并固定。

### 2.6 Prompt Recovery 接口
- 恢复提示模板：`q ⊕ "Immediate recovery: " + 阶段指令`。
- 恢复动作由同一冻结π0.5策略生成，结束后恢复原始指令 `q`。
- **设计优势**：策略冻结、仅通过指令增强实现纠错，无需策略微调或额外动作头。

## 6. 主要结论与发现

- **标准LIBERO成功率提升**：No Assistance 70.9% → Rule + Prompt 82.6%，**Learned Binary + Prompt 80.2%**（接近特权上界）。
- **LIBERO Plus d4**：Rule + Prompt 79.7%，Learned 79.0%（差距仅0.7pp）。
- **LIBERO Plus d5**：Rule + Prompt 73.6%，Learned 72.6%（差距仅1.0pp）。
- **扰动鲁棒性（标准LIBERO平均）**：No Assistance 81.14% → Rule + Prompt 88.12%（+6.98）→ Learned 86.88%（+5.74）。
- **Combined扰动下**：从70.7% → 82.6%（+11.7），从70.7% → 80.2%（+9.3）。
- **真实世界**：平均成功率从基线 82.5% → 88.3%（+5.8pp）。
- **验证器检测**：Accuracy 93.09%，Recall 94.85%，AUROC 0.902，AUPRC 0.7123。
- **核心结论**：可观测的视觉-本体-动作历史**足以推断潜在任务状态**，无需特权坐标即可实现与特权规则验证器接近的恢复性能。

## 7. 优点

- **非侵入式设计**：冻结VLA基策略，仅通过外部验证器+提示增强实现闭环纠错，无需微调或新增动作头。
- **可部署性**：Learned Verifier 仅依赖可观测输入（双视角RGB + 本体 + 动作），适合实际部署。
- **轻量高效**：子毫秒级推理延迟（p50 0.457ms），CPU即可运行。
- **解释性强**：将执行过程分解为5个语义阶段，提供可解释的进度估计与失败诊断。
- **消融系统**：分别评估时间历史、视角模态、状态-动作信息的贡献。
- **多场景验证**：同时覆盖仿真（多基准×多扰动）与真实世界三类任务。
- **理论贡献**：识别"执行状态理解"为VLA系统的基本缺失能力，并提出可行的解耦方案。
