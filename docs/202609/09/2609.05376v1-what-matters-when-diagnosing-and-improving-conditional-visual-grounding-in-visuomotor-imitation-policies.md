## 摘要
视动模仿策略在分布内视觉条件下可以取得高性能，但当引入视觉相似的物体或容器时则会失败。我们将这种行为视为条件视觉接地问题：成功控制所需的视觉目标随操作阶段而变化，在更复杂的任务中，还随观察到的任务状态而变化。我们使用带Transformer的动作分块方法（ACT），系统地引入具有可控颜色和形状相似度的干扰物和容器，并将失败定位到抓取和放置阶段。我们发现，干扰物敏感性同时取决于视觉相似性的类型和操作阶段。基于此诊断，我们评估了干扰物增强、阶段相关的注意力正则化，以及基于外观的视觉提示，作为改善目标选择同时保留控制所需空间信息的互补干预措施。这些干预措施显著提高了仿真中以及在物理UR3e机器人上的鲁棒性。我们进一步在一个预训练的视觉-语言-动作策略上，针对一个状态条件化的器械处理任务，检查了相同的失败模式，其中医疗器械的观察状态决定了正确的目标位置。综合来看，结果表明即使底层操作技能保持完好，视觉干扰物仍可能导致物体或目标位置选择错误，并且明确改进目标选择能够在不同的视动策略学习范式中显著恢复性能。

## Abstract
Visuomotor imitation policies can achieve high performance under in-distribution visual conditions yet fail when visually similar objects or receptacles are introduced. We study this behavior as a problem of conditional visual grounding: the visual target required for successful control changes with the manipulation phase and, in more complex tasks, with the observed task state. Using Action Chunking with Transformers (ACT), we systematically introduce distractor objects and receptacles with controlled color and shape similarity and localize failures to picking and placement. We find that distractor sensitivity is specific to both the type of visual similarity and the manipulation stage. Guided by this diagnosis, we evaluate distractor augmentation, phase-dependent attention regularization, and appearance-based visual prompting as complementary interventions for improving target selection while preserving spatial information required for control. These interventions substantially improve robustness in simulation and on a physical UR3e. We further examine the same failure pattern in a pretrained vision-language-action policy on a state-conditioned instrument-handling task, where the observed state of a medical instrument determines the correct destination. Together, the results show that visual distractors can cause incorrect object or destination selection even when the underlying manipulation skill remains intact, and that explicitly improving target selection can substantially recover performance across distinct visuomotor policy-learning regimes.

# 论文总结：条件视觉接地在视动模仿策略中的诊断与改进

## 1. 核心问题与整体含义

- **研究背景**：视觉模仿策略（如 ACT）在受控视觉条件下表现良好，但在部署场景中常因视觉相似干扰物（distractor）而失败。整体成功率指标无法区分两种本质不同的失败模式：
  - 操控技能本身退化；
  - 操控技能完好但目标选错。
- **核心问题**：将这种现象形式化为**条件视觉接地（Conditional Visual Grounding）**问题——当前应当关注的视觉参考物随操控阶段（picking / placing）甚至任务状态（VLA 场景下随器械状态）动态变化。
  - 对 ACT：在抓取阶段关注目标物体，在放置阶段关注目标容器。
  - 对 VLA：目标容器取决于观察到的医疗器械状态。
- **研究动机**：通过对失败进行阶段级定位（cue / referent / stage 三维归因），诊断视觉接地错误的根源，并据此设计针对性干预，从而在不同策略学习范式下提升鲁棒性。

## 2. 方法论

### 2.1 核心思想
- 借鉴视觉接地与视觉提示（visual prompting）的思路，将"目标选择"从隐式特征提取中显式化，通过干扰物增强 + 阶段注意力正则化 + 外观式视觉提示三种互补机制加强任务相关接地，同时保留控制所需的空间几何信息。

### 2.2 关键技术细节

- **ACT 框架上的可控干扰诊断**：
  - 设计两个仿真 pick-and-place 任务：Task 1（固定容器）和 Task 2（容器位置也随机化）。
  - 每个任务收集 100 条干净脚本演示训练 ACT。
  - 评估时引入颜色 / 形状匹配度可控的干扰物和干扰容器（1–3 个），full mixed 条件包含各类竞争者各一。
  - 拆解指标：端到端成功率、P(pick)、P(lift|pick)、P(place|pick, lift)，用于将失败定位到阶段。

- **三类互补干预机制**：
  1. **图像级 Copy-Paste 增强**：将合成干扰物粘贴到干净演示图像中，打破干扰物外观与动作之间的虚假相关性。
  2. **阶段相关注意力正则化**：监督解码器交叉注意力的特定头，使其聚焦于当前阶段相关目标并远离合成干扰物。训练损失为：
     - $L = L_{ACT} + \lambda_\phi L_\phi + \lambda_+(1 - \langle A, M_\phi\rangle) + \lambda_- \langle A, M_d\rangle$
     - 其中 $L_\phi$ 为阶段预测损失，$M_\phi$ 为阶段相关掩码，$M_d$ 为干扰物掩码，$A$ 为受监督头的归一化注意力。
  3. **外观式视觉提示（Appearance-based Visual Prompting）**：为目标物体和容器提供位置无关的裁切图，由联合训练的阶段预测器选择当前阶段对应的提示。仿真中使用特权分割，硬件上使用一次性人工标注 + SAM 2 自动分割。

- **ACT-Modified 架构**（图 1）：
  - 全景图与阶段选定的视觉提示分别经视觉编码器编码，进入 ACT 解码器的视觉记忆；
  - 阶段预测器决定使用对象提示还是容器提示；
  - 机器人本体感知（qpos）作为状态条件；
  - 解码器融合视觉记忆、学习到的查询、交叉注意力和位置嵌入，输出动作序列（action chunk）。

- **预训练 VLA 案例研究（π0.5）**：
  - 微调 π0.5 处理一个 7 步医疗器械处理流程（固定机位 + 腕部相机），含两个空间模糊的"路由"子目标；
  - 比较：(a) 提示训练检查点（关闭 vs 恢复 RGB 提示），(b) 正则化检查点（仅清洁 RGB + 显式左/右文本指令）；
  - 每子目标 5 次试验，共 75 次试验。

## 6. 主要结论与发现

- **ACT 失败具有 cue 特异性与阶段局部化**：
  - 对象选择对颜色最敏感（3 个颜色匹配干扰物使 P(pick) 从近 100% 降至 39.2%）；
  - 容器选择对形状最敏感（使条件放置成功率从近 100% 降至 33.9%）；
  - full mixed 干扰下端到端成功率：Task 1 = 39.5%，Task 2 = 14.0%；
  - 失败主要源于接地错误而非操控能力丧失，因为正确选择后的 lift / place 条件成功率仍保持 93–95%。
- **三类干预效果显著**：
  - DataAug：Task 1 100%，Task 2 64%（无需显式目标提示）；
  - ACT-Modified：Task 1 94.5%，Task 2 88.5%；
  - 物理 UR3e：标准 ACT 在干扰下 0/20 成功，ACT-Modified 13/20（Task 1）和 12/20（Task 2）；
  - 干净场景下三种方法性能相当，证明干预未损害操控能力。
- **表征层面的关键发现**：
  - 鲁棒性不仅要求对干扰物不变性，还需要保留任务相关几何结构（容器左右位置）；
  - DataAug 最不变但容器几何保留较弱，条件放置仅 66.3%；
  - ACT-Modified 容器几何保留最高，条件放置达 100%；
  - 目的地几何保留度与放置性能的关联强于纯不变性。
- **VLA 跨范式验证**：
  - π0.5 在路由子目标上的失败同样源于目标选择而非操控序列；
  - 提示训练模型去掉 RGB 线索时 20/25（缺口全部来自路由子目标 5/10→10/10）；
  - 提示与正则化都能恢复性能，验证了条件接地框架的跨范式适用性。

## 7. 优点 / 亮点

- **诊断驱动的研究范式**：将"整体成功率下降"拆解为 cue / referent / stage 三维归因，并匹配 P(pick)、P(lift|pick)、P(place|pick,lift) 的条件概率链，方法论上具有可推广性。
- **可控干扰设计**：颜色与形状匹配度的解耦使得可以分别定位对象选择与容器选择瓶颈，结果可信度较高。
- **三类互补干预的设计逻辑清晰**：增强（数据层面）、注意力正则化（特征层面）、视觉提示（输入层面）覆盖不同抽象层级。
- **多层级表征诊断**：从视觉编码器到 Transformer 记忆再到解码器状态，结合 t-SNE 可视化与定量指标（cosine shift、phase retention、container silhouette）。
- **因果性补充证据**：杯子选择探针直接干预提示身份，区分"提示与成功行为相关"vs"提示主动引导选择"。
- **跨范式适用性**：不仅验证 ACT，也在预训练 π0.5 上展示同一接地失效模式，框架具有迁移价值。
- **诚实报告局限**：作者主动声明颜色–形状层次依赖资产、硬件样本量小、VLA 条件信息量不等价等问题。

## 8. 不足与局限

- **资产特异性的颜色–形状层次**：观察到的"对象对颜色敏感、容器对形状敏感"依赖当前仿真资产集，需要在视觉因素完全均衡的数据集上进一步验证。
- **硬件评估样本量小**：仅 20 次/单元，难以做统计推断，仅能用于确认仿真趋势的硬件迁移性。
- **VLA 案例规模与条件不对称**：每子目标仅 5 次试验，且提示条件与正则化条件接收的信息量不同（前者为通用"高亮"指令，后者为显式左/右文本），作者明确说明二者不可直接比较。
- **VLA 任务结构局限**：使用可见污染代理而非通用污染理解，且为固定路由规则而非通用场景。
- **表征分析为相关性而非因果**：注意力图与特征位移被视为诊断而非机制解释，因果性结论主要依赖直接提示干预。
- **提示类变体接收额外目标信息**：虽然 DataAug-only 的结果证明不依赖显式目标提示也能获得大量鲁棒性增益，但 ACT-Modified 的优势无法完全归因于学习本身。
- **任务复杂度有限**：ACT 部分仅涉及单阶段 pick-and-place，尚未在多阶段长视野任务上验证条件接地的有效性。
- **算力信息披露不足**：未提供 GPU 型号、训练时长、超参数搜索规模等细节，复现成本难以估算。
