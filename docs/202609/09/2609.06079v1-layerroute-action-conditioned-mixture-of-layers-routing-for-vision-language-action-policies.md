## Abstract
Vision-Language-Action (VLA) policies leverage pretrained vision-language models (VLMs) to guide action generation for robot control. VLMs provide hierarchical visual-semantic representations that evolve across layers, from local visual geometry to abstract, language-aligned semantics; different manipulation tasks may therefore require different mixtures of layer representations. Meanwhile, the action module maintains intermediate representations that evolve throughout action computation and may provide useful information for subsequent decisions. However, existing VLA interfaces offer limited flexibility in representation access: VLM information is exposed through fixed layer assignments for each action layer, while intermediate action states are only propagated implicitly through residual streams without explicit reuse. We introduce LayerRoute, an action-conditioned representation routing interface that enables adaptive access to VLM layers and action representations. The Layer Mixture Router dynamically forms mixtures of cached VLM representations, while Action-State Reread reuses earlier action representations. Across diverse simulation and real-world benchmarks, LayerRoute consistently improves StarVLA-$π$ and $π_{0.5}$, achieving up to 7.2 gains on LIBERO Long with only 0.31% / 3.87% additional parameters. Ablation studies validate the benefit of action-conditioned layer routing, while routing analyses reveal structured allocation patterns across action layers and task settings.

# LayerRoute 论文总结

## 1. 核心问题与研究动机

- **背景**：视觉-语言-动作（VLA）策略通过预训练的视觉-语言模型（VLM）为机器人操控生成动作；近年来成为通用机器人策略的主流范式。
- **关键观察**：VLM 各层表征具有层次性——**浅层**对应局部视觉几何与纹理，**深层**对应抽象、语言对齐的语义。不同操控任务对这些特征的依赖差异显著：
  - 抓取定位、夹爪对齐、接触敏感放置 → 更依赖**细粒度视觉证据**；
  - 指令落地、对象角色消歧、子目标选择 → 更依赖**抽象语义表征**。
- **现有 VLA 接口的两层局限**：
  1. **VLM 深度访问固定**：动作层只能通过预先指定的固定层获取 VLM 表征，无法根据动作计算需要动态调整。
  2. **动作状态仅残差传播**：动作模块内部早期中间状态只能通过残差流间接访问，无法被后续层显式重用，长时域任务尤其受限。
- **研究意义**：突破"固定表示接口"是提升 VLA 策略灵活性的关键。

---

## 2. 方法论

### 2.1 整体思想
提出 **LayerRoute**，一个**动作条件化的表示路由接口**，包含两个互补模块：

| 模块 | 功能 |
|------|------|
| **Layer Mixture Router** | 跨 VLM 深度动态混合缓存表征 |
| **Action-State Reread** | 显式重用早期动作中间状态 |

### 2.2 Layer Mixture Router（动作条件化的层混合路由器）
- 缓存 VLM 在多个深度处的隐状态 $V_n \in \mathbb{R}^{B \times T_v \times D_v}$，$n \in \{0,\dots,N\}$；
- 在动作层 $s$：
  1. 对当前动作状态 $a^{(s)}$ 与每个候选 VLM 状态 $V_n$ 进行池化，得到紧凑摘要 $p_a^{(s)}$, $p_{V,n}$；
  2. 通过 LayerNorm + 投影矩阵 $W_q, W_k$ 映射到共享路由器空间（$d_{sel}=256$）：$q^{(s)}, k_n^{(s)}$；
  3. 计算缩放点积相似度 → softmax → 得到 VLM 深度分布 $\alpha_n^{(s)}$；
  4. 加权求和得到路由后的 VLM 表征 $\tilde V^{(s)} = \sum_n \alpha_n^{(s)} V_n$；
  5. 该表征替代原始编码器上下文，作为 cross-attention 的 KV。
- **关键特点**：同一动作层内的所有 VLM token 位置**共享同一深度分布**（样本级、层级别）。

### 2.3 Action-State Reread（动作状态重读）
- 每个动作层维护一个 **Action State Bank**，保存初始状态 + 早期块保留的状态；
- 在动作层 $s$，使用一个**可学习的层专属查询 $q_A^{(s)} \in \mathbb{R}^{D_a}$**；
- 对 token $t$ 计算其与各源状态 $A_{i,t}$ 的兼容性 → softmax → **token 专属权重** $\rho^{(s)}_{t,i}$；
- 加权求和得到重读状态 $\hat a^{(s)}$，输入到 FFN。
- **关键特点**：与 VLM 路由器不同，这里权重是 **token 级**的，反映每个 token 对早期状态的差异化需求。

### 2.4 在两个代表性 VLA 上的实例化

| 维度 | StarVLA-π | π0.5 |
|------|-----------|------|
| **VLM 主干** | Qwen3-VL | PaliGemma |
| **缓存深度** | [5, 11, 17, 23, 29, 35]（6 层） | [2, 5, 8, 11, 14, 17]（6 层，因果在线） |
| **动作模块** | 36 层 DiT，18 个 cross-attn + 18 个 self-attn | Flow-matching action expert，18 层 |
| **路由器接入** | 直接作为 cross-attn 上下文 | 通过 8-head action-to-VLM cross-attn adapter，残差更新后再进入原生 prefix/suffix joint attention |
| **动作状态重读** | 全部 36 个 DiT 块 | 全部 18 个动作层 |
| **附加参数** | **+0.31%** | **+3.87%** |
| **推理延迟** | +10.03% | +25.04% |
