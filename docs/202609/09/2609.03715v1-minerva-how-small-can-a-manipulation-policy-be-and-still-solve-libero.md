## 摘要
如今，拥有数十亿参数的视觉-语言-动作（VLA）模型在 LIBERO 操控基准上占据主导地位，但该基准实际所需的模型容量仍不清楚。我们提出了 MINERVA（MINimal Efficient Robotic Vision-Action policy，最小高效机器人视觉-动作策略），这是一个刻意设计得紧凑的视觉运动策略系列，旨在衡量这一任务特定的容量下限。一个仅含 0.54M 参数的策略在四个标准 LIBERO 套件上的 2,000 次展开中达到了 95.1% 的平均成功率，仅比已报告的 LeRobot $\pi_{0.5}$ 结果低 2.4 个百分点，而参数量却少了 7,700 倍。性能在参数接近 1M 时趋于饱和，在低于 0.25M 时崩溃。在广泛的架构、训练和推理扫描中，仅有动作块长度和视觉容量持续超过 $\pm$1 点的训练种子带宽。流匹配在三组种子下相比直接 L1 回归未表现出可检测的优势，而回归在 GPU 上最高可快 3.8 倍。任务 ID 排列探测显示，标准 LIBERO 指令条件化主要在已记忆的任务之间进行选择：仅改变任务 ID 映射就会使成功率降至接近随机水平。相同的方案在 89 个 LIBERO-90 任务上达到了 94.6% 的成功率，而 LIBERO-Plus 的扰动将性能降低到 46–56%，且对光度变化的鲁棒性近乎为零。该 0.54M 参数策略在笔记本 CPU 上每个块可在 5–9 毫秒内完成每一步的重规划，无需 GPU，比 SmolVLA 快 113 倍，比 $\pi_{0.5}$ 快 1,400 倍。这些结果首次为 LIBERO 的任务特定容量下限提供了经验估计，并推动了面向部署高效的机器人策略进行容量感知设计与蒸馏。

## Abstract
Vision-language-action (VLA) models with billions of parameters now dominate the LIBERO manipulation benchmark, but the model capacity actually required by the benchmark remains unclear. We introduce MINERVA (MINimal Efficient Robotic Vision-Action policy), a family of deliberately compact visuomotor policies designed to measure this task-specific capacity floor. A 0.54M-parameter policy achieves 95.1% average success over 2,000 rollouts on the four standard LIBERO suites, only 2.4 points below the reported LeRobot $π_{0.5}$ result despite using 7,700$\times$ fewer parameters. Performance saturates near 1M parameters and collapses below 0.25M. Across broad architectural, training, and inference sweeps, only action-chunk length and vision capacity consistently exceed a $\pm$1-point training-seed band. Flow matching provides no detectable advantage over direct L1 regression across three seeds, while regression is up to 3.8$\times$ faster on GPU. A task-ID permutation probe shows that standard LIBERO instruction conditioning primarily selects among memorized tasks: changing only the task-ID mapping reduces success to near chance. The same recipe achieves 94.6% success across 89 LIBERO-90 tasks, while LIBERO-Plus perturbations reduce performance to 46--56%, with near-zero robustness to photometric shifts. The 0.54M policy replans every control step in 5--9 ms per chunk on a laptop CPU, 113$\times$ faster than SmolVLA and 1,400$\times$ faster than $π_{0.5}$, without a GPU. These results establish a first empirical estimate of LIBERO's task-specific capacity floor and motivate capacity-aware design and distillation for deployment-efficient robot policies.

# MINERVA 论文结构化总结

## 1. 核心问题与整体含义（研究动机与背景）

- **核心问题**：LIBERO 操控基准目前由数十亿参数的视觉-语言-动作（VLA）模型主导，但**该基准本身实际需要多少模型容量**并不清楚。对于已部署的固定任务集机器人，**最小可行参数规模（empirical capacity floor）** 才真正决定部署成本（能否上边缘设备、CPU 是否够用、功耗预算等）。
- **研究意义**：把"多大的模型才够"从工程经验转化为可测量的实证量；并由此质疑：在标准 LIBERO 上报告的"~97% 分数"究竟衡量的是真正的多模态泛化能力，还是任务级别的记忆？
- **理论框架**：参照部署高效强化学习（deployment-efficient RL）以及信息论任务复杂度（policy information capacity）的思路，把"任务所需最小参数"视为任务集合的一个内禀量，可在环境、传感噪声、形态改变时重新测量。

## 2. 方法论

### 2.1 核心思想
- "**只放任务集真正用得上的东西**"——既然 LIBERO 标准评估是 40 个固定任务的记忆性测试（LIBERO-PRO 已论证），那么语言通路可以用 **40 项任务 ID 嵌入**代替，预训练 VLM 可以省略，只保留视觉编码与闭环动作生成。
- 通过 **逐级缩小容量**（9.7M → 4.9M → 0.99M → 0.54M → 0.24M → 0.09M）来定位"崩溃点"。

### 2.2 架构（MINERVA 家族）
- **感知**：两路相机视角（主视角与腕视角，256² → 144² → 128²）通过共享的**从头训练 CNN**（4 个 stride-2 阶段，深度可分离残差块 [26]），由任务嵌入经 FiLM [27] 调制；接 **spatial-softmax 关键点 [22]** 与线性投影；8 维本体感受状态由 2 层 MLP 编码；拼接成条件向量 c，使用 **n_obs = 2** 步观测历史。
- **动作头**：生成动作块 **a = a_{1:H}**，H=16，采用 **条件流匹配（conditional flow matching）[23]**：
  - 训练时采样 τ ~ Beta（偏向高噪声），插值 a_τ = τ a + (1-τ)ε，回归目标为常数速度 (a − ε)，损失 L_fm = ‖v_θ(a_τ, τ, c) − (a − ε)‖²₂。
  - 推理时从 ε ~ N(0, σ²I) 出发，做 10 步欧拉积分；σ 为初始噪声温度。
- **头结构**：4 层 DiT [24]（AdaLN-Zero 调制 MLP 在各块间共享），把 16 个动作 token 上的 **self-attention 替换为 MLP-mixer [25]**；可选的 L1 回归头走"learned queries in, chunk out, 单次前向"。
- **训练辅助**：仅训练时用一个小头（<9k 参数）预测 episode 进度，推理丢弃。
- **模型变体**：
  - MINERVA-0.5M (0.54M)：CNN 宽度 32/64/112/160，48 个关键点，头宽 96
  - MINERVA-1M (0.99M)：40/80/160/224, 64 关键点, 头宽 128
  - MINERVA-5M (4.89M)：恢复全宽 CNN 与头的 self-attention
  - MINERVA-10M (9.66M)：进一步取消 AdaLN 共享
- **知识蒸馏**：小模型用更大教师（冻结）的速度预测作为第二回归目标 L = L_fm + λ‖v_θ − v_φ‖²₂，λ=1；教师不计入参数量。

### 2.3 推理策略
- **每步重规划 + ACT 风格时间集成（temporal ensembling）[14]**：指数加权（衰减 0.01）平均所有覆盖当前时间步的块预测。
- **Mode-seeking 采样**：对亚 1M 模型，初始噪声温度 σ = 0.85，可加 0.2–2.3 分。
- 还系统比较了 BID 候选选择 [15]、RTC 软修复 [16] 与普通分块法。

### 2.4 任务 ID 排列探针（permutation probe）
- 固定所有权重，只**改写任务 ID 映射**：在套件内旋转 ID、或全部强制为套件内 task-0 ID，验证指令条件化的因果作用。

## 6. 主要结论与发现

- **容量下限**：标准 LIBERO 的经验容量下限约为 **0.5M 参数**；0.54M 模型平均成功率 95.05%（含 L1 头版本 95.75%），仅比 LeRobot 报告的 π0.5 (4.1B) 低 2.4 分。
- **饱和与崩溃**：性能在 ~1M 参数处饱和（0.99M 达 96.75%，与 9.66M 的 97.45% 只差 0.7 分）；**0.25M 以下崩溃**（0.24M → 88.6%，0.09M → 68.3%）。
- **崩溃结构**：长视野套件（Long）最先崩塌；0.24M 模型仍能解 95.2% 的 Spatial，但 Long 只剩 73.0%。短视野能力在小模型中存活得远多于长视野子目标链接能力。
- **唯一稳健的设计变量**：在 ±1 分种子带宽之外稳定有效的设计选择只有两个——**动作块长度**与**视觉容量分配**。
  - 块长效应不对称：块长 8 破坏 Goal 套件（86–89% vs 96.6–97.4%），块长 32 破坏 Long 套件（80–82% vs 87.6–92.8%），**块长决定牺牲哪一套**。
  - 视觉饥饿（0.13M）三种子复测 −1.41 分，Long 套件 −4.6 分。
- **流匹配 vs L1 回归**：三种子下 **L1 回归 +0.34 分（无显著差异）**，但推理只需 1 次前向而非 10 步欧拉，**GPU 上最高快 3.8×**；论文因此发布回归头版本。
- **预算分配规则**："**缩减动作头，而非视觉**"——在固定 ~1M 预算下，把视觉压到 0.13M 是不可逆的损失，但压缩动作头不影响。
- **任务条件化的因果性**：1M 模型权重固定后，仅重排任务 ID，平均成功率从 96.75% 跌至 **6.5%**；强制为 suite task-0 时 16.2%；Spatial/Goal/Long 几乎正好落在 1/10（Object 因场景视觉差异残留 22–36%）。
- **规模外推**：在 LIBERO-90（89 个任务，2.25× 任务量）上同配方 0.995M 模型达到 **94.6%**；共享 ID 的任务 93.6% vs 唯一 ID 任务 95.1%。
- **鲁棒性代价**（LIBERO-Plus）：0.54M/0.99M/4.89M 平均降至 46.7%/46.0%/55.7%；**光照鲁棒性在所有规模都近乎 0**（≤6.5%），证实"标准 LIBERO 不测量这种鲁棒性"。
- **部署速度**：0.54M 模型每块 CPU 8 线程 5–9 ms（≈5 ms 含 L1 头）；比 SmolVLA 快 **113×**，比 π0.5 快 **1,400×**；无需 GPU。
- **采样温度效应**：mode-seeking（σ=0.85）仅在 <1M 模型上稳定增益（0.2–2.3 分），≥1M 无收益。
- **整体定位**：论文主张 **报告超过 ~97% 的 LIBERO 分数不太可能衡量大模型真正带来的能力**；要测这些能力需要扰动式协议（如 LIBERO-PRO / LIBERO-Plus）。

## 7. 优点

- **明确的研究问题**："任务到底需要多少参数"是一个可测量、可操作化的问题；论文把它转化为一条清晰的容量-性能曲线。
- **极简且针对性的设计**：用 40 项任务 ID 嵌入替代语言通路，在机制层面呼应了 LIBERO-PRO 的"记忆化"诊断，而非泛泛而谈。
- **严谨的消融统计**：建立 ±1 分种子带宽并据此解读每条结论，是该基准上少见的统计严谨做法；显式区分"通过带宽"与"未通过带宽"两类消融。
- **丰富的诊断工具**：任务 ID 排列探针把相关性证据升级为因果证据；既给容量曲线也给扰动审计。
- **超低部署门槛**：CPU 上 5 ms / 块的端到端延迟，方法自然指向"嵌入式+规划器"的实际机器人集成场景。
