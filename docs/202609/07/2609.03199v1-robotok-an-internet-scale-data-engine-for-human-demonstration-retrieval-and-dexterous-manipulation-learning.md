## 摘要
机器人学习日益依赖广泛且多样的演示数据，然而机器人数据的采集成本高昂，难以覆盖现实任务中长尾分布的需求。为应对这一瓶颈，我们提出了 RoboTok——一种互联网规模的数据引擎，给定一段人类操作查询视频，即可从网络视频中检索与操作相关的人类演示，用于训练灵巧机器人策略。具体而言，我们从以估计的演员为中心的参考坐标系中表达的 3D 手部轨迹中学习一个潜在运动空间。该表征使得操作行为能够在摄像机视角、场景外观和演员遮挡等变化下进行比较，同时保持足够的紧凑性，以便在大规模互联网视频集合中进行高效搜索与持续索引。我们在检索基准和下游机器人策略性能上对 RoboTok 与现有机器人数据检索方法进行了对比评估。实验结果表明，RoboTok 能够检索到更具相关性的操作演示，并提升下游任务的成功率，确立了以手部姿态轨迹感知的检索方式，使网络视频成为机器人学习中可扩展且持续增长的监督来源。

## Abstract
Robot learning increasingly depends on broad and diverse demonstrations, yet collecting robot data remains expensive and poorly suited to covering the long tail of real-world tasks. To address this bottleneck, we introduce RoboTok, an internet-scale data engine that, given a query human manipulation video, retrieves manipulation-relevant human demonstrations from web videos for training dexterous robot policies. Specifically, we learn a latent motion space from 3D hand trajectories expressed in estimated actor-centered reference frames. This representation enables manipulation behaviors to be compared across variations in camera viewpoint, scene appearance, and actor occlusions, while remaining compact enough for efficient search and continual indexing over internet-scale video collections. We evaluate RoboTok against existing robot-data retrieval approaches on retrieval benchmarks and downstream robot policy performance. Our results show that RoboTok retrieves more relevant manipulation demonstrations and improves downstream task success, establishing hand-pose trajectory-aware retrieval as a way to make web video a scalable and continuously growing source of supervision for robot learning.

# RoboTok 论文详细总结

## 一、核心问题与研究动机

- **机器人数据采集瓶颈**：机器人学习（尤其是灵巧手操作策略训练）依赖大规模、多样化的演示数据，但真实机器人遥操作数据集（如 Open X-Embodiment、DROID、BridgeData V2）的采集成本极高，且难以覆盖真实世界任务、物体和环境的长尾分布。
- **网络视频的潜力与挑战**：互联网中持续增长的人类操作视频（如 Action100M、HowTo100M）蕴含极其丰富的操作行为，理论上可作为机器人学习的"无限"监督源；但这些视频存在任意视角、场景外观差异、人物遮挡等问题，且**视觉/语义相似并不等同于操作行为相似**。
- **本文要解决的关键问题**：如何在大规模、异构、无标签的互联网人类视频中，自动识别并检索与查询任务具有相似操作行为的演示片段，服务于灵巧手机器人模仿学习。这是首个面向互联网规模人类视频的演示检索框架。

## 二、方法论

### 1. 核心思想
- **核心洞察**：灵巧手部运动只有在相对于"演员"或被操作物体的参考系下表达时，才最具有操作语义意义。
- **做法**：从估计的演员（躯干）为中心的参考坐标系下的 3D 手部轨迹中，学习一个紧凑的潜在动作空间，使操作行为可跨视角、场景、外观、遮挡进行比较，同时支持高效向量检索与持续索引。

### 2. 数据处理流水线（Figure 2）
1. **候选片段筛选**：从 Action100M 中筛选 4–8 秒长、近似静态相机（Lucas–Kanade 检验）、最多双手出现、且手部可见的片段；贪心去重叠，保留较长片段。
2. **3D 手部关键点提取**：以 5 fps 使用 **WiLoR** 估计 21 关节手部关键点，并在帧间链接以稳定左右手标识。
3. **度量尺度恢复**：WiLoR 在弱透视相机模型下重建手部，使用 **MoGe-2** 估计度量深度，将其变换到度量相机坐标系。
4. **缺失值填补**：使用 **HaWoR** 对缺失手部姿态进行补全。
5. **以自我为中心的轨迹表示**：训练一个轻量级躯干帧估计器，仅以手腕轨迹为输入（**不要求人体可见**），按 SMPL-H 模型预测演示者的静态躯干坐标系，将手部轨迹转换到该参考系。

### 3. 检索模型学习
- **相似度度量（监督信号）**：使用 **动态时间规整（DTW）** 在归一化的 egocentric 3D 手姿态轨迹上计算长度归一化负对齐代价 $s(i,j) = -\frac{\text{DTW}(x_i, x_j)}{(L_i+L_j)/2}$，作为运动相似性"伪真值"oracle。
- **学习目标**：训练一个编码器 $\Gamma: \mathcal{X} \to S^{d-1}$，使得内积相似度保持 DTW 排序：$s(i,j) > s(i,k) \Rightarrow \langle \Gamma(x_i), \Gamma(x_j) \rangle > \langle \Gamma(x_i), \Gamma(x_k) \rangle$。
- **编码器**：轻量级 cross-attention 轨迹编码器，每帧做位置编码，池化后得到 ℓ2 归一化的 $d$ 维嵌入。
- **批次构造**：以 anchor 为中心，对每个 anchor $a$ 取 DTW 下 top-K=20 邻域 $R(a)$，从中采样 2 个正样本 $p_1, p_2$ 与 1 个"边界负样本" $n$（top-K 之后立即出现的轨迹），组成 $G(a)=\{a, p_1, p_2, n\}$；每批 49 组，共 196 条轨迹。
- **损失函数**：组合损失 $\mathcal{L} = \mathcal{L}_{\text{set}} + \lambda \mathcal{L}_{\text{rank}}$：
  - $\mathcal{L}_{\text{set}}$：鼓励 oracle top-K 邻域的得分高于边界及负样本（决定谁进入邻域）。
  - $\mathcal{L}_{\text{rank}}$：鼓励采样正样本之间的相对排序匹配 DTW 排序（决定邻域内排序）。
- **推理（两阶段）**：
  - **离线**：所有 egocentric 轨迹经编码器一次前向计算，构建内积索引。
  - **在线**：查询片段编码后，通过余弦相似度做最近邻搜索，无需对全语料计算 DTW。
  - 新片段可直接编码加入索引，**无需重新训练**，支持持续扩展。

## 六、主要结论与发现

1. **检索质量大幅领先**：在 RoboTok 评估语料上，RoboTok mAP@20=0.353（vs STRAP 0.007、HAND 0.0009），Recall@20 接近 0.996；Kendall τ=0.487 表明排序也基本正确。
2. **跨数据集迁移有效**：在 AssemblyHands 上 mAP@5=0.261（vs STRAP 0.133），证实 actor-relative 3D 手部轨迹表示可跨域泛化。
3. **对原始 VTDexManip**：6 个任务中 5 个超过 VT-JointPretrain，平均提升 seen +7.45%、unseen +5.83%。
4. **对 HARDER 版本提升尤为显著**：瓶盖旋转 +17.8%、水龙头拧动 +38.0%、杠杆滑动 +59.8%（对次优方法 HAND），且训练收敛更快。
5. **关键论断**：actor-centered 3D 手部轨迹感知检索，能够将互联网视频转化为可扩展且持续增长的机器人学习监督源。

## 七、优点与亮点

- **🎯 视角无关的运动表示**：用仅依赖手腕轨迹估计的躯干坐标系来规范 3D 手部轨迹，无需人体或物体直接可见，鲁棒且实用。
- **🔍 无需语义/标签**：检索完全基于运动相似度，不需要文本标签或视觉外观匹配，规避了"视觉相似≠操作相似"的核心难题。
- **⚡ 可扩展架构**：昂贵的 DTW 计算只在训练时进行；推理阶段仅做内积检索，新数据可即插即用，无需重训。
- **📊 全面且公平的对比**：在两个语料、多种指标、多个基线、原始与 HARDER 双重设定下验证，结论可信度较高。
- **🤖 直接下游验证**：不只评估检索指标，还端到端训练 PPO 策略评估对机器人学习的实际增益，体现"实用价值"。
- **🌐 互联网规模定位**：明确将网络视频作为持续扩展的监督源，定位与传统机器人数据集互补。

## 八、不足与局限

- **相机运动假设**：当前仅支持**近似静态相机**视频；移动相机（第三人称、动态 egocentric）是显式留待未来工作的方向。
- **HARDER 任务覆盖有限**：仅 3 个任务在更难设置下评估，结论的全面性受限。
- **部分任务上未稳定领先**：Bimanual Hand-over 在 unseen 物体上低于 Base 与 HAND，提示对双手交接等复杂协调任务仍可能不足。
- **伪真值依赖 DTW**：训练目标与评估真值均基于 DTW，可能引入 oracle 偏差；AssemblyHands 上的传感器级 GT 提供一定外部校准，但样本量较小（N=831），统计显著性有限。
- **检索空间仅为"手部轨迹"**：完全忽略物体、接触、力/触觉、任务语义等丰富信息，可能丢失需要物体交互理解的任务相关性。
- **算力与训练细节缺失**：未报告 GPU 型号、数量、训练时长、数据处理流水线各阶段耗时，**复现性受限**。
- **下游评估在仿真中**：PPO 引导的策略实验仅在 VTDexManip 仿真环境完成，缺乏真实机器人实验与跨 embodiment（如不同灵巧手形态）验证。
- **Action100M 来源偏差**：作为互联网视频语料，存在地域、文化、任务类型分布偏差，可能影响长尾覆盖的实际效果，文中未做偏差分析。
- **检索"相关"的定义由 DTW 决定**：DTW 适合度量运动学相似，但能否完全对齐"对下游机器人有用的演示"仍存隐式假设。
