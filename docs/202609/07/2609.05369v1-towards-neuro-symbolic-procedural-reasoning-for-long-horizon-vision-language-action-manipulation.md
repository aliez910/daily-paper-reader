## 摘要
视觉-语言-动作（VLA）模型能够执行短时操作技能，但在需要持续任务状态、依赖感知推理、条件决策以及可靠定位的长时序流程中仍然十分脆弱。我们研究了一种神经-符号框架，将学习得到的VLA控制与显式任务图以及多模态过程记忆相结合。任务图编码动作依赖关系、有效转移与分支条件，而记忆则维护当前活动步骤、已完成动作、文本上下文以及任务相关的视觉证据。这些结构共同指导物体选择、目标位置定位、子目标调度以及期望状态转移的验证。人类演示通过注视或显著性线索提供额外的空间与时间引导。为单独评估其对策略学习的影响，我们初步研究绕过了跨视角注视迁移，直接在机器人视角的遥操作视频中对伪注视进行标注。所得到的引导信息用于VLA的微调与推理过程。我们研究了两个长时序操作领域——工作空间清理与手术器械处理，它们需要有序执行、基于视觉的决策以及条件分支。我们评估了正确物体与目标位置的选择、子任务完成度、任务进度、步骤顺序一致性、完整任务成功率以及过程或执行错误。本工作将结构化符号推理与源自演示的视觉引导视为可靠的VLA长时序操作的互补机制。

## Abstract
Vision-language-action (VLA) models can execute short manipulation skills, but remain brittle in long-horizon procedures requiring persistent task state, dependency-aware reasoning, conditional decisions, and reliable grounding. We investigate a neuro-symbolic framework that combines learned VLA control with explicit task graphs and multimodal procedural memory. Task graphs encode action dependencies, valid transitions, and branch conditions, while memory maintains the active step, completed actions, textual context, and task-relevant visual evidence. Together, these structures guide object selection, destination grounding, subgoal dispatch, and verification of expected state transitions. Human demonstrations provide additional spatial and temporal guidance through gaze or saliency cues. To isolate their effect on policy learning, our initial study bypasses cross-view gaze transfer and directly annotates pseudo-gaze in robot-view teleoperation videos. The resulting guidance is used during VLA fine-tuning and inference. We study two long-horizon manipulation domains, workspace clearing and surgical-instrument handling, which require ordered execution, visually grounded decisions, and conditional branching. We evaluate correct-object and destination selection, subtask completion, task progress, step-order consistency, complete-task success, and procedural or execution mistakes. This work positions structured symbolic reasoning and demonstration-derived visual guidance as complementary mechanisms for reliable long-horizon VLA manipulation.

# 论文总结：面向长时序 VLA 操作的神经-符号程序推理

## 1. 核心问题与研究动机

- **核心问题**：现有视觉-语言-动作（VLA）模型（如 OpenVLA、π0.5）虽能执行短时操作技能，但在**长时序程序性任务**中表现脆弱，缺乏对持续任务状态、动作依赖关系、条件分支决策以及可靠视觉对齐的建模能力。
- **深层矛盾**：VLA 端到端策略擅长"低层控制"（how），但缺乏对"高层任务结构"（what happens next）的显式推理；纯符号规划则难以处理连续视觉控制。
- **研究目标**：将**显式符号任务结构**（任务图 + 事件记忆）与**学习的 VLA 控制**相融合，并通过演示衍生的视觉显著性（saliency）增强空间定位可靠性，从而在长流程任务中实现可靠操控。

## 2. 方法论

### 2.1 整体框架：observe–ground–remember–choose–execute–verify 循环

| 模块 | 作用 |
|---|---|
| 任务图 G=(V,E) | 编码动作依赖、前后置条件、分支条件、执行者角色 ρ（机器人/人类/其他智能体） |
| 事件记忆 M_t | 追加式记录决策、观察到的状态转移、视觉证据 |
| VLM 推理器 | 根据图与记忆选择/验证下一子目标 |
| VLA 执行器（π_θ） | 由图决定 "what"，由 VLA 决定 "how" |
| 感知模块 | 固定全局相机 + 腕部相机，用于状态转移验证 |

### 2.2 关键数学形式化

- **节点定义**：每个节点 v_i = (ℓ_i, ρ_i, P_pre, P_succ, P_fail, z_i)，包含指令、执行者角色、可视化验证条件、状态。
- **机器人节点的动作生成**：
  
  $$\hat{A}_t = \pi_\theta(I_t^b, I_t^w, q_t, \ell_i)$$
  
  其中 I^b 为全局视图，I^w 为腕部视图，q_t 为状态，ℓ_i 为当前子目标指令。

- **多智能体协作**：人类完成的协作动作作为外部事件更新记忆并可触发后续机器人节点。

### 2.3 稀疏程序显著性（Sparse Procedural Saliency）

- **标注方式**：在每个引导子目标的一条代表性基座相机轨迹上标注时变伪注视点 g_t（绕过跨视角真实注视迁移）。
- **特征与跟踪**：DINOv2 特征 + 金字塔 Lucas-Kanade 光流稳定化，用于跨演示迁移与时间对应。
- **两种策略接口**：
  1. **Prompt-as-input**：在 RGB 图像上渲染洋红色空心环 R(I^b_t, g_t)，作为视觉提示。
  2. **Prompt-as-supervision**：将 g_t 转为 token 级目标分布 G_t，对动作条件注意力 S_t 做 KL 散度正则化：
     
     $$\mathcal{L}_{reg} = \mathcal{L}_{act} + \lambda D_{KL}(G_t \| S_t)$$
     
     推理时使用干净图像（无环提示）。

### 2.4 论文自身定位
- 当前为**初步研究**（initial study），主要评估显著性引导对策略学习的影响；端到端神经-符号管线的完整评估留待未来工作。

## 6. 主要结论与发现

1. **两种显著性机制均能完成所有 25/25 次试验**（在带提示或带正则化条件下），相比去掉提示环时的 5/10 容器路由成功率有显著提升。
2. **失败模式集中于"目标位置错放"**（wrong-destination placements），提示环的移除直接导致空间模糊场景下的定位失败。
3. **两种机制行为等价但机理不同**：
   - 提示环：在部署时保留可见空间线索。
   - 注意力正则化：将监督内化，推理时无需任何视觉覆盖。
4. **基座相机单独已足够**——可能因为全局视图消解了空间歧义，腕部视图负责近距离控制。
5. **当前已触及性能天花板**，下一步应转向**泛化能力评估**（反转源-目的几何、独立移动物体与容器、保留场景测试、相机扰动）。
6. 论文自我定位：**符号结构决定 "what happens next"，稀疏视觉引导改善 "how 当前子目标被对齐"**，二者是互补机制。

## 7. 优点与亮点

- **方法论视角清晰**：将"高层任务结构"与"低层连续控制"显式分离，提供了可解释的神经-符号分层架构。
- **两种显著性接口的设计**：prompt-as-input 与 prompt-as-supervision 的对比视角新颖，覆盖了"外部可解释"与"内部内化"两种部署哲学。
- **标注策略务实**：绕开跨视角真实注视迁移难题，先用伪注视隔离变量，为后续真实注视迁移留出接口。
- **多智能体协作建模**：任务图中显式包含人类角色 ρ_i 与外部事件，体现对协作场景的考虑。
- **诊断可视化**：注意力热力图为策略行为提供了可解释的定性证据。
- **问题域选择有意义**：手术器械处理任务真实、需求迫切，对自动化具有应用价值。

## 8. 不足与局限

### 8.1 实验层面
- **样本量过小**（75 次试验），统计效力不足。
- **任务覆盖不完整**：声称研究两个长时序领域（工作空间清理、手术器械处理），但仅报告了一个领域的真实机器人结果。
- **泛化测试缺失**：未做保留场景、独立物体、反转几何、相机扰动等关键鲁棒性实验。
- **无外部基线对比**：未与 SayCan、Inner Monologue、LoHoVLA、TraceVLA、OpenVLA-OFT 等方法在相同任务上对比。
- **得分饱和**导致两种机制难以区分。

### 8.2 方法层面
- **端到端管线未评估**：任务图调度、记忆更新、转移验证、恢复机制等核心组件**未在真实机器人上闭环测试**。
- **伪注视的限制**：当前方法仅在演示中"复现"空间关系，**不能将显著性重定向到未见坐标**；跨视角真实注视迁移尚未实现。
- **基座相机依赖**：论文承认尚未将几何显著性迁移到腕部坐标。
- **可扩展性疑问**：当任务图节点大幅增加、跨多个物体类别与分支时，VLM 推理器的开销与可靠性未讨论。

### 8.3 应用层面
- **手术场景的临床转化距离远**：真实手术环境的器械多样性、光照、遮挡、刚性约束等远超实验室遥操作。
- **对人工标注的依赖**：伪注视需手工标注，难以规模化。
