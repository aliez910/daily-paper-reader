## 摘要
视觉运动模仿策略在分布内视觉条件下能够取得高性能，但在引入视觉相似的物体或容器时则会出现失败。我们将这一行为视为条件视觉定位问题加以研究：成功控制所需的视觉目标随操作阶段而变化，在更复杂的任务中还会随所观察到的任务状态而变化。我们使用基于Transformer的动作分块方法（ACT），系统性地引入具有受控颜色与形状相似度的干扰物体和容器，并将失败归位于抓取与放置阶段。我们发现，干扰物敏感性既取决于视觉相似度的类型，也取决于操作阶段。在这一诊断的指导下，我们评估了干扰物增强、阶段相关的注意力正则化以及基于外观的视觉提示作为互补性干预手段，用以改善目标选择，同时保留控制所需的空间信息。这些干预在仿真与物理UR3e平台上均显著提升了鲁棒性。我们进一步在预训练的视觉-语言-动作策略上，于一项以状态为条件的器械操作任务中检验了相同的失败模式，其中医疗器械的观察状态决定了正确的目的地。综上，结果表明，即使底层操作技能完好，视觉干扰物仍可能导致错误的物体或目的地选择，而显式地改善目标选择能够在不同的视觉运动策略学习范式下显著恢复性能。

## Abstract
Visuomotor imitation policies can achieve high performance under in-distribution visual conditions yet fail when visually similar objects or receptacles are introduced. We study this behavior as a problem of conditional visual grounding: the visual target required for successful control changes with the manipulation phase and, in more complex tasks, with the observed task state. Using Action Chunking with Transformers (ACT), we systematically introduce distractor objects and receptacles with controlled color and shape similarity and localize failures to picking and placement. We find that distractor sensitivity is specific to both the type of visual similarity and the manipulation stage. Guided by this diagnosis, we evaluate distractor augmentation, phase-dependent attention regularization, and appearance-based visual prompting as complementary interventions for improving target selection while preserving spatial information required for control. These interventions substantially improve robustness in simulation and on a physical UR3e. We further examine the same failure pattern in a pretrained vision-language-action policy on a state-conditioned instrument-handling task, where the observed state of a medical instrument determines the correct destination. Together, the results show that visual distractors can cause incorrect object or destination selection even when the underlying manipulation skill remains intact, and that explicitly improving target selection can substantially recover performance across distinct visuomotor policy-learning regimes.

# 论文总结：视觉运动模仿策略中条件视觉定位的诊断与改进

## 一、核心问题与研究动机

- **核心现象**：基于视觉的模仿学习策略（如 ACT、VLA）在训练分布内（clean 场景）可达到接近 100% 的成功率，但在部署时若出现与目标视觉相似的干扰物（distractor），成功率会大幅下降。
- **关键区分**：聚合成功率下降并不能区分两种失败原因——
  1. 策略丧失了操控执行能力（motor skill loss）；
  2. 操控技能仍然完好，但对**错误的目标实体**施加了正确动作。
- **核心概念**——**条件视觉定位（Conditional Visual Grounding）**：在候选参照集合 $R_t$、指令 $\ell$ 与执行上下文 $c_t$ 给定时，正确的动作需要选择上下文相关的参照 $r^\star_t \in R_t$。该参照并非静态：
  - **ACT 任务中**：与操作阶段（phase）相关——抓取阶段关注物体（object），放置阶段关注容器（receptacle）；
  - **VLA 任务中**：与观察到的器械状态相关——状态决定正确目的地。
- **研究问题**：视觉失败能否被定位到具体的线索、参照物和执行阶段？这一诊断能否指导有效的干预措施？
- **研究意义**：将"分布外鲁棒性差"这一笼统问题拆解为"目标选择"与"控制执行"两个子问题，从而设计更精准的修复策略。

## 二、方法论

### 1. ACT 受控诊断
- **两个仿真抓放任务**：
  - Task 1：物体随机放置，容器固定；
  - Task 2：物体与容器位置均随机，需要在抓取与放置两个阶段都进行视觉定位。
- **训练数据**：每任务 100 条干净脚本演示；
- **干扰物设计**：通过改变颜色（color-matched）、形状（shape-matched）相似度，控制 1–3 个干扰物/类；Full mixed condition 包含每类一个干扰物。
- **失败定位指标**：除端到端成功率外，还测量
  - $P(\text{pick})$：正确抓取概率；
  - $P(\text{lift}|\text{pick})$：抓取后成功抬起概率；
  - $P(\text{place}|\text{pick},\text{lift})$：抬起后正确放置概率。

### 2. 三种诊断驱动的干预机制（ACT-Modified）
- **（A）图像空间 Copy-Paste 增强**：在干净演示中合成插入干扰物，削弱偶发外观相关性。
- **（B）阶段相关注意力正则化**：监督 Transformer 解码器的一个 cross-attention head，使其当前阶段应聚焦的目标 / 容器 mask $M_\phi$ 对齐，并远离干扰物 mask $M_d$。
- **（C）基于外观的视觉提示（Visual Prompting）**：提供目标物体 / 容器的位置无关裁剪（positionless crops），由阶段预测器在执行时选择合适的提示；硬件上提示通过人工初始标注 + SAM 2 分割获得。
- **总损失函数**：

$$
\mathcal{L} = \mathcal{L}_{\text{ACT}} + \lambda_\phi \mathcal{L}_\phi + \lambda_+ (1 - \langle A, M_\phi \rangle) + \lambda_- \langle A, M_d \rangle
$$

  其中 $A$ 为受监督 head 的归一化注意力，$\mathcal{L}_\phi$ 为阶段预测损失。

- **架构示意（Figure 1）**：全帧观察 + 阶段选定的视觉 prompt 经视觉编码器编码后输入 ACT Transformer 解码器；阶段预测器选择 prompt；机器人本体感知（qpos）提供状态条件；动作序列编码器与 CLS 潜在路径在训练时形成 CVAE 后验，推理时固定为 $z=0$。

### 3. 预训练 VLA 案例研究
- **模型**：对 $\pi_{0.5}$ 进行微调；
- **数据**：231 条遥操作片段，含固定基座与腕部相机；
- **任务**：7 步器械处理流程，5 个子目标评估（含 2 个空间模糊的路由子目标，正确目的地取决于器械观察状态）；
- **评估**：每子目标、每条件 5 次试验，共 75 次。

## 三、实验设计

### 仿真 ACT 实验
- **场景**：两个 pick-and-place 仿真任务（Task 1、Task 2）；
- **基准（benchmark）**：clean 场景与多种受控干扰物配置（颜色匹配、形状匹配、混合）；
- **对比方法**：
  - Standard ACT（基线）；
  - Augmentation only（仅 Copy-Paste 增强）；
  - ACT-Modified（增强 + 注意力正则化 + 视觉提示）。

### 真实硬件实验
- **平台**：UR3e 机械臂；
- **任务**：与仿真相同的 Task 1、Task 2；
- **样本量**：每个 cell 20 次试验（clean 与 full mixed distractors）。

### VLA 案例研究
- **任务**：器械处理流程中的 5 个子目标；
- **对比**：prompt-trained $\pi_{0.5}$ checkpoint（有/无预期 RGB 线索）vs. 正则化 clean-input checkpoint；
- **样本量**：75 次试验（5 trials × 5 subgoals × 3 conditions）。

### 表示层诊断（Table II）
- **对象**：Standard ACT / DataAug / Modified 在视觉编码器、Transformer 记忆、解码器状态上的对比；
- **指标**：
  - Place shift：放置阶段 clean→full 余弦距离；
  - Phase retained：full→clean 抓/放质心分离度；
  - Container silhouette：full-distractor 容器位置轮廓；
  - Conditional placement：条件放置成功率。

## 五、实验数量与充分性

### 数量
- **仿真**：每 cell 600 次 rollout（Task 1/2 × 各方法 × clean/干扰条件），3 个训练种子，结果统计较稳健；

## 六、主要结论与发现

- **ACT 失败是 cue-specific 与 stage-localized**：
  - 颜色匹配干扰物主要损害 $P(\text{pick})$（Task 2 中降至 39.2%），而 $P(\text{lift}|\text{pick})$ 与 $P(\text{place}|\text{pick},\text{lift})$ 保持高位；
  - 形状匹配干扰物主要损害条件放置（降至 33.9%），$P(\text{pick})$ 几乎不受影响；
  - Full mixed distractors 下，端到端成功率从近 100% 跌至 Task 1 的 39.5% 和 Task 2 的 14.0%；
  - 失败本质上是"目标选择错"，而非"操控技能丧失"。
- **物体中心干预显著恢复鲁棒性**：
  - Augmentation only：Task 1 100.0% / Task 2 64.0%（仿真）；
  - ACT-Modified：Task 1 94.5% / Task 2 88.5%（仿真）；硬件上 mixed distractors 下从 0/20 提升至 13/20 与 12/20。
- **鲁棒表征需要"不变性 + 几何保持"**：
  - DataAug 比 Modified 更"不变"（shift 0.0011 vs 0.0125），但其容器位置几何保留更弱（0.0889 vs 0.2037），条件放置率仅 66.3% vs 100.0%；
  - 结论：**目的地几何的保持与放置性能的相关性强于单纯的不变性**。
- **因果证据**：将目标 prompt 替换为 distractor prompt，使 distractor 选择率从 0–1% 跃升至 35–91%，证明 prompt 身份能主动引导闭环选择，而非仅与成功行为相关。
- **VLA 案例研究的跨范式证据**：
  - 移除预期 RGB 线索时，prompt-trained $\pi_{0.5}$ 整体 20/25，所有失败集中在两个路由子目标（5/10），其他子目标不受影响；
  - 恢复线索或使用正则化变体均达 25/25（含路由 10/10）；
  - 失败再次定位于"上下文相关目的地的选择"，而非操控执行。

## 七、优点与亮点

- **诊断框架清晰**：将"分布外失败"拆解为"目标选择 vs. 操控执行"两个维度，并提出"何时何物重要"（What matters, when?）的视角；
- **受控实验设计严谨**：通过颜色 / 形状相似度的正交控制，能够精细区分 cue-specific 与 phase-localized 失败；
- **多层次诊断结合**：行为级（成功率分解）+ 表示级（decoder state 几何）+ 因果级（prompt 替换）三层证据相互印证；
- **互补干预设计**：增强、注意力正则化、视觉提示三种机制分别针对外观相关性、注意力聚焦、外观线索三个层面，构成可组合的工具箱；
- **跨范式适用性**：ACT 与预训练 VLA 上均观察到相同的"目标选择错"模式，框架具有一定通用性；
- **公平性意识**：明确区分 prompt-bearing 与 non-prompt 变体，避免不当对比；
- **物理验证**：在 UR3e 上验证了仿真中观察到的行为排序，而非仅停留于仿真。

## 八、不足与局限

- **资源披露不全**：未提供 GPU 型号、训练时长、推理延迟等算力信息，限制可复现性评估；
- **硬件样本量小**：UR3e 每 cell 仅 20 次试验，难以做精细统计分析；
- **VLA 实验规模与可比性**：仅 75 次试验；prompt 与正则化条件接收的指令不等价，作者承认不可直接比较，仅能提供"趋同行为证据"；
- **颜色–形状层级结论的普适性有限**：作者明确指出该层级基于所评估的素材资产，需在视觉因子完全反平衡的数据集上进一步验证；
- **prompt-bearing 变体的信息优势**：虽然有 augmentation-only 对照，但 Modified 仍额外接收目标外观信息，可能高估其在无额外提示场景中的实际可用性；
- **注意力与表示分析的因果性弱**：作者明确承认这些分析是**相关性**而非因果解释，因此引入 prompt 替换作为因果补充，但仍属间接证据；
- **VLA 任务使用可见污染代理**：并非真实的污染理解；且器械处理使用固定路由规则而非通用污染理解；
- **跨架构结论的边界**：作者强调 ACT 与 $\pi_{0.5}$ **并未被证明共享同一内部捷径**，案例研究仅提供"框架可用"的初步证据；
- **失败定位的资产依赖**：所提出的阶段定位与 cue-specific 结论可能在其他视觉素材、相机视角或任务结构下有所不同，泛化能力需进一步验证。
