## 摘要
视觉-语言-动作（VLA）或世界动作（WAM）模型最近在机器人操作中展现出卓越的性能。在 LIBERO 基准上，最先进的方法已取得接近 100% 的成功率，看似表明这些模型已具备实际部署的条件。然而，在现有基准上近乎完美的表现可能具有误导性：理想条件下的成功并不等同于真实世界中的鲁棒性。现有基准主要评估从预定义初始状态开始的任务完成情况，而真实世界中的交互不可避免地会遇到各种失败，例如抓取失败、碰撞以及物体意外移动。因此，机器人不仅需要成功执行任务，还需要识别并从失败中恢复以继续完成任务。然而这一能力在很大程度上尚未被衡量，揭示了基准性能与真实世界可靠性之间的关键差距。为弥补这一差距，我们提出了 LIBERO-Recover 基准，一个面向机器人操作中失败恢复的大规模基准。该基准建立在 LIBERO 之上，收集了来自最先进具身模型的真实执行失败，并构建了 1000 多个涵盖四个恢复层次的场景：(1) 动作重试，(2) 动作适应，(3) 物体状态恢复，以及 (4) 环境恢复。我们评估了四项核心能力：空间理解、物体结构推理、交互理解以及拓扑推理。作为首个面向具身失败恢复的大规模基准，LIBERO-Recover 将评估从"机器人能否成功？"转变为"机器人在失败后能否恢复？"，致力于推动鲁棒且可泛化的具身智能体的发展。项目将在 https://liulin815.github.io/LIBERO-Recovery/ 公开。

## Abstract
Vision-Language-Action (VLA) or World Action (WAM) models have recently demonstrated remarkable performance in robotic manipulation. On LIBERO, SOTA method have achieved nearly 100\% success rates, seemingly suggesting that the models are ready for deployment in real world. However, near perfect performance on existing benchmarks can be misleading: success under ideal conditions does not imply real world robustness. Existing benchmarks primarily evaluate task completion from predefined initial states, while real world interactions inevitably involve failures such as failed grasps, collisions, and unintended object movements. A robot must therefore not only execute tasks successfully, but also recognize and recover from failures to continue the task. Yet this capability remains largely unmeasured, revealing a critical gap between benchmark performance and real world reliability. To address this gap, we introduce LIBERO-Recover Benchmark, a large scale benchmark for failure recovery in robotic manipulation. Built upon LIBERO, we collect real execution failures from SOTA embodied models and construct 1,000+ scenarios across four recovery levels: (1) Action Retry, (2) Action Adaptation, (3) Object State Recovery, and (4) Environmental Recovery. We evaluate four core capabilities: spatial understanding, object structure reasoning, interaction understanding, and topological reasoning. As the first large-scale benchmark for embodied failure recovery, LIBERO-Recover shifts evaluation from \emph{Can the robot succeed?''} to \emph{Can the robot recover after failure?''}, promoting robust and generalizable embodied agents. # LIBERO-RECOVER 论文总结

## 一、核心问题与研究背景

- **现实痛点**：现有机器人操作基准（如 LIBERO）上的 SOTA 模型已接近 100% 成功率，但这种近乎完美的表现具有误导性——这些基准仅在理想初始状态下评估一次性任务完成，忽略了真实交互中不可避免的失败（如抓取失败、碰撞、物体意外位移）。
- **关键缺口**：真实部署要求机器人不仅能成功完成任务，还需具备识别失败、恢复被破坏状态、重新规划并继续执行的能力，但这一核心能力在现有基准中几乎未被衡量。
- **论文主张**：标准基准的高分不能代表真实可靠性，需将评测范式从"机器人能否成功？"转向"机器人在失败后能否恢复？"，并揭示了 LIBERO 评测范式的局限。

## 二、核心方法论

### 2.1 问题形式化

- **传统执行**：从初始状态 $s_0$ 执行动作序列到达满足目标 $G(s_T, l)=1$ 的终止状态，不显式考虑失败后处理。
- **失败恢复设定**：执行在中间状态 $s_f$ 偏离预期任务进展，且 $G(s_f, l)=0$，任务仍可恢复，此时需要恢复策略 $\pi_{rec}$ 重新规划动作。失败状态需满足三个条件：执行诱发、任务相关、当前计划失效但仍可恢复。

### 2.2 失败分类与难度等级

- **L1 动作重试（Action Retry）**：$s_f \approx s_{expected}$，只需重试失败动作（如重新抓取）。
- **L2 动作适配（Action Adaptation）**：物体配置有限变化但仍可直接使用，需调整动作 $a' = \pi(o_f, l) \neq a_{failed}$。
- **L3 物体状态恢复（Object State Recovery）**：失败显著改变了任务相关物体，需先恢复物体状态再继续原任务（如先归位被位移的碗）。
- **L4 环境恢复（Environmental Recovery）**：失败影响与任务无直接关联的物体或状态，需推理任务相关与无关状态及其交互拓扑。

### 2.3 场景构建流程（三阶段管线）

1. **任务执行阶段**：从 LIBERO 四套任务套件（130 子任务）出发，部署 π0、π0.5、OpenVLA、GR00T、Wan-Policy、Cosmos-Policy 作为"失败生成器"，自然产生失败轨迹，**不进行任何人工扰动或失败注入**。
2. **失败定位阶段**：使用 Qwen3.5-27B-Instruct 对执行视频进行时序分析，将每段视频分为 $V_{pre} \cup V_{fail} \cup V_{post}$，并从仿真器中检索对应的机器人状态与物体位姿。
3. **失败特征化阶段**：根据失败分类法由 Qwen3.5-27B-Instruct 判断恢复类型与难度等级。

### 2.4 评估指标

- **恢复成功率（RSR）**：在失败状态下能否最终完成任务，并按 L1–L4 细分。
- **恢复退化度（RD）**：$RD = 1 - \frac{M_{post}+\epsilon}{M_{pre}+\epsilon}$，衡量失败后执行能力的损失。
- **恢复一致性（RC）**：$RC = 1 - \mathrm{Std}_k(R_k)$，衡量同一任务内不同失败状态间恢复表现的稳定性。

## 六、主要结论与发现

- **发现 1**：在预定义场景下的成功不能保证对真实失败的鲁棒泛化，所有模型在 LIBERO-Recover 上均出现 **超过 50% 的性能下降**，且标准基准排名无法预测失败恢复能力。
- **发现 2**：现有模型擅长局部动作修正，但难以进行状态级恢复。L1/L2 与 L3/L4 之间存在显著性能跃迁，揭示"动作级纠错→状态级恢复"的能力断层。
- **发现 3**：失败会引发**复合式分布漂移**，从 Pre 到 Dur 再到 Post，成功率逐步下降（LIBERO-100 上 RD 高达 100%）。
- **发现 4**：WAM 策略的恢复一致性（RC）高于传统 VLA，可能受益于对动作-状态转移的显式建模。
- **发现 5**：更小的动作块（chunk size 从 32→4）通过更频繁的反馈显著提升恢复能力。
- **发现 6**：**失败恢复训练存在迁移鸿沟**——将恢复数据加入标准训练虽提升 LIBERO-Recover 表现，但对标准 LIBERO 成功率几乎无帮助甚至略有下降，表明恢复能力难以迁移到自然执行中产生的失败。
- **发现 7**：提供任务初始帧作为时序上下文可显著提升恢复（如 OpenVLA-OFT 在 LIBERO-100 上从 10.3% → 24.7%）。
- **发现 8**：失败恢复数据呈现更集中的状态分布（KDE 显示多个高密度区域集中于抓取、放置等关键交互处），而标准演示数据更分散。

## 七、优点

- **首个大规模失败恢复基准**：填补了基准性能与真实可靠性之间的关键缺口。
- **自然失败收集**：与现有手工扰动物体位姿、外观或场景布局的基准不同，所有失败来源于 SOTA 模型的真实执行，更贴近真实场景。
- **四级递进难度设计**：从动作重试到环境恢复，系统覆盖不同推理深度的恢复需求。
- **多维度指标体系**：RSR、RD、RC 互补地评估恢复能力、损失程度与一致性。
- **关键洞察丰富**：揭示了失败恢复迁移鸿沟、复合分布漂移、WAM 优势等重要现象。
- **透明可复现**：基于 LIBERO 构建，融合 Qwen3.5-27B 进行时序分析，配合人工遥操作标注，流程清晰。

## 八、不足与局限

- **覆盖偏差**：难度等级分布极不均衡（L4 仅 64 个场景，且占比随难度下降），可能影响高级别统计可靠性，且未做人工均衡以"忠实反映经验失败分布"。
- **生成器多样性有限**：失败仅来自少数几个 SOTA 模型系列，可能未涵盖其他模型家族（如 RT-2、UniVLA、RoboMamba 等）的失败模式。
- **仿真单一性**：仅在仿真环境验证，**未在真实机器人上验证**；仿真到真实的迁移问题未讨论。
- **数据规模有限**：3,184 条恢复轨迹规模相对较小，且仅 413 个场景被人工标注恢复，可能限制微调效果。
- **迁移鸿沟未解决**：实验发现恢复训练难以迁移到自然失败场景，但论文未提供解决方案或深入分析原因。
- **评估细节不充分**：论文未明确报告 GPU 算力、训练时长、推理耗时等工程细节，影响复现性评估。
- **应用范围受限**：当前评测局限于 LIBERO 仿真器中的桌面操作任务，对移动操作、双手机器人、长视野任务等的覆盖尚未涉及。
