## 摘要
视觉-语言-动作（VLA）模型通过整合视觉感知、语言理解和连续动作控制，为通用机器人操作提供了一条可扩展的路径。然而，我们揭示了 VLA 架构的一个关键局限：动作专家对 VLM 特征中可用的三维几何和二维语义信息的访问有限。这种可访问性差距削弱了感知基础，并限制了细粒度机器人操作任务的性能。为解决此问题，我们提出 V-Link，它在视觉-语言（VL）到动作（A）的特征传递过程中显式恢复视觉表征。具体而言，V-Link 在 VLM 内学习互补的空间查询与语义查询表征，并通过非对称通路将它们注入 Action DiT。语义查询补充了原始的 VLM 图像标记，而空间查询则为面向空间定位的动作生成提供了专门的几何条件。在 LIBERO、LIBERO-Plus 和 RoboTwin 2.0 上，我们的 V-Link 相对基线模型 GR00T N1.6 将平均成功率分别提升了 +1.9%、+31.2% 和 +18.8%。在 AGIBOT A3 Ultra 上，V-Link 在两项真实世界的人形机器人任务中进一步获得了 +20% 和 +24% 的提升。

## Abstract
Vision-language-action (VLA) models provide a scalable path toward generalist robotic manipulation by integrating visual perception, language understanding, and continuous action control. However, we reveal a critical limitation of VLA architectures: the action expert has limited access to the 3D geometric and 2D semantic information available in VLM features. This accessibility gap weakens perceptual grounding and limits performance on fine-grained robotic manipulation. To address this issue, we propose V-Link, which explicitly recovers visual representations during the vision-language (VL) to action (A) feature transfer. Specifically, V-Link learns complementary Spatial and Semantic Query representations within the VLM and injects them into Action DiT through asymmetric pathways. Semantic Queries complement the original VLM image tokens, whereas Spatial Queries provide dedicated geometric conditioning for spatially grounded action generation. Across LIBERO, LIBERO-Plus, and RoboTwin 2.0, our V-Link improves the average success rate over base model GR00T N1.6 by +1.9%, +31.2%, and +18.8%, respectively. On the AGIBOT A3 Ultra, V-Link further achieves gains of +20% and +24% on two real-world humanoid tasks.

# V-Link 论文总结

## 1. 核心问题与研究动机

- **背景**：视觉-语言-动作（VLA）模型通过将视觉感知、语言理解与连续动作控制融合，被视为通用机器人操控的可扩展范式，其中"双系统"架构（以 GR00T N1.6 为代表）由负责多模态理解的 VLM 与负责高频控制的 Action DiT 组成，二者之间通过"VL→A 特征传递"进行信息交互。
- **关键问题**：作者指出当前双系统 VLA 架构存在一个被忽视的**视觉表征可及性瓶颈（accessibility bottleneck）**：仅靠 VLM 最终层特征传递，Action DiT 对其中蕴含的 3D 几何信息与 2D 语义信息的访问能力极为有限。
- **诊断证据**：作者设计了冻结表征 + 轻量任务头（深度估计 / 语义分割）的诊断协议，发现在冻结的 Action DiT 特征上，深度 MAE 从 VLM 的 0.015 升至 0.071，分割 mIoU 从 0.665 降至 0.290，验证了显著的感知信息衰减。
- **核心假设**：高纠缠的 VLM 最终层特征在仅动作监督下，Action DiT 易陷入"语义捷径（semantic shortcut）"，快速降低动作损失而忽略结构性的 3D 空间线索，导致细粒度操控所需的感知锚定不足。

## 2. 方法论

### 2.1 整体框架
V-Link 在 GR00T N1.6 的基础上，在 VLM 内联合学习两类互补的可学习查询（**Spatial Query** 与 **Semantic Query**），并通过**非对称通路**将其注入 Action DiT。

### 2.2 VLM 表征解耦（VLM Representations Decoupling）
- 在 VLM 输入序列中追加两组查询 token：$E_d$（Spatial Query）与 $E_s$（Semantic Query），与文本 token $E_t$、图像 token $E_o$ 拼接后进入 VLM。
- 设计**因果注意力掩码 $M_q$**，使两类查询彼此隔离并独立从图像-文本中提取信息，不破坏原始多模态计算。
- 经过多层 Transformer 后，最终层输出为 $E'_d$ 与 $E'_s$，分别用于下游几何与语义任务。
- 配套训练期监督头（推理时移除）：
  - **深度头 $\Phi_{Depth}$**（≈2.3M 参数）：LN→Linear→GELU→Dropout + 2 层 per-view Transformer Encoder + 卷积解码器，输出 softplus 约束的正值 metric depth。
  - **语义头 $\Phi_{Seg}$**：相同结构，输出 Softmax 分割 logits。
- 损失设计：
  - 深度损失：$L_{depth} = L_{sm} + \lambda_1^d L_{rel} + \lambda_2^d L_{patch}$，其中 $\lambda_1^d=0.1$，$\lambda_2^d=0.5$，含 smooth-L1、绝对相对损失（强调近场/机械臂/操作区域）及 top-k 难样本 patch 损失。
  - 语义损失：$L_{seg} = L_{CE} + \lambda^s L_{Dice}$，$\lambda^s=0.5$，缓解背景与类别不平衡。
- 训练时先用同一超参数 warm up VLM LoRA、查询 token 与任务头，再进行联合优化。

### 2.3 Action DiT 中的视觉表征恢复
- 沿用 GR00T N1.6 的 32 层 AlternateVLDiT（每 4 层为一周期：非图像 CA → 状态/动作 SA → 图像 CA → 状态/动作 SA）。
- 仅在 $\ell = 4k+2$ 的图像交叉注意力层注入查询。
- **非对称注入机制**：
  - 状态/噪声动作 token $H_l$ 同时作为 query，与 VLM 图像 token $E'_o$ 和 Semantic Query $E'_s$ 做**两组并行交叉注意力**，输出 $N_l$ 与 $S_l$。
  - 融合投影：$Z_l = H_l + \text{Fuse}(N_l, g_l S_l)$，$g_l \in [0,1]$ 为可学习门控参数。
  - 再以 $Z_l$ 为 query，与 Spatial Query $E'_d$ 做空间交叉注意力，输出 $H'_l = Z_l + \text{CA}_{Spatial}(Z_l, E'_d)$，最后 FFN 得到 $H_{l+1}$。
- 设计动机：语义捷径通过补充语义查询缓解；空间几何通过强制几何条件分支专门注入，避免被语义信号压制。
- **总损失**：$L = L_{act} + \lambda_1^a L_{depth} + \lambda_2^a L_{seg}$，$\lambda_1^a=0.1$，$\lambda_2^a=0.002$。

## 3. 实验设计

### 3.1 数据集与基准
- **LIBERO**（4 个子套件：Spatial / Object / Goal / Long）
- **LIBERO-Plus**（7 种分布偏移：Camera / Robot / Language / Light / Background / Noise / Layout）
- **RoboTwin 2.0**：选取 6 个挑战性任务（Move Pillbottle Pad、Move Stapler Pad、Place Bread Skillet、Place Phone Stand、Press Stapler、Turn Switch），每任务 50 条演示，共 300 条
- **真实机器人**：AGIBOT A3 Ultra，2 个任务（Autonomous Power-On / Power-Off），每任务 100 条遥操作演示

### 3.2 评估协议
- LIBERO / LIBERO-Plus：每任务 50 次试验
- RoboTwin 2.0：每任务 100 次试验
- 真实任务：每任务 50 次连续试验
- LIBERO-Plus 不做微调，仅在标准 LIBERO 训练后评估泛化鲁棒性

### 3.3 对比方法
- **2D VLA**：OpenVLA、Dita、CoT-VLA、π0-FAST、π0、π0.5、UniVLA、OpenVLA-OFT
- **3D VLA**：SpatialVLA、GeoVLA、3D-CAVLA、Spatial Forcing、GR00T N1.6（基线）
- **RoboTwin 2.0 对比**：π0、Xiaomi Robotics-0、EventVLA、π0.5、GR00T N1.6
- 真实任务对比：GR00T N1.6

## 6. 主要结论与发现

- **可及性差距可被恢复**：通过 Spatial/Semantic Query 注入，Action DiT 在诊断协议下的深度 MAE 与分割 mIoU 显著优于基线（Fig. 6），证明视觉表征在 VL→A 传递后被有效保留。
- **量化增益显著**：
  - LIBERO 平均成功率 99.3%，相对 GR00T N1.6（97.4%）提升 +1.9%，相对 Spatial Forcing（98.5%）提升 +0.8%；最大提升在 LIBERO-Long（+5.1%）。
  - LIBERO-Plus 总成功率 75.0%，相对基线 +31.2%，相对之前最佳 +5.4%；噪声偏移 +60.4%，语言偏移 +47.3%，光照偏移 +30.6%。
  - RoboTwin 2.0 平均 56.8%，相对基线 +18.8%。
  - AGIBOT A3 Ultra 真实任务：Power-On 98%（vs 78%），Power-Off 94%（vs 70%），提升 +20% 与 +24%。
- **查询互补**：Spatial Query 主要驱动 Move/Place 任务提升（+13.2%），Semantic Query 主导 Contact 任务提升（+18.0%），二者结合最优（56.8%）。
- **任务监督与查询注入缺一不可**：仅注入而无监督仅 40.3%，仅监督而不注入仅 39.8%，二者结合 56.8%。
- **查询规模与延迟权衡**：3×5×5 网格为最佳精度-效率平衡点。
- **推理高效**：仅增加 1.58 ms 延迟，无需任何额外感知输入或标注。

## 7. 优点

- **新视角的诊断方法**：用"冻结表征 + 轻量任务头"作为可及性的量化度量，方法论上具可推广性，便于后续工作诊断类似瓶颈。
- **设计思路清晰**：将 3D 几何与 2D 语义解耦后通过非对称通路分别注入，符合"语义捷径"假设的因果对应。
- **训练-推理解耦干净**：查询监督头仅用于训练，推理时完全去除，不引入额外传感器或标注依赖。
- **实验覆盖全面**：仿真（标准、分布偏移、双臂操作）+ 真实机器人（人形 A3 Ultra）的组合验证了泛化性。
- **消融逻辑清晰**：从查询组成、监督信号、注入机制到查询容量逐层剥离，避免"一锅炖"式 ablation。
- **效率突出**：1.58 ms 的延迟增加对实时控制影响极小，实用性高。
- **工程细节充分**：因果掩码设计、warm-up 流程、损失加权（特别是 $L_{rel}$、$L_{patch}$ 抑制背景主导）等工程技巧具体。

## 8. 不足与局限

- **诊断协议的可推广性有限**：深度估计 MAE 与分割 mIoU 是间接代理指标，与"对操控有用的视觉信息"之间的因果关系未严格验证。
- **监督信号依赖伪标签**：真实任务使用 GroundingDINO+SAM3 生成关键物体分割伪标签，会引入分割模型的偏差；同时依赖 Lingbot-Depth 补全深度，可能引入深度估计误差。
- **查询 token 设计粗糙**：每组查询用规则网格（$V \times H \times W$）初始化，缺乏任务自适应或语义位置先验；3×6×6 已出现轻微性能下降（56.8%→56.5%），原因未深入分析。
- **Gating 参数 $g_l$ 的行为未充分分析**：可学习门控在所有层共享/逐层共享的实现细节与梯度动态缺乏消融。
- **真实任务覆盖有限**：仅 2 个 Power-On/Off 类任务，场景多样性、干扰物体、光照变化等未充分验证；缺乏与 π0、π0.5 等其他基线在真实场景下的对照。
- **基线饱和度问题**：在 LIBERO 标准套件上基线已达 97.4%，+1.9% 的提升主要来源于 Long 套件（+5.1%），需关注"长时序"是否主要由 Semantic Query 贡献，文中未细分。
- **算力与训练成本披露不完整**：仅提及 4×H100、DeepSpeed ZeRO-2，但未给出 GPU 总训练小时数、能耗或与基线的对比成本。
- **架构绑定 GR00T N1.6**：因果掩码与 AlternateVLDiT 注意力周期的耦合较深，迁移到 π0、UniVLA 等其他 VLA 架构需重写注入逻辑，通用性受限。
- **未能解释"语义捷径"的具体机制**：仅给出假设（动作损失偏好语义），未在梯度层面（如特征梯度分析）严格证明。
- **未分析失败模式**：缺少典型失败案例的细致归因，例如哪些任务仍依赖外感受器误差补偿、哪些情况下 Spatial Query 反而引入噪声。
