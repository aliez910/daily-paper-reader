## 摘要
视觉-语言-动作（VLA）模型展现出强大的语义理解能力，但在部署过程中会出现系统性失败。这些失败发生的条件，以及是否能在不重新训练的情况下予以修正，目前仍缺乏清晰认识。本文旨在弥合这一空白。我们提出了CorrectVLA框架，该框架将任务级自然语言修正转化为加性的动作幅度调整，且无需修改策略权重。由人类提供一条任务级修正，并将其统一应用于所有回放过程，无需在每回合进行干预。在仿真环境中，CorrectVLA在分布内和分布外任务上均能恢复执行错位失败。在UFactory xArm7的实机器人环境偏移实验中，CorrectVLA在基础策略几乎完全失效的场景下恢复了近乎完美的成功率，并在不同物体位置和类别间实现了泛化。通过对LIBERO-90上失败模式的分类分析，我们发现：执行错位失败（即策略到达了正确目标但动作幅度校准失当）属于可修正的子集；而语义理解本身崩溃的其他失败模式则不适用于本方法。该方法在策略具备策略正确性时成功，在缺乏基本理解能力时失败，从而为推理时修正确立了切实可行的操作边界。

## Abstract
Vision-Language-Action (VLA) models demonstrate strong semantic understanding yet exhibit systematic failures during deployment. The conditions under which these failures occur, and whether they can be corrected without retraining, remain poorly understood. In this paper, we take steps toward addressing this gap. We present CorrectVLA, a framework that translates task-level natural language corrections into additive action magnitude adjustments without modifying policy weights. A human provides a single task-level correction, applied uniformly across all rollouts without per-episode intervention. In simulation, CorrectVLA recovers execution misalignment failures across both in-distribution and OOD tasks. In real-robot experiments on a UFactory xArm7 under environment shift, CorrectVLA restores near-perfect success where the base policy almost entirely breaks down, generalizing across object locations and identities. Through a taxonomy of failure modes on LIBERO-90, we find that execution misalignment failures, where the policy reaches the correct target but miscalibrates action magnitudes, represent the correctable subset, while other failure modes where semantic comprehension itself breaks down are not amenable to this approach. The approach succeeds when policies possess strategic correctness and fails when fundamental comprehension is absent, establishing a practical operational boundary for inference-time correction.

# 论文总结：通过语言反馈实现 VLA 模型失败的无训练动作修正

## 一、核心问题与研究动机

- **背景**：视觉-语言-动作（VLA）模型（如 OpenVLA、π0.5 等）借助大规模预训练在语义理解层面表现优异，但在部署到新环境（光照变化、视角偏移、桌面配置不同等）时会出现系统性失败。
- **核心问题**：
  - VLA 模型在部署中究竟在何种条件下、以何种方式失败？
  - 这些失败是否能够在不重新训练、不收集新演示的前提下被纠正？
- **现状缺口**：现有方案要么依赖训练时收集新演示并更新权重（成本高、需要 GPU 时长与基础设施），要么采用测试时采样/验证选优（无法针对系统性幅度误差生成真正的"纠正"动作）。
- **核心洞见**：将"任务语义理解"与"动作幅度校准"两类问题分离；当策略在战略层面正确、仅在执行幅度上偏置时，可通过人类稀疏语言反馈直接在推理时修正，无需改动模型权重。

## 二、方法论

### 2.1 整体框架 CorrectVLA
- 输入：冻结的 VLA 策略 $\pi_\theta$、一次失败回放 $\tau^{fail}$、人类给出的 K 条任务级自然语言反馈 $\{f_1,\dots,f_K\}$（$K \ll T$，即"稀疏"）。
- 输出：每个时间步每个维度的加性偏差 $\delta_{t,d}$，与原动作相加：
  $$a^{corrected}_{t,d} = a_{t,d} + \delta_{t,d}$$
- 关键约束：策略权重 $\theta$ 不变；不需要新演示或 GPU 训练；任务级反馈一次性给出，所有回合复用。

### 2.2 三阶段语言-动作落地（Grounding）流程
- **阶段 A：结构化参数抽取（Structured Parameter Extraction）**
  - 由 LLM 从自然语言中抽取四类参数，构成 $c_k = (d_k, s_k, m_k, t_{start,k}, t_{end,k})$：
    - $d_k \in \{x, y, z, roll, pitch, yaw, gripper\}$：动作维度
    - $s_k \in \{+1, -1\}$：方向
    - $m_k \in \{slightly, more, much\}$：幅度词
    - $[t_{start,k}, t_{end,k}]$：时间窗口
- **阶段 B：幅度量化（Magnitude Quantification）**
  - 将幅度词映射到经验验证的数值区间并按方向赋符号，得到带符号的标量幅度 $w_k \in [-1, 1]$：
    - "slightly" → [0.3, 0.5]；"more" → [0.5, 0.8]；"much" → [0.8, 1.0]
  - 例如 "more" 取负方向 → $w_k = -0.65$
- **阶段 C：时间分布（Temporal Distribution）**
  - 用分段线性包络 $\phi_k(t)$ 将修正沿时间窗口平滑展开：在窗口起点为 0，中点达到峰值，窗口终点归 0，窗口外恒为 0。形式化为三段函数（论文公式 (1)）。
- **整体落地函数**：对同一维度的所有反馈求和：
  $$\delta_d(t) = \sum_{k: d_k = d} w_k \cdot \phi_k(t)$$
  性质：反馈稀疏、时域局部、跨维度可加；策略权重冻结；任务级反馈跨回合复用。

### 2.3 动作空间适配
- 仿真（Franka Panda）使用 7-DoF 末端执行器动作空间，可直接施加修正。
- 真实机器人（xArm7 使用关节速度控制）通过 Jacobian 伪逆将笛卡尔修正转换为最小范数关节速度：$\dot{q} = J^\dagger(q)\dot{x}$。

### 2.4 失败模式分类
- 在 LIBERO-90 上对 133 个任务-模型评估（73 OpenVLA-OFT + 60 π0.5）总结出四类失败：
  - **任务误解（Task Misunderstanding）**：约 47% / 50%，误读空间/关系语言，操作错误物体
  - **执行错位（Execution Misalignment）**：约 23% / 22%，目标正确但幅度错误（抓太浅、推太弱）—— **唯一可被本方法修正的子集**
  - **感知失败（Perception Failure）**：约 25% / 22%，完全忽略目标物体
  - **多步规划失败（Multi-step Planning）**：约 5% / 6%，首个子目标成功后放弃第二个

## 六、主要结论与发现

- **执行错位失败可被稀疏修正**：约 22-23% 的 OOD 失败属于"目标正确但幅度错误"，是唯一适用于推理时修正的子集
- **仿真结果**：
  - π0.5 分布内基线 93.0%（1861/2000）→ CorrectVLA 恢复 65/139 失败，成功率提升至 96.3%
  - π0.5 OOD 基线 27.1%（122/450）→ CorrectVLA 恢复 33/328，成功率提升至 34.4%
  - 所有任务误解类失败均未被恢复（与分类一致）
- **真实机器人结果**（机器人基座偏移后）：
  - π0.5 基线：10%（2/20）→ CorrectVLA：95%（19/20）

- **操作原则**：诊断当前活跃的失败模式 → 施加"最小充分干预"；不必默认走重训练路线

## 七、优点与亮点

- **新颖的失败模式分类**：首次系统地把 VLA 部署失败划分为四类，并定量给出每类占比，跨两种架构结果一致

- **稀疏性 + 局部时域**：通过分段线性包络将修正仅作用于关键瓶颈时刻，不破坏策略整体轨迹结构
- **跨维度可加**：支持多维、多条反馈叠加，工程上易于实现
- **仿真 + 真实机器人双重验证**：从 LIBERO 到 xArm7，从分布内到强分布偏移（基座重定位），证据链完整
- **明确的操作边界**：方法在"策略具备战略正确性"时成功，在"语义理解缺失"时失败，给出清晰的适用边界

## 八、不足与局限

- **幅度映射的离散区间**：依赖人工预定义的"slightly/more/much"区间 [0.3-0.5] / [0.5-0.8] / [0.8-1.0]，引入了意图与实际幅度之间的方差，可能需要多轮修正才能收敛；论文未给出该方差量化
- **任务级反馈假设过强**：默认同一任务内的失败模式一致——若同一任务在不同回合呈现不同失败模式，单条修正难以泛化
- **失败分类基于仿真**：LIBERO-90 的失败分布可能无法代表真实世界；真实部署中失败模式的相对比例与可修正性仍待验证
- **真实机器人任务覆盖窄**：仅抓放两类任务、单一基座偏移类型，未覆盖工具使用、复杂操作或动态障碍等更广泛场景
- **缺乏参数消融**：未系统研究反馈条数 K、幅度大小、时间窗口长度对恢复率的影响；LLM 抽取误差的影响也未量化
- **对人类反馈质量敏感**：依赖人类观察者准确指出"哪个维度、在哪段时间窗口、向哪个方向偏多少"——若反馈语义有歧义或时序定位错误，将直接导致修正失败

- **基策略规模与对比广度**：仅对比 π0.5 与 OpenVLA-OFT，未与同期的 ITPS、FOREWARN 等运行时修正方法在统一基准上直接对照
