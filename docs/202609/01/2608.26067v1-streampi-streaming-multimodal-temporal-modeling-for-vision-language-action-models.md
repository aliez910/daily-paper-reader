## 摘要
视觉-语言-动作（VLA）模型已在机器人操控中展现出有效性，然而 pi0.5 等当前最先进的模型仍采用单帧范式，限制了其保留历史观测和形成精确空间感知的能力。本文提出 StreamPI——一种流式多模态时序建模框架，在不引入任何额外参数的前提下，为单帧 VLA 赋予时序推理能力。其核心设计之一是指令锚定的时序建模。该方法将每对（视觉观测，语言指令）视为一个原子时序单元：在每个单元内部采用双向注意力以实现跨模态融合，而在单元之间采用因果注意力以保持自回归流式推理。这确保了语言指令在整个任务执行过程中充当持续的语义锚点。为了弥合同步训练与异步真实机器人部署之间的差距，我们引入随机间隔流式训练策略：合理的帧间间隔（例如每 3 帧）能够带来更快、更平滑的动作执行。更进一步，对间隔进行随机化能够进一步提升模型对帧时序扰动的鲁棒性，从而支持实际中的异步部署。此外，通过利用 LLM 主干网络的长度外推能力，StreamPI 能够无缝继承预训练的单帧权重，并支持灵活的单帧与多帧推理。在涵盖依赖记忆和精确感知场景的真实机器人任务，以及仿真基准 LIBERO 上的实验表明，StreamPI 在多项任务上均优于 pi0.5。

## Abstract
Vision-Language-Action (VLA) models have demonstrated effectiveness in robot manipulation, yet state-of-the-art models such as pi0.5 operate under a single-frame paradigm, limiting their ability to retain past observations and develop precise spatial perception. In this paper, we propose StreamPI, a streaming multimodal temporal modeling framework that equips single-frame VLA with temporal reasoning capability without introducing any additional parameters. One core design is instruction-anchored temporal modeling. It treats each (visual observation, language instruction) pair as an atomic temporal unit: bidirectional attention within each pair enables cross-modal fusion, while causal attention across pairs preserves autoregressive streaming inference. This ensures the language instruction serves as a persistent semantic anchor throughout task execution. To bridge the gap between synchronous training and asynchronous real-robot deployment, we introduce a andom-interval streaming training strategy: a proper inter-frame interval (e.g., every 3 frames) enables faster and smoother action execution. Beyond this, randomizing the interval further improves robustness to frame-timing perturbations, supporting asynchronous deployment in practice. Furthermore, by leveraging the length extrapolation capability of the LLM backbone, StreamPI seamlessly inherits pretrained single-frame weights and supports flexible single-frame and multi-frame inference. Experiments on real-robot tasks spanning memory-dependent and precise perception scenarios, as well as the simulation benchmark LIBERO, demonstrate that StreamPI outperforms pi0.5 across diverse tasks.

# StreamPI 论文总结

## 1. 核心问题与研究动机

**核心问题**：当前最先进的视觉-语言-动作（VLA）模型（如 π0、π0.5）均采用**单帧推理范式**，即每个动作仅基于当前单张图像观测生成，缺乏对历史观测的访问能力。这一限制带来两个关键缺陷：

- **记忆缺失**：无法保留和利用过去时刻的观测信息，对需要跨帧推理的任务（如跟踪运动物体、判断遮挡关系）无能为力。
- **空间感知不足**：单帧图像缺乏多视角几何线索，难以实现亚厘米级精度的操控。

**应用场景的迫切性**：
- 在自动驾驶领域，多帧融合方法（如 BEVDet4D、BEVFormer）已被证明能显著提升 3D 场景理解能力。
- VGGT 等视觉几何基础模型同样验证了时间聚合对深度估计和 3D 重建的重要性。
- 这些发现应自然地迁移到具身操控任务中。

**现有方案的不足（四个挑战）**：
1. **计算开销大**：直接拼接多帧使序列长度线性增长，推理延迟对实时控制不可接受。
2. **指令遗忘**：语言指令以固定文本 token 注入，随视觉 token 累积而被逐渐稀释。
3. **训练-部署失配**：训练使用规则采样的帧序列，而真实机器人部署产生异步且间隔不固定的观测流。
4. **表征破坏**：引入视频编码器会新增参数，其特征分布与强大的 VLA 预训练模型不对齐，可能破坏基础模型的视觉-语言表征。

## 2. 方法论

### 2.1 整体框架
StreamPI 是基于 π0.5 预训练权重的**流式多模态时序建模框架**，核心思想是：**将每对（视觉观测，语言指令）视为一个不可分割的"原子时序单元"**，通过结构化注意力机制实现高效时序建模，**不引入任何额外参数**。

### 2.2 指令锚定的时序建模（核心创新）

**原子时序单元定义**：
$$u_t = (V_t, l_t)$$

其中 $V_t$ 为多视角视觉观测（前视、左腕、右腕相机），$l_t$ 为语言指令。

**输入序列构造**（取最近 T 帧）：
$$U = [u_{t-T+1}, u_{t-T+2}, \ldots, u_t]$$

**两级注意力结构**：
- **单元内双向注意力**（Intra-pair）：同一原子单元内的视觉 token 与文本 token 互相充分关注，实现跨模态融合：
  $$h_\tau = \text{Attn}_{bi}(V_\tau, l_\tau)$$
- **单元间因果注意力**（Inter-pair）：当前单元的融合表征仅关注历史单元的表征，保持自回归流式推理结构：
  $$o_t = \text{Attn}_{causal}(h_{t-T+1}, \ldots, h_t)$$

**关键优势**：
- 语言指令作为"语义锚点"始终与对应视觉帧绑定，从根本上避免指令遗忘。
- 通过分组因果注意力掩码（block-wise causal mask）实现，无需任何新参数。

### 2.3 无参数时序扩展

利用 LLM 主干网络的**长度外推能力**（受 LongLoRA 等工作启发），仅通过扩展位置编码即可处理更长序列。完全继承 π0.5 预训练权重，同时支持训练时与推理时的单帧/多帧灵活切换。

### 2.4 随机间隔流式训练策略

**问题背景**：训练时假设固定帧间隔，部署时实际为异步可变间隔，存在失配。

**解决方案**：
- 在基础间隔 $\bar{\delta}$ 上加入均匀随机扰动 $\epsilon \sim \mathcal{U}(-\Delta, +\Delta)$，截断至 $[\delta_{min}, \delta_{max}]$。
- 训练时帧间隔在 [3, 7] 之间随机采样。
- 配合**时间掩码策略**：从完整 T 帧中随机丢弃最早的 k 帧（k ∈ {0, ..., T-1}），模拟流式推理的渐进观测模式。

### 2.5 流式推理流程

- 维护滚动 KV-Cache（最大长度 T）。
- 每个新到达的帧只需编码一次，通过 cross-attention 复用历史缓存表征。
- 推理延迟几乎不随时序长度增长：单帧 94.4ms，T=5 时仅 103.6ms（仅增加 9.2ms）。

## 6. 主要结论与发现

1. **整体性能提升**：StreamPI（T=5）在 LIBERO 上以 98.3% 平均成功率超越 π0.5（96.9%），最大增益出现在 LIBERO-Long（+2.6%）和 LIBERO-Goal（+2.8%）。

2. **CALVIN 长时序优势显著**：平均序列长度达 4.547，远超 π0.5（4.313）和 MemoryVLA（4.090），尤其在第 5 个子任务上保持 85.0% vs π0.5 的 79.5%。

3. **真实机器人大幅领先**：
   - Shell Game：80.0% vs 46.7%（+33.3%）
   - Rolling Object Grasping：63.3% vs 26.7%（+36.6%）
   - Pen Insertion：66.7% vs 40.0%（+26.7%）
   - Cup Insertion：92.0% vs 60.0%（+32.0%）

4. **双向 + 因果组合是最佳**：单元内双向注意力对长视野任务尤为关键（T=5 时 LIBERO-Long 提升 5.6%）。

5. **随机间隔训练持续优于固定间隔**：T=3 时从 96.4% 提升到 97.5%，T=5 时从 97.0% 提升到 98.3%。

6. **跨流泛化良好**：用 T=5 训练，推理 T=1 仍优于单帧基线；T=3 接近 T=5 性能。

## 7. 方法与实验设计的亮点

- **完全无参数扩展**：通过注意力掩码重塑实现时序建模，零新增参数，保留预训练表征完整性。
- **指令锚定设计**：从根本上解决多帧 VLA 的"指令遗忘"问题，结构简洁优雅。
- **训练-部署一致性**：随机间隔训练策略直接对症解决异步部署问题，方法论严谨。
- **推理效率极高**：5 帧推理仅增加 9.2ms 延迟，且延迟增长是次线性的。
- **无需新视频编码器**：避免了特征分布不对齐破坏预训练表征的风险。
- **继承 π0.5 全部权重**：为社区复用强大预训练模型提供简单易用的方案。
- **实验设计层次丰富**：从注意力机制、消融、跨流泛化到真实机器人，全面覆盖。

## 8. 不足与局限

**作者自陈局限**：
- 训练时需加载所有历史帧，**极长时序**（>100 帧）的训练成本不可接受。
- 随机间隔训练虽增强鲁棒性，但**未完全解决真实机器人极端异步**的情况。

**实验层面**：
- 真实机器人任务**试验次数有限**（15-30 trial），统计置信度可能不足。
- 真实机器人的成功率绝对值（如 Shell Game 80%）仍有较大提升余地。
- 论文未报告**失败模式分析**或**错误归因**，难以判断改进来自记忆还是几何感知。

**方法层面**：

- **未提供不同硬件/相机配置下的泛化性验证**，实际部署门槛可能高于论文呈现。

**应用与安全**：
- 作者指出更强操控能力可能影响劳动力市场，且对分布外场景的鲁棒性是未来关键工作。
