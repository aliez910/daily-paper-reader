## 摘要
视觉-语言-动作（VLA）模型利用预训练的视觉-语言表征进行机器人控制，然而简单地堆叠历史帧并不能可靠地捕捉近期的物理变化。在多阶段操作任务中这一问题尤为突出，因为视觉上相似的状态可能依据先前的执行情况而需要采取不同的动作。为应对这一挑战，我们提出了 TemporalFlow-VLA，通过物理基础的时间监督来学习紧凑的执行历史。该方法利用记录的机器人状态、机器人几何以及已标定的相机，构建了机器人-表面时间流作为仅在训练阶段使用的目标，并对两个与执行对齐的时间查询进行监督，从而为动作专家提供结构化的历史信息。几何监督路径在部署时不参与评估。TemporalFlow-VLA 在 LIBERO 上取得了 97.63 ± 0.26% 的平均成功率，其中 LIBERO Long 为 96.60 ± 0.87%；在 12 个 RoboTwin 任务上的 Clean/Randomized 成功率达到 85.5%/84.2%。其相对此前方法的优势在更长时域、多阶段操作任务上表现得最为明显。受控的历史干预实验表明，动作预测同时依赖于历史内容与时间顺序。借助异步特征缓存，时间条件维持了单帧级别的服务端采样延迟，且不引入额外的历史编码开销。总体而言，TemporalFlow-VLA 提供了一种紧凑且具备物理基础的接口，使模型能够利用有序的执行历史，而无需在部署阶段进行显式运动估计或几何处理。

## Abstract
Vision-language-action (VLA) models leverage pretrained vision-language representations for robot control, yet simply adding historical frames does not reliably capture recent physical change. This is especially problematic in multi-stage manipulation, where visually similar states may require different actions depending on prior execution. To address this challenge, we present TemporalFlow-VLA, which learns compact execution history through physically grounded temporal supervision. Using recorded robot states, robot geometry, and calibrated cameras, we construct robot-surface temporal flow as a training-only target and supervise two execution-aligned temporal queries that provide structured history to the action expert. The geometric supervision path is not evaluated at deployment. TemporalFlow-VLA achieves 97.63 +/- 0.26% average success on LIBERO, including 96.60 +/- 0.87% on LIBERO Long, and 85.5%/84.2% Clean/Randomized success across 12 RoboTwin tasks. It shows its clearest advantage over prior methods on longer-horizon, multi-stage manipulation. Controlled history interventions show that action prediction depends on both historical content and temporal order. With asynchronous feature caching, temporal conditioning maintains single-frame-level server-side sampling latency without additional historical-encoding overhead. Overall, TemporalFlow-VLA provides a compact, physically grounded interface for exploiting ordered execution history without explicit motion estimation or geometric processing at deployment.

# TemporalFlow-VLA 论文总结

## 1. 核心问题与整体含义（研究动机与背景）

- **核心痛点**：现有主流 VLA 模型（如 π0、π0.5）通常仅以"当前 RGB 观测 + 语言 + 当前机器人状态"为条件生成动作块（action chunk），忽略了近期执行历史。
- **多阶段操作的歧义问题**：在长时域、多阶段操作中，视觉上相似但实际处于不同任务阶段的状态很常见（如抓取失败后回到抓取前位姿、夹爪接近/携带/恢复三种状态可能对应同一末端位姿），缺少时间演变信息会导致策略重复已执行动作、误判阶段、错误累积。
- **简单堆叠历史帧的局限**：
  - ViSTR-Bench 等基准测试表明 MLLM 对连续视觉线索中的运动、空间关系、动力学推理存在持续困难。
  - Liao & Cao (2026) 的机理审计发现，多帧冻结 VLA 中"历史独有信息"很弱，历史仅在当前观测不可靠时才起作用。
  - **本文诊断（图2）**：在固定当前帧的情况下打乱 3 帧历史，offline action flow-matching loss 几乎不变；而**移除**历史会使 loss 上升约 4.6%。说明历史"有用"，但"无约束的多帧基线"对历史顺序不敏感。
- **关键洞见**：问题不在于"是否提供历史"，而在于**用什么结构表征近期物理变化以适配控制**。本文将"显式运动提示"作为训练监督而非推理时提示。

## 2. 方法论

### 2.1 整体架构

- 在预训练 VLA（如 π0.5）上并行新增一条**时间路径**，保留原有"当前观测 → 动作"通路不动。
- 三个时刻的 head-camera 观测：$t-15$、$t-8$、$t$（对于 16 步 action chunk，恰好对应上一个 chunk 的起点和中点）。
- **核心载体**：两个可学习的、与执行对齐的时间查询 $Q_8$、$Q_{15}$，是动作专家获取历史的**唯一**通道（历史图像 patch 不能直接进入动作专家）。

### 2.2 运动学-几何-接地的机器人表面时序流（训练时目标）

- 输入：记录的关节构型 $q_\tau$、URDF 正运动学 $T_B^l(q_\tau)$、已标定的 $T_{C\leftarrow B}$ 和相机内参 $K$。
- 流程：
  1. 仅渲染机器人的源帧，提取每个可见机器人像素 $p$ 在 base 坐标系下的三维表面交点 $\bar{X}_B^s(p)$ 及其所属连杆 $l(p)$（采样以**深度可见像素**为依据而非固定 mesh 点，自然按投影面积加权）。
  2. 将源帧像素反变换到连杆坐标系，再以目标时刻正运动学运回，再投到目标图像：$\tilde{u}_t(p) = \Pi_K(T_{C\leftarrow B}\,\bar{X}_B^t(p))$。
  3. 通过最近邻查找 + 连杆一致性 + 残差 ≤ 5 mm 三重过滤保留有效对应。
  4. 在 $224\times224$ 策略图像平面上以 patch（$14\times14$）为单位做平均，得到 $16\times16\times2$ 的流监督 $F_\rho$；$c_\rho(k)=|V_k|/|S_k|$ 作为支持度，$M_\rho(k)=\mathbb{1}[c_\rho(k)\ge 0.1]$ 作为掩码。
- **特点**：完全离线预计算，无需手动光流标注，部署时该几何管线不存在。

### 2.3 分层时间查询与联合掩码注意力

- 时间 token $q_8$、$q_{15}$ 与标准 π0.5 前缀拼接，并仅为历史 patch $V_{15}$、$V_8$ 添加可学习的"帧身份"嵌入：
  $P^0 = [P_{std}(V_0,L,s);\, V_{15};\, V_8;\, q_8;\, q_{15}]$。
- **有向掩码注意力**（非对称可见集）：
  - $Q_8$：$A_8 = \{L, V_8, V_0, q_8\}$——专门编码近半个 chunk 的运动。
  - $Q_{15}$：$A_{15} = \{L, V_{15}, V_8, V_0, q_8, q_{15}\}$——可在 $Q_8$ 的近程摘要基础上整合更长程历史。
  - **强制方向**：$Q_8 \to Q_{15}$，避免两个尺度互相泄漏、保持各自语义清晰。
- **流解码器**：每个时间尺度有独立的 query-conditioned 解码器 $D_\rho$，由 query 状态 $z_\rho$ 通过 FiLM（$\gamma_\rho, \beta_\rho$）调制源帧 VLM 空间特征 $V_\rho$，再经逐点两层 MLP 预测流：
  $H_\rho = \text{LN}(V_\rho)\odot(1+\gamma_\rho(z_\rho))+\beta_\rho(z_\rho)$，$\hat{F}_\rho = W_{o\rho}\,\text{GELU}(W_{h\rho}H_\rho+b_{h\rho})+b_{o\rho}$。
- **损失**：仅在 $M_\rho=1$ 的 patch 上做 Huber：
  $L_\rho^{flow} = \frac{\sum_k M_\rho(k)\,\ell_{Huber}(\hat{F}_\rho(k),F_\rho(k))}{\sum_k M_\rho(k)+\epsilon}$，$L_{temp}=\tfrac{1}{2}(L_8^{flow}+L_{15}^{flow})$。
- **最终目标**：$L = L_{action} + \lambda_{temp} L_{temp}$，实验中 $\lambda_{temp}=1.0$。
- **进入动作专家**：复用 π0.5 现有 joint masked self-attention，对动作 token 屏蔽对 $V_{15}, V_8$ 的直接访问，仅允许读取 $Q_8, Q_{15}$；无需新增 cross-attention 模块或历史专用残差门控，保留 AdaRMS 调制。

### 2.4 异步历史特征缓存（部署效率）

- 朴素方案需 3 次视觉编码：$T_{naive}=3T_{vision}+T_{joint}+T_{action}$。
- 异步缓存：动作 chunk 执行期间后台线程预先编码历史帧并存入带时间戳环形缓冲；replan 时仅当前帧同步编码：
  $T_{cache}\approx T_{vision}+T_{joint}+T_{action}$。
- 剧集开始时缺失历史用最早观测占位并标记无效，直到两个必需历史 token 都可用后才启用缓存。

## 7. 优点

## 9. 综合评价

TemporalFlow-VLA 提出了一种**把"近期物理变化"显式编码进 VLA** 的可落地路径：通过离线运动学-几何管线获得机器人表面流作为辅助监督，引导两个时间对齐的查询 $Q_8$、$Q_{15}$ 在不同时间尺度上压缩历史；再以有向掩码注意力和异步特征缓存保证这些表征对动作专家可用且几乎不增加推理时延。在 LIBERO 与 RoboTwin 2.0 上取得了当前最佳的长 horizon 结果（RoboTwin 随机化 +8.0 pp、H=3 +14.5 pp），并通过离线干预与在线消融证明**历史的内容、顺序与显式运动目标都不可或缺**。

其最大价值在于：把"显式运动表征"的代价从推理侧搬到了离线标签侧，把"历史"从无差别的 token 堆叠变成**有物理内容、可被动作 token 直接调用的紧凑摘要**——这是对当前主流 VLA 仅依赖当前观测这一长期局限的针对性修正。

但研究仍属**结构与目标设计层面**的探索：固定历史尺度、对单一 embodiment 与桌面任务的依赖、转引 baseline 带来的对比公平性、真机规模偏小、训练开销上升 20%，都使其距离"通用、即插即用的历史编码模块"尚有距离。后续工作若能：
1. 引入自适应历史尺度或基于任务语义的间隔选择；
2. 在多 embodiment、多视角、动态干扰下做更广泛的真机验证；
3. 系统对比流监督与其他物理先验（如接触、力、关节轨迹）的相对贡献，

将更充分地验证"物理接地的时间表征"是否是通向长时域稳健操控的必经之路。
