## 摘要
在不确定环境中确保可靠性仍是长时序机器人操作的难题。端到端 VLA 模型数据需求大且不透明，难以诊断和验证。分层管线更具可解释性，但其规划往往与观测的关联较弱，与底层动作的对齐也较弱，且在计算时缺乏在线反馈，从而导致开环行为和幻觉。为解决这些问题，我们提出了 Triplet-to-Track 系统（TTS），这是一个闭环的长时序模仿学习系统，利用人类视频来减少对机器人采集数据的依赖。TTS 将高层子目标表示为以实例为基准的三元组，并将其转化为用于执行的连续轨迹先验，同时通过观测监控任务进度以进行在线重规划。在多种真实世界长时序任务上，TTS 取得了 74.8% 的平均成功率，并支持物体级和组合泛化。

## Abstract
Ensuring reliability in uncertain environments remains difficult for long-horizon robotic manipulation. End-to-end VLA models are data-heavy and opaque, making diagnosis and verification difficult. Hierarchical pipelines are more interpretable, but their plans are often weakly grounded in observations, weakly aligned with low-level actions, and computed without online feedback, leading to open-loop behavior and hallucinations. To address these issues, we introduce the Triplet-to-Track System (TTS), a closed-loop long-horizon imitation learning system that uses human videos to reduce reliance on robot-collected data. TTS represents high-level subgoals as instance-grounded triplets, translates them into continuous track priors for execution, and monitors task progress from observations for online replanning. Across diverse real-world long-horizon tasks, TTS achieves a 74.8\% average success rate and supports object-level and compositional generalization.

# Triplet2Track 论文总结

## 1. 核心问题与整体含义

- **研究背景**：长时序（long-horizon）机器人在不确定环境中的可靠性问题尚未解决；任务目标在初始观测中常常只部分可见，需要在多步交互之后才可验证，因此难点不在反应式控制，而在能否维持"与持续演化的观测一致"的规划。
- **现有两类方法的两难**：
  - **端到端 VLA**（如 π0.5、OpenVLA、GR-2）：直接将图像与语言映射到底层动作，但严重依赖大规模数据，且推理过程不可解释，难以诊断。
  - **分层管线**（如 SeeDo、PALO、LoHoVLA）：用 VLM/LLM 产生高层规划，依赖 web 知识以减少机器人数据；但规划常常**与观测弱对齐**（物体级幻觉、错位）、**与底层动作弱匹配**，并且多在**开环**模式下运行，缺乏在线反馈，导致错误累积。
- **核心挑战**：需要一种既能保证数据效率（利用人类视频）、又能保证规划可验证可追溯、并能在线纠错的分层闭环系统。

## 2. 方法论

### 2.1 整体框架
TTS（Triplet-to-Track System）是一个**三层闭环分层模仿学习系统**：
1. **Task Planner（任务规划器）**：从人类视频中生成"实例接地"的三元组（triplet），作为可验证的离散子目标。
2. **Track Predictor（轨迹预测器）**：将每个三元组转换（transition）编译为实体对齐的连续点轨迹（point track），作为物理运动先验。
3. **Action Policy（动作策略）**：以轨迹为物理先验生成末端执行器动作。

### 2.2 形式化建模
- 将任务建模为**上下文 POMDP**：$M_\ell = (\mathcal{S}, \mathcal{A}, \mathcal{P}, \Omega, O, \rho_0)$。
- **三元组空间** $\mathcal{C} = \mathcal{I} \times \mathcal{R} \times \mathcal{I}$，谓词 $c = (x, r, y)$，$x,y$ 为物体实例，$r$ 来自预定义关系词表（如 on、over、grasped）。可定义 $\mathrm{hold}(o_t, c) \in \{0,1\}$。
- **轨迹空间** $\mathcal{T}$：实体对齐的 DINO 运动描述子 $\tau = \{z_t, ..., z_{t+L-1}\}$，$z_i \in \mathbb{R}^d$。
- 每一步：Task Planner 根据 $(o_t, \ell, c_k)$ 提出 $c_{k+1}$；Track Predictor 把 $c_k \to c_{k+1}$ 映射为 $\tau_k$；低层策略输出 $a_{t:t+L-1} \sim \pi_L(\cdot | o_t, c_k, \tau_k)$。

### 2.3 Task Planner（离散、可验证的三元组）
- **Relation Predictor（关系预测器）**：两级级联结构
  - **LTP（轻量 Transformer 预测器）**：4 层 Transformer + 2 层线性层，输入为 SAM2 解码器给出的每实例 token，输出 $P_t \in \mathbb{R}^{n \times n \times |\mathcal{R}|}$，对每个有序物体对的关系做 softmax。预测方法 $\hat r^{LTP}_{xy}(t) = \arg\max_{r \in R} P_t(x, y, r)$。
  - **错误模式分析**：定义 spurious flip (FP) 和 missing change (FN)，证明当 $\rho < \frac{2p}{1+3p}$（实测 $p \in (0.80, 0.90)$, $\rho \approx 0.02$）时抖动翻转主导。
  - **事件触发 VLM 校验器**：仅当窗口 argmax 变化时才调用 LoRA 微调的 InternVL2.5，在实例 mask 约束下分类，从而高响应+高精度。
- **Graph-Guarded Next Triplet Generator（图约束下一三元组生成器）**：
  - 从人类视频中构建**时序图** $G=(V,E)$：节点 = 任务相关三元组，边 = 观测到的可行 transition。通过相邻帧的 relation table $R_t$ 与 $R_{t+1}$ 的差异抽取并去重合并。
  - 将图编码为邻接矩阵 $A$，当前节点 $c_k$ 对应行作为候选掩码 $M_k$，零样本 VLM（如 GPT-4o）只在 $M_k$ 范围内打分支。
  - **闭包执行规则**：若 guard set 全部满足（$G_k = 1$），按掩码选下一节点；否则 relocalize 至 $c_0$ 并重规划。形式化：
  $$c_{k+1} = \begin{cases} \mathrm{VLM}(o_t, \ell, c_k, M_k), & G_k = 1 \\ c_0, & G_k = 0 \end{cases}$$

### 2.4 Track Predictor（连续轨迹）
- **数据准备**：由 Relation Predictor 给出 transition $(x, r \to r', y)$，使用 Grounding-DINO + SAM2 取出 $x,y$ 的像素 mask $(M_x, M_y)$，用 mask 衍生 box 内 seed 点 + CoTracker3 抽取实体对齐轨迹 $V_{t:t+H}$，构成样本 $D_{x:y} = \{(O_{t:t+H}, M_x, M_y, V_{t:t+H}, e(r \to r'))\}$，其中 $e(r \to r')$ 为关系 delta 的离散文本嵌入。
- **多模态掩码轨迹预测**：借鉴 ATM 的设置，把 mask 与关系 delta 同时 token 化并经 Transformer backbone + 轨迹解码器输出预测 $v_{t+1}$。  
- **辅助损失**：(1) 掩码 patch 重建；(2) 关系变化识别（用 mask 解码器特征 + 文本 decoder 中间 token 预测 $\delta_r$）。
- **关键设计**：轨迹以三元组 transition 为条件而非纯运动先验，从而具备更强的归纳偏置，提升物体级与组合泛化。

### 2.5 Action Policy（动作生成）
- 训练样本 $D^t_{\text{act}} = \{O_{t:t+H}, S_t, A_t, M_x, M_y, e\}$，$A_t$ 为 7 维末端位姿 + 1 维夹爪宽度。
- 网络 = Transformer backbone + MLP Action Head，并配有可学习 action token；action token 与轨迹先验再次融合后解码出 $a_t$；训练用 L2 回归损失。
- **推理**：滚动时窗，每 5 步由 Relation Predictor 校验当前 $c_{k+1}$ 是否完成；guard 违规则回溯到 $c_0$ 重规划。

## 3. 实验设计

### 3.1 硬件与任务场景
- **机器人**：7-DoF Franka；**相机**：两路 1280×720 Intel RealSense D435i（第三人称 + 眼在手）。
- **三类任务族**：
  - **Dynamic Scale Balancing (DSB)**：左盘一堆青蛙配重，需将棕/蓝/红配重按需放入右盘以保持平衡，要求**闭环**重规划（最多 12 个子目标）。
  - **Sequential Stacking (SS)**：按指定顺序（如红-黄-蓝）堆叠方块；训练仅见一种顺序，测试需推广到新顺序（最多 11 个子目标）。

公平性处理：Relation Predictor 仅用于任务完成检测与 guard 校验，不为基线 VLM 提供额外空间监督。

## 6. 主要结论与发现
- TTS 在 7 个真实长时序设置中平均 74.8% 成功率，显著超过最强基线（SeeDo 30.4%）。
- **结构化的实例-空间表示**（三元组 + 轨迹）既能抑制规划幻觉，又能让执行可追溯。
- **闭环 guard + 时序图约束**显著降低逻辑错序与对象误选的发生率（DSB 上 78.6% vs 26.7%）。
- **以三元组 transition 为条件的轨迹预测器**在数据极少时（≤40 条机器人示教）仍能保持可用性能，体现数据高效。
- 级联 LTP+VLM 关系预测器在速度（32.2 s vs 仅 VLM 的 202.6 s）与精度（98.4% vs 98.8%）之间达到可接受折中。
- 支持**对象级**（DPP 跨类别）与**组合级**（SS 新顺序）的双重泛化。

## 7. 优点
- **可解释、可追溯**：每一步对应显式三元组与轨迹，失败可定位到规划或控制层。
- **实例接地**：用 $(x, r, y)$ 把空间关系绑定到具体实例，避免纯语义规划的幻觉。
- **闭环反馈**：guard 校验 + relocalize 至 $c_0$ 重规划，应对执行偏差与扰动。
- **数据高效**：人类视频构建时序图 + Track Predictor 在动作无关视频上预训练，大幅减少对机器人数据需求。
- **级联感知**：LTP 高频 + VLM 事件触发校验兼顾响应性与精度。
- **方法桥梁清晰**：离散三元组 ↔ 连续轨迹的显式接口，让规划与控制对齐。

## 8. 不足与局限
- **图外失败**：当 transition 未出现在人类视频所建图 $G$ 内时系统失效，规划被 mask 限制而无法生成新分支。
- **感知误差依赖**：Relation Predictor 与 SAM2/Grounding-DINO 的错误会沿级联向上传播，影响 guard 判据。
- **非三元组任务**：可形变物体、流体、布料等任务难以用预定义关系词表 $R$ 表达。
