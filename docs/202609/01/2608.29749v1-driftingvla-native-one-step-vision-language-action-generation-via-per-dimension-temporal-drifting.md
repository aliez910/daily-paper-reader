## 摘要
传统的基于流的视觉-语言-动作（VLA）模型支持表达丰富的连续动作生成，但依赖多步细化来生成每个动作块，增加了在线机器人控制中的延迟。为解决这一问题，我们提出了DriftingVLA，一种原生一步式VLA，仅通过单次动作专家前向传播即可生成完整的动作块。DriftingVLA无需学习在推理时需要迭代积分的速度场，而是采用分布漂移目标来学习直接的从噪声到动作块的映射，以实现一步部署。由于机器人动作维度具有不同的控制语义和分布特征，我们进一步引入了逐维度时间漂移（PDTD）。PDTD将每个动作维度的完整时间轨迹视为独立的漂移单元，从而实现更细粒度的建模并塑造维度特定的动作分布。这种逐维度分解仅作用于训练目标；共享的VLA模型仍然联合生成完整的动作块，从而保留跨维度依赖关系。DriftingVLA在LIBERO上取得了98.32%的成功率，在RoboTwin 2.0上取得了81.09%，在六个真实世界单臂和双臂任务上取得了77.67%，优于所评估的多步流策略和一步式VLA基线方法。原生一步式部署还使动作块生成速度提升了3.36倍，在不牺牲控制性能的情况下消除了迭代细化过程。

## Abstract
Conventional flow-based vision-language-action (VLA) models support expressive continuous action generation but rely on multi-step refinement to produce each action chunk, increasing latency in online robot control. To address this issue, we introduce DriftingVLA, a native one-step VLA that generates a complete action chunk with a single action-expert forward pass. Rather than learning a flow field that requires iterative integration at inference, DriftingVLA uses a distribution-drifting objective to learn a direct noise-to-action-chunk mapping for one-step deployment. Since robot action dimensions carry distinct control semantics and distributional characteristics, we further introduce Per-Dimension Temporal Drifting (PDTD). PDTD treats the complete temporal trajectory of each action dimension as a separate drifting unit, enabling finer-grained modeling and shaping of dimension-specific action distributions. This per-dimension decomposition applies only to the training objective; the shared VLA model still generates the complete action chunk jointly, thereby preserving cross-dimensional dependencies. DriftingVLA achieves 98.32% success on LIBERO, 81.09% on RoboTwin 2.0, and 77.67% across six real-world single- and dual-arm tasks, outperforming the evaluated multi-step flow policy and one-step VLA baselines. Native one-step deployment also delivers a 3.36-fold speedup in action-chunk generation, eliminating iterative refinement without sacrificing control performance.

# DriftingVLA 论文总结

## 1. 核心问题与整体含义

**研究背景与动机：**
- 近年来，基于流匹配（Flow Matching）的视觉-语言-动作（VLA）模型成为机器人端到端控制的主流方案，能够表达丰富的连续动作分布。
- 然而，这类方法在推理阶段需要对每个动作块执行**多步迭代求解 ODE**（例如 10–20 步积分），生成一个动作块延迟较高，难以满足实时在线控制的需求。
- 现存一步式 VLA（如基于一致性模型/扩散蒸馏的方案）虽然减少了步数，但通常带来性能下降，或者需要复杂的蒸馏流程。
- 同时，机器人动作的不同维度（如末端位置 xyz、姿态旋转、夹爪开合、关节角等）具有**完全不同的物理含义与统计分布**，一刀切的统一扩散/流场难以精细刻画各维度。

**整体目标：** 设计一个**原生一步（native one-step）** 的 VLA 模型，无需迭代细化即能输出高质量动作块，同时对每个动作维度的轨迹进行更细粒度的建模。

## 2. 方法论

### 2.1 核心思想
将传统流匹配中"学习速度场→积分 ODE 得到动作"的两阶段范式，替换为**分布漂移目标（Distribution-Drifting Objective）**：直接学习从噪声分布到动作块分布的端到端映射，单次前向传播即可生成完整动作块。

### 2.2 关键技术细节

**（1）分布漂移训练目标**
- 不再预测速度向量  $v_\theta(x_t, t)$，而是在不同时间步 $t\in[0,1]$ 上让网络直接预测**去噪后的样本** 或采用类似 Consistency / Mean-Flow 的捷径。
- 训练时最小化模型预测与真实动作之间的直接回归损失，使模型在 $t=0$ 时只需一次前向即可得到最终动作块。
- 推理阶段无需数值积分器，显著降低延迟。

**（2）逐维度时间漂移（Per-Dimension Temporal Drifting, PDTD）**
- 将一个动作块 $A\in\mathbb{R}^{D\times H}$（$D$ 为动作维度，$H$ 为时间步长度）拆分为 $D$ 个独立的**逐维度时间轨迹**。
- 对每个维度单独施加漂移/扩散时间表（timestep schedule），使每个维度可以根据自身分布特性（如方差大小、量纲、变化幅度）学习各自合适的噪声调度。
- **关键点**：PDTD **只作用于训练目标**；在网络前向时，共享的 VLA 模型仍然**联合生成完整动作块**，从而保留跨维度依赖关系。
- 这一解耦使得：训练目标更细粒度、可针对性强；推理保持高效且动作整体一致性。

**（3）模型架构**
- 采用主流 VLA 范式：视觉编码器（如 SigLIP / DINOv2）+ 大语言模型主干 + 动作专家（action expert）。
- 动作专家接收 token 级条件（来自 LLM 的融合表征），输出整个动作块。
- 在 LIBERO / RoboTwin / 真实任务上的训练均基于该统一架构。
