## 摘要
人类视频数据集已成为昂贵真实机器人数据的一种极具吸引力的替代方案，能够以可扩展的方式提供丰富的多样性。为了弥合人类与机器人之间的具身差异，现有方法通常在任务匹配的设定下对视频进行机器人化处理，或在大规模数据上分别处理观察与动作的对齐问题。在本工作中，我们系统地考察了机器人化后的人类视频能否为视觉-语言-动作（VLA）策略的预训练提供有效且可扩展的监督信号。为此，我们开发了一条机器人化处理流程，能够将异构的人类视频转换为与机器人对齐的观察和动作轨迹，同时跨标注层级推断缺失的中间信号。基于该流程，我们构建了 HuRo 数据集，包含来自五个人类视频源的约 63 万个机器人化片段以及 1.42 亿帧经过处理的图像。在四个真实世界操作任务上的实验表明，增加机器人化预训练的数据规模可将整体任务完成率从 51.5% 提升至 80.3%，并在空间与视觉偏移条件下的分布外（OOD）完成率从 34.9% 提升至 72.2%。进一步的消融实验显示，视觉层面的机器人化能够提升分布外鲁棒性，而结合动作重定向的端到端预训练优于仅依赖视觉的迁移方法。代码与数据已在项目网站发布：https://3587jjh.github.io/HuRo。

## Abstract
Human video datasets have emerged as a compelling alternative to expensive real-robot data, offering rich diversity at scale. To bridge the human-to-robot embodiment gap, existing approaches either robotize videos in task-matched settings or address observation and action alignment separately at scale. In this work, we systematically examine whether robotized human videos can provide effective and scalable supervision for pretraining vision-language-action (VLA) policies. To this end, we develop a robotization pipeline that converts heterogeneous human videos into robot-aligned observations and action trajectories while inferring missing intermediate signals across annotation levels. Using this pipeline, we construct the HuRo dataset, comprising about 630K robotized episodes and 142M processed frames from five human-video sources. Across four real-world manipulation tasks, increasing robotized pretraining scale improves overall completion from 51.5% to 80.3% and OOD completion under spatial and visual shifts from 34.9% to 72.2%. Ablations further show that visual robotization improves OOD robustness and that end-to-end pretraining with retargeted actions outperforms visual-only transfer. Code and data are released on our website: https://3587jjh.github.io/HuRo.

## 2. 方法论

### 2.1 整体思路

构建一条"人类视频 → 机器人化片段（episode）"的流水线，将异构人类视频转换为包含语言指令、机器人对齐图像、机器人状态与动作的统一格式片段，用于 VLA 端到端预训练。

### 2.2 流水线三大阶段

**（1）人类视频标注（Human Video Annotation）**
- 相机内参估计：`droidcalib` 为主，静态片段回退 `AnyCalib`，将原图矫正为针孔图像；
- 手部检测与跟踪：`100DoH` + `BOT-SORT`，左右手分别获得时序一致的裁剪框；
- 手部姿态估计：`HAWOR` 输出 MANO 手部姿态 \(P_t^h\)（\(h\in\{L,R\}\)），包含腕部、指尖与局部结构信息；
- 相机轨迹估计：手部区域 mask 后的 `DROID-SLAM`，结合 `MoGe-2` 恢复公制尺度，`GeoCalib` 与重力对齐；
- 切片与 VLM 标注：按手部有效帧聚类形成操作片段，切分为定长 chunk；将手腕轨迹投影到 RGB 上送入 `Qwen3.5`，为每个 chunk 生成一条指令 \(l_i\)，并做一致性校验；
- 输出标注 chunk：\(H_i = (\{I_t\}, K, \{T^{W\leftarrow C_{src}}_t\}, \{P_t^h\}_{h\in\{L,R\}}, l_i)\)。

**（2）动作转换（Action Conversion）**
- 提取指尖位置与局部手部结构作为 IK 目标，从 \(C_{src}\) 变换到世界系 \(W\)；
- 估计 chunk 级对齐变换 \(T^{B\leftarrow W}_{\xi_i}\)（3D 平移 + 偏航），将人类手部目标映射到机器人基座系；
- 用 `PyRoKi` 两阶段 IK 求解：
  - **稀疏阶段**：联合优化 \(T^{B\leftarrow W}_{\xi_i}\) 与稀疏时间步关节构型，目标包括指尖位置、局部手部结构、视角一致性和关节限制/静止正则；
  - **稠密阶段**：固定对齐后对完整轨迹 \(\{q_t\}\) 优化，额外加时序平滑项；
- 通过正向运动学得到策略状态序列 \(\{s_t\}\)；
- **动作派生**：因人类视频无机器人动作，定义为状态差 \(a_t = s_{t+1}\)，最后一步重复末端状态。

**（3）视觉转换（Visual Conversion）**
- 用 `SAM2`（+ `Detectron2` 辅助提示）分割人体手臂区域，`ProPainter` 修补得到干净帧 \(\bar{I}_t\)；
- 用 `Isaac Sim` 渲染目标机器人：相机内参 \(K\)、对齐后的自中心相机轨迹 \(T^{B\leftarrow C_{obs}}_t = T^{B\leftarrow W}_{\xi_i}\cdot T^{W\leftarrow C_{src}}_t\) 与关节构型 \(q_t\)；
- 合成机器人化观测 \(\tilde{I}_t\)；
- 输出 HuRo 片段：\(E_i = \{(\tilde{I}_t, s_t, a_t, l_i)\}\)。

### 2.3 跨标注层级的统一处理

- 5 个数据源标注完备度差异大（Ego4D/EPIC 仅 RGB，Ego10K 多相机内参，EgoVerse/EgoDex 还含相机几何与手部姿态）；
- 流水线"按需估计缺失信号"，最终将所有源统一到同一机器人表示，实现异构融合。

### 2.4 HuRo 数据集（ALLEX 形态实例）

- 目标机器人 ALLEX：双臂 7-DoF + 双手 15-DoF + 2-DoF 颈 + 2-DoF 腰；
- 5 个数据源：EgoDex 56%、EgoVerse 27%、Ego4D 10%、Ego10K 6%、EPIC-Kitchens 2%；
- 规模：**约 63 万 episodes，1.42 亿帧，约 1,317 小时（30 fps）**。

### 2.5 VLA 策略训练

- **架构**：基于 `GR00T-N1.6-3B`（VLM + DiT 动作头）；
- **动作接口**：EEF 形式，左右腕 6D 相对位姿（连续 6D 旋转）+ 双手关节绝对目标；
- **预测**：H=40 步动作块；
- **训练**：flow-matching 目标，VLM 初始化为 GR00T-N1.6-3B checkpoint，动作头从零初始化；视觉编码器联合微调；
- **超参**：预训练 80k 步、全局 batch 2048、AdamW、lr=1e-4、weight decay=1e-5；下游微调 30k 步、batch 128、lr=1e-4 + cosine。

## 3. 实验设计

### 3.1 真实机器人任务（ALLEX，4 个）

|---|---|---|---|
| Apple Pick-and-Place | 43 | 12/12 | 单臂 pick-and-place |

### 3.2 主要对比与消融

- **Scaling 消融**：HuRo 数据集按比例采 0% / 10% / 50% / 100%；
- **视觉机器人化消融**：100% PT + 去除机器人叠加（保留人类观测 + 重定向动作）；
- **端到端 vs. 仅视觉迁移**：No PT / PT(Visual Only)（仅复用视觉通路，初始化动作头）/ PT(Visual + Action)；
- **参考模型**：`π0.5`、`GR00T N1.6`（用其官方预训练 checkpoint 直接微调）；
- **附录补充对比**：
  - 与 Masquerade 风格机器人化（固定外参 EEF + Hand）；
  - 与人类域预训练对比（Human-HRDT、Human-VITRA）；
  - 与视频生成预训练 I2V + IDM（DreamGen 范式）在 0.7M/3.5M/7M 帧预算下比较；
  - OpenArm 跨形态迁移、Diverse Pick-and-Place 多抓取任务；
  - 多形态联合预训练（ALLEX + OpenArm）。

### 3.3 Benchmark 与评价指标

- ID（分布内）与 OOD（空间/视觉偏移）完成率；
- 视觉/语言覆盖率：基于 DINOv3 特征与 OpenImages 参考集；
- 流水线质量诊断：旋转/平移误差、手部关键点误差、IK 指尖残差、关节限位/自碰撞、画面修复 PSNR、人体去除率。

## 5. 实验数量与充分性

- **控制变量实验**：4 任务 × 4 规模（0%/10%/50%/100% PT） + No-overlay 变体 + 参考模型 = 主实验丰富且对齐清晰；
- **案例研究**：Cup Stacking 单独深挖（ID/OOD 表现 + 抓取质量定性分析）；
- **消融覆盖**：
  - 视觉机器人化的有无；
  - 端到端 vs. 仅视觉迁移（带 4 种物体、ID/OOD 各 36/18 次试次）；
  - 与 Masquerade 风格机器人化对比（共享标注、仅改变机器人化方式）；
  - 与人类域预训练对比（Human-HRDT、Human-VITRA）；
  - 与视频生成预训练 I2V+IDM 在 3 个数据规模上的对比；
  - 跨形态迁移（ALLEX→OpenArm）；
  - 多形态联合预训练（ALLEX + OpenArm）。
- **覆盖度评估**：使用 DINOv3 + OpenImages 计算视觉覆盖；统计唯一动词、唯一物体、动宾对；
- **统计性**：每任务 12–24 次真实 rollout；同一实验在独立环境复测以保证公平性；
- **客观性**：所有基线共享同一架构与训练流程，仅改变"机器人化方式"或"预训练数据来源"，对照组设计干净；
- **附录还提供**：详细 rollout 协议、子目标评分规则、流水线伪代码、覆盖率词云、关节限位与碰撞审计、相机对齐误差分布等。
- **总体**：实验设计较为充分，覆盖 scaling、消融、跨源、跨形态、人/机器人形态对比与生成式方法对比，对照公平；但任务数仍较少（仅 4 个真实任务 + 2 个补充任务），真实机器人试验次数有限，可能影响统计推断强度。

## 6. 主要结论与发现

1. **可扩展性**：随着 HuRo 数据集预训练规模增大，下游真实操作完成率单调提升；
   - 整体完成率：51.5% → 80.3%；
   - ID：68.1% → 88.4%；
   - OOD（空间+视觉偏移）：34.9% → 72.2%。
2. **超越基线**：100% HuRo 预训练在 ID 与 OOD 上同时优于 `π0.5`、`GR00T N1.6`。
3. **视觉机器人化的必要性**：去除机器人叠加后 ID 仅略降（89.4% vs 88.4%），但 OOD 显著下降（55.7% vs 72.2%），且不如 10% PT 的 OOD（59.5%），说明视觉对齐带来独立于动作监督的鲁棒性收益。
4. **端到端动作预训练不可替代**：PT(Visual Only) 仅带来微弱提升（ID 31.9%、OOD 13.9%），而 PT(Visual + Action) 达 ID 61.1%、OOD 50.0%，说明动作头也要端到端预训练。
5. **优于视频生成路线**：在 0.7M / 3.5M / 7M 帧三种预算下 HuRo 均优于 I2V+IDM；HuRo 在 0.7M 帧就优于 I2V+IDM 的 7M 帧；I2V+IDM 在 OOD 上 3.5M→7M 几乎停滞，HuRo 持续上升。
6. **跨形态迁移**：ALLEX 预训练可有效迁移到 OpenArm，Human-HRDT 在 ID 略优但 OOD 更差，HuRo 整体最佳。
7. **多形态联合**：ALLEX+OpenArm 联合预训练在 Diverse Pick-and-Place 上达 ID 91.7% / OOD 77.8%，优于仅 ALLEX 预训练。
8. **异构源的价值**：50% 混合源（~71M 帧）的视觉/语言覆盖均高于全量 EgoDex（78.9M 帧），且下游表现更佳。

## 7. 优点

- **流水线工程完整**：跨标注层级统一处理，标注差异大的异构源（5 个）可融合；
- **联合观测-动作机器人化**：相比仅视觉或仅动作的工作，更接近真实部署形态；
- **Scaling 行为清晰**：在多个任务、ID/OOD 上都展示出稳定的规模化收益；
- **消融全面且控制干净**：通过共享架构与训练流程，仅切换"机器人化方式"或"预训练数据来源"，保证对比公平；
- **跨形态验证**：ALLEX 主实验 + OpenArm 迁移 + 多形态联合预训练，验证泛化潜力；
- **对比广度**：同时与人类域预训练（HRDT/VITRA）和视频生成路线（I2V+IDM）对比；
- **公开承诺**：代码与数据开源（含流水线伪代码、覆盖率分析、质量审计），社区友好；
- **可解释性分析**：Cup Stacking 案例研究与抓取行为定性图帮助理解失败模式。

## 8. 不足与局限

- **机器人化保真度有限**：
  - 机器人叠加未显式建模机器人与场景几何之间的遮挡关系；
  - inpainting 与渲染伪影仍存在；
  - 不同保真度对下游策略学习的影响未系统研究；
- **缺乏力/触觉信号**：机器人化仅提供视觉与运动学动作，无法用于接触丰富任务；
- **运动学重定向无物理建模**：未建模自碰撞与接触；审计显示仅 55.2% 轨迹无检测到的非抓取自接触，说明轨迹仅适合作为"预训练监督"而非可执行示教；
- **关节限位合规率仅 62.5%**（虽投影后全部合规，但原始轨迹存在限位越界）；
- **真实任务与试次有限**：仅 4 个真实任务（+2 个补充），每任务 12–24 次真实 rollout，统计强度较弱；
- **算力信息不充分**：未给出分布式训练规模、训练总时长、能耗等，难以判断实际复现成本；
- **数据源偏差风险**：EgoDex 占 56% 主导，分布偏向特定操作类型，可能影响预训练偏差；
- **场景局限**：评估集中在桌面级 ALLEX 操作，未覆盖移动操作、长时序任务、动态环境；
- **依赖重组件较多**：HAWOR、SLAM、MoGe-2、ProPainter、Isaac Sim、Qwen3.5 等任一环节出错都可能影响最终数据质量；
- **未直接与"任务匹配机器人化"基线做严格等价对比**：与 Phantom / DexUMI / WARPED / RwoR 等方法的差异主要在设定层面，未在同一基准上横向打分。
