## 摘要
基于视觉-语言-动作（VLA）策略的长时程机器人操控任务在执行过程中仍然容易出现偏差，因为仅凭最终任务是否成功难以诊断和纠正由动作噪声、物体位移或目标错位所导致的失败。本文提出一种阶段感知的失败验证与提示恢复框架，能够在不更新参数且不依赖特权仿真器状态的前提下，对固定的VLA策略进行闭环纠错。该框架引入了一种基于可观测历史的学习验证器，通过对多视角视觉观测、本体感知状态以及已执行动作进行时序建模，联合估计操控进度与执行风险。为提供可解释的任务理解，框架通过语义进度阶段（包括接近、对齐、抓取、运送与放置）对操控执行过程进行建模，并识别各阶段特有的失败模式。在检测到异常执行后，框架保留原始指令并生成阶段条件化的恢复提示，从而使同一个冻结的VLA策略能够产生纠错动作。在LIBERO和LIBERO Plus上进行的大量多轮评估表明，所提方法在多种扰动下显著提升了闭环可靠性。在无法访问特权物体或目标坐标的情况下，学习验证器在所评估场景中取得了接近特权基于规则验证器的恢复性能。上述结果表明，可观测的视觉-本体感知-动作历史足以推断潜在的任务状态，并使现有VLA策略实现实用的失败恢复。

## Abstract
Long-horizon robot manipulation with Vision-Language-Action (VLA) policies remains vulnerable to execution-time deviations, as final task success provides little information for diagnosing and correcting failures caused by action noise, object displacement, or goal misalignment. We introduce a stage-aware failure verification and Prompt Recovery framework that enables closed-loop correction of a fixed VLA policy without parameter updates or privileged simulator states. The framework introduces an observable-history-based Learned Verifier that jointly estimates manipulation progress and execution risk by temporally modeling multi-view visual observations, proprioceptive states, and executed actions. To provide interpretable task understanding, we represent manipulation execution through semantic progress stages, including approach, alignment, grasp, transport, and placement, and identify stage-specific failure patterns. Upon detecting abnormal execution, the framework preserves the original instruction and generates a stage-conditioned recovery prompt, allowing the same frozen VLA policy to produce corrective actions. Extensive multi-round evaluations on LIBERO and LIBERO Plus demonstrate that the proposed approach substantially improves closed-loop reliability under diverse perturbations. Without access to privileged object or goal coordinates, the Learned Verifier achieves recovery performance close to that of the privileged rule-based verifier in the evaluated settings. These results show that observable visual-proprioceptive-action history is sufficient to infer latent task states and enable practical failure recovery for existing VLA policies.

# VLA-Corrector 论文总结

## 一、核心问题与研究动机

- **核心痛点**：现有的视觉-语言-动作（VLA）策略（如 RT-2、π0、OpenVLA、Octo 等）在长时程机器人操控任务中，能够生成符合指令的动作序列，但缺乏**执行状态感知**与**闭环纠错**机制，即"知道要做什么，却不知道是否做对了"。
- **失败来源**：在真实交互过程中，动作噪声、物体位移、抓取误差、目标区域偏移等微小的执行偏差会逐步累积，导致轨迹偏离。
- **现有方法的不足**：
  - 动作分块（action chunking）与重规划（replanning）机制在两次查询之间存在延迟窗口，旧动作可能在环境变化后仍被执行；
  - 缺乏基于可观测信号的执行风险监控与恢复触发机制；
  - 已有恢复方案多依赖策略微调、额外动作头或特权仿真器状态，难以在真实部署中使用。
- **研究问题**：能否仅凭可观测的交互历史（视觉、本体感知、已执行动作）来推断潜在的任务执行状态，并在不修改底层冻结 VLA 策略的前提下实现闭环纠错？

## 二、方法论

### 2.1 整体框架（VLA-Corrector）

- **闭环流程**：观测与指令 → π0.5 冻结策略 → 动作分块 → 风险验证器 → 触发门控 → Prompt Recovery → 任务恢复。
- **核心设计原则**：
  - 策略能力与执行可靠性**解耦**：VLA 生成动作，验证器负责监控与恢复；
  - 底层 VLA 策略参数完全冻结（base π0.5 = OpenPI pi05_libero）；
  - 不访问任何特权仿真器状态（物体/目标坐标、BDDL 谓词等）。

### 2.2 关键技术模块

- **特权基于规则的验证器（Privileged Rule-Based Verifier）**：
  - 使用状态机 `APPROACH → ALIGN → GRASP → MOVE → PLACE → SUCCESS`；
  - 利用仿真器地面真值（物体位姿、末端运动学、距离、夹爪状态、运动谓词）发出结构化恢复记录；
  - 仅作为**性能上界参考**，不可部署。

- **学习型验证器（Learned Verifier）**：
  - **输入**：双视角 RGB（agent-view + wrist-view，分辨率 112×112）、8 维本体感知状态、7 维已执行动作；
  - **历史窗口**：8 步序列，每 2 个环境步采样一次；
  - **视觉分支**：参数自由的空间统计特征器（3×4×4 自适应平均池化 + RGB 均值/标准差）→ 每视图 54 维 → 拼接投影至 64 维；
  - **状态-动作分支**：15 维向量投影至 32 维；
  - **时序融合**：GRU（隐藏维度 64）；
  - **双预测头**：
    - 执行风险：`p_t = σ(w_fᵀ z_t + b_f)`，预测 10 步预测视域内是否发生失败事件；
    - 执行阶段：`ĉ_t = argmax_c Softmax(W_stage z_t + b_stage)`，五类（APPROACH, ALIGN, GRASP, MOVE, PLACE）；
  - **训练数据**：120 集 episode（60%/20%/20% 训练/验证/测试划分），30 epoch，batch size 32，学习率 10⁻³，权重衰减 10⁻⁴，**CPU 训练**。

- **教师监督对齐机制**：
  - 教师不提供特权坐标作为回归目标；
  - 将特权任务进度转化为操作标签：`min |e − t| ≤ 10` 标记为正（风险），`> 20` 为负，中间区域排除训练；
  - 阶段头仅作为**恢复路由器**，不是 5 类风险检测器。

- **在线触发门控**：
  - 阈值 τ = 0.40，四帧连续确认，10 步冷却期，每 2 个环境步查询一次；
  - 低置信度（< 0.9625）的阶段估计路由到通用恢复提示 `UNKNOWN_FAILURE`。

- **Prompt Recovery**：
  - 形式：`q_rec = q ⊕ r_t`（原任务指令 + "Immediate recovery: " + 阶段指令）；
  - 触发时丢弃待执行动作块，用同一冻结 π0.5 策略生成恢复动作（最多 100 步）；
  - 恢复完成后立即恢复原指令继续执行。

## 三、实验设计

### 3.1 数据集 / 基准

- **仿真**：
  - 标准 LIBERO（聚合 SPATIAL、GOAL、OBJECT、10、90 五个子套件）；
  - LIBERO Plus（对应 Spatial、Goal、Object、10 子套件的难度 4 和难度 5）。
- **真实环境**：物理机器人平台上的三个代表性任务：
  - Pick and Open（玩具抽屉）；
  - Place（木块放入四格盒）；
  - Pour Water（塑料瓶倒水）。

### 3.2 扰动协议

- **Clean**：无扰动；
- **Action Noise**：零均值高斯噪声 σ = 0.1；
- **Target-Object Shift**：目标物体 XY 坐标偏移 0.1 m；
- **Goal-Region Shift**：目标区域 XY 坐标偏移 0.1 m；
- **Combined**：上述三者叠加；
- 图像噪声关闭（image_noise_std = 0.0）。

### 3.3 对比方法

| 配置 | 在线验证器 | Prompt Recovery |
|---|---|---|
| No Assistance | 无 | 无 |
| Rule + Prompt | 特权基于规则验证器 | 有 |
| Learned Binary + Prompt | 学习型验证器 | 有 |

三者共享同一冻结 VLA 策略与初始状态/种子/扰动协议（replan_steps=5，正常执行上限 280 步，每次恢复最多 100 步）。

### 3.4 评估指标

- 主指标：回合成功率（success rate）；
- 验证器质量：Accuracy、Precision、Recall、Positive F1、AUROC、AUPRC；

## 六、主要结论与发现

- **仿真结果**：
  - 标准 LIBERO：No Assistance 70.9% → Rule + Prompt 82.6%（↑11.7），Learned Binary + Prompt **80.2%**（↑9.3）；
  - LIBERO Plus 难度 4：73.7% / 79.7% / **79.0%**；
  - LIBERO Plus 难度 5：66.7% / 73.6% / **72.6%**；
  - 在 Combined 扰动下提升最显著（+11.7 pp / +9.3 pp）；
- **学习型验证器性能**：93.1% Accuracy、61.1% Precision、94.9% Recall、74.4% Positive F1、AUROC 0.902、AUPRC 0.7123；
- **触发门控**：79.2% 触发精度，恢复成功率 77.0%（Rule）/ 75.0%（Learned）；
- **真实世界**：平均成功率 88.3% vs. 基线 82.5%（↑5.8 pp）；
- **核心结论**：
  - 可观测的视觉-本体感知-动作历史足以推断潜在任务状态并实现实用恢复；
  - 学习型验证器性能接近特权基于规则验证器（差距 ≤ 2.4 pp）；
  - 阶段感知 Prompt Recovery 是冻结 VLA 策略获取恢复能力的有效接口。

## 七、优点与亮点

- **非侵入式设计**：完全冻结底层 π0.5 策略参数，不修改视觉编码器或动作头，可作为通用插件；
- **验证器-策略解耦**：将状态估计与控制策略分离，避免昂贵的策略再训练；
- **阶段感知语义建模**：将操作过程抽象为五个可解释阶段，失败模式可被识别与路由；
- **轻量化验证器**：仅参数自由的视觉特征化器 + GRU + 双预测头，CPU 上亚毫秒推理，部署门槛低；
- **统一接口**：Rule-based 与 Learned Verifier 共享同一 Prompt Recovery 接口，使性能差异完全归因于验证器能力；
- **扰动可控的评估协议**：在 LIBERO/LIBERO Plus 上系统注入噪声与空间偏移，便于复现与对比；
- **仿真 + 真实双重验证**：从仿真基准迁移到真实机器人平台，且无需真实数据微调；
- **教师-学生对齐策略**：避免特权坐标回归，阶段头仅作为路由器而非风险检测器，定位清晰。

## 八、不足与局限

- **算力与训练规模偏小**：验证器仅 120 集 episode 在 CPU 上训练 30 epoch，泛化能力与数据规模上限存疑；
- **基线 VLA 单一**：仅验证了 π0.5 一种策略，未报告在 OpenVLA、Octo、RT-2 等其他主流 VLA 上的可移植性；
- **扰动类型有限**：未覆盖光照变化、遮挡、新物体干扰、动态目标等更复杂的真实世界扰动；
- **阶段定义刚性**：五阶段（APPROACH/ALIGN/GRASP/MOVE/PLACE）状态机对任务结构敏感，跨任务类别（如非抓取型任务）可能需要重新设计；
- **触发门控阈值依赖验证集**：τ = 0.40、确认帧数 4、冷却 10 步等超参在验证集上选择后固定，对未见任务的鲁棒性未充分讨论；
- **Precision 较低**：学习型验证器仅 61.1% Precision，可能引入不必要的恢复干预（虽然论文报告触发精度 79.2%，但仍有提升空间）；
- **仿真到真实的迁移细节有限**：真实实验中扰动方式与评估指标较单一，未充分探讨 sim-to-real gap 对验证器的影响；
- **缺乏失败案例的定性分析**：未深入展示典型失败模式（如特定阶段的误触发、特定扰动下的失效）；
- **训练标签依赖特权信号**：尽管验证器仅用可观测输入推理，但教师标签仍依赖仿真器特权状态，纯真实环境下的端到端训练路径未探索。
