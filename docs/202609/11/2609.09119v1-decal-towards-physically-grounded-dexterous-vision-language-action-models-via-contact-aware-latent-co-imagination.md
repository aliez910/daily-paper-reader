## Abstract
Dexterous manipulation involves contact-rich and fine-grained interactions with the physical world, posing significant challenges for existing vision-language-action (VLA) models due to severe visual occlusions and complex contact dynamics. While recent works have incorporated tactile sensing into robotic manipulation, most approaches still rely on homogeneous multimodal fusion, lacking adaptive tactile integration and explicit modeling of physical dynamics. In this work, we present DeCAL, a physically-grounded dexterous vision-language-action model that unifies understanding, imagination and action generation for contact-rich dexterous manipulation. Built upon a Mixture-of-Transformers (MoT) architecture, DeCAL leverages specialized experts for each capability while enabling efficient information flow among them. To effectively leverage tactile information, we introduce Adaptive Visuo-Tactile Fusion that dynamically regulates tactile interactions via a contact-aware gating strategy. Furthermore, we propose Visuo-Tactile Latent Co-Imagination to jointly model visual and tactile dynamics, equipping the policy with implicit physical world knowledge. Experimental results show that DeCAL consistently achieves state-of-the-art performance across all tasks, attaining a 71% average success rate and an 83.4% progress success rate, while also demonstrating strong generalization to unseen scenarios. # DeCAL 论文总结

## 1. 核心问题与整体含义

- 灵巧操作（dexterous manipulation）是机器人领域的关键难题，其核心特征是**接触密集**（contact-rich）和**细粒度**（fine-grained），容易出现严重的视觉自遮挡和复杂的接触动力学。
- 现有视觉-语言-动作（VLA）模型（如 GR00T N1.6、InternVLA-A1）虽然借助大规模预训练在通用任务上取得进展，但在**接触密集场景**下表现欠佳，原因主要有：
  - 视觉遮挡导致接触状态难以观察；
  - 单凭 RGB 缺乏物理可观测性；
  - 缺乏对接触动力学（contact dynamics）的显式建模与未来预测。
- 已有引入触觉的方法（ViTacFormer、DECO 等）大多采用**同质化多模态融合**（homogeneous fusion），未按接触状态自适应地调节触觉贡献，也未对未来视-触交互进行显式想象，因此仍以"反应式"策略为主。
- 论文的目标是提出一个**物理接地的灵巧 VLA 模型**，将理解、想象、动作生成统一起来，并通过接触感知机制充分发挥触觉信号的作用。

## 2. 方法论

### 2.1 整体架构：Mixture-of-Transformers (MoT)
- 三大专家模块：
  - **理解专家 (Understanding Expert)**：基于 Qwen3-VL，融合语言指令、多视角 RGB 与触觉特征，输出跨模态上下文 embedding。
  - **生成专家 (Generation Expert)**：基于 Qwen3，对未来的视觉与触觉潜在进行**并行非自回归想象**，形成物理接地的前瞻表征。
  - **动作专家 (Action Expert)**：基于 Qwen3，使用 **Factorized Flow Matching** 解耦手臂（6+6 DoF）和灵巧手（22+22 DoF）动作的去噪过程。
- **跨模态联合注意力 (Cross-Modal Joint Attention)**：通过分块注意力掩码实现**单向信息流**（Understanding → Generation → Action），并对状态/动作 token 采用非对称注意力设计。

### 2.2 自适应视-触融合 (Adaptive Visuo-Tactile Fusion)
- **触觉特征提取**：每个指尖的变形深度图 (Deform Map) 由共享 ResNet 编码 → 空间池化 → 跨指 Transformer 融合，得到：
  - **局部 token**：保留细粒度接触细节；
  - **全局 token**：汇总所有指尖的整体接触状态。
- **接触感知门控机制 (Contact-Aware Gating)**：
  - 公式为 $\tilde{X} = X + \sigma \odot \text{CrossAttn}(Q_{vl}, K_{local}, V_{local})$；
  - 其中 $\sigma = \text{Gate}(z_{global})$ 由全局触觉 token 派生；
  - 当无接触时 $\sigma$ 趋近 0（主要由视觉驱动），接触发生时显著增大，允许触觉主导动作生成。

### 2.3 视-触潜在协同想象 (Visuo-Tactile Latent Co-Imagination)
- **视觉潜在预测**：用 Cosmos VAE 编码多视角图像，32×32 latent 经 8×8 卷积压缩至 4×4，并行解码预测未来帧；训练时直接对 Cosmos 特征做 L2 回归。
- **触觉潜在预测**：6-DoF 力向量经专用 Force Encoder 编码产生触觉潜在；训练时通过重建未来原始图像 (R)、变形图 (M) 和力向量 (F) 进行间接监督。
- **推理时**：仅在 latent 空间生成未来视-触表征，跳过像素级重建以降低延迟。

### 2.4 训练目标
$$\mathcal{L}_{total} = \lambda_v \mathcal{L}_{visual} + \lambda_t \mathcal{L}_{tactile} + \mathcal{L}_{action}$$
- 视觉前瞻用 Cosmos 特征 L2 回归；
- 触觉前瞻用 raw 图像、变形图、力向量的重建损失加权；
- 动作预测采用 flow matching 目标 $v_\theta$ 拟合传输速度场。

- DeCAL 在**所有 6 个任务**上均取得最高的 SR，平均 SR = **71%**、平均 PSR = **83.4%**，比最强基线高出 15% 以上；

- DeCAL 的未来视觉生成质量（COSMOS Cos↑ 与 LPIPS↓）优于 InternVLA-A1；
- 全局触觉 token 在不同接触模式（wipe、拧、插、压）下呈现清晰聚类，表明触觉表征有效；
- 触觉门控 $\sigma$ 在接触阶段显著上升，在非接触阶段保持低值，验证了自适应融合的有效性；
- 6-DoF 力预测与 GT 高吻合，证明潜在协同想象能有效建模接触动力学。

## 7. 优点

- **统一的 MoT 架构**：把理解、想象、动作三类能力整合在单向信息流框架中，结构清晰且高效；
- **接触感知门控**：用全局触觉 token 自适应调节触觉贡献，避免了"无论是否接触都注触觉"带来的噪声扰动；
- **视-触协同想象**：相比纯视觉前瞻，引入触觉潜在可同时建模几何变形与力动态，使模型在遮挡/接触阶段更稳健；
- **Factorized Flow Matching**：将手臂与灵巧手动作解耦，缓解了高 DoF 下统一去噪导致的协调性退化；
- **真实机器人验证**：任务覆盖广（擦拭、对齐装配、旋转拧开、移液、灯泡螺纹等），并做了 ID + 4 类 OOD 测试；
- **公平对照完备**：除视觉/触觉基线外，专门复现 InternVLA-A1t 进行触觉注入公平比较；
- **实时性可接受**：单卡 RTX 4090 上 0.27 s/chunk 推理延迟。

## 8. 不足与局限
