## 摘要
长时域机器人操作在使用视觉-语言-动作（VLA）策略时仍然容易受到执行过程中的偏差影响，因为最终任务成功提供的信息不足以诊断和修正由动作噪声、物体位移或目标不一致所引发的失败。我们提出了一种阶段感知的失败验证与提示恢复框架，能够在不更新参数或依赖特权模拟器状态的情况下实现对固定VLA策略的闭环修正。该框架引入了一种基于可观测历史的学习验证器，通过对多视角视觉观测、本体感知状态和已执行动作进行时序建模，联合估计操作进度与执行风险。为了提供可解释的任务理解，我们将操作执行过程表示为语义进度阶段，包括接近、对齐、抓取、运输和放置，并识别各阶段特有的失败模式。在检测到异常执行后，框架保留原始指令并生成阶段条件化的恢复提示，使同一个冻结的VLA策略能够产生纠正动作。在LIBERO和LIBERO Plus上的大量多轮评估表明，所提方法在多种扰动下显著提升了闭环可靠性。在无法访问特权物体或目标坐标信息的条件下，学习验证器在所评估场景中达到了接近特权基于规则验证器的恢复性能。这些结果表明，可观测的视觉-本体感知-动作历史足以推断潜在的任务状态，并使现有VLA策略具备实用的失败恢复能力。

## Abstract
Long-horizon robot manipulation with Vision-Language-Action (VLA) policies remains vulnerable to execution-time deviations, as final task success provides little information for diagnosing and correcting failures caused by action noise, object displacement, or goal misalignment. We introduce a stage-aware failure verification and Prompt Recovery framework that enables closed-loop correction of a fixed VLA policy without parameter updates or privileged simulator states. The framework introduces an observable-history-based Learned Verifier that jointly estimates manipulation progress and execution risk by temporally modeling multi-view visual observations, proprioceptive states, and executed actions. To provide interpretable task understanding, we represent manipulation execution through semantic progress stages, including approach, alignment, grasp, transport, and placement, and identify stage-specific failure patterns. Upon detecting abnormal execution, the framework preserves the original instruction and generates a stage-conditioned recovery prompt, allowing the same frozen VLA policy to produce corrective actions. Extensive multi-round evaluations on LIBERO and LIBERO Plus demonstrate that the proposed approach substantially improves closed-loop reliability under diverse perturbations. Without access to privileged object or goal coordinates, the Learned Verifier achieves recovery performance close to that of the privileged rule-based verifier in the evaluated settings. These results show that observable visual-proprioceptive-action history is sufficient to infer latent task states and enable practical failure recovery for existing VLA policies.

# VLA-Corrector 论文总结

## 1. 核心问题与研究动机

- **核心问题**：长时域机器人操控任务中，VLA（Vision-Language-Action）策略虽然能生成符合指令的动作，但缺乏"执行状态感知"能力——即"知道要做什么，但不知道是否做对了"。
- **失败根源**：实际执行中的累积偏差（动作噪声、物体位移、抓取不完美、目标区域偏移）会逐步使原本有效的轨迹偏离，而策略对此毫无察觉，最终导致任务失败。
- **关键缺口**：现有 VLA 系统在"动作生成"与"可靠具身智能"之间存在核心鸿沟，缺少执行过程中的自我监控与纠错机制。
- **研究假设**：能否仅依靠可观测的交互历史（视觉、本体感知、执行动作）推断执行状态，并在不修改基础策略的前提下实现闭环恢复？

## 2. 方法论

### 2.1 整体框架
- **冻结策略**：基础控制器采用 OpenPI π0.5 (pi05_libero) 预训练模型，全程冻结，不修改任何参数。
- **闭环闭环流程为**：观测与指令 → π0.5 策略 → 动作块 → 风险验证器 → 触发门控 → 提示恢复 → 任务恢复。

### 2.2 两种验证器
- **特权规则验证器（Rule-Based Verifier）**：
  - 使用模拟器真值（物体/区域位姿、末端运动学、距离、夹爪状态、运动谓词等）。
  - 维护有限状态机：APPROACH → ALIGN → GRASP → MOVE → PLACE → SUCCESS。
  - 仅作为性能上界参考，部署时不可用。
- **学习验证器（Learned Verifier）**：
  - 输入：8 步可观测历史窗口（每 2 步采样一次），包含双视角 RGB（112×112）、8 维本体感知、7 维执行动作。
  - 视觉分支：无参数空间统计特征化器（3×4×4 自适应平均池化 + RGB 均值/标准差，每视图 54 维）。
  - 序列建模：GRU（隐藏维度 64）。
  - 两个预测头：
    - 二进制风险头：$p_t = \sigma(w_f^\top z_t + b_f)$
    - 阶段分类头：5 类（APPROACH/ALIGN/GRASP/MOVE/PLACE）
  - 教师监督：特权状态机生成阶段标签和失败事件标签，失败窗口定义为 ±10 步内，排除 ±10~20 步的模糊区域。
  - 推理延迟：p50 = 0.457 ms，p95 = 0.589 ms。

### 2.3 在线触发门控
- 阈值 τ = 0.40 + 连续 4 帧确认 + 10 步冷却期。
- 阶段路由：置信度 < 0.9625 则使用通用恢复提示。

### 2.4 提示恢复（Prompt Recovery）
- 公式：$q_t^{rec} = q \oplus r_t$，即在原任务指令后追加阶段条件化的恢复指令片段。
- 同一冻结 π0.5 策略生成恢复动作，完成后立即恢复原始任务指令。
- 无需策略微调、无需额外动作头、无需直接轨迹修改。

## 3. 实验设计

### 3.1 数据集/Benchmark
- **标准 LIBERO**：LIBERO-SPATIAL、LIBERO-GOAL、LIBERO-OBJECT、LIBERO-10、LIBERO-90。
- **LIBERO Plus**：对应的 Spatial/Goal/Object/10 套件，难度等级 4 和 5。

### 3.2 扰动协议
- **干净条件**：无扰动。
- **动作噪声**：归一化动作上叠加 σ=0.1 的高斯噪声。
- **目标物体位移**：XY 偏移 0.1 m。
- **目标区域位移**：XY 偏移 0.1 m。
- **组合扰动**：三者同时施加。

### 3.3 对比方法（三种配置）

|------|----------|---------|
| No Assistance | 无 | 无 |
| Rule + Prompt | 特权规则验证器 | 有 |

### 3.4 评估指标
- 主要指标：回合成功率（1000 个回合/条件）。
- 验证器指标：精度、召回率、正 F1、AUROC、AUPRC。

- **可解释性局限**：阶段标签来自特权教师，学习验证器对阶段的预测准确率未单独报告。
