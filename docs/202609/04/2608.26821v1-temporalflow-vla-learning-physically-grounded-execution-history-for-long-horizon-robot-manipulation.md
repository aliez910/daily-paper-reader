## 摘要
视觉-语言-动作（VLA）模型利用预训练的视觉-语言表征进行机器人控制，然而简单添加历史帧并不能可靠地捕捉近期的物理变化。这在多阶段操作任务中尤为突出，因为视觉上相似的状态可能因先前执行情况不同而需要不同的动作。为应对这一挑战，我们提出了TemporalFlow-VLA，它通过物理锚定的时序监督来学习紧凑的执行历史。利用记录的机器人状态、机器人几何信息和已标定相机，我们构建机器人-表面时序流作为仅在训练阶段使用的目标，并对两个与执行对齐的时序查询进行监督，从而向动作专家提供结构化的历史信息。几何监督路径在部署时不参与推理。TemporalFlow-VLA在LIBERO上达到了97.63 ± 0.26%的平均成功率，其中LIBERO-Long为96.60 ± 0.87%，并在12项RoboTwin任务上取得了85.5%/84.2%的Clean/Randomized成功率。该方法在更长视野、多阶段操作任务上相较于先前方法展现出最为显著的优势。受控历史干预实验表明，动作预测同时依赖于历史内容与时序顺序。借助异步特征缓存，时序条件控制在不引入额外历史编码开销的情况下，保持了单帧级别的服务端采样延迟。总体而言，TemporalFlow-VLA提供了一个紧凑且物理锚定的接口，可利用有序的执行历史，且在部署时无需显式的运动估计或几何处理。

## Abstract
Vision-language-action (VLA) models leverage pretrained vision-language representations for robot control, yet simply adding historical frames does not reliably capture recent physical change. This is especially problematic in multi-stage manipulation, where visually similar states may require different actions depending on prior execution. To address this challenge, we present TemporalFlow-VLA, which learns compact execution history through physically grounded temporal supervision. Using recorded robot states, robot geometry, and calibrated cameras, we construct robot-surface temporal flow as a training-only target and supervise two execution-aligned temporal queries that provide structured history to the action expert. The geometric supervision path is not evaluated at deployment. TemporalFlow-VLA achieves 97.63 +/- 0.26% average success on LIBERO, including 96.60 +/- 0.87% on LIBERO Long, and 85.5%/84.2% Clean/Randomized success across 12 RoboTwin tasks. It shows its clearest advantage over prior methods on longer-horizon, multi-stage manipulation. Controlled history interventions show that action prediction depends on both historical content and temporal order. With asynchronous feature caching, temporal conditioning maintains single-frame-level server-side sampling latency without additional historical-encoding overhead. Overall, TemporalFlow-VLA provides a compact, physically grounded interface for exploiting ordered execution history without explicit motion estimation or geometric processing at deployment.

# TemporalFlow-VLA 论文总结

## 1. 核心问题与研究动机

- **问题背景**：视觉-语言-动作（VLA）模型（如 π0、π0.5）通常仅基于当前 RGB 观测、语言指令和机器人状态生成动作块（action chunk），缺乏对近期执行历史的有效利用。
- **关键挑战**：在多阶段操作任务中，外观相似的状态可能需要截然不同的动作——例如失败的抓取与抓取前状态相似，相同的末端执行器位姿可能对应"接近""抓持"或"恢复"等不同阶段。仅堆叠历史帧并不能可靠刻画近期物理变化。
- **诊断实验（Fig. 2）**：在固定当前帧的情况下打乱 3 帧历史观测，offline action flow-matching loss 几乎不变；而移除历史则使损失上升约 4.6%。说明现有 baseline 对历史顺序不敏感。
- **研究目标**：找到一种结构化、可控、利用有序执行历史的方法，且部署阶段无需额外的运动估计或几何推理开销。

## 2. 方法论

### 核心思想
- **物理锚定的执行历史**：利用记录的关节状态、URDF 几何和相机标定，将机器人表面运动投影到策略 RGB 平面，得到"机器人表面时序光流（robot-surface temporal flow）"，作为**仅训练阶段使用的监督目标**。
- **两个执行对齐的时序查询**：
  - **Q8**：编码 t−8 → t 的近期运动；
  - **Q15**：编码 t−15 → t 的完整历史，可在 Q8 基础上进一步整合。
- **分层有向掩码注意力**：Q8 仅能读取 L、V8、V0、自身；Q15 还可读取 V15 与 Q8。动作 token 只能通过 Q8/Q15 获取历史信息，**禁止直接访问历史图像 patch**。

### 关键技术细节
- **机器人表面光流构建（Eq. 1–6）**：通过正运动学 + 相机标定将源帧机器人像素反向变换到 link 坐标系，再用目标时刻的正运动学前向投影；按 14×14 patch 聚合为 16×16×2 的目标，掩码 Mρ(k) 标记有效机器人支持比例 ≥0.1 的 patch。
- **FiLM 调制解码器（Eq. 11–12）**：Qρ 的最终状态 zρ 通过 γρ/βρ 通道投影对源帧 VLM 空间特征做调制，再用 pointwise MLP 预测光流；两个解码器参数独立、不共享卷积或上采样。
- **损失函数（Eq. 13–14, 19）**：使用 Huber 损失在 Mρ=1 处计算光流重建损失 L_temp = (L8 + L15)/2；总损失 L = L_action + λ_temp · L_temp，λ_temp = 1.0。
- **异步历史特征缓存（D 节）**：在执行当前 16 步动作块期间，后台进程提前编码 t−15 和 t−8 帧的视觉特征并写入时间戳环缓存；重规划时仅需同步编码当前帧，将关键路径上 3 次视觉编码压缩为 1 次（Eq. 25–26）。
- **基础架构**：以 π0.5 为 backbone，保留原始 current-observation pathway，仅添加平行时序通路。

## 6. 主要结论与发现

- **基准结果**：LIBERO 平均 97.63 ± 0.26%（Spatial 97.60、Object 99.40、Goal 96.93、Long 96.60）；RoboTwin 2.0 Clean/Rand. 平均 85.5% / 84.2%。
- **长地平线优势显著**：RoboTwin Rand. 条件下 H=2/H=3 比 runner-up 分别高 5.5 / 14.5 个百分点；LIBERO Long 比最强列出方法高 2.1 个百分点。
- **历史敏感性**：动作预测对历史内容与时序顺序均敏感；6 个任务中 5 个对"打乱"更敏感，put_bottles_dustbin 对"移除"更敏感。
- **光流监督的必要性**：2Q w/o Flow 优于 Multi-frame（83.2/83.6 vs 79.8/81.5），加入光流后进一步提升至 85.5/84.2，且 H2 段提升 3.7/1.5 点。
- **双查询互补**：Q8 only 与 Q15 only 各有长短，二者联合监督整体最优。
- **推理效率**：异步缓存将单次重规划延迟从 68.10 ms 降至 62.78 ms（节省 5.32 ms / 7.8%），且关键路径仅 1 次视觉编码。
- **真实迁移**：Three-Cup Stacking 57.8% → 77.8%（+20.0），Two-Bottle Packing 86.7% → 97.8%（+11.1）。

## 7. 优点 / 方法亮点

- **物理可解释的监督**：用确定性机器人表面光流替代人工光流标注或学习式运动估计，标签成本为零，物理意义清晰。
- **紧凑的时序接口**：仅 2 个可学习查询取代多帧历史 token，动作专家通过既有 joint masked attention 接收历史，无需额外 cross-attention 或门控。
- **部署友好**：几何渲染与光流解码器仅在训练时启用，部署时推理开销与单帧 VLA 相当；异步缓存进一步消除历史编码关键路径延迟。
- **架构兼容性**：保留原 VLA 通路，仅以"旁路"形式注入时序信息，对既有 AdaRMS 残差调制等机制零侵入。
- **长地平线可解释性**：在 16 步 chunk 框架内自然对齐 t−8 / t−15 两个历史时刻，监督信号时间尺度与执行时间尺度对齐。

## 8. 不足与局限

- **历史尺度选择固定**：仅尝试 t−8 与 t−15 两个时刻，未系统研究历史帧数、时间间隔、采样粒度对表征学习的影响；论文也将此列为未来方向。
- **真实机器人实验规模有限**：仅 2 个三阶段任务、单一平台（AgiBot A3），未对消融配置（如 2Q w/o Flow、Q8 only、Q15 only）做实物迁移验证，难以确认各组件在物理世界中的边际贡献。
- **数据生成假设**：依赖 URDF、关节状态记录与相机标定，对于商品级无标定相机或非标准机器人的迁移存在工程门槛。
- **场景与对象运动盲点**：时序光流仅覆盖机器人本体，不刻画物体运动；若物体动力学对任务阶段判定更关键（如堆积、堆叠），监督信号可能不足。
- **跨论文基线可比性**：RoboTwin 表中部分 baseline 数字引自第三方报告（X-VLA†、GigaWorld），未经同条件复现，可能存在统计口径差异。
- **随机化鲁棒性仍存差距**：RoboTwin Rand. 整体 84.2% 仍低于 Clean 85.5%，H2/Rand. 仅 80.8%，提示在强域随机化下方法仍有退化空间。
- **训练成本增加 20%**：尽管部署开销可控，但训练阶段的额外开销在大规模训练时不可忽视。
- **未报告**：训练总时长、单次推理内存占用、长任务 rollout 失败案例分析等。
