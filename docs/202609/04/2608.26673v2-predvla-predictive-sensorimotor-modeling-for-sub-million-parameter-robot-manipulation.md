## 摘要
大规模预训练的视觉-语言-动作模型在机器人操控任务中取得了优异性能，而紧凑型替代方案则主要通过压缩主流的观测到动作的映射范式来追求效率。本文探究预测性感觉运动建模能否比直接的观测到动作映射更有效地利用受限的参数预算。我们提出了 PredVLA，一种语言条件预测编码策略，仅包含 68 万个可训练网络参数，且无需机器人数据预训练。其分层循环动力学预测视觉特征与本体感觉，而观测仅通过预测误差驱动的在线推断影响潜在状态。在 LIBERO 上，PredVLA 在三个短视野套件中达到 86.9% 的平均成功率，在全部四个套件中达到 75.4%。在采用相同冻结前端、演示数据、动作解码器与评估协议的受控对比下，PredVLA 的三套件平均成功率分别达到参数匹配的 Transformer 与 LSTM 行为克隆策略的 3.7 倍与 7.4 倍。逐机制过渡至循环行为克隆基线的消融实验表明，将预测路径替换为直接观测输入造成了最大的单项性能下降，约占端点差距的 70%。进一步的消融实验识别出训练时潜在推断、测试时误差回归、分层时间尺度以及感知预测误差通道的各自贡献。上述结果共同表明，预测性感觉运动建模可作为紧凑型语言条件机器人控制的一种强有力归纳偏置。

## Abstract
Large pretrained vision-language-action models achieve strong robot-manipulation performance, while compact alternatives have largely pursued efficiency by compressing the prevailing observation-to-action paradigm. We investigate whether predictive sensorimotor modeling can make more effective use of a limited parameter budget than direct observation-to-action mapping. We present PredVLA, a language-conditioned predictive-coding policy with only 0.68 million trainable network parameters and no robot-data pretraining. Its hierarchical recurrent dynamics predict visual features and proprioception, while observations influence latent state only through prediction-error-driven online inference. On LIBERO, PredVLA achieves an 86.9% mean success rate across the three short-horizon suites and 75.4% across all four suites. Under a controlled comparison using the same frozen front end, demonstrations, action decoder, and evaluation protocol, PredVLA achieves 3.7x and 7.4x the three-suite mean success rates of parameter-matched Transformer and LSTM behavior-cloning policies, respectively. A mechanism-by-mechanism transition to the recurrent behavior-cloning baseline shows that replacing the predictive pathway with direct observation input produces the largest single performance drop, accounting for approximately $70\%$ of the endpoint gap. Further ablations identify distinct contributions from training-time latent inference, test-time error regression, hierarchical timescales, and sensory prediction-error channels. Together, these results support predictive sensorimotor modeling as a strong inductive bias for compact language-conditioned robot control.

# PredVLA 论文总结

## 1. 核心问题与研究动机

- **背景**：大规模预训练的视觉-语言-动作（VLA）模型（如 RT-2、Octo、OpenVLA、π0）在机器人操控上性能强劲，但参数量高达数十亿，训练、适配与部署成本高昂。
- **现有紧凑方案的不足**：TinyVLA（约 100M+）、SmolVLA（约 450M）、Evo-1（约 0.77B）等压缩方案仍停留在亿级参数，且大多沿用主流的"观测→动作"映射范式进行压缩。
- **核心问题**：在受限参数预算下，是否必须采用"观测到动作"的小型化版本？能否通过一种**不同的计算原理**（即预测性感官运动建模）更高效地利用参数？
- **研究目标**：探究能否用**亚百万级（<1M）可训练网络参数**、**无机器人数据预训练**，实现强语言条件操控，并系统比较预测编码范式与传统行为克隆范式。

## 2. 方法论

### 2.1 核心思想

PredVLA 是一种**语言条件预测编码策略**，核心特征是**感官观测从不直接进入循环动力学**，仅通过"预测误差驱动的在线推断"影响潜在状态，从而形成"预测-误差-推断-动作"的闭环。

### 2.2 架构组成

- **冻结前端**（Frozen Front-end）：
  - 语言：`all-MiniLM-L6-v2` 句子编码器 + 固定 PCA → 64 维语言表示 `l`（每集恒定）
  - 视觉：ImageNet 预训练 ResNet18 ×2（agentview + eye-in-hand）+ 固定 PCA → 每相机 96 维，192 维拼接
  - 本体感觉：9 维（关节角度 + 夹爪状态），直接使用
- **可训练循环控制器**（仅 0.68M 参数）：
  - 四个模块按层级组织：`T`（顶层，接收语言）→ `V`（视觉分支） + `A_top` → `A_bottom`（动作分支）
  - 状态维度：`dT=64, dV=256, dAtop=256, dAbottom=256`，自由变量维度 `r=64`
  - 分层时间常数：短视野 `(T,V,Atop,Abottom)=(16,8,5,2)`，长视野 `(30,14,8,2)`

### 2.3 关键数学公式

- **先验自由变量**（自父模块生成）：
  $$c_{p,t}^{l} = W_{pri}^{l\top} d_{par(l),t} + b_{pri}^{l}, \quad l \neq T$$
- **确定性状态更新**（含模块特定时间常数）：
  $$h_t^l = \left(1 - \frac{1}{\tau_l}\right) h_{t-1}^l + \frac{1}{\tau_l} \tanh\left( W_{rec}^l d_{t-1}^l + W_{td}^l d_{par(l),t} + U^l c_{q,t}^l + \beta_t^l + b^l \right)$$
- **顶层模块**额外加入语言项 `W_lang l`
- **横向通路**：
  - V→A：`z_t^{VA} = W_{VA} d_t^V`，注入 A_top
  - A→V（传出拷贝）：使用**预测的**前一动作与本体感觉 `β_t^V = W_{ba} \hat{a}_{t-1} + W_{bq} \hat{q}_{t-1}`（**不使用观测**）
- **自由能目标**：
  $$E(I) = \sum_{t \in I} [\lambda_v \varepsilon_v(t) + \lambda_q \varepsilon_q(t) + C_t]$$
  - 精度项：`ε_v = ||v-ŷ_v||²/dim v`，`ε_q` 类似
  - 复杂度项：`C_t = Σ_l w_l · ½ ||c_{q,t}^l - c_{p,t}^l||²`（二次惩罚，代替 KL）

### 2.4 训练与推断流程

- **训练**：后验自由变量 `c_q` 与网络权重联合 BPTT 优化；损失 = `λ_v·ε̄_v + λ_q·ε̄_q + λ_a·NLL(a) + C̄`，30K 步，Adam，batch 32，序列长度 200（短）/ 500（长），学习率 6e-5 / 自由变量 1e-2
- **测试时在线推断（误差回归）**：网络权重冻结，**仅优化自由变量** `c_q`，采用滑动窗口（40 步）+ 10 次迭代 + η=0.05
- **精确开环控制**：令 `n_itr=0` 即可，**无需重新训练**且语言条件不变

### 2.5 动作输出

5 分量对角高斯混合解码（末端执行器 7 维命令），执行时取权重最大分量的均值。

## 3. 实验设计

### 3.1 数据集与基准

- **LIBERO 基准** [Liu et al., NeurIPS 2023]，四个套件：
  - **SPATIAL / GOAL / OBJECT**：各 10 个短视野任务，每任务 50 条演示，平均 125–149 步
  - **LONG (libero_10)**：10 个长视野任务，平均 276 步
- 每个套件单独训练一个控制器；PCA 基在整个数据集上联合拟合后固定

### 3.2 对比方法（受控对比）

| 模型 | 参数量 | 相对 PredVLA |
|---|---|---|
| BC-Transformer | 646,628 | 0.957× |
| BC-RNN (LSTM) | 674,276 | 0.998× |
| BC-TF chunk=8 | 772,558 | 1.143× |
| BC-TF chunk=16 | 916,478 | 1.356× |

所有基线共用**冻结前端、演示数据、动作解码器、评估协议**；基线训练 50K 步（多于 PredVLA 的 30K）。

### 3.3 "机制阶梯"（Mechanism-by-Mechanism Ladder）

从 PredVLA (L0) 到 BC-RNN (L6) 逐步替换/移除组件：
- L0 → L1：禁用在线误差回归（n_itr=0）→ 精确开环
- L1 → L2：移除自由变量与潜变量自由能推断
- **L2 → L3：移除预测通路，观测直接输入循环**（关键一跳）
- L3 → L4：时间常数全部置 1（取消分层）
- L4 → L5：将 PV-RNN 单元替换为 LSTM
- L5 → L6：现有 BC-RNN 基线（端点）
- L2b：L2 基础上额外加入直接视觉前馈通路（侧支）

### 3.4 消融实验（A1–A6）

- A1–A3（架构重训）：移除分层时间常数、移除 V→A 瓶颈、移除传出拷贝通路
- A4–A6（推断时变更）：分别移除视觉误差项 `λ_v=0`、本体误差项 `λ_q=0`、在线误差回归 `n_itr=0`
- 另含**观测扰动实验**：将一定比例 α ∈ {0.25, 0.5, 0.75, 1.0} 的视觉/本体观测替换为无关 episode 的观测

## 6. 主要结论与发现

### 6.1 主结果（LIBERO）

- 三短套件平均 **86.94%**；四套件平均 **75.35%**
- 与参数匹配基线对比：3.7× Transformer、7.4× LSTM
- 与已发表模型对比：参数规模远小于 OpenVLA（7B）与 Octo（93M），四套件均值接近

### 6.2 机制阶梯的关键发现

- **预测通路是关键**：L2→L3 一次性下降 52.36 点，占 PredVLA↔BC-RNN 总差距的 **70.4%**
- **测试时误差回归 + 训练时潜变量推断**各自贡献显著（L0→L1 降 8.83 点，L1→L2 再降 13.34 点）
- **分层时间常数与预测机制强耦合**：完整预测架构下取消分层导致 17–29 点下降；预测已移除后再取消分层仅 −1.23 点
- **直接视觉前馈不能替代预测**：L2b 加入直接视觉输入后性能反而下降（63.92→48.60），尤其 OBJECT 从 66.91 降至 24.66

### 6.3 感官通道贡献

- **视觉 vs 本体误差通道在不同任务贡献不均**：OBJECT 套件对本体误差极其敏感（移除降 14.17 点），而 SPATIAL/GOAL 相对均衡
- **观测扰动**：本体感觉扰动对 OBJECT 影响巨大（α=0.25 即降 49.74 点），视觉扰动较鲁棒
- 提示在线推断会**根据任务结构灵活调用不同感官信号**

### 6.4 精确开环控制

- 设 `n_itr=0` 即可获得严格开环策略，短套件仍可达 73–78%；LONG 仅 28%，说明长视野任务对在线校正依赖更强

## 7. 优点与亮点

- **极小参数预算 + 强性能**：0.68M 参数实现接近 7B OpenVLA 量级的四套件均值
- **架构创新性**：将经典预测编码（PV-RNN / CERNet）首次系统性地引入现代 VLA 评测体系
- **受控实验设计典范**：
  - 共享前端/演示/解码器/协议的参数匹配对比
  - 机制阶梯 + 配对消融明确归因
- **精确开环对照**：仅通过 `n_itr=0` 即得到严格意义上的开环策略，**避免训练两套模型**带来的混淆
- **透明的资源结构**：冻结前端完全分离通用表征与机器人控制容量，使"机器人数据训练的控制容量"可单独度量
- **分层设计验证**：在受限参数预算下，"归纳偏置 > 单纯堆容量"得到实证支持

## 8. 不足与局限

- **仅仿真**：未在真实机器人上验证；物理扰动下的鲁棒性未知
- **单一机器人形态**：仅 LIBERO 默认仿真平台；未测试跨 embodiment 迁移
