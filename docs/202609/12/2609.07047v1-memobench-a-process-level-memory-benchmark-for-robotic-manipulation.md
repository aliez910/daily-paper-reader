## 摘要
机器人操作常常需要对已经不再可见的信息进行操作，然而视觉-语言-动作策略通常在当前观测主要决定下一步动作的情况下进行评估。现有的机器人记忆基准揭示了这一差距，但它们仍主要依赖最终任务成功率，因此将遗忘与操作失败混为一谈。我们提出了 \textbf{MEMOBench}，一个用于机器人操作过程级记忆评估的基准。MEMOBench 包含 30 个依赖历史信息的任务、1{,}500 条专家演示以及来自 84 个模板的 4{,}200 个可执行检查点实例。每个检查点将粗粒度到细粒度的语言与模拟器谓词配对，并标注一种记忆操作：存储、更新或压缩。这些标注定义了记忆存储率、记忆更新率和记忆压缩率，用于在任务成功率之外衡量记忆保真度。在标准 VLA 策略与记忆增强 VLA 策略中，最强的记忆模块基线仅取得 31.9\% 的平均成功率，并且高存储能力往往伴随着较弱的更新与压缩能力。检查点语言还可用于监督语义对齐、对比对齐以及逐帧对齐的记忆目标，从而在不同记忆操作上带来适度提升。MEMOBench 为面向记忆的机器人策略提供了诊断式评估套件与训练监督信号。项目主页见 https://github.com/Collab-gen/MEMOBench。

## Abstract
Robotic manipulation often requires acting on information that is no longer visible, yet Vision-Language-Action policies are usually evaluated when the current observation largely determines the next action. Existing robotic memory benchmarks expose this gap, but they still rely mainly on final task success and therefore conflate forgetting with manipulation failure. We present \textbf{MEMOBench}, a benchmark for process level memory evaluation in robotic manipulation. MEMOBench includes 30 history dependent tasks, 1{,}500 expert demonstrations, and 4{,}200 executable checkpoint instances from 84 templates. Each checkpoint pairs coarse to fine language with a simulator predicate and labels one memory operation: Storage, Update, or Compression. These annotations define Memory Storage Rate, Memory Update Rate, and Memory Compression Rate, which measure memory fidelity alongside task success. Across standard and memory augmented VLA policies, the strongest memory module baseline reaches only 31.9\% average success rate, and high storage often coexists with weak update and compression. Checkpoint language also supervises semantic, contrastive, and framewise memory alignment objectives, yielding modest gains across different memory operations. MEMOBench provides a diagnostic evaluation suite and training supervision for memory grounded robotic policies. The project page is available at https://github.com/Collab-Gen/MEMOBench.

# MEMOBench 论文总结

## 1. 核心问题与研究背景

机器人操控经常需要基于已经不再可见的历史信息进行决策（例如记住"刚才指过的牛奶"、"炉灶之前是开着的"或"重复三次"），这违反了马尔可夫假设。然而当前主流的视觉-语言-动作（VLA）策略（π0、π0.5、OpenVLA、Octo 等）在评测时多以当前观测决定下一步动作。已有研究指出此类策略在历史依赖任务上的成功率仅 0–5%。

现有机器人记忆基准（MemoryBench、MIKASA-Robo、LIBERO-Mem、RoboMME、RMBench、RoboCerebra、RoboMemArena 等）虽然暴露出这一问题，但仍存在三大共性局限：
- 任务结构简单（积木、按钮居多），标注多停留在子目标/关键帧层面；
- 评测以最终成功率或阶段成功率为主，将记忆失败与操控失败混为一谈；
- 无法定位失败发生在"未存储"、"未更新"还是"未压缩"。

MEMOBench 的整体目标是把"记忆"从"操控"中解耦出来，提供过程级（process-level）的诊断评测与训练监督。

## 2. 方法论

### 2.1 两层记忆分类法

- **任务类型层**（记忆什么内容）：Temporal（事件计数、时序、状态转换）、Spatial（被遮挡/隐藏后的位置）、Object（视觉相似实例中的指代一致性）、Procedural（演示动作模式/操作序列）。
- **记忆操作层**（记忆如何变化）：
  - **Storage (∅ → M)**：新观察到任务相关信息；
  - **Update (M → M′)**：外部状态改变后修正已有记忆条目（含删除）；
  - **Compression (M → M̂)**：把累积信息聚合为紧凑表征。
三种操作在每个 checkpoint 上互斥。检索（Retrieval）不单独标注，因为可在任意决策步发生。

### 2.2 过程级 Checkpoint 标注

每个任务 τ 定义有序 checkpoints C_τ = {c₁,…,c_K}，每个 checkpoint 包含：
- **粗到细三级语言**（如 "put tomato in" → "put the tomato into the top drawer of the cabinet"）；
- **可执行仿真谓词**，直接在仿真器中验证环境状态是否满足；
- **操作标签** S/U/C。

全基准共 30 个任务、84 个 checkpoint 模板、1500 条专家演示、4200 个 checkpoint 实例。默认粒度下实例分布为 Storage 1750、Update 1600、Compression 850。顺序敏感分析采用 prefix completion（c_k 视为通过的充要条件是 c₁…c_k 均通过）。

### 2.3 过程级评测指标

- **SR**（Success Rate）：BDDL 目标最终完成率；
- **MSR**（Memory Storage Rate）、**MUR**（Memory Update Rate）、**MCR**（Memory Compression Rate）：分别按 checkpoint 集合 C^S、C^U、C^C 在仿真器中的谓词完成率计算宏平均；
- 任务不含某种操作时该列记为 N/A 并从宏平均中剔除。

公式形式为 $r_o(\tau) = \frac{1}{N}\sum_i \frac{1}{|C_o^\tau|}\sum_{c\in C_o^\tau} v_i(c)$。

### 2.4 注释驱动的记忆对齐目标

基于 RoboMME π0.5 记忆模块（Dai et al., 2026），提出三种训练时对齐损失（仅训练时使用，评测时不变）：
- **Semantic Memory Alignment**：池化记忆向量投影到 SigLIP 文本空间，最小化正对余弦距离；
- **Contrastive Memory Alignment**：双向 InfoNCE，重复 subgoals 作为正例避免假负梯度，温度 τ = 0.07 可学习；
- **Framewise Memory Alignment**：把记忆 reshape 为 (B, F=32, P=16, d)，对每帧做 masked mean 与文本对齐，按时间近因线性加权。

总损失 $L_{total} = L_{action} + \lambda L_{align}$，λ 取 0.1（Semantic/Contrastive）或 0.05（Framewise）。

### 2.5 双盲标注一致性验证

三名未参与原始标注的标注员对 84 个模板盲标注，Fleiss' κ = 0.799；两两 Cohen's κ 介于 0.695–0.868；三人完全一致 70/84（83.3%）；多数票与发布标签一致 71/84（84.5%）。

整体实验较为充分：从多模型到多步长到多对齐目标，并辅以 oracle 分解和失败归因，试图将"记忆失败"和"操控失败"分层归因。然而仍存在覆盖盲区（详见第 8 节）。

## 6. 主要结论与发现

- 当前 VLA 远未饱和 MEMOBench：最强记忆增强基线（π0.5 + RoboMME 记忆模块，replan=5）平均 SR 仅 31.9%，标准 π0.5 为 30.4%；
- **存储强、更新/压缩弱** 是普遍模式：π0 在 replan=5 取得 94.0% 临时 MSR，但对应临时 SR 仅 4.4%；π0.5 + Memory 在 replan=20 取得 90.0% MSR，但 SR 仅 7.6%；
- **任务类型失衡**：对象记忆 SR 可达 99.6%，而空间记忆 SR 仅 0–10%；
- **过程指标间相关性**：MSR vs SR r=0.59、MUR r=0.55、MCR r=0.46（弱-中等相关），证明 SR 无法替代过程指标；
- **对齐带来适度但专门化的提升**：Contrastive 平均 SR 从 27.9% 提到 29.3%；Framewise 在稀疏 replan=50 时更稳定（27.3% vs 21.8%）；不同目标偏好不同操作（Framewise→MSR、Semantic→MUR、Contrastive→MCR）；
- **Oracle 记忆分解**：用真值记忆文本注入 prompt 后，时间/空间 MUR 由 18.4%/0.3% 提升至 54.2%/84.1%，MCR 由 2.0%/6.4% 提升至 53.0%/60.7%，SR 由 2.2%/0.0% 提升至 54.9%/45.8%——证实剩余失败主因确为记忆内容缺失；
- **乱序记忆控制**：将 subgoals 顺序打乱训练，首个存储 checkpoint 仍可达 90%，但 update checkpoint 跌至 24%，最终成功率仅 2%，证明顺序记忆监督对该时间任务有效；
- **标注粒度消融**：更细的语言并不单调带来更好结果，粗粒度最终成功率反而最高（4/50），关键在于语言是否保留了状态变化信息；
- **失败模式**：在典型三 checkpoint 炉灶任务 150 次 rollout 中仅 10 次成功，63 次在第一 update 检查点失败，41 次到达最后检查点时仍持有陈旧记忆——验证"陈旧记忆"是主要失败模式；
- **特权监督参考行** MemER：平均 SR 56.4%，但空间 MUR 52.8%、过程 SR/MUR 仅 19.6%/21.0%，说明即便有特权 checkpoint 监督，MEMOBench 仍未饱和。

## 7. 优点与亮点

- **首次把记忆操作（Storage/Update/Compression）作为一等公民进行显式标注**，使过程级诊断成为可能，而非仅停留在子目标或关键帧层面；
- **三层级语言 + 可执行仿真谓词**双轨设计，使标注既可人读又可机验，避免直接读取模型内部状态；
- **指标体系与标注体系自洽**：MSR/MUR/MCR 与三类操作标签一一对应，并提供 prefix completion 等顺序敏感变体；
- **既可评测又可训练**：checkpoint 语言同时作为评测谓词与对齐监督信号，提供诊断 + 训练的统一工具；
- **盲标注一致性高**（Fleiss' κ=0.799），且对剩余分歧做了混淆矩阵定位（Update/Compression 边界），给出明确裁决规则；
- **多维度对比 + Oracle 分解 + 乱序控制 + 粒度消融**，从相关性、因果性、监督信号三角度交叉验证结论；
- **失败模式分类**把"未存储/陈旧记忆/晚发陈旧记忆"清晰区分，避免了平均指标掩盖失败结构。

## 8. 不足与局限

- **仅仿真评测**：未在真实机器人上验证过程级指标是否迁移，未覆盖传感器噪声、接触动力学、视觉域偏移等现实因素；
- **模型覆盖有限**：主对比仅 6 个模型，对齐研究全部基于同一 π0.5 + RoboMME 骨架，缺少状态空间模型（SSM）等其他架构家族；
- **标注主观性**：Update 与 Compression 边界仍存在分歧（84 模板中 14 个有标注员间分歧），论文给出规则但未提供自动化方案；
- **任务分布不均衡**：操作标签数量刻意不均匀（Storage 1750、Update 1600、Compression 850），压缩操作样本相对较少；
- **任务结构相对简单**：仍以抽屉、炉灶、微波炉等家用夹具为主，缺少更复杂长时序、多智能体或语言指令突变的场景；
- **Oracle 分解假设过强**：把真值 subgoals 直接拼入 prompt，等于绕过了记忆编码与检索瓶颈，更接近"理想记忆系统"上界而非可达上界；
- **算力披露有限**：仅给出 A40×4、3–4 天的总计，没有逐基线训练成本，无法判断对齐实验相对收益的边际算力代价；
- **MEMOBench 不评估真实安全/失败代价**：仅给出指标差距，不讨论对真实部署的影响；
- **项目页标注为 fresh_fetch**，但 PDF 元数据中的 arXiv ID（2609.07047v1）年份为 2026，存在版本号与时序一致性的潜在问题，需读者自行核查最新版本。
