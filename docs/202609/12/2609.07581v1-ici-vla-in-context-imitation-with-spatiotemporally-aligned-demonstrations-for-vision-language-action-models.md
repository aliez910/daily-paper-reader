## 摘要
视觉-语言-动作（VLA）策略通常通过额外的梯度更新来适应新的操作环境，这在任务特定数据或算力稀缺时限制了快速部署。我们提出了 ICI-VLA，一个训练与检索框架，通过上下文演示为文本-动作视觉语言模型（VLM）赋予少样本测试时自适应能力。与基于动作特定多模态融合的主流 VLA 设计不同，ICI-VLA 保留了原生的文本生成接口。ICI-VLA 仅在离线训练期间更新其参数；在推理时，策略保持固定，并以检索到的微演示为条件进行动作生成。该框架将长轨迹分解为短的、带语义标签的示例，并利用通过动态时间规整（DTW）挖掘的正样本训练 RD-编码器，使检索到的上下文与当前子任务的阶段和几何特征对齐。我们进一步引入了目标动作掩码（Target Action Masking），一种旨在减少直接动作复制并增加对当前观测依赖的上下文破坏目标。ICI-VLA 在 LIBERO 上达到了 97.7% 的平均成功率，在 RoboTwin 2.0 上达到了 60.4%，超过 RoboTwin 2.0 上报告的最高基线平均值 19.3 个百分点。它在四个物理任务上也达到了 83.2%。这些结果表明，一个固定的 VLA 策略可以从测试时对时空对齐演示的条件化中受益。

## Abstract
Vision-Language-Action (VLA) policies are commonly adapted to new manipulation settings through additional gradient updates, which limits rapid deployment when task-specific data or compute is scarce. We present ICI-VLA, a training and retrieval framework that equips a text-action VLM with few-shot test-time adaptation through in-context demonstrations. Unlike mainstream VLA designs based on action-specific multimodal fusion, ICI-VLA retains the native text-generation interface. ICI-VLA updates its parameters only during offline training; at inference, the policy remains fixed and conditions action generation on retrieved micro-demonstrations. The framework decomposes long trajectories into short, semantically labeled examples and trains an RD-Encoder with positives mined by Dynamic Time Warping (DTW), aligning the retrieved context with the phase and geometry of the current subtask. We further introduce Target Action Masking, a context-corruption objective designed to reduce direct action copying and increase reliance on the current observation. ICI-VLA reaches average success rates of 97.7% on LIBERO and 60.4% on RoboTwin 2.0, exceeding the highest reported baseline average on RoboTwin 2.0 by 19.3 percentage points. It also achieves 83.2% across four physical tasks. These results indicate that a fixed VLA policy can benefit from conditioning on spatiotemporally aligned demonstrations at test time.

# ICI-VLA 论文总结

## 1. 核心问题与整体含义（研究动机与背景）

- **传统 VLA 适配范式的瓶颈**：现有视觉-语言-动作（VLA）模型（如 RT-2、OpenVLA、π0 等）在迁移到新操作任务时，通常需要收集任务特定数据并通过梯度微调更新参数。这种"每任务一微调"的方式在数据或算力稀缺时成本极高，限制了在动态环境中的快速部署能力。
- **核心洞察**：受到语言模型上下文学习（ICL）的启发——LLM/VLM 仅通过在 prompt 中加入少量演示即可适配新任务而无需梯度更新——作者认为 VLA 也应具备类似能力：让演示在**测试时**作为上下文条件，而非仅作为训练数据。
- **两大技术挑战**：
  - **时序错配（temporal aliasing）**：长轨迹与短动作块（action chunk）之间的时间尺度不匹配。
  - **语义-动态错配（semantic-dynamic mismatch）**：视觉/语义相似的演示可能需要完全不同的运动模式，使上下文反而成为误导性的"动作前缀"，诱使模型直接复制而非基于当前观测推理。
- **基础架构选择**：采用 VLA-0 的"零结构修改"纯文本生成 VLM 范式（Qwen3-VL-4B），直接以文本形式生成连续动作，保留预训练模型的推理与泛化先验。

## 2. 论文提出的方法论

### 2.1 整体框架（离线训练 vs. 测试时推理严格分离）

- 离线阶段：构建演示库、训练检索器、微调 VLA 策略。
- 测试阶段：所有参数冻结，仅通过检索到的演示作为上下文条件化动作生成；无任何梯度更新。

### 2.2 三大核心技术

#### (1) 机器人演示库构建（Stage I）
- 数据规模：约 **11,200 条长轨迹**（LIBERO + RoboTwin 2.0 + 约 1,000 条物理 Aloha 演示）。
- 使用 **Qwen3-VL** 将长轨迹自动分割为带语义标签的子任务级"**微演示**"（micro-demonstration）。
- 每个微演示 $E = \langle T, T_{\text{sub}}, O, Z, A_{i:i+k} \rangle$，包含全局指令、子任务指令、主/腕相机观测、初始本体状态及文本化的 k 步动作块。
- 最终得到约 **139,659 个子任务级示例**。

#### (2) 时空对齐检索器训练（Stage II）—— RD-Encoder
- 基础模型：**Qwen3-VL-Embedding-2B**。
- **语义硬过滤（Semantic Hard-Filtering）**：利用当前嵌入计算余弦相似度，去除语义不相关候选，保留 Top-64 语义相容候选。
- **DTW 几何排序**：以离线 DTW 距离度量候选与锚点轨迹的形状相似度（多臂末端执行器 3D 位置，均值欧氏距离），取最低代价为正样本 $P^+$，同语义子任务中相位错位的候选作为难负样本 $N^-$。
- **迭代对比优化**：交替进行候选检索、DTW 三元组挖掘与 InfoNCE 损失优化，直至锚点变动 < 5% 或达 5 个循环。
- 损失函数：
$$\mathcal{L}_{CL} = -\log \frac{\exp(e_A^\top e_{P^+}/\tau)}{\exp(e_A^\top e_{P^+}/\tau) + \sum_i \exp(e_A^\top e_{N_i^-}/\tau)}$$
- **关键设计**：推理时检索器**完全不知道目标动作**，仅根据可观测输入排序。

#### (3) VLA 微调与 Target Action Masking（Stage III）
- 策略微调 **Qwen3-VL-4B**，冻结 RD-Encoder。
- **Target Action Masking**：训练时随机掩盖上下文动作块中的目标 token 位置 $M$，仅优化未掩盖位置 $U$ 的损失：
$$\mathcal{L}_{\text{act}} = -\sum_{j \in U} \log \pi_\theta(a_{q,j} \mid I_q, E^*, e_{a_q,<j})$$
- 该目标显式降低对"精确动作前缀延续"的依赖，迫使模型更依赖当前观测与检索上下文。推理时关闭掩码。
- 系统提示结构：系统指令 + 检索到的参考示例 + 当前查询。

### 2.3 测试时自适应机制
- 查询 $I_q = \langle T, T_{\text{sub}}, O_t, Z_t \rangle$。
- 检索：$E^* = \arg\max_{E \in \mathcal{D}} s_\phi(I_q, E)$。
- 动作生成：$A_{t:t+k} \sim \pi_\theta(\cdot \mid I_q, E^*)$。
- 当策略置信度 < 0.65 时刷新演示上下文；每回合默认检索 **3 个示例**。

## 6. 主要结论与发现

- **仿真结果**：
  - **LIBERO**：平均成功率 **97.7%**，较基准级最高基线 OpenVLA-OFT（96.4%）高 1.3 点；Long 子集提升最大（96.8% vs 93.2%）。
  - **RoboTwin 2.0**：平均成功率 **60.4%**，较基准级最高基线 OpenVLA-OFT（41.1%）高 **19.3 个百分点**；Easy 与 Hard 分别高 17.2 / 21.8 点。
- **物理实验**：四任务平均 **83.2%**（95% CI: 80.8–85.4），显著优于 π0（66.4%）和 VLA-0（63.0%）。
- **检索质量**：Recall@1 从基础嵌入的 27.8% 提升至完整 RD-Encoder 的 **70.8%**（+43.0 点）；Recall@5 从 52.4% 提升至 90.1%。
- **消融关键发现**：
  - 去掉 Target Action Masking → LIBERO 降至 71.5%，RoboTwin 2.0 暴跌至 10.7%，证明其为最关键组件。
  - 去掉 DTW → 92.5% / 31.4%；去掉语义过滤 → 88.4% / 38.1%。
- **超参规律**：$N_e=3$ 最优，$N_{\text{iter}}=5$ 后趋于饱和（变化 ≤ 0.3 点）。
- **核心结论**：**一个完全冻结的 VLA 策略仍能通过测试时时空对齐的演示上下文获得显著性能提升**，验证了文本中心策略原生 ICL 路径的可行性。

## 7. 优点

- **范式创新**：首次将"任务级参数更新"完全替换为"测试时检索条件化"，提出清晰的离线/在线分离框架。
- **方法细节扎实**：
  - 子任务级微演示分解有效缓解时序错配。
  - DTW 几何监督 + 语义过滤的双重对齐机制具针对性。
  - Target Action Masking 作为简单而有效的正则项，避免直接复制。
- **保留 VLM 原生能力**：零结构修改的纯文本生成接口最大化继承预训练先验，避免引入额外动作头带来的工程复杂度和能力退化风险。
- **评估全面**：仿真 + 物理 + 检索器直接评估 + 消融 + 敏感性 + 定性六类证据相互印证。
- **公开公平性声明**：明确指出外部基线的协议不可直接配对对比，避免过度解读。
- **统计严谨**：物理评估提供 Wilson 置信区间。

## 8. 不足与局限

- **检索库依赖性强**：
  - 性能依赖约 11,200 条轨迹、139,659 个微演示的覆盖率；新场景若库覆盖不足将快速退化。
  - 离线建库与检索成本未明确量化，未来需提升检索效率。
- **超参选择风险**：3 示例、5 循环、置信度阈值 0.65 均仅基于验证集选定，未在最终测试集上重新检验，存在轻微过拟合验证集的可能。
- **检索训练泄漏风险**：作者声明训练/库/评估轨迹不重叠，但任务定义、对象、布局、指令模板在划分间可能复用（作者已声明），检索器可能从语义层面"记忆"任务模板。
- **基础模型依赖**：严重依赖 Qwen3-VL 系列（4B 策略 + 2B 检索器 + VL 分段器）的强能力；尚未验证在其他 VLM 骨干上的可迁移性。
- **物理实验规模有限**：仅 4 个任务、单一 Aloha 平台，未涉及多场景、跨形态实验；光照、干扰物的变化范围未充分细分。
- **Target Action Masking 的机制解释**：作者承认该目标"未显式监督运动学残差"，其内部是否真正提升观测依赖、抑或仅是隐式正则，仍需更细致的可解释性研究。
- **"零样本" vs. "少样本" 命名**：
  - 作者特意强调其方法是 few-shot 而非 zero-shot，但实际部署仍依赖 1,000+ 物理演示和外部视觉规划器（Qwen3-VL planner）做子任务切换，弱化了"零修改原生 ICL"的纯粹性。
- **未与其他 ICL 类方法受控对比**：REGENT、RICL、MEM 等仅作概念讨论，未在统一协议下实测，难以判断相对竞争力。
- **跨形态泛化未涉及**：未来工作方向，但当前缺失对不同机器人形态（移动臂、人形等）的验证。
