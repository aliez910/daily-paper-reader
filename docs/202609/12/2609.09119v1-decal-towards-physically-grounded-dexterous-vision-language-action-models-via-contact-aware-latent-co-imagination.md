## Abstract

Experimental results show that DeCAL consistently achieves state-of-the-art performance across all tasks, attaining a 71% average success rate and an 83.4% progress success rate, while also demonstrating strong generalization to unseen scenarios. ## 1. 核心问题与研究动机

**核心问题**：灵巧操作（dexterous manipulation）涉及大量接触密集（contact-rich）且精细的物理交互，现有 VLA 模型在该场景下面临两大瓶颈：

- **严重视觉遮挡与可观测性不足**：多指灵巧手在操作中产生严重自遮挡，纯视觉无法可靠获取接触状态、力变化、滑移与形变等关键物理信号。
- **多模态融合方式粗放**：已有引入触觉感知的工作多将触觉作为辅助信号做"同质化"融合，缺乏**自适应的触觉集成机制**，且整体策略偏反应式（reactive），**未对未来接触动力学进行显式建模**，难以推断接触状态的演化过程。

**研究含义**：将触觉感知真正嵌入 VLA 框架，并以"物理基础（physically-grounded）"的方式联合建模视觉与触觉的未来演化，是实现精细灵巧操作的关键一步。

## 2. 方法论

DeCAL 基于**混合 Transformer（Mixture-of-Transformers, MoT）** 架构，由三个专家（Expert）协同构成，并通过**自适应视觉-触觉融合**与**视觉-触觉潜在协同想象**两大核心机制实现接触密集型操作。

### 2.1 整体架构（三专家）

| 专家 | 子任务 | 骨干网络 |
|---|---|---|
| 理解专家（Understanding Expert） | 场景与语言理解 | Qwen3-VL |
| 生成专家（Generation Expert） | 视觉/触觉未来预测 | Qwen3 |
| 动作专家（Action Expert） | 动作块生成 | Qwen3 |

- 三专家之间通过**分块注意力掩码（blockwise attention mask）**实现**单向信息流**：理解→生成→动作，确保感知与想象信息能有效引导动作。
- 理解专家内部为双向注意力，生成专家内部双向，动作专家中状态/动作 token 采用非对称注意力设计。

### 2.2 自适应视觉-触觉融合（Adaptive Visuo-Tactile Fusion）

- **触觉特征提取**：每个指尖的变形图（deform map）经共享 ResNet 编码，再经空间池化与跨指 Transformer 融合，得到两类表征：
  - 局部 token（保留细粒度接触细节，作为 cross-attention 的 K/V）
  - 全局 token（汇总整体接触状态，用于门控）
- **接触感知门控（Contact-Aware Gating）**：由于触觉仅在接触阶段有意义，直接融合会污染视觉注意力。门控机制形式化如下：
  - 
  $$\tilde{X} = X + \sigma \odot \text{CrossAttn}(Q_{vl}, K_{local}, V_{local})$$
  - $$\sigma = \text{Gate}(z_{global})$$
  - 其中 $\sigma$ 由全局触觉 token 派生，无接触时趋于 0，使策略以视觉为主。

### 2.3 视觉-触觉潜在协同想象（Visuo-Tactile Latent Co-Imagination）

生成专家并行预测未来 H 步的视觉与触觉潜变量：

- **视觉潜变量**：用 Cosmos VAE 编码多视角图像，并通过 8×8 卷积将 32×32 token 压缩为 4×4，复用理解专家的 KV Cache 进行并行解码。
- **触觉潜变量**：用专用力编码器处理 6-DoF 力/力矩信号，再解码为原始触觉图像、形变图与 6-DoF 力向量三种粒度。
- 训练时对视觉潜变量做 L2 回归，对触觉潜变量以多任务重建损失间接监督；推理时直接以潜变量作为上下文，跳过像素级重建以满足实时性。

### 2.4 分解式流匹配（Factorized Flow Matching）

针对臂（arm）与手（hand）的运动学差异，将动作块拆为两路独立噪声→token→共享 Transformer 去噪→解码，**解耦粗粒度臂运动与精细手指动作**，避免联合去噪掩盖高自由度手指行为。

### 2.5 训练目标

$$\mathcal{L}_{total} = \lambda_v \mathcal{L}_{visual} + \lambda_t \mathcal{L}_{tactile} + \mathcal{L}_{action}$$

- $\mathcal{L}_{visual}$：潜变量 L2 损失
- $\mathcal{L}_{tactile}$：原始图、形变图、力的多任务加权重建损失
- $\mathcal{L}_{action}$：流匹配速度场损失

## 6. 主要结论与发现

1. **全面 SOTA**：在 6 个接触密集任务上一致超越所有基线，平均 **SR 71%**、**PSR 83.4%**，相对最强基线平均 SR 提升 ≥15%。
2. **ID 阶段级优势显著**：平均阶段成功率 0.91，远超 GR00T N1.6 (0.69)、InternVLA-A1 (0.68)、ViTacFormer (0.79)、DECO (0.78)，尤其在接触密集后期阶段（如装配插入、旋盖）提升明显。
3. **OOD 泛化强**：在 4 种 OOD 场景下均最佳，**未见物体场景**下 SR 达 75%，超过最强基线 30 个百分点。
4. **消融有效性**：四个组件均对最终性能有正贡献，其中 Factorized FM 和视觉/触觉潜变量生成对 Assemble Parts、Twist Cap 影响最大。
5. **未来视觉生成质量更优**：相比 InternVLA-A1 在 Cosmos 特征相似度和 LPIPS 两项上均更优，证实触觉引入有助于环境演化建模。
6. **触觉表征结构化**：t-SNE 显示全局触觉 token 在不同接触模式（握持、扭转、插入、擦拭）下自然聚类，表明编码器学到有意义结构。
7. **门控行为可解释**：门控值在非接触阶段保持低，接触时显著上升，与"触觉仅在接触时关键"的直觉一致。

## 7. 方法与实验亮点

- **统一框架设计**：MoT 架构在同一模型中整合理解、想象、动作三种能力，避免多阶段流水线引入的误差传播。
- **接触感知门控**：从"是否正在接触"这一物理信号出发自适应调节触觉权重，比固定/线性融合更具可解释性，也更适合稀疏触觉信号。
- **潜变量协同想象**：仅在潜空间而非像素空间预测未来，兼顾物理动态建模与实时控制（0.27s/动作块）。
- **分解式流匹配**：把高自由度手指动作从粗粒度臂运动中解耦，对高 DoF 灵巧手尤其关键。
- **多模态输入完备**：视觉（三相机）、语言、触觉三模态共同输入，最大化利用 VLM 已有世界知识。
- **评测体系完整**：主实验 + 阶段级 + OOD + 消融 + 生成质量 + 定性分析 + 失败案例，构建了较立体的评估视角。
