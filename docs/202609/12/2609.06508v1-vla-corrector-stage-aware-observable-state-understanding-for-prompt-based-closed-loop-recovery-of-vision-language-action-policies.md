## 摘要
长时序机器人操控在使用视觉-语言-动作（VLA）策略时仍然容易受到执行阶段偏差的影响，因为仅依据任务最终是否成功，难以诊断并修正由动作噪声、物体位移或目标错位所导致的失败。为此，我们提出了一种阶段感知的失败验证与提示恢复框架，能够在无需参数更新或特权模拟器状态的条件下，对固定的VLA策略进行闭环修正。该框架引入了一种基于可观测历史的学习验证器，通过对多视角视觉观测、本体感受状态和已执行动作进行时序建模，联合估计操控进度与执行风险。为了提供可解释的任务理解，我们将操控执行过程表示为语义化的进度阶段，包括接近、对齐、抓取、搬运与放置，并据此识别各阶段特定的失败模式。在检测到异常执行后，框架保留原始指令，并生成阶段条件化的恢复提示，使同一个冻结的VLA策略能够生成修正动作。在LIBERO与LIBERO Plus上开展的大量多轮评估表明，所提方法在多种扰动条件下显著提升了闭环可靠性。在不依赖特权物体或目标坐标的情况下，学习验证器在所评估设定中的恢复性能已接近基于规则的特权验证器。上述结果表明，仅凭可观测的视觉-本体感受-动作历史即可推断潜在的任务状态，并为现有VLA策略实现切实可行的失败恢复。

## Abstract
Long-horizon robot manipulation with Vision-Language-Action (VLA) policies remains vulnerable to execution-time deviations, as final task success provides little information for diagnosing and correcting failures caused by action noise, object displacement, or goal misalignment. We introduce a stage-aware failure verification and Prompt Recovery framework that enables closed-loop correction of a fixed VLA policy without parameter updates or privileged simulator states. The framework introduces an observable-history-based Learned Verifier that jointly estimates manipulation progress and execution risk by temporally modeling multi-view visual observations, proprioceptive states, and executed actions. To provide interpretable task understanding, we represent manipulation execution through semantic progress stages, including approach, alignment, grasp, transport, and placement, and identify stage-specific failure patterns. Upon detecting abnormal execution, the framework preserves the original instruction and generates a stage-conditioned recovery prompt, allowing the same frozen VLA policy to produce corrective actions. Extensive multi-round evaluations on LIBERO and LIBERO Plus demonstrate that the proposed approach substantially improves closed-loop reliability under diverse perturbations. Without access to privileged object or goal coordinates, the Learned Verifier achieves recovery performance close to that of the privileged rule-based verifier in the evaluated settings. These results show that observable visual-proprioceptive-action history is sufficient to infer latent task states and enable practical failure recovery for existing VLA policies.

# VLA-Corrector 论文结构化总结

## 1. 核心问题与研究动机

- **问题定位**：长时序机器人操控任务中，基于视觉-语言-动作（VLA）的策略虽然在指令理解上表现良好，但缺乏"知道自己做对了没有"的执行状态自检能力，导致一旦出现执行偏差便难以挽救。
- **典型偏差来源**：动作噪声、目标物体位移、抓取不完整、目标区域偏移等累积性扰动。
- **核心矛盾**：最终成败信号无法诊断失败原因，且 action chunking 策略存在 replanning 延迟，旧动作在新环境下继续执行会进一步偏离轨迹。
- **类比启发**：生物体通过持续的自我监控（self-monitoring）避免此类累积偏差，凸显"执行状态感知"对具身智能体的关键意义。
- **研究目标**：在不修改 VLA 策略参数、不访问特权仿真状态的前提下，从可观测交互历史中推断执行状态并触发闭环恢复。

## 2. 方法论

### 2.1 整体架构
- **三模块串联**：冻结 VLA 策略 → 风险验证器 → 触发门控 → Prompt Recovery（提示恢复）。
- 控制流程：观测 + 指令 → π0.5 输出动作块 → 仅执行前 5 步 → 验证器读取历史判断 → 若触发则丢弃当前 chunk、注入恢复提示生成修正动作 → 恢复完成后切回原指令。

### 2.2 Learned Verifier（学习验证器）
- **输入**：可观测历史 $h_t = \{(I^a_i, I^w_i, s_i, u_i)\}_{i=0}^{t}$，含双视角 RGB、8 维本体状态、7 维已执行动作。
- **时间窗口**：8 步历史，每 2 个环境步采样一次，图像分辨率 112×112。
- **视觉分支**：无参数空间统计特征化器，对每视角做 3×4×4 adaptive-average-pooling + RGB 均值/标准差，得到 54 维特征；双视角拼接后投影至 64 维。
- **状态-动作分支**：15 维向量投影至 32 维。
- **时序融合**：GRU（hidden=64）。
- **双预测头**：
  - 二值风险：$p_t = \sigma(w_f^\top z_t + b_f)$。
  - 阶段分类：$\ell_t^{stage} = W_{stage} z_t + b_{stage}$，五类 {APPROACH, ALIGN, GRASP, MOVE, PLACE}。
- **训练标签生成**：教师基于特权状态给出阶段 $c_t$ 与失败事件集 $E$，在 10 步内为正例、20 步以外为负例，中间模糊区不参与训练。

### 2.3 触发门控与路由
- 阈值 $\tau = 0.40$ + 4 帧连续确认 + 10 步冷却。
- 阶段置信度低于 0.9625 时回退为通用恢复提示（UNKNOWN_FAILURE）。
- 评估时每 2 环境步查询一次。

### 2.4 Prompt Recovery
- 在原指令 $q$ 后追加 "Immediate recovery:" + 阶段指令 $r_t$，得到 $q_t^{rec} = q \oplus r_t$。
- 由同一个冻结 π0.5 生成恢复动作，恢复完成后恢复原指令。
- 单次干预最多 100 步，正常执行上限 280 步。

### 2.5 特权规则验证器（仅作上界）
- 基于仿真器真值（物体/区域位姿、末端运动学、距离、BDDL 谓词等）实现 APPROACH → ALIGN → GRASP → MOVE → PLACE → SUCCESS 状态机，仅作为监督训练源与性能上界。

## 3. 实验设计

### 3.1 数据集/Benchmark
- **标准 LIBERO**：SPATIAL / GOAL / OBJECT / 10 / 90 五个子套件聚合。
- **LIBERO Plus**：在 difficulty 4 和 difficulty 5 下测试对应 Spatial / Goal / Object / 10。
- **真实机器人**：3 类任务——Pick and Open、Place、Pour Water，每任务 40 次试验。

### 3.2 扰动协议
- 干净（Clean）、动作高斯噪声 ($\sigma=0.1$)、目标物体 XY 偏移 0.1 m、目标区域 XY 偏移 0.1 m、组合扰动。

### 3.3 对比方法
| 配置 | 验证器 | Prompt Recovery |
|---|---|---|
| No Assistance | 无 | 无 |
| Rule + Prompt | 特权规则 | 共享接口 |
| Learned Binary + Prompt | Learned Verifier | 共享接口 |

## 6. 主要结论与发现

- **量化收益**：标准 LIBERO 成功率从 70.9%（No Assistance）提升至 82.6%（Rule + Prompt）和 80.2%（Learned Binary + Prompt）。
- **鲁棒性**：扰动条件下提升最显著，组合扰动下绝对提升 +11.7 pp（Rule）与 +9.3 pp（Learned）。
- **LIBERO Plus**：difficulty 4 时 Learned 与 Rule 分别达 79.0% / 79.7%；difficulty 5 时 72.6% / 73.6%。
- **真实世界**：平均成功率 88.3% vs 基线 82.5%，绝对提升 5.8 pp。
- **关键发现**：仅凭可观测的视觉-本体-动作历史即可近似推断潜在任务状态，无需特权坐标；学习验证器与特权验证器的差距仅 2.4 pp 以内。
- **范式意义**：将策略能力（VLA）与执行可靠性（验证器）解耦，可在不重训的前提下为已有 VLA 注入恢复能力。

## 7. 优点

- **非侵入式设计**：冻结 VLA 策略，仅添加轻量验证器与提示恢复，便于在已有部署中接入。
- **解耦架构清晰**：状态估计与控制策略分离，验证器训练不影响控制性能。
- **计算高效**：验证器结构简单（无参数视觉特征 + 小 GRU），CPU 推理亚毫秒级。
- **评测系统化**：扰动协议跨多基准、多难度、多扰动类别；消融覆盖时间、视角、模态维度。
- **真实世界验证**：3 类真实任务且明确说明无真实数据用于训练，避免数据泄漏。
- **Prompt Recovery 的接口通用性**：特权规则与学习验证器共享同一恢复接口，使得性能差异可归因于检测与门控质量。
- **阶段感知路由**：为恢复提示提供语义化上下文，提高恢复针对性。

## 8. 不足与局限

- **数据规模有限**：仅 120 条 episode 训练验证器，泛化能力存疑；真实环境未单独采集数据用于验证器微调。
- **阶段标签依赖人工/特权**：五阶段定义与教师标签源自仿真特权状态，迁移到新任务需要重新定义或标注。
- **真实世界覆盖窄**：仅测试"目标物体位移"一种扰动；缺少动作噪声、光照变化、目标区域偏移等真实常见扰动。
- **性能上界偏松**：Rule + Prompt 使用仿真真值作为对照上界，与现实部署不可比，存在"上界抬高 Learned 表现"的解读偏差。
- **未给出的细节**：基线/真实机器人平台的 GPU 型号、控制频率、传感器型号等缺失；真实试验的失败模式与误触发统计未细化。
- **缺乏对 Prompt Recovery 自身的消融**：未比较不同提示模板、是否包含原指令、不同路由粒度的影响。
- **学习验证器结构限制**：视觉分支仅用无参数统计特征，对复杂场景可能欠表达；阶段预测的混淆矩阵未单独报告。
- **应用边界**：阶段定义针对桌面级抓取-放置类任务，对接触密集、工具使用、长链路组合任务是否仍适用未验证。
- **离线阈值与在线阈值不一致**（离线 0.03294 vs 在线 0.40），增加了调参与重现难度。
