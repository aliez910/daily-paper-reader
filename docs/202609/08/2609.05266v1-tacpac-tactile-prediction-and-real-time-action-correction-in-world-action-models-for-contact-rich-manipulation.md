## 摘要
World-action模型通过预测的未来观测来引导动作生成，但以视觉为中心的预测缺失了决定接触密集型操作成败的局部接触线索。然而，在我们的实验中，仅将未来触觉观测作为额外视角进行朴素预测，仅能恢复约三分之一的可达增益。这一差距反映了时间错位问题：预测发生在执行之前，而触觉反馈则在执行期间到来。为此，我们提出了TacPAC，将触觉预测转化为实时动作修正。在基础模型规划完一个动作片段后，TacPAC会缓存该规划所依赖的预测接触信息以及规划自身的表征，随后由一位触觉专家将每一帧新观测到的触觉图像与该缓存进行比对，以修正尚未执行的动作。由此，反馈不再是孤立地被解读，而是相对于规划的预期进行解读；并且每次修正只需对该缓存执行一次前向传播，其计算开销比重生成该动作片段低20.7倍。在涵盖精密插装、易碎物体操作、物体重定向以及长视野操作的五项真实机器人任务中，TacPAC在所有任务上均取得领先，将纯视觉基础模型的平均成功率由22%提升至64%。代码已开源：https://github.com/LogosRoboticsGroup/TacPAC。

## Abstract
World-action models guide action generation with predicted future observations, but vision-centric predictions miss the local contact cues that decide contact-rich manipulation. However, naively predicting future tactile observations as additional views recovers only a third of the achievable gain in our experiments. This gap reflects a timing mismatch: predictions precede execution, while tactile feedback arrives during it. We introduce TacPAC, which turns tactile prediction into real-time action correction. Once the base model has planned an action chunk, TacPAC caches the predicted contact that plan was conditioned on together with the plan's own representation, and a tactile expert reads each newly observed tactile image against that cache to correct the actions not yet executed. Feedback is thus interpreted against what the plan anticipated rather than in isolation, and one correction is a single pass over that cache, $20.7\times$ cheaper than regenerating the chunk. On five real-robot tasks spanning precision insertion, fragile-object handling, object reorientation, and long-horizon manipulation, TacPAC leads every task and raises the average from 22% for its vision-only base model to 64%. Code is available at https://github.com/LogosRoboticsGroup/TacPAC.

# TacPAC 论文总结

## 1. 核心问题与研究动机

- **关键问题**：接触密集型操作（如精密插装、易碎物体抓取）的成败取决于局部接触状态（形变、初始滑移、微小错位），而以视觉为中心的 World-Action 模型（WAM）难以捕捉这些信号。
- **现有方案的不足**：将触觉观测作为额外视图进行"未来预测"的朴素做法仅能恢复约 1/3 的潜在增益。这是因为存在**时间错位**——预测在执行前完成，而触觉反馈则在执行期间到来，导致预测无法用于修订已经规划但尚未执行的动作。
- **代表性场景**：充电器插头插装、马铃薯薯片抓取等任务中，视觉只能给出全局语境，无法解析局部接触变化。

## 2. 方法论

### 2.1 核心思想

- 将"触觉预测"从一次性生成视角转变为**实时动作校正**依据：基础模型规划好动作块后，缓存该规划所依赖的预测接触与规划表征，再由触觉专家把新观测与缓存对比，输出针对尚未执行动作的逐步 delta。

### 2.2 架构与技术细节

- **三专家 Mixture-of-Transformers（MoT）**：
  - **视频专家**：预测未来视觉与触觉观测（latent 视频流包含触觉视图）。
  - **动作专家**：通过层间注意力关注预测结果，生成动作块 $\hat{a}$。
  - **触觉专家**：单次前向传播读取缓存，对动作块进行实时修正。
- **非对称注意力掩码**：动作 token 可关注所有视频与动作 token；视频 token 只关注视频 token，保证动作不污染观测预测。
- **缓存构建**：基础模型去噪完成后，额外做一次 $\tau=0$ 的"清洁前向"，保存触觉与动作的层间 KV cache（视觉 key 不缓存），仅需一次额外的 pass（62.6 ms）。
- **触觉专家工作机制**：
  - 查询序列 = 当前触觉图像 + 已更新动作块（已执行部分用真实指令填充，未执行部分保留 $\hat{a}$，并加状态嵌入）。
  - 输出 $\Delta a = f(I_m, \hat{a}, m, C)$，修正后 $\hat{a} + \Delta a$。
  - 修正值叠加到**原始规划**而非上一修正，避免误差累积。
- **训练与推理流程**（Algorithm 1）：
  - **Stage 1**：训练视频与动作专家，使用 flow matching 损失（视频+动作）。
  - **Stage 2**：冻结全部，**只训练触觉专家**，并从已训练的动作专家初始化。
  - 每个 episode 采样 $K=4$ 个执行偏移 $m$，监督损失仅作用于未执行后缀：$L_{tac} = \frac{1}{H-m}\sum_{i\ge m}\|\hat{a}_i+\Delta a_i - a_i\|^2$。
  - 推理时基模型以 1.59 Hz 规划，触觉专家以 32.9 Hz 异步修正；为补偿延迟 $d$，修正只写回到 $[m+d, H]$ 区间。

## 3. 实验设计

### 3.1 任务与平台

- **机器人**：Flexiv Rizon 4 单臂 + 集成两个 InTac S1 触觉传感器。
- **相机**：腕部 RealSense D405 + 第三人称 RealSense D435i。
- **动作接口**：30 Hz 控制频率，动作块水平 $H=48$，对应 1.6 秒运动；7 维关节指令 + 1 维夹爪指令。
- **5 项真实机器人任务**：
  1. 充电器插头插装（精密对齐）。
  2. 多物体水果搬运（多阶段）。
  3. 易碎薯片搬运（破损即失败）。
  4. 空瓶立起（力调节+重定向）。
  5. 扩展卡插装（紧密公差）。

### 3.2 对比方法（Baseline）

- 通用 VLA：$\pi_{0.5}$、ACT。
- 视-触觉策略：VITaL。
- 视觉 WAM：LingBot-VA。
- 触觉 WAM：Dream-Tac、T-Rex。
- 自身组件消融 4 个变体（见下文）。

## 6. 主要结论与发现

- **Q1 整体性能**：TacPAC 在 5 项任务上均取得最高成功率，平均 **64%**，较最强基线 T-Rex（48%）提升 16 个百分点。
  - 插装：80% vs 65%；水果：65% vs 50%；薯片：90% vs 85%；立瓶：40% vs 30%；插卡：45% vs 35%。
- **Q2 触觉预测为何不够**：触觉在接触过渡阶段最活跃，但该阶段很短且发生在动作块执行**内部**而非之前；朴素的触觉预测目标仅能把视觉 WAM 从 22% 提升到 37%（约 1/3 增益）。
- **Q3 组件必要性**：每条路径都不可缺。
  - 无触觉专家（仅预测）：37%。
  - 无触觉预测：33%。
  - 无触觉 cache：47%（注意：base 模型保持预测，但切断专家对预期接触的访问）。
  - 完整 TacPAC：64%。仅恢复 cache 访问即贡献 **17 个百分点**，是核心收益来源。
- **Q4 实时性**：触觉专家 30.4 ms/次，几乎能在下一个控制步前返回；异步写回机制避免运动抖动。
- **与 Dream-Tac、T-Rex 的对比**：Dream-Tac 擅长易碎任务的"接触预期"；T-Rex 擅长实时修正但缺乏预期；TacPAC 同时具备两者，从而在两类任务上都领先。

## 7. 优点与亮点

- **问题洞察新颖**：明确指出 WAM 触觉预测"预测与执行时间错位"的结构性局限，把"预测 vs 修正"的关系形式化为 KV cache 的设计选择。
- **架构简洁高效**：单次缓存遍历完成校正（30.4 ms、20.7× 加速比），且 delta 累加到原始规划而非上次修正，避免误差传播。
- **两阶段训练策略**：在 base 模型自身规划上训练修正器，使监督信号与推理时面对的"基线 gap"完全一致。
- **消融设计干净**：在固定 base、tactile expert、tactile input 与参数量的前提下，仅切断 cache 访问就产生 17 个百分点差距，构成强证据。
- **任务难度梯度合理**：涵盖插装/易碎/重定向/长视野四类挑战，且明确说明哪些基线在哪类任务失败、为何失败。
- **时序诊断扎实**：用 296 个 episode、284k 帧对触觉活动按执行阶段做量化，支撑"接触过渡短而活跃"的论证。

## 8. 不足与局限

- **任务与平台范围有限**：仅 5 项任务、单臂机器人、单一触觉传感器型号（InTac S1）；未涉及双臂、灵巧手、移动操作或长视距多阶段任务。
- **真实试验样本量**：每方法×每任务 20 次在真实机器人中常见但仍偏少，未报告跨训练的统计方差或显著性检验。
- **基线适配差异**：Dream-Tac 需调门控超参、VITaL 等基线的训练数据量与作者实现细节未完全披露，可能影响比较公平性。
- **对触觉数据的强依赖**：在没有高分辨率触觉传感器的平台上无法直接应用；不同触觉传感器间的迁移未评估。
- **基模型仍是 WAM 本身的局限**：仍受限于 WAM 的训练数据规模与场景多样性，论文承认"no pretraining"也能胜出，但不能保证在分布外任务上同样领先。
- **未涵盖失败恢复策略**：触觉修正可能引入抖动风险，论文仅实证"未见抖动"，未给出最坏情况下的安全/降级机制。
- **训练时长未公开**：算力与 epoch 公开，但每次训练的墙钟时间未给出，难以复现成本估算。
