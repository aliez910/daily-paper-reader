## 摘要
视觉-语言-动作（VLA）模型利用预训练的视觉-语言表征进行机器人控制，然而仅仅增加历史帧并不能可靠地捕捉近期的物理变化。在多阶段操作任务中，这一问题尤为突出，因为视觉上相似的状态可能需要根据先前的执行情况采取不同的动作。为应对这一挑战，我们提出了 TemporalFlow-VLA，它通过物理接地的时序监督来学习紧凑的执行历史。利用记录的机器人状态、机器人几何以及已标定的相机，我们将机器人表面时序流构建为仅在训练阶段使用的目标，并对两个与执行对齐的时序查询进行监督，从而为动作专家提供结构化的历史信息。几何监督路径在部署时不参与推理。TemporalFlow-VLA 在 LIBERO 上取得了 97.63 ± 0.26% 的平均成功率，其中 LIBERO Long 上为 96.60 ± 0.87%，并在 12 项 RoboTwin 任务中分别达到 85.5%/84.2% 的洁净/随机化成功率。该方法在长视野、多阶段操作任务上相较于已有方法展现出最为显著的优势。受控的历史干预实验表明，动作预测同时依赖于历史内容与时序顺序。借助异步特征缓存，时序条件控制在保持服务器端单帧级采样延迟的同时，不会带来额外的历史编码开销。总体而言，TemporalFlow-VLA 提供了一个紧凑、物理接地的接口，使得有序执行历史得以被充分利用，而无需在部署阶段进行显式运动估计或几何处理。

## Abstract
Vision-language-action (VLA) models leverage pretrained vision-language representations for robot control, yet simply adding historical frames does not reliably capture recent physical change. This is especially problematic in multi-stage manipulation, where visually similar states may require different actions depending on prior execution. To address this challenge, we present TemporalFlow-VLA, which learns compact execution history through physically grounded temporal supervision. Using recorded robot states, robot geometry, and calibrated cameras, we construct robot-surface temporal flow as a training-only target and supervise two execution-aligned temporal queries that provide structured history to the action expert. The geometric supervision path is not evaluated at deployment. TemporalFlow-VLA achieves 97.63 +/- 0.26% average success on LIBERO, including 96.60 +/- 0.87% on LIBERO Long, and 85.5%/84.2% Clean/Randomized success across 12 RoboTwin tasks. It shows its clearest advantage over prior methods on longer-horizon, multi-stage manipulation. Controlled history interventions show that action prediction depends on both historical content and temporal order. With asynchronous feature caching, temporal conditioning maintains single-frame-level server-side sampling latency without additional historical-encoding overhead. Overall, TemporalFlow-VLA provides a compact, physically grounded interface for exploiting ordered execution history without explicit motion estimation or geometric processing at deployment.

# TemporalFlow-VLA 论文总结

## 1. 核心问题与整体含义

- **研究背景**：视觉-语言-动作（VLA）模型借助预训练的视觉-语言表征完成机器人控制，但多数代表性 VLA（如 π0、π0.5）主要依据当前 RGB 观测、语言指令与机器人状态生成动作。
- **核心痛点**：
  - 多阶段操作中存在"视觉相似但语义不同"的状态歧义，例如失败的抓取与抓取前状态外观接近、相同的末端位姿可能对应接近、搬运、恢复等不同阶段；
  - 简单地堆叠历史帧并不能可靠地为动作预测提供"物理变化"信息；
  - 诊断实验显示：将 3 帧历史随机打乱、保留当前帧，动作 flow-matching 损失几乎不变；而移除历史则使损失上升约 4.6%，说明基线对历史顺序不敏感；
  - ViSTR-Bench 等研究指出 MLLM 在运动感知、空间关系、结果预测与物理动力学方面存在持续困难。
- **研究动机**：并非"是否使用历史"，而是如何以对控制有用的结构化形式表征近期物理演化。

## 2. 方法论

### 2.1 核心思想
- 利用记录的机器人关节状态、URDF 几何与相机标定，**离线**计算"机器人表面时序流"，作为训练阶段的监督目标；
- 设计两个执行对齐的时序查询（Q8 与 Q15），仅通过联合掩码注意力向动作专家传递结构化历史；
- 部署阶段不保留任何运动估计器或几何处理器，时序信息仅作为查询编码存在。

### 2.2 关键技术细节

- **机器人表面时序流构建**：
  - 对区间 ρ ∈ {8, 15}，分别以 s = t − ρ 与 t 为时间点；
  - 通过正向运动学 T_lB(q_τ) 与标定变换 T_C←B 将源帧像素 p 从基坐标系转到目标帧的链接坐标系，并在 z 轴方向找到机器人表面交点 X_B^s(p)；
  - 通过 Π_K 投影回目标图像像素 ũ_t(p)；
  - 在最近像素查找中要求：投影在图像范围内、同属一个链接 l(p)、3D 残差 ≤ 5 mm；
  - 最终生成 16 × 16 × 2 的块级流标签 F_ρ(k)，并定义覆盖率 c_ρ(k) 与掩码 M_ρ(k)（c_ρ(k) ≥ 0.1）。

- **层次化时序查询与联合注意力**：
  - 可学习 token q8、q15 与历史 patch V15、V8 一同被附加到 π0.5 的标准前缀；
  - **有向掩码机制**：Q8 仅能读取语言 token、t−8 观测、当前观测及自身；Q15 额外可读取 t−15 观测与 Q8，形成 Q8 → Q15 的单向信息流；
  - 每个区间拥有独立的 query-conditioned 解码器 D_ρ(V_ρ, z_ρ)：以查询 z_ρ 经 FiLM 调制（γ_ρ、β_ρ）后接两层 pointwise MLP 输出预测流；
  - 损失函数：`L_ρ^flow = Σ M_ρ(k) · ℓ_Huber(F̂_ρ(k), F_ρ(k)) / (Σ M_ρ(k) + ε)`，`L_temp = (L_8^flow + L_15^flow) / 2`；
  - 总损失：`L = L_action + λ_temp · L_temp`，主实验中 λ_temp = 1.0。

- **动作专家的接入方式**：
  - 不引入额外 cross-attention 模块或历史专用残差门；
  - 利用既有联合掩码自注意力机制，使动作 token 仅通过 Q8 与 Q15 间接获取历史视觉信息，并阻断其对 V8、V15 的直接访问；
  - 完整保留原始 AdaRMS 残差调制。

- **异步历史特征缓存**：
  - 将头部相机观测写入时间戳环形缓冲区；
  - 后台进程异步提取并存储历史视觉特征 V_τ，C[τ] = V_τ；
  - 重规划 t 时刻：V_15 = C[t−15]，V_8 = C[t−8]，仅当前帧同步编码；
  - 部署延迟从 `T_naive = 3T_vision + T_joint + T_action` 降至 `T_cache ≈ T_vision + T_joint + T_action`；
  - 剧集开始缺失的历史用最早观测填充并标记无效，直到两个历史帧 token 都可用时才启用缓存。

## 3. 实验设计

### 3.1 数据集 / 场景
- **LIBERO**：包含 Spatial、Object、Goal、Long 四套基准；
- **RoboTwin 2.0**：12 项双臂任务，按操作步数分为 H=1、H=2、H=3 三组（参照 LingBot-VA 分组方式），每任务 50 个干净演示 + 500 个随机化演示；
- **真实机器人**：AgiBot A3 上两项三阶段任务（Three-Cup Stacking、Two-Bottle Packing），各 280 次演示，仅头部相机用于训练时序流监督。

### 3.2 对比方法
- **RoboTwin 2.0**：π0、π0.5、X-VLA †（GigaWorld-Policy 中的 RoboTwin 再评估版本）、GigaWorld；
- **LIBERO**：π0.5、GR00T N1.7、CronusVLA、HAMLET、MotionVLA；
- **真实机器人**：仅与基础策略（Baseline）对比，无第三方基线。

### 3.3 评估协议
- LIBERO：3 个种子（0、2、5），每套 500 次 rollout，报告 mean ± SD；
- RoboTwin：每任务 100 次 rollout，分 Clean 与 Randomized 两个条件；
- 真实机器人：每任务 3 轮 × 15 次试验，共 45 次；
- 此外进行：离线历史扰动诊断、推理效率对比（RTX 4090，前 15 次重规划）。

## 4. 资源与算力

- 训练硬件：**8 张 NVIDIA H100 GPU**，单卡 batch size 32；
- 训练时长：
  - LIBERO：联合训练 Spatial、Object、Goal、Long 共 **30k steps**；
  - RoboTwin 2.0：12 任务联合训练 **60k steps**；
- 训练开销：增加时序模块与辅助流解码器后，wall-clock 训练时间相对基线增加约 **20%**；
- 部署硬件（推理效率测试）：**RTX 4090** 单卡，未包含 RPC、仿真步进与视频写入时间；
- 未明确说明：单步实际耗时、H100 训练总小时数、能耗与碳足迹等。

## 5. 实验数量与充分性

- 实验类型涵盖：仿真基准评估、离线历史扰动诊断、组件消融（Multi-frame vs 2Q w/o Flow vs Q8 only vs Q15 only vs Ours）、推理效率评估、真实机器人迁移评估；
- 消融维度包含：原始历史、查询瓶颈、流监督、单一查询与组合查询对比；
- 优点：
  - 仿真基准覆盖标准 LIBERO 与高难度 RoboTwin 2.0，并按 horizon 分组报告 H=1/2/3 表现；
  - 离线扰动实验同时控制内容（移除）和顺序（打乱 t−15 与 t−8），并区分了六个任务的差异化敏感性；
  - 真实机器人在具有"必须跨阶段保持进度"特征的两项三阶段任务上验证了迁移能力；
- 不足：
  - 真实机器人仅对比自身 Baseline，未与第三方 VLA 方法在物理平台上对照；
  - 真实实验只评估了 2 个任务、每方法每任务 45 次试验，统计显著性有限；
  - 仿真中三种方法的 baseline 数字直接来自先前论文（π0、π0.5 来自 LingBot-VA，X-VLA † 与 GigaWorld 来自 GigaWorld-Policy），并未在本工作中重新训练，存在基准不公平风险；
  - 离线流匹配损失扰动不能直接等同于在线成功率的因果证据。

## 6. 主要结论与发现

- **LIBERO**：平均成功率 **97.63 ± 0.26%**，Long 子集 **96.60 ± 0.87%**，比其列出的最强先前方法高 2.1 个百分点；
- **RoboTwin 2.0**：Clean **85.5%**、Randomized **84.2%**，在 Randomized 上比最佳已发表基线高 8.0 个百分点；
- **Horizon 依赖性收益**：H=2 提升 5.5 分、H=3 提升 14.5 分，而 H=1 平均并非最高，验证了"近期执行历史对多阶段任务最有用"的假设；
- **历史依赖性诊断**：打乱或移除历史都会升高动作 flow-matching 损失，且打乱在五项任务上比移除更敏感（仅 put bottles 任务例外）；
- **消融结论**：双查询无流监督已优于 Multi-frame（83.2%/83.6% vs 79.8%/81.5%），加入流监督后进一步达到 85.5%/84.2%；Q8 only 与 Q15 only 均弱于组合，说明长短程互补；
- **推理效率**：异步缓存将平均重规划延迟从 68.10 ms 降至 62.78 ms，15 次重规划累计节省 79.8 ms（7.8%）；
- **真实机器人**：Three-Cup Stacking 从 57.8% 提升至 77.8%（+20.0），Two-Bottle Packing 从 86.7% 提升至 97.8%（+11.1）。

## 7. 优点

- **物理接地监督**：利用自有的关节状态与几何，将机器人表面流作为训练目标，不依赖人工光流标注或额外传感器；
- **部署简洁性**：训练阶段的几何路径在部署时整体移除，无运动/光流/轨迹估计器；
- **联合注意力机制巧妙**：通过有向掩码自然地把"短程 → 长程"的层级关系内嵌进 VLA 既有注意力，避免新增模块；
- **稀疏历史暴露**：动作 token 仅能通过两个查询获取历史，大幅压缩了动作分支的时间带宽；
- **异步特征缓存**：解决历史重编码的延迟成本，工程实用性突出；
- **诊断性实验设计**：用离线 flow-matching 损失严格区分"历史有无"和"历史顺序"两类因素的影响；
- **horizon 分组报告**：明确展示出方法在长视野、多阶段任务上的差异化优势。

## 8. 不足与局限

- **固定时序尺度**：硬编码使用 t−15 与 t−8 两个时间点，未探索历史帧数、时间间隔对不同任务的适配性，论文已在结论中明确指出这是未来工作方向；
- **仿真对比的基线复用**：多个对比方法的数字直接继承先前工作，存在训练配置、随机种子、可视化标注差异带来的基准偏差；
- **真实机器人迁移规模有限**：仅 2 个任务、2 种方法（自身 Baseline 与本文方法），缺乏与 π0.5、TraceVLA 等同期方法的物理对照；
- **离线诊断与在线行为的脱节**：flow-matching 损失扰动并不直接反映成功率，且未在真实场景下实施打乱/移除历史的消融；
- **场景与外观变化范围**：真实实验中两个任务都属于相对结构化场景，未覆盖长视野中常见的物体外观剧变、视觉遮挡、光照突变等情况；
- **计算开销报告粗粒度**：仅给出训练 +20% 与推理 7.8% 两个总量指标，未报告显存占用、首帧延迟、吞吐量等更细粒度的部署指标；
- **依赖标定数据**：需要相机-机器人外参标定才能生成监督，且 URDF 与关节轨迹质量直接影响监督信号，给系统迁移带来额外工程门槛；
- **未利用 RGB 之外的模态**：历史监督完全建立在机器人自身运动上，对物体运动、外力扰动等"非自我运动"信息无明确建模。
