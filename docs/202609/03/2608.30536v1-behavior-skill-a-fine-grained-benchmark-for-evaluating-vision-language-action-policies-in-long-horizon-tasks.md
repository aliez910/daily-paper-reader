## 摘要
长周期移动操作任务的可靠执行仍然具有挑战性，因为整体任务的成功依赖于多个组成技能的顺利完成。然而，现有基准仍然主要依赖完整任务的回放和任务级聚合指标，使得中间阶段的失败难以观察和分析。我们提出了 Behavior-Skill，一个围绕可执行组成技能重新构建长周期任务学习与评估的基准。它包含来自 50 个家庭任务和 34 个语义技能类别的 10,000 次演示中的 235,492 个技能实例。每个实例将一条技能指令与对齐的观察-动作片段配对，并进一步关联一个可恢复的中间状态和技能成功条件，以在有效前置条件下实现独立评估。我们进一步引入了轨迹级和技能级指标，以刻画超越聚合任务成功率的策略能力。在完整 50 个任务基准上对包括 pi0.5 和 GR00T 在内的代表性 VLA 策略进行的大量实验表明，失败在不同技能间高度不均匀，其中接触丰富的操作技能构成了持续的瓶颈。这些结果表明，Behavior-Skill 通过揭示中间能力概貌来补充完整任务评估，以分析和改进长周期 VLA 策略。Behavior-Skill 已公开发布，地址为 https://github.com/nubot-nudt/Behavior-Skill。

## Abstract
Reliable execution of long-horizon mobile manipulation tasks remains challenging because overall task success depends on the successful completion of multiple constituent skills. Existing benchmarks, however, still rely primarily on full-task rollouts and aggregate task-level metrics, making intermediate failures difficult to observe and analyze. We present Behavior-Skill, a benchmark that reformulates the learning and evaluation of long-horizon tasks around executable constituent skills. It contains 235,492 skill instances from 10,000 demonstrations across 50 household tasks and 34 semantic skill categories. Each instance pairs a skill instruction with an aligned observation-action segment, and is further associated with a restorable intermediate state and a skill success condition to enable independent evaluation under valid preconditions. We further introduce trajectory-level and skill-level metrics to characterize policy capability beyond aggregate task success. Extensive experiments across representative VLA policies including pi0.5 and GR00T on the complete 50-task benchmark show that failures are highly non-uniform across skills, with contact-rich manipulation skills forming persistent bottlenecks. These results demonstrate that Behavior-Skill complements full-task evaluation by exposing intermediate capability profiles for analyzing and improving long-horizon VLA policies. Behavior-Skill is publicly available at https://github.com/nubot-nudt/Behavior-Skill.

# Behavior-Skill 论文总结

## 一、核心问题与研究动机

长周期移动操作任务（long-horizon mobile manipulation）的可靠执行是当前具身智能领域的核心挑战之一。尽管 VLA（Vision-Language-Action）模型如 RT-2、OpenVLA、π0 系列、GR00T 等在短周期基准上取得了 80% 以上的成功率，但在长周期基准 BEHAVIOR-1K 上最佳性能仅 31.4%，表明长周期多阶段任务远未解决。

**关键洞察**：长周期任务的成功本质上依赖多个**组成技能（constituent skills）**的可靠串行执行——任何一个技能的失败都会中断任务进程。然而现有基准普遍存在以下局限：
- 数据组织以**任务级**为单位，仅提供任务级语言标注；
- 评测通过**完整任务回放**进行，仅给出最终任务成功率或整体进度指标；
- 中间技能失败难以被观察和分析，无法定位真正的能力瓶颈。

随着任务周期变长，这种缺陷愈发明显：早期失败会阻止后续技能被执行，聚合指标信息量有限，策略能力画像缺失。

## 二、方法论

### 2.1 核心思想
Behavior-Skill 将组成技能确立为长周期任务学习与评估的**基本单元**，提供：
1. **技能数据集**——基于 BEHAVIOR-1K 标注的细粒度技能实例；
2. **独立技能评估框架**——支持在有效前置条件下独立评测每个技能；
3. **能力导向的评测指标**——从轨迹级和语义技能类型两个互补维度刻画策略能力。

### 2.2 技能数据集构建
- **规模**：来自 10,000 次演示、50 个 BEHAVIOR-1K 长周期任务，共 **235,492 个技能实例**，平均执行时长 16.6 秒；
- **技能分类**：34 个语义技能类别，执行时长从 3.2 秒到 70.9 秒不等；
- **多模态标注上下文**：
  - 文本：原始技能记录（动作标签、物体 ID、技能类型、时间区间）+ 任务描述 + 已完成技能描述；
  - 视觉：采用**时长自适应采样策略**（最多保留 64 个时间戳），将头部、左腕、右腕三视角拼接为多视角观测；
  - 动作：将技能区间内 23-DoF 帧级动作（底盘 + 双 7-DoF 臂 + 双夹爪）聚合为紧凑运动描述（如"左臂移动，夹爪闭合；右臂移动，夹爪张开"）；
- **标注流程**：使用 Qwen3-VL-235B-A22B-Instruct 自动生成标注，辅以 ChatGPT-5 一致性检查与人工审核。

### 2.3 独立技能评估框架
每个评估单元定义为四元组：
$$E_{i,j} = (S_{i,j},\ L_{i,j},\ G_{i,j},\ H_{i,j})$$
- **$S_{i,j}$**：技能执行前的模拟器中间状态；
- **$L_{i,j}$**：技能指令；
- **$G_{i,j}$**：BDDL（Behavior Domain Definition Language）形式定义的技能成功条件；
- **$H_{i,j}$**：最大评测时界（设为原始演示时长的 2 倍）。

**关键步骤**：
1. **中间状态恢复**：由于 BEHAVIOR-1K 的 HDF5 记录使用 active-object filter，单帧不足以恢复完整场景；采用基于轨迹的状态重建——从初始状态顺序应用转移事件并执行动作直至目标技能起始帧，序列化完整状态并重建 assisted-grasp 约束；
2. **技能成功条件**：基于任务 BDDL 与技能标注联合分析，提取操作对象、交互类型等；针对导航、抓取、交接等中间行为，引入少量技能专属谓词扩展（如机器人-物体邻近、交接关系），并通过与原生 BDDL 谓词相同的接口集成；
3. **评测流程**：从恢复状态初始化 → 注入 BDDL 目标 → 策略接收观测与指令执行 → 每步通过 BDDL 引擎判定成功 → 满足即终止，否则到时界判定失败。

### 2.4 评测指标

**任务技能完成率（Task Skill Completion Rate, TSCR）**——轨迹级：
$$TSCR(\tau_i) = \frac{1}{M_i}\sum_{j=1}^{M_i} y_{i,j},\quad \overline{TSCR} = \frac{1}{N}\sum_{i=1}^{N} TSCR(\tau_i)$$

**技能类型成功率（Skill-Type Success Rate, STSR）**——语义技能类型级：
$$STSR_k = \frac{\sum_{i,j}\mathbb{I}(c_{i,j}=k)\,y_{i,j}}{\sum_{i,j}\mathbb{I}(c_{i,j}=k)}$$

二者互补：TSCR 刻画单次演示内技能完成比例，STSR 聚合同类技能的执行成功率，揭示能力分布。

## 三、实验设计

### 3.1 基准与场景
- **主评测**：完整 50 任务 BEHAVIOR-1K 基准；
- **细粒度分析**：12 任务子集（参照 [14] 协议）；
- **对比传统评测**：3 个代表性任务（Make Microwave Popcorn、Wash a Baseball Cap、Cook Hotdogs）。

### 3.2 对比方法
- **π0.5** 和 **GR00T N1.7** 两个代表性 VLA 策略；
- 每个策略下设置两种变体：
  - **Task**：任务指令训练 + 任务 prompt 推理；
  - **Skill**：技能指令训练 + 技能 prompt 推理；
- 二者除语言条件外，其余架构、观测、动作、优化目标、训练调度完全一致。

### 3.3 数据划分
每任务随机保留 10 次演示作为评测集，其余用于训练；共 500 次评测演示，包含其全部技能。

## 六、主要结论与发现

1. **技能失败高度不均**：即使经过 Skill 训练，π0.5 的整体 TSCR 仅 48.4%，GR00T N1.7 仅 42.5%——不足半数技能能可靠完成；
2. **能力瓶颈集中**：接触丰富操作技能（Open Lid、Close Door、Close Lid、Pick Up From、Pour 等）成功率持续最低，而简单空间推理/状态转换技能（Sweep Surface、Place Under、Hold、Spray、Release、Move To）成功率较高；
3. **跨策略共性**：两个差异显著的 VLA 策略表现出"惊人相似"的能力画像，说明瓶颈是**结构性的**而非架构特有的；
4. **Skill 训练带来有限提升**：TSCR 分别提升 +6.0 和 +5.6 个百分点，但无法消除低成功率瓶颈；
5. **任务级与技能级指标严重背离**：如 Wash a Baseball Cap 和 Cook Hotdogs 的 QScore 均为 0%，但 TSCR 分别为 80.0% 和 69.0%；Make Microwave Popcorn QScore=10% 时 TSCR=75.0%；传统完整任务评测因早期失败导致大量后续技能被"未执行"，遮蔽了真实能力分布；
6. **技能难度与任务上下文相关**：同一语义技能在不同任务中成功率差异巨大（如 Open Door 在 Make Microwave Popcorn 中仅 9.0%，在 Cook Hot Dogs/Wash a Baseball Cap 中达 78.0%），表明语义标签不能单独决定难度，物体几何、目标关系、场景上下文共同影响执行可靠性。

## 七、优点与亮点

1. **评测视角创新**：将组成技能作为基本评测单元，突破了任务级聚合指标的局限，为长周期策略提供可解释的能力画像；
2. **框架完整**：数据集 + 中间状态恢复 + BDDL 目标 + 指标体系，构成端到端可复用的评测框架，并已开源；
3. **数据规模大**：235,492 个技能实例、34 类语义技能，是目前规模最大的技能级长周期操作数据集之一；
4. **技术细节扎实**：
   - 提出轨迹式状态重建解决 active-object filter 导致的状态丢失问题；
   - 设计时长自适应视觉采样策略高效利用多模态信息；
   - 引入技能专属 BDDL 谓词扩展，统一接口集成；
5. **指标互补**：TSCR + STSR 从轨迹和语义两个维度刻画能力；
6. **基线实验设计严谨**：Task/Skill 设置共享除语言条件外的所有变量，确保对比公平。

## 八、不足与局限

1. **覆盖策略有限**：仅在 π0.5 与 GR00T N1.7 上评测，未涵盖 OpenVLA、RT-2、Octo、Hi Robot、InstructVLA 等代表性 VLA 模型；
2. **缺乏消融实验**：未系统检验各组件（如状态重建策略、BDDL 谓词扩展、采样策略、标注质量）对结果的影响；
3. **未涉及任务规划与技能分解**：作者明确指出，Behavior-Skill 聚焦独立技能评估，**不覆盖**任务规划、自动任务分解以及技能间的**顺序依赖关系**，这是长周期任务的核心难点之一；
4. **域局限于仿真**：完全基于 BEHAVIOR-1K 仿真环境，未涉及真实机器人评测或 sim-to-real 一致性验证；
5. **训练算力信息缺失**：未披露 GPU 型号、数量与实际训练耗时，影响可复现性评估；
6. **技能粒度依赖原始标注**：技能语义类别来自 BEHAVIOR-1K 原始标注，可能存在标注粒度不均或一致性不足的问题；
7. **评测时界设定为原始演示时长的 2 倍**：对不同技能的最优时界缺乏论证，可能对长时长技能不够友好；
