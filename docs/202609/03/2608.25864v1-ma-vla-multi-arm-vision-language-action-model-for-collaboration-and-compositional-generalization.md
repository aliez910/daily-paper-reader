## 摘要
多机械臂协作正成为具身操作的核心能力。最近的视觉-语言-动作（VLA）模型将感知、语言与控制融为一体，但大多数将语言表示为单一的全局指令，并未提供明确的机制来分配和组合各机械臂特定的行为。这种设计限制了向训练中未见过的协作模式的迁移。我们提出 MA-VLA，一个通过原子动作分配实现多机械臂协作的统一框架。MA-VLA 将协作行为分解为中层原子提示，并将其分配给各个机械臂，从而实现明确的子目标规约以及跨任务的可组合复用。为减少对固定执行角色的依赖，我们引入了 Arm Shuffle（机械臂随机重排），一种在训练时对每个机械臂的观测、状态以及所分配的原子提示进行置换的策略。该置换强制实现与角色无关的指令跟随，并支持重组成未见过的协调模式，我们将其称为多机械臂组合泛化。我们还构建了一个基准测试，其中测试时的协作模式在训练集中完全不存在。在仿真与真实世界评估中，先前的最先进 VLA 在这些未见过的协作场景下基本失败，而 MA-VLA 则始终表现良好。这些结果表明，结构化的、按机械臂划分的原子动作分配为多机械臂具身系统中的可扩展泛化提供了一条切实可行的路径。代码、模型和数据可在 https://github.com/zhangzaibin/future-robots 获取。

## Abstract
Multi-arm collaboration is becoming a core capability in embodied manipulation. Recent vision-language-action (VLA) models integrate perception, language, and control, but most represent language as a single global instruction and do not provide an explicit mechanism for assigning and composing arm-specific behaviors. This design limits transfer to collaboration patterns that differ from those observed during training. We present MA-VLA, a unified framework for multi-arm collaboration via atomic action assignment. MA-VLA decomposes cooperative behavior into mid-level atomic prompts and allocates them to individual arms, enabling explicit subgoal specification and compositional reuse across tasks. To reduce reliance on fixed execution roles, we introduce Arm Shuffle, a training-time permutation of the observation, state, and assigned atomic prompts for each arm. This permutation enforces role-agnostic instruction following and supports recomposition into unseen coordination patterns, which we term multi-arm compositional generalization. We also construct a benchmark in which test-time collaboration patterns are absent in training set. Across simulation and real-world evaluations, prior state-of-the-art VLAs largely fail under these unseen collaborations, while MA-VLA consistently succeeds. These results indicate that structured, per-arm atomic action assignment offers a practical route to scalable generalization in multi-arm embodied systems. Code, models, and data are available at https://github.com/zhangzaibin/future-robots

# MA-VLA 论文总结

## 一、核心问题与研究动机

- **研究背景**：多机械臂协作是具身操作中的核心能力，能够通过并行执行与协调控制解决单臂难以完成的任务。
- **现有 VLA 的局限**：现有视觉-语言-动作（VLA）模型通常将语言视为单一的全局指令映射到控制输出，缺乏显式的任务分解与子任务分配机制，导致：
  - 协作分工只能隐式地从数据中学习；
  - 容易过度拟合训练中出现的少数固定协作模式；
  - 无法泛化到训练时未见的协作模式（如新的堆叠顺序、传递策略）。
- **本文核心问题**：研究一种**多臂组合泛化（multi-arm compositional generalization）**能力——即系统能否通过重组训练中已知的"原子动作"，在测试时完成训练未出现的协作模式。
- **关键设定**：原子动作集合 U_train 与测试集 U_test 相同，但协作模式 P_test 不属于 P_train（OOD），差异来源包括：(i) 臂角色分配；(ii) 时序与同步；(iii) 中间状态与臂间交互。

## 二、方法论

### 2.1 整体架构

MA-VLA 是统一的端到端 VLA 框架，包含两个核心组件：

- **VLM 规划器 P_φ**：将高层指令分解为按时间阶段排序的、每臂的子指令（原子提示）。
- **VLA 执行器 π_θ**：将这些语言化的子目标落地为各臂的连续控制动作。
- 采用基于 pi0（流匹配）的控制生成，并加入多头投影层将共享潜空间分离为各臂专属的动作输出头。

### 2.2 VLM 规划器：基于原子提示的任务分解

- 给定高层指令 l、视觉观测 I 和预定义的原子提示集合 A（一个有限的、可复制的动作词汇表），规划器在一次前向传播中生成 T 个阶段、每阶段 N 个臂的子指令：
  $$l = (p^1, \ldots, p^T),\quad p^t = (p^t_1, \ldots, p^t_N),\quad p^t_i \in A$$
- 实际使用 GPT-4.1 进行提示模板选择与规范化，规划器不进行微调，仅生成语言提示。
- 阶段（stage）表示时间锚定的子目标，执行直到任务相关的终止条件满足。

### 2.3 VLA 执行器：多臂动作生成

- 各臂的原子提示拼接为统一指令串：
  $$u_t = \text{Arm}_0:p^0_t,\ \text{Arm}_1:p^1_t,\ \ldots,\ \text{Arm}_N:p^N_t$$
- 输入：(1) 多视角观测 I_t（全局 + 腕部 RGB-D）；(2) 各臂本体感知状态 s_t；(3) 统一指令 u_t。
- 输出：所有臂的动作向量：
  $$[a^1_t,\ldots,a^N_t] = \pi_\theta(I_t, s_t, u_t)$$
- 流匹配用于生成时序平滑、动作空间物理一致的轨迹。

### 2.4 训练策略：组合泛化的随机正则化

- **Arm Shuffle**：在每次训练迭代中，以概率 p_shuffle 随机置换各臂的（状态、视角、原子提示、动作）四元组：
  $$\{(s^i_t, v^i_t, p^i_t, a^i_t)\} \xrightarrow{\text{shuffle}} \{(s^{\sigma(i)}_t, v^{\sigma(i)}_t, p^{\sigma(i)}_t, a^{\sigma(i)}_t)\}$$
  - 强制模型不依赖臂的固定身份或位置，而是根据原子提示的语义决定行为。
- **View Dropout**：以概率 p_drop 随机遮蔽部分相机视角，迫使模型利用冗余的空间线索。
- 训练目标仍是行为克隆损失，但输入在数据层面被扰动：
  $$\mathcal{L}_t(\theta) = \mathbb{E}\bigg[\sum_{i=1}^{N} \ell\big(\pi_\theta(\tilde{I}_t, s^i_t, p^i_t), a^i_t\big)\bigg]$$

## 六、主要结论与发现

- **同域性能**：MA-VLA 在 RoboFactory 双臂（83.5% vs Pi0 80.3%）、三/四臂（83.3% vs Pi0 76.5%）和 RoboTwin 2.0 Hard（49.0% vs Pi0 41.1%）上均稳定优于 Pi0 与扩散策略基线，臂数越多增益越明显。
- **OOD 组合泛化**：所有基线（含 Pi0）在 OOD 协作任务上成功率均为 0.0%，MA-VLA 在仿真 OOD 平均提升约 +13%，真机 OOD 上从 0/20 提升到 2–10/20（不同任务）。
- **消融结论**：
  - 原子提示主要提升 ID 性能；
  - Arm Shuffle 是 OOD 突破的关键（成功率从 0.0% → 11.7%）；
  - View Dropout 在 OOD 上进一步小幅提升；
  - Separate Model 不能跨臂协调，推理开销随臂数线性增长，验证统一框架必要性。
- **总论**：结构化的"按臂原子动作分配"+ 训练时的角色随机化 + 视角冗余正则化，是实现多臂具身系统可扩展组合泛化的可行路径。

## 七、优点与亮点

- **问题定义新颖**：明确提出"多臂组合泛化"这一尚未被广泛研究的设置，并构造了 OOD 协作基准。
- **可解释的协作接口**：通过原子提示将"谁做什么"显式化，分工不再隐式。
- **训练时正则化简洁有效**：Arm Shuffle + View Dropout 不改变训练目标，仅在数据层扰动，便于与现有 VLA 集成。
- **统一端到端框架**：单模型一次性输出所有臂的动作，相比"独立臂 VLA"具备部署与扩展优势。
- **多层级评测**：仿真 + 真机 + 同域 + OOD + 消融，论证较为立体。
- **开源**：代码、模型、数据公开（GitHub: zhangzaibin/future-robots）。

## 八、不足与局限

- **OOD 绝对成功率仍偏低**：仿真 OOD 平均仅 ~13%，真机 OOD 多在 10/20 以下，说明对"未见协作模式"的泛化能力仍有较大提升空间。
- **数据规模有限**：仿真 150 条、真机 50 条演示，相比大规模 VLA 训练数据明显不足，可能限制表达力和鲁棒性。
- **原子词汇表的封闭性**：A 为有限、预定义的人工模板集合，限制了对未覆盖行为的处理能力；规则解析器依赖人工设计的状态谓词。
- **规划器未微调**：依赖 GPT-4.1 调用，引入外部 API 依赖、推理延迟与潜在的不稳定性；规划阶段与执行阶段解耦，端到端优化存在空缺。
- **真机评估规模偏小**：每任务仅 20 次测试，且仅在 SO101 双臂平台验证，未覆盖更多臂或更复杂硬件。
- **基线适配的公平性风险**：ACT/DP/DP3 等原本面向单臂，多臂适配未必最优，可能放大 MA-VLA 的相对优势；Pi0 的接口与训练设置较原生，可能对其他基线略不公平。
- **应用限制**：在长视野、强时序耦合、对错误累积敏感的协作任务中（如 Deliver 这种长流水线），MA-VLA 在 ID 上的错误率仍较高，尚未达到实用门槛。
- **缺失讨论**：论文未给出训练时长、推理延迟、参数规模、计算能耗等开销数据，也未深入分析失败案例的成因。
