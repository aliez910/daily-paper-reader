## 摘要
视觉-语言-动作（VLA）模型在机器人操作领域展现出日益显著的应用潜力，但其实际部署仍受高推理延迟和不稳定异步执行所限制。这一挑战在基于流匹配的 VLA 模型中尤为突出，因为其动作解码需要以视觉语言模型（VLM）上下文为条件，并进行多次迭代。尽管高效推理方法能够提高控制频率，异步方法能够减少执行过程中的空闲时间，但现有方法往往无法同时实现低延迟推理以及准确、时间一致的异步执行。我们提出了 FlashVLA，这是一种以统一形式解决这两项挑战的流式动作解码框架。FlashVLA 维护一个流式动作缓冲区，其中包含处于不同噪声水平的多个动作块，并采用分块因果注意力对其进行解码。该设计使 FlashVLA 能够在每次推理时生成一个可执行动作块。此外，其分块自回归形式能够隐式保持动作的连续性，从而在无需额外未来状态条件的情况下实现平滑的异步执行。在大量仿真和真实世界实验中，FlashVLA 在保持强大任务性能的同时显著提升了推理速度。在真实世界部署中，它能够在单块 GPU 上实现不低于 30 Hz 的控制频率，并进行平滑的异步推理。

## Abstract
Vision-Language-Action (VLA) models are increasingly promising for robotic manipulation, yet their real-world deployment remains bottlenecked by high inference latency and unstable asynchronous execution. This challenge is particularly pronounced in flow-matching-based VLA models, where action decoding requires multiple iterative steps conditioned on the VLM context. While efficient inference methods improve control frequency and asynchronous methods reduce execution idle time, existing approaches often fail to jointly achieve low-latency inference and accurate, temporally consistent asynchronous execution. We introduce \textbf{FlashVLA}, a streaming action decoding framework that addresses both challenges in a unified formulation. FlashVLA maintains a streaming action buffer with multiple chunks at different noise levels and decodes them using chunk-wise causal attention. This design allows FlashVLA to produce one executable action chunk per inference step. Moreover, its chunk-wise autoregressive formulation implicitly preserves action continuity, enabling smooth asynchronous execution without extra future-state conditioning. Across extensive simulated and real-world experiments, FlashVLA substantially improves inference speed while maintaining strong task performance. It can achieve $\geq$30\,Hz control frequency on a single GPU with smooth asynchronous inference in real-world deployment.

# FlashVLA 论文详细总结

## 一、核心问题与研究动机

- **VLA 模型部署瓶颈**：视觉-语言-动作（VLA）模型（尤其是基于流匹配的 π0.5）在机器人操作中展现出强大的泛化能力，但实际部署面临两大瓶颈：
  - **高推理延迟**：在 RTX 4090 上对 π0.5 的 profiling 显示，动作解码消耗了 75% 的单步推理时间，主要来自每个 chunk 所需的 10 次顺序去噪步骤。
  - **异步执行不稳定**：同步推理会在每个 chunk 边界使机器人停滞；异步推理虽能重叠预测与执行，但基于陈旧观测进行预测，动作到达的机器人状态是模型未曾见过的，预测-执行失配随 lookahead 增长。
- **现有方法的不足**：高效推理方法（轻量骨干、量化、token 剪枝等）只让每次前向更便宜；异步方法（未来状态条件、动作流匹配等）则在解码后修补失配。两者均未解决根本问题——**每个 action chunk 都是孤立解码的**，既造成延迟集中，又造成 chunk 间互不知晓轨迹。
- **本文核心洞察**：延迟与异步失配源于同一结构性原因——孤立解码。一次性将 chunk **联合解码**，可同时消除这两种代价。

## 二、方法论

### 2.1 核心思想
借鉴长视频生成中的流式分块扩散（streaming chunk-wise diffusion），将 VLA 动作解码从"孤立"转变为"联合"——维护一个含 N 个处于不同噪声水平的 action chunk 的流式缓冲区，在 chunk 级因果注意力下同时推进。

### 2.2 关键技术细节

- **流式动作缓冲区**：缓冲区 $B_t = [x_{\tau_1}^{(1)}, x_{\tau_2}^{(2)}, \dots, x_{\tau_N}^{(N)}]$，其中 $\tau_1 < \tau_2 < \dots < \tau_N$，$\tau_i = 0.001 + 0.999 \cdot \frac{i-1+u_i}{N}$，$u_i \sim \text{Beta}(1.5, 1.0)$。
  - 第 1 个槽：接近干净、即将执行；第 N 个槽：纯噪声、若干步后执行。
  - 噪声水平与去噪进度、执行顺序同步对齐。
- **块级因果注意力（chunk-wise causal attention）**：噪声更高的 chunk 可关注噪声更低（更干净）的 chunk，但反向不行。信息沿时间正向流动而非沿噪声反向。
- **三个运行时性质**：
  1. **摊销去噪**：每个 chunk 经历 N 次去噪步骤，但 N 次分散在 N 个前向步中，每步同时推进所有 chunk。
  2. **隐式异步条件**：未来 chunk 通过因果注意力已隐式以正在执行的轨迹为条件。
  3. **块级记忆**：每个高噪声 chunk 可关注缓冲区中所有早期 chunk，形成短而结构化的已细化 chunk 历史。

### 2.3 流式推理算法

- **冷启动（Cold Start）**：用 N-1 个 padding chunk + 1 个高斯噪声初始化，运行 N-1 次推理填充缓冲区；期间机器人执行安全默认动作（关节空间保持初始状态或末端执行器的零动作）。
- **稳态流式（Steady Streaming）**：每次推理（i）所有 chunk 同时推进一步；（ii）弹出最干净 chunk 执行；（iii）剩余 chunk 前移；（iv）尾部追加新的纯噪声 chunk。
- **系统级优化**：CUDA Graph 编译 + 线性层打包 + PyTorch max-autotune，与算法设计正交但对实现完整延迟收益至关重要。

### 2.4 训练：多缓冲区联合微调（Multi-Buffer Joint Fine-tuning）

- **挑战**：对于单个观测 $o_t$，冷启动产生 N 种不同缓冲区配置（j 个真实 chunk + N-j 个 padding），独立处理会将数据集乘以 N。
- **解决方案**：将 N 种配置**打包进单个训练样本**，共享同一观测编码，attention mask 隔离各缓冲区。
- **训练目标**：标准的 flow-matching loss 在所有缓冲区配置上求和：
  $$L_{\text{joint}} = \sum_{j=1}^{N} \sum_{i=1}^{j} \mathbb{E}_{\tau_i, z_i} \| v_\theta(x_{\tau_i}^{(i)}, \tau_i | o_t, B_t^{(j)}) - (z_i - a_i^{(i)}) \|^2$$

### 2.5 模型架构改动

- 仅需对动作专家（action expert）做轻微改动：使用 FiLM 增强多层时间步条件。
- 对 SmolVLA 等不原生支持 FiLM 的模型，新增 time-MLP 和 FiLM 层。
- 对存在梯度爆炸问题的数据集（如 RoboTwin 2.0 50 任务），重新初始化动作专家的 normalization 层，其余权重从预训练加载。

## 六、主要结论与发现

- **延迟大幅降低**：动作解码单步延迟最高下降 20×；LIBERO 上 end-to-end 每步时间从 53.8 ms 降至 22.1 ms（2.43×）；RTX 5090 双视图下达到约 50 Hz 策略更新率（20.3 ms）。
- **异步执行提升且鲁棒**：LIBERO 上 d=1 时平均成功率从 96.9% 升至 97.8%，并在 d=1–4 全程保持在 97.5%–98.3%；VLASH 在 d=4 下降至 93.1%。
- **同步质量不降反升**：LIBERO 平均成功率 96.9% → 97.9%；RoboTwin 2.0 从 86.0% 升至 90.5%。
- **长horizon 显著增益**：RoboTwin 2.0 长horizon 任务成功率提升 36.6 点（Clean：54.2% → 90.8%；Random：51.8% → 88.4%）；LIBERO-Long 提升 3.8 点。
- **块级因果 mask 是关键**：移除因果 mask 后异步成功率降约 10 点，证明块级因果注意力是异步连续性的核心机制，而非缓冲区本身。
- **跨架构可迁移**：SmolVLA 推理延迟 1.95× 加速，任务成功率持平；LingBot-VLA 推理延迟 2.81× 加速，成功率提升 3.4–4.1 点。
- **真实世界 30 Hz 控制**：在 RTX A4000 上推理延迟 67.3 ms（约两个 30 Hz 周期），两步异步延迟实现平滑 30 Hz 控制；平均任务得分 80.0% → 84.4%，完成时间 1.3× 加速。

## 七、优点与亮点

- **统一框架同时解决两个问题**：单结构改动（chunk 联合解码 + 块级因果注意力）同时消除延迟与异步失配，区别于以往两类方法的独立修补。
- **方法简洁优雅**：将长视频生成中的 streaming chunk-wise diffusion 范式迁移到动作解码，且论证其更适合动作（"low-noise chunks 不仅即将显示，而且即将执行"）。
- **drop-in 即插即用**：只需动作专家的轻微改动 + 一次微调即可适配任何 flow-matching VLA。
- **跨架构泛化强**：在 π0.5、SmolVLA、LingBot-VLA 三种架构上均验证有效。
- **实验设计系统**：同步、异步、跨延迟档位、跨任务horizon、跨架构、消融等多个维度齐备。
- **真实世界验证完整**：不仅有仿真，还有 Franka 真实部署，并覆盖不同horizon 任务。
- **长horizon 增益机制清晰**：通过因果 mask 提供"块级记忆"，对长horizon 任务产生结构性优势。

## 八、不足与局限

- **冷启动开销**：每个 episode 需 N-1 次 warm-up 推理，在极短任务上代价相对明显。
- **依赖预训练权重**：多缓冲区联合微调继承预训练模型的独立 chunk 训练目标，从零开始预训练可能带来进一步增益（但本文未验证）。
- **真实世界评估规模有限**：仅在单一 Franka 平台 + 单 RTX A4000 上、3 个任务（每任务 15 次 trial）评估，多样性不足。
- **跨平台鲁棒性未验证**：未在 A100、其他 GPU 或嵌入式平台验证；不同硬件的延迟数字可能差异显著。
- **泛化风险**：方法在概念上仅适用于 flow-matching 类 VLA 头部，对基于自回归 token 或扩散的 VLA 头部适配性未充分讨论。
- **评估偏差**：真实世界仅与 π0.5 三种配置对比，未与 VLASH、StreamingVLA 等异步基线在真实平台上直接比较。
- **buffer 跨度需手工调优**：经验性发现"总 buffer 跨度 ≈ 预训练 native chunk 长度"为最佳，缺乏理论指导。
- **噪声调度形式**：使用 Beta 分布（1.5, 1.0）+ 线性插值，该选择是否最优缺乏与其它调度（如 cosine、quadratic）的比较。
