## 摘要
视觉-语言-动作（VLA）模型通过整合视觉感知、语言理解和连续动作控制，为通用机器人操作提供了一条可扩展的路径。然而，我们揭示了 VLA 架构的一个关键局限性：动作专家对 VLM 特征中可用的 3D 几何信息和 2D 语义信息的访问有限。这种可访问性差距削弱了感知基础，并限制了细粒度机器人操作任务的性能。为解决此问题，我们提出了 V-Link，在视觉-语言（VL）到动作（A）的特征传递过程中显式恢复视觉表征。具体而言，V-Link 在 VLM 中学习互补的空间和语义查询表征，并通过非对称路径将其注入到 Action DiT 中。语义查询补充了原始的 VLM 图像标记，而空间查询则为空间基础的动作生成提供了专门的几何条件。在 LIBERO、LIBERO-Plus 和 RoboTwin 2.0 上，我们的 V-Link 在基础模型 GR00T N1.6 之上分别将平均成功率提升了 +1.9%、+31.2% 和 +18.8%。在 AGIBOT A3 Ultra 上，V-Link 在两项真实世界人形机器人任务上进一步取得了 +20% 和 +24% 的增益。

## Abstract
Vision-language-action (VLA) models provide a scalable path toward generalist robotic manipulation by integrating visual perception, language understanding, and continuous action control. However, we reveal a critical limitation of VLA architectures: the action expert has limited access to the 3D geometric and 2D semantic information available in VLM features. This accessibility gap weakens perceptual grounding and limits performance on fine-grained robotic manipulation. To address this issue, we propose V-Link, which explicitly recovers visual representations during the vision-language (VL) to action (A) feature transfer. Specifically, V-Link learns complementary Spatial and Semantic Query representations within the VLM and injects them into Action DiT through asymmetric pathways. Semantic Queries complement the original VLM image tokens, whereas Spatial Queries provide dedicated geometric conditioning for spatially grounded action generation. Across LIBERO, LIBERO-Plus, and RoboTwin 2.0, our V-Link improves the average success rate over base model GR00T N1.6 by +1.9%, +31.2%, and +18.8%, respectively. On the AGIBOT A3 Ultra, V-Link further achieves gains of +20% and +24% on two real-world humanoid tasks.

# V-Link 论文总结

## 一、核心问题与研究动机

- **研究背景**：视觉-语言-动作（VLA）模型被视为通用机器人操控的可扩展路径，其中"双系统架构"将视觉-语言模型（VLM）与独立的动作专家（Action DiT）相结合，是 GR00T N1.6 等代表性模型的主流设计。
- **关键问题**：现有方法通常仅将 VLM 最后一层特征迁移给动作专家，但作者揭示了一个被忽视的"视觉表征可访问性瓶颈"——动作专家对 VLM 特征中蕴含的 **3D 几何信息** 和 **2D 语义信息** 访问严重不足。
- **诊断证据**：作者提出冻结表征 + 轻量级任务头的诊断协议，发现从 VLM 到 Action DiT，深度估计 MAE 由 0.015 急剧上升至 0.071，语义分割 mIoU 由 0.665 下降至 0.290，证实存在显著的表征退化。
- **根本原因假设**：在仅以动作损失监督的情况下，Action DiT 倾向于利用"语义捷径"快速拟合动作，而忽略了结构性关键的 3D 空间线索，导致陷入缺少空间锚定的局部最优。
- **研究意义**：先前工作（如 Spatial Forcing、EVO-0、VLA-Adapter）主要改进 VLM 内部表征或 VLM-Action 的连接效率，但鲜有研究显式解决迁移后 Action DiT 内的视觉表征可访问性问题。本文正是填补这一空白。

## 二、方法论：核心思想与关键设计

### 1. 整体思路
- 在 VLM 内引入两组**可学习的查询标记**——Spatial Query 与 Semantic Query，通过专门设计的**因果注意力掩码**从 VLM 多层特征中独立提取几何与语义表征，并通过**非对称通路**注入 Action DiT，使两类感知信息在动作生成过程中均可被显式访问。

### 2. VLM 表征解耦
- 输入序列扩展为 $E = [E_t; E_o; E_d; E_s]$，其中 $E_d$、$E_s$ 分别为 Spatial Query 与 Semantic Query。
- 自定义因果掩码 $M_q$ 使两类 Query 只能关注图像与文本 token，避免相互干扰及破坏原生多模态计算流。
- 经过 $N$ 个 Transformer 块后，输出 $[E'_t, E'_o, E'_d, E'_s]$，并经 Qwen 最终 RMSNorm 层归一化。

### 3. 训练专用监督头（仅训练时使用，推理时移除）
- **深度头 $\Phi_{Depth}$**：~2.3M 参数，由 LN → Linear(2048→256) → GELU → Dropout、每视角 2 层 Transformer Encoder、卷积解码器组成。
  - 损失：$\mathcal{L}_{depth} = \mathcal{L}_{sm} + \lambda_1^d \mathcal{L}_{rel} + \lambda_2^d \mathcal{L}_{patch}$，结合 smooth-L1、相对误差与 top-k 困难 patch 损失。
  - 激活函数使用 softplus 保证正深度值。
- **语义头 $\Phi_{Seg}$**：结构与深度头一致，输出经 Softmax。
  - 损失：$\mathcal{L}_{seg} = \mathcal{L}_{CE} + \lambda_s \mathcal{L}_{Dice}$，结合交叉熵与 Dice 损失缓解类别不平衡。
- **训练策略**：先 warm-up（VLM LoRA、Query 集、监督头），再联合优化。

### 4. Action DiT 中的非对称注入
- 在 GR00T N1.6 的 32 层 AlternateVLDiT 中，仅在满足 $\ell = 4k+2$（即图像交叉注意力层）注入查询表征，保持原 4 层循环的交替注意力节奏。
- **语义通路**：状态 + 噪声动作 token $H_\ell$ 作为 query，分别与 VLM 图像 token $E'_o$ 和 Semantic Query $E'_s$ 进行**并行交叉注意力**，通过 Fuse 投影与可学习门控 $g_\ell$ 融合后以残差方式加入：
  $$Z_\ell = H_\ell + \text{Fuse}(N_\ell, g_\ell S_\ell)$$
- **空间通路**：融合后的 $Z_\ell$ 再与 Spatial Query $E'_d$ 进行交叉注意力，提供专用几何条件：
  $$H'_\ell = Z_\ell + \text{CA}_{Spatial}(Z_\ell, E'_d)$$
  $$H_{\ell+1} = H'_\ell + \text{FFN}(H'_\ell)$$
- **整体目标**：$\mathcal{L} = \mathcal{L}_{act} + \lambda_1^a \mathcal{L}_{depth} + \lambda_2^a \mathcal{L}_{seg}$，其中 $\lambda_1^a=0.1$，$\lambda_2^a=0.002$。

### 5. 关键设计理念
- 训练时显式监督让 Query 学习到 3D 几何与 2D 语义表征；
- 推理时仅使用 VLM 和 Action DiT，不需要深度/分割标注或额外头；
- 强制空间通路在融合后必经，避免 Action DiT 再次走语义捷径。

## 六、主要结论与发现

- **性能提升**（相对基座 GR00T N1.6）：
  - **LIBERO**：平均成功率 +1.9%（97.4% → 99.3%），其中 LIBERO-Long +5.1%，达到 SOTA；
  - **LIBERO-Plus**：+31.2%（43.8% → 75.0%），特别在噪声（+60.4%）、语言（+47.3%）、光照（+30.6%）偏移下提升显著；
  - **RoboTwin 2.0**：+18.8%（38.0% → 56.8%），6 任务均提升；
  - **真实人形任务**：Power-On 98%（+20%）、Power-Off 94%（+24%）。
- **关键发现**：
  - 诊断显示 Action DiT 存在严重的视觉表征可访问性瓶颈；
  - Spatial 与 Semantic Query 在 t-SNE 中呈分离分布，证明学到不同表征；
  - 任务监督与查询注入缺一不可（Table V/VI：仅去除任一项性能提升均受限）；
  - 推理开销极小（仅 +1.58 ms），具备部署实用性。
- **总体结论**：在 VL-to-A 接口进行显式视觉表征恢复是提升细粒度机器人操控性能的有效且高效途径。

## 七、优点与亮点

- **诊断视角新颖**：首次系统揭示"VL→A 迁移后视觉表征可访问性退化"问题，并提出冻结表征 + 轻量级头诊断协议加以度量，方法论具有可推广性。
- **非对称注入设计精妙**：Semantic Query 通过并行交叉注意力补充图像语义；Spatial Query 通过强制必经的几何条件化通路防止语义捷径，体现"对症下药"的工程哲学。
- **零推理开销**：辅助监督头仅训练时使用，推理完全无需深度/分割标注，工程友好。
- **实验体系完整**：覆盖仿真 + 真实、对比 + 消融、定量 + 定性 + 诊断 + 可视化，结果说服力强。
- **跨模态解耦显式化**：通过因果掩码与专门监督头实现几何/语义表征解耦，相比隐式对齐（如 Spatial Forcing）更可控、可解释。
