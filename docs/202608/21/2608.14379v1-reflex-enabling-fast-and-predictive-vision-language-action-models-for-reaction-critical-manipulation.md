## 摘要
视觉-语言-动作（VLA）模型近期在机器人操作任务中取得了令人瞩目的性能。然而，现有基准测试主要评估模型在静态操作任务上的泛化能力，在很大程度上忽视了动态交互场景。为弥补这一不足，我们提出了ReflexBench，一个面向反应关键型操作任务的基准测试。ReflexBench包含六个动态任务，并引入了一种将仿真器步进与机器人控制解耦的评估框架，同时支持在同步和异步推理下配置延迟。基于ReflexBench，我们提出了ReflexVLA，一种专为反应关键型操作任务设计的高效VLA模型，无需大规模机器人数据预训练。ReflexVLA通过潜在未来预测以及视觉骨干网络内的多帧时间融合来增强时间推理能力，同时通过批量视觉编码与CUDA Graph重放来降低部署延迟。实验表明，ReflexVLA在持续提升动态操作性能的同时，在标准静态操作基准测试上仍保持了具有竞争力的精度，实际机器人实验进一步验证了其在实际部署条件下的有效性。项目主页：https://reflexvla.github.io

## Abstract
Vision-Language-Action (VLA) models have recently achieved promising performance in robotic manipulation. However, existing benchmarks mainly evaluate generalization on static manipulation tasks and largely overlook dynamic interaction scenarios. To address this gap, we present ReflexBench, a benchmark for reaction-critical manipulation. ReflexBench contains six dynamic tasks and introduces an evaluation framework that decouples simulator stepping from robot control while supporting configurable latency under synchronous and asynchronous inference. Building upon ReflexBench, we propose ReflexVLA, an efficient VLA model designed for reaction-critical manipulation without large-scale robot-data pretraining. ReflexVLA enhances temporal reasoning through latent future prediction and multi-frame temporal fusion within the vision backbone, while reducing deployment latency through batched visual encoding and CUDA Graph replay. Experiments show that ReflexVLA consistently improves dynamic manipulation performance while maintaining competitive accuracy on standard static manipulation benchmarks, and real-world experiments further demonstrate its effectiveness under practical deployment conditions. Project website: https://reflexvla.github.io

## 1. 核心问题与研究动机

- **研究背景**：视觉-语言-动作（VLA）模型在机器人操作中取得显著进展，但现有基准测试主要评估**静态操作任务**的泛化能力，**忽略了动态交互场景**。
- **关键挑战**：
  - 当前 VLA 模型主要基于**当前观测**进行条件化动作生成，存在**推理延迟**问题。
  - 在动态环境中（移动物体、目标拦截、轨迹依赖任务），感知与执行之间的延迟会导致任务失败。
- **现有研究的不足**：
  - 动态操作基准通常仅作为评估平台，缺乏统一的"**预测能力 + 效率**"研究框架。
  - 增强预测推理的方法往往引入额外计算开销。
  - 关注推理加速的方法通常只关注效率，未明确解决**未来感知**决策需求。
- **核心目标**：同时实现**强预测能力**和**低推理延迟**，填补当前 VLA 研究的空白。

## 2. 方法论

论文提出两个核心组件：**ReflexBench**（基准测试）和 **ReflexVLA**（模型）。

### 2.1 ReflexBench（基准测试）

- **任务列表**（6个动态任务）：
  - Conveyor Belt Pick-and-Place（传送带分拣）
  - Ball Catching（接球）
  - Whack-a-Mole（打地鼠）
  - Rolling Ball Interception（滚动球拦截）
  - Ball Throwing（投球入箱）
  - Rotating Peg Insertion（旋转插孔）
- **数据采集**：采用基于规划的数据收集流水线，将任务分解为顺序子目标；处理动态物体时预测未来轨迹；复杂交互场景使用任务特定的强化学习策略生成演示轨迹。
- **延迟感知评估框架**：
  - **解耦仿真器步进与机器人控制**：环境动力学独立演化，更真实地模拟部署条件。
  - **同步推理**：仿真器暂停以收集当前观测并查询策略，执行期间机器人保持空闲。
  - **异步推理**：策略推理与动作执行重叠，提高响应性但动作略显陈旧。
  - **延迟阻塞机制**：可手动指定延迟值，通过实时因子（RTF）转换真实推理延迟到仿真延迟：
    
    $$RTF = \frac{t_{sim}}{t_{wall}}$$

### 2.2 ReflexVLA（模型）

基于 VLA-Adapter 架构，包含三个关键设计：

- **(A) 潜在未来预测**：
  - 在冻结的 DINOv3 语义潜空间中进行未来预测，而非直接预测未来图像：
    
    $$y_{t+i} = \phi_{DINOv3}(o_{t+i}), \quad y_{t+i} \in \mathbb{R}^{1024}$$
  - 附加 H 个可学习的未来 token，每个对应一个未来控制步，与动作预测的时间结构对齐。
  - 投影未来 token 隐藏表示到 DINOv3 特征空间：
    
    $$\hat{y}_{t+i} = f_{pred}\left(h_{t+i}^{future}\right)$$
  - 使用**掩码余弦相似度损失**：
    
    $$L_{future} = \frac{\sum_{i=1}^{H} m_i [1 - \cos(\hat{y}_{t+i}, y_{t+i})]}{\sum_{i=1}^{H} m_i}$$
  - 总损失：$L = L_{act} + \lambda_{future} L_{future}$，其中 $\lambda_{future} = 0.05$。

- **(B) 多帧时序融合**：
  - 在视觉骨干网络**中间层特征**上进行时序融合（保留更丰富的局部外观与运动线索）。
  - 对每个相机视角 v 和补丁位置 p，将 T 帧历史特征形成时序轨迹，先归一化、降维、添加时序位置编码。
  - 应用**因果时序注意力层**（防止未来信息泄露）：
    
    $$\Delta x_{v,p,t} = \text{Up}\left(\text{MHA}_{causal}(z_{v,p,1:T})\right)$$
  - 将时序表示集成到当前帧特征：
    
    $$\tilde{x}_{v,p,t} = x_{v,p,t}^{final} + \Delta x_{v,p,t}$$
  - **关键优势**：语言模型消费的视觉 token 数量与单帧设置相同，避免语言模型端的多帧开销。

- **(C) 推理延迟优化**：
  - **批处理视觉编码**：将所有视角-帧图像批量为单次视觉编码器前向传播，避免 V×T 次独立前向传播。
  - **CUDA Graph 重放**：捕获完整推理流水线为 CUDA 图，新观测拷贝到预分配缓冲区后直接重放：
    
    $$\hat{a}_{t:t+H-1} = G(x_{text}, x_{vision}, x_{state})$$
  - 这些优化**不修改策略架构或学习目标**，仅降低部署开销。

## 6. 主要结论与发现

- **关于推理范式（Q1）**：
  - 高频异步推理优于同步推理；较大块大小配合较短动作时域效果更佳。
- **关于 ReflexBench 性能（Q2）**：
  - ReflexVLA 平均成功率 50.4%，**优于所有现有基线**。
  - 相比基线 VLA-Adapter（30.3%），提升约 20 个百分点。
  - 以 1B 参数超越 OpenVLA-OFT（7B，36.0%）和 π0.5（4B，36.9%），性能与 PUMA（4B，50.2%）相当但仅需其 1/4 参数量。
- **关于静态任务性能（Q3）**：
  - LIBERO 上平均成功率 97.2%，与最佳 VLA 相当，证明动态优化未损害静态泛化能力。
- **关于消融研究（Q4）**：
  - 冻结 DINOv3 预测目标远优于可训练目标（62.8% vs. 4.9%）。
  - 中间层特征融合优于最终层（71.7% vs. 68.2%）。
  - 延迟优化使成功率从 71.7% 提升到 73.8%，同时**延迟从 125.1 ms 降至 65.0 ms**（近 50% 降幅）。
- **关于真实世界实验（Q5）**：
  - 在所有三个真实世界任务上均优于 SmolVLA。
  - 模型规模仅为 PUMA 的 1/4，但性能相当。

## 7. 优点与亮点

- **方法层面**：
  - **统一框架**：将预测推理与推理加速在单一模型中联合优化，填补了研究空白。
  - **潜在未来预测的创新性**：在语义潜空间而非像素空间预测，避免低层次外观细节的干扰。
  - **未来 token 与动作块对齐**：预测时间结构与控制时间结构精确对应。
  - **中间层特征融合**：发现中间层特征保留更丰富的运动线索，是细致且有价值的观察。
  - **轻量化设计**：1B 参数即可达到与大规模模型相当甚至更优的性能。
  - **系统级优化**：CUDA Graph 重放 + 批处理视觉编码实现近 50% 延迟降低。
- **实验层面**：
  - **延迟感知评估协议**：解耦仿真步进与机器人控制，提供更真实的延迟模拟。
  - **RTF 转换机制**：可基于真实推理延迟在仿真中复现，连接仿真与现实。
  - **双重验证**：同时在 ReflexBench 动态基准与 LIBERO 静态基准上验证，证明了方法的有效性与通用性。
  - **真实世界部署**：在真实机械臂上验证，证明方法的实用性。

## 8. 不足与局限

- **方法层面**：
  - 未来预测和时序融合组件仅在**微调阶段引入**，未经过大规模预训练，可能限制其潜力。
  - 推理范式仅考虑了**朴素同步/异步推理**，未探索更先进的 RTC（Real-Time Chunking）等机制。
  - 仅使用了 2 帧时序观测作为输入，时序上下文窗口相对较短。
- **实验层面**：
  - 真实世界实验任务数较少（仅 3 个），每个任务仅 20 次评估，**统计可靠性有限**。
  - 数据采集规模较小（每任务仅 200 个片段），可能影响模型泛化能力。
  - 训练时长、显存占用等算力细节未充分披露。
  - 6 个 ReflexBench 任务中部分任务（如 Ball Catching）所有方法成功率均很低（< 10%），表明这些任务本身仍具挑战性，方法提升空间有限。
- **应用层面**：
  - 主要针对桌面级操作任务，对更复杂的动态场景（如多智能体交互、人机协作等）未涉及。
  - 中间层特征融合的具体层数选择及其对不同任务的影响未深入分析。
  - 对光照变化、遮挡等真实世界干扰因素的鲁棒性未充分测试。
- **偏差风险**：
  - 数据采集部分依赖 RL 策略生成演示，可能引入**策略偏差**。
  - 与 PUMA 等方法相比，真实世界实验中任务设置可能不完全一致，存在公平性争议。
