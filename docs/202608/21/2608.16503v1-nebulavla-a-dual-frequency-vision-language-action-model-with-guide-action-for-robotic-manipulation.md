## 摘要
视觉-语言-动作（VLA）模型在现实世界中的部署常常受到效率与性能权衡、跨具身泛化以及执行平滑性的制约。本文提出 NebulaVLA，一种异步双频率架构，将高层语义推理与底层动作控制解耦，从而优化计算资源并提升模块化程度。为了弥合异构机器人之间的语义鸿沟，我们引入了 GESTURE-7，一种统一的语言对齐动作表征。此外，我们提出的引导动作算法通过基于掩码的平滑性约束来保证运动学连续性。全面的评估表明，NebulaVLA 显著优于同步基线方法，在 LIBERO-Plus 上取得了 85.5% 的平均成功率，并将动作生成速度提升了约 2.7 倍。这种异步设计为实际机器人应用提供了高效且响应迅速的控制能力。

## Abstract
Real-world deployment of Vision-Language-Action (VLA) models is often bottlenecked by efficiency-performance trade-offs, cross-embodiment generalization, and execution smoothness. We present NebulaVLA, an asynchronous dual-frequency architecture that decouples high-level semantic reasoning from low-level action control, optimizing computational resources and modularity. To bridge semantic gaps across heterogeneous robots, we introduce GESTURE-7, a unified language-grounded action representation. Furthermore, our Guide Action algorithm enforces kinematic continuity via mask-based smoothness constraints. Comprehensive evaluations demonstrate that NebulaVLA significantly outperforms synchronous baselines, achieving an 85.5\% average success rate on LIBERO-Plus and accelerating action generation by \textasciitilde 2.7$\times$. This asynchronous design enables highly efficient and responsive control for practical robotics.

# NebulaVLA 论文总结

## 一、核心问题与研究动机

视觉-语言-动作（VLA）模型虽然在机器人操作领域取得了显著进展，但在实际部署中仍面临三大瓶颈：

- **效率-性能权衡**：现有的同步单体架构采用统一的时间分辨率，无法同时支撑低频语义理解与高频运动控制，导致计算开销与实时性需求难以兼顾。
- **跨本体泛化不足**：将连续运动学映射到离散 token 需要庞大的词表和大量演示数据，难以在不同形态的机器人平台间建立统一的动作语义。
- **执行平滑性差**：异步实时推理与动作块（chunk）生成之间存在时间失配，导致明显的抖动和执行不连续问题。

本文提出 NebulaVLA，借鉴 Kahneman 的"快-慢系统"认知范式，系统性地解决上述问题。

## 二、方法论

### 2.1 整体架构：异构双频率设计

NebulaVLA 采用分层快-慢架构，将语义推理与动作控制解耦：

- **System 2（S2，慢系统）**：以 Qwen3-VL 为视觉-语言骨干网络，运行频率约 **10 Hz**，处理自然语言指令与稀疏视觉输入，输出抽象动作指导。
- **System 1（S1，快系统）**：采用 Diffusion Transformer（DiT），运行频率约 **20 Hz**，基于 S2 的指导、高频视觉输入和动作历史输出执行动作。
- **高频视觉编码器**：S1 使用经过对比微调的 DINOv2 编码器，与末端执行器状态进行视觉-本体感知对齐。
- **Q-Former**：压缩 S2 的指导特征，作为 S1 的条件输入。

该架构原生支持分布式部署，可将 S1 与 S2 部署在不同计算设备上。

### 2.2 GESTURE-7 统一动作表征

GESTURE-7（Gesture Enumerated State Token for Unified Robot End-effector-7D）是一个 7 维连续向量：

$$s = [x, y, z, r, p, w, g]$$

- **位置** $(x, y, z)$：末端执行器的笛卡尔位置（量化到整数厘米）；
- **姿态** $(r, p, w)$：翻滚角、俯仰角、偏航角（量化到整数度）；
- **手势** $g$：离散的自然语言关键词（如 grasp、push、pinch 等）。

核心创新：异构机器人（灵巧手、平行夹爪、机械臂）执行相同动作时共享同一关键词，实现跨本体的语义统一，便于与语言条件 RL 集成。

### 2.3 Guide Action 引导动作机制

受图像外绘（Image Outpainting）启发，将块拼接直接嵌入生成过程，避免事后平滑：

- **原理**：下一个动作块的生成条件依赖于前一个块中未执行的动作（即"引导点"，如 $a_4$-$a_7$）；
- **训练时**：引导点数量随机采样自 $\{0, 1, 2, 3\}$，以适应推理延迟；
- **条件概率模型**：

$$p_\theta(A_{t-1}^{full} \mid A_t^{full}, A^{prior}, \tau)$$

- **去噪过程中的硬约束**：在每一步去噪后，使用二值掩码强制保留已知动作：

$$A_{t-1}^{full} = M \odot A_{t-1}^{prior} + (1 - M) \odot A_{t-1}^{noisy}$$

其中 $M[1..k] = 1$（锚定区域，严格保留），$M[k+1..T] = 0$（生成区域，由模型预测）。

### 2.4 三阶段训练流程

- **Stage 1（S2 监督微调）**：基于 Qwen3-VL 进行 SFT，包含五类任务——位姿回归、关键点回归、2D 路径点预测、3D 轨迹预测、思维链（CoT）生成。
- **Stage 2（S2 强化学习）**：采用 GRPO 算法优化轨迹规划能力，使用 GESTURE-7 距离、关键点定位奖励、路径点奖励、轨迹奖励和格式奖励（权重 0.5）。
- **Stage 3（S1 监督微调）**：联合优化 S1 与 S2，使用带掩码的加权流匹配损失（仅在生成区域计算 L2 损失）：

$$\mathcal{L}(\theta) = \mathbb{E}_{\epsilon, t} \left[ (1 - M) \odot (\epsilon - \epsilon_\theta(x_t, t))^2 \right]$$

训练过程中保持两系统的视觉编码器冻结。

## 六、主要结论与发现

- **性能领先**：NebulaVLA 在 LIBERO-Plus 上达到 **85.5%** 平均成功率，比 InternVLA-M1（81.3%）高 4.2%，显著超越 OpenVLA-OFT+（79.6%）、GR00T N1.5（59.0%）和 π0.5（58.0%）。
- **效率提升**：动作生成速度提升约 **2.7 倍**，异构版本延迟从 115 ms 降至 42 ms。
- **真实性能**：Task 1 成功率 92.08%，Task 2 成功率 92.5%，均优于 InternVLA-M1。
- **轨迹平滑性**：Guide Action 在所有 7 个关节上降低急动度，平均减少 **25.6%**，关节 12 与 13 分别降低 41.2% 和 45.1%。
- **训练有效性**：三阶段训练整体提升 1.7%–2.5%，S2 SFT 显著改善 Layout 维度（+6.2%），S2 RL 进一步提升 Language 与 Layout。
- **跨本体潜力**：GESTURE-7 通过语言关键词统一异构机器人动作语义，原生支持语言条件 RL。

## 七、优点与亮点

- **架构创新**：提出显式数据流解耦的双频率架构，原生支持分布式部署，为实际机器人提供了工程友好的模块化方案。
- **统一表征**：GESTURE-7 通过自然语言关键词桥接异构机器人，兼具连续运动精度与离散语义抽象。
- **生成式平滑**：Guide Action 将平滑约束内化于扩散去噪过程，无需事后平滑处理，保证语义一致性。
- **完整训练流程**：SFT + GRPO RL + 流匹配 SFT 的三阶段设计兼顾语义规划与动作控制。
- **工程实用性**：异构架构在边缘设备上灵活部署，平衡计算资源与控制响应性。

## 八、不足与局限

- **Camera 维度退化**：GESTURE-7 训练隐式建立了固定视觉-空间映射，相机姿态扰动下性能下降（91.0 vs 93.5）。
- **频率配置静态**：当前的 10 Hz/20 Hz 频率分配是经验性设定，缺乏任务自适应的动态调度机制。
- **引导锚点局限**：固定长度的引导点在快速变化环境中可能引入响应延迟。
- **工程挑战**：异构硬件同步、多传感器时间戳对齐、分布式时钟一致性等部署问题尚未充分解决。
- **真实实验规模有限**：仅 2 个任务、单一平台、每项 10 次试验，统计显著性论证不足；跨本体（如从 AgiBot 到其他机器人）的实际迁移未经验证。
- **消融深度不足**：Guide Action 的引导点数对性能的影响、GRPO 奖励权重的敏感性分析等未充分展开。
- **基线复现细节**：部分基线（如 N1.5、π0.5）通过 LeRobot 库复现，与官方实现可能存在差异，影响公平性。
- **未来方向**：作者提出需在 GESTURE-7 框架中引入观察视角条件建模，以改善相机扰动下的鲁棒性。
