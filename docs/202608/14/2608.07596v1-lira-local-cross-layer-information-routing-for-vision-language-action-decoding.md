## 摘要
视觉-语言-动作（VLA）模型将预训练视觉-语言模型（VLM）的表征转化为机器人动作，然而如何将 VLM 的中间特征路由至动作解码器这一接口问题尚未得到充分探索。现有设计要么仅暴露表征层级中较窄的一部分，要么将每个解码器块机械地对应到单一 VLM 层，从而限制了跨深度获取互补任务线索的能力。本文提出 LIRA，一种局部跨层动作条件机制，将 VLM 到动作的条件建模构建为深度感知的信息路由。LIRA 以任务标记特征以及由 VLM 中间状态导出的 LIRA 查询特征为操作对象，并为每个并行融合块分配以对应 VLM 层为中心、深度对齐的局部窗口。并行融合块先聚合相邻的 LIRA 查询特征，再将其与任务标记特征及本体感知输入相整合，进而完成动作预测。该路由接口保持骨干网络架构、动作解码器及有监督训练方案均不改变。在 LIBERO、LIBERO-Plus、CALVIN ABC→D 以及真实世界操作任务上，在相同的 0.5B 参数配置下，LIRA 在主要综合指标上优于 VLA-Adapter 基线。在面向 LIBERO-Plus 的零样本迁移中，LIRA 将平均成功率从 59.1% 提升至 78.0%，带来 18.9 个百分点的提升，表明在受控分布偏移下模型的鲁棒性得到显著增强。

## Abstract
Vision-Language-Action (VLA) models transform representations from pretrained vision-language models (VLMs) into robot actions, yet the interface that routes intermediate VLM features into action decoders remains underexplored. Existing designs either expose only a narrow part of the representation hierarchy or rigidly match each decoder block to one VLM layer, restricting access to complementary task evidence across depths. We introduce LIRA, a local cross-layer action-conditioning mechanism that formulates VLM-to-action conditioning as depth-aware information routing. LIRA operates on task-token features and LIRA Query features derived from intermediate VLM states, then assigns each Parallel Fusion Block a depth-aligned local window centered on its corresponding VLM layer. Parallel Fusion Blocks aggregate neighboring LIRA Query features and integrate them with task-token features and proprioceptive inputs before action prediction. This routing interface leaves the backbone architecture, action decoder, and supervised training recipe unchanged. Across LIBERO, LIBERO-Plus, CALVIN ABC$\rightarrow$D, and real-world manipulation, LIRA improves the principal aggregate metrics over the VLA-Adapter baseline under the same 0.5B-parameter configuration. In zero-shot transfer to LIBERO-Plus, LIRA increases average success from 59.1% to 78.0%, an 18.9-point gain indicating improved robustness under controlled distribution shifts.

# LIRA 论文总结

## 一、核心问题与研究动机

- **整体背景**：视觉-语言-动作（VLA）模型通过复用预训练视觉-语言模型（VLM）的表征来生成机器人动作，但 VLM 到动作解码器之间的"中间表征路由接口"研究尚不充分。
- **现有接口的局限**：
  - **仅末层条件化**（如 OpenVLA-OFT）：仅暴露 VLM 末端表征，丢失中间层丰富信息。
  - **严格的层对齐条件化**（如 VLA-Adapter）：将每个解码器块与单一 VLM 层一一对应，相邻层互补信息难以被同一解码块访问。
  - **全局聚合**（如 π0.5）：跨深度混合表征，模糊了局部层级结构。
- **核心问题**：如何将 VLM 中间表征以更合理的方式路由到动作解码器，使每个解码块既能保留深度对齐的语义锚点，又能获取邻近层的互补任务线索？
- **关键假设**：相邻 VLM 层为同深度动作预测提供互补证据，因此应将"局部跨层路由"作为归纳偏置。

## 二、方法论：LIRA 核心思想与关键技术

### 2.1 总体架构
- 基于 VLA-Adapter 框架，引入**可学习的 LIRA Query 标记**（默认 M=64）追加到 VLM 输入序列中。
- VLM 共 L 层 Transformer，每层提取两类特征：
  - **任务标记特征** $T_t^{(i)}$：包含视觉-语言表征。
  - **LIRA Query 特征** $R_t^{(i)} \in \mathbb{R}^{M \times d_v}$：作为 VLM 到动作解码器的条件接口。
- 动作解码器由 L 个并行融合块（PFB）组成，由 Action Query 标记初始化。
- **本体感知状态** $P_t$ 通过可学习投影 $\phi_p$ 编码为 $E_t^p$。

### 2.2 局部跨层路由（核心创新）
- **窗口定义**：为第 $i$ 个 PFB，以其对应 VLM 层 $i$ 为中心，选取半径 $r$ 的局部邻域：
  $$W_r^{(i)} = \{\ell \in \{1,\ldots,L\} \,|\, |\ell - i| \leq r\}$$
- **特征聚合**：将窗口内各层的 LIRA Query 特征沿 token 维度拼接：
  $$\tilde{R}_t^{(i)} = \text{Concat}_{\text{tok}}\left(\left\{R_t^{(\ell)}\right\}_{\ell \in W_r^{(i)}}\right)$$
- **默认窗口**：$r=1$，即内部 PFB 接收 3 层（$3M$ 特征），边界 PFB 接收 2 层（$2M$ 特征）。
- **PFB 更新**：任务标记特征保持与对应 VLM 层对齐，提供深度语义锚点；LIRA Query 特征提供局部邻域互补信息：
  $$X_t^{(i)} = \text{PFB}_i\left(X_t^{(i-1)};\, T_t^{(i)},\, \tilde{R}_t^{(i)},\, E_t^p\right)$$

### 2.3 关键设计优势
- **零额外参数**：通过 token 维度拼接直接接入现有 cross-attention，无需新增投影层。
- **窗口宽度可调**：$r=0$ 退化为单层条件化；增大窗口逐步接近全局聚合；默认三层窗口在两者间取得最佳平衡。
- **训练目标不变**：采用 L1 连续动作回归损失，监督训练流程完全保留。

## 七、优点

- **最小化架构侵入**：保持骨干、解码器、训练流程完全不变，仅修改路由接口，零额外参数。
- **归纳偏置清晰**：明确提出"深度局部性"先验，并通过窗口宽度、拓扑、查询预算消融提供充分证据。
- **受控对比严谨**：与 VLA-Adapter 架构仅在路由机制上形成差异，实验隔离了路由设计的影响。
- **效率优势显著**：0.5B 参数下同时实现高吞吐（186.3 Hz）和低内存（12.8 GB），便于实际部署。
- **鲁棒性提升突出**：在 LIBERO-Plus 零样本迁移上取得 18.9 点大幅提升，表明局部跨层信息有助于应对受控分布偏移。
- **多维度验证**：仿真 + 真实、3 个基准 + 多种消融，覆盖全面。

## 八、不足与局限

- **骨干单一**：仅在 Qwen2.5-0.5B + Prismatic 风格 VLM 上验证，结论对其他 VLM 骨干（如 LLaMA、InternVL）的迁移性未知。
- **动作解码器单一**：仅验证 PFB-based 架构，是否适配其他动作解码器（如 diffusion、flow-matching）尚不明确。
- **真实实验样本量小**：每任务仅 10 次试验，统计可信度有限，作者亦明确标注为"preliminary"。
- **无跨本体验证**：仅在 Franka Research 3 上测试，且无接触丰富 / 力敏感任务评估。
- **未充分验证分布外泛化**：LIBERO-Plus 为受控扰动，结果不意味着开放环境下的通用 OOD 泛化能力。
- **窗口宽度选择依赖消融**：最佳窗口大小（3 层）需通过实验确定，缺乏理论指导。
- **训练时长未公开**：论文未给出具体 epoch 数与总训练时间，算力使用透明度不足。
