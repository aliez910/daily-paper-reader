## Abstract
Robust robot control benefits from explicitly modeling state transitions, but video-generation world action models (WAMs) introduce substantial deployment cost. Existing latent WAMs avoid explicit future generation, but often compress predictive representations or separate predictive modeling from the representations used for action generation. We introduce JEPA-WAM, a latent WAM built in a pretrained V-JEPA space, which couples latent transition prediction with continuous action generation through a shared predictor. JEPA-WAM predicts a spatially structured joint current-future target that captures task-shared visual temporal structure between current and future observations, while preserving dense patch-level correspondence. Through the shared predictor, transition supervision directly shapes the backbone, from which dedicated representations are extracted for action prediction. The same design can also be instantiated in pretrained VLA policies while preserving their original perception and action pathways. On LIBERO-Plus, JEPA-WAM achieves 79.2%, the best result without large-scale robot-policy pretraining, while its pretrained $π_{0.5}$ instantiation reaches 86.3%, achieving the best overall performance. Experiments on RoboTwin 2.0 and real-world bimanual manipulation further demonstrate strong generalization under visual and spatial shifts.

# JEPA-WAM 论文总结

## 1. 核心问题与研究背景

**研究动机**：机器人控制中的鲁棒性常受益于显式建模状态转移，但当前主流的两类世界动作模型（World Action Models, WAMs）均存在显著缺陷：

- **视频生成式 WAMs**（如 WorldVLA、Causal World Modeling）：通过迭代生成未来帧显式建模状态转移，但部署时推理成本极高，且生成帧对动作生成而言存在大量冗余信息。
- **现有潜在 WAMs**（如 VLA-JEPA、Being-H0.7、Frappe）：在潜在空间中建模状态转移以避免显式帧生成，但存在两类普遍局限：
  - **表征压缩**：要么复用生成器中间特征（优化目标是帧生成而非状态变化），要么将未来观测压缩为少量 token 或子目标，丢失细粒度空间结构。
  - **预测与动作解耦**：要么将预测的未来表征作为附加上下文输入动作模块（引入冗余信息），要么引入独立的预测模块或潜动力学子目标（对动作生成所用表征的塑造作用弱）。

**整体目标**：构建一个潜在 WAM，既能保留转移建模对鲁棒性的益处，又能避免显式帧生成的部署成本，同时让预测监督直接作用于动作生成的骨干网络。

## 2. 方法论

### 2.1 整体架构

JEPA-WAM 是一个三组件架构：
1. **冻结的 V-JEPA 2.1 编码器** $E_J$：提供稠密 patch 级视觉表征（24×24 token grid，1024 维）。
2. **共享预测器** $F_\theta$（Qwen2.5-0.5B，hidden dim 896）：同时承担"转移预测"与"动作表征提取"两个任务。
3. **DiT 动作专家** $A_\psi$：基于条件流匹配（flow matching）的 16 层 DiT-L。

### 2.2 关键技术创新

**(1) V-JEPA 表征空间与空间结构化联合当前-未来目标**

不预测"绝对的未来表征" $E_J(O_{t+\delta})$，而是构造"当前-未来联合表征"作为预测目标。具体做法：
- 将当前帧 $O_t^v$ 与未来帧 $O_{t+\delta}^v$ 沿时间维度堆叠（`Stack_time`），形成双帧输入。
- 送入冻结的 V-JEPA 2.1 编码器（利用其 tubelet size=2 的特性），得到 $Y_{t,t+\delta}$。
- 该目标保留了与当前表征 $Z_t$ 相同的相机与 patch-token 排列顺序，保留 patch 级对应关系。
- 优势：联合编码让 V-JEPA 同时看到两端观测，使目标强调"哪些区域稳定/变化、局部物体与空间关系如何演化"，即"任务共享的视觉时间结构"，而无需重建独特的未来观测。

形式化：
$$Z_t = \text{Concat}_{v \in V} E_J(O_t^v) \in \mathbb{R}^{N_{vis} \times d_J}$$
$$Y_{t,t+\delta} = \text{Concat}_{v \in V} \text{sg}\big[E_J(\text{Stack\_time}(O_t^v, O_{t+\delta}^v))\big]$$

**(2) 共享预测器耦合转移预测与动作生成**

- 通过两层视觉 projector $P_{vis}$（1024→896→896）将 V-JEPA 特征映射到 Qwen 输入空间。
- 视觉 token、任务指令 $\ell$、**专用的动作占位符 token** $P_{act}$ 一同输入共享预测器：
$$(Q_t^{wm}, C_t) = F_\theta(P_{vis}(Z_t), \ell, P_{act})$$
- 其中 $Q_t^{wm}$（视觉 token 位置的隐藏态）用于转移预测，保留 patch 顺序；$C_t$（动作占位符的隐藏态）用于动作条件化。
- 关键设计：**动作占位符**隔离了转移预测与动作生成的梯度，避免互相干扰；同时因为二者共享同一骨干，转移监督直接塑造动作生成的表征。

**(3) 潜转移预测损失**

预测头 $G_\phi$（token-wise MLP，896→2048→1024）将 $Q_t^{wm}$ 映射回 V-JEPA 空间：
$$\hat{Y}_{t,t+\delta} = G_\phi(Q_t^{wm}) \in \mathbb{R}^{N_{vis} \times d_J}$$

损失为 patch 级平均余弦距离：
$$\mathcal{L}_{wm} = \frac{1}{B N_{vis}} \sum_{b=1}^{B} \sum_{n=1}^{N_{vis}} \Big(1 - \cos(\hat{Y}^{(b)}_{t,t+\delta,n}, Y^{(b)}_{t,t+\delta,n})\Big)$$

由于 V-JEPA 编码器和目标表征均 stop-gradient，仅 $F_\theta$ 和 $G_\phi$ 受更新。

**(4) 动作生成损失**

采用 StarVLA 的 DiT + 条件流匹配设计，动作专家额外接收本体感受状态 $s_t$ 与 32 个可学习 future token。主 LIBERO 实验使用 velocity prediction：
$$\mathcal{L}_{act} = \mathbb{E}_{\epsilon, \tau}\big[\|A_\psi(a_\tau, \tau, s_t, C_t) - (a - \epsilon)\|_2^2\big]$$
其中 $a_\tau = (1-\tau)\epsilon + \tau a$，$\tau$ 按 Beta(1.5, 1.0) 采样。RoboTwin 实验改用 x-prediction（直接预测干净动作）。

总损失：
$$\mathcal{L} = \mathcal{L}_{act} + \lambda_{wm} \mathcal{L}_{wm}, \quad \lambda_{wm} = 0.5$$

**(5) 部署策略**

部署时移除目标分支和预测头，仅保留当前帧编码、视觉 projector、共享预测器与动作专家，**无需未来观测**。使用 4 步 Euler 积分生成动作 chunk。

**(6) 向预训练 VLA 的迁移**

可将同一联合当前-未来目标应用到预训练 π0.5：
- 在 VLM 前缀追加 64 个可学习 future token（灵感来自 VaLR）。
- 将其隐藏态 reshape 为 8×8 粗粒度空间网格 → LayerNorm + MLP（2048→2048→1408） → 双线性上采样到 24×24。
- 对齐到冻结的 V-JEPA 2.1 ViT-G 联合当前-未来目标。
- 通过对齐损失塑造 π0.5 的 VLM 骨干，但**不修改原始感知与动作通路**：future token 仅自注意于原前缀，action token 被屏蔽不可见其。

## 7. 优点与贡献

### 7.1 方法论层面

1. **统一的联合当前-未来目标**：相比"仅未来表征"或"端点位移"目标，joint target 通过 V-JEPA 的 tubelet 双帧编码同时访问当前与未来观测，使目标成为"任务共享的视觉时间结构"而非"独特的未来场景重建"，这一定位独特且合理。
2. **空间结构保留**：通过避免卷积对齐（iREPA 风格）和重用 V-JEPA 的 patch-token 排列顺序，模型直接监督 patch 级时间结构，避免了空间信息损失。
3. **共享预测器的耦合设计**：单一 Qwen2.5 骨干同时服务转移预测与动作生成，使转移监督"零成本"地塑造动作表征，无需额外模块、附加上下文或独立子目标；同时通过专用动作占位符 token 隔离梯度，避免两任务互相干扰。
4. **轻量级部署**：与视频生成式 WAM 相比，未来帧从未参与推理，推理路径仅是"当前帧 → 编码 → projector → 共享预测器 → DiT 动作专家"，延迟仅 85 ms，远低于 Cosmos-Policy / ABot-M0 等。
5. **对通用潜在 WAM 框架的提炼**：论文明确总结出三条设计原则（避免压缩、避免预测/动作解耦、保留空间结构），为后续研究提供了清晰的指导。

### 7.2 实验层面

1. **跨基准的鲁棒性**：同时在 LIBERO（ID）、LIBERO-Plus（7 类 OOD）、RoboTwin 2.0（双臂 + 域随机化）、真实世界（5 任务 ID/OOD）四个层面验证，性能全面领先。
2. **可迁移性**：同一 transition 监督可直接迁移到预训练 π0.5 而不破坏原始 VLA 通路（通过专用 future token + 屏蔽 action attention），证明了世界建模机制与现有 VLA 框架的兼容性。
3. **深入的可解释性**：通过冻结表征探针（附录 C.2）系统性地证明联合目标在时间间隔编码、轨迹结构保留、空间 patch 诊断等多维度均优于端点差目标，给出了"为什么有效"的因果性证据，而非仅依赖经验结果。
4. **真实世界验证**：在 AgileX COBOT Magic 平台上验证 ID 与 OOD 设置下的实际增益，包含桌面物品操作与抽屉开合等有意义的任务。
5. **全面的消融**：6 类设计选择均给出量化结果，且每个组件都有清晰的边际贡献解释。

## 8. 不足与局限

### 8.1 方法论层面

1. **转移目标的语言条件化有限**：当前联合当前-未来目标主要受当前视觉观测驱动，对任务指令 $\ell$ 的显式融合较弱。这意味着对于"相同当前帧 + 不同指令"的情形，转移目标的判别力可能不足，模型难以将语言指令直接注入到转移预测中。
2. **二阶 / 高阶时间结构建模不足**：联合目标仍主要刻画"当前 vs 单一未来"的两点关系，对于长程、复合动作链的多步时间结构的建模能力未明确验证。
3. **时间间隔 $\delta$ 固定**：论文未明确说明训练时未来帧与当前帧的时间跨度如何选取与采样，且推理时仅用当前观测，未来"被建模的多远"由训练时决定，缺乏灵活性。
4. **对本体感受与动作历史的弱使用**：转移目标仅依赖视觉，理论上可加入 proprio 或 prior actions 作为额外条件，但当前未探索。
5. **依赖预训练 V-JEPA 编码器**：性能提升部分源于 V-JEPA 2.1 的强大表征，若 V-JEPA 不开源 / 不可用，方法的复现门槛较高。
6. **推理时仍无法利用未来信息**：虽然避免生成未来帧是设计目的，但也意味着策略不能像视频生成式 WAM 那样在测试时"想象"未来，存在功能上的固有取舍。

### 8.2 实验层面

1. **真实世界实验规模有限**：每任务 100 演示、每设置 10 rollout 属于较小规模，统计置信区间较宽；未公开跨平台、跨光照、跨物体的多场景测试。
2. **消融主要在 LIBERO-Plus 上**：每个组件在 RoboTwin 2.0、真实世界上的边际贡献未充分验证，且单一基准的消融结果可能不完全泛化。
3. **计算资源细节缺失**：GPU 型号、单卡显存、训练时长、单次实验墙钟时间均未报告；RoboTwin 2.0 与真实世界的训练配置未给出，与 LIBERO 训练之间的差异（如 batch size、步数）未对齐说明。
4. **未报告方差**：除 RoboTwin 上报告了方差外，LIBERO 与真实世界大多仅报告单点成功率，未给出多次随机种子下的标准差，难以评估统计显著性。
5. **未与最新 SOTA（如 GR-RFT、HiRT 等）对比**：截至论文知识截止，部分更新的 VLA 与 WAM 工作未被纳入对比。
6. **OOD 测试覆盖有限**：LIBERO-Plus 的扰动虽是 OOD，但仍基于相同任务语义；RoboTwin 2.0 Random 主要考察视觉域随机化，未涉及完全未见物体类别、抽象指令变化等更深度的分布外。
7. **迁移实验仅在 π0.5 上验证**：未证明该机制对 π0、Being-H0.7、Cosmos-Policy 等其他大规模预训练 VLA 的通用性。

### 8.3 潜在的研究方向

- 引入指令条件化的转移目标（如通过 cross-attention 将语言注入联合表征预测）。
- 引入多步未来预测与时间因果损失（CEILing、动态时间间隔）。
- 探索 JEPA-WAM 与视频生成式 WAM 的混合部署（如少量"想象"步骤辅助决策）。
- 在更多 VLA 骨干、更多真实平台、更多样化任务上系统验证迁移机制的可推广性。
