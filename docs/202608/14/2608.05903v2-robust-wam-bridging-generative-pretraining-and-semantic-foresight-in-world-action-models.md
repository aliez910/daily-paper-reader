## 摘要
主流的世界-动作模型（WAMs）通过将预训练的视频生成模型（VGMs）适配于机器人控制，将其学到的动力学先验迁移用于动作预测。这些 VGMs 通常在变分自编码器（VAE）潜在空间中进行训练。然而，VAE 潜在空间针对像素重建进行了优化，侧重于细粒度的外观细节，导致在视觉变化下动作预测较为脆弱。近期研究在语义潜在空间中构建 WAM，对外观变化更加鲁棒。然而，这些模型无法利用仅在 VAE 空间中存在的、大规模的 VGM 预训练。为克服这一困境，我们提出了 Robust-WAM，一种面向基于视频生成的 WAM 的通用后训练方法，在保留基于 VAE 的生成路径的同时，在动作流上引入一个轻量级的语义前瞻对齐目标。这既保留了大规 VGM 预训练的优势，又将动作建立在外观不变的动力学之上，使其在光照变化及其他视觉分布外条件下依然可靠。具体而言，我们采用可学习的查询令牌，通过将其输出的隐藏状态与未来真实帧的语义前瞻进行对齐，从而将未来场景的语义引入动作流。为了建立每个查询与其所描述的未来步骤之间的时间对应关系，我们为其赋予匹配动作令牌的位置编码。在分布外泛化仿真基准以及真实机器人上的实验表明，我们的 Robust-WAM 在不牺牲分布内性能的前提下，始终提升多种 WAM 基线方法的成功率。

## Abstract
Mainstream World-Action Models (WAMs) adapt pretrained video generation models (VGMs) for robot control, transferring their learned dynamics prior for action prediction. These VGMs are typically trained in a variational autoencoder (VAE) latent space. However, the VAE latent space is optimized for pixel reconstruction, which rewards fine appearance detail and leaves the action prediction fragile under visual shifts. Recent works build WAMs in semantic latent space, which are more robust to appearance shifts. However, these models cannot leverage the large-scale VGM pretraining that exists only in VAE space. To overcome this dilemma, we propose Robust-WAM, a general post-training method for video-generation-based WAMs that preserves the VAE-based generative path and adds a lightweight semantic foresight alignment objective on the action stream. This retains the large-scale VGM pretraining while grounding actions in appearance-invariant dynamics that stay reliable under illumination shifts and other visual out-of-distribution conditions. Specifically, we employ learnable query tokens to bring future-scene semantics into the action stream by aligning their output hidden states with the semantic foresight of future ground-truth frames. To establish the temporal correspondence between each query and the future step it describes, we give it the positional encoding of the matching action tokens. Experiments on out-of-distribution generalization simulation benchmarks and a real-robot setup show that our Robust-WAM consistently improves the success rates of multiple WAM baselines without sacrificing in-distribution performance.

# Robust-WAM 论文详细总结

## 1. 核心问题与研究动机

**研究背景**：世界-动作模型（World-Action Models, WAMs）是当前机器人操作领域的重要范式，通过将大规模预训练的视频生成模型（VGMs）与动作生成结合，利用前者学到的动力学先验来提升策略质量。

**核心矛盾（两难困境）**：
- **VAE 潜空间 WAM**（主流路线，如 FastWAM、GE-Act、LingBot-VA）：复用大规模 VGM 预训练（如 Wan、Cosmos）学到丰富动力学先验，但 VAE 潜空间以像素重建为优化目标，过度编码纹理、光照等外观细节，导致动作预测在视觉分布外（OOD）条件下（如光照、纹理、视角偏移）脆弱失效。
- **语义潜空间 WAM**（如 LDA-1B）：在 DINO/V-JEPA 等语义特征空间中建模，对外观变化天然鲁棒，但放弃了大尺度 VGM 预训练，需要从零重新训练，代价高昂。

**研究目标**：在保留 VAE 生成路径与大规模动力学先验的前提下，向动作流注入外观不变的语义前瞻信息，弥合两类方法之间的鸿沟，提升 OOD 鲁棒性而不牺牲分布内（InD）性能。

## 2. 方法论

### 2.1 整体思想
Robust-WAM 是一种**通用、即插即用的后训练方法**，不改变原有 WAM 的 VAE 编码、视频 DiT 的去噪路径、视频-动作交叉注意力架构，只在**动作流上额外引入"语义前瞻对齐"目标**。

### 2.2 关键技术细节

**(1) 可学习的语义查询 token**
- 对每个未来时间步 j 和每个相机视角 c，引入一个可学习查询 token q，共 K = T_f × C 个。
- 这些查询 token 被**前缀拼接**到动作 token 序列之前：`h = [q; ha]`，与动作 token 一起进入动作 DiT。
- 关键设计：每个查询 token 复用其所对应动作步 τⱼ 的**位置编码**（来自原 WAM 的位置编码映射 Φ），即查询 j 使用与第 τⱼ 个动作 token 相同的位置编码，从而显式建立"查询 ↔ 未来步"的时间对应关系。

**(2) 对齐目标**
- 教师信号：冻结的 **DINOv3**（ViT-B/16）提取每个未来真实帧的 **CLS 嵌入** z*（维度 d_z = 768）。
- 选用 CLS 而非 patch 特征：CLS 表征场景高层语义（物体及其空间布局），对纹理、光照不敏感。
- 通过一个线性头 g 将动作 DiT 输出中查询 token 的隐藏状态映射到目标维度，使用**余弦对齐损失**：
  $$\mathcal{L}_{\text{align}} = \frac{1}{K}\sum_{k=1}^{K}\left(1 - \cos(g(\bar{h}_k), z_k^*)\right)$$
- 总损失：`L = L_WAM + λ_align · L_align`，其中 λ_align = 0.1。

**(3) 推理时简化**
- 训练时需要 DINOv3 教师和头部 g，推理时**完全丢弃**这两个组件，仅保留 K 个查询 token 本身，因此不增加推理成本。

**(4) 与不同架构的集成**
- **动作专家型 WAM**（MoT 架构，如 GE-Act、FastWAM、Motus）：查询 token 直接拼接到动作专家的 token 序列，参与自注意力与对视频塔的交叉注意力。
- **统一视频-动作型 WAM**（如 LingBot-VA）：查询 token 插入动作段，使用与对应动作 token 相同的 sequence/frame/noise ID，从而继承 flex-attention 掩码规则下的双向/自回归交互模式。

## 6. 主要结论与发现

- **Q1 OOD 鲁棒性**：在 LIBERO-Plus 上，FastWAM 从 49.7% → 58.9%（+9.2），GE-Act 从 78.0% → 80.9%（+2.9）；同时 clean LIBERO 性能小幅提升（97.6 → 97.9、96.5 → 97.3）。说明对齐目标显著提升 OOD 性能而不损失 InD 性能。
- **Q2 跨架构泛化性**：在统一视频-动作架构 LingBot-VA 上，RoboTwin random 划分从 29.8% → 34.4%（+4.6），clean 不变（81.2%）。证明方法对 MoT 与统一架构均有效。
- **Q3 设计选择**：
  - DINOv3 CLS 作为对齐目标优于 DINOv3 Patch、DA3 及二者组合。
  - 完整时序查询设计显著优于无时序位置编码（55.0% vs 58.9%）与当前帧目标（52.7% vs 58.9%）。
- **Q4 真实场景**：GE-Act 基线在紫光/青光下从 80.0% 跌至 57.3%，加 Robust-WAM 后 OOD 平均达 80.0%，InD-OOD 差距从 22.7 缩小到 2.7 点。
- **LIBERO-Plus 分轴**：FastWAM 在噪声（+18.9）、相机（+12.4）、光照（+11.3）、背景（+10.3）轴上增益最大；语义对齐不仅带来外观鲁棒性，还改善了几何与视角变化下的稳健性。
- **对比 LDA-1B**：后者虽然在语义空间建模，但因缺乏大规模 VGM 预训练，clean 90.6% / OOD 45.5% 远低于 GE-Act+Robust-WAM 的 97.3%/80.9%，印证了"语义应增强而非替换 VAE 预训练先验"的论断。

## 7. 优点

- **方法简洁、通用、即插即用**：不动 WAM 的 VAE 路径，仅在动作流上插入 K 个查询 token 与一个对齐损失，对多种 WAM 架构开箱即用。
- **解决了 WAM 领域的核心权衡**：首次以低成本后训练方式同时获得 VGM 大规模预训练动力学先验与语义级外观鲁棒性。
- **查询-动作时间对齐设计清晰**：通过共享位置编码让查询显式对应未来动作步，消融实验明确证实了时序位置编码与未来帧目标两者的必要性。
- **对齐目标选择合理**：DINOv3 CLS 表征场景高层语义，对纹理与光照天然不敏感；冻结教师不增加推理开销。
