## Abstract
Vision-Language-Action (VLA) models can follow instructions and manipulate objects, but their performance often collapses out of distribution (OOD), when the scene, viewpoint, or object differs from training. Adapting to each new situation typically requires collecting more data and fine-tuning. We present StellaVLA, a framework that instead adapts at test time by conditioning on a single retrieved demonstration. The key idea is to move beyond imitating what an expert did and instead convey why: an automated offline pipeline converts each raw trajectory into a structured demonstration, e.g., a task plan, sub-goal descriptions, and verbalized 3D motion, at zero human-annotation cost. Provided as in-context guidance, this structured demonstration lets the policy reason about the task rather than mimic a pixel trajectory, which also makes it transferable across embodiments (real-robot, human-hand, or XR demonstrations). A parallel dual-training design internalizes this reasoning during training through a joint action-and-language objective, while inference uses the action expert alone, preserving real-time, high-frequency control with no added latency. On the VLA-Arena leaderboard(Aug 1, 2026), StellaVLA ranks first with an overall score of 0.63, versus 0.44 and 0.22 for the strong prior models ($π_{0.5}$ and LingBot-VLA), and it further leads on LIBERO with 98.8% average success rate and LIBERO-Plus with 85.1% success rate. Our real-robot benchmark demonstrates that StellaVLA can use both human/robot demos and human-to-robot (XR) demos as in-context structured demonstration to help VLA model adapt to OOD tasks.

# StellaVLA 论文总结

## 1. 核心问题与研究动机

- **根本挑战**：Vision-Language-Action（VLA）模型在分布外（OOD）场景下性能急剧下降（场景、视角、物体变化时表现崩塌），传统适应方式需重新采集数据并微调，成本高、效率低。
- **现有 ICIL（In-Context Imitation Learning） 的局限**：将检索到的专家轨迹（连续观测 + 动作）作为上下文前缀，但仅停留在"模仿专家做了什么"，缺少对"为什么这样做"的显式结构化表达，导致策略出现 **行为惯性（behavioral inertia）**，倾向于回退至预训练先验。
- **核心假设**：将专家的中间推理（task plan、sub-goal、3D 运动语言化等）显式化，可让 VLA 策略从"模仿动作"转向"理解任务"，从而提升 OOD 泛化能力。

## 2. 方法论

### 2.1 核心思想
将原始专家轨迹通过**零人工标注成本的离线 pipeline** 转化为"结构化演示（structured demonstration）"，并在测试时作为 in-context 提示引导策略推理，而非单纯的动作模仿。

### 2.2 关键技术细节

- **离线结构化上下文提取（Sec. 3.1）**：
  - 输入原始轨迹 $\tau = \{(o_t, a_t)\}_{t=1}^{T}$ 与任务指令 $I$。
  - 使用 Qwen3-VL 等 VLM 因果演绎式将长时序轨迹分段为 $K$ 段，每段由 $t_{start}^{(k)} \to t_{end}^{(k)}$ 标记，并标注语义子目标。
  - **两层级结构化上下文 $l_k$**：
    - **语义理性（Semantic Rationale）**：子目标文字描述（如"抓住蓝色杯子把手"）。
    - **运动学理性（Kinematic Rationale）**：3D 工作空间位移（如 $\Delta x, \Delta y, \Delta z$） + 通过相机内外参投影得到的 2D 像素轨迹。
  - 确定性 verbalizer $\Phi$ 将连续动作映射为语言文本 token，无需引入专用动作 token。
  - 转换后：$\tau^{rat} = \{(o_t, a_t, s_t, l_k)\}_{t=1}^{T}$，形成检索池 $\mathcal{D}_{pool}$。

- **并行双训练范式（Sec. 3.2）**：
  - 训练输入：$x_t = P_{demo} \oplus I \oplus o_t$（检索到的演示 + 指令 + 当前观测），其中 $P_{demo}$ 通过任务指令的**语言嵌入余弦相似度 leave-one-out** 检索 top-1 演示。
  - **统一 VLM backbone $f_\theta$** 产生共享隐表征 $h_t$。
  - 两个并行专家：
    - **Action expert**：轻量 MLP，回归未来 $H$ 步动作 chunk $\hat{A}_t$。
    - **Spatial-language expert**：原生自回归 LM 头，输出当前子目标 $\hat{s}_t$ 和动作的语言化描述 $\hat{m}_t$。
  - 监督信号：$c_t = (s_t, \Phi(A_t))$（子目标 + 动作 chunk 的 2D/3D 语言化）。
  - **联合目标**：$\mathcal{L} = \mathcal{L}_{act} + \lambda \mathcal{L}_{lang}$，$\mathcal{L}_{act}$ 为 L1 回归损失，$\mathcal{L}_{lang}$ 为自回归交叉熵损失，默认 $\lambda = 0.3$。

- **非对称推理与缓存（Sec. 3.3）**：
  - 推理时**移除** spatial-language expert，仅通过单次前向传播 + 轻量 MLP 输出动作 chunk，避免自回归解码延迟。
  - 演示前缀 $P_{demo}$ 在 episode 内固定，KV cache 仅计算一次，后续步只对当前观测重做前向。

- **跨具身迁移**：real-robot、human-hand（XR 录制）、XR-retargeted 三类演示统一进入同一结构化池；检索仅基于任务语言嵌入，可在跨具身间检索；执行始终以目标机器人的原生控制空间监督。

### 2.3 算法流程（文字版）
1. 离线阶段：对所有原始轨迹运行 VLM 分割 → 生成任务计划、子目标描述、3D/2D 运动语言化 → 构建设结构化演示池。
2. 训练阶段：leave-one-out 检索 → 拼接为上下文前缀 → 与指令、当前观测共同输入 backbone → 双专家并行预测动作与语言监督 → 计算联合损失反向传播。
3. 推理阶段：检索结构化演示 → 计算 KV cache → 每步仅对当前观测重做前向 → 由 action expert 输出动作 chunk。

## 6. 主要结论与发现

- **基准结果**：
  - **VLA-Arena** 总分 0.63，排名第一，超过 π₀.₅ (0.44) 与 LingBot-VLA (0.22)；L0/L1/L2 三个等级均值分别为 0.84/0.62/0.43。
  - **LIBERO** 98.8% 平均成功率，领先 StarVLA-OFT（96.6%）；Goal 与 Long 套件提升最显著（+3.4 / +3.0）。
  - **LIBERO-Plus** 85.1%，相比 StarVLA-OFT（75.0%）+10.1 pp；视角 (+23.5)、噪声 (+19.7)、机器人初始态 (+14.7)、语言 (+8.3) 上提升最大。
- **因果发现**：
  - 移除演示：98.8 → 62.4；提供错误任务演示：进一步降至 44.9，说明检索演示被主动用作任务规范，而非被忽略；
  - 演示中"文本部分"几乎承担了全部可迁移任务信息（text-only 98.8/84.4 vs image-only 92.9/75.7），图像部分反而成为 OOD 捷径；
  - 演示源（机器人 / 人手 / XR-retargeted）切换仅引起 0.0014–0.0016 σ 的动作差异，表明跨源一致。
- **效率结论**：推理时模型侧 88–91 ms（前向 + MLP），无演示路径 64 ms；如打开自回归语言解码则升至 3177 ms（约 36× 慢），证实"训练期吸收推理、部署期丢弃语言头"的设计是必要的。
- **跨具身**：真实机器人三类混合演示源池上，in-dist 85%、OOD-L1 75%（同样两任务上 StarVLA-OFT 跌 25 pp、π₀.₅ 跌 20 pp）。

## 7. 优点与亮点

- **从"模仿动作"到"模仿推理"的范式转变**：将 ICIL 的 raw trajectory 升格为 hierarchical semantic + kinematic rationale，是核心概念贡献。
- **零人工标注的离线结构化 pipeline**：借助开源 VLM 自动生成任务计划与子目标，可扩展到大规模数据。
- **并行双专家 + 非对称推理**：巧妙将自回归语言解码的延迟问题隔离到训练阶段，部署端保留实时高频控制能力。
- **KV-cache 演示前缀 + 仅一次重算**：让长上下文推理成本摊销到整个 episode。
- **跨具身桥接**：在同一语义空间内统一机器人 / 人手 / XR 演示，无需对齐源动作空间。
- **因果消融充分**：通过 Table 5 提供"演示被策略主动使用"的直接证据，而不仅是相关性结果。

## 8. 不足与局限

- **长时序组合仍力不从心**：VLA-Arena Long Horizon 套件 L1/L2 各方法成功率均接近 0；固定前缀策略无法在执行漂移后重新规划。
- **检索质量依赖**：错误任务演示比"无演示"还差（44.9 < 62.4），OOD 下检索可靠性是关键瓶颈。
- **运动学粒度粗**：$\Phi$ 的量化文本化可能在精细操作中引入离散化误差，作者建议未来使用连续 token 化或混合表征。
- **真实机器人评估规模偏小**：单格 10 rollout，OOD-L2 仅有 progress score（满分 4）；可重复性受人工判定影响。
- **跨源一致性证据有限**：Table 4 仅做单步动作 L1 比较，并不构成闭环不变性证明，且 closure 上"完全相同上下文"这一前提在实际部署中难以严格保证。
