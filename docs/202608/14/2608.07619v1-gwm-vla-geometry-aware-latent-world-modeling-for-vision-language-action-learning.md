## 摘要
视觉-语言-动作（VLA）模型在机器人操作任务中表现强劲，但在视觉与环境发生偏移时性能常常下降。潜空间世界建模为提升鲁棒性提供了一种有前景的方法，然而现有方法通常独立地对各个相机视角进行编码，并在未显式建模几何关系的情况下预测整体场景动态。我们提出了GWM-VLA，一种面向VLA学习的几何感知潜空间世界建模框架。GWM-VLA结合了几何感知的多视角状态编码、以全局上下文为条件的目标视角预测，以及由机器人动作监督约束的共享潜空间-动作表征。具体而言，VGGT-Ω在每个时间步联合聚合多视角观测，以构建几何感知的多视角状态。潜空间世界模型利用多视角聚合后得到的patch token与register token，预测所选目标视角在下一时刻的patch token，从而保留多视角几何信息，同时无需预测完整的多视角状态。在实验中我们以腕部视角作为目标视角，更加关注末端执行器的运动以及夹爪与物体之间的局部交互。最终，共享的潜空间-动作表征同时作为潜空间世界模型与流匹配动作头的条件，使潜空间预测监督与真实机器人动作监督能够协同塑造同一套潜空间-动作表征。在仿真环境和真实环境中的实验均验证了GWM-VLA的有效性与鲁棒性。

## Abstract
Vision-Language-Action (VLA) models achieve strong robotic manipulation performance but often degrade under visual and environmental shifts. Latent world modeling offers a promising approach to improving robustness, yet existing methods commonly encode camera views independently and predict holistic scene dynamics without explicitly modeling their geometric relationships. We propose GWM-VLA, a geometry-aware latent world modeling framework for VLA learning. GWM-VLA combines geometry-aware multi-view state encoding, global context-conditioned target-view prediction, and shared latent-action representations grounded by robot-action supervision. Specifically, VGGT-$Ω$ jointly aggregates multi-view observations at each timestep to construct geometry-aware multi-view states. The latent world model predicts the next-step patch tokens of a selected target view using patch and register tokens obtained after multi-view aggregation, thereby retaining multi-view geometric information without predicting the complete multi-view state. We use the wrist view as the target in our experiments, placing greater emphasis on end-effector motion and local gripper-object interactions. Finally, the shared latent-action representations condition both the latent world model and the flow-matching action head, allowing latent-prediction supervision and ground-truth robot-action supervision to jointly shape the same latent-action representations. Experiments across both simulation and real-world environments demonstrate the effectiveness and robustness of GWM-VLA.

- **本文核心问题**：能否利用联合聚合的多视角几何表征作为预测状态，构建面向 VLA 学习的几何感知潜空间世界建模框架？

## 2. 方法论

### 2.1 整体框架

GWM-VLA 包含三大核心组件：
1. 基于 **VGGT-Ω** 的几何感知多视角编码器；
2. 以**全局上下文为条件的目标视图预测**潜空间世界模型；
3. **共享潜在动作表征**条件化的流匹配动作头。

每个时间步独立进行多视角聚合，不同时间步独立处理。

### 2.2 几何感知多视角状态编码

- 使用**冻结的预训练 VGGT-Ω** 聚合器，在每个时间步 $t$ 将多视角观测 $\{I_t^v\}_{v=1}^{V}$ 联合处理为单个几何样本：
  $$\{R_t, P_t\} = E_\Omega(\{I_t^v\}_{v=1}^{V})$$
- $R_t$ 与 $P_t$ 分别表示 register token 与 patch token，二者均经过跨视角交互后提取。
- 聚合器全程冻结。

### 2.3 全局上下文条件化的目标视图预测

- **不预测完整多视角状态**，而是选取单一目标视图 $v^*$（实验中为腕部视角）。
- 提取目标视图对应的 register 与 patch token：$r_t = R_t^{v^*}$，$p_t = P_t^{v^*}$。
- $p_t$ 作为待预测的目标视图潜空间状态，$r_t$ 作为全局几何上下文。
- 潜空间世界模型 $F_\phi$ 以共享潜在动作序列 $A_{0:T-1}$ 为条件做下一步预测：
  $$\hat{p}_{1:T} = F_\phi(p_{0:T-1}, r_{0:T-1}, A_{0:T-1})$$
- 采用**时间因果注意力**：同一时间步内 token 可双向交互，时间步 $t$ 只能关注不晚于 $t$ 的 token。
- 训练采用 **teacher forcing**，以真实 $p_{t+1}$ 作为监督，使用 $\ell_1$ 损失：
  $$L_{wm} = \frac{1}{T}\sum_{t=0}^{T-1}\|\hat{p}_{t+1} - p_{t+1}\|_1$$

### 2.4 统一潜在动作表征

- 视觉-语言骨干使用 **Qwen3-VL-2B**。
- 插入按时间步分组的可学习潜在动作查询 token $Q_A = \{Q_A^0, Q_A^1, \ldots, Q_A^{T-1}\}$。
- 所有潜在动作表征均由当前观测 $O_0$ 产生，$t$ 索引未来动作时域位置而非独立观测。
- 共享潜在动作序列 $A_{0:T-1} = Q_\theta(O_0, \ell, Q_A)$ **同时条件化**世界模型与动作头，避免像 VLA-JEPA 那样引入额外的 embodied action query。

### 2.5 条件流匹配动作头

- 使用条件流匹配（Lipman et al., 2023）生成动作块。
- 给定高斯噪声 $\epsilon \sim \mathcal{N}(0, I)$、流时间 $\gamma \sim U(0,1)$，$u^\gamma = (1-\gamma)\epsilon + \gamma u_{0:T-1}$，优化：
  $$L_{action} = \mathbb{E}\left[\|v_\psi(u^\gamma, \gamma | A_{0:T-1}, s_0) - (u_{0:T-1} - \epsilon)\|_2^2\right]$$
- 动作头以共享潜在动作序列与当前本体感知状态 $s_0$ 为条件。

### 2.6 联合优化

$$L = L_{action} + \lambda L_{wm}$$

- 默认 $\lambda = 0.1$，世界模型损失仅作为辅助训练目标，部署时不使用。

## 3. 实验设计

### 3.1 数据集
- **预训练**：DROID 数据集（约 76,000 条机器人演示轨迹，跨多机构、多操作员、多任务、多视角、多布局）。
- **仿真微调**：LIBERO 标准演示集。
- **真实环境**：自采集 100 条 SO-101 机器人遥操作演示，覆盖 5 个 pick-and-place 任务。

### 3.2 基准
- **LIBERO**（in-distribution）：包含 Spatial、Object、Goal、LIBERO-10 四个任务套件，Franka Panda 机械臂。
- **LIBERO-Plus**（out-of-distribution 鲁棒性）：7 个扰动维度——相机视角、机器人初始状态、语言指令、光照、背景、视觉噪声、物体布局。
- **真实环境**：在 SO-101 上评估 ID、OOD-task、OOD-layout 三种设置，各任务 10 次尝试。

### 3.3 对比方法
- **VLA 类**：OpenVLA-OFT、π0、π0-FAST、CoT-VLA、WorldVLA、GR00T N1、π0.5、villa-X。
- **潜动作类**：LAPA、UniVLA。
- **世界模型类**：VLA-JEPA（仅机器人演示版本作为最直接基线）。

### 3.4 消融实验（在 LIBERO Spatial 上）
- 目标视图选择（腕部 / 第三人称 / 混合）。
- 共享潜在动作 vs. embodied query 动作条件。

- 潜在状态预测的定性可视化（深度解码 + 相机坐标点云）。

## 6. 主要结论与发现

- **LIBERO**：GWM-VLA 达到 **97.1%** 平均成功率，与 OpenVLA-OFT 并列最佳，比 VLA-JEPA（无人类视频）高 1.0 个百分点。
- **LIBERO-Plus**：达到 **76.9%** 平均成功率，超过 OpenVLA-OFT 7.3 个百分点、超过 VLA-JEPA 基线 **14.0 个百分点**，为 SOTA；在语言、光照、物体布局扰动下排名第一。
- **真实环境**：在 ID 与 OOD-layout 设置下取得最高平均成功率；OOD-task（组合指令泛化）场景下 π0.5 最佳（60.0%），GWM-VLA 为 53.3%，仍显著优于 π0。
- **消融发现**：
  - 腕部视角预测（92.8%）优于第三人称（87.8%）与混合视图（92.4%）。
  - 直接共享潜在动作条件化（92.8%）优于 embodied query（88.0%）。
  - 表征深度越深效果越好，Layer 24 最佳（92.8%）。
- **定性发现**：预测的潜空间状态保留了下一步的抓取器与物体周围场景几何结构，但细节被平滑化。

## 7. 优点

- **几何与世界建模的融合创新**：首次将 VGGT-Ω 的联合多视角几何聚合作为潜空间世界模型的预测状态，弥补了 VLA-JEPA 独立编码各视图的缺陷。
- **目标视图聚焦策略**：仅预测单一目标视图的 patch token，降低预测负担，同时通过 register token 保留全局几何上下文，兼顾效率与几何一致性。
- **共享潜在动作表征设计**：避免引入额外 embodied action 查询，使潜空间预测监督与机器人动作监督协同塑造同一表征，结构简洁。
- **系统性的鲁棒性验证**：在 7 维 OOD 扰动上验证，显著超越基线，尤其在视觉噪声、背景、相机视角、语言变化上提升明显。
- **仿真 + 真实环境双重验证**：覆盖 LIBERO 与 SO-101 真实机器人，结论可信度较高。
- **充分的关键设计消融**：目标视图、动作条件、表征深度均有针对性实验支持设计选择。

## 8. 不足与局限

- **多视角依赖性强**：依赖同一时间步的多视角观测来构建几何感知潜空间状态，难以直接应用于**大规模人类视频预训练**（通常为单视角）。
- **固定目标视图**：训练时使用固定目标视图（腕部），最优目标视图可能因任务与传感器配置而异，缺乏自适应目标视图选择或多目标预测机制。
- **真实环境规模有限**：仅 100 条演示、5 个任务、每任务 10 次尝试，统计显著性可能不足。
- **OOD-task 表现欠佳**：在组合指令泛化（OOD-task）上落后于 π0.5，提示**空间鲁棒性与组合指令泛化是不同挑战**，方法对后者支持不足。
- **消融规模受限**：单卡 10K 步的小规模消融可能无法完全反映大规模训练下的真实表现差异。
- **缺乏对预测潜空间状态的定量评估**：定性可视化虽展示了几何保留能力，但无 3D 重建精度等定量指标。
- **超参数敏感性披露有限**：仅简要提及 λ=0.1 与 layer 24 的消融，未充分探索其他关键超参数（如预测时域 T、潜在动作 token 数量 K 等）。
- **方法复杂度较高**：依赖冻结的 VGGT-Ω 编码器与大型 VLM（Qwen3-VL-2B），部署时计算开销与延迟问题未讨论。
