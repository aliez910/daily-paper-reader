## 摘要
视觉-语言-动作（VLA）模型通常通过自回归的文本坐标或不透明的动作令牌来暴露空间接地能力，从而在多模态推理与机器人执行之间形成脆弱的接口。本文提出 Pointing-VLA，这是一种构建于 Embodied-R1 之上的具类型隐状态空间读出机制。几何专属的预测头可直接输出归一化点、对象功能接地（OFG）热力图以及视觉轨迹，而无需将几何信息序列化为文本。在所评测的 Bridge/WidowX 仿真任务以及物理抓取-放置部署中，显式的执行契约将 PICK 分配给以源对象为条件的 OFG，将 PLACE 分配给 Pointing，从而提供与阶段直接对齐的空间目标。在启用碰撞检测的 CuRobo 执行环境下，Pointing-VLA 在 Bridge/WidowX 上取得了当前最优（SOTA）的性能，在所评测的四项任务集上平均成功率达到 72.9%，且无需针对 Bridge 的特定微调。Pointing 与 OFG 在原生评测和跨数据集评测中表现出互补的优势。OFG/接触读出机制可迁移至 NORA-1.5，在保持或提升成功率的同时，将记录的控制器时间缩减超过 20 倍；此外，在共享的外部测试套件上，具类型预测头比 Embodied-R1 的文本解码速度快 6.68–6.90 倍。当作为空间引导集成至 π₀.₅ 动作策略时，Pointing-VLA 在三种视觉场景下将自主真实机器人任务的成功率从 52.7% 提升至 80.7%。上述结果确立了具类型空间读出作为一种高效且可检视的接口，能够连接具身推理与机器人执行。

## Abstract
Vision-language-action (VLA) models often expose spatial grounding through autoregressive text coordinates or opaque action tokens, creating brittle interfaces between multimodal reasoning and robot execution. We present Pointing-VLA, a typed hidden-state spatial readout built on Embodied-R1. Geometry-specific heads predict normalized points, object-functional grounding (OFG) heatmaps, and visual trajectories without serializing geometry as text. For the evaluated Bridge/WidowX and physical pick-place deployments, an explicit execution contract assigns PICK to source-conditioned OFG and PLACE to Pointing, providing direct stage-aligned spatial targets. Pointing-VLA achieves SOTA performance on Bridge/WidowX, averaging 72.9\% across the evaluated four-task set without Bridge-specific finetuning under collision-enabled CuRobo execution. Pointing and OFG show complementary strengths across native and cross-dataset evaluations. The OFG/contact readout transfers to NORA-1.5, preserving or improving success while reducing recorded controller time by more than 20$\times$; typed heads are also 6.68--6.90$\times$ faster than Embodied-R1 text decoding on a shared external suite. When integrated as spatial guidance for a $π_{0.5}$ action policy, Pointing-VLA raises autonomous real-robot success from 52.7\% to 80.7\% across three visual contexts. These results establish typed spatial readouts as an efficient, inspectable interface between embodied reasoning and robot execution.

# Pointing-VLA 论文总结

## 一、核心问题与研究动机

- **接口瓶颈问题**：现有视觉-语言-动作（VLA）模型在将空间接地信息传递给机器人执行端时存在两类缺陷：
  - **自回归文本坐标**：需要逐 token 生成数字，存在生成失败、解析失败和空间定位错误三类风险（论文 Figure 1 展示了两种典型失效情形）。
  - **不透明动作令牌**：隐藏了空间推理过程，难以被人类审查或被下游执行栈利用。
- **统一输出假设的问题**：将"指代点""功能区域""视觉轨迹"等本质不同的空间目标折叠为单一输出分布，会产生负干扰，并因序列化而降低执行效率。
- **核心主张**：具身接地应被视作**具类型（typed）的接口预测**，而非文本坐标生成。这与神经科学中"视觉识别"与"行动导向的视觉运动表征"的分离观点以及"群体读出（population readout）"思想一致。

## 二、方法论：核心思想与关键技术

### 1. 整体架构
- **基础骨干**：复用 Embodied-R1 的多模态隐状态 $\mathbf{H}_{mm}^{e} = \{h_i^e\}_{i=1}^{N_e}$，每个空间专家共享相同的骨干结构与 Grounding Adapter 主体，但保留独立的 LoRA、learned queries 与解码器。
- **Grounding Adapter**：1024-D 投影 + learned queries + query cross-attention + FFN，输出固定数量的接地 token $\mathbf{G}_e$ 与全局摘要 $g_e = \text{Pool}(\mathbf{G}_e)$。
- **三大几何专属读出头**：

| 专家 | 任务 | 输出几何 |
|------|------|----------|
| Pointing | 指代点定位 | 单一归一化坐标 $(\hat{x}, \hat{y}) \in [0,1]^2$ |
| OFG | 对象功能接地 | 二维热图 $\hat{\mathbf{H}}_{ofg}$，峰值即接触点 |
| VTG | 视觉轨迹 | $T=8$ 个归一化路点 |

### 2. 关键技术细节

**Pointing 头**：通过指针查询 $q_{pt}$ 对接地 token 做 cross-attention，再经 $\text{LN}$ 与线性层直接输出归一化坐标：
$$A_{pt} = \text{softmax}\left(\frac{(q_{pt}W^Q)(G_{pt}W^K)^\top}{\sqrt{d}}\right),\quad z_{pt} = A_{pt}(G_{pt}W^V)$$
$$(\hat{x},\hat{y}) = \sigma(W_p\,\text{LN}(z_{pt}) + b_p)$$

**OFG 头**：先用全局摘要 $g_{ofg}$ 通过 FiLM 调制视觉塔特征图 $\mathbf{F}_{vis}$，再用卷积热图解码器得到热图：
$$\mathbf{F}'_{ofg} = \gamma(g_{ofg})\odot \mathbf{F}_{vis} + \beta(g_{ofg}),\quad \hat{\mathbf{H}}_{ofg} = f_{hm}(\mathbf{F}'_{ofg})$$

**VTG 头**：带时序编码的 waypoint queries 直接对完整多模态序列做 attention，避免固定接地 token 瓶颈。

### 3. 显式执行契约
- **固定分配**：源对象条件化的 OFG → PICK 接触点；Pointing → PLACE 目标点。
- **契约构造**：$q_{pick} = T_{pick}(\ell, c_{src})$，$q_{place} = T_{place}(\ell, c_{goal})$，由指令 $\ell$、源描述 $c_{src}$、目标描述 $c_{goal}$ 拼装。
- **图像→机器人坐标映射**：通过深度 $D$、相机内参 $K$、相机到机器人外参 $T_{r\leftarrow c}$ 将像素坐标转换为机器人系目标。

### 4. 训练策略
- **分阶段训练**：几何预热（训练 adapter + 8 个 queries + 几何头）→ LoRA 特化（仅低秩更新）→ 任务延续（按需更新子集）。
- **损失函数**：$\mathcal{L} = \lambda_{pt}\mathcal{L}_{pt} + \lambda_{box}\mathcal{L}_{box} + \lambda_{ofg}\mathcal{L}_{ofg} + \lambda_{vtg}\mathcal{L}_{vtg} + \lambda_{aux}\mathcal{L}_{aux}$；Point/VTG 用 SmoothL1，OFG 用高斯关键点 MSE 或类别平衡 BCE。
- **GRPO 风格精炼**：对 Pointing 头进行群组归一化优化，使用 point-in-box 奖励和 KL 参考正则。

## 六、主要结论与发现

- **SOTA 性能**：在 Bridge/WidowX 四任务平均 **72.9%**，未做 Bridge 专用微调，且 CuRobo 全程启用碰撞检测无规划失败。
- **几何类型化收益**：Pointing 保持稀疏点精度（VABench-P 64.3%）；OFG 将 Part-Affordance-2K 全集精度由 40.9% 提升至 57.3%（+16.4 点）。
- **互补性**：Pointing 在 RefCOCO/RoboAff 上更强；OFG 在 AGD20K/Part-Affordance-2K 上更强，说明两者并非可替代而是分工。
- **效率**：具类型读出比 Embodied-R1 文本解码快 **6.68–6.90×**；NORA-1.5 迁移后控制器时间缩短 **20× 以上**。
- **真实机器人**：将 π0.5 的自主成功率从 **52.7% → 80.7%**（+28.0 pp），失败主要下降来自抓取阶段（47→16）和托盘到位（13→4），验证了 OFG-PICK/Pointing-PLACE 的阶段对齐贡献。
- **VTG 表现**：300 例 VABench-V 上 RMSE=0.1042、ADE=0.1368、FDE=0.1493。

## 七、方法与实验的亮点

- **"类型化接口预测"作为核心理念**：明确区分点/区域/轨迹三种几何，避免单一输出分布的负干扰。
- **显式执行契约**：固定 PICK→OFG、PLACE→Pointing，无需推理时选择器，简化了栈结构。
- **接口可检视**：相比动作令牌，热图与坐标可被人类或上游模块检查。
- **跨骨干迁移性**：将 OFG 读出冻结挂接到 NORA-1.5，验证了读出层与骨干解耦。
- **统一评估协议**：跨数据集下将所有输出标准化为单点比较，保证对比公平。
- **失败阶段诊断**：在真实机器人上做阶段分解而非只报总数，定位了瓶颈为抓取与托盘到位。

## 八、不足与局限

- **闭循环几何感知执行仍是瓶颈**：Spoon-on-towel 任务表现不稳，论文明确将其列为"下一杠杆点"；真实机器人中 post-grasp transfer 仍是主要残余瓶颈（47→16 之外的部分未继续下降）。
