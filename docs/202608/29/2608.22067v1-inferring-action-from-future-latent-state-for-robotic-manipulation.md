## 摘要
世界-动作模型（World-Action Models，WAMs）以视频生成为主干构建机器人控制，联合预测密集的未来视觉轨迹与机器人动作。我们认为，视频生成是世界-动作建模中一个不必要的中间目标。对于机器人操作任务而言，世界模型的目标并非复现世界在每个中间时刻的外观，而是预测动作执行后世界将达到的状态。中间帧仅刻画了物理状态之间的视觉过渡，消耗了大量模型容量与算力，却并未直接指定机器人动作所意图产生的物理结果。本文提出 DELE-w0.5，无需依赖视频生成，直接从预测的未来状态中推断机器人动作。具体而言，DELE-w0.5 从对应的紧凑未来潜在状态中推断动作序列。该未来潜在状态刻画了与动作相关的机器人交互物理结果，并充当世界建模与动作生成之间的显式桥梁。DELE-w0.5 的核心设计原则是建模机器人在动作作用下物理世界如何变化，而非其视觉外观如何逐帧演变。该建模范式消除了由密集视频表征引入的高维视觉冗余，从而显著降低训练成本，并支持低延迟推理。在四项长时序操作任务上开展的 480 次真实机器人实验中，DELE-w0.5 在所有对比策略中取得最优性能，整体任务成功率达到 62.5%，宏观有序阶段进度达到 81.3%，分别超出最强基线 47.5 与 30.7 个百分点。

## Abstract
World-Action Models (WAMs) build robot control on video-generation backbones, which jointly predict dense future visual trajectories and robot actions. We argue that video generation is an unnecessary intermediate objective for world-action modeling. For robotic manipulation, the goal of a world model is not to reproduce how the world looks at every intermediate moment, but to predict the state that the world will reach after an action is executed. The intermediate frames only describe the visual transition between physical states, which consumes substantial model capacity and computation, but do not directly specify the physical outcome that the robot action is intended to produce. In this paper, we propose DELE-w0.5, which infers robot actions from predicted future states without relying on video generation. Concretely, DELE-w0.5 infers the action sequence from its corresponding compact future latent state. The future latent state captures the action-relevant physical outcome of robot interaction and serves as an explicit bridge between world modeling and action generation. The core design principle of DELE-w0.5 is to model how the physical world changes under robot actions, rather than how its visual appearance evolves frame by frame. This formulation removes the high-dimensional visual redundancy introduced by dense video representations, and it therefore enables cheaper training and low-latency inference. Across 480 real-robot trials on four long-horizon manipulation tasks, our DELE-w0.5 achieves the best performance among all compared policies, attaining 62.5 overall full-task success and 81.3 macro ordered-stage progress, outperforming the strongest baseline by 47.5 and 30.7 percentage points, respectively.

# 论文总结：面向机器人操作的基于未来潜在状态的动作推断（DELE-w0.5）

## 1. 核心问题与研究动机

- **主流范式的局限**：当前 World-Action Models（WAMs）以视频生成模型为骨干，联合预测密集的未来视觉轨迹与机器人动作（如 DreamZero、τ0-WM、GigaWorld-Policy 等）。
- **结构性失配**：视频生成的高维、敏感于外观的特性，使中间帧仅刻画状态间的视觉过渡，并不直接指定动作所意图的物理结果。
- **算力与延迟代价**：未来视频潜变量比动作序列大得多，主导了序列长度、显存与计算预算；推理时还需对高维潜变量做迭代去噪，显著拖慢控制回路。
- **核心论点**：对于机器人操作，世界模型的真正目标不是复现世界"每帧看起来怎样"，而是预测"动作执行后世界将达到什么状态"——即建模动作相关的未来物理结果，而非逐帧视觉外观。

## 2. 方法论

### 2.1 整体思路

- **三种范式的概率推断对比**：
  - VLA 推断 $p_\theta(A_t \mid O_t, q_t, L)$
  - WAM 推断 $p_\theta(A_t, O_{t:t+\Delta t} \mid O_t, q_t, L)$（含中间视频帧）
  - **DELE-w0.5 推断** $p_\theta(A_t, O_{t+\Delta t} \mid O_t, q_t, L)$（仅预测末端潜在状态）
- **核心创新**：以紧凑的未来潜在状态替代整段视频，作为世界建模与动作生成之间的"显式桥梁"，避免视频冗余并实现低延迟控制。

### 2.2 编码器与表征

- **视觉编码器**：DINO-v3，将多视角 RGB（头戴视角 + 双腕视角）压缩为潜在表征 $\hat{z}_t$。
- **语言编码器**：Qwen3，将任务指令（如"把花放进花瓶"）编码为语言 token $\hat{l}$。
- **本体感知**：$q_t$（双臂 14-DoF）。
- **动作空间**：单臂 7-DoF（3 位移 + 3 旋转 + 1 夹爪）；动作块长度 $H=60$。
- **未来状态目标**：$\hat{z}_{t+\Delta t} = \text{VisionEncoder}(O_{t+\Delta t})$。

### 2.3 双流注意力架构（HeTu-1.0）

- **条件流（Condition Stream）**：
  - 将语言 token 与当前观测 token 拼接为 $Z_t^c = [l, z_t]$。
  - 经单流自注意力融合得 $\hat{Z}_t^c$。
  - AdaLN（$\gamma_c = 1 + W_{\text{AdaLN}} t_c + b_{\text{AdaLN}}$，其中 $t_c$ 对应 $\tau=1$）调制后产出 $Q_c, K_c, V_c$（RMSNorm + QKNorm + 可学习缩放）。
- **噪声流（Noise Stream）**：
  - 对动作块 $A_t$ 与未来潜状态 $\hat{z}_{t+\Delta t}$ 注入流匹配噪声：
    - $A_t^\tau = \tau A_t + (1-\tau)\epsilon$
    - $z_{t+\Delta t}^\tau = \tau \hat{z}_{t+\Delta t} + (1-\tau)\epsilon$
  - 同样经单流自注意力与 AdaLN 产出 $Q_n, K_n, V_n$。
- **联合注意力**：将两流的 Q/K/V 拼接，经掩码注意力 + 投影层同时输出 $\hat{A}_t^\tau$ 与 $\hat{z}_{t+\Delta t}^\tau$。

### 2.4 流匹配训练目标

- 速度场回归损失（动作与状态各一项）：
  - $\mathcal{L}_a = \mathbb{E}_{\tau,\epsilon}\left[\|u_a(A_t^\tau, z_{t+\Delta t}^\tau, q_t, l) - (A_t - \epsilon)\|_2^2\right]$
  - $\mathcal{L}_o = \mathbb{E}_{\tau,\epsilon}\left[\|o_a(A_t^\tau, z_{t+\Delta t}^\tau, q_t, l) - (\hat{z}_{t+\Delta t} - \epsilon)\|_2^2\right]$
  - 总目标 $\mathcal{L} = \mathcal{L}_a + \lambda \mathcal{L}_o$，其中 $\lambda$ 平衡两项。

### 2.5 训练与推理的注意力掩码

- **训练时**：语言与当前观测双向互注意；动作 token 可访问语言、当前观测及自身；未来潜状态可访问所有组（避免信息泄漏的前提下学习状态转移）。
- **推理时**：未来潜状态组被移除，模型直接从语言 + 当前观测直接推断动作，序列更短、无视觉生成、延迟极低。
