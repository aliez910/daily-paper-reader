## 摘要
视觉-语言-动作（VLA）模型将视觉观测编码为扁平的二维块标记，这些标记本身不包含固有的几何结构；而为其补充稠密单目深度信息则会注入逐像素的标量值，这些标量既不编码表面朝向，也不编码几何置信度。这使得策略网络在进行动作预测时缺乏结构化的空间推理能力。我们提出了GaussVLA，一种基于Mamba的VLA模型，其中包含两个定制模块：Gaussian空间分词器（GST），用于将冻结的语义特征和深度特征提升为紧凑的三维高斯标记，并通过可学习的查询在几何显著区域进行池化；以及深度感知思维链（DA-CoT），在语言和流时间条件调控下执行结构化的非自回归几何推理。在仿真和真实世界评估中，GaussVLA展现了出色的空间操作性能，同时保持参数高效性。在LIBERO基准上，它仅凭2亿参数就取得了93.5%的平均成功率，并在空间任务套件上达到100.0%的成功率，相较SpatialVLA在平均成功率上提升了19.7%，同时参数效率显著更高。

## Abstract
Vision-Language-Action (VLA) models encode visual observations as flat 2D patch tokens that carry no intrinsic geometric structure, and augmenting them with dense monocular depth injects per-pixel scalar values that encode neither surface orientation nor geometric confidence. This leaves the policy with limited structured spatial reasoning for action prediction. We propose GaussVLA, a Mamba-based VLA that incorporates two custom modules: Gaussian Spatial Tokenizer (GST) to lift frozen semantic and depth features into compact 3D Gaussian tokens, pools geometrically salient regions with learned queries, and \emph{Depth-Aware Chain-of-Thought (DA-CoT)} that performs structured, non-autoregressive geometric reasoning under language and flow-time conditioning. Across both simulation and real-world evaluations, GaussVLA demonstrates strong spatial-manipulation performance while remaining parameter-efficient. On LIBERO, it achieves 93.5% average success and 100.0% success on the Spatial suite with only 200M parameters, improving over SpatialVLA by 19.7% relative average success while remaining significantly more parameter-efficient.

# GaussVLA 论文总结

## 1. 核心问题与研究背景

- **VLA 视觉表征的根本缺陷**：现有视觉-语言-动作模型（如 OpenVLA、π0、SpatialVLA 等）通常将 RGB 观测编码为扁平的二维 patch token，丢失了内禀的三维几何结构，对所有 patch 一视同仁，无法体现深度、表面朝向或几何可靠性。
- **单目深度增强的局限**：直接拼接稠密单目深度（如 SpatialVLA）只能提供逐像素的标量距离，无法表达表面朝向，也不携带几何置信度，难以应对需要精细几何推理的任务。
- **推理机制的不足**：已有 Chain-of-Thought 方法（如 CoT-VLA、ECoT）多在二维图像空间进行自回归文本推理，延迟高、与动作解码脱耦；而 RD-VLA 等隐式递归推理又牺牲了可审计性。
- **效率与规模的权衡**：主流大模型（3.3B–7B 参数）部署成本高，Transformer 注意力的二次复杂度难以承载语言、视觉、3D token 与本体感觉混合的长序列。
- **研究目标**：提出一种能够同时具备结构化三维几何表征、显式空间推理、轻量化线性时序建模的 VLA 框架，弥补空间操作能力短板。

## 2. 方法论

### 2.1 整体框架
- **双流冻结视觉编码**：分别使用 SigLIP-SO400M/14（语义）与 Depth-Anything-V2（几何）提取 patch 级语义特征 $F^{(m)}_{t,r} \in \mathbb{R}^{d_s}$ 与 patch 中心深度 $d^{(m)}_{t,r}$，二者对齐到同一 patch 网格（$P=256$）。
- **GST（Gaussian Spatial Tokenizer）**：将每个 patch 提升为 3D 高斯基元（mean + covariance + opacity）。
- **DA-CoT（Depth-Aware Chain-of-Thought）**：基于 GST token 进行结构化、非自回归空间推理。
- **Mamba 主干**：以线性时序建模整合语言、GST、DA-CoT、动作 token。
- **Flow-Matching 动作头**：以 10 步 Euler 积分解码动作 chunk（$H=10$，7-DoF）。

### 2.2 GST 关键设计
- **可学习深度校正**：$\tilde{d}^{(m)}_{t,r}=\lambda_d d^{(m)}_{t,r}+\beta_d$，并利用相机内参 $\mathbf{K}^{(m)}$ 反投影得到三维坐标 $c^{(m)}_{t,r}$。
- **高斯参数预测头**：由语义特征回归残差均值偏移 $\Delta\mu$、对数尺度 $\eta$（对应协方差）以及不透明度 $\alpha$（作为置信度）。
- **受限偏移**：$\mu^{(m)}_{t,r}=c^{(m)}_{t,r}+\rho\tanh(\Delta\mu^{(m)}_{t,r})$，$\rho=0.8\,\text{m}$ 约束工作空间范围。
- **3D Fourier 位置编码**：将 $\mu^{(m)}_{t,r}$ 用 $L=10$ 波段编码，得到几何感知 patch token $g^{(m)}_{t,r} = f^{(m)}_{t,r}\oplus\gamma(\mu^{(m)}_{t,r})\oplus\eta^{(m)}_{t,r}$。
- **置信度加权的空间注意力池化**：以 $N_g=128$ 个可学习查询 $\mathbf{Q}$ 通过 cross-attention 聚合 patch token，并将 $\log\alpha$ 作为偏置项加入 softmax，从而实现"几何显著区域"的优先选择。

### 2.3 DA-CoT 关键设计
- 将 GST 标记展平后投影到推理空间 $\mathbb{R}^{d_c}$，与语言 token $l^{\text{cot}}$ 和流时间 token $\varphi_\tau$ 拼接，形成条件上下文 $C_\tau$。
- 通过 $N_r=4$ 个可学习推理查询的自注意力 → cross-attention(到 $C_\tau$) → FFN 得到 $R_\tau$。
- **核心思想**：以极少量查询（$N_r=4$ vs. GST $128$ 个）实现非自回归的全局几何推理，并通过流时间条件锚定到动作预测目标。

### 2.4 训练目标
- **流匹配损失** $\mathcal{L}_{\text{FM}}=\|v_\theta(Z_\tau,O,l,\tau)-U\|_2^2$。
- **GST 深度一致性损失** $\mathcal{L}_{\text{GST}}$：对 $\mu_{z}$ 与 $\tilde{d}$ 做不透明度加权回归（$\lambda_{\text{GST}}=0.05$）。
- **DA-CoT 监督损失** $\mathcal{L}_{\text{CoT}}$：令 DA-CoT token 辅助预测目标速度（$\lambda_{\text{CoT}}=0.10$）。
- 总损失 $\mathcal{L}=\mathcal{L}_{\text{FM}}+\mathcal{L}_{\text{GST}}+\mathcal{L}_{\text{CoT}}$。

## 7. 优点与亮点

- **几何表征创新**：首次在 VLA 中引入 3D 高斯基元（mean + covariance + opacity），同时编码位置、局部朝向与置信度，比伪点云（如 SpatialVLA）更具结构性。
- **置信度加权池化**：$\log\alpha$ 作为 softmax 偏置，使模型自动聚焦几何可靠区域，且通过相关性分析验证其与深度不确定性的内在对应。
- **非自回归 CoT**：DA-CoT 以极少量查询（$N_r=4$）实现结构化空间推理，规避了文本 CoT 的秒级延迟，同时保留可监督信号。
- **Mamba 主干**：以线性时序建模整合异构多模态 token，吞吐量优于 Transformer（9.82→3.28 GFLOPs）。
- **参数高效**：仅 200M（其中可训练 179M）参数即可在多个基准上超越 3.3B–7B 的大模型。
- **真实机器人验证**：在消费级 GPU（GTX 1080 Ti）上完成多任务与 OOD 部署。
- **表征可解释性**：线性探针实验清楚展示 GST / DA-CoT 在三维几何量预测上的递增优势。
