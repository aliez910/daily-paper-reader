## 摘要
世界-动作模型（World-Action Models, WAMs）以视频生成模型为基础构建机器人控制，联合预测密集的未来视觉轨迹与机器人动作。我们认为，视频生成对于世界-动作建模而言并非必要的中间目标。对于机器人操控而言，世界模型的目标并非再现每一中间时刻的世界外观，而是预测动作执行后世界将达到的状态。中间帧仅描述物理状态之间的视觉过渡，这会消耗大量的模型容量与计算资源，但并未直接指明机器人动作意图产生的物理结果。在本文中，我们提出DELE-w0.5，无需依赖视频生成即可从预测的未来状态中推断机器人动作。具体而言，DELE-w0.5从其对应的紧凑未来潜在状态中推断动作序列。未来潜在状态捕捉了机器人交互中与动作相关的物理结果，并充当世界建模与动作生成之间的显式桥梁。DELE-w0.5的核心设计原则是对机器人物理世界在动作作用下如何变化进行建模，而非逐帧刻画其视觉外观的演化。该建模方式消除了密集视频表征所引入的高维视觉冗余，因而能够以更低的成本进行训练并实现低延迟推理。在四个长时序操控任务上的480次真实机器人试验中，我们的DELE-w0.5在所有对比策略中取得了最优性能，整体全任务成功率达到62.5，宏观有序阶段进度达到81.3，分别比最强基线高出47.5和30.7个百分点。

## Abstract
World-Action Models (WAMs) build robot control on video-generation backbones, which jointly predict dense future visual trajectories and robot actions. We argue that video generation is an unnecessary intermediate objective for world-action modeling. For robotic manipulation, the goal of a world model is not to reproduce how the world looks at every intermediate moment, but to predict the state that the world will reach after an action is executed. The intermediate frames only describe the visual transition between physical states, which consumes substantial model capacity and computation, but do not directly specify the physical outcome that the robot action is intended to produce. In this paper, we propose DELE-w0.5, which infers robot actions from predicted future states without relying on video generation. Concretely, DELE-w0.5 infers the action sequence from its corresponding compact future latent state. The future latent state captures the action-relevant physical outcome of robot interaction and serves as an explicit bridge between world modeling and action generation. The core design principle of DELE-w0.5 is to model how the physical world changes under robot actions, rather than how its visual appearance evolves frame by frame. This formulation removes the high-dimensional visual redundancy introduced by dense video representations, and it therefore enables cheaper training and low-latency inference. Across 480 real-robot trials on four long-horizon manipulation tasks, our DELE-w0.5 achieves the best performance among all compared policies, attaining 62.5 overall full-task success and 81.3 macro ordered-stage progress, outperforming the strongest baseline by 47.5 and 30.7 percentage points, respectively.

# 论文总结：DELE-w0.5 — 从未来潜在状态推断动作以实现机器人操控

## 1. 核心问题与研究动机

- **背景**：机器人操控领域目前主流的两类架构为视觉-语言-动作模型（VLA）和世界-动作模型（WAM）。WAM 借助视频生成 backbone 联合预测未来视觉轨迹与机器人动作，希望通过视觉预测为策略提供物理先验。
- **核心问题**：作者指出**视频生成并非世界-动作建模的必要中间目标**。对于机器人操控而言，世界模型的目标不是逐帧再现视觉外观，而是预测"动作执行后世界将达到何种状态"。中间帧仅描述物理状态间的视觉过渡，消耗大量模型容量与算力，却不直接服务于动作决策。
- **关键不匹配（mismatch）**：
  - 视频表征维度远高于动作序列，主导了序列长度、显存与训练成本。
  - 推理时需要迭代去噪生成高维视觉潜变量，控制环路被不必要的视觉合成所阻塞。
  - 优化视觉重建的潜变量特征并不必然对齐到控制所需的物理结局。

## 2. 方法论

### 2.1 整体思路

- 重新表述 WAM 任务为：**从紧凑的、与动作因果相关的未来潜在状态直接推断动作序列**，不再生成任何中间视频帧。
- 三种范式的概率推断对比：
  - VLA：$p_\theta(A_t \mid O_t, q_t, L)$
  - WAM（视频式）：$p_\theta(A_t, O_{t:t+\Delta t} \mid O_t, q_t, L)$
  - **DELE-w0.5**：$p_\theta(A_t, O_{t+\Delta t} \mid O_t, q_t, L)$

### 2.2 架构：双流注意力机制

- **Condition Stream（条件流）**：
  - 文本编码器采用 **Qwen3**；视觉编码器采用 **DINO-v3**（三视角：头部 + 双腕部相机）。
  - 投影层将两种模态对齐到共同隐藏维度 1024。
  - **Single-Stream Attention Block** 拼接语言与视觉 token，做统一自注意力融合。
  - 经 **AdaLN 调制 + RMSNorm + QKNorm** 输出条件流的 Qc、Kc、Vc（timestep 固定为 τ=1）。
- **Noise Stream（噪声流）**：
  - 对动作 chunk $A_t = [a_{t+1},…,a_{t+H}]$（H=60）和下一时刻视觉潜变量 $\hat z_{t+\Delta t}$ 加噪：$A_t^\tau = \tau A_t + (1-\tau)\epsilon$，$\epsilon \sim \mathcal N(0,I)$。
  - 同样经过 Single-Stream + AdaLN，得到 Qn、Kn、Vn。
- **联合注意力**：
  - 拼接 $Q = \text{cat}(Q_c, Q_n)$，$K,V$ 同理；
  - 通过 **Masked Attention** 进行联合去噪，输出预测的 $\hat A_t^\tau$ 与 $\hat z_{t+\Delta t}^\tau$。
- **训练目标（Flow Matching）**：
  - 同时回归动作速度场 $\mathcal L_a$ 与未来状态速度场 $\mathcal L_o$：
    $$\mathcal L = \mathcal L_a + \lambda \mathcal L_o$$
  - 使用流匹配（Flow Matching）而非扩散，便于少步采样与低延迟推理。
- **注意力掩码设计**：
  - 训练时：语言与当前观测双向互看；动作 token 看 {语言, 当前观测, 动作}；未来状态 token 看所有 token。
  - 推理时：**直接去掉未来状态 token 序列**，故无需生成任何视觉 token，显著缩短序列长度。

### 2.3 与现有 WAM 的本质区别

| 维度 | 视频式 WAM | DELE-w0.5 |
|---|---|---|
| 中间目标 | 逐帧视频重建 | 未来潜在状态 |
| 推理序列长度 | 长（含多帧视频 token） | 短（仅动作） |
| 迭代去噪对象 | 视频 + 动作潜变量 | 仅动作 + 紧凑未来状态 |
| 计算瓶颈 | 视觉合成 | 直接动作生成 |
