## 摘要
视觉-语言-动作（VLA）模型通过整合视觉感知、语言理解和连续动作控制，为通用机器人操作提供了一条可扩展的路径。然而，我们揭示了 VLA 架构的一个关键局限：动作专家对 VLM 特征中可用的三维几何和二维语义信息的访问有限。这种可访问性差距削弱了感知基础，并限制了在细粒度机器人操作任务上的性能。为了解决这一问题，我们提出了 V-Link，在视觉-语言（VL）到动作（A）特征传递过程中显式地恢复视觉表征。具体而言，V-Link 在 VLM 内部学习互补的空间和语义查询表征，并通过非对称路径将其注入到 Action DiT 中。语义查询补充了原始的 VLM 图像令牌，而空间查询则为基于空间的动作生成提供专门的几何条件。在 LIBERO、LIBERO-Plus 和 RoboTwin 2.0 上，我们的 V-Link 在基础模型 GR00T N1.6 之上将平均成功率分别提升了 +1.9%、+31.2% 和 +18.8%。在 AGIBOT A3 Ultra 上，V-Link 进一步在两项真实世界人形机器人任务上分别取得了 +20% 和 +24% 的性能提升。

## Abstract
Vision-language-action (VLA) models provide a scalable path toward generalist robotic manipulation by integrating visual perception, language understanding, and continuous action control. However, we reveal a critical limitation of VLA architectures: the action expert has limited access to the 3D geometric and 2D semantic information available in VLM features. This accessibility gap weakens perceptual grounding and limits performance on fine-grained robotic manipulation. To address this issue, we propose V-Link, which explicitly recovers visual representations during the vision-language (VL) to action (A) feature transfer. Specifically, V-Link learns complementary Spatial and Semantic Query representations within the VLM and injects them into Action DiT through asymmetric pathways. Semantic Queries complement the original VLM image tokens, whereas Spatial Queries provide dedicated geometric conditioning for spatially grounded action generation. Across LIBERO, LIBERO-Plus, and RoboTwin 2.0, our V-Link improves the average success rate over base model GR00T N1.6 by +1.9%, +31.2%, and +18.8%, respectively. On the AGIBOT A3 Ultra, V-Link further achieves gains of +20% and +24% on two real-world humanoid tasks.

# V-Link 论文总结

## 1. 核心问题与研究背景

- **研究对象**：Vision-Language-Action（VLA）模型，特别是双系统架构（如 NVIDIA GR00T N1.6），由 VLM 与独立的 Action DiT（动作专家）组成，二者通过"最终层特征传递"实现视觉-语言到动作（VL-to-A）的特征迁移。
- **关键问题**：作者发现 VLA 架构存在**视觉表征可访问性瓶颈（accessibility bottleneck）**——Action DiT 对 VLM 特征中蕴含的 3D 几何信息和 2D 语义信息访问有限。
- **诊断证据**（冻结特征 + 轻量任务头探测）：
  - 深度估计 MAE 从 VLM 特征的 0.015 升至 Action DiT 特征的 0.071；
  - 语义分割 mIoU 从 VLM 的 0.665 降至 Action DiT 的 0.290。
- **归因假设**：最终层 VLM 特征高度纠缠，叠加仅由动作损失驱动的优化，使得 Action DiT 倾向于利用"语义捷径"快速降低动作损失，而忽视结构关键的 3D 空间线索，导致局部最优。
- **整体含义**：揭示了双系统 VLA 中一个被忽视的感知–动作脱节问题，对细粒度机器人操控构成性能瓶颈。

## 2. 方法论：V-Link

### 2.1 核心思想

- 在 VLM 内部引入两组可学习令牌——**空间查询（Spatial Queries）**与**语义查询（Semantic Queries）**——分别专门捕获 3D 几何与 2D 语义信息；
- 通过**非对称注入通路**将两组查询分别送入 Action DiT：语义查询以并行交叉注意力补充原 VLM 图像令牌，空间查询在融合后作为强制性的几何条件通路，避免语义捷径。

### 2.2 关键技术细节

- **因果注意力掩码**：在 VLM 自注意力中将两组查询与原多模态流隔离，使两组查询独立地从图像/文本令牌中聚合线索而不干扰原始多模态计算。
- **训练专用监督头**（约 2.3M 参数，推理时移除）：
  - 深度头 $\Phi_{Depth}$：LN(2048) → Linear(2048,256) → GELU → Dropout → 逐视角 Transformer 编码器 → 卷积解码器；
  - 语义头 $\Phi_{Seg}$：结构同上，输出 Softmax 分割 logits。
- **损失设计**：
  - 深度损失：$L_{depth} = L_{sm} + \lambda_1^d L_{rel} + \lambda_2^d L_{patch}$（smooth-L1 + 绝对相对损失 + 困难块挖掘 top-k 损失，$\lambda_1^d=0.1$, $\lambda_2^d=0.5$）；
  - 语义损失：$L_{seg} = L_{CE} + \lambda^s L_{Dice}$（$\lambda^s=0.5$）；
  - 总目标：$L = L_{act} + \lambda_1^a L_{depth} + \lambda_2^a L_{seg}$（$\lambda_1^a=0.1$, $\lambda_2^a=0.002$）。
- **训练流程**：先以同一超参对 LoRA、查询集与任务头进行热身（warm-up），再联合优化。

### 2.3 Action DiT 中的非对称注入

- 遵循 GR00T 的交替注意力结构（32 层 = 8×4 层循环），仅在图像交叉注意力层（$\ell = 4k+2$）注入两组查询：
  - **并行交叉注意力**：$N_l = CA_{VLM}(H_l, E_o')$，$S_l = CA_{Semantic}(H_l, E_s')$；
  - **门控残差融合**：$Z_l = H_l + Fuse(N_l, g_l S_l)$；
  - **空间条件交叉注意力**：$H_l' = Z_l + CA_{Spatial}(Z_l, E_d')$；
  - **FFN 输出**：$H_{l+1} = H_l' + FFN(H_l')$。

### 2.4 推理阶段

- 移除任务头，无需深度/语义标注；额外延迟仅 +1.58 ms（43.21 ms → 44.79 ms）。
