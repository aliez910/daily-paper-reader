## 摘要
视觉-语言-动作（VLA）模型已在机器人操作中展现出有效性，然而 pi0.5 等最先进的模型仍采用单帧范式，这限制了它们保留历史观测和发展精确空间感知的能力。本文提出 StreamPI——一种流式多模态时序建模框架，能够在不引入任何额外参数的情况下为单帧 VLA 赋予时序推理能力。一项核心设计是指令锚定的时序建模：它将每个（视觉观测，语言指令）对视为一个原子时序单元，对内采用双向注意力以实现跨模态融合，对间采用因果注意力以保持自回归流式推理。这确保了语言指令在整个任务执行过程中充当持续的语义锚点。为弥合同步训练与异步真实机器人部署之间的差距，我们引入了一种随机间隔的流式训练策略：合理的帧间间隔（例如每 3 帧）能够实现更快、更平滑的动作执行。在此基础上，对间隔进行随机化进一步增强了对帧时序扰动的鲁棒性，从而在实践中支持异步部署。此外，通过利用 LLM 主干的长度外推能力，StreamPI 能够无缝继承预训练的单帧权重，并支持灵活的单帧与多帧推理。在涵盖记忆依赖与精确感知场景的真实机器人任务以及仿真基准 LIBERO 上的实验表明，StreamPI 在多种任务上均优于 pi0.5。

## Abstract
Vision-Language-Action (VLA) models have demonstrated effectiveness in robot manipulation, yet state-of-the-art models such as pi0.5 operate under a single-frame paradigm, limiting their ability to retain past observations and develop precise spatial perception. In this paper, we propose StreamPI, a streaming multimodal temporal modeling framework that equips single-frame VLA with temporal reasoning capability without introducing any additional parameters. One core design is instruction-anchored temporal modeling. It treats each (visual observation, language instruction) pair as an atomic temporal unit: bidirectional attention within each pair enables cross-modal fusion, while causal attention across pairs preserves autoregressive streaming inference. This ensures the language instruction serves as a persistent semantic anchor throughout task execution. To bridge the gap between synchronous training and asynchronous real-robot deployment, we introduce a andom-interval streaming training strategy: a proper inter-frame interval (e.g., every 3 frames) enables faster and smoother action execution. Beyond this, randomizing the interval further improves robustness to frame-timing perturbations, supporting asynchronous deployment in practice. Furthermore, by leveraging the length extrapolation capability of the LLM backbone, StreamPI seamlessly inherits pretrained single-frame weights and supports flexible single-frame and multi-frame inference. Experiments on real-robot tasks spanning memory-dependent and precise perception scenarios, as well as the simulation benchmark LIBERO, demonstrate that StreamPI outperforms pi0.5 across diverse tasks.

# StreamPI 论文总结

## 1. 核心问题与整体含义（研究动机与背景）

- **单帧范式的固有限制**：当前最先进的 VLA 模型（如 π0、π0.5）仅依赖单帧观测进行动作预测，缺乏对历史观测的记忆能力，导致两类关键能力缺失：
  - **记忆能力**：无法处理"杯子藏物（Shell Game）""滚动物体抓取"等需要跨帧上下文的任务；
  - **精确空间感知**：单帧缺少运动视差与多视角几何线索，难以完成"细瓶插笔""杯子套筒"等亚厘米级精度的操作。
- **现有方案的瓶颈**：
  1. **计算开销爆炸**：将多帧图像沿时间维拼接使序列长度线性增长，无法满足实时控制；
  2. **指令遗忘（Instruction Forgetting）**：语言指令以固定文本 token 注入，随视觉 token 累积而逐渐被稀释；
  3. **训练-部署不匹配**：训练采用固定间隔采样，真实机器人部署却是异步、可变帧率；
  4. **表征破坏**：引入额外的视频编码器会引入参数分布偏移，可能损害 VLA 主干已学到的视觉-语言特征。
- **研究目标**：在不引入任何新增参数的前提下，为单帧 VLA 模型（如 π0.5）赋予流式时序推理能力，兼顾效率、鲁棒性与表征完整性。

## 2. 方法论

### 2.1 核心思想
将每个 **(视觉观测 Vₜ, 语言指令 l)** 对定义为"原子时序单元 uₜ"，通过双层注意力结构（单元内双向 + 单元间因果）实现指令锚定的时序建模，并借助 LLM 主干的长度外推能力无缝继承 π0.5 预训练权重。

### 2.2 关键技术细节
- **指令锚定的时序单元**：
  $$u_t = (V_t, l_t)$$
  序列构造：$U = [u_{t-T+1}, u_{t-T+2}, \dots, u_t]$
- **单元内双向注意力**（Intra-pair）：
  $$h_\tau = \text{Attn}_{\text{bi}}(V_\tau, l_\tau)$$
  保证每个时间步内部多视角视觉与语言指令的充分跨模态融合。
- **单元间因果注意力**（Inter-pair）：
  $$o_t = \text{Attn}_{\text{causal}}(h_{t-T+1}, \dots, h_t)$$
  维持自回归结构，防止未来帧信息泄露。
- **零参数扩展**：仅通过重构注意力掩码（block-wise causal mask）+ 扩展位置编码实现多帧推理，不新增任何参数。
- **KV 缓存流式推理**：每时刻仅编码当前帧 $u_{t_n}$，通过 cross-attention 复用缓存的 $\{(h_{t_0}, \dots, h_{t_{n-1}})\}$，避免重复计算。
- **随机间隔流式训练**：
  - 基础间隔 $\bar{\delta}$ 上叠加扰动 $\epsilon \sim \mathcal{U}(-\Delta, +\Delta)$，截断至 $[\delta_{\min}, \delta_{\max}]$；
  - **时间掩码（Temporal Masking）**：随机丢弃最早 k 帧以模拟流式推理的增量观测模式。
- **算法伪代码**（Algorithm 1）：初始化空缓存 → 循环编码当前帧 → 缓存满则刷新 → 更新 KV-Cache → 预测动作块并下发。

## 3. 实验设计

### 3.1 数据集与基准
- **LIBERO 仿真基准**：四个子套件——Spatial、Object、Goal、Long，每套 10 个任务、每任务 50 次试验；
- **CALVIN 基准**：评估长达 5 步连续子任务的长程时序推理能力；
- **真实机器人任务**（AgileX PiperX 6-DoF 双臂 + 3 个 RealSense 相机）：
  - **记忆依赖类**：Shell Game（15 种模式）、Rolling Object Grasping（30 次试验）；
  - **精确感知类**：Pen Insertion into Narrow Bottle（30 次试验）、Cup Insertion into Cup Sleeve（25 次试验）。
  - 每任务 100 条人类遥操演示（30 FPS）。

### 3.2 对比方法
- **基线**：π0.5（单帧 VLA）；
- **LIBERO 上对比**：Diffusion Policy、Octo、SpatialVLA、TraceVLA、OpenVLA、CoT-VLA、π0-FAST、SmolVLA、GR00T-N1、UniVLA、FLOWER、CronusVLA、TriVLA、4D-VLA、CogACT、ST-π、MemoryVLA、π0、π0.5 等 17 种方法；
- **CALVIN 上对比**：π0.5、MemoryVLA。

### 3.3 消融研究
- **注意力方向消融**：单元内（双向 vs 因果）× 单元间（固定因果）× 不同 T（1/3/5）；
- **随机间隔训练消融**：固定 δ=1 vs 随机 δ~U[3,7]，测试 δ ∈ {1,3,5}；
- **跨流长度泛化**：T=5 训练的模型在 T ∈ {1,3,5} 下的表现。

## 6. 主要结论与发现

- **真实机器人任务**（vs π0.5）：
  - Rolling Object Grasping：26.7% → 63.3%（+36.6%）；
  - Shell Game：46.7% → 80.0%（+33.3%）；
  - Pen Insertion：40.0% → 66.7%（+26.7%）；
  - Cup Insertion into Sleeve：60.0% → 92.0%（+32.0%）。
- **LIBERO**：平均成功率 96.9% → 98.3%（T=5），LIBERO-Long 提升最显著（92.4% → 95.0%）；
- **CALVIN**：平均序列长度 4.313（π0.5）→ 4.547，第 5 步成功率 79.5% → 85.0%，显著优于 MemoryVLA（4.090，第 5 步 69.4%）；
- **零参数特性**：通过注意力掩码重构 + 长度外推即可获得时序能力，完整保留预训练表征；
- **指令锚定重要性**：单元内双向注意力相比因果注意力在 LIBERO-Long（T=5）上带来 +4.5% 提升；
- **随机间隔训练有效性**：相比固定间隔 δ=1，平均成功率提升 1.1~1.3%。

## 7. 优点

- **零参数增量**：仅通过注意力掩码重构和位置编码扩展即可将单帧 VLA 升级为时序 VLA，不引入新参数，保留预训练表征完整性；
- **指令锚定设计**：从根本上解决了长程任务中的"指令遗忘"问题，是相比 CronusVLA、MemoryVLA 等的关键差异；
- **KV 缓存流式推理**：T=5 时仅比单帧慢 9.2 ms（103.6 vs 94.4 ms），计算开销近常数；
- **随机间隔训练**：直接对真实部署中异步、可变帧率场景进行针对性增强；
- **任务全面性**：同时覆盖记忆依赖与精确感知两类互补任务类型，验证方法的通用性；
- **可视化分析充分**：提供 8 张连续帧对比图，直观展示 π0.5 在空间错位、动作时序判断、动态预测等方面的失败模式。

## 8. 不足与局限

- **训练成本**：长时域（>100 帧）训练需加载全部历史帧，显存与计算开销将不可接受；
- **异步鲁棒性有限**：随机间隔训练在"极端异步"（如丢帧、突发大间隔）场景下效果未充分验证；
- **实验覆盖偏差**：
  - 真实机器人仅采用 6-DoF 双臂 + 3 相机配置，未涵盖移动底盘、灵巧手等异构平台；
  - 每个真实任务仅 100 条演示，可能限制策略泛化性；
  - LIBERO 套件接近饱和，增量空间有限，对方法差异的敏感性下降；
- **OOD 安全性**：论文在 Broader Impacts 中自承未充分评估 OOD 场景下的安全风险；
- **应用限制**：依赖 π0.5 的 LLM 主干长度外推能力，迁移到非 LLM 主干 VLA（如基于纯 ViT 的轻量模型）时需额外设计；
- **训练-部署间隔不一致**：训练时 δ~U[3,7]，真实部署也采样此分布，但仿真推理固定 δ=5，可能引入轻微评估偏差。
