## Abstract
Vision-language-action (VLA) models have become a dominant paradigm for generalist embodied agents, demonstrating strong complex and long-horizon task completion in structured settings. Yet it remains an open question whether current VLA systems can benefit from more effective architectural design, scale to substantially larger and more heterogeneous data regimes, and achieve broader generalization across tasks and embodiments. To this end, we present GigaBrain-0.7, an embodied foundation model with substantially improved generalization across diverse robot embodiments. Specifically, GigaBrain-0.7 unifies understanding, prediction, and action through a three-system architecture, scales pretraining to over 37,000 hours of heterogeneous embodied data, and introduces one-stage alignment training that jointly optimizes vision-language understanding and multi-embodiment action generation. Compared with the preceding GigaBrain-0 series and prior state-of-the-art models including $π_{0.5}$, GigaBrain-0.7 achieves substantial improvements in foundation zero-shot capabilities, language-conditioned instruction following, and post-training task success rates. In particular, on our in-house Maker H01 platform and mainstream robot embodiments, GigaBrain-0.7 demonstrates strong task adaptability and completion ability across both home and industrial scenarios. All training code and pretrained model weights will be released.

## 一、核心问题与研究动机

- **背景**：视觉-语言-动作（VLA）模型已成为通用具身智能体的主流范式，能够在结构化环境中完成复杂长视野任务。然而当前 VLA 系统仍面临三大开放问题：
  1. 架构设计是否足够有效，能否支持"理解—预测—动作—持续改进"全链路协同；
  2. 数据能否扩展到更大规模与更异构形态（多自由度、多硬件、多种演示形式）；
  3. 能否在任务与本体（embodiment）层面实现更广泛的泛化。
- **关键挑战**：机器人数据在不同本体、动作空间与执行条件下差异巨大，若缺乏合适的对齐与上下文建模，更大的数据多样性反而可能引入干扰而非可迁移知识；现有 VLA 多局限于反应式"观察→动作"映射，缺乏对未来的预测与行为进度的评估。
- **目标**：构建一种统一的具身基础模型系统，在异构数据规模下协调理解、预测、动作与经验驱动改进，实现跨本体、跨场景的涌现能力。

## 二、方法论：核心思想、关键技术与算法流程

### 1. 总体思路：三系统架构

- **System 1（动作与控制）**：基于 PaliGemma2（3B）+ Action Expert（0.5B）的 VLA 模型，通过流匹配（Flow Matching, FM）生成连续动作块，同时支持基于 NTP 的离散动作通路。
- **System 2（理解与规划）**：PaliGemma2（3B）视觉语言模型，接收当前视觉与语言指令，输出思维链（CoT）推理与子任务分解。
- **System 3（预测与评估）**：基于 GigaWorld-1 的世界价值模型（5B），预测未来视觉子目标图像并输出任务进度价值估计 $V_t$，推导二元优势条件 $A_t \in \{0,1\}$。
- **交互机制**：三系统通过语义、视觉与价值三种结构化接口通信，保持各自专精目标的同时协同工作。

### 2. 关键技术细节

- **单阶段对齐预训练**：在同一训练阶段联合优化视觉-语言理解、分层任务预测、离散动作与连续动作生成（$\mathcal{L}_{VLA} = \mathcal{L}_{NTP} + \mathcal{L}_{FM}$），避免多阶段训练的优化碎片化。
- **Soft Knowledge Insulation（Soft KI）**：FM 梯度进入 VLM 主干时按系数 $\alpha_{KI} \in (0,1)$ 衰减，既允许适应具身控制又保留通用视觉语言能力。
- **Mixture-of-Transformers（MoT）架构**：VLM 与 Action Expert 共享联合注意力但保持独立 FFN；VL 流采用因果自注意力，Action Expert 双向关注 VLM+自身的拼接上下文。
- **时空块（Temporal-Spatial Blocks）**：在视觉编码器中先做时序聚合再做空间融合，仅向主干传递当前帧富集后的 token，控制上下文长度。
- **本体感知状态接口**：通过 Robot ID + 元素级有效性掩码的投影模块处理不同本体的状态维度差异；主 Action Expert 参数跨本体共享，仅本体相关的输入/输出投影独立。
- **旋转表示**：全程采用连续 6D 旋转格式。
- **分层任务监督**：每条轨迹同时携带任务级指令 $\ell$ 与子任务指令 $\hat{\ell}_t$，混合"两指令均提供"与"仅任务级指令"两种监督模式。

### 3. 世界模型驱动的后训练

- **System 3 冻结**，向 System 1 提供子目标图像 $g_t$ 与优势条件 $A_t$。
- **条件丢弃**：子目标图与价值条件分别以 0.50 与 0.15 的概率丢弃，暴露四种条件组合。
- **推理时**：仅使用正向进度条件引导动作生成，不做候选动作打分或选择。

### 4. 经验驱动强化学习（三阶段）

- **离线阶段**：通过真实机器人回滚收集成功/失败/修正片段，使用 AWR 形式的优势加权回归优化策略。
- **在线阶段**：采用 Actor-Critic 框架，由人工干预在困难状态下提供修正示范，结合分块进度差与终局稀疏信号作为奖励。
- **持续迭代**：形成"回滚 → 修正 → 更新"闭环，可在部署中反复运行。

- **基准测试**：MiMo-Embodied 13 子基准；RoboTwin 2.0 Co-Train 协议；EBench；RoboColiseum 4 维度。
- **经验驱动 RL**：4 个真实机器人任务 × 3 阶段（SFT / Offline RL / Online RL）。

### 客观性与公平性评估

- **优势**：
  - 评测设置跨真实机器人、仿真、VLM 三个维度，覆盖全面；
  - 提供 ID 与 OOD 双重评估；
  - 与多代基线（$\pi$ 系列、GigaBrain 系列、Xiaomi、Galaxea 等）对比，引用文献充分；
  - 附录公开了完整的 leaderboard 快照及 URL 与访问日期，提升可复现性。
- **不足**：
  - 部分对比在某些任务上不完整（标"–"或仅部分基线），导致均值仅在完整评估上计算，可能引入选择性偏差；
  - OOD 设置由作者自行设计，缺少对 OOD 难度的客观度量；

  - 经验驱动 RL 仅有 4 个任务，且全部达到 100% 成功率，可能存在任务过易或评测次数不足的问题。

## 六、主要结论与发现

- **零样本能力**：经过异构数据预训练后，同一 GigaBrain-0.7 策略在 PiPER 与 Maker H01 上无需任务特定适应即可执行多任务语言跟随与复杂操作，展现跨本体泛化能力。
- **后训练性能**：在 6 类语言跟随任务上，PiPER 平均成功率 91.5%，H01 平均 84.2%，均超过 $\pi_{0.5}$ 与 GigaBrain-0.1；在复杂操作上 PiPER 84.9%、H01 74.1%，相对 $\pi_{0.5}$ 提升 8–30 个百分点。
- **基准测试领先**：RoboTwin 2.0 Co-Train 协议下 Hard 设置 67.9% 排名第一；EBench SR 33.30% / Score 46.1 居公开 VLA 模型之首；RoboColiseum 四项能力维度均领先开源模型。
- **缩放规律**：机器人数据规模与组合多样性均带来持续收益，复杂可形变任务对数据规模更敏感，验证了"涌现能力"假说。
- **三系统价值**：System 3 的子目标图像与价值条件在任务接近饱和时仍能提升平均得分与缩短完成时间，且在难任务（如 Gift Wrapping）上从 0% 提升至 80%。
- **经验驱动 RL**：4 个真实任务 SFT→Offline→Online 三个阶段的平均成功率由 30.0% → 57.5% → 100%，证明在线人类修正对精度关键任务尤为有效。

## 七、优点与亮点

- **三系统架构设计**：把"理解—预测—动作—评估"解耦到三个独立但可通信的子系统，分工清晰且保留各自专精目标。
- **单阶段对齐预训练**：避免多阶段训练常见的优化碎片化与灾难性遗忘问题，联合优化 NTP 与 FM 两个动作通路。
- **Soft KI 改进**：相比 $\pi_0$ 的硬性 KI，软性梯度衰减更平衡通用视觉语言能力与具身控制适应。
- **海量异构数据**：37K 小时具身数据 + 2.72 亿 VLM 样本，覆盖 16 种机器人本体与多种演示形式（真实、UMI、EGO、仿真、世界模型生成）。
- **统一本体表征**：通过 Robot ID 与维度掩码实现单一策略跨本体共享。
- **世界模型作为可扩展数据引擎与策略条件**：System 3 既能生成训练数据，又能为策略提供预测与价值条件，扮演双重角色。
- **经验闭环**：离线 AWR + 在线 Actor-Critic + 人类修正形成完整的 rollout-correction-update 闭环，且全程使用同一 System 1 部署策略，不引入独立控制器。
- **评测全面**：跨真实机器人、仿真、VLM 基准、ID/OOD、缩放消融、组件消融六大维度系统评估。

## 八、不足与局限

- **算力披露缺失**：未给出 GPU 型号、数量或训练时长，外部难以估算训练成本与可复现性。
- **OOD 仍存在差距**：在跨物体实例 + 跨场景 + 跨任务组合的多重分布偏移下，GigaBrain-0.7 性能明显下降，表明对真实世界长尾分布的鲁棒性仍有限。
- **接触丰富任务未饱和**：在 PiPER 扫米（40%）、H01 多项复杂操作上成功率偏低，说明精细物理交互仍是开放问题。
- **任务设计主观性**：OOD 设置由作者自行定义，缺乏对 OOD 难度的标准化度量；语言跟随任务由团队设计，可能引入数据集偏差。
- **基线评估不完全**：部分表格中基线数据不完整（仅有部分任务的报告），影响跨模型比较的公平性。
- **依赖冻结世界模型**：System 3 冻结后只在训练时使用，推理时不显式生成视频，可能在需要持续想象的场景下受限。
- **安全与伦理讨论缺失**：未讨论大规模人类示范数据与真实机器人部署中的安全、隐私、滥用风险。
- **开源程度声明**：虽承诺开源代码与权重，但论文未给出具体的发布计划与许可细节。
