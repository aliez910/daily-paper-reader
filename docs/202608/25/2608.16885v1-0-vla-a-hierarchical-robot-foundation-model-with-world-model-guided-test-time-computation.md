## 摘要
长时序机器人操控要求机器人既能可靠地执行各项单一技能，又能在长任务中将它们连贯地串联起来。现有的大多数分层视觉-语言-动作（VLA）模型仅通过单次前向传播做出决策，缺乏将额外算力分配给困难或重要决策的机制。我们提出了 τ₀-VLA，一种分层机器人基础模型，它通过世界模型引导的测试时计算，将高层子任务生成建模为一个可扩展计算量的推理问题。在每一次推理步骤中，高层策略利用执行记忆生成一个子任务，并在需要时对多个备选方案进行搜索，再确认其输出。低层策略随后在多种机器人本体上执行所生成的子任务。该策略使用 40,115 小时的多模态协同训练异构真实世界数据进行训练。在域内与分布偏移的设定下，分配额外的测试时计算量显著提升了下一子任务预测准确率，且这些增益进一步转化为长时序机器人操控任务上更高的闭环成功率。

## Abstract
Long-horizon robot manipulation requires a robot to both execute individual skills reliably and sequence them coherently over extended tasks. Most hierarchical vision-language-action (VLA) models make each such decision with a single forward pass, leaving no mechanism to allocate additional computation to difficult or consequential choices. We introduce $τ_0$-VLA, a hierarchical robot foundation model that formulates high-level subtask generation as a compute-scalable inference problem through world-model-guided test-time computation. At each inference step, the high-level policy uses execution memory to generate a subtask and, when needed, searches over alternatives before committing to its output. A low-level policy then executes the generated subtask across multiple robot embodiments. The policy is trained on 40,115 hours of heterogeneous real-world data with multimodal co-training. Across in-domain and distribution-shifted settings, allocating additional test-time computation substantially improves next-subtask prediction accuracy, and these gains translate into higher closed-loop success on long-horizon robot manipulation tasks.

# τ₀-VLA 论文总结

## 1. 核心问题与研究动机

- **核心问题**：长时序机器人操控任务（如清洁房间、做饭、做奶茶）需要在分钟到小时尺度内连贯地串联多个子任务，机器人既要可靠执行单一技能，又要正确判断"接下来该做什么"。
- **关键瓶颈**：现有分层视觉-语言-动作（VLA）模型在高层决策时**仅做一次前向传播**便直接输出下一子任务，无法为困难或关键的决策分配额外算力。一旦高层选错子任务，再精准的低层控制也无法挽回——"执行错的任务执行得越完美，反而越糟"。
- **研究假设**：作者将"生成下一子任务"重新定位为**可扩展计算量的推理问题（test-time computation, TTC）**，借鉴 LLM 中测试时计算（如 DeepSeek-R1、o1）扩展思路，让高层策略根据决策难度自适应地"多想几步"。

## 2. 方法论

### 2.1 系统总体架构
- **分层结构**：高层策略（μ）生成子任务 z*_t → 低层策略 π_θ 根据子任务生成动作块 a_{t:t+H-1} → 执行后真实观测反馈回高层形成闭环。
- **高层策略四组件**：
  - **提案模型 P（Qwen3.5-9B）**：基于当前观测、任务指令、执行记忆 M_{t-1}、已生成子任务 z*_{t-1}，给出直接提议 z^dir_t 并更新执行记忆为 M_t。
  - **世界模型 W（Step1X-Edit 初始化）**：输入头相机 RGB 与候选子任务，预测执行该子任务后的**终端头相机图像** ô。
  - **价值模型 V**：将 (任务指令, 候选子任务, 预测终端图像) 映射为 5 级 ordinal 质量分数 ∈ [0.05, 0.95]。
  - **反思模型 F**：基于观测对齐上下文与保留分支摘要生成最终子任务，可与提议重合但不受候选集约束。

### 2.2 测试时计算（TTC）流程
- **自适应路由**：基于提案模型的 token 平均概率与 logit margin 计算 g_t ∈ {0,1}；g_t=0 走快速路径直接采纳 z^dir_t，g_t=1 启动搜索。
- **Beam Search（Algorithm 1）**：
  - 初始化根分支 b_root（上下文为 h_t）。
  - 每层 d ∈ {1,...,D}：对每个保留分支独立采样 N 个候选子任务 → 世界模型预测终端图像 → 价值模型打分 → 全局累积得分排序 → 保留 top-B 分支。
  - 深度 D、宽度 B、分支因子 N 控制计算预算。
- **关键设计**：
  - 每次扩展使用**该分支的预测图像**（而非真实观测）作为下一轮的视觉输入，递归形成"想象—评估"链。
  - 搜索过程中的记忆为**分支局部**，永不覆盖持久执行记忆 M_t。

### 2.3 执行记忆与自纠错训练
- 记忆机制通过自动数据构造支持**自纠错**：扰动输入记忆（滞后、超前、错误表示），训练高层策略读取正确的目标。覆盖五种实例族：within-subtask、transition、catch-up、rollback、error-think，无需额外人工标注。
- **数据构造管线**：用 google/Gemma4-31B-it 作为标注器生成 `<think>` / `<memory>` / `<subtask>` 三段式标注，并设置跨任务污染过滤、空子任务检测、记忆污染过滤等多层质量控制。

### 2.4 低层策略（VLA）
- **结构**：Qwen3.5-2B 视觉-语言骨干 + Mixture-of-Transformers (MoT) 动作专家，通过全注意力层跨流交互。
- **统一动作空间**：40 维（双臂末端位姿 6D+6D、左右夹爪、腰部、平面底盘速度、双臂各 8 关节），通过掩码支持固定基座、双臂、移动整身三种形态。
- **掩码流匹配（Masked Flow Matching）**：在统一动作空间下只对活跃通道计算损失与采样；使用 reverse-time reparameterization；动作 horizon H=30，10 步 Euler 积分。
- **三阶段训练**：① 知识隔离协同训练 → ② 端到端协同训练 → ③ 任务级微调。

### 2.5 异步双系统部署
- 高层子任务生成与低层动作生成**异步流水线**：后台 worker 约每 1 秒刷新缓存的子任务，控制循环以 ~30 Hz 读取缓存的子任务立即输出动作块；高层慢决策只延迟下一次指令刷新，不阻塞低层执行。
