## 摘要
现代视觉-语言-动作（VLA）策略已习得广泛的操控技能，但其通常仅依据当前观测或一段短而固定长度的历史来生成每个动作片段。然而，现实世界的操控任务往往是非马尔可夫的，要求机器人保留并推理来自长时程交互历史中的任务相关信息，以决定下一步动作。为应对这一挑战，我们提出了 HyMeS——一种混合学习框架，利用编码智能体的推理与记忆管理能力，来引导马尔可夫型 VLA 完成记忆依赖型操控任务。具体而言，HyMeS 通过基于梯度的模仿学习习得底层运动技能，而编码智能体则通过启发式学习获得高层记忆管理策略——根据 rollout 反馈迭代更新可执行的启发式系统。此外，我们通过多模态阶段完成验证来闭合引导与执行之间的回路，利用本体感受信号和多帧 VLM 判别结果更新记忆。与端到端的记忆增强型 VLA 相比，HyMeS 仅需对可复用的运动技能提供演示，而无需为每一种历史依赖型的任务配置分别提供演示，从而实现数据高效的可组合泛化。在 RoboMemArena 上，相较于 pi0.5，HyMeS 将平均累积成功率从 52.5% 提升至 66.2%，平均任务成功率从 41.3% 提升至 60.1%；同时在累积成功率上超越 PrediMem 4.5 个百分点，在任务成功率上领先 14.5 个百分点。

## Abstract
Modern vision-language-action (VLA) policies have acquired broad manipulation skills, but typically generate each action chunk from the current observation or a short fixed-length history. However, real-world manipulation is often non-Markovian, requiring robots to retain and reason over task-relevant information from long-horizon interaction histories to determine the next action. To address this challenge, we propose HyMeS, a hybrid learning framework that leverages the reasoning and memory-management capabilities of coding agents to steer a Markovian VLA for memory-dependent manipulation. Specifically, HyMeS learns low-level motor skills through gradient-based imitation learning, while a coding agent acquires high-level memory-management strategies through heuristic learning by iteratively updating an executable heuristic system from rollout feedback. Furthermore, we close the loop between steering and execution through multimodal stage-completion verification, which updates memory using proprioceptive signals and multi-frame VLM judgments. Compared with end-to-end memory-augmented VLAs, HyMeS requires demonstrations only for reusable motor skills rather than for every history-dependent task configuration, enabling data-efficient compositional generalization. On RoboMemArena, HyMeS improves mean cumulative success from 52.5% to 66.2% and mean task success from 41.3% to 60.1% over pi0.5, while outperforming PrediMem by 4.5 points in cumulative success and 14.5 points in task success.

# 论文总结：Skills in Weights, Memory in Code（HyMeS）

## 一、核心问题与研究动机

- **问题背景**：现代视觉-语言-动作（VLA）策略（如 π0.5、π0.6）已具备广泛的操控能力，但本质上仍是**马尔可夫型**的——仅依据当前观测或一段短而固定长度的历史生成动作 chunk。
- **核心矛盾**：真实机器人操作常常是**非马尔可夫**的，例如"按卡片上数字按下按钮几次"这类任务，所需的提示信息在初始观测后即消失，只有靠长程历史才能正确决策（动作观测出现别名化/歧义）。
- **现有方案的不足**：现有记忆增强型 VLA 通过扩大上下文、加入记忆模块或历史 token，将记忆逻辑与运动技能**端到端**联合训练。但这要求演示数据覆盖**组合爆炸式**的记忆配置，样本效率低，且记忆逻辑无法显式读取或编辑。
- **本文目标**：将"运动技能"与"记忆管理"分别在不同表征空间中学习，从而实现数据高效的可组合泛化。

## 二、方法论

### 1. 整体框架：HyMeS = 权重空间 + 代码空间

- **权重空间（Weight Space）**：VLA（如 π0.5）通过基于梯度的流匹配模仿学习，仅学习**可复用运动技能**；训练完成后**冻结权重**，不参与记忆相关更新。
- **代码空间（Code Space）**：由编码智能体（如 Claude Code / Codex）维护一个**可执行启发式程序** $P = (C, V, U)$，包含约束选择规则、事件验证规则与记忆更新规则；通过 rollout 反馈迭代修订，而非梯度下降。
- **核心问题形式化**（公式 1）：$\pi^*(a_t|h_t,\ell) = \pi^*(a_t|o_t, z_t, \ell)$，其中 $z_t = \phi(h_t)$ 是紧凑任务状态，无法从单帧 $o_t$ 恢复。

### 2. 运动技能学习（权重空间）

- 用流匹配目标（公式 6-7）从专家演示 $D$ 微调 VLA 速度场 $v_\theta$。
- 微调后参数 $\theta^*$ 固定，记忆获取过程**不更新权重**。

### 3. 记忆策略学习（代码空间）

- 符号记忆状态 $s_t = (\text{plan}, \rho_t, B_t, N_t, F_t)$，由可执行规则直接维护。
- 给定候选程序 $P^{(n)}$，运行后生成符号轨迹 $\xi_n$ 与阶段评判 $b_n$；编码智能体对比二者定位失败阶段，诊断约束奖励或验证规则是否不当，修订产生 $P^{(n+1)}$（公式 10）。
- 选择开发集上最佳的程序 $P^*$，**评估时冻结**。

### 4. 记忆条件下的动作引导（Steering）

- 当前阶段 $\rho_t$ 与符号记忆 $s_t$ 选定可微约束 $R_{\rho_t}(a, o_t; s_t)$，例如 Endpoint 距离奖励（公式 11）。
- 将约束梯度注入流匹配速度场（公式 12）：
  $$\hat{v} = v_{\theta^*}(a^\tau, \tau | o_t, \ell) + \lambda_t \nabla_{a^\tau} R_{\rho_t}(a^\tau, o_t; s_t)$$
- 引导强度 $\lambda_t$（公式 13）随约束残差 $p_t$ 衰减，避免在接触阶段过度干扰运动策略。

### 5. 多模态阶段完成验证（PACE）

- **本体感受证据**：检测动作依赖的运动模式，使用符号锁存器保存持续事件。
- **视觉证据**：Qwen3-VL-8B 基于当前阶段与最近最多 5 帧 RGB 判断完成情况。
- 两个证据取 OR（公式 14）后，**在最近 w=5 次查询中至少 k=3 次通过**才触发阶段切换（公式 15），抑制偶发错误。
- 一旦切换，由 $U$ 更新记忆绑定、计数与持久状态，进入下一阶段约束。

## 六、主要结论与发现

- 仿真整体：**CSR 52.5% → 66.2%，TSR 41.3% → 60.1%**（vs. π0.5）；**CSR +4.5、TSR +14.5**（vs. PrediMem）。

## 七、优点与亮点

- **清晰的范式分离**：将"运动技能 vs. 记忆策略"分别置于权重空间与代码空间，物理意义清晰。
- **数据高效**：演示预算与可复用运动技能数量挂钩，而非与历史依赖组合数量挂钩。
- **可解释性**：符号记忆 $s_t$ 在每一步都可读，便于失败定位（论文将其细分为记忆更新失败、运动执行失败、事件验证失败三类）。
- **双向耦合**：相比 VLS 等单向引导，HyMeS 通过 PACE 将执行反馈读回用于记忆更新。
- **冻结策略权重**：新记忆配置可通过编辑代码实现，无需重新采集演示。
- **仿真和真实平台双向验证**，且严格控制变量。

## 八、不足与局限

- **记忆表征受限**：仅适用于可被紧凑符号状态描述的任务，对开放式、连续视觉/语言记忆未覆盖。
- **失败根源并未消除**：正确记忆 + 正确约束 ≠ 接触成功；瞄准偏差、抖动导致的额外按压、按压深度不足等仍造成失败（如图 4）。
- **遮挡场景仍弱**：视觉完成证据在目标隐藏时最不可靠，遮挡类任务 CSR 与基线持平。
- **延迟与成本**：周期性 VLM 查询与编码智能体调用的推理延迟与计算开销未量化，仅在结论中提及。
- **episode 规模有限**：每任务 10–20 条 episode，统计置信区间未给出。
- **开发阶段依赖闭源 LLM**（Opus 4.8），可复现性受限。
- **计数类任务早期阶段失败**：作者自陈这些失败可能源于冻结 VLA 自身或引导干扰，并非记忆逻辑问题，但未深入分析。
- **无理论与收敛性保证**：启发式程序通过工程迭代修订，缺乏形式化保证。
