## 摘要
为了在多样化情境中有效运作，机器人不仅需要准确完成操作任务，还需使其动作的执行方式适应任务、物体与交互场景。我们探讨这种执行层面的变化能否作为一种可复用的行为因素在任务间共享。我们提出了 MoMo，一个由两阶段组成的模仿学习框架：第一阶段为时空动作分词器，第二阶段为行为克隆 Transformer，它以任务与连续的运动模式条件作为输入。在六个真实机器人操作任务中，改变该条件可产生稳定型、动态型以及介于两者之间的行为，人类的评分者能够予以区分，且这些行为在关节速度、加速度以及末端执行器接近俯仰角方面均存在差异。在仅以单一模式演示的任务上，MoMo 能够在保持任务成功率的同时，将所请求的未见模式迁移到任务执行中。综上所述，这些结果为对未见过的任务-模式组合的组合泛化提供了证据，并表明运动模式可在任务间复用，从而控制操作技能的执行方式。

## Abstract
To operate effectively across diverse contexts, robots must not only perform manipulation tasks accurately but also adapt how their actions unfold to the task, object, and interaction setting. We ask whether this execution-level variation can be learned as a reusable behavioral factor shared across tasks. We present \textbf{MoMo}, a two-stage imitation-learning framework consisting of a spatiotemporal action tokenizer and a behavior-cloning transformer that takes task and a continuous motion-mode condition as inputs. Across six real-robot manipulation tasks, varying this condition produces steady, dynamic, and intermediate behaviors that human raters can distinguish and that differ in joint speed, acceleration, and end-effector approach pitch. On tasks demonstrated in only one mode, MoMo transfers the unseen requested mode while largely preserving task success. Together, these results provide evidence of compositional generalization to unseen task--mode combinations and show that motion mode can be reused across tasks to control how a manipulation skill is performed.

## 一、核心问题与研究背景

- **研究问题**：机器人在多样化情境中执行操作任务时，不仅要保证任务完成（"做什么"），还需要根据任务、物体和交互情境调整动作的执行方式（"怎么做"）。这种执行层面的变化能否被抽象为一种**跨任务可复用的行为因子（behavioral factor）**，从而避免每个任务都重新学习一遍相同的行为风格？
- **核心概念——运动模式（motion mode）**：被定义为一种**与任务无关的行为调制因子**，用于调控操作执行的"质量维度"（节奏、平滑度、犹豫、加速度、末端执行器朝向等），而非定义任务本身。它不是技能原语，也不是任务标签。
- **现有方法的不足**：当前大多数风格/行为条件化的操作策略将行为与任务联合学习，要将某种行为扩展到新任务必须重新采集该任务下的演示数据，导致行为无法成为跨任务的复用因子。
- **本文的视角**：借鉴动作分词（action tokenization）与动画角色中的解耦运动表示，提出在学习的动作 token 空间中，将运动模式表示、控制并跨任务复用。

## 二、方法论

### 2.1 总体框架：两阶段模仿学习

- **阶段一（Stage 1）**：训练**时空动作分词器（Spatiotemporal Action Tokenizer）**，将每个 2 秒的动作块编码为空间码流与时间码流两组离散码。
- **阶段二（Stage 2）**：冻结阶段一权重，训练一个**行为克隆 Transformer**，根据视觉观测、本体感知、任务标识与连续运动模式标量 $s \in [0, 1]$ 预测阶段一的码索引，再通过冻结的分词器解码为动作块。

### 2.2 阶段一：时空动作分词器

- **空间分支（spatial encoder）**：
  - 输入为原始关节空间轨迹 $a \in \mathbb{R}^{100 \times 7}$（绝对关节位置）。
  - 采用 1D 卷积堆栈，5× 时间下采样得到 $K=20$ 个时间位置、$D=256$ 维的潜变量 $z_{\text{sp}}$。
  - 自然捕获路径几何、接触与末端目标。

- **时间分支（temporal encoder）**：
  - 先计算关节增量 $\Delta q_t = q_{t+1} - q_t$，再做 **DCT-II 变换**，保留前 $C=16$ 个低频系数。
  - 通过 2 层 MLP 投影到与空间分支对齐的 $K \times D$ 潜变量 $z_{\text{te}}$。
  - 由于只输入速度/加速度的时频结构，自然捕获节奏、平滑度等动力学信息。

- **残差向量量化（RVQ）**：
  - 两个分支分别经过独立 RVQ 堆栈：空间 $L_{\text{sp}}=4$ 层，码本尺寸 $[64, 512, 512, 512]$（第一层小码本作为内容瓶颈）；时间 $L_{\text{te}}=4$ 层，码本尺寸 $256$。
  - 码本采用 EMA 更新，更新延迟到优化器更新后，以让对比梯度能通过残差链回传到码本。

- **融合与解码**：
  - 两个量化流拼接后通过融合 MLP：$z_q = \text{LayerNorm}(\text{GELU}(W_f [z_q^{\text{sp}}; z_q^{\text{te}}]))$，再由 1D 上采样解码器重建动作块 $\hat{a} = \psi(z_q)$。
  - 时间量化流上还接一个辅助 DCT 预测头，确保时间码保留频域结构。

- **训练损失（7 项）**：
  - $L = L_{\text{recon}} + \lambda_{\text{DCT}} L_{\text{DCT}} + \lambda_{\text{swap-task}} L_{\text{swap-task}} + \lambda_{\text{swap-mode}} L_{\text{swap-mode}} + \lambda_{\text{con}} L_{\text{con}} + \lambda_{\text{MI}} L_{\text{MI}} + L_{\text{commit}}$
  - 重建损失（L1）+ DCT 监督
  - **交换损失（swap loss）**：将基础块的空间码与同任务相反模式供体的时码组合解码，分别要求逼近基础路径与供体的频域内容
  - **对比损失**：时间码上的残差对比学习，使更深码本层对齐运动模式
  - **对抗互信息损失（adversarial MI）**：惩罚空间潜变量中关于运动模式的信息
  - 提交损失（commitment loss）

### 2.3 阶段二：行为克隆 Transformer

- **输入**：前视与腕部相机（ResNet-34 提取特征）、当前本体感知、任务标识嵌入、连续运动模式标量 $s \in [0,1]$ 的嵌入。
- **输出**：
  - 每个码本层、每个时间位置上的码索引分布（用交叉熵损失监督）
  - 一个连续偏移头（offset head），用于补偿量化误差（L1 损失）
- **训练目标**：$L_{\text{Stage2}} = \frac{1}{K(L_{\text{sp}} + L_{\text{te}})} \sum_{k,\ell} \text{CE}(p_k^{(\ell)}, i_k^{(\ell)}) + \|o - o^*\|_1$
- **推理**：取 argmax 选码 → 在冻结码本中查找 → 融合解码 → 加偏移 → 通过时间聚合（temporal aggregation，借鉴 ACT）平均重叠块以稳定 50 Hz 执行。

### 2.4 两种运动模式原型

- **Mode A（稳定型）**：低速度方差、均匀加速度、抓取前暂停、保持末端水平、沿高效路径移动——适合精确、安全传递。
- **Mode B（动态型）**：更高速度峰值、更强加速度、含回弹/犹豫、含交互驱动的姿态变化（如接近时转向用户）——适合人机交互场景。
- 标量 $s$ 的取值约定：$s$ 高对应 Mode A，$s$ 低对应 Mode B，$s=0.5$ 取中间插值。

## 三、实验设计

### 3.1 硬件与平台

- **机器人**：Interbotix X-Series 单臂 ALOHA 主-从配置——WidowX-250 主导臂 + ViperX-300 6-DOF 从动臂。
- **相机**：俯视固定相机 + 腕部相机，分辨率 $480 \times 640$。
- **频率**：数据采集与执行均为 50 Hz；动作块长度 $T = 100$（2 秒）。

### 3.2 数据集与任务

- **六个真实机器人操作任务**，分为两类：
  - **四任务（双模式训练）**：pick（移动物体）、pour（倾倒容器）、look（末端朝向物体/盘子）、avoid（末端侧向避开物体），每个任务采集 60 次演示（30 Mode A + 30 Mode B）。
  - **两任务（单模式训练，用于 OOD 迁移测试）**：highfive（接近并触碰人手，仅 Mode A）、push（将视中物体推到用户盘前，仅 Mode B）。
- 数据集保存为 Robomimic 格式 HDF5，训练时以步长 10 对预堆叠块降采样。
- 初始物体位置在 $\pm 5$ cm 内固定，每次轨迹从固定默认位姿开始，时长 16–20 s。

### 3.3 评估协议

- **每个 (任务, 标量) 单元做 $N=20$ 次 rollout**，标量取三档 $s \in \{0.1, 0.5, 0.9\}$。
- **运动学指标**：
  - 关节速度（rad/s）
  - 关节加速度（rad/s²）
  - 末端接近俯仰角（FK 计算，正值=朝下）
- **人类盲评**：3 位专家评估者盲评风格贴合度（0–10）和任务完成度（0–10），对请求的标量与是否为迁移单元均设盲。
- **对比项**：无外部基线对比，主要在任务-标量网格内部验证模式区分、插值性与迁移性。

## 六、主要结论与发现

- **运动模式是可复用的行为因子**：改变运动模式标量 $s$ 能在多个任务上一致地切换执行节奏与风格，三项客观指标和人类盲评均支持该结论。
- **空间/时间解耦在潜空间中成立**：
  - 空间码主要按任务聚类，对模式不敏感；
  - 时间码主要按模式排成 Mode A–Mode B 带状结构，跨任务重叠。
- **组合泛化得到证据**：在仅以单一模式演示的任务（push、highfive）上，请求未见模式能将时码推向目标模式的训练分布区域，而空码保持在任务簇内，执行结果朝请求模式移动且任务成功率大体保留。
- **解耦是部分而非完全的**：运动模式存在几何相关量（如末端接近俯仰角）被空间分支部分吸收，导致 highfive 的速度/加速度变化幅度受限；push 在未见模式下的接触可靠性下降。
- **标量动力学指标可能低估了行为变化**：highfive 的速度/加速度区分度弱，但人类评估者仍能正确识别其迁移模式，说明平滑度、犹豫、末端姿态编排等更细微的动态特征未被速度单一指标捕捉。

## 七、优点与亮点

- **架构创新**：明确将动作分词解耦为空间流与时间流两条 RVQ 链路，分别承载任务相关结构与行为模式——这一先验设计比单一码本更利于可控解耦。
- **多目标协同训练**：reconstruction + DCT + swap + contrastive + adversarial MI + commitment 七项损失协同强化时空解耦，目标函数设计系统。
- **冻结阶段一的复用接口**：将分词器作为稳定接口，阶段二只需在有限离散码空间上做策略学习，降低学习复杂度并保留可复用性。
- **推理时双轴条件化**：任务标识与运动模式标量在推理时分别可寻址，使行为调控成为运行时可调旋钮，而非训练时绑定属性。
- **评估多维度**：客观动力学指标 + 潜空间 PCA 可视化 + 盲评三者交叉验证，避免单一指标的片面性。
- **迁移测试设计巧妙**：通过单模式训练任务构造 OOD (任务, 模式) 组合，验证了"行为因子跨任务复用"的核心假设。

## 八、不足与局限

- **任务规模有限**：仅 6 个任务、单一物体集合、$\pm 5$ cm 内的固定初始条件；任务分布远不足以声称广泛的组合泛化。
- **模式维度单一**：仅两个原型模式 + 一维标量 $s$；真实场景下的运动模式更丰富（如谨慎/果断/庆祝/疲惫等），现有设计难以涵盖。
- **解耦不彻底**：运动模式的部分几何相关量（如接近俯仰角）被空间分支吸收，造成迁移幅度受限；这是文中自承认的"部分而非完全"的解耦。
- **缺乏基线对比**：未与 Neural Policy Style Transfer、带风格条件的 diffusion policy、或现有 style-conditioned 行为克隆方法做对照，难以判断 MoMo 在风格解耦质量、迁移幅度上的相对优劣。
- **评估主观性偏倚**：盲评仅 3 位专家评估者，且都被描述为"专家"而非"朴素参与者"，可能对模式语义具有先验共识，存在评估者偏差风险。
