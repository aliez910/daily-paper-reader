## 摘要
将触觉感知融入视觉-语言-动作（VLA）模型对于接触丰富的操作任务具有重要前景，因为仅依靠视觉观察往往无法捕捉物理交互中的关键线索。然而，在任务特定数据有限的情况下，如何学习具有信息量的触觉表征并将其有效适配到预训练的VLA模型中仍是一个挑战。现有方法要么聚焦于瞬时接触状态，要么使用6D力矩序列建模时序交互动态，导致高维触觉信号未能得到充分探索。为应对这些挑战，我们提出了τ，一种触觉增强的VLA框架，它受联合嵌入预测架构（JEPA）的启发，通过未来视觉监督学习一种动作条件的时空触觉表征，并将其与视觉-语言特征融合以生成动作。该监督在潜空间中运行，且仅在训练阶段使用，因此不会增加部署开销。我们还引入了TacAura，一个涵盖四种代表性接触丰富操作任务的同步视觉、本体感知及基于视觉的触觉信号数据集。实验表明，τ优于现有模型，并能泛化到未见过的物体和场景，展现出更优的操作性能与鲁棒性。

## Abstract
Incorporating tactile sensing into Vision-Language-Action (VLA) models holds promise for contact-rich manipulation, where visual observations alone often fail to capture critical cues about physical interactions. However, learning informative tactile representation while effectively adapting it to pretrained VLA models remains challenging under limited task-specific data. Existing methods either focus on instantaneous contact states or model temporal interaction dynamics using 6D wrench sequences, leaving high-dimensional tactile signals underexplored. To address these challenges, we present τ, a touch-augmented VLA framework that learns an action-conditioned spatiotemporal tactile representation from future visual supervision inspired by the Joint-Embedding Predictive Architecture (JEPA), and fuses it with vision-language features for action generation. This supervision operates in latent space and is used only during training, adding no deployment overhead. We also introduce TacAura, a dataset of synchronized vision, proprioception, and vision-based tactile signals across four representative contact-rich manipulation tasks. Experiments show that τ outperforms existing models and generalizes to unseen objects and scenes, delivering improved manipulation performance and robustness.

## 1. 核心问题与研究动机

- **关键挑战**：在接触丰富（contact-rich）的机器人操作任务中，仅依靠视觉难以捕捉接触状态、力分布、变形模式等关键物理交互线索，因此需要将触觉感知融入视觉-语言-动作（VLA）模型。
- **现有方法的不足**：
  - 多数方法仅关注**瞬时接触状态**，忽略了时序交互动态。
  - 部分方法使用 6D 力矩（wrench）序列建模时序交互，但无法捕捉高维视觉触觉信号（fine-grained spatial contact patterns）的动态信息。
  - 即便考虑时序，也缺乏对自身演化或跨模态预测的监督。
- **开放问题**：在有限 Vision-Tactile-Language-Action (VTLA) 数据条件下，如何建模高维视觉触觉信号的时序交互动态，并将其有效适配到预训练 VLA 模型中。

## 2. 方法论

### 2.1 整体框架
τ 由三大组件构成：
1. **预训练 π0.5 VLA 主干**：基于 flow matching 的条件动作生成器。
2. **触觉编码与适配模块**：将原始触觉图像（左右手 DM-Tac 传感器，各含 1 通道 normal + 2 通道 shear 形变图）映射到 VLA 的多模态嵌入空间。
3. **JEPA 风格的预测式自监督分支**：仅训练时使用，推理阶段移除，零部署开销。

### 2.2 关键技术细节

- **触觉编码器**：以 π0.5 视觉编码器初始化，左右传感器共享权重，输出双侧触觉特征 $z^{touch}_t = [E_{tou}(T^L_t); E_{tou}(T^R_t)]$。
- **触觉适配器**：单层线性层 $A_{tou}$ 将触觉特征投影到 LLM 对齐空间，得到 $Z^{touch}_t$。
- **多模态融合**：将视觉 token $Z^{vision}_t$、语言 token $Z^{language}_t$、触觉 token $Z^{touch}_t$ 拼接，输入 LLM 与动作专家预测动作块 $\hat{a}_{t:t+H}$。
- **JEPA 风格预测**：MLP predictor $P(\cdot)$ 接收当前触觉 token 与动作序列 token，预测未来多个时间偏移 $\Delta_k$ 处的视觉特征变化：
$$\Delta \hat{z}^{vision}_{t+\Delta_k} = P(Z^{touch}_t, Z^{action}_{t:t+H})_k - z^{vision}_t$$
- **目标特征变化**：通过 VLA 视觉编码器提取未来帧特征，并减去当前帧特征（stop-gradient）。
- **加权 cosine 对齐损失**：权重 $w_{t+\Delta_k}$ 由触觉变化幅度导出（clip 到 [0.2, 5.0]），强调有显著接触变化的关键时刻。
- **训练目标**：
$$\mathcal{L}_{total} = \mathcal{L}_{IL} + \lambda \mathcal{L}_{SSL}, \quad \lambda = 0.3$$
其中 $\mathcal{L}_{IL}$ 为 flow matching 模仿学习损失。

### 2.3 创新点
- 不同于原始 JEPA 预测绝对特征，τ 预测**未来视觉特征的变化量**，直接面向控制相关动态。
- 跨模态 SSL 信号来源多样化（wrist / front / dual-view 三个变体）。

## 3. 实验设计

### 3.1 数据集 / 场景
- **TacAura 数据集**：自建，4 个接触丰富任务，每任务 100 条专家演示：
  - 插头插入（Plug Insertion）：精确几何对齐
  - USB 插入（USB Insertion）：精确几何对齐
  - 印章按压（Stamp Press）：力控制
  - 白板擦除（Whiteboard Erasing）：力调制
- **硬件**：Franka Research 3 + Franka Hand + DM-Tac WS 触觉传感器（320×240, ~40 FPS），3 个 RGB-D 相机（2 个第三人称 + 1 个腕部），10 Hz 对齐数据。
- **数据基础设施**：开源遥控操作工具、多流同步与转换工具。

### 3.2 评估指标
- 各任务分 3 个阶段（抓取 / 对齐 / 插入 或 拾取 / 接触 / 完成），每阶段成功率 + 全任务成功率。
- 每任务 20 次试验，中度随机化。

## 6. 主要结论与发现

- **显著性能提升**：τ-Wrist Sup. 平均全任务成功率 71.25%，相比最强基线 T-Rex†（31.25%）提升 40 个百分点。
- **任务级最佳结果**：
  - 插头插入：从 0%（ForceVLA† 对齐后插入率）→ 65%
  - USB 插入：20% → 50%
  - 印章按压：45% → 90%
  - 白板擦除：50% → 95%
- **视图选择呈任务依赖性**：
  - Front-view 监督擅长几何对齐任务（插头、USB）
  - Wrist-view 监督擅长力控制任务（印章、白板）
  - Dual-view 监督因简单融合策略受限
- **泛化能力良好**：
  - 白板擦除对物体和场景变化几乎无退化

- **基线失败主要发生在"最后执行"阶段**：抓取/对齐成功率普遍较高，但完成率显著下降。

## 7. 优点与亮点

- **方法创新**：
  - 首次将 JEPA 风格预测式自监督引入触觉增强 VLA 训练。
  - 监督信号为**未来视觉特征变化量**而非绝对特征，规避了像素级重建带来的开销。
  - 触觉变化幅度加权使 SSL 聚焦于关键接触时刻。
- **部署友好**：SSL 分支仅训练时使用，推理阶段移除，零额外开销。
- **数据基础设施**：开源了完整数据栈（遥控、数据转换、采集），TacAura 弥补了 VTLA 数据空白。
- **实验严谨**：阶段级评估能精确定位方法改进的关键环节（如最终完成）。
- **消融充分**：三个关键组件（动作序列条件、SSL、触觉模块）逐一移除验证贡献。
