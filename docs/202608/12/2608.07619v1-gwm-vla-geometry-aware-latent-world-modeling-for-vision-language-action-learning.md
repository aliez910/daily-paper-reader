## 摘要
视觉-语言-动作（VLA）模型在机器人操控任务中表现出色，但在视觉和环境发生变化时性能常常下降。潜在世界建模为提升鲁棒性提供了一条有前景的途径，但现有方法通常独立编码各个相机视角，并在未显式建模其几何关系的情况下预测整体场景动态。我们提出了 GWM-VLA，一个面向 VLA 学习的几何感知潜在世界建模框架。GWM-VLA 结合了几何感知的多视角状态编码、由全局上下文条件化的目标视角预测，以及由机器人动作监督所约束的共享潜在-动作表征。具体而言，VGGT-Ω 在每个时间步联合聚合多视角观测，以构建几何感知的多视角状态。潜在世界模型利用多视角聚合后得到的 patch token 与 register token 来预测所选目标视角的下一时刻 patch token，从而在保留多视角几何信息的同时无需预测完整的多视角状态。我们在实验中将腕部视角作为目标视角，以更着重关注末端执行器的运动以及局部夹爪-物体的交互。最后，共享的潜在-动作表征同时作用于潜在世界模型和流匹配动作头，使潜在预测监督与真实机器人动作监督能够共同塑造同一组潜在-动作表征。在仿真与真实环境中的实验均验证了 GWM-VLA 的有效性与鲁棒性。

## Abstract
Vision-Language-Action (VLA) models achieve strong robotic manipulation performance but often degrade under visual and environmental shifts. Latent world modeling offers a promising approach to improving robustness, yet existing methods commonly encode camera views independently and predict holistic scene dynamics without explicitly modeling their geometric relationships. We propose GWM-VLA, a geometry-aware latent world modeling framework for VLA learning. GWM-VLA combines geometry-aware multi-view state encoding, global context-conditioned target-view prediction, and shared latent-action representations grounded by robot-action supervision. Specifically, VGGT-$Ω$ jointly aggregates multi-view observations at each timestep to construct geometry-aware multi-view states. The latent world model predicts the next-step patch tokens of a selected target view using patch and register tokens obtained after multi-view aggregation, thereby retaining multi-view geometric information without predicting the complete multi-view state. We use the wrist view as the target in our experiments, placing greater emphasis on end-effector motion and local gripper-object interactions. Finally, the shared latent-action representations condition both the latent world model and the flow-matching action head, allowing latent-prediction supervision and ground-truth robot-action supervision to jointly shape the same latent-action representations. Experiments across both simulation and real-world environments demonstrate the effectiveness and robustness of GWM-VLA.

# GWM-VLA 论文总结

## 1. 核心问题与研究背景

- **核心问题**：视觉-语言-动作（VLA）模型虽然在机器人操控任务上表现优异，但在视角、光照、背景纹理、物体布局及传感器噪声等视觉与环境扰动下性能明显下降，暴露出对视觉外观相关性的依赖，缺乏对"动作引起状态变化"的建模能力。
- **研究动机**：
  - 显式世界模型（如 DreamZero、π0.7）需预测未来图像，不得不建模纹理、光照等外观细节，效率与鲁棒性受限。
  - 潜在世界建模（如 VLA-JEPA）虽更紧凑，但采用 V-JEPA2 对各相机视角**独立编码后拼接**，丢失了跨视角几何关联（对应关系、相机相对场景结构）。
  - 几何基础模型（VGGT、VGGT-Ω）已能联合聚合多视角，但如何用作"预测性状态"服务于潜在世界建模尚未被充分探索。

## 2. 方法论

### 2.1 整体框架三大设计
- **几何感知多视角状态编码**：在每个时间步用冻结的 VGGT-Ω 编码器联合聚合多视角观测，得到 register token $R_t$ 与 patch token $P_t$。
- **全局上下文条件化的目标视角预测**：潜在世界模型仅预测所选**目标视角**（实验中为腕部视角）下一时刻的 patch token，并以该视角对应的 register token 作为全局几何上下文。
- **共享潜在-动作表征**：由 VLM（Qwen3-VL-2B）产生的潜在动作 token 同时条件化潜在世界模型与流匹配动作头，使潜在预测与真实动作监督共同塑造同一组表征。

### 2.2 关键公式与流程（文字描述）
1. 每步观测 $O_t=\{I_t^v\}_{v=1}^V$ 经冻结 VGGT-Ω 聚合：$\{R_t, P_t\}=E_\Omega(\{I_t^v\})$。
2. 提取目标视角 $v^\star$（腕部视角）的 token：$r_t=R_{t}^{v^\star}$，$p_t=P_{t}^{v^\star}$；$p_t$ 作为待预测状态，$r_t$ 作为全局上下文。
3. 潜在世界模型（时间因果注意力）：$\hat{p}_{1:T}=F_\phi(p_{0:T-1}, r_{0:T-1}, A_{0:T-1})$；同一时间步内双向注意力，跨步只允许 $t$ 步关注 $\le t$ 的步。
4. 训练采用 Teacher Forcing：下一时刻监督目标由同一编码器对未来观测 $O_{t+1}$ 编码得到。
5. 潜在动作 $A_{0:T-1}=Q_\theta(O_0, \ell, Q_A)$，由 Qwen3-VL 中的可学习查询 token 提取，分组覆盖未来 T 步。
6. 动作头为条件流匹配，噪声-真值插值 $u_\gamma=(1-\gamma)\epsilon+\gamma u_{0:T-1}$，优化速度场预测。
7. **联合损失**：$\mathcal{L}=\mathcal{L}_{\text{action}}+\lambda \mathcal{L}_{\text{wm}}$，其中 $\mathcal{L}_{\text{wm}}$ 为 $\ell_1$ 潜在预测损失，$\lambda=0.1$；世界模型损失仅用于训练，不用于推理。

## 6. 主要结论与发现

- **LIBERO**：97.1% 平均成功率，与 OpenVLA-OFT 并列最佳，超过仅机器人版 VLA-JEPA 1.0 个百分点。
- **LIBERO-Plus**：76.9% 平均成功率，**达到 SOTA**，超过 OpenVLA-OFT 7.3 个百分点、超 VLA-JEPA 14.0 个百分点；在语言、光照、物体布局扰动中排名第一。
- **真实世界**：在 ID 与 OOD-layout 设定下取得最高平均成功率，但对完全未见物体-容器组合的 OOD-task 上 π0.5 更优（60.0% vs GWM-VLA 53.3%，远超 π0）。
- **消融**：腕部视角目标（92.8%）显著优于第三人称（87.8%），混合视角接近腕部单独使用；VGGT-Ω 第 24 层表征最优；直接共享潜在动作 token 比额外引入 embodied action query 高 4.8 个百分点。
- **定性分析**：预测的下一时刻潜在状态经独立训练的解码器重建后，仍保留场景布局与夹爪-物体几何主结构，但细节被平滑。

## 7. 优点

- **方法创新**：
  - 首次将多视角几何联合编码（VGGT-Ω）作为**预测性状态**而非纯感知输入，并显式建模其时序演化。
  - "目标视角 + 全局几何上下文"设计在保留多视角几何的同时降低了预测负担。
  - 共享潜在动作表征实现"预测学习"与"控制学习"耦合，比 VLA-JEPA 额外引入 embodied action query 的方案更简洁、更有效。
- **设计选择充分验证**：目标视角选择、表征深度、动作条件方式均通过消融得到明确结论（腕部视角 + Layer 24 + 共享潜在动作）。
- **鲁棒性收益显著**：在 7 类视觉/环境扰动下大幅领先基线，方法论与实验结果一致性高。
- **真实世界补充**：在有限演示条件下仍展现竞争力，验证方法的实用性。

## 8. 不足与局限

- **多视角依赖**：几何感知状态要求同一时间步多视角观测，**难以直接应用于大规模人类视频预训练**，限制方法的可扩展性。
- **目标视角固定**：训练全程使用腕部视角，论文承认最优目标可能因任务/传感器配置而异，缺少自适应目标视角或多目标联合预测机制。
- **真实世界评估规模有限**：仅 5 个任务、每任务 10 次评估，统计置信度不足；OOD-task 评估未与 VLA-JEPA 等强基线直接比较。
- **消融实验与主结果不可比**：消融仅在 10k 步、单卡、轻量配置下进行，不能完全反映完整预训练下的真实效果。
- **定性可视化仅为定性**：使用单独训练的解码器重建潜在状态的 3D 几何，未给出定量重建误差，难以判断"几何保持"的真实程度。
- **资源透明度不足**：未给出总训练时长、参数量、推理时延与计算开销对比，限制复现评估。
- **OOD-task 失败分析不足**：论文未对 OOD-task 上落后于 π0.5 的原因（指令组合泛化、概念接地等）做进一步剖析。
