## Abstract
Embodied visuomotor models, including Diffusion Policy (DP) and Vision-Language-Action (VLA) models, have demonstrated promising performance on robotic manipulation benchmarks. However, their potential remains fundamentally constrained by the scarcity of large-scale embodied trajectory datasets, leading to insufficient compositional generalization in out-of-distribution (OOD) scenarios with limited capability to capture reusable skill structures. To address this limitation, we propose Skill-Based Memory (SkillMemo) framework that implicitly decomposes long-horizon demonstrations into latent atomic skills and integrates skill-level features into a dynamic episodic memory bank for solving compositional tasks. Specifically, we first introduce an expert-guided trajectory segmentation module built upon a Mixture-of-Experts (MoE) architecture, which implicitly partitions trajectories into distinct skill primitives represented by learned gating coefficients. We further design a skill-level episodic memory architecture that stores compact skill representations as retrievable key-value pairs. During inference, the memory bank retrieves the most relevant skill primitives which are subsequently fused with the model's current gating distribution, providing a robust contextual prior to refine action predictions. Extensive experiments on the simulation benchmark and real-world manipulation tasks demonstrate that SkillMemo consistently enhances both DP and VLA backbones, achieving state-of-the-art performance and outperforming $π_{0.5}$, while exhibiting strong compositional generalization to unseen task configurations.

## 2. 方法论

### 2.1 整体框架 SkillMemo
两个核心组件：
1. **Expert-Guided Trajectory Segmentation (EGTS)**：利用 MoE 隐式分割轨迹为原子技能。
2. **Skill-Level Episodic Memory Architecture (SLMA)**：以 Key-Value 形式存储技能并在推理时检索融合。

### 2.2 EGTS：专家引导的轨迹分割
- **MoE 架构**：给定中间特征 $h_t$，由 $N$ 个专家 $\{E_1,...,E_N\}$ 与门控网络 $G$ 构成：
  $$y_t = \sum_{i=1}^{N} g_i(h_t) \cdot E_i(h_t)$$
- 每个专家捕获局部运动原语，门控网络随时间变化的权重隐式定义技能边界。
- **正则化**：
  - 基于 Partial Information Decomposition (PID) 的协同信息损失 $L_{PID}$，鼓励专家之间的协同大于各自贡献之和，使专家专业化于互补技能。
  - 专家负载均衡损失 + top-$k$ 路由，防止专家退化（collapse）。

### 2.3 SLMA：技能级记忆架构
- **记忆存储（Memory Storage）**：
  - **Key**（键）：对技能片段内所有时间步的潜特征做时间聚合，得到紧凑的质心特征 $k_m = \frac{1}{L}\sum_{t\in\tau_m} h_t$。
  - **Value**（值）：存储该技能片段内所有时间步的门控分布序列 $v_m = \{g(h_t)\}_{t\in\tau_m}$。
  - 整体记忆库 $\mathcal{M} = \{(k_m, v_m)\}_{m=1}^{M}$。

- **记忆检索（Memory Retrieval）**：
  - 用当前观测潜特征 $q_t$ 与所有 key 计算余弦相似度，选取 Top-$N$ 最相关的记忆条目。
  - 设置可靠性阈值 $\delta$，仅当平均相似度满足要求才使用检索结果。
  - **融合公式**：$g'(q_t) = \lambda g(q_t) + (1-\lambda)\frac{1}{N}\sum_{n=1}^{N} v_n[t']$，其中 $\lambda$ 控制记忆干预强度。

- **记忆更新（Memory Update）**：针对终身学习场景，采用基于优先级的剪枝策略：
  - 移除时间戳最旧/长期未被调用/检索可靠度低于阈值的条目，保持记忆库紧凑且高质量。

### 2.4 算法流程（简述）
1. 训练阶段：MoE 模块隐式将示范分割为原子技能，同时构建记忆库。
2. 推理阶段：当前观测特征与记忆键比对 → 检索 Top-$N$ 技能 → 与当前门控分布加权融合 → 增强动作预测。

## 6. 主要结论与发现

- **核心定量结果**：
  - DP 骨干平均成功率 64.6%，较 DP 基线提升 3.4%，较 IMLE Policy 提升 1.8%。

- **专家激活可视化**验证 MoE 隐式分割可识别抓取、开灶等语义动作阶段，无需显式标签。
- **真实世界**：组合泛化任务提升尤为显著（如 Strawberry on Plate 从 65.0% 提升至 75.0%）。

## 7. 优点与亮点

- **技能级而非视觉语义级的记忆**：克服现有 MemoryVLA/HAMLET 等方法的粒度限制，将行为模式作为可复用单元。
- **MoE + 记忆库的协同设计**：将门控权重天然作为技能"标签"用于检索，避免额外的技能发现标注。
- **理论正则化**：引入 PID 协同信息损失，为专家专门化提供信息论支撑。
- **模型无关性**：可无缝插入 DP 与多尺度 VLA，具有较高通用性。
- **终身学习机制**：基于使用频率与可靠度的动态剪枝，使记忆库具备可持续扩展能力。
- **真实世界验证充分**：从单任务到未见组合任务，覆盖典型接触丰富操作场景。

## 8. 不足与局限

- **专家数与计算开销的权衡**：专家数增大带来显著推理延迟（如 $N=10$ 推理时间是 $N=2$ 的近 3 倍），限制实时部署。
- **记忆库容量上限**：$M_{max}=1000$ 在长时间终身学习场景下可能成为瓶颈，且剪枝策略可能丢失潜在有用但短期不活跃的技能。
- **仿真与真实差距**：真实任务示范仅 50 条 + 40 次 rollout，统计强度有限；真实世界单任务改进在某些任务上仅 +2.5%~5%。
- **未明确评估项**：训练时长、与人类水平的对比、失败模式分析、不同语言指令下的鲁棒性等均未深入展开。
- **可靠性阈值与融合权重超参敏感**：$\delta$ 与 $\lambda$ 对性能影响未做系统敏感性分析。
- **应用限制**：当前评估集中于桌面级 UR5e 操作，对移动机器人、人形机器人或柔性物体操作的迁移性未验证。
- **偏差风险**：所有真实任务均使用相似桌面环境与少量物体，可能存在数据采集偏差，影响对外推广的可靠性。
