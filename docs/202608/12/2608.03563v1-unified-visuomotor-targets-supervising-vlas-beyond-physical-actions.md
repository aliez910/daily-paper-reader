## 摘要
VLA 模型通过视觉与语言观测预测机器人动作。这虽是一种自然的选择，却造成了不匹配：VLM 编码了丰富且高层次的场景与目标表征，而机器人动作则是低层次信号，任务结构十分有限。我们探讨一个核心问题：在不改变策略架构设计的前提下，改变其训练时所预测的内容，能否带来性能更优、训练更高效的策略。为此，我们提出 UVT（统一视觉运动预测目标），一种统一的潜在预测目标，将运动控制信息与视觉场景过渡信息联合编码，且无需任何架构改动或额外数据。UVT 应用于两个具有代表性的 VLA 系统，在仿真基准与真实双臂操作任务中均显著提升了训练效率、最终任务性能以及策略鲁棒性，尤其在训练预算受限和环境条件严苛的情况下增益尤为突出。Rollout 视频与更多定性结果详见项目页面：https://unified-visuomotor-targets.github.io/

## Abstract
VLA models are trained to predict robot actions from visual and language observations. This is a natural choice, but it creates a mismatch: VLMs encode rich, high-level representations of scenes and goals, while robot actions are low-level signals with limited task structure. We ask whether changing what the policy is trained to predict, rather than how it is architecturally designed, can yield better and more efficiently trained policies. We propose UVT (Unified Visuomotor Target), a unified latent prediction target that jointly encodes motor control and visual scene transition information, requiring no architectural changes and no additional data. Applied to two representative VLA systems across simulation benchmarks and real bimanual manipulation tasks, UVT improves training efficiency, final task performance, and policy robustness, with particularly strong gains under limited training budgets and challenging environmental conditions. Rollout videos and additional qualitative results are available at our project webpage: https://unified-visuomotor-targets.github.io/

# 论文总结：统一视觉运动预测目标（UVT）

## 1. 核心问题与研究动机

- **核心问题**：当前 Vision-Language-Action（VLA）模型将"预测机器人动作"作为标准的模仿学习监督目标，但这与 VLM 内部编码的丰富高层语义表征之间存在显著的**表征错配**（representation mismatch）：
  - VLM 自然擅长预测与任务相关的语义输出（物体存在、空间关系、目标状态等）
  - 而机器人关节角度、笛卡尔位姿等低层动作信号缺乏任务结构，同一手腕运动或夹爪修正会出现在任务目标完全不同的场景中
  - 这导致训练语义预测器去输出运动学信号时**收敛慢、鲁棒性差**

- **关键疑问**：在不改变策略架构（不改 backbone、不增加数据）的前提下，仅通过**改变预测目标**本身，能否获得更优、训练更高效的策略？

- **背景定位**：过往研究主要聚焦于"如何适配架构"（如 MLP 头、Flow-Matching 头、cross-attention 模块等），本文则反其道而行——聚焦于"目标应当是什么"。同时，现有 Latent Action Models（LAMs）多用于大规模预训练，本文首次将其作为下游 VLA 微调的监督信号。

## 2. 方法论

### 2.1 核心思想

提出 **UVT（Unified Visuomotor Target）**，一种**统一的潜在预测目标**，将两类异质信号融合为一个 32 维潜变量 `u_t`：
- **运动控制信号** `a_t`：连续动作 chunk（k 个未来步，d 维，如 7D 笛卡尔 + 夹爪）
- **视觉场景过渡信号** `z_t`：来自预训练 LAM（如 UniVLA、Villa-X 等）的离散 dynamics code，捕捉帧间视觉变化

UVT = "动作告诉你机器人怎么动，dynamics code 告诉你场景怎么变；融合两者，VLA 得到与高层语义更匹配的监督信号"。

### 2.2 关键技术细节

**步骤 1：构建 UVT（Multimodal VAE, MVAE）**

- 两个编码器分别将 `a_t` 和 `z_t` 映射为对角高斯分布：
  $$(\mu_a, \log\sigma_a^2) = f_a(a_t),\quad (\mu_z, \log\sigma_z^2) = f_z(z_t)$$
- 使用 **Weighted Product-of-Experts (PoE)** 进行融合，可学习精度权重 α_a、α_z 用于全局平衡：
  $$\tau = \alpha_a \tau_a + \alpha_z \tau_z,\quad \mu = \frac{\alpha_a \tau_a \odot \mu_a + \alpha_z \tau_z \odot \mu_z}{\tau}$$
- 取融合后的均值作为 `u_t ∈ R^32`
- 两个解码器从同一 `u_t` 重建动作和 dynamics code，确保信息完整性

**训练目标**：
$$\mathcal{L}_{UVT} = \mathcal{L}_{ACT} + \mathcal{L}_{DYN} + \mathcal{L}_{KL}$$
- $\mathcal{L}_{ACT} = \|a_t - \hat{a}_t\|_1$（L1 重建损失）
- $\mathcal{L}_{DYN} = CE(z_t, \hat{z}_t)$（交叉熵）
- $\mathcal{L}_{KL} = D_{KL}(\mathcal{N}(\mu_t, \sigma_t^2) \| \mathcal{N}(0, I))$（正则化，使潜空间良态）

**步骤 2：VLA 微调（关键：无需架构改动）**

- 预计算所有样本的 `u_t`
- VLA 策略预测 $\hat{u}_t = f_\theta(x_t)$
- 总损失：
$$\mathcal{L}_{VLA} = \|\hat{u}_t - u_t\|_2^2 + \gamma \|\hat{a}_t - a_t\|_1$$
  - 第一项将策略预测对齐到 UVT 空间
  - 第二项确保可执行动作的有效重建
  - $\gamma = 0.5$ 为平衡系数
- **关键设计**：动作解码器 `g_a` 在 VLA 训练阶段**保持可训练**，以适应预测 `u_t` 的分布偏移（而非冻结）

### 2.3 适配不同 VLA 头

- **回归头（VLA-Adapter）**：直接 L2 预测 `u_t`
- **Flow-Matching 头（π0.5）**：在生成目标时将 `a_t` 替换为 `u_t`，生成过程完全不变

## 3. 实验设计

### 3.1 数据集与基准

- **仿真基准**：
  - **LIBERO**：四类任务（Object / Spatial / Goal / Long）
  - **LIBERO-Plus**：更具挑战性的扩展，加入视觉/对象状态的扰动，用于鲁棒性压力测试
- **真实场景**：双臂操作平台，3 个任务：
  - **Lift Pot**：双臂同时抓取铝锅两侧把手并提起（同步性挑战）
  - **Close Marker**：双臂分别抓取马克笔本体与笔帽并对齐插入（精度挑战）
  - **Plate Handover**：右臂抬起纸盘并转交给左臂放置（协作挑战）

### 3.2 基线方法

- **VLA-Adapter**（带回归头的小规模 VLA）
- **π0.5**（基于 Flow-Matching 的大规模 VLA）
- 消融中对比：
  - **Villa-X head** 辅助预测
  - **UniVLA head** 辅助预测
  - **UVT 完整方法**

### 3.3 评估指标

- 任务成功率
- 训练步数下的固定预算性能（10k vs 100k）
- 真实任务中定义 Full-success 与 Half-success：Success Rate = (Full + 0.5 × Half) / 50

## 6. 主要结论与发现

1. **改变监督目标比改变架构更高效**：UVT 提供与 VLM 表征更匹配的监督信号，显著加速收敛、提升最终性能
2. **强训练效率增益**：例如 LIBERO-Plus Spatial 任务在 10k 步时从 34.0% 跃升至 81.5%（+47.5%）
3. **架构无关性**：在 VLA-Adapter（回归头）与 π0.5（Flow-Matching 头）上都取得一致提升
4. **显著真实机器人提升**：Close Marker 基线 0% → UVT 38%；Plate Handover 18% → 40%
5. **UVT 表征分析**：
   - 在 t-SNE 上呈现清晰的 suite 级聚类（无监督情况下），证明融合了任务级信息
   - 从 `u_t` 解码的动作轨迹比原始演示更平滑，抑制低层执行器噪声
6. **融合优于辅助头**：双头辅助（额外预测 `z_t`）只获得微小增益，UVT 通过单一共享空间融合获得显著更大增益

## 7. 优点

- **视角新颖**：从"目标函数设计"角度切入 VLA 训练问题，与当前主流的架构改造路线形成互补
- **零侵入性**：无需架构改动、无需额外数据、无需修改训练 schedule，纯即插即用
- **多架构泛化**：首次同时验证了 UVT 在回归式和 Flow-Matching 式 VLA 头上的通用性
- **充分消融**：与多种主流 LAM（Villa-X、UniVLA）的两头方案对比，有力证明 MVAE 共享空间融合的必要性
- **可视化分析深入**：t-SNE 与时序轨迹分析从定性与定量两个角度证明 UVT 表征的优势
- **Sim2Real 一致性强**：仿真与真实均观察到提升，且基线 0% 的 Close Marker 改进具有强说服力

---

## 8. 不足与局限

- **真实评估规模有限**：每任务 50 trial，来自单一机器人平台；缺少跨平台、多场景、多物体的 Real-world 统计显著性检验
- **演示规模固定**：仅使用 30 条演示，未验证在更大规模（如 100+）演示下 UVT 是否仍保持优势
- **对 SOTA 主流模型对比不足**：未与 OpenVLA、π0、RT-2 等大模型 base 比较
- **方法依赖预训练 LAM**：UVT 性能上限受限于 LAM 提取 dynamics code 的质量；LAM 在未见场景/物体上的失败模式可能传导
- **超参数未充分探索**：α_a、α_z 的可学习权重设计值得更细的 ablation；γ=0.5 单一取值是否鲁棒未验证
- **未讨论失败模式**：在 LIBERO-Plus 仍未饱和的任务（如 Long 中 100k 步仅 72.1%）上未深入分析失败原因
- **理论分析薄弱**：缺少对"为何 fusion > auxiliary head"的形式化分析，目前仅靠实验支撑
- **未来方向有待验证**：作者提及可应用于 navigation、多智能体等场景，但未给出任何实证
- **长程规划能力未评估**：Long 任务表现仍受限，说明 UVT 难以从根本上解决长程依赖问题
- **动作 - 动力学权重 α 的可解释性**：作为可学习标量，在不同任务上的分布未被分析
