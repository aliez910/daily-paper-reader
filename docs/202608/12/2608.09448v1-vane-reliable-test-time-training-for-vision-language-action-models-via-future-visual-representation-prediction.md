## 摘要
测试时训练（TTT）为基于无标注部署数据流来适配视觉-语言-动作（VLA）策略提供了一种轻量化的途径，但在闭环操控任务中仍难以可靠地使用。共享的适配空间可能混合不兼容的任务修正，而在线更新可能在尚未知晓其后果时就改变后续动作。本文为VLA策略提出了一个可靠的TTT框架——VANE。VANE以当前的视觉-语言上下文为条件进行提示适配，并从已执行动作的未来视觉后果中学习。候选更新与在线策略相互隔离，在后续观测上进行评估，并且仅在得到未来证据支持时才被采纳，从而使适配过程具有选择性与可逆性。在SimplerEnv WidowX上，VANE相对于对应的TTT基线将平均成功率提升了3.2个百分点。在Google Robot上的结果进一步表明，部署阶段的性能增益仍取决于具体任务与具体硬件形态。综上，这些结果展示了一种受限的、基于证据的VLA策略在线适配方法。

## Abstract
Test-time training (TTT) offers a lightweight way to adapt vision--language--action (VLA) policies from unlabeled deployment streams, but it remains difficult to use reliably in closed-loop manipulation. A shared adaptation space can mix incompatible task corrections, while an online update can alter subsequent actions before its consequences are known. We introduce a reliable TTT framework for VLA policies (VANE). VANE conditions prompt adaptation on the current vision--language context and learns from the future visual consequences of executed actions. Candidate updates are isolated from the live policy, evaluated on subsequent observations, and committed only when supported by future evidence, making adaptation selective and reversible. On SimplerEnv WidowX, VANE improves average success by $3.2$ percentage points over the corresponding TTT baseline. Results on Google Robot further show that deployment-time gains remain task- and embodiment-dependent. Together, these results demonstrate a constrained, evidence-based approach to adapting VLA policies during interaction.

# VANE 论文总结

## 1. 核心问题与研究动机

- **背景**：视觉-语言-动作（VLA）模型已成为机器人操控的强大策略骨干，但将其适配到新任务或新视觉环境代价高昂——传统方法需额外任务演示与反复微调。机器人部署天然产生无标签视觉流，**测试时训练（TTT）**提供了一种轻量化替代方案。
- **核心矛盾**：TTT 用于闭环操控时存在两大可靠性问题：
  1. **共享适配空间混淆**：单一潜在提示（latent prompt）会强制异质任务的修正方向进入同一参数块，产生任务干扰。论文诊断显示，一个在所有任务上联合优化的共享 prompt 反而把 QwenPi 在 WidowX 上的成功率从 64.1% 降到 63.3%，而任务独立 prompt 可达 66.1%。
  2. **在线更新的因果耦合**：候选更新在被未来证据验证前就已改变后续动作，从而影响其自身评估所用的数据，形成闭环干扰。
- **论文定位**：提出"**可靠 TTT**"——候选更新需具备选择性、可逆性，并以未来证据为提交依据。

## 2. 方法论：VANE 三组件

### 2.1 整体流程
- 顺序管道：MoLP 决定"**适配什么**"→ WPI 提供"**适配信号**"→ AGV-TTT 决定"**何时提议、何时提交**"。
- 部署期仅冻结的潜在提示库可被更新；路由器、策略骨干与视觉编码器均冻结。

### 2.2 上下文路由的潜在提示混合（MoLP）
- 维护一个全局潜在提示库 $P = \{P_i\}_{i=1}^{E}$（$E=8$，每个提示形状 $[16, 1024]$）。
- 取 VLM 最终投影层最后一个有效 token $c_t$，经线性路由器产生选择概率 $q_t = \mathrm{softmax}(W_r c_t + b_r)$，按 **Top-K (K=2)** 稀疏选择子集 $S_t$，按概率加权组合有效提示 $p_t$。
- **关键设计**：提示库不按任务/本体分块，依靠视觉-语言上下文自动组合；路由器冻结、仅提示库参与 TTT。

### 2.3 世界预测接口（WPI）
- 用冻结的 **V-JEPA 2 编码器** $f_\omega$ 提取当前视觉 token $Z_t$ 与未来视觉 token $Z_{t+k}$（$k=8$）。
- Latent-Action DiT 查询由提示、当前视觉潜变量与带噪动作 token 拼接组成：
  $$Q^{(0)}_\tau = [\,p_t \mid E_z(Z_t) \mid E_a(A_\tau, \tau)\,]$$
- 视觉与动作 token 通过共享自注意力交互，将视觉潜变量槽直接解码为未来表示 $\hat{Z}_{t+k}$，训练目标为：
  $$\mathcal{L}_{\mathrm{wpi}} = \frac{1}{NC}\|\hat{Z}_{t+k} - \mathrm{sg}(Z_{t+k})\|_F^2$$
- 与 state-grounding 代理相比，WPI 满足：① 目标可观测（未来延迟观测即可获取）；② 策略相关（跨时间、动作条件、保留语义结构）。
- 在 QwenPi 骨干上替换 state-grounding 分支得到 **QwenWPI**。

### 2.4 注意力门控与验证驱动的 TTT（AGV-TTT）
- **事件检测**：在策略推理时同时收集动作→VLM 跨层注意力与动作→预测潜变量注意力；对每通道、每个去噪步 $u$、每层 $l$ 计算归一化分布 $a_{c,u,l}$，聚合时序变化 $\Delta c_t$。当任一通道偏离鲁棒基线（基于中位数 + 1.4826·MAD）即触发事件。
- **聚焦的影子提议**：在事件帧，根据预测潜变量注意力选择高注意力视觉 token 子集 $K_t$ 与权重 $F_{t,n}$，构造聚焦损失 $\mathcal{L}_{\mathrm{focus},t} = \sum_{n \in K_t} F_{t,n} e_{t,n}$；在**影子副本**上做一步 AdamW 后立即恢复在线状态，故候选更新在验证通过前不进入控制器。
- **未来验证与原子提交**：在随后 $H_v = 4$ 帧 WPI 对上，用**配对随机性**（相同输入、聚焦权重、高斯噪声、流时间）同时评估旧/候选提示；当且仅当 ① 聚焦损失改善 $R_{\mathrm{focus}} > 0$、② 全局损失不退化 $R_{\mathrm{global}} \geq 0$、③ 多数未来帧支持时才原子提交提示库与优化器状态；否则全部回滚。

### 2.5 训练目标
$$\mathcal{L}_{\mathrm{train}} = \mathcal{L}_{\mathrm{act}} + 0.1 \cdot \mathcal{L}_{\mathrm{wpi}} + 0.01 \cdot \mathcal{L}_{\mathrm{lb}}$$
其中 $\mathcal{L}_{\mathrm{act}}$ 为 flow-matching 动作损失（目标速度 $A_1 - A_0$），$\mathcal{L}_{\mathrm{lb}}$ 为路由负载均衡损失。

## 6. 主要结论与发现

- **WidowX（4 任务平均）**：
  - TTT-VLA：67.4%；QwenPi + SG-LP + TTT：63.9%；QwenPi + MoLP + AGV-TTT：68.8%；QwenWPI + FP-LP + TTT：68.0%；QwenWPI + MoLP + AGV-TTT：**71.2%**（较对应 TTT 基线 +3.2 pp）。
  - 单独组件增益：MoLP 在每种代理-协议组合下均带来 +1.4 ~ +4.2 pp；WPI 在所有 8 个匹配对比中优于 state grounding（差距 1.3 ~ 4.1 pp）；AGV-TTT 是唯一在所有 4 行配置上相对 No TTT 都提升的协议（+0.5 ~ +1.6 pp）。
- **Google Robot（3 任务）**：QwenPi + MoLP + AGV-TTT 达 76.7%，较 TTT-VLA 66.3% 高 10.4 pp，但**跨系统差异不能归因于单一组件**；加入 Put in Drawer 后 QwenWPI 完整配置从 64.6% 升至 70.4%，说明增益**强烈依赖任务与本体**。
- **未来验证的必要性**（单提示 QwenWPI）：Event+Accept-All 67.3% < Online TTT 67.5% < AGV-TTT 69.0%，验证贡献 +1.7 pp。
- **优化效率**：AGV-TTT 仅在 1.3% 的可用帧触发反向，反向次数减少约 **75×**（98.7%），仅 19.4% 的提议被接受。
- **可视化-表征漂移**：WidowX（MMD ≈ 0.330 PCA-95）比 Google Robot（MMD ≈ 0.262）距离 RT-1/Bridge 训练参考更远；该顺序与代理优劣顺序在 WidowX 上更稳定一致。

## 7. 优点

- **三组件解耦清晰**：MoLP（适配空间）、WPI（监督信号）、AGV-TTT（更新时机）各自独立贡献，因子实验使归因透明。
- **闭环可靠性设计严谨**：影子副本 + 配对随机性验证 + 原子提交/回滚保证了"提议数据、验证证据、部署动作"的因果分离，避免了候选更新污染自身评估。
- **标签-自由的强监督**：用延迟观测的未来视觉表征替代即时 state grounding，无需专家动作、奖励或成功标签即可获得策略相关的代理目标。
- **优化高效**：稀疏事件触发 + 验证过滤，反向传播次数降至 1.3%，同时仍带来性能提升。
- **多 checkpoint 平均**与 episode 级 bootstrap 置信区间提升了结果稳健性。
- **诊断先于方法**：先揭示单提示干扰与注意力重分布现象，再提出针对性设计，论证链完整。
