## 摘要
现代视觉-语言-动作（VLA）策略已习得广泛的操控技能，但通常仅基于当前观测或固定长度的短历史来生成每个动作块。然而，现实中的操控往往是非马尔可夫的，要求机器人保留并推理来自长程交互历史中与任务相关的信息，以决定下一步动作。为应对这一挑战，我们提出了 HyMeS——一种混合学习框架，利用编码智能体的推理与记忆管理能力来引导一个马尔可夫型 VLA，以完成记忆依赖型操控。具体而言，HyMeS 通过基于梯度的模仿学习习得底层运动技能，而编码智能体通过启发式学习习得高层记忆管理策略，即根据 rollout 反馈迭代更新一个可执行的启发式系统。此外，我们通过多模态阶段完成验证来闭合引导与执行之间的闭环，该验证利用本体感受信号和多帧 VLM 判断来更新记忆。与端到端的记忆增强型 VLA 相比，HyMeS 只需为可复用的运动技能提供演示，无需为每一种依赖历史的任务配置都提供演示，从而实现数据高效的可组合泛化。在 RoboMemArena 上，HyMeS 将 pi0.5 的平均累积成功率从 52.5% 提升至 66.2%，平均任务成功率从 41.3% 提升至 60.1%，并在累积成功率上比 PrediMem 高出 4.5 个百分点，在任务成功率上高出 14.5 个百分点。

## Abstract
Modern vision-language-action (VLA) policies have acquired broad manipulation skills, but typically generate each action chunk from the current observation or a short fixed-length history. However, real-world manipulation is often non-Markovian, requiring robots to retain and reason over task-relevant information from long-horizon interaction histories to determine the next action. To address this challenge, we propose HyMeS, a hybrid learning framework that leverages the reasoning and memory-management capabilities of coding agents to steer a Markovian VLA for memory-dependent manipulation. Specifically, HyMeS learns low-level motor skills through gradient-based imitation learning, while a coding agent acquires high-level memory-management strategies through heuristic learning by iteratively updating an executable heuristic system from rollout feedback. Furthermore, we close the loop between steering and execution through multimodal stage-completion verification, which updates memory using proprioceptive signals and multi-frame VLM judgments. Compared with end-to-end memory-augmented VLAs, HyMeS requires demonstrations only for reusable motor skills rather than for every history-dependent task configuration, enabling data-efficient compositional generalization. On RoboMemArena, HyMeS improves mean cumulative success from 52.5% to 66.2% and mean task success from 41.3% to 60.1% over pi0.5, while outperforming PrediMem by 4.5 points in cumulative success and 14.5 points in task success.

# 论文总结：HyMeS——权重承载技能、代码承载记忆的混合学习框架

## 一、核心问题与研究动机

- **关键瓶颈**：现有视觉-语言-动作（VLA）模型（如 π0.5、π0.6）虽然具备广泛的运动技能，但其策略本质上是**马尔可夫的**：仅依据当前观测或固定长度的短历史生成动作块。
- **现实任务的非马尔可夫性**：实际机器人操作常需在长程交互历史中保留与推理任务相关信息（如一次性观察到的线索、需要计数的重复次数、被遮挡物体的源位置等）。这些信息无法从当前观测中恢复，导致观测"别名"（observation aliasing），使同一个观测可能对应多个互斥的动作模式。
- **现有方案的不足**：端到端记忆增强型 VLA（MemoryVLA、PrediMem、MemoryWAM 等）将记忆逻辑与运动技能纠缠在权重空间中学习，需大量演示覆盖组合式的记忆配置，存在遗忘、可解释性差等问题。
- **核心洞察**：运动技能是连续的、可组合的；而记忆逻辑是离散的、组合式的，二者性质不同，应在不同的表征空间中分别学习。

## 二、方法论

### 2.1 核心思想
将**运动技能学习**与**记忆策略学习**解耦：
- **权重空间**（weight space）：通过基于梯度的模仿学习获得可复用的运动技能；
- **代码空间**（code space）：通过编码智能体（coding agent）的启发式学习获得高层记忆管理策略；
- 二者通过**记忆条件化动作引导**（memory-conditioned steering）形成双向闭环。

### 2.2 关键技术组件

**(1) 运动技能学习（权重空间）**
- 基于流匹配的 VLA（如 π0.5）通过模仿学习微调：
  $$\theta^* = \arg\min_\theta \mathbb{E}\|v_\theta(a_\tau, \tau | o, \ell) - (a - \epsilon)\|_2^2$$
- 微调完成后**冻结权重**，所有记忆相关推理不再修改策略参数。

**(2) 记忆策略学习（代码空间）**
- 启发式程序 $P = (C, V, U)$，包含约束选择规则 $C$、事件验证规则 $V$、记忆更新规则 $U$；
- 符号记忆状态 $s_t = (\text{plan}, \rho_t, B_t, N_t, F_t)$，显式记录活跃阶段、物体绑定、计数、持续状态；
- 编码智能体（Opus 4.8）通过 rollout 反馈迭代修订程序：$P^{(n+1)} = \text{Edit}(P^{(n)}, \xi_n, b_n)$。

**(3) 记忆条件化动作引导**
- 当前阶段约束 $R_{\rho_t}(a, o_t; s_t)$ 通过开放词汇检测、掩码细化、深度反投影锚定到场景关键点；
- 引导力注入去噪过程：
  $$\hat{v} = v_{\theta^*}(a_\tau, \tau | o_t, \ell) + \lambda_t \nabla_{a_\tau} R_{\rho_t}(a_\tau, o_t; s_t)$$
- 引导强度按 Sigmoid 调度衰减：接近交互区时减弱引导，让运动策略主导接触执行。

**(4) 多模态阶段完成验证（PACE）**
- 融合**本体感受证据**（关节状态序列检测动作模式）与**视觉证据**（Qwen3-VL-8B 基于多帧判断完成）；
- 在最近 $w$ 次查询中至少 $k$ 次通过才触发阶段切换（$w=5, k=3$），抑制偶发误判；
- 验证通过后由 $U$ 规则更新记忆，形成闭环。

### 2.3 算法闭环
$$R_t = C(s_t, o_t, \ell), \quad a_t = \text{Steer}(\pi_{\theta^*}, R_t, o_t, \ell)$$
$$e_t = V(O_W, A_W; s_t), \quad s_{t+1} = U(s_t, e_t, o_t)$$

## 三、实验设计

### 3.1 仿真基准
- **RoboMemArena**（已修正）：12 个任务，160 个回合，覆盖四类记忆依赖能力：

  - **计数类**（counting）：重复事件计数；
  - **序列类**（sequence）：多阶段顺序执行；
  - **遮挡类**（occlusion）：物体隐藏后定位。
- 修正了可能导致假阳性的成功判定，并剔除可凭观测捷径或运动失败解决的任务。

### 3.2 真实机器人实验
- **SO-101 机器人**，3 个记忆依赖任务，共 35 次试验：观察-抓取、数字引导按钮按压、放回方块。

### 3.3 对比方法
- **π0.5**（reactive 基线）：相同微调权重，验证记忆机制带来的提升；
- **PrediMem**：RoboMemArena 原文中的记忆增强基线（VLM 规划器 + 关键帧记忆）；
- 真实机器人上仅对比 π0.5 与 HyMeS（共享权重），隔离记忆机制的独立贡献。

### 3.4 评估指标
- **CSR**（累积成功率）：子目标完成的平均程度；
- **TSR**（任务成功率）：整任务完成率。

## 六、主要结论与发现

- **总体性能**：在 RoboMemArena 上，HyMeS 将 CSR 从 52.5% 提升至 66.2%，TSR 从 41.3% 提升至 60.1%（相对 π0.5）；并超过 PrediMem 4.5 个 CSR 点、14.5 个 TSR 点。
- **类别细分**：
  - 计数类：TSR 提升 30.0 个百分点（依赖显式计数器与验证转换）；
  - 转移类：TSR 提升 26.6 个百分点（依赖对象-位置绑定）；
  - 序列类：TSR 提升 22.5 个百分点（依赖显式阶段状态）；
  - 遮挡类：PrediMem 因记忆不可靠反而低于 π0.5，HyMeS 在 CSR 上与之持平、TSR 高 7.0 点，说明**经验证的阶段切换**限制了错误绑定的破坏。
- **真实机器人**：SO-101 上 TSR 从 25.7% 提升至 57.1%，验证了硬件可行性。
- **消融结论**：
  - Rollout 启发式精炼带来 CSR +8.5、TSR +18.4 的提升；
  - 仅用视觉或仅用本体感受均会退化（TSR 分别降 21.7 和 8.4 点），二者互补显著。
- **可解释性**：符号记忆在每一步可读，失败可定位到记忆更新、运动执行或事件验证三类原因。

## 七、优点与亮点

- **清晰的范式创新**：首次将"运动技能 = 权重空间 / 记忆逻辑 = 代码空间"作为统一的设计原则，物理意义明确；
- **数据高效**：演示仅需覆盖可复用运动技能，无需为每种历史配置收集数据，组合泛化能力强；
- **可解释性与可编辑性**：符号记忆与可执行代码均可读可改，便于失败归因与人工干预；
- **双向闭环**：与现有推理时引导方法（VLS 等）相比，HyMeS 的引导约束依赖显式符号记忆，且将执行反馈（本体+视觉）写回记忆；
- **冻结策略的稳健性**：记忆获取完全不更新策略权重，避免灾难性遗忘与组合配置爆炸；
- **多模态验证机制**：本体感受 + 多帧 VLM 的 k-of-w 投票方案在抑制偶发误判上简单有效。

---

## 八、不足与局限

- **任务范围受限**：当前仅适用于能以"紧致符号状态"刻画历史的操作任务，对更开放、需要多模态或层次化记忆的任务尚不适用；
- **运动能力瓶颈**：失败分析表明，即使记忆与约束正确，接触密集型执行仍可能失败（瞄准偏差、抖动等），受限于冻结 VLA 的本征能力；
- **推理延迟与成本**：周期性 VLM 查询与编码智能体调用增加每回合的推理时延与 API 成本；
- **遮挡鲁棒性**：视觉验证在遮挡场景下最不可靠，导致该类任务整体表现偏低；
- **算力披露不全**：未报告训练与评估所用的 GPU 型号、数量与时长，复现成本难以估算；
- **基准范围有限**：12 个仿真任务 + 3 个真实任务，难以全面反映各类长程操作场景的泛化能力；
- **依赖外部基础模型**：编码智能体（Opus 4.8）与 VLM（Qwen3-VL-8B）的性能上限会传导至整体系统。
