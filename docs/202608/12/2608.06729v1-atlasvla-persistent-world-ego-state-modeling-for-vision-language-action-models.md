## 摘要
尽管视觉-语言-动作（VLA）模型推动了具身智能的发展，但其本质上反应式的范式严重限制了其在部分可观测和长时程任务中的性能。当仅使用单个腕部相机时，模型不可避免地会因物体离开视野而产生感知遗忘，并在多步执行过程中产生时序任务进度遗忘。为克服这些瓶颈，我们提出了AtlasVLA，这是一种通过持久化世界-自我状态，将直接反应式操作转变为前瞻性推理的新框架。AtlasVLA具有双记忆架构：一个4D持久化世界状态记忆，将瞬时的2D观测提升为全局更新的体素哈希空间状态以解决视觉盲区；以及一个自我工作状态记忆，用于追踪历史自我状态和任务进度。通过对扩散Transformer（DiT）以联合的世界-自我状态为条件进行调节，AtlasVLA实现了鲁棒的空间推理。在LIBERO、RLBench以及真实世界基准上的广泛评估表明，AtlasVLA仅使用腕部相机即可达到最先进的性能。值得注意的是，它显著优于多视角基线方法，在LIBERO-Long上实现了9.4%的绝对成功率提升，在真实世界长时程任务中实现了17.5%的提升。

## Abstract
While Vision-Language-Action (VLA) models have advanced embodied AI, their fundamentally reactive paradigm severely limits performance in partially observable and long-horizon tasks. When restricted to a single wrist-mounted camera, they inevitably suffer from perception forgetting as objects exit the field of view, and temporal task-progress forgetting} during multi-step execution. To overcome these bottlenecks, we propose AtlasVLA, a novel framework that transitions from direct reactive manipulation to proactive reasoning through a persistent world-ego state. AtlasVLA features a dual-memory architecture: a 4D Persistent World State Memory that lifts transient 2D observations into a globally updated, voxel-hashed spatial state to resolve visual blind spots, and an Ego-Working State Memory that tracks historical ego state and task progress. By conditioning a diffusion transformer (DiT) on this joint World-Ego state, AtlasVLA enables robust spatial reasoning. Extensive evaluations across LIBERO, RLBench, and real-world benchmarks demonstrate that AtlasVLA achieves state-of-the-art performance using solely a wrist camera. Remarkably, it decisively outperforms multi-view baselines, yielding absolute success rate improvements of 9.4% on LIBERO-Long and 17.5% in real-world long-horizon tasks.

# AtlasVLA 论文总结

## 1. 核心问题与研究动机

- **VLA 模型的局限性**：当前视觉-语言-动作（VLA）模型普遍采用**反应式（reactive）**范式，即直接将当前观测映射为动作，缺乏对历史与全局信息的记忆。
- **单腕部相机下的两大遗忘问题**：
  - **感知遗忘（Perception Forgetting）**：当物体离开腕部相机视野后，模型丧失对该物体的空间信息。
  - **任务进度遗忘（Temporal Task-Progress Forgetting）**：在多步长程任务中，模型难以追踪历史执行状态与子任务进度。
- **长程、部分可观测任务中的痛点**：上述缺陷使得 VLA 在长时域、复杂场景中性能急剧下降，制约了具身智能的实用化。
- **研究目标**：从"反应式操控"转向"前瞻性推理（proactive reasoning）"，实现仅靠单腕部相机即可完成复杂长程操控。

---

## 2. 方法论：核心思想与关键技术

### 2.1 整体框架
AtlasVLA 通过**持久化的世界-自我状态（World-Ego State）**建模，将直接反应式动作生成升级为基于记忆状态的条件推理。

### 2.2 双记忆架构（Dual-Memory Architecture）

- **4D 持久世界状态记忆（4D Persistent World State Memory）**
  - 将瞬时的 2D 观测"提升（lift）"到**全局更新的体素哈希（voxel-hashed）空间状态**。
  - 4D 维度包含（X, Y, Z, 时间），通过体素哈希实现高效、稀疏的 3D 空间存储。
  - 作用：消除视觉盲区，保留历史中被遮挡或离开视野的物体信息。

- **自我工作状态记忆（Ego-Working State Memory）**
  - 追踪**历史自我状态**（如末端执行器位置、姿态、夹爪状态等）。
  - 追踪**任务进度**（当前已完成子任务、剩余步骤、目标状态）。
  - 作用：解决时序任务进度遗忘问题。

### 2.3 动作生成模块
- 采用**扩散 Transformer（DiT）**作为动作解码器。
- 以**联合的世界-自我状态（Joint World-Ego State）**为条件进行调节（conditioning）。
- 实现主动的空间推理（proactive spatial reasoning），而非被动响应。

### 2.4 核心思想
通过"**持久记忆 + 状态条件**"将单视角瞬时观测转化为全局时空推理依据，使模型能"看回过去"和"看回被遮挡区域"。

## 6. 主要结论与发现

- AtlasVLA 通过持久世界-自我状态建模，**将 VLA 从反应式范式推进到主动推理范式**。
- **仅靠单腕部相机**即可达到 SOTA，**显著超越多视角基线**。
- 在 LIBERO-Long 和真实长程任务上均取得显著提升（9.4% / 17.5%），**证明了双记忆架构的有效性**。
- 表明"记忆+推理"是单视角长程操控的关键，而增加相机数量并非唯一出路。

## 7. 优点与亮点

- **问题定义清晰**：明确指出"感知遗忘"和"任务进度遗忘"两大瓶颈，定位精准。
