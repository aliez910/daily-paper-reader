## 摘要
视觉-语言-动作（VLA）模型作为一种可扩展的机器人操控方法，日益受到关注。尽管这些模型是有效的动作预测器，但将它们部署为机器人智能体暴露出关键缺陷：缺乏故障恢复机制、长时间跨度执行的不一致性，以及对观测、任务或本体变化的鲁棒性有限。现有方案通过模型重训练或环境特定模块分别解决这些局限，然而真正需要的是一个能够系统地将预训练VLA转化为机器人智能体的通用框架。我们提出RoboBRIDGE，这是一个模块化框架，它在五个协调模块（即Monitor（监控器）、Perceptor（感知器）、Planner（规划器）、Controller（控制器）和Robot Interface（机器人接口））之上提供编排层，以利用包括预训练VLA在内的现成组件来构建鲁棒的机器人智能体。Monitor将快速故障检测与分层恢复相结合，在错误级联之前加以纠正。当环境偏离当前计划时，Planner触发重规划，而Perceptor异步更新场景理解，避免执行停滞。在Controller内部，原始技能微调将操控分解为具有专用LoRA适配器的域不变原语，从而在使用VLA时降低对域偏移的敏感性。在LIBERO、RoboCasa以及跨越多种机器人平台和VLA主干的真实案例研究中，RoboBRIDGE始终优于独立策略以及先前增强的VLA部署。这些结果表明，可靠的机器人智能体并非仅来自动作预测器的规模化扩展，而是源于围绕其构建的结构化编排。

## Abstract
Vision-Language-Action (VLA) models have attracted growing interest as a scalable approach to robotic manipulation. While these models are effective action predictors, deploying them as robotic agents exposes critical gaps: no mechanism for failure recovery, inconsistent execution over long horizons, and limited robustness to shifts in observations, tasks, or embodiments. Existing solutions address these limitations individually through model retraining or environment-specific modules, yet what is needed is a general framework that systematically transforms a pretrained VLA into a robotic agent. We present RoboBRIDGE, a modular framework that provides an orchestration layer over five coordinated modules, namely Monitor, Perceptor, Planner, Controller, and Robot Interface, to compose robust robotic agents from off-the-shelf components, including pretrained VLAs. The Monitor pairs rapid failure detection with hierarchical recovery to correct errors before they cascade. When the environment diverges from the current plan, the Planner triggers replanning while the Perceptor updates scene understanding asynchronously, avoiding execution stalls. Within the Controller, primitive skill fine-tuning factors manipulation into domain-invariant primitives with dedicated LoRA adapters, reducing sensitivity to domain shifts when a VLA is used. Across LIBERO, RoboCasa, and real-world case studies spanning multiple robot platforms and VLA backbones, RoboBRIDGE consistently outperforms both standalone policies and prior augmented VLA deployments. These results suggest that reliable robotic agency does not arise from scaling action predictors alone, but from structured orchestration around them.

## 2. 方法论

### 2.1 整体框架
RoboBRIDGE 是一个由 **五个协同模块** 构成的模块化编排框架：

| 模块 | 职责 |
|---|---|
| **Perceptor（感知器）** | 将原始观测转换为以对象为中心的场景状态（身份、3D 位姿、语义属性） |
| **Planner（规划器）** | 接收语言指令与场景状态，分解为有序的"原始技能"序列 |
| **Controller（控制器）** | 由动作生成策略（任意 VLA 或经典控制器）占据，将每个技能映射为低层动作 |
| **Monitor（监控器）** | 验证执行结果，触发分层恢复 |
| **Robot Interface（机器人接口）** | 抽象机器人特定 API、坐标变换与安全限制 |

围绕该框架设计了三大核心机制：

### 2.2 两阶段监控（Two-phase Monitoring）
- **Phase 1 – 轻量成功检查**：用 VLM 等模型以受限输出格式周期性评估当前观测 $o_t$ 与计划上下文 $c_t$，得到二元成功标志 $suc_t$ 与置信度 $con_t$。运行约 5 Hz，不阻塞控制回路。
$$D_{\text{check}}: (o_t, c_t) \mapsto (suc_t, con_t)$$
- **Phase 2 – 失败诊断与恢复**：当 $suc_t = \text{false}$ 且 $con_t \geq \gamma_{\text{thresh}}$ 时，立即停机并调用诊断模型，得到恢复目标 $r_t$。按代价由低到高分层共四级：
  1. **retry** – 重执行当前基元；
  2. **re-generate** – 重生成轨迹但保留计划与感知状态；
  3. **replan** – 基于最新异步感知结果重规划；
  4. **re-perceive** – 强制完整重感知后再重规划。

### 2.3 反应式规划与异步感知
- **异步感知**：感知线程持续更新线程安全缓冲区 $B$（只保留最新结果），与执行线程解耦以隐藏感知延迟。
- **分歧触发的重规划**：执行完每个基元后，计算当前计划所用观测 $\bar{o}^{\text{plan}}$ 与最新感知 $\bar{o}^{\text{lat}}$ 之间的分歧：
$$\Delta(\bar{o}_a, \bar{o}_b) = \max_{i \in O_a \cap O_b}\left\| p_a(i) - p_b(i) \right\|_2 + \lambda \cdot |O_a \triangle O_b|$$
  当 $\Delta \geq \tau$ 时，保留高层动作序列（如 PICK → PLACE），仅重新生成当前及后续基元的空间参数。

### 2.4 原始技能微调（Primitive Skill Fine-tuning）
当 Controller 为 VLA 时，将操控分解为域不变基元集合 $\mathcal{P} = \{\text{MOVE}, \text{GRIP}, \text{ROTATE}, \ldots\}$，每个基元绑定一个独立的 LoRA 适配器 $\Delta\theta_k$，训练数据按基元类型筛选：
$$f_{\theta + \Delta\theta_k}: (i, s_t, p_t) \mapsto a_t^{(k)}$$
推理时通过两层解析器选择适配器：
$$\text{RESOLVE}(p_t) = \begin{cases} \Delta\theta_{p_t}, & \text{if adapter exists} \\ \frac{1}{|\mathcal{P}|}\sum_{p \in \mathcal{P}} \Delta\theta_p, & \text{otherwise} \end{cases}$$
LoRA 切换在原位完成，不重载骨干网络；7-DoF 增量动作可经 IK 求解或回退到笛卡尔速度指令控制，跨平台兼容。

### 2.5 算法主流程（Algorithm 1）
依次为：环境重置 → 初始感知 → 计划生成 → 启动异步感知线程 → 循环执行基元（解析适配器 → 动作采样 → 环境步进 → 失败监控 → 必要时恢复）→ 检查场景分歧 → 必要时重规划。

## 6. 主要结论

1. **VLA ≠ 智能体**：仅扩大动作预测器无法解决长时序、失败恢复与域泛化问题，结构化编排是关键。
2. **RoboBRIDGE 在多个基准、多个骨干上一致提升**：LIBERO 平均成功率从 35.5% 升至 39.7%；RoboCasa 平均成功率从 3.7% 升至 7.5%（剔除 PnP 任务后从 6.2% 升至 11.4%）。
3. **监控是必要而非充分**：单独规划质量不足，所有 LLM 骨干在无监控时落入 1.8–8.0% 的窄区间；监控带来显著且与推理能力正相关的增益（Claude Opus 4.6 提升 +8.1%）。
4. **控制器无关性**：LoRA FT、全量 FT、IK 控制器均能受益于 RoboBRIDGE；甚至 LoRA FT + 框架（27.1%）逼近独立的全量 FT（31.9%），表明少参数更新 + 编排可逼近昂贵微调效果。
5. **CycleVLA 等"模型内自纠错"机制不足以替代外部编排**：CycleVLA 仅 7.5%，显著低于 RoboBRIDGE 内的同款控制器。
6. **失败模式可识别**：感知错误（遮挡、相似物体）与接触密集型不可逆操控失败是两大主要瓶颈。

## 7. 优点

- **架构设计通用且优雅**：5 模块解耦清晰，策略无关；可与 LoRA FT、全量 FT、IK 控制等多种控制器即插即用，符合"工具增强智能体"的设计哲学。
- **两阶段监控降低开销**：5 Hz 轻量检查 + 按需深度诊断，避免每步都调用大模型，兼顾实时性与诊断深度。
- **异步感知 + 分歧触发重规划**：用极低开销的集合运算与欧氏距离判断，避免冗余高层推理，又能在场景漂移时及时更新空间参数。
- **LoRA 基元切换机制**：在不解冻骨干的前提下实现操控阶段解耦，支持原位切换，参数效率高。
- **控制变量严谨**：主表仅切换"是否使用框架"，其他变量完全一致，使收益归因明确。
- **跨平台真实实验**：在 Franka 与 UR7e 两个真实机器人上验证，且在未见环境下表现一致，证明实际可部署性。
- **朴素的算式设计**：分歧度量 $\Delta$ 只涉及最大欧氏距离与集合对称差，推理开销可忽略。
