## 摘要
动作分块通过预测多个未来动作来缩短机器人模仿学习的有效决策时域，而传统的相位条件仅描述当前控制时刻。当预测时域跨越过程性边界时，将当前相位分配给整个分块会产生结构性的时序失配。本文提出TRACT，将相位结构化的动作分块分解为一个被接受的当前相位以及位于未来时域内的单个CURRENT-to-NEXT（当前至下一阶段）边界。任务局部图约束时序相位权威，累积边界分布则通过相位特定的查询路径与动作路径单调地路由未来查询。在接触执行方面，因果响应缺失积分器将策略意图与符合ACK条件的后续运动进行比较，当方向性响应被抑制时累积机械臂补偿，并在确认恢复后衰减。在六种真实机器人变体上各进行十次试验，完整TRACT实现了10/10的全序列成功率，擦拭完成率中位数[最小，最大]为99.00%[88.75%，100.00%]，未观察到相位歧义，无停顿现象。在当前完整方法包及评估设置下，路由表示相比扁平表示获得了更优的观测任务结果（成功率6/10对比3/10；擦拭完成率中位数77.08%对比8.03%）。时序权威将观测到的相位歧义从8/10降至0/10，响应积分将停顿从4/10降至0/10。该包比较未能将路由与其他生成器包之间的差异完全隔离开。

## Abstract
Action chunking shortens the effective decision horizon of robot imitation learning by predicting multiple future actions, while conventional phase conditioning describes the current control instant. When a predicted horizon crosses a procedural boundary, assigning the current phase to the entire chunk creates a structural temporal mismatch. We present TRACT, which factorizes phase-structured action chunking into an accepted current phase and a single CURRENT-to-NEXT boundary inside the future horizon. A task-local graph constrains chronological phase authority, and a cumulative boundary distribution monotonically routes future queries through phase-specific query and action paths. For contact execution, a causal response-deficit integrator compares policy intent with ACK-eligible subsequent motion, accumulates arm compensation when directional response is suppressed, and decays after confirmed recovery. Across six real-robot variants with ten trials each, full TRACT achieves 10/10 full-sequence success, 99.00 [88.75, 100.00]% median [min, max] wipe completion, zero observed phase ambiguity, and zero stalls. Under the current complete method package and evaluation setting, the routed representation obtains better observed task results than the flat package (6/10 vs. 3/10 success; 77.08% vs. 8.03% median wipe completion). Chronological authority reduces observed phase ambiguity from 8/10 to 0/10, and response integration reduces stalls from 4/10 to 0/10. The package comparison does not isolate routing from other generator-package differences.

# TRACT 论文详细总结

## 1. 核心问题与整体含义（研究动机与背景）

**研究背景**：长视域、接触密集型（contact-rich）的机器人操作要求机器人完成"取工具→建立接触→维持擦除→归还工具"的连续工序，各步骤既需保持物理接触，又需遵循严格的程序顺序。

**关键问题**：
- **动作分块（Action Chunking）的时序结构错配**：模仿学习中策略在每个查询时刻预测未来 H 步动作（如 30 步 ≈ 1 秒），然而当预测区间跨越一个程序性相位边界（procedural boundary）时，将"当前相位 ct"赋给整段分块会产生结构性时间失配（temporal mismatch）。
- **两种相位模糊**：① 当前相位模糊——在视觉与本体感受相似的接触建立、重复擦拭、释放阶段，下一步合法动作不同；② 未来边界模糊——分块是否跨越下一相位、跨越何处未知。
- **接触执行响应缺口**：语义正确的分块可能因接触摩擦导致实际物理运动小于策略意图，造成相位一致但运动停滞。

## 2. 方法论

### 2.1 整体框架

TRACT 将相位结构化动作分块显式分解为两个不同时间尺度的决策：
- **当前相位接受**（present-phase acceptance）——属性属于当前控制时刻
- **未来边界路由**（future-boundary routing）——属性属于未来动作时域

系统输出三元组：

$$(c_t, k_t, A_t) = \Pi(o_{\leq t}, a^{exec}_{<t}), \quad A_t = \{a_{t,j}\}_{j=0}^{H-1}$$

其中 $c_t$ 为当前接受相位，$k_t \in \{0,...,H\}$ 为分块内首个采用后续相位语义的查询索引（H 表示块内不发生过渡）。

### 2.2 时序相位权威（Chronological Phase Authority）

- **共享编码器**输出局部状态 $h^{loc}_t$ 与回合级状态 $h^{ep}_t$
- **相位预测头**：$\ell^{phase}_t = A^{phase}(h^{loc}_t, h^{ep}_t)$，取最大概率类为诊断建议 $\tilde{c}_t$
- **过渡权威头**：$p^{adv}_t = \sigma(A^{auth}(h^{loc}_t, h^{ep}_t, Emb(c_{t-1})))$
- **相位管理器（Phase Manager）**：综合前进证据 $p^{adv}_t$、返工证据 $e^{rw}_t$、有效 tick 证据 $v^{tick}_t$，在任务局部转移图约束 $L(c_{t-1}) = \{c_{t-1}, n(c_{t-1})\} \cup R(c_{t-1})$ 内接受相位；每次接受原子更新 $c_t$，并清空不兼容的块与时序集成（temporal ensemble）血缘

任务含 P3 自环与一个 P4→P2 重擦授权边，属于当前时刻权威事件，触发新 P2 块的生成。

### 2.3 单调块内路由（Monotone Intra-Chunk Routing）

- **相对相位估计器**：预测分类边界分布 $\pi_t(k) = P(k_t=k | M_t, c_t, h^{exec}_t)$
- **累积分布作为 NEXT 门**：$\gamma_{t,j} = \sum_{r=0}^{j}\pi_t(r)$，具有 $\gamma_{t,j+1} \geq \gamma_{t,j}$ 的单调性
- **专家目标**：$k^\star_t$ 为块内首个相位列等于合法后续 $n(c_t)$ 的查询；不存在则 $k^\star_t = H$
- **相位特定查询银行**：$\hat{Q}_{t,j} = (1-\gamma_{t,j})Q(c_t)_j + \gamma_{t,j}Q(n(c_t))_j$
- **解码动作**：$a^{TRACT}_{t,j} = H_{shared}(z_{t,j}) + (1-\gamma_{t,j})R_{c_t}(z_{t,j}) + \gamma_{t,j}R_{n(c_t)}(z_{t,j})$，其中共享主干保持公共动作表示，残差路径注入相位特定位姿、轨迹与夹爪语义
- **路由禁用变体**（TU）：用单一共享查询/动作路径替代相位特定路径，实现"扁平"相位条件分块
- **训练损失**：$L_{N_0} = 10L_{action} + L_{sb} + 5L_{route} + 10L_{grip} + 10L_{safe} + L_{alias}$，含结构边界、夹爪路由、解码安全、严格别名监督

由于 $\gamma_{t,j}$ 是累积分布，路由形态仅支持"当前前缀 + 合法后续后缀"，振荡或无关相位序列表示支撑为零，单调性在动作解码前即可保证。

### 2.4 因果执行闭环（Causal Execution Closure）

- **普通 TE 融合**：仅在匹配回合、相位、过渡、时间戳、新鲜血缘下融合同物理时刻预测
- **方向融合 $d_t$**：融合原始块内路径与指数加权 TE 趋势，兼容投影仅作用于平移
- **响应缺口度量**：$u_t$ 为期望增量，$y_t$ 为实现增量，$\rho_t = clip(\langle y_t, d_t\rangle / \max(\langle u_t, d_t\rangle, \epsilon), 0, 1)$
- **响应缺口事件**：$e^{resp}_t = 1 - \rho_t$，相位特定方向速度阈值 $\theta_{b,c_t}$
- **缺口状态积分**：$s_t = (1-\alpha)s_{t-1} + \alpha e^{et}_t$，其中 $\alpha = 1-\exp(-1/(f\tau_{rise}))$
- **部署补偿**：仅写入臂部吸引子 $\Delta\xi^{int}_t$，不影响相位、路由与夹爪；确认恢复后按 $\exp[-1/(f\tau_{decay})]$ 衰减

**核心发现**：
1. **路由表示优势**：当前完整方法包与评估设置下，路由包 TR 显著优于扁平包 TU（6/10 vs 3/10；77.08% vs 8.03% 中位擦拭率）

3. **因果响应积分作用**：TR→TF 同检查点切换积分器，成功率由 6/10 升至 10/10，停顿由 4/10 降至 0/10

5. **TP 典型失败**：擦除开始后过早 P3→P4 转移，导致擦除中途停止
6. **TU 典型失败**：接受 P1→P2 后陈旧 P1 下降动作偏移工具；P2→P3 后陈旧 P2 下降扰动工具，引发停顿

## 7. 优点

- **问题分解清晰**：将"当前相位接受"与"未来边界路由"显式拆为两个时间尺度决策，揭示了现有方法忽略的块内时序异质性
- **理论保证**：累积边界分布 $\gamma_{t,j}$ 提供单调性结构保证，仅支持"CURRENT 前缀 + NEXT 后缀"，无需依赖解码器行为
- **任务局部图约束**：通过 $L(c_{t-1})$ 与 $R(c_{t-1})$ 限制接受空间，避免任意相位跳跃
- **因果执行闭环**：仅使用因果执行证据（ACK 血缘、方向速度恢复），无需演示响应基线或额外示教
- **多机制对比设计**：TU–TR（包对比）、TP–TR（运行时权威）、TR–TF（同检查点积分器）三组对照清晰分离各组件贡献

- **执行证据充足**：机制审计数据（7,105 跨越块、99.80% 精度）与试验结果形成双重佐证
