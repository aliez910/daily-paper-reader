## 摘要
许多近期的机器人策略通过将大规模预训练的视觉-语言模型（VLM）用作动作主干来追求更强的控制能力。我们提出了 WorldDiT，一种统一的扩散 Transformer 架构，它将动作生成与视觉世界建模相耦合，并在没有大规模预训练 VLM 动作主干的情况下取得了强劲的性能。在训练过程中，单个扩散 Transformer 生成连续的动作块，并基于未来相机帧预测归一化的 RGB patch 目标。在四个 LIBERO 仿真套件上，在报告全部四个套件结果的方法中，WorldDiT 处于总模型参数量与平均成功率的已报告 Pareto 前沿之上。这些结果为未来的可扩展性研究提供了一个强大的十亿参数以下的基线。

## Abstract
Many recent robot policies pursue stronger control by using large pretrained vision-language models (VLMs) as the action backbone. We introduce WorldDiT, a unified diffusion transformer architecture that couples action generation with visual world modeling and achieves strong performance without a large pretrained VLM action backbone. During training, a single diffusion transformer generates continuous action chunks and predicts normalized RGB patch targets from future camera frames. Across four LIBERO simulation suites, WorldDiT lies on the reported Pareto frontier for total model parameters and mean success among methods reporting all four suites. These results provide a strong sub-billion-parameter baseline for future scaling studies.

- **研究意义**：为未来可扩展性（scaling）研究提供一个**十亿参数以下的强基线**，并探索统一的世界-动作建模路径，避免对超大 VLM 的依赖。

## 2. 方法论

### 2.1 整体架构
- **WorldDiT** = 一个**共享 DiT 主干** + **冻结的视觉/语言编码器** + **可训练的状态编码器**
- **输入端**：
  - **冻结**：MAE 图像编码器、共享 Perceiver Resampler、CLIP 文本编码器
  - **可训练**：机器人状态编码器（将机械臂与夹爪分量分别编码后拼接）
- **统一主干**：深度 4，隐藏维度 1024，16 个注意力头，4 个 register tokens。

### 2.2 训练流程
- **观察窗口**：在十步窗口中，前 3 步（𝐶=3）为观测上下文，最后 1 步（i+𝐻）为预测目标槽。
- **两个预测目标**（共享一个 DiT 骨干）：
  1. **连续动作块**：H=7 步动作（ℝ⁷ˣᵈᵃ），由高斯噪声经流匹配反推；
  2. **归一化 RGB patch 目标**：从未来第 i+H 步的主相机与腕相机帧中各采 64 个 16×16 patch（共 128 个 768 维向量），每个 patch 用其自身均值方差归一化。
- **流匹配目标**（Flow Matching）：
  - 取 ε ~ N(0, I)，τ ~ U[0,1]，定义 x_τ = (1-τ)ε + τy
  - 损失：`L_flow = E[||v_θ(x_τ, τ, c) - (y - ε)||²]`
  - 总损失 = 加权和：`L_total = w_action · L_action_flow + w_rgb · L_rgb_flow`（文中 w_action=0.1，w_rgb=0.001）
- **关键设计**：RGB patch 预测**仅在训练时提供监督**，**推理时不进入计算图**。

### 2.3 推理流程（Receding-Horizon）
- 输入 3 步历史 H_t → 通过多模态编码得到条件表示 G_t
- 动作 token 从高斯噪声初始化，**20 步 Euler 数值积分**解 ODE：`dx/dτ = v_act_θ(x, τ, G_t)`
- 解码得到 H=7 的动作块，**执行前 3 个动作**，滑窗更新历史并重新规划；同时对重叠时间动作采用**时间集成（temporal ensembling）**。

## 7. 优点

- **架构简洁统一**：单一共享 DiT 同时处理动作与视觉两个模态，公式上自然兼容（都使用流匹配）
- **训练-推理解耦**：RGB patch 预测头与目标仅在训练时参与监督，**推理时纯动作路径**，不增加部署成本
- **紧凑高效**：总参数 < 400M，远小于 π₀、π₀.5、OpenVLA-OFT 等十亿级 VLA
- **多模态输入融合自然**：冻结的 MAE 视觉 + CLIP 文本 + 可训练状态编码器，通过 Perceiver Resampler 统一对齐
- **退化控制（receding-horizon）稳健**：动作块 + 时间集成 + 三步执行-重规划
- **讨论了未来扩展方向**：可探索 world-and-action 模型的混合专家（MoE）分解（如 Paris / Paris 2.0），适配异构硬件与算力受限机器人平台
