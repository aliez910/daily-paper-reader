## 摘要
现代视觉-语言-动作（VLA）策略已习得广泛的操控技能，但通常仅基于当前观测或固定长度的短历史生成动作片段。然而，现实世界中的操控任务往往具有非马尔可夫性，要求机器人保留并推理来自长时程交互历史的、与任务相关的信息，以决定下一步动作。为应对这一挑战，我们提出了 HyMeS，一种混合学习框架，利用编码智能体的推理与记忆管理能力，引导马尔可夫型 VLA 完成记忆依赖型操控任务。具体而言，HyMeS 通过基于梯度的模仿学习习得底层运动技能，而编码智能体则通过启发式学习，从回滚反馈中迭代更新可执行的启发式系统，从而获得高层记忆管理策略。此外，我们通过多模态阶段完成验证来闭合引导与执行之间的闭环，该验证利用本体感受信号和多帧 VLM 判断来更新记忆。与端到端的记忆增强型 VLA 相比，HyMeS 仅需对可复用的运动技能提供示范，而无需对每一种历史依赖的任务配置都提供示范，从而实现数据高效的可组合泛化。在 RoboMemArena 上，HyMeS 将 pi0.5 的平均累积成功率从 52.5% 提升至 66.2%，平均任务成功率从 41.3% 提升至 60.1%，并在累积成功率上超越 PrediMem 4.5 个百分点，在任务成功率上超越其 14.5 个百分点。

## Abstract
Modern vision-language-action (VLA) policies have acquired broad manipulation skills, but typically generate each action chunk from the current observation or a short fixed-length history. However, real-world manipulation is often non-Markovian, requiring robots to retain and reason over task-relevant information from long-horizon interaction histories to determine the next action. To address this challenge, we propose HyMeS, a hybrid learning framework that leverages the reasoning and memory-management capabilities of coding agents to steer a Markovian VLA for memory-dependent manipulation. Specifically, HyMeS learns low-level motor skills through gradient-based imitation learning, while a coding agent acquires high-level memory-management strategies through heuristic learning by iteratively updating an executable heuristic system from rollout feedback. Furthermore, we close the loop between steering and execution through multimodal stage-completion verification, which updates memory using proprioceptive signals and multi-frame VLM judgments. Compared with end-to-end memory-augmented VLAs, HyMeS requires demonstrations only for reusable motor skills rather than for every history-dependent task configuration, enabling data-efficient compositional generalization. On RoboMemArena, HyMeS improves mean cumulative success from 52.5% to 66.2% and mean task success from 41.3% to 60.1% over pi0.5, while outperforming PrediMem by 4.5 points in cumulative success and 14.5 points in task success.

# 论文总结：HyMeS——面向记忆依赖型机器人操作的混合学习框架

## 一、核心问题与研究背景

- **关键瓶颈**：现有视觉-语言-动作（VLA）策略（如 π0.5、π0.6、OpenVLA 等）虽已习得广泛的操控技能，但其架构本质上仍为**马尔可夫型**：仅依据当前观测或固定长度的短上下文生成动作片段。
- **任务痛点**：现实操控任务具有**非马尔可夫性**，需要从长时程交互历史中检索与任务相关的信息（如初始观察到的卡片颜色、需要重复的次数、物体原始位置等），而这些信息无法从当前单一观测恢复。
- **现有方案的局限**：
  - 端到端记忆增强 VLA（如 MemoryVLA、PrediMem、MemoryVLA++ 等）将记忆逻辑与运动技能耦合在权重空间中，需要覆盖组合式记忆空间的机器人示范数据，存在代价高、易遗忘、潜变量不可解释等问题。
  - 推理时引导方法（如 VLS、PPGuide、TouchGuide 等）虽保留基础策略，但引导信号仅基于当前观测或外部反应式信号，缺乏对 episode 级记忆的维护。
- **本文定位**：将**运动技能学习**与**记忆策略学习**解耦到不同表征空间（权重空间 vs. 代码空间），实现数据高效的可组合泛化。

## 二、核心方法论

### 1. 总体框架：双空间协同

- **权重空间（Weight Space）**：基于预训练 π0.5，通过基于梯度的流匹配模仿学习精调 VLA 的运动技能权重 θ*。精调完成后权重全程冻结，不因记忆需求而改动。
- **代码空间（Code Space）**：由编码智能体（如 Claude Code / Codex，底层为 Opus 4.8 模型）维护可执行启发式程序 P = (C, V, U)，分别包含约束选择规则、事件验证规则和记忆更新规则。

### 2. 数学建模

- **问题形式化**：在任务相关历史可被压缩为紧凑任务状态 zₜ 的前提下，专家策略满足 π*(aₜ|hₜ, ℓ) = π*(aₜ|oₜ, zₜ, ℓ)，而马尔可夫策略 πθ(aₜ|oₜ, ℓ) 因观测混淆（aliasing）无法区分不同动作模式。
- **闭环流程**：在每个控制步 t，依次执行：选择约束 Rₜ = C(sₜ, oₜ, ℓ) → 引导动作生成 aₜ = Steer(πθ*, Rₜ, oₜ, ℓ) → 阶段验证 eₜ = V(W_t; sₜ) → 记忆更新 sₜ₊₁ = U(sₜ, eₜ, oₜ)。

### 3. 关键技术细节

- **记忆条件引导（Memory-Conditioned Steering）**：在流匹配去噪过程中，向速度场注入约束奖励梯度：
  $$\hat{v} = v_{\theta^*}(a_\tau, \tau|o_t, \ell) + \lambda_t \nabla_{a_\tau} R_{\rho_t}(a_\tau, o_t; s_t)$$
  并通过 sigmoid 衰减调度 λ_t，使得记忆负责全局行为选择，VLA 负责接触丰富的运动执行。
- **可执行符号记忆**：sₜ = (plan, ρₜ, Bₜ, Nₜ, Fₜ)，记录阶段规划、活跃阶段、对象-位置绑定、事件计数与持久状态。
- **启发式学习（Heuristic Learning）**：编码智能体根据第 n 次回滚产生的符号执行轨迹 ξⁿ 与基准阶段判定 bⁿ 对程序进行编辑 P⁽ⁿ⁺¹⁾ = Edit(Pⁿ, ξⁿ, bⁿ)，无需梯度或专家动作标签。
- **多模态阶段完成验证 PACE（Proprioception-And-Completion-driven stagE-switching）**：
  - 本体感受信号捕捉动作相关运动模式并通过符号锁存器保留持续事件；
  - 视觉信号由 Qwen3-VL-8B 在 5 帧窗口内判读完成；
  - 通过 k-of-w 投票机制（默认 w=5, k=3）抑制孤立错误后才触发阶段切换。

## 七、主要结论与发现

- **核心收益**：在相同 π0.5 权重下，HyMeS 将整体 CSR 从 52.5% 提升到 66.2%，TSR 从 41.3% 提升到 60.1%。
- **相对基线**：相比 PrediMem，CSR 高 4.5 个百分点，TSR 高 14.5 个百分点，表明 HyMeS 能更高效地将中间进度转化为完整任务成功。
- **类别细分**：转移任务提升 26.6 个 TSR 点，计数任务提升 30.0 个 TSR 点，序列任务提升 22.5 个 TSR 点；遮挡任务相对 π0.5 仅 CSR 持平（50.6%）、TSR 提升 7.0 个点，是最困难类别。
- **真实机器人**：SO-101 上总体 TSR 从 25.7% 升至 57.1%，每个任务分别提升 50.0、26.7、20.0 个百分点。
- **消融结论**：
  - 回滚精炼使 CSR +8.5、TSR +18.4 个点，证明回滚经验是有效的记忆策略学习信号；
  - 仅视觉验证使 CSR/TSR 分别下降 16.0/21.7 点；仅本体感受验证分别下降 8.8/8.4 点，说明双模态互补对可靠阶段切换至关重要。

## 八、优点与亮点

- **范式创新**：首次系统提出"技能存于权重、记忆存于代码"的混合学习范式，清晰解耦两个本质不同的问题。
- **数据高效**：只需可复用运动技能的示范，无需覆盖组合式记忆配置，新记忆需求通过编辑代码即可实现，显著降低采集成本。
- **可解释性与可调试性**：符号记忆在每个控制步都可读，使失败可定位到记忆更新、运动执行或事件验证三类（论文图 4 即展示了抓取偏差、抖动误判为多按、按下深度不足等具体失败模式）。
- **闭环双向耦合**：在 VLS 的引导接口基础上引入记忆条件与执行反馈，构成双向耦合，区别于单向反应式引导方法。
- **实证完整**：涵盖仿真、真实机器人、分类别分析与失败可视化。
- **优雅的衰减调度**：通过 sigmoid 衰减让记忆主导全局行为选择，运动策略主导接触丰富执行，避免引导干扰电机行为。

## 九、不足与局限

- **状态表示局限**：仅适用于可压缩为紧凑符号状态的任务，难以直接扩展到开放词汇、视觉线索模糊或需要层次化/多模态记忆的复杂任务（作者列为未来工作）。
- **失败仍源于底层能力**：任务最终成功率仍受限于运动技能本身与阶段完成验证的可靠性，即使记忆与约束正确，瞄准偏差、抖动误判等仍会导致失败。
- **推理延迟与成本**：周期性 VLM 查询与编码智能体调用增加每回合延迟与算力开销，论文明确承认此点。
- **遮挡场景表现有限**：在遮挡任务上仅与 π0.5 持平于 CSR、TSR 仅提升 7.0 个点；视觉完成验证在遮挡下最不可靠。
- **基准覆盖偏窄**：消融任务仅 6 个，且未与最新一批记忆增强 VLA（MemoryVLA++、HiMem-WAM、EventVLA、Chronos 等）进行直接对比；真实机器人任务规模较小（35 次试验）。
- **算力信息缺失**：未报告训练算力、回滚次数、采样规模等关键复现性信息。
- **依赖外部强 VLM**：PACE 的可靠性强依赖 Qwen3-VL-8B 判读质量，模型替换或领域外分布可能带来性能下降。
- **代码空间修改安全边界**：编码智能体迭代编辑启发式程序，缺乏对程序正确性或安全性的形式化约束。
