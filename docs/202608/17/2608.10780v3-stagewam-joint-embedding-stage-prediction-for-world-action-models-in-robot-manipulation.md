## 摘要
通用机器人策略旨在将多模态观察与语言任务指令映射到跨多样化任务的动作。然而，现有方法通常将未来表示为固定的、短小的视频-动作片段。这种短期未来捕捉了用于动作执行的局部场景演化，但并未明确描述指定任务如何从当前阶段推进到下一阶段的阶段级未来。因此，我们区分了机器人操作中两种互补的未来：用于捕捉局部场景演化的短期物理未来，以及用于表征任务进度的阶段级语义未来。我们提出了 StageWAM，它在基于 Motus 的世界动作模型（WAM）的基础上，引入了 Stage-JEPA——一种目标条件联合嵌入预测架构（JEPA）预测器。给定当前观察与任务指令，Stage-JEPA 利用冻结的 V-JEPA2 编码器提取当前状态表示，并预测下一推断阶段的潜在目标。在 RoboTwin 2.0 的 50 个任务（涵盖干净与随机化环境）中，StageWAM 取得了 90.25% 的整体成功率，并将成功执行轨迹的平均执行步数相对最强基线减少了 5.97%。

## Abstract
Generalist robot policies aim to map multimodal observations and linguistic task instructions to actions across diverse tasks. However, existing methods typically represent the future as a fixed, short video-action chunk. This short-term future captures local scene evolution for action execution, but it does not explicitly describe the stage-level future that specifies how a task should progress from its current stage to the next. We therefore distinguish two complementary futures for robot manipulation: a short-term physical future to capture local scene evolution and a stage-level semantic future to represent task progress. We introduce StageWAM, which augments a Motus-based World Action Model (WAM) with Stage-JEPA, a goal-conditioned Joint-Embedding Predictive Architecture (JEPA) predictor. Given the current observation and task instruction, Stage-JEPA uses a frozen V-JEPA2 encoder to extract the current-state representation and predicts the latent target of the next inferred stage. Across 50 RoboTwin 2.0 tasks in clean and randomized environments, StageWAM achieves 90.25% overall success and reduces the mean number of execution steps in successful rollouts by 5.97% relative to the strongest baseline.

# StageWAM 论文总结

## 1. 核心问题与研究动机

- **现有策略的局限**：通用机器人策略（如 VLA、WAM）通常将未来预测建模为**固定的短时视频-动作片段**，仅能刻画局部场景演化（物体运动、接触等），但**没有显式建模"任务应从当前阶段推进到下一阶段"的语义进展**。
- **两类"未来"的区分缺失**：
  - **短期物理未来**：描述视频与动作的局部演化。
  - **阶段级语义未来**：描述下一个任务相关状态（物体状态、空间对齐、机器人–物体交互等）应当是什么。
- **核心问题**：如何让机器人在生成局部动作之前，先预测"下一个有意义的阶段"？
- **直接预测远期目标图像的不足**：像素级预测容易强调外观而非任务完成，因此本文转向在**表征空间（潜在空间）**中做预测，借鉴 JEPA 的思路。

## 2. 方法论：核心思想与关键技术细节

### 2.1 整体框架 StageWAM
- 在基于 **Motus** 的 World Action Model（WAM）基础上，新增 **Stage-JEPA**（目标条件 JEPA 预测器）分支。
- **Stage-JEPA**：用冻结的 **V-JEPA2** 编码器提取当前状态表征，并预测下一阶段的潜在目标。
- **门控接口（Gated Interface）**：通过一个全局有界标量门 α，将预测的阶段潜在注入到 WAM 的视频 token 中，作为去噪条件。

### 2.2 任务形式化
- 经典行为克隆：`A_t = π(o_t, s_t, l)`
- WAM 联合建模：`p_φ(V_t^short, A_t | o_t, s_t, l)`，其中 V_t^short = (o_{t+1}, …, o_{t+H_v}) 为短期视觉未来。
- **阶段条件操作**（本文新增）：
  - 阶段未来预测：`Ŷ_t^stage = f_θ(o_t, l)`
  - 条件 WAM：`p_φ(V_t^short, A_t | o_t, s_t, l, Ŷ_t^stage)`

### 2.3 两阶段训练流程
- **Stage I：训练 JEPA 预测器**
  - **阶段对自动构建**：无需人工标注阶段边界。基于冻结 V-JEPA2 特征的过渡启发式：
    - 每 8 帧采样候选中心，最多 32 个候选。
    - 每个候选取中心 64 帧切片，用冻结 V-JEPA2 编码为 token 表示 U_j 与池化表示 v_j。
    - 评分：在局部窗口 w=2 内计算表征变化（含 clip 级欧氏距离与 token 级最大距离），并做逐段 min-max 归一化。
    - 时间 NMS（半径 r=3）保留最多 K=5 个关键帧；与首末帧一起构成边界序列 B = (b_0, …, b_L)。
    - 稠密配对：对每个阶段区间 [b_i, b_{i+1})，将每个当前帧 t 与下一边界 b_{i+1} 配对为 (t, b_{i+1})。
  - **目标条件预测**：将每对 (t, b_{i+1}) 转为以 t 为中心的 64 帧当前切片 S_t 和以 b_{i+1} 为中心的 64 帧目标切片 S_t^target；冻结 V-JEPA2 独立编码得到 z_t 与 z_t^target；预测器输出 token 级下一阶段预测 Ẑ_t^target，池化并归一化为 ẑ_t^target。
  - **损失函数（余弦对齐）**：`L_stage = (1/B) Σ_i (1 − (ẑ_target_i)^T z_target_i)`。
- **Stage II：训练阶段条件 WAM**
  - 冻结 Stage-JEPA，仅训练 WAM 与门控接口。
  - WAM 主体采用 Motus（Mixture-of-Transformers）：视频专家（来自 Wan2.2 初始化）、动作专家、理解专家（冻结 Qwen3-VL）；通过 Tri-modal Joint Attention 交互。
  - **门控注入机制**：
    - Stage-JEPA 输出 `Ẑ_t^target ∈ R^{N_j × d_j}`，池化为标量特征并经 MLP `P_ψ` 映射到 Wan 视频 token 维度：`h_t = P_ψ(Pool(Ẑ_t^target)) ∈ R^{d_v}`。
    - 全局门：`α = 0.2 σ(β)`（β 为可学习零维标量，α 初始 0.02，所有样本/层/token/通道共享）。
    - 加性注入：`X̃_vt = X_vt + α h_t`（h_t 为样本特有，被广播到该样本全部视频 token）。
  - **训练损失**：`L = L_video + L_action + L_reg`，其中 `L_reg = λ_g α² + λ_ρ(ρ − ρ_0)²`，ρ 衡量注入特征相对原视频 token 的幅值比。

### 2.4 闭环推理
- 维护 64 帧因果观察缓冲区（不足时用最早观测帧重复填充）。
- 每步先用冻结 Stage-JEPA 从缓冲区与指令预测阶段潜在，再调用 WAM 生成短期视频未来与动作块；执行、追加观测、再查询。
- **阶段边界与目标切片仅为训练时监督**，推理时模型自行从历史预测阶段条件。

## 6. 主要结论与发现

- **整体性能**：StageWAM 在 RoboTwin 2.0 上达到 clean **91.42%** / randomized **89.08%** 成功率（整体 90.25%），优于最强基线。
- **分语义类别**：在 clean 7 类中 5 类领先、randomized 中 6 类领先；Handover、Targeted placement、Container packing、Arrangement & stacking、Tool use 上提升显著。
- **提升显著的任务类型**：需要"明确任务进展变化"的任务（交接、目标放置、装载、堆叠、工具使用/动态操控）受益最明显。
- **改进有限的任务**：Acquisition & lifting 主要依赖抓取几何与接触稳定性，阶段结构可补空间有限；Articulated/device interaction 还需要机制特定接触与时序精确性，当前间接阶段信号不够。
- **执行效率**：平均回合长度 156.28 → 132.80 步（−15.02%，包含失败）；成功回合 79.57 → 74.82 步（−5.97%），减少冗余修正。
- **消融结论**：
  - 去掉 JEPA 退化最大（87.23%）；
  - 仅在当前帧表征使用阶段信号也明显退化（89.89%），说明注入未来潜在位置关键；
  - 去掉 Stage-I 训练仍有竞争力（89.98%），但加入任务特定目标更佳；
  - 门控正则项影响较小（89.88%）。

## 7. 优点

- **概念清晰**：明确区分"短期物理未来"与"阶段级语义未来"，为未来建模提供双时间尺度视角。
- **无需人工阶段标注**：基于 V-JEPA2 表征变化 + 时间 NMS 自动构造阶段边界。
- **简洁集成**：通过全局标量门 α 的加性注入，对 WAM 主干侵入小、可复用到任何带视觉条件流的 WAM。
- **完整证据链**：仿真 50 任务 × 双配置 + 完整逐项结果 + 4 项消融 + 轨迹可视化 + 真实机器人验证。
- **效率收益显著**：在不损成功率的前提下缩短成功回合平均步长。
- **强基线对比**：与 Motus（直接骨干）使用同协议，公平性较高。

## 8. 不足与局限

- **工具使用类在随机化下降**：clean 95.57% → randomized 87.86%，与 X-VLA、π0.5 等相比优势缩小；Hanging Mug、Place Object Cabinet 等少数任务上低于 Motus。
- **真实机器人评估偏少**：仅 2 个任务、每任务 20 次试验，且每任务单独训练一个模型；缺乏与 Motus 在真实平台上的直接对比（仅与 π0.5 对比）。
