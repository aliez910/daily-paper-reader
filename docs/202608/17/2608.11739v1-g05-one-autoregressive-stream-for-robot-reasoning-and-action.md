## 摘要
当前主流的视觉-语言-动作（VLA）模型范式是将预训练的VLM与单独训练的流匹配动作专家相耦合。这使得VLM沦为上下文编码器，而非决策者。我们提出了G0.5，一个预训练的自回归VLA，其中单个Transformer解码器在统一目标下同时输出推理token与动作token。三个关键组件使这一方案在基础模型规模下可行：一个可学习的跨具身动作分词器，将异构机器人动作映射到统一的词表；一条原生思维链流，将任务分解、物体定位与动作提示与动作token交错排列；以及一个视觉记忆模块，通过视觉编码器注入多秒级的历史信息。由于推理与动作共享同一套权重，预训练VLM的能力得以直接迁移至物理行为：模型能紧密遵循指令，并能通过提示直接调整动作粒度、任务时长以及对分布外场景的应对方式，无需额外训练。G0.5在大规模机器人数据集与VQA样本联合预训练后，在7个独立场景中全面超越现有最优模型：R1lite与R1pro机器人的真实世界微调（76.7%，对比π_{0.5}的53.3%与GR00T-N1.7的24.4%）、2025年BEHAVIOR挑战赛中50项长时序家庭移动操控任务的通用策略评估（31.4%，对比π_{0.5}的26.3%与挑战赛冠军的26.1%）、DROID后训练后对未见环境与物体的零样本迁移（82.5%）、语言跟随的Pick-and-Place基准（98.9%）、LIBERO（93.3%）以及SimplerEnv-Bridge（87.3%）。

## Abstract
The prevailing recipe for Vision-Language-Action (VLA) models couples a pretrained VLM with a separately trained flow-matching action expert. This makes the VLM a context encoder rather than a decision-maker. We introduce G0.5, a pretrained autoregressive VLA in which a single transformer decoder emits reasoning and action tokens under a single objective. Three components make this tractable at foundation-model scale: a learnable cross-embodiment action tokenizer that maps heterogeneous robot actions into a shared vocabulary; a native chain-of-thought stream interleaving task decomposition, object grounding, and action hints with action tokens; and a visual memory module that injects multi-second history through the vision encoder. Because reasoning and action share a single set of weights, the pretrained VLM's capabilities carry over to physical behavior: the model follows instructions closely, and prompts directly steer action granularity, task horizon, and out-of-distribution scene handling without further training. Pretrained on a large collection of robot datasets together with VQA samples, G0.5 surpasses state-of-the-art models across 7 independent regimes: real-world fine-tuning on R1lite and R1pro robots (76.7\% vs.\ 53.3\% for $π_{0.5}$ and 24.4\% for GR00T-N1.7), the 2025 BEHAVIOR Challenge on 50 long-horizon household mobile manipulation tasks using a generalist policy (31.4\% vs.\ 26.3\% for $π_{0.5}$ and 26.1\% for the challenge winner), DROID post-training followed by zero-shot transfer to an unseen environment and objects (82.5\%), a language-following Pick-and-Place benchmark, LIBERO (98.9\%), RoboTwin 2.0 (93.3\%), and SimplerEnv-Bridge (87.3\%).

## 1. 核心问题与研究动机

- **背景**：当前主流的视觉-语言-动作（VLA）模型范式（如 π₀、π₀.₅、GR00T-N1 等）通常将预训练的视觉-语言模型（VLM）与一个单独训练的流匹配（flow-matching）动作专家模块进行耦合。
- **核心问题**：在这种"两阶段/双模块"设计中，VLM 实际上被降级为一个**上下文编码器**（context encoder），仅负责把图像和语言指令编码为特征向量，而不参与真正的决策过程；决策逻辑完全交给后接的、单独训练的动作专家。
- **由此带来的局限**：
  - 预训练 VLM 中蕴含的推理、规划、知识与泛化能力无法被充分迁移到物理动作层面；
  - 模型对指令的细粒度遵循、长时序任务规划、分布外场景的应对均受限于动作专家的能力；
  - 提示（prompt）无法直接调控动作粒度或任务跨度，缺乏灵活性。
- **整体目标**：证明 VLM 的"推理能力"可以直接迁移为"物理行为能力"，并通过单一自回归流同时建模语言推理与机器人动作。

## 2. 方法论

### 2.1 整体核心思想

- 采用**单一 Transformer 解码器**，在**统一的自回归目标**下，交错输出"推理 token"和"动作 token"，推理与动作共享同一套参数。
- 这是一种"把 VLM 直接当作决策者"的范式，与传统"VLM 编码 + 动作专家解码"形成对比。

### 2.2 三大关键组件

1. **跨具身动作分词器（Learnable Cross-Embodiment Action Tokenizer）**
   - 一个可学习的分词器，将来自不同形态、不同自由度机器人的异构动作空间映射到一个**统一的离散词表**；
   - 使单一自回归模型能够处理多种机器人本体（embodiment）的数据。

2. **原生思维链流（Native Chain-of-Thought Stream）**
   - 在动作 token 之前/之间，交错插入**任务分解（task decomposition）、物体定位（object grounding）、动作提示（action hints）**等推理 token；
   - 让模型具备"先想后做"的链式思考能力，推理与动作在同一序列中联合训练。

3. **视觉记忆模块（Visual Memory Module）**
   - 通过视觉编码器注入**多秒级的历史视觉信息**；
   - 解决自回归模型上下文窗口受限、无法感知长时间历史的问题，使其适用于长时序任务。

### 2.3 算法流程（基于摘要重构）

- 输入：当前多模态观测（视觉 + 语言指令 + 历史视觉记忆）；
- 处理：
  1. 视觉编码器对当前帧及多秒历史帧进行编码；
  2. 分词器将目标机器人动作映射为离散动作 token；
  3. 单个 Transformer 解码器以自回归方式依次生成"推理 token（任务分解/物体定位/动作提示）→ 动作 token 序列"；
- 输出：推理文本 + 一段连续动作 chunk（去分词后送入机器人执行）。

## 6. 主要结论与发现

1. **统一自回归范式有效**：单一 Transformer 解码器在统一目标下同时生成推理与动作 token，可以在多个基准上击败"VLM + 流匹配专家"的双模块设计。
2. **VLM 能力可直接迁移到物理动作**：推理与动作共享权重后，指令遵循、任务规划等 VLM 能力直接体现在机器人行为上。
3. **提示即可调控行为**：通过修改 prompt，无需再训练即可调整：
   - 动作粒度（精细 vs. 粗粒度）；
   - 任务跨度（短时序 vs. 长时序）；
   - 分布外场景的应对方式。
4. **跨具身能力**：通过统一动作词表，模型在不同机器人本体间共享能力。
5. **SOTA 成绩**：在 7 个独立 regime 上均超越现有最优模型，真实机器人相对 π₀.₅ 提升超过 23 个百分点。
