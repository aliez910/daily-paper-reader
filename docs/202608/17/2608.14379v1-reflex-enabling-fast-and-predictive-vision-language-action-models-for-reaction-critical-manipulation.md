## 摘要
视觉-语言-动作（VLA）模型近期在机器人操作任务中取得了令人瞩目的性能。然而，现有基准主要评估模型在静态操作任务上的泛化能力，在很大程度上忽视了动态交互场景。为填补这一空白，我们提出了ReflexBench，一个针对反应关键型操作任务的基准。ReflexBench包含六个动态任务，并引入了一种评估框架，该框架将仿真器步进与机器人控制解耦，同时支持在同步和异步推理下的可配置延迟。在ReflexBench的基础上，我们提出了ReflexVLA，一种专为反应关键型操作任务设计的高效VLA模型，无需大规模机器人数据预训练。ReflexVLA通过在视觉骨干网络中引入潜在未来预测与多帧时序融合来增强时序推理能力，同时通过批处理视觉编码和CUDA Graph重放来降低部署延迟。实验表明，ReflexVLA在持续提升动态操作性能的同时，在标准静态操作基准上保持了具有竞争力的准确率，真实世界实验进一步验证了其在实际部署条件下的有效性。项目主页：https://reflexvla.github.io

## Abstract
Vision-Language-Action (VLA) models have recently achieved promising performance in robotic manipulation. However, existing benchmarks mainly evaluate generalization on static manipulation tasks and largely overlook dynamic interaction scenarios. To address this gap, we present ReflexBench, a benchmark for reaction-critical manipulation. ReflexBench contains six dynamic tasks and introduces an evaluation framework that decouples simulator stepping from robot control while supporting configurable latency under synchronous and asynchronous inference. Building upon ReflexBench, we propose ReflexVLA, an efficient VLA model designed for reaction-critical manipulation without large-scale robot-data pretraining. ReflexVLA enhances temporal reasoning through latent future prediction and multi-frame temporal fusion within the vision backbone, while reducing deployment latency through batched visual encoding and CUDA Graph replay. Experiments show that ReflexVLA consistently improves dynamic manipulation performance while maintaining competitive accuracy on standard static manipulation benchmarks, and real-world experiments further demonstrate its effectiveness under practical deployment conditions. Project website: https://reflexvla.github.io

## 1. 核心问题与研究动机

- **核心问题**：现有的视觉-语言-动作（VLA）模型在静态机器人操控任务上表现优异，但面对需要**快速反应**和**对未来状态进行预测**的动态交互场景时，仍面临两个关键瓶颈：
  - **感知-执行延迟（latency）**：现有 VLA 模型通常基于当前观测条件化动作输出，推理延迟会造成显著的动作滞后，在动态场景中可能导致任务失败（如拦截运动物体、在精准时刻插入零件等）。
  - **未来感知能力不足**：多数 VLA 模型仅依赖当前帧观测，缺乏对未来状态（如物体运动轨迹）的显式推理能力。
- **现有研究方向的局限性**：
  - 动态操作基准（如 DynamicVLA、PUMA 等）主要作为评测平台，未提供统一框架同时考察"预测能力"与"推理效率"。
  - 增强预测推理的方法往往引入额外计算开销。
  - 关注推理加速的方法（如 FASTER、VLASH）通常只关注效率本身，并未显式建模未来感知。
- **论文意义**：首次将**反应速度**与**未来预测**统一在同一框架中，提出基准（ReflexBench）与模型（ReflexVLA）两方面的系统性解决方案。

## 2. 方法论

### 2.1 ReflexBench（基准与评估框架）

- **任务设计**：包含 6 个反应关键型仿真操控任务：
  - 传送带抓取放置（Conveyor Belt Pick-and-Place）
  - 接球（Ball Catching）
  - 打地鼠（Whack-a-Mole）
  - 滚动球拦截（Rolling Ball Interception）
  - 抛球入箱（Ball Throwing）
  - 旋转插孔（Rotating Peg Insertion）
- **数据采集**：采用基于规划的数据收集管线，将任务分解为多个子目标阶段，并利用实时位置/速度预测未来轨迹；对于复杂交互动力学，训练任务专属的强化学习策略生成演示轨迹。每任务 200 条专家演示。
- **延迟感知评估协议**：
  - **仿真器与控制解耦**：仿真器持续运行，策略推理过程不会暂停环境。
  - **同步推理（Synchronous）**：仿真器暂停等待策略推理完成，模拟推理阻塞部署。
  - **异步推理（Asynchronous）**：策略推理与动作执行重叠，新动作在下一周期生效。
  - **延迟注入**：利用实时因子（RTF）将真实推理延迟映射为仿真延迟。

### 2.2 ReflexVLA（核心模型）

模型以紧凑型 VLA 架构（VLA-Adapter）为基座，融合三个关键设计：

#### (a) 潜在未来预测（Latent Future Prediction）

- 直接预测未来图像代价高且迫使模型关注低层外观细节，故改为在**语义潜在空间**中预测。
- 使用冻结的 DINOv3 编码器提取未来观测特征 $y_{t+i} = \phi_{\text{DINOv3}}(o_{t+i}) \in \mathbb{R}^{1024}$。
- 在多模态输入序列中追加 $H$ 个可学习的未来 token（$H$ 与动作块大小相同），经过 Transformer 后投影到 DINOv3 特征空间，通过掩码余弦相似度损失进行预测：
  - $\mathcal{L}_{\text{future}} = \frac{\sum_i m_i[1 - \cos(\hat{y}_{t+i}, y_{t+i})]}{\sum_i m_i}$
- 总损失：$\mathcal{L} = \mathcal{L}_{\text{act}} + \lambda_{\text{future}} \mathcal{L}_{\text{future}}$，其中 $\lambda_{\text{future}} = 0.05$。

#### (b) 多帧时序融合（Multi-Frame Temporal Fusion）

- 简单拼接多帧视觉 token 会导致语言模型输入 token 数膨胀至 $V \cdot T \cdot P$，计算成本二次增长。
- 在视觉骨干网络**中间层**特征上执行时间融合（保留更丰富的局部外观与运动线索），最终只将当前帧的融合表示送入语言模型。
- 对每个视图-空间位置构建时间轨迹，经 LayerNorm → 降维投影 → 因果多头注意力 → 上投影回原维度后，叠加到当前帧最终层特征上：
  - $\tilde{x}_{v,p,t} = x^{\text{final}}_{v,p,t} + \Delta x_{v,p,t}$
- 因果掩码保证与在线部署一致；视觉 token 数与单帧设置相同，避免语言模型侧计算开销剧增。

#### (c) 推理延迟优化（Inference Latency Optimization）

- **批处理视觉编码**：将 $V \times T$ 张图像打包为一次视觉骨干前向，减少框架开销并提升 GPU 利用率。
- **CUDA Graph 重放**：将完整推理流程捕获为 CUDA Graph $\hat{a}_{t:t+H-1} = G(x_{\text{text}}, x_{\text{vision}}, x_{\text{state}})$，消除每次控制周期的 GPU 内核调度与运行时分发开销。
- 上述优化不修改策略架构或学习目标，仅降低部署开销。

## 6. 主要结论与发现

- **ReflexVLA 在 ReflexBench 上以 1B 参数取得最优平均成功率 50.4%**，超越所有基线（含 7B 的 OpenVLA-OFT 和 4B 的 PUMA）。
- 相比基座模型 VLA-Adapter（30.3%），ReflexVLA 提升 +20.1%，验证三大设计的有效性。
- **异步推理 + 大块大小 + 短执行步数 + 高频**组合在反应关键型任务中表现最佳。
- 在 LIBERO 上平均成功率 97.2%，与最佳 VLA 相当（97.3%），表明动态操控增强未损害通用静态操控能力。
- 消融研究发现：
  - 冻结 DINOv3 特征作为预测目标显著优于可学习目标（62.8% vs 4.9%）。
  - 中间层特征做时序融合优于最终层（71.7% vs 68.2%）。
  - 推理延迟优化不仅降低延迟（125.1 ms → 65.0 ms），还提升成功率（71.7% → 73.8%）。
- 真实世界实验中，ReflexVLA 在 3 个任务上均优于 SmolVLA，并在仅 1/4 模型大小下与 PUMA 相当。

## 8. 不足与局限

- **未进行大规模预训练**：未来预测与时序融合模块仅在微调阶段引入，作者承认这可能限制其全部潜力。

- **延迟建模简化**：仿真中的延迟注入未涵盖更复杂的真实部署因素（如通信抖动、传感器噪声、CPU-GPU 异构执行等）。
- **缺少失败案例分析**：对 VLA-Adapter 与 ReflexVLA 在个别任务（如 Ball Catching 仅 7.3%）上的性能瓶颈未深入分析。
