## 摘要
世界动作模型（WAM）通过联合建模动作与未来观测来提升机器人策略学习。然而，未来预测仅以任务提示和观测上下文为条件，可能会捕捉到的是通用的任务推进过程，而非已执行动作所特有的后果。我们提出了SelfWAM，一个基于模态专用混合变换器（MoT）架构构建的统一自接地WAM，它联合预测动作、动作条件下的未来RGB帧以及机器人自掩码，从而将未来预测建立在机器人可见本体及其动作引起的运动之上。在联合训练过程中，SelfWAM允许未来视觉查询关注已演示动作的干净副本，使视频分支成为特定动作的后果模型，同时保持快速仅动作推理路径不变。为了将视频学习聚焦于与动作相关的视觉变化，我们针对未来机器人自掩码预测使用了提示特定的目标函数，该函数去除了外观细节，并提供了其时间演化与条件动作紧密耦合的目标。干净动作条件与未来自掩码监督的结合，使未来预测能够更直接地反映已执行动作如何改变机器人可见的运动以及周围场景。在RoboTwin 2.0和真实世界操控任务上的实验表明，SelfWAM能够生成对动作更敏感的未来预测，并在保持快速策略推理的同时提升策略性能。

## Abstract
World Action Models (WAMs) improve robot policy learning by jointly modeling actions and future observations. However, conditioning future prediction only on the task prompt and observation context risks capturing generic task progression rather than the action-specific consequences of the executed action. We introduce SelfWAM, a unified self-grounded WAM built on a modality-specialized Mixture-of-Transformers (MoT) architecture that jointly predicts actions, action-conditioned future RGB frames, and robot self-masks, thereby grounding future prediction in the robot's visible body and its action-induced motion. During joint training, SelfWAM allows future visual queries to attend to a clean copy of the demonstrated action, turning the video branch into an action-specific consequence model while leaving the fast action-only inference path unchanged. To focus video learning on action-relevant visual changes, we use prompt-specific objectives for future robot self-mask prediction, which removes appearance details and provides a target whose temporal evolution is tightly coupled with the conditioning action. Together, clean-action conditioning and future self-mask supervision make future predictions more directly reflect how the executed action changes the robot's visible motion and the surrounding scene. Experiments on RoboTwin 2.0 and real-world manipulation tasks show that SelfWAM produces more action-sensitive futures and preserves fast policy inference, while improving policy performance.

# SelfWAM 论文详细总结

## 1. 核心问题与整体含义（研究动机与背景）

- **现有 WAM 的关键缺陷**：World Action Models（WAM）通过联合建模动作与未来观测来提升机器人策略学习，但当前方法（如 FastWAM）在做未来视频预测时，仅以当前观测和任务提示为条件，并未将"产生该未来的演示动作"作为条件输入。这意味着视频分支仅学到"通用的任务推进过程"，而无法显式区分不同动作带来的差异化视觉后果。
- **因果耦合不足带来的风险**：
  - 同一观测可能对应多个合理动作，各自会引发截然不同的未来；动作未被条件化时，模型难以建立动作—后果的因果对应。
  - RGB 未来预测中，外观、纹理、光照、背景等弱相关因素可能主导学习目标，遮蔽对机器人运动本身的监督。
- **本文的核心主张**：机器人策略需要一个"自接地（self-grounded）"的未来预测——显式建模机器人可见本体及其动作诱导的运动，将未来视觉预测从"被动观察者"转变为"动作后果模型"。

## 2. 方法论

### 2.1 整体框架：基于 MoT 的统一自接地 WAM

- **双流 MoT 架构**：
  - **视频流**：使用预训练的视频扩散主干（WAN2.2-5B）处理当前观测与 noisy 未来视频潜变量。
  - **动作流**：一个轻量级动作专家，处理 noisy 未来动作 token，其参数通过权重插值从视频主干迁移而来。
  - 两路通过混合注意力（mixed attention）耦合，模态特定的 FFN 分别处理各自 token。
- **保留 FastWAM 的快速动作推理路径**：部署时仅运行当前观测编码与动作专家去噪，丢弃干净动作与未来视频分支。

### 2.2 关键创新一：Clean-Action 条件化（非对称信息流）

- 在训练时构造一条**"干净动作流"**：将演示动作以未扰动（timestep=0）的副本编码，并仅暴露给**未来视觉查询**，从而：
  - 视频分支成为"动作特定后果模型"——能根据不同动作条件生成不同未来。
  - 策略侧（noisy 未来动作 token）只能看到当前观测、语言、本体感知与自身 noisy 动作状态，**无法访问干净动作副本或未来视觉 token**，避免目标泄漏。
- **形式化注意力规则**（设 O 为当前上下文，$\tilde{A}$ 为 noisy 动作 token，A 为干净动作 token，$\tilde{V}$ 为 noisy 视觉 token）：
  - $\tilde{Q}_A \rightarrow \{O, \tilde{A}\}$
  - $\tilde{Q}_V \rightarrow \{O, \tilde{V}, A\}$
  - $Q_A \rightarrow \{O, A\}$
- 部署或可选 rollout 时，干净动作槽可插入候选动作样本，配合输出 prompt（RGB / 自掩码）生成对应未来。

### 2.3 关键创新二：未来机器人自掩码预测

- **目标定义**：预测与未来 RGB 时空对齐的机器人自掩码视频（binary segmentation），而非 RGB，从而：
  - 去除外观、纹理、背景等与动作弱相关的变化；
  - 掩码的时间演化直接由条件动作决定，提供更聚焦的"具身运动"监督信号。
- **实现方式**：复用同一视频主干，仅通过不同输出 prompt（"a robot-arm mask video…"）切换预测目标，共享时空 token 布局、噪声调度与位置编码。
- **训练实例设计**：
  - RGB 实例：L_rgb + L_act 双监督；
  - 掩码实例：仅 L_mask 监督，不计入动作目标；
  - 采样比例为 9:1。

### 2.4 训练目标与优化

- 采用 flow-matching 目标，总损失：
  $$L = \lambda_{\text{act}} L_{\text{act}} + \lambda_{\text{video}} L_{\text{rgb/mask}}$$
- 设置 $\lambda_{\text{act}} = \lambda_{\text{video}} = 1$，AdamW，学习率 $1\times10^{-4}$，训练 5 epoch。

### 2.5 问题形式化

- 策略最优解：$\pi^*(c_t) = \arg\min_{\hat{a}} E[\ell_a(\hat{a}, a_t) | c_t]$
- 世界模型最优解：$F^*(c_t, a_t) = \arg\min_{\hat{o}} E[d_v(\hat{o}, o_t^{\text{fut}}) | c_t, a_t]$
- 二者联合学习，分别回答"做什么"与"在给定动作下将发生什么"。

## 6. 主要结论与发现

- **策略性能**：
  - RoboTwin 2.0 平均成功率 92.62%（clean 92.16% / random 93.08%），优于 FastWAM（91.84%）、GigaWorld-Policy（85.70%）、Motus（87.84%）、π0.5（79.75%）、π0（62.16%）；
  - 在场景随机化设置下提升更明显，提示自接地监督有助于提升外观鲁棒性；
  - 真实机器人四任务平均 95%，优于 FastWAM（85%）与 π0.5（90%）。
- **未来视频保真度**：LPIPS 由 0.0636 降至 0.0429，PSNR 由 29.24 升至 32.79，FVD-I3D 由 45.92 降至 34.55。
- **动作敏感性**：WorldArena Action Following 由 0.0000 提升至 0.0184；Subject/Background Raw Consistency 同步提升。
- **方向性扰动**：动作未条件化基线几乎不变，SelfWAM 预测的机器人自掩码按指令方向移动，与真实运动趋势一致。
- **连续插值**：SelfWAM 在 α 变化时预测从"保持"渐变到"演示动作结果"，呈现连续、方向一致的变化；基线则几乎不变。
- **推理效率**：动作-only 延迟 +0.97%（320.7 → 323.9 ms），动作+视频联合延迟 +1.36%，峰值显存无变化，部署成本几乎不变。
- **clean-path / noisy-path 一致性**：最大 NRMSE ~1e-5，最大余弦距离 ~6e-11，验证干净动作表示可被视为去噪路径的零噪声端点，不存在层级特异性失配。

## 7. 优点

- **方法论亮点**：
  - **非对称信息流设计**精巧：通过"干净动作副本仅暴露给未来视觉查询"实现动作条件化同时防止目标泄漏，既保留了 FastWAM 的快速动作推理路径，又将视频分支转为动作特定后果模型。
  - **自掩码作为辅助目标**：以最小代价（不增加部署开销）提供"具身聚焦"的监督信号，巧妙避开 RGB 监督中外观/背景噪声的主导问题。
  - **统一架构与多任务复用**：同一视频主干、同一时空布局，仅切换 prompt 与目标，复用预训练视频扩散先验。
- **实验亮点**：
  - 同时报告 clean / random 仿真、真实机器人、未来视频保真度、动作敏感性、推理效率、组件消融、表征一致性诊断；
  - 引入 WorldArena 指标与方向扰动、连续插值研究，从"参考相似度"拓展到"动作敏感性"维度；
  - 在 RoboTwin 2.0 上报告完整 50 任务级别的结果，便于下游研究者细粒度分析。
- **工程亮点**：
  - 推理代价几乎不增加，部署友好；
  - 训练/部署解耦清晰，便于在边缘机器人平台上落地。

## 8. 不足与局限

- **物理建模局限**：
  - 论文明确指出未显式建模接触（contact）、力（force）、被遮挡的交互——这对接触密集型操作与部分可观测场景的鲁棒性仍是关键瓶颈；
  - 自掩码采用离线 RobotSeg 生成，标签噪声可能传播到世界模型监督中。
- **评估覆盖**：
  - 真实机器人仅 4 个相对结构化的桌面任务，且每任务 10 次试验，统计样本偏小；
  - RoboTwin 2.0 视频质量评估使用 1% 数据子集，且是已观测轨迹的拟合而非真正"未来预测泛化"测试，论文中已诚实指出这一点。
- **效率与扩展性**：
  - 训练需要 64×A800 算力（约 30 小时），对中小实验室门槛较高；
  - 干净动作与未来视觉 token 在训练时仍需进入 Transformer，长序列注意力成本随 H 与 K 增长；
  - 真实机器人的 9.5M transitions 数据规模与 π0.5 等基础模型相比仍较小，泛化上限受数据约束。
- **方法层面**：
  - 自掩码监督采样比例仅 10%，未来若进一步增大比例可能引入外观信息损失或训练不稳定性，论文未给出系统研究；
  - 干净 / noisy 路径一致性虽得到验证，但隐含假设是动作专家容量充足且迁移插值足够稳健，对其他视频主干是否仍成立尚需验证。
- **公平性与偏差风险**：
  - 真实机器人评估样本小、易受摆放随机化与人工判断影响，论文中规则明确（"完全无人为干预才算成功"）但仍存在主观偏差；
  - FastWAM 等基线未在干净动作 + 自掩码配置下对比，难以完全剥离"动作条件化"与"自掩码监督"的独立贡献——虽做了消融，但仅在 RoboTwin 2.0 上进行。
