## 摘要
VLA模型的视觉表征对于空间精确的机器人操控仍然不可靠。我们发现，VLA中的视觉编码器同样存在先前在通用视觉Transformer中所记录的注意力伪影，并进一步揭示，在具身策略中，这些伪影与后训练阶段所获得的空间感知能力密切相关。随着编码器学习诸如物体位置、深度顺序和局部几何等任务相关信息，有限的全局token容量会导致部分信息溢出到信息量较低的patch token中。我们提出了AtVLA，一个将可学习的register token插入视觉编码器的框架。该框架仅使用具身数据和原始动作目标进行端到端训练，这些register token便涌现为承载具身空间信息的专用载体，而其余patch token则恢复了干净且空间忠实的注意力分布，这对于精确目标定位和细粒度接触至关重要。干净的注意力恢复了可靠的定位能力，但无法弥补低分辨率观测中已丢失的几何细节。因此，AtVLA将注意力矫正与不确定性门控的局部精化相结合。动作专家采样多个动作块，并通过其不一致性来估计不确定性；仅对不确定性较高的预测，利用动作条件下的注意力展开来确定任务相关区域，对其进行裁剪后以高分辨率重新编码，并附加到已缓存的前缀上以生成精化后的动作。在LIBERO、SimplerEnv以及一个具有挑战性的单视角真实世界基准上的实验表明，AtVLA将LIBERO的平均成功率从94.2%提升至98.4%，将真实世界成功率从46.5%提升至69.0%。裁剪操作仅在约30%的重规划步骤中触发，在代表性部署设置下，总计算量仅为基础模型的1.4–1.6倍。

## Abstract
Visual representations of VLA models remain unreliable for spatially precise robotic manipulation. We uncover that vision encoders in VLAs also exhibit attention artifacts previously documented in generic Vision Transformers, and further show that, in embodied policies, these artifacts are closely associated with spatial perception capabilities acquired during post-training. As the encoder learns task-relevant information such as object location, depth ordering, and local geometry, limited global-token capacity causes part of this information to spill into low-information patch tokens. We introduce AtVLA, a framework that inserts learnable register tokens into the visual encoder. Trained end-to-end using only embodied data and the original action objective, these registers emerge as dedicated carriers of embodied spatial information, while the remaining patch tokens recover clean and spatially faithful attention distributions crucial for precise target localization and fine-grained contact. Clean attention restores reliable localization, but cannot recover geometric details lost in low-resolution observations. AtVLA therefore couples attention rectification with uncertainty-gated local refinement. The action expert samples multiple action chunks and estimates uncertainty from their disagreement; only for uncertain predictions, action-conditioned attention rollout identifies the task-relevant region, which is cropped, re-encoded at high resolution, and appended to the cached prefix for refined action generation. Across LIBERO, SimplerEnv, and a challenging single-view real-world benchmark, AtVLA improves the average LIBERO success rate from 94.2% to 98.4% and real-world success from 46.5% to 69.0%. The cropping is triggered on approximately 30% of replanning steps, resulting in only 1.4-1.6x the total computation of the base model under the representative deployment setting.

## 1. 核心问题与研究动机

- **研究背景**：视觉-语言-动作（VLA）模型通过大规模视觉-语言预训练与机器人数据后训练，将语义知识迁移到连续控制策略中，但在需要**空间精确操控**（目标定位、几何推理、精细接触）时仍存在明显的视觉表征瓶颈。
- **关键观察**：
  - 当前 VLA 的视觉编码器存在先前在通用 Vision Transformer 上记录的"高范数伪迹"（attention artifacts），即低信息背景 patch 被当作全局信息仓库，挤压局部空间内容、破坏 dense attention map。
  - 本文的**新发现**是：这些伪迹在**具身后训练（embodied post-training）阶段被加剧**——随着编码器习得任务相关的目标位置、深度顺序、实例结构与局部几何信息，有限的全局 token 容量会让部分任务相关信息"溢出"到 patch token，存入了错误的表征通道。
- **两个被识别的瓶颈**：
  - (a) 目标定位常常出错，注意力图被高范数伪迹污染；
  - (b) 即使定位正确，低分辨率第三视角难以提供接触区域所需的局部几何细节；腕部相机虽近却受视角变化影响。
- **核心动因**：需要一个"先恢复可靠定位，再按需提升分辨率"的选择性粗到精机制，同时避免引入额外传感器、标定或显式 3D 表达。

## 2. 方法论：核心思想与关键技术细节

AtVLA 由两个互补机制构成：**Register 增强视觉编码** 和 **不确定性门控的局部视觉精化**。整体基于 π0 框架（PaliGemma + 流匹配 action expert）。

### 2.1 Register-Enhanced Visual Prefix（寄存器增强视觉前缀）

- 在 SigLIP 视觉编码器（224×224 输入，patch size 14，16×16 = 256 patches）的 class token 之后，插入 **N_r = 4 个可学习 register embedding**（每维 1152，参数量仅 4,608）。
- 编码器输出拆分为 `h_cls, R_t, P_t`，其中 `R_t ∈ R^{N_r × d_v}` 为 register 特征，`P_t ∈ R^{N_b × d_v}` 为空间 patch 特征。
- 与此前 Darcet 等只在内部使用 register 不同，本文**保留 R_t 输出**，经 PaliGemma visual projector Π 投影后拼接进多模态前缀：
  $$C_t^{bt} = [\Pi(R_t); \Pi(P_t); E_{lang}(\ell); E_{state}(s_t)]$$
- 多相机视角各自独立编码，结果按顺序串联。

### 2.2 Uncertainty-Gated Action Prediction（不确定性门控动作预测）

- LLM backbone 对 `C_t^{bt}` 做一次前缀 prefill 并缓存 KV。
- 流匹配 action expert 用相同 ODE 求解与噪声调度从 K=4 个独立高斯初始化采样 K 个动作块 `A^{(k)}_{1:H}`。
- 不确定性定义为近端 h 个执行步的平移维度（Δx, Δy, Δz）上的 K 样本**标准差均值**：
  $$U_t = \frac{1}{h|D_{tr}|}\sum_{j=1}^h \sum_{d \in D_{tr}} \sqrt{\frac{1}{K-1}\sum_{k=1}^K (A^{(k)}_{j,d} - \bar{A}_{j,d})^2}$$
- 阈值 τ 在每个 embodiment 各自的 episode-disjoint 验证集上以"最大化裁剪收益且触发率 ≤ 30%"为目标校准（如取不确定性分布的 70% 分位）。
- `U_t ≤ τ` → 走 confident path，直接执行 K 样本均值的动作块；
- `U_t > τ` → 进入 attention-guided refinement。

### 2.3 Attention-Guided Local Refinement（注意力引导的局部精化）

- 直接复用 action-expert 在采样过程中已经计算好的 attention，无需重复计算。聚合 18 层 joint-attention 层、跨头平均、跨欧拉步 Q={3,6,9} 平均后加 residual 并 row-normalize：
  $$fM_l = \text{RowNorm}\left(I + \frac{1}{|H||Q|}\sum_{m,q} M_{l,m,q}\right)$$
- 在层间做 **attention rollout**：`M_roll = fM_L · ... · fM_1`，只取前 h 个 action token 行对 256 个 base image patch 列的聚合值，重塑为 16×16 显著图并双线性上采样至原图分辨率。
- 用"对比窗口搜索"选择裁剪框（候选边长 {84, 112, 140}，步长 14，与 SigLIP patch 对齐），最大化窗口内注意力的均值与外环 ρ(b)\b 注意力的均值的差：
  $$b^*_t = \arg\max_{b \in B}\left[\frac{1}{|b|}\sum_{u \in b}S_t(u) - \frac{1}{|\rho(b)\setminus b|}\sum_{u \in \rho(b)\setminus b}S_t(u)\right]$$
- 选中的窗口四边各 +10% padding 并夹到图像边界，裁剪后 resize 到 224×224，经同 register-augmented ViT 重新编码，丢掉 crop 侧的 register 输出（因 base registers 已概括全局），仅保留 256 个 crop patch feature `P^c_t`。
- 用一个两层 MLP（4→256→d_LLM，GELU）将归一化坐标 `(x1/W, y1/H, x2/W, y2/H)` 映射为位置编码 `e_b`，加到每个 crop token 上：
  $$C^+_t = [C^{bt}_t; \Pi(P^c_t) + \tfrac{1}{N_c}\mathbf{1}e_b^\top]$$
- 只对新追加的 crop 段做 prefill，复用 base prefix 的 KV cache，再让 action expert 跑一次生成 refined action chunk。
- 显著图非有限、总注意力 < 10⁻⁶、窗口退化或裁剪边 < 56 px 即视为 invalid，跳过裁剪、走 base-only 路径（训练推理一致）。

### 2.4 三阶段后训练

- **Stage 0（Register Adaptation，20K 步）**：前 4K 步只训练 register，后 16K 步同时解冻 SigLIP 最后 4 个 block，LLM/AE/Projector 全部冻结，仅用 L_π0。
- **Stage 1（Ground-Truth Crop Alignment，10K 步）**：base 编码器与 register 冻结，训练 crop-position MLP 与 LoRA（rank=32），让策略学会解读 crop token。
- **Stage 2（Joint Refinement，40K 步）**：rank-32 LoRA 全开 + register + projector + crop-position MLP 联合优化，objective 为：
  $$L = L_{\pi_0} + \lambda_{cp} L_{cp} + \lambda_{ag} L_{ag}, \quad \lambda_{cp}=0.1, \lambda_{ag}=1.0$$
- **Crop 课程**：40K 步分为三段：
  - 0–40%：全部用 ground-truth crop（α=0, p_drop=0）；
  - 40–90%：α 从 0 线性增至 1，p_drop 从 0 增到 0.3；rollout 无效时不回退到 GT crop 而直接走 base-only，与部署一致；
  - 90–100%：α=1, p_drop=0.3，完全用 rollout crop。
- `L_ag` 是 action 到 image patch 的注意力的负对数似然，鼓励其集中到标注的任务相关区域内（p∈Ω(b_gt)）。

## 6. 主要结论与发现

- **AtVLA 在基准测试上一致取得最好成绩**：LIBERO Spatial 99.3%、Object 99.4%、Goal 98.3%、Long-10 96.5%（平均 94.2→98.4%），SimplerEnv Pick Coke Can 91.3%、Move Near 81.6%、Open/Close 57.5%，真实世界 Kitchen Grab 75→80、Building Blocks Spatial 55→70 等多数任务领先。
- **Register 的有效性**：
  - 注意力图变得干净且空间忠实，定位与精细接触均受益；
  - linear probe 显示 Registers 在物体定位、深度、法向量预测上均 > 0.70，强于 CLS 与 pool(patch)；
  - 从模型中移除 register 后，所有 LIBERO suite 平均下降 4.45%。
- **具身训练是 register 涌现的关键**：尝试混入 ImageNet/CC3M 数据反而会破坏从机器人演示获得的能力，因此 register 完全用 embodied 数据 + 动作目标训练。
- **裁剪受益场景**：
  - 显著提升物体/抓握类任务（Kitchen Grab/Pick、LIBERO-Object）；
  - 在空间关系和小目标叠堆类（LIBERO-Spatial、Building Blocks Spatial/Grab）上也明显获益；
  - 对长视野任务（LIBERO-Long-10、真实世界 long-horizon）也有提升，归因于附加的视觉上下文支撑后续决策；
  - 局限：Open/Close Drawer 类柜面占满画面的任务，裁剪基本等于保留整图，收益有限。
- **裁剪质量来自具身注意力**：相比外部通用 VLM 提供的裁剪（π0+Cropping），完整 AtVLA 优势更大，证实 attention rollout 在具身后训练后能精准定位交互区域。
- **开销可控**：仅 ~30% 重规划步骤触发裁剪，总计算量 1.4–1.6× π0。

---

## 7. 优点

- **诊断扎实**：先系统分析 VLA 视觉编码器的伪迹与具身后训练的关系，再据此设计 register，从 root cause 而非表面症状出发解决问题。
- **结构简洁**：
  - 只新增 4 个 register token（共 4,608 参数）；
  - 训练仍使用 π0 原始 action objective，不需要新的视觉自监督或外挂 3D 表达；
  - 不引入额外传感器 / 标定 / 显式 3D；
  - 推理时 KV cache 复用，crop 段只需增量 prefill。
- **机制设计精巧**：
  - register 既吸收全局信息、释放 patch token 的空间表达力，又**作为额外的全局上下文**继续参与动作生成，相比 Darcet et al. 的"丢弃 register"更充分利用；
  - 不确定性门控（K=4 样本平移维度标准差）简单有效；
  - attention rollout + 对比窗口搜索直接利用策略内部信号，不依赖外挂的开放词汇检测器；
  - Stage 2 三阶段 crop 课程（GT→混合→rollout-only、含 crop-dropout）显著降低 train–test mismatch。
- **评测全面**：
  - 覆盖 4 个 LIBERO suite + SimplerEnv + 自建真实世界双套件；
  - 多个受控消融（加/去 register、register 数量、裁剪源对比、混入通用视觉数据 vs 纯具身数据）；
  - linear probe 给出"register 真的编码了任务相关空间信息"的定量证据。
- **真实世界可复现**：单视角 Intel RealSense D435i + Franka Research 3 + RTX 4090，部署门槛低。

---

## 8. 不足与局限

- **真实世界基准的自有性**：Kitchen 与 Building Blocks 由作者自建、自训、自评，缺少与第三方基准（如 BridgeData/SimplerEnv-WidowX、RLBench、Calvin）的对齐，跨论文比较仍受场景差异影响。
- **SimplerEnv Wid­owX 套件被主动排除**，可能影响对模型在不同 embodiment 上视觉增强鲁棒性的判断。
- **统计噪声**：Table 1 部分基线（部分 SimplerEnv 行、部分 baseline）为引用值而非复测值，未给出 std；真实世界每个任务 20 次实验虽报告 std，但样本量仍偏小，难以做显著性与跨任务稳定性推断。
- **阈值 τ 与 embodiment 强耦合**：每种 embodiment 都要做 episode-disjoint 验证集校准，迁移到新机器人平台需重新标定，存在部署
