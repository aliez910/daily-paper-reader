## 摘要
移动操作是具身智能的一项关键能力，使机器人能够在开放世界环境中完成复杂的多阶段任务。然而，移动操作对视觉-语言-动作（VLA）策略提出了两个关键挑战：在数据层面，高效采集高质量的全身示教需要协调控制移动底盘和机械臂；在模型层面，现有VLA模型主要依赖局部相机观测，其有限的视场范围阻碍了全局空间理解。为应对这些挑战，我们开发了一个全身遥操作系统和一个全景感知的VLA策略。该系统通过单一VR接口实现对轮式双臂机器人的协调控制，并支持采集包含5.5小时多模态示教的真实世界移动操作数据集。基于该数据集，我们提出了PanoVLA，一种用于移动双臂操作的全景感知视觉-语言-动作策略。PanoVLA基于混合变换器（Mixture-of-Transformers）架构构建，通过专用的全景编码与融合模块引入全局空间上下文，实现全景观测与语言指令及机器人状态的有效融合以生成动作。在四项真实世界移动操作任务上的评估表明，PanoVLA的平均阶段完成率达到91.3%，端到端成功率达到73.4%，显著优于局部视角基线方法。这些结果表明，引入全景空间上下文能够提升移动机器人的空间理解能力和闭环操作性能。

## Abstract
Mobile manipulation is a key capability for embodied intelligence, enabling robots to accomplish complex multi-stage tasks in open-world environments. However, mobile manipulation poses two key challenges for vision-language-action (VLA) policies: At the data level, the efficient collection of high-quality whole-body demonstrations demands the coordinated control of both the mobile base and the robotic arms; at the model level, existing VLA models predominantly rely on local camera observations, whose limited field of view hinders global spatial understanding. To address these challenges, we develop a whole-body teleoperation system and a panoramic-aware VLA policy. The system enables coordinated control of a wheeled bimanual robot through a single VR interface and supports the acquisition of a real-world mobile manipulation dataset comprising 5.5 hours of multimodal demonstrations. Building upon this dataset, we propose PanoVLA, a panorama-aware vision-language-action policy for mobile bimanual manipulation. Built upon a Mixture-of-Transformers architecture, PanoVLA introduces global spatial context through dedicated panorama encoding and fusion modules, enabling effective integration of panoramic observations with language instructions and robot states for action generation. Evaluation on four real-world mobile manipulation tasks demonstrates that PanoVLA achieves an average stage completion rate of 91.3\% and an end-to-end success rate of 73.4\%, substantially outperforming local-view baselines. These results demonstrate that incorporating panoramic spatial context improves spatial understanding and closed-loop manipulation performance in mobile robots.

# 面向移动操作的全身遥操作全景感知 VLA 学习（PanoVLA）论文总结

## 一、核心问题与研究背景

- **研究对象**：移动双臂操作（Mobile Bimanual Manipulation），即机器人在开放环境中需同时协调移动底盘与双臂机械臂完成多阶段任务。
- **两大核心挑战**：
  1. **数据采集层面**：高质量全身示教需要同时协调移动底盘、双臂和夹爪，传统遥操作系统（如 Mobile ALOHA、TeleMoMa）多采用独立的摇杆/键盘控制底盘与机械臂，导致操作割裂、示教效率低、动作不流畅。
  2. **模型感知层面**：现有 VLA 模型（如 π0、π0.5、OpenVLA、Octo 等）依赖前视 + 腕部局部相机，视场（FoV）有限；在长程移动任务中，底盘运动、机械臂自遮挡会使目标物体或地标频繁离开视野，难以建立机器人中心的全局空间理解。
- **研究动机**：单纯的"加更多相机"并不能形成一致的全局空间表征；而全景相机虽能提供 360° 环绕观测，但 ERP（等距柱状投影）图像存在非透视畸变，与常规视觉编码器（如 SigLIP）的预训练域差距大。因此需要专门的全景表征与融合机制。

## 二、核心方法

### 1. 基于 GMR 的全身遥操作系统
- **硬件**：VR 头显（头部 6DoF）+ 双手控制器 + 腰部/双脚三处追踪点；轮式双臂机器人（RANGER MINI 3 底盘 + 两根 6DoF Agilex PIPER 臂 + 平行夹爪）；顶部 1 颗 360° 相机 + 前视 + 双腕部 RGB 相机。
- **核心思路**：将稀疏人体运动重建为 SMPL 姿态，再通过 **General Motion Retargeting (GMR)** 优化框架映射为机器人全身命令。
- **关键创新**：
  - 将移动底盘建模为 **3DoF 平面虚拟浮动基座**，与双臂关节配置联合优化：  
    $$\mathbf{q}^* = \arg\min_{q}\ \lambda_{\text{pos}}L_{\text{pos}} + \lambda_{\text{rot}}L_{\text{rot}} + \lambda_{\text{base}}L_{\text{base}} + \lambda_{\text{reg}}L_{\text{reg}}$$
  - 其中 $L_{\text{pos}}, L_{\text{rot}}$ 对齐手/末端执行器位姿，$L_{\text{base}}$ 耦合底盘与人体骨盆运动，$L_{\text{reg}}$ 抑制关节极限。
  - 提出 **成本驱动的运动模式切换**（spin / 转向 / 对角平移），周期性选择与期望速度最匹配的执行模式。
- **数据协议**：25 Hz 同步记录局部三路 RGB、ERP 全景、本体感知（17DoF）、全身动作；共 **800 条轨迹、约 5.5 小时、约 50 万帧**。

### 2. PanoVLA 模型架构（核心贡献）
- **总体框架**：基于 π0.5 的 **三专家 Mixture-of-Transformers (MoT)** 结构，包含：
  1. **VLM 专家**：编码局部视图（SigLIP）+ 语言指令 + 17DoF 本体状态，输出 VLM cache $C_{\text{vlm}}$。
  2. **全景专家（Panorama Expert）**：融合全景 token 与 VLM cache，输出全景 cache $C_{\text{pano}}$。
  3. **动作专家**：基于级联合并的 cache $C_t = [C_{\text{vlm}}; C_{\text{pano}}]$，通过**条件流匹配（Conditional Flow Matching）**预测 32 步动作块。
- **块式因果注意力**：每个 block 内双向自注意力；后续 block 仅能关注自身及之前 block。
- **全景编码器（Panorama Encoder）**：
  - 双鱼眼 → 球面重投影 → ERP 图像；
  - 使用全景基础模型 **MTPano**（[35]）提取分割与深度分支的中间特征，沿通道拼接得到统一稠密表征；
  - 通过自适应平均池化 + 轻量 MLP 适配器 $A_\psi$ 压缩为固定数量的全景 token $Z_{\text{pano}} \in \mathbb{R}^{N_p \times d}$：  
    $$Z_{\text{pano}}^t = A_\psi\big(E_p(\Pi_{\text{sph}}(I_{\text{pano}}^t))\big)$$
- **训练目标**（流匹配损失）：  
  $$\mathcal{L} = \mathbb{E}_{p(a|o_t,l),\,q(x_\tau|a)}\left[\|v_\theta^{\text{act}}(x_\tau,\tau|C_t) - u(x_\tau|a)\|_2^2\right]$$
- **冻结策略**：训练时冻结语言模型（Gemma-2B）与 MTPano 编码器，仅优化其余模块。

## 三、实验设计

### 数据集
- 四个真实世界移动操作任务（每任务 200 条轨迹）：
  | 任务 | 目标 | 空间布局 |
  |------|------|---------|
  | Move Pen | 将笔放入笔筒 | 前/左/右 |
  | Move Block | 将积木转移到前方区域 | 左/右/双侧 |
  | Open Curtain | 拉开两侧窗帘 | 左/右 |
  | Wipe Table | 用毛巾擦拭长桌污渍并归位 | 跨长桌延展 |

### 对比基线（所有基线均基于 π0.5 框架，控制变量）
1. **π0.5**：仅使用局部 SigLIP 视图（标准基线）。
2. **π0.5 w/ Pano**：将 ERP 全景作为额外图像输入，复用 SigLIP 编码，无专属全景分支。
3. **π0.5 w/ Stacked Pano**：将全景重投影为 3 张间隔 120° 的透视视图并拼接。
4. **PanoVLA（本文）**：MTPano 编码 + 全景专家融合。

### 评估协议
- **指标**：端到端成功率（SR）+ 阶段完成率（SCR）。
- **设置**：每任务 **15 次闭环真实机器人试验**，全程不进行人工干预/复位，记录所有阶段。

### 消融实验
- **专家容量消融**：50M / 100M / 200M / 300M。
- **全景编码器消融**：MTPano vs SigLIP。
- 均在 Move Pen 任务上完成。

## 五、实验数量与充分性

- **主实验**：4 个任务 × 4 个方法 × 15 次试验 = 共 240 次真实机器人闭环试验。
- **消融实验**：5 组（4 组专家容量 + 2 组编码器，重叠 100M），均在 Move Pen 上 15 次试验。
- **充分性评价**：
  - **优点**：所有方法在同一数据集与训练设置下训练，进行了严格的受控对比；任务设计覆盖了短程定位（Move Pen/Block）与长程多阶段状态跟踪（Open Curtain/Wipe Table），多样性较好。
  - **不足**：消融仅在单一任务上完成，主结果未提供统计显著性检验（如多次随机种子或置信区间）；15 次试验的样本量较小，SR 指标的方差可能较大；缺乏跨任务统一训练或泛化性实验。

## 六、主要结论与发现

- **性能**：PanoVLA 在四项任务上均取得最高 SR；平均 **SCR 91.3% / SR 73.4%**，相对 π0.5 基线（SCR 58.6% / SR 30.0%）分别提升约 **32.7%** 与 **43.4 个百分点**。
- **关键发现**：
  1. 全景感知对移动操作至关重要，但**并非所有全景输入方式等价**——直接喂 ERP 图像给 SigLIP 提升有限甚至在 Wipe Table 上退化（SR 仅 20%）。
  2. **透视化重投影（Stacked Pano）**能部分缓解畸变但牺牲了跨视图连续性，整体性能反而下降。
  3. PanoVLA 在**长程、多阶段状态跟踪**任务（如 Wipe Table 返回毛巾阶段）上优势最显著，验证了全景专家对任务状态转换与全局一致性的建模价值。
  4. **MTPano 比 SigLIP 更适配全景图像**（SR 86.7% vs 40.0%），证明几何感知的全景表征是关键。
  5. **100M 参数的全景专家**在容量-数据效率上达到最佳权衡，进一步扩大容量收益递减。

## 七、优点与亮点

- **系统级贡献**：提出 GMR 框架下统一的人-底盘-臂联合优化映射，无需独立底盘控制器即可实现自然协调的全身示教。
- **数据集价值**：5.5 小时同步多模态数据（含 ERP 全景 + 局部三视图 + 本体 + 全身动作），填补了全景移动操作数据集的空白。
- **架构创新**：在 VLA 中显式分离"局部语义"与"全景空间"两路专家，通过 KV cache 融合，避免了简单拼接图像带来的表征冲突。
- **严谨的对照**：所有基线共享同一训练数据与训练流程，确保对比的公平性。
- **消融设计**：覆盖了全景编码器选择与专家容量两个关键设计维度，结果支撑了方法选择的合理性。

## 八、不足与局限

- **数据规模有限**：5.5 小时 / 800 条轨迹对训练大规模 VLA 而言规模较小，可能限制模型泛化；未在未见场景/物体上进行零样本测试。
- **评估样本量小**：每任务仅 15 次试验，无置信区间或统计显著性检验，且消融仅在 Move Pen 一项任务上完成。
- **任务相对受限**：四个任务均在受控实验室环境中，桌面 / 笔筒 / 窗帘等场景相对结构化；缺少拥挤、动态或室外环境。
- **未与其它 VLA 体系横向比较**：未与 π0、OpenVLA、RDT-1B、SG-VLA、MoManipVLA、AC-DiT 等近期移动操作 VLA 直接对比，方法层面的相对优势仍待验证。
- **全景分支的额外开销**：增加 ~100M 参数与额外的全景编码前向，推理时延与显存成本未报告；对实时高频闭环控制的实际部署影响有待评估。
- **GMR 重映射假设**：依赖人体比例与机器人运动学的隐式匹配，对操作者身材/姿态有要求；不同操作员的可重复性未讨论。
- **标注偏差风险**：800 条轨迹均由同一团队采集，存在示教风格与策略偏差，未报告操作员间一致性或多源数据的影响。
- **未提及**：训练总时长、GPU-hours、单任务能耗等资源指标缺失。
