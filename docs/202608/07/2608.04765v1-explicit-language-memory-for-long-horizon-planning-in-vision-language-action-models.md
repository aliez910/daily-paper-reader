## 摘要
视觉-语言-动作（VLA）模型为连接视觉感知、语言理解和机器人控制提供了一种统一的范式。然而，现有VLA模型在长时程任务中仍面临重大挑战：稀疏的专家演示限制了跨任务组合泛化能力；长时程任务的非马尔可夫性质使得仅以当前观测为条件的策略难以保持时间一致性；有限的闭环纠错能力导致执行误差不断累积；端到端的动作微调可能会削弱视觉-语言模型（VLM）主干网络的高级语义表征能力。为应对这些问题，我们提出了一种带有显式语言记忆模块的分层长时程VLA架构。其核心思想是将离散的时间观测转换为具有时间逻辑的连贯文本记忆序列。该系统在结构上解耦为高层VLM和底层VLA：高层VLM通过视觉问答训练范式执行语义推理，底层VLA则以子任务指令和视觉观测为条件执行精确的连续控制。高层VLM以先前记忆为上下文锚点，递归地更新语言记忆和子任务指令，从而在长时程执行过程中实现持续的时间跟踪和动态纠错。我们在多种仿真环境中对所提方法进行了评估，并在真实机器人平台上开展了仿真到现实的迁移实验。结果表明，显式语言记忆在提升VLA模型在复杂长时程任务上的成功率和鲁棒性的同时，还为决策过程提供了可解释的语义描述。

## Abstract
Vision-language-action (VLA) models provide a unified paradigm for connecting visual perception, language understanding, and robotic control. However, existing VLA models still face major challenges in long-horizon tasks: sparse expert demonstrations constrain cross-task compositional generalization; the non-Markovian nature of long-horizon tasks makes it difficult for policies conditioned only on current observations to maintain temporal consistency; limited closed-loop error correction allows execution errors to accumulate; and end-to-end action fine-tuning may weaken the high-level semantic representations of vision-language model (VLM) backbones. To address these issues, we propose a hierarchical long-horizon VLA architecture with an explicit language-memory module. The central idea is to convert discrete temporal observations into a coherent textual memory sequence with temporal logic. The system is decoupled into a high-level VLM and a low-level VLA: the high-level VLM performs semantic reasoning through a visual question answering training paradigm, while the low-level VLA executes precise continuous control conditioned on subtask instructions and visual observations. The high-level VLM recursively updates both language memory and subtask instructions using the previous memory as a contextual anchor, enabling persistent temporal tracking and dynamic correction during long-horizon execution. We evaluate the proposed method in multiple simulation environments and conduct sim-to-real experiments on a real robotic platform. The results demonstrate that explicit language memory improves the success rate and robustness of VLA models on complex long-horizon tasks while providing an interpretable semantic account of the decision process.

# 论文总结：面向 VLA 长时程规划的显式语言记忆

## 1. 核心问题与研究动机

- **研究背景**：VLA（视觉-语言-动作）模型通过统一策略将视觉感知、语言理解与机器人控制联合建模，已成为具身智能的主流范式；但在**长时程、多阶段任务**中表现仍不理想。
- **关键挑战**（论文明确列出的四大痛点）：
  1. **专家演示稀疏**，跨任务组合泛化能力受限；
  2. **长时程任务的非马尔可夫性**，仅依赖当前观测的策略无法保持时序一致性，容易跳步、重复已完成动作或在未观察到的失败后继续推进；
  3. **闭环纠错能力有限**，执行误差沿时间步持续累积；
  4. **端到端动作微调**可能削弱 VLM 主干网络的高层语义表征能力。
- **核心思想**：将时序历史以**自然语言记忆**的形式显式压缩保留，使高层语义规划与低层连续控制解耦。

## 2. 方法论

### 2.1 分层策略架构

- **整体分解**：将策略 $\pi(a_{t:t+H}, s_t, m_t \mid o_t, m_{t-1}, l)$ 拆为两个条件策略：
  - **高层 VLM** $\pi^{HL}(s_t, m_t \mid o_t, m_{t-1}, l)$：基于当前观测、上一步记忆、全局指令，输出更新后的记忆 $m_t$ 和子任务指令 $s_t$；
  - **低层 VLA** $\pi^{LL}(a_{t:t+H} \mid o_t, s_t)$：基于当前观测和子任务指令，预测长度为 $H$ 的连续动作块。
- **循环执行**：每步先做高层语义更新，再生成动作块执行 $H$ 步，再回到观测，形成闭合循环（公式见原文 Eq. 1）。

### 2.2 递归语言记忆机制

- **记忆结构**：自然语言摘要，包含（1）已完成阶段（过去时）、（2）当前证据、（3）下一意图。
- **滚动压缩规则**：子任务完成前保留目标类别、颜色、位置等细节；完成后压缩为简短过去时陈述，注意力转向下一步。例如：
  - $m_t$："I am moving to the red radio on the coffee table."
  - $m_{t+1}$："I moved to the radio, and I am going to pick up the red radio."
- **更新条件**：仅在当前观测提供阶段切换证据时才更新记忆，避免冗余写入。

### 2.3 自动化记忆监督

- **输入**：专家视频 + 人工标注的技能名、描述、起止时间戳。
- **生成方式**：用通用 VLM（Gemini 3.5 Flash 或本地 Qwen3.5-9B）根据当前帧 + 完整技能标注生成两条监督：
  - 简洁子任务（"动作 + 目标 + 上下文"，无主语）；
  - 第一人称语言记忆（已完成技能的过去时 + 下一技能的未来时）。
- **约束**：提示中明确要求使用自然物体名和可见属性，避免 "frame、sequence、index" 等实现术语。

### 2.4 独立分支训练

- **高层 PaliGemma**：自回归预测记忆与子任务，损失如 Eq. 3 所示（$L_{HL}$）；
- **低层 VLA（$\pi_{0.5}$ 风格）**：以流匹配（flow-matching）目标训练动作专家，损失如 Eq. 4 所示（$L_{LL}$）；
- **关键设计**：两分支**独立训练**，避免在一个总损失中手动平衡语义生成与连续控制。

### 2.5 闭环推理

- 初始化 $m_0 = \emptyset$；
- 每步：观测 → 高层更新 $(m_t, s_t)$ → 低层生成动作块 $a_{t:t+H}$ → 执行 → 直至高层判定终止或达到 $T_{\max}$；
- 由于记忆与子任务均为可见文本，整个循环生成**可解释日志**，便于失败诊断。

## 3. 实验设计

### 3.1 仿真与真实平台

| 平台 | 任务 | 评分阶段 |
|---|---|---|

| **Genie Sim 3.0** | 单包裹分拣（Isaac Sim 人形机器人） | Follow / PickUp-1 / Inside-1 / Upright / PickUp-2 / Inside-2 |

### 3.2 对比方法

- **基线**：原生 $\pi_{0.5}$ 策略（VLM 预测语义子任务 + 流匹配动作专家）；
- **提出方法**：$\pi_{0.5}$ + 显式语言记忆（高层 PaliGemma 递归更新记忆，低层 $\pi_{0.5}$ 不变）。

### 3.3 评估指标

- **总体评价**：实验规模适中、对比公平（同一基线 + 同一硬件栈），但在**统计严谨性**和**消融完整性**方面有明显不足。

## 6. 主要结论与发现

1. **BEHAVIOR-1K "开收音机"**：平均成功率 30.0% → 40.0%，最大提升在 PickUp（10% → 30%）；MoveTo 已饱和，PressOn 仍为两者难点。
2. **Genie Sim 单包裹分拣**：41.7% → 63.9%；Follow 与 PickUp-1 翻倍，Inside-1（扫描台放置）从 50% → 83.3%。
3. **Genie Sim 连续多包裹分拣**：31.3% → 46.9%；基线从未达到第 3、4 次成功放置，加入记忆后在 12.5% 评估中达到 4 次全部成功。
4. **真实 XLeRobot 抓放**：62.5% → 66.3%，提升较小（任务阶段数少，记忆收益空间有限）。
5. **核心机制验证**：定性日志显示，无记忆基线在 PickUp 后错误地提前推进到 Place；带记忆模型必须等到观测到"按钮按压"完成后才推进。
6. **方法边界**：语言记忆解决"做什么、当前处于哪一阶段"，**不直接改善接触式运动执行**（PressOn 失败揭示了低层控制的瓶颈）。
7. **意外收益**：失败状态可写入记忆，使后续决策可触发"重开夹爪→再抓取"等上下文级恢复，无需独立的恢复控制器。

## 7. 优点

- **可解释性强**：记忆与子任务均为自然语言，可直接用于日志分析、失败归因与人机交互；
- **训练解耦**：高层语义与低层动作独立训练，避免联合损失中两类目标的手动权衡；
- **自动化数据流水线**：利用通用 VLM 把视频+时间戳自动转成监督，降低标注成本；
- **跨平台验证**：仿真 + sim-to-real 双重证据，且在三种不同形态（家居、桌面、人形）上均提升；
- **失败可作为上下文**：将"未抓稳""未完成"等失败显式写入记忆，自然支持上下文级重试，无需专门设计恢复策略；
- **计算开销可控**：记忆是压缩后的文本，而非堆叠历史帧，规避了上下文长度爆炸问题。

## 8. 不足与局限

- **真实实验规模小**：仅 25 条训练轨迹、20 次评估，无法支撑分钟级、多物体、含环境变化的真实长时程结论；
- **缺乏统计严谨性**：未报告随机种子、置信区间或显著性检验，仿真结果波动未知；
- **缺少关键消融**：未对记忆格式、记忆更新频率、子任务粒度、VLM backbone 选择、动作块长度 $H$ 等做系统消融；
- **推理开销增加**：每次高层 VLM 调用在前，**端到端延迟与部署复杂度上升**，论文承认但未量化；
- **依赖低层能力**：PressOn 失败表明语义记忆无法弥补低层运动精度不足；
- **恢复能力依赖数据**：当前仅观察到简单重试，更鲁棒的恢复需要专门收集失败-纠正演示；
- **仅文本记忆**：未来可融合视觉证据、触觉/力反馈以区分成功接触、滑动抓取、碰撞等图像中模糊的状态；
- **任务泛化性未验证**：实验均为单一任务，未在多任务组合、长时程（数十分钟）跨任务执行下验证。
