## 摘要
动作分块通过预测多个未来动作来缩短机器人模仿学习的有效决策时域，而传统的阶段条件描述的是当前控制时刻。当预测时域跨越过程性边界时，将当前阶段赋予整个分块会产生结构性时序失配。本文提出 TRACT，将阶段结构化的动作分块分解为已接受的当前阶段以及未来时域内唯一的"当前到下一阶段"边界。任务局部图约束阶段时序权威性，累积边界分布以单调方式将未来查询路由到阶段专属的查询路径与动作路径。在接触执行方面，因果响应缺口积分器将策略意图与 ACK 资格的后续运动进行比较，在方向性响应受抑时累积机械臂补偿，并在确认恢复后进行衰减。在六种真实机器人变体上每种进行十次试验的实验中，完整 TRACT 取得了 10/10 的全序列成功率、中位数[最小值，最大值]擦除完成率 99.00[88.75, 100.00]%、零观测阶段歧义以及零停滞。在当前完整方法包与评估设置下，路由表征获得了优于扁平包的观测任务结果（成功率 6/10 对比 3/10；中位数擦除完成率 77.08% 对比 8.03%）。时序权威性将观测到的阶段歧义从 8/10 降低至 0/10，响应积分将停滞从 4/10 降低至 0/10。包对比未能将路由与其他生成器包的差异隔离开来。

## Abstract
Action chunking shortens the effective decision horizon of robot imitation learning by predicting multiple future actions, while conventional phase conditioning describes the current control instant. When a predicted horizon crosses a procedural boundary, assigning the current phase to the entire chunk creates a structural temporal mismatch. We present TRACT, which factorizes phase-structured action chunking into an accepted current phase and a single CURRENT-to-NEXT boundary inside the future horizon. A task-local graph constrains chronological phase authority, and a cumulative boundary distribution monotonically routes future queries through phase-specific query and action paths. For contact execution, a causal response-deficit integrator compares policy intent with ACK-eligible subsequent motion, accumulates arm compensation when directional response is suppressed, and decays after confirmed recovery. Across six real-robot variants with ten trials each, full TRACT achieves 10/10 full-sequence success, 99.00 [88.75, 100.00]% median [min, max] wipe completion, zero observed phase ambiguity, and zero stalls. Under the current complete method package and evaluation setting, the routed representation obtains better observed task results than the flat package (6/10 vs. 3/10 success; 77.08% vs. 8.03% median wipe completion). Chronological authority reduces observed phase ambiguity from 8/10 to 0/10, and response integration reduces stalls from 4/10 to 0/10. The package comparison does not isolate routing from other generator-package differences.

# TRACT 论文总结

## 1. 核心问题与研究动机

**问题背景**：基于动作分块（Action Chunking）的模仿学习（如 ACT）通过单次策略查询预测未来多个动作，从而缩短有效决策时域并产生平滑行为。然而，当预测的整段动作块（chunk）跨越过程性阶段（procedural phase）边界时，将"当前阶段"标签赋给整个未来动作视野会产生**结构性时序失配**。

**具体表现**：在接触富集操作（如平面擦拭任务）中，相似的视觉/本体感觉状态可能出现在接触建立、重复擦拭、释放等不同阶段，但各自有效的下一动作差异显著。典型失败模式包括：
- 阶段切换后的动作延迟过渡
- 过早阶段推进导致擦拭中断
- 接触响应被抑制时出现阶段一致性的执行停滞

**两类歧义**：
- **当前阶段歧义**（present-phase ambiguity）：当前物理时刻应处于哪个阶段
- **未来边界歧义**（future-boundary ambiguity）：预测视野是否跨越到下一阶段，以及跨越位置

## 2. 方法论

TRACT 将阶段结构化动作分块分解为两个时间尺度上的独立决策，并附加一个下游因果执行闭环。

### 2.1 阶段时序权威性（Chronological Phase Authority）
- 共享编码器产生局部状态 $h_t^{loc}$ 与回合级状态 $h_t^{ep}$
- 阶段头输出原始类别 logits $\ell_t^{phase}$，给出诊断性建议 $e_t^{ct}$
- 权威头基于前一已接受阶段嵌入 $Emb(c_{t-1})$ 输出推进概率 $p_t^{adv}$
- **阶段管理器（Phase Manager）** $M$ 综合 $e_t^{ct}$、$p_t^{adv}$、显式返工证据 $e_t^{rw}$、有效 tick 证据 $v_t^{tick}$ 与防抖条件，决定接受阶段 $c_t$，约束其属于任务局部转移图的合法集 $L(c_{t-1})$
- 每次接受的转移会原子地更新 $c_t$、清除不兼容的 chunk 与时间集成（TE）血统，并在新阶段下生成新的 chunk

### 2.2 单调块内路由（Monotone Intra-Chunk Routing）
- **结构化边界估计器**：在已接受 $c_t$ 条件下，预测分类边界分布 $\pi_t(k)$，其累积概率 $\gamma_{t,j} = P(k_t \leq j)$ 即为 NEXT 门，保证单调性（$\gamma_{t,j+1} \geq \gamma_{t,j}$）
- 专家目标 $k_t^\star$：在 chunk 中首个阶段标签等于 $n(c_t)$ 的查询索引；若无则为 $H$（无转移）
- **阶段专属查询库**：查询 $j$ 被构造为 $eQ_{t,j} = (1-\gamma_{t,j})Q(c_t)_j + \gamma_{t,j}Q(n(c_t))_j$
- **路由动作生成**：解码器 $D_\theta$ 输出 $z_{t,:}$，最终动作由共享时间主干 $H_{shared}$ 与阶段专属残差路径 $R_{c_t}$、$R_{n(c_t)}$ 经同一单调门组合
- 支持的路由族恰好是"当前阶段前缀 + 合法下一阶段后缀"，振荡或非法序列的支持被设为零
- 终端阶段 $P_5$ 固定 $k_t^\star = H$；$P_4 \to P_2$ 返工被视为当前时刻权威事件，清除旧血统并启动新 $P_2$ chunk

### 2.3 因果执行闭环（Causal Execution Closure）
- 假设路由已提供阶段对齐意图，闭环专门处理**未被建模的接触动力学**（如摩擦）造成的方向响应抑制
- 计算策略方向 $d_t$（融合原始块内路径与带 TE 趋势的方向）
- 比较期望增量 $u_t$ 与实际增量 $y_t$，得到响应比 $\rho_t$
- 响应赤字 $e_t^{et} = \mathrm{clip}(e_t^{resp}(1-R_t), 0, 1)$，其中 $R_t$ 由速度恢复度决定
- 状态更新：$s_t = (1-\alpha)s_{t-1} + \alpha e_t^{et}$，$\alpha = 1 - \exp(-1/(f\tau_{rise}))$
- 修正仅作用于机械臂吸引力子空间，体输出 $T_t^{cmd} = T_t^{TE} \cdot \mathrm{Exp}(\Delta\xi_t^{int})$，**保持阶段、路由与夹爪语义不变**
- 确认恢复后以 $\exp(-1/(f\tau_{decay}))$ 衰减；血统失效、上下文变更或非活跃阶段则重置

### 2.4 训练课程
- $N_0 \to N_3$ 完成路由 Nominal 训练与因果历史精炼；冻结生成器与普通 TE
- 之后进行监督式 Manager 拟合与离线阶段自回归校准
- Nominal 与 Manager 参数从不共享优化器
- 损失函数：$\mathcal{L}_{N_0} = 10\mathcal{L}_{action} + \mathcal{L}_{sb} + 5\mathcal{L}_{route} + 10\mathcal{L}_{grip} + 10\mathcal{L}_{safe} + \mathcal{L}_{alias}$

## 7. 优点

- **问题分解清晰**：将"当前阶段接受"与"未来边界路由"明确分离到不同时间尺度，避免单阶段标签赋给整段视野的结构性问题
- **路由单调性由表征保证**：累积边界分布 $\gamma_{t,j}$ 的非递减性使振荡或非法序列在解码前即被排除
- **闭环职责分明**：阶段管理器约束过程性状态，路由分配阶段对齐语义，积分器仅处理物理响应抑制——三组件对应嵌套失败模式，互不替代
- **多种对照设计**：$T_U$–$T_R$ 交叉对比、$T_P$–$T_R$ 权威性对比、$T_R$–$T_F$ 积分器对比，形成机制级证据链
- **冻结 replay 补充诊断**：除闭环成功率外，提供阶段精度、合法链完成率等独立指标
- **训练课程严谨**：Nominal 与 Manager 参数不共享优化器，避免梯度干扰
