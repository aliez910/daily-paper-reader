## 摘要
具身视觉运动模型，包括扩散策略（DP）和视觉-语言-动作（VLA）模型，已在机器人操作基准测试中展现出良好性能。然而，其潜力仍受到大规模具身轨迹数据稀缺的根本性制约，导致在分布外（OOD）场景中组合泛化能力不足，难以捕获可复用的技能结构。为解决这一局限，我们提出了基于技能的记忆（SkillMemo）框架，该框架将长时序演示隐式分解为潜在的原子技能，并将技能级特征集成到动态情景记忆库中以求解组合任务。具体而言，我们首先引入基于混合专家（MoE）架构的专家引导轨迹分割模块，该模块通过学习得到的门控系数将轨迹隐式划分为不同的技能基元。我们进一步设计了技能级情景记忆架构，将紧凑的技能表示以可检索的键值对形式进行存储。在推理阶段，记忆库检索最相关的技能基元，并将其与模型当前的门控分布相融合，为动作预测的精炼提供稳健的上下文先验。在仿真基准和真实世界操作任务上的大量实验表明，SkillMemo 能够持续增强 DP 和 VLA 主干网络，达到最先进性能并超越 π₀.₅，同时对未见过的任务配置表现出强大的组合泛化能力。

## Abstract
Embodied visuomotor models, including Diffusion Policy (DP) and Vision-Language-Action (VLA) models, have demonstrated promising performance on robotic manipulation benchmarks. However, their potential remains fundamentally constrained by the scarcity of large-scale embodied trajectory datasets, leading to insufficient compositional generalization in out-of-distribution (OOD) scenarios with limited capability to capture reusable skill structures. To address this limitation, we propose Skill-Based Memory (SkillMemo) framework that implicitly decomposes long-horizon demonstrations into latent atomic skills and integrates skill-level features into a dynamic episodic memory bank for solving compositional tasks. Specifically, we first introduce an expert-guided trajectory segmentation module built upon a Mixture-of-Experts (MoE) architecture, which implicitly partitions trajectories into distinct skill primitives represented by learned gating coefficients. We further design a skill-level episodic memory architecture that stores compact skill representations as retrievable key-value pairs. During inference, the memory bank retrieves the most relevant skill primitives which are subsequently fused with the model's current gating distribution, providing a robust contextual prior to refine action predictions. Extensive experiments on the simulation benchmark and real-world manipulation tasks demonstrate that SkillMemo consistently enhances both DP and VLA backbones, achieving state-of-the-art performance and outperforming $π_{0.5}$, while exhibiting strong compositional generalization to unseen task configurations.

## 一、核心问题与研究动机

- **数据稀缺瓶颈**：具身视觉运动模型（Diffusion Policy, DP）与视觉-语言-动作模型（VLA）依赖大规模机器人轨迹数据进行微调，但此类数据采集成本高昂，导致模型在数据量受限时退化为"单一整体策略（monolithic policy）"。
- **组合泛化不足**：在分布外（OOD）场景中，面对已知物体、容器与指令的新颖组合，现有模型无法有效捕获与重用可复用的行为/技能结构，泛化能力显著下降。
- **现有方法局限**：
  - 强化学习方法（RL）依赖昂贵的真实环境交互；
  - 运动基元库方法依赖静态预定义基元，灵活性差；
  - 现有记忆增强方法（如 MemoryVLA 的双流感知-认知记忆库、HAMLET 的时序令牌）仅存储整体性的视觉-语义表示，缺乏**技能级别的细粒度行为先验**。
- **核心假设**：若能将长时程演示**隐式分解为潜在原子技能**，并以键值对形式存储于可检索的情景记忆库，则在推理时通过检索-融合即可实现对未见任务组合的组合泛化。

## 二、方法论：核心思想与关键技术

### 1. 整体框架
SkillMemo 是一种**即插即用**的增强模块，可同时作用于 DP 与 VLA 主干，包含两个核心组件：

- **专家引导轨迹分割（Expert-Guided Trajectory Segmentation, EGTS）**：基于混合专家（MoE）实现隐式技能分解。
- **技能级情景记忆架构（Skill-Level Memory Architecture, SLMA）**：以键值对形式存储、检索并融合技能基元。

### 2. 关键技术细节

**(1) EGTS 模块——隐式技能分割**

- **显式 vs 隐式分割**：论文指出显式按固定 chunk size $L$ 划分轨迹（公式 1）会遗漏潜在技能边界，因此采用基于 MoE 的**隐式分割**。
- **MoE 路由机制**：给定中间特征 $h_t$，MoE 层输出 $y_t = \sum_{i=1}^N g_i(h_t) \cdot E_i(h_t)$，其中 $E_i$ 为第 $i$ 个专家网络，$g_i(h_t)$ 为对应的门控权重。每个专家捕获一类局部运动基元，门控网络随时间动态调制专家激活，隐式定义技能边界。
- **协同正则化（PID 损失）**：基于"部分信息分解"理论设计损失 $L_{PID} = -[I(\{A,B\};G) - I(A;G) - I(B;G)]$，鼓励专家联合表示含有的任务相关信息大于各自贡献之和，从而驱动各专家分工到互补的、非重叠的技能。
- **辅助策略**：采用 top-k 路由与负载均衡损失以防止专家坍缩。

**(2) SLMA 模块——技能级情景记忆**

- **记忆存储**：
  - 键（Key）：对每个技能段 $\tau_m$ 的潜变量 $h_t$ 做时序聚合得到紧凑的质心特征 $k_m = \frac{1}{L}\sum_{t \in \tau_m} h_t$（公式 4），保证检索效率。
  - 值（Value）：存储整段内的门控权重序列 $v_m = \{g(h_t)\}_{t \in \tau_m}$（公式 5），保留技能执行的时序动力学。
  - 记忆库容量 $M_{\max} = 1000$。
- **记忆检索**：
  - 计算当前状态表征 $q_t$ 与所有键 $k_m$ 的余弦相似度（公式 6），取 Top-N 最相关条目。
  - **可靠性校验**：取检索平均相似度与阈值 $\delta$ 比较，过低则不启用记忆干预。
  - **门控融合**：$g'(q_t) = \lambda g(q_t) + (1-\lambda)\frac{1}{N}\sum_{n=1}^N v_n[t']$（公式 7），通过超参 $\lambda$ 控制记忆介入强度，按时间步对齐融合。
- **记忆更新（终身学习）**：
  - 当记忆库满时采用**优先级剪枝策略**，按三标准淘汰：(a) 时间戳最旧；(b) 长期未被成功检索；(c) 反复低于可靠性阈值。该策略在记忆多样性与质量间取得平衡。

## 六、主要结论与发现

- SkillMemo 在 **DP 与多种 VLA 主干上一致带来性能提升**，且作为即插即用模块可叠加于不同规模的模型。
- **关键结果**：
  - DP 主干：Push-T 55.2、BlockPush 78.1、Kitchen 60.6，平均 64.6%，超越 IMLE Policy（62.8%）与 STEP（61.6%）等基线；
  - VLA 主干：π₀.₅-SkillMemo 在 LIBERO 平均 98.0%，超过 π₀.₅（96.8%）与 MemoryVLA（96.5%）；
  - 组合泛化：在 LIBERO-Goal 训练的模型跨套件测试 Spatial 达 75.6%，反超在 Spatial 上专门训练的基线（72.1%）；真实世界"Strawberry on Plate"从 65.0% 提升至 75.0%。
- **机理验证**：专家门控系数在抓取、放锅等关键阶段出现明显峰值，说明 MoE 路由确实捕获了语义化的运动原语，无需显式标注即可实现技能分工。
- **专家数权衡**：$N=5$ 在精度与推理时延间达到较优平衡；继续增至 10 仅带来边际提升但推理时延显著增加（3.93→7.94 秒）。

## 七、优点与亮点

- **机制创新**：将"隐式 MoE 技能发现"与"显式键值情景记忆"耦合，既避免了显式分割的边界误差，也弥补了纯隐式方法的可解释性与可检索性不足。
- **方法通用性**：单一框架同时适配 DP（小模型）与 UniAct/UniVLA/π₀.₅（大模型），展示出较强的可扩展性。
- **理论与正则化结合**：引入 PID 协同信息损失，从信息论角度为专家分工提供理论支撑，是论文的一个方法学亮点。
- **终身学习视角**：记忆剪枝策略考虑了时间戳、使用频次与可靠性三个维度，符合人类记忆衰减规律。
- **实验广度**：同时覆盖仿真多基准、零样本跨域、真实世界组合任务，并通过门控可视化提供了机理性证据。

## 八、不足与局限

- **真实任务规模有限**：仅 5 个真实任务且每个任务 40 次 trial，统计置信度有限；未见组合任务集中在相近物体/容器类（草莓、柠檬、玉米、黄油），组合多样性受限。
- **超参敏感性未充分报告**：$\lambda$、$\delta$、$M_{\max}$ 等关键超参对性能的影响未在主文中给出系统分析。

- **与最新记忆增强方法对比不足**：未与 HAMLET（2025）、MAP-VLA、RoboMemory 等同类工作在同一基准上做头对头比较，影响定位精度。
