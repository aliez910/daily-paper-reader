## 摘要
视觉-语言-动作（VLA）模型在通用机器人操作中展现出强大潜力，但现有的大多数模型依赖于二维视觉-语言骨干网络，缺乏对目标物体的细粒度三维理解，尤其是在遮挡、姿态变化、尺度变化以及精确空间交互等场景下。我们提出了一种基于$\pi_0$的以物体为中心的三维表征对齐框架，利用SAM3D作为冻结的三维教师，在训练过程中为目标物体提供三维先验。具体而言，我们使用目标识别模型定位任务相关物体，生成相应的物体掩码，并利用SAM3D提取密集的物体级三维表征，将其与$\pi_0$的中间视觉特征对齐。该方法使策略能够内化目标物体的三维信息，同时保留原有的RGB-语言到动作的推理流程，且在测试时无需深度图、点云、掩码、SAM3D或额外的三维模块。仿真实验表明，该方法取得了稳定的性能提升，在LIBERO上达到99.1\%，在CALVIN上达到平均长度4.11。真实世界实验进一步表明，我们的方法在长时序操作任务中尤为有效，在这类任务中机器人需要在多个子任务中聚焦于不同的目标物体。

## Abstract
Vision-Language-Action (VLA) models have shown strong potential for general robot manipulation, but most existing models rely on 2D visual-language backbones and lack fine-grained 3D understanding of target objects, especially under occlusion, pose variation, scale changes, and precise spatial interaction. We propose an object-centric 3D representation alignment framework built upon $π_0$, using SAM3D as a frozen 3D teacher to provide target-object 3D priors during training. Specifically, we localize task-relevant objects with object recognition models, generate corresponding object masks, and use SAM3D to extract dense object-level 3D representations, which are aligned with intermediate visual features of $π_0$. This enables the policy to internalize target-object 3D information while preserving the original RGB-language-to-action inference pipeline without requiring depth, point clouds, masks, SAM3D, or additional 3D modules at test time. Simulation experiments show consistent improvements, achieving 99.1\% on LIBERO and an average length of 4.11 on CALVIN. Real-world experiments further demonstrate that our method is particularly effective in long-horizon manipulation scenarios where the robot must focus on different target objects across multiple subtasks.

# 论文总结：SAM3D-Guided Object-Centric Representation Alignment for Vision-Language-Action Models

## 1. 核心问题与研究动机

- **背景**：视觉-语言-动作（VLA）模型通过将预训练的视觉-语言模型适配到机器人动作预测，已成为通用机器人操控的重要方向。然而，现有 VLA 主要依赖 **2D RGB 视觉骨干**，仅从动作预测损失中学习，缺乏对目标物体的**细粒度 3D 理解能力**（形状、姿态、尺度、空间布局）。
- **现有方案的不足**：
  - 显式 3D 方法（如引入深度图、点云、RGB-D 输入）需要额外的 3D 观测，改变原有输入-输出接口。
  - 空间增强方法（如 SpatialVLA、Spatial Forcing）侧重**全局场景级**空间表征，而非**物体级**几何先验。
  - 视觉接地方法（如 ReconVLA）虽提升目标区域注意力，但监督仍停留在 2D 图像空间，无法提供目标物体的 3D 形状或布局先验。
- **核心问题**：能否在**不改变 RGB 输入-动作输出推理流程**的前提下，将**以物体为中心的 3D 知识**注入到 RGB-based VLA 策略中？

## 2. 方法论

### 2.1 整体框架：SAM3D-VLA

- 基于 **π₀** 架构（SigLIP 视觉编码器 + Gemma 语言模型 + 连续动作专家 + Flow Matching 动作生成）构建。
- 核心思想：训练阶段引入**冻结的 SAM3D 作为 3D 教师**，为 π₀ 中间视觉特征提供物体级 3D 监督；**推理阶段完全恢复 π₀ 原生的 RGB-语言-动作流程**，无需任何额外 3D 模块。
- 与现有方法的对比定位（Figure 1）：
  - (a) 显式 3D 场景中心（需要深度/点云）
  - (b) 显式 3D + 动作对齐（需要 3D 信息）
  - (c) 隐式 3D 场景中心（仅全局空间）
  - (d) **隐式 3D 物体中心（本文）**：仅训练时使用 SAM3D，测试时无需 3D 输入

### 2.2 关键技术细节

- **物体定位与掩码生成**（训练时数据管线）：
  - 使用 **Grounding DINO / YOLO** 进行开放词汇目标检测，定位子任务相关物体。
  - 使用 **SAM2** 生成分割掩码。
  - 得到图像-掩码对后输入冻结的 SAM3D 教师。
- **子任务分解（Subtask-aware）**：
  - 对长时序任务，使用 **GPT-4o** 将高层指令分解为多个子任务，每个子任务关联对应的目标物体掩码。
  - 提供**阶段特定**（stage-specific）的 SAM3D 监督，使策略在不同操作阶段聚焦不同目标物体。
- **3D 表征对齐流程**：
  - SAM3D 提取最后一层 Transformer 块的密集物体级 3D 特征 $T_t \in \mathbb{R}^{(BV) \times L_T \times D_T}$，包含形状、表面结构、空间布局等先验。
  - 将教师特征 reshape 为 2D 网格，通过**双线性插值**空间重采样到学生视觉 token 的分辨率（$H_S \times W_S = L_S$）。
  - 在学生侧，从 π₀ Gemma 的某一中间层 $m$ 提取视觉特征 $S_t = h_t^{(m)} \in \mathbb{R}^{B \times (V L_S) \times D_S}$。
  - 通过投影头 $P_\phi$ 将学生特征映射到 SAM3D 特征空间：$\hat{T}_t = P_\phi(S_t)$。
  - 构造 token 级掩码 $m_t$，仅对**目标物体 token** 计算对齐损失。

### 2.3 损失函数

- **动作损失（标准 π₀ Flow Matching）**：
  $$L_{\text{action}} = \mathbb{E}_{\tau, \epsilon}\left[\|v_\theta(A_t^\tau, \tau, o_t) - (A_t - \epsilon)\|_2^2\right]$$
- **对齐损失（Masked Normalized MSE）**：
  $$L_{\text{align}} = \text{MSE}\big(\text{Norm}(\hat{T}_t)[M_t],\; \text{Norm}(\bar{T}_t)[M_t]\big)$$
  - 使用 ℓ2 归一化，鼓励方向性对齐，对尺度差异鲁棒。
- **总损失**：
  $$L = L_{\text{action}} + \alpha L_{\text{align}}$$
- **冻结表征探针实验（Frozen-representation Probe）**：
  - 训练完成后，**冻结整个 VLA 主干**，仅训练一个轻量两层 MLP 探针 $P_\omega$ 从 $S_t$ 预测 SAM3D 目标 $\bar{T}_t$。
  - 若探针性能更好 → 说明 SAM3D 物体级 3D 先验确实被编码到了 VLA 特征中。

## 3. 实验设计

### 3.1 仿真基准

- **LIBERO Benchmark**：
  - 四个子集：Spatial、Object、Goal、Long（共 40 个任务，每个 500 条专家演示）。
  - 重点关注长时序（LIBERO-Long）：每任务含两个连续子任务，目标物体跨阶段变化。
- **CALVIN Benchmark**：
  - 34 个任务、4 个不同环境（A/B/C/D），长时序挑战由 5 个连续子任务组成。
  - 报告每个子任务的成功率与平均完成长度（Avg. Len）。

### 3.2 对比方法

- **2D VLA 基线**：Diffusion Policy、Octo、OpenVLA、Dita、CoT-VLA、π₀、UniVLA、OpenVLA-OFT。
- **显式 3D VLA**：SpatialVLA、GeoVLA、3D-CAVLA。
- **隐式 3D VLA**：Spatial Forcing。
- **对象中心方法**（CALVIN 上）：ReconVLA。

### 3.3 真实世界实验

- **平台**：AgileX Piper-X 双臂移动机器人，配备 3 个全向轮、2 个 6-DoF 臂、2 个腕部相机 + 1 个头部相机。
- **任务场景**：
  - 基础任务：堆碗（Stack bowls）、挂杯（Hang cup）、开抽屉（Open drawer）。
  - 长时序任务：烹饪（Cook）、插花（Flower）、积木堆叠（Stack）。
- **评估设置**：
  - **标准设置（ST）**：物体处于典型初始位姿。
  - **遮挡设置（OC）**：物体位置变化、干扰物、局部遮挡。

## 6. 主要结论与发现

- **LIBERO**：平均成功率 **99.1%**（所有对比方法中最高），其中：
  - Spatial 99.2%、Object 99.7%、Goal 99.1%、**Long 98.4%**（显著优于 π₀ 的 85.2%）。
- **CALVIN**：平均长度 **4.11**，5-step 成功率 **71.6%**，超越 ReconVLA（3.95 / 64.1%）等所有对比方法。
- **真实世界 Piper-X**：
  - 平均成功率：ST 从 π₀ 的 50.2% → **65.2%**；OC 从 21.3% → **44.3%**。
  - 长时序任务提升尤为显著（Cook：5%→26%；Flower：13%→45%；Stack：10%→38%）。
- **机制验证**：冻结表征探针实验表明，对齐训练后 SAM3D 物体级 3D 先验可从 VLA 中间特征中被更准确地恢复，证实 3D 知识确实被内化到策略表征中。
- **核心结论**：训练时注入的物体级 3D 先验是提升 VLA 策略的有效途径，**无需在测试时增加任何 3D 模块开销**。

## 7. 优点与亮点

- **设计理念新颖**：明确指出"物体级 3D 理解"是 RGB-based VLA 的关键瓶颈，区别于既有工作的"全局场景级空间感知"或"动作空间空间化"。
- **训练-推理解耦**：教师模块（SAM3D、检测器、分割器）**仅在训练时使用**，推理时完全沿用 π₀ 原生 RGB-语言-动作流程，部署开销为零。
- **子任务感知**：通过 GPT-4o 分解高层指令，将子任务与目标物体掩码关联，提供阶段特定监督，特别适合长时序多物体任务。
- **归一化 MSE 对齐损失**：对 SAM3D 与 π₀ 特征空间的尺度差异鲁棒。
- **冻结探针验证机制**：不仅报告性能提升，还从可解释性角度证明 3D 先验被有效编码到 VLA 表征中。
- **跨域一致性**：仿真（LIBERO、CALVIN）与真实世界 Piper-X 上均取得稳定提升，且对遮挡设置鲁棒性显著增强。

## 8. 不足与局限

- **对自动标注的依赖**：
  - 子任务分解（GPT-4o）、目标定位（Grounding DINO / YOLO）、分割（SAM2）任一环节出错都会引入**噪声监督**。
- **SAM3D 自身的限制**：
  - SAM3D 处理单张图像，在严重遮挡、透明物体、视角不佳等情况下可靠性可能下降。
- **算力信息披露不足**：仅提及 8×H100，未给出训练时长、batch size、学习率等关键超参。
- **消融实验不充分**：
  - 未报告关键组件（如子任务分解、mask 约束、归一化 MSE、α 取值）的消融结果，难以判断各模块的独立贡献。
- **真实世界评估范围有限**：
  - 仅在单一机器人平台（AgileX Piper-X）的桌面任务上评估，未涵盖移动操作、双手机巧操作、不同光照/背景等更广泛场景。
- **方法可推广性**：理论上对齐框架不局限于 π₀，但论文未验证在其他主流 VLA 骨干（如 OpenVLA、UniVLA）上的效果。
- **未来工作方向**（作者自述）：改进子任务-物体关联、探索多视角或时序 3D 教师、在更多 VLA 骨干与机器人平台上验证。
