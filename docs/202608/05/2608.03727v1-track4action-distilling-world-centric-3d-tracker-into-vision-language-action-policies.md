## Abstract
Action labels tell a vision-language-action (VLA) policy which robot commands to imitate, but not how those commands change the 3D world. The aligned demonstration clip contains this missing supervision because its $K$ frame transitions record the geometry, motion, visibility, and camera change produced during the corresponding $K$ actions. We introduce Track4Action, a framework that distills this realized transition from a frozen world-centric 3D tracker into a current-observation VLA policy. During training, Track4World encodes the clip $V_{t:t+K}$ into a pooled tracker feature. Learnable track queries infer this feature from current VLA hidden states, match it in a shared space, and condition a flow-matching action head through a feature-wise gate. The tracker feature only defines the alignment target, so neither the clip nor the tracker is used at deployment. Track4Action reaches 82.3% on zero-shot LIBERO-Plus, improving the alignment-free variant by 7.6 points and LaMP by 3.0 points. It obtains 80.44% and 81.48% on the clean and randomized RoboTwin 2.0 splits, and 67.5% average success across four physical bimanual tasks, 25.0 points above the alignment-free variant. The gains across simulation and physical tasks support action-aligned 3D tracker features as privileged supervision for tracker-free VLA deployment. Our project page is available at https://wing0night.github.io/track4action-project-page.

# Track4Action 论文总结

## 1. 核心问题与研究动机

- **关键问题**：现有 VLA（Vision-Language-Action）策略仅从动作标签中学习"模仿哪条机器人指令"，却缺少对"该指令如何改变 3D 世界"的监督。相同的末端执行器位移在不同的 3D 结构下，可能意味着自由空间移动、抓取物体运输或改变相机视角——这些区别决定任务成败，但动作标签不包含这些信息。
- **研究空白**：
  - 世界模型方法预测未来图像、几何或视觉特征，但通常目标为通用未来内容；
  - 几何感知方法编码 3D 结构或运动先验，但多为单帧空间特征；
  - 既有方法未充分利用"由演示动作块实现的那一段具体 4D 运动"作为监督信号。
- **核心假设**：演示视频中与动作块对齐的 K+1 帧（对应 K 个动作产生的 K 次状态转换）天然包含了所需物理证据，可被提取为"特权监督"用于训练，但在推理时无需使用。
- **研究目标**：能否让一个动作对齐的 3D 跟踪器在训练时监督 VLA，部署时完全不依赖该跟踪器？

## 2. 方法论

### 2.1 整体框架
- **教师（仅训练时）**：冻结的世界中心 3D 跟踪器 Track4World，对与动作块对齐的视频片段 $V_{t:t+K}$ 进行编码，得到池化的跟踪特征。
- **学生（部署时）**：当前观测的 VLA 策略（Qwen3.5-2B 主干 + DiT-B 流匹配动作头，共 3.3B 参数），通过可学习 track queries 在共享对齐空间中匹配教师特征，并通过特征门控将该表征反馈到动作头。
- **关键设计**：教师特征仅作为对齐目标，**不进入动作头**；部署时无需片段，也无需运行 Track4World。

### 2.2 关键技术细节
1. **世界中心跟踪监督**：
   - 输入：与动作块 $A_t^\star = (a_t, \ldots, a_{t+K-1})$ 时间对齐的 K+1 帧片段 $V_{t:t+K}$；
   - 通过 Track4World 提取场景、运动、可见性与相机线索 token，并池化为 $f_t^{trk} = \text{sg}[\text{Pool}(\mathcal{T}(V_{t:t+K}))]$，其中 $\text{sg}$ 阻止梯度流入教师网络；
   - 该特征描述该动作块对应的世界变化，而非通用未来事件。

2. **Track Queries 蒸馏**：
   - VLA 主干对当前观测与指令编码得到 $H_t = E_\theta(l, I_t)$；
   - 可学习 track queries $Q$ 通过交叉注意力读取 $H_t$，得到动作导向瓶颈表征 $Z_t = D_\theta(Q, H_t)$；
   - 对齐损失：$\mathcal{L}_{\text{align}} = \|\bar{z}_t - \bar{f}_t^{trk}\|_2^2$，将学生映射到与教师共享的特征空间。

3. **动作生成与门控融合**：
   - $Z_t$ 通过特征门控（feature-wise gate）与 $H_t$ 融合，形成动作条件 $H_t^{cond}$；
   - 教师特征 $f_t^{trk}$ 永远不会进入 $H_t^{cond}$，保证部署时不依赖片段；
   - 动作头使用流匹配（Flow Matching）建模速度场，并优化标准条件速度目标 $\mathcal{L}_{act}$；
   - 总损失：$\mathcal{L} = \lambda_{act}\mathcal{L}_{act} + \lambda_{align}\mathcal{L}_{align}$。

4. **Track4Action 的两条连接特权监督与控制的设计**：
   - **时间对齐**：跟踪器目标与动作块对应的 K 次状态转换严格对齐，描述"动作特异的世界变化"；
   - **动作导向**：track queries 既是对齐目标，又通过门控融合进入动作头，使对齐损失塑造的是"面向动作"的表征而非孤立辅助解码器。

## 6. 主要结论与发现

- **LIBERO**：Track4Action 平均 97.0%，超过 π0.5（96.9%）和 F1（95.7%），其中 LIBERO-Long 从 86.2% 提升到 95.8%，表明跟踪监督对长时域任务帮助最大；

- **总体结论**：动作对齐的世界中心 3D 跟踪特征是一种有效的"特权监督"，可在保持 tracker-free 部署的同时显著提升 VLA 策略在仿真与物理、长时域与零样本扰动下的性能。

## 7. 优点

- **训练-部署解耦的特权监督设计**：教师（Track4World）和动作对齐片段仅用于训练目标构造，部署时完全剔除跟踪器与片段，保持 VLA 原始推理接口；
- **动作导向的对齐通路**：track queries 同时承担"匹配教师目标"与"通过门控融合进入动作头"两个角色，使对齐损失直接塑造面向动作的表征，而非孤立辅助任务；
- **统一蒸馏接口**：同一框架在单臂 Cartesian、双臂关节、零样本扰动、物理平台之间迁移，无需为不同观测/动作空间重新设计；
- **严苛的对照实验**：对齐无关变体在数据、优化、模型规模、rollout 上与完整模型完全一致，确保差距来源于跟踪蒸馏通路；
- **跨域表现稳定**：LIBERO-Plus +7.6、RoboTwin +39/+41、真实世界 +25，跨基准增益一致且方向正向。

## 8. 不足与局限

- **依赖时序演示数据**：Track4Action 需要时间对齐的视频片段来构造训练目标，独立采样的图像-动作对无法提供该监督；独立运动的物体会削弱动作-世界转换的对应关系；
- **目标粒度有限**：池化跟踪特征强调段级世界运动，可能丢失局部接触对应；
- **继承教师缺陷**：在遮挡或快速运动下，Track4World 的误差会被传递；且只使用主相机视角；
- **物理评估范围偏窄**：仅 1 个双臂平台、4 个任务、3 类视觉扰动，覆盖的本体类型、相机配置、物理扰动仍然有限；
- **未报告算力与训练时长**：训练成本与可复现性细节缺失；
- **消融不够细致**：除"对齐 vs. 不对齐"外，缺少对 K 大小、gate 形式、查询数量、teacher 容量等组件的单独消融；
- **过程分数部分未超越强基线**：真实世界毛巾折叠任务上 Track4Action 仅 40%，低于 π0.5 的 70%，说明在可形变物体操作上仍有明显不足。
