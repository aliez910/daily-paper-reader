## 摘要
视觉-语言-动作（VLA）模型通常采用以大语言模型为中心的 $V \to L \to A$ 路径，其中视觉观测被投影到大语言模型的表示空间，然后再被解码为机器人动作。尽管该方案有效，但这种设计在每次策略调用时都会带来巨大的计算和内存开销。在本文中，我们提出了 TurboVLA，一种新的 VLA 范式，它将传统的 $V \to L \to A$ 路径重构为直接的 $V + L \to A$ 映射。TurboVLA 没有使用大语言模型作为感知与动作之间的核心接口，而是独立地编码视觉观测和语言指令，通过轻量级的双向视觉-语言交互在二者之间直接交换信息，并使用紧凑型解码器预测连续动作块。这种简洁的设计直接从视觉和语言特征构建任务条件表示，显著降低了 VLA 推理的计算和内存成本。在 LIBERO 基准上，TurboVLA 仅使用 0.2B 参数，在消费级 RTX 4090 上即实现了 97.7% 的平均成功率、31.2 ms 的推理延迟和 0.9 GB 的推理显存，其性能可与甚至超过规模显著更大的 VLA 策略。这些结果确立了 TurboVLA 作为当前主流的以大语言模型为中心的 VLA 范式的一种简洁而有效的替代方案，为如何连接视觉、语言和动作以实现高效的机器人操作提供了新的视角。代码已开源：https://github.com/H-EmbodVis/TurboVLA。

## Abstract
Vision-language-action (VLA) models commonly adopt an LLM-centric $V \to L \to A$ pathway, where visual observations are projected into the representation space of a large language model before being decoded into robot actions. Although effective, this design incurs substantial computation and memory overhead at every policy invocation. In this work, we introduce TurboVLA, a new VLA paradigm that reformulates the conventional $V \to L \to A$ pathway as a direct $V + L \to A$ mapping. Instead of using a large language model as the central interface between perception and action, TurboVLA independently encodes visual observations and language instructions, directly exchanges information between them through lightweight bidirectional vision-language interaction, and predicts continuous action chunks with a compact decoder. This simple design constructs task-conditioned representations directly from visual and linguistic features, significantly reducing the computational and memory costs of VLA inference. On LIBERO, TurboVLA achieves 97.7% average success with only 0.2B parameters, 31.2 ms inference latency, and 0.9 GB inference VRAM on a consumer-grade RTX 4090, matching or outperforming substantially larger VLA policies. These results establish TurboVLA as a simple and effective alternative to the prevailing LLM-centric VLA paradigm, offering a new perspective on how vision, language, and action can be connected for efficient robotic manipulation. Code is available at https://github.com/H-EmbodVis/TurboVLA.

# TurboVLA 论文总结

## 1. 核心问题与研究动机

- **主流 VLA 模型的设计瓶颈**：现有 Vision-Language-Action（VLA）模型普遍采用 **以大语言模型（LLM）为中心的 $V \to L \to A$ 路径**——视觉观测先被投影到 LLM 的语言空间，再与指令一起经 LLM 处理，最后解码为机器人动作。虽然这一设计借力 LLM 强大的语义推理能力，但在每一次策略调用中都带来沉重的计算和显存开销。
- **影响实时部署**：高延迟、占用大量显存，使得在资源受限的机器人平台上部署、进行高频闭环控制十分困难。
- **核心反思**：作者提出关键问题——**执行级控制是否一定需要以 LLM 为核心接口？** 一旦指令已确定操控意图，策略需要的是"如何依据视觉证据执行"，而非开放式语言生成或任务分解。因此，LLM 的广泛生成与推理能力对于执行层任务而言是过剩的。

## 2. 方法论

### 总体范式
- 将传统 $V \to L \to A$ 重构为 **直接的 $V + L \to A$ 映射**：
  - 独立编码视觉观测与语言指令；
  - 通过**轻量级双向跨模态交互**直接交换信息；
  - 使用紧凑解码器一次性预测**连续动作块**（无需自回归 token 生成）。

### 模块细节
1. **多模态特征编码**
   - **视觉编码器**：DINOv3（Siméoni et al., 2025），提取空间视觉特征，并加入位置嵌入和相机视角嵌入，多视角拼接为 $Z_v^n$。
   - **指令编码器**：轻量 BERT（Devlin et al., 2026 发表前的 2019 原文，保留完整 token 序列而非池化向量，以便保留物体、属性、空间关系）。$Z_l \in \mathbb{R}^{N_l \times d}$，$d=256$。
   - **机器人状态编码**：$Z_s^n = f_{state}(s^n)$，单独由小网络处理，**不参与视觉-语言交互**，仅送入动作解码器。
2. **视觉-语言交互模块**
   - $N=6$ 层双向跨注意力结构（借鉴 Grounding DINO 的跨模态交互设计），每层包括：LayerNorm + 双向交叉注意力 + 模态专属 FFN + 残差。
   - **视觉→指令**注意力：将场景上下文注入指令流；
   - **指令→视觉**注意力：将任务语义注入视觉流；
   - 最后将更新后的视觉流和指令流拼接得到 $Z_{vl}^n = [V_n^N; L_n^N]$。
3. **连续动作块预测**
   - 使用 ACT 风格（Zhao et al., 2023）的轻量 Transformer 解码器，将 $Z_{vl}^n$ 与 $Z_s^n$ 拼接后，由 $H$ 个可学习查询并行解码整个动作块 $\hat{A}_n \in \mathbb{R}^{H \times d_a}$。
   - 训练目标为 $\ell_1$ 损失，行为克隆，无需任何语言建模辅助目标。

### 关键设计取舍
- 摒弃 LLM 中央化表示；
- 显式分离"任务条件场景理解"与"本体的状态注入"两个模块；
- 非自回归、并行输出动作块，避免 token-by-token 生成开销。

## 6. 主要结论与发现

1. **执行级控制不需要 LLM 中央化**：TurboVLA 用 0.2B 参数即匹配甚至超过数 B 参数量 VLA 的能力（LIBERO 97.7% vs π0.5 96.9%、CogVLA 97.4%）。
2. **显著的效率领先**：
   - 推理延迟 31.2 ms（对应 32 Hz 实时控制），比 π0.5 的 93.6 ms 提升约 3 倍，比 OpenVLA-OFT 的 112.2 ms 高 3.6 倍；
   - 推理 VRAM 仅 0.9 GB，约 π0.5（12.8 GB）的 7%；
   - 参数量约 π0.5 的 6%。
3. **架构简洁性收益**：仅靠双向跨模态交互就把语义指令高效注入视觉特征，无需大容量 LLM。
4. **泛化性验证**：在 RoboTwin 2.0 双臂 50 任务上达到 60.2%，超过 π0.5（57.0%）与 StarVLA-α（50.3%），延迟仅 43.4 ms。
5. **真实机器人表现**：四任务上 92.5% / 80% / 90% / 87.5%，一致优于 π0.5。
6. **消融发现**：
   - 去除语言后性能下降 27%（尤其 LIBERO-Goal 从 97.4% → 11.6%），证明策略无法仅凭视觉先验处理多行为场景；
   - 双向交互比单向或无交互均更优（97.7% > 96.5% > 96.1% > 95.2%）；
   - $N=6$ 是性能-效率最佳平衡点；
   - $H=12$ 为最佳动作块长度。

## 7. 方法/实验亮点

- **范式突破**：首次清晰将 VLA 从 LLM-centric 转向 V+L→A 直接路径，并给出系统化论证与替代方案。
- **极轻量级部署**：0.2B 参数、<1 GB VRAM 为消费级 GPU 边缘部署提供了现实路径。
- **组件解耦**：视觉-语言交互专注任务条件场景理解；机器人状态条件显式注入动作解码器，职责清晰。
- **借鉴成熟模块**：双向跨注意力来自 Grounding DINO，文本编码器用 BERT，动作解码用 ACT，头部组合稳健可靠。
- **多维度验证**：仿真 + 双臂 + 真实机器人三层验证；语言、监督信号、交互深度、动作长度等多个消融维度都有覆盖。

- **复现性高**：DINOv3 + BERT + ACT 解码器、$\ell_1$ 行为克隆、OpenVLA 协议等均为公开工具，门槛低。

## 8. 不足与局限

- **执行级专精**：模型针对具体执行指令设计，缺少高层任务规划与复杂语义推理能力，作者明确承认这是局限。
- **基础模型规模受限**：DINOv3 + BERT 的组合在开放世界理解与抽象语义上弱于真正大规模预训练 VLM，可能影响分布外指令表现。

- **算力细节不完整**：未披露训练墙钟时长、显存峰值、优化器配置、量化策略等。
- **缺乏延迟分布/抖动分析**：单点延迟难以反映真实机器人控制中的 worst-case 行为。
- **未提供机器人硬件规格细节**：除"AgileX Piper、6-DoF、D435 RGB-D"外缺少具体计算平台、推理线程等描述，限制可重复性。

- **未来工作留白**：作者提出将高层 LLM 规划与 TurboVLA 高效执行结合，但未给出具体层级化框架。
