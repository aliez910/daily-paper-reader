## 摘要
人类在执行长时序操作时，会保留对先前动作所建立成果的记忆，同时持续调整正在进行的运动。相比之下，按动作分块（action-chunked）的视觉-语言-动作（VLA）策略在每次查询时都会根据当前输入重新规划。现有方法要么通过记忆保留长期任务证据，要么通过动作复用与集成保留短期运动，导致跨查询的衔接并不完整。我们提出了 ChainVLA，一个具有 1.2B 参数的 VLA 策略，通过一个联合且可修正的执行状态将连续的查询链式连接起来。其中，进度上下文（Progress Context）将循环的工作状态与稀疏的事件记忆相结合，以承载由观测推导出的任务进度；而运动尾部（Motion Tail）则将前一次预测中尚未执行的后续部分输入到状态构建与动作生成中。这两个组件共同调节一个解码器，使其在最新观测下重新生成每个动作时域，从而让所携带的状态能够引导下一次预测，又不会将其固化。ChainVLA 在 RMBench 上取得了 62.8% 的平均成功率，并在四个 LIBERO 套件上达到 98.8%；而移除运动尾部或进度上下文后，RMBench 的成功率分别下降至 11.2% 和 3.0%。这种不对称的消融结果与以下观点一致：运动连续性有助于保留从中推断任务进度的观测流。

## Abstract
Humans perform long-horizon manipulation by retaining knowledge of what earlier actions have established while continuously adapting the motion underway. By contrast, action-chunked vision-language-action (VLA) policies repeatedly replan from the current input at each query. Existing methods preserve either long-term task evidence through memory or short-term motion through action reuse and ensembling, leaving the cross-query handoff incomplete. We introduce ChainVLA, a 1.2B-parameter VLA policy that chains successive queries through a joint and revisable execution state. Progress Context combines a recurrent Working State with sparse event memory to carry observation-derived task progress, while Motion Tail feeds the preceding prediction's unexecuted continuation into state construction and action generation. Together, the two components condition a decoder that regenerates each action horizon under the latest observation, allowing the carried state to guide the next prediction without fixing it. ChainVLA reaches 62.8% average success on RMBench and 98.8% across four LIBERO suites, while removing Motion Tail or Progress Context reduces RMBench success to 11.2% and 3.0%, respectively. These asymmetric ablations are consistent with motion continuity helping preserve the observation stream from which task progress is inferred.

# ChainVLA 论文总结

## 1. 核心问题与研究动机

- **问题定位**：基于动作分块（action-chunked）的 VLA 策略在长时序操作任务中采用"滚动重规划"范式——每次查询基于当前观测、本体状态与指令从零生成一组 H 长动作序列，仅执行前缀后即废弃剩余尾部并重新规划。这导致**跨查询的状态交接不完整**，体现在两个耦合层面：
  - **任务层**：早期任务证据（如已完成的子任务、初始布局）可能已不在当前视野中，仅靠当前观测无法判断下一步动作；
  - **运动层**：重规划会丢弃前次预测中尚未执行的后续尾部，新生成的前缀可能与被替换的运动在姿态空间上存在跳变。
- **理论意义**：作者将缺失的跨查询衔接形式化为"决策不充分性"准则（Eq. 1），即当相同当前输入对应不同历史时，最优执行前缀集不相交。该问题在记忆依赖型任务（如 RMBench Put Back Block）中尤为突出：相同观测与指令可能对应截然不同的任务历史。
- **现有方法的不足**：第一类通过记忆机制（MemoryVLA、Mem-0 等）保留长期任务证据，但无法保留预测侧的未执行尾部；第二类通过时序集成、实时执行或连续性方法保留短期运动，但无法承载更早的任务证据；二者均未实现跨查询的完整衔接。
- **核心研究问题**：如何在 VLA 策略中跨查询链式连接"任务进度"与"运动连续性"，同时保证新一轮预测对新观测的可修正性？

## 2. 方法论

### 2.1 核心思想
ChainVLA（1.2B 参数，Florence-2-large 视觉-语言骨干 + 条件流解码器）引入**联合且可修正的执行状态** $s_k = (g_k, u_k)$，在每次查询处执行"读—更新—写"转换，使原本独立解码的动作分块形成跨查询链式连接。

- **进度上下文（Progress Context, $g_k$）**：承载由观测推导的任务进度，由循环工作状态（Working State）与稀疏事件记忆（Sparse Event Memory）融合形成；
- **运动尾部（Motion Tail, $u_k$）**：携带前一次预测中尚未执行的尾部后缀，作为下一轮解码的先验。

### 2.2 关键技术细节

- **查询转换方程（Eq. 3）**：
  $$(A_k, W_k, C_{k+1}) = F_\theta(x_k, D_k, W_{k-1}, C_k, u_k), \quad u_{k+1} = \text{Tail}(A_k)$$
  即当前查询读取：当前输入 $x_k$、已执行动作 $D_k$、前轮工作状态 $W_{k-1}$、事件记忆 $C_k$、进入的 Motion Tail $u_k$；输出动作时域 $A_k$、更新后的 $W_k$、可能写入的事件 $C_{k+1}$，并将未执行尾部作为下一轮先验。

- **Working State（Eq. 4）**：使用 8 个可学习工作查询 $\eta_k$ 与当前多模态 token $X_k$ 做交叉注意力，并递归融合上一轮 live token $L_{k-1}$；pooled summary $\bar{W}_k$ 驱动事件检索。

- **稀疏事件记忆**：每条事件包含 64 视觉 token、8 Stage Info token、8 时间 token、检索键与写入查询索引，容量 16；首次有效事件作为锚点，stage 标注数据由阶段转换触发写入，无标注数据按三查询周期写入；检索时采用 age-aware 余弦相似度评分（Eq. 5）。

- **Motion Tail（Eq. 6）**：通过两条模型侧路径生效——token 路径编码为 $U_k$ 条件化 Working State 构建；动作空间路径将归一化尾部对齐到完整时域表示，提供解码器初始均值 $\mu_{k+1}$；条件流解码器从该初始状态出发，在最新观测下**重新生成每个时域位置**（任何位置都允许被修改）。

- **训练目标**：标准条件流动作损失 + 可用阶段的阶段监督 + Motion Tail 重叠一致性正则（权重 0.2），训练时按情节查询顺序展开，传入的尾部在条件化下一查询前做 detach。

- **执行侧辅助**：解码后控制器对重叠步做线性混合（blending），属于执行侧衔接，与模型侧两条路径独立；首次查询时 Motion Tail 路径被屏蔽，使用标准噪声初始化。

## 6. 主要结论与发现

- **性能结果**：ChainVLA 在 RMBench 取得 62.8% 平均成功率（1.2B 参数），领先于在五任务完整覆盖下最强对比（Mem-0 52.8% 于 8B+2B）；在 Put Back Block、Swap Blocks 等任务上达到 96% / 74%；在 LIBERO 四套件平均 98.8%（Long 98.2%）。
- **不对称消融**：去除 Progress Context 后平均降至 3.0%（任务进度信号丢失导致策略连贯地走向错误子目标），去除 Motion Tail 后降至 11.2%（记忆通路完整但运动断裂），二者同时移除仅 1.6%；部分状态远低于完整模型——两半并非相互独立的可加性改进。
- **运动连续性支撑任务进度**：作者将这一不对称解读为"运动连续性先于、保护并支撑任务进度推断"——观测流是 Progress Context 的输入，离线分布外的恢复运动会污染用于检索的视点序列；但作者也强调该结论为相关性而非因果链。
- **边界诊断一致性**：在配对 rollout 下，Full 较 w/o Motion Tail 在 $CD_p$、$CD_R$、$B_2$、$RMSE_3$ 上分别降低 56.6% / 40.4% / 57.4% / 43.1%；边界指标是诊断量而非目标——更平滑并不等于更高成功率（Linear Continuation 边界最平滑但成功率 0–2%）。
- **替代方案**：FIFO 观测历史 + Temporal Ensemble 仅 35.6%，说明"在编码后拼接历史+对解码后动作做集成"无法替代"在状态构造与解码阶段即衔接上一预测尾部"。

## 7. 方法与实验设计的亮点

- **将跨查询衔接形式化**：明确区分"进度"与"运动"两类互补组件，并给出决策不充分性准则与查询转换方程，提供了一个清晰可分析的框架；
- **可修正而非固定化的状态传递**：解码器在最新观测下重生每个时域位置，使所携带状态成为可修订先验，而非将后续动作固化；
- **Motion Tail 两条模型侧路径**：token 路径接入 Working State，轨迹初始化路径为条件流解码器提供有意义的初始均值，比"纯拼接历史+后平滑"更早介入生成过程；

- **小模型大效果**：1.2B 参数下的 ChainVLA 在 LIBERO 平均与 7B 级 Mem-VLA、CronusVLA 等量级相当，并在 RMBench 上明显优于参数大数倍的对比方法。
