## 摘要
为了在不同情境下有效运作，机器人不仅需要准确地完成操作任务，还必须使其动作的执行方式适应任务、物体和交互场景。我们探讨这种执行层面的变化能否作为一种可在任务间共享的可复用行为因子被习得。我们提出了\textbf{MoMo}，一个两阶段的模仿学习框架，由时空动作分词器和一个行为克隆Transformer组成，后者以任务和连续运动模式条件作为输入。在六项真实机器人操作任务中，改变该条件能够产生稳定型、动态型和介于两者之间的行为，人类评估者可以对其进行区分，并且这些行为在关节速度、加速度和末端执行器接近俯仰角方面存在差异。对于仅以一种模式示范的任务，MoMo能够迁移到未示范的请求模式，同时在很大程度上保留了任务成功率。综上，这些结果为对未见过的任务-模式组合的组合泛化提供了证据，并表明运动模式可在任务间复用，以控制操作技能的执行方式。

## Abstract
To operate effectively across diverse contexts, robots must not only perform manipulation tasks accurately but also adapt how their actions unfold to the task, object, and interaction setting. We ask whether this execution-level variation can be learned as a reusable behavioral factor shared across tasks. We present \textbf{MoMo}, a two-stage imitation-learning framework consisting of a spatiotemporal action tokenizer and a behavior-cloning transformer that takes task and a continuous motion-mode condition as inputs. Across six real-robot manipulation tasks, varying this condition produces steady, dynamic, and intermediate behaviors that human raters can distinguish and that differ in joint speed, acceleration, and end-effector approach pitch. On tasks demonstrated in only one mode, MoMo transfers the unseen requested mode while largely preserving task success. Together, these results provide evidence of compositional generalization to unseen task--mode combinations and show that motion mode can be reused across tasks to control how a manipulation skill is performed.

# MoMo 论文总结

## 一、核心问题与研究动机

- **关键问题**：机器人在不同情境下不仅需要"完成任务"，还需要调整"如何执行该任务"（节奏、加速度、末端姿态、犹豫等）。现有模仿学习方法通常将行为风格与任务耦合学习，每扩展一个新行为都需要新任务的对应演示，缺乏可复用、可跨任务迁移的行为因子。
- **抽象概念**：作者提出 **motion mode（运动模式）** —— 一种任务无关的行为调制因子（task-agnostic behavioral modulation factor），它改变动作的执行方式而非任务目标。
- **类比区分**：运动模式不是技能原语（skill primitive），也不是任务标签，而是作用在策略之上的"执行质量维度"。
- **研究假设**：动作的分词化（tokenization）可以为"任务相关结构"与"行为相关变化"提供分离的接口，使得后者可被跨任务复用。

## 二、方法论

### 整体框架（两阶段）

- **Stage 1：时空动作分词器（Spatiotemporal Action Tokenizer）**
  - 将动作片段 $a \in \mathbb{R}^{100 \times 7}$ 分别送入两个并行编码器：
    - **空间编码器 $E_{sp}$**：1D 卷积栈处理原始关节空间的绝对轨迹，输出 $z_{sp} \in \mathbb{R}^{K \times D}$（$K=20, D=256$），捕获路径几何、接触、末端目标。
    - **时间编码器 $E_{te}$**：先计算关节差分 $\Delta q_t = q_{t+1} - q_t$，再做 II 型 DCT，保留前 $C=16$ 个低频系数，再经 MLP 投射到 $z_{te} \in \mathbb{R}^{K \times D}$，捕获节奏、平滑度、犹豫等。
  - 两个 latent 流各自经过独立的 **RVQ（残差向量量化）** 码本：
    - 空间栈：$L_{sp}=4$ 层，码本大小 [64, 512, 512, 512]（首层作为内容瓶颈）。
    - 时间栈：$L_{te}=4$ 层，每层大小 256。
    - 公式：$i^{(\ell)}_k = \arg\min_n \|r^{(\ell)}_k - e^{(\ell)}_n\|_2$，$z^{(\ell)}_{q,k} = e^{(\ell)}_{i^{(\ell)}_k}$，残差 $r^{(\ell+1)}_k = r^{(\ell)}_k - z^{(\ell)}_{q,k}$。
  - **融合与解码**：$z_q = \text{LayerNorm}(\text{GELU}(W_f[z_{q,sp}; z_{q,te}]))$，再经 1D 上采样解码器 $\psi$ 给出 $\hat{a} = \psi(z_q)$。
  - **辅助 DCT 头**：从 $z_{q,te}$ 预测 DCT 目标，确保时间码保留频域动态信息。

- **Stage 1 损失函数（七项）**：
  $$L = L_{recon} + \lambda_{DCT} L_{DCT} + \lambda_{swap\text{-}task} L_{swap\text{-}task} + \lambda_{swap\text{-}mode} L_{swap\text{-}mode} + \lambda_{con} L_{con} + \lambda_{MI} L_{MI} + L_{commit}$$
  - $L_{recon}$：L1 重建损失。
  - $L_{swap\text{-}task}$ / $L_{swap\text{-}mode}$：将基线片段的空间码与同任务-反模式配对的供体的时间码解码，强制空间码维持路径、时间码维持频率特征。
  - $L_{con}$：残差对比损失（参考 VQ-Style），强制时间码对应运动模式。
  - $L_{MI}$：空间 latent 的对抗互信息惩罚，剥离任务信息。
  - $L_{commit}$：标准 commitment loss。

- **Stage 2：行为克隆 Transformer（Behavior Cloning Transformer over Stage 1 Codes）**
  - 输入：前置 + 手腕相机图像（ResNet-34 特征）、当前本体感知、**任务标识 embedding**、**连续运动模式缩放器 $s \in [0,1]$**。
  - 输出：每个码本层级的 codebook 索引（分类头）+ 连续偏移头（offset head，用于补偿量化误差）。
  - 训练目标：分类交叉熵 + L1 偏移损失：
    $$L_{Stage2} = \frac{1}{K(L_{sp}+L_{te})} \sum_{k,\ell} \text{CE}(p^{(\ell)}_k, i^{*(\ell)}_k) + \|o - o^*\|_1$$
  - **Stage 1 编码器、码本、融合、解码器全部冻结**，仅训练 Transformer 与 offset head。
  - **推理（Inference）**：每个分类头取 argmax，按 stack 汇总码向量，融合并解码；若 $s$ 处于中间值则产生插值行为；高级调控 $s$ 即可在运行时无重训地切换模式。

### 关键设计逻辑

- **空间 vs. 时间双向解耦**：架构先验性地把"路径几何"与"时间参数化"分离。
- **离散 token 作为稳定接口**：冻结 Stage 1 让 Stage 2 简化为在有限 code 空间上的策略学习。
- **运行时可控**：模式通过连续缩放器调节，可人工或由上层 LLM 策略编排。

## 三、实验设计

### 任务与场景

- **硬件**：单臂 ALOHA leader–follower 配置（WidowX-250 leader + ViperX-300 6-DOF follower），两路相机（俯视 + 腕视，480×640），50 Hz 控制，chunk 长度 $T=100$（2 秒）。
- **六个真实机器人操作任务**：
  - 双模式训练（每任务 60 条演示，A/B 各 30）：
    - **pick**（放置物体）、**pour**（倾倒）、**look**（定向末端）、**avoid**（侧向避开）。
  - 单模式训练（用于 OOD 迁移测试）：
    - **highfive**（仅 Mode A 演示）、**push**（仅 Mode B 演示）。
- **对象与场景**：假食物、盘子、平底锅、锅、纸巾等桌面物体；物体初始位置与目标位置均固定（≤5 cm 变化）；轨迹从固定默认姿态出发，时长 16–20 秒。

### 评测协议

- 每个任务-缩放器组合 **N=20 次 rollout**，缩放器取 $s \in \{0.1, 0.5, 0.9\}$（Mode B、插值、Mode A）。
- **客观指标**（per segment）：
  - 关节速度（rad/s）
  - 关节加速度（rad/s²）
  - 末端接近俯仰（approach pitch，从正向运动学得到，正值=朝下）
- **人类评估**：3 位专家盲评，每次 rollout 视频打分（0–10）：
  - **风格贴合度（style adhesion）**：从 Mode B 到 Mode A。
  - **任务完成度（task completion）**：从完全失败到干净成功。
- **对比方法**：本文未与具体 baseline 模型（如 ACT、Diffusion Policy、BeT/VQ-BeT/FAST）做定量对比，工作重心在于验证"运动模式可控性 + 跨任务迁移"这一新命题。

## 四、实验数量与充分性

- **实验规模**：6 任务 × 3 缩放器 × 20 rollout = 360 次真实机器人 rollout。
- **统计检验**：对 4 个已训练任务 + 2 个迁移任务，分别计算缩放器 $s$ 与命令速度/加速度之间的 **Spearman 秩相关系数**（Table I）。

- **人类评估**：3 位专家 × 6 任务 × 3 缩放器 = 54 单元 × 2 评分维度。
- **潜在偏差来源**：
  - 单一物体位置初始化范围（±5 cm），泛化宽度有限。
  - 专家评估者非盲选（属于研究内部"expert rater"），可能引入确认偏差。
  - 无与现有动作分词基线（VQ-BeT、FAST）的实验对比，无法证明该框架相对已有方案在通用任务上的优势。
- **总体评价**：实验设计聚焦于"模式可控性 + 跨任务迁移"这一明确假设，统计检验较为严谨；然而样本规模、单一种体型、缺乏 baseline 对比均限制结论的外推性。

## 五、主要结论与发现

- **行为可控性**：调节缩放器 $s$ 可在所有已训练任务上单调改变关节速度、加速度与末端接近俯仰，$s=0.5$ 插值点稳定落在两原型之间。
- **人类可区分**：盲评者能在所有任务上（含两个迁移单元）正确区分 Mode A / 插值 / Mode B 的风格。
- **组合泛化**：在仅演示单一模式的任务（highfive、push）上，模型能将未演示的请求模式迁移过去，任务成功率大部分保留。
- **潜空间结构**：
  - 空间码 $z_{q,sp}$ 聚类主要按"任务"组织，与模式无关。
  - 时间码 $z_{q,te}$ 沿 PC1 形成一条 Mode B–Mode A 带，所有任务在时间码上重叠。
  - 迁移时，空间码留在任务聚类内，时间码位移到请求模式区域。
- **作者自我定位**：本文提供的是"任务-模式因子化的初步证据"，而非完全解耦的表征。

## 六、优点与亮点

- **架构创新**：将动作片段分解为独立的"空间流 + 时间流"双 RVQ 栈，并通过 DCT 域差分特征让时间流自然聚焦于节奏与平滑度。
- **组合式可复用**：用冻结分词器提供稳定 code 词汇，模式通过一个连续标量即可在运行时调控，无需重训。
- **跨任务迁移实证**：在 OOD 任务-模式对上（训练时该任务从未演示该模式）证实了模式的可迁移性，并通过 latent 可视化解释为"时间码位移、空间码保留"。
- **多维度验证**：客观运动指标 + Spearman 统计检验 + 盲评人类主观评分 + 潜空间 PCA，多角度交叉验证。
- **任务设计兼顾多样性**：双模式 4 任务 + 单模式 2 任务，覆盖精准抓取、倾倒、姿态定向、避让、推、互动等多个接触/空间类型。
- **应用前景**：将 $s$ 暴露给上层 LLM 策略，机器人可在交互中实时调整行为模式。

## 七、不足与局限

- **任务-模式解耦不完全**：模式存在几何相关性（approach pitch），空间编码器会吸收部分行为信息，限制迁移幅度。
- **单一硬件与平台**：仅在 Interbotix X-Series ALOHA 配置、桌面场景、单一物体集上验证，未推广到多形态机器人或非桌面场景。
- **样本规模有限**：每任务 60 演示、每单元 20 rollout，初始物体位置仅 ±5 cm 抖动，外推风险高。
- **缺乏 baseline 对比**：未与 ACT、Diffusion Policy、VQ-BeT、FAST 等现有模仿学习/动作分词方法对比，难以判断风格可控性是否相对于已有方案是新颖贡献。
- **模式空间受限**：仅两个原型 + 1 维标量缩放器，真实运动模式维度更丰富；两个原型均靠"temporal 维度"为主，缺少更复杂的"交互-语境"调制。
- **人类评估局限**：仅 3 位专家评分（而非非专家大样本），盲评指标主观性强；样式贴合度定义在 Mode B ↔ Mode A 区间，训练有偏。
- **量化指标欠捕获**：作者自承，速度/加速度标量指标低估了实际行为差异（raters 仍能感知 highfive 模式差异），但未补充更细粒度的度量（如 jerk、轨迹熵、目标对齐误差）。
- **迁移失败案例**：push 在迁移至 Mode A 时，虽然轨迹被正确减速，但接触阶段可靠性下降，影响任务完成度。
- **潜空间结论仅基于 PCA**：线性降维可能掩盖高维结构，缺少 t-SNE/UMAP 或聚类指标（如 NMI、ARI）。
