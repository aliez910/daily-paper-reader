## 摘要
VLA模型的视觉表征在空间精确的机器人操控任务中仍然不够可靠。我们发现，VLA中的视觉编码器同样存在先前在通用视觉Transformer中被记录的注意力伪影，并进一步证明，在具身策略中，这些伪影与后训练阶段获得的空间感知能力密切相关。当编码器学习任务相关信息（如目标位置、深度顺序和局部几何结构）时，有限的全局token容量导致部分信息溢出到低信息的patch token中。我们提出了AtVLA框架，该框架在视觉编码器中插入可学习的寄存器token。仅使用具身数据和原始动作目标进行端到端训练，这些寄存器便成为承载具身空间信息的专用载体，而其余的patch token则恢复出干净且空间保真的注意力分布，这对于精确的目标定位和细粒度的接触至关重要。干净的注意力恢复了可靠的定位能力，但无法恢复在低分辨率观测中丢失的几何细节。因此，AtVLA将注意力矫正与不确定性门控的局部优化相结合。动作专家采样多个动作分块并根据其不一致性估计不确定性；仅对不确定的预测，通过动作条件化的注意力展开识别任务相关区域，将其裁剪、以高分辨率重新编码，并附加到缓存的前缀上用于精细动作生成。在LIBERO、SimplerEnv以及具有挑战性的单视角真实世界基准测试中，AtVLA将LIBERO的平均成功率从94.2%提升至98.4%，真实世界成功率从46.5%提升至69.0%。在典型的部署设置下，约30%的重规划步骤触发裁剪操作，仅为基础模型总计算量的1.4至1.6倍。

## Abstract
Visual representations of VLA models remain unreliable for spatially precise robotic manipulation. We uncover that vision encoders in VLAs also exhibit attention artifacts previously documented in generic Vision Transformers, and further show that, in embodied policies, these artifacts are closely associated with spatial perception capabilities acquired during post-training. As the encoder learns task-relevant information such as object location, depth ordering, and local geometry, limited global-token capacity causes part of this information to spill into low-information patch tokens. We introduce AtVLA, a framework that inserts learnable register tokens into the visual encoder. Trained end-to-end using only embodied data and the original action objective, these registers emerge as dedicated carriers of embodied spatial information, while the remaining patch tokens recover clean and spatially faithful attention distributions crucial for precise target localization and fine-grained contact. Clean attention restores reliable localization, but cannot recover geometric details lost in low-resolution observations. AtVLA therefore couples attention rectification with uncertainty-gated local refinement. The action expert samples multiple action chunks and estimates uncertainty from their disagreement; only for uncertain predictions, action-conditioned attention rollout identifies the task-relevant region, which is cropped, re-encoded at high resolution, and appended to the cached prefix for refined action generation. Across LIBERO, SimplerEnv, and a challenging single-view real-world benchmark, AtVLA improves the average LIBERO success rate from 94.2% to 98.4% and real-world success from 46.5% to 69.0%. The cropping is triggered on approximately 30% of replanning steps, resulting in only 1.4-1.6x the total computation of the base model under the representative deployment setting.

# 论文总结：AtVLA——面向视觉-语言-动作模型的自适应视觉优化

## 一、核心问题与研究动机

- **背景**：视觉-语言-动作（VLA）模型通过在机器人示教数据上对大规模视觉-语言模型进行后训练，将语义理解与指令跟随能力迁移到连续控制策略中，已成为通用机器人操控的主流范式。
- **核心矛盾**：机器人控制不仅需要语义识别，还要求视觉编码器保留空间保真表征以支持目标定位、几何推理与精确接触；但 VLA 视觉编码器在此方面表现不可靠。
- **两大视觉瓶颈**：
  1. **注意力伪影（Attention Artifacts）**：视觉编码器中存在高范数（high-norm）的"异常 token"，它们聚集在低信息背景或无关物体区域，挤占局部空间内容，破坏密集注意力图的空间对应关系；这一现象在通用 ViT 中已被报道（Darcet et al. 2023），本文进一步揭示其在具身后训练阶段被加剧——当编码器学习目标位置、深度顺序、实例结构和局部几何等任务相关信息时，原始全局 token 容量有限，导致部分具身空间信息溢出到 patch token 中。
  2. **定位正确 ≠ 操作精确**：即使能正确定位目标，精细操作仍需要接触区域附近的局部几何细节；这些细节在低分辨率第三视角观测中可能仅占少量 patch；腕部相机虽然能提供近距离视角，但视角与位姿变化敏感、目标区域位置不稳定；引入显式视觉专家或 3D 表示又会带来额外传感、标定与建模复杂度。

## 二、方法论

### 2.1 整体框架

AtVLA 在 π0（3B PaliGemma + 300M 动作专家）基础上引入两个互补机制：
1. **寄存器增强视觉编码（Register-Enhanced Visual Prefix）**
2. **不确定性门控的局部视觉优化（Uncertainty-Gated Local Refinement）**

整体流程：原始观测 → 寄存器增强视觉编码 → 多视角 patch tokens + 寄存器特征作为前缀 → LLM backbone 构建可复用 KV cache → 动作专家采样 K=4 个动作分块 → 基于近端平移维度的标准差估计不确定性 → 低不确定性直接执行，高不确定性则进行动作条件注意力展开 → 裁剪、224×224 高分辨率重新编码 → crop 位置编码后追加到前缀 → 重生成精细动作。

### 2.2 关键技术细节

- **寄存器增强视觉前缀**：
  - 在 SigLIP 视觉编码器中插入 Nr=4 个可学习寄存器嵌入，每个 1152 维，仅增加 4,608 个参数；
  - 输入序列为 `[CLS; REG₁…REG₄; patch₁…patch₂₅₆]`；
  - 寄存器输出 Rt 经 PaliGemma 视觉投影器 Π 后与 patch tokens 一同进入下游；
  - 多相机视角各自独立编码并按前缀顺序拼接。
- **不确定性门控动作预测**：
  - 动作专家基于共享前缀从独立高斯初始化出发采样 K=4 个动作分块 A⁽ᵏ⁾₁:ₕ；
  - 不确定性 Ut 仅在"实际执行"的近端 h 个动作的平移维度 Dtr={Δx,Δy,Δz} 上计算 K 样本标准差均值；
  - 阈值 τ 在 episode 不相交的验证集上以约 30% 触发率为预算，按"裁剪带来的近端动作误差下降"校准；
  - 门控决策在每个动作分块重规划步上执行一次，而非每个底层控制步。
- **注意力引导局部优化**：
  - 从动作专家的 18 层联合注意力矩阵中，按 Euler 去噪步 Q={3,6,9} 和所有注意力头平均；
  - 加残差连接并按行归一化后做注意力展开（rollout）得到 Mroll；
  - 取近端 h 个 action-token 行到 256 个 base patch 列的均值，重塑为 16×16 显著性图 St，再双线性上采样；
  - 寄存器列被排除（其无固定图像网格对应关系）；
  - 候选方形窗口边长 S={84, 112, 140} 像素，14 像素步长；采用"内部注意力 − 1.25× 扩展环带注意力"的对比评分；
  - 选中的窗口加 10% padding、clip 到原图边界后缩放到 224×224；
  - crop 归一化坐标 (x1/W, y1/H, x2/W, y2/H) 经两层 MLP（4→256→dLLM，GELU 激活）得到位置编码，加到每个 crop patch token；
  - crop 视角的寄存器输出被丢弃（全局上下文已由 base 寄存器概括）；
  - base/language/state 的 KV cache 被复用，仅对 crop 段进行新一次 prefetch；
  - 失效回退：显著性图非有限、总注意力质量 <10⁻⁶、候选分数无效、坐标退化或裁剪后边长 <56 像素等情况下，跳过 crop 细化，退回 base 路径。
- **训练目标与课程**：
  - 总损失 L = Lπ₀ + λcp·Lcp + λag·Lag，λcp=0.1，λag=1.0；
  - Lag 监督 action-to-image 注意力集中在标注的任务相关区域 Ω(bgt) 内；
  - 三阶段训练：
    1. **Stage 0 寄存器适配**（20K 步）：4K 步仅更新寄存器，16K 步再解冻最后 4 个 SigLIP block；
    2. **Stage 1 真值裁剪对齐**（10K 步）：冻结视觉编码器，仅优化 crop 位置 MLP 与 LoRA（rank 32）；
    3. **Stage 2 联合优化**（40K 步）：三阶段 crop 课程——前 40% 用真值裁剪（α=0, pdrop=0），40%–90% 线性过渡到 attention rollout 裁剪（α 0→1, pdrop 0→0.3），最后 10% 全 rollout 裁剪（α=1, pdrop=0.3）；
  - 优化器 AdamW，batch size 4，恒定学习率 1×10⁻⁴。

- **机制有效性**：
  - 寄存器 token 在物体定位、深度、表面法线的线性探针得分均 >0.70，强于 CLS 与 pooled patch；
  - 移除寄存器使 LIBERO 平均下降约 4.45 个百分点，说明寄存器并非仅抑制伪影，还承载任务相关具身知识；
  - 寄存器数量 <4 时性能下降甚至低于 π0 基线（伪影吸收不充分、扰乱已建立的多模态协调），4 个为"最小充分容量"。
- **裁剪作用**：
  - 外部 VLM 提供的裁剪常无法聚焦于交互关键区域，弱于具身训练下的 attention rollout 裁剪；
  - 裁剪对长时序任务（LIBERO-Long-10、真实世界长时序）也有帮助，提示其同时支持局部精度与时序规划；
  - 在 Open/Close Drawer 等目标占满画面的场景中裁剪收益有限。
- **开销可控**：仅约 30% 重规划步触发裁剪，总计算量约为 π0 的 1.4–1.6×。
- **失败处理**：无效 rollout 直接退回 base 路径，与训练时一致，避免训练—部署偏差。

## 七、优点

- **问题定位精准**：将"具身后训练获得的空间能力与通用 ViT 的注意力伪影现象联系起来"，并通过探针与消融加以佐证；
- **极轻量**：仅增加 4,608 个寄存器参数 + 一个小型 crop 位置 MLP，不改变 π0 的动作表示与生成过程；
- **即插即用**：保留原始动作目标、KV cache 复用、门控粒度设在重规划步；
- **课程设计完备**：三阶段训练 + 三阶段 crop 课程（真值 → 混合 → rollout）显著缩小训练—部署差距；
- **不确定性门控降低开销**：避免对每一步都进行高分辨率重编码；
- **评估多维度**：仿真 + 单视角真实世界 + 线性探针 + 定性可视化 + 多基线 + 受控变体；
- **可解释性**：寄存器被显式保留并输入下游动作生成，使得"被吸收的具身信息"
