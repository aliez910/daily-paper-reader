## 摘要
可供性引导的模仿学习通过将视觉感知压缩为特定任务的几何约束（例如固定接触点），在机器人操作任务中展现出令人瞩目的性能。然而，常用的静态可供性在精度要求严格的任务中或当物体位置发生扰动时可能变得不再一致，从而导致接触后轨迹漂移。为解决这一问题，我们提出了AffordTrajDP，一个通过以物体为中心的时间传播来构建可供性轨迹、从而引导渐进式操作过程的动态框架。具体而言，给定一个RGB-D观测，我们的核心洞见在于：所检索到的锚点可供性捕获了末端执行器与目标物体之间期望的接触点，它可以通过可供性传播向前传播，以物体的SE(3)位姿作为天然的传播介质，从而产生一条可在整个执行过程中提供时间一致、状态感知引导的可供性轨迹。AffordTrajDP在ManiSkill3上达到了70.0%的平均成功率，较强基线方法提升高达17.8%。在Galaxea A1和UR7e机械臂上进行的真实世界实验涵盖了堆叠方块、取杯、适配器插入、套环、放入碗中以及USB插入等任务，进一步验证了该方法在物体位置变化和外观变化下的鲁棒性；其中在Galaxea A1上对已见和未见物体实例均进行了评估，消融实验进一步证实了各所提组件的贡献。

## Abstract
Affordance-guided imitation learning has shown impressive performance in robotic manipulation tasks by compressing visual perception into task-specific geometric constraints (e.g., fixed contact points). However, the commonly used static affordances can become inconsistent in precision-critical tasks or under object location perturbations, leading to post-contact trajectory drift. To address this issue, we propose AffordTrajDP, a dynamic framework that constructs affordance trajectories via object-centric temporal propagation to guide the progressive manipulation process. Specifically, given an RGB-D observation, our core insight is that a retrieved anchor affordance, which captures the desired contact point between the end-effector and the target object, can be propagated forward via affordance propagation, using the object's SE(3) pose as a natural propagation medium, to yield an affordance trajectory that provides temporally consistent, state-aware guidance throughout execution. AffordTrajDP achieves 70.0% average success rate on ManiSkill3, outperforming strong baselines by up to 17.8%. Real-world experiments on Galaxea A1 and UR7e robotic arms, covering StackCube, PickCup, AdapterInsertion, Ring-on-Peg, Put-in-Bowl, and USB Insertion, further validate robustness under object placement variations and appearance changes, with seen and unseen object instances evaluated on Galaxea A1, and ablations confirm the contribution of each proposed component.

# AffordTrajDP 论文详细总结

## 1. 核心问题与研究动机

- **研究背景**：仿可供性（affordance）引导的模仿学习通过将视觉感知压缩为任务特定的几何约束（如固定接触点），在机器人操作中取得了显著效果。
- **关键局限**：现有方法普遍将可供性视为**静态**的——一次性从参考示范中检索并通过刚体变换迁移到目标物体后，接触点和接触后轨迹在整个回合中保持不变。
- **失效模式**：在**精度严格**（如适配器插入、插销对接）或**物体位姿受扰**的场景下，一旦目标物体发生接触后偏移，静态先验便与物体的实际位姿发生渐进式失准，导致接触后轨迹漂移、抖动或失败。
- **核心诊断**（作者明确提出的新视角）：现有可供性条件信号只覆盖了所需信息的"一半"——
  - 仅跟踪物体全局位姿（PRISM-DP 跟踪当前帧、SPOT 预测未来位姿轨迹）的方法**丢弃了"在哪里接触"的语义**；
  - 仅检索语义接触点（AffordDP）的方法**丢弃了"接触点应如何随时间更新"的位姿演化**。
- **总体目标**：首次提出一种同时保留"在哪里接触"与"接触点如何演化"的条件信号，并据此设计一套动态可供性引导的视觉运动策略。

## 2. 方法论

### 2.1 整体框架
AffordTrajDP 由三个核心模块组成：
1. **锚点可供性生成（Anchor Affordance Generation）**：从记忆库中检索语义最相似的源实例，并通过密集视觉对应将源接触点迁移到目标物体。
2. **未来 SE(3) 位姿轨迹预测**：基于目标物体当前位姿历史，使用扩散模型（DDIM）预测未来 H 步位姿。
3. **可供性传播（Affordance Propagation）**：将锚点接触点沿预测的位姿轨迹进行刚体传播，生成时变的可供性轨迹，作为扩散策略的条件信号。

### 2.2 关键技术细节

- **可供性表征**：`Φ = (c, τ)`，其中 `c ∈ R³` 为静态 3D 接触点，`τ ∈ R^{3×H}` 为动态接触点轨迹。
- **锚点检索流程**：
  - 用 GroundedSAM 在第一帧裁剪目标物体区域；
  - 用 CLIP 图像编码器提取外观特征 `z`；
  - 记忆库中按任务标签过滤后取最近邻，迁移接触点；
  - 通过源-目标密集视觉对应，将源像素匹配点反投影到目标 RGB-D 获得 `c^{tgt}`。
- **未来位姿预测**：
  - 使用 FoundationPose 跟踪得到物体 6D 位姿序列；
  - 将源物体轨迹表达在**目标物体坐标系**下 `T^{src}_{tgt}(t) = (T^{tgt}_W(t))^{-1} · T^{src}_W(t)`，消除场景布局差异；
  - 在向量化的 SE(3) 空间 `x = [t; q] ∈ R⁷`（平移 + 单位四元数）上训练 DDIM；
  - 条件为位姿历史 `h_t`，每步去噪后重新归一化四元数；
  - 选用 DDIM（非马尔可夫确定性反向过程）可减少去噪步数并避免随机扰动传播到可供性轨迹。
- **可供性传播公式**（核心创新点）：

  $$p_{t+k} = T_{t+k} \cdot \tilde{c}, \quad k = 0, \dots, H$$

  其中 `T_{t+k}` 来自预测的位姿轨迹，`\tilde{c}` 为齐次坐标的锚点接触点。

- **动作生成**：
  - 静态可供性 `c` 由 2 层 MLP 编码（隐维 256）；
  - 动态可供性轨迹 `τ` 由带 `[CLS]` token 的 Transformer 编码（2 层、2 头、`d_model=64`、FFN=256、dropout=0.1、GELU）得到 64 维特征；
  - 与点云等其他观测拼接后送入基于 DDIM 的扩散策略（1D U-Net，FiLM 条件化，通道宽度 [512, 1024, 2048]），预测 16 步动作序列，滚动执行前 8 步，控制频率 10 Hz。

## 6. 主要结论与发现

- **仿真**：在 ManiSkill3 六任务上平均 SR 达 **70.0%**，超过 DP3（52.2%）、AffordDP（57.8%）、SPOT（62.1%），最大提升 **17.8%**。
- **真实世界**：
  - Galaxea A1 上统一策略平均 SR 66.1%，DP3 仅 35.0%；
  - UR7e 上平均 SR 72.5%，DP3 40.8%；
  - 已在/未见物体实例均显著优于基线。
- **关键发现**：
  - 语义接触点与位姿轨迹**各自必要、单独不足**——只有联合使用才能带来稳定的大幅提升（66.1%）；
  - 精度越严格的任务（如 AdapterInsertion）受益越大；
  - 在 StackCube 未见实例上，+Traj 反而低于 DP3（20% vs 40%），说明**没有语义锚点的位姿轨迹是噪声**；
  - 接触后 FoundationPose 跟踪误差比轨迹扩散预测误差更大，提示上游跟踪是后接触位姿不确定性的主要来源（作者明确标注为相关分析而非受控消融）。
- **总体结论**：动态可供性传播可有效替代静态约束，为高精度操作与位姿扰动场景提供时序一致的视觉-运动引导。
