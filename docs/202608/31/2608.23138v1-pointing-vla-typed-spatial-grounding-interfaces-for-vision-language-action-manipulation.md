## Abstract
Vision-language-action (VLA) models often expose spatial grounding through autoregressive text coordinates or opaque action tokens, creating brittle interfaces between multimodal reasoning and robot execution. We present Pointing-VLA, a typed hidden-state spatial readout built on Embodied-R1. Geometry-specific heads predict normalized points, object-functional grounding (OFG) heatmaps, and visual trajectories without serializing geometry as text. For the evaluated Bridge/WidowX and physical pick-place deployments, an explicit execution contract assigns PICK to source-conditioned OFG and PLACE to Pointing, providing direct stage-aligned spatial targets. Pointing-VLA achieves SOTA performance on Bridge/WidowX, averaging 72.9\% across the evaluated four-task set without Bridge-specific finetuning under collision-enabled CuRobo execution. Pointing and OFG show complementary strengths across native and cross-dataset evaluations. The OFG/contact readout transfers to NORA-1.5, preserving or improving success while reducing recorded controller time by more than 20$\times$; typed heads are also 6.68--6.90$\times$ faster than Embodied-R1 text decoding on a shared external suite. When integrated as spatial guidance for a $π_{0.5}$ action policy, Pointing-VLA raises autonomous real-robot success from 52.7\% to 80.7\% across three visual contexts. These results establish typed spatial readouts as an efficient, inspectable interface between embodied reasoning and robot execution.

# Pointing-VLA 论文总结

## 1. 核心问题与整体含义

**研究背景与动机**

- **现有 VLA 模型的接口瓶颈**：现有 Vision-Language-Action（VLA）模型通过自回归文本坐标（如"[222, 172]"）或不透明的动作 token 暴露空间定位，这导致多模态推理与机器人执行之间的接口脆弱且难以检查。
- **两种典型失败模式**（论文图 1）：
  - 生成阶段无法产出可解析坐标；
  - 语法合法但空间错误的坐标落出目标区域。
- **将几何信息序列化为文本的代价**：解析成为额外的执行依赖、密集的部件级证据在执行前被丢弃、token 被用于"拼写数字"而非几何推理。
- **核心主张**：具身接地应被视为**类型化接口预测**，而非文本坐标生成——指代点、功能区域、视觉轨迹在几何性质上不同（稀疏点 vs 密集区域 vs 时序轨迹），混叠输出分布会产生负干扰，并使下游执行变慢。

## 2. 方法论

### 核心思想
- 基于 Embodied-R1 骨干，设计**类型化隐藏状态空间读出头**：点（Pointing）、对象功能接地热图（OFG）、视觉轨迹生成（VTG）。
- 阶段化训练：几何 warm-up → LoRA 专化 → 任务延续。
- 显式执行契约：将 PICK 绑定 source-conditioned OFG、PLACE 绑定 Pointing，VtG 用于需要路径注释的请求。

### 关键技术细节

**隐空间预测管线**

- 共享 Grounding Adapter 体（1024 维投影）+ 学得查询 + 专家专属解码器。
- 对点与 OFG 专家：8 个学得接地查询；最强 VTG 专家用时序查询直接注意全多模态序列以避免固定 token 瓶颈。
- 关键算子（公式层面）：
  - 点解码：`A_pt = softmax((q_pt W_Q)(G_pt W_K)^T / √d)`，再经 `LN + Linear + Sigmoid` 归一化到 `[0,1]^2` 图像坐标；
  - OFG：用全局接地摘要 `g_ofg` 通过 FiLM 调制视觉特征图 `F_vis`，卷积解码器输出热图，取峰值为功能接触点；
  - VTG：T=8 个归一化路径点；
- 预测评估准则：点用点入框（PIB）或点入掩码（PIM）；轨迹用 RMSE/ADE/FDE。

**执行契约（pick-place 主干）**

- 给定指令 ℓ、源描述 `c_src`、目标描述 `c_goal`，构造 slot 级查询；OFG 输出 PICK 接触、Pointing 输出 PLACE 目标，二者确定且无推理期选择器。
- 外部包装层用深度 `D`、相机内参 `K`、相机到机器人外参 `T_r←c`，将图像坐标转换为机器人坐标 `X_r`，关节已有的执行器直接消费。

**训练目标**

- 加权空间目标：`L = λ_pt L_pt + λ_box L_box + λ_ofg L_ofg + L_aux`；
- OFG 采用高斯关键点的 MSE 或类平衡 BCE；
- Pointing 头部另用 **GRPO 式组归一化精修**：以策略中心 µ、σ 采样 `a_i = clip(µ+σε_i, 0, 1)`，对落入 `B*` 的样本奖励 1、其他用距离衰减 0.5·max(0, 1−d/ρ)，再算组归一化优势 `A_i`；
- 损失：`L_GRPO = −mean(sg(A_i) log π_i) + λ_sft SmoothL1(µ, p*) + λ_kl D_ref + λ_σ L_σ`；
- **Source-conditioned OFG** 采用密集源掩码重建 + source-over-distractor 排序 + 干扰抑制。

## 6. 主要结论与发现

- **原生接地**（表 1）：Pointing-VLA 在 VABench-P 达 64.3%（与 Embodied-R1 持平），Part-Affordance-2K 由 40.9% 提到 57.3%（+16.4 pp），证明几何特化的有效性。
- **轨迹接口**：VTG 在 VABench-V 上达到 0.1042 RMSE、0.1368 ADE、0.1493 FDE。
- **机制消融**：8 个查询 + rank-32 LoRA 组合最优；GRPO 精修使 PIB 从 61.3% 提到 64.3%，证明设计空间并非参数越多越好。
- **固定契约**：Source-conditioned OFG 在堆叠任务上 100% 源选择准确率；总成功率 72.9%（70/96），高于次优组合 14.6 pp。
- **跨数据集**：Pointing 在 RefCOCO / RoboAff 最强；OFG 在 AGD20K 最强——接口几何存在互补。
- **运行效率**：类型化读出比 Embodied-R1 自回归解码快 6.68–6.90×。
- **跨 backbone**：冻结 NORA-1.5 + OFG/contact 读出，竖直姿态任务由 89% 提到 95%，控制器时延缩短 20 倍以上。
- **Bridge/WidowX SOTA**：72.9% 平均，4 任务均较强（Stack 100%、Eggplant 91.7%）；相比 Embodied-R1+CuRobo（52.1%）显著领先，且无需 Bridge 专用微调。
- **真实机器人**：π0.5 + Pointing-VLA 三个上下文共 150 trials 总成功率由 52.7% 升至 80.7%（+28 pp）；抓取失败由 47 降至 16，托盘到位失败由 13 降至 4。
- **总体结论**：类型化空间读出构成具身 VLM 推理与机器人执行之间高效、可检查的接口范式。

## 7. 优点与亮点

- **问题角度新颖**：将关注点从"模型如何把感知-语言映射为动作"切到"VLA 应在执行前暴露何种空间表示"，定位为接口设计而非模型设计。
- **跨学科动机**：明确援引 Goodale & Milner 的腹背双流假说与 Cisek 的可供性竞争理论，给出"vision-for-action / population-readout"理论支撑。
- **执行契约替代选择器**：固定 PICK ↔ OFG、PICK ↔ Pointing 绑定，将阶段与几何对齐，避免推理期路由开销与不确定切换。
- **多粒度几何并行**：点（稀疏指代）、OFG（保留部件级功能区域）、VTG（时序路径）三类接口各取所需。
- **跨 backbone 可迁移**：在 NORA-1.5 上以冻结 backbone 复用读出，验证解耦价值。
- **效率数据扎实**：6.68–6.90× 推理加速与 20× 控制器时延缩减均给出在统一外部协议下的可比口径。
- **部署闭环完整**：覆盖模拟 Bridge/WidowX（含 CuRobo 碰撞感知规划）和真实 PiPER 机器人，并分析抓取/转移/托盘/不确定四类失败阶段。
- **零 Bridge 专用微调**：在未见过的 Bridge/WidowX 部署上仍获 SOTA，体现强泛化。
