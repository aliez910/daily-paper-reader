## 摘要
视觉-语言-动作（VLA）模型通过整合视觉感知、语言理解和连续动作控制，为通用机器人操作提供了一条可扩展的路径。然而，我们揭示了VLA架构的一个关键局限性：动作专家对VLM特征中可用的三维几何信息和二维语义信息的访问有限。这种可访问性差距削弱了感知基础，并限制了细粒度机器人操作任务的性能。为了解决这一问题，我们提出了V-Link，在视觉-语言（VL）到动作（A）的特征传递过程中显式恢复视觉表征。具体而言，V-Link在VLM内部学习互补的空间查询和语义查询表征，并通过非对称路径将其注入Action DiT中。语义查询补充了原始的VLM图像令牌，而空间查询为基于空间的动作生成提供了专门的几何条件。在LIBERO、LIBERO-Plus和RoboTwin 2.0上，我们的V-Link相比基线模型GR00T N1.6分别将平均成功率提升了+1.9%、+31.2%和+18.8%。在AGIBOT A3 Ultra上，V-Link在两项真实世界人形机器人任务上分别进一步取得了+20%和+24%的性能提升。

## Abstract
Vision-language-action (VLA) models provide a scalable path toward generalist robotic manipulation by integrating visual perception, language understanding, and continuous action control. However, we reveal a critical limitation of VLA architectures: the action expert has limited access to the 3D geometric and 2D semantic information available in VLM features. This accessibility gap weakens perceptual grounding and limits performance on fine-grained robotic manipulation. To address this issue, we propose V-Link, which explicitly recovers visual representations during the vision-language (VL) to action (A) feature transfer. Specifically, V-Link learns complementary Spatial and Semantic Query representations within the VLM and injects them into Action DiT through asymmetric pathways. Semantic Queries complement the original VLM image tokens, whereas Spatial Queries provide dedicated geometric conditioning for spatially grounded action generation. Across LIBERO, LIBERO-Plus, and RoboTwin 2.0, our V-Link improves the average success rate over base model GR00T N1.6 by +1.9%, +31.2%, and +18.8%, respectively. On the AGIBOT A3 Ultra, V-Link further achieves gains of +20% and +24% on two real-world humanoid tasks.

# V-Link 论文总结

## 1. 核心问题与整体含义

- **研究背景**：视觉-语言-动作（VLA）模型通过融合 VLM（视觉-语言模型）与 Action DiT（动作专家）双系统结构，为通用机器人操控提供可扩展路径。其核心是"VL→A 特征传递"，决定 VLM 哪些信息可被动作专家访问。
- **关键问题**：当前主流方案（如 NVIDIA GR00T N1.6）仅传递 VLM 最后一层特征到 Action DiT，导致动作专家**对 3D 几何信息和 2D 语义信息的访问受限**，形成"视觉表征可访问性瓶颈"。
- **诊断实验证据**（参考 Spatial Forcing 思路）：冻结 VLM 与 Action DiT 特征，仅训练轻量级深度估计头和语义分割头进行评估。结果显示——从 VLM 到 Action DiT，深度估计 MAE 从 0.015 升到 0.071，语义分割 mIoU 从 0.665 跌至 0.290，差距显著。
- **作者假设**：在"动作监督"驱动下，Action DiT 倾向利用语义捷径快速降低动作损失，而忽视结构性的 3D 空间线索，导致陷入缺乏空间基础的局部最优。
- **研究意义**：揭示了双系统 VLA 中"表征可访问性"这一被忽视的瓶颈，对精细化机器人操控具有重要价值。

## 2. 方法论：核心思想、关键技术与流程

### 2.1 整体思路
在 VLM 中学习两组可学习的查询令牌——**空间查询（Spatial Queries, $E_d$）**与**语义查询（Semantic Queries, $E_s$）**，通过特定监督信号将二者解耦，再以**非对称路径**注入 Action DiT，分别补充语义信息与几何条件。

### 2.2 关键组件

- **VLM 输入构造**：
  $$E = [E_t; E_o; E_d; E_s]$$
  其中 $E_t$、$E_o$ 为文本与多视角图像令牌。
- **因果注意力掩码 $M_q$**：在自注意力中隔离两类查询，使其可独立聚合 VLM 图像/文本特征而不扰乱原有计算。
- **轻量级任务头（仅训练时使用）**：
  - **深度头 $\Phi_{Depth}$**（约 2.3M 参数）：含投影层、Per-view 编码器、卷积解码器；输出用 softplus 约束正值。
    - 损失：$L_{depth} = L_{sm} + \lambda_1^d L_{rel} + \lambda_2^d L_{patch}$（smooth-L1 + 绝对相对损失 + top-k 难样本 patch 损失）。
  - **语义分割头 $\Phi_{Seg}$**：输出经 Softmax 得到 logits。
    - 损失：$L_{seg} = L_{CE} + \lambda^s L_{Dice}$（交叉熵 + Dice 损失）。
- **训练策略**：先用相同超参数 warm-up VLM LoRA + 查询 + 任务头，再联合优化；推理时移除辅助头，无需深度/语义标注。

### 2.3 Action DiT 中的非对称注入
仅在 4k+2 层（图像交叉注意力层）注入查询：
1. **语义查询并行交叉注意力**：与 VLM 图像令牌并列，作为 K/V 与状态/动作令牌做交叉注意力；
   $$Z_l = H_l + \text{Fuse}(N_l, g_l S_l)$$
   其中 $g_l$ 为可学习门控参数。
2. **空间查询专用几何条件**：将融合后的 $Z_l$ 作为 Q，空间查询作为 K/V，进行空间交叉注意力：
   $$H'_l = Z_l + \text{CA}_{Spatial}(Z_l, E'_d)$$
3. 最后经 FFN 输出 $H_{l+1}$。

### 2.4 总训练目标
$$L = L_{act} + \lambda_1^a L_{depth} + \lambda_2^a L_{seg}$$
其中 $\lambda_1^a = 0.1$，$\lambda_2^a = 0.002$，$L_{act}$ 为 flow-matching 动作生成损失。

## 6. 主要结论与发现

- **关键现象**：现有 VLA 中 VL→A 特征传递存在视觉表征可访问性瓶颈，Action DiT 对 3D 几何信息访问远不如对语义信息。
- **V-Link 效果**（相对 GR00T N1.6）：
  - LIBERO：+1.9%（99.3% 平均成功率，4 个子套件均第一）。
  - LIBERO-Plus：+31.2%（75.0% 总分，6/7 设置第一，噪声 +60.4%、语言 +47.3%、光照 +30.6%）。
  - RoboTwin 2.0：+18.8%（56.8% 平均，6 任务全部提升）。
  - 真实 AGIBOT A3 Ultra：通电 98%（+20%），断电 94%（+24%）。
- **效率代价**：仅 +1.58 ms 推理延迟。
- **消融发现**：
  - 空间查询 +13.2%、语义查询 +9.8%，二者结合达 +18.8%，呈互补；
  - 仅注入无监督 → 仅 +2.3%；仅监督无注入 → +1.8%；二者联合达 +18.8%，说明"专门化"与"注入"缺一不可。
  - 查询令牌 3×5×5 网格为最佳精度-效率折衷。
- **定性结论**：V-Link 在 Action DiT 中有效恢复了 3D 深度与 2D 语义结构（图 5）。

## 7. 优点

- **问题洞察新颖**：首次明确提出并诊断"VL→A 视觉表征可访问性瓶颈"，填补了双系统 VLA 表征分析的研究空白。
- **诊断方法严谨**：冻结特征 + 轻量头控制变量的可访问性测度协议，可迁移用于其他模型分析。
- **架构设计巧妙**：因果注意力掩码隔离查询，避免破坏原生多模态流；非对称注入路径分别处理语义与几何，思路清晰。
- **效果全面**：仿真 3 个基准 + 真实机器人，覆盖泛化与鲁棒性；延迟开销极小（+1.58 ms）。
- **充分消融**：从查询设计、监督信号、注入机制到令牌数量逐项验证，逻辑严密。
- **推理友好**：辅助头仅训练时使用，推理不依赖深度/分割标注或 3D 基础模型。

## 8. 不足与局限

- **真实机器人覆盖有限**：仅 2 个任务（通电/断电）、单平台（AGIBOT A3 Ultra），未见跨平台、跨任务多样性验证。
- **基座依赖性强**：V-Link 以 GR00T N1.6 为基础，未展示在其他双系统 VLA（如 π0、OpenVLA-OFT）上的可迁移性。
- **监督依赖**：训练需深度与语义伪真值（真实机器人使用 Lingbot-Depth 与 GroundingDINO + SAM3 生成），增加了数据准备成本与误差传递风险。
- **缺少置信度/方差报告**：多数成功率缺少多次运行的标准差，难以判断提升的统计显著性。
- **未做失败案例分析**：缺少对失败模式的系统归因（如哪些任务/偏移仍受限）。
- **未见大模型规模验证**：实验集中在 3B 模型，缺乏对更大规模 VLM（如 7B/13B）的扩展性测试。
- **任务定义较窄**：仿真集中在桌面/厨房操作类任务，未覆盖移动机器人、长时序复合任务等更广泛场景。
- **应用限制**：依赖多视角相机与一定质量的深度伪真值，对低成本传感器或极端光照环境下的鲁棒性存疑。
