## 摘要
基于查询的视觉-语言-动作（VLA）模型具有低延迟推理的优势，对双臂机器人操控颇具吸引力，但我们观察到，在复杂的双臂任务中，它们仍可能出现动作不连续和执行失败的情况。我们假设，多视角与语言融合的不稳定性是导致这些失败的因素之一，并且常常伴随着注意力扩散到干扰区域的现象。为提升鲁棒性，我们提出了模态掩码机制（M3），这是一种极其简单、仅在训练阶段使用的策略，无需架构改动，也无需大规模机器人预训练。M3 在训练过程中随机掩码一部分模态通道，使策略暴露在受控的部分观测下，从而促使其减少对干扰性线索的依赖，更多地依赖依然可靠的证据。我们在 RoboTwin 2.0 的十个双臂任务以及三个长时序真实任务上对 M3 进行了评估。相较于 Adapter 基线，M3 在 Clean 设置下将平均成功率提升了 21.7%，在 Clean2Rand 设置下（策略基于干净演示训练，并在随机化场景下评估）提升了 11.4%，同时将真实场景下全任务的平均成功率提升超过 30%。这些结果表明，结构化的训练时掩码是提升双臂操控中基于查询的 VLA 策略鲁棒性的一种实用方法。

## Abstract
Query-based Vision-Language-Action (VLA) models offer low-latency inference that is attractive for bimanual robotic manipulation, but we observe that they can still exhibit discontinuous actions and execution failures in complex dual-arm tasks. We hypothesize that unstable multi-view and language fusion is one contributing factor in these failures, often coinciding with attention spreading to distracting regions. To improve robustness, we introduce the Modality Masking Mechanism (M3), an embarrassingly simple, training-only strategy that requires no architectural changes or large-scale robot pretraining. M3 stochastically masks subsets of modality channels during training, exposing the policy to controlled partial observations and encouraging it to rely less on distracting cues and more on evidence that remains reliable. We evaluate M3 on ten bimanual tasks from RoboTwin 2.0 and on three long-horizon real-world tasks. Compared with the Adapter baseline, M3 improves average success by 21.7% in the Clean setting and 11.4% in Clean2Rand, where policies are trained on clean demonstrations and evaluated on randomized scenes, while also improving averaged real-world full-task success by over 30%. These results suggest that structured training-time masking is a practical way to improve the robustness of query-based VLA policies for bimanual manipulation.

# 论文总结：通过模态掩码机制增强双臂 VLA 模型鲁棒性

## 1. 核心问题与研究动机

- **研究对象**：基于查询（query-based）的视觉-语言-动作（VLA）模型，例如 VLA-Adapter、OpenVLA-OFT 等。这类模型通过可学习的 action query 在单次前向传播中解码动作块（action chunk），具备低延迟、并行推理的优势，非常适合双臂机器人操控。
- **核心问题**：尽管查询式 VLA 推理效率高，但在复杂双臂任务中仍存在两大痛点：
  - **动作不连续与执行失败**：末端执行器轨迹出现抖动、跳变，导致任务失败；
  - **注意力扩散（attention spreading）**：模型将注意力分散到与任务无关的图像区域（如背景、夹爪、闲置手臂的视角），而非集中于目标物体或接触区域。
- **归因假设**：训练时始终同时暴露所有多视角图像与语言信号，使模型学到的是**跨视角虚假相关**（例如将闲置手臂相机中的高显著性干扰物与成功动作错误关联）。当推理时遇到分布偏移（distractor、遮挡、光照变化），这些"巧合性"线索失效，模型无法判断哪些证据可靠。
- **理论框架**：作者将问题形式化为**部分可观测下的决策问题**（POMDP 视角），提出通过结构化的训练期部分可观测训练来迫使模型学习"何时应信任哪个模态"。

## 2. 方法论：M3（Modality Masking Mechanism）

### 2.1 核心思想

M3 是一种**仅作用于训练阶段**的简单正则化策略，无需任何架构改动，也不引入额外推理时参数。其核心是：在每次训练迭代中，对模态 token 和 action query 进行**随机子集遮蔽**，使模型必须在"部分观测"条件下仍能拟合真实动作，从而促使其学习更鲁棒的证据选择。

### 2.2 三条双臂专属设计准则

| 准则 | 含义 | 实验验证 |
|------|------|----------|
| **准则 1**：保留自我中心（egocentric）视角作为稳定空间锚 | 腕部视角易受遮挡、光照、干扰物影响；自我中心视角提供全局几何参考 | 遮蔽 ego 视图平均成功率仅 37.0%，保留 ego 则达 64.0%（表 3a） |
| **准则 2**：双臂腕部视角**联合遮蔽**而非独立遮蔽 | 左右腕部相机空间相关，独立遮蔽时模型仍可通过 ego↔单腕做虚假匹配；联合遮蔽强制模型从全局 ego 提取几何结构 | 联合遮蔽双臂腕部 Avg SR = 64.0%，远超单腕遮蔽的 32.7% |
| **准则 3**：action query 子集遮蔽（query dropout） | 随机丢弃部分 query 但保留至少 1 个，避免 query 共适应（co-adaptation），促使 query 专门化（粗粒度路径规划 / 细粒度接触对齐 / 时序一致性） | 较优 mask ratio 为 0.1，过高（如 0.9）反而退化至 43.7% |

### 2.3 技术实现

- **采样方式**：通过伯努利分布采样掩码向量：
  - 腕部视角：`u_v ~ Bernoulli(1 - p_v)` 对左右腕部**联合**采样；
  - 语言：`u_ℓ ~ Bernoulli(1 - p_ℓ)`；
  - action query：逐元素 `u_q(i) ~ Bernoulli(1 - p_q)`，并约束 ∥u_q∥₁ ≥ 1，保证至少一个 query 活跃。
- **统一可见性向量**：对所有 token（E/L/R/T/Q）构造一个二值指示向量 `m ∈ {0,1}`，满足：
  - ego 始终可见；
  - wrist 同时受 `u_v` 控制；
  - text 受 `u_ℓ` 控制；
  - action queries 受 `u_q` 逐元素控制。
- **注意力融合**：在 self-attention 的缩放点积中叠加一个**方形可加掩码** $\tilde{M}$：
  $$\tilde{M}_{xy} = \begin{cases} 0 & \text{if } m_x = 1 \text{ and } m_y = 1 \\ -\infty & \text{otherwise} \end{cases}$$
  $$\text{Attn} = \text{softmax}\left(\frac{QK^\top}{\sqrt{d}} + M_c + \tilde{M}\right)V$$
  其中 $M_c$ 为因果掩码。被遮蔽的 token 既不"看"他人（行掩码），也不"被看"（列掩码）。
- **Query Rescaling**：对保留下来的可见 query 做缩放补偿 $\tilde{q}_i = \frac{1}{1-p_q} q_i$，保持期望特征能量，鼓励信息分布到不同 query slot 上。
- **训练目标**：沿用基线的 L1 回归损失（式 8），但输入为经 M3 掩码后的部分观测：$\mathcal{L}_{M3} = \|g_\theta(V_t^{M3}, T_t^{M3}, Q_t^{M3}) - \hat{A}_t\|_1$。

### 2.4 与通用正则化的区别

消融实验（表 4b）证明：通用 token dropout（31.8%）、modality dropout（24.1%）、视觉增强（22.3%）、区域增强（23.0%）均远不及 M3（64.0%）。说明**结构化、面向双臂多视角的掩码设计**才是关键，而非简单 dropout。

- 真实世界中采用三轮重复、场景布局固定；
- M3 与 Adapter 使用相同的训练超参（学习率、batch size、step 数、LoRA rank），唯一变量是 M3 引入的训练时掩码。
- 局限性：每任务仅 50 条演示，规模较小；仿真评测为单次运行（single-run），未提供多次随机种子的统计方差。

## 6. 主要结论与发现

1. **结构性训练期掩码是改善查询式双臂 VLA 鲁棒性的实用方法**：在 Clean 设置下 M3 平均提升 21.7%，Clean2Rand 下提升 11.4%，真实世界 OOD 下提升 48.6%。
2. **双臂多视角存在特有的"闲置臂干扰"问题**：腕部相机会抓取与当前子任务无关的高显著性干扰，跨视角融合产生短路；ego 保留 + 双腕联合遮蔽是消融后的最佳组合。
3. **M3 具有跨主干可迁移性**：在结构不同的 OpenVLA-OFT（7B）上同样带来 +21.3% 的提升，说明其效果不依赖于特定 VLM 架构。
4. **M3 改善训练效率**：在长时序任务上收敛更快、最终 plateau 更高（图 9）。
5. **M3 改善注意力聚焦**：空间热力图与 token 注意力矩阵均显示注意力更集中于目标与接触区域；定量分析（图 11）发现不连续轨迹的 prompt 无关注意力更高，M3 轨迹则更低。
6. **领域偏移下基线退化剧烈**：Adapter 在 Clean2Rand 下从 41.0% 跌至 3.7%（-37.3%），π0 也仅 12.9%，表明依赖干净演示训练的双臂 VLA 普遍脆弱，而 M3 在不依赖大规模预训练的情况下达到最高 15.1%。
7. **通用 dropout/augmentation 不够**：只有"结构化的、面向多视角双臂场景"的掩码策略才能带来显著收益。

## 7. 方法与实验设计的亮点

- **极简实用**：无架构改动、无额外推理参数、无需大规模预训练，可"即插即用"地应用到现有 VLA-Adapter / OpenVLA-OFT 上；
- **问题诊断明确**：从可视化与定量分析双角度论证了"注意力扩散 → 动作不连续 → 任务失败"的因果链，为方法设计提供清晰依据；
- **设计准则来自消融反馈**：三条准则（保留 ego / 双腕联合 / query 子集）均得到实验验证，避免了启发式设计的盲目性；
- **跨主干验证**：在结构不同的 OpenVLA-OFT 上同样有效，提升了方法的普适性可信度；
- **真实世界充分性**：3 任务 × 3 轮 ×（16+8 试验），含 OOD clutter 设置，并提供阶段级分解与定性案例；
- **可视化 + 定量结合**：注意力热力图、token 间注意力矩阵、训练曲线、阶段分解、轨迹时间线，多角度呈现效果。

## 8. 不足与局限

- **训练数据规模小**：每任务仅 50 条干净演示，可能限制更复杂任务的扩展性；
- **仿真评估为单次运行**：未提供多次随机种子下的均值与方差，难以判断小幅度差异（如 +2 ~ +5%）的统计显著性；
- **架构覆盖有限**：主要在 VLA-Adapter（0.5B）与 OpenVLA-OFT（7B）上验证，未涉及扩散式 VLA（如 π0 / RDT），作者也将"扩散式动作解码下 M3 的影响"列为未来工作；
- **未覆盖更多模态**：未涉及 3D 几何信息（点云、深度）、触觉、力觉等；
- **真实平台单一**：仅在 Agilex Cobot 上验证，未推广到不同本体（ALOHA、Franka 等）；
- **失败案例仍存在**：如 Block Rank Size 在 Clean2Rand 下所有方法均接近 0%，作者承认 M3 并不能消除 Clean2Rand 下注意力的部分弥散；
- **超参需手动调节**：pv、pℓ、pq 与最佳 query mask ratio（0.1）需任务无关地人工设定，未做自动调度；
- **理论分析有限**：缺乏对为何 query mask ratio = 0.1 最优的更深理论解释；
- **论文语言细节**：行文中多处使用"may improve""consistent with the hypothesis"等保守表述，说明作者也承认 M3 的机理仍以经验观察为主，尚未完全形式化。
