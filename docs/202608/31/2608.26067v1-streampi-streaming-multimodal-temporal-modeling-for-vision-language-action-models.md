## 摘要
视觉-语言-动作（VLA）模型已在机器人操控任务中展现出有效性，然而诸如 pi0.5 等当前最先进的模型仍受限于单帧范式，难以保留历史观测并形成精确的空间感知。本文提出 StreamPI——一种流式多模态时序建模框架，无需引入任何额外参数即可为单帧 VLA 赋予时序推理能力。其核心设计之一是指令锚定的时序建模：将每个（视觉观测，语言指令）对视为一个原子时序单元，在单元内部采用双向注意力以实现跨模态融合，在单元之间采用因果注意力以保持自回归流式推理，从而确保语言指令在任务执行过程中充当持续的语义锚点。为弥合同步训练与异步真实机器人部署之间的鸿沟，我们引入了随机间隔流式训练策略：采用适当的帧间间隔（例如每 3 帧）能够带来更快、更平滑的动作执行；而在此基础上进一步对间隔进行随机化，则可提升模型对帧时序扰动的鲁棒性，从而支持实际场景中的异步部署。此外，凭借 LLM 主干网络的长度外推能力，StreamPI 可无缝继承预训练的单帧权重，并灵活支持单帧与多帧推理。在涵盖依赖记忆与精确感知的真实机器人任务以及仿真基准 LIBERO 上的实验表明，StreamPI 在多样化任务中均优于 pi0.5。

## Abstract
Vision-Language-Action (VLA) models have demonstrated effectiveness in robot manipulation, yet state-of-the-art models such as pi0.5 operate under a single-frame paradigm, limiting their ability to retain past observations and develop precise spatial perception. In this paper, we propose StreamPI, a streaming multimodal temporal modeling framework that equips single-frame VLA with temporal reasoning capability without introducing any additional parameters. One core design is instruction-anchored temporal modeling. It treats each (visual observation, language instruction) pair as an atomic temporal unit: bidirectional attention within each pair enables cross-modal fusion, while causal attention across pairs preserves autoregressive streaming inference. This ensures the language instruction serves as a persistent semantic anchor throughout task execution. To bridge the gap between synchronous training and asynchronous real-robot deployment, we introduce a andom-interval streaming training strategy: a proper inter-frame interval (e.g., every 3 frames) enables faster and smoother action execution. Beyond this, randomizing the interval further improves robustness to frame-timing perturbations, supporting asynchronous deployment in practice. Furthermore, by leveraging the length extrapolation capability of the LLM backbone, StreamPI seamlessly inherits pretrained single-frame weights and supports flexible single-frame and multi-frame inference. Experiments on real-robot tasks spanning memory-dependent and precise perception scenarios, as well as the simulation benchmark LIBERO, demonstrate that StreamPI outperforms pi0.5 across diverse tasks.

# StreamPI 论文总结

## 1. 核心问题与整体含义（研究动机与背景）

- **现状瓶颈**：当前最先进的 VLA 模型（如 π0 和 π0.5）均采用**单帧推理范式**，每一步动作仅依据当前帧图像预测，缺乏对历史观测的记忆能力，且难以通过时间聚合形成精确的空间感知。
- **关键缺陷**：
  - **记忆缺失**：对于"贝壳游戏"中物体被遮蔽后再寻找、跟踪动态移动物体等任务，单帧推理根本无法处理。
  - **空间感知不足**：单帧缺乏多视角几何线索与运动视差，无法支持高精度操作（如同毫米级插孔任务）。
  - **指令遗忘**：常规 VLA 将语言指令作为固定文本前缀；随着时序展开，视觉 token 持续累积，指令影响力被稀释，模型在长时任务中容易"忘记目标"。
- **已有方案的不足**：
  - **窗口式多帧 VLA**（如 ChronusVLA 等）计算开销随帧数线性增长，不利于实时控制。
  - **视频编码器方案**引入额外参数且分布与预训练 VLA 不对齐，可能破坏已有表征。
- **研究目标**：在不引入新参数、不破坏预训练表征的前提下，为 π0.5 等强单帧 VLA 注入**高效、鲁棒的时序推理能力**，并解决训练-部署异步性鸿沟。

## 2. 方法论

### 2.1 整体框架：流式多模态时序建模（Streaming Multimodal Temporal Modeling）

- **核心思想**：将每个时刻的（视觉观测，语言指令）配对作为一个**原子时序单元**（Atomic Temporal Unit），通过 KV-Cache 实现流式自回归推理。
- **关键组件**：
  1. **指令锚定的时序建模**（Instruction-Anchored Temporal Modeling）
  2. **随机间隔流式训练策略**（Random-Interval Streaming Training）
  3. **零参数扩展**（Parameter-free Temporal Extension）

### 2.2 指令锚定的时序建模（详见 §3.2）

- **原子单元定义**：$u_t = (V_t, l_t)$，其中 $V_t$ 为多视角图像（前视 + 左/右腕视），$l_t$ 为语言指令。
- **输入序列**：取最近 $T$ 帧构成 $U = [u_{t-T+1}, u_{t-T+2}, \ldots, u_t]$。
- **两级注意力结构**：
  - **单元内（Intra-pair）双向注意力**：
    $$h_\tau = \mathrm{Attn}_{bi}(V_\tau, l_\tau)$$
    保证视觉与文本在同一时刻充分跨模态融合。
  - **跨单元（Inter-pair）因果注意力**：
    $$o_t = \mathrm{Attn}_{causal}(h_{t-T+1}, \ldots, h_t)$$
    保证流式自回归结构，未来帧不泄露到过去表征。
- **零参数实现**：仅通过重组注意力掩码实现上述层级结构，并扩展位置编码；**完全继承 π0.5 预训练权重**，借助 LLM 的长度外推能力支持多帧推理。

### 2.3 随机间隔流式训练策略（详见 §3.3）

- **随机间隔采样**：基础间隔 $\bar{\delta}$ 上叠加扰动 $\epsilon \sim U(-\Delta, +\Delta)$，裁剪至 $[\delta_{min}, \delta_{max}]$，让模型接触多样化帧时序。
- **时间掩码（Temporal Masking）**：随机遮蔽最早 $k$ 帧（$k \in \{0, \ldots, T-1\}$），模拟流式推理中的增量观测模式。
- **流式推理流程（Algorithm 1）**：
  - 初始步编码完整单元并初始化 KV-Cache；
  - 后续步仅编码新帧，通过 Cross-Attention 查询历史 Cache；
  - Cache 达到上限 $T$ 后自动清空并重启；
  - 推理延迟随帧数仅微弱增长（详见资源部分）。

## 3. 实验设计

### 3.1 仿真基准（Benchmark）

- **LIBERO**（四个子套件）：
  - LIBERO-Spatial / Object / Goal / Long；
  - 每套 10 个任务，每任务 50 次试验，报告成功率。
- **CALVIN**：长时序多任务基准，要求连续完成最多 5 个子任务，报告各序列位置成功率及平均序列长度。

### 3.2 真实机器人任务

- **硬件**：AgileX PiperX 6-DoF 机械臂（Aloha 风格），3 路相机（前视 D455 + 双腕视 D435），30 FPS 遥操作。
- **4 个任务**（每任务 100 条示范）：
  - **记忆依赖任务**：
    - **Shell Game**（贝壳游戏，15 种模式）：物体被遮蔽后多轮换位再找回；
    - **Rolling Object Grasping**（滚动瓶抓取，30 次试验）：抓取持续移动物体。
  - **精确感知依赖任务**：
    - **Pen Insertion into Narrow Bottle**（笔插入窄瓶，3 种模式 ×10 次）：亚厘米精度 + 时序判断；
    - **Cup Insertion into Cup Sleeve**（杯子插筒，5 个位置 ×5 次）。

### 3.3 对比方法

- **基线**：π0.5（单帧）。
- **LIBERO 上的对比**：Diffusion Policy、Octo、SpatialVLA、TraceVLA、OpenVLA、CoT-VLA、π0-FAST、SmolVLA、GR00T-N1、UniVLA、FLOWER、CronusVLA、TriVLA、4D-VLA、CogACT、ST-π、MemoryVLA、π0、π0.5。
- **CALVIN 上的对比**：MemoryVLA、π0.5。

## 7. 优点（亮点）

- **零额外参数**：仅通过注意力掩码与位置编码扩展即可继承 π0.5 全部预训练权重，规避表征破坏风险；
- **KV-Cache 流式推理**：推理复杂度对时序长度近似常数，T=5 仅比 T=1 多 9.2 ms；
- **指令锚定设计**：从根本上解决长时序中"指令被视觉淹没"问题，简单有效；
- **训练-部署对齐**：随机间隔训练显式覆盖异步观测分布，提升真实部署鲁棒性；
- **双轨验证**：仿真（LIBERO、CALVIN）+ 真实机器人记忆/精度任务，结果一致；
- **跨帧灵活**：单/多帧推理可无缝切换（T=5 训练 → T=1/3 推理仍强）；
- **代码与模型权重公开**（项目主页可见），便于复现。

## 8. 不足与局限

- **训练成本随帧数线性增长**：所有 $T$ 帧需同时加载，训练超长时序（>100 帧）代价不可承受；
- **极端异步未充分解决**：随机间隔训练仅在 $[\delta_{min}, \delta_{max}]$ 区间内扰动，对真实机器人中剧烈时间抖动、丢帧、观测延迟等情况的鲁棒性未做系统化评测；
- **LIBERO 饱和**：多个子套件已接近 100%，增益易受随机性影响；
- **真实机器人任务数量有限**：仅 4 个任务、每个 100 条示范，多样性不足；未公开跨物体/跨场景泛化测试；
- **无消融对 KV-Cache 大小上限 $T$ 与缓存替换策略的系统研究**；
- **与其他窗口式 VLA 的计算-精度权衡比较不够细致**：未对窗口法与本方法的延迟/成功率做统一基准；
- **应用风险**（作者自陈）：更强大的操控模型可能影响劳动力市场；OOD 场景下安全性需进一步验证；
- **依赖 π0.5 预训练质量**：方法对骨干 LLM 的长度外推能力有强假设，迁移到其他 VLA 时的兼容性未广泛验证。
