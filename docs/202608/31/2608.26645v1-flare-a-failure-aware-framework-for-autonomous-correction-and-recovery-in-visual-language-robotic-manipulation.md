## 摘要
视觉-语言-动作模型（VLA）在泛化至复杂的长时序机器人操作任务方面已展现出显著潜力。然而，其性能仍然脆弱，因为这些模型通常在轨迹单调且无失败的演示数据上进行训练。这种对"完美"数据的依赖使其无法从常见的执行错误中恢复，例如抓取失败、物体掉落或意外碰撞。本文提出FLARE，一种通过"重试"与"重置"范式为VLA赋予鲁棒错误恢复能力的新框架。首先，我们引入"重试"机制，通过在演示中注入扰动片段与桥接片段，将机器人位姿与环境状态解耦，从而使策略能够自主应对执行偏差。其次，针对关键的状态破坏性（OOD）失败，我们引入"重置"流程。我们利用多模态大语言模型（MLLM）进行离线失败分析，从执行视频中自动识别OOD状态。该分析支持以高效且有针对性的方式收集一个小型、以物体为中心的"重置"技能库，并对其进行训练以将环境恢复至任务有效状态。我们的完整框架将这些习得的策略加以集成。推理时，在线MLLM监控器在任务执行与"重置"技能之间进行仲裁。在具有挑战性的、接触密集型操作任务上的实验表明，我们的方法显著提升了任务成功率与鲁棒性。

## Abstract
Vision-Language-Action Models~(VLAs) have demonstrated significant promise in generalizing to complex, long-horizon robotic manipulation tasks. However, their performance remains brittle, as they are typically trained on trajectory-monotonic, failure-free demonstrations. This reliance on ``perfect" data leaves them unable to recover from common execution errors, such as a missed grasp, a dropped object, or an unexpected collision. In this paper, we propose FLARE, a novel framework that endows VLAs with robust error recovery capabilities through a ``Retry" and ``Reset" paradigm. First, we introduce a ``Retry" mechanism by injecting perturbation and bridging segments that decouple robot pose from environment state into demonstrations, enabling the policy to autonomously handle execution deviations. Second, to address critical, state-breaking (OOD) failures, we introduce a ``Reset" pipeline. We leverage an MLLM for offline failure analysis to automatically identify OOD states from execution videos. This analysis enables the efficient, targeted collection of a small library of object-centric ``Reset" skills, which are trained to restore the environment to a task-valid state. Our full framework integrates these learned policies. At inference, an online MLLM monitor arbitrates between task execution and ``Reset" skills. Experiments on challenging, contact-rich manipulation tasks show our approach significantly improves task success and robustness.

# FLARE 论文总结：面向视觉-语言机器人操作的故障感知恢复框架

## 1. 核心问题与整体研究动机

### 1.1 背景
- **VLA 的兴起与局限**：视觉-语言-动作模型（VLA，如 π0、OpenVLA、RT-2）在复杂长时序机器人操作任务上展现了强大的泛化能力，但其在开放世界环境中仍然非常脆弱——微小的扰动、意外接触或轻微的执行偏差都可能导致不可逆的任务失败。
- **缺乏自我纠错能力**：与人不同，VLA 不具备持续的自我修正能力；实现真正的机器人自主性，不仅需要熟练的任务执行，还需要鲁棒且可泛化的失败恢复机制。

### 1.2 问题根源（数据层面）
作者将当前 VLA 的脆弱性归因于训练数据本身的两大根本缺陷：
- **轨迹单调性（trajectory-monotonicity）**：人类演示数据稀缺且带有隐性习惯偏差（如总是从相似角度抓取杯子的把手），导致机器人在训练中形成机器人位姿 $s_t^r$ 与环境状态 $s_t^e$ 之间的虚假强相关。当面对合法但未见过的机器人配置时（in-distribution error, ID error），策略会错误地将其判断为 out-of-distribution 而失败。
- **成功中心偏差（success-centric）**：演示数据几乎全部是成功轨迹，缺乏任何恢复行为样本。当发生灾难性失败（如杯子倾倒）导致环境进入 OOD 状态时，策略完全无法恢复。

### 1.3 核心研究问题
如何让 VLA 在 **不依赖昂贵 RL 训练**、**不依赖固定技能库** 的前提下，自主应对 ID 与 OOD 两类失败，实现真正的鲁棒自主性。

## 2. 方法论

### 2.1 整体框架（ID/OOD 错误分类 + Retry/Reset 双重机制）

作者提出 **FLARE (Failure-Aware Retry/Reset)** 框架，核心是：
- **错误分类**：将失败分为 **ID 错误**（环境状态有效但机器人位姿偏离）和 **OOD 错误**（环境本身处于无效/灾难状态）。
- **Retry（重试）**：针对 ID 错误，通过数据增增强化策略对位姿偏差的鲁棒性。
- **Reset（重置）**：针对 OOD 错误，通过 MLLM 引导高效采集专门的"重置"技能库。

### 2.2 Retry 机制：扰动-桥接增广（Perturbation & Bridging）

**目标**：解耦机器人位姿 $s_t^r$ 与环境状态 $s_t^e$，使策略学会从任意位姿执行正确的下一动作。

**流程**：
1. **轨迹组合**：从人类演示的子任务片段（如"抓取杯子"、"放置杯子"）出发，通过 MimicGen 生成基线任务轨迹 $T_{\text{task}} = (a_0, a_1, \dots, a_N)$。
2. **注入扰动-桥接段 $d_i$**：在子任务片段之间插入两阶段片段：
   - **扰动阶段 $d_i^A$**：使用随机关节速度或末端执行器运动，将机械臂移至任意 OOD 位姿（破坏位姿-状态相关性）。
   - **桥接阶段 $d_i^B$**：通过无规划器运动学插值（位置线性插值 + 旋转 SLERP），将机械臂从扰动后的位姿恢复到下一任务片段所需的合法起始位姿。
3. **训练数据生成**：
   - 扰动动作 $d_i^A$ **不作为训练目标**（其本身无意义）。
   - 训练样本由 **桥接动作 + 后续任务动作** 构成：$(d_i^B, a_{i+1}, a_{i+2}, \dots)$，迫使 VLA 学会从多样化的机器人起始位姿执行正确的 $a_{i+1}$。

### 2.3 Reset 机制：MLLM 驱动的失败挖掘

**目标**：针对成功演示数据中完全缺失的 OOD 恢复行为，高效采集并学习以物体为中心的"重置"技能。

**关键步骤**：
1. **失败采集**：使用具备 Retry 能力的策略执行数百回合任务，收集全部成功与失败的执行视频与轨迹日志。
2. **离线 MLLM 失败分析**：调用 Gemini-2.5-Pro（temperature=0.7）对失败视频进行结构化 JSON 分析，输出：
   - `error_type`：ID-Retryable / OOD-Reset Required
   - `reset_target`：需要重置的物体名称
   - `error_group`：构成失败状态的物体集合（保留相对位姿的"语义失败资产"）
   - `failure_timestamp`：失败发生的关键帧
4. **重置数据集自举（bootstrap）**：根据时间戳从日志中提取对应的高保真环境状态（如 MuJoCo state），作为新的人类演示起点。
5. **人类演示 + 增广**：对每个识别出的以物体为中心的重置技能，采集约 20 条人类演示，并应用相同的扰动-桥接增广至 500 条。

### 2.4 统一训练与闭环推理

- **模块化专家策略库**：采用 **LoRA** 在共享的预训练 VLA backbone（π0.5）上训练一组专用适配器：
  - 主任务适配器 $\pi_{\text{task}}^{\text{LoRA}}$：在 $D_{\text{task aug}}$ 上训练，使用主任务指令。
  - 重置技能适配器 $\{\pi_{\text{reset},j}^{\text{LoRA}}\}$：每个物体级重置技能训练一个独立 LoRA，使用对应的重置指令（如 "reset the cup"）。
- **闭环编排（在线 MLLM 监控器）**：
  - 默认加载主任务适配器并执行任务；
  - 若观察到 ID 错误，**不干预**，依靠 VLA 的内在 Retry 鲁棒性自主恢复；
  - 若观察到 OOD 错误，MLLM 仲裁切换到对应的重置适配器执行恢复；
  - 恢复完成后重新加载主任务适配器，无缝继续任务。

## 6. 主要结论与发现

### 6.1 性能结果
- **平均成功率 84.0%**，显著超越 Phoenix（57.8%）与 π0.5（72.2%），**甚至超过了 Phoenix-Human 上界（78.9%）**；
- 在 9 个任务中 **8 个取得 SOTA**；仅 Threading D0 略低于最佳，但仍优于 Phoenix；
- 在 D1（更难）任务上的提升幅度普遍大于 D0，说明扰动-桥接的解耦效应对环境变化具有更强鲁棒性。

### 6.2 消融与组件发现
- 移除 Reset 模块后平均成功率下降 **3.5%**，证明 OOD 恢复技能不可或缺；
- Oracle（人工反馈指令）版本比当前自动 MLLM 监控器再高 **7%**，提示更强的 MLLM 可进一步提升；
- 扰动-桥接的最佳超参数：**旋转 $r=30°$**、**平移 $t=0.7$**（过大反而损害泛化）。

### 6.3 MLLM 失效分析能力
- Gemini-2.5-Pro 在 Retry/Reset 分类上准确率 **88%–96%**，验证了视频级语义推理用于自动失败挖掘的可行性。

### 6.4 重置技能难度
- 重置"咖啡机盖"、"T 形块"等较易（成功率 84%–88%），但重置"咖啡胶囊"和"U 形块"难度极大（仅 20%–24%），需要更高级的灵巧操作能力。

## 8. 不足与局限

### 8.1 方法层面
- **预定义重置技能库限制**：当前 Reset 技能库是人工枚举的（每个任务最多 2 个物体级技能），无法处理需要非标准、多步或协作式动作的复杂 OOD 状态；
- **复杂位姿调整能力不足**：对需要灵巧手内姿态修正的物体（如咖啡胶囊、U 形块）成功率显著偏低；
- **对 MLLM 准确率依赖**：当 MLLM 误判错误类型时，会直接导致错误的恢复决策；
- **通用性假设**：假设所有失败都可以归为可枚举的"物体级"重置，对结构性损坏（如机械卡死）无效。

### 8.2 实验层面
- **真实世界任务数量有限**：仅 2 个真实任务，覆盖任务类型偏少；
- **硬件受限**：仅在简单夹爪上验证，未在灵巧手或多指手上测试；
- **MLLM 评估规模小**：仅 50 条人工标注视频；
- **算力与训练细节不透明**：未报告 GPU 类型、数量、训练时长、显存占用，难以评估实际部署成本；
- **缺少对长时间跨度的鲁棒性测试**：未评估多日累积漂移、传感器老化等长期部署问题。

### 8.3 应用风险
- **安全与可解释性**：作者承认需要安全约束与人工紧急接管，但实际安全机制未在论文中验证；
- **隐私与依赖**：依赖外部闭源 MLLM（Gemini-2.5-Pro），存在数据外传与供应商依赖风险；
- **对域外任务的迁移性未知**：方法在 RoboMimic 仿真 + 真实世界简单场景上验证，未证明其在高度动态、非刚体、协作型任务上的有效性。
