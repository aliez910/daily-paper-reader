## 摘要
视觉-语言-动作模型（VLAs）在泛化至复杂的、长时序机器人操作任务方面展现了显著的前景。然而，其性能仍然脆弱，因为这些模型通常在轨迹单调且无故障的演示数据上进行训练。这种对"完美"数据的依赖使其无法从常见的执行错误中恢复，例如抓取失败、物体掉落或意外碰撞。本文提出FLARE，一种通过"重试"（Retry）与"重置"（Reset）范式赋予VLAs强大错误恢复能力的新颖框架。首先，我们通过在演示数据中注入扰动片段与桥接片段（将机器人位姿与环境状态解耦），引入"重试"机制，使策略能够自主应对执行偏差。其次，针对破坏状态的（OOD）关键故障，我们引入"重置"流水线。我们利用多模态大语言模型（MLLM）进行离线故障分析，以自动从执行视频中识别OOD状态。基于该分析，我们高效且有针对性地构建了一个小型、以物体为中心的"重置"技能库，这些技能经过训练可将环境恢复至任务有效状态。本文的完整框架将这些习得的策略加以集成。在推理阶段，在线MLLM监控器在任务执行与"重置"技能之间进行仲裁。在具有挑战性的、富含接触的操作任务上的实验表明，本方法显著提升了任务成功率与鲁棒性。

## Abstract
Vision-Language-Action Models~(VLAs) have demonstrated significant promise in generalizing to complex, long-horizon robotic manipulation tasks. However, their performance remains brittle, as they are typically trained on trajectory-monotonic, failure-free demonstrations. This reliance on ``perfect" data leaves them unable to recover from common execution errors, such as a missed grasp, a dropped object, or an unexpected collision. In this paper, we propose FLARE, a novel framework that endows VLAs with robust error recovery capabilities through a ``Retry" and ``Reset" paradigm. First, we introduce a ``Retry" mechanism by injecting perturbation and bridging segments that decouple robot pose from environment state into demonstrations, enabling the policy to autonomously handle execution deviations. Second, to address critical, state-breaking (OOD) failures, we introduce a ``Reset" pipeline. We leverage an MLLM for offline failure analysis to automatically identify OOD states from execution videos. This analysis enables the efficient, targeted collection of a small library of object-centric ``Reset" skills, which are trained to restore the environment to a task-valid state. Our full framework integrates these learned policies. At inference, an online MLLM monitor arbitrates between task execution and ``Reset" skills. Experiments on challenging, contact-rich manipulation tasks show our approach significantly improves task success and robustness.

# FLARE 论文总结

## 1. 核心问题与研究动机

- **VLA 模型的脆弱性瓶颈**：现有的视觉-语言-动作模型（如 π0、OpenVLA 等）在长时序、接触丰富的操作任务上展现了强大的泛化能力，但面对轻微扰动、意外接触或执行漂移时极易崩溃，无法像人类那样进行自我修正。
- **数据根源问题**：作者将脆弱性归因于数据本身的局限——
  - **轨迹单调性（trajectory-monotonic）**：演示数据中机器人位姿与环境状态呈现强虚假相关，策略过拟合于特定的位姿-状态组合；
  - **成功偏见（success-centric）**：数据集几乎不包含失败及恢复轨迹，导致模型对 OOD 状态毫无经验。
- **两类错误形式化**：
  - **ID 错误**：环境状态仍有效、但机器人位姿落在演示分布的低概率区域，理论上只需"重试"正确动作；
  - **OOD 错误**：环境本身进入任务策略无法恢复的灾难态（如杯子倒塌、零件卡住），需要专门的"重置"技能。
- **研究目标**：构建一种数据驱动的统一机制，使 VLA 兼具 ID 错误的内在重试鲁棒性与 OOD 错误的对象级重置能力，从"模仿执行"迈向"韧性自主"。

## 2. 方法论

### 2.1 整体框架
- **Retry/Reset 双范式**：在同一 VLA 骨干（π0.5）上以 LoRA 适配器集合的形式集成主任务策略与多个重置技能策略，由在线 MLLM 监控器在两者间仲裁。

### 2.2 Retry：扰动-桥接数据增广
- **轨迹合成**：基于 MimicGen 将少量人类演示扩展为完整任务轨迹 $T_{\text{task}}=(a_0,a_1,\dots,a_N)$。
- **扰动-桥接段注入**：在每个子任务段之间插入 $d_i=(d_i^A, d_i^B)$：
  - **扰动段 $d_i^A$**：随机关节速度/末端运动，将机械臂推到任意 OOD 位姿；
  - **桥接段 $d_i^B$**：通过位置线性插值 + 旋转 SLERP，把机械臂从扰动末端拉回下一子任务的合法起点。
- **训练数据构造**：丢弃扰动动作本身，仅将 $(d_i^B, a_{i+1}, a_{i+2}, \dots)$ 作为训练序列，迫使策略学会"从任意位姿执行正确的下一步"，从而打破位姿-状态耦合。
- **超参**：最大旋转 45°、最大平移 0.5 m，论文中通过消融得最佳 $r=30°, t=0.7$。

### 2.3 Reset：基于 MLLM 的失败挖掘与重置技能学习
- **失败采集**：让具备 Retry 能力的策略执行数百回合，收集所有成功/失败视频与轨迹日志。
- **MLLM 离线分析**：使用 Gemini-2.5-Pro 对失败视频做结构化分析，输出 JSON：失败原因、`retry`/`reset` 策略、需重置对象、错误组（涉及的所有对象集合）以及失败时间戳。
- **错误组语义保留**：将错误组内所有对象作为一个"语义失败资产"，在生成新重置演示时整体重定位以保持相对位姿，从而学到语义级的恢复能力。
- **重置数据引导**：利用失败时间戳从日志中提取精确 MuJoCo 状态 $s_t$ 作为起始配置；针对每个对象级重置技能（如"扶正咖啡杯"）仅采集 10–20 条人类演示，再用相同的扰动-桥接增广扩展至 500 条。
- **适配器训练**：每个重置技能训练独立的 LoRA 适配器 $\pi^{\text{reset},j}_{\text{LoRA}}$，以指令 $I_{\text{reset}}$（如 "reset the cup"）激活。

### 2.4 统一训练与闭环推理
- **模块化策略库**：共享 π0.5 预训练骨干 + 一组 LoRA 适配器（主任务 1 个 + 每个重置技能各 1 个）。
- **闭环仲裁流程**：
  1. 初始化加载主任务适配器 $\pi^{\text{task}}_{\text{LoRA}}$；
  2. 在线 MLLM 监控执行过程；
  3. ID 错误 → 不干预，由 VLA 内在 Retry 能力自主恢复；
  4. OOD 错误 → 监控器识别所需重置技能，热切换到对应 LoRA，执行恢复；
  5. 恢复完成后再切回主任务适配器，无缝继续原任务。

## 6. 主要结论与发现

- **整体性能领先**：FLARE 在 9 个任务中 8 个取得 SOTA，平均成功率 **84.0%**，显著高于 Phoenix（57.8%）和 π0.5（72.2%），相对 π0.5 提升 +11.8%；甚至**超过了 Phoenix-Human**（78.9%）。
- **D1 高难度任务增益更明显**：归因于扰动-桥接增广带来的位姿-状态解耦，使策略对场景随机化更鲁棒。
- **真实世界可迁移**：Stack Three Blocks 由 62.5%→75.0%，Insert U-shaped Block 由 45.0%→55.0%。
- **重置模块必要**：移除 Reset 后平均下降 3.5%；人工指令上界（Ours-Oracle）相比 MLLM 自主判断再提升约 7%，提示更强大的多模态监控器仍有空间。
- **MLLM 离线分析有效**：Retry/Reset 二分类准确率 88%/96%，重置对象识别 88%/78%，时间戳定位 78%/66%。

## 7. 优点

- **问题归因新颖**：从"数据范式"层面而非"模型架构"层面解释 VLA 脆弱性，提出 ID/OOD 错误二分法，逻辑清晰。
- **数据增广与策略学习一体化**：扰动-桥接增广同时服务于 Retry 鲁棒性与 Reset 技能泛化，统一且可复用。
- **MLLM 双角色设计**：离线作为失败分析员挖掘 OOD 数据、在线作为仲裁器切换技能，避免了传统 MLLM 系统对固定技能库的依赖。
- **模块化与可扩展**：LoRA 适配器库支持热插拔新增恢复技能，不会破坏已有策略。
- **实验覆盖较广**：含仿真 + 真实世界 + 多种基线 + 消融 + 超参敏感性 + MLLM 能力评估，并附视频分析 Prompt 设计，体现工程透明度。
