## 摘要
多臂协作正成为具身操作中的核心能力。近期，视觉-语言-动作（VLA）模型将感知、语言与控制融为一体，但大多数模型将语言表示为单一的全局指令，并未提供用于分配和组合各臂特定行为的显式机制。这一设计限制了模型向训练中未观察到的协作模式的迁移能力。我们提出了 MA-VLA，一个通过原子动作分配实现多臂协作的统一框架。MA-VLA 将协作行为分解为中层原子提示，并将其分配给各个机械臂，从而实现显式的子目标指定与跨任务的组合复用。为减少对固定执行角色的依赖，我们引入了 Arm Shuffle（臂洗牌），即在训练时对每条臂的观测、状态及其分配的原子提示进行排列。该排列强制实现与角色无关的指令跟随，并支持向未见过的协调模式进行重组，我们将这种能力称为多臂组合泛化。我们还构建了一个基准测试，其中测试阶段的协作模式在训练集中均未出现。在仿真与真实环境的评估中，先前最先进的 VLA 模型在这些未见过的协作下基本失败，而 MA-VLA 则始终能够成功。这些结果表明，结构化的、逐臂的原子动作分配为多臂具身系统的可扩展泛化提供了一条切实可行的路径。代码、模型与数据可在 https://github.com/zhangzaibin/future-robots 获取。

## Abstract
Multi-arm collaboration is becoming a core capability in embodied manipulation. Recent vision-language-action (VLA) models integrate perception, language, and control, but most represent language as a single global instruction and do not provide an explicit mechanism for assigning and composing arm-specific behaviors. This design limits transfer to collaboration patterns that differ from those observed during training. We present MA-VLA, a unified framework for multi-arm collaboration via atomic action assignment. MA-VLA decomposes cooperative behavior into mid-level atomic prompts and allocates them to individual arms, enabling explicit subgoal specification and compositional reuse across tasks. To reduce reliance on fixed execution roles, we introduce Arm Shuffle, a training-time permutation of the observation, state, and assigned atomic prompts for each arm. This permutation enforces role-agnostic instruction following and supports recomposition into unseen coordination patterns, which we term multi-arm compositional generalization. We also construct a benchmark in which test-time collaboration patterns are absent in training set. Across simulation and real-world evaluations, prior state-of-the-art VLAs largely fail under these unseen collaborations, while MA-VLA consistently succeeds. These results indicate that structured, per-arm atomic action assignment offers a practical route to scalable generalization in multi-arm embodied systems. Code, models, and data are available at https://github.com/zhangzaibin/future-robots

# MA-VLA 论文总结

## 1. 核心问题与研究动机

- **研究背景**：多臂协作正成为具身操控（embodied manipulation）的核心能力，相比单臂，多臂可通过并行执行与协同控制完成单臂无法完成的复杂任务（如物体传递、堆叠、长流程装配等）。
- **现有 VLA 的局限**：
  - 多数视觉-语言-动作（VLA）模型把语言指令视为**单一的全局命令**直接映射为控制信号，缺乏对各机械臂子任务进行**显式分解与分配**的机制。
  - 各臂的劳动分工只能由模型从数据中**隐式推断**，因此容易过拟合到训练中观察到的少量固定协作模式，迁移到未见协作结构时表现脆弱。
- **本文关注的核心问题**：**多臂组合泛化（multi-arm compositional generalization）**——在原子动作（atomic actions）集合不变的前提下，是否能将训练中见过的"原子动作+角色分配"重新组合成测试时未见的协作模式（例如新的堆叠顺序、新的物体传递策略）。
- **关键观察**：人类协作源于"分工"，将复杂目标拆分为中层原子动作并显式分配到执行者，是泛化的天然来源。本文受此启发，希望让 VLA 也具备类似的显式分工与重组能力。

## 2. 方法论

### 2.1 整体框架
MA-VLA 采用**分层结构**，由两部分组成：
1. **VLM-based Planner（规划器）$P_\phi$**：基于冻结的视觉-语言大模型（实验中使用 GPT-4.1），将高层指令 $l$ 和观测图像 $I$ 分解为 $T$ 个阶段，每阶段为每条臂分配一个原子提示（atomic prompt），得到 $p_i^t \in \mathcal{A}$，形成阶段化子目标序列：
   $$(p^1, \dots, p^T) = P_\phi(I, l, \mathcal{A})$$
   其中 $\mathcal{A}$ 是预定义的有限原子动作词表（如 grasp、hold、align、place 等），通过模板约束保证输出合法性。
2. **VLA Executor（执行器）$\pi_\theta$**：以 $\pi_0$ 为骨干（来自官方 pi0_base checkpoint），使用 flow-matching 公式生成连续动作轨迹，并在末端加入 **multi-head projection layer** 把共享隐表示拆分为各臂专属的动作头。

### 2.2 统一语言接口
执行器将所有臂的原子提示拼接为**统一指令字符串**：
$$u_t = \text{Arm0}: p_t^0,\ \text{Arm1}: p_t^1,\ \dots,\ \text{ArmN}: p_t^N$$
然后一次性输入：
$$[a_t^1, \dots, a_t^N] = \pi_\theta(I_t, s_t, u_t)$$
其中 $I_t$ 包含全局视图与各臂腕部视图，$s_t = [s_t^1, \dots, s_t^N]$ 为各臂本体感知拼接。该设计在单次前向传播内**联合预测所有臂动作**，避免各臂独立推理造成的协同缺失。

### 2.3 Arm Shuffle（臂洗牌）—— 核心正则化策略
- 在每次训练迭代中以概率 $p_{\text{shuffle}}$ 随机置换每条臂对应的"观测-状态-提示-动作"四元组：
  $$(s_t^i, v_t^i, p_t^i, a_t^i) \xrightarrow{\text{shuffle}} (s_t^{\sigma(i)}, v_t^{\sigma(i)}, p_t^{\sigma(i)}, a_t^{\sigma(i)})$$
- 目的：防止模型把行为绑定到固定的机械臂身份（arm index），强迫模型**根据语义内容而非空间位置**解释原子提示，从而实现**角色无关的指令跟随**。

### 2.4 View Dropout（视角丢弃）
- 以概率 $p_{\text{drop}}$ 随机遮蔽部分相机视图（替换为零），鼓励模型利用冗余视觉线索，提升对视觉扰动的鲁棒性。

### 2.5 训练目标
两种扰动都被包装在统一的**行为克隆（BC）损失**中，训练目标保持不变：
$$\mathcal{L}_t(\theta) = \mathbb{E}_{(O_t, l, A_t) \sim D} \left[ \sum_{i=1}^N \ell\big(\pi_\theta(\tilde{I}_t, s_t^i, p_t^i), a_t^i\big) \right]$$
其中 $\tilde{I}_t$、$s_t^i$、$p_t^i$ 可为经过 Arm Shuffle 和 View Dropout 扰动后的输入。

## 6. 主要结论与发现

- **域内性能**：MA-VLA 在 RoboFactory、RoboTwin 2.0 (Hard)、真实 SO101 上**一致优于** ACT、DP、DP3、Pi0-FAST、Pi0 等基线。
  - RoboFactory：双臂平均 83.5%（Pi0 80.3%）；三/四臂平均 83.3%（Pi0 76.5%）。
  - RoboTwin 2.0：平均 49.0%（Pi0 41.1%）。
  - 真实 SO101：所有 ID 任务均优于 Pi0。
- **域外组合泛化**：先前 SOTA VLA 在 OOD 上**全部为 0%**，而 MA-VLA 在 RoboFactory + RoboTwin 2.0 五个 OOD 任务上平均取得 **13%** 的成功率。
- **真实 OOD**：MA-VLA 在角色反转等未见模式上拿到非零成功率（Stack Bowls 10/20、Place Cubes 8/20），Pi0 全部为 0/20。
- **组件贡献**：
  - 原子动作显著提升域内性能。
  - Arm Shuffle 是 OOD 泛化"从 0 到非 0"的关键。
  - View Dropout 在 OOD 上带来进一步增益，且对域内影响很小。
- **独立臂模型的对比**：单臂独立训练的 Separate Pi0 域内甚至略优（61.0% vs 53.0%），但 OOD 为 0%，且推理资源随臂数线性增长，证明**统一模型 + Shuffle** 在泛化与可扩展性上的优势。

## 7. 优点与亮点

- **核心思想简洁且符合直觉**：将"人类分工协作"的结构化表征（原子动作 + 角色分配）显式注入 VLA，是当前单全局指令范式之外的有益补充。
- **Arm Shuffle 设计巧妙**：仅在训练时做输入置换，不改变推理流程，几乎零部署成本，却显著缓解"臂身份绑定"问题。
- **统一模型 + 多头输出**：单次前向预测所有臂动作，天然捕获臂间依赖，避免独立推理导致的协同缺失。
- **多维度验证充分**：仿真（3 平台、15+ 任务）+ 真实机器人（4 任务）+ 域内/域外双评估 + 三类消融。
- **工程细节完备**：原子词表模板约束、规则化解析器生成标签、flow-matching 平滑控制、multi-head projection 等设计均较成熟。
- **可扩展性**：模型数量不随臂数线性增长，相比 Separate Pi0 在部署与算力上更友好。

## 8. 不足与局限

- **域外成功率仍偏低**：尽管 MA-VLA 显著优于基线（基线为 0），但平均 13% 的 OOD 成功率说明距离"可扩展泛化"的实用目标仍有较大差距，复杂长流程组合仍易失败。
- **真实实验规模有限**：每任务仅 20 个 episode、50 条演示，缺乏对长尾场景、物体多样性、干扰物鲁棒性的统计性结论。
- **依赖外部 VLM 规划器**：使用 GPT-4.1 进行原子动作分配，推理时需要云端调用，存在延迟、成本与可重复性风险；规划器并未与执行器联合训练。
- **超参数敏感**：$p_{\text{shuffle}}$、$p_{\text{drop}}$ 在不同 OOD 任务中需要手工调优，缺乏统一的自动选择策略或对任务复杂度的预测机制。
- **原子词表封闭**：$\mathcal{A}$ 是预定义的有限词表，难以覆盖开放世界中新出现的协作行为，可能限制长尾泛化。
