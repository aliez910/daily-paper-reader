## 摘要
视觉-语言-动作（VLA）模型在机器人操控中已展现出有效性，然而诸如 pi0.5 等最先进模型仍采用单帧范式，限制了其保留历史观测和发展精确空间感知的能力。本文提出 StreamPI，一个流式多模态时间建模框架，无需引入任何额外参数即可为单帧 VLA 赋予时间推理能力。其核心设计之一是指令锚定的时间建模，它将每个（视觉观测，语言指令）对视为原子时间单元：对内采用双向注意力以实现跨模态融合，对间采用因果注意力以保持自回归流式推理。这确保了语言指令在整个任务执行过程中充当持续存在的语义锚点。为弥合同步训练与异步真实机器人部署之间的差距，我们引入随机间隔流式训练策略：合适的帧间间隔（例如每 3 帧）可实现更快、更平滑的动作执行；此外，对间隔进行随机化进一步提升了对帧时序扰动的鲁棒性，从而在实践中支持异步部署。除此之外，通过利用 LLM 主干网络的长度外推能力，StreamPI 能够无缝继承预训练的单帧权重，并灵活支持单帧与多帧推理。在涵盖依赖记忆与精确感知场景的真实机器人任务以及仿真基准 LIBERO 上的实验表明，StreamPI 在多种任务上均优于 pi0.5。

## Abstract
Vision-Language-Action (VLA) models have demonstrated effectiveness in robot manipulation, yet state-of-the-art models such as pi0.5 operate under a single-frame paradigm, limiting their ability to retain past observations and develop precise spatial perception. In this paper, we propose StreamPI, a streaming multimodal temporal modeling framework that equips single-frame VLA with temporal reasoning capability without introducing any additional parameters. One core design is instruction-anchored temporal modeling. It treats each (visual observation, language instruction) pair as an atomic temporal unit: bidirectional attention within each pair enables cross-modal fusion, while causal attention across pairs preserves autoregressive streaming inference. This ensures the language instruction serves as a persistent semantic anchor throughout task execution. To bridge the gap between synchronous training and asynchronous real-robot deployment, we introduce a andom-interval streaming training strategy: a proper inter-frame interval (e.g., every 3 frames) enables faster and smoother action execution. Beyond this, randomizing the interval further improves robustness to frame-timing perturbations, supporting asynchronous deployment in practice. Furthermore, by leveraging the length extrapolation capability of the LLM backbone, StreamPI seamlessly inherits pretrained single-frame weights and supports flexible single-frame and multi-frame inference. Experiments on real-robot tasks spanning memory-dependent and precise perception scenarios, as well as the simulation benchmark LIBERO, demonstrate that StreamPI outperforms pi0.5 across diverse tasks.

# StreamPI 论文深度总结

## 1. 核心问题与整体含义

- **研究背景**：Vision-Language-Action（VLA）模型已成为机器人通用操控的主流范式，将视觉感知、语言理解与动作生成统一到端到端框架中；RT-2、OpenVLA、π0、π0.5 等代表性工作持续推动这一方向的发展。
- **关键痛点**：当前最先进 VLA 模型（如 π0.5）采用**单帧推理范式**，每步动作仅基于当前时刻的一张图像观测，缺乏对历史观测的记忆能力，难以建立精确的空间感知。
- **两大瓶颈**：
  - **记忆缺失**：无法处理单帧歧义任务（如判断哪个杯子藏了物体、追踪动态移动目标）。
  - **空间感知不足**：无法利用时序信息增强 3D 几何理解，而自动驾驶和 3D 重建领域已验证多帧融合能显著提升深度估计与 3D 重建精度。
- **四大挑战**：① 多帧拼接导致序列线性增长、推理延迟难以满足实时控制；② 视觉 token 随时间累积会"稀释"语言指令的语义信号，造成指令遗忘；③ 训练时的固定采样间隔与部署时异步观测流之间存在显著不匹配；④ 引入额外视频编码器会破坏预训练 VLA 模型的视觉-语言表征。
- **研究目标**：在不引入任何新参数的前提下，为 π0.5 类强单帧 VLA 模型赋予高效、鲁棒的流式时间推理能力。

## 2. 方法论

### 2.1 整体框架

- **核心思想**：将每个 `(视觉观测, 语言指令)` 对视为**原子时间单元（atomic temporal unit）**，单元内双向注意力实现跨模态融合，单元间因果注意力实现流式自回归推理。
- **形式化定义**：
  - 单帧输入 `x_t = [V_t, l_t]`，多视图观测 `V_t = {v_t^f, v_t^l, v_t^r}`（前视 + 双手腕相机）。
  - 原子单元 `u_t = (V_t, l_t)`，滚动窗口由 T 个单元组成：`U = [u_{t-T+1}, ..., u_t]`。
- **两类注意力**：
  - **Intra-pair Bidirectional Attention**（单元内双向）：`h_τ = Attn_bi(V_τ, l_τ)`，保证每一帧内图像与指令充分融合。
  - **Inter-pair Causal Attention**（单元间因果）：`o_t = Attn_causal(h_{t-T+1}, ..., h_t)`，使历史信息以自回归方式累积。
- **零参数扩展**：完全通过重构注意力掩码实现，无新增参数；借助 LLM 主干的**长度外推能力**，可无缝继承 π0.5 全部预训练权重，仅需扩展位置编码。

### 2.2 流式推理（Streaming Inference）

- 维护 **KV-Cache**：首帧独立编码并缓存 `h_{t0}`；后续每帧仅编码新观测，其表征通过跨注意力访问历史 KV，避免重复计算。
- 推理开销恒定，与时间视域长度无关，适合长程操控任务。

### 2.3 随机间隔流式训练（Random-Interval Streaming Training）

- **随机间隔采样**：以基础间隔 `δ̄` 为中心叠加扰动 `ε ~ U(-Δ, +Δ)`，得到 `δ = δ̄ + ε`，裁剪至 `[δ_min, δ_max]`，使模型在训练阶段就接触多样化的帧间距。
- **时间掩码（Temporal Masking）**：随机遮蔽最早 k 帧（`k ∈ {0, 1, ..., T-1}`），模拟流式推理的增量观测模式。
- **部署意义**：显著提升对真实机器人异步观测流的鲁棒性，并支持以更大间隔（如 δ=5）减少在线推理频次，留出更多时间给动作执行。

## 3. 实验设计

### 3.1 真实机器人任务（AgileX PiperX 6-DoF + 3 个 RealSense 相机）

- **记忆依赖类**：
  - Shell Game（贝壳游戏）：物体被藏于某杯下，洗牌后需选出正确杯子。
  - Rolling Object Grasping：抓取连续滚动的瓶子。
- **精确感知依赖类**：
  - Pen Insertion into Narrow Bottle：将笔从一瓶插入另一窄口瓶。
  - Cup Insertion into Cup Sleeve：将杯子精确插入杯套。
- 每个任务收集 **100 条遥操演示**（30 FPS），指令语言明确给出。

### 3.2 仿真基准

- **LIBERO**：4 个子套件（Spatial / Object / Goal / Long），每套 10 任务 × 50 次试验，报告成功率。
- **CALVIN**：测试最长 5 个连续子任务的执行能力，报告各位置成功率与平均序列长度。

### 3.3 对比方法

- **真实机器人**：仅与 π0.5 基线对比。
- **LIBERO**：与 Diffusion Policy、Octo、SpatialVLA、TraceVLA、OpenVLA、CoT-VLA、π0-FAST、SmolVLA、GR00T-N1、UniVLA、FLOWER、CronusVLA、TriVLA、4D-VLA、CogACT、ST-π、MemoryVLA、π0、π0.5 等近 20 种方法对比。

## 4. 资源与算力

- **LIBERO 训练**：8 张 **NVIDIA H100 GPU**，batch size = 256，训练 **30k 步**。
- **真实机器人训练**：8 张 H100，batch size = 128，训练 **50k 步**。
- **流式帧数设置**：训练时 `T ∈ {3, 5}`；随机间隔范围 `δ ∈ [3, 7]`。
- **推理硬件**：单张 **NVIDIA GeForce RTX 4090**，测量推理延迟。
- **推理延迟实测**（T=1 → T=10）：94.4 → 97.9 → 103.6 → 110.9 → 117.9 ms，T=5 时仅比单帧增加 9.2 ms。
- **训练超参**：沿用 π0.5 优化器与学习率，全程微调。

## 5. 实验数量与充分性

- **总体规模**：包含 4 个真实机器人任务、2 个仿真基准（LIBERO 4 子套件 + CALVIN）、多组消融与跨设置测试。
- **消融维度**：
  - 注意力方向（intra-pair 双向 vs 因果 × inter-pair 因果 × T ∈ {1,3,5}）。
  - 训练间隔（固定 δ=1 vs 随机 δ ∈ [3,7]）× T ∈ {3,5}× 测试间隔 δ ∈ {1,3,5}。
  - 跨流泛化（训练 T=5，测试 T ∈ {1,3,5}）。
  - 与 ST-π、MemoryVLA 等强基线在 CALVIN 上的逐位成功率对比。
- **充分性评估**：
  - LIBERO 整体已接近饱和（多数方法 >95%），进一步提升空间有限，作者明确指出此点，结论较克制。
  - 真实机器人任务每条指令均附"逐试验 0/1 表"，过程透明。
  - 但真实机器人实验仅与 π0.5 一对一对比，未与 π0、CronusVLA、MemoryVLA 等做实物对比，存在一定对比盲区。

## 6. 主要结论与发现

- **真实机器人**：StreamPI 在四项任务上均大幅领先 π0.5。
  - Rolling Object Grasping：26.7% → 63.3%（+36.6）。
  - Shell Game：46.7% → 80.0%（+33.3）。
  - Pen Insertion：40.0% → 66.7%（+26.7）。
  - Cup Insertion：60.0% → 92.0%（+32.0）。
- **LIBERO**（T=5）：平均成功率 96.9% → **98.3%**，其中 LIBERO-Long 提升 +2.6%、LIBERO-Goal +2.8%；LIBERO-Spatial 无提升（已饱和于静态空间关系）。
- **CALVIN**：平均序列长度 4.313 → **4.547**；第 5 个子任务成功率 79.5% → 85.0%，明显优于 MemoryVLA（69.4%）。
- **跨流泛化**：以 T=5 训练的模型在 T=1 时仍优于 π0.5，说明习得的时序结构在无历史帧时仍具残差价值。
- **核心发现**：指令锚定的双向 + 因果分层注意力是长时程任务的关键；随机间隔训练是连接同步训练与异步部署的桥梁。

## 7. 优点

- **零参数增量**：完全继承 π0.5 预训练权重与表征完整性，避免新模块引入的特征对齐风险。
- **指令锚定机制**：将语言指令"绑定"到每一帧观测，从根本上缓解视觉累积造成的指令遗忘问题。
- **流式推理高效**：KV-Cache 使推理成本与时间视域解耦，T=5 时延迟仅增加 ~10 ms。
- **部署鲁棒性强**：随机间隔训练 + 时间掩码显著提升对异步观测流的适应性。
- **灵活推理粒度**：同一模型支持单帧与多帧推理，部署友好。
- **实验层次丰富**：从仿真到真实、从短时到长时、从静态到动态多维度验证。
- **可视化与逐试验结果齐全**：附录提供丰富的逐次试验 0/1 表与连续帧对比图，过程透明。

## 8. 不足与局限

- **训练代价**：所有 T 帧均需在训练时加载，极长视域（>100 帧）训练成本难以承受，作者将其列为未来工作。
- **极端异步未充分覆盖**：随机间隔训练缓解一般异步问题，但对极端不规则帧率/丢失帧仍不完善。
- **真实机器人对比范围有限**：仅与 π0.5 对比，未引入 MemoryVLA、CronusVLA、ST-π 等多帧基线，难以判断相对位置。
- **任务规模偏小**：真实机器人每任务仅 15–30 次试验，统计显著性可能受随机性影响。
- **依赖较强 backbone 长度外推**：当前优势建立在 π0.5 LLM 已具备较好长度外推能力之上，对不具备该能力的 VLA backbone 迁移性未充分讨论。
- **潜在社会影响**：作者承认更强大的操控能力可能冲击工业劳动力市场，且对分布外场景的鲁棒性仍需加强。
