## 摘要
视觉-语言-动作（VLA）模型通过整合视觉感知、语言理解和连续动作控制，为通用机器人操控提供了一条可扩展的路径。然而，我们揭示了VLA架构的一个关键局限：动作专家对VLM特征中可用的3D几何信息和2D语义信息的访问能力有限。这一可及性差距削弱了感知基础，并限制了精细化机器人操控任务的表现。为解决此问题，我们提出了V-Link，在视觉-语言（VL）到动作（A）的特征传递过程中显式恢复视觉表征。具体而言，V-Link在VLM中学习互补的Spatial与Semantic Query表征，并通过非对称通路将其注入Action DiT中。Semantic Query补充了原始VLM的图像token，而Spatial Query则为空间对齐的动作生成提供专门的几何条件。在LIBERO、LIBERO-Plus和RoboTwin 2.0上，我们的V-Link相较基线模型GR00T N1.6分别将平均成功率提升+1.9%、+31.2%和+18.8%。在AGIBOT A3 Ultra上，V-Link在两项真实世界人形机器人任务上进一步取得了+20%和+24%的增益。

## Abstract
Vision-language-action (VLA) models provide a scalable path toward generalist robotic manipulation by integrating visual perception, language understanding, and continuous action control. However, we reveal a critical limitation of VLA architectures: the action expert has limited access to the 3D geometric and 2D semantic information available in VLM features. This accessibility gap weakens perceptual grounding and limits performance on fine-grained robotic manipulation. To address this issue, we propose V-Link, which explicitly recovers visual representations during the vision-language (VL) to action (A) feature transfer. Specifically, V-Link learns complementary Spatial and Semantic Query representations within the VLM and injects them into Action DiT through asymmetric pathways. Semantic Queries complement the original VLM image tokens, whereas Spatial Queries provide dedicated geometric conditioning for spatially grounded action generation. Across LIBERO, LIBERO-Plus, and RoboTwin 2.0, our V-Link improves the average success rate over base model GR00T N1.6 by +1.9%, +31.2%, and +18.8%, respectively. On the AGIBOT A3 Ultra, V-Link further achieves gains of +20% and +24% on two real-world humanoid tasks.

# V-Link 论文结构化总结

## 一、核心问题与研究动机

- **背景**：视觉-语言-动作（VLA）模型已成为通用机器人操控的主流范式，其中双系统架构（如 NVIDIA GR00T N1.6）将视觉-语言模型（VLM）与独立的动作专家（Action DiT）耦合，由 VLM 的最后一层特征传递给 Action DiT 完成控制。
- **核心问题**：作者揭示了现有 VLA 架构中存在一个被忽视的**视觉表征可访问性瓶颈（accessibility gap）**——尽管 VLM 内部编码了丰富的 3D 几何与 2D 语义信息，但在 VL→A 特征传递过程中，Action DiT 难以有效访问这些信息。
- **诊断实验**：冻结 VLM 与 Action DiT 的特征，仅训练轻量级深度估计与语义分割头作为"探针"。结果显示：
  - 深度 MAE 从 VLM 的 0.015 上升到 Action DiT 的 0.071（误差增大近 5 倍）
  - 分割 mIoU 从 0.665 降至 0.290（性能下降约 56%）
- **归因分析**：在仅有动作监督的情况下，Action DiT 倾向于依赖语义捷径（semantic shortcuts），而忽略对精确操作至关重要的 3D 几何线索，导致陷入缺乏空间接地的局部最优。

## 二、方法论

### 核心思想
- 在 VLM 内部学习两组**互补的可学习查询表征**——Spatial Query（空间查询）与 Semantic Query（语义查询），并通过**非对称通路**将它们注入 Action DiT，恢复视觉表征的可访问性。

### 关键技术细节

**1. VLM 内部表征解耦（Representation Decoupling）**
- 在 VLM 输入序列中追加两组可学习 token：Spatial Query $E_d$ 与 Semantic Query $E_s$，与文本 token $E_t$、图像 token $E_o$ 拼接：
  $$E = [E_t; E_o; E_d; E_s]$$
- 采用**定制因果注意力掩码** $M_q$ 隔离两组查询，避免破坏原始多模态计算流；经过多个 Transformer block 后，两组查询分别聚合几何与语义线索。
- 训练阶段附加轻量辅助头（各约 2.3M 参数）：
  - **深度头**：投影层 + 两个 per-view Transformer 编码器 + 卷积解码器，输出 $V$ 个视角的稠密深度图 $\hat{D}$，使用 softplus 保证正值。
  - **分割头**：架构相同，输出像素级分类 logits。
- 损失函数：
  - 深度损失：$L_{depth} = L_{sm} + 0.1 \cdot L_{rel} + 0.5 \cdot L_{patch}$，其中 $L_{rel}$ 强调近场物体，$L_{patch}$ 是 top-k 难块挖掘损失。
  - 分割损失：$L_{seg} = L_{CE} + 0.5 \cdot L_{Dice}$
- 推理时移除辅助头，无需深度/分割标注。

**2. Action DiT 中的非对称注入**
- GR00T N1.6 的 32 层 AlternateVLDiT 采用 4 层周期循环：CA(non-img) → SA(state/action) → CA(img) → SA(state/action)。V-Link 仅在图像交叉注意力层（$\ell = 4k+2$）进行注入。
- **Semantic Query 通路**：与原 VLM 图像 token 并行做交叉注意力，结果经 Fuse 投影并通过门控参数 $g_l$ 与可学习残差融合：
  $$Z_l = H_l + \text{Fuse}(N_l, g_l S_l)$$
- **Spatial Query 通路**：对融合后的 $Z_l$ 做空间交叉注意力，提供专用几何条件：
  $$H'_l = Z_l + \text{CA}_{Spatial}(Z_l, E'_d)$$
- 最终经 FFN 输出 $H_{l+1}$。
- **总训练目标**：$L = L_{act} + 0.1 \cdot L_{depth} + 0.002 \cdot L_{seg}$

### t-SNE 验证
- 在 RoboTwin 2.0 rollouts 上对 5000 个观测的图像 token、Spatial Query、Semantic Query 做均值池化后 t-SNE 可视化，三类分布在嵌入空间清晰分离，证明查询学到差异化表征。

## 三、实验设计

### 数据集与基准
- **LIBERO**：标准仿真基准，包含 Spatial、Object、Goal、Long 四个子套件。
- **LIBERO-Plus**：LIBERO 的鲁棒性增强版，包含 Camera、Robot、Language、Light、Background、Noise、Layout 共 7 种分布偏移。
- **RoboTwin 2.0**：双臂仿真基准，选 6 个挑战任务（Move Pillbottle Pad、Move Stapler Pad、Place Bread Skillet、Place Phone Stand、Press Stapler、Turn Switch），每任务 50 条演示，共 300 条。
- **真实机器人**：AGIBOT A3 Ultra 人形机器人，两项任务（Autonomous Power-On / Power-Off），每任务 100 条遥操作演示。

### 评估协议
- LIBERO/LIBERO-Plus 每任务 50 trials，RoboTwin 2.0 每任务 100 trials，真机每任务 50 trials。
- 真机训练使用 Lingbot-Depth 补全缺失深度，GroundingDINO + SAM3 生成关键对象伪标签，其余像素标为背景；推理时无需任何辅助标注。

### 对比方法
- **2D VLA**：OpenVLA、Dita、CoT-VLA、π0-FAST、π0、π0.5、UniVLA、OpenVLA-OFT
- **3D VLA**：SpatialVLA、GeoVLA、3D-CAVLA、Spatial Forcing、Evo-Depth、Xiaomi Robotics-0、EventVLA
- 基模型：GR00T N1.6

## 四、资源与算力

- 所有模型从 GR00T N1.6 3B 初始化。
- 使用 **4 张 NVIDIA H100 GPU**，BF16 精度训练，DeepSpeed ZeRO-2。
- 优化器：AdamW，初始学习率 $1 \times 10^{-4}$，权重衰减 $1 \times 10^{-5}$，余弦衰减 + 5% 预热。
- VLM 冻结语言与视觉骨干，使用 rank-128 LoRA 适配。
- 训练步数：LIBERO 80K 步（全局 batch 160），RoboTwin 2.0 120K 步（全局 batch 128）。
- 推理延迟：基模型 43.21 ms → V-Link 44.79 ms，仅增加 1.58 ms（H100，torch.compile，4 步去噪，3 视角输入，batch 1，平均 1000 次）。

## 六、主要结论与发现

- **LIBERO**：V-Link 平均成功率 99.3%，比 GR00T N1.6（97.4%）提升 +1.9%，比 Spatial Forcing（98.5%）提升 +0.8%，四个子套件均排名第一，Long 子套件提升最大（+5.1%）。
- **LIBERO-Plus**：V-Link 总成功率 75.0%，比此前最佳提升 +5.4%，比基模型提升 +31.2%，在 Noise（+60.4%）、Language（+47.3%）、Lighting（+30.6%）偏移下增益尤为显著。
- **RoboTwin 2.0**：V-Link 平均成功率 56.8%，比基模型提升 +18.8%，六项任务全部稳定提升。
- **真机**：AGIBOT A3 Ultra 上 Power-On 98%（基模型 78%）、Power-Off 94%（基模型 70%）。
- **核心发现**：(1) Spatial Query 与 Semantic Query 各自承担差异化角色——前者贡献 Move/Place 类几何任务，后者贡献 Contact 类语义定位任务；(2) 任务监督与查询注入缺一不可，单独使用收益有限（+2.3%、+1.8%），联合使用收益显著（+18.8%）；(3) Query token 数量适中（3×5×5）即可达到最佳精度-效率平衡。

## 七、优点

- **问题洞察新颖**：首次明确揭示并量化了 VL→A 特征传递中的"视觉表征可访问性瓶颈"，通过冻结特征 + 探针头的诊断协议给出了直观证据。
- **方法设计优雅**：两组互补查询 + 非对称注入机制分工明确（语义补充 vs. 几何强制），并用因果注意力掩码保持原始多模态计算流不被破坏。
- **训练-推理解耦干净**：辅助头仅训练时使用，推理无需任何深度或分割标注，部署门槛低。
- **工程友好**：仅增加 1.58 ms 推理延迟，参数开销小（每头约 2.3M），便于在已有 GR00T N1.6 流程上即插即用。
- **实验充分且包含诊断证据**：不仅给策略成功率，还通过深度 MAE/分割 mIoU 反向验证表征确实被恢复，且提供 t-SNE 可视化、查询数量搜索等系统分析。
- **跨仿真与真机验证**：覆盖标准基准、鲁棒性偏移、精细操作、真机人形机器人，泛化性证据较完整。

## 八、不足与局限

- **基模型依赖性强**：方法专为 GR00T N1.6 的 AlternateVLDiT 注意力周期设计，迁移到其他双系统 VLA（如 π0 的统一架构）或单系统 VLA 时，需要重新设计注入层与时机。
- **消融完整性不足**：查询消融、任务监督与注入消融均仅在 RoboTwin 2.0 的 Move/Place/Contact 子集上报告，LIBERO 上缺乏对应消融，难以判断贡献的稳定性。
- **真实场景覆盖有限**：仅在 AGIBOT A3 Ultra 的 Power-On/Off 两项任务上验证真机表现，任务类型偏结构化（插拔充电），未能覆盖更复杂、动态的真机操控场景。
- **超参数选择细节未充分讨论**：门控参数 $g_l$ 的初始化与学习行为、Query warm-up 与联合训练的过渡策略等细节较少展开。
- **标注依赖仍存在**：训练阶段需深度图与分割 GT（真机场景需 Lingbot-Depth、GroundingDINO、SAM3 生成伪标签），数据准备成本不可忽略，对缺乏深度传感器的场景存在应用门槛。
- **公平比较性问题**：不同方法在不同基准的训练数据量、步数、超参数并非完全一致，跨方法比较的公平性需要审慎看待；此外，论文主要展示相对基模型 GR00T N1.6 的提升，绝对对比的最强方法可能仍存在差异。
- **理论解释偏直觉**：关于 Action DiT 倾向于"语义捷径"导致几何退化的解释更多基于经验观察，缺乏更严格的理论分析（如损失景观或信息瓶颈视角）。
