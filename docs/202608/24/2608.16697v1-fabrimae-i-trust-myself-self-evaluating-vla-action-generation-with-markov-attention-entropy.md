## 摘要
视觉-语言-动作模型（VLAs）将视觉感知、语言指令和动作生成整合到跨异构架构的端到端策略中。然而，使 VLAs 能够在没有外部监督的情况下自评估其动作生成可靠性，仍然是一项重大挑战。现有方法要么依赖专家标注，要么仅从输出统计量估计不确定性，在很大程度上忽略了内部信号。在本工作中，我们观察到内部视觉模态熵在异构 VLAs 之间对成功任务和失败任务表现出一致的区分。尽管 VLAs 在动作生成方面的架构各异，我们表明它们共享一个在视觉感知、语言指令和状态输入下演化的共同潜在动作生成抽象，我们将此表述为条件生成马尔可夫链。基于这一表述，我们提出了 MAE（马尔可夫注意力熵），这是一个直接将内部注意力信号转换为架构感知可靠性得分的自评估框架，并引入了 LIBERO-Reflect，这是一个包含 4,000 个回合的基准测试，涵盖四个子集中的 2,000 个标准回合和 2,000 个挑战性回合。跨异构 VLA 架构和多样化场景的大量实验表明，MAE 在 AUPR、AUROC 和 FPR@95 上始终优于最先进的基线方法。我们进一步实例化 FabriMAE 用于无验证器的测试时动作选择，表明 MAE 引导的多重采样以较小的运行时开销提高了 PI 系列方法在 LIBERO-Plus 上的鲁棒性。

## Abstract
Vision-Language-Action models (VLAs) integrate visual perception, language instruction, and action generation into end-to-end policies across heterogeneous architectures. However, enabling VLAs to self-evaluate their action generation reliability without external supervision remains a major challenge. Existing methods either rely on expert annotations or estimate uncertainty only from output statistics, largely ignoring internal signals. In this work, we observe that internal visual modality entropy exhibits consistent distinctions between successful and failed tasks across heterogeneous VLAs. Although VLAs' architectures differ in their action generation, we show that they share a common latent action generation abstraction evolving under visual perception, language instruction, and state input, which we formulate as a Conditional Generative Markov Chain. Based on this formulation, we propose MAE (Markov Attention Entropy), a self-evaluation framework that directly converts internal attention signals into architecture-aware reliability scores, and introduce LIBERO-Reflect, a 4,000-episode benchmark combining 2,000 standard episodes and 2,000 challenging episodes across four subsets. Extensive experiments across heterogeneous VLA architectures and diverse scenarios show that MAE consistently outperforms state-of-the-art baselines on AUPR, AUROC, and FPR@95. We further instantiate FabriMAE for verifier-free test-time action selection, showing that MAE-guided multiple sampling improves PI-family robustness on LIBERO-Plus with small observed runtime overhead.

# FabriMAE 论文总结：基于马尔可夫注意力熵的 VLA 动作生成自评估

## 1. 核心问题与整体含义

### 研究背景
- 视觉-语言-动作模型（VLA）将视觉感知、语言指令和动作生成整合到端到端策略中，覆盖多种异构架构。
- VLA 在跨机器人任务泛化时，需要对其生成的动作何时可能失败进行可靠的估计。

### 现有方法的不足
- **依赖外部监督**：早期方法依赖专家标注或外部评估模型（如 AHA、RoboMonkey），部署成本高、对标注或评估器漂移敏感。
- **仅利用输出统计**：黑盒方法（如多采样一致性、自置信度分数）可能过度自信，且可解释性有限。
- **白盒信号研究碎片化**：LLM 中已有 softmax 置信度、温度缩放、激活模式等白盒自评估研究，但 VLA 中的内部信号（路径偏差、潜在动作瓶颈等）尚未被统一为跨家族的可靠性度量。

### 核心研究问题
能否在不依赖外部监督的前提下，将 VLA 内部信号转化为统一的、跨异构动作生成架构的自评估度量？

### 关键观察
在异构 VLA 中，**内部视觉模态熵**在成功任务与失败任务之间表现出一致的区分性，这构成 MAE 的核心动机。

## 2. 方法论

### 2.1 核心思想：条件生成马尔可夫链（Conditional Generative Markov Chain）

将异构 VLA 的动作生成抽象为统一的马尔可夫链：

- **状态空间 Z**：潜在动作状态（离散动作 token 前缀 / 连续潜在动作表示 / 动作轨迹）。
- **条件空间 C**：(Vt, X, Rt)，即视觉表征、语言指令、可选状态输入。
- **转移核 Pθ**：架构相关的转换核（自回归离散读出、连续读出、Flow 风格细化）。
- **链结构**：$z_{t,0} \to z_{t,1} \to \cdots \to z_{t,K} \to a_t$，最终动作 $a_t = g_\theta(z_{t,K})$。
- **马尔可夫性**：给定当前潜在动作状态 $z_{t,k}$ 和条件 $C_t$，下一状态 $z_{t,k+1}$ 不再依赖更早状态。

这一公式将两类异构 VLA 统一到同一框架：
- **Latent-Readout VLAs**（如 OpenVLA、OpenVLA-OFT）：演化潜在动作表示，通过读出头映射到可执行动作。
- **Latent-Refinement VLAs**（如 PI 系列、QwenPI-Flow）：维持动作或轨迹表示，通过流/扩散风格的迭代动力学进行细化。

### 2.2 马尔可夫注意力熵（MAE）

**核心思想**：转移核更新潜在动作状态时需查询条件上下文；Transformer 注意力刻画了这种信息路由；注意力熵度量了这种路由行为。

**关键技术细节**：

1. **提取注意力矩阵**：在内部生成步 $k$、层 $\ell$、头 $h$，得到动作查询 token 到条件上下文 token 的注意力矩阵 $A^{(t,k,\ell,h)} \in \mathbb{R}^{S_a \times S_c}$。

2. **视觉模态归一化**：将 key 侧拆分为视觉 token 集 $I_v$ 与语言 token 集 $I_x$，对视觉注意力分布进行归一化：
$$p_v^{(t,k,\ell,h)}(j|i) = \frac{A_{ij}^{(t,k,\ell,h)}}{\sum_{r \in I_v} A_{ir}^{(t,k,\ell,h)} + \epsilon}$$

3. **视觉注意力熵计算**：
$$H_v^{(t,k,\ell,h)}(i) = -\sum_{j \in I_v} p_v^{(t,k,\ell,h)}(j|i) \log p_v^{(t,k,\ell,h)}(j|i)$$

4. **回合级 MAE 分数**：在最终生成步 $k=K$ 处取值，先对执行步和动作查询取均值 $E_{\ell,h}$，再选择每层 Top-m 头并按方向 $\omega \in \{-1, +1\}$ 取值：
$$\text{MAE}_\omega^{(m)}(E) = \frac{1}{L}\sum_{\ell=1}^L \frac{1}{m}\sum_{h \in \text{TopM}_m(\omega E_{\ell,:})} \omega E_{\ell,h}$$

### 2.3 架构感知方向

- **MAE-D**（递减熵方向，$\omega=-1$）：用于 Latent-Readout VLAs。**可靠执行的视觉注意力更集中**，弥散视觉寻址表示潜在动作状态未定位到必要视觉证据。
- **MAE-C**（递增熵方向，$\omega=+1$）：用于 Latent-Refinement VLAs。**可靠执行在最终细化步保留更广的视觉寻址**，过低熵表示最终动作轨迹以过窄的视觉上下文确定。

方向选择基于架构推断图而非标签或验证集优化，避免了对失败的过拟合。

### 2.4 FabriMAE：免验证器的测试时动作选择

针对 PI 系列 Latent-Refinement VLAs 的推理时应用：
- 每步采样 $n$ 个候选动作块，计算每个候选最终细化步的 MAE-C 分数；
- 选择分数最高的候选执行：$i^\star = \arg\max_{i \in \{1,...,n\}} \text{MAE}(i)$，$a_t^\star = a^{(i^\star)}_t$；
- **分支（Branch）变体**：在细化的前 70% 共享前缀，将共享潜在状态复制到 10 个候选并添加高斯扰动（噪声尺度 $0.15 \cdot \text{std}(x_{shared})$），最后 30% 独立细化；
- 策略冻结，无需外部验证器或奖励模型。

### 3.1 数据集与基准

### 3.3 对比的基线（7 种）

- **黑盒**：Random、Verbal Confidence（使用 GPT-4.1 + 拼接图像接触表）、Self-Consistency（仅 OpenVLA 适用）。

注意：连续动作头（OFT）与流匹配头（PI）不暴露离散动作 token 概率，因此 token 统计基线在这些模型上不适用。

## 6. 主要结论与发现

1. **MAE 优于现有基线**：在 AUROC、AUPR、FPR@95 上全面超越黑盒与白盒基线；OpenVLA-OFT 在 Goal Semantics 上 AUROC 提升 105.3%；OpenVLA 在 Object Binding 上 AUROC 提升 90.1%。
2. **跨架构迁移性**：在 Latent-Readout 与 Latent-Refinement 两类 VLA 上均有效，无需修改评分框架。
3. **视觉熵优于文本熵**：文本侧熵无法稳定替代视觉信息，视觉注意力熵是动作相关自评估的合适信号。
4. **Top-1 头选择最优**：在 Top-m 扫描中，Top-1 给出最稳定且最高效的排序性能。
5. **全层聚合最佳**：限制到浅/中/深层均不能全面占优，全层聚合避免架构或任务特定的层带超参。
6. **FabriMAE 提升 PI 系列鲁棒性**：在 LIBERO-Plus 上，PI0.5 配合分支 FabriMAE（70% 分支比、0.15 噪声尺度）总体成功率 86.80%，较 Normal 提升 1.10 个百分点，较独立采样提升 0.60 个百分点，且运行时开销小（增加 7.20%）。
8. **架构感知的方向规则**：方向由架构推断图决定，不需要标签或验证集优化，避免了对失败的过拟合。

---

## 7. 优点

- **统一抽象**：通过条件生成马尔可夫链将异构 VLA 动作生成统一到一个框架。
- **架构感知**：MAE-D 与 MAE-C 的方向区分反映了不同家族的内在动力学差异，具有理论支撑。
- **无需外部监督**：仅复用同一前向传播的内部注意力，无额外 rollout、辅助模型或奖励模型。
- **低开销**：MAE 增加 < 5% 推理延迟，FabriMAE 增加约 7% 回合时间。
- **理论与实证结合**：附录 I 从推理计算图角度论证方向规则的合理性，增强可解释性。
- **基准构建严谨**：LIBERO-Reflect 通过标准/挑战配对、实际模拟器标签、多能力子集设计，减少了数据集源捷径的风险。
- **应用拓展**：除后验排序外，还能直接驱动免验证器的测试时动作选择。

---

## 8. 不足与局限

- **VLA 覆盖有限**：仅评估了 3 个开源 VLA（OpenVLA、OpenVLA-OFT、QwenPI-Flow），未涵盖扩散策略、3D 表征 VLA、真实机器人训练模型等。
- **基准局限于模拟器**：LIBERO-Reflect 基于 LIBERO/LIBERO-PRO 构建，未在真实机器人环境中验证。
- **挑战回合失败率极高**：部分模型在挑战子集上成功率接近 0%（如 QwenPI-Flow Reflect-Goal/Object 为 0%，OpenVLA Reflect-10/Object 为 0%），可能导致指标不稳定。
- **OFT/PI 模型的 token 基线缺失**：由于动作头接口不同，连续动作与流匹配模型无法应用 token 概率基线，限制了白盒基线的公平比较（论文明确指出此为接口不匹配问题）。
- **Verbal Confidence 引入外部 LLM**：该基线使用了 GPT-4.1 + 拼接图像查询，并非严格的纯内部自评估，可能不完全公平。
- **OpenVLA 在标准侧的基线成功率较低**（72.1%），挑战侧成功率近乎 0%，使得排序问题在该模型上偏向极端不平衡。
- **方向规则的普适性**：MAE-D/MAE-C 的方向划分依赖于潜在空间是否能显式承载"细化"或"读出"过程，对于更复杂的混合架构（如带 token 后细化的模型）适用性需进一步研究。
- **注意力熵的内在解释**：论文未深入探讨注意力熵为何在两类架构上呈现相反方向与成功/失败的关联，缺乏更深层的机理分析。
