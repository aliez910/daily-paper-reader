## 摘要
许多近期的机器人策略通过使用大规模预训练视觉-语言模型（VLM）作为动作主干来追求更强的控制能力。我们提出了WorldDiT，一种统一的扩散Transformer架构，它将动作生成与视觉世界建模相耦合，在不使用大规模预训练VLM动作主干的情况下仍取得了强大的性能。在训练过程中，单个扩散Transformer生成连续的动作块，并基于未来相机帧预测归一化的RGB patch目标。在四个LIBERO仿真套件上，WorldDiT在报告全部四个套件的方法中，其总模型参数量与平均成功率处于所报告的Pareto前沿上。这些结果为未来的扩展研究提供了一个强大的十亿参数以下的基线。

## Abstract
Many recent robot policies pursue stronger control by using large pretrained vision-language models (VLMs) as the action backbone. We introduce WorldDiT, a unified diffusion transformer architecture that couples action generation with visual world modeling and achieves strong performance without a large pretrained VLM action backbone. During training, a single diffusion transformer generates continuous action chunks and predicts normalized RGB patch targets from future camera frames. Across four LIBERO simulation suites, WorldDiT lies on the reported Pareto frontier for total model parameters and mean success among methods reporting all four suites. These results provide a strong sub-billion-parameter baseline for future scaling studies.

## 2. 方法论

### 2.1 整体思路
提出 **WorldDiT**：一个统一的扩散 Transformer（DiT），在共享主干中**同时学习连续动作生成**与**未来归一化 RGB patch 预测**两个目标。训练时两个目标均参与；推理时仅使用动作路径，RGB patch 头不进入推理图。

### 2.2 模型组件
- **冻结编码器**：
  - MAE 图像编码器（视觉）
  - Perceiver Resampler（多视角视觉聚合）
  - CLIP 文本编码器（语言指令 ℓ）
- **可训练组件**：
  - 机器人状态编码器（臂 + 夹爪分别编码、拼接、投影）
  - 共享 DiT 主干（depth=4，hidden=1024，16 heads，4 register tokens）
  - RGB 输入/输出线性投影（768→hidden→768）

### 2.3 输入窗口与目标
- **窗口长度**：N=10 步
- **观测上下文**：C=3 步（含主腕相机图像、机械臂状态、语言指令）
- **动作目标**：H=7 步的动作块 $A_i \in \mathbb{R}^{7\times d_a}$
- **未来 RGB patch 目标**：
  - 取 $i+H$ 时刻的主相机与腕相机帧
  - 每帧 224×224 → 16×16 patch，每 patch 向量 768 维
  - 每个 patch 用自身的均值方差归一化
  - 每相机保留 64 个均匀采样 patch，两相机拼接得到 $Y^{rgb}_i \in \mathbb{R}^{128 \times 768}$
- 损失仅作用于**最后一个时间槽**对应的 RGB patch 目标。

### 2.4 训练目标（Flow Matching）
- 对动作或 RGB patch 目标 $y$，采样 $\epsilon \sim \mathcal{N}(0,I)$，$\tau \sim U[0,1]$，构造 $x_\tau = (1-\tau)\epsilon + \tau y$
- 速度场回归损失：
  $$L_{\text{flow}} = \mathbb{E}_{\epsilon,y,\tau}\left\| v_\theta(x_\tau,\tau,c) - (y-\epsilon) \right\|_2^2$$
- 总损失为加权求和：
  $$L_{\text{total}} = w_{\text{action}} L^{\text{action}}_{\text{flow}} + w_{\text{rgb}} L^{\text{rgb}}_{\text{flow}}$$

### 2.5 推理流程（Receding Horizon）
- 输入：长度 C=3 的历史 $H_t = \{\ell, (o_j, s_j)\}$
- 动作 token 从高斯噪声出发，沿学习的速度场数值积分
- 使用 **20 步欧拉积分**：$x_{\tau+\Delta\tau} = x_\tau + \Delta\tau \cdot v_\theta(x_\tau,\tau,c)$
- 得到动作块 $\hat{A}_t \in \mathbb{R}^{7\times d_a}$，**执行前 3 步后滑窗重规划**，并对重叠绝对时刻动作做时间集成（temporal ensembling）

## 7. 优点

- **架构统一性**：动作与视觉目标共享一个 DiT 主干与同一个 flow-matching 形式，工程简洁、概念清晰
- **推理轻量**：RGB patch 头与目标 token 不进入推理图，部署路径仅含动作生成
- **参数高效**：~399M 总参数即可在 LIBERO 上达到 94.9% 均值，性能/参数性价比突出
- **多模态条件融合**：冻结 MAE/CLIP + 可训练 state encoder，兼顾通用先验与领域适配
- **滑动时窗 + 时间集成**：推理使用 receding-horizon（执行前 3 步再重规划）+ temporal ensembling，控制平滑
- **诚实报告局限**：明确指出 300/500 episode 用于 checkpoint 选择、报告数字不可作无偏测试估计
