## 摘要
视觉-语言-动作（VLA）模型通常采用以大语言模型为中心的 $V \to L \to A$ 路径，将视觉观测投影到大语言模型的表示空间后再解码为机器人动作。尽管这种设计有效，但每次策略调用都会产生巨大的计算和内存开销。在本文中，我们提出了 TurboVLA，一种将传统的 $V \to L \to A$ 路径重构为直接 $V + L \to A$ 映射的新型 VLA 范式。TurboVLA 不再使用大语言模型作为感知与动作之间的中心接口，而是独立编码视觉观测和语言指令，通过轻量级的双向视觉-语言交互直接在两者之间交换信息，并使用紧凑型解码器预测连续动作块。这种简洁的设计直接从视觉和语言特征构建任务条件表示，显著降低了 VLA 推理的计算和内存成本。在 LIBERO 数据集上，TurboVLA 仅有 0.2B 参数，在消费级 RTX 4090 上实现了 97.7% 的平均成功率、31.2 ms 的推理延迟和 0.9 GB 的推理显存，性能匹配甚至优于规模显著更大的 VLA 策略。这些结果表明，TurboVLA 是当前主流的以大语言模型为中心的 VLA 范式的一种简洁而有效的替代方案，为连接视觉、语言和动作以实现高效机器人操控提供了新的视角。代码已开源：https://github.com/H-EmbodVis/TurboVLA。

## Abstract
Vision-language-action (VLA) models commonly adopt an LLM-centric $V \to L \to A$ pathway, where visual observations are projected into the representation space of a large language model before being decoded into robot actions. Although effective, this design incurs substantial computation and memory overhead at every policy invocation. In this work, we introduce TurboVLA, a new VLA paradigm that reformulates the conventional $V \to L \to A$ pathway as a direct $V + L \to A$ mapping. Instead of using a large language model as the central interface between perception and action, TurboVLA independently encodes visual observations and language instructions, directly exchanges information between them through lightweight bidirectional vision-language interaction, and predicts continuous action chunks with a compact decoder. This simple design constructs task-conditioned representations directly from visual and linguistic features, significantly reducing the computational and memory costs of VLA inference. On LIBERO, TurboVLA achieves 97.7% average success with only 0.2B parameters, 31.2 ms inference latency, and 0.9 GB inference VRAM on a consumer-grade RTX 4090, matching or outperforming substantially larger VLA policies. These results establish TurboVLA as a simple and effective alternative to the prevailing LLM-centric VLA paradigm, offering a new perspective on how vision, language, and action can be connected for efficient robotic manipulation. Code is available at https://github.com/H-EmbodVis/TurboVLA.

## 1. 核心问题与研究动机

视觉-语言-动作（VLA）模型已成为语言条件机器人操控的主流框架，其通常采用 **以大语言模型为中心的 V → L → A 路径**：

- 视觉观测首先通过投影器映射到 LLM 的表征空间；
- 然后与语言指令 token 拼接后送入 LLM 处理；
- 最后由动作头或动作专家解码出机器人动作。

**核心问题与瓶颈：**

- **实时性不足**：LLM 的前向计算开销巨大，导致策略推理延迟高、控制频率低，难以满足响应式机器人操控的需求；
- **部署门槛高**：多 B 参数的 LLM 占用数 GB 推理显存，难以在消费级硬件或资源受限平台上部署；
- **过度泛化能力浪费**：执行级控制（execution-level control）无需开放语言生成或任务级规划，但通用 LLM 的广域推理能力远超此需求。

**TurboVLA 的核心观察**：
> 一旦指令已经明确了操控技能，执行策略无需进行开放的语言生成或自主任务分解，只需根据指令决定当前视觉证据如何引导动作。因此，轻量文本编码器（如 BERT）足以提供执行相关语义，紧凑的跨模态交互即可让语言和视觉协同构建控制导向的表示。

由此提出 **直接 V + L → A 范式**：去掉 LLM 中心，将视觉与语言独立编码后直接交互，构造面向连续动作预测的紧凑表征。

## 2. 方法论

### 2.1 总体架构

TurboVLA 由三个核心模块组成：

1. **多模态特征编码器**（视觉编码器 + 轻量文本编码器 + 状态编码器）
2. **视觉-语言交互模块**（双向交叉注意力）
3. **连续动作块解码器**（非自回归并行解码）

### 2.2 模块细节

**（1）多模态特征编码**
- **文本编码**：使用 BERT（或 T5-small / SigLIP-Base 等可替换）提取 token 级指令特征 $Z_l = P_l(f_{\text{text}}(x)) \in \mathbb{R}^{N_l \times d}$，保留完整 token 序列而非池化嵌入，以保留目标、属性与空间关系供细粒度视觉条件化使用。
- **视觉编码**：使用 DINOv3 提取每个相机视角的空间特征，加上位置嵌入与相机视角嵌入后拼接：
  
  $$Z_v^{(i)} = P_v(f_{\text{img}}(I^{(i)})) + E_{\text{pos}}^{(i)} + e_{\text{view}}^{(i)}$$
  
  $$Z_v = [Z_v^{(1)}; \ldots; Z_v^{(K)}]$$
- **状态编码**：本体感知状态 $s_n$ 经轻量投影网络 $f_{\text{state}}$ 编码为 $Z_s \in \mathbb{R}^{N_s \times d}$，直接送入动作解码器，不参与跨模态交互，以保留交互模块对任务条件场景理解的聚焦。

**（2）视觉-语言交互模块（核心创新）**

设计受 **Grounding DINO** 启发，采用 **N 层双向交叉注意力**：

$$\{Z_v^{\ell}, Z_l^{\ell}\} = \text{FusionLayer}^{\ell}(\{Z_v^{\ell-1}, Z_l^{\ell-1}\}), \ell=1,\ldots,N$$

每层包含：
- 层归一化
- 视觉→指令交叉注意力（场景上下文注入指令流）
- 指令→视觉交叉注意力（任务语义调节视觉特征）
- 模态特定 FFN + 残差连接

最终输出拼接：$Z_{vl} = [Z_v^N; Z_l^N]$。

**（3）连续动作块预测**

采用 **ACT 风格**的 Transformer 解码器，将融合多模态特征与机器人状态映射为一段连续动作：

$$\hat{A}_n = D_\theta(Q_a, [Z_{vl}; Z_s]) \in \mathbb{R}^{H \times d_a}$$

其中 $Q_a$ 为 H 个可学习的动作查询。所有动作查询 **并行解码**，单次前向即可输出 H 步连续动作块（无需自回归动作 token 生成）。

**训练目标**：行为克隆 + $\ell_1$ 损失，无任何辅助语言建模损失。

### 2.3 与 LLM-centric VLA 的本质区别

| 维度 | LLM-centric VLA | TurboVLA |
|------|----------------|----------|
| 路径 | V→L→A | V+L→A（独立编码） |
| 中心 | LLM（≥2B 参数） | 无 LLM，0.2B 总参数 |
| 指令处理 | LLM 内部融合 | 紧凑文本编码器 + 双向交叉注意力 |
| 动作生成 | 自回归 token 或 action expert | 单一前向 + action chunk 解码 |
| 推理延迟 | 60–700 ms | 31.2 ms |

## 3. 实验设计

### 3.1 基准与场景

- **LIBERO**：单臂操控基准，包含四个子套件（LIBERO-Object / Spatial / Goal / Long），每套 10 个语言条件任务；

- **真实机器人**：AgileX Piper 平台（6-DoF + 腕部 RGB-D + 第三视角 RGB-D），4 个任务：grab roller / move playing card / press stapler / stack three bowls。

### 3.2 对比方法

**三大类对照（共 17+ 个模型）**：
- **非 VLA 基线**：Diffusion Policy；

- **双臂**：Diffusion Policy、ACT、DP3、π0、FlowPolicy、RDT、SeedPolicy（per-task） + UP-VLA、π0.5、StarVLA-α（multi-task）。

### 3.3 评估指标

- 主要指标：任务成功率；
- 效率指标：总参数量（Params B）、推理延迟（ms）、推理 VRAM（GB）；
- 所有指标在 **RTX 4090、batch size=1** 下测量，延迟统一从多模态输入到动作块（或等量自回归 token）输出。

### 3.4 评测协议

- LIBERO：使用 OpenVLA 提供的 modified no noops RLDS 数据；联合训练一个跨子套件模型（DINOv3 ViT-B）；预测 12 步 7-DoF 动作块；80k 步训练（10k warm-up），有效 batch size 7256；采用 VLA-Adapter rollout 协议，每任务 50 次 rollout，共 2,000 次试验；
- RoboTwin 2.0：DINOv3 ViT-L，预测 50 步 14 维绝对关节位置；55k 步训练（1k warm-up），有效 batch size 192；50 任务各 100 次 rollout（仅 clean setting）；
- 真实机器人：从 LIBERO 预训练初始化，每任务 65 次遥操作微调，共 12.5k 步；每任务 40 次测试。

## 6. 主要结论与发现

1. **范式重构有效**：直接 V+L→A 范式在不依赖 LLM 中心的前提下，与甚至超越多 B 参数 LLM-centric VLA 的表现持平或更好；
2. **效率-性能前沿推进**：
   - LIBERO 平均成功率 **97.7%**，超越 π0.5（96.9%）、CogVLA（97.4%）、Mantis（96.7%）等能力导向模型；
   - 推理延迟从 π0.5 的 93.6 ms **降至 31.2 ms**（约 3× 加速）；
   - 参数量 0.2B（约为 π0.5 的 6%），推理 VRAM **0.9 GB**（远低于其他模型的 1.5–16 GB）；
3. **双臂扩展性良好**：RoboTwin 2.0 上 50 个任务平均 60.2%，超越 π0.5（57.0%）与 StarVLA-α（50.3%）；
4. **实际部署可验证**：真实机器人 4 个任务上均超越 π0.5，证明低算力路径在实际场景的可用性；
5. **语言条件不可或缺**：去除语言后成功率从 97.7% 跌至 70.8%（尤其 LIBERO-Goal 降至 11.6%），证明 BERT 级语义编码已具备足够判别能力；
6. **设计选择敏感**：双向交叉注意力优于单向与无交互；最优交互深度 N=6；最优动作块长度 H=12。

## 7. 方法与实验设计的亮点

- **明确的范式重定义**：第一次显式将 VLA 路径区分为 V→L→A 与 V+L→A，并系统论证 LLM 中心化的非必要性；
- **极简且可解释的架构**：仅用 BERT + DINOv3 + N 层双向交叉注意力 + ACT 解码器即可超越多 B 模型；
- **可替换性验证**：文本编码器（BERT / T5-Small / SigLIP）与交互深度均可独立调优，证明框架不依赖特定 backbone；

- **端到端真实部署验证**：不仅停留在仿真，还给出真实机器人与 π0.5 的直接对比；
- **轻量化门槛下沉**：将实时语言条件操控部署的硬件门槛从多卡高端 GPU 拉低至单卡 RTX 4090，甚至为边缘部署（如文中配图所示）打开可能。

   - 模型规模与交互深度的缩放规律仅做了 N ∈ {2,4,6,8} 的小范围实验；
   - 更大规模 backbone（如 DINOv3 ViT-L+）与更长视频观测（多帧历史）的扩展效应未验证；
8. **理论分析有限**：
   - 缺少对 LLM 中心化必要性的形式化论证；
   - 双向交叉注意力优于单向的机制原因（注意力可视化、特征分析）未深入展开。
