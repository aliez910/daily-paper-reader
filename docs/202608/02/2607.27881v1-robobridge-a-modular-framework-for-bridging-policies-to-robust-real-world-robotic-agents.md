## 摘要
视觉-语言-动作（VLA）模型作为一种可扩展的机器人操作方法日益受到关注。尽管这些模型是有效的动作预测器，但将其部署为机器人智能体暴露出关键的缺陷：缺乏失效恢复机制、长时序执行不一致，以及对观测、任务或本体变化的鲁棒性有限。现有解决方案通过模型重训练或环境特定模块分别解决这些局限，但真正需要的是一个能够系统地将预训练VLA转化为机器人智能体的通用框架。本文提出RoboBRIDGE，一个模块化框架，它在五个协同模块（即监控器、感知器、规划器、控制器和机器人接口）之上提供编排层，从而将现成组件（包括预训练VLA）组合成稳健的机器人智能体。监控器结合快速失效检测与分层恢复，在错误级联之前予以纠正。当环境偏离当前规划时，规划器触发重规划，同时感知器异步更新场景理解，避免执行停滞。在控制器内部，对底层技能进行微调，将操作分解为具有专用LoRA适配器的域不变底层技能，从而在使用VLA时降低对域偏移的敏感性。在LIBERO、RoboCasa以及涵盖多种机器人平台和VLA骨干网络的真实案例研究中，RoboBRIDGE始终优于独立的策略和先前的增强型VLA部署。这些结果表明，可靠的机器人智能体并非仅通过扩大动作预测器规模即可获得，而需要围绕动作预测器进行结构化的编排。

## Abstract
Vision-Language-Action (VLA) models have attracted growing interest as a scalable approach to robotic manipulation. While these models are effective action predictors, deploying them as robotic agents exposes critical gaps: no mechanism for failure recovery, inconsistent execution over long horizons, and limited robustness to shifts in observations, tasks, or embodiments. Existing solutions address these limitations individually through model retraining or environment-specific modules, yet what is needed is a general framework that systematically transforms a pretrained VLA into a robotic agent. We present RoboBRIDGE, a modular framework that provides an orchestration layer over five coordinated modules, namely Monitor, Perceptor, Planner, Controller, and Robot Interface, to compose robust robotic agents from off-the-shelf components, including pretrained VLAs. The Monitor pairs rapid failure detection with hierarchical recovery to correct errors before they cascade. When the environment diverges from the current plan, the Planner triggers replanning while the Perceptor updates scene understanding asynchronously, avoiding execution stalls. Within the Controller, primitive skill fine-tuning factors manipulation into domain-invariant primitives with dedicated LoRA adapters, reducing sensitivity to domain shifts when a VLA is used. Across LIBERO, RoboCasa, and real-world case studies spanning multiple robot platforms and VLA backbones, RoboBRIDGE consistently outperforms both standalone policies and prior augmented VLA deployments. These results suggest that reliable robotic agency does not arise from scaling action predictors alone, but from structured orchestration around them.

# RoboBRIDGE 论文总结

## 1. 核心问题与研究动机

- **研究背景**：视觉-语言-动作（VLA）模型（如 OpenVLA、π0.5、GR00T-N1.5、SmolVLA 等）作为通用机器人操作基础模型，能够直接将多模态观测与语言指令映射到低层动作，任务覆盖范围不断扩大。
- **本质问题**：VLA 本质上只是一个"动作预测器"，而不是完整的"机器人智能体"。当作为单体前向策略部署时，存在三大关键缺陷：
  - **缺乏失败恢复机制**：一次抓取失败或碰撞不会被察觉，错误会沿着长时序任务逐级级联。
  - **长程一致性不足**：每次推理都是独立的，无法跟踪任务进度或修正累积误差。
  - **对领域偏移的鲁棒性差**：在观测、任务或具身（embodiment）分布变化时性能急剧下降，sim-to-real 与跨机器人部署天然脆弱。
- **现有工作的局限**：已有研究（Code-as-Monitor、DoReMi、SAFE、FailSafe、CycleVLA、ISR-LLM、LoRA 微调等）往往只针对单一失效模式，并绑定特定模型架构或环境设置，缺乏统一解决方案。
- **本文主张**：机器人智能体不必是更大的策略，而是需要一个**与策略无关（policy-agnostic）**的**通用编排框架**，将任意动作生成策略提升为稳健智能体——类比 LLM 领域中通过 LangChain、AutoGen 等编排框架将模型变成工具增强 Agent 的范式。

## 2. 方法论

### 2.1 整体框架：五大模块

RoboBRIDGE 是一个模块化编排框架，由五个协同模块组成：

- **Monitor（监控器）**：闭环检测执行结果并触发分层恢复。
- **Perceptor（感知器）**：将原始观测转化为以对象为中心的场景状态（身份、3D 位姿、语义属性）。
- **Planner（规划器）**：分解语言指令为有序的基元技能（primitive skills）序列。
- **Controller（控制器）**：由任意动作生成策略（VLA、LoRA 微调策略、IK 控制器等）占据，将每个基元翻译为低层动作。
- **Robot Interface（机器人接口）**：抽象具身特定的 API、时序、安全限制与坐标变换。

### 2.2 关键技术一：两阶段监控与分层失败恢复

- **阶段 1（轻量成功检查）**：使用 VLM 等检查器 $D_{\text{check}}$，在受限输出格式下周期性评估当前观测 $o_t$ 与计划上下文 $c_t$，输出二值成功标志 $suc_t$ 与置信度 $con_t$：
  $$D_{\text{check}} : (o_t, c_t) \mapsto (suc_t, con_t)$$
- **阶段 2（失败诊断与恢复）**：当 $suc_t = \text{false}$ 且 $con_t \geq \gamma_{\text{thresh}}$ 时，立即停止机器人并调用诊断模型 $D_{\text{diag}}$，输出恢复目标 $r_t$：
  $$D_{\text{diag}} : (o_t, c_t) \mapsto (r_t, \text{reason}_t)$$
- **分层恢复策略（按重算范围递增）**：
  1. **retry**：重新执行当前基元。
  2. **re-generate**：保留当前规划和感知状态，重新生成轨迹。
  3. **replan**：基于最新异步感知结果重新规划。
  4. **re-perceive**：对象状态不可信时强制重新感知再规划。
- **设计意图**：应用最小但足够的修正，避免不必要的重算。

### 2.3 关键技术二：反应式规划与异步感知

- **生产者-消费者架构**：感知线程持续更新线程安全缓冲区 $B$ 中最新的检测结果 $\bar{o}_t = D_{\text{percept}}(o_t)$，执行线程按序执行基元。
- **分歧触发的重规划**：每个基元完成后比较用于规划时的观测 $\bar{o}_{\text{plan}}$ 与当前最新观测 $\bar{o}_{\text{lat}}$，分歧度量：
  $$\Delta(\bar{o}_a, \bar{o}_b) = \max_{i \in O_a \cap O_b} \|p_a^{(i)} - p_b^{(i)}\|_2 + \lambda \cdot |O_a \triangle O_b|$$
  当 $\Delta \geq \tau$ 时，保留高层动作序列（如 PICK → PLACE），只重新生成当前与后续基元的空间参数。
- **设计意图**：将感知延迟隐藏在执行背后，避免场景漂移带来的脆弱性。

### 2.4 关键技术三：基元技能微调（Primitive Skill Fine-tuning）

- **基元技能集合**：将操作分解为领域无关的基元 $P = \{\text{MOVE}, \text{GRIP}, \text{ROTATE}, \ldots\}$，每个基元由专用 LoRA 适配器 $\Delta\theta_k$ 实现：
  $$f_{\theta + \Delta\theta_k} : (i, s_t, p_t) \mapsto a_t^{(k)}$$
- **控制器切换（RESOLVE）**：根据当前基元 $p_t$ 选择对应适配器；若不存在则采用所有适配器的均值作为后备。
- **动作生成**：预测 7-DoF delta 动作（3D 平移 $\delta x$、3D 旋转 $\delta\phi$、夹爪 $g$），优先尝试 IK 求解，失败时回退为笛卡尔速度指令。
- **设计意图**：减少对观察/任务/具身变化的敏感性；适配器内存换入避免重新加载骨干。

### 2.5 完整算法流程（Algorithm 1）

1. 环境重置与初始感知 → 生成初始规划 $\bar{P}$；
2. 启动异步感知线程持续更新 $B$；
3. 对每个基元 $p_j$：解析 LoRA → 循环执行动作 → 阶段 1 检查 → 检测到失败时阶段 2 诊断并恢复；
4. 基元完成后检查与最新观测的分歧度，必要时触发重规划。

## 6. 主要结论与发现

- **整体结论**：可靠的机器人智能体不来源于对动作预测器的简单规模化，而源于在其周围的结构化编排。
- **仿真结果**：
  - LIBERO：GR00T-N1.5 平均成功率 35.5% → 39.7%（+4.2），长程任务从 10.6% 提升到 20.0%（+9.4）；
  - RoboCasa：所有 3 个 VLA 骨干均获一致提升，平均 3.7% → 7.5%（去除 PnP 后 6.2% → 11.4%）。
- **真实世界**：监控在训练与未见环境中均能早期识别失败，以最小代价恢复并继续推进，无需重新启动整个计划。
- **关键消融发现**：
  - Monitor + Planner 缺一不可，且其收益随 LLM 骨干诊断能力提升而放大（Claude Opus 4.6 +8.1%，GPT-5 mini +6.2%，弱模型几乎无增益）。
  - LoRA-FT + RoboBRIDGE（27.1%）接近 Full-FT standalone（31.9%），但只更新极少参数。
  - 经典 IK 控制器在 RoboBRIDGE 中也能达到 22.1%，证明框架对策略类型不敏感。
  - 仅靠模型内自校正（CycleVLA）平均仅 7.5%，远低于外部编排（LoRA-FT w/RB 27.1%）。
- **失败模式**：两类主导失败——感知错误（遮挡、混淆对象）与不可恢复的操作失败（接触密集场景），指明未来改进方向。

## 7. 优点

- **范式创新**：明确提出"动作预测器 → 智能体"的范式差距，并给出可与 LLM Agent 编排框架相对应的结构化解决方案。
- **策略无关性**：可插入任意动作生成器（VLA、LoRA 微调、IK、脚本），Controller 接口对实现无要求。
- **关键设计细节**：
  - 两阶段 Monitor 巧妙地将高成本诊断限制在必要时刻，兼顾延迟与可靠性。
  - 分层恢复（retry → re-generate → replan → re-perceive）按重算范围递增，体现"最小充分修正"原则。
  - 异步感知 + 分歧触发重规划，在保持长程一致性的同时避免执行停顿。
  - 基元 LoRA 适配器以极小额外参数换域不变性，并可通过均值回退避免缺失。
- **广度充分**：3 个 VLA 骨干 + 2 个仿真基准 + 2 个真实机器人 + 7 种 LLM 规划 / 诊断骨干的对比，结论有较强的可推广性。
- **可组合性**：每个模块都可独立替换，模块化设计便于社区二次开发。

## 8. 不足与局限

- **算力透明性不足**：未披露 GPU 型号、卡数、训练时长、推理延迟等关键资源信息，难复现。
- **样本量较小**：每任务评估约 17 次 rollouts，任务级波动较大，结论的统计显著性可能受限。
