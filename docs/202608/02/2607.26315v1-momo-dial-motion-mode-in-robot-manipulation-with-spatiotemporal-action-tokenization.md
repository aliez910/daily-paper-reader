## 摘要
为了在多样化场景中有效运作，机器人不仅需要精确地执行操作任务，还需使动作展开方式适应任务目标、物体特性以及交互环境。我们探讨这种执行层面的变化能否作为一种可复用的行为因子，在不同任务间共享学习。为此，我们提出了 \textbf{MoMo}——一种两阶段模仿学习框架，包含一个时空动作分词器与一个行为克隆 Transformer，后者以任务及连续的运动模式条件作为输入。在六项真实机器人操作任务中，调整该条件可产生稳定型、动态型以及介于两者之间的行为模式，人类评估者能够对其加以区分，且这些模式在关节速度、加速度及末端执行器接近俯仰角上均存在差异。对于仅以单一模式示教的任务，MoMo 能够迁移至未示教的请求模式，同时在很大程度上保持任务成功率。上述结果共同表明，模型在未见过的任务–模式组合上具有组合泛化能力，并证明运动模式可在不同任务间复用，从而调控操作技能的执行方式。

## Abstract
To operate effectively across diverse contexts, robots must not only perform manipulation tasks accurately but also adapt how their actions unfold to the task, object, and interaction setting. We ask whether this execution-level variation can be learned as a reusable behavioral factor shared across tasks. We present \textbf{MoMo}, a two-stage imitation-learning framework consisting of a spatiotemporal action tokenizer and a behavior-cloning transformer that takes task and a continuous motion-mode condition as inputs. Across six real-robot manipulation tasks, varying this condition produces steady, dynamic, and intermediate behaviors that human raters can distinguish and that differ in joint speed, acceleration, and end-effector approach pitch. On tasks demonstrated in only one mode, MoMo transfers the unseen requested mode while largely preserving task success. Together, these results provide evidence of compositional generalization to unseen task--mode combinations and show that motion mode can be reused across tasks to control how a manipulation skill is performed.

# MoMo 论文总结

## 1. 核心问题与整体含义

- **研究动机**：在真实场景中，机器人不仅需要"完成任务"，还需"如何完成"任务（节奏、平稳性、犹豫、加速度、末端姿态等）。现有的风格/行为条件化操控策略通常把行为和任务纠缠学习，使行为无法作为跨任务可复用的因子。
- **核心问题**：能否把"运动模式"（motion mode）作为一种与任务解耦的、可复用的行为调制因子，使同一任务能以不同模式执行，并能泛化到未见过的（任务，模式）组合。
- **预期意义**：为机器人操控的"组合泛化"提供证据——让一个轻量级条件信号即可在推理时调控行为质量，无需重训或重示教。

## 2. 方法论

### 整体框架
两阶段模仿学习：
- **Stage 1（动作分词器）**：将长度为 T=100（2 秒）的关节动作块编码为离散的时空码序列。
- **Stage 2（行为克隆 Transformer）**：从视觉+本体感知+任务 ID+连续运动模式标量 s，预测 Stage 1 的码索引，再由冻结的 Stage 1 解码回动作块。

### Stage 1 关键技术
- **双流编码器**：
  - **空间流**：1D 卷积编码器直接处理关节空间波形 → z_sp ∈ R^{K×D}（K=20, D=256），捕捉路径几何、接触与末端目标。
  - **时间流**：先对关节增量 ∆q 做 II 型 DCT，取前 C=16 个低频系数，再经 MLP → z_te ∈ R^{K×D}，捕捉节奏/平滑度/韵律结构。
- **残差矢量量化（RVQ）**：
  - 空间栈：L_sp=4 层，码本 [64, 512, 512, 512]（小首层码本作内容瓶颈）。
  - 时间栈：L_te=4 层，每层 256。
  - EMA 码本更新，并延迟一步以让对比梯度经残差链回传。
- **融合解码**：z_q = LayerNorm(GELU(W_f · [z_q^sp; z_q^te]))，再用 1D 上采样解码器还原动作块。
- **辅助 DCT 预测头** h_DCT 从 z_q^te 重建 DCT 目标，保证时间码保留频域信息。
- **训练目标（七项损失）**：
  $$L = L_{recon} + \lambda_{DCT} L_{DCT} + \lambda_{swap\text{-}task} L_{swap\text{-}task} + \lambda_{swap\text{-}mode} L_{swap\text{-}mode} + \lambda_{con} L_{con} + \lambda_{MI} L_{MI} + L_{commit}$$
  - swap 损失：同任务反模式下的 spatial/temporal 码交叉重组监督。
  - L_con：时间码上的残差对比损失（参考 VQ-Style）。
  - L_MI：空间潜码上的对抗式互信息惩罚，去除运动模式信息。

### Stage 2 关键技术
- 编码器：ResNet-34 处理前置+腕部相机 + 本体 + 任务嵌入 + 模式标量嵌入。
- 解码器：每个码本层一个分类头（CE 损失）+ 连续偏移头（L1 损失，用于补偿量化误差）。
- 损失：
  $$L_{Stage2} = \frac{1}{K(L_{sp}+L_{te})} \sum_{k,\ell} CE(p_{k}^{(\ell)}, i_{k}^{(\ell)}) + \|o - o^*\|_1$$
- **推理**：任务 ID 选定技能，s 调节执行质量；使用 ACT 的时间聚合平滑 50 Hz 执行。

## 3. 实验设计

- **硬件/平台**：Interbotix X-Series 单臂 ALOHA（WidowX-250 主臂 + ViperX-300 6-DOF 从臂）；前置俯视相机 + 腕部相机（480×640）；控制频率 50 Hz。
- **任务与示教**：
  - 双模式任务（各 60 次示教，30/30 分配）：**pick**、**pour**、**look**、**avoid**。
  - 单模式迁移任务：**highfive**（仅 Mode A）、**push**（仅 Mode B）。
  - 数据存为 Robomimic 格式 HDF5；训练时按步幅 10 子采样。
- **评估协议**：每任务 × 三档 s ∈ {0.1, 0.5, 0.9}（B / 中间 / A），每格 N=20 次 rollout；初始位置在 ±5 cm 内变化。
- **运动度量**：关节速度、关节加速度（关节位置的二阶差分）、末端接近俯仰角（正运动学）。
- **人工评估**：3 位专家评分员盲评"风格贴合度"（0–10）和"任务完成度"（0–10）。
- **对比方法**：论文未与具体基线（如原始 ACT、扩散策略、其他风格迁移方法）做 head-to-head 对比；侧重于自证模式的"可调节性、可迁移性、组合性"。

## 6. 主要结论与发现

- 调节运动模式标量 s 可在 6 个任务上产生**单调可区分**的稳态（Mode A）、动态（Mode B）与中间行为，三项动力学指标（速度、加速度、接近俯仰角）均呈现有序变化（Spearman ρ 高度负相关，p < 10⁻⁶）。
- 模式具有**跨任务复用性**：双模式任务的训练潜空间中，**空间码按任务聚类、时间码按模式呈带状**；迁移任务上空间码锁定于原任务聚类，时间码向请求模式区域移动。
- 对**未见（任务，模式）组合**（highfive@B、push@A）能实现模式迁移，任务成功率大体保留（push@A 的接触可靠性略降）。
- **风格贴合度**在所有任务、所有标量档均单调有序，包括两个迁移格——人类评分员能稳定感知模式，即便客观速度/加速度差异不显著（highfive）。
- 因子分解是**部分**而非完全：运动模式存在几何关联，末端接近俯仰角在 A/B 间系统性差异，使得空间码也会吸收部分模式信息。

## 7. 优点

- **结构化先验显式**：空间/时间双流 + DCT + 残差增量输入的设计直观地将"路径几何 vs 时间动力学"分开。
- **多损失协同**：重建 + DCT + swap + 对比 + MI + commit，形成显式的解耦压力，并将 VQ-Style 的角色式对比思想迁移到操作任务上。
- **闭环真实机器人验证**：6 个真实任务、20 次/格 rollout，且配合双盲人类评估，证据链较完整。
- **潜空间诊断清晰**：通过 PCA 把空间/时间码的"任务/模式"分聚类结构可视化，论证模式可被作为跨任务调制因子复用。
- **推理时可寻址**：s 是运行时连续控制信号，使操作员/上层策略可在不重训的情况下随上下文调整行为。

## 8. 不足与局限

- **模式维度单一**：仅定义两个原型 + 一维标量 s；真实运动模式空间更丰富，需要更高维条件。
- **解耦不完全**：运动模式存在几何相关（接近俯仰角），空间码部分吸收模式信息，限制了 highfive@B 的速度幅度。
- **迁移样本稀薄**：仅 2 个单模式任务，对"组合泛化"的结论仍为初步证据；缺少更系统的 OOD 测试集。
- **评估范围窄**：
  - 单一硬件平台（单臂 ALOHA）；
  - 初始物体位姿固定在 ±5 cm 内，环境扰动有限；
  - 人工评估仅 3 位专家评分员，存在评分偏差，缺乏普通被试。
- **缺少基线对比**：未与 ACT、扩散策略、BeT/VQ-BeT/FAST 或风格迁移方法做同条件对照，难以量化架构/损失设计的边际收益。
- **缺少消融**：swap-loss、对比损失、MI 惩罚各自贡献未报告。
- **接触可靠性退化**：push@A 迁移格接触阶段成功率下降，提示在严格任务场景下模式迁移仍有代价。
- **应用局限**：动作块长 2 秒、码本结构固定，对高频闭环、动态障碍、长视野任务的可扩展性需进一步验证。
