## Abstract
Vision-Language-Action (VLA) policies have advanced language-conditioned robotic manipulation, yet action-imitation objectives provide only weak supervision for metric 3D structure and short-horizon physical evolution. Geometry-enhanced policies mainly improve current-scene grounding, whereas predictive policies often model future dynamics in RGB or latent spaces and may incur substantial deployment cost. GaussianDream demonstrates that training-time current Gaussian reconstruction and future Gaussian prediction provide effective 3D supervision, but its dense VGGT/TGE-based prefix jointly carries state, dynamics, and action-conditioning information. We present \textbf{\methodname}, a compact, policy-native extension that inserts \textbf{World State Tokens} and \textbf{World Prediction Tokens} directly into the VLA backbone. A training-only \textbf{World Representation Head} decodes these tokens into a Current World and coupled Future Prediction over shared Gaussian primitives, while static--dynamic factorization preserves persistent structure and focuses residual motion on interaction-relevant regions. At inference, the head, renderer, auxiliary objectives, and VGGT/TGE pathway are removed, leaving only 20 world tokens without online Gaussian decoding or rollout. \method achieves \textbf{98.6\%} on LIBERO and \textbf{87.8\%} on LIBERO-Plus, with clear gains under Camera and Layout shifts. Real-robot experiments further improve average success from 29.2\% to 52.5\% over reproduced $π_{0.5}$ while maintaining efficient closed-loop control.

# GaussianDream++ 论文总结

## 一、核心问题与研究动机

- **背景**：Vision-Language-Action (VLA) 策略（如 RT-2、OpenVLA、π0、π0.5）借助大规模视觉-语言预训练与机器人演示数据，显著推动了语言条件下的机器人操控。但其优化目标主要是动作模仿，对**度量级 3D 结构**和**短时物理演化**仅提供弱监督。
- **现存挑战**：
  1. 场景几何、可见性与接触相关空间关系通常被隐式编码在 2D 视觉特征中，对抓取与放置中的细微误差敏感。
  2. 行为克隆只监督目标动作，未充分利用轨迹中的密集 3D 信息。
  3. 当前状态与未来演化通常通过分离的辅助目标或纠缠的单一表征学习，而操控任务以**持久场景结构**为主、交互引发的变化相对稀疏。
- **前作局限**：GaussianDream 通过训练时的当前/未来高斯重建与预测提供了有效 3D 监督，但其基于 VGGT/TGE 的稠密 1024 token 前缀**同时承载状态、动力学和动作条件信息**，且部署时仍需运行专用时序几何通路。
- **本文定位**：提出 GaussianDream++，将世界建模压缩到**策略原生**的极简表征中，部署时只需额外 20 个 token，不依赖任何在线高斯解码或未来展开。

## 二、方法论

### 核心思想

- 用两组**可学习 Token** 替换 GaussianDream 的稠密前缀：16 个 **World State Tokens**（世界状态 Token）+ 4 个 **World Prediction Tokens**（世界预测 Token），直接嵌入 PaliGemma 主干的 prefix 中。
- 训练阶段由轻量 **World Representation Head** 将其解码为可微渲染的 **Current World** 与 **Future Prediction**，在共享高斯基元上提供密集几何与时序监督；推理阶段丢弃该头与所有辅助分支，仅保留 20 个 token。
- 通过**静态-动态因子化**（static-dynamic factorization）保留持久结构，将预测容量集中到交互相关区域。

### 关键技术细节

- **Token 与主干融合**：在 PaliGemma prefix 中追加 Z_S ∈ ℝ^(16×d) 与 Z_P ∈ ℝ^(4×d)；状态 Token 保留 4×4 粗空间结构并接受空间/光线嵌入。PaliGemma 联合上下文化后得到 (H_VLt, H_St, H_Pt)，Action Expert 通过**原生注意力通路**直接消费。
- **Current World 重建**（式 5–10）：
  - 几何-外观分支解耦：几何分支预测度量深度与高斯属性 (尺度、旋转、不透明度)，外观分支在 stop-gradient 几何特征 + 图像特征融合后预测球谐系数。
  - 多视图度量反投影 U(·) 得到高斯中心 μ_i，组成 G_t = {(μ_i, s_i, q_i, α_i, c_i)}。
  - 通过可微 Gaussian Splatting 渲染 (Î_t, D̂_t, Â_t)，损失 L_cur = λ_rgb L_rgb + λ_depth L_depth + λ_α L_α + λ_reg L_reg。
- **耦合未来预测**（式 11–15）：
  - 复用 Current World 作为共享模板，仅预测**水平位移残差** Δμ_i^h = H_Δ(F_Gt,i, H_Pt,h, e_h)。
  - 静态-动态门控 m_i^h ∈ [0,1] 用于抑制静态区域运动，μ_{t+h}^i = μ_t^i + m_i^h Δμ_i^h。
  - 用各水平对应的相机内外参 (K_{t+h}, T_{t+h}) 渲染，避免视点变化被误吸为物理运动。
  - 损失 L_fut = Σ_h w_h (λ_rgb L_rgb^h + λ_depth L_depth^h + λ_flow L_flow^h + λ_stat L_stat^h)。

  - 不再需要 VGGT/TGE 前缀构造通路，也无在线高斯解码/渲染/未来展开。

## 六、主要结论与发现

- **LIBERO**：GaussianDream++ 平均成功率 **98.6%**，比匹配协议下 π0.5 复现 +1.7 pp，比 GaussianDream +0.2 pp（基线已接近饱和）。
- **LIBERO-Plus**：Overall **87.8%**，相对 GaussianDream +0.8 pp，相对 π0.5 复现 +2.3 pp。
  - Camera：73.2 → 80.1（+6.9 pp vs π0.5 复现；+2.8 pp vs GaussianDream）。
  - Layout：87.7 → 90.0（+2.3 pp vs π0.5 复现；+1.6 pp vs GaussianDream）。
  - Noise：89.9 → 94.2。
  - Robot：77.9 → 73.0，**略低于 π0.5 复现**，提示本体泛化仍是独立挑战。
- **实机**：池化成功率 29.2% → **52.5%**（+23.3 pp）；Bowl-Proximity 25.0% → 46.7%，Eggplant-to-Pink-Plate 33.3% → 58.3%；Camera 与 Layout 条件下均显著提升。
- **效率**：本地匹配部署下 latency 从 286 ms → 330 ms（+44 ms，约 1.15×），不再运行 VGGT/TGE，也无在线高斯解码/渲染/未来展开。
- **消融结论**：
  - 仅增加 token 容量（无高斯监督）只能把 Overall 从 85.5% → 86.3%，证明增益主要来自**结构化高斯监督**而非纯容量。
  - 度量深度是最强几何约束；3D flow 主要影响 Noise/Layout；RGB 影响 Lighting/Background；α 监督影响可见性敏感偏移。
  - 当前世界、未来预测、耦合解码、静态一致性逐项叠加，逐步收敛到 87.8%。

## 七、优点

- **设计思路清晰且工程友好**：将世界监督完全内化为策略原生 token，去除运行时 VGGT/TGE 与在线高斯解码，部署开销极低（仅 +44 ms）。
- **角色分离的 token 化世界表征**：World State 与 World Prediction 分工明确，配合静态-动态门控，使预测容量集中在交互相关区域，避免在静态背景上浪费。
- **非对称训练-部署范式**：训练时享受稠密高斯监督（RGB、深度、不透明度、3D flow、静态一致性），部署时完全卸载辅助模块，是“训练时重、推理时轻”的典型范本。
- **评测较为充分且规范**：明确划分匹配协议与已发表结果、引入 LIBERO-Plus 七项偏移、设计结构与监督两类消融、补充实机任务与延迟测量。
- **定性可视化**：展示 Current Reconstruction 与 Future Prediction，有助于理解所学表征的物理意义。

## 八、不足与局限

- **未披露算力与训练细节**：GPU 型号/数量、训练时长、数据规模、批大小等关键信息缺失，难以评估可复现成本与方法的可扩展边界。
