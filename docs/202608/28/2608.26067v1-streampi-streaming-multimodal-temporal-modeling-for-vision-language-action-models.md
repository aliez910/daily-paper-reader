## 摘要
视觉-语言-动作（VLA）模型已在机器人操作任务中展现出有效性，然而诸如 pi0.5 等当前最先进的模型仍采用单帧范式，限制了其保留历史观测信息并进行精确空间感知的能力。本文提出 StreamPI，一个流式多模态时序建模框架，能够在不引入任何额外参数的情况下为单帧 VLA 赋予时序推理能力。其核心设计之一是指令锚定的时序建模：它将每一对（视觉观测、语言指令）视为一个原子时序单元，在每个单元内部采用双向注意力以实现跨模态融合，而在单元之间采用因果注意力以保留自回归流式推理特性。这确保了语言指令在任务执行过程中充当持续的语义锚点。为了弥合同步训练与异步真实机器人部署之间的差距，我们引入了一种随机间隔流式训练策略：合适的帧间间隔（例如每 3 帧）有助于实现更快、更平滑的动作执行；在此基础上对间隔进行随机化处理，则进一步提升模型对帧时序扰动的鲁棒性，从而支持实际场景中的异步部署。此外，借助 LLM 主干网络的长度外推能力，StreamPI 能够无缝继承预训练的单帧权重，并灵活支持单帧与多帧推理。在涵盖记忆依赖与精确感知场景的真实机器人任务以及仿真基准 LIBERO 上的实验表明，StreamPI 在多样化任务中均优于 pi0.5。

## Abstract
Vision-Language-Action (VLA) models have demonstrated effectiveness in robot manipulation, yet state-of-the-art models such as pi0.5 operate under a single-frame paradigm, limiting their ability to retain past observations and develop precise spatial perception. In this paper, we propose StreamPI, a streaming multimodal temporal modeling framework that equips single-frame VLA with temporal reasoning capability without introducing any additional parameters. One core design is instruction-anchored temporal modeling. It treats each (visual observation, language instruction) pair as an atomic temporal unit: bidirectional attention within each pair enables cross-modal fusion, while causal attention across pairs preserves autoregressive streaming inference. This ensures the language instruction serves as a persistent semantic anchor throughout task execution. To bridge the gap between synchronous training and asynchronous real-robot deployment, we introduce a andom-interval streaming training strategy: a proper inter-frame interval (e.g., every 3 frames) enables faster and smoother action execution. Beyond this, randomizing the interval further improves robustness to frame-timing perturbations, supporting asynchronous deployment in practice. Furthermore, by leveraging the length extrapolation capability of the LLM backbone, StreamPI seamlessly inherits pretrained single-frame weights and supports flexible single-frame and multi-frame inference. Experiments on real-robot tasks spanning memory-dependent and precise perception scenarios, as well as the simulation benchmark LIBERO, demonstrate that StreamPI outperforms pi0.5 across diverse tasks.

# StreamPI 论文结构化总结

## 一、核心问题与研究动机

- **研究背景**：视觉-语言-动作（VLA）模型（如 π0/π0.5、OpenVLA 等）已成为通用机器人操作的统一框架，将感知、语言理解与动作生成整合于端到端架构中。
- **核心痛点**：当前主流 VLA（如 π0.5）采用**单帧推理范式**，每个动作仅由当前帧观测预测，**无法访问任何历史上下文**，带来两个根本缺陷：
  - **记忆能力缺失**：无法解析单帧中天然模糊的任务（如"找出藏球的杯子"、"抓取运动目标"）。
  - **精确空间感知不足**：缺乏跨帧几何线索聚合，难以支撑亚厘米级精度的抓取/插入。
- **现有方案的不足**：窗口式多帧 VLA 方法将 K 帧同时拼接输入，导致**序列长度线性增长、推理延迟不可接受**，且视觉令牌累积会**稀释语言指令信号**（"指令遗忘"问题），同时引入额外视频编码器会**破坏预训练特征分布**。
- **四个待解挑战**：计算开销、指令遗忘、训练-部署失配（同步帧 vs 异步实际帧率）、表征破坏。

## 二、方法论

### 1. 整体思路
- 提出 **StreamPI**：一种**流式多模态时序建模框架**，在不引入任何新参数的前提下，为单帧 VLA 注入时序推理能力。
- 四大设计支柱：流式推理、指令锚定时序建模、随机间隔训练、零参数扩展。

### 2. 指令锚定时序建模（Instruction-Anchored Temporal Modeling）
- **原子时序单元**：将每一时刻的多视角视觉观测 $V_t=\{v_t^f, v_t^l, v_t^r\}$ 与语言指令 $l_t$ 打包为一个不可分割的单元 $u_t = (V_t, l_t)$。
- **块状注意力结构**：
  - **单元内双向注意力**（Intra-pair Bidirectional）：每个 $u_\tau$ 内图像与文本 token 充分双向融合，得到语义对齐表征 $h_\tau = \text{Attn}_{\text{bi}}(V_\tau, l_\tau)$。
  - **单元间因果注意力**（Inter-pair Causal）：跨单元采用因果掩码，$o_t = \text{Attn}_{\text{causal}}(h_{t-T+1}, \dots, h_t)$，保证流式自回归推理。
- **关键优势**：语言指令作为**持续语义锚点**绑定到每帧观测，从根本上避免长程任务中的指令遗忘。

### 3. 零参数时序扩展
- 上述层次化注意力模式**完全通过重组注意力掩码实现**，无需新参数。
- 利用 LLM 主干网的**长度外推能力**（类比 LongLoRA、StreamingLLM），直接继承 π0.5 全部预训练权重。
- 仅需扩展输入 token 序列与位置编码即可支持多帧。

### 4. 随机间隔流式训练（Random-Interval Streaming Training）
- **帧间隔随机化**：以基础间隔 $\bar{\delta}$ 为中心施加扰动 $\epsilon \sim U(-\Delta, +\Delta)$，得到 $\delta = \bar{\delta}+\epsilon$，剪裁至 $[\delta_{\min}, \delta_{\max}]$。
- **时序掩码**：随机遮蔽最早 $k$ 帧（$k \in \{0, \dots, T-1\}$），模拟流式推理的渐进观测模式。
- **目的**：桥接训练时的固定帧率与部署时的异步可变帧率，提升鲁棒性。

### 5. 流式推理（KV Cache 机制）
- 算法 1 给出伪代码：仅编码新到达帧 $u_{t_n}$，与缓存中的历史表征 $\{h_{t_0}, \dots, h_{t_{n-1}}\}$ 做交叉注意力。
- 缓存满则滚动刷新，避免冗余重计算。
- 实测：单帧 94.4 ms、3 帧 97.9 ms、5 帧 103.6 ms、10 帧 117.9 ms（RTX 4090 上），开销极低。

## 六、主要结论与发现

- **真实机器人**（相对 π0.5）：
  - Rolling Object Grasping：26.7% → 63.3%（**+36.6%**）。
  - Shell Game：46.7% → 80.0%（**+33.3%**）。
  - Pen Insertion：40.0% → 66.7%（**+26.7%**）。
  - Cup Insertion：60.0% → 92.0%（**+32.0%**）。
- **LIBERO**（T=5 vs π0.5）：平均 96.9% → 98.3%（+1.4%），其中 Long +2.6%、Goal +2.8%；Spatial 无提升。
- **CALVIN**：平均序列长度 4.313 → 4.547，第 5 步成功率 79.5% → 85.0%，显著优于 MemoryVLA（69.4%）。
- **消融关键发现**：
  - 单元内双向注意力显著优于因果注意力（T=5 时 Long +5.6%）。
  - 单元间因果聚合随 T 增大增益更明显（T=1→5 平均 +1.8%）。
  - 随机间隔训练优于固定间隔（T=3: 96.4→97.5；T=5: 97.0→98.3）。
  - T=5 训练的模型可零成本迁移到 T=3 推理，性能几乎不损。
- **效率结论**：T=5 推理仅比单帧多 9.2 ms，验证流式设计的实用性。

## 七、优点与亮点

- **零参数增量**：通过纯注意力掩码重塑实现时序建模，**完整保留预训练 VLA 的视觉-语言表征**，避免视频编码器引入的表征破坏问题。
- **指令锚点设计**：单元内双向注意力 + 跨单元因果注意力的层次结构，**优雅地解决了指令遗忘问题**，区别于 MemoryVLA 等解耦方法。
- **训练-部署对齐**：随机间隔采样 + 时序掩码直接针对真实部署中的异步帧率扰动，提升实际可用性。
- **流式 KV Cache 机制**：延迟近乎常数，支持长程任务实时控制。
- **即插即用**：借助 LLM 长度外推能力无缝继承 π0.5 权重，无需修改架构即可切换单/多帧推理。
- **实验验证多维度**：仿真 + 真机 + 消融 + 定性可视化交叉佐证。

## 八、不足与局限

- **训练成本**：处理超长时序时仍需加载所有帧，长时域（>100 帧）训练代价不可接受，作者自承。
- **异步鲁棒性局限**：随机间隔训练**未完全解决极端异步**情况（如长时丢帧、突发延迟）。
- **真实机器人对比基线单一**：仅与 π0.5 对比，未与 MemoryVLA、CronusVLA 等多帧 VLA 在同硬件上同任务比较，难以判定相对优劣。
- **数据集覆盖有限**：LIBERO 已接近饱和，提升空间小；CALVIN 任务结构与现实差距较大；真机任务仅 4 类且为实验室环境，未在杂乱家居、工业等场景验证。
- **统计严谨性不足**：真实机器人 trial 数较少，未报告多次重复实验的均值置信区间，结论可能受初始状态噪声影响。
