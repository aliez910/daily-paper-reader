## 摘要
长时程机器人操作要求机器人既要可靠地执行各项技能，又要在长时间跨度内将其连贯地衔接起来。大多数分层视觉-语言-动作（VLA）模型通过单次前向传播完成每一次此类决策，缺乏为困难或关键的抉择分配额外计算资源的机制。我们提出 $τ_0$-VLA——一种分层机器人基础模型，通过世界模型引导的测试时计算，将高层子任务生成建模为一个可扩展计算规模的推理问题。在每一步推理中，高层策略利用执行记忆生成子任务，并在必要时对多种候选方案进行搜索，最终确定输出；随后，低层策略在多种机器人本体上执行所生成的子任务。该策略基于 40,115 小时的多模态异构真实世界数据进行多模态协同训练。在域内和分布偏移场景下，分配额外测试时计算显著提升了下一子任务的预测准确率，且这些性能增益进一步转化为长时程机器人操作任务中更高的闭环成功率。

## Abstract
Long-horizon robot manipulation requires a robot to both execute individual skills reliably and sequence them coherently over extended tasks. Most hierarchical vision-language-action (VLA) models make each such decision with a single forward pass, leaving no mechanism to allocate additional computation to difficult or consequential choices. We introduce $τ_0$-VLA, a hierarchical robot foundation model that formulates high-level subtask generation as a compute-scalable inference problem through world-model-guided test-time computation. At each inference step, the high-level policy uses execution memory to generate a subtask and, when needed, searches over alternatives before committing to its output. A low-level policy then executes the generated subtask across multiple robot embodiments. The policy is trained on 40,115 hours of heterogeneous real-world data with multimodal co-training. Across in-domain and distribution-shifted settings, allocating additional test-time computation substantially improves next-subtask prediction accuracy, and these gains translate into higher closed-loop success on long-horizon robot manipulation tasks.

# τ₀-VLA 论文总结

## 一、核心问题与研究动机

长时程机器人操作（如清洁房间、烹饪、制作奶茶等）需要机器人在分钟到小时级别的时间跨度内连贯地完成多个子任务，且每个决策都具有"不可逆性"：错误的子任务选择即使被精确执行也无法挽回。研究指出，当前分层视觉-语言-动作（VLA）模型在高层决策上普遍采用**单次前向推理**机制，缺乏针对困难或关键决策分配额外计算的途径，这构成长时程执行的主要瓶颈。

论文的核心论点是：**高层子任务生成应当被建模为一个可扩展计算量的推理问题**，允许机器人根据决策难度动态增加推理预算，类似于大语言模型中的测试时计算（Test-Time Computation, TTC）范式。

## 二、方法论

### 2.1 整体架构
τ₀-VLA 是一个分层系统，包含高层策略（High-Level Policy）和低层策略（Low-Level Policy）：
- **高层策略**：维护执行记忆（Execution Memory），生成当前子任务；可在不确定时触发测试时搜索
- **低层策略**：在统一 40 维状态-动作空间中跨多种机器人本体执行子任务

### 2.2 高层策略（关键创新）
高层策略由四个组件构成：

1. **提案模型 P**：基于 Qwen3.5-9B，根据上下文 $h_t = (\ell, M_{t-1}, z^*_{t-1}, o_t)$ 生成直接提案 $z^{dir}_t$ 并更新执行记忆 $M_t$；其 token 置信度同时用于自适应路由判断

2. **世界模型 W**：基于 Step1X-Edit，给定头部相机图像 $\tilde{o}$ 和候选子任务 $z$，预测任务完成后的终端观测图像 $\hat{o}$

3. **价值模型 V**：将候选质量评估建模为五级多选题 VQA（从"明显错误"到"明显正确"，映射到 [0.05, 0.95] 标量分数），输入为全局指令、候选子任务、想象终端图像

4. **反思模型 F**：基于观察对齐的真实上下文与保留分支摘要，生成最终子任务 $z^*_t$（可与保留提案重合，但不局限于候选集）

### 2.3 测试时搜索流程（propose–predict–evaluate loop）
- **初始化**：根分支 $b_{root}$ 路径为空，初始分数为 0
- **每层扩展 d**：对每个保留分支独立调用提案模型 N 次，生成 N 个候选
- **预测与评分**：对每条候选分支 $(\hat{o} = W(\tilde{o}, z), v = V(\ell, z, \hat{o}))$，累计得分 $S(b \oplus z) = S(b) + v$
- **剪枝**：全局保留 Top-B 分支，按路径 $\rho$、终端图像 $\hat{o}$、累计分数 $S$ 汇总为 $C_t$
- **递归深度**：D 层后由反思模型 F 生成最终子任务

### 2.4 自适应路由
基于提案模型的 token 概率均值 $u^{all}_t$ 和 memory 字段内 logit margin 均值 $u^{mem}_t$，通过阈值 $\delta_{all}$、$\delta_{mem}$ 决定走"快速通道"（直接采用 $z^{dir}_t$）还是 TTC 路由；该决策复用前向传播得到的统计量，无需额外推理调用。

### 2.5 低层策略
- **初始化**：Qwen3.5-2B + Mixture-of-Transformers (MoT) 动作专家
- **统一空间**：40 维状态-动作空间，涵盖左/右末端执行器、双臂关节、夹爪、腰部、移动底座，通过 per-sample mask 处理不同本体
- **动作生成**：采用掩码条件流匹配（Masked Flow Matching），每个 chunk 联合预测 H 个时间步的速度场（$\tau=1$ 为噪声，$\tau=0$ 为干净动作）
- **三阶段训练**：知识隔离协同训练 → 端到端协同训练 → 任务特定微调

### 2.6 执行记忆的可纠错训练
通过对已有演示的记忆扰动（"落后"、"超前"、"失败错误反思"等五种实例家族，详见 Table VI），让高层策略学会在记忆与观测不一致时进行修复，无需额外人工标注。

### 2.7 异步双系统部署
由于高层推理慢于底层控制周期（~30 Hz），采用异步流水线：后台 worker 持续刷新缓存中的子任务（~1 Hz），控制循环读取缓存即可，无需阻塞等待。

## 六、主要结论与发现

1. **TTC 显著提升子任务预测精度**：在 4 个评估设置下 TTC 均优于 Plan Once 和 Best-of-N（OOD Book Organization：74.0% vs 50.0% vs 57.5%）
2. **预测精度提升转化为闭环成功率提升**：Table III 中 TTC 在 Make Milk Tea（5/10 → 7/10）、Book Organization（6/10 → 9/10）、Clean Room（5/10 → 7/10）上均带来明显增益
3. **计算-精度呈饱和曲线**：低算力时增益陡峭，随后逐渐平缓，存在最优预算点
4. **执行记忆对长时程任务至关重要**：尤其在跨房间切换、不可见状态变化（如加盐）等场景中，记忆机制消除了重复或遗漏错误
5. **分层系统普遍优于直接执行**：在所有长时程任务上，分层系统（Plan Once，无搜索）已经比 direct execution 表现更好，证明了记忆与子任务分解本身的收益
6. **跨本体低层策略有效**：在 Collect Laundry 与 Tidy Makeup Table 上 τ₀-VLA Direct Execution 取得 SOTA 表现（Collect Laundry 10/10，Makeup Puff 10/10）
7. **Best-of-N 增益有限**：单步选择缺少 TTC 的多步展开与反思机制，因此相对于 Plan Once 的增益显著小于 TTC

## 七、优点与亮点

1. **计算可扩展性视角新颖**：将测试时计算从动作级别上移到子任务级别，定位介于"纯语言推理"和"动作级搜索"之间的恰当抽象层级
2. **执行记忆可纠错机制**：通过程序化扰动生成的训练样本，使高层策略能自动纠正落后、超前、错误等记忆异常，无需额外人工标注
3. **闭环反思 + 多步束搜索**：反思模型不局限于候选集合，可基于分支摘要重新生成，避免了"束搜索即终点"的局部最优问题
4. **统一动作空间与 MoT 架构**：单一模型支持固定底座、双臂协调、移动全身控制三种本体
5. **细粒度评估方法**：基于前驱图的 Progress 评分能区分"重复尝试"、"跳过"、"部分完成"，避免简单的 0/1 评分掩盖信息
6. **OOD 验证**：通过 Book Organization 任务区分训练集内外的初始排列，对泛化能力进行了直接测试
7. **异步部署工程方案**：双系统异步流水线使得慢速高层决策不阻塞高频底层控制，方案可落地
8. **数据标注流程清晰**：利用 Gemma4-31B-it 作为自动标注器，并设计了三层污染过滤（跨任务污染、空子任务、记忆污染），通过率-保留率权衡分析较为详尽
