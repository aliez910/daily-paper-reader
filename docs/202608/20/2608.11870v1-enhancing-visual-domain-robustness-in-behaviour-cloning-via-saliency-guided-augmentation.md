## 摘要
在基于视觉的行为克隆（BC）中，传统图像增强方法（如随机裁剪和颜色抖动）在显著的视觉域偏移下往往表现不足，这些偏移包括阴影、干扰物和背景的变化。基于叠加的增强方法通过混合域内与域外图像，在提升计算机视觉泛化能力方面展现出潜力，但由于必须保留任务关键语义、时空关系以及智能体与目标的交互，其在行为克隆中的适用性仍不确定。为此，我们提出了 RoboSaGA——一种面向基于视觉的行为克隆的显著性引导增强方法，属于叠加增强家族。RoboSaGA 利用基于策略的显著性在像素级别动态调整增强强度，从而在任务无关区域进行激进增强的同时保留任务关键信息。它能够无缝集成到现有架构中，无需对结构进行修改，也无需额外的学习目标。在仿真和真实环境中的实验表明，RoboSaGA 在保持域内性能的同时，显著提升了对视觉域偏移的鲁棒性，包括干扰物与背景变化，以及光照与阴影变化。代码已开源：https://github.com/Zheyu-Zhuang/RoboSaGA。

## Abstract
In vision-based behavior cloning (BC), conventional image augmentations such as Random Crop and Color Jitter often fall short under substantial visual domain shifts, including changes in shadows, distractors, and backgrounds. Superimposition-based augmentations, which blend in-domain and out-of-domain images, have shown promise for improving generalization in computer vision, but their suitability for BC remains uncertain because task-critical semantics, spatiotemporal relationships, and agent-target interactions must be preserved. To address this, we introduce RoboSaGA, a Saliency-Guided Augmentation method within the superimposition family tailored for vision-based BC. RoboSaGA dynamically adjusts augmentation intensity at the pixel level using policy-driven saliency, enabling aggressive augmentation in task-irrelevant regions while preserving task-critical information. It integrates seamlessly into existing architectures without requiring structural modifications or additional learning objectives. Experiments in both simulated and real-world settings show that RoboSaGA preserves in-domain performance while substantially improving robustness to visual domain shifts, including distractor and background changes, as well as lighting and shadow variations. Code is available at https://github.com/Zheyu-Zhuang/RoboSaGA.

# 论文总结：RoboSaGA——基于显著性引导增强的视觉行为克隆域鲁棒性方法

## 1. 核心问题与研究动机

- **核心问题**：基于视觉的行为克隆（BC）在真实部署中常遭遇显著的视觉域偏移（Visual Domain Shifts, VDS），包括光照/阴影变化、干扰物出现以及背景纹理变化，导致从有限演示数据中学习的策略泛化能力急剧下降。
- **现有方法的局限**：
  - **传统增强**（Random Crop、Color Jitter）虽能改善域内性能，但在背景与干扰物等大幅度视觉变化下仍显著退化。
  - **叠加式增强**（Superimposition）在计算机视觉中已被证明有效，但在 BC 中应用受限，原因在于 BC 需同时保留任务关键语义、时空关系以及智能体-目标的交互信息。
- **研究意义**：缓解真实机器人演示数据稀缺与视觉多样性不足之间的矛盾，使 BC 策略在不受控环境中具备更强的鲁棒性。

## 2. 方法论：RoboSaGA（Saliency-Guided Augmentation）

### 核心思想
- 通过策略自身回传的显著性图作为**逐像素融合因子**，在任务无关区域施加激进叠加，在任务关键区域保持保守，从而在"破坏性增强"与"任务语义保留"之间取得平衡。

### 关键模块

- **叠加公式**（通用形式）：
  $$x^* = M \odot x + (1 - M) \odot x^O$$
  其中 $M \in \mathbb{R}^{h \times w}$ 为融合矩阵，$x^O$ 为域外图像（来自 MSCOCO 5000 张 + 合成图 1000 张）。

- **显著性提取（Saliency Extraction）**：
  - 使用 **FullGrad** 从视觉编码器 $f_\theta(x)$ 的输出特征反向传播梯度至输入分辨率，结合权重与偏置，生成比 Grad-CAM/SmoothGrad 更清晰锐利的显著性图。
  - **显著性裁剪（Saliency Clipping）**：
    $$s^v_i = \min(g^v_i, \lambda), \quad \lambda = 0.8$$
    - 裁剪阈值 $\lambda$ 允许在显著性最高区域也施加微弱的叠加，从而增强对背景变化的鲁棒性。

- **选择性增强**：
  - 每个训练 batch 中仅对 $\alpha = 50\%$ 的轨迹进行增强（避免过激进增强导致收敛困难）。
  - 每个样本独立增强（实验表明轨迹内共享参数与独立增强无显著差异）。

- **全局显著性缓冲（Global Saliency Buffer）**：
  - FullGrad 计算昂贵，引入 buffer 缓存历史显著性图，按更新频率排序后仅对最久未更新的 $\beta = 10\%$ 样本重算。
  - 显著性图以 8-bit 单通道存储于 $84 \times 84$ 分辨率下，10000 样本约占用 67 MB 显存。
  - 前 $\gamma = 10$ 个 epoch 为 warm-up 期，buffer 返回全 1 图，待编码器学习到任务相关特征后再启用强增强。
  - 实验表明：使用 buffer 在几乎不损失性能的情况下，将每 batch 增强处理时间从 0.70s 缩短至 0.22s（约 1/3）。

- **算法流程（Algorithm 1 概述）**：
  1. 对每个 batch $M$ 中的每个视觉编码器 $v$：
  2. 按更新频率排序 batch 索引，选取底部 $\beta$ 个计算新显著性并更新 buffer；
  3. 均匀采样 $\alpha$ 个轨迹索引，从 buffer 中取出对应显著性图；
  4. 根据显著性图叠加 OOD 图像，生成增强 batch $M^*$；
  5. 使用 $M^*$ 优化策略。

### 与现有方法的关系
- **Guided Erase**（变体）：将显著性图二值化（阈值 0.5）后做擦除式增强——类似 KeepAugment，但显著性来自视觉编码器而非分类 logits，且区域大小自适应。
- **Random Overlay**（变体）：将逐像素融合矩阵替换为全局常数（0.5）——剥离显著性引导后的基线。
- RoboSaGA = 显著性引导 + 软融合 = Erase 与 Overlay 的协同。

### 集成特性
- 无需新增可学习模块、无需特殊损失函数；
- 模块化适用于多相机视角；
- 兼容 BC-MLP、BC-RNN（[7]）、Diffusion Policy（[2]）三种策略架构。

## 6. 主要结论与发现

- **传统增强的局限**：Color Jitter 能部分缓解光照变化（差距 0.33→0.10 量级），但在阴影下仍有 0.33 的差距；对背景与干扰物的改善仅约 8%。
- **叠加增强的有效性**：
  - Random Overlay 即能将仿真背景+干扰物差距从 0.60 降至 0.24，真实环境从 0.71 降至 0.18；
  - 所有叠加方法在光照/阴影下差距均低于 0.1。
- **RoboSaGA 的进一步提升**：
  - 仿真：相对 Random Overlay 再降低 41.6% 的性能差距（最终 0.14）；
  - 真实：再降低 72%（最终 0.05），三种策略均一致受益；
  - Guided Erase 擅长对抗干扰物（0.06），但背景鲁棒性不足（0.55）；RoboSaGA 兼具两者优势（背景 0.13、干扰物 0.06）。
- **表示学习对比**：在有动作标签的 BC 场景下，SODA 的一致性损失相对直接训练带来的收益边际，平均仅约 0.02–0.04 的差距改善。
- **策略差异**：Diffusion Policy 在域偏移下退化最小（自身差距 0.13 vs BC-RNN 0.15 vs BC-MLP 0.15），但所有策略均一致地从 RoboSaGA 中获益。
- **显著性图的特征**：BC-MLP（无历史）产生的显著性图更接近人类直觉；BC-RNN 与 Diffusion Policy 的显著性图会出现"人类认为无关区域被聚焦"的现象，作者将其归因于多感官输入、历史依赖、多视角融合的复合作用。

## 7. 优点与亮点

- **方法设计亮点**：
  - 完全即插即用：无需修改网络结构或损失函数；
  - 像素级软融合，介于"擦除式"与"恒定叠加式"之间，兼具两者优势；
  - 显著性裁剪机制允许在任务区域也施加微弱叠加，避免对任务语义的过度保护；
  - 模块化适配多相机视角与多种 BC 策略。
- **工程亮点**：
  - Global Saliency Buffer 显著降低 FullGrad 计算开销（约 3 倍加速），同时几乎不损失性能；
  - 8-bit 单通道存储控制显存占用；warm-up 策略保证编码器先习得任务知识。
- **实验亮点**：
  - 同时覆盖仿真（4 任务）与真实机器人实验，且评估策略涵盖 MLP、RNN、Diffusion 三类主流架构；
  - 引入"性能差距"作为统一评估指标，便于跨方法公平比较；
  - 通过显式消融清楚说明 Erase 与 Overlay 各自的优劣边界。

## 8. 不足与局限

- **计算开销**：FullGrad 仍比训练本身慢约 1.5 倍；对更大编码器尚不友好，需要借助 mid-layer 近似或离线 buffer + 知识蒸馏等扩展方案（论文已指出但未实现）。
- **任务覆盖局限**：
  - 真实世界实验仅 1 个 3-DoF pick-and-place 任务，结论的推广性需更多任务验证；
  - Transport 任务下 BC-MLP/BC-RNN 在所有方法下表现均不理想，作者归因于第二视角中机械臂占比过大、目标像素密度低，但未做针对性改进。
- **显著性解释性的局限**：
  - 对于具有历史依赖的策略（BC-RNN、Diffusion Policy），显著性图与人类直觉常不一致，作者仅作观察未深入分析；
  - 这种不对齐是否会在更复杂任务中引发策略失效，尚待验证。
- **超参数与稳健性**：
  - 显著性裁剪阈值 $\lambda=0.8$、buffer 更新比例 $\beta=10\%$、增强比例 $\alpha=50\%$ 等超参数固定于所有任务，未提供敏感度分析；
  - OOD 图像来源固定为 MSCOCO + 合成图，未考察不同 OOD 来源的影响。
- **OOD 图像域选择偏差**：所选 MSCOCO 与合成图主要覆盖自然场景与几何/纹理图案，可能与工业、医疗等垂直领域的真实部署场景存在分布差异，迁移性未做评估。
