## 摘要
视觉-语言-动作（VLA）模型近期在机器人操作任务中取得了令人瞩目的性能。然而，现有基准主要在静态操作任务上评估泛化能力，在很大程度上忽略了动态交互场景。为弥补这一不足，我们提出了ReflexBench，一个面向反应关键型操作任务的基准。ReflexBench包含六个动态任务，并引入了一个评估框架，该框架将仿真器步进与机器人控制解耦，同时支持同步和异步推理下的可配置延迟。在ReflexBench的基础上，我们提出了ReflexVLA，一种专为反应关键型操作任务设计的高效VLA模型，无需大规模机器人数据预训练。ReflexVLA通过潜在未来预测和视觉骨干网络中的多帧时序融合来增强时序推理能力，同时通过批量视觉编码和CUDA Graph回放来降低部署延迟。实验表明，ReflexVLA在持续提升动态操作性能的同时，在标准静态操作基准上保持了具有竞争力的精度，且真实世界实验进一步验证了其在实际部署条件下的有效性。项目网站：https://reflexvla.github.io

## Abstract
Vision-Language-Action (VLA) models have recently achieved promising performance in robotic manipulation. However, existing benchmarks mainly evaluate generalization on static manipulation tasks and largely overlook dynamic interaction scenarios. To address this gap, we present ReflexBench, a benchmark for reaction-critical manipulation. ReflexBench contains six dynamic tasks and introduces an evaluation framework that decouples simulator stepping from robot control while supporting configurable latency under synchronous and asynchronous inference. Building upon ReflexBench, we propose ReflexVLA, an efficient VLA model designed for reaction-critical manipulation without large-scale robot-data pretraining. ReflexVLA enhances temporal reasoning through latent future prediction and multi-frame temporal fusion within the vision backbone, while reducing deployment latency through batched visual encoding and CUDA Graph replay. Experiments show that ReflexVLA consistently improves dynamic manipulation performance while maintaining competitive accuracy on standard static manipulation benchmarks, and real-world experiments further demonstrate its effectiveness under practical deployment conditions. Project website: https://reflexvla.github.io

## 2. 论文提出的方法论

### 2.1 ReflexBench：延迟感知的动态操控基准

- **六个反应关键型任务**：
  - 传送带分拣（Conveyor Belt Pick-and-Place）
  - 接球（Ball Catching）
  - 打地鼠（Whack-a-Mole）
  - 滚球拦截（Rolling Ball Interception）
  - 抛球入桶（Ball Throwing）
  - 旋转插孔（Rotating Peg Insertion）
- **数据收集**：采用基于规划的分阶段（subgoal）流水线，利用实时位置/速度预测未来轨迹；复杂交互场景使用任务特定的强化学习策略生成演示。
- **延迟感知评估**：
  - 解耦仿真器步进与机器人控制，模拟真实世界推理—执行延迟；
  - 支持**同步推理**（推理期间机器人空闲）与**异步推理**（推理与执行重叠）；
  - 通过 Real-Time Factor（RTF = t_sim / t_wall）将真实推理延迟折算为仿真延迟；
  - 用户可手动指定延迟值，便于系统性分析。

### 2.2 ReflexVLA 模型三大核心设计

#### (1) 潜未来预测（Latent Future Prediction）
- 在多模态序列中追加 H 个可学习的"未来 token"，其中 H 等于动作 chunk 大小；
- 使用**冻结的 DINOv3 编码器**提取未来观测的语义潜特征 y_{t+i}；
- 模型从 i-th 未来 token 的隐藏表示经投影头预测 ŷ_{t+i}，与冻结 DINOv3 特征对齐；
- 损失函数采用**掩码余弦相似度**：
  
  $$L_{future} = \frac{\sum_{i=1}^{H} m_i [1 - \cos(\hat{y}_{t+i}, y_{t+i})]}{\sum_{i=1}^{H} m_i}$$
  
- 总损失：L = L_act + λ_future · L_future（λ_future = 0.05）
- 关键设计：冻结目标避免表征空间不稳定；预测语义潜空间而非像素，降低开销。

#### (2) 多帧时序融合（Multi-Frame Temporal Fusion）
- 在**视觉骨干中间层特征**（而非最终层）上做时序融合，保留更丰富的局部与运动信息；
- 对每个视图 v 与每个 patch 位置 p，沿 T 帧构建时序轨迹；
- 操作流程：LayerNorm → 下投影（加时序位置编码）→ 因果多头注意力 → 上投影 → 与当前帧最终特征相加；
- 因果掩码防止信息泄露，保证在线部署一致性；
- 关键优势：**送入语言模型的视觉 token 数量与单帧设置相同**，避免语言模型侧的二次复杂度膨胀。

#### (3) 推理延迟优化（Inference Latency Optimization）
- **批量视觉编码**：将 V×T 张图像合并为单次前向，替代 V×T 次独立推理，显著减少框架开销；
- **CUDA Graph 回放**：将完整推理流水线（视觉编码、时序融合、多模态投影、语言模型推理、动作预测）捕获为静态计算图 G，新观测拷贝到预分配缓冲区后直接重放，避免重复内核调度；
- 不改变策略架构与学习目标，纯系统级加速。

## 6. 主要结论与发现

- **ReflexVLA 在 ReflexBench 上取得 50.4% 平均成功率**，超过所有基线（包括 4B 的 PUMA 和 7B 的 OpenVLA-OFT），相对 backbone（VLA-Adapter）的 30.3% 提升约 20 个百分点；
- **LIBERO 上仍保持 97.2% 的平均成功率**，与最佳 VLA 几乎持平，证明未来预测与时序融合模块并未牺牲静态任务能力；
- **冻结的 DINOv3 作为未来预测目标**显著优于可训练目标（62.8% vs 4.9%，提升 26.0%）；
- **中间层特征做时序融合**优于最终层（71.7% vs 68.2%），证明语义过深的特征不利于建模局部运动；
- **批量编码 + CUDA Graph** 将推理延迟从 125.1 ms 降至 65.0 ms（约 48% 加速），同时成功率提升 2.1%；
- **推理范式结论**：高频率异步推理 + 较大 chunk size + 较短的 action horizon 组合对动态操控最优；
- **真实世界**：ReflexVLA 在 Conveyor Belt Pick-and-Place 上 16/20 成功，PressButtons 30 秒内平均按 22.5 个按钮，CatchBalls 10 球接 6.7 球，优于 SmolVLA 与 PUMA。

## 7. 优点与亮点

- **问题定位精准**：明确指出"未来感知"与"低延迟推理"在现有 VLA 研究中割裂的不足，提出一体化解决方案；
- **基准设计严谨**：ReflexBench 将仿真器步进与机器人控制解耦，支持 RTF 折算的延迟注入，比传统"暂停推理"方式更贴近真实部署；
- **设计取舍巧妙**：
  - 在潜空间做未来预测而非像素预测，兼顾效率与语义；
  - 中间层做时序融合保持视觉 token 数量不变，避免语言模型侧二次复杂度膨胀；
  - 时序注意力使用因果掩码，与在线部署严格一致；
- **系统级优化与算法优化并重**：批量编码 + CUDA Graph 是不依赖模型架构修改的纯部署加速，可推广到其他 VLA；
- **评测规范**：每个成功率报告均值±标准差，且明确随机种子数；
- **真实世界验证**：在 AgileX Piper 平台上做了三组对照实验，增强结论可信度。

## 8. 不足与局限

- **演示数据规模有限**：每任务仅 200 条，且未涉及大规模机器人预训练，作者在 Limitations 中也承认这一限制可能未充分发挥未来预测/时序融合的潜力；
- **真实世界实验覆盖不足**：仅 3 个任务、20 次重复，且仅与 SmolVLA、PUMA 两个基线对比，未与 DynamicVLA、π0.5 等对比；
- **未探索更先进的推理机制**：作者承认未考虑 Real-Time Chunking（RTC）等更复杂的执行调度策略；
- **演示数据来源偏差**：依赖基于规划的分阶段合成与任务特定 RL，可能与人类示教分布存在差距，影响策略的"自然反应性"；
- **延迟模型简化**：RTF 折算假设推理延迟可在仿真中以恒定阻塞时间模拟，未建模异步推理中"动作陈旧性"的细粒度动态；
- **计算资源信息缺失**：未报告训练时长、GPU 数量、显存占用等关键资源信息，影响复现性评估；
- **任务复杂度有限**：六个任务虽然涵盖典型动态交互，但未涉及多智能体协作、工具使用或更长视野的动态规划场景；
- **消融粒度有限**：对每个组件只在单一任务（Conveyor Belt）上做累积消融，未对每个任务分别报告。
