## 摘要
现代视觉-语言-动作（VLA）策略已具备广泛的操控技能，但通常仅基于当前观测或固定长度的短历史生成每个动作片段。然而，现实世界中的操控任务往往是非马尔可夫的，要求机器人保留并推理长时程交互历史中与任务相关的信息，以决定下一步动作。为应对这一挑战，我们提出 HyMeS，一种混合学习框架，它利用编码智能体的推理与记忆管理能力来引导一个马尔可夫型 VLA 完成记忆依赖型操控任务。具体而言，HyMeS 通过基于梯度的模仿学习获得底层运动技能，而编码智能体则通过从推演反馈中迭代更新可执行的启发式系统，以启发式学习获得高层记忆管理策略。此外，我们通过多模态阶段完成验证来连接引导与执行环节，该验证利用本体感知信号与多帧 VLM 判断来更新记忆。与端到端的记忆增强型 VLA 相比，HyMeS 仅需为可复用的运动技能提供演示，而无需为每一种历史依赖的任务配置提供演示，从而实现数据高效的组合泛化。在 RoboMemArena 上，相对于 pi0.5，HyMeS 将平均累积成功率从 52.5% 提升至 66.2%，平均任务成功率从 41.3% 提升至 60.1%，同时在累积成功率上较 PrediMem 高出 4.5 个百分点，在任务成功率上高出 14.5 个百分点。

## Abstract
Modern vision-language-action (VLA) policies have acquired broad manipulation skills, but typically generate each action chunk from the current observation or a short fixed-length history. However, real-world manipulation is often non-Markovian, requiring robots to retain and reason over task-relevant information from long-horizon interaction histories to determine the next action. To address this challenge, we propose HyMeS, a hybrid learning framework that leverages the reasoning and memory-management capabilities of coding agents to steer a Markovian VLA for memory-dependent manipulation. Specifically, HyMeS learns low-level motor skills through gradient-based imitation learning, while a coding agent acquires high-level memory-management strategies through heuristic learning by iteratively updating an executable heuristic system from rollout feedback. Furthermore, we close the loop between steering and execution through multimodal stage-completion verification, which updates memory using proprioceptive signals and multi-frame VLM judgments. Compared with end-to-end memory-augmented VLAs, HyMeS requires demonstrations only for reusable motor skills rather than for every history-dependent task configuration, enabling data-efficient compositional generalization. On RoboMemArena, HyMeS improves mean cumulative success from 52.5% to 66.2% and mean task success from 41.3% to 60.1% over pi0.5, while outperforming PrediMem by 4.5 points in cumulative success and 14.5 points in task success.

# 论文总结：Skills in Weights, Memory in Code（HyMeS）

## 1. 核心问题与研究动机

- **问题背景**：现代视觉-语言-动作（VLA）策略（如 π0.5、π0.6）虽然掌握了广泛的操控技能，但本质上是**马尔可夫的**，仅依赖当前观测或固定长度的短历史生成动作块。
- **现实需求**：真实操控任务往往是**非马尔可夫**的。例如"按卡片上显示的数字按下按钮次数"的任务中，按钮的次数要求是早期观测到的瞬时线索，之后无法从当前观测中恢复；机器人需要保留并推理长时程交互历史中的任务相关信息。
- **现有方法的局限**：现有的记忆增强型 VLA（如 MemoryVLA、EventVLA、MemoryWAM 等）通过扩展观测窗口或增加记忆模块，并以端到端方式从机器人演示中学习。这导致：
  - 记忆逻辑是组合性、离散的，在权重空间中学习困难；
  - 需要覆盖组合空间的演示数据；
  - 易遗忘、难以检查或编辑；
  - 演示成本随历史依赖配置数量组合爆炸。
- **核心洞察**：低层运动技能已被现代 VLA 充分掌握，问题不在"会不会按按钮"，而在"该不该再按一次"。

## 2. 方法论

### 2.1 整体框架：技能存权重，记忆存代码

HyMeS（**Hy**brid learning with **Me**mory **S**trategies to steer）将问题分解为两个独立的学习任务：

| 学习组件 | 学习空间 | 学习机制 | 学习内容 |
|---|---|---|---|
| VLA 策略 π_θ | 权重空间 | 梯度模仿学习 | 可复用底层运动技能 |
| 启发式程序 P=(C,V,U) | 代码空间 | 编码智能体迭代启发式学习 | 高层记忆管理策略 |

**学习完成后，VLA 权重冻结**，记忆策略不再修改参数。

### 2.2 问题形式化

任务依赖紧凑任务状态 z_t = ϕ(h_t)，使专家策略满足 π*(a_t | h_t, ℓ) = π*(a_t | o_t, z_t, ℓ)。当 z_t 无法从 o_t 恢复时即出现**观测混淆（observation aliasing）**，马尔可夫策略必须对不一致的动作模式取平均。

### 2.3 关键公式

**(1) 权重空间的运动技能学习**（流匹配目标）：
$$a^\tau = (1-\tau)\epsilon + \tau a$$
$$\theta^* = \arg\min_\theta \mathbb{E}_{(o,a,\ell)\sim D, \tau,\epsilon} \| v_\theta(a^\tau, \tau|o,\ell) - (a-\epsilon) \|_2^2$$

**(2) 闭环过程**：在时刻 t，符号记忆 s_t 由 P 维护，控制循环为：
- R_t = C(s_t, o_t, ℓ) — 选定当前阶段的可微约束
- a_t = Steer(π_θ*, R_t, o_t, ℓ) — 受约束引导的动作生成
- e_t = V(W_t; s_t) — 阶段完成事件验证
- s_{t+1} = U(s_t, e_t, o_t) — 记忆更新

**(3) 记忆条件化的动作引导**：
$$\hat{v} = v_{\theta^*}(a^\tau, \tau|o_t, \ell) + \lambda_t \nabla_{a^\tau} R_{\rho_t}(a^\tau, o_t; s_t)$$
约束梯度被注入流匹配的去噪过程中，将动作生成引导到与当前记忆一致的动作模式。

**(4) 引导衰减调度**：当接近交互区域时降低引导强度：
$$\lambda_t = \frac{\lambda_0}{1 + \exp(\beta(p_t - p_{mid}))}$$
让符号程序决定"做什么"，让冻结 VLA 负责"怎么做好"。

### 2.4 关键组件

- **符号记忆** s_t = (plan, ρ_t, B_t, N_t, F_t)：包含阶段计划、活动阶段、目标绑定、计数、持久状态，由可执行规则更新。
- **PACE 多模态阶段完成验证**：结合**本体感知证据**（检测动作触发的运动模式，符号锁存器保留持久事件）与**视觉证据**（Qwen3-VL-8B 对最多 5 帧 RGB 图像进行多帧判断），周期查询，k-of-w 投票（实验中 w=5, k=3）：
$$e_t = \mathbb{I}\left[\sum_{i=r(t)-w+1}^{r(t)} d_i \geq k\right]$$
仅当最近 w 次查询中至少 k 次通过时才推进阶段。

### 2.5 代码空间的迭代优化

编码智能体（Opus 4.8）根据执行轨迹 ξ_n 和基准阶段裁决 b_n 诊断失败原因（约束奖赏定义错误？验证规则过严或过宽？），并执行：
$$P^{(n+1)} = \text{Edit}(P^{(n)}, \xi_n, b_n)$$

仅使用 rollout 反馈，**无需梯度、无需专家动作标签**。在评估期间程序 P* 冻结，仅用于实例化上下文相关规则。

## 6. 主要结论与发现

1. **记忆增益显著**：在相同策略权重下，HyMeS 将整体 CSR 从 52.5% → 66.2%，TSR 从 41.3% → 60.1%（相对 π0.5）；较 PrediMem 在 CSR 上高 4.5 个百分点、在 TSR 上高 14.5 个百分点。
2. **类别表现**：
   - 计数类 TSR 增益最大（30.0 点），显示显式计数器的价值；
   - 转移类 TSR 提升 26.6 点，显示显式对象-位置绑定的价值；
   - 序列类 TSR 提升 22.5 点，显示显式阶段状态的价值；
   - 遮挡类最难——PrediMem 在 CSR 上反而低于 π0.5（38.3% vs 50.4%），表明不可靠的记忆会误导执行；HyMeS 在 CSR 上匹配 π0.5（50.6%），TSR 上提升 7.0 点。
3. **真实机器人有效**：SO-101 上 TSR 从 25.7% → 57.1%，单符号状态同时支持线索保留、计数、源-位置关联。
4. **演示成本与可解释性**：
   - 演示预算与**可复用运动技能数量**而非历史依赖配置数量挂钩——单个微调检查点即可应对多种历史配置；
   - 符号状态在每步可读，失败可定位到记忆更新、运动执行或事件验证三个层面。
5. **消融结论**：
   - 推演精炼（从 P^(0) 到 P*）带来 +8.5 CSR、+18.4 TSR，验证推演经验是有效的学习信号；
   - 视觉+本体双证据优于任一单模态（仅视觉：−16.0 CSR、−21.7 TSR；仅本体：−8.8 CSR、−8.4 TSR）。

## 7. 方法与实验设计的优点

- **解耦设计清晰**：将"运动技能"与"记忆管理"分别在权重空间与代码空间学习，回归了"做什么 vs 怎么做"的经典分离。
- **数据高效**：组合泛化能力强，无需为每种历史配置收集新演示。
- **可解释性与可编辑性**：符号记忆可读、可改、可定位失败，便于诊断与调试（如图 4 的失败模式分析）。
- **闭环反馈**：PACE 多模态阶段验证实现从执行回读到记忆更新的双向耦合，避免了单向注入引导的局限。
- **引导衰减调度**：在交互密集区域让冻结 VLA 主导，避免引导干扰接触丰富动作。
- **公平实验设置**：与基线共享演示、观测、策略权重；评估冻结推演经验。
- **真实机器人验证**：不仅仿真，还在 SO-101 上验证，证明了硬件可行性。
- **跨平台兼容**：仿真（OpenPI/π0.5）与真实机器人（LeRobot/SO-101）均可使用同一框架。

## 8. 不足与局限

- **符号记忆表达局限**：当前仅适用于能由紧凑符号状态表示的任务，无法处理需要丰富感知记忆或世界模型的开放指令。
- **运动执行仍是瓶颈**：失败分析表明，正确的记忆与约束不能保证接触丰富动作的成功（瞄准偏差、按钮深度不足等）。
- **阶段验证可靠性**：遮挡场景下视觉完成证据最不可靠；本体信号亦可能漏检（按钮深度不足被识别为未完成）。
- **推理成本**：周期性 VLM 查询与编码智能体调用增加了每次回合的延迟与费用（论文明确承认）。
- **统计量偏少**：SO-101 仅 35 次试验，部分类别子任务数仅 2 个，统计显著性有限。
- **任务覆盖偏差**：基准选择排除了能通过观测捷径解决的任务，这可能高估记忆模块相对反应式策略的优势——若任务可被当前观测解决，马尔可夫策略本就足够。
