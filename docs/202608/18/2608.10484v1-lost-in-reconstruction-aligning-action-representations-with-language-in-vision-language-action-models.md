## 摘要
动作动词不仅描述动作的物理结果，还描述动作的执行方式。然而，视觉-语言-动作模型（VLAs）中的动作表征通常针对原始动作空间中L1/L2损失下的重建进行优化，而数值上的接近未必反映语言上有意义的区别。在BridgeV2上，我们表明动作轨迹包含超出视觉状态变化的动词接地信息，并且仅基于重建的离散分词会系统性地侵蚀这些信息。为解决该问题，我们提出了SALT，一种语义对齐的动作分词器，它通过一个辅助目标来增强VQ-VAE风格的分词器，该目标要求冻结的视觉-语言模型从量化后的动作潜变量中恢复回合指令。使用SALT训练的策略在SimplerEnv中达到了71.9%的平均成功率，而仅基于重建的VQ-VAE分词器为42.7%，FAST为31.2%。SALT还发展出动词专用编码，同时保持重建保真度。这些结果表明，机器人动作轨迹为语言接地提供了来源，并且在动作表征中保留这种结构可以显著改善语言条件下的控制。

## Abstract
Action verbs describe not only the physical outcomes of actions, but also how those actions are performed. Yet action representations in vision-language-action models (VLAs) are typically optimized for reconstruction under L1/L2 losses in raw action space, where numerical proximity need not reflect linguistically meaningful distinctions. On BridgeV2, we show that action trajectories contain verb-grounding information beyond visual state changes, and that reconstruction-only discrete tokenization systematically erodes this information. To address this problem, we introduce SALT, a Semantically ALigned action Tokenizer that augments a VQ-VAE-style tokenizer with an auxiliary objective requiring a frozen vision-language model to recover the episode instruction from quantized action latents. Policies trained with SALT achieve 71.9% average success in SimplerEnv, compared with 42.7% for a reconstruction-only VQ-VAE tokenizer and 31.2% for FAST. SALT also develops verb-specialized codes while maintaining reconstruction fidelity. These results show that robot action trajectories provide a source of language grounding and that preserving this structure in action representations can substantially improve language-conditioned control.

# 论文总结：SALT——面向视觉-语言-动作模型的语义对齐动作分词器

## 1. 核心问题与研究动机

- **VLA 中"动作-语言对齐"的缺位**：现有 VLA（如 RT-1/RT-2、OpenVLA、π0 等）通常把动作表征视作连续控制空间中的数值序列，用 L1/L2 重建损失训练离散动作分词器（Bin、FAST、VQ-VAE 等）。这些方法默认"数值接近 = 语义接近"，但这一假设并不成立。
- **动词的双重语义负荷**：动作动词不仅描述动作的结果（goal，体现在首末帧的视觉变化中），还描述动作的执行方式（manner/motion dynamics，如接触模式、夹爪时序、轨迹形状）。仅靠视觉对齐无法捕获 motion-specific 的接地信号。
- **离散化接口是瓶颈**：分词器在语言进入 VLA 之前就已固定，其动作词表与语言抽象无显式关联；下游策略训练无法恢复被丢失的语言接地结构。
- **论文核心问题**：机器人动作轨迹自身能否提供超越视觉的语言接地信号？重建目标的离散分词是否系统性地破坏该信号？能否设计一个在保留重建精度的同时保留语言相关结构的动作分词器？

## 2. 方法论：SALT（Semantically ALigned action Tokenizer）

### 核心思想
在 VQ-VAE 风格分词器训练阶段，引入一个由冻结 VLM 驱动的辅助生成目标：要求该 VLM 仅从量化后的动作潜码恢复整个回合的自然语言指令。这一压力迫使动作潜空间按语言可区分性进行组织，而不是仅按重建误差。

### 关键技术细节
- **基础架构**：残差 VQ-VAE（Residual VQ），将 8 步 / 7-DoF 的动作块编码为 K 个码本索引。文中采用 7 个残差组，每组 256 码 → 每块 7 个 token ID。
- **训练损失**：
  - $L = L_{\text{recon}} + L_{\text{VQ}} + \lambda L_{\text{align}}$
  - $L_{\text{recon}}$：动作重建损失
  - $L_{\text{VQ}}$：码本与 commitment 损失
  - $L_{\text{align}}$：冻结 VLM 从潜码生成指令的交叉熵
- **对齐接口**：将每个动作块的量化潜码 $q_i$ 转为软前缀嵌入 $p_i = g \cdot q_i + PE(i)$，与提示词一并输入冻结的预训练 LM，让其生成指令 $w_{1:L}$。
  - $L_{\text{align}} = -\frac{1}{L}\sum_{t=1}^{L} \log p_{\text{LM}}(w_t \mid w_{<t}, P, s)$
- **梯度流**：LM 冻结，梯度通过输入嵌入与 straight-through 量化器反传至编码器与码本；不引入预定义动词表、文本编码器或对比负样本。
- **部署流程**：训练完分词器后丢弃 LM，冻结分词器，下游 VLA 正常以离散 token ID 训练，最终通过解码器还原为连续动作。

## 3. 实验设计

### 数据集与场景
- **训练集**：BridgeV2（27,575 回合，7-DoF WidowX 250 遥操作），筛选后得到 17 个动词类、27,271 回合；按 90/10 划分 24,544/2,727。
- **评估基准**：SimplerEnv 的 visual-matching WidowX 套件（4 个桌面任务）：
  1. put spoon on towel
  2. put carrot on plate
  3. stack green block on yellow
  4. put eggplant in basket

- **诊断数据集**：同一 BridgeV2 用于 Diagnostic 1（互信息估计）与 Diagnostic 2（分词器探针），均采用 5 折分层交叉验证。

### 对比方法

## 6. 主要结论与发现

1. **动作轨迹确实承载动词接地信息**：在 BridgeV2 上，motion 与 goal 提供互补的动词信息；运动维度在合并表征中额外贡献约 0.059 bit，集中在 move、put、push 等动词上。
2. **重建式离散化系统性地侵蚀动词接地**：Bin / FAST / VQ-VAE 在所有压缩率下都低于连续轨迹参考（1.26 bit），且压缩越强丢失越多。
3. **SALT 显著提升任务成功率**：在 SimplerEnv 上达到 **71.9%** 平均成功率，VQ-VAE 为 42.7%，FAST 为 31.2%，在四个任务上均领先，困难任务（stack、eggplant）提升最显著。
4. **语义结构传递至下游**：尽管对齐目标只监督分词器潜码，但 SALT 的 token ID Macro-F1（39.1）与下游 action embedding Macro-F1（43.7）均最高，且 token ID 精度（58.7%）追平连续参考（58.0%）。
5. **词表涌现动词专精码**：SALT 学到对 flip（98%）、turn（74%）、pour、topple 等动作高度选择性的码字；能将"lever vertical to front"这类换述指令与 turn 归为同一码，证明对齐追踪的是**意义**而非表面词汇。
6. **不牺牲重建质量**：SALT 在保持相似重建 L1（0.088 vs VQ-VAE 0.080）与运动签名秩相关 ≥0.92 的前提下获得上述增益。

## 7. 优点与亮点

- **聚焦 VLA 中被忽视的"动作接口"**：把"语言接地"从视觉侧延伸到动作侧，提出动作-语言对齐这一被长期忽略的研究问题。
- **生成式对齐 vs 对比式**：利用冻结 VLM 生成指令，避免依赖预定义动词表、文本编码器或负样本，且天然匹配 VLA 自回归 token 消费接口。
- **干净严格的消融**：SALT 与 VQ-VAE 在架构、容量、数据、训练预算上完全对齐，差异可干净归因于对齐目标。
- **多维度证据链**：互信息估计、速率-失真曲线、token ID 探针、action embedding 探针、无探针 majority-vote 查询、码本-动词共现可视化共同支持结论。
- **涌现语义结构的可解释性**：可视化显示 SALT 码字自然按动词聚类，且对换述表达具有鲁棒性。
- **方法学严谨**：显式控制压缩预算（≈7 token / 8 步，约 7.0–8.6 bits/timestep）、报告 macro-F1 与 per-class accuracy，附 McNemar 检验与标准误。

## 8. 不足与局限

- **语言多样性受限**：BridgeV2 过滤后仅 17 个动词类，且分布严重长尾（前两类占 65%），无法充分测试语言多样性扩展后 SALT 是否仍受益。
- **适用面有限**：SALT 仅适用于有可学习潜码的分词器（VQ-VAE 系列），不能直接扩展到 Bin 或基于信号处理的 FAST。
- **评估范围较窄**：
  - 仅 0.5B 参数 VLA、单一数据集、单一仿真器；
  - 缺少真实机器人部署；
  - 缺少大规模多本体预训练场景验证。
- **因果机制未建立**：论文展示了"对齐 → 更好码本 → 更好策略"的相关性，但未解释**为什么**语义组织的码字会让自回归预测更易学到正确策略。
- **LM 依赖性**：SALT 训练阶段需要额外的前向/反向通过预训练 LM（虽 LM 冻结），增加了分词器训练的计算与工程复杂度（虽论文报告了总开销可控）。
- **类别不平衡偏差**：尽管报告 macro-F1，长尾动词仍可能因样本量少而探针估计不稳定；SALT 对罕见动词的提升主要来自可视化定性观察，缺乏严格的统计检验。
