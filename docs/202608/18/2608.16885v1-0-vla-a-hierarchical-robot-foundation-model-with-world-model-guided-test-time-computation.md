## 摘要
长时程机器人操作要求机器人既能可靠地执行各项技能，又能在长时间跨度任务中将这些技能进行连贯的序列组合。大多数分层视觉-语言-动作（VLA）模型在每次决策时仅通过单次前向传播完成，缺乏将额外计算资源分配给困难或重要决策的机制。我们提出 τ₀-VLA，一种分层机器人基础模型，它通过世界模型引导的测试时计算，将高层子任务生成形式化为一个可扩展计算量的推理问题。在每一次推理过程中，高层策略利用执行记忆生成子任务，并在必要时在多个候选方案中进行搜索，然后才提交最终输出。底层策略随后在多种机器人形态上执行所生成的子任务。该策略基于 40,115 小时的多模态异构真实世界数据进行协同训练。在域内与分布外设定下，增加测试时计算量显著提升了下一子任务的预测精度，而这些增益进一步转化为长时程机器人操作任务上更高的闭环成功率。

## Abstract
Long-horizon robot manipulation requires a robot to both execute individual skills reliably and sequence them coherently over extended tasks. Most hierarchical vision-language-action (VLA) models make each such decision with a single forward pass, leaving no mechanism to allocate additional computation to difficult or consequential choices. We introduce $τ_0$-VLA, a hierarchical robot foundation model that formulates high-level subtask generation as a compute-scalable inference problem through world-model-guided test-time computation. At each inference step, the high-level policy uses execution memory to generate a subtask and, when needed, searches over alternatives before committing to its output. A low-level policy then executes the generated subtask across multiple robot embodiments. The policy is trained on 40,115 hours of heterogeneous real-world data with multimodal co-training. Across in-domain and distribution-shifted settings, allocating additional test-time computation substantially improves next-subtask prediction accuracy, and these gains translate into higher closed-loop success on long-horizon robot manipulation tasks.

# τ₀-VLA 论文总结

## 一、核心问题与研究动机

长时程机器人操控（long-horizon manipulation）要求机器人同时具备两项能力：可靠地执行单个子技能，以及在分钟甚至小时级别的任务中将其连贯地串接起来。例如清理房间、做饭、泡奶茶等任务，不仅涉及众多原子操控动作，还需要在执行过程中持续推断"已经完成了什么"、"还剩什么"，并据此前瞻性地选择下一子任务。

当前主流的分层视觉-语言-动作（VLA）模型虽然在架构上引入了高层语义决策，但高层策略往往以**单次前向推理**完成子任务决策，缺乏为关键或困难的决策额外分配计算资源的机制。一旦高层做出错误决策，低层即使完美执行也已对环境造成不可逆改变，事后再"重规划"也难以挽回错误承诺的代价。因此论文作者指出：**长时程执行的核心瓶颈已不再是分层接口本身，而是高层决策的推理过程**。

## 二、方法论

### 1. 整体架构

τ₀-VLA 采用两层闭环架构：
- **高层策略 μ**：维护执行记忆、生成子任务，并在必要时调用世界模型引导的测试时计算（Test-Time Computation, TTC）。
- **低层策略 π_θ**：将当前多视角观测、本体状态与子任务文本条件映射为动作块。

高层和低层通过异步流水线协同工作（后台 worker 持续刷新每集当前的"已提交子任务"至缓存，约每秒刷新一次；低层控制循环直接读取缓存，无需等待高层决策完成），低层以约 30 Hz 的控制频率执行。

### 2. 高层策略的四个核心组件

- **提案模型 P（Proposal）**：基于 Qwen3.5-9B 微调，输入上下文 h_t = (ℓ, M_{t-1}, z*_{t-1}, o_t)，输出直接子任务提案 z^dir_t 与更新后的执行记忆 M_t。
- **世界模型 W（World Model）**：从 Step1X-Edit 初始化，根据当前头部 RGB 图像 õ 和候选子任务 z 预测执行后的终点头部图像 ô。
- **价值模型 V（Value Model）**：基于全局指令、候选子任务与预测图像打分，输出 5 档有序质量等级（映射到 [0.05, 0.95] 区间）。
- **反思模型 F（Reflective Model）**：接收保留分支摘要 C_t 与观测对齐的真实上下文 h̄_t，生成最终子任务 z*_t，输出可不限于候选集。

### 3. 自适应路由与测试时搜索

由提案模型同一前向传播产生的 token 置信度与 logit margin 计算路由统计量 u^all_t、u^mem_t；当两者均超过各自阈值时走 fast 路由（直接提交 z^dir_t），否则触发 TTC。

TTC 流程（Algorithm 1：Search(h_t, P, W, V, N, B, D)）：
1. 初始化单根分支 b_root，路径为空、累积分数为 0。
2. 对每个保留分支 b ∈ Q_{t,d-1}，调用提案模型 N 次生成候选 z^b,i_{t,d}。
3. 对每个候选子任务，分别调用 W 与 V 得到预测终点图像与质量分数。
4. 累积分数为父分支分数加上当前价值分数；上下文变为 (ℓ, M^b,i_{t,d}, z, ô)。
5. 通过 Top-B 全局裁剪保留得分最高的 B 个分支，并按递归扩展至深度 D。
6. 最终将保留分支摘要 C_t 传给反思模型 F，生成最终子任务。

搜索过程产生"分支本地记忆"，不污染持续执行记忆 M_t。

### 4. 低层策略

- **骨干网络**：Qwen3.5-2B。
- **动作专家**：Mixture-of-Transformers（MoT），在全注意力层中动作 token 与骨干 token 通过联合注意力交互，由独立参数的 Transformer 流处理。
- **训练目标**：基于条件流匹配（Conditional Flow Matching）的遮蔽版本。统一 40 维状态/动作空间（涵盖双臂末端位姿 6D 旋转、夹爪、腰部、平面基座速度与各 8 个关节角），不同本体用掩码标识有效通道。
- **三阶段训练**：
  1. **知识隔离协同训练（KI）**：冻结骨干梯度仅训练动作专家；
  2. **端到端协同训练**：解锁骨干，联合微调；
  3. **任务特定适配**：针对部署本体进行小规模数据微调。

### 5. 训练数据

- 低层策略数据共 **40,115 小时**：约 23.4K 小时内部数据（AGIBOT G1 21.9K 小时 + G2 585 小时 + ARX AC One 578 小时 + Franka 347 小时）+ 16.7K 小时公开机器人数据（含 9.25K 小时 UMI 数据）+ 多模态协同训练数据。
- 高层策略监督自动生成：使用 Gemma4-31B-it 标注 `<think>` 与 `<memory>` 字段，配合可执行子任务标注与分段轨迹，构建 5 种训练实例族：within-subtask（58%）、transition（15%）、catch-up（10%）、rollback（12%）、error-think（5%）。仅扰动输入记忆、保留正确目标，使高层学会自我修复时序错位、运行超前或失败恢复。

- **大规模真实数据**：4 万小时异构真实机器人数据 + 多模态协同训练在工业级规模上具说服力。
- **评估体系严谨**：统一的进度评分函数基于先决图（处理重试与分支依赖）、LLM-as-a-Judge 含多轮仲裁、统一的壁钟限制与重置流程。
- **理论与实验闭环**：不仅展示开环准确率，还直接验证闭环物理成功率，证实 TTC 增益确实可被物理执行兑现。

## 八、不足与局限

1. **算力信息披露缺失**：训练用 GPU 型号 / 数量 / 时长未在主文中披露，限制了对训练成本与可复现性的判断。
2. **基线公平性存疑**：GR00T N1.7、LingBot-VLA 在多任务上 0/10 的极端表现，提示这些基线并未在评估的特定任务与本体上做任务适配，与 τ₀-VLA 的"任务特定适配"阶段不对称；这可能夸大 τ₀-VLA 的相对优势。
3. **每任务试验数偏少**：仅 10 次物理试验，统计显著性受限，且未提供置信区间或方差。
4. **TTC 的部署成本**：TTC 通过世界模型 + 价值模型 + 反思模型的多次前向传播实现，开销不容忽视。虽然异步流水线缓解了延迟，但每次高层决策仍需额外算力，且未给出与 Best-of-N 在 wall-clock 层面的对比。
5. **OOD 设置局限于初始排列**：Book Organization 的 OOD 仅在初始书序上与训练不同，未涵盖更广泛的分布偏移（如新物体、新场景布局、新指令措辞）。
6. **TTA 路由阈值依赖标定**：δ_all 与 δ_mem 需在每个任务的留出验证集上标定，限制了对未见过任务的零样本迁移能力。
7. **数据/代码不完全公开**：论文未明确开源声明，附录中仅给出详细设计说明但未提供完整权重或代码链接。
8. **应用范围限定于家庭类结构化场景**：所有评估任务均为受限的家庭任务（清洁、烹饪、洗衣、整理），未在更开放的环境（如户外、拥挤人流、协作多机器人）中验证。
9. **TTC 反思模型的输出"可不限于候选集"**：这带来了"搜索-反思"之间的不一致风险——若反思结果不在 Top-B 候选中，则搜索实质上未能约束最终输出，搜索的工程意义可能被弱化（论文未对此现象进行单独分析）。
