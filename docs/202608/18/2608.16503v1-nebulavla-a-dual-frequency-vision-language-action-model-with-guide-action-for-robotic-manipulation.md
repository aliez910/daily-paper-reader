## 摘要
视觉-语言-动作（VLA）模型在实际部署中常受限于效率与性能之间的权衡、跨具身泛化以及执行平滑性等问题。我们提出了NebulaVLA，一种异步双频架构，将高层语义推理与底层动作控制解耦，从而优化计算资源并提升模块化程度。为弥合异构机器人之间的语义鸿沟，我们引入了GESTURE-7，一种统一的语言锚定动作表示。此外，我们提出的引导动作（Guide Action）算法通过基于掩码的平滑性约束来强制保证运动学连续性。综合评估表明，NebulaVLA显著优于同步基线，在LIBERO-Plus上达到了85.5%的平均成功率，并将动作生成速度提升约2.7倍。这种异步设计为实际机器人应用提供了高效且响应迅速的控制。

## Abstract
Real-world deployment of Vision-Language-Action (VLA) models is often bottlenecked by efficiency-performance trade-offs, cross-embodiment generalization, and execution smoothness. We present NebulaVLA, an asynchronous dual-frequency architecture that decouples high-level semantic reasoning from low-level action control, optimizing computational resources and modularity. To bridge semantic gaps across heterogeneous robots, we introduce GESTURE-7, a unified language-grounded action representation. Furthermore, our Guide Action algorithm enforces kinematic continuity via mask-based smoothness constraints. Comprehensive evaluations demonstrate that NebulaVLA significantly outperforms synchronous baselines, achieving an 85.5\% average success rate on LIBERO-Plus and accelerating action generation by \textasciitilde 2.7$\times$. This asynchronous design enables highly efficient and responsive control for practical robotics.

# NebulaVLA 论文总结

## 1. 核心问题与研究动机

视觉-语言-动作（VLA）模型在实际机器人部署中面临三大瓶颈：

- **效率与性能权衡**：当前主流 VLA 采用单体的同步架构（synchronous architecture），统一的时序分辨率无法同时支持低频语义推理与高频运动控制，导致计算资源浪费或响应迟滞。
- **跨本体泛化不足**：将连续动作映射到离散 token 需要海量数据和庞大词表，难以在不同构型机器人（灵巧手、夹爪、机械臂）之间建立统一的动作语义。
- **执行平滑性差**：异步推理与动作分块（action chunk）生成在时间上错位，容易产生明显抖动和边界不连续（boundary discontinuity）。

论文旨在系统性地解决上述问题，提升 VLA 模型在真实机器人部署中的实用性。

## 2. 方法论

### 2.1 整体架构：异构双频率系统

借鉴认知科学中的快慢系统（System 1/System 2）范式，NebulaVLA 将语义推理与动作控制解耦：

- **System 2（S2）**：以 Qwen3-VL 为骨干的视觉语言模型，约 10 Hz 运行，处理自然语言指令和稀疏视觉输入，输出抽象的动作引导（action guidance）。
- **System 1（S1）**：基于 DiT 的扩散式动作生成器，约 20 Hz 运行，通过 Q-Former 压缩 S2 引导、结合高频视觉特征和动作历史，输出连续动作。

两个系统通过显式数据流规范解耦，天生支持分布式部署，可在边缘设备上灵活拆分。

### 2.2 GESTURE-7 统一动作表征

GESTURE-7（Gesture Enumerated State Token for Unified Robot End-effector-7D）是一个 7 维连续向量：

$$s = [x, y, z, r, p, w, g]$$

- (x, y, z) 为末端执行器笛卡尔位置（厘米，整数量化）；
- (r, p, w) 为姿态角（roll, pitch, yaw，整数度）；
- g 为自然语言关键词（如 "grasp"、"push"、"rotate"），用于表示手部姿态。

量化设计降低学习负担，不同构型执行相同动作可共享同一关键词（如灵巧手和夹爪的抓取均用 "grasp"），天然支持跨本体 RL 训练。

### 2.3 Guide Action 机制

为缓解异步执行中的分块边界不连续问题，借鉴图像外扩（Image Outpainting）思路，将下一分块的生成条件化于前序未执行的动作锚点：

$$p_\theta(A^{full}_{t-1} \mid A^{full}_t, A^{prior}, \tau)$$

在每一步去噪后，通过二元掩码 M 强制保留已知动作：

$$A^{full}_{t-1} = M \odot A^{prior}_{t-1} + (1 - M) \odot A^{noisy}_{t-1}$$

其中 M[1..k]=1 为锚点区域（强制保留），M[k+1..T]=0 为生成区域。引导动作点数 k 在训练中随机采样（0–3），以适应不同的推理延迟。

### 2.4 三阶段训练流程

- **Stage 1（S2 SFT）**：涵盖空间定位（位姿回归、关键点回归）、轨迹预测（2D/3D waypoint）和思维链推理五项任务。
- **Stage 2（S2 RL）**：基于 GRPO 强化学习，使用 GESTURE-7 距离、关键点定位、waypoint（DTW+欧氏距离）、轨迹和格式奖励。
- **Stage 3（S1 SFT）**：联合微调 S2 和 S1，对新生成区域使用加权流匹配损失：$\mathcal{L}(\theta) = \mathbb{E}_{\epsilon,t}[(1-M)\odot(\epsilon - \epsilon_\theta(x_t, t))^2]$。

## 6. 主要结论

- **仿真性能**：NebulaVLA 在 LIBERO-Plus 上以 85.5% 平均成功率超越所有同步基线，比 InternVLA-M1（81.3%）高 4.2%，比 OpenVLA-OFT+（79.6%）高 5.9%。
- **推理加速**：相比同步基线动作生成速度提升约 2.7 倍；异构频率架构推理延迟从 115 ms 降至 42 ms。
- **真实部署**：Task 1 成功率达 92.08%，Task 2 达 92.5%，均优于 InternVLA-M1。
- **平滑性**：Guide Action 使平均关节抖动降低 25.6%，关节 12/13 分别降低 41.2% 和 45.1%。
- **消融结论**：三阶段训练逐步提升性能（SFT 主要优化 Layout 维度，RL 进一步增强 Language 和 Layout 语义耦合维度）。

## 7. 优点

- **架构创新**：异构双频率设计是首次将 S1/S2 范式系统化、显式数据流化并原生支持分布式部署，兼顾效率与精度。
- **统一表征**：GESTURE-7 通过自然语言关键词桥接异构本体，兼具连续可微性与离散语义性，便于与 RL 集成。
- **内在平滑性**：Guide Action 将平滑约束内化到扩散生成过程，替代了事后插值/平滑的"打补丁"路线，具备概念上的优雅性。
- **工程可落地**：S1/S2 可独立部署于不同设备，为边缘计算场景提供切实可行的方案。
- **实验体系较完整**：仿真+真实、消融、可视化、定量分析多角度验证。

- **引导锚点引入响应延迟**：固定锚点数量 k 在快速变化环境中可能造成响应滞后。
- **硬件同步工程难题**：分布式部署涉及多传感器时间戳对齐和分布式时钟一致性，论文未深入解决。
