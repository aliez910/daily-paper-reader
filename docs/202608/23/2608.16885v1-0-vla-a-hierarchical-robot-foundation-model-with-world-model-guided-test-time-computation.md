## 摘要
长时序机器人操作要求机器人既能够可靠地执行各项单一技能，又能在长程任务中将这些技能连贯地串联起来。大多数分层视觉-语言-动作（VLA）模型通过单次前向传播做出此类决策，缺乏为困难或关键的决策分配额外计算资源的机制。我们提出了τ_0-VLA，一种分层机器人基础模型，通过世界模型引导的测试时计算，将高层子任务生成建模为一种可扩展计算的推理问题。在每一步推理中，高层策略利用执行记忆生成子任务，并在需要时对多种备选方案进行搜索后再确定输出。随后，低层策略在多种机器人本体上执行所生成的子任务。该策略在累计40,115小时的异构真实世界数据上，通过多模态联合训练得到。在域内及分布偏移场景下，分配更多测试时计算显著提升了下一子任务的预测精度，且这些性能增益进一步转化为长时序机器人操作任务中更高的闭环成功率。

## Abstract
Long-horizon robot manipulation requires a robot to both execute individual skills reliably and sequence them coherently over extended tasks. Most hierarchical vision-language-action (VLA) models make each such decision with a single forward pass, leaving no mechanism to allocate additional computation to difficult or consequential choices. We introduce $τ_0$-VLA, a hierarchical robot foundation model that formulates high-level subtask generation as a compute-scalable inference problem through world-model-guided test-time computation. At each inference step, the high-level policy uses execution memory to generate a subtask and, when needed, searches over alternatives before committing to its output. A low-level policy then executes the generated subtask across multiple robot embodiments. The policy is trained on 40,115 hours of heterogeneous real-world data with multimodal co-training. Across in-domain and distribution-shifted settings, allocating additional test-time computation substantially improves next-subtask prediction accuracy, and these gains translate into higher closed-loop success on long-horizon robot manipulation tasks.

## 1. 核心问题与研究动机

- **长时序操作的核心挑战**：长时序机器人操作任务（如清洁房间、烹饪、泡奶茶）要求机器人在分钟甚至小时尺度上，将多个子任务连贯编排。每个高层决策都是"决定性决策"，错误的子任务选择即使被精确执行也无法挽回。
- **现有分层 VLA 的局限**：现有分层视觉-语言-动作（VLA）模型在每个高层决策上仅进行单次前向推理，没有"事前评估"机制，缺乏对困难或关键决策分配额外计算资源的手段。
- **核心瓶颈的转移**：瓶颈不在于分层动作接口的可用性，而在于生成下一个子任务的推理过程本身。
- **本文定位**：将高层子任务生成重新建模为一个**可扩展计算的推理问题**（类比 LLM 中的 test-time compute scaling），通过世界模型在测试时对候选子任务进行后果评估，再做出承诺。

## 2. 方法论

### 2.1 整体架构（分层双层系统）

- **高层策略（High-Level Policy）**：负责维护执行记忆、决定何时调用额外测试时计算（TTC）、生成当前子任务。
- **低层策略（Low-Level Policy）**：将当前观测和生成的子任务映射为机器人动作块。
- **统一动作空间**：40 维状态-动作空间，覆盖末端执行器位姿、关节、夹爪、腰部、移动底座，支持固定基座、双臂、移动全身等多种本体。

### 2.2 高层策略组成

- **提议模型（Proposal, P）**：基于 Qwen3.5-9B，接收当前多视角观测、任务指令、执行记忆、上一子任务，生成直接提议子任务 z_dir 并更新记忆。
- **自适应路由**：根据提议模型生成 token 的置信度统计量（生成 token 平均概率、logit 边距）判断是否触发 TTC。gt=0 走快速路径；gt=1 触发搜索。
- **世界模型（World Model, W）**：基于 Step1X-Edit 初始化，预测候选子任务执行完毕后的头部 RGB 终端图像。
- **价值模型（Value Model, V）**：以全局指令、候选子任务、想象终端图像为输入，输出 5 级序数质量标签，映射为 [0.05, 0.95] 标量分数。
- **反射模型（Reflective Model, F）**：在 TTC 末端，基于保留分支摘要和观察对齐上下文，生成最终子任务 z*（可不限于候选集合）。

### 2.3 测试时搜索（Beam Search）

- **算法流程**：
  - 初始化：根分支上下文为 h_t，路径为空，累积分数为 0。
  - 每层深度 d ∈ {1,…,D}：对每个保留分支独立调用 P 采样 N 个候选子任务。
  - 对每个候选：W 预测终端图像，V 给出分数，累积得分。
  - 全局 Top-B 剪枝，保留最有希望的分支。
  - 递归扩展至深度 D，输出分支摘要集合 C_t。
- **关键设计**：每个分支维护 branch-local 记忆，不覆盖持久执行记忆；非根分支以想象图像作为下一层上下文。

### 2.4 可修正执行记忆训练

- **自动扰动**：在不增加人工标注前提下，对原始示范中的记忆进行扰动，构造 5 类训练家族（within-subtask、transition、catch-up、rollback、error-think），比例分别为 58%/15%/10%/12%/5%。
- **目标**：训练高层策略从滞后、超前或失败状态中恢复，使记忆与视觉证据对齐。

### 2.5 低层策略

- **结构**：Qwen3.5-2B 视觉语言骨干 + Mixture-of-Transformers（MoT）动作专家，联合注意力但参数流分离。
- **训练目标**：使用掩码条件流匹配（masked flow matching），对无效通道掩码，仅监督有效维度。
- **动作块**：H=30 步动作块，推理时使用 10 步均匀 Euler 积分。

### 2.6 训练流程

- **低层三阶段**：
  1. 知识隔离协同训练（KI）
  2. 端到端协同训练
  3. 任务特定微调
- **高层各组件独立微调**：提议/价值/反射模型分别基于 Qwen3.5-9B 微调，世界模型基于 Step1X-Edit 单独训练。

### 2.7 异步双系统部署

- 高层子任务由后台 worker 每约 1 秒刷新并发布到缓存；低层控制循环以 ~30 Hz 频率读取缓存执行动作 chunk，高层决策延迟不会阻塞控制频率。

## 6. 主要结论与发现

- **测试时计算显著提升下一子任务预测精度**：TTC 在 4 个评估场景均超过 Plan Once 和 Best-of-N。在 OOD Book Organization 上，TTC 达 74.0% 准确率，远超 Plan Once（50.0%）和 Best-of-N（57.5%）。
- **测试时计算转化为闭环任务成功率**：Make Milk Tea SR 从 5/10 升至 7/10；Book Organization 从 6/10 升至 9/10；Clean Room 从 5/10 升至 7/10。
- **执行记忆的关键价值**：在 Clean Room 上，无记忆的失败集中在挂包和后续整理阶段；在 Tomato and Egg Stir Fry 上记忆能显式记录"已加盐"步骤，避免重复或遗漏。
- **分层结构优于直接执行**：τ₀-VLA 分层系统在四个长时程任务上平均 SR 45.00%，优于直接执行的 27.50%。
- **计算-精度呈饱和趋势**：低算力下增益显著，之后边际递减并趋于平台，符合测试时计算扩展的常见规律。
- **跨本体统一控制**：单一低层策略在三种机器人上均表现良好（Collect Laundry 10/10、Tidy Makeup Table 三个子组全部超过 92.5% Progress）。
