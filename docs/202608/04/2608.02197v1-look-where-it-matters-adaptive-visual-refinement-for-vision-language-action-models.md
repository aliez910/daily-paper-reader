## 摘要
VLA模型的视觉表征在需要空间精确性的机器人操作任务中仍不可靠。我们发现VLA中的视觉编码器同样存在先前在通用Vision Transformer中记录到的注意力伪影，并进一步表明，在具身策略中，这些伪影与后训练阶段获得的空间感知能力密切相关。当编码器学习任务相关信息（如物体位置、深度排序与局部几何）时，有限的全局token容量会使部分信息溢出到低信息量的patch token中。我们提出了AtVLA，一个将可学习寄存器（register）token插入视觉编码器的框架。该框架仅使用具身数据和原始动作目标进行端到端训练，这些寄存器作为具身空间信息的专用载体浮现，而剩余的patch token则恢复出干净、空间保真的注意力分布，对精确目标定位与细粒度接触至关重要。干净的注意力恢复了可靠的定位能力，但无法恢复在低分辨率观测中丢失的几何细节。因此，AtVLA将注意力矫正与不确定性门控的局部细化相结合。动作专家采样多个动作块并依据其不一致性估计不确定性；仅对不确定的预测，由动作条件化的注意力展开过程识别任务相关区域，对其裁剪并以高分辨率重新编码，再附加到已缓存的前缀中以生成细化后的动作。在LIBERO、SimplerEnv以及一个具有挑战性的单视角真实世界基准上，AtVLA将LIBERO的平均成功率从94.2%提升至98.4%，将真实世界成功率从46.5%提升至69.0%。裁剪操作仅在约30%的重规划步骤中触发，在典型部署设置下，总计算量仅为基线模型的1.4至1.6倍。

## Abstract
Visual representations of VLA models remain unreliable for spatially precise robotic manipulation. We uncover that vision encoders in VLAs also exhibit attention artifacts previously documented in generic Vision Transformers, and further show that, in embodied policies, these artifacts are closely associated with spatial perception capabilities acquired during post-training. As the encoder learns task-relevant information such as object location, depth ordering, and local geometry, limited global-token capacity causes part of this information to spill into low-information patch tokens. We introduce AtVLA, a framework that inserts learnable register tokens into the visual encoder. Trained end-to-end using only embodied data and the original action objective, these registers emerge as dedicated carriers of embodied spatial information, while the remaining patch tokens recover clean and spatially faithful attention distributions crucial for precise target localization and fine-grained contact. Clean attention restores reliable localization, but cannot recover geometric details lost in low-resolution observations. AtVLA therefore couples attention rectification with uncertainty-gated local refinement. The action expert samples multiple action chunks and estimates uncertainty from their disagreement; only for uncertain predictions, action-conditioned attention rollout identifies the task-relevant region, which is cropped, re-encoded at high resolution, and appended to the cached prefix for refined action generation. Across LIBERO, SimplerEnv, and a challenging single-view real-world benchmark, AtVLA improves the average LIBERO success rate from 94.2% to 98.4% and real-world success from 46.5% to 69.0%. The cropping is triggered on approximately 30% of replanning steps, resulting in only 1.4-1.6x the total computation of the base model under the representative deployment setting.

# 论文总结：AtVLA — 面向视觉-语言-动作模型的自适应视觉优化

## 1. 核心问题与研究动机

- **问题背景**：视觉-语言-动作（VLA）模型在大规模预训练中继承了丰富的语义先验，但在需要空间精确性的机器人操作任务中，其视觉表征仍存在严重不可靠性。
- **观察发现**：作者发现 VLA 模型中的视觉编码器同样存在先前在通用 Vision Transformer（如 Darcet et al. 2023）中观察到的"高范数伪影"——背景 patch 被挪用为全局信息的"仓库"，挤占了局部空间内容，破坏了密集注意力图。
- **关键洞察**：在具身后训练过程中，编码器需要学习物体位置、深度排序、实例结构和局部几何等任务相关信息。然而，原始全局 token 容量有限，导致这些空间信息"溢出"到本应表达局部内容的 patch token 中。这表明注意力伪影与具身训练获得的空间感知能力密切相关，且这一病理在前人工作中未被显式分析。
- **第二个瓶颈**：即使定位正确，也难以保证精细操作。细粒度动作需要目标接触区域的局部几何细节，但在低分辨率第三人称观测中，这些细节可能仅占几个 patch；腕部摄像头虽提供近景但视角敏感。

## 2. 方法论

### 2.1 整体架构（AtVLA）

AtVLA 基于 π0 基线策略，新增两大互补机制：

- **寄存器增强的视觉前缀编码**（Register-Enhanced Visual Prefix）
- **不确定性门控的局部视觉细化**（Uncertainty-Gated Local Refinement）

### 2.2 寄存器增强视觉编码

- 在 SigLIP 编码器（224×224，patch=14 → 256 个 patch）中插入 **N_r=4 个可学习的寄存器嵌入**：
  
  $X_t = [x_{cls}; r_1, ..., r_{N_r}; p_1, ..., p_{N_b}]$

- 编码器输出三组特征：类标记 h_cls、寄存器特征 R_t、patch 特征 P_t。**关键差异**：与原版仅将寄存器作为内部工作空间不同，AtVLA 保留 R_t 并通过 PaliGemma 视觉投影器 Π 投射，**作为额外的全局上下文暴露给下游策略**。
- 前缀构成：$C^t_b = [\Pi(R_t); \Pi(P_t); E_{lang}(\ell); E_{state}(s_t)]$
- 多视角情况下，各视角独立编码后拼接。

### 2.3 不确定性门控动作预测

- LLM 骨干构建可复用的 KV 缓存前缀；流匹配动作专家从独立高斯初始化采样 **K=4** 个动作块：
  
  $A^{(k)}_{1:H} = \text{ODESolve}(v_\theta, z^{(k)}_0 | C^t_b)$

- 不确定性度量：在近端 h 步平移维度上计算 K 个样本的标准差均值 $U_t$。
- 阈值 $\tau$ 在保留集上校准（按经验取验证分布的第 70 百分位并按裁剪收益微调），目标触发率约 30%。
- 当 $U_t \leq \tau$（自信路径）：直接执行均值动作块，不进行任何裁剪。

### 2.4 注意力引导的局部细化（不确定路径）

1. **注意力展开（Attention Rollout）**：复用基础动作采样过程中已计算的注意力，对动作专家的 18 个联合注意力层在头部和去噪步 {3, 6, 9} 上做平均，加残差连接并按行归一化：
   
   $f_M^l = \text{RowNorm}(I + \frac{1}{|H||Q|}\sum_{m\in H}\sum_{q\in Q}M^l_{m,q})$
   $M_{roll} = f_M^L f_M^{L-1} \cdots f_M^1$

2. 取前 h 个动作 token 行对 256 个基础图像 patch 列的注意力均值，重塑为 16×16 显著性图 S_t；**排除寄存器列**（因寄存器不保留固定的图像网格对应）。
3. **对比窗口搜索**：在候选窗口集 {84, 112, 140 像素} 上，最大化窗口内/外环的注意力差值（公式 8），抑制弥散全图裁剪和孤立峰值。
4. 选中区域填充 10%，裁剪、重缩放到 224×224，由相同的寄存器增强视觉编码器重新编码。
5. **裁剪位置编码**：通过 MLP 将归一化坐标 $(x_1/W, y_1/H, x_2/W, y_2/H)$ 映射到 LLM 隐藏维，加到每个裁剪 patch token：
   
   $C^t_+ = [C^t_b; \Pi(P^{c}_t) + \mathbf{1}_{N_c} \mathbf{e}^\top_b]$

6. **缓存复用**：仅预取裁剪段 KV；基础图像/指令/状态的 KV 缓存保留。
7. **无效展开处理**：包含非有限值、注意力总质量 < 10⁻⁶、候选评分失败、裁剪退化等情况下，跳过细化，沿自信路径执行。

### 2.5 训练目标与三阶段课程

总体目标：$L = L_{\pi_0} + \lambda_{cp} L_{cp} + \lambda_{ag} L_{ag}$，$\lambda_{cp}=0.1$，$\lambda_{ag}=1.0$。

- **阶段 0（寄存器适配，20K 步）**：前 4K 步仅更新寄存器；后 16K 步额外解冻 SigLIP 最后 4 个 transformer block。
- **阶段 1（真实标注裁剪对齐，10K 步）**：冻结完整 SigLIP、寄存器、投影器；仅优化裁剪位置编码器和 rank-32 LoRA。
- **阶段 2（联合精修，40K 步）**：三组件 LoRA、寄存器、投影器、裁剪位置编码器均更新。引入 $L_{ag}$（公式 14）鼓励动作到图像注意力集中在任务相关区域内。
- **裁剪课程**：0–40% 步全部使用标注裁剪（α=0，p_drop=0）；40–90% 步 α 从 0 线性增至 1，p_drop 从 0 增至 0.3（无效展开 → 跳过细化，与推理一致）；最后 10% 步 α=1，p_drop=0.3。

## 6. 主要结论与发现

- **注意力伪影是可矫正的**：在 VLA 视觉编码器中插入 4 个可学习寄存器 token，使用具身数据和原始动作目标端到端训练，能显著清除高范数伪影，使注意力重新聚焦于任务相关区域，**无需任何视觉自监督预训练或额外视觉监督**。
- **寄存器成为具身空间信息的专用载体**：线性探针显示寄存器特征对物体位置、深度、表面法线的预测准确率均超过 0.70，显著优于 CLS token 和池化 patch 特征；移除寄存器导致 LIBERO 平均下降 4.45 个百分点。
- **干净注意力不足以恢复几何细节**：低分辨率观测中缺失的局部细节需要高分辨率重编码来弥补。
- **裁剪应选择性触发**：当且仅当 K=4 个动作块采样出现显著不一致（不确定性超阈值）时才进行裁剪；约 30% 重规划步骤触发，总计算量仅 1.4–1.6 倍。
- **定量收益**：
  - LIBERO 平均成功率：**94.2% → 98.4%**（π0 → AtVLA Full）；
  - 真实世界平均成功率：**46.5% → 69.0%**；
  - SimplerEnv：Pick Coke Can 88.0 → 91.3，Move Near 80.3 → 81.6，Open/Close Drawer 56.0 → 57.5；
  - 在 LIBERO-Long-10 上 π0 + Cropping 也获得显著提升（85.2 → 93.3），说明裁剪还有助于长时序规划。
- **寄存器容量规律**：数量过少会引入额外干扰（甚至低于 π0 基线），4 个时性能与探针分数均饱和，是"最小充分容量"。

## 7. 优点与亮点

- **机制层面的洞察**：首次明确指出 VLA 视觉编码器的注意力伪影与具身后训练获得的空间信息溢出有关，**填补了通用 ViT 寄存器文献与 VLA 接地问题之间的空白**。
- **双重互补设计**：寄存器修复 + 不确定性门控细化在"先恢复可靠定位，再按需增强局部几何"上形成清晰分工。
- **部署友好**：仅在 30% 步骤触发裁剪，KV 缓存复用，计算开销增加有限（1.4–1.6 倍），可在 4090 上实时部署。
- **训练流程严谨**：三阶段课程 + 裁剪课程（真实标注 → 混合 → 纯 rollout）+ 裁剪丢弃，使训练与推理分布对齐，避免"ground-truth fallback" 造成的 train-test gap。
- **对比充分**：跨模拟与真实世界、跨通用 VLA 与受控消融变体，论证了各组件的独立贡献与协同效应。
- **诊断实验深入**：线性探针 + 注意力图定性 + 计算量分解，便于读者理解模型内部行为。
- **保留基线动作表示**：不修改 π0 的动作空间或生成流程，仅在视觉端增量修改，便于即插即用。

## 8. 不足与局限

- **单视角真实世界基准**：仅依赖单个第三人称 RealSense 摄像头，未测试多视角融合、深度相机或立体视觉配置；在遮挡严重或深度模糊场景下的表现未充分评估。
- **真实世界任务规模有限**：每套件 5 个任务类别，多样性可能不足；缺乏跨物体类别、跨光照、跨背景的全面压力测试。
- **SimplerEnv 评估覆盖偏少**：仅 3 个 Google Robot 任务，且省略 WidowX；Open/Close Drawer 上 AtVLA 与 π0 + Cropping 提升有限（多数裁剪覆盖整张图），反映任务几何特性对方法敏感度的限制。
- **外部 VLM 裁剪的对比**：π0 + Cropping 使用无具身预训练的外部 VLM 生成裁剪，结果偏弱，但说明裁剪质量对系统性能影响大；若引入更强的外部裁剪模型，对比公平性需重新审视。
- **阈值 τ 需要按具身校准**：每个 embodiment 单独校准（LIBERO / Google Robot / Franka），增加部署成本，且需保留集与"裁剪收益"度量；尚未证明对未见 embodiment 的零样本迁移能力。
- **触发率 30% 是设计预算而非完全自适应**：阈值优化受 30% 上限约束（公式 25），可能在某些场景下限制进一步性能提升。
- **计算量分析为近似值**：文中以"专家单次采样 ≈ 10–15% π0 单次规划、裁剪细化 ≈ 20–25%"为假设，实际硬件/实现可能差异较大。
- **缺乏失败模式系统分析**：对仍失败的案例（如 SimplerEnv Open/Close Drawer 性能饱和）未给出深入诊断或可视化。
- **训练数据规模偏小**：LIBERO 仅 2,000 条轨迹，真实世界训练数据量未披露；在大规模数据下寄存器行为是否仍稳定未验证。
- **依赖固定 patch 网格假设**：对比窗口搜索、crop 位置编码等均假设 patch 网格对齐（stride=14=patch size），对非规则输入或多尺度融合未涉及。
