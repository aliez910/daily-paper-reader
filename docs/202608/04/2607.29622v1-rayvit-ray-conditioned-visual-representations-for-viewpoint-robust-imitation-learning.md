## 摘要
视觉模仿学习使机器人能够直接从图像中获取视觉运动技能，但 RGB 观测缺乏显式的几何线索，导致所学策略在面对相机扰动时表现脆弱。为此，我们提出了射线条件视觉 Transformer 编码器（RayViT），一种将相机几何信息注入预训练 ViT 主干网络的轻量化架构。RayViT 将相机几何表示为 Plücker 射线图，并将其分块为射线特征，利用门控交叉注意力生成射线条件类别标记。这些射线特征被作为密集位置嵌入加入，同时射线类别标记替换原始的 ViT 类别标记，以提供几何感知的汇总表征。我们结合辅助余弦相似度损失，持续提升几何感知标记的性能与鲁棒性。在仿真和真实机器人任务上的实验表明，相较于基线方法，RayViT 在多任务 RoboCasa 基准的相机扰动下将鲁棒性提升了约 13 个百分点，并在真实世界多任务中将平均完成阶段数提升了 1.78 个。

## Abstract
Visual imitation learning enables robots to acquire visuomotor skills directly from images, yet RGB observations lack explicit geometric cues, making learned policies brittle to camera perturbations. To address this, we propose \textbf{Ray-conditioned Vision Transformer Encoder (RayViT)}, a lightweight architecture that injects camera geometry into pretrained ViT backbones. RayViT represents camera geometry as a Plücker ray map, patchifies it into ray features, and uses gated cross-attention to produce a ray-conditioned class token. These ray features are added as dense positional embeddings, while the ray class token replaces the original ViT class token to provide a geometry-aware summary representation. We combine this approach with an auxiliary cosine similarity loss to consistently improve the performance and robustness for geometry-aware tokens. Experiments on sim- and real-robot tasks demonstrate that RayViT improves robustness by approximately 13 percentage points under camera perturbations in multi-task RoboCasa benchmark and by 1.78 average completed stages in real-world multi-task success rate compared to baselines.

# RayViT 论文总结

## 1. 核心问题与研究背景

- **关键痛点**：视觉模仿学习（Imitation Learning）通常直接基于 RGB 图像训练策略，但 RGB 观测本身**缺乏显式的几何线索**，因此策略对**相机位姿扰动**非常脆弱。
  - 实际场景中，相机常因避障、机器人运动等原因发生平移/旋转，导致策略性能急剧下降。
  - 预训练 ViT（如 DINOv3）虽提供丰富语义先验，但表征的是场景外观，**对相机-世界几何关系完全无知**，导致策略学到的是"视角相关的表观-动作映射"而非"视角无关的任务表征"。
- **现有方案的不足**：
  - **数据增广派**（多视角采集、域随机化、新视角合成）：成本高、难以在真实场景规模化。
  - **显式 3D 表征派**（点云、点图、深度）：依赖深度传感器或额外重建；点云密度、噪声、物理尺度难以统一；与纯图像先验的 ViT 主干兼容性差。
- **本文定位**：在不增加传感器、不依赖多视角数据增广的前提下，把**相机几何**直接注入预训练 ViT 表征流中，从而获得**对相机扰动鲁棒**的视觉模仿学习策略。

## 2. 方法论

### 2.1 整体思路
- **几何表征选择**：采用 **Plücker 射线图（Plücker ray map）**——每个像素对应一条 3D 视线的方向与空间矩，构成一个 6 维向量。该图与 RGB 图像**逐像素对齐**，提供密集的"位姿-像素"对应关系。
- **两条互补的几何注入路径**：
  1. **射线条件类令牌（Ray-conditioned CLS Token）**：用一个可学习的 query token，通过**门控交叉注意力**对射线 patch 特征做池化式聚合，得到几何感知的全局汇总令牌，**替换**原 ViT 的 CLS 令牌。
  2. **射线位置嵌入（Ray Positional Embedding）**：把射线 patch 特征以**加法方式**注入图像 patch token 输入端，与 RoPE **并行保留**。
- **辅助损失**：在不同视角的中间层类令牌之间施加**余弦相似度对齐损失**，以抓手（in-hand）视角作为锚点（anchor），鼓励"同一场景不同视角"得到一致表征。

### 2.2 关键技术细节
- **Plücker 射线建模**（像素 $p=(u,v,1)^\top$，相机内参 $K$，外参 $(R,t)$）：
  - 世界系相机中心 $o_w = -R^\top t$
  - 视线方向 $d_w(u,v) = R^\top K^{-1} p / \|R^\top K^{-1} p\|_2$
  - 每像素 6D 射线特征 $r(u,v) = [d_w(u,v),\, o_w \times d_w(u,v)]$。
- **Patch 化**：通过**平均池化**（核大小等于 patch 大小）将射线图降采样到 ViT patch 分辨率，**保持几何语义**（非参数化，避免可学习卷积破坏 Plücker 坐标含义）；随后通过 2 层 MLP + GELU 投影到主干隐藏维度。
- **门控交叉注意力模块**：
  - 由 2 个轻量交叉注意力块组成；
  - 可学习 query 与 patch 对齐的射线特征做 cross-attention；
  - 借鉴 Qwen 的做法，在注意力后接**可学习的逐元素 sigmoid 门控**，自适应调节几何条件强度，避免淹没预训练语义信号；
  - 最终 query token 作为"射线条件 CLS"替换原 CLS 进入 ViT 前向。
- **位置嵌入注入**：射线 patch 特征**加在 ViT 编码器输入端**，与原 RoPE **并行共存**——RoPE 处理图像平面内局部空间关系，射线特征提供绝对 3D 锚定；RoPE 内部不被修改，保留预训练注意力动力学。
- **跨视角对齐损失**：
  - 在中间层（默认第 10 层）类令牌 $c_v, c_g$ 上施加：
    $$L_{\cos} = 1 - \frac{1}{N-1}\sum_{v \in V} \cos(c_v, c_g),\quad L = L_{\text{IL}} + \lambda L_{\cos}$$
  - 锚点 $g$ 选抓手相机视角（最贴近操作目标、背景干扰少）。
  - **关键发现**：余弦损失仅在 token 已具几何感知时才生效（RGB 基线上施加反而无稳定增益）。

### 2.3 推理/训练流程
- 输入：多视角 RGB + 各相机射线图；
- 视觉编码：DINOv3（默认 ViT-Small，21.6M）+ 门控交叉注意力模块（3.85M）+ 射线 patch 投影（0.15M）；
- 策略头：冻结 CLIP ViT-B/32 语言 token + decoder-only xLSTM（8 个 x-Block，8 个 attention head，embedding dim 768）+ 得分式扩散策略（DDIM、动作块长度 10）；
- 端到端训练，视觉编码器**全量微调**。

## 6. 主要结论与发现

- **鲁棒性显著提升**：在 RoboCasa 相机扰动设置下，RayViT 比 RGB 基线平均成功率高出约 **13 个百分点**，性能下降幅度从 18.5 压缩到 2.5。
- **真实机器人**：在 4 个真实多任务上，扰动相机下 RayViT 平均完成阶段数比 RGB 基线提升 **1.78**（如 Cup Stack 扰动下从 1.05 → 3.50，Drop 仅 -0.12）。
- **默认设置保持竞争力**：固定相机下与最强基线相当甚至略优（RayViT-cls 平均 43.2% vs RGB 42.5%）。
- **关键洞察**：
  - 几何注入（射线 CLS + 射线位置嵌入）比单纯密集 3D 点图更能抵抗视角扰动；
  - 后期拼接式条件（CamPose）在多任务无多视角增广设置下表现欠佳，说明**早期注入到 ViT token 流**更有效；
  - **余弦对齐损失只有在几何感知 token 上才稳定有效**，二者是协同关系；
  - 在更深中间层（第 10 层左右）施加余弦损失收益最大；
  - 即使**无预训练权重**，RayViT 仍优于 RGB（说明几何注入收益并非仅依赖预训练分布）；
  - 方法可迁移到不同预训练 ViT 主干（DINOv3 / EUPE），具有较好通用性。

- **轻量化与即插即用**：仅新增约 4M 参数即可注入几何先验，无需多视角增广、无需深度/点云重建。

  - 用**门控交叉注意力**生成几何感知 CLS，对预训练分布扰动最小；

- **充分的多视角消融**：层扫描、锚点选择（抓手）、有无预训练等细节均给出实验支撑。

## 8. 不足与局限

- **主干类型局限**：仅针对 **ViT 类预训练视觉编码器**，未涉及卷积类（如 ResNet、ConvNeXt）主干。
- **依赖视角锚点**：跨视角对齐损失需预设一个任务相关的"锚点视角"（本文默认抓手相机），在**单视角**或**无抓手视角**场景下需额外设计。
- **依赖外参标定**：需要相机在世界坐标系的外参标定；外参不准会直接影响射线图质量（论文虽提到工具辅助但未深入鲁棒性分析）。
- **扰动设置有限**：相机扰动仍是"两相机中替换一个 + 限定位移/角度范围"，未覆盖极端稀疏视角、遮挡或相机数量大幅变化的情况。
- **真实实验规模偏小**：仅 4 个真实任务，每任务 20 rollouts，无多种子统计；真实扰动下也仅与 RGB 基线对比，未与 CamPose/Adapt3R 等几何方法在真机上横向比较。
- **未对几何失败模式深入分析**：若射线图噪声、标定偏差或抓手持相机被遮挡时性能如何退化，论文未给出系统诊断。
- **应用范围**：面向多任务模仿学习的视觉编码增强，尚未推广到 VLA（Vision-Language-Action）大模型或强交互式任务（如双臂、灵巧手、长视频）。
