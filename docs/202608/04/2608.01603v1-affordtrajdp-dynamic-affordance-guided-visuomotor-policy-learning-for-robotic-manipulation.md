## 摘要
可供性引导的模仿学习通过将视觉感知压缩为任务特定的集合约束（例如固定的接触点），在机器人操作任务中展现出了令人瞩目的性能。然而，常用的静态可供性在对精度要求较高的任务或物体位置发生扰动时可能变得不一致，从而导致接触后的轨迹漂移。为解决这一问题，我们提出了 AffordTrajDP——一个通过以物体为中心的时间传播构建可供性轨迹、用于引导渐进式操作过程的动态框架。具体而言，给定 RGB-D 观测，我们核心的洞见是：通过检索得到的锚点可供性捕捉了末端执行器与目标物体之间期望的接触点，可借助物体的 SE(3) 位姿作为自然传播介质，通过可供性传播将其向前传播，从而生成在执行全程提供时间一致、状态感知引导的可供性轨迹。AffordTrajDP 在 ManiSkill3 上取得了 70.0% 的平均成功率，较强基线方法最高提升了 17.8%。在 Galaxea A1 与 UR7e 机械臂上开展的涵盖 StackCube、PickCup、AdapterInsertion、Ring-on-Peg、Put-in-Bowl 以及 USB Insertion 等任务的真实实验，进一步验证了该方法在物体位置变化与外观变化下的鲁棒性；在 Galaxea A1 上还评估了已见与未见物体实例的表现，消融实验进一步证实了各所提组件的贡献。

## Abstract
Affordance-guided imitation learning has shown impressive performance in robotic manipulation tasks by compressing visual perception into task-specific geometric constraints (e.g., fixed contact points). However, the commonly used static affordances can become inconsistent in precision-critical tasks or under object location perturbations, leading to post-contact trajectory drift. To address this issue, we propose AffordTrajDP, a dynamic framework that constructs affordance trajectories via object-centric temporal propagation to guide the progressive manipulation process. Specifically, given an RGB-D observation, our core insight is that a retrieved anchor affordance, which captures the desired contact point between the end-effector and the target object, can be propagated forward via affordance propagation, using the object's SE(3) pose as a natural propagation medium, to yield an affordance trajectory that provides temporally consistent, state-aware guidance throughout execution. AffordTrajDP achieves 70.0% average success rate on ManiSkill3, outperforming strong baselines by up to 17.8%. Real-world experiments on Galaxea A1 and UR7e robotic arms, covering StackCube, PickCup, AdapterInsertion, Ring-on-Peg, Put-in-Bowl, and USB Insertion, further validate robustness under object placement variations and appearance changes, with seen and unseen object instances evaluated on Galaxea A1, and ablations confirm the contribution of each proposed component.

# AffordTrajDP 论文总结

## 1. 核心问题与研究动机

- **核心问题**：现有可供性（affordance）引导的视觉运动模仿学习方法通常将接触点视为**静态先验**——一次性从演示中检索并通过单次刚体变换迁移到目标场景，之后便不再更新。这种设计在物体初始位姿对齐后基本可用，但一旦任务进入**接触后阶段**（post-contact），由于物体可能被推动、滑动或发生位姿变化，固定的接触点先验会逐渐与物体的实际状态**失准**，从而引发轨迹漂移、抖动甚至任务失败。
- **受影响的任务类型**：该问题在精度敏感任务（如插入、对齐）中尤为突出。作者明确指出，先前方法存在两种"半截子"信号：
  - 仅保留**"在何处接触"的语义**（如 AffordDP 的接触点），但丢失接触点应如何随物体运动而更新；
  - 仅保留**"物体位姿如何演化"的几何信息**（如 PRISM-DP、SPOT 的位姿轨迹），但丢失应在物体的哪个局部进行接触的语义。
- **整体含义**：作者将这种缺失形式化为"缺少一个同时保留'何处接触'与'接触如何演化'的联合条件信号"，并以此诊断为动机，提出 AffordTrajDP 作为首个构造"状态一致、时变"可供性轨迹的策略框架。

## 2. 方法论

### 核心思想
- 将**锚点接触点**（来自检索得到的静态可供性）通过**预测的 SE(3) 物体位姿轨迹**进行**刚体传播**，从而在每个未来时刻得到一个动态接触点，形成可供性轨迹 $\tau_{t:t+H}$，作为扩散策略的时变条件信号。
- "锚点"携带语义，"位姿轨迹"携带时序动态，二者结合即同时回答"接触何处 + 接触如何演化"。

### 关键技术细节

**（1）锚点可供性生成（Anchor Affordance Generation）**
- 物体记忆库 $\mathcal{M} = \{(\ell, c, z, T)\}$，其中 $c \in \mathbb{R}^3$ 为接触点，$z$ 为外观嵌入，$T \in SE(3)$ 为位姿，$\ell$ 为任务标签。
- 检索流程：
  1. 用 **GroundedSAM** 裁剪目标物体区域；
  2. 用 **CLIP** 图像编码器提取外观特征；
  3. 在同任务标签下按余弦相似度检索最近邻源实例；
  4. 通过**密集视觉对应**将源实例接触点反投影到目标 RGB-D，得到目标锚点 $c^{tgt} \in \mathbb{R}^3$。

**（2）动态可供性传播（Dynamic Affordance Propagation）**
- **位姿表达**：源物体位姿被表达在目标物体坐标系下，公式为
  $$T_{src}^{tgt}(t) = \left[T_{tgt}^{W}(t)\right]^{-1} T_{src}^{W}(t)$$
  从而消除绝对场景布局差异，提升跨实例泛化能力。
- **轨迹扩散模型**：在向量化 $x(t) = [t(t); q(t)] \in \mathbb{R}^7$（平移 + 单位四元数）上训练一个 DDIM 模型，条件为**位姿历史 $h_t$**（而非原始观测）；采用非马尔可夫确定性采样以减少噪声向可供性轨迹的传播。
- **接触点传播**：通过齐次坐标刚体变换
  $$p_{t+k} = T_{t+k}\,\tilde{c},\quad k = 0,\dots,H$$
  将锚点 $c^{tgt}$ 沿预测的位姿序列传播，得到动态可供性轨迹 $\tau_{t:t+H}$。

**（3）动作生成（Action Generation）**
- 静态可供性 $c^{tgt}$ → 2 层 MLP（256 维）编码；
- 动态可供性轨迹 $\tau^{tgt} \in \mathbb{R}^{4 \times 3}$ → 2 层 Transformer（带 [CLS] token、$d_{model}=64$、2 头、FFN=256、dropout=0.1、GELU）→ 64 维轨迹特征；
- 与其他观测融合形成条件特征 $f_t$，送入 1D 条件 U-Net 扩散策略，采用 16 步动作块、仅执行前 8 步（receding-horizon），10 Hz 控制频率。

### 算法流程概览
1. RGB-D 输入 → GroundedSAM 裁剪 + CLIP 检索 → 锚点 $c^{tgt}$；
2. FoundationPose 当前位姿 → 位姿历史 → 轨迹扩散模型 → 未来位姿序列 $\{T_{t+k}\}$；
3. 刚体传播 → 动态可供性轨迹 $\tau^{tgt}$；
4. 与点云、 proprioception 一起条件化扩散策略 → 输出动作。

## 6. 主要结论与发现

- **整体性能**：AffordTrajDP 在 ManiSkill3 6 个任务上取得 **70.0% 平均成功率**，相对 DP3（52.2%）和 AffordDP（57.8%）最高提升 **17.8%**，全面优于 DP3、AffordDP、SPOT；
- **真实场景**：
