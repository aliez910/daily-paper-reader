## 摘要
视觉-语言-动作（VLA）策略的实时部署需要异步执行，即在执行当前动作分块的同时并行计算后续动作分块，这会导致预测与执行之间的错位，并表现为分块间的不连续性。现有方法要么仅对分块边界进行表面平滑处理，要么需要昂贵的策略优化，要么仅前向预测本体感受状态而忽略了关键的视觉观测。本文提出 FutureRTC，一种即插即用的适配框架，可在不修改底层策略的前提下，为异步 VLA 控制预测执行时刻的观测与状态。具体而言，FutureRTC 包含一个状态校正模块，用于补偿前向推演所得本体感受状态与真实执行时刻本体感受状态之间的偏差；以及一个观测预测模块，通过将机器人运动作为显式的物理先验，借助运动感知特征迁移与重建来预测执行时刻的视觉表征。此外，我们引入一种策略一致性损失，以使基于预测上下文生成的动作分块与 VLA 策略在期望执行时刻输入下产生的动作分块保持一致。在仿真与真实环境中的大量实验表明，FutureRTC 对推理延迟具有更强的鲁棒性，能够生成更平滑的轨迹、实现更快的执行速度，并获得持续更高的任务成功率。

## Abstract
Real-time deployment of Vision-Language-Action (VLA) policies necessitates asynchronous execution, wherein subsequent action chunks are computed concurrently with the execution of the current chunk, leading to prediction-execution misalignment and manifesting as inter-chunk discontinuities. Existing methods either superficially smooth chunk boundaries, require costly policy optimization, or exclusively forward-predict proprioceptive states yet neglect critical visual observations. In this paper, we propose \textbf{FutureRTC}, a plug-and-play adaptation framework that predicts execution-time observations and states for asynchronous VLA control without modifying the underlying policy. Specifically, FutureRTC features a state correction module to compensate for the discrepancy between rolled-forward and actual execution-time proprioceptive states and an observation prediction module that forecasts execution-time visual representations by leveraging robot motion as an explicit physical prior through motion-aware feature transport and reconstruction. Furthermore, we introduce a policy consistency loss to align the action chunks generated from predicted contexts with those produced under the expected execution-time inputs of the VLA policy. Extensive experiments across simulated and real-world environments demonstrate that FutureRTC achieves superior robustness to inference delays, resulting in smoother trajectories, faster execution, and consistently higher task success rates.

# FutureRTC 论文总结

## 1. 核心问题与研究动机

- **背景**：视觉-语言-动作（VLA）模型（如 π0、π0.5、OpenVLA 等）规模庞大，单次推理耗时显著，而机器人控制需要高频反馈（30 Hz 以上），因此实时部署面临根本性矛盾。
- **两种执行范式的取舍**：
  - **同步执行**：每个动作分块（action chunk）必须等待推理完成才能执行，导致 stop-and-go 停顿，但分块基于最新的观测与本体感受状态，准确性高。
  - **异步执行**：在当前分块执行期间并行计算下一个分块，消除停顿、提升实时性，但生成时刻比执行时刻早 `d` 步，产生**预测-执行错位（prediction-execution misalignment）**，表现为块间不连续、轨迹抖动、误差累积。
- **现有方法缺陷**：
  - 推理时方法（如 RTC、TE、BID）：仅对块边界做启发式平滑，不解决根本错位，且引入额外运行时开销。
  - 训练时方法（如 T-RTC、REMAC、VLASH）：需对 VLA 进行昂贵重训或微调；VLASH 仅前向预测本体感受状态，忽略了陈旧视觉观测的关键影响。
- **本文目标**：在不修改底层 VLA 策略的前提下，预测执行时刻的观测与状态，缓解预测-执行错位，实现**准确、平滑、快速**三者的统一。

## 2. 方法论

### 核心思想
设计一个**即插即用的预期适配器** ϕ(·)，从陈旧的对 (o_{t+K−d}, s_{t+K−d}) 出发，结合已提交动作序列，预测执行时刻的对 (ẑ_{t+K}, ŝ_{t+K})，使冻结的 VLA 策略生成的下一分块自然对齐到执行时刻 t+K。

### 关键技术模块

- **状态校正模块（SCM, ϕ_SCM）**：
  - 先用已提交动作序列对陈旧状态做前向积分，得到 s̃_{t+K} = s_{t+K−d} ⊕ Σ a_i。
  - 用 MLP 预测补偿残差 s̃_Δ = ϕ_SCM(s̃_{t+K}, d/d_max)，最终 ŝ_{t+K} = s̃_{t+K} ⊕ s̃_Δ。
  - 损失函数：`L_state = ‖(s_{t+K} ⊖ s̃_{t+K}) − s̃_Δ‖²`，仅需几百行参数（+0.04 M）。

- **观测预测模块（OPM, ϕ_OPM）**：
  - 在 VLA 视觉编码器的**隐空间**而非像素空间操作，保证与冻结策略兼容且计算开销低。
  - **运动先验构建**：对延迟窗口内的每个动作 a_i，构造物理特征向量 u_i = [a_i, Σa_j, a_i − a_{i−1}, Σ|a_j|, i/d]，送入时序自注意力得到动作条件运动先验 c_motion。
  - **特征迁移（Transport）**：由 c_motion + 陈旧隐变量 z_{t+K−d} + 相机嵌入 + 位置嵌入 + 校正状态 ŝ_{t+K} 经线性/卷积层投影为 2D 流场 Δp 和迁移门 α∈[0,1]，通过可微分双线性采样得到 z_trans = (1−α)·z_{t+K−d} + α·W(z_{t+K−d}, p−Δp)。
  - **门控残差合成（Synthesis）**：另一分支基于 F、z_trans − z_{t+K−d}、初始观测 z_0 预测合成特征 r 与合成门 β，最终 ẑ_{t+K} = z_trans + β·r。β 用以补偿无法由几何迁移解释的内容（如接触形变、新暴露区域）。
  - 损失函数：`L_obs = ‖z_{t+K} − ẑ_{t+K}‖²`。

- **策略一致性损失（L_policy）**：
  - 用单步 flow-matching 近似，让冻结策略在 (ẑ, ŝ) 下生成的分块逼近在真实执行时刻对 (z_{t+K}, s_{t+K}) 下生成的分块：`L_policy = ‖πθ(z,s) − πθ(ẑ,ŝ)‖²`。
  - 总损失：`L_total = L_state + L_obs + λ·L_policy`，λ=10。

### 算法流程
1. 在生成时刻 t+K−d 取陈旧观测隐变量 z_{t+K−d}、本体感受状态 s_{t+K−d}。
2. SCM 用已提交动作校正状态 → ŝ_{t+K}。
3. OPM 以 (z_{t+K−d}, 已提交动作, ŝ_{t+K}) 为输入预测 → ẑ_{t+K}。
4. VLA 策略生成 A_{m+1} = πθ(·|ẑ_{t+K}, ŝ_{t+K})，因对齐到执行时间 t+K，可直接从索引 [0: K−1] 执行，不再丢弃前 d 个动作。

## 6. 主要结论与发现

- 在所有仿真基准与真实任务上，FutureRTC 在不同延迟下均取得**最高成功率与最少执行步数/时间**。
- LIBERO 上 π0.5 成功率从 d=5 到 d=20 仅下降 5.7%、SmolVLA 下降 6.4%；Kinetix 从 d=0 到 d=4 仅下降 3.0%。
- 视觉观测陈旧是错位的**主要来源**：仅校正状态对 π0.5 收益甚微（因状态以文本 token 编码），校正观测即可恢复绝大部分性能；二者同时校正在 A[0:K−1] 执行下达到延迟无关上界，证明异步执行本身无内在性能损失，关键在于上下文对齐。
- FutureRTC 生成的轨迹速度/加速度最平滑，块边界无明显尖峰。
- 延迟 d 越大，相较基线的优势越显著；小延迟下与若干训练时方法接近但仍具竞争力。

## 7. 优点与亮点

- **真正即插即用**：冻结 VLA 权重不变，适配器仅引入约 5–6 M 参数与约 3 ms 推理延迟，可直接复用到不同 VLA 骨干（已验证 π0.5 与 SmolVLA）。
- **首创同时预测执行期视觉与状态**：相比 VLASH 仅前向预测本体感受状态，将视觉信息纳入预测显著提升延迟鲁棒性。
- **显式物理先验**：把已提交动作映射为物理特征并通过运动感知 warping 迁移视觉特征，比直接让网络隐式学习前向积分更可解释、更稳定。
- **门控双分支设计**：迁移门 α 处理几何位移，合成门 β 处理无法迁移的内容（接触形变、新暴露区域），分工明确。
- **策略一致性损失**：把预测上下文与冻结 VLA 期望的分布对齐，避免预测漂移。
- **多维度验证**：仿真+真实、多种延迟、多种骨干、消融、平滑度、错位来源分析兼具，论证链条完整。

## 8. 不足与局限

- **应用场景假设**：观测预测模块基于"机器人是场景变化的主因"这一前提，在由独立外部主体主导的高动态场景（如人机共处、移动障碍物）中可能失效，作者在 Limitation 中明确指出。
- **策略架构限制**：当前实现仅适用于 **flow-matching VLA**，且在隐空间中预测视觉；尚未扩展到自回归策略或离散扩散策略（如 DiscreteRTC），作者声明为未来工作。
- **真实世界覆盖有限**：仅 3 个双臂任务、2 档延迟、单一机器人平台（AgileX Cobot Magic），泛化性证据尚不充分。
- **训练资源与时长未披露**：仿真训练的 wall-clock 时间、训练数据规模、收敛细节未给出，难以评估实际部署成本。
- **对极端延迟的鲁棒性未充分测试**：LIBERO 上限 d=20，更高延迟下（如 d=30+）表现未知。
- **缺乏对失败案例的系统分析**：未对失败模式（如遮挡、强光、快速运动模糊）做定性剖析。
- **理论保证缺失**：方法本身是经验驱动的，没有对预测误差的传播或稳定性进行理论刻画。
