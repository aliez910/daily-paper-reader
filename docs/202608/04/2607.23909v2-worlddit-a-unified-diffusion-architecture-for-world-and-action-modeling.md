## 摘要
许多最新的机器人策略通过使用大型预训练视觉-语言模型（VLMs）作为动作骨干网络来追求更强的控制能力。我们提出了 WorldDiT，一种统一的扩散 Transformer 架构，它将动作生成与视觉世界建模相结合，在不使用大型预训练 VLM 动作骨干网络的情况下取得了优异的性能。在训练过程中，单个扩散 Transformer 生成连续的动作块，并从未来相机帧预测归一化的 RGB patch 目标。在四个 LIBERO 仿真套件中，WorldDiT 在总模型参数与平均成功率之间处于报告的帕累托前沿上，是报告了全部四个套件结果的方法中的最优。这些结果为未来规模扩展研究提供了一个强大的亚十亿参数基线。

## Abstract
Many recent robot policies pursue stronger control by using large pretrained vision-language models (VLMs) as the action backbone. We introduce WorldDiT, a unified diffusion transformer architecture that couples action generation with visual world modeling and achieves strong performance without a large pretrained VLM action backbone. During training, a single diffusion transformer generates continuous action chunks and predicts normalized RGB patch targets from future camera frames. Across four LIBERO simulation suites, WorldDiT lies on the reported Pareto frontier for total model parameters and mean success among methods reporting all four suites. These results provide a strong sub-billion-parameter baseline for future scaling studies.

# WorldDiT 论文总结

## 一、研究动机与核心问题

- **领域背景**：当前主流机器人策略普遍采用大型预训练视觉-语言模型（VLM）作为动作骨干网络，以获得更强的感知与泛化能力。
- **关键困惑**：当策略参数量高达数十亿时，难以拆解"动作设计、预训练骨干、二者组合"三者各自对性能提升的贡献。
- **核心问题**：能否在不依赖大型预训练 VLM 的前提下，利用一个统一的扩散 Transformer 架构同时完成"动作生成"与"未来视觉预测（世界建模）"，并保持优异的控制性能？
- **本文目标**：为未来的缩放研究提供一个十亿参数以下的强基线。

## 二、方法论：核心思想与技术细节

### 2.1 核心思想

- 使用 **一个共享的扩散 Transformer（DiT）骨干**同时建模两类目标：
  - 连续动作块生成；
  - 未来相机帧的归一化 RGB patch 预测（作为辅助监督）。
- 训练时双任务联合学习，**推理时仅走动作路径**，RGB 分支不进入推理计算图。

### 2.2 关键技术细节

- **输入窗口**：长度 N=10，其中 C=3 个已观测步 + 7 个目标动作步 + 1 个未来 RGB patch 目标（来自 i+H 时刻的主腕相机帧）。
- **多模态编码**：
  - 视觉：冻结的 MAE 图像编码器 + 共享 Perceiver Resampler；
  - 语言：冻结的 CLIP 文本编码器；
  - 状态：可训练的机械臂/夹爪独立编码 + 线性投影得到每步一个状态 token。
- **RGB patch 预处理**：CLIP-预处理的 224×224 RGB 帧切成 16×16 patch（768 维），按各自均值方差归一化，每相机保留 64 个均匀间隔的 patch，拼接得 Y_rgb ∈ ℝ^{128×768}。
- **可训练投影接口**：线性输入投影将 768 维 patch 映射到骨干隐维度；RGB 输出投影再映射回 768 维 patch 速度。
- **骨干配置**：depth=4，hidden size=1024，16 个注意力头，4 个 register token。
- **动作块**：H=7 步连续动作 A_i ∈ ℝ^{7×7}。

### 2.3 训练目标（Flow Matching）

- 对动作或 RGB patch 目标 y，采样 ε∼N(0,I)，τ∼U[0,1]，构建：
  - x_τ = (1−τ)ε + τy
- 损失函数：
  - L_flow = E_{ε,y,τ} ‖v_θ(x_τ,τ,c) − (y−ε)‖²
- 总损失（仅最后一个时间步产生监督）：
  - **L_total = w_action · L_action_flow + w_rgb · L_rgb_flow**
  - 实际权重：w_action = 0.1，w_rgb = 0.001

### 2.4 推理流程

- 仅以 H_t = {ℓ, {(o_j, s_j)}} 条件化骨干；
- 从 N(0,I) 初始化动作 token；
- 用 **20 步欧拉积分**沿速度场从 τ=0 积分至 τ=1，得到 7 步动作块；
- **执行前 3 个动作、更新观测窗口、重新规划**（receding-horizon + 时序集成）。

## 三、实验设计

### 3.1 数据集与基准

- **基准**：LIBERO 操作基准（Liu et al., 2023）；
- **下游套件（4 个）**：libero_spatial、Spatial；libero_object、Object；libero_goal、Goal；libero_10（Long）；
- **预训练数据**：libero_90 多任务拆分，仅用于 pretrain，不评估。

### 3.2 对比方法

- 共对比 **24 种方法**，按"是否使用大型预训练 VLM 作为动作骨干"分组：
  - **含大型 VLM 骨干**：ACoT VLA、MMaDA VLA、VLANeXt、VLA Adapter、OpenVLA-OFT、π0.5、MemoryVLA、Discrete Diffusion VLA、VLA-0、π0、GR00T N1、UD VLA、π0-FAST、CoT VLA、WorldVLA、SpatialVLA、OpenVLA；
  - **不含大型 VLM 骨干**：WorldDiT、DreamVLA、FlowVLA、DiT Policy、Octo、Diffusion Policy、Seer。

### 3.3 评估协议

- 每个套件 500 次仿真回放（共 2000 次）；
- 采用动作集成 + 时序集成；
- 无头 EGL 渲染；
- 使用 5000 次自我中心随机初始化；
- **注意**：报告的 94.9% 包含用于中间检查点选择的 300 次/套数据，并非完全留出。

## 四、资源与算力

- **硬件**：单节点 8 × **NVIDIA RTX Pro 6000** GPU；
- **精度**：bf16 混合精度；
- **预训练**（libero_90）：30 epochs，per-GPU 批量=40，梯度累积=2，学习率 1×10⁻⁴，余弦退火 + 1 epoch 预热；

- **未明确公布**：单次训练的总时长（小时/天数）、总 GPU 小时；
- **推理**用 20 步欧拉积分，无具体延迟数据。

## 五、实验数量与充分性

- **实验数量**：
  - 4 个下游套件各做一次配置评估（同一架构），即"1 配置 × 4 套件"；
  - 无显式消融：未对 RGB patch 损失权重、骨干深度/宽度、上下文长度 C、动作块长度 H、动作执行前缀长度等做对比；
  - 无真实世界实验；
  - 无跨基准测试（如 Meta-World、RLBench、RoboSuite 等）。
- **公平性问题**：
  - 对比方法的分数来自**已发表报告**而非统一协议下重跑；
  - WorldDiT 自身分数包含"用于检查点选择的 300 次/套"数据，存在留出集污染风险；
  - 部分方法（如 Seer）的全四套件均值缺失，被排除在 Pareto 之外；
  - 缺乏随机种子敏感性分析、置信区间或多次独立训练的误差统计。
- **整体评价**：实验覆盖面**有限**，更接近"一份强基线声明"，而非系统性研究。

## 六、主要结论与发现

- 在 LIBERO 四套件上，WorldDiT 分别取得 **Spatial 98.0%、Object 97.0%、Goal 92.8%、Long 91.8%、均值 94.9%**；
- 总参数 **399.084M**，可训练参数 **135.107M**；该数据点**位于已报告方法的参数-成功率 Pareto 前沿上**；
- 凡是均值高于 WorldDiT 的方法，其总参数量都更大；而总参数量相同或更少的方法，均值均更低；
- 表明：**不依赖大型 VLM 骨干，也能用统一扩散 Transformer 实现有竞争力的控制与世界建模**；
- 讨论中指出：未来可探索归一化 RGB 目标对控制质量的影响、缩放行为以及向异构/低算力平台的部署（如 Paris 系列去中心化思路）。

## 七、优点

- **架构创新**：首次明确提出"单一 DiT 骨干 + 动作流 + 归一化 RGB patch 流"的双流统一扩散，并以 flow matching 形式同构处理；
- **部署简洁**：训练时双任务，推理时仅走动作分支，模型部署图无 RGB 头，不引入额外推理开销；
- **参数效率高**：在不到 4 亿总参数下达到 Pareto 前沿，远小于多数数十亿参数的 VLA/VLM 方案；
- **多视角融合**：同时利用主腕相机和腕部相机作为 RGB patch 源，提供更丰富的世界监督；
- **代码与权重开源姿态**（bageldotcom/worlddit），便于后续复现与研究。

## 八、不足与局限

- **实验规模有限**：
  - 仅测试一组配置，没有做模型尺寸/数据规模的消融，无法证伪或支持"更大即更好"的缩放猜想；
  - 无真实环境实验，仿真到现实的迁移未验证；
- **评估公平性存疑**：
  - 报告 94.9% 包含 300 次/套的中间检查点选择数据，并非完全留出测试；
  - 对比方法采用各自论文中报告分数，未在统一协议下重跑；
  - 缺失置信区间与多次随机种子统计；
- **方法与目标层面的局限**：
  - 辅助 RGB patch 监督仅作用于最后一个时间步，单步目标能否充分捕捉多步动态仍有疑问；
  - RGB patch 损失权重（0.001）远小于动作损失权重（0.1），辅助任务贡献的边际效益未做敏感性分析；
  - RGB patch 的"按各自均值方差归一化"使得视觉目标实际去除了强度信息，对动态预测的指导价值需进一步验证；
- **数据局限**：仅基于 LIBERO 仿真，缺少对长时序、复杂接触、灵巧操作场景的覆盖；
- **开放性问题**：是否能在更大规模（如十亿参数以上）持续保持 Pareto 前沿，尚未可知。
