## 摘要
视觉-语言-动作（VLA）模型在通用机器人操控任务中展现出了强大的潜力，但现有的大多数模型依赖于二维视觉-语言骨干网络，缺乏对目标物体的细粒度三维理解，尤其是在遮挡、姿态变化、尺度变化以及精确空间交互等情况下。我们提出了一种基于 π₀ 构建的以物体为中心的三维表征对齐框架，在训练阶段使用 SAM3D 作为冻结的三维教师模型来提供目标物体的三维先验。具体而言，我们利用物体识别模型定位任务相关物体，生成相应的物体掩码，并使用 SAM3D 提取稠密的物体级三维表征，再将其与 π₀ 的中间视觉特征进行对齐。这使得策略能够在保留原始 RGB-语言-动作推理流程的同时内化目标物体的三维信息，并且在测试时无需深度、点云、掩码、SAM3D 或额外的三维模块。仿真实验表明该方法取得了持续的性能提升，在 LIBERO 上达到了 99.1%，在 CALVIN 上取得了 4.11 的平均长度。真实世界实验进一步证明，我们的方法在长时序操控场景中尤为有效，在这类场景中机器人需要在多个子任务中聚焦于不同的目标物体。

## Abstract
Vision-Language-Action (VLA) models have shown strong potential for general robot manipulation, but most existing models rely on 2D visual-language backbones and lack fine-grained 3D understanding of target objects, especially under occlusion, pose variation, scale changes, and precise spatial interaction. We propose an object-centric 3D representation alignment framework built upon $π_0$, using SAM3D as a frozen 3D teacher to provide target-object 3D priors during training. Specifically, we localize task-relevant objects with object recognition models, generate corresponding object masks, and use SAM3D to extract dense object-level 3D representations, which are aligned with intermediate visual features of $π_0$. This enables the policy to internalize target-object 3D information while preserving the original RGB-language-to-action inference pipeline without requiring depth, point clouds, masks, SAM3D, or additional 3D modules at test time. Simulation experiments show consistent improvements, achieving 99.1\% on LIBERO and an average length of 4.11 on CALVIN. Real-world experiments further demonstrate that our method is particularly effective in long-horizon manipulation scenarios where the robot must focus on different target objects across multiple subtasks.

- **背景**：视觉-语言-动作（VLA）模型（如 π₀、OpenVLA、SpatialVLA 等）已成为通用机器人操控的重要范式，依赖大规模预训练的视觉-语言骨干网络理解指令并预测动作。
- **瓶颈**：现有 VLA 模型主要依赖 2D RGB 图像，仅从动作预测目标中隐式学习视觉表征，难以捕捉目标物体的 **3D 几何特性**（形状、位姿、尺度、空间布局）。

- **核心问题**：能否在 **不改变推理管线**（不引入深度图、点云、掩码或额外 3D 模块）的前提下，向 RGB-based VLA 中注入以物体为中心的 3D 知识？

## 2. 方法论

### 2.1 整体框架
- 基于 π₀（SigLIP 视觉编码器 + Gemma-4B 多模态 Transformer + 连续动作专家 + 流匹配）构建。
- **训练时**：引入冻结的 SAM3D 作为 3D 教师，为中间视觉特征提供物体级 3D 监督；**推理时**：完全沿用 π₀ 的 RGB-语言-动作管线，无需任何 3D 额外输入。

### 2.2 关键技术细节

**（1）物体定位与掩码生成**
- 用 Grounding DINO / YOLO 等开放词汇检测模型定位子任务相关目标；
- 用 SAM2 分割生成二值物体掩码 M̃ₜ；
- 多视图图像-掩码对展平后输入 SAM3D 提取稠密 3D 特征 Tₜ ∈ ℝ^(BV)×L_T×D_T)。

**（2）空间-维度对齐**
- 将 SAM3D 教师 token 重塑为 2D 网格 T²Dₜ，通过 **双线性插值** 重采样至学生视觉 token 分辨率 (H_S, W_S)，得到 ¯T₂Dₜ ∈ ℝ^(BV)×D_T×H_S×W_S；
- 展平并重组多视图：¯Tₜ ∈ ℝ^(B×V L_S)×D_T；
- 学生侧提取 Gemma 第 m 层视觉特征 Sₜ = h⁽ᵐ⁾ₜ ∈ ℝ^(B V L_S)×D_S；
- 通过投影器 P_φ 将学生特征映射到 SAM3D 空间：T̂ₜ = P_φ(Sₜ)。

**（3）以物体为中心的对齐损失**
- 构造 token 级掩码 mₜ 并沿特征维扩展为 Mₜ；
- 对师生特征做 ℓ₂ 归一化后，仅在目标物体 token 上计算归一化 MSE：
  
  ℒ_align = MSE( Norm(T̂ₜ)[Mₜ],  Norm(¯Tₜ)[Mₜ] )

- 总损失：ℒ = ℒ_action + α ℒ_align（流匹配动作损失 + 对齐损失）。

**（4）子任务感知数据处理（长时序关键）**
- 对高层指令用 GPT-4o 分解为子任务序列；
- 每个子任务关联其对应目标物体的掩码，提供 **阶段特异性**（stage-specific）的 SAM3D 监督，使策略在不同操控阶段聚焦不同目标。

**（5）冻结表征探针实验（机制验证）**

- 探针性能提升 ⇒ 学到的 VLA 特征能更好地恢复 SAM3D 式物体 3D 先验。

## 6. 主要结论与发现

- **LIBERO**：SAM3D-VLA 平均 SR 达 **99.1%**（Spatial 99.2 / Object 99.7 / Goal 99.1 / Long 98.4），在 Long 子集上显著优于多数 2D / 3D VLA（π₀ 85.2%、Spatial Forcing 96.0%）；
- **CALVIN**：平均长度 **4.11**，5 步成功率 **71.6%**，超过 ReconVLA（3.95 / 64.1%）和 UniVLA（3.80）；
- **真实世界**：平均成功率 ST 从 50.2% → **65.2%**，OC 从 21.3% → **44.3%**；长时序任务（Cook / Flower / Stack）增益尤为突出；
- **机制**：探针实验证明对齐训练后，SAM3D 式 3D 物体先验可从 VLA 中间特征中更准确地恢复，验证了知识蒸馏的有效性。

## 7. 优点与亮点

- **训练-推理解耦设计**：3D 监督仅在训练阶段，推理时完全保持原始 RGB→动作管线，部署成本零增加；
- **物体中心而非场景中心**：聚焦任务相关目标，避免全局 3D 表示带来的冗余与歧义；
- **子任务感知机制**：通过 GPT-4o 分解指令 + 阶段特定物体掩码，针对长时序中切换目标场景提供针对性监督；
- **归一化 MSE 对齐损失**：对师生特征尺度差异鲁棒，关注方向一致性而非绝对幅值；
- **冻结探针验证**：不仅报告性能指标，还提供表征层面的可解释性证据；
- **跨平台验证**：仿真（LIBERO + CALVIN）+ 真实机器人双线验证，覆盖基础与长时序、ST 与 OC 设置。

## 8. 不足与局限

- **依赖管线噪声**：训练依赖自动生成的子任务标注、检测与分割结果，分解/接地/分割错误会引入噪声监督；
- **教师模型局限**：SAM3D 仅处理单图像，在严重遮挡、透明物体、视角不佳场景下可靠性受限；
- **真实世界覆盖有限**：仅在单一机器人平台（Piper-X）的桌面任务上验证，缺少多平台、多形态机器人泛化；
- **缺乏系统消融**：未提供 α、对齐层 m、子任务分解必要性、视觉接地 vs. 物体中心消融等的完整消融；
