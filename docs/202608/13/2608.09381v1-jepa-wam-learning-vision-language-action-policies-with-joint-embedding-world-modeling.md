## Abstract
Robust robot control benefits from explicitly modeling state transitions, but video-generation world action models (WAMs) introduce substantial deployment cost. Existing latent WAMs avoid explicit future generation, but often compress predictive representations or separate predictive modeling from the representations used for action generation. We introduce JEPA-WAM, a latent WAM built in a pretrained V-JEPA space, which couples latent transition prediction with continuous action generation through a shared predictor. JEPA-WAM predicts a spatially structured joint current-future target that captures task-shared visual temporal structure between current and future observations, while preserving dense patch-level correspondence. Through the shared predictor, transition supervision directly shapes the backbone, from which dedicated representations are extracted for action prediction. The same design can also be instantiated in pretrained VLA policies while preserving their original perception and action pathways. On LIBERO-Plus, JEPA-WAM achieves 79.2%, the best result without large-scale robot-policy pretraining, while its pretrained $π_{0.5}$ instantiation reaches 86.3%, achieving the best overall performance. Experiments on RoboTwin 2.0 and real-world bimanual manipulation further demonstrate strong generalization under visual and spatial shifts.

# JEPA-WAM 论文总结

## 一、核心问题与研究背景

### 1.1 核心问题
- **机器人控制的鲁棒性瓶颈**：现有 VLA 策略（如 π0、OpenVLA、RDT-1B）的动作预测目标仅隐式建模状态转移，在分布偏移下鲁棒性受限。
- **世界动作模型（WAM）的部署代价**：基于视频生成的 WAM（WorldVLA、GigaWorld-Policy 等）需迭代生成未来帧，部署成本高昂。
- **潜在 WAM 的两大设计缺陷**：
  - **预测表征层面**：要么复用视频生成器的中间特征（并非为状态变化表示而优化），要么将未来观测压缩为少量 latent token / 子目标（丢失细粒度空间结构）。
  - **策略整合层面**：要么将预测的未来表征作为动作模块的附加上下文（可能引入冗余信息），要么引入独立的预测目标或潜在动力学模块（对动作生成所用表征的影响较弱）。

### 1.2 研究动机
需要一种潜在 WAM，既能保留世界建模的预测能力，又不依赖显式未来帧生成，并通过统一架构让预测监督直接塑造动作生成所用的主干表征。

## 二、方法论

### 2.1 整体框架
JEPA-WAM 由四个核心组件构成：
1. **冻结的 V-JEPA 2.1 编码器**（300M 参数，ViT-L/16，384×384 输入，输出 24×24 网格 patch token）
2. **视觉投影器 P_vis**：两层的 MLP（1024→896→896），将 V-JEPA 特征映射到 Qwen 隐藏空间
3. **共享预测器 F_θ**：基于 Qwen2.5-0.5B，处理视觉 token、任务指令 ℓ 和专用 action placeholder token Pact
4. **DiT 动作专家 A_ψ**：16 层 DiT-L 流匹配模型，预测动作块

### 2.2 关键技术细节

#### （1）当前视觉表征
对每个相机视图独立编码，并按固定相机顺序拼接多视图视觉 token：

$$Z_t = \text{Concat}_{v \in V} E_J(O_t^v) \in \mathbb{R}^{N_{vis} \times d_J}$$

保留 patch 级别的相机与空间 token 顺序，作为 JEPA-WAM 的潜在视觉状态空间。

#### （2）联合当前-未来目标
训练时将 t 与 t+δ 时刻的观测沿时间维度拼接，联合输入 V-JEPA 编码器（利用 V-JEPA 的两帧 tubelet 机制保持 24×24 空间网格）：

$$Y_{t,t+\delta} = \text{Concat}_{v \in V} \text{sg}\left[E_J(\text{Stack}_{time}(O_t^v, O_{t+\delta}^v))\right]$$

- 强调两时刻的**视觉关系**（稳定/变化区域、局部物体与空间关系演化）
- **不要求重建唯一未来观测**，避免对单一未来过度承诺
- 保留 **patch 级空间结构**（不进行全局池化或压缩）

#### （3）共享预测器
$$(Q_t^{wm}, C_t) = F_\theta(P_{vis}(Z_t), \ell, P_{act})$$

- **Q_t^{wm}**（视觉 token 位置的隐藏态）：用于预测联合目标，保留相机和空间顺序
- **C_t**（专用 action placeholder 的隐藏态）：用于动作条件化，聚合视觉与任务上下文

#### （4）潜在转移预测
预测头 G_ϕ（MLP：896→2048→1024）将 Q_t^{wm} 映射回 V-JEPA 空间：

$$\hat{Y}_{t,t+\delta} = G_\phi(Q_t^{wm})$$

采用 **patch 级余弦距离损失**（均值）：

$$\mathcal{L}_{wm} = \frac{1}{BN_{vis}}\sum_{b=1}^{B}\sum_{n=1}^{N_{vis}}\left(1 - \cos(\hat{Y}^{(b)}_{t,t+\delta,n}, Y^{(b)}_{t,t+\delta,n})\right)$$

#### （5）动作生成（流匹配）
采用 StarVLA 风格的 DiT 动作专家，条件流匹配：

$$\mathcal{L}_{act} = \mathbb{E}_{\epsilon, \tau}\left\|A_\psi(a_\tau, \tau, s_t, C_t) - (a - \epsilon)\right\|_2^2$$

其中 $a_\tau = (1-\tau)\epsilon + \tau a$，τ 由 Beta 分布采样（α=1.5, β=1.0）。

#### （6）联合训练与部署
$$\mathcal{L} = \mathcal{L}_{act} + \lambda_{wm} \mathcal{L}_{wm}, \quad \lambda_{wm} = 0.5$$

**部署时移除目标分支与预测头**，仅保留当前帧 V-JEPA 编码器、视觉投影器、共享预测器与动作专家，使用 4 步欧拉积分生成动作块。

#### （7）迁移至预训练 VLA（π0.5）
在 π0.5 的 VLM 前缀追加 64 个可学习 future token，重塑为 8×8 空间网格，经 LayerNorm+MLP（2048→2048→1408）+ 双线性上采样至 24×24，对齐到 V-JEPA 的联合目标：
- action token 被遮蔽，禁止关注 future token
- 原始感知与动作通路完全保留
- 转移损失权重经 1K 步线性升温至 λ_wm=0.1

## 六、主要结论与发现

### 6.1 性能结论
- **LIBERO**（分布内）：平均成功率 **96.7%**，与强基线相当；π0.5 + JEPA Obj. 达 **97.8%**（从 96.9% 提升）

- **真实世界**：JEPA-WAM 取得 ID 59.8% / OOD 54.2%（vs. π0 的 51.8% / 22.5%）；π0.5 + JEPA Obj. 提升至 ID 90.3% / OOD 84.7%

### 6.2 设计发现
- **视觉表征**：V-JEPA 单独替换 DINOv2+SigLIP 即可提升 3.8%（73.2→77.0），尤其在 Camera/Light/Noise 扰动上
- **转移目标**：联合当前-未来目标（79.2%）> Future only（77.3%）>> Endpoint difference（70.9%）
- **空间结构**：iREPA 式卷积变换使性能从 79.2% 降至 74.7%
- **监督层级**：对预测器最终层监督优于第 16 层（79.2% vs. 76.5%）
- **动作条件化**：专用 action placeholder 优于 full hidden（79.2% vs. 73.1%）
- **表征分析**：联合目标保留超出端点差异的**时间间隔信息**（分类 67.2% vs. 47.0%）、对**未见时间间隔的泛化能力**（MAE 8.88 vs. 13.32）、以及**去除端点位移后的轨迹结构**（R² 0.582 vs. 0.485）

## 七、优点与亮点

- **方法统一性**：共享预测器同时承担转移预测与动作条件化，避免引入额外模块或分离的动力学头
- **目标设计精巧**：联合当前-未来目标同时表达时间关系与空间结构，无需未来帧生成
- **空间对应保留**：patch 级余弦距离保持端到端空间监督，对位置敏感变化友好
- **零额外部署开销**：推理时无需目标编码与转移预测，延迟仅 85 ms（接近 π0.5 的 54 ms）
- **强迁移性**：作为即插即用附加分支可加载到 π0.5，不改变原感知/动作通路
- **深入表征分析**：不仅给出策略消融，还通过冻结探针从表征层面解释联合目标的优越性
- **完备实验覆盖**：仿真 3 基准 + 真实双臂 + 20 任务全表 + 6 项消融 + 4 项表征探针
