## 摘要
具身智能同时要求长时序推理与实时闭环响应能力。近期提出的双系统视觉-语言-动作（VLA）架构融合了快速反应控制与慢速审慎推理，以平衡推理速度与任务成功率。然而，现有双过程VLA将快速模块紧密耦合于慢速模块的中间表征之上，需进行端到端联合训练，限制了模块化、可扩展性以及系统切换的灵活性。本文提出环境感知模型选择（EMS），一种通过环境感知模型选择在不同规模的两个完全解耦系统间进行切换的自适应VLA推理框架。大规模审慎系统提供全局一致的轨迹规划以确保任务成功，而轻量级反应系统实现高频闭环控制。基于强化学习的切换策略根据实时反馈动态选择调用哪个系统，从而稀疏使用慢速系统，在预训练知识利用与运行效率之间取得平衡。相较于先前的分层VLA框架，我们的设计具有三大优势：（1）完全解耦且模块化的双系统架构，支持即插即用的模型替换；（2）自适应、环境感知的切换策略；（3）面向响应式闭环控制的高频推理。我们在仿真与真实环境中对EMS进行了广泛评估。在LIBERO基准上，EMS在达到与大规模基线相当的成功率的同时，将有效动作频率提升至93.4 Hz。该框架在真实双臂操控任务中进一步展现出强大的可扩展性，在保持稳健性能的同时加速了任务完成。

## Abstract
Embodied intelligence demands both long-horizon reasoning and real-time closed-loop responsiveness. Recent dual-system Vision-Language-Action (VLA) architectures combine fast reactive control with slow deliberative reasoning to balance inference speed and task success rate. However, existing dual-process VLAs tightly couple the fast module to intermediate representations of the slow module, necessitating end-to-end joint training and limiting modularity, extensibility and flexible system switching. In this paper, we propose Environment-aware Model Selection (EMS), an adaptive VLA inference framework that switches between two fully decoupled systems of different scales through environment-aware model selection. The large-scale deliberative system provides globally consistent trajectory planning to ensure task success, while a lightweight reactive system enables high-frequency closed-loop control. A reinforcement-learning-based switching policy dynamically selects which system to invoke based on real-time feedback, enabling sparse use of the slow system and thereby balancing pretrained knowledge utilisation with runtime efficiency. Our design offers three key advantages over prior hierarchical VLA frameworks: (1) a fully decoupled and modular dual-system architecture that supports plug-and-play model replacement; (2) an adaptive, environment-aware switching strategy; (3) high-frequency inference for responsive closed-loop control. We extensively evaluate EMS in both simulation and real-world environments. On the LIBERO benchmark, EMS achieves success rates comparable to the large-scale baseline while increasing the effective action frequency to 93.4 Hz. The framework further demonstrates strong extensibility in real-world dual-arm manipulation tasks, where it accelerates task completion while maintaining robust performance.

## 二、方法论

### 2.1 整体框架：EMS（Environment-aware Model Selection）
EMS 由三个组件构成：
1. **System 2（慢系统/审慎系统）**：大参数 VLA（如 PI0），生成动作块（action chunk），约 10 Hz 推理，提供全局一致的轨迹规划；
2. **System 1（快系统/反应系统）**：轻量视觉运动策略（如 BCVILT、ACT），约 100 Hz 推理，独立端到端动作生成；
3. **轻量切换模块**：基于强化学习的浅层全连接网络，仅以机器人状态 $s_t$ 作为输入（避免引入计算瓶颈），二分类决策选择调用哪个系统。

**关键设计原则**：两个系统**仅在动作层面交互**，不共享中间特征，**架构无关（architecture-agnostic）**，支持即插即用。

### 2.2 问题形式化
系统选择被建模为**两动作马尔可夫决策过程（MDP）**：
- 状态：机器人状态 $s_t$；
- 动作：$\hat{a}_t \in \{0, 1\}$，0 表示快系统，1 表示慢系统；
- 奖励：稀疏的回合奖励 $R_{total}$（成功为 $+r$，失败为 $-r$），均匀分配到每步：$r_t = R_{total}/T$。

### 2.3 执行工作流（闭环三步）
1. **切换决策**：切换模块基于当前状态 $s_t$ 选择系统；
2. **策略推理**：选定系统基于观测 $o_t$（含多视角 RGB、语言指令）生成动作或动作块；
3. **动作执行**：执行完整动作序列后到达下一决策边界。

### 2.4 动作融合（Action Fusion）
为缓解切换边界处的控制不连续，对切换时刻的动作做平均：
$$a_t = \frac{a_t^{fast} + a_t^{slow}}{2}$$
- **慢→快**：将慢系统规划块中的重叠动作与快系统最新观测的动作融合；
- **快→慢**：快系统额外执行一步再融合。

### 2.5 分阶段训练流水线

| 阶段 | 目标 | 训练方式 |
|------|------|----------|
| **Stage I** | 微调 System 2 | 在遥操轨迹 $D_{tele}$ 上模仿学习：$\max_{\theta_2} \mathbb{E}[\log \pi_{slow}(a_t\|o_t, l)]$ |
| **Stage II** | 蒸馏 System 1 | 用微调好的 System 2 生成成功回放 $D_{distill}$，System 1 从头模仿学习，对齐慢系统的轨迹分布：$\max_{\theta_1} \mathbb{E}[\log \pi_{fast}(a_t\|o_t, l)]$ |
| **Stage III** | 训练切换模块 | 同时采用在线 RL（DQN）与离线 RL（IQL）两条路线 |

**Stage III 关键技术细节**：
- **在线 DQN**：Double Q-learning + Dueling Network + NoisyNet（自适应探索）+ 优先经验回放（按 TD-error 采样）；
- **离线 IQL**：避免外推误差，通过 advantage-weighted 行为克隆隐式策略提升：
  - $L_Q = \mathbb{E}[(r_t + \gamma V_\psi(s_{t+1}) - Q_\theta(s_t, \hat{a}_t))^2]$
  - $L_V = \mathbb{E}[\rho_\tau(Q_\theta(s_t, \hat{a}_t) - V_\psi(s_t))]$（expectile regression）
  - $L_\pi = \mathbb{E}[\exp(\beta A(s_t, \hat{a}_t)) \log \pi_\phi(\hat{a}_t|s_t)]$

### 2.6 关键指标定义
- **切换比 $\rho_{sw} = N_{slow} / N_{fast}$**：一回合内慢系统调用动作数与快系统调用动作数之比；
- **有效动作频率 $f_{action} = N_{chunk} \times f_{infer}$**：分块策略下等效控制频率。

## 六、主要结论与发现

1. **性能-效率平衡**：EMS 在 LIBERO 上达到 **92.40% 平均成功率**，与 System 2（PI0, 94.15%）相当，但**将切换比从 0.33 降至 0.153**，有效动作频率达 **93.37 Hz**（远超 PI0 的 50 Hz）；
2. **自适应切换优于固定切换**：相比每 4 块调用一次的 Fixed Switching 基线，EMS 成功率提升 2.05%，慢系统调用减少 53.6%；
3. **最困难套件上略胜 System 2**：在 LIBERO-10 上，EMS（85.40%）略优于 PI0（85.20%）；
4. **轨迹蒸馏必要**：基于 PI0 蒸馏轨迹训练 System 1 较遥操数据训练平均提升 4.80%；
5. **动作融合对长程任务重要**：去除后 LIBERO-10 成功率下降 3%；
6. **真实双臂加速**：真机任务完成时间从 System 2 的 29s 降至 23s（System 1 单独 18s 但成功率仅 60%，常需重规划）；
7. **自适应切换呈现任务-状态感知模式**：慢系统在初始规划、关键抓取、阶段切换、错误纠正时被调用，平时由快系统主导。

## 七、优点与亮点

### 7.1 方法亮点
- **完全解耦的双系统架构**：动作级接口而非特征级耦合，是与 FiS-VLA、DP-VLA 等的核心区别；
- **架构无关、即插即用**：System 1/2 均可独立替换升级，无需联合训练；
- **RL 驱动的环境感知切换**：将系统选择形式化为 MDP 并用 DQN/IQL 求解，决策轻量；
- **轨迹蒸馏 + 动作融合**：解决双系统切换的轨迹一致性问题；
- **在线 + 离线双 RL 路线**：分别适配仿真交互和真实场景的离线数据采集需求。

### 7.2 实验亮点
- 跨越仿真（LIBERO + Realman）与真实双臂系统的端到端验证；
- 消融实验直接对应三大设计组件（蒸馏、初始化、动作融合）；
- 提供切换比、动作频率、任务完成时间三维评估。

## 八、不足与局限

### 8.1 方法层面
- **切换模块输入受限**：仅以机器人状态 $s_t$ 为输入，未利用视觉信息，可能在感知关键阶段判断不足；
- **动作融合的简单平均**可能损失最优动作，且假设两个系统的动作在同构空间（实际可能不一致）；
- **切换决策粒度**：决策边界由已执行完的动作/块决定，无法在动作块内做更细粒度的混合；
- **切换延迟风险**：慢系统 ~10 Hz 推理时，若切换瞬间需调用慢系统，可能引入数百毫秒等待；
- **奖励设计简单**：仅使用稀疏的二值成功/失败信号，分配到每步的稠密化可能稀释关键信号。

### 8.2 实验层面
- **真机试验样本量小**：每模型仅 10 次试验，难以得出统计鲁棒结论；
- **真实任务单一**：仅 1 种双臂堆叠任务，未验证跨任务、跨物体的泛化；
- **缺少与最新 SOTA 双系统方法**的直接、定量对比（FiS-VLA、HiRT、CogACT、Hume 等）；
- **未报告失败模式分析**：如慢系统被调用但仍失败的场景；
- **算力与训练成本不透明**：复现性受影响。

### 8.3 应用层面
- 当前依赖两个独立模型的部署（存储、显存），对边缘部署仍是挑战；
- 真机实验中 System 1 失败占主导（60%），EMS 70% 仍显著低于 System 2（100%），说明轻量模型在真实双臂控制中的能力差距仍是瓶颈；
- 切换策略的训练需要环境交互或离线数据采集，在新任务/新机器人上的迁移成本未讨论。
