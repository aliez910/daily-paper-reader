## 摘要
视觉-语言-动作（VLA）模型为连接视觉感知、语言理解与机器人控制提供了统一范式。然而，现有VLA模型在长时程任务中仍面临重大挑战：稀疏的专家演示数据限制了跨任务组合泛化能力；长时程任务的非马尔可夫特性使仅基于当前观测的条件策略难以维持时序一致性；有限的闭环纠错能力导致执行误差不断累积；端到端的动作微调可能削弱视觉-语言模型（VLM）骨干网络的高级语义表征能力。为解决这些问题，我们提出了一种具有显式语言记忆模块的层次化长时程VLA架构。其核心思想是将离散的时间观测转化为具有时序逻辑的连贯文本记忆序列。该系统解耦为高层VLM和底层VLA：高层VLM通过视觉问答训练范式执行语义推理，而底层VLA则以子任务指令和视觉观测为条件执行精确的连续控制。高层VLM以先前的记忆作为上下文锚点，递归地更新语言记忆和子任务指令，从而在长时程执行过程中实现持续的时序跟踪和动态纠错。我们在多个仿真环境中对所提方法进行了评估，并在真实机器人平台上开展了仿真到现实的迁移实验。实验结果表明，显式语言记忆提高了VLA模型在复杂长时程任务上的成功率和鲁棒性，同时为决策过程提供了可解释的语义说明。

## Abstract
Vision-language-action (VLA) models provide a unified paradigm for connecting visual perception, language understanding, and robotic control. However, existing VLA models still face major challenges in long-horizon tasks: sparse expert demonstrations constrain cross-task compositional generalization; the non-Markovian nature of long-horizon tasks makes it difficult for policies conditioned only on current observations to maintain temporal consistency; limited closed-loop error correction allows execution errors to accumulate; and end-to-end action fine-tuning may weaken the high-level semantic representations of vision-language model (VLM) backbones. To address these issues, we propose a hierarchical long-horizon VLA architecture with an explicit language-memory module. The central idea is to convert discrete temporal observations into a coherent textual memory sequence with temporal logic. The system is decoupled into a high-level VLM and a low-level VLA: the high-level VLM performs semantic reasoning through a visual question answering training paradigm, while the low-level VLA executes precise continuous control conditioned on subtask instructions and visual observations. The high-level VLM recursively updates both language memory and subtask instructions using the previous memory as a contextual anchor, enabling persistent temporal tracking and dynamic correction during long-horizon execution. We evaluate the proposed method in multiple simulation environments and conduct sim-to-real experiments on a real robotic platform. The results demonstrate that explicit language memory improves the success rate and robustness of VLA models on complex long-horizon tasks while providing an interpretable semantic account of the decision process.

## 2. 方法论

### 2.1 整体架构：分层 VLM–VLA

策略被分解为一个高层语义分支 $\pi^{HL}$ 和一个底层动作分支 $\pi^{LL}$：

$$
\pi(a_{t:t+H}, s_t, m_t \mid o_t, m_{t-1}, l) = \pi^{LL}(a_{t:t+H} \mid o_t, s_t) \cdot \pi^{HL}(s_t, m_t \mid o_t, m_{t-1}, l)
$$

其中 $l$ 为全局任务指令，$o_t$ 为当前视觉与本体观测，$m_{t-1}$ 为上一时刻的语言记忆，$s_t$ 为当前子任务指令，$a_{t:t+H}$ 为长度 $H=30$ 的连续动作块。$\pi^{HL}$ 决定"任务处于什么阶段、接下来该做什么"，$\pi^{LL}$ 决定"如何精确执行该子任务"。

### 2.2 递归语言记忆机制

记忆 $m_t$ 是结构化的自然语言摘要，包含：
- 已完成的里程碑（过去时态陈述）；
- 当前任务状态、相关物体属性与位置；
- 已观测到的失败信息；
- 下一阶段意图。

更新遵循 **滚动压缩规则**：子任务完成前保留物体的类别、颜色、位置等细节；完成后压缩为简短过去式描述，注意力切换到下一动作。例如：
- $m_t$：`I am moving to the red radio on the coffee table.`
- $m_{t+1}$：`I moved to the radio, and I am going to pick up the red radio.`

高层 VLM **仅在当前观测提供里程碑变化证据时才更新记忆**，避免每帧都生成新文本，保证记忆长度在实际中保持有界。

### 2.3 自动记忆监督管线

训练高层分支需要为每帧提供 $(m_t, s_t)$ 监督目标。流程为：
1. 专家演示视频 + 人工标注的技能名称、描述、起止时间戳；
2. 按时间戳定位每帧对应的活跃技能；
3. 使用通用 VLM（论文提及两种来源：托管的 Gemini 3.5 Flash API 与本地部署的 Qwen3.5-9B），基于当前帧与完整技能标注生成：
   - **子任务**：`action + 目标物体 + 上下文` 的简洁形式，不含主体；
   - **第一人称记忆**：过去时态陈述已完成的技能，再用未来时态过渡到下一技能。

提示词中明确要求使用自然物体名称与可见属性，并禁用 "frame / sequence / index / skill index" 等实现术语。最终得到帧对齐的 $(m_t, s_t)$ 作为高层策略的监督目标。

### 2.4 独立分支训练

- **高层分支**：使用 **PaliGemma**（与 π0.5 同族 VLM），以自回归方式联合预测 $m_t$ 与 $s_t$，损失为
  $$L_{HL}=-\mathbb{E}\big[\log\pi^{HL}_m(m_t \mid o_t, m_{t-1}, l) + \log\pi^{HL}_s(s_t \mid o_t, m_{t-1}, l)\big]$$
- **底层分支**：沿用 π0.5 的 **300M 参数 Gemma action expert**，以 flow-matching 目标优化：
  $$L_{LL}=\mathbb{E}\big[\|a_{t:t+H}-\pi^{LL}(o_t, s_t)\|_2^2\big]$$
- 两者 **独立训练**，避免在单一目标中人为权衡语义生成与连续控制。

### 2.5 闭环推理

部署时 $m_0=\varnothing$，循环执行：`观测 → 更新 $(m_t, s_t)$ → 生成动作块 → 执行 → 终止判断`。由于记忆与子任务均为可见文本，运行时还可产出可与动作失败对齐的 **可解释日志**。

## 6. 主要结论与发现

- **阶段成功率显著提升**：
  - BEHAVIOR-1K 收音机任务：平均成功率 30.0% → **40.0%**，其中 PickUp 由 10.0% 跃升至 30.0%；
  - Genie Sim 3.0 单包裹分拣：41.7% → **63.9%**，Follow 与 PickUp-1 均翻倍，扫码放置由 50.0% → 83.3%；
  - Genie Sim 3.0 连续四包裹分拣：31.3% → **46.9%**，基线从未达到第 3、4 次成功，记忆模型在 12.5% 评估中完成全部 4 次；
  - XLeRobot 真机：62.5% → **66.3%**，变化较小，符合"任务短，记忆增益有限"的预期。
- **阶段一致性改善**：显式记忆防止了在 PickUp 后直接跳转至 PlaceOn，避免跳过 PressOn；在包裹分拣中防止跳过扫码步骤直接放入蓝筐。
- **语义规划与运动控制的边界**：PressOn 成功率仍低（基线 0%，加记忆 10%），说明语言记忆解决的是"做什么、处于哪一阶段"，但不直接提升按钮定位、几何对齐、接触力等低级控制能力。
- **上下文中的失败恢复**：在抓取失败等情形下，记忆可记录"未抓稳"，触发重新张开夹爪并重试，被作者称为 **in-context 适应**——并非独立恢复控制器，而是让失败状态进入后续决策的上下文。
- **可解释性**：记忆与子任务为可见文本，便于将失败归因到"高层语义错误"或"底层控制错误"。

## 7. 优点

1. **记忆表示紧凑且可监督**：滚动压缩 + 文本形式让记忆长度有界、可训练、可直接检视，规避了"历史帧全量拼接"的成本；
2. **监督管线可扩展**：使用通用 VLM 自动从专家视频 + 技能标注生成 $(m_t, s_t)$，避免了昂贵的人工逐帧标注；
3. **解耦训练避免损失博弈**：高层与底层各自优化不同目标，避免在单一损失中人为权衡语义生成与运动控制；
4. **跨平台验证**：覆盖家庭仿真、人形机器人仿真、低成本真机三类平台，具有较强的迁移代表性；
5. **细粒度评估指标**：阶段级成功率比单一终态指标更具有诊断性；
6. **失败可归因**：区别"语义错误"与"控制错误"，并展示 in-context 失败恢复能力。

1. **真机评估规模有限**：仅 25 条训练轨迹、20 次评估，且为短程 pick-and-place，**无法代表分钟级真实长时程任务**（多物体、重复交互、环境变化等）；
2. **缺乏统计严谨性**：未给出多随机种子实验、置信区间或显著性检验，单均值易受随机性影响；
