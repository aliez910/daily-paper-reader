## 摘要
视觉-语言-动作（VLA）模型将预训练视觉-语言模型（VLM）的表征转化为机器人动作，然而将中间层VLM特征路由至动作解码器的接口尚未得到充分探索。现有设计要么仅暴露表征层级中较窄的一部分，要么将每个解码器块刚性匹配到单一VLM层，从而限制了跨深度互补任务线索的访问。我们提出LIRA，一种局部跨层动作条件化机制，将VLM到动作的条件化建模为深度感知的信息路由。LIRA作用于任务词元特征和由VLM中间状态导出的LIRA查询特征，并为每个并行融合块分配一个以对应VLM层为中心的深度对齐局部窗口。并行融合块对邻近的LIRA查询特征进行聚合，并将其与任务词元特征及本体感受输入融合后用于动作预测。该路由接口保持骨干网络架构、动作解码器以及有监督训练流程不变。在LIBERO、LIBERO-Plus、CALVIN ABC→D以及真实世界操作任务中，LIRA在相同的0.5B参数配置下提升了相对于VLA-Adapter基线的主要综合指标。在向LIBERO-Plus的零样本迁移中，LIRA将平均成功率从59.1%提升至78.0%，提升达18.9个百分点，表明在受控分布偏移下其鲁棒性显著增强。

## Abstract
Vision-Language-Action (VLA) models transform representations from pretrained vision-language models (VLMs) into robot actions, yet the interface that routes intermediate VLM features into action decoders remains underexplored. Existing designs either expose only a narrow part of the representation hierarchy or rigidly match each decoder block to one VLM layer, restricting access to complementary task evidence across depths. We introduce LIRA, a local cross-layer action-conditioning mechanism that formulates VLM-to-action conditioning as depth-aware information routing. LIRA operates on task-token features and LIRA Query features derived from intermediate VLM states, then assigns each Parallel Fusion Block a depth-aligned local window centered on its corresponding VLM layer. Parallel Fusion Blocks aggregate neighboring LIRA Query features and integrate them with task-token features and proprioceptive inputs before action prediction. This routing interface leaves the backbone architecture, action decoder, and supervised training recipe unchanged. Across LIBERO, LIBERO-Plus, CALVIN ABC$\rightarrow$D, and real-world manipulation, LIRA improves the principal aggregate metrics over the VLA-Adapter baseline under the same 0.5B-parameter configuration. In zero-shot transfer to LIBERO-Plus, LIRA increases average success from 59.1% to 78.0%, an 18.9-point gain indicating improved robustness under controlled distribution shifts.

# LIRA 论文总结

## 1. 核心问题与研究背景

**研究问题**：视觉-语言-动作（VLA）模型通过复用预训练视觉-语言模型（VLM）表征来生成机器人动作，但 **VLM 中间层特征到动作解码器的路由接口** 长期未被充分探索。

**现有方案的三大局限**：
- **仅使用最后一层特征**：只暴露表征层级的极末端，丢失了中间层的丰富信息；
- **一对一层级对齐**：每个解码器块只与单一 VLM 层刚性绑定，限制了跨深度互补信息的访问；
- **全局聚合**：将所有 VLM 层特征混合，可能抹平局部结构。

**核心动机**：论文假设 **相邻 VLM 层提供互补的任务证据**，因此应设计一种"局部跨层"路由接口，既保留深度对齐的结构，又能利用邻近层的互补表征，从而提升 VLA 在受控分布偏移下的鲁棒性。

## 2. 方法论

### 2.1 整体框架
LIRA 构建在 **VLA-Adapter** 之上，主体结构不变：Prismatic 风格 VLM + Parallel Fusion Block (PFB) 动作解码器。其核心改动是为 PFB 引入"局部跨层信息路由"。

### 2.2 关键组件
1. **LIRA Query Tokens**：在 VLM 输入中追加 $M=64$ 个可学习的 VLM 侧查询 token，每层 Transformer 提取其特征 $R^{(\ell)}_t \in \mathbb{R}^{M \times d_v}$；
2. **Task-Token Features** $T^{(\ell)}_t$：保留视觉-语言 token 的层级特征；
3. **Proprioceptive Embedding** $E^p_t = \phi_p(P_t)$：本体感知状态投影。

### 2.3 局部跨层路由（核心公式）
对第 $i$ 个 PFB，定义以其匹配 VLM 层为中心的局部窗口：

$$
W_r(i) = \{\ell \in \{1, \ldots, L\} \mid |\ell - i| \leq r\}
$$

将窗口内所有相邻层的 LIRA Query 特征沿 token 维度拼接：

$$
\tilde{R}^{(i)}_t = \text{Concat}_{\text{tok}}\left(\{R^{(\ell)}_t \mid \ell \in W_r(i)\}\right)
$$

默认 **$r=1$**（三层窗口），首尾边界自然截断为两层。每个 PFB 的更新为：

$$
X^{(i)}_t = \text{PFB}_i\left(X^{(i-1)}_t;\ T^{(i)}_t,\ \tilde{R}^{(i)}_t,\ E^p_t\right)
$$

### 2.4 设计亮点
- **零新增参数**：特征直接拼接复用现有 cross-attention，无需额外投影层；
- **结构化局部上下文**：匹配层提供"语义锚点"，窗口内邻近层提供互补信息；
- **可调窗口宽度**：$r=0$ 退化为单层对齐，$r$ 增大逼近全局聚合，提供显式控制旋钮。

### 2.5 训练目标
监督连续动作回归的 L1 损失，动作 chunk 长度 $H$，目标与 VLA-Adapter 完全一致，便于公平对比。

## 6. 主要结论与发现

| 基准 | VLA-Adapter | **LIRA** | 提升 |
|------|------------|---------|------|
| LIBERO 平均 | 97.3% | **98.9%** | +1.6 pts |
| LIBERO-Long | 95.0% | **97.6%** | +2.6 pts |
| CALVIN 5-task | 76.5% | **80.5%** | +4.0 pts |
| CALVIN 平均序列长度 | 4.42 | **4.52** | +0.10 |
| LIBERO-Plus 零样本 Overall | 59.1% | **78.0%** | **+18.9 pts** |
| LIBERO-Plus 微调 Overall | 81.0% | **82.9%** | +1.9 pts |
| 真实机器人 Pick-and-Place | 7/10 | **9/10** | — |

**关键发现**：
- **零样本迁移增益最大**（+18.9 pts），证明局部跨层路由对分布偏移的鲁棒性贡献最显著；
- **序列越长优势越大**：CALVIN 5-task 提升 4.0 pts，表明跨子目标信息传递更可靠；
- **窗口宽度 $r=1$（三层）为最优**：过窄欠利用互补信息，过宽混叠远层结构；
- **LIRA Query 数量提升并不能复现 LIRA 增益**（256 tokens 仅 93.0% vs LIRA 64 tokens 97.6%），证明改进来自"路由拓扑"而非"更多 query"。

## 7. 方法与实验设计的优点

- **问题视角新**：将 VLM→动作接口重新定义为"深度感知信息路由"，跳出传统"加层/扩规模"的改进路径；
- **零参数增量的实用价值**：不改变骨干、解码器、训练流程即可获得显著提升，工程可落地性极强；
- **理论先验明确**：明确提出"局部性先验"假设，并通过路由拓扑、窗口宽度、Query 预算三组消融系统验证；
- **可解释的消融设计**：Flashback / Column-wise / Q-Former / Local window 四种拓扑横向对比，论据充分；
- **匹配基线严格**：与 VLA-Adapter 在 0.5B 配置、相同训练 recipe 下对比，避免了"靠规模取胜"的混淆；
- **系统级资源对比**：给出内存与吞吐数据，凸显紧凑 VLA 的实用潜力；
- **仿真 + 真实双重验证**：增强结论可信度。

## 8. 不足与局限

- **实验覆盖偏差风险**：
  - 真实机器人仅 **10 次/任务**，样本量过小，无法支撑统计显著性；
  - 仅使用 **单一 VLM 骨干（Qwen2.5-0.5B）**，未验证跨骨干泛化；
  - 仅在 **单一机器人平台（Franka Research 3）** 评估，未涉及跨 embodiment；
- **任务范围局限**：未覆盖接触密集型（insertion、装配）和力敏感操作，论文也明确承认这一点；
- **理论分析不足**：未深入分析"为何三层窗口最优"，缺乏对中间层表征语义的细粒度可视化或探针分析；
- **窗口宽度选择**：默认 $r=1$ 来自消融实验，但不同任务/骨干的最优 $r$ 是否一致未深入讨论；
- **可扩展性疑问**：当 VLM 层数变化（如从 24 层到 80 层）时，固定半径窗口的覆盖比例会改变，最优 $r$ 可能需重选；
- **计算开销未量化**：虽然声称零新增参数，但拼接操作带来的 attention 复杂度（token 数 ×3）对长序列的延迟影响未报告；
- **未与更大模型公平比较**：LIBERO-Plus 上 LIRA 78.0% vs OpenVLA-OFT 69.6% 看似 LIRA 占优，但后者为 7B 模型且未微调，参数效率的代价是否合理需读者自行权衡。
