## 摘要
具身视觉运动模型，包括扩散策略（Diffusion Policy, DP）和视觉-语言-动作（Vision-Language-Action, VLA）模型，已在机器人操作基准测试中展现出令人瞩目的性能。然而，其潜力从根本上受限于大规模具身轨迹数据集的稀缺，导致在分布外（OOD）场景中组合泛化能力不足，且难以捕获可复用的技能结构。为解决这一局限，我们提出了基于技能的记忆（Skill-Based Memory, SkillMemo）框架，该框架将长时序演示隐式分解为潜在的原子技能，并将技能级特征整合到动态情景记忆库中，以解决组合任务。具体而言，我们首先引入了一个基于混合专家（Mixture-of-Experts, MoE）架构构建的专家引导轨迹分割模块，该模块通过学习到的门控系数将轨迹隐式划分为不同的技能基元。此外，我们设计了一种技能级情景记忆架构，将紧凑的技能表示存储为可检索的键值对。在推理阶段，记忆库检索最相关的技能基元，并将其与模型当前的门控分布融合，为优化动作预测提供鲁棒的上下文先验。在仿真基准和真实世界操作任务上的大量实验表明，SkillMemo 能持续提升 DP 和 VLA 骨干网络的性能，达到最先进水平并超越 π_{0.5}，同时对未见过的任务配置展现出强大的组合泛化能力。

## Abstract
Embodied visuomotor models, including Diffusion Policy (DP) and Vision-Language-Action (VLA) models, have demonstrated promising performance on robotic manipulation benchmarks. However, their potential remains fundamentally constrained by the scarcity of large-scale embodied trajectory datasets, leading to insufficient compositional generalization in out-of-distribution (OOD) scenarios with limited capability to capture reusable skill structures. To address this limitation, we propose Skill-Based Memory (SkillMemo) framework that implicitly decomposes long-horizon demonstrations into latent atomic skills and integrates skill-level features into a dynamic episodic memory bank for solving compositional tasks. Specifically, we first introduce an expert-guided trajectory segmentation module built upon a Mixture-of-Experts (MoE) architecture, which implicitly partitions trajectories into distinct skill primitives represented by learned gating coefficients. We further design a skill-level episodic memory architecture that stores compact skill representations as retrievable key-value pairs. During inference, the memory bank retrieves the most relevant skill primitives which are subsequently fused with the model's current gating distribution, providing a robust contextual prior to refine action predictions. Extensive experiments on the simulation benchmark and real-world manipulation tasks demonstrate that SkillMemo consistently enhances both DP and VLA backbones, achieving state-of-the-art performance and outperforming $π_{0.5}$, while exhibiting strong compositional generalization to unseen task configurations.

## 1. 核心问题与研究动机

- **数据稀缺瓶颈**：具身视觉运动模型（DP 与 VLA）虽在机器人操作基准上表现优异，但其能力从根本上受限于大规模具身轨迹数据集的稀缺。
- **组合泛化不足**：在 OOD（分布外）场景下，面对已知物体、容器和指令的新颖组合，模型容易失效，难以将已学行为重组以应对新任务。
- **缺乏可复用技能结构**：现有模型倾向于用单一整体网络（monolithic network）编码整条行为轨迹，无法捕获细粒度、可复用的行为子结构（如"抓取"、"放置"、"旋转"等原子动作）。
- **已有记忆方法的缺陷**：如 MemoryVLA（双流感知-认知记忆库）、HAMLET（时序令牌）等方法存储的是粗粒度的视觉-语义整体表征，缺少对**技能级别行为模式**的显式存储与组合机制。

## 2. 方法论：SkillMemo 框架

SkillMemo 由两大核心模块构成，整体形成"先分割、再存储、检索融合"的闭环。

### 2.1 专家引导轨迹分割（EGTS）

- **核心思想**：用 **混合专家（MoE）** 架构对长时序演示做**隐式分解**，避免显式分段对技能边界定义的依赖。
- **公式表达**：
  - 给定中间特征 $h_t$，MoE 层输出：
    $$y_t = \sum_{i=1}^{N} g_i(h_t) \cdot E_i(h_t)$$
  - 其中 $E_i$ 为专家网络，$g_i(h_t)$ 为对应门控权重；门控网络的时间演化即隐式定义技能边界。
- **正则化机制**：
  - **PID 协同信息损失**：$L_{PID} = -[I(\{A,B\};G) - I(A;G) - I(B;G)]$，鼓励专家协同表达任务相关信息，迫使各专家专攻互补技能。
  - **专家负载均衡损失 + Top-k 路由**：防止专家坍缩（expert collapse）。

### 2.2 技能级情景记忆架构（SLMA）

- **存储结构**：以键值对形式组织记忆库 $M = \{(k_m, v_m)\}$。
  - **记忆键（Key）**：对每个技能段 $\tau_m$ 做时序聚合得到紧凑质心特征 $k_m = \frac{1}{L}\sum_{t \in \tau_m} h_t$，避免逐帧存储带来的可扩展性问题。
  - **记忆值（Value）**：存储该段所有时间步的**完整门控权重序列** $v_m = \{g(h_t)\}_{t \in \tau_m}$，保留时序动态。
- **检索机制**：
  - 计算当前状态表征 $q_t$ 与所有记忆键的余弦相似度：$s(q_t, k_m) = \frac{q_t \cdot k_m}{\|q_t\|\|k_m\|}$。
  - 取 Top-N 最相关条目，引入**可靠性阈值 $\delta$** 过滤低置信度检索。
- **门控融合**：将检索到的门控分布与当前门控按权重融合：
  $$g'(q_t) = \lambda g(q_t) + (1-\lambda) \cdot \frac{1}{N}\sum_{n=1}^{N} v_n[t']$$
  其中 $\lambda$ 控制记忆干预强度，$v_n[t']$ 为时间对齐的检索门控。
- **动态更新与剪枝**：记忆库容量有限（$M_{max}=1000$），通过**时间戳、检索使用率、可靠性**三准则进行优先级剪枝，模拟人类遗忘机制。

## 6. 主要结论与发现

- **统一提升**：SkillMemo 在 DP 与多种 VLA（UniAct、UniVLA、$\pi_{0.5}$）骨干上均带来一致性增益。
- **SOTA 性能**：$\pi_{0.5}$-SkillMemo 在 LIBERO 上达到 **98.0% 平均成功率**，超越 $\pi_{0.5}$（96.8%）和 MemoryVLA（96.5%）。

- **组合泛化显著**：在 LIBERO 跨子集零样本测试中，在 Goal 上训练的模型在未见 Spatial 子集上达到 **75.6%**，甚至超过在 Spatial 上专门训练的结果（72.1%）。
- **真实世界一致**：所有 5 个真实任务均优于 DP 基线（最高 +12.5%）；未见组合上平均提升约 10%。
- **专家激活呈现语义峰值**：门控权重在"抓取"、"开火"等关键动作阶段出现显著尖峰，证实隐式技能分解的有效性。

## 7. 优点与亮点

- **方法新颖性**：首次将 MoE 隐式技能发现与**结构化情景记忆库**耦合，区别于已有的静态技能库或纯隐式分解。
