## 摘要
视觉-语言-动作（VLA）模型为连接视觉感知、语言理解和机器人控制提供了一种统一的范式。然而，现有VLA模型在长时序任务中仍面临重大挑战：稀疏的专家演示限制了跨任务的组合泛化能力；长时序任务的非马尔可夫特性使得仅以当前观测为条件的策略难以保持时间一致性；有限的闭环纠错能力使执行误差不断累积；端到端的动作微调可能会削弱视觉-语言模型（VLM）骨干网络的高层语义表征。为应对上述问题，我们提出了一种具有显式语言记忆模块的层次化长时序VLA架构。其核心思想是将离散的时间观测转化为具有时间逻辑的连贯文本记忆序列。该系统解耦为高层VLM和低层VLA：高层VLM通过视觉问答训练范式进行语义推理，低层VLA以子任务指令和视觉观测为条件执行精确的连续控制。高层VLM以先前的记忆为上下文锚点，递归地更新语言记忆和子任务指令，从而在长时序执行过程中实现持续的时间跟踪和动态纠错。我们在多个仿真环境中对所提方法进行了评估，并在真实机器人平台上开展了仿真到现实的迁移实验。实验结果表明，显式语言记忆在提升VLA模型在复杂长时序任务上的成功率和鲁棒性的同时，为决策过程提供了可解释的语义解释。

## Abstract
Vision-language-action (VLA) models provide a unified paradigm for connecting visual perception, language understanding, and robotic control. However, existing VLA models still face major challenges in long-horizon tasks: sparse expert demonstrations constrain cross-task compositional generalization; the non-Markovian nature of long-horizon tasks makes it difficult for policies conditioned only on current observations to maintain temporal consistency; limited closed-loop error correction allows execution errors to accumulate; and end-to-end action fine-tuning may weaken the high-level semantic representations of vision-language model (VLM) backbones. To address these issues, we propose a hierarchical long-horizon VLA architecture with an explicit language-memory module. The central idea is to convert discrete temporal observations into a coherent textual memory sequence with temporal logic. The system is decoupled into a high-level VLM and a low-level VLA: the high-level VLM performs semantic reasoning through a visual question answering training paradigm, while the low-level VLA executes precise continuous control conditioned on subtask instructions and visual observations. The high-level VLM recursively updates both language memory and subtask instructions using the previous memory as a contextual anchor, enabling persistent temporal tracking and dynamic correction during long-horizon execution. We evaluate the proposed method in multiple simulation environments and conduct sim-to-real experiments on a real robotic platform. The results demonstrate that explicit language memory improves the success rate and robustness of VLA models on complex long-horizon tasks while providing an interpretable semantic account of the decision process.

# 论文总结：面向视觉-语言-动作模型长时序规划的显式语言记忆

## 一、核心问题与研究动机

论文聚焦于当前 **Vision-Language-Action（VLA）模型在长时序（long-horizon）任务中的系统性不足**，明确指出了四项关键挑战：

- **稀疏专家演示**：现有数据集多为短片段演示，难以支撑跨任务的组合泛化。
- **非马尔可夫性（non-Markovian）**：长时任务中"同一观测"可能对应不同决策，仅依赖当前帧的策略无法判断"前一阶段是否成功"。
- **闭环纠错能力有限**：错误会沿动作序列不断累积，缺乏显式的状态恢复机制。
- **端到端微调削弱 VLM 语义表征**：直接将动作头接入大 VLM 进行全参数微调，往往损害高层语言理解能力。

作者认为，**时序一致性与控制精度是两个独立的问题**，应分别优化；为此需要一个显式的、可监督的中间状态表征来桥接高层语义与低层运动控制。

## 二、方法论

### 1. 总体思路：分层架构 + 显式语言记忆

将策略分解为两个子模块：

$$\pi(a_{t:t+H}, s_t, m_t \mid o_t, m_{t-1}, l) = \pi^{LL}(a_{t:t+H} \mid o_t, s_t) \cdot \pi^{HL}(s_t, m_t \mid o_t, m_{t-1}, l)$$

- **高层 VLM** $\pi^{HL}$：以当前观测 $o_t$、上一时刻记忆 $m_{t-1}$、全局指令 $l$ 为输入，输出**更新的语言记忆 $m_t$** 与**子任务指令 $s_t$**。
- **低层 VLA** $\pi^{LL}$：以 $o_t$ 和 $s_t$ 为条件，预测长度为 $H$ 的连续动作块 $a_{t:t+H}$。
- 循环：执行 $H$ 步 → 获取新观测 → 递归更新记忆。

### 2. 显式语言记忆机制

- **结构化自然语言摘要**，包含：已完成阶段（过去时）、当前阶段、下一意图（未来时）、目标对象属性（颜色、位置等）。
- **滚动压缩规则（rolling-compression）**：子任务完成前保留细节，完成后压缩为简短过去时陈述，注意力转向下一步。
- 例子（开收音机任务）：

  > $m_t$："I am moving to the red radio on the coffee table."
  > $m_{t+1}$："I moved to the radio, and I am going to pick up the red radio."

### 3. 自动化记忆监督管线

利用带技能标注（名称、描述、起止时间戳）的专家视频：
- 用通用 VLM（论文中提到 Gemini 3.5 Flash API 与本地部署的 Qwen3.5-9B）对每帧生成"子任务 + 第一人称语言记忆"。
- 输出格式：动作 + 目标物体 + 上下文（子任务）；过去时已完成动作 + 未来时下一动作（记忆）。
- 提示词明确要求使用自然物体名、避免"帧/序列/索引"等实现术语。

### 4. 独立分支训练

- **高层**：基于 PaliGemma（与 π0.5 同家族 VLM），通过 LoRA 微调，自回归预测记忆与子任务：

  $$\mathcal{L}_{HL} = -\mathbb{E}[\log\pi^{HL}_m(m_t|...) + \log\pi^{HL}_s(s_t|...)]$$

- **低层**：沿用 π0.5 的 300M 参数 Gemma action expert，使用 **flow-matching 动作目标**：

  $$\mathcal{L}_{LL} = \mathbb{E}\|a_{t:t+H} - \pi^{LL}(o_t, s_t)\|_2^2$$

- 两分支**独立训练**，避免语义生成与连续控制之间的损失平衡调参问题。

### 5. 闭环推理

初始化 $m_0 = \varnothing$，每步循环执行"观测 → 更新记忆与子任务 → 生成动作块 → 执行 → 终止判定"，直至高层指示任务完成。完整的记忆与子任务文本同时作为可解释日志。

### 评价指标

## 六、主要结论与发现

1. **整体性能提升**：
   - BEHAVIOR-1K 开收音机：平均成功率从 **30.0% → 40.0%**（PickUp 提升最显著，10% → 30%）。
   - Genie Sim 单包裹分拣：**41.7% → 63.9%**；连续四包裹分拣：**31.3% → 46.9%**。
   - 真实 XLeRobot 抓放：**62.5% → 66.3%**（提升较小，符合"短任务收益有限"的预期）。
2. **阶段一致性（phase consistency）增强**：记忆使阶段推进依赖于观测证据，避免跳过未完成里程碑（如跳过按钮按压、跳过条码扫描）。
3. **可解释性**：记忆与子任务皆为文本，可与动作失败对齐分析，便于诊断高层语义错误 vs 低层控制错误。
4. **上下文内失败恢复**：当抓取失败时，记忆记录"物体未抓住"并触发重抓，无需单独的恢复控制器。
5. **能力边界明确**：语言记忆主要解决"做什么、当前在哪个阶段"，**不能直接改善接触式动作（如 PressOn 成功率仍低）**；语义规划与运动控制是互补而非替代关系。

## 七、优点与亮点

- **方法层面**：
  - 将"历史表征"从原始观测序列迁移到**紧凑、可监督的文本记忆**，避免上下文与算力随任务时长线性增长。
  - **层次化分解**让高层语义跟踪与低层连续控制各自拥有独立优化目标，规避端到端微调对 VLM 骨干的损害。
  - **滚动压缩规则**使记忆在保留语义锚点的同时保持有界长度。
  - **自动化监督管线**降低了对人工标注的依赖，可从普通专家视频扩展。
- **实验层面**：
  - 覆盖**仿真 + sim-to-real**，并明确划分阶段级成功率，能精确定位失败原因。
  - 真实机器人平台（低成本双臂移动机器人 XLeRobot）展示方法的工程可落地性。
- **可解释性**：
  - 决策全过程以自然语言记录，便于事后审计、人在环路调试与失败诊断。
- **实用价值**：
  - 不需要单独设计恢复控制器，失败状态可直接进入下一决策的上下文。

  - 仅与 π0.5 对比，未与 HAMLET、MemoryVLA、MAP-VLA、Embodied CoT、dVLA 等长时序或带记忆的 VLA 工作直接比较。

  - 仅 25 条训练轨迹、20 次评估试验、单一短任务（4 阶段），无法证明在分钟级、多物体、环境变化场景下的有效性。
- **工程开销**：
  - 分层推理增加了高层 VLM 调用，**端到端延迟与部署复杂度高于原生 π0.5**。
- **未能触及的能力边界**：
  - PressOn 等接触式动作成功率仍低，表明语言记忆无法替代低层控制精度。
  - 恢复行为依赖训练数据中存在失败与纠正片段，**当前数据缺乏多样化失败-恢复示范**。
- **模态局限**：
  - 当前记忆仅基于语言，未融合视觉证据、力觉/触觉等多模态信号，难以区分"成功接触"与"滑动抓取"等仅靠图像难以分辨的状态。

  - 统一骨干同时生成记忆、子任务与动作；
  - 收集并标注大规模失败-恢复示范数据集。
