## 摘要
虽然视觉-语言-动作（VLA）模型推动了具身智能的发展，但其根本性的反应式范式在部分可观测和长周期任务中严重限制了性能。当仅使用单一腕部相机时，随着物体离开视野，模型不可避免地遭受感知遗忘问题，且在多步执行过程中会出现时间性任务进度遗忘。为克服这些瓶颈，我们提出了AtlasVLA——一种通过持久化世界-自我状态，从直接反应式操作转向主动推理的新框架。AtlasVLA采用双记忆架构：一个4D持久化世界状态记忆，将瞬态的二维观测提升为全局更新的体素哈希空间状态，以解决视觉盲区；以及一个自我工作状态记忆，用于跟踪历史自我状态和任务进度。通过将扩散变换器（DiT）以该联合世界-自我状态为条件，AtlasVLA实现了鲁棒的空间推理。在LIBERO、RLBench以及真实世界基准上的广泛评估表明，AtlasVLA仅使用腕部相机即可达到最先进的性能。值得注意的是，它以明显优势超越了多视图基线，在LIBERO-Long上取得了9.4%的绝对成功率提升，在真实世界长周期任务中取得了17.5%的提升。

## Abstract
While Vision-Language-Action (VLA) models have advanced embodied AI, their fundamentally reactive paradigm severely limits performance in partially observable and long-horizon tasks. When restricted to a single wrist-mounted camera, they inevitably suffer from perception forgetting as objects exit the field of view, and temporal task-progress forgetting} during multi-step execution. To overcome these bottlenecks, we propose AtlasVLA, a novel framework that transitions from direct reactive manipulation to proactive reasoning through a persistent world-ego state. AtlasVLA features a dual-memory architecture: a 4D Persistent World State Memory that lifts transient 2D observations into a globally updated, voxel-hashed spatial state to resolve visual blind spots, and an Ego-Working State Memory that tracks historical ego state and task progress. By conditioning a diffusion transformer (DiT) on this joint World-Ego state, AtlasVLA enables robust spatial reasoning. Extensive evaluations across LIBERO, RLBench, and real-world benchmarks demonstrate that AtlasVLA achieves state-of-the-art performance using solely a wrist camera. Remarkably, it decisively outperforms multi-view baselines, yielding absolute success rate improvements of 9.4% on LIBERO-Long and 17.5% in real-world long-horizon tasks.

# AtlasVLA 论文深度总结

## 1. 核心问题与整体含义

- **研究背景**：视觉-语言-动作（VLA）模型是当前具身智能领域的重要范式，通过端到端的方式将视觉感知与语言指令映射为机器人动作，推动了通用操作策略的发展。
- **关键瓶颈**：现有 VLA 模型本质上采用 **反应式（Reactive）范式**，即根据当前观测直接预测动作，缺乏对历史信息与全局状态的记忆能力。
- **两类遗忘问题**：
  - **感知遗忘（Perception Forgetting）**：当仅使用单一腕部相机时，物体一旦离开视野，模型便失去对场景中关键物体的跟踪能力（即"视觉盲区"）。
  - **任务进度遗忘（Temporal Task-Progress Forgetting）**：在多步长周期任务执行过程中，模型缺乏对已完成子任务与剩余进度的记忆，容易丢失任务上下文。
- **整体含义**：本文主张 VLA 模型必须从"直接反应式操作"转向"主动推理（Proactive Reasoning）"，其关键在于构建持久化的世界-自我状态记忆，以同时缓解上述两种遗忘。

## 2. 方法论

### 核心思想
提出 **AtlasVLA 框架**，引入 **双重记忆架构（Dual-Memory Architecture）**，将反应式的 VLA 范式升级为主动推理范式。

### 关键技术组件
- **4D 持久化世界状态记忆（4D Persistent World State Memory）**：
  - 将瞬时的 2D 观测（来自腕部相机的图像）提升为 **全局更新的体素哈希（Voxel-Hashed）空间状态**。
  - "4D" 含义推测为三维空间 + 时间维度，能够记录物体随时间变化的空间位置与属性。
  - 通过体素哈希高效管理大规模三维空间数据，解决腕部相机单一视角下的视觉盲区问题。
- **自我工作状态记忆（Ego-Working State Memory）**：
  - 跟踪 **历史自我状态（Historical Ego State）**——即机器人自身过去的位置、动作与感知。
  - 跟踪 **任务进度（Task Progress）**——即当前任务的执行阶段与已完成/待完成的子任务。
- **联合条件生成（Conditioned Generation）**：
  - 将 **扩散 Transformer（Diffusion Transformer, DiT）** 以"世界-自我状态"（World-Ego State）联合作为条件进行动作生成。
  - DiT 利用双重记忆提供的长时序上下文，实现鲁棒的空间推理。

### 算法流程（文字说明）
1. 腕部相机获取当前 2D 观测；
2. 将新观测动态地写入 4D 持久世界状态记忆，更新全局三维空间状态；
3. 维护并更新自我工作状态记忆（包含历史动作、末端位姿与任务进度标记）；
4. 将世界-自我联合状态作为条件送入 DiT；
5. DiT 通过去噪过程生成机器人动作序列。

## 7. 优点与亮点

- **范式创新**：明确区分"反应式"与"主动推理"两种范式，并将后者落实到双重记忆架构。
- **双重记忆互补**：世界状态记忆解决空间盲区，自我工作状态记忆解决时序/任务进度遗忘，二者正交且协同。
- **表示选择**：4D 体素哈希结构兼具空间精度与查询效率，适合长周期累积式场景建模。
- **生成模型选择**：使用 DiT 而非纯 Transformer，能更好地建模多模态动作分布。
- **极简传感器依赖**：仅依赖单一腕部相机，降低硬件部署门槛，同时性能优于多视角基线，体现方法本身的内在优势。
- **评测覆盖广**：仿真（LIBERO、RLBench）+ 真实场景双管齐下，且突出长周期任务，与方法动机高度契合。
- **可观增益**：9.4%（LIBERO-Long）与 17.5%（真实世界）的提升幅度具有工程说服力。
