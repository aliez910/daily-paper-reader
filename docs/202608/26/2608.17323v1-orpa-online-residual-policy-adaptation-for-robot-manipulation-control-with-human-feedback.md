## 摘要
通过模仿学习训练的机器人操作策略（例如基于 Transformer 的动作分块方法 ACT）在理想条件下能够取得优异的性能，但通常对细微的执行误差和分布偏移较为敏感。修正这些失败通常需要进行数据集聚合以及对完整策略的重新训练，计算开销巨大，难以满足实时部署的需求。本文提出在线残差策略自适应（ORPA）框架，能够在不修改底层策略参数的前提下，依据反馈即时修正机器人动作。ORPA 在预训练的控制策略之上引入一个轻量级的反馈条件模块，该模块直接在关节空间中预测残差调整量，使系统能够在运行过程中自适应调整行为。我们在 ALOHA 平台上对一组对精度敏感的操作任务对 ORPA 进行了评估，结果表明，相较于基线控制策略以及基于规则的反运动学修正方法，ORPA 在成功率以及对小幅扰动的恢复能力方面均取得了提升。

## Abstract
Robotic manipulation policies trained via imitation learning, such as Action Chunking with Transformers (ACT), can achieve strong performance under ideal conditions but often remain sensitive to small execution errors and distribution shifts. Correcting these failures typically requires dataset aggregation and full-policy retraining, which is computationally expensive and unsuitable for real-time deployment. In this work, we propose Online Residual Policy Adaptation (ORPA), a framework that enables immediate, feedback-driven correction of robot actions without modifying the underlying policy parameters. ORPA augments a pretrained control policy with a lightweight, feedback-conditioned module that predicts residual adjustments directly in joint space, allowing the system to adapt its behavior at runtime. We evaluate ORPA on a set of precision-sensitive manipulation tasks using the ALOHA platform, demonstrating improvements in success rate and recovery from small perturbations compared to baseline control policies and rule-based inverse kinematics corrections.

# ORPA 论文详细总结

## 1. 核心问题与研究背景

- **研究对象**：基于模仿学习的机器人操作策略（以 ACT 为代表），其依赖 Transformer 架构预测分块动作序列，在理想条件下表现优异。
- **核心痛点**：此类策略对**执行误差**（末端位姿、方向、时序的微小偏差）和**分布偏移**（物体位移、视角变化、未训练工况）极为敏感，容易在精度敏感任务（杂乱抓取、狭窄空间放置、双臂协调操作）中失败。
- **现有方案的不足**：
  - **数据集聚合 + 全策略重训练**（如 DAgger、HG-DAgger）：计算昂贵、需重复数据采集、修改整个策略网络，不适合实时部署；
  - **基于规则的逆运动学（IK）修正**：将反馈词（如"too left"）映射为固定末端偏移，假设"相同反馈 = 相同修正"，无法感知任务阶段、物体构型与执行上下文；
  - **语言驱动方法**（OLAF、YAY Robot）：依赖 LLM 推理，单步纠正而非整段动作，且每次纠正都需经过 FK→IK 转换链路，存在时延与时序不一致问题。

## 2. 方法论：ORPA 框架

### 2.1 核心思想
- **不动基策略**：将预训练 ACT 作为冻结的底层控制器，仅在其之上附加一个轻量级**反馈条件残差模块**；
- **残差学习**：不在末端空间、而在**关节空间**直接预测修正量 Δa_t，通过 `a_final = â + Δa` 的形式叠加到 ACT 输出；
- **上下文感知**：修正量同时条件于视觉观测、机器人状态、当前 ACT 预测与人类反馈编码，使修正幅度/方向随任务阶段自适应变化。

### 2.2 关键技术模块
- **Feedback Encoder (FE)**：将离散反馈词（"too left / too right / too high / good"）嵌入为潜变量 `r_t = f_ψ(f_t)`；
- **Policy Updater (PU)**：基于 Transformer，输入 `(r_t, o_t, â_{t:t+k})` 输出残差 Δa_t；
- **作用范围**：作用于 ACT 输出的整段动作 chunk（k=100，50Hz），保证时序一致性。

### 2.3 合成数据生成（关键创新）
- 不依赖人工采集纠错示范；
- 在成功示范基础上，对物体位置/姿态施加受控扰动 → 模拟执行失败；
- 根据扰动方向自动分配反馈标签；
- 残差监督目标：`Δa*_t = a_ref − a_perturbed`。

### 2.4 训练目标
- ACT 参数冻结，仅优化 FE 与 PU；
- 损失函数：`L_ORPA = MSE(a_final, a_ref)`，Adam 优化器，学习率 1e-5，2000 epoch，batch size 8；
- 算法流程见论文 Algorithm 2：采样 → ACT 预测 → 反馈编码 → 残差预测 → 加性修正 → MSE 损失反向传播。

## 6. 主要结论与发现

- **成功率显著提升**：
  - Cube Transfer：60% → 92.3%（离散）/ 91.7%（连续）；
  - Bimanual Insertion：60% → 80.3%（离散）/ 84.7%（连续）；
- **优于规则 IK 与 OLAF**：规则 IK 在 Cube Transfer 上仅 76–81%，OLAF 为 78.5%；
- **真机表现**：三个任务分数由 0.79–0.83 提升至 0.81–0.86，加入观测扰动训练后效果更好；
- **行为层面发现**：ACT 自身具备一定的内插与重抓恢复能力，ORPA 在此之上进一步提供反馈驱动的微调；
- **重要观察**：并非所有扰动都需要纠错（如 "too low" 时 ACT 仍可自行恢复），验证了残差模块的**自适应调节**特性。

## 7. 优点

- **轻量且即插即用**：仅训练 FE + PU 两个小模块，部署开销极低；
- **保留基策略性能**：不修改 ACT 参数，避免灾难性遗忘；
- **关节空间直接建模**：省去 FK/IK 链路，降低时延与累积误差；
- **Chunk 级修正**：在动作序列层面进行修正，保证时序一致性；
- **自监督数据生成**：用合成扰动替代昂贵的人工纠错示范；
- **任务阶段感知**：相同反馈在不同阶段可产生不同修正量，超越规则方法的局限。
