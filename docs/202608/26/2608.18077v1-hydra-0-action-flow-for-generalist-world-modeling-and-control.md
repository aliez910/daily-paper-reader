## 摘要
我们提出了 Hydra-0，一种以动作流为条件的通用世界模型，其中机器人动作以像素运动的形式表示。这一共享的视觉界面通过学习跨具身、跨任务、跨环境以及跨视频生成主干的动作后果，实现了通用世界建模与控制。我们的最优配置相较于动作条件基线，机器人运动误差降低 90.4%，物体运动误差降低 60.2%，同时支持零样本组合以及数据高效的自适应。在 RoboLab 基准上，Hydra-0 在回放成功率与参考成功率之间取得了 r=0.96 的皮尔逊相关性。此外，我们还揭示了该界面一种涌现的逆向模式：一种世界动作模型，能够根据从人类示教迁移而来的期望物体流预测兼容的机器人运动。训练好的动作头将所得隐式特征映射为可执行动作，无需任务特定的专家机器人示教数据。综上所述，这些结果展现了动作流作为一种共享控制接口的潜力，能够将异构训练数据、开环策略评估以及机器人控制有机联结起来。

## Abstract
We introduce Hydra-0, a generalist world model conditioned on action flow, which represents robot actions as pixel motion. This shared visual interface enables generalist world modeling and control by learning action consequences across embodiments, tasks, environments, and video-generation backbones. Our best configuration achieves 90.4% lower robot-motion error and 60.2% lower object-motion error than our action-conditioned baseline, while supporting zero-shot composition and data-efficient adaptation. On the RoboLab benchmark, Hydra-0 achieves a Pearson correlation of r=0.96 between replayed and reference success rates. Finally, we uncover an emergent inverse mode of this interface: a world action model that predicts compatible robot motion from desired object flow transferred from a human demonstration. A trained action head maps the resulting latent features to executable actions without requiring task-specific expert robot demonstrations. Together, these results demonstrate the potential of action flow as a shared control interface connecting heterogeneous training data, open-loop policy evaluation, and robot control.

# Hydra-0 论文总结

## 一、核心问题与研究动机

- **关键瓶颈**：异构机器人平台（不同机械臂构型、自由度、控制接口）的动作表征差异巨大（关节角、末端位姿、速度等），使得通用世界模型难以在跨本体、跨任务数据上联合训练。
- **根本矛盾**：现有动作条件（action-conditioned）视频生成模型以本体专属的数值向量作为控制信号，无法泛化到未见过的机器人或新任务，限制了大规模数据复用与通用策略学习。
- **研究目标**：寻找一种**跨本体通用、与视觉模态同构**的控制接口，使世界模型能在异构数据上训练，并自然支持开环评估与下游控制。

## 二、方法论

### 核心思想
- 提出 **Action Flow（动作流）**：将机器人动作编码为**像素级运动场**（即下一帧相对于当前帧每个像素的光流），作为跨具身的共享视觉接口。
- 这种表征与视频生成模型天然同构（视频预测本质上就是预测像素运动），因此可与现有视频扩散 / 自回归模型无缝结合，无需修改主干网络。

### 关键组件
1. **正向模式（Action Flow → 未来视频）**：世界模型以当前观测图像 + 机器人末端执行器或关节对应的 action flow 为条件，预测未来帧。
2. **逆向模式（物体流 → 机器人动作流）**：
   - 从人类示教视频中提取**期望的物体运动流**；
   - 由世界模型根据物体流反推出兼容的**机器人动作流**（隐空间特征）；
   - 通过额外训练的 **action head**（动作映射头）将隐式特征解码为可执行的控制指令。
3. **统一接口优势**：本体差异（执行器构型、关节数、运动学）被吸收进 action flow 的几何结构中，模型只需关注"动作产生的视觉后果"。

### 训练流程（文字概述）
- 数据预处理：对每条机器人轨迹，用光流估计 / 正运动学投影生成 action flow 标注。
- 联合训练：在多本体、多任务混合数据上以视频预测目标训练条件世界模型。
- 逆模式训练：额外加入人类示教数据（仅有物体运动），训练模型根据物体流推断动作流；最后独立训练轻量级 action head。
