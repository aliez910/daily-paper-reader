## 摘要
视觉-语言-动作（VLA）策略在机器人操作任务中表现强劲，但在面对破坏视觉观测、机器人状态与执行动作之间时间对齐的运行时干扰时仍然脆弱。我们提出 ActFovea，一种即插即用的安全保障框架，能够在不重新训练或修改底层 VLA 策略的前提下检测并缓解此类失效。ActFovea 利用机器人运动学、本体感知状态及近期动作构建以动作条件调节的注视区域，保留与接触相关的区域和预测的运动走廊，同时抑制与任务无关的视觉内容。它通过评估视觉运动和观测新鲜度是否与几何、本体感知及动作转移保持一致来检测运行时风险。对于可恢复的干扰，ActFovea 构建针对特定干扰的候选观测，并在验证所产生的动作片段后才接受恢复操作。当观测陈旧或被重放导致无法可靠恢复时，则启动有界的安全失效流程。在 $π_0$ 的多个 LIBERO 套件闭环评估中，ActFovea 将局部视觉叠加场景下的成功率从 49.3\% 提升至 90.3\%，弥合了 93.7\% 的洁净性能差距。它在动作漂移和视觉延迟场景下进一步将成功率分别提升 7.0 和 9.8 个百分点，同时保持洁净任务性能不受影响。在冻结观测重放场景下，ActFovea 在所有试验中均能及时触发安全失效，无任何未受保护的失效发生。上述结果表明，时空视觉-动作一致性为 VLA 策略的运行时安全保障提供了一种有效的基础。

## Abstract
Vision-language-action (VLA) policies achieve strong performance in robotic manipulation but remain vulnerable to runtime disturbances that break the temporal alignment among visual observations, robot states, and executed actions. We introduce ActFovea, a plug-and-play safeguarding framework that detects and mitigates such failures without retraining or modifying the underlying VLA policy. ActFovea uses robot kinematics, proprioceptive states, and recent actions to construct action-conditioned foveated regions that retain contact-relevant areas and predicted motion corridors while suppressing task-irrelevant visual content. It detects runtime risks by evaluating whether visual motion and observation freshness remain consistent with geometric, proprioceptive, and action transitions. For recoverable disturbances, ActFovea constructs disturbance-specific candidate observations and accepts a recovery only after verifying the resulting action chunk. When stale or replayed observations make reliable recovery impossible, it invokes a bounded safe-failure procedure. In closed-loop evaluations of $π_0$ across multiple LIBERO suites, ActFovea increases success under localized visual overlays from 49.3\% to 90.3\%, closing 93.7\% of the gap to clean performance. It further improves success under action drift and visual delay by 7.0 and 9.8 percentage points, respectively, while preserving clean-task performance. Under frozen-observation replay, ActFovea triggers timely safe failure in all trials, with no unprotected failures. These results demonstrate that spatiotemporal visual-action consistency provides an effective basis for runtime safeguarding of VLA policies.

# ActFovea 论文总结

## 一、核心问题与研究动机

- **研究背景**：视觉-语言-动作（VLA）策略（如 π0、OpenVLA、RT-2 等）已成为通用机器人操作的强大范式，其通过动作分块（action chunking）机制摊销推理开销并提升时序一致性。
- **核心问题**：VLA 策略在闭环执行中极易受到运行时干扰，破坏**视觉观测、本体感知与已执行动作**三者之间的时空一致性。具体包括：
  - **空间视觉不一致**：局部视觉叠加（localized overlays）篡改任务相关图像证据；
  - **时序视觉不一致**：视觉反馈延迟使图像与机器人当前状态失配；
  - **动作轨迹不一致**：平滑的动作分块漂移（SilentDrift 类攻击）使轨迹失去状态支撑；
  - **冻结观测重放**：反复使用陈旧帧，使策略失去新鲜视觉依据。
- **现有方法不足**：训练时鲁棒化（SafeVLA、Phantom Menace 等）需重新训练；推理时控制屏障（VLSA）和观测干预（BYOVLA）通常只针对单一类干扰，缺乏**统一的、面向可恢复性判断**的运行时闭环保障。
- **核心洞察**：可靠的判断必须基于一个可观测的结构——**时空视觉-动作一致性**，即视觉内容、本体感知转移与候选动作应当共同描述机器人与环境的同一物理演化过程。

## 二、方法论

### 2.1 总体框架

- **设计目标**：即插即用（plug-and-play），不修改底层 VLA 策略参数，仅通过**观测-动作接口**进行干预。
- **三大组件**：
  1. **动作条件注视区域构建（Action-Conditioned Foveation）**：基于运动学与动作历史动态构建以交互为中心的保留区。
  2. **一致性监控器（Consistency Monitor）**：综合几何、动态、时序、本体感知等分量评分，输出风险 Rt 并路由扰动类型。
  3. **扰动条件候选观测 + 动作分块验证 + 风险自适应执行 + 安全失效**：形成统一的恢复-执行-失效闭环。

### 2.2 关键技术细节

- **保留区掩码 M_v^t**（式 2）：
  - 由投影接触中心圆盘 M_v^c,t（半径 r_c）和运动走廊 M_v^Γ,t（半径 r_Γ）并集后膨胀（半径 r_m）而成。
  - 接触中心通过正向运动学将夹爪 pinch 点投影至相机模型；严格投影不可用时退化为常速笛卡尔外推或上一帧跟踪中心。
- **过滤图像生成**（式 3）：在保留区外对背景做归一化、平滑、灰度混合，编辑强度 α 有界且保留任务关键区域。
- **一致性监控**：综合
  - **几何一致性**：观测中心 ĉ_v^t 与投影中心的距离；
  - **任务一致性**：投影走廊内的支持度；
  - **动态一致性**：预测与观测位移的方向与幅值一致性；
  - **时序证据**：时间戳健康度、缺失运动、滞后估计、整体重放相似度；
  - **动作-本体一致性**等分量。加权和后与 EMA 平滑结合，按式 4 得出最终风险 R_t。
- **扰动路由**：确定性路由器依据时序持久性区分
  - 视觉延迟（lag 主导）、
  - 动作漂移（动态 + 本体不一致主导）、
  - 局部叠加（区域检测证据主导）、
  - 冻结重放（强陈旧证据 + 保持锁存器）→ 不可恢复状态。
- **候选观测库（Recovery Bank）**：保留原始与注视后观测；对有限视觉延迟加入时序稳定化候选（图像平面平移补偿，腕部相机衰减）。
- **叠加区域修复**（式 5）：通过中值稠密光流将最近清洁参考对齐至当前帧，估计叠加图样 Q̂ 与混合系数 α̂，逆混合重建，羽化融合；仅当**每视图**均满足最弱视图质量门控才接受。
- **动作分块验证**（式 6）：评估首动作方向、末端方向、运动幅值、平滑度、horizon、分块漂移等指标；得分 V_k = clip(wᵀu_k + b_k, 0, 1)；选取得分最高、优先级匹配、且满足策略动作包络的候选；原始动作作为保守回退。
- **风险自适应执行**（式 7）：监控器缩放 λ_mon^t 与执行时长 h_mon^t 联合验证器缩放 λ_ver^t 与执行时长 h_ver^t，二者仲裁；监控级 hold 与验证级 safe-failure 可强制运动归零；保持阶段延续上一帧夹爪命令。
- **有界安全失效**：新鲜证据耗尽时，夹紧执行（hold 锁存器），可能预置一个截短的反向动作后保持。

## 三、实验设计

### 3.1 基准与协议

- **VLA 策略**：使用 π0 在 LIBERO 上的**冻结**检查点。
- **基准套件**：LIBERO 四套件（Spatial / Object / Goal / 10），每套件 10 个任务，每任务 50 个回合，每方法-场景共 **2000 回合**。

  - **平滑动作分块漂移**：基于任务族相位的运动维度扰动；

- 任务成功率 SR、防御增益 Gain（百分点）、归一化恢复率 NRR（式 8）。

### 3.3 对比方法（训练时无关推理方法）

- **Action Clip/Smoothing**：对运动维度施加固定有界平滑；
- **Fixed Short Horizon**：缩短动作前缀后重新规划；
- **Timestamp-Only Hold**：基于帧龄与重复图像证据暂停执行；

## 六、主要结论与发现

- **局部视觉叠加**：Base VLA 49.3% → ActFovea 90.3%，**NRR = 93.7%**（最大增益 +41.0 pp）。
- **多视角视觉延迟**：76.2% → 86.0%，NRR = 59.8%（+9.8 pp）。
- **平滑动作漂移**：83.1% → 90.1%，NRR = 73.1%（+7.0 pp）。
- **未扰动场景**：93.0% → 93.8%，**几乎无性能损失**。
- **冻结观测重放**：100% 触发及时安全失效，**零未受保护失效**；仅 2.0 个有界动作步被执行，累积动作范数 0.326。
- **机制分工**（消融表 4）：
  - **动作验证**是时序/动作侧恢复的核心（去掉后增益骤降为 -1.2 / +2.3 pp）；
  - **扰动分型、候选库、候选扩展**对空间叠加恢复至关重要（去掉后增益分别跌至 -7.6 / -33.3 / -31.7 pp）；
  - 表明"分而治之"的统一管道有效，但各组件对不同扰动的贡献度不同。
- **统一管道 vs 单一保守规则**：固定短 horizon、timestamp-only hold 等单一规则无法跨扰动迁移，而 ActFovea 是唯一同时改善三类可恢复扰动且不损伤洁净性能的方法。

## 七、优点（方法与实验亮点）

- **即插即用、不重训**：仅通过观测-动作接口干预，对冻结 VLA 完全黑盒友好，部署成本低。
- **统一的时空一致性原则**：将异质扰动统一为视觉-动作一致性违反，使一条管道支持多类扰动，避免堆叠专门检测器。
- **以交互为中心的注视机制**：不同于几何中心或静态 ROI，保留区跟随接触点与运动走廊，能在 9-13% 的保留率下保持任务关键证据。
- **可恢复性感知**：显式区分"可恢复 / 边界 / 不可恢复"，并通过 hold 锁存器与 bounded safe-failure 提供有界安全终端。
- **扰动条件候选库 + 动作分块验证**：将"修复观测"与"接受动作"解耦，原始观测作为保守回退，工程鲁棒性强。
- **实验规模较大**，含四 LIBERO 套件 + 万级回合 + 完整消融，论证较充分。
