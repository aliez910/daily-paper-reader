## 摘要
VLA模型的视觉表征在空间精确的机器人操控任务中仍然不可靠。我们发现，VLA中的视觉编码器同样存在先前在通用视觉Transformer中被记录的注意力伪影，并进一步证明，在具身策略中，这些伪影与后训练阶段习得的空间感知能力密切相关。随着编码器学习任务相关信息（如物体位置、深度顺序与局部几何），有限的全局token容量会导致其中部分信息泄露到低信息量的patch token中。我们提出了AtVLA框架，通过在视觉编码器中插入可学习的寄存器token来实现这一目标。该方法仅使用具身数据和原始的动作目标进行端到端训练，这些寄存器逐渐成为承载具身空间信息的专用载体，而其余patch token则恢复出干净且空间保真的注意力分布，这对于精确的目标定位和细粒度接触至关重要。干净的注意力恢复了可靠的定位能力，但无法弥补低分辨率观测中丢失的几何细节。因此，AtVLA将注意力矫正与不确定性门控的局部细化相结合。动作专家对多个动作分块进行采样，并依据它们之间的分歧估计不确定性；仅对不确定的预测，由动作条件化的注意力展开来识别任务相关区域，将其裁剪后重新以高分辨率编码，并附加到已缓存的前缀上以实现细化的动作生成。在LIBERO、SimplerEnv以及一个具有挑战性的单视角真实世界基准测试上，AtVLA将LIBERO的平均成功率从94.2%提升至98.4%，将真实世界成功率从46.5%提升至69.0%。在代表性的部署设定下，约30%的重规划步骤会触发裁剪操作，使得总计算量仅为基线模型的1.4–1.6倍。

## Abstract
Visual representations of VLA models remain unreliable for spatially precise robotic manipulation. We uncover that vision encoders in VLAs also exhibit attention artifacts previously documented in generic Vision Transformers, and further show that, in embodied policies, these artifacts are closely associated with spatial perception capabilities acquired during post-training. As the encoder learns task-relevant information such as object location, depth ordering, and local geometry, limited global-token capacity causes part of this information to spill into low-information patch tokens. We introduce AtVLA, a framework that inserts learnable register tokens into the visual encoder. Trained end-to-end using only embodied data and the original action objective, these registers emerge as dedicated carriers of embodied spatial information, while the remaining patch tokens recover clean and spatially faithful attention distributions crucial for precise target localization and fine-grained contact. Clean attention restores reliable localization, but cannot recover geometric details lost in low-resolution observations. AtVLA therefore couples attention rectification with uncertainty-gated local refinement. The action expert samples multiple action chunks and estimates uncertainty from their disagreement; only for uncertain predictions, action-conditioned attention rollout identifies the task-relevant region, which is cropped, re-encoded at high resolution, and appended to the cached prefix for refined action generation. Across LIBERO, SimplerEnv, and a challenging single-view real-world benchmark, AtVLA improves the average LIBERO success rate from 94.2% to 98.4% and real-world success from 46.5% to 69.0%. The cropping is triggered on approximately 30% of replanning steps, resulting in only 1.4-1.6x the total computation of the base model under the representative deployment setting.

# 论文总结：AtVLA — 面向视觉-语言-动作模型的自适应视觉细化

## 1. 核心问题与研究动机

VLA 模型通过在大规模机器人演示数据上后训练，继承了视觉-语言基础模型的语义先验，已在通用机器人操控中展现出良好泛化能力。然而，机器人操控不仅需要语义识别，还要求视觉编码器保留**空间保真**的表征以实现目标定位、几何推理和精细接触。文章指出当前 VLA 存在两大视觉瓶颈：

- **注意力伪影（Attention Artifacts）**：通用 ViT 中已被记录的"高范数伪影"在 VLA 视觉编码器中同样存在——低信息的背景 patch 被改用作全局信息仓库，挤占局部空间内容并破坏密集注意力图谱。
- **后训练加剧该问题**：具身后训练需要编码器习得物体位置、深度顺序、实例结构与局部几何等空间信息，但原始全局 token 容量有限，导致这些具身空间信息"溢出"到 patch token 中，使"有用具身知识被存储在了错误的表征通道"。
- **精细几何的分辨率限制**：即使定位正确，接触区域附近的局部几何在低分辨率第三视角中仅占少量 patch；腕部相机虽提供近景但视点敏感。
- **核心研究问题**：具身后训练如何重塑预训练编码器的视觉表征？这些表征在细粒度操控中是否足够可靠？

## 2. 方法论

AtVLA 在 π0（基于 PaliGemma + SigLIP-So400m + Gemma-2B + 300M 动作专家）基础上引入两大互补机制：**寄存器增强视觉前缀** + **不确定性门控局部细化**。

### 2.1 寄存器增强视觉前缀

- 在 SigLIP 编码器中（224×224，patch=14，N_b=256 patch token）在 CLS token 后插入 **N_r=4 个可学习寄存器 token**：
  $$X_t = [x_{cls}; r_1, \dots, r_{N_r}; p_1, \dots, p_{N_b}]$$
- 编码器输出为 $[h_{cls}, R_t, P_t] = E_{vis}(X_t)$，其中 $R_t$（寄存器特征）和 $P_t$（patch 特征）都经 PaliGemma 投影器 $\Pi$ 暴露给下游策略：
  $$C_t^{base} = [\Pi(R_t); \Pi(P_t); E_{lang}(\ell); E_{state}(s_t)]$$
- **关键创新点**：与"丢弃寄存器"的原始做法不同，AtVLA **保留寄存器输出作为多槽全局具身空间上下文**，而 patch token 恢复干净的空间局部表征。多视角时各视图独立编码后拼接。

### 2.2 不确定性门控动作预测

- LLM 骨干网处理 $C_t^{base}$ 一次，构建可复用 KV 缓存。
- 动作专家从独立高斯初始化中采样 **K 个动作分块**（共享视觉/语言前缀）：
  $$z_0^{(k)} \sim \mathcal{N}(0, I), \quad A_{1:H}^{(k)} = \text{ODESolve}(v_\theta, z_0^{(k)} | C_t^{base})$$
- 不确定性度量：限定在平移维度 $D_{tr}$ 与即将执行的前 h 步：
  $$U_t = \frac{1}{h|D_{tr}|}\sum_{j=1}^{h}\sum_{d\in D_{tr}}\sqrt{\frac{1}{K-1}\sum_{k=1}^{K}\left(A_{j,d}^{(k)} - \bar{A}_{j,d}\right)^2}$$
- 若 $U_t \le \tau$，沿原路径返回平均动作分块；否则触发局部细化。**阈值在验证集上校准**，按"约 30% 触发率"和"细化带来的误差缩减"双重约束选取。

### 2.3 注意力引导的局部细化

当 $U_t > \tau$ 时：

1. **注意力 rollout**：复用动作采样中已产生的注意力矩阵，对每层 l 在多头与多个 denoising 步（Q={3,6,9}）上平均，加残差连接、行归一化得 $\bar{M}_l$；rollout 传播 $M_{roll} = \bar{M}_L \bar{M}_{L-1}\cdots\bar{M}_1$（覆盖动作专家全部 18 层联合注意力）。
2. **显著性图**：从前 h 个 action-token 行到 256 个 base-image patch 列取均值，重塑为 16×16 图 $S_t$；双线性上采样至原图分辨率。**排除寄存器列**（其不对应固定网格）。
3. **对比窗口搜索**：候选方形窗口边长 $S=\{84, 112, 140\}$ 像素，stride=14。对窗口 b，扩展上下文窗口 $\rho(b)$（×1.25），选择**内部与邻环区分度最大**的窗口：
   $$b_t^* = \arg\max_{b\in B}\left[\frac{1}{|b|}\sum_{u\in b}S_t(u) - \frac{1}{|\rho(b)\setminus b|}\sum_{u\in\rho(b)\setminus b}S_t(u)\right]$$
   该对比准则抑制"全图裁剪"与"孤立尖峰"两种退化。
4. **裁剪重编码**：裁剪区域 10% padding 后 resize 到 224×224，经同一寄存器增强编码器；丢弃 crop 侧寄存器（全局信息已由 base 寄存器承载），保留 256 个 crop patch 特征 $P_t^c$。
5. **位置嵌入**：将归一化坐标 $(x_1/W, y_1/H, x_2/W, y_2/H)$ 经两层 MLP(4→256→d_LLM) + GELU 得 $e_b$，加到每个 crop patch 投影上：
   $$C_t^+ = [C_t^{base}; \Pi(P_t^c) + \mathbf{1}_{N_c}e_b^\top]$$
6. **前缀缓存复用**：仅新追加 crop 段需重新预填充，base/image/language/state 的 KV 缓存直接复用。

### 2.4 训练策略（三阶段后训练课程）

保留 π0 原动作损失 $\mathcal{L}_{\pi_0}$，仅引入两个辅助项：
$$\mathcal{L} = \mathcal{L}_{\pi_0} + \lambda_{cp}\mathcal{L}_{cp} + \lambda_{ag}\mathcal{L}_{ag},\quad \lambda_{cp}=0.1,\ \lambda_{ag}=1.0$$

- **Stage 0 寄存器适应（20K 步）**：前 4K 步仅训寄存器（lr=1e-4），后 16K 步解冻 SigLIP 最后 4 个 transformer block（lr=2e-5）。
- **Stage 1 真值裁剪对齐（10K 步）**：冻结完整视觉编码器，引入 ground-truth 裁剪并训练 crop 位置 MLP + LoRA（rank-32）。
- **Stage 2 联合精化与推理对齐（40K 步）**：LoRA 全开，叠加 $\mathcal{L}_{ag}$。**三段式裁剪课程**：
  - 0–40% 步：全用真值裁剪，dropout=0；
  - 40–90% 步：rollout 裁剪比例 $\alpha$ 从 0 线性增至 1，dropout 从 0 增至 0.3；rollout 无效时直接跳过裁剪（与推理失败处理一致，避免 train-test 偏差）；
  - 最后 10%：全部 rollout 裁剪，dropout=0.3。

$\mathcal{L}_{ag}$ 鼓励 action-to-image 注意力集中于真值框内 patch。

## 3. 实验设计

### 3.1 数据集 / 场景 / Benchmark

- **LIBERO**（4 个标准子集：Spatial、Object、Goal、Long-10），训练数据 40 任务 × 50 演示 = 2,000 条轨迹。
- **SimplerEnv Google Robot 套件**：Pick Coke Can、Move Near、Open/Close Drawer（刻意省略 WidowX，因其需 BridgeData 训练与本体适配）。
- **真实世界基准**（Franka Research 3 + 单视角 Intel RealSense D435i）：
  - **Kitchen**：杂乱家庭场景中视觉接地、接触点定位与空间推理；
  - **Building Blocks**：小物体抓取、堆叠、空间结构构建（含长时序任务）。

### 3.2 对比方法

- **公开基准**：Octo、OpenVLA、π0、π0.5、SpatialVLA、CoT-VLA、RoboVLM、OFT、VLANeXt、TraceVLA、RT-1-X、RT-2-X。
- **受控消融变体（共享同一 π0 初始化与数据）**：
  - π0 + Registers：仅寄存器增强；
  - π0 + Cropping：仅由外部未在具身数据上训练的 VLM 提供裁剪；
  - **AtVLA（Full）**：寄存器 + 注意力引导裁剪。
- **真实世界**：所有本地方法使用同一相机观测、任务演示与相近微调步数。

### 3.3 主要结果

- **LIBERO**：AtVLA 全套在四子集均最佳（99.3 / 99.4 / 98.3 / 96.5），平均 98.4%（π0 为 94.2%）。
- **SimplerEnv**：PCC 91.3、MN 81.6（最佳），O/C 57.5（因场景大部分是橱柜，裁剪退化为全图）。
- **真实世界**：AtVLA 在 10 项任务中均最强，整体从 46.5% → 69.0%（相对 π0）；尤其在 Building Blocks Spatial / Grab / Long 类目提升显著。
- **受控变体**：π0+Registers 偏强空间推理/定位；π0+Cropping 偏强细粒度与长时序但受裁剪质量制约；消融去掉寄存器后平均掉 4.45%。

### 3.4 针对性分析（Q1–Q4）

- **Q1**：寄存器后注意力显著恢复空间保真度，可可靠引导裁剪。
- **Q2**：线性探针显示寄存器在物体定位、深度、法向量三类任务探针上得分最高（均 >0.70），强于 CLS 与池化 patch 特征。
- **Q3**：裁剪在细粒度、长时序任务带来最大增益，但错误的裁剪会污染策略输入、增加动作不确定性。
- **Q4**：计算量估算 $C_{AtVLA} = N(C_{base} + K C_A + r(C_{crop}+C_A))$，在 K=4、r≈0.3 下约 1.4–1.6× π0。

## 6. 主要结论与发现

1. **VLA 视觉编码器的"高范数伪影"与具身后训练习得的空间信息密切相关**，原本用于全局语义的 token 容量不足以承载物体位置、深度顺序、局部几何等具身空间信息，导致溢出到背景 patch。
2. **可学习寄存器 token 可被纯具身动作目标训练成具身空间信息的专用载体**，同时使剩余 patch 恢复干净、空间保真的注意力分布。
3. **不确定性门控的、按需局部细化**比无条件全图细化更高效：仅约 30% 重规划步触发裁剪，总计算仅 1.4–1.6× π0。
4. **寄存器 + 注意力引导裁剪两者协同**：寄存器提供"看哪里"，裁剪补充"看不清的几何"。
5. **寄存器特征在三类线性探针上均优于 CLS 与 patch 池化**，证明其编码了超越原始全局 token 的具身空间结构。
6. 4 个寄存器是"最小充分容量"；过少不能吸收伪影，过多则无额外增益。
7. 在 LIBERO、SimplerEnv、真实世界基准上一致提升，且对空间推理与长时序任务增益尤为显著。

## 7. 优点

- **问题诊断深入**：不仅复现通用 ViT 的注意力伪影，还明确将其归因到"具身后训练习得的空间信息溢出"，给出了机制性解释。
- **保留而非丢弃寄存器输出**，并通过线性探针验证其蕴含丰富空间信息——这是相对"Vision Transformers Need Registers"的实质性扩展。
- **不确定性门控机制优雅**：复用动作采样过程的天然随机性，无需额外监督；以"约 30% 触发率"硬性预算平衡精度与开销。
- **KV 缓存复用**与注意力 rollout 复用基础采样过程，使细化分支的边际成本极低。
- **三段式裁剪课程**显式缓解 train-test 偏差（rollout 无效时直接跳过裁剪，与推理一致）。
- **受控变体设计严谨**：π0+Registers、π0+Cropping、AtVLA(Full) 三者共享初始化与数据，可单独归因。
- **真实世界单视角场景下的显著提升**（+22.5 个百分点）说明方法的实用价值。
- **报告了真实部署延迟/计算开销**，未仅停留在仿真指标。

## 8. 不足与局限

- **数据集与平台局限**：
  - 真实世界仅 10 项任务、单一机器人（Franka）、单视角（无腕部相机）；
  - SimplerEnv 省略 WidowX 套件，缺少跨本体验证；
  - 缺少多视角、3D 传感器或腕部相机协同验证。
- **裁剪机制局限**：
  - Open/Close Drawer 任务中场景被橱柜主导，裁剪退化为近似全图，未能命中把手/接触点；
  - 外部 VLM 裁剪（π0+Cropping）质量差时反而损害策略；
  - 假设任务相关区域近似方形且可被固定尺寸集合 {84,112,140} 覆盖，极细长目标或显著变形物体可能失效。
- **注意力 rollout 依赖**：仅基于 action-to-image 注意力，若基础采样过程中注意力本身被伪影干扰，则 rollout 可能指向错误区域（虽已用寄存器矫正，但未给出失败案例的系统化统计）。
- **训练资源消耗**：3 阶段 70K 步在 8 张 RTX 6000 Ada 上完成，未给出具体小时数；门槛相对较高。
- **阈值与超参敏感性**：不确定性阈值 $\tau$ 需按 embodiment 分别校准，对新机器人迁移存在一定工程负担。
- **未与最新 VLA（如 π0.5、OpenVLA-OFT 等）做头对头单视角适配**，部分基线得分引用自原始论文，可能存在评测设置差异。
- **风险偏差**：所有真实世界实验 20 次独立试验，置信区间仍较宽（部分任务 ±10%），单视角几何模糊性可能系统性影响 Spatial/Grab 类任务。
- **应用限制**：未讨论光照剧烈变化、透明/反光物体、高度杂乱遮挡等真实世界极端情形。
