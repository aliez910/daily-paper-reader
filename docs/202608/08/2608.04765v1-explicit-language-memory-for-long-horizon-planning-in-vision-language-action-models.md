## 摘要
视觉-语言-动作（VLA）模型为连接视觉感知、语言理解与机器人控制提供了统一范式。然而，现有VLA模型在长时序任务中仍面临重大挑战：稀疏的专家演示限制了跨任务组合泛化能力；长时序任务的非马尔可夫性质使得仅以当前观测为条件进行策略学习难以保持时间一致性；有限的闭环纠错能力导致执行误差不断累积；端到端的动作微调可能会削弱视觉-语言模型（VLM）骨干网络的高级语义表征能力。为解决这些问题，我们提出了一种带有显式语言记忆模块的层次化长时序VLA架构。其核心思想是将离散的时序观测转换为具有时间逻辑的连贯文本记忆序列。该系统解耦为高层VLM和低层VLA：高层VLM通过视觉问答训练范式执行语义推理，低层VLA以子任务指令和视觉观测为条件执行精确的连续控制。高层VLM以先前记忆作为上下文锚点，递归地更新语言记忆和子任务指令，从而在长时序执行过程中实现持续的时间跟踪和动态纠错。我们在多个仿真环境中对所提方法进行了评估，并在真实机器人平台上进行了仿真到现实的迁移实验。实验结果表明，显式语言记忆提升了VLA模型在复杂长时序任务上的成功率和鲁棒性，同时为决策过程提供了可解释的语义说明。

## Abstract
Vision-language-action (VLA) models provide a unified paradigm for connecting visual perception, language understanding, and robotic control. However, existing VLA models still face major challenges in long-horizon tasks: sparse expert demonstrations constrain cross-task compositional generalization; the non-Markovian nature of long-horizon tasks makes it difficult for policies conditioned only on current observations to maintain temporal consistency; limited closed-loop error correction allows execution errors to accumulate; and end-to-end action fine-tuning may weaken the high-level semantic representations of vision-language model (VLM) backbones. To address these issues, we propose a hierarchical long-horizon VLA architecture with an explicit language-memory module. The central idea is to convert discrete temporal observations into a coherent textual memory sequence with temporal logic. The system is decoupled into a high-level VLM and a low-level VLA: the high-level VLM performs semantic reasoning through a visual question answering training paradigm, while the low-level VLA executes precise continuous control conditioned on subtask instructions and visual observations. The high-level VLM recursively updates both language memory and subtask instructions using the previous memory as a contextual anchor, enabling persistent temporal tracking and dynamic correction during long-horizon execution. We evaluate the proposed method in multiple simulation environments and conduct sim-to-real experiments on a real robotic platform. The results demonstrate that explicit language memory improves the success rate and robustness of VLA models on complex long-horizon tasks while providing an interpretable semantic account of the decision process.

# 面向视觉-语言-动作模型长时序规划的显式语言记忆 — 论文总结

## 1. 核心问题与研究动机

论文聚焦于 **视觉-语言-动作（VLA）模型在长时序任务中的四大固有缺陷**：

- **稀疏专家演示**：难以支撑跨任务组合泛化；
- **非马尔可夫性**：仅以当前观测为条件的策略无法维护时序一致性（同一视觉状态在不同阶段可能对应截然不同的决策）；
- **闭环纠错能力弱**：执行误差沿动作链不断累积；
- **端到端动作微调风险**：可能损害 VLM 骨干网络的高层语义表征能力。

整体含义：VLA 模型虽然在短时序动作生成上表现优异，但缺乏一种紧凑、可解释、能跨决策持久保留任务进度的"记忆"机制，限制了其向数分钟乃至十余分钟级复杂任务扩展的能力。

## 2. 方法论

### 2.1 核心思想

提出一种 **分层长时序 VLA 架构**，核心是 **将离散时序观测压缩为带时序逻辑的连贯文本记忆序列**。系统解耦为：

- **高层 VLM**（基于 PaliGemma）：负责语义推理与阶段追踪；
- **低层 VLA**（基于 π0.5）：负责精确连续动作生成。

### 2.2 概率分解公式

$$\pi(a_{t:t+H}, s_t, m_t \mid o_t, m_{t-1}, l) = \pi_{LL}(a_{t:t+H} \mid o_t, s_t) \cdot \pi_{HL}(s_t, m_t \mid o_t, m_{t-1}, l)$$

- $l$：全局任务指令；
- $o_t$：当前视觉 + 本体观测；
- $m_{t-1}$：上一时刻语言记忆；
- $s_t$：当前子任务指令；
- $a_{t:t+H}$：连续动作块（$H=30$）。

### 2.3 关键技术细节

- **递归语言记忆机制**：记忆 $m_t$ 以"过去时描述已完成阶段 + 现在时描述当前状态 + 将来时描述下一意图"的结构化自然语言形式存在；只有当当前观测提供阶段切换证据时才更新；
- **滚动压缩规则**：未完成的子任务保留颜色、位置等细节；完成后压缩为简短陈述；
- **自动监督流水线**：利用通用 VLM（Gemini 3.5 Flash API 或本地 Qwen3.5-9B），结合专家视频与技能标注，自动生成对齐的 $(m_t, s_t)$ 监督信号；
- **独立分支训练**：高层以自回归方式预测 $m_t$ 与 $s_t$；低层以 flow-matching 目标优化动作块，避免端到端联合损失平衡难题；
- **高层损失**：$\mathcal{L}_{HL} = -\mathbb{E}[\log\pi^{HL}_m + \log\pi^{HL}_s]$；
- **低层损失**：$\mathcal{L}_{LL} = \mathbb{E}\|a_{t:t+H} - \pi_{LL}(o_t, s_t)\|^2_2$；
- **闭环推理流程**：初始化 $m_0=\varnothing$，循环观测→更新记忆→生成动作块→执行，直至高层状态判定任务终止。

## 6. 主要结论与发现

- **性能提升**：
  - BEHAVIOR-1K 收音机任务：平均成功率 30.0% → **40.0%**，PickUp 阶段提升最大（10% → 30%）；

## 7. 优点

- **架构设计清晰**：高层语义推理 + 低层运动控制的解耦避免了单一端到端损失中语言与控制目标的相互干扰；
- **可解释性强**：语言记忆与子任务均为可见文本，可与动作日志对齐，便于失败归因；
- **自动化监督**：利用通用 VLM 自动生成 $(m_t, s_t)$ 训练标签，降低人工标注成本；
- **跨平台验证**：从仿真到低成本真实机器人多场景覆盖，验证方法实用性；
- **闭环节流成本低**：相较堆叠历史帧的方法，记忆长度受控，部署更现实；
- **设计假设明确**：论文清楚区分了"语义记忆能做什么"（阶段跟踪、跳过预防、失败记录）与"不能做什么"（接触式精细操作、几何对齐），结论边界清晰。

## 8. 不足与局限

- **真实机器人评估规模过小**：仅 25 条轨迹、20 次试验的短任务，无法证明分钟级真实场景的有效性；
- **缺乏统计严谨性**：未报告多次随机种子结果或置信区间，难以判断改进的统计显著性；
- **缺少消融实验**：未验证记忆格式选择、记忆更新频率、不同 VLM 主干（如 Qwen vs. PaliGemma）、LoRA 与全参数微调差异等组件贡献；
- **计算开销增大**：每次动作生成前需先调用高层 VLM，端到端延迟与部署复杂度高于原生 π0.5；
- **数据需求隐性**：依赖专家技能级标注（技能名、起止时间戳），泛化至无标注场景受限；
- **不能弥补低层控制缺陷**：PressOn 阶段在两种方法上均接近失败，说明语义记忆无法解决接触式精细动作问题；
- **失败恢复依赖数据**：可靠的上下文恢复需要多样化的失败-恢复演示，目前尚不具备；
- **记忆格式局限性**：仅文本模态，缺乏视觉证据、触觉/力反馈等模态，对视觉模糊状态区分不足。
