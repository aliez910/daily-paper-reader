## 摘要
接触丰富的操作任务需要精确的跟踪与机械顺应性，其中可变阻抗控制能够提升任务成功的鲁棒性，而静态顺应性则无法适应变化的接触约束。可变阻抗技能可以从示范中学习，避免复杂的建模，但顺应性在缺乏力信息的运动学数据中是隐含变量。现有方法从轨迹变化中推断顺应性，但这些变化可能反映的是几何适应而非在空间布局变化时的主动顺应性。因此，本文提出可变阻抗扩散策略（VIDP），一种基于模仿学习的可变阻抗控制框架，采用任务参数化方向感知混合模型（TP-DAMM）从多样化示范中提取物理一致的轨迹分布。通过将分布映射到刚度轮廓，VIDP 在无需力传感器的情况下联合预测位姿动作与任务顺应性。真实世界实验表明，VIDP 在任务成功率上显著优于固定阻抗基线，同时相对于高刚度控制器降低了交互力，相对于低刚度基线减少了跟踪误差。

## Abstract
Contact-rich manipulation requires precise tracking and mechanical compliance, where variable impedance control can improve robustness in task success, whereas static compliance cannot adapt to varying contact constraints. Variable impedance skills can be learned from demonstrations, avoiding complex modeling, but compliance is a hidden variable in force-agnostic kinematic data. While existing methods infer compliance from trajectory variations, these variations may reflect geometric adaptation and not intentional compliance when subject to changing spatial layouts. Therefore, this letter introduces Variable Impedance Diffusion Policy (VIDP), an imitation learning-based variable impedance control framework leveraging a Task-Parameterized Directionality-Aware Mixture Model (TP-DAMM) to extract physically consistent trajectory distributions from diverse demonstrations. By mapping distributions to stiffness profiles, VIDP jointly predicts pose actions and task compliance without force sensors. Real-world experiments show that VIDP significantly outperforms fixed-impedance baselines in task success rate while reducing interaction forces with respect to high stiffness controllers and tracking errors with respect to low stiffness baselines.

## 一、核心问题与研究动机

- **任务背景**：接触丰富的机器人操作（如插孔装配、绕线、绕缆）需要同时兼顾精确跟踪与机械顺应性。静态阻抗（固定刚度）无法适应变化的接触约束。
- **核心矛盾**：可变阻抗可显著提升任务鲁棒性，但刚度参数在纯运动学（无力学信号）演示数据中是**隐藏变量**，难以直接学习。
- **现有方法局限**：
  - 依赖力/力矩传感器：成本高、噪声大、与视觉难以同步，且商用协作机器人常不具备；
  - 从轨迹方差反推刚度：仅在固定参考系下有效，无法泛化到不同空间布局；
  - 扩散策略类的视觉运动策略：将接触任务视为纯几何问题，忽略了内在柔顺性。
- **关键歧义**：当人类在不同空间布局下演示同一任务时，**轨迹变化**可能源于"主动顺应"（如顺从表面应力）或"几何适应"（如变换落点），传统方法无法区分。
- **研究目标**：从**缺乏力信号**、**空间布局多样化**的演示中学习**可变阻抗**策略，在无外置力传感器条件下联合预测位姿与任务顺应性。

## 二、方法论

- **整体框架**：VIDP = TP-DAMM（轨迹分布提取）+ 刚度映射 + 扩散策略（DDPM）端到端训练，三阶段流程（图1）。
- **核心组件 1：TP-DAMM（任务参数化方向感知混合模型）**
  - 继承 TP-GMM 的多任务帧对齐能力（投影到 P 个候选参考系后取 Product of Gaussians 融合）；
  - 继承 DAMM 的方向感知能力，对速度方向进行单位球 S^{d-1} 上的黎曼统计；
  - 状态增强：在每个任务帧 j 下，将局部位置 x^{(j)}_t 与基于 Fréchet 均值与对数映射的方向偏差 d^{(j)}_{t,m} 拼接为 \hat{x}^{(j)}_{t,m} ∈ R^{d+1}；
  - 协方差采用块对角结构，独立建模空间分布 Σ_pos 与方向方差 σ²_dir；
  - 推理采用**并行分裂-合并 Gibbs 采样**（Algorithm 1），必要时对增强空间做 SVD 降维以避免退化（Nm < D_aug 时）。
- **核心组件 2：分布到刚度的映射**
  - 取融合后的空间协方差 \hat{Σ}_m，做特征值分解 (\hat{Σ}_m)^{-1} = V_m Λ_m V_m^T；
  - 将特征值按全局 [λmin, λmax] 线性重映射到机器人可执行刚度区间 [κmin, κmax]，再重建 K_trans = V_m D_m V_m^T；
  - 在时间维度施加滑动平均滤波，平滑跨聚类切换的刚度跳变。
- **核心组件 3：可变阻抗扩散策略**
  - 监督信号：先用 TP-DAMM 为每条演示推断刚度轨迹，形成 D = {(O_t, A_t)} 训练集；
  - 观测 O_t：腕戴 RGB 图像（CLIP-ViT 微调 + 注意力池化）+ 末端 6D 旋转 + 3D 位置（MLP 编码）；
  - 动作 A_t = [p⊤, r⊤, c⊤]⊤ ∈ R^{15}：位姿 + 上三角 Cholesky 因子 c，通过 K_trans = U^T U 重建对称正定刚度矩阵；
  - 训练：1D 时序 U-Net 噪声预测，AdamW + 余弦学习率，标准 DDPM MSE 损失；
  - 推理加速：DDIM 调度器 + Real-Time Chunking（RTC）异步执行，并将扩散模型重解释为最优传输条件流，通过梯度引导（公式 (13)）保证动作块的时序一致性。
- **控制层**：关节阻抗控制 τ_cmd = Ĉ\dot{q} + ĝ + K_P(qd − q) + K_D(\dot{qd} − \dot{q})，K_P, K_D 经雅可比映射到操作空间，阻尼比 ζ = 0.707，旋转与零空间刚度固定为保守标称值。

## 七、优点

- **方法创新**：将 TP-GMM 的多任务帧对齐与 DAMM 的方向感知正交融合，块对角协方差 + 黎曼方向统计 + 任务参数化并行采样，思路清晰、工程可实现。

- **数据效率与硬件友好**：完全去力传感器，仅依赖 RGB + 末端位姿，对真实机器人和缺乏力矩传感的商用协作平台友好。
- **实时性**：DDIM + RTC + OT 条件流重解释，确保接触丰富任务中的低延迟与跨块一致性。
- **实验贴合任务**：刚体、混合接触、可形变三类任务覆盖广，物理指标（力、功、误差）多维度佐证。
- **可视化与可解释性**：阶段化刚度剖面（图 3）直观展示了策略的物理意义。

## 八、不足与局限

- **任务帧依赖**：TP-DAMM 需**预先定义候选参考帧**（起手位、孔位、钩子位置等），缺乏自动发现机制，限制了在高度杂乱场景中的可扩展性。
- **自交状态空间脆弱**：聚类对自相交的轨迹分布鲁棒性差，作者在 Limitations 中明确指出。
- **视觉遮挡失败**：策略在视觉遮挡严重的接触下表现不好（作者承认为未来工作）。
