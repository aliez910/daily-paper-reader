## 摘要
我们提出了 Hydra-0，一种以动作流为条件的通用世界模型，其中机器人动作以像素运动的形式表示。这一共享的视觉界面能够通过跨本体、跨任务、跨环境以及跨视频生成主干学习动作后果，从而实现通用世界建模与控制。我们最优的配置相较于动作条件基线，将机器人运动误差降低了 90.4%，物体运动误差降低了 60.2%，同时支持零样本组合和数据高效适配。在 RoboLab 基准测试中，Hydra-0 在回放成功率与参考成功率之间达到了 r=0.96 的皮尔逊相关性。此外，我们发现了该界面一种涌现的逆向模式：一种世界动作模型，能够根据从人类示教中迁移而来的期望物体流预测兼容的机器人运动。训练好的动作头将所得的潜在特征映射为可执行动作，无需针对特定任务的专家机器人示教数据。综上所述，这些结果展示了动作流作为一种共享控制接口的潜力，它能够连接异构训练数据、开环策略评估和机器人控制。

## Abstract
We introduce Hydra-0, a generalist world model conditioned on action flow, which represents robot actions as pixel motion. This shared visual interface enables generalist world modeling and control by learning action consequences across embodiments, tasks, environments, and video-generation backbones. Our best configuration achieves 90.4% lower robot-motion error and 60.2% lower object-motion error than our action-conditioned baseline, while supporting zero-shot composition and data-efficient adaptation. On the RoboLab benchmark, Hydra-0 achieves a Pearson correlation of r=0.96 between replayed and reference success rates. Finally, we uncover an emergent inverse mode of this interface: a world action model that predicts compatible robot motion from desired object flow transferred from a human demonstration. A trained action head maps the resulting latent features to executable actions without requiring task-specific expert robot demonstrations. Together, these results demonstrate the potential of action flow as a shared control interface connecting heterogeneous training data, open-loop policy evaluation, and robot control.

## 1. 核心问题与研究动机

- **背景**：随着视频生成式世界模型（如 Sora 类模型）在通用场景建模上的兴起，机器人学习社区开始尝试将其拓展到具身控制。然而，将这些"通用世界模型"直接用于机器人策略学习时，面临一个根本性障碍——**动作表示的异构性**。
- **核心问题**：
  - 不同机器人本体（机械臂、移动底盘、人形机器人等）的动作空间在维度、量纲、物理含义上差异巨大；
  - 跨任务、跨环境的训练数据无法以统一形式被同一模型消费；
  - 传统"动作 token"或"低维控制向量"作为条件接口难以泛化到异构数据与多主干视频生成模型。
- **研究目标**：寻找一种**统一的、与本体无关的、可作为视觉信号处理的动作表示**，使世界模型能够学到跨本体的"动作—后果"映射，并支持下游策略生成。

## 2. 方法论

### 2.1 核心思想
- 将**机器人动作表示为像素光流（action flow）**——即从当前帧到下一帧图像中"机器人相关像素"的运动矢量场。
- 该表示本质上是**一张二维图像**（与视频帧同构），可以作为一种**共享的视觉接口**注入到任何视频生成式世界模型中，无需修改其主干架构。

### 2.2 关键技术细节
- **条件接口替换**：在视频生成扩散模型中，将常规的"动作向量条件化"替换为"以 action flow 图像作为额外视觉条件通道"，与世界模型共享视觉 token 空间。
- **统一表征空间**：所有机器人末端或关节运动都被重投影到像素平面，形成稠密光流场；这一步骤天然吸收了本体差异（不同 D-H 参数、关节构型都被光流"消化"）。
- **附加 Action Head**：在潜在特征上额外训练一个 **action head**，将世界模型的潜在表示映射回**可执行的动作向量**（即逆向模式 / inverse mode）。
- **涌现的逆向模式**：从人类示教视频中提取"目标物体光流"作为条件，世界模型预测出与之兼容的机器人光流，再经 action head 解码为可执行动作——**无需任务专属的专家机器人示教**。

### 2.3 算法流程（文字描述）
1. 收集多本体、多任务的机器人轨迹数据；
2. 利用前向运动学或末端跟踪，将每一步动作渲染为像素光流图；
3. 训练视频生成式世界模型，以"当前帧 + 动作光流 → 下一帧"为目标；
4. 并行训练 action head：潜在特征 → 可执行动作；
5. 推理阶段（正向）：给定当前观测 + 预测动作光流 → 预测未来帧；
6. 推理阶段（逆向）：给定当前观测 + 期望物体光流 → 预测机器人光流 → action head → 执行。
