## 摘要
长时序机器人操控要求机器人既能可靠地执行各项子技能，又能在长任务中以连贯的顺序对它们加以组合。大多数分层视觉-语言-动作（VLA）模型仅通过单次前向传播即可做出每项决策，缺乏为困难或关键的决策分配额外计算资源的机制。我们提出了 $τ_0$-VLA——一种分层机器人基础模型，它通过世界模型引导的测试时计算，将高层子任务生成问题建模为可扩展计算量的推理问题。在每个推理步骤中，高层策略利用执行记忆生成子任务，并在必要时对备选方案进行搜索后再确定输出。随后，低层策略在多种机器人本体上执行所生成的子任务。该策略基于 40,115 小时的异构真实世界数据，并结合多模态协同训练进行训练。在域内和分布偏移场景下，增加测试时计算量可显著提升下一子任务的预测精度，且这些性能增益进一步转化为长时序机器人操控任务中更高的闭环成功率。

## Abstract
Long-horizon robot manipulation requires a robot to both execute individual skills reliably and sequence them coherently over extended tasks. Most hierarchical vision-language-action (VLA) models make each such decision with a single forward pass, leaving no mechanism to allocate additional computation to difficult or consequential choices. We introduce $τ_0$-VLA, a hierarchical robot foundation model that formulates high-level subtask generation as a compute-scalable inference problem through world-model-guided test-time computation. At each inference step, the high-level policy uses execution memory to generate a subtask and, when needed, searches over alternatives before committing to its output. A low-level policy then executes the generated subtask across multiple robot embodiments. The policy is trained on 40,115 hours of heterogeneous real-world data with multimodal co-training. Across in-domain and distribution-shifted settings, allocating additional test-time computation substantially improves next-subtask prediction accuracy, and these gains translate into higher closed-loop success on long-horizon robot manipulation tasks.

## 二、方法论

### 1. 整体架构（高层 + 低层双层策略）
- **高层策略 μ**（基于 Qwen3.5-9B）：负责维护执行记忆、决定是否触发测试时搜索，并生成当前子任务。包含四个子模块：
  - **提议模型 P（Proposal）**：根据上下文（任务指令、执行记忆、上一子任务、当前观测）生成直接子任务提议 `z_dir` 并更新记忆 `M_t`；同时输出 token 置信度用于自适应路由。
  - **世界模型 W（World Model）**：基于 Step1X-Edit 初始化，给定头相机图像与候选子任务，预测执行完成后的终止图像 `ô`。
  - **价值模型 V（Value Model）**：以任务指令、候选子任务、预测终止图像为输入，输出 5 档序数质量标签，映射为标量分数（0.05–0.95）。
  - **反思模型 F（Reflective）**：在保留分支汇总 `C_t` 与观测对齐的真实上下文基础上，自回归生成最终子任务 `z*_t`（可不限于候选集）。
- **低层策略 π_θ**（基于 Qwen3.5-2B + MoT 动作专家）：输入多视角观测、本体感知状态、子任务文本命令、控制元数据 `η`，通过条件流匹配输出 H=30 步的统一动作块。

### 2. 自适应路由与测试时搜索
- **路由规则**：仅依据提议模型单次前向中的 token 概率均值与 logit margin 均值判断 `g_t∈{0,1}`，`g_t=0` 走快速通道直接输出 `z*_t`；`g_t=1` 进入搜索。
- **Beam Search（提议–预测–评估循环）**：
  - 维护集合 `Q_{t,d}`，初始为根分支；每层深度 d∈{1,…,D} 对每个保留分支 b 调用 P 采样 N 次，得到 N×B 个候选子任务；
  - 用 W 预测每个候选的终止图像，用 V 打分；
  - 全局按累积分数保留 Top-B 分支，进入下一深度递归；
  - 终止后由 F 在 `C_t`（含分支路径、终止图像、累积分数）上生成最终子任务。
- **关键设计**：分支内记忆为局部且不覆盖持久执行记忆 `M_t`；非根分支以预测图像替代真实观测进行下一轮扩展。

### 3. 可修正执行记忆（Correctable Memory）
- 通过人为扰动现有示范中的记忆（滞后、超前、错误），训练高层策略识别并恢复与真实视觉证据对齐的记忆，无需额外标注。
- 实例家族包括 within-subtask（58%）、transition（15%）、catch-up（10%，落后修复）、rollback（12%，超前回退）、error-think（5%，错误反思）。

### 4. 统一 40 维状态-动作空间
- 涵盖左右末端执行器位姿（Rot6D）、左右夹爪、腰部、平面底盘速度、左右各 8 维关节角；
- 通过**通道掩码 M** 实现跨本体共享：固定基座、双臂、移动全身控制；
- **带掩码的条件流匹配**：在 `τ∈[0,1]` 上对有效通道施加掩码、训练时只监督活跃通道。

### 5. 训练阶段
- **低层**：三阶段训练——(1) Knowledge-Isolated 协同训练（冻结 VLM 梯度）；(2) 端到端协同训练；(3) 任务特定微调。
- **高层**：提议、价值、反思模型从同一机器人预训练 VLM 微调；世界模型单独从 Step1X-Edit 训练；价值与反思模型使用离线 rollout（P+W 交替生成）数据集训练。

## 六、主要结论与发现

- **测试时计算显著提升高层决策质量**：TTC 在 4 个设定上均高于 Plan Once 与 Best-of-N；例如 Book Organization OOD 下 TTC 达 74.0%，Plan Once 仅 50.0%。
- **高层决策增益转化为闭环成功率**：Make Milk Tea 5/10 → 7/10、Book Organization 6/10 → 9/10、Clean Room 5/10 → 7/10。
- **分层系统显著优于直接执行**：四个长视野任务平均 SR 从 27.5%（τ₀-VLA 直接执行）升至 45.0%（Plan Once 分层），Progress 从 80.10% 升至 87.85%。
- **执行记忆对关键里程碑跟踪必不可少**：尤其是 Tomato and Egg Stir Fry 的"加盐"步骤（视觉变化小）和 Clean Room 的房间切换。
- **Compute-Accuracy 呈现饱和趋势**：低算力时增益最大，约 ~2 PFLOPs/sample 后趋于平台。
- **Best-of-N 的增益有限**：仅做单步采样+打分，无多步展开与反思，提升幅度明显小于 TTC。

## 七、优点

- **架构创新清晰**：将"提议-预测-评估-反思"循环形式化为可微扩展的 beam search，且与高层 VLM 输出解耦（提议与反思可分离）。
- **统一动作空间 + 掩码流匹配**：单一低层策略支持 AGIBOT G1 / G2、ARX AC One、Franka 等多种本体，无需为每个本体设计专属头。
- **训练数据规模庞大**：40,115 小时异构真实数据 + 多模态协同训练，避免灾难性遗忘 VLM 能力。
- **执行记忆设计新颖**：通过扰动-恢复训练范式免费获得"自纠正"能力，无需额外标注；五类扰动覆盖真实部署中的常见失效模式。
- **异步双系统服务**：工程层面解决高层慢推理与低层高频控制的时间失配问题。
- **评估协议严谨**：基于 DAG 的 Progress 评分能区分"跳过里程碑"与"完成但低质量"；先决门控逻辑使部分失败不再牵连后续无关步骤。
- **OOD 验证充分**：Book Organization OOD 设置直接考察高层策略对未见初始状态的鲁棒性。
- **失败模式分析细致**：识别出最终接触密集操作（盖杯盖、插吸管）为剩余瓶颈。

- **世界模型仅作用于单步预测**：以头相机 RGB 图像为输入，且预测"执行完成后"的终止状态，难以处理需要中途视觉反馈的细粒度纠错。
- **接触密集操作仍是短板**：盖杯盖、插吸管等接触密集步骤在所有方法上都是失败集中区。
- **应用边界**：所有评估均在受控的家庭/实验室场景，物体初始位姿有限制或受随机范围约束，对真实开放环境的泛化未充分验证。
