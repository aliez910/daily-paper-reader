## 摘要
视觉-语言-动作（VLA）模型在实际部署中常常受到效率-性能权衡、跨具身泛化以及执行平滑性等瓶颈的限制。我们提出了 NebulaVLA，一种异步双频率架构，将高层语义推理与底层动作控制解耦，从而优化计算资源并提升模块化程度。为了弥合异构机器人之间的语义鸿沟，我们引入了 GESTURE-7，一种统一的语言驱动的动作表征。此外，我们的引导动作（Guide Action）算法通过基于掩码的平滑性约束来强制保证运动学连续性。全面的评估表明，NebulaVLA 显著优于同步基线，在 LIBERO-Plus 上取得了 85.5% 的平均成功率，并将动作生成速度提升了约 2.7 倍。这种异步设计为实际机器人应用提供了高效且响应迅速的控制能力。

## Abstract
Real-world deployment of Vision-Language-Action (VLA) models is often bottlenecked by efficiency-performance trade-offs, cross-embodiment generalization, and execution smoothness. We present NebulaVLA, an asynchronous dual-frequency architecture that decouples high-level semantic reasoning from low-level action control, optimizing computational resources and modularity. To bridge semantic gaps across heterogeneous robots, we introduce GESTURE-7, a unified language-grounded action representation. Furthermore, our Guide Action algorithm enforces kinematic continuity via mask-based smoothness constraints. Comprehensive evaluations demonstrate that NebulaVLA significantly outperforms synchronous baselines, achieving an 85.5\% average success rate on LIBERO-Plus and accelerating action generation by \textasciitilde 2.7$\times$. This asynchronous design enables highly efficient and responsive control for practical robotics.

# NebulaVLA 论文总结

## 一、核心问题与研究动机

视觉-语言-动作（VLA）模型正从模块化流水线向端到端学习范式演进（RT-1 → OpenVLA → InternVLA 等），但在实际机器人部署中仍面临三大核心瓶颈：

- **效率-性能权衡**：现有 VLA 多采用单一同步架构，统一的时序分辨率难以同时支撑低频语义推理与高频运动控制，导致计算资源浪费或控制延迟过高。
- **跨具身泛化受限**：连续运动学到离散 token 的映射需庞大词表与海量演示数据，难以在异构机器人（灵巧手、夹爪、机械臂等）之间建立统一语义。
- **执行平滑性差**：异步推理与动作块生成的时序错位会导致关节抖动和块边界不连续，影响实际部署。

NebulaVLA 旨在以"快-慢系统"认知范式（Kahneman）为理论基础，系统性地同时解决上述三大问题。

## 二、方法论

### 2.1 整体架构：异构双频率设计

- **System 2（≈10 Hz）**：高层语义规划器，以 Qwen3-VL 为视觉-语言骨干，接收自然语言指令与稀疏视觉输入，输出抽象动作指导（abstract action guidance）。
- **System 1（≈20 Hz）**：低层反应式控制器，使用 Q-Former 压缩 S2 输出，结合高频视觉（DINOv2）与动作历史，通过扩散 Transformer（DiT）生成具体执行动作。
- 两系统通过显式数据流解耦，支持分布式部署与独立硬件调度。

### 2.2 GESTURE-7：统一动作表征

- 7 维连续末端执行器向量：`[x, y, z, r, p, w, gesture]`
  - 位置 (x, y, z)：量化到整数厘米
  - 姿态 (r, p, w)：量化到整数角度
  - 手势 (gesture)：离散自然语言关键词（如 `grasp`、`push`、`pinch`、`thumb_bent_finger`）
- 同一语义动作在不同具身（灵巧手、夹爪）下共享同一关键词，天然支持跨具身泛化与语言条件强化学习。

### 2.3 Guide Action：基于掩码的平滑性机制

- **核心思想**：借鉴图像外绘（Image Outpainting），将上一动作块中**未执行完**的尾部动作（guide anchors）作为条件，约束下一动作块的扩散去噪过程。
- **公式重定义**：

$$
A_{t-1}^{full} = M \odot A_{t-1}^{prior} + (1 - M) \odot A_{t-1}^{noisy}
$$

  其中 M 为二元掩码：锚点区域（M=1）严格保留已知动作，生成区域（M=0）由模型预测。
- **训练时自适应**：导引点数量 k 在 [0, 3] 区间随机采样，使模型自适应推理延迟。
- **损失函数**：仅在生成区域（1−M）施加 L2 噪声预测损失。

### 2.4 三阶段训练流程

| 阶段 | 优化对象 | 方法 | 关键任务 |
|------|----------|------|----------|
| Stage I | System 2 | SFT | 5 类任务：位姿回归、关键点回归、2D 路标预测、3D GESTURE-7 轨迹预测、CoT 子任务分解 |
| Stage II | System 2 | GRPO 强化学习 | 同 5 类任务 + 4 类奖励（距离/定位/路标/轨迹/格式） |
| Stage III | System 1+2 | 加权 Flow-Matching SFT | 蒸馏 S2 先验，仅在生成区域施加 L2 损失；视觉编码器冻结 |

## 六、主要结论与发现

1. **仿真性能领先**：LIBERO-Plus 平均成功率 85.5%，超越 InternVLA-M1（81.3%）4.2%，大幅领先 GR00T N1.5（59.0%）与 π0.5（58.0%）。
2. **推理效率大幅提升**：异构架构推理延迟 42 ms（vs 同构 115 ms，InternVLA-M1 81 ms），动作生成速度提升约 2.7×。
3. **真实世界成功率高**：Pick-and-Place 92.08%，Feeding 92.5%，均显著高于 InternVLA-M1（77.91% / 72.5%）。
4. **轨迹平滑性显著改善**：Guide Action 使关节 jerk 平均降低 25.6%，最大单关节降幅达 45.1%。
5. **三阶段训练必要**：S2 SFT + S2 RL + S1 SFT 渐进式训练带来 1.7–2.5% 总体 SR 提升，其中 SFT 对 Layout 维度提升最显著（+6.2%）。
6. **设计权衡**：摄像机视角扰动维度性能略有下降，归因于 GESTURE-7 训练隐式建立了固定视觉-空间映射。

## 七、优点与亮点

- **架构创新性强**：首次在 VLA 中显式以"快-慢认知"理论指导双频率解耦，并通过 Q-Former 跨频率信息桥接。
- **模块化与可部署性**：S1/S2 独立部署天然适配边缘计算与分布式系统，工程落地价值高。
- **跨具身表征统一**：GESTURE-7 通过语言关键词天然兼容 RL 与跨平台迁移，量化策略降低学习负担并抑制幻觉。
- **平滑约束内生化**：Guide Action 在生成过程内强制连续性，避免了后处理平滑方法的语义不一致问题。
- **多维度验证充分**：仿真 + 真实世界 + 消融 + 可视化（关节轨迹）+ 平滑度量化（jerk 表）形成完整证据链。
- **效率-性能兼得**：在提升 SR 的同时显著降低延迟，突破传统同步架构的帕累托前沿。

## 八、不足与局限

### 方法层面
- **频率配置静态化**：当前 10 Hz / 20 Hz 为经验设定，缺乏任务自适应的动态调度机制。
- **Guide Action 的响应延迟**：固定锚点策略在快速变化环境中可能引入额外响应滞后。
- **GESTURE-7 视觉-空间耦合假设**：摄像机视角扰动维度性能下降（91.0% < 93.5%），泛化能力受限。
- **量化精度损失**：位置与姿态量化到整数单位，可能影响需要亚厘米/亚度精度的任务。

### 实验层面
- **真实世界任务覆盖不足**：仅 2 类任务（Pick-and-Place、Feeding），双臂机器人在更复杂长时序任务上的表现未被验证。
- **缺乏多平台部署验证**：真实实验仅在 AgiBot A2 单一平台完成，跨具身迁移性证据尚不充分。
- **训练时长与数据规模未披露**：影响结果可复现性。
- **扰动维度局限**：LIBERO-Plus 之外的极端扰动（如光照剧变、动态遮挡）未覆盖。
- **工程挑战未解决**：作者自承多传感器时间戳对齐、分布式时钟同步等工程难题仍待处理。

### 应用限制
- 依赖 Qwen3-VL 等大模型作 S2 骨干，对硬件资源有较高门槛
- 异构频率架构对任务规划与执行频率匹配有隐含假设，不适用于所有任务类型
