## 摘要
端到端模仿学习避免了用于接近与抓取的手工机器人运动规划，但策略仍需决定采摘哪颗果实以及在何处闭合夹爪。遮挡会使策略在采摘过程中丢失所选果实，而正确的闭合点难以仅从像素中推断。本文提出 HarvestPoint-ACT，将这两项决策在感知阶段显式化，并提供给策略网络。一个带有关键点分支的实例分割前端为每个可见果实预测掩膜和采摘点，其中采摘点指定了夹爪闭合的位置。一个调度器根据遮挡程度和行进距离对检测到的候选进行排序，并选择一个目标。每次尝试后，调度器会重新检测和重新排序候选，因为树冠形态可能已发生变化。所选果实被编码为一个八维状态输入动作分块 Transformer，包含绝对采摘点、夹爪到该采摘点的向量、有效标志位以及置信度分数。当所选果实暂时未被检测到时，系统会在机器人基坐标系中保留最近一次的采摘点估计并将其标记为陈旧，若丢失状态持续则中止此次尝试。在树冠模拟装置上，HarvestPoint-ACT 取得了 88% 的成功率，在重度遮挡条件下成功率为 75%。

## Abstract
End-to-end imitation learning avoids hand-made robot motion for approaching and grasping, but the policy must still decide which fruit to pick and where to close the gripper. Occlusion can make the policy lose the selected fruit during harvesting, and the correct closing point is difficult to infer from pixels alone. This paper presents HarvestPoint-ACT, which makes both decisions explicit in perception and provides them to the policy. An instance segmentation front end with a keypoint branch predicts a mask and a harvest point for each visible fruit, where the harvest point specifies the location to close the gripper. A scheduler ranks detected candidates by occlusion and travel distance and selects one target. After each attempt, it redetects and reranks the candidates because the canopy may have changed. The selected fruit is encoded for an action chunking transformer as an eight-dimensional state, containing the absolute harvest point, the vector from the gripper to that point, a validity flag, and a confidence score. When the selected fruit is temporarily undetected, the system retains the last harvest point estimate in the robot base frame and marks it as stale, and aborts the attempt if the loss persists. On a canopy mock-up, HarvestPoint-ACT achieves a success rate of 88%, and of 75% under heavy occlusion.

# HarvestPoint-ACT 论文总结

## 1. 核心问题与研究动机

- **任务背景**：选择性水果采摘是农业自动化中尚未完全解决的问题，主要瓶颈在于**感知—动作耦合**：系统需要在杂乱、可变形且自遮挡的树冠中选定果实并安全接近。
- **传统方法的局限**：模块化流水线（检测→3D 定位→运动规划→视觉伺服）虽可解释，但误差会逐级累积，且难以编码接触引起的枝条形变。
- **端到端模仿学习的盲点**：ACT 等 visuomotor 策略虽可直接从观察映射到动作，但仍面临两大挑战：
  - **目标身份歧义**：外观相似的果实加上遮挡、目标脱离腕相机视野或邻果显著性提高，容易使策略漂移或停滞。
  - **抓取点难以从像素推断**：正确的闭合位置是受果柄、支撑枝与夹爪几何约束的**任务特定可供性（affordance）**，不能简单等价于掩膜质心。
- **论文核心立意**：将"选哪个果实"与"在何处闭合夹爪"这两项决策在感知阶段**显式化**并显式提供给策略网络，以缓解遮挡下的目标丢失与抓取点歧义问题。

## 2. 方法论

### 2.1 整体框架
- 任务被拆分为两层：**任务层**（调度器选目标）与**运动层**（ACT 策略执行接近与抓取）。
- 观测 o_t = (I_t^rgb, x_t, e_t)，其中 e_t 为新增的 8 维采摘点状态；动作 a_τ 为末端相对位移 + 夹爪张开量。
- 策略输出长度为 H=100 的动作块，执行前 k=50 个后重查询，形成 receding-horizon 闭环。

### 2.2 感知与采摘点提取
- 使用 **Mask R-CNN + 关键点分支**，在自标注数据集上微调，得到每帧检测集合 D_t = {(M_i, u_i, c_i)}。
- 关键点为手工标注的**度量采摘点**：果实本体上避开果柄与支撑枝、可被夹爪闭合的点。
- **深度一致性校验**：单像素深度不可靠，因此先与掩膜内中位深度 ẑ_i 比较；若 |D_t(u_i) − ẑ_i| ≤ τ_z 则采用，否则在窗口 W(u_i) ∩ M_i 内按
  u_i⋆ = arg max { λ_d·EDT(u; M_i) − λ_z·|D_t(u) − ẑ_i| }
  搜索更鲁棒的像素；仍无合格像素则丢弃该候选。
- 通过相机内参 K 与手眼标定将 u_i⋆ 反投影并变换到机器人基坐标系 B，得到 P_i^B。

### 2.3 任务层调度
- **遮挡指数** ϕ_i = |∂M_i ∩ N_r(Ω_i)| / |∂M_i|，其中 Ω_i 包含其他掩膜像素及"近处"前景像素，用于衡量果实被遮挡程度。
- **优先级评分**：J(i) = w_o(1 − _i) − w_d·d̂_i，按"少遮挡优先 + 距离近优先"排序。
- **每次采摘后重新检测与重排**：因摘除会改变树冠几何，预先规划采摘序列易失效。

### 2.4 采摘点条件化（核心创新之一）
- 8 维状态 e_t：
  - **相对向量** P̂_t − p_t（夹爪→采摘点，3D）
  - **绝对位置** P̂_t ∈ ℝ³
  - **有效位** v_t ∈ {0,1}
  - **置信度** ĉ_t ∈ [0,1]
- 该状态作为新增 encoder token 与末端状态 x_t 并列送入 ACT，其余架构不变。
- 实验表明：将掩膜作为额外图像通道输入并不能进一步提升性能，目标身份已由 e_t 表达。

### 2.5 目标持久化与优雅降级
- **Step 1 匹配更新**：通过掩膜 IoU 与三维距离阈值（τ_iou、τ_p）匹配，匹配上则按 P̂_t = (1−α)P̂_{t−1} + α·P_j^B 融合，置 v_t=1。
- **Step 2 保持估计**：若未匹配上，不进行图像搜索（避免误跟邻果），保留 P̂_t，置 v_t=0，按 ĉ_t ← γ·ĉ_{t−1} 衰减置信度。
- **Step 3 中止与重调度**：连续丢失超过 T_max 个周期则回撤并重新检测调度；失败的尝试直接丢弃。

### 2.6 算法流程（Algorithm 1）
- 外层 while 循环不断检测并按 J(i) 选取目标 i⋆；
- 内层 while 循环执行感知→匹配/保持→组装观测→策略查询→执行前 50 个动作；
- 抓取成功后回退并释放果实，否则进入下一轮外层循环。

## 6. 主要结论与发现

- 在人工树冠上 **HarvestPoint-ACT 取得 88% 的总体成功率、92% 的接近成功率**，平均循环时间约 21.5 s。
- **基线普遍在夹爪未触果即闭合**而失败，原因是缺乏"距离线索"：基线只看到腕部 RGB 与自身位姿，无法得到果实到夹爪的距离，且遮挡下图像本身也会变得模糊。
- **遮挡鲁棒性**：ϕ_i ∈ [0, 0.25) 时 90% 成功，ϕ_i ∈ [0.75, 1] 时仍保持 75%（原文表 II 数据：90/80/80/75–76%）；随着遮挡加深，平均耗时从约 12 s 增至约 29 s，但策略仍能完成采摘。
- 持久化机制有效：检测暂时丢失时，旧采摘点在基坐标系下保持有效，不会因目标消失而中断任务。
- 主要失败模式为**接触相关**：拖拽叶片导致臂体停滞，或接触提前将果实碰落。

## 7. 优点 / 亮点

- **将感知输出显式化为策略输入**：采摘点同时承载身份（是哪颗果）与几何（在哪闭合）信息，把"度量抓取点"作为一个 token 注入 ACT，工程简洁且改动最小。
- **采摘点语义化定义**：放弃掩膜质心，使用避开果柄与支撑枝的手工标注点，并通过 EDT + 深度一致性修正，缓解边界像素与遮挡边缘问题。
- **保守的目标匹配策略**：遮挡下不进行图像级搜索，避免在外观相似果实之间误跟，体现"宁缺毋滥"。
- **任务层与运动层解耦**：调度器独立于策略，可替换为其它规划方法，便于扩展。
- **公平对比**：所有方法共享同一示教集、同一查询频率，对照充分。
- **算法伪代码与状态描述清晰**：8 维状态设计、Algorithm 1 三步持久化机制都具备较好的可复现性。

## 8. 不足与局限

- **场景单一**：仅在实验室人工柑橘树冠验证，缺乏真实果园、多作物、多光照、多季节数据，泛化能力未知。
- **果实假设过强**：
  - 假设果实"在接近过程中几乎不动"，无法处理风吹或接触诱发的运动；
  - 不建模接触（拖叶、缠绕、提前脱落）；
  - 仅适用于直接抓取果体的作物，不适用于需要切割果柄的作物（需不同末端与采摘点定义）。
- **硬件与视野局限**：单腕部相机 + 固定基座，无法处理单视点不可见的果实；尚未集成移动底盘。

- **评估统计不充分**：4 布局 × 25 次的实验规模偏小，未给出置信区间或显著性检验，对个别基线（如 SmolVLA）成功率为 0 的差异缺少消融溯源。
