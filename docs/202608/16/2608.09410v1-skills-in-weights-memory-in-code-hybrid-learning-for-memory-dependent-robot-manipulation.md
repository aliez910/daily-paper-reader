## 摘要
现代视觉-语言-动作（VLA）策略已习得广泛的操控技能，但其通常仅依据当前观测或短时固定长度的历史生成每个动作片段。然而，真实场景中的操控任务往往是非马尔可夫的，机器人需要保留并推理长时程交互历史中的任务相关信息，以决定下一步动作。为应对这一挑战，我们提出了HyMeS——一种混合学习框架，利用编码智能体的推理与记忆管理能力来引导一个马尔可夫型VLA完成记忆依赖型操控任务。具体而言，HyMeS通过基于梯度的模仿学习掌握底层运动技能，同时编码智能体通过启发式学习——即依据回放反馈迭代更新可执行的启发式系统——获取高层记忆管理策略。此外，我们借助多模态阶段完成验证来衔接引导与执行环节，利用本体感知信号和多帧VLM判断更新记忆。与端到端的记忆增强型VLA相比，HyMeS仅需对可复用的运动技能提供示教，而无需为每种历史依赖的任务配置单独示教，从而实现数据高效的组合泛化。在RoboMemArena基准上，HyMeS相较pi0.5将平均累积成功率从52.5%提升至66.2%，将平均任务成功率从41.3%提升至60.1%；同时，在累积成功率上以4.5个百分点、在任务成功率上以14.5个百分点优于PrediMem。

## Abstract
Modern vision-language-action (VLA) policies have acquired broad manipulation skills, but typically generate each action chunk from the current observation or a short fixed-length history. However, real-world manipulation is often non-Markovian, requiring robots to retain and reason over task-relevant information from long-horizon interaction histories to determine the next action. To address this challenge, we propose HyMeS, a hybrid learning framework that leverages the reasoning and memory-management capabilities of coding agents to steer a Markovian VLA for memory-dependent manipulation. Specifically, HyMeS learns low-level motor skills through gradient-based imitation learning, while a coding agent acquires high-level memory-management strategies through heuristic learning by iteratively updating an executable heuristic system from rollout feedback. Furthermore, we close the loop between steering and execution through multimodal stage-completion verification, which updates memory using proprioceptive signals and multi-frame VLM judgments. Compared with end-to-end memory-augmented VLAs, HyMeS requires demonstrations only for reusable motor skills rather than for every history-dependent task configuration, enabling data-efficient compositional generalization. On RoboMemArena, HyMeS improves mean cumulative success from 52.5% to 66.2% and mean task success from 41.3% to 60.1% over pi0.5, while outperforming PrediMem by 4.5 points in cumulative success and 14.5 points in task success.

# HyMeS 论文总结：权重承载技能，代码承载记忆

## 1. 核心问题与研究动机

- **背景**：现代视觉-语言-动作（VLA）模型（如 π0.5、π0.6）已具备广泛的操作技能，但本质上仍是**马尔可夫型**的——仅依据当前观测或短时固定长度上下文生成动作片段。
- **核心痛点**：真实操控任务常呈**非马尔可夫性**，需要机器人保留并推理长程交互历史中的任务相关信息。例如：
  - 按压按钮的次数由任务开始时卡片上写下的数字决定（视觉线索很快消失）；
  - "将奶油放入微波炉后将爆米花放到奶油原先的位置"这类需要追溯源位置的任务。
- **现有方案的不足**：已有的"记忆增强型 VLA"（MemoryVLA、PrediMem、EventVLA、Chronos 等）通过扩展上下文窗口、增加记忆 token 或循环记忆模块，并以**端到端**方式从演示数据中学习历史条件策略。这导致：
  - 演示成本随任务状态组合空间指数增长；
  - 记忆逻辑与运动技能耦合纠缠，难以解释与编辑；
  - 易出现遗忘问题。
- **本文立意**：将"运动技能学习"与"记忆策略学习"**解耦**——前者放在权重空间，后者放在代码空间，从而实现**数据高效、可解释、可组合泛化**的记忆依赖操控。

## 2. 方法论

### 2.1 核心思想

HyMeS（**Hy**brid learning with coding agent for **Me**mory-dependent **S**teering）将系统拆为两部分：
- **权重空间**（Weight Space）：一个冻结的、经过任务微调的流匹配 VLA（基于 π0.5），负责"如何动"；
- **代码空间**（Code Space）：一个由编码代理维护的可执行启发式程序 $P = (\mathcal{C}, \mathcal{V}, \mathcal{U})$，负责"何时动、动哪个目标"，即记忆管理。

VLA 在学习完可复用运动技能后即固定，记忆逻辑的获取完全**不更新网络权重**，也无需覆盖所有任务状态组合的专家示教。

### 2.2 关键技术细节

**（1）问题形式化**

- 控制步 $t$ 的观测为 $o_t$（RGB + 本体感知），交互历史为 $h_t = (o_1, a_1, \ldots, o_t)$；
- 任务状态 $z_t = \phi(h_t)$（如按钮剩余次数、源位置绑定）**不可从 $o_t$ 单独恢复**；
- 专家策略满足 $\pi^*(a_t \mid h_t, \ell) = \pi^*(a_t \mid o_t, z_t, \ell)$；马尔可夫策略 $\pi_\theta(a_t \mid o_t, \ell)$ 因 $o_t$ 存在别名（aliased）而无法在多种合法动作模式间消歧。

**（2）权重空间的运动技能学习**

- 使用流匹配目标（flow-matching）：
  $$a^\tau = (1-\tau)\epsilon + \tau a,\quad \theta^* = \arg\min_\theta \mathbb{E}\big[\|v_\theta(a^\tau, \tau \mid o, \ell) - (a-\epsilon)\|_2^2\big]$$
- $\theta^*$ 学到后即**冻结**，记忆获取阶段不再更新。

**（3）代码空间的记忆策略学习**

- 符号记忆状态：$s_t = (\text{plan}, \rho_t, B_t, N_t, F_t)$，其中 $\rho_t$ 为当前阶段，其余维护任务绑定、重复事件计数和持久交互状态；
- 编码代理（基于 Opus 4.8）从候选程序 $P^{(n)}$ 出发，结合回放轨迹 $\xi_n$ 与基准给出的阶段判定 $b_n$，通过 $\text{Edit}(P^{(n)}, \xi_n, b_n)$ 迭代修订约束奖励、事件验证规则与转移规则；
- 学习过程**不使用梯度、不使用专家动作标签**，只从执行反馈中修订软件；
- 评估时 $P^\star$ 被冻结。

**（4）闭环控制流程**

$$
R_t = \mathcal{C}(s_t, o_t, \ell), \quad
a_t = \text{Steer}(\pi_{\theta^*}, R_t, o_t, \ell), \quad
e_t = \mathcal{V}(W_t; s_t), \quad
s_{t+1} = \mathcal{U}(s_t, e_t, o_t)
$$

其中 $W_t$ 是滑动验证窗口，$e_t \in \{0,1\}$ 为阶段完成事件。

**（5）记忆条件化的动作引导**

- 阶段 $\rho_t$ 与记忆 $s_t$ 选择可微约束 $R_{\rho_t}(a, o_t; s_t)$，例如抓取阶段实例化为末端到目标关键点的负距离平方：
  $$R_{\text{reach}} = -\|ee(a) - \Gamma(\text{target}(s_t), o_t)\|_2^2$$
- 将其梯度注入流匹配速度场：
  $$\hat v = v_{\theta^*}(a^\tau, \tau \mid o_t, \ell) + \lambda_t \nabla_{a^\tau} R_{\rho_t}(a^\tau, o_t; s_t)$$
- 引导强度 $\lambda_t$ 随约束残差衰减，使 VLA 在接近接触区域时让位给底层运动策略。

**（6）多模态阶段完成验证（PACE）**

- **本体感知证据**：检测动作依赖的运动模式并通过符号锁存器保留持久事件；
- **视觉证据**：Qwen3-VL-8B 基于当前阶段与最近 5 帧 RGB 判断；
- 合并规则：$d_r = e_r^{\text{prop}} \lor e_r^{\text{vlm}}$；
- 阶段切换采用 **k-of-w 投票**（文中 $w=5, k=3$）：仅当最近 $w$ 个查询中至少 $k$ 个判定为 PASS 时才推进阶段，避免偶发错误。

## 3. 实验设计

### 3.1 基准与场景

- **仿真**：RoboMemArena 的修正版 12 任务协议，共 **160 个回合**，覆盖四类记忆能力：
  - **Transferring**（位置/对象转移）：3 个任务 × 10 回合；
  - **Counting**（计数）：3 个任务 × 10 回合；
  - **Sequence**（顺序执行）：2 个任务 × 20 回合；
  - **Occlusion**（遮挡）：4 个任务 × 15 回合。
- **真实机器人**：SO-101 平台上的 3 个记忆依赖任务，共 **35 次试验**（观察-拾取 10、数字引导按按钮 15、放回积木 10）。

### 3.2 评估指标

- **CSR（Cumulative Success Rate）**：阶段级平均子目标完成率；
- **TSR（Task Success Rate）**：全任务成功率。

### 3.3 对比方法

- **π0.5**（反应式基线）：与 HyMeS 共享同一微调后的策略权重；
- **PrediMem**（RoboMemArena 原生记忆增强基线）：VLM 规划器 + 最近帧/关键帧记忆；文中在其上重新评估修正后的 12 任务协议（而非原 26 任务结果）。

### 3.4 协议筛选说明

- 文中明确指出"任务筛选仅依赖协议检查与 π0.5 行为，不参考 HyMeS 自身结果"，并剔除了可凭观测捷径或纯运动失败解决的任务，降低了"自选基准"的风险。

- **消融实验**（6 任务子集，覆盖全部四类）：

## 6. 主要结论与发现

- **整体性能**：在 RoboMemArena 上，HyMeS 较 π0.5 将 CSR 从 52.5% 提升至 **66.2%**、TSR 从 41.3% 提升至 **60.1%**；较 PrediMem 分别高出 **4.5** 与 **14.5** 个百分点；
- **类别细分**：
  - Counting（计数）TSR 提升最大（+30.0 pp）；
  - Transferring（转移）+26.6 pp；
  - Sequence（顺序）+22.5 pp；
  - Occlusion（遮挡）最困难，但 TSR 仍 +7.0 pp；
- **真实机器人**：SO-101 上的 TSR 从 25.7% 跃升至 **57.1%**（三任务合计 35 次试验），证明可执行记忆在硬件上同样有效；
- **消融发现**：
  - 用 $P^\star$ 替代一击即中的 $P^{(0)}$，CSR/TSR 分别提升 **8.5 / 18.4** 个点——回放经验对记忆管理启发式是关键反馈信号；
  - 仅视觉 PACE：CSR/TSR 下降 16.0 / 21.7；
  - 仅本体感知 PACE：下降 8.8 / 8.4；两者互补才稳定；
- **设计收益**：演示预算只与"可复用运动技能数量"挂钩，而与"历史依赖任务配置数"无关——同一微调检查点可用于不同的目标颜色、所需次数等。

## 7. 优点与亮点

- **思路新颖**：将记忆从"端到端学习的神经模块"转为"可执行代码空间的可编辑对象"，巧妙绕开了组合爆炸、遗忘与可解释性差三大痛点；
- **解耦设计清晰**：权重空间管"动作质量"，代码空间管"动作选择"，职责分明，便于回溯失败原因（运动执行 vs. 阶段验证 vs. 记忆更新）；
- **双向闭环**：通过 PACE 把执行反馈读回记忆更新，再通过引导把记忆写入动作生成——是"推-拉"式耦合，而非单向 steering；
- **引导强度自适应**：$\lambda_t$ 随约束残差衰减，使记忆负责"宏观选择"、VLA 负责"接触区精细执行"，分工合理；
- **实证充分**：仿真 + 真机双线验证，并提供失败模式的逐项归因（图 4），体现严谨的诊断思路；
- **可组合泛化**：同一 $\theta^\star$ 下通过修改 $P^\star$ 即可应对新的目标/计数配置，演示成本不爆炸。

## 8. 不足与局限

- **历史表征受限**：方法依赖"紧凑符号状态"可表达的任务，对开放性、模糊或多模态长程历史的支持有限；
- **错误来源未根除**：失败分析显示，即便记忆与约束正确，仍受限于底层运动精度（如瞄准偏差）与阶段验证可靠性（如按压深度不足、抖动引起的多按）；
- **延迟与成本**：周期性 VLM 查询与编码代理调用为每回合增加**推理时间与算力开销**，文中未给出具体数字；
- **真机规模较小**：SO-101 仅 35 次试验、3 个任务，统计显著性与跨平台迁移能力仍待扩大；
- **PrediMem 比较口径**：尽管在修正后的 12 任务上重新评估，但 PrediMem 的设计目标是 26 任务且其原回放可能带有提示词工程调优，比较未必完全对等；
- **任务筛选透明度**：剔除"可凭观测捷径解决"或"被运动失败主导"的任务虽合理，但具体筛选阈值与每任务的可解性边界并未细化披露，可能引入一定协议偏差；
- **未来方向**：作者亦提及计划扩展到分层、多模态记忆以应对更长程与更开放的指令。
