## 摘要
通用机器人策略旨在将多模态观测与语言任务指令映射到跨多种任务的动作。然而，现有方法通常将未来表示为固定的、较短的视频-动作片段。这种短时未来捕捉的是用于动作执行的局部场景演化，但并未显式地刻画阶段级未来——即任务应如何从当前阶段推进至下一阶段。因此，我们将机器人操作中的两种互补未来加以区分：用于刻画局部场景演化的短时物理未来，以及用于表示任务进度的阶段级语义未来。我们提出了 JEPA-WAM，通过阶段级联合嵌入预测架构（Stage-JEPA）来增强基于 Motus 的世界-动作模型（WAM）。给定当前观测与任务指令，Stage-JEPA 利用冻结的 V-JEPA2 编码器提取当前状态表示，并预测下一推断阶段的潜在目标。在干净与随机化环境下的 50 项 RoboTwin 2.0 任务中，JEPA-WAM 取得了 90.25% 的总体成功率，并将成功回合中的平均执行步数相对于最强基线降低了 5.97%。

## Abstract
Generalist robot policies aim to map multimodal observations and linguistic task instructions to actions across diverse tasks. However, existing methods typically represent the future as a fixed, short video-action chunk. This short-term future captures local scene evolution for action execution, but it does not explicitly describe the stage-level future that specifies how a task should progress from its current stage to the next. We therefore distinguish two complementary futures for robot manipulation: a short-term physical future to capture local scene evolution and a stage-level semantic future to represent task progress. We introduce JEPA-WAM, which augments a Motus-based World Action Model (WAM) with Stage-JEPA, a goal-conditioned Joint-Embedding Predictive Architecture (JEPA) predictor. Given the current observation and task instruction, Stage-JEPA uses a frozen V-JEPA2 encoder to extract the current-state representation and predicts the latent target of the next inferred stage. Across 50 RoboTwin 2.0 tasks in clean and randomized environments, JEPA-WAM achieves 90.25% overall success and reduces the mean number of execution steps in successful rollouts by 5.97% relative to the strongest baseline.

# JEPA-WAM 论文总结

## 1. 核心问题与研究动机

- **现有策略的局限**：通用机器人策略（如 VLA、WAM）通常将未来建模为固定的、较短的视频-动作片段（video-action chunk），仅能捕捉用于动作执行的**局部场景演化**，但无法显式刻画**任务应如何从当前阶段推进到下一阶段**。
- **两种未来的解耦**：论文明确区分两种互补的未来：
  - **短时物理未来（short-term physical future）**：刻画局部视频-动作演化；
  - **阶段级语义未来（stage-level semantic future）**：表示任务进度，如对象状态、空间对齐、人机交互关系的变化。
- **核心问题**：如何在生成局部动作之前，先预测任务下一阶段应当达到的语义目标？直接预测远端目标图像会被像素级细节干扰，与任务完成度不对齐。
- **关键观察**：JEPA（联合嵌入预测架构）天然适合建模阶段级未来——它预测的是潜在表征而非像素，对低层外观不敏感，同时保留任务相关的语义与物理结构。

## 2. 方法论

### 2.1 整体架构

JEPA-WAM 在基于 Motus 的世界-动作模型（WAM）上**增加一个 Stage-JEPA 分支**，形成两阶段串行训练：

- **Stage I**：训练一个目标条件（goal-conditioned）JEPA 预测器，从当前观测与任务指令推断下一阶段的潜在目标；
- **Stage II**：冻结 JEPA 预测器，训练 WAM，使其以预测的阶段潜变量为条件，生成短时视觉未来与动作块。

### 2.2 关键技术细节

- **阶段对自动构建（Stage-pair construction）**：
  - 每 8 帧采样候选中心，最多 32 个；
  - 用冻结的 V-JEPA2（facebook/vjepa2-vitl-fpc64-256）编码 64 帧片段；
  - 计算邻域候选位置之间的表征距离（含 clip-level 与 token-level 两种），对序列做 min-max 归一化并取较大者作为变化分数；
  - 通过贪心 NMS（半径 r=3）选出至多 K=5 个关键帧，结合首末帧形成阶段边界；
  - 每个阶段区间内每个当前帧 t 与下一边界 b_{i+1} 配对，得到稠密训练对 (t, b_{i+1})。

- **目标条件阶段预测**：
  - 冻结 V-JEPA2 编码器 E，分别编码当前片段 S_t 与目标片段 S^{target}_t，得到 z_t 与 z^{target}_t；
  - 可训练预测器由 V-JEPA2 的预测器初始化，结合任务指令 cross-attention 适配器；
  - 训练目标为余弦对齐损失 L_stage = 1 - (ẑ^{target}_i)^⊤ z^{target}_i，仅优化预测器与指令适配器；
  - V-JEPA2 输入 64 帧 → 8192 个 token，从中均匀采样 512 个 context token 与 256 个 target token。

- **门控条件接口（Gated interface）**：
  - 将 Stage-JEPA 输出经 mean-pool 与 MLP P_ψ 映射到 Wan 视频 token 维度；
  - 通过一个**全局共享的有界标量门** α = 0.2·σ(β) 进行加性注入：Ẋ^v_t = X^v_t + α·h_t；
  - 门 α 在所有样本、层、token、通道间共享，初值为 0.02；
  - 训练目标加入两个正则项：λ_g·α² 鼓励门值小，λ_ρ·(ρ-ρ₀)² 约束注入比例 ρ = ‖αh_t‖/‖X^v_t‖ 接近 ρ₀=0.08。

- **WAM 骨干**：基于 Motus（Mixture-of-Transformers），包含视频生成专家（Wan2.2 初始化）、动作专家、视觉-语言理解专家（冻结 Qwen3-VL），通过 Tri-modal Joint Attention 在每层交互。Wan2.2 VAE 编码视频潜变量；视频与动作流分别加噪后联合去噪。

### 2.3 闭环推理

- 维护一个 64 帧因果观测缓冲（不足时用最早帧重复填充，无未来帧）；
- 每步先由冻结 Stage-JEPA 预测阶段潜变量，再由 WAM 预测有限时域视觉未来与动作块；
- 执行动作块、扩展缓冲、循环查询。

## 3. 实验设计

### 3.1 数据集与场景

- **主实验**：RoboTwin 2.0（双手机器人操作 benchmark），**50 个任务**，每个任务在 **clean 与 randomized 两种配置**下评估；
- **评估量级**：每个任务-配置组合运行 100 个闭环回合，每配置 5000 回合，每 checkpoint 共 **10000 回合**，禁用 early stopping；
- **真实机器人**：LIFT2（ARX R5）双手机器人平台，2 个任务（Cube_Grasp、Power_Strip），每个任务 20 次评估，使用任务进度评分（0-100）；
- **任务分类**：50 个任务按语义分为 7 类：获取与提升、交接、目标放置、容器装箱、排列与堆叠、铰接/设备交互、工具使用与动态操作。

### 3.2 对比方法

- **GO-1**：基于视觉-语言-潜动作的 AgiBot 基础模型；
- **π0.5**：直接由视觉观测与语言指令预测动作块的通用 VLA；
- **X-VLA**：通过大规模跨任务/跨具身预训练强化 VLA 控制；
- **Motus**：统一语言条件理解、未来视频与动作预测的 WAM（即论文方法的骨干基线）；
- **真实机器人**：仅与 π0.5 对比；
- 基线数据来源于 Motus（Bi et al. 2025）已发表结果，JEPA-WAM 与 Motus 使用相同闭环协议。

## 4. 资源与算力

- **硬件**：8 块 NVIDIA A800 80GB GPU；
- **有效批量大小**：两阶段均为 256；
- **Stage I**：1000 步优化，FP16 编码 + FP32 学习模块，lr=1e-5，weight decay=0.01，100 warmup；
- **Stage II**：BF16 训练 4 个完整 epoch，lr=1e-6，weight decay=0.01，200 warmup，per-GPU batch=4，累积 8 步；

## 6. 主要结论与发现

- **整体性能**：JEPA-WAM 在 50 个 RoboTwin 任务上 clean 设置 91.42%、randomized 设置 89.08%，总体 **90.25%**，相对最强基线 Motus 在干净环境下 7 个语义类别中胜出 5 个，随机化下胜出 6 个；
- **任务相关收益**：在依赖显式阶段进度变化的任务（交接、目标放置、容器装箱、排列堆叠、工具使用）上提升最显著；获取提升类（依赖抓取几何与接触稳定性）收益较小；铰接/设备交互因需精确时序接触，间接条件信号不足；
- **执行效率**：所有回合平均长度从 156.28 降至 132.80 步（-15.02%），仅成功回合从 79.57 降至 74.82 步（**-5.97%**）；
- **消融结论**：
  - 移除整个 JEPA 分支退化最大（91.42→87.80 clean）；
  - 仅在当前帧表征中使用 Stage-JEPA（不注入视频 token）也明显下降；
  - 不做 Stage-I 训练（仅用 V-JEPA2 预训练预测器初始化）仍较强，但略低于完整训练；
  - 移除门控正则项影响较小，说明有界门本身已提供稳定约束；
- **阶段监督特性**：平均阶段长度 44.74 帧（中位 34 帧），81.72% 间隔短于 V-JEPA2 的 64 帧窗口，约 84-87% 的 current-target 切片对共享源帧——表明 Stage-I 学习的是**时序上下文下的下一阶段表征**，而非严格单帧外推。

## 7. 优点

- **问题解耦清晰**：首次显式区分"短时物理未来"与"阶段级语义未来"，为多阶段操作任务提供了新的建模范式；
- **避免像素级重建的副作用**：用 JEPA 在表征空间预测阶段目标，比直接预测远端图像更鲁棒，对低层外观变化不敏感；
- **阶段边界自动构建**：无需人工阶段标注，利用 V-JEPA2 表征变化 + NMS 自动发现关键帧；
- **可插拔的接口设计**：门控加性注入 + 全局标量门 α 跨层/样本共享，正则化稳定，理论上可推广到其他具备视觉条件流的 WAM；
- **两阶段解耦训练**：先对齐阶段潜变量、再训练 WAM 局部细节，避免细节损失破坏语义目标；
- **评估规模大**：50 任务 × 2 配置 × 100 回合的仿真评估 + 真实机器人双任务验证；
- **代码/数据诊断透明**：附录给出阶段长度、切片重叠、训练配对距离等统计，有助于复现与审视。

## 8. 不足与局限

- **真实机器人评估不足**：仅 2 个任务、各 20 次 roll-out，统计力度弱，未充分验证 sim-to-real 与跨任务泛化；
- **缺乏跨数据集泛化**：未在 LIBERO、RLBench、真实多场景数据等独立 benchmark 上验证；
- **阶段边界启发式依赖**：每 8 帧采样、NMS 半径 r=3、最多 K=5 关键帧等为手工设定，可能在动作节奏变化大的任务上失效；
- **切片重叠问题**：约 84-87% 的训练对 current-target 切片共享源帧，意味着 Stage-I 学习的是"包含当前信息的下一阶段表征"，与"从当前推断未来"在概念上有偏差；
- **推理延迟问题**：论文自身指出 WAM 推理延迟制约了高频闭环控制，JEPA 额外引入一次前向传播，加剧延迟；
- **应用限制**：当前在 LIFT2 等结构化环境上验证，对杂乱、柔性物体、非结构化环境未充分测试；
