## 摘要
移动操作是具身智能的一项关键能力，使机器人能够在开放世界环境中完成复杂的多阶段任务。然而，移动操作对视觉-语言-动作（VLA）策略提出了两个关键挑战：在数据层面，高质量全身示教数据的高效采集要求协调控制移动底座和机械臂；在模型层面，现有VLA模型主要依赖局部相机观测，其有限的视场范围阻碍了全局空间理解。为应对这些挑战，我们开发了一套全身遥操作系统和一种全景感知VLA策略。该系统通过单一VR界面对轮式双臂机器人进行协调控制，并支持采集包含5.5小时多模态示教的真实世界移动操作数据集。基于该数据集，我们提出了PanoVLA——一种面向移动双臂操作的全景感知视觉-语言-动作策略。PanoVLA基于Transformer混合架构构建，通过专用的全景编码与融合模块引入全局空间上下文，使全景观测、语言指令和机器人状态能够有效融合以生成动作。在四项真实世界移动操作任务上的评估表明，PanoVLA达到了91.3%的平均阶段完成率和73.4%的端到端成功率，大幅优于局部视角基线方法。上述结果表明，融合全景空间上下文能够提升移动机器人的空间理解能力和闭环操作性能。

## Abstract
Mobile manipulation is a key capability for embodied intelligence, enabling robots to accomplish complex multi-stage tasks in open-world environments. However, mobile manipulation poses two key challenges for vision-language-action (VLA) policies: At the data level, the efficient collection of high-quality whole-body demonstrations demands the coordinated control of both the mobile base and the robotic arms; at the model level, existing VLA models predominantly rely on local camera observations, whose limited field of view hinders global spatial understanding. To address these challenges, we develop a whole-body teleoperation system and a panoramic-aware VLA policy. The system enables coordinated control of a wheeled bimanual robot through a single VR interface and supports the acquisition of a real-world mobile manipulation dataset comprising 5.5 hours of multimodal demonstrations. Building upon this dataset, we propose PanoVLA, a panorama-aware vision-language-action policy for mobile bimanual manipulation. Built upon a Mixture-of-Transformers architecture, PanoVLA introduces global spatial context through dedicated panorama encoding and fusion modules, enabling effective integration of panoramic observations with language instructions and robot states for action generation. Evaluation on four real-world mobile manipulation tasks demonstrates that PanoVLA achieves an average stage completion rate of 91.3\% and an end-to-end success rate of 73.4\%, substantially outperforming local-view baselines. These results demonstrate that incorporating panoramic spatial context improves spatial understanding and closed-loop manipulation performance in mobile robots.

## 2. 方法论

### 2.1 全身遥操作系统

- **硬件配置**：单一 VR 头显采集 6-DoF 头部姿态 + 双手持手柄（手部姿态 + 抓取指令）+ 腰部与双脚踝佩戴的三个追踪器，重建为 **SMPL 人体模型**。
- **机器人形态**：RANGER MINI 3 自由度移动底盘 + 双臂 6-DoF Agilex PIPER + 平行夹爪 + 顶置 360° 全景相机（Insta X5）+ 1 前视 RGB + 2 腕部 RGB。
- **运动重定向（GMR-based）**：将底盘建模为 **3-DoF 平面虚拟浮动基座**，并与双臂关节配置共同参与同一优化目标：

$$
q^* = \arg\min_q \left( \lambda_{pos} L_{pos} + \lambda_{rot} L_{rot} + \lambda_{base} L_{base} + \lambda_{reg} L_{reg} \right)
$$

其中 $L_{pos}/L_{rot}$ 负责手-夹爪位姿对齐，$L_{base}$ 将底盘平面运动耦合到操作员的骨盆位移与朝向，$L_{reg}$ 抑制关节极限与过度配置变化。
- **底盘模式切换**：根据旋转/平移误差代价，在 **spin / ackermann / diagonal-translation** 三种底盘模式间动态切换，使虚拟 3-DoF 指令在真实底盘上可执行。

### 2.2 PanoVLA 模型架构

采用 **三专家 Mixture-of-Transformers（MoT）** 架构，基础为 π0.5 双专家结构，在 VLM 与 Action 专家之间插入 **Panorama Expert**。

- **VLM 专家**：以 Gemma-2B 为语言骨干，SigLIP 编码局部前视/腕部图像，结合语言指令与本体感知状态，生成 VLM KV-cache $C_{vlm}$。
- **全景编码器（Panorama Encoder）**：
  1. 双鱼眼图像 → 球面重投影 → ERP（Equirectangular Projection）图像；
  2. 用 MTPano 提取语义与深度双分支密集特征，沿通道拼接；
  3. 自适应池化 + 轻量 MLP 适配器压缩为固定数量的全景 token $Z_{pano}$。
- **全景专家（Panorama Expert）**：通过联合自注意力将全景 token 与 VLM cache 融合，生成 panoramic cache $C_{pano}$。
- **动作专家**：基于拼接 cache $C_t = [C_{vlm}; C_{pano}]$，使用 **条件流匹配（CFM）** 预测 32 步动作块，损失为：

$$
L = \mathbb{E}_{p(a|o_t,l), q(x_\tau|a)} \left\| v^\theta_{act}(x_\tau, \tau | C_t) - u(x_\tau | a) \right\|_2^2
$$

整个流程通过 **block-wise causal mask** 控制信息流向，KV-cache 作为专家间的融合接口。

## 3. 实验设计

### 3.1 数据集

自建 **PanoVLA 数据集**（非公开下载），专门面向移动操作：

| 维度 | 内容 |
|---|---|
| 总时长 | 约 5.5 小时 |
| 总轨迹数 | 800 条成功示教（4 任务 × 200 条） |
| 单条长度 | 约 20–30 秒，25 Hz，约 500K 同步帧 |
| 模态 | 前视 + 腕部 RGB、顶置 360° ERP、本体感知（17 维）、全身动作（17 维：14 维双臂+夹爪 + 3 维底盘 $v_x, v_y, \omega$） |

**4 个任务**（Table I）：
- **Move Pen**：将笔放入笔筒，笔筒放置于前/左/右；
- **Move Block**：将积木转移至前区，目标位于左/右/两侧；
- **Open Curtain**：分别打开左右两侧窗帘（双侧顺序交互）；
- **Wipe Table**：擦拭桌面污渍并归还抹布（长桌 + 多阶段状态跟踪）。

### 3.2 评测基准与对比方法

- **评测指标**：每任务 15 次闭环真实机器人试验，不允许人工恢复；
  - **SR（Success Rate）**：整任务完全成功的二值指标；
  - **SCR（Stage Completion Rate）**：各阶段完成比例的平均。
- **基线对比**（均为 π0.5 衍生，控制变量）：
  - **π0.5**：纯局部视野；
  - **π0.5 w/ Pano**：把 ERP 图当普通图片由 SigLIP 编码；
  - **π0.5 w/ Stacked Pano**：将 ERP 重投影成 3 张 120° 等分的透视图像拼接输入；
  - **PanoVLA**：本文方法（MTPano 编码 + 全景专家融合）。

## 6. 主要结论与发现

- **性能结果**：PanoVLA 在四项任务上的 **平均 SCR = 91.3%、SR = 73.4%**，显著优于 π0.5 基线（SCR 58.6%、SR 30.0%）；
- **任务特性分析**：
  - 在 **Move Pen**（单目标、定位为主）上，π0.5 w/ Pano 与 PanoVLA 持平（86.7% SR），说明 ERP 图本身已能提供足够空间信息；
  - 在 **Open Curtain** 与 **Wipe Table**（多阶段状态跟踪 + 长程空间一致性）上，PanoVLA 的优势最明显，例如 Wipe Table 的 SR 从 20.0% 提升至 46.7%；
- **几何表征 vs. 简单堆叠**：将全景图重投影为透视图像拼接（Stacked Pano）反而在多数任务上劣于直接使用 ERP 输入，提示**跨视角连续性**对机器人中心空间理解至关重要；
- **专家容量**：100M 参数的全景专家在数据量有限的情况下提供最佳性价比，50M 容量不足、>200M 无明显收益；
- **编码器选择**：MTPano（全景场景理解预训练）显著优于 SigLIP（透视图像预训练），SCR 从 75.6% 提升至 95.6%，验证了**几何感知全景表征**的必要性。

## 7. 优点与亮点

- **系统级解决方案**：从数据采集（全身遥操作）、数据集构建到策略学习构成完整闭环，而非单一模型改进；
- **统一 VR 遥操作**：通过 GMR 把底盘融合进同一优化目标，避免了"joystick + VR 臂"的解耦控制，演示更自然；
- **创新的 MoT 架构设计**：将"专家 KV-cache 拼接"作为融合接口，使全景上下文能以细粒度方式被动作专家利用，且不破坏原始 VLM 的语义通路；
- **几何感知全景编码**：选用 MTPano 同时提供语义与深度密集特征，而非简单把 ERP 当作 RGB；
- **细粒度评测**：除整任务 SR 外，引入 SCR 和阶段级分析，更能反映长程任务的稳定性与失败模式；
- **任务设计多样**：覆盖单目标、双侧、长距离往返等典型空间布局，验证全景感知在多种任务中的迁移性。

## 8. 不足与局限

- **数据集规模有限**：仅 5.5 小时 / 800 条轨迹 / 4 个任务，远小于 Open X-Embodiment 等大规模数据集，泛化性受限于数据多样性；
- **消融覆盖不足**：专家容量与编码器消融只在 Move Pen 上进行，结论对其他任务的迁移性未充分验证；
- **任务同质化**：四个任务均在相对结构化的桌面/家庭环境中完成，对**户外、拥挤场景或强光照变化**等开放世界条件的鲁棒性未评估；
- **统计显著性未量化**：每任务仅 15 次试验，未报告置信区间或显著性检验，差异可能受随机波动影响；
- **误差来源未深入诊断**：除 Wipe Table 外，未对其他任务的失败阶段进行细分（例如定位失败 vs. 操作失败 vs. 状态跟踪失败），限制了后续改进方向的指向性；
- **全景传感器假设较重**：依赖顶置 360° 相机硬件，未讨论全景遮挡、动态物体、机器人自身在全景中占大面积等典型问题；
- **底盘控制精度限制**：底盘为低成本 RANGER MINI UGV，论文承认虚拟 3-DoF 指令需经模式切换执行，可能引入追踪误差，影响精细任务表现；
