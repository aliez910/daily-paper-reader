## 摘要
VLA模型的视觉表征对于需要空间精确性的机器人操控而言仍不够可靠。我们发现VLA中的视觉编码器同样存在此前在通用视觉Transformer中被记录的注意力伪影，并进一步表明，在具身策略中，这些伪影与后训练阶段所获得的空间感知能力密切相关。随着编码器学习物体位置、深度顺序和局部几何等任务相关信息，有限的全局token容量导致这些信息的一部分溢出到低信息量的patch token中。我们提出了AtVLA，一个将可学习的寄存器token插入视觉编码器的框架。该框架仅使用具身数据与原始动作目标进行端到端训练，这些寄存器便涌现为承载具身空间信息的专用载体；与此同时，其余的patch token恢复出干净且空间保真的注意力分布，这对精确的目标定位与细粒度接触至关重要。干净的注意力恢复了可靠的定位能力，但无法恢复低分辨率观测中丢失的几何细节。因此，AtVLA将注意力矫正与不确定性门控的局部细化相结合：动作专家采样多个动作块并依据它们之间的分歧估计不确定性；仅当预测不确定时，由动作条件化的注意力展开识别出任务相关区域，对其裁剪后以高分辨率重新编码，并附加到缓存的前缀中以生成精细化的动作。在LIBERO、SimplerEnv以及一个具有挑战性的单视角真实世界基准上，AtVLA将LIBERO的平均成功率从94.2%提升至98.4%，并将真实世界成功率从46.5%提升至69.0%。裁剪仅在约30%的重规划步骤中被触发，在典型部署设置下，总计算量仅为基线模型的1.4–1.6倍。

## Abstract
Visual representations of VLA models remain unreliable for spatially precise robotic manipulation. We uncover that vision encoders in VLAs also exhibit attention artifacts previously documented in generic Vision Transformers, and further show that, in embodied policies, these artifacts are closely associated with spatial perception capabilities acquired during post-training. As the encoder learns task-relevant information such as object location, depth ordering, and local geometry, limited global-token capacity causes part of this information to spill into low-information patch tokens. We introduce AtVLA, a framework that inserts learnable register tokens into the visual encoder. Trained end-to-end using only embodied data and the original action objective, these registers emerge as dedicated carriers of embodied spatial information, while the remaining patch tokens recover clean and spatially faithful attention distributions crucial for precise target localization and fine-grained contact. Clean attention restores reliable localization, but cannot recover geometric details lost in low-resolution observations. AtVLA therefore couples attention rectification with uncertainty-gated local refinement. The action expert samples multiple action chunks and estimates uncertainty from their disagreement; only for uncertain predictions, action-conditioned attention rollout identifies the task-relevant region, which is cropped, re-encoded at high resolution, and appended to the cached prefix for refined action generation. Across LIBERO, SimplerEnv, and a challenging single-view real-world benchmark, AtVLA improves the average LIBERO success rate from 94.2% to 98.4% and real-world success from 46.5% to 69.0%. The cropping is triggered on approximately 30% of replanning steps, resulting in only 1.4-1.6x the total computation of the base model under the representative deployment setting.

# AtVLA 论文结构化总结

## 1. 核心问题与研究动机

- **核心问题**：VLA 模型虽然在语义理解上继承了视觉-语言预训练的丰富先验，但其视觉表征在空间精确的机器人操控任务中仍然不可靠。
- **观察到的两类瓶颈**：
  - **定位失效**：模型经常无法正确识别目标物体、无法消歧任务类型。检查注意力分布后发现，VLA 视觉编码器存在与通用 ViT 类似的高范数伪影（high-norm artifacts）——背景 patch 被征用为全局信息仓库，挤压了局部空间内容，污染了密集注意力图。
  - **几何细节缺失**：即便定位正确，低分辨率第三方观测中目标附近的细粒度几何信息只占少数 patch；腕部相机虽提供近距视角，但视角/姿态敏感。引入 3D 视觉专家会带来额外传感、标定与建模复杂度。
- **关键发现**：上述注意力伪影与具身后训练高度相关。随着编码器学习物体位置、深度顺序、实例结构与局部几何等任务相关信息，原有全局 token 容量不足导致信息溢出到 patch token 中，即"有用知识被存放在错误的表征通道"。
- **核心研究问题**：具身后训练如何重塑视觉编码器的表征？这些表征是否足以支撑细粒度操作？

## 2. 方法论

### 2.1 整体框架：AtVLA

- 在 π0 基础上引入两个互补机制：**寄存器增强视觉编码**（Register-Enhanced Visual Prefix）和**不确定性门控局部视觉细化**（Uncertainty-Gated Local Refinement）。

### 2.2 寄存器增强视觉前缀

- 在 SigLIP 视觉编码器的 [CLS] 之后插入 $N_r = 4$ 个可学习寄存器 token $r_1, \dots, r_{N_r}$，与 256 个 patch token 并行。
- 编码器输出三组特征：$[h_{cls}, R_t, P_t]$，其中 $R_t \in \mathbb{R}^{N_r \times d_v}$ 为寄存器特征，$P_t \in \mathbb{R}^{N_b \times d_v}$ 为 patch 特征。
- 与 Darcet et al. (2023) 丢弃寄存器输出不同，本方法**保留** $R_t$ 并通过 PaliGemma 视觉投影器 $\Pi$ 投射，与 patch token、语言编码、状态编码一起构成多模态前缀 $C_t^{bt}$。
- 训练后寄存器涌现为承载具身空间信息的"专用载体"，patch token 恢复干净的空间保真注意力分布。

### 2.3 不确定性门控动作预测

- LLM 主干对 $C_t^{bt}$ 进行一次前向，构造可复用的 KV-cache。
- 动作专家从独立高斯初始化中采样 $K$ 个动作块：$A^{(k)}_{1:H} = \text{ODESolve}(v_\theta, z^{(k)}_0 \mid C_t^{bt})$。
- 不确定性度量：仅在平动维度 $D_{tr}=\{\Delta x, \Delta y, \Delta z\}$ 与近期执行的 $h$ 步上计算 K 个采样之间的标准差：
  $$U_t = \frac{1}{h|D_{tr}|} \sum_{j=1}^{h} \sum_{d \in D_{tr}} \sqrt{\frac{1}{K-1}\sum_{k=1}^{K}\left(A^{(k)}_{j,d} - \bar{A}_{j,d}\right)^2}$$
- 阈值 $\tau$ 在验证集上以"约 30% 触发率"约束校准。

### 2.4 注意力引导的局部细化（仅当 $U_t > \tau$）

1. **动作条件化注意力展开**：复用动作专家前向中已计算的注意力矩阵；对层 $l$ 在所有头与固定去噪步 $\{3,6,9\}$ 上平均，加残差、行归一化得 $\tilde{M}_l$；通过 $M_{roll} = \tilde{M}_L \tilde{M}_{L-1} \cdots \tilde{M}_1$ 逐层传播。
2. **显著性图**：取前 $h$ 个动作 token 行对 256 个 base-image patch 列的平均，重塑为 $16\times16$ 图；双线性上采样到原图分辨率。
3. **对比式窗口搜索**：在候选尺寸 $S=\{84,112,140\}$ 像素（步长 14）上搜索最大化"窗口内平均注意力 − 周围环带平均注意力"的方形窗口。
4. **裁剪与重编码**：裁剪区域加 10% padding、clip 到图像边界、resize 到 $224\times224$，由同一寄存器增强编码器重新编码；丢弃裁剪侧的寄存器输出（基视图寄存器已含全局上下文），仅保留 $N_c=256$ 个裁剪 patch 特征。
5. **位置编码**：将归一化坐标 $(x_1/W, y_1/H, x_2/W, y_2/H)$ 经两层 MLP 映射后加到每个裁剪 token。
6. **KV-cache 复用**：仅对新增裁剪段重新 prefetch，基视图/语言/状态的 KV 直接复用。

### 2.5 训练目标与三阶段课程

- 总损失：$L = L_{\pi_0} + \lambda_{cp} L_{cp} + \lambda_{ag} L_{ag}$，其中 $L_{ag}$ 鼓励动作对图像注意力集中在真值交互区域内。
- **Stage 0（寄存器适配，20K 步）**：前 4K 步仅更新寄存器，后 16K 步同时放开 SigLIP 最后 4 个 block。
- **Stage 1（真值裁剪对齐，10K 步）**：冻结视觉编码器与寄存器，训练裁剪位置编码器 + rank-32 LoRA。
- **Stage 2（联合精修，40K 步）**：所有三组件的 LoRA + 寄存器 + 投影器 + 位置编码器联合优化；引入"真值裁剪 → 模型自身 rollout 裁剪"的渐进课程（$\alpha: 0\to1$），并配合 crop dropout（$0\to0.3$）。

### 2.6 部署计算

- 自信路径：无裁剪编码；不确定路径：1 次额外视觉编码 + 1 次精细化动作生成。
- 任务级计算公式（论文 Eq. 12–13）：在 $K=4$、$r\approx 0.3$ 的代表设置下，总计算量约为 $\pi_0$ 的 **1.4–1.6×**。

- **基准覆盖较充分**：LIBERO（4 套件）+ SimplerEnv（3 任务）+ 自建真实基准（10 个 Kitchen / Building Blocks 子任务），覆盖仿真到真实、单视角到杂乱场景。
- **消融较系统**：单独评估 Register、Cropping、全模型三组对照；线性探针、寄存器数量消融、移除寄存器消融；并对比了真值裁剪 vs 模型自身 rollout 裁剪的训练分布对齐。
- **公平性**：所有方法在真实基准上使用相同相机观测、任务演示与可比训练步数；标准差来自 20 次独立实验；表格中区分了"已发表基线"与"本地复现"两种来源。
- **分析维度多元**：从定量（成功率）、定性（注意力可视化、裁剪区域）、机理（线性探针）、成本（计算量倍数、触发率）四个角度交叉验证。
- **可能不足**：真实世界任务多样性仍局限于 Kitchen + Building Blocks 两类，未覆盖柔性物体/液体/光照剧变等极端场景；SimplerEnv 缺少 WidowX；阈值 $\tau$ 需按本体标定。

## 6. 主要结论与发现

- **性能提升**：
  - LIBERO 平均成功率：$\pi_0$ 的 94.2% → **AtVLA 98.4%**（所有四个子套件均最优）。
  - SimplerEnv：Pick Coke Can 91.3、Move Near 81.6、Open/Close Drawer 57.5（前者领先）。
  - 真实世界：$\pi_0$ 的 46.5% → **AtVLA 69.0%**（10 个任务均最优或并列最优）。
- **机理结论**：
  - 寄存器 token 确实承担具身空间信息（线性探针 ≥ 0.70，高于 CLS 与池化 patch）。
  - 清洁注意力可恢复可靠定位但不能恢复低分辨率损失的几何细节，二者必须协同。
  - 训练分布与推理分布对齐（rollout 裁剪 + dropout）是缩小 train–test gap 的关键。
- **成本结论**：约 30% 重规划步触发细化，整体计算仅 $\pi_0$ 的 1.4–1.6×。

## 7. 优点

- **诊断深入**：首次将 VLA 视觉编码器的注意力伪影与具身后训练任务信息溢出联系起来，并给出机理性的解释（"全局 token 容量不足 → 信息溢出 → patch 污染"）。
- **设计优雅**：寄存器不仅"吸收伪影"还"承载具身空间信息"被下游使用，而非简单丢弃；末端动作条件化注意力 rollout 与自适应裁剪形成闭环。
- **训练与推理分布对齐**：Stage 2 的渐进课程 + crop dropout + 无效 rollout 跳过（不回落真值）有效避免了 train–test 失配。
- **计算友好**：触发率受控（≈30%），KV-cache 复用，整体开销仅 1.4–1.6×。
- **评估多维且诚实**：报告标准差、独立实验次数、阈值按本体标定、给出失败案例（Open/Close Drawer 退化原因分析）。
- **可插拔**：仅在 π0 上加 4,608 参数寄存器 + 轻量位置 MLP + LoRA，无需改动作空间或部署接口。

## 8. 不足与局限

- **应用范围**：依赖单视角第三方摄像头，腕部相机视角敏感问题未被直接利用；未引入 3D 表征或多视角融合，复杂遮挡与深度模糊场景下仍受限于 2D 裁剪。
- **失败案例**：Open/Close Drawer 场景因 cabinet 占满画面，裁剪无法显著聚焦于把手/接触点，导致该任务收益有限；说明该方法对"目标已占满视野"的任务帮助较小。
- **裁剪尺寸硬编码**：候选窗口 $\{84,112,140\}$ 与 1.25× 上下文扩张、10% padding 为超参数，可能需按任务或相机距离调整。
- **外部裁剪基线限制**：π0 + Cropping 由未经具身训练的外部 VLM 出框，效果略低于 AtVLA，但仅能说明"具身化裁剪预测的必要性"，不能直接说明无 register 时裁剪的上限。
