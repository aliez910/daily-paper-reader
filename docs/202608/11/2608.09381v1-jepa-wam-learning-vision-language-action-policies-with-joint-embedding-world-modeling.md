## 摘要
稳健的机器人控制得益于对状态转移的显式建模，但视频生成式世界动作模型（WAM）带来了显著的部署成本。现有的潜在 WAM 避免了显式的未来生成，但通常会压缩预测表征或将预测建模与用于动作生成的表征相分离。我们提出了 JEPA-WAM，一种构建在预训练 V-JEPA 空间中的潜在 WAM，它通过一个共享预测器将潜在转移预测与连续动作生成相耦合。JEPA-WAM 预测一个具有空间结构、联合当前-未来目标，捕捉当前与未来观察之间任务共享的视觉时序结构，同时保持密集的 patch 级对应关系。通过共享预测器，转移监督直接作用于骨干网络，并从中提取专用表征用于动作预测。相同的设计也可以在预训练的 VLA 策略中实例化，同时保留其原有的感知与动作通路。在 LIBERO-Plus 上，JEPA-WAM 取得了 79.2% 的成功率，是不依赖大规模机器人策略预训练的最佳结果；其预训练的 π_{0.5} 实例化版本达到了 86.3%，取得了最佳的整体性能。在 RoboTwin 2.0 和真实世界双臂操作上的实验进一步表明，该方法在视觉和空间变化下具有强大的泛化能力。

## Abstract
Robust robot control benefits from explicitly modeling state transitions, but video-generation world action models (WAMs) introduce substantial deployment cost. Existing latent WAMs avoid explicit future generation, but often compress predictive representations or separate predictive modeling from the representations used for action generation. We introduce JEPA-WAM, a latent WAM built in a pretrained V-JEPA space, which couples latent transition prediction with continuous action generation through a shared predictor. JEPA-WAM predicts a spatially structured joint current-future target that captures task-shared visual temporal structure between current and future observations, while preserving dense patch-level correspondence. Through the shared predictor, transition supervision directly shapes the backbone, from which dedicated representations are extracted for action prediction. The same design can also be instantiated in pretrained VLA policies while preserving their original perception and action pathways. On LIBERO-Plus, JEPA-WAM achieves 79.2%, the best result without large-scale robot-policy pretraining, while its pretrained $π_{0.5}$ instantiation reaches 86.3%, achieving the best overall performance. Experiments on RoboTwin 2.0 and real-world bimanual manipulation further demonstrate strong generalization under visual and spatial shifts.

# JEPA-WAM 论文详细总结

## 一、核心问题与研究动机

- **研究背景**：视觉-语言-动作（VLA）策略在多种操作任务上取得了强劲性能，但其动作预测目标仅隐式建模状态转移，在分布偏移下鲁棒性受限。世界动作模型（WAM）通过同时建模未来状态与动作生成来缓解该问题。
- **现有方法的痛点**：
  - **视频生成式 WAM**：对未来进行迭代式帧预测，**部署成本高昂**。
  - **潜在 WAM**：虽避免显式生成，但存在两类缺陷：
    1. **目标压缩问题**——复用生成器特征或将未来压缩为少量 latent token / subgoal，丢失细粒度空间结构。
    2. **通路分离问题**——要么把预测的未来表征作为动作模块的额外上下文（造成冗余），要么引入独立的预测目标或 latent dynamics 模块（与动作表征通路解耦，对动作骨干的影响弱）。
- **本文针对的核心问题**：如何在保留状态转移建模的同时，避免显式未来生成，并以一种直接塑造动作生成骨干网络的方式耦合预测与动作？

## 二、方法论

### 2.1 整体架构

- **核心思想**：在预训练 V-JEPA 2.1 表征空间中构建一种 **潜在 WAM**，通过 **共享预测器**（Shared Predictor）将潜在转移预测与连续动作生成耦合在同一骨干上。
- **三大核心组件**：
  - 冻结的 **V-JEPA 2.1 编码器**（ViT-L/16，384×384 输入，24×24 patch grid，1024 维），提供稠密 patch 级视觉表征。
  - **共享预测器**  $F_\theta$（基于 Qwen2.5-0.5B，LoRA rank 32）：同时承担两件事——(a) 预测当前-未来联合转移目标；(b) 产出专用表征 $C_t$ 用于动作条件化。
  - **DiT 流匹配动作专家**（16 层 DiT-L）：使用条件流匹配预测动作块。

### 2.2 关键技术细节

- **当前视觉表征** $Z_t$：将多视角观察按固定相机顺序独立通过 V-JEPA 后拼接，得到 $Z_t \in \mathbb{R}^{N_{vis} \times d_J}$，保留相机与 patch 顺序。
- **空间结构化的当前-未来联合目标** $Y_{t,t+\delta}$：
  - 将 $O_{v,t}$ 与 $O_{v,t+\delta}$ 沿时间维度 stack，再送入冻结的 V-JEPA 编码器，得到目标表征。
  - 借助 V-JEPA 2.1 的 tubelet 大小为 2 这一特性，两帧输入产生与单图相同的空间 token 网格，从而 **保持 patch 级稠密对应**。
  - 目标强调的是 **时序关系**（哪些区域保持稳定 / 变化、局部物体与空间关系如何演化），而非要求重建完整且唯一的未来。
  - 编码使用 stop-gradient。
- **视觉接口对齐**：两层 MLP projector $P_{vis}$（1024→896→896），参考 Prismatic 单阶段微调方案；机器人策略训练时 V-JEPA、projector 与 base Qwen 冻结，仅训练 LoRA 适配器、过渡预测头和动作专家。
- **共享预测器机制**：
  - 在预测器输入中，除了视觉 token 与任务指令 $\ell$，还加入 **64 个专用 action placeholder** $P_{act}$。
  - 在视觉 token 位置的隐藏态 $Q_t^{wm}$ 由预测头 $G_\phi$ 映射回 V-JEPA 空间，得到 $\hat{Y}_{t,t+\delta} = G_\phi(Q_t^{wm}) \in \mathbb{R}^{N_{vis} \times d_J}$。
  - action placeholder 处隐藏态 $C_t$ 被送入动作专家。
- **转移预测损失** $L_{wm}$：在 $\hat{Y}_{t,t+\delta}$ 与 $Y_{t,t+\delta}$ 之间使用 **平均 patch 级余弦距离**。
- **动作预测损失** $L_{act}$：基于条件流匹配的速度预测目标（RoboTwin 2.0 上改用 x-prediction）。
- **联合训练目标**：$L = L_{act} + \lambda_{wm} L_{wm}$，$\lambda_{wm}=0.5$。
- **部署简化**：推理时移除目标分支与预测头，仅保留 V-JEPA、projector、共享预测器与动作专家；动作块通过 4 步 Euler 积分生成。

### 2.3 迁移到预训练 VLA 策略（$\pi_{0.5}$ + JEPA Obj.）

- 在 $\pi_{0.5}$ 的 VLM 前缀中追加 **64 个可学习 future tokens**，其输出隐藏态 $R_t \in \mathbb{R}^{64 \times 2048}$ 被 reshape 为 $8 \times 8$ 粗空间网格，经 LayerNorm + MLP（2048→2048→1408）+ 双线性上采样到 $24 \times 24$，对齐到 V-JEPA 的联合当前-未来目标。
- future tokens 可以关注原有图像与语言前缀，但 **动作 token 被阻止关注这些新查询**，从而保留原 $\pi_{0.5}$ 动作通路，仅以辅助过渡监督塑造 VLA 共享骨干。

## 三、实验设计

### 3.1 基准与场景

- **LIBERO**（ID）：同时在四个标准 suite 上训练并评估。
- **LIBERO-Plus**（OOD，无微调）：直接在 LIBERO 训练得到的策略上评估七类扰动（Camera / Robot / Language / Light / Background / Noise / Layout）。
- **RoboTwin 2.0**：20 个双臂操作任务，使用 Clean 演示训练，分别评估 Clean 与 Random 设置。
- **真实世界**：AgileX COBOT Magic 双臂平台，5 个任务（面包置盘、水果置盘、三块置盘、三块堆叠、抽屉放鸭子），ID 与 OOD（背景 / 物体初始配置变化）共 10 次 rollout。

### 3.2 对比方法

- **无大规模机器人预训练**：Diffusion Policy、ResVLA、Fast-WAM、VLA-Adapter、RoVLA、ACT、DP3、JEPA-WAM。
- **有大规机器人预训练**：$\pi_{0.5}$、VLA-JEPA、Motus、Being-H0.7、PokeVLA、ABot-M0、Cosmos-Policy、RDT-1B、$\pi_0$ 以及 $\pi_{0.5}$+JEPA Obj.。

### 3.3 关键结果

- **LIBERO（ID）**：JEPA-WAM 取得 96.7%，$\pi_{0.5}$+JEPA Obj. 进一步提升到 97.8%。
- **LIBERO-Plus（OOD）**：
  - JEPA-WAM 达 **79.2%**，无大规模预训练方法中最佳。
  - $\pi_{0.5}$+JEPA Obj. 达 **86.3%**，整体最佳（$\pi_{0.5}$ 基线 84.5%）。
- **RoboTwin 2.0**：JEPA-WAM 在 Clean 上 79.9%、Random 上 36.9%；$\pi_{0.5}$+JEPA Obj. 在 Clean 上提升至 84.6%。
- **真实世界**：JEPA-WAM 平均得分 ID 59.8% / OOD 54.2%，而 $\pi_0$ 仅为 51.8% / 22.5%；$\pi_{0.5}$+JEPA Obj. 在 ID/OOD 上分别达 90.34% / 84.68%。

## 四、资源与算力

## 六、主要结论与发现

- **潜在 WAM 也可保留强 ID 性能**：JEPA-WAM 在 LIBERO 上 96.7%，与最强基线持平。
- **OOD 泛化显著提升**：无需 OOD 微调，在 LIBERO-Plus 与 RoboTwin 2.0 Random 上均取得无大规模预训练方法的最佳结果。
- **联合当前-未来目标优于仅未来预测或端点差分**：
  - 端点差分目标仅 70.9%，联合目标 79.2%。
  - frozen probe 表明联合目标使时间间隔更易解码（67.2% vs 47.0%），并对未见间隔（10/30/50 帧）泛化更好（MAE 8.88 vs 13.32 帧）；在去掉端点位移后仍能恢复轨迹残差（$R^2$=0.582 vs 0.485）。
- **空间结构必须保留**：iREPA 卷积变换降至 74.7%，说明 patch 级对应不能被局部卷积抹平。
- **共享预测器的耦合方式关键**：
  - 中间层监督（Lower-16）降至 76.5%。
  - 移除专用 action placeholder、改为 Full-hidden 条件化降至 73.1%，验证专用动作读取的必要性。
- **同一目标设计可迁移到预训练 VLA**：$\pi_{0.5}$ 在 LIBERO-Plus 上从 84.5% 升至 86.3%，RoboTwin Clean 从 75.4% 升至 84.6%，真实世界 ID/OOD 同样提升。
- **推理无需未来帧生成**：部署中只保留动作生成通路，验证了"训练时建模转移、部署时不付出额外开销"的实用性。

## 七、优点与亮点

- **设计精巧的目标表征**：联合当前-未来目标在冻结的 V-JEPA 空间内既保留稠密 patch 结构，又强调时序关系，避免了主流方法的"压缩或解耦"缺陷。
- **共享预测器的耦合范式**：把过渡监督直接作用于动作生成的同一骨干，并通过专用 action placeholder 隔离动作读取，兼顾了"直接影响"与"避免干扰"。
- **可迁移性强**：同一目标设计以插入式 future tokens 形式附加到 $\pi_{0.5}$，不改动原感知/动作通路，对预训练 VLA 的提升幅度反而更大。
- **评测体系完备**：横跨仿真（ID/OOD）、不同长度动作块、真实世界 ID/OOD，并辅以 frozen probe 与空间诊断，分析具有说服力。
- **推理高效**：去除未来帧生成后，延迟明显低于同类 WAM（85 ms vs ABot-M0 125 ms）。
- **消融有序**：四个核心设计选择均给出对应 baseline，且定量差异较大（如 Full-hidden 比专用 placeholder 低 6.1 个百分点），结论稳健。

## 八、不足与局限

- **语言条件化缺失**：作者明确指出，过渡目标学习的是 **与语言无关** 的通用视觉时序结构；当同一观察在不同指令下可能导致截然不同的过渡时，监督信号的表达力可能受限。
- **真实世界规模有限**：仅 5 个任务、每任务 100 条演示、每个条件 10 次 rollout，未涉及更复杂的扰动（光照剧烈变化、相机机型差异、对象类别外推）。
- **GPU / 训练时长未披露**：算力相关可复现性信息不完整，限制了对计算开销的独立评估。
- **$\delta$ 选择依赖基准**：时间偏移 $\delta$ 是基准特定超参（LIBERO 31、RoboTwin 50），需手动设置，缺乏对不同 $\delta$ 的系统敏感性分析。
- **迁移实例相对单一**：仅在 $\pi_{0.5}$ 上验证迁移，未对其他主流预训练 VLA（如 OpenVLA、RDT）做迁移实验，限制了结论的泛化面。
- **frozen probe 仅辅助证据**：probe 分析虽强，但仅针对 RoboTwin Clean-20 等设置，对 LIBERO 等基准的表征特性是否一致尚未验证。
- **潜在偏差风险**：
  - 真实世界评估使用归一化部分得分，可能掩盖某些任务的二元成败差异。
  - OOD 设置由同一团队设计，可能与训练分布在"扰动强度"上不易完全对齐到真实部署。
