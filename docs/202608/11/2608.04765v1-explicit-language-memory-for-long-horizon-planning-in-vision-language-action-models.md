## 摘要
视觉-语言-动作（VLA）模型为连接视觉感知、语言理解和机器人控制提供了一种统一的范式。然而，现有VLA模型在长时序任务中仍面临重大挑战：稀疏的专家演示限制了跨任务的组合泛化能力；长时序任务的非马尔可夫特性使得仅以当前观测为条件难以保持时序一致性；有限的闭环误差修正能力使执行误差不断累积；端到端的动作微调可能会削弱视觉-语言模型（VLM）主干网络的高级语义表征能力。为解决这些问题，我们提出了一种具有显式语言记忆模块的分层长时序VLA架构。其核心思想是将离散的时间观测转化为具有时间逻辑的连贯文本记忆序列。该系统被解耦为高层VLM和底层VLA：高层VLM通过视觉问答训练范式进行语义推理，底层VLA以子任务指令和视觉观测为条件执行精确的连续控制。高层VLM以前一时刻的记忆作为上下文锚点，递归地更新语言记忆和子任务指令，从而实现长时序执行过程中的持续时间跟踪和动态纠错。我们在多个仿真环境中对所提方法进行了评估，并在真实机器人平台上开展了仿真到现实的迁移实验。实验结果表明，显式语言记忆在提升VLA模型在复杂长时序任务上的成功率和鲁棒性的同时，为决策过程提供了可解释的语义解释。

## Abstract
Vision-language-action (VLA) models provide a unified paradigm for connecting visual perception, language understanding, and robotic control. However, existing VLA models still face major challenges in long-horizon tasks: sparse expert demonstrations constrain cross-task compositional generalization; the non-Markovian nature of long-horizon tasks makes it difficult for policies conditioned only on current observations to maintain temporal consistency; limited closed-loop error correction allows execution errors to accumulate; and end-to-end action fine-tuning may weaken the high-level semantic representations of vision-language model (VLM) backbones. To address these issues, we propose a hierarchical long-horizon VLA architecture with an explicit language-memory module. The central idea is to convert discrete temporal observations into a coherent textual memory sequence with temporal logic. The system is decoupled into a high-level VLM and a low-level VLA: the high-level VLM performs semantic reasoning through a visual question answering training paradigm, while the low-level VLA executes precise continuous control conditioned on subtask instructions and visual observations. The high-level VLM recursively updates both language memory and subtask instructions using the previous memory as a contextual anchor, enabling persistent temporal tracking and dynamic correction during long-horizon execution. We evaluate the proposed method in multiple simulation environments and conduct sim-to-real experiments on a real robotic platform. The results demonstrate that explicit language memory improves the success rate and robustness of VLA models on complex long-horizon tasks while providing an interpretable semantic account of the decision process.

## 1. 核心问题与整体含义

### 1.1 研究背景
- 视觉-语言-动作（VLA）模型（如 RT-2、OpenVLA、π0、π0.5）试图以统一策略将感知、语言与控制结合，使机器人能够基于视觉观测与语言指令生成动作。
- 然而，VLA 在**长时序（long-horizon）、多阶段**任务中表现仍然脆弱，难以胜任分钟级甚至十分钟级的连续操作。

### 1.2 现有 VLA 在长时序任务中的四大瓶颈
- **跨任务组合泛化受限**：专家演示稀疏，难以在不同任务间复用语义知识。
- **非马尔可夫性导致时间一致性弱**：仅以当前观测为条件的策略无法记住"按钮是否已被按下""包裹是否已经过扫描"等关键历史状态，从而出现跳步、重复或基于错误前提的决策。
- **闭环误差修正能力有限**：执行错误沿动作链累积，缺乏动态纠错机制。
- **端到端动作微调削弱高层语义**：直接对 VLM 进行动作微调可能损害其原有的高层语义表征能力。

### 1.3 核心假设
- 论文提出"**显式语言记忆**"假设：长时序任务的关键不在于保留每一帧原始观测，而在于以自然语言形式维护一份**有结构的、可监督的状态摘要**，使阶段推进（phase progression）必须等到观测证据支持当前里程碑完成。

## 2. 方法论

### 2.1 整体思路
- 将长时序策略分解为**高层语义规划**与**底层连续控制**两个耦合子模块，整体策略被分解为：

$$
\pi(a_{t:t+H}, s_t, m_t \mid o_t, m_{t-1}, l)
= \pi^{LL}(a_{t:t+H} \mid o_t, s_t) \cdot \pi^{HL}(s_t, m_t \mid o_t, m_{t-1}, l)
$$

其中：
- $l$：全局任务指令
- $o_t$：当前视觉与本体感知观测
- $m_{t-1}, m_t$：前后时刻的自然语言记忆
- $s_t$：简洁子任务指令
- $a_{t:t+H}$：长度为 $H$ 的连续动作块

### 2.2 关键技术细节

#### （1）高层 VLM：递归语言记忆
- 记忆 $m_t$ 不是逐帧叙事，而是一份**结构化自然语言摘要**，包含：
  - 已完成的里程碑（过去时态）
  - 完成证据
  - 目标对象属性（类别、颜色、位置）
  - 已观察到的失败
  - 下一待执行意图
- 采用**滚动压缩（rolling compression）规则**：子任务完成前保留细节，完成后压缩为简短过去时陈述，注意力转向下一步。
- 示例（开收音机任务）：
  - $m_t$：I am moving to the red radio on the coffee table.
  - $m_{t+1}$：I moved to the radio, and I am going to pick up the red radio.
- 仅当当前观测提供里程碑切换证据时才更新记忆。

#### （2）底层 VLA：动作块生成
- 接收当前观测 $o_t$ 与子任务指令 $s_t$，输出长度为 $H=30$ 的连续动作块。
- 采用与 π0.5 相同的**流匹配（flow matching）动作专家**作为底层控制模块。

#### （3）自动记忆监督流水线
- 每条专家示教包含视频 + 技能级标注（技能名、描述、起止时间戳）。
- 使用通用 VLM（Gemini 3.5 Flash API 或本地 Qwen3.5-9B）逐帧生成两字段监督：
  1. **简洁子任务**：形式为 "动作 + 目标对象 + 上下文"，省略施事者。
  2. **第一人称语言记忆**：过去时描述已完成技能，将来时描述下一步。
- 提示词显式要求使用自然对象名称与可见属性，避免出现"帧""索引""技能编号"等实现术语。

#### （4）独立分支训练
- 高层采用 PaliGemma，以**自回归方式**同时预测 $m_t$ 与 $s_t$，损失：
$$
L_{HL} = -\mathbb{E}\left[\log \pi^{HL}_m(m_t \mid o_t, m_{t-1}, l) + \log \pi^{HL}_s(s_t \mid o_t, m_{t-1}, l)\right]
$$
- 底层采用与 π0.5 相同的**流匹配动作目标**：
$$
L_{LL} = \mathbb{E}\left[\|a_{t:t+H} - \pi^{LL}(o_t, s_t)\|_2^2\right]
$$
- 两分支独立训练，避免在单一目标中手工平衡语言生成与连续控制损失。

#### （5）闭环推理
- 初始化 $m_0 = \emptyset$，循环执行：观测 → 更新 $(m_t, s_t)$ → 生成动作块 → 执行 → 直到高层判定任务终止。
- 记忆与子任务均为可见文本，可形成**可解释日志**与动作失败对齐分析。

## 6. 主要结论与发现

- **阶段成功率提升**：
  - BEHAVIOR-1K 收音机：平均成功率由 30.0% 提升至 **40.0%**（PickUp 由 10% → 30%）。
  - Genie Sim 单包裹分拣：41.7% → **63.9%**；Follow 与 PickUp-1 由 50% 翻倍至 100%；扫描区放置由 50% → 83.3%。
  - Genie Sim 连续四包裹：31.3% → **46.9%**；基线从未完成第 3、4 个摆放，记忆模型在 12.5% 试验中完成全部 4 次。
  - 真机抓放：62.5% → **66.3%**（提升较小，符合任务仅 4 阶段的预期）。
- **阶段一致性（phase consistency）**：记忆机制使阶段推进必须以观测证据为条件，减少跳步与过早过渡。
- **语义与运动解耦**：记忆解决"做什么、处于哪一阶段"，不直接提升接触式操作（如 PressOn 按钮）成功率——表明语义记忆与底层控制能力各司其职。
- **可解释性**：记忆与子任务均为文本，可直接读取用于失败归因（区分高层语义错误与底层控制错误）。
- **上下文内失败恢复**：当抓取失败时，记忆可记录"物体未被夹紧"，引导松开-再抓策略，无需单独设计恢复控制器。

## 7. 优点

- **问题定位精准**：直击长时序任务中"非马尔可夫性导致阶段错乱"这一核心瓶颈，而非泛泛追求更大模型或更多数据。
- **结构简洁、可解释性强**：以自然语言作为记忆载体，使策略决策过程可被人类直接审阅与诊断。
- **分层解耦设计**：将语义规划与连续控制分离，避免在单一损失中手工平衡两种目标，同时保留各自的可替换性。
- **监督成本可控**：利用通用 VLM（Gemini/Qwen）自动从示教视频与时间戳生成 (memory, subtask) 监督，无需昂贵的人工标注。
- **三平台验证**：覆盖家庭仿真、人形机器人仿真、低成本真机，证明方法具有一定跨场景迁移能力。
- **价值在于"互补"而非"替代"**：明确指出记忆不能替代底层控制能力提升，定位诚实。

## 8. 不足与局限

### 8.1 实验层面
- **无消融实验**：未量化记忆格式、子任务指令、压缩规则等组件各自的贡献。
- **统计显著性缺失**：未报告多随机种子方差与置信区间，改进幅度是否稳定可复现存疑。
- **真机数据量极小**：仅 25 条示教、20 次评估，无法支撑对真机泛化性的强结论。
- **任务数量有限**：每个平台只评估 1 个主任务（连续包裹分拣虽更复杂但仍是同一任务族），缺乏任务多样性。
- **基线单一**：仅与原生 π0.5 对比，未与 OpenVLA、RT-2、π0 等其他 VLA 对照，方法通用性边界不清。

### 8.2 方法层面
- **推理延迟与算力开销增加**：每步需额外调用高层 VLM，部署复杂度与端到端延迟高于原生 π0.5。
- **记忆形式单一**：仅依赖自然语言，对图像中隐含的物理交互信号（接触力、滑移、碰撞）不敏感，难以区分"看似抓到"与"实际抓紧"。
- **VLM 标注质量依赖**：监督信号由通用 VLM 自动生成，可能继承其幻觉与对象误识别问题。
- **失败恢复依赖数据**：要可靠实现"松开-重抓"等恢复行为，需要专门的失败-恢复示教数据，目前训练集中未明确覆盖。

### 8.3 应用层面
- **复杂接触式操作仍是短板**：PressOn 成功率仅由 0% → 10%，表明记忆无法补偿底层运动精度不足。
- **未覆盖多对象、动态环境、长时间跨度的真实场景**，离真正部署仍有距离。
- **未来方向**：作者提出将记忆扩展为"视觉 + 语言 + 触觉/力反馈"的多模态记忆，以补足语言无法表达的状态。
