## 摘要
以可供性引导的模仿学习通过将视觉感知压缩为任务特定的几何约束（例如固定接触点），在机器人操作任务中展现出令人印象深刻的效果。然而，常见的静态可供性在对精度要求较高的任务中，或在物体位置发生扰动的情况下可能变得不一致，导致接触后出现轨迹漂移。为解决这一问题，我们提出了 AffordTrajDP，这是一个通过以物体为中心的时间传播机制构建可供性轨迹以引导渐进式操作过程的动态框架。具体而言，给定 RGB-D 观测，我们的关键洞见在于：检索得到的锚定可供性刻画了末端执行器与目标物体之间期望的接触点，可通过可供性传播，利用物体的 SE(3) 位姿作为自然传播介质，将其向前传播以生成一条可供性轨迹，从而在整个执行过程中提供时间一致、状态感知的引导。AffordTrajDP 在 ManiSkill3 上取得了 70.0% 的平均成功率，较强基线方法提升最高达 17.8%。在 Galaxea A1 与 UR7e 机械臂上围绕堆叠方块、取杯、适配器插入、套环、放碗以及 USB 插入等任务开展的真实世界实验进一步验证了该方法在物体放置变化与外观变化下的鲁棒性，其中在 Galaxea A1 上对已见与未见物体实例均进行了评估；消融实验亦证实了各个所提出组件的贡献。

## Abstract
Affordance-guided imitation learning has shown impressive performance in robotic manipulation tasks by compressing visual perception into task-specific geometric constraints (e.g., fixed contact points). However, the commonly used static affordances can become inconsistent in precision-critical tasks or under object location perturbations, leading to post-contact trajectory drift. To address this issue, we propose AffordTrajDP, a dynamic framework that constructs affordance trajectories via object-centric temporal propagation to guide the progressive manipulation process. Specifically, given an RGB-D observation, our core insight is that a retrieved anchor affordance, which captures the desired contact point between the end-effector and the target object, can be propagated forward via affordance propagation, using the object's SE(3) pose as a natural propagation medium, to yield an affordance trajectory that provides temporally consistent, state-aware guidance throughout execution. AffordTrajDP achieves 70.0% average success rate on ManiSkill3, outperforming strong baselines by up to 17.8%. Real-world experiments on Galaxea A1 and UR7e robotic arms, covering StackCube, PickCup, AdapterInsertion, Ring-on-Peg, Put-in-Bowl, and USB Insertion, further validate robustness under object placement variations and appearance changes, with seen and unseen object instances evaluated on Galaxea A1, and ablations confirm the contribution of each proposed component.

# AffordTrajDP 论文总结

## 1. 核心问题与研究动机

- **问题背景**：以可供性（affordance）引导的模仿学习在机器人操作中通过将视觉感知压缩为任务相关的几何约束（如固定接触点）取得显著效果，但这类"静态可供性"存在两个关键缺陷：
  - 在**精度敏感任务**（如适配器插入、USB 插入）中，接触后的微小偏差会累积，导致轨迹漂移、振荡甚至失败；
  - 在**物体位置扰动**（放置位置变化、外观变化、遮挡）下，静态先验难以持续与目标对齐。
- **既有方法的局限**：作者指出以往条件信号只保留了"在哪儿接触"或"接触如何随时间变化"二者之一：
  - **语义接触点方法**（如 AffordDP）只检索一次性接触点，传递后整回合不再更新；
  - **位姿轨迹方法**（如 SPOT、PRISM-DP）只跟踪物体整体运动，缺乏语义接触信息。
- **研究意义**：作者认为这是首个明确诊断出的"双重信号缺失"问题，并据此提出 AffordTrajDP 框架，同时提供"哪里接触"与"接触如何演化"两类引导信号。

## 2. 方法论

### 2.1 整体框架
- AffordTrajDP = **Anchor Affordance Generation（锚点可供性生成）** + **Dynamic Affordance Propagation（动态可供性传播）** + **Action Generation（动作生成）**。
- 核心思想：以物体 SE(3) 位姿作为"传播介质"，将语义锚点接触点沿预测的未来位姿轨迹传播，得到时序一致的动态可供性轨迹，用于条件化扩散策略。

### 2.2 关键技术细节

- **锚点可供性检索（Anchor Affordance）**：
  - 使用 GroundedSAM 裁剪目标物体区域；
  - 用 CLIP 图像编码器提取外观嵌入并构建物体记忆 $\mathcal{M}=\{(\ell, c, z, T)\}$；
  - 推理时按任务标签 $\ell$ 在余弦相似度上取最近邻，得到源接触点 $c^{src}$；
  - 通过密集视觉对应（dense correspondence）将源接触点传递到目标实例，得到 $c^{tgt}\in\mathbb{R}^3$。
- **未来位姿轨迹预测**：
  - 用 GroundedSAM + Any6D + FoundationPose 提取演示中的 SE(3) 位姿轨迹；
  - 为消除场景布局差异，将源物体位姿表达在目标物体坐标系下：$T^{src}_{tgt}(t)=\big(T^{tgt}_W(t)\big)^{-1}T^{src}_W(t)$；
  - 训练一个 **DDIM 条件扩散模型**预测未来 $H=4$ 步 SE(3) 位姿；输入为位姿历史 $h_t$，向量化为 $x(t)=[t(t);q(t)]\in\mathbb{R}^7$，训练目标为标准 MSE 噪声预测损失。
  - DDIM 的非马尔可夫确定性反向过程避免了每步随机扰动向可供性轨迹的传播，同时减少推理延迟。
- **可供性传播（Affordance Propagation）**：
  - 将锚点接触点 $\tilde c=[(c^{tgt})^\top,1]^\top$ 通过预测的刚体变换 $T_{t+k}$ 传播至未来时刻：$p_{t+k}=T_{t+k}\tilde c,\;k=0,\dots,H$；
  - 得到动态可供性轨迹 $\tau_{t:t+H}=\{p_t,\dots,p_{t+H}\}$，最终可供性 $\Phi^{tgt}=(c^{tgt},\tau^{tgt})$。
- **动作生成**：
  - 静态锚点用 2 层 MLP 编码（隐维 256）；
  - 动态轨迹（4 步）经线性嵌入 + 可学习 [CLS] token + 正弦位置编码，再经小型 Transformer（2 层，2 头，$d_{model}=64$）编码为 64 维特征；
  - 与点云等其它观测拼接为 $f_t$，作为 DDIM 扩散策略的条件；
  - 动作预测 16 步、仅执行前 8 步（receding-horizon），控制频率 10 Hz。

## 6. 主要结论与发现

- **仿真**：AffordTrajDP 在 ManiSkill3 6 任务平均成功率 70.0%，较 DP3 (52.2%) 提升 17.8%、较 AffordDP (57.8%) 提升 12.2%、较 SPOT (62.1%) 提升 7.9%；在 PegInsertion/PlugCharger 等精度敏感任务上提升最大（PlugCharger 24.7% vs DP3 11.3%）。
- **真实 Galaxea A1**：平均成功率 66.1%，较 DP3 (35.0%) 显著提升；AdapterInsertion 上由 10% 提升至 30%（seen+unseen 平均）。
- **真实 UR7e**：平均成功率 72.5%，在 USB Insertion 等亚毫米精度任务上从 3/30 提升至 11/30。
- **消融发现**：
  - 语义接触与位姿轨迹**各自必要、单独不充分**；
  - +Contact 优于 +Center（说明语义定位而非几何先验起作用）；
  - +Trajectory 无语义锚时反而在未见实例上**劣于基线**（StackCube unseen: 20% vs 40%），证实"轨迹条件化"需要语义锚才有意义；
  - 全方法将两组件联合后取得最大且稳定的增益（66.1% vs 47.2%）。
- **误差特性**：位姿轨迹预测误差在 4 步内基本不随回合步累积；FoundationPose 自身跟踪误差在接触后持续上升、量级与预测误差相当，作者据此假设（而非已证）"上游跟踪噪声是后接触误差的主要来源"。

- **问题形式化清晰**：明确指出"接触位置语义"与"接触演化几何"两种条件信号在以往工作中各持其一，首次形式化双重缺失问题。
- **方法设计简洁**：通过 SE(3) 传播将已有的静态可供性升级为时间一致动态轨迹，不依赖额外的力/触觉信号。

- **细节考虑**：在目标坐标系下表达位姿以消除场景布局差异，使用 DDIM 而非 DDPM 以降低每步随机扰动对轨迹传播的污染。

## 8. 不足与局限
