## 摘要
尽管视觉-语言-动作（VLA）模型推动了具身智能的发展，但其本质上反应式的范式在部分可观测和长时程任务中严重限制了性能。当仅使用单个腕部摄像头时，模型不可避免地会在物体离开视野时出现感知遗忘，并在多步执行过程中出现时序任务进度遗忘。为克服这些瓶颈，我们提出了 AtlasVLA，一个通过持久化世界-本体状态从直接反应式操作转向主动推理的新型框架。AtlasVLA 采用双重记忆架构：一个 4D 持久化世界状态记忆，将瞬态的二维观测提升为全局更新的、体素哈希的空间状态以解决视觉盲区问题；以及一个本体工作状态记忆，用于跟踪历史本体状态和任务进度。通过将扩散 Transformer（DiT）以联合的“世界-本体”状态为条件，AtlasVLA 实现了鲁棒的空间推理。在 LIBERO、RLBench 以及真实世界基准上的广泛评估表明，AtlasVLA 仅凭腕部摄像头即可达到最先进的性能。值得注意的是，它以压倒性优势超越了多视角基线，在 LIBERO-Long 和真实世界长时程任务上分别取得了 9.4% 和 17.5% 的绝对成功率提升。

## Abstract
While Vision-Language-Action (VLA) models have advanced embodied AI, their fundamentally reactive paradigm severely limits performance in partially observable and long-horizon tasks. When restricted to a single wrist-mounted camera, they inevitably suffer from perception forgetting as objects exit the field of view, and temporal task-progress forgetting} during multi-step execution. To overcome these bottlenecks, we propose AtlasVLA, a novel framework that transitions from direct reactive manipulation to proactive reasoning through a persistent world-ego state. AtlasVLA features a dual-memory architecture: a 4D Persistent World State Memory that lifts transient 2D observations into a globally updated, voxel-hashed spatial state to resolve visual blind spots, and an Ego-Working State Memory that tracks historical ego state and task progress. By conditioning a diffusion transformer (DiT) on this joint World-Ego state, AtlasVLA enables robust spatial reasoning. Extensive evaluations across LIBERO, RLBench, and real-world benchmarks demonstrate that AtlasVLA achieves state-of-the-art performance using solely a wrist camera. Remarkably, it decisively outperforms multi-view baselines, yielding absolute success rate improvements of 9.4% on LIBERO-Long and 17.5% in real-world long-horizon tasks.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究领域**：视觉-语言-动作（Vision-Language-Action, VLA）模型，是具身智能与机器人操控领域的核心方向。
- **现存痛点**：现有 VLA 模型本质上是**反应式（reactive）**范式，即仅依据当前帧的观测直接输出动作。这种范式在两类场景中存在显著缺陷：
  - **部分可观测性（partial observability）**：当任务被限制在仅使用单个腕部摄像头时，物体一旦离开视野便无法再被感知，导致**感知遗忘（perception forgetting）**；
  - **长时程任务（long-horizon tasks）**：在多步骤执行过程中，模型缺乏对已完成步骤的归纳与对剩余任务进度的判断，导致**时序任务进度遗忘（temporal task-progress forgetting）**。
- **整体立意**：论文主张 VLA 模型应当从"反应式操控"转向"主动推理（proactive reasoning）"，核心思路是引入**持久化的世界-本体状态（persistent world-ego state）**来弥补单视角与短时记忆的不足。

## 2. 方法论

### 2.1 核心思想
提出 **AtlasVLA** 框架，将"瞬时 2D 观测"显式地提升为"持久化 4D 空间状态"，并通过双记忆架构为下游策略提供完整的全局态势。

### 2.2 关键模块
- **4D 持久化世界状态记忆（4D Persistent World State Memory）**
  - 将每一帧的瞬时 2D 观测逐步**提升（lift）**为一个**全局持续更新的体素哈希（voxel-hashed）空间状态**；
  - 通过累积式表达，缓解物体离开视野后的视觉盲区问题；
  - "4D"暗示同时包含空间维度与时间演化维度。
- **本体工作状态记忆（Ego-Working State Memory）**
  - 跟踪**历史本体状态**（机器人自身的位姿、夹爪状态等）；
  - 同时维护**任务进度信号**，使模型具备对已完成步骤与剩余子目标的归纳能力。
- **扩散 Transformer 策略（DiT Policy）**
  - 将一个扩散 Transformer（Diffusion-based Transformer）以**联合世界-本体状态（joint World-Ego state）**作为条件；
  - 在该条件化表示下进行动作采样，以实现鲁棒的空间推理。

### 2.3 算法逻辑（文字层面）
1. 由腕部相机获取当前 2D 观测；
2. 将 2D 观测写入世界状态记忆，更新全局体素哈希表示；
3. 同时将本体观测与任务进度信号写入自我工作状态记忆；
4. 策略网络以"世界状态 + 自我状态"为联合条件，扩散采样输出动作序列。
