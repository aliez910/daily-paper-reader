## 摘要
长时序机器人操作要求机器人既能可靠地执行各项技能，又能在长时间任务中将它们连贯地串联起来。然而，现有的大多数分层视觉-语言-动作（VLA）模型在每次决策时仅通过单次前向传播完成，缺乏为困难或关键的决策分配额外计算资源的机制。本文提出 τ₀-VLA，一种分层机器人基础模型，它通过世界模型引导的测试时计算，将高层子任务生成建模为一个可扩展计算量的推理问题。在每次推理过程中，高层策略利用执行记忆生成一个子任务，并在必要时对候选方案进行搜索后再确定输出。底层策略则在多种机器人本体上执行所生成的子任务。该模型基于 40,115 小时的异构真实世界数据，通过多模态联合训练得到。在域内以及分布外偏移场景下，分配更多测试时计算可显著提升下一子任务预测的准确率，并将这种增益进一步转化为长时序机器人操作任务中更高的闭环成功率。

## Abstract
Long-horizon robot manipulation requires a robot to both execute individual skills reliably and sequence them coherently over extended tasks. Most hierarchical vision-language-action (VLA) models make each such decision with a single forward pass, leaving no mechanism to allocate additional computation to difficult or consequential choices. We introduce $τ_0$-VLA, a hierarchical robot foundation model that formulates high-level subtask generation as a compute-scalable inference problem through world-model-guided test-time computation. At each inference step, the high-level policy uses execution memory to generate a subtask and, when needed, searches over alternatives before committing to its output. A low-level policy then executes the generated subtask across multiple robot embodiments. The policy is trained on 40,115 hours of heterogeneous real-world data with multimodal co-training. Across in-domain and distribution-shifted settings, allocating additional test-time computation substantially improves next-subtask prediction accuracy, and these gains translate into higher closed-loop success on long-horizon robot manipulation tasks.

# τ₀-VLA 论文总结

## 1. 核心问题与研究动机

- **长时序机器人操作的核心瓶颈**：长时序任务（如打扫房间、做菜、泡奶茶等）需要机器人既能可靠执行单步技能，又能在分钟至小时级别连贯地串联子任务序列；错误的子任务选择即便动作再精确也无法挽回，因为执行过程已经改变环境状态。
- **现有分层 VLA 模型的局限**：大多数分层 VLA 模型在高层决策时仅做一次前向传播，缺乏为困难或关键决策分配额外算力的机制，难以前置评估候选方案。
- **研究问题**：如何在开放性语言子任务搜索、视觉结果预测和执行记忆三者之间建立有效耦合，使高层决策的计算量可随决策难度伸缩？
- **本文核心观点**：将"下一个子任务"的生成建模为可扩展的推理问题，借鉴语言模型中测试时计算（test-time computation, TTC）的思路，通过世界模型引导的束搜索与反思模型，在决策前显式评估候选后果。

## 2. 方法论

### 2.1 系统总体架构

- **分层结构**：
  - 高层策略 μ：维护执行记忆、决定是否调用 TTC、生成当前子任务。
  - 低层策略 πθ：将当前观测与所生成的子任务映射为动作块。
- **统一状态与动作空间**：40 维向量，覆盖末端执行器位姿（Rot6D）、夹爪、腰部、平面基座速度，以及左右臂各 8 个关节；通过 mask 处理不同本体。
- **闭环机制**：高层每个逻辑推理步先产生子任务 z*ₜ，低层据此生成 H=30 步动作块；执行后真实观测并入下一轮高层推理记忆。

### 2.2 高层策略

- 包含四个组件：
  - **提案模型 P**：由 Qwen3.5-9B 微调，同时更新执行记忆 Mₜ 并给出直接提案 z^dirₜ。
  - **世界模型 W**：基于 Step1X-Edit，给定头相机图像 õ 与候选子任务 z，预测子任务完成时的终端头相机图像 ô。
  - **价值模型 V**：以全局指令、候选子任务、预测终端图像为输入，按五档（clearly wrong → clearly correct，标量 [0.05, 0.95]）打分。
  - **反思模型 F**：基于保留分支摘要 Cₜ 与观测对齐上下文 h̄ₜ 生成最终子任务 z*ₜ，输出可不限于保留候选。
- **自适应路由**：利用提案模型同一前向传播产生的 token 置信度统计（全 token 平均概率与 <memory> 字段平均 logit margin），设定阈值 δ_all、δ_mem 后判断是否触发 TTC，无需额外推理。
- **测试时束搜索（SEARCH）**：
  - 初始化根分支，逐层深度 d=1..D 展开。
  - 每个保留分支 b 调用提案模型 N 次得到候选 {z_{b,i}}，再由 W 与 V 给出预测图像与分数。
  - 累计分数 S(b⊕z) = S(b) + v(b⊕z)，全局取 Top-B 保留。
  - 深度 D 可递归扩展，分支局部记忆与预测图像作为下一深度上下文。
  - 搜索得到的候选摘要 Cₜ 输入反思模型以提交最终子任务。
- **可修正的执行记忆**：训练时扰动输入记忆（落后、超前、错误记录等 5 类情形），标签仍读自示范数据，迫使高层学会对照视觉证据修复记忆；不需额外人工标注。

### 2.3 低层策略

- **结构**：Qwen3.5-2B 视觉-语言主干 + Mixture-of-Transformers（MoT）动作专家，在每个全注意力层动作 token 与主干 token 通过 joint attention 交互，但走两套独立参数化的 Transformer 流。
- **动作生成**：用条件流匹配（conditional flow matching）在统一 40 维动作空间训练速度场；按 Black et al. 的线性高斯路径反向重参数化。
- **Masked Flow Matching**：仅对有效通道施加 mask M（对角矩阵），插值 a^τ = τMϵ + (1−τ)Ma、目标速度 u = M(ϵ−a)，损失仅作用于激活通道，并在积分前后对动作向量重新施加 mask。
- **三阶段训练**：
  1. 知识隔离联合训练（KI）：动作专家与多模态数据共同训练，反向阻断动作 loss 流入主干；
  2. 端到端联合训练：解除 KI，使动作梯度参与主干微调；
  3. 任务自适应微调：在目标本体、视角、物体配置的小量示范上精调。

### 2.4 异步双系统部署

- 高层策略（约每秒刷新一次）后台异步计算下一子任务并写入每回合缓存；控制循环仅读取缓存并以约 30 Hz 调用低层策略。高层推理延迟只影响"下一次命令刷新"，不会中断执行。

- **直接执行 vs Hierarchical**：在四个长时序任务上，τ₀-VLA 直接执行平均 SR 27.5%（进度 80.1%），Hierarchical Plan Once 提升到 SR 45.0%（进度 87.85%），显著优于 GR00T（2.5%）、LingBot-VLA（0%）、π0.5（22.5%）。
- **TTC 进一步提升**：在 Make Milk Tea、Book Organization、Clean Room 上，TTC 分别将 SR 从 5/10→7/10、6/10→9/10、5/10→7/10，且进度全面提升；尤其 Book Organization 这种无固定执行计划的任务收益最大。
- **开环精度**：TTC 在 Make Milk Tea、Book Organization (In-Domain)、Book Organization (OOD)、Clean Room 上分别达到 72.0 / 83.0 / 74.0 / 87.0%，一致优于 Plan Once 与 Best-of-N，OOD 设置上增益最大。
- **算力-精度**：精度随测试时计算先快速增长后趋于饱和，呈典型的"saturating exponential"曲线，说明中等算力下性价比最高。
- **执行记忆价值**：在 Clean Room、Tomato and Egg Stir Fry（如加盐这种视觉变化微小的步骤）等需要跨阶段状态跟踪的任务上，记忆机制显著降低重复/遗漏。
- **本体泛化**：在 ARX AC One 与 Franka 上 τ₀-VLA 均明显优于基线（Collect Laundry SR 10/10、Tidy Makeup Table 三组合计接近满分），表明低层策略具备跨本体泛化能力。

## 7. 优点

- **思路创新**：把高层子任务生成显式建模为可扩展推理任务，并将世界模型用于"决策前"后果评估，与以往"决策后"用于重规划的工作形成区别。
- **完整的系统级贡献**：从数据收集（4 万小时）、统一动作空间、记忆自扰训练、自适应路由、异步双系统部署到真实机器人长时序评估，端到端可落地。
- **零额外标注的记忆扰动训练**：用 5 类扰动（within-subtask / transition / catch-up / rollback / error-think）训练模型修正记忆，兼顾鲁棒性与效率。
- **评测严谨**：含依赖图进度评分、LLM-as-Judge 多轮投票、in-domain 与 OOD 对照、算力-精度曲线，多角度交叉验证。
- **跨本体泛化**：40 维统一空间 + masked flow matching 让单一低层策略支持固定基座、双臂、移动全身控制三种模式。
