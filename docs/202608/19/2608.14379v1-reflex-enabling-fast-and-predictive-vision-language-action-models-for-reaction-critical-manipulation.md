## 摘要
视觉-语言-动作（VLA）模型近期在机器人操作中取得了令人瞩目的性能。然而，现有基准主要评估静态操作任务的泛化能力，在很大程度上忽视了动态交互场景。为弥补这一不足，我们提出了 ReflexBench，一个针对反应关键型操作的基准。ReflexBench 包含六个动态任务，并引入了一种将仿真器步进与机器人控制解耦的评估框架，同时支持在同步与异步推理下配置可调延迟。基于 ReflexBench，我们提出了 ReflexVLA，一种无需大规模机器人数据预训练、专为反应关键型操作设计的高效 VLA 模型。ReflexVLA 通过潜在未来预测和多帧时序融合在视觉骨干网络中增强时序推理能力，并通过批处理视觉编码和 CUDA Graph 重放降低部署延迟。实验表明，ReflexVLA 在持续提升动态操作性能的同时，在标准静态操作基准上也保持了具有竞争力的准确率，且真实世界实验进一步验证了其在实际部署条件下的有效性。项目主页：https://reflexvla.github.io

## Abstract
Vision-Language-Action (VLA) models have recently achieved promising performance in robotic manipulation. However, existing benchmarks mainly evaluate generalization on static manipulation tasks and largely overlook dynamic interaction scenarios. To address this gap, we present ReflexBench, a benchmark for reaction-critical manipulation. ReflexBench contains six dynamic tasks and introduces an evaluation framework that decouples simulator stepping from robot control while supporting configurable latency under synchronous and asynchronous inference. Building upon ReflexBench, we propose ReflexVLA, an efficient VLA model designed for reaction-critical manipulation without large-scale robot-data pretraining. ReflexVLA enhances temporal reasoning through latent future prediction and multi-frame temporal fusion within the vision backbone, while reducing deployment latency through batched visual encoding and CUDA Graph replay. Experiments show that ReflexVLA consistently improves dynamic manipulation performance while maintaining competitive accuracy on standard static manipulation benchmarks, and real-world experiments further demonstrate its effectiveness under practical deployment conditions. Project website: https://reflexvla.github.io

### ReflexBench（动态操控基准）

- **6 个反应关键型任务**：
  - 传送带抓取放置（Conveyor Belt Pick-and-Place）
  - 接球（Ball Catching）
  - 打地鼠（Whack-a-Mole）
  - 滚球拦截（Rolling Ball Interception）
  - 投球入箱（Ball Throwing）
  - 旋转插孔（Rotating Peg Insertion）
- **数据采集**：采用**基于规划的分阶段数据采集流水线**，将任务分解为子目标，并对动态物体进行未来轨迹预测；复杂交互场景下额外使用任务专属 RL 策略生成示范。
- **延迟感知评估协议**（核心创新）：
  - **解耦仿真器步进与机器人控制**，避免仿真在策略推理时"暂停"造成的失真；
  - 支持**同步推理**（sync，推理期间机器人空闲）和**异步推理**（async，推理与上一轮动作执行重叠）；
  - 引入**延迟阻塞机制**，可通过 Real-Time Factor (RTF) 将真实策略推理延迟映射到仿真时间。

### ReflexVLA（高效可预测 VLA 模型）

在 VLA-Adapter（1B）基座上引入三个核心设计：

#### A. 潜在未来预测（Latent Future Prediction）

- 思想：不直接预测未来图像（计算昂贵且关注低级纹理），而是在**冻结 DINOv3 的语义潜空间**中预测未来视觉特征。
- 实现：对未来 H 步观测编码为 $y_{t+i} = \phi_{\text{DINOv3}}(o_{t+i}) \in \mathbb{R}^{1024}$，并向多模态输入序列追加 H 个可学习的预测 token，H 与动作 chunk 大小一致。
- 损失函数：
  - 每个未来 token 的隐藏态通过 $f_{\text{pred}}$ 投影到 DINOv3 空间得到 $\hat{y}_{t+i}$；
  - 采用**掩码余弦相似度损失** $\mathcal{L}_{\text{future}}$；
  - 总损失 $\mathcal{L} = \mathcal{L}_{\text{act}} + \lambda_{\text{future}} \mathcal{L}_{\text{future}}$，权重 $\lambda_{\text{future}}=0.05$。
- 效果：开销可忽略，但鼓励模型学习与控制直接相关的场景动力学。

#### B. 多帧时序融合（Multi-Frame Temporal Fusion）

- 思路：直接在**视觉骨干中间层特征**上进行时间维度融合，**不让语言模型看到额外的历史 token**，从而避免注意力二次复杂度暴涨。
- 流程：
  1. 提取所有视图、所有帧的中间层特征 $X_{\text{mid}}$ 与最终层特征 $X_{\text{final}}$；
  2. 对每个 (视图, 空间块) 位置沿时间维度归一化、降维、加位置编码；
  3. 应用**因果多头时序注意力**（causal MHA）防止信息泄露；
  4. 将时序增量 $\Delta x$ 加回到当前帧的最终层特征上，形成融合表征。
- 优势：语言模型消费的视觉 token 数量与单帧设置相同，引入极小的语言侧开销。

#### C. 推理延迟优化（Inference Latency Optimization）

- **批量化视觉编码**：将 V×T 张图像打包成一次 ViT 前向，避免 V×T 次独立推理带来的框架调度开销；
- **CUDA Graph 重放**：将完整推理流水线（视觉编码、时序融合、多模态投影、语言模型、动作头）捕获为 CUDA Graph $\hat{a}_{t:t+H-1} = G(x_{\text{text}}, x_{\text{vision}}, x_{\text{state}})$，每次控制周期直接 replay，消除 kernel 调度与运行时派发开销；
- 不改变策略架构或学习目标，纯粹系统级优化。

## 6. 主要结论与发现

- **延迟与推理范式**：
  - 异步推理在高频下优于同步推理，但在低频下因观测-动作失配而表现更差；
  - 大 chunk + 短 action horizon + 异步推理组合在两个代表任务上均取得最佳效果。
- **ReflexVLA 在动态任务上的表现**（Table I）：
  - 平均成功率 **50.4%**，在所有方法中最高；
  - 相比基座 VLA-Adapter（30.3%）提升 20.1 个百分点；
  - 优于 7B 的 OpenVLA-OFT（36.0%）和 4B 的 π0.5（36.9%），与 4B 的 PUMA（50.2%）相当但参数仅为其 1/4。
- **静态任务上的保持能力**（Table II）：LIBERO 平均 97.2%，与 VLA-Adapter（97.3%）几乎持平，说明动态增强设计未损害通用性能。
- **消融结论**（Table III）：
  - 未来预测必须用**冻结 DINOv3 特征**作为监督目标（trainable 会带来 31.9% 的性能下降）；
  - 时序融合在**中间层特征**上做效果最好（71.7%）；
  - 延迟优化将成功率从 71.7% 进一步提升到 73.8%，同时将延迟从 125.1 ms 降到 **65.0 ms**（近一半）。
- **真实世界结论**（Table IV）：ReflexVLA 在 3 个真实任务上均优于 SmolVLA，并在大多数指标上超越或接近 PUMA。

## 7. 优点（方法与实验亮点）

- **基准设计创新**：ReflexBench 显式建模推理延迟并支持 sync/async 两种部署范式，比传统"推理时暂停仿真"的评测更贴近真实部署；
- **三设计协同**：首次在同一框架中同时优化**预测能力**（潜在未来预测）、**时序感知**（中间层时序融合）和**推理效率**（批量编码 + CUDA Graph），三者互补而非互斥；
- **冻结 DINOv3 语义目标**：避免在联合优化中监督信号漂移，是工程上非常实用的 trick；
- **时序融合放在中间层**：关键洞察——深层语义特征反而损失运动信息，这一点对其他多模态模型也有借鉴意义；
- **轻量且高效**：仅 1B 参数、65 ms 延迟即可在动态任务上击败 7B 模型，展示了系统级优化与算法设计的协同价值；
- **评估较为全面**：同时覆盖动态基准、静态基准与真实世界机器人，避免单一评估带来的偏差；
- **延迟/频率/horizon 的系统性扫描**为后续 VLA 推理范式选择提供了实用参考。

## 8. 不足与局限

- **未做大规模机器人预训练**：未来预测和时序融合仅在微调阶段引入，未在预训练阶段验证，可能限制其上限；
- **未探索更先进的推理机制**：如 RTC（Real-Time Chunking）等动作修正类方法未纳入对比；
- **数据集规模较小**：每个任务仅 200 条示范，难以充分体现模型在数据规模上的扩展性差异；
- **真实世界评估偏少**：每任务仅 20 次评估，置信区间较宽，统计结论有限；
- **延迟设置仍为近似**：通过 RTF 把真实延迟映射到仿真时间，未在仿真中直接测量真实策略耗时，可能与端到端部署存在偏差；
- **任务覆盖偏差**：6 个任务均偏向"桌面级 + 快速运动"场景，对更长时序依赖、接触丰富或多智能体动态任务未覆盖；
- **算力描述不充分**：未给出训练时长、显卡小时数、超参数搜索成本等；
- **潜在偏差风险**：基座为 VLA-Adapter，且 ReflexVLA 直接基于其微调，对其他基座的可迁移性未做验证。
