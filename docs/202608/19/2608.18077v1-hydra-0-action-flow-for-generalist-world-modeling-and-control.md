## 摘要
我们提出了 Hydra-0，一个以动作流为条件的通用世界模型，它将机器人动作表示为像素运动。这一共享视觉接口通过跨具身形态、任务、环境以及视频生成主干学习动作效应，从而实现通用世界建模与控制。我们的最佳配置相比动作条件基线，将机器人运动误差降低 90.4%，将物体运动误差降低 60.2%，同时支持零样本组合与数据高效自适应。在 RoboLab 基准上，Hydra-0 在重放成功率与参考成功率之间取得了 r=0.96 的皮尔逊相关系数。最后，我们发现了该接口的一种涌现的逆向模式：一个世界动作模型，能够从人类演示迁移而来的期望物体运动流预测兼容的机器人运动。训练好的动作头将所得潜在特征映射为可执行动作，无需任务特定的专家机器人演示数据。综上，这些结果展示了动作流作为一种共享控制接口的潜力，它能够将异构训练数据、开环策略评估与机器人控制连接起来。

## Abstract
We introduce Hydra-0, a generalist world model conditioned on action flow, which represents robot actions as pixel motion. This shared visual interface enables generalist world modeling and control by learning action consequences across embodiments, tasks, environments, and video-generation backbones. Our best configuration achieves 90.4% lower robot-motion error and 60.2% lower object-motion error than our action-conditioned baseline, while supporting zero-shot composition and data-efficient adaptation. On the RoboLab benchmark, Hydra-0 achieves a Pearson correlation of r=0.96 between replayed and reference success rates. Finally, we uncover an emergent inverse mode of this interface: a world action model that predicts compatible robot motion from desired object flow transferred from a human demonstration. A trained action head maps the resulting latent features to executable actions without requiring task-specific expert robot demonstrations. Together, these results demonstrate the potential of action flow as a shared control interface connecting heterogeneous training data, open-loop policy evaluation, and robot control.

# Hydra-0：面向通用世界建模与控制的动作流 — 论文总结

## 1. 核心问题与研究动机

- **核心问题**：如何训练一个能够跨**本体（embodiment）、任务、环境**泛化的通用机器人世界模型与策略？
- **背景与痛点**：
  - 通用机器人策略需要整合来自不同机器人形态、不同任务、不同环境的异构训练数据。
  - 传统的**离散动作表示**（如关节角度、末端位姿）难以在不同本体之间形成统一接口，导致：
    - 不同机器人数据无法在同一个模型中有效共享；
    - 世界模型对未见过的本体或场景泛化能力受限；
    - 难以利用非机器人数据（如人类演示视频）。
- **核心洞察**：将机器人动作统一表示为**像素空间的运动轨迹（pixel-level motion）**，以视觉为媒介实现跨本体的接口统一。

## 2. 方法论

### 2.1 核心思想：Action Flow（动作流）
- **定义**：将机器人动作编码为像素级的运动流（optical-flow 风格的密集运动场），而非传统的离散控制量。
- **本质**：动作流是一个**共享的视觉条件**，与图像观测处于同一表征空间。
- **优势**：不同机器人本体的动作可被投影到统一的"视觉运动"语义空间，从而打通跨本体数据壁垒。

### 2.2 关键技术细节
- **世界模型架构**：基于视频生成主干（video-generation backbone），以 action flow 作为条件输入，学习"在给定当前帧 + 动作流的情况下，未来帧如何演变"。
- **Action Head（动作头）**：一个独立训练的解码器，将世界模型产生的**潜在特征（latent features）** 映射回可执行的真实机器人动作（如关节指令）。
- **训练范式**：
  - 世界模型使用大量异构视频数据 + 对应的 action flow 进行训练；
  - 动作头仅需少量本体专属数据微调即可适配到新机器人。
- **涌现的逆向模式（Inverse Mode）**：
  - 从人类演示视频中提取**期望的物体运动流**；
  - 世界模型反向推理出**兼容的机器人运动流**；
  - 动作头将运动流解码为机器人动作；
  - **无需任务特定的专家机器人演示数据**，即可实现人类示教到机器人动作的迁移。

### 2.3 方法流程（文字描述）
1. **离线阶段**：采集多本体机器人轨迹 → 计算每帧的 action flow → 训练条件世界模型；
2. **动作解码**：训练 action head 将世界模型 latent 映射回原始动作空间；
3. **在线控制**：给定当前观测 + 期望动作流 → 世界模型预测未来 → action head 输出可执行动作；
4. **逆向泛化**：从人类演示提取物体运动流 → 反向推理机器人运动流 → 动作头解码执行。
