## 摘要
视觉-语言-动作（VLA）模型中的视觉表征在需要空间精确性的机器人操控任务上仍然不够可靠。我们发现，VLA模型中的视觉编码器同样表现出先前在通用视觉Transformer中被记录过的注意力伪影，并进一步揭示，在具身策略中，这些伪影与后训练阶段所获得的空间感知能力密切相关。随着编码器学习到与任务相关的信息——例如物体位置、深度排序和局部几何结构——受限的全局token容量使得部分此类信息溢出至低信息量的patch token中。我们提出了AtVLA框架，通过在视觉编码器中插入可学习的寄存器token来解决这一问题。仅使用具身数据并以原始动作目标进行端到端训练，这些寄存器便涌现为承载具身空间信息的专用通道，而剩余的patch token则恢复出干净且空间保真的注意力分布，这对于精确的目标定位和细粒度接触至关重要。干净的注意力可恢复可靠的定位能力，但无法挽回低分辨率观测中已丢失的几何细节。因此，AtVLA将注意力矫正与不确定性门控的局部精修相结合：动作专家对多个动作块进行采样，并依据其分歧度估计不确定性；仅对具有不确定性的预测，动作条件化的注意力展开将识别任务相关区域，对其裁剪后以更高分辨率重新编码，并附加至已缓存的前缀中以生成精修后的动作。在LIBERO、SimplerEnv以及一项具有挑战性的单视角真实世界基准上的实验表明，AtVLA将LIBERO的平均成功率从94.2%提升至98.4%，将真实世界成功率从46.5%提升至69.0%。裁剪操作仅在约30%的重规划步骤中被触发，在典型部署设置下，其总体计算量仅为基线模型的1.4至1.6倍。

## Abstract
Visual representations of VLA models remain unreliable for spatially precise robotic manipulation. We uncover that vision encoders in VLAs also exhibit attention artifacts previously documented in generic Vision Transformers, and further show that, in embodied policies, these artifacts are closely associated with spatial perception capabilities acquired during post-training. As the encoder learns task-relevant information such as object location, depth ordering, and local geometry, limited global-token capacity causes part of this information to spill into low-information patch tokens. We introduce AtVLA, a framework that inserts learnable register tokens into the visual encoder. Trained end-to-end using only embodied data and the original action objective, these registers emerge as dedicated carriers of embodied spatial information, while the remaining patch tokens recover clean and spatially faithful attention distributions crucial for precise target localization and fine-grained contact. Clean attention restores reliable localization, but cannot recover geometric details lost in low-resolution observations. AtVLA therefore couples attention rectification with uncertainty-gated local refinement. The action expert samples multiple action chunks and estimates uncertainty from their disagreement; only for uncertain predictions, action-conditioned attention rollout identifies the task-relevant region, which is cropped, re-encoded at high resolution, and appended to the cached prefix for refined action generation. Across LIBERO, SimplerEnv, and a challenging single-view real-world benchmark, AtVLA improves the average LIBERO success rate from 94.2% to 98.4% and real-world success from 46.5% to 69.0%. The cropping is triggered on approximately 30% of replanning steps, resulting in only 1.4-1.6x the total computation of the base model under the representative deployment setting.

# 论文总结：AtVLA——面向视觉-语言-动作模型的自适应视觉精修

## 1. 核心问题与研究动机

- **VLA模型视觉表征的可靠性问题**：尽管视觉-语言-动作（VLA）模型继承了大规模视觉-语言预训练的丰富语义先验，但其视觉表征在需要空间精度的机器人操控任务中仍然不可靠，无法支撑精确的目标定位与细粒度接触。
- **发现的注意力伪影（attention artifacts）**：研究者发现 VLA 中的视觉编码器同样表现出通用 Vision Transformer 中已记录的高范数伪影——背景 patch 被挪用为全局信息仓库，导致密集空间特征被扭曲，破坏了任务相关目标的空间定位。
- **具身后训练的副作用**：在 embodied post-training 过程中，编码器需学习物体位置、深度排序、实例结构和局部几何等操控相关信息，但全局 token 的容量有限，使部分任务相关空间信息溢出至低信息量的 patch token，进一步加剧了上述伪影。
- **低分辨率几何信息丢失**：即使定位正确，精确操控仍需接触区域附近的几何细节，而第三视角低分辨率观测中此类细节可能仅占少数 patch；腕部相机虽可弥补，但视角敏感且与目标的相对位置不稳定。
- **核心问题**：如何在不引入额外感知或显式 3D 表征的前提下，恢复 VLA 视觉表征的空间保真度，并在需要时提供局部高分辨率感知？

## 2. 方法论

### 2.1 整体框架
AtVLA 基于 π0 策略，在视觉编码器中引入**可学习寄存器 token（register tokens）**用于承载具身空间信息，并通过**不确定性门控的局部精修**机制按需对关键区域进行高分辨率重编码。

### 2.2 关键技术细节

- **寄存器增强的视觉前缀**：
  - 在 SigLIP 编码器（224×224，patch size 14，256 个 patch token）的 class token 后插入 N_r = 4 个 1152 维可学习寄存器嵌入。
  - 输入序列：`[CLS; r₁..r₄; p₁..p₂₅₆]`，输出 `[h_cls; R_t; P_t]`。
  - 与 Darcet 等（2023）丢弃 register 输出的做法不同，AtVLA **保留** register 输出并通过 PaliGemma 视觉投影器 Π 投射后与 patch tokens、language tokens、state tokens 一同构成多模态前缀 `C_t^b`，使寄存器成为面向下游策略的多 slot 全局上下文。
  - 多视角情况下每路独立编码并拼接。

- **不确定性门控的动作预测**：
  - LLM backbone 一次计算并缓存 KV；动作专家对同一 prefix 从独立高斯初始化采样 K = 4 条动作块（10 步 Euler 求解）。
  - 不确定性定义为前 h 个执行步、3 个平移维度的**多采样标准差均值** `U_t`。
  - 阈值 τ 在 episode-disjoint 验证集上校准，按约 30% 触发率预算挑选。
  - 当 `U_t ≤ τ`：走 confident path，直接返回均值动作块。
  - 当 `U_t > τ`：触发局部精修分支。

- **注意力引导的局部精修**：
  - **复用动作采样过程中已计算的注意力**进行 rollout：对 18 层动作专家的注意力矩阵在头维度与第 {3, 6, 9} 步去噪步上平均，加上残差后 row-normalize，逐层相乘得到 `M_roll`。
  - 取前 h 个 action token 行到 256 个 base image patch 列的 rollout 值，reshape 为 16×16 显著性图 S_t，双线性上采样后**排除 register 列**（其无固定图像栅格对应）。
  - **对比式窗口搜索**：在 {84, 112, 140} 像素的方形候选窗口中，选择内部注意力与扩大 1.25× 上下文环差值最大的窗口，并外扩 10% padding。
  - 裁剪后 resize 至 224×224，经同一带 register 的视觉编码器；**丢弃 crop 侧的 register 输出**（全局上下文已由 base register 概括），仅保留 256 个 crop patch 特征。
  - **Crop 位置编码**：`(x₁/W, y₁/H, x₂/W, y₂/H)` 经两层 MLP (4→256→d_LLM, GELU) 得到 `e_b`，加到每个 crop patch token 上以保留其在原图中的空间位置。
  - 精修后前缀 `C_t^+ = [C_t^b; Π(P_t^c) + 1_N_c e_b^T]`，**仅预取新增 crop 段，base/language/state 的 KV 缓存复用**。

- **训练目标与课程**：
  - 损失：`L = L_π0 + λ_cp L_cp + λ_ag L_ag`，其中 λ_cp=0.1，λ_ag=1.0。
  - `L_cp` 监督预测的 crop 坐标；`L_ag` 鼓励 action-to-image attention 集中在标注的任务相关区域。
  - **三阶段 post-training**：
    - Stage 0（Register Adaptation, 20K 步）：先冻结 backbone 仅训 4 个 register（4K 步），再额外解冻 SigLIP 最后 4 个 block（16K 步）。
    - Stage 1（Crop Alignment, 10K 步）：引入标注 ground-truth crop，冻结视觉编码器，仅训 crop-position MLP + LoRA(r=32)，使策略学会解读额外 crop token。
    - Stage 2（Joint Refinement, 40K 步）：三阶段 crop 课程——
      - 0~40%：全部使用 ground-truth crop；
      - 40~90%：线性过渡到 rollout crop α: 0→1，crop dropout p_drop: 0→0.3；
      - 最后 10%：全部使用 rollout crop，p_drop=0.3，与推理一致。

- **无效 rollout 处理**：saliency 图非有限、总注意力 < 10⁻⁶、坐标退化或裁剪边长 < 56 像素时跳过精修，使用 base-only 路径，训练与推理保持一致。

## 6. 主要结论与发现

- **Register 有效吸收注意力伪影**：在 SigLIP 中插入 4 个 register token 即可让 patch token 恢复出与目标对齐的干净注意力分布，且无需引入额外视觉预训练数据。
- **Register 编码丰富任务相关空间信息**：线性探针表明 register 在物体定位、深度、表面法向任务上的 probe accuracy 均 ≥ 0.70（0.85/0.88/0.82），显著高于 CLS（0.76）与空间 patch（0.60），说明 embodied 后训练获取的空间/几何信息确实转移到了 register slot。
- **Register 数量 4 为饱和点**：过少（1–3）反而因残留伪影干扰已建立的视觉-LLM 协调，导致性能低于 π0；过多不再带来收益。
- **裁剪带来细粒度与长程双重收益**：
  - 提升细粒度抓取/放置与接触点定位；
  - 在 LIBERO-Long-10 与真实世界 long-horizon 任务上同样有效，说明额外视觉上下文支持时序扩展规划。
- **裁剪质量依赖 embodied 监督**：未经过具身训练的外部 VLM 生成的 crop（π0+Cropping）常无法聚焦交互关键区域，性能略低于完整 AtVLA；但纯 register 变体在空间推理与物体定位上也很强。
- **计算开销可控**：约 30% 重规划步骤触发裁剪，总计算量 1.4–1.6×。
- **性能提升幅度**：
  - LIBERO 平均成功率 94.2% → 98.4%；
  - 真实世界成功率 46.5% → 69.0%；
  - SimplerEnv：Pick Coke Can 88.0→91.3、Move Near 80.3→81.6、Open/Close Drawer 56.0→57.5。

## 7. 优点与亮点

- **机制层面的新发现**：明确指出 VLA 视觉编码器中注意力伪影与具身后训练获得的空间表征之间的因果联系，并提出 register 作为"具身空间信息专用承载通道"的解释，配套线性探针实证。
- **优雅且轻量的工程设计**：register 仅增加 4,608 参数；不改变 π0 的动作表示、流匹配目标或部署接口；注意力 rollout 复用采样过程中的矩阵，几乎零额外成本；crop KV 不重算 base prefix。
- **不确定性门控按需精修**：避免对每步都进行高分辨率处理，用动作分歧度自适应决定"何时该仔细看"。
- **三阶段课程训练**：先单独对齐 register、再对齐 crop 格式、最后联合优化并做 crop 推理对齐训练，规避了 train–test 不一致。
- **公平对比**：使用受控 π0 变体隔离每个组件贡献，并公开标准差。
- **跨仿真+真实世界验证**：尤其在单视角真实场景下取得大幅提升，对部署友好。

## 8. 不足与局限

- **单视角设置**：仅评估单一第三视角 RealSense；未涉及腕部相机、深度相机、多视角融合或 3D 表征，对强遮挡/对称物体的鲁棒性未充分验证。
- **Embodiment 单一**：仅在 Franka 上做真实实验，SimplerEnv 也仅限 Google Robot 套件（省略 WidowX 套件），泛化到其他形态（移动机械臂、人形等）未知。
- **标注依赖**：训练阶段需要 ground-truth 任务相关区域框用于 stage 1 与 stage 2 早期阶段，影响数据准备的可负担性。
- **阈值需逐 embodiment 校准**：不确定性尺度与 action 归一化耦合，不同机器人需重新选择 τ；实际部署带来额外工程负担。
- **Crop 触发率固定 30% 的代价–收益权衡**：在 Open/Close Drawer 等大面积被柜体占据的场景中，crop 收益有限，可能触发不必要的额外开销。
- **真实实验规模较小**：每任务 20 次独立试验，置信区间较宽，统计显著性需谨慎解读；缺少多日 / 多光照 / 多扰动测试。
- **未报告训练墙钟时长与碳足迹**：仅给出步数与 GPU 型号，缺少小时数与能耗指标。
- **裁剪尺寸/分辨率受限于 SigLIP 输入分辨率**：固定 224×224 重新编码，理论上仍受限于 ViT 的最大分辨率，无法利用更长焦段的细节。
- **安全/失败恢复未讨论**：当 rollout 失效（≈边界条件）时回退到 base path，但未系统分析此类情形下策略的安全性（如抓取失败、碰撞）。
