## 摘要
视觉-语言-动作（VLA）模型在机器人操作任务中表现出色，但当规范指令仅被简单改述时，其性能会出现灾难性下降。尽管这种脆弱性通常通过代价高昂的数据扩增来缓解，但我们的探针分析揭示了根本原因在于架构层面，而非语义理解的缺失。具体而言，我们证明了当前的VLA模型能够在内部成功保留正确的任务标识。实际上的失败源于动态视觉观测与文本的联合编码，这引入了系统性的特征偏移。由于下游动作策略对这些变化高度敏感，因此无法将保留的语义转化为正确的控制指令。为解决这一结构性瓶颈，我们提出了语义重绑定（Grounded Semantic Re-binding, GSR），一项精巧的干预措施：通过将独立提取的任务语义与原生视觉特征显式融合，绕过不稳定的联合路由，从而从头训练一个完全重新初始化的动作专家。这一有针对性的干预仅借助规范演示便显著恢复了改述不变性。在LIBERO-Para基准上，GSR将成功率提升高达44.6%，使轻量级模型得以媲美大规模扩增的基线，并将最先进模型的PRIDE分数推至70.4的新纪录，在指令生成能力上超越近期推出的大规模预训练模型Xiaomi-Robotics-0。基于这些洞见，我们还推出了ParaVLA——一个原生解耦的0.33B参数模型，对指令改述展现出近乎完美的鲁棒性。归根结底，我们的工作证明了鲁棒的语义基础可通过精巧的结构设计实现，从而绕过低效的暴力数据扩增范式。

## Abstract
Vision-Language-Action (VLA) models excel in robotic manipulation but suffer catastrophic performance drops when canonical instructions are simply paraphrased. Although this brittleness is typically addressed through costly data scaling, our probing reveals that the root cause is architectural rather than a lack of semantic understanding. Specifically, we demonstrate that current VLAs successfully retain the correct task identity internally. The failure actually stems from the joint encoding of dynamic visual observations and text, which introduces systematic feature shifts. Because the downstream action policy is highly vulnerable to these variations, it fails to translate the preserved semantics into correct control commands. To resolve this structural bottleneck, we propose Grounded Semantic Re-binding (GSR), an elegant intervention that bypasses unstable joint routing by explicitly fusing independently extracted task semantics with native visual features to train a completely re-initialized action expert from scratch. This targeted intervention dramatically restores paraphrastic invariance using only canonical demonstrations. On the LIBERO-Para benchmark, GSR improves success rates by up to 44.6 percent. It enables lightweight models to rival massively scaled baselines and pushes state-of-the-art models to a new record PRIDE score of 70.4, outperforming the recently introduced large-scale pretrained model Xiaomi-Robotics-0 in instruction generation capabilities. Building on these insights, we also introduce ParaVLA, a natively decoupled 0.33B-parameter model exhibiting near-perfect robustness to instruction rewording. Ultimately, our work proves that robust semantic grounding can be achieved through elegant structural design, bypassing the inefficient brute-force data scaling paradigm.

# 论文总结：面向视觉-语言-动作模型鲁棒指令泛化的语义重绑定

## 一、核心问题与研究背景

- **关键现象**：当前的视觉-语言-动作（VLA）模型在机器人操作任务上表现优异，但在指令被简单改述（paraphrase）时性能出现灾难性下降。例如 VLA-Adapter、SmolVLA、π0.5 等模型在 LIBERO-Para 基准上最高出现 67.53% 的成功率跌落。
- **主流应对与局限**：现有方法通常依赖大规模数据扩增或语言覆盖增强来缓解此类失败，代价高昂且治标不治本。
- **作者的核心洞见（动机）**：通过探针（probing）实验，作者发现 VLA 模型实际上**在内部成功保留了正确的任务语义**，真正失败源自**架构层面**——动态视觉观测与文本的联合编码引入系统性特征漂移，导致下游动作策略难以将保留的语义转化为正确控制指令。
- **研究意义**：揭示了一个反直觉结论——指令鲁棒性问题不是"理解不够"，而是"传递路径断裂"。为从架构而非数据角度解决该问题提供了理论与实证基础。

## 二、方法论

### 1. 核心思想：Grounded Semantic Re-binding（GSR）

- **关键思路**：将指令语义独立于当前视觉观测提取（即"纯语义"），再将其注入到模型原有的多模态融合阶段，从而绕过不稳定的联合编码路径。
- **三大设计原则**：
  1. 使用**冻结的 T5-large 编码器**提取稳定的、与图像无关的纯文本语义；
  2. 保留模型**原有的视觉/状态通路**继续处理真实场景信息；
  3. **完全重新初始化**动作专家（action expert），而非微调预训练权重，使动作模块从零学习如何映射"纯语义 + 视觉"到动作。

### 2. 关键技术细节（架构感知注入）

- **针对 VLA-Adapter**：将 T5 token 投影后作为侧车 K/V 注入每个 MLPResNetBlock_Pro，并独立使用 attention softmax 与门控进行融合；Qwen 主干只接收图像与固定中性提示 "perform the task"。
- **针对 SmolVLA**：将 T5 语义注入 SmolVLM 原生语言槽位（而非绕开视觉），通过 8 头 grounding attention 让纯语义在原始多模态计算中看到场景。
- **针对 π0.5**：由于 PaliGemma 原生路径已具鲁棒性，保留其真实指令，仅将 T5 作为**补充语义信号**注入任务 token 位置。
- **通用注入准则（如图 3）**：
  - 若原生语言通路脆弱（如 VLA-Adapter、SmolVLA）→ 中性化原始文本，强制依赖 T5；
  - 若原生通路已具鲁棒性（如 π0.5）→ 保留真实指令，T5 作为补充。

### 3. ParaVLA：原生解耦架构（替代方案）

- 完全取消联合 V-L 编码：图像由冻结/微调的 **DINOv2-Large** 编码，文本由冻结 **T5-large** 编码，二者仅在动作专家内部融合。
- 参数规模仅 **0.33B**，T5 每个任务仅运行一次并缓存，无额外推理开销。
- 关键缺陷：扩展视觉模型规模时难以获得 VLM 级别的 scaling 收益。

## 六、主要结论与发现

- **核心结论**：VLA 指令改述失败的根因是**架构性的语义传递断裂**，而非数据不足或语义理解缺失。
- **方法有效性**：
  - VLA-Adapter：Full Para SR 46.82% → **70.94%**（+24.12）；
  - SmolVLA：4.47% → **49.12%**（+44.65，最大提升）；
  - π0.5：73.60% → **75.59%**，PRIDE **70.4**（刷新纪录，超过 Xiaomi-Robotics-0 的 69.2）。
- **关键探针发现**：
  - 模型在错误任务 vs. 改述的预测动作距离比（Δw/Δp）显著大于 1，说明任务身份保留；
  - 仅替换 VLA-Adapter 最终 Bridge-Attention 块的 Qwen 特征（其它不变）即可将 paired 成功率从 60% 提升至 96%；
  - 移除估计的 wording 子空间方向可将动作 gap 从 0.4361 降至 0.2282，闭环成功率 55% → 90%。
- **架构差异**：VLA-Adapter 存在单一"语义瓶颈"（最终块恢复率 96.8%）；SmolVLA 与 π0.5 任务信息分布式处理，无单点瓶颈。
- **路线冲突**：脆弱的原生编码器会"劫持"模型控制（如 W/C 条件下 VLA-Adapter 从 47.31% 跌至 5.11%）。
- **ParaVLA**：0.33B 参数实现 92% 规范 vs 91% 改述成功率，差距仅 1%，近乎完美的改述不变性。

## 七、优点与亮点

- **诊断深度**：从固定观测审计到层级激活补丁再到 wording 子空间估计，形成多层次因果证据链，论证严密。
- **架构感知的通用方法**：并非固定结构补丁，而是根据各模型原生路径可靠性决定"中性化 vs. 保留"，在 3 类代表性 VLA 上均有效。
- **极强的数据效率**：仅用规范演示训练即可大幅提升改述鲁棒性，颠覆"暴力数据扩增"范式。
- **跨尺度可迁移**：轻量模型（VLA-Adapter 0.51B）经 GSR 后媲美大规模基线；同时对已 SOTA 的 π0.5 仍有正收益（PRIDE 70.4 新纪录）。
- **因果干预证据**：仅替换一个 final block 的 Qwen 特征就使 paired 成功率 60% → 96%，为"瓶颈假设"提供强因果支持。
- **路线冲突实验**：揭示"双通路"潜在劫持风险，对实际部署有指导价值。
- **开源承诺**：代码与模型在 GitHub 公开（GSR-ParaVLA）。

## 八、不足与局限

- **实机器人验证规模偏小**：仅 6 任务、5 trials/条件，且 GSR 在 6 个任务中仅 2 个（任务 1、4）达到 100%/100%，任务 3、5、6 完全失败（0%），未能充分展示真实环境的鲁棒性。
- **π0.5 规范性能轻微下降**：标准 matched 训练下 Goal SR 从 93% 降至 91%；虽延长训练可恢复至 96%，但仍说明重初始化带来的收敛代价未完全解决。
- **ParaVLA 扩展性瓶颈**：作者承认纯解耦架构难以享受 VLM 的 scaling 收益；升级 DINO 规模时性能未提升，限制其作为通用方案的潜力。
- **T5 作为外部组件**：T5-large 与 VLA 视觉/动作头之间存在分布差异，未来需更细致的融合方案；T5 的语言偏见也可能限制开放词汇泛化。
- **训练数据局限**：仅在 LIBERO-Goal 上训练与评估，未在 LIBERO-Spatial/Object/Long 或真实世界多任务场景上验证迁移性。
- **对照不够全面**：缺少与 CAST、RoVLA、Stable Language Guidance 等近期鲁棒性方法的直接同条件对比。
- **作者未明确报告**：训练总 GPU 小时、推理延迟、能耗等部署相关指标。
- **方法对手动错误仍脆弱**：Goal-100 中 cyclic wrong-task 指令下，T5 路径失败率仍较高（C/W 条件下 SmolVLA 仅 3.23%），说明 GSR 主要解决"语义等价"而非"语义对抗"问题。
