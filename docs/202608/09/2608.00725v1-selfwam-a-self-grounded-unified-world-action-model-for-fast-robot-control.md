## 摘要
世界动作模型（World Action Models, WAMs）通过联合建模动作与未来观测来提升机器人策略学习效果。然而，仅基于任务提示和观测上下文来预测未来，可能会捕捉到的是通用的任务进展，而非执行动作所产生的特定于动作的结果。我们提出了 SelfWAM，一种基于模态专用 Transformer 混合（Mixture-of-Transformers, MoT）架构构建的统一自锚定 WAM，它能够联合预测动作、由动作条件化的未来 RGB 帧以及机器人自身掩码，从而将未来预测锚定于机器人可见的本体及其由动作引发的运动。在联合训练过程中，SelfWAM 允许未来视觉查询关注已执行动作的干净副本，使视频分支成为一个针对特定动作的结果模型，同时保持快速仅动作推理路径不变。为使视频学习聚焦于与动作相关的视觉变化，我们使用针对提示的目标函数来预测未来的机器人自身掩码，该目标函数去除了外观细节，并提供了一个时间演化与条件化动作紧密耦合的目标。干净的动作条件化与未来自身掩码监督共同作用，使未来预测能够更直接地反映执行动作如何改变机器人可见运动及周围场景。在 RoboTwin 2.0 和真实世界操作任务上的实验表明，SelfWAM 能够生成对动作更敏感的未来预测，同时保持快速策略推理，并提升策略性能。

## Abstract
World Action Models (WAMs) improve robot policy learning by jointly modeling actions and future observations. However, conditioning future prediction only on the task prompt and observation context risks capturing generic task progression rather than the action-specific consequences of the executed action. We introduce SelfWAM, a unified self-grounded WAM built on a modality-specialized Mixture-of-Transformers (MoT) architecture that jointly predicts actions, action-conditioned future RGB frames, and robot self-masks, thereby grounding future prediction in the robot's visible body and its action-induced motion. During joint training, SelfWAM allows future visual queries to attend to a clean copy of the demonstrated action, turning the video branch into an action-specific consequence model while leaving the fast action-only inference path unchanged. To focus video learning on action-relevant visual changes, we use prompt-specific objectives for future robot self-mask prediction, which removes appearance details and provides a target whose temporal evolution is tightly coupled with the conditioning action. Together, clean-action conditioning and future self-mask supervision make future predictions more directly reflect how the executed action changes the robot's visible motion and the surrounding scene. Experiments on RoboTwin 2.0 and real-world manipulation tasks show that SelfWAM produces more action-sensitive futures and preserves fast policy inference, while improving policy performance.

# SelfWAM 论文详细总结

## 一、论文的核心问题与整体含义

### 1.1 研究背景
- **世界动作模型（WAMs）的兴起**：近年研究通过联合建模动作与未来视觉观测，将预训练视频动力学先验引入策略学习，从而提升机器人视觉运动策略的性能。
- **代表方法**：Ye 等的 DreamZero、Ma 等的 DiT4DiT、LingBot-VA、ImageWAM，以及 Yuan 等的 FastWAM。其中 FastWAM 仅在训练阶段使用未来视频预测作为协同训练目标，部署时直接预测动作，实现了高效的闭环控制。

### 1.2 现有方法的核心缺陷
- **未来预测未与执行动作显式关联**：FastWAM 等方法的未来视频预测仅基于当前观测进行条件化，而未以产生该目标未来的演示动作作为条件。
- **后果**：辅助目标并未显式要求模型区分不同动作所产生的视觉后果，导致视频分支学到的是通用任务进展，而非"动作—后果"映射。
- **RGB 预测的次要问题**：仅靠 RGB 预测无法将视觉目标导向最具动作相关性的变化，物体外观、纹理、光照与背景变化容易主导学习目标，而与机器人动作仅弱相关。

### 1.3 论文的研究目标
- 设计一个统一的**自锚定（self-grounded）动作条件化 WAM**：
  - 显式建模机器人可见本体及其由动作引发的运动；
  - 让未来预测直接反映"执行动作如何改变机器人可见运动与场景"；
  - 在不牺牲策略性能的前提下，保留 FastWAM 式的快速仅动作推理路径。

## 二、论文提出的方法论

### 2.1 核心思想
- 基于 FastWAM 的两流 Mixture-of-Transformers（MoT）架构，扩展出一条**干净动作副本（clean action copy）**的条件化通路，使未来视频查询可关注演示动作。
- 额外引入**未来机器人自掩码预测**作为辅助目标，去除外观与背景变化，将视觉监督聚焦于机器人可见运动。
- 通过**非对称信息流**（asymmetric information flow）防止目标泄漏：干净动作仅暴露给未来视频查询，不暴露给含噪动作预测查询。

### 2.2 架构设计
- **两流 MoT 结构**：
  - **视频流**：使用预训练的视频扩散主干（WAN2.2-5B）联合处理当前观测编码与含噪未来视频潜变量。
  - **动作流**：使用轻量级动作专家处理含噪未来动作 token；动作专家的参数通过对视频专家对应权重进行一维线性插值初始化。
  - **混合注意力（mixed attention）**控制不同 token 组之间的信息交换；注意力之后 token 返回各自模态流继续处理。
- **共享特征**：语言与本体感知特征同时条件化两个流。

### 2.3 关键信息流（有向注意力）
- 定义 token 组：
  - $O$：当前上下文 token；
  - $\hat{A}$：含噪未来动作 token；
  - $A$：干净动作 token；
  - $\hat{V}$：含噪未来视觉 token。
- **有向注意力规则**：
  - $Q_{\hat{A}} \to \{O, \hat{A}\}$（含噪动作查询只能看到当前上下文与含噪自身）；
  - $Q_{\hat{V}} \to \{O, \hat{V}, A\}$（未来视觉查询可看到当前上下文、含噪自身、干净动作副本）；
  - $Q_{A} \to \{O, A\}$（干净动作 token 可看到当前上下文与自身）。
- **效果**：未来视频预测与演示动作显式绑定；策略无法从干净动作副本或未来视频中恢复目标；策略侧计算图与"仅动作部署"完全一致。

### 2.4 干净动作副本的实现
- 标准动作流接收被加噪的未来动作 chunk 并学习去噪。
- 同一动作 chunk 创建第二份作为**干净条件流**：不被加噪，使用相同的动作分词器与动作块编码，分配干净去噪时间步 $t=0$。
- 两个流共享动作语义与时间对齐；时间步嵌入区分"干净条件"与"去噪状态"。

### 2.5 机器人自掩码预测
- 同一视频主干同时用于 RGB 预测与机器人自掩码预测。
- 每个演示生成两个世界模型训练实例：
  - **RGB 实例**：当前 RGB 观测 + 未来 RGB clip；含动作监督。
  - **自掩码实例**：相同当前 RGB + 对齐的机器人分割 clip；不含动作监督，仅以干净动作为条件。
- 自掩码实例的提示词为 "A robot-arm mask video recorded from a robot's point of view executing the following instruction: <task>"。
- 两种实例共享相同的时空 token 布局、噪声调度、位置编码与有向注意力模式，仅提示词与未来目标不同。

### 2.6 训练与部署目标函数
- 总体损失：
  $$L = \lambda_{\text{act}} L_{\text{act}} + \lambda_{\text{video}} L_{\text{rgb/mask}}$$
  其中 $L_{\text{act}}$ 为动作去噪损失，$L_{\text{rgb}}$ 与 $L_{\text{mask}}$ 分别为 RGB 与自掩码视频去噪损失，$L_{\text{rgb/mask}}$ 为二者混合期望。
- 动作损失对每个策略训练样本计算一次；掩码提示副本仅贡献 $L_{\text{mask}}$。
- **部署路径**：仅编码当前上下文，用轻量级动作专家去噪得到动作 chunk；不实例化干净动作与未来视觉 token。
- **可选诊断**：候选动作可插入干净动作槽位，由输出提示选择 RGB 或自掩码生成。

### 3.3 对比方法

## 六、论文的主要结论与发现

### 6.1 策略性能
- **RoboTwin 2.0**：SelfWAM 在 clean（92.16%）、random（93.08%）与平均（92.62%）三项上均略优于 FastWAM（91.82/91.86/91.84），改进在 random 设置下更明显，提示自锚定监督有助于提升对外观变化的鲁棒性。
- **真实机器人**：4 任务平均成功率 95%，优于 FastWAM（85%）和 π0.5（90%），且在 4 个任务上至少与最佳基线相当。

### 6.2 未来预测保真度
- 在 275 条轨迹上，相比无动作条件的 FastWAM，SelfWAM 将 LPIPS 从 0.0636 降至 0.0429，PSNR 从 29.24 升至 32.79，FVD-I3D 从 45.92 降至 34.55——感知相似度、像素级保真度、视频分布质量均提升。

### 6.3 动作敏感性
- WorldArena Action Following：SelfWAM 0.0184 vs. FastWAM 0.0000（动作条件化带来几乎全部提升）；self-mask 监督进一步略升至 0.0184（与 w/o self-mask 几乎相同）。
- 主体、背景一致性同步提升；光度一致性略降。
- 方向性扰动：基线几乎不变，SelfWAM 沿指令方向移动预测自掩码，与真值趋势一致。
- 连续插值：从 hold 到演示动作，SelfWAM 渐进过渡到演示动作结果。

### 6.4 消融结论
- 仅加入动作条件 RGB 预测：策略性能（90.80/90.80）与 FastWAM 接近，提示修改信息流不严重干扰动作学习。
- 进一步加入未来自掩码监督：提升至 92.16/93.08——自掩码提供更聚焦于本体的训练信号，更有利策略。

### 6.5 推理效率
- 仅动作推理延迟 +0.97%（323.9 ms vs. 320.7 ms）；
- 动作 + 视频推理延迟 +1.36%（677.5 ms vs. 668.4 ms）；
- 峰值显存 13.959 GiB，与 FastWAM 完全一致。

### 6.6 路径一致性
- Clean 与 noisy 动作路径在 $\sigma=0$ 下逐层 NRMSE $\le 1\times 10^{-5}$，余弦距离 $\le 6\times 10^{-11}$，无任何层出现突变——干净动作可被视为去噪路径的零噪声端点。

---

## 七、优点

- **统一架构而非多模块拼装**：在单一 MoT 内联合建模动作、动作条件 RGB 与自掩码，避免引入独立的额外专家；自掩码预测被视为视频模型的"第二输出域"，保持架构简洁。
- **非对称信息流设计精巧**：干净动作副本只对未来视觉查询可见，干净动作 token 仅看自身与当前上下文；既保证未来预测被动作条件化，又彻底防止目标泄漏到策略侧，部署路径与训练路径严格一致。
- **自掩码目标的引入有充分动机**：去除外观/背景变化，使视觉信号的时间演化被强制与条件动作对齐，弥补 RGB 预测容易被纹理/光照"淹没"的缺陷；同时把监督焦点从场景拉回机器人本体。
- **"训练—部署"开销解耦**：自锚定全部体现在训练阶段的目标函数中，部署仍为轻量级动作专家；额外算力代价极低（<1.4% 延迟、零显存增长）。
- **实验多维度、可视化与定量并重**：不仅报成功率，还通过方向扰动、连续插值、WorldArena 指标、路径一致性等多角度验证"动作条件化"与"自锚定"各自的有效性。
- **真实性评估完整**：在仿真 + 真实双臂机器人上分别评估，且真实机器人数据集规模可观（约 950 万 transitions），并给出真实机器人自掩码的离线生成方案（RobotSeg），具备较强可复现性。
- **附录资料详尽**：提供了实现细节、任务级仿真结果、WorldArena 指标说明、动作敏感性诊断、clean/noisy 路径一致性分析、限制说明等。

## 八、不足与局限

- **真实机器人实验规模偏小**：仅 4 个 pick-and-place 任务、每任务 10 次试验，未涵盖接触丰富、铰接物体、遮挡严重等更具挑战的场景，统计置信度有限。
- **仿真改进幅度有限**：RoboTwin 2.0 平均成功率仅提升约 0.78 个百分点，且附录承认并非所有任务都受益，优势集中于少数任务（Open Microwave、Hanging Mug、Handover Block、Place Mouse Pad），泛化性说服力受限。
- **基线选择不完整**：真实机器人评估只对比 FastWAM 与 π0.5，缺少 π0、Motus、GigaWorld-Policy 等基线。
- **未来视频评估同分布**：使用与训练同分布的 1% 子集评估 LPIPS/PSNR/FVD，未做"未见过动作/场景"的真正泛化测试；论文自身也承认"不应解释为对未见过视频的泛化测试"。
- **部分指标反向**：完整 SelfWAM 的 Photometric Raw Consistency 反而略低于去自掩码版本（1.4361 vs. 1.5168），但论文未对此现象深入分析。
- **应用范围受限**：
  - 不显式建模接触、力及遮挡下的相互作用；
  - 依赖外部自掩码生成器（RobotSeg）产生训练目标，引入额外的标注成本与误差风险；
  - 自掩码实例采样比仅为 9:1，自锚定信号的相对权重受到人为调参影响；
  - 仅在 14 维关节控制 + 固定双臂 ALOHA 平台上验证，向其他本体（移动底盘、灵巧手、人形）迁移的可行性未验证。
- **方法动机以"消融—提升"为主**：缺少失败案例的可视化分析，难以判断 SelfWAM 在哪些典型失败模式下优于/劣于基线。
- **算力门槛高**：需要 64 张 A800 训练约 30 小时，对学术资源受限的研究者不友好；未讨论减少训练数据量或 backbone 规模下的性能保持情况。
