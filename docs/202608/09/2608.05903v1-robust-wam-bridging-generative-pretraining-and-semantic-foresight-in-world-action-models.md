## 摘要
主流的世界-动作模型（World-Action Models, WAMs）通过将预训练的 video generation models（VGMs）适配于机器人控制任务，利用其学习到的动力学先验来预测动作。这些 VGMs 通常在 variational autoencoder（VAE）latent space 中进行训练。然而，VAE latent space 优化目标是像素重建，这倾向于保留精细的外观细节，导致动作预测在视觉偏移下变得脆弱。近期研究尝试在 semantic latent space 中构建 WAMs，这类模型对外观偏移具有更强的鲁棒性，但无法利用仅存在于 VAE latent space 中的大规模 VGM 预训练。为解决这一困境，我们提出 Robust-WAM，一种面向基于 video generation 的 WAMs 的通用 post-training 方法，在保留基于 VAE 的生成路径的同时，在动作流上引入一个轻量级的语义前瞻对齐目标。该方法既保留了大规 VGM 预训练的优势，又将动作建立在对外观变化不敏感的动力学之上，从而在光照变化及其他视觉分布外条件下依然可靠。具体而言，我们采用可学习的 query tokens，通过将其输出的隐藏状态与来自真实未来帧的语义前瞻对齐，把未来场景的语义信息引入动作流。为建立每个 query 与其所描述的未来步骤之间的时间对应关系，我们为其赋予匹配 action tokens 的 positional encoding。在分布外泛化仿真基准以及真实机器人平台上的实验表明，我们的 Robust-WAM 在多个 WAM 基线上稳定提升成功率，且不会牺牲分布内性能。

## Abstract
Mainstream World-Action Models (WAMs) adapt pretrained video generation models (VGMs) for robot control, transferring their learned dynamics prior for action prediction. These VGMs are typically trained in a variational autoencoder (VAE) latent space. However, the VAE latent space is optimized for pixel reconstruction, which rewards fine appearance detail and leaves the action prediction fragile under visual shifts. Recent works build WAMs in semantic latent space, which are more robust to appearance shifts. However, these models cannot leverage the large-scale VGM pretraining that exists only in VAE space. To overcome this dilemma, we propose Robust-WAM, a general post-training method for video-generation-based WAMs that preserves the VAE-based generative path and adds a lightweight semantic foresight alignment objective on the action stream. This retains the large-scale VGM pretraining while grounding actions in appearance-invariant dynamics that stay reliable under illumination shifts and other visual out-of-distribution conditions. Specifically, we employ learnable query tokens to bring future-scene semantics into the action stream by aligning their output hidden states with the semantic foresight of future ground-truth frames. To establish the temporal correspondence between each query and the future step it describes, we give it the positional encoding of the matching action tokens. Experiments on out-of-distribution generalization simulation benchmarks and a real-robot setup show that our Robust-WAM consistently improves the success rates of multiple WAM baselines without sacrificing in-distribution performance.

# Robust-WAM 论文总结

## 1. 核心问题与研究动机

- **主流范式**：World-Action Models（WAMs）通过将预训练 Video Generation Models（VGMs）适配于机器人控制，复用其从 web-scale 视频中学到的动力学先验来预测动作。
- **关键矛盾**：VGMs 通常在 VAE latent space 中训练，目标是像素重建，因此潜空间保留了大量与纹理、光照相关的外观信息，而对控制无关紧要。
- **导致的问题**：动作预测继承外观偏差，在光照、色调等视觉分布外（OOD）条件下变得脆弱。
- **替代方案及其代价**：近期方法（如 LDA-1B）改用 DINO / V-JEPA 等 semantic latent space，对外观偏移更鲁棒，但放弃了大规模 VGM 预训练积累的强动力学先验，需要从零重新训练。
- **核心权衡**：VAE-WAMs（动力学先验强 ↔ 外观鲁棒性弱）vs Semantic-WAMs（外观鲁棒 ↔ 动力学先验弱），二者难以兼得。

## 2. 方法论

### 2.1 核心思想
- 提出一种 **通用 post-training 方法**：保留原 WAM 的 VAE 视频生成路径，仅在动作流上额外加入轻量的"语义前瞻对齐"目标。
- 不替换潜空间，而是直接纠正动作表征中的外观偏差。

### 2.2 关键技术细节
- **Per-Frame Semantic Query Tokens**：
  - 在 action DiT 的 noised action tokens 前添加 K 个可学习 query tokens `q ∈ R^{K×d}`。
  - 每个 query 对应一个未来帧和一个相机视角。
  - 每个 query 复用其对应动作 token 的位置编码 `Φ(q_n, τ⌈n/C⌉)`，建立 query 与未来时间步的时序对应。
- **Semantic Foresight Targets**：
  - 目标为**冻结的 DINOv3 ViT-B/16 CLS embedding**（d_z = 768），离线提取。
  - CLS 表征场景内容（物体、空间布局），对纹理与光照不敏感。
- **Alignment Objective**：
  - 通过线性头 `g: R^d → R^{d_z}` 将 query 输出映射到目标空间，使用逐 query 余弦对齐损失：

    $$L_{\text{align}} = \frac{1}{K}\sum_{k=1}^{K}\Big(1 - \cos\big(g(\bar{h}_k),\, z_k^*\big)\Big)$$

  - 总损失：`L = L_WAM + λ_align · L_align`，其中 `λ_align = 0.1`。
- **训练-推理差异**：训练时使用 DINOv3 教师与对齐头 `g`；推理时丢弃二者，仅保留 K 个 query tokens，因此不增加推理时输入。
- **架构适配**：
  - **Action-Expert WAMs**（如 GE-Act、FastWAM、Motus）：query 直接插入专家 token 序列，参与自注意与对视频塔的交叉注意。
  - **Unified WAMs**（如 LingBot-VA）：query 插入动作段，分配相同的 sequence/frame/noise ID，继承 flex-attention 掩码规则。

## 3. 实验设计

  - LIBERO-Plus 覆盖 7 个扰动轴：相机视角、光照、背景纹理、布局、机器人初始状态、传感器噪声、语言。

## 6. 主要结论与发现

- **OOD 鲁棒性显著提升且不损失 InD 性能**：

- **思路新颖且简洁**：不替换潜空间，仅在动作流注入语义监督，避免破坏大规模 VGM 预训练。
- **即插即用**：对 MoT 与 unified 两种 WAM 架构均适用，无需重训视频生成部分。
- **零推理开销**：教师与对齐头仅训练时使用，部署时仅增加 K 个 query tokens。
- **实验覆盖广**：仿真+真实机器人，多架构、多基线，含 per-axis 细粒度分析与完整消融。
- **有效性证据强**：跨多种 WAM、多个基准、真实环境均稳定提升；最大提升出现在外观/光照/噪声等核心场景。
- **与现有工作的清晰区分**：相对 FLARE / FRAPPE / FutureVLA 等 future representation alignment 方法，强调了"在预训练 WAM 内部"和"显式时序耦合 query 与未来步"两点差异。
