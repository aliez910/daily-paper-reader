## 摘要
可供性引导的模仿学习通过将视觉感知压缩为任务特定的几何约束（例如固定的接触点），已在机器人操作任务中展现出优异性能。然而，常用的静态可供性在对精度要求较高的任务中，或当物体位置发生扰动时，可能变得不一致，从而导致接触后轨迹漂移。为解决这一问题，我们提出了 AffordTrajDP，一个动态框架，它通过以物体为中心的时间传播构建可供性轨迹，以指导渐进式操作过程。具体而言，给定 RGB-D 观测，我们的核心洞见是：检索到的锚点可供性（捕捉了末端执行器与目标物体之间期望的接触点）可以利用物体的 SE(3) 位姿作为自然的传播媒介，通过可供性传播向未来时间步进行传播，从而得到一条可在整个执行过程中提供时间一致、状态感知的引导的可供性轨迹。AffordTrajDP 在 ManiSkill3 上取得了 70.0% 的平均成功率，较强基线方法提升高达 17.8%。在 Galaxea A1 和 UR7e 机械臂上进行的真实世界实验涵盖了 StackCube、PickCup、AdapterInsertion、Ring-on-Peg、Put-in-Bowl 和 USB Insertion 等任务，进一步验证了该方法在物体放置变化和外观变化下的鲁棒性；针对 Galaxea A1 评估了已见和未见物体实例，并通过消融实验验证了各提出组件的贡献。

## Abstract
Affordance-guided imitation learning has shown impressive performance in robotic manipulation tasks by compressing visual perception into task-specific geometric constraints (e.g., fixed contact points). However, the commonly used static affordances can become inconsistent in precision-critical tasks or under object location perturbations, leading to post-contact trajectory drift. To address this issue, we propose AffordTrajDP, a dynamic framework that constructs affordance trajectories via object-centric temporal propagation to guide the progressive manipulation process. Specifically, given an RGB-D observation, our core insight is that a retrieved anchor affordance, which captures the desired contact point between the end-effector and the target object, can be propagated forward via affordance propagation, using the object's SE(3) pose as a natural propagation medium, to yield an affordance trajectory that provides temporally consistent, state-aware guidance throughout execution. AffordTrajDP achieves 70.0% average success rate on ManiSkill3, outperforming strong baselines by up to 17.8%. Real-world experiments on Galaxea A1 and UR7e robotic arms, covering StackCube, PickCup, AdapterInsertion, Ring-on-Peg, Put-in-Bowl, and USB Insertion, further validate robustness under object placement variations and appearance changes, with seen and unseen object instances evaluated on Galaxea A1, and ablations confirm the contribution of each proposed component.

# AffordTrajDP 论文总结

## 1. 核心问题与研究动机

- **问题定位**：基于扩散模型的视觉运动策略（visuomotor policy）严重依赖稠密视觉观测，对物体外观、背景、视角变化等环境扰动敏感，泛化能力受限。
- **既有改进路线**：物体中心（object-centric）表征（如 6D 位姿、3D 点流）通过结构化中间表示提升鲁棒性，但已有效可供性（affordance）方法大多将可供性视为**静态先验**（固定接触点、键帧、典型参考系）。
- **核心缺陷**：
  - 静态可供性在精度关键型任务（如插孔、轴孔装配）中，接触后无法跟随物体姿态变化，导致轨迹漂移、振荡或失败；
  - 现有条件信号存在"半截子"问题——要么保留"在哪接触"的语义（AffordDP），要么保留"接触如何随时间演化"的位姿轨迹（PRISM-DP、SPOT），**缺少同时保有两者**的信号。
- **本文诊断**：精接触失败的根因不是单一信号不足，而是缺乏"同时保持接触语义与时间演化"的联合条件信号。

## 2. 方法论

### 2.1 整体框架
AffordTrajDP 通过"以物体 SE(3) 位姿为传播媒介"，将一个静态锚点接触点沿预测的未来位姿轨迹前向传播，得到**时变、状态一致的可供性轨迹** Φ = (c, τ)，并以此条件化下游 DDIM 扩散策略。

### 2.2 关键技术模块

- **锚点可供性生成（Anchor Affordance Generation）**
  - 用 GroundedSAM 裁剪目标物体区域，CLIP 图像编码器提取外观嵌入 z，任务标签 ℓ 共同组成记忆 M = {(ℓ, c, z, T)}；
  - 测试时按任务内余弦相似度检索最相似源实例；
  - 通过稠密视觉对应把源接触点反投影到目标 RGB-D，得到目标锚点 c_tgt ∈ ℝ³。

- **动态可供性传播（Dynamic Affordance Propagation）**
  - 训练数据来源：FoundationPose 跟踪示教中的 6D 位姿轨迹 T(t) ∈ SE(3)，并将其转换为目标物体坐标系下的相对轨迹（T_tgt^W⁻¹ · T_src^W），使轨迹布局无关；
  - 训练目标：基于 DDIM 的扩散模型预测 SE(3) 未来轨迹，参数化为 [t; q] ∈ ℝ⁷（每步归一化为单位四元数），条件为姿态历史 h_t；
  - 传播公式：用预测的 {T_{t+k}} 将齐次锚点 \tilde c 通过刚性变换 p_{t+k} = T_{t+k} · \tilde c 得到 τ_t:t+H，构成可供性轨迹。

- **动作生成（Action Generation）**
  - 静态 c 用轻量 MLP 编码，动态 τ 用前置 [CLS] 的 Transformer 编码器得到 64 维特征；
  - 与点云、位姿等观测一起形成条件特征 f_t；
  - 动作策略采用 1D 条件 U-Net + FiLM，16 步动作序列、滚动 8 步、控制频率 10 Hz，DDIM 采样 K=10 步。

### 2.3 设计选择
- 使用 DDIM 而非 DDPM，保证反向过程确定性，避免随机扰动累积到可供性轨迹；
- 未来位姿预测用 H=4，与传播出的可供性轨迹长度一致，便于时序对齐。

## 6. 主要结论与发现

- **仿真**：在 6 任务上平均成功率 70.0%，相比 DP3（52.2%）、AffordDP（57.8%）、SPOT（62.1%）提升 7.9–17.8 个百分点；
- **精度任务收益最大**：PlugCharger 从 11.3% 提升到 24.7%，PegInsertion 从 23.3% 提升到 46.0%；
- **真实平台**：Galaxea A1 平均成功率 66.1%（DP3 为 35.0%）；UR7e 平均 72.5%（DP3 为 40.8%）；
- **消融**：
  - 接触点单独使用：47.2%，优于基线 35.0%，但远低于完整方法 66.1%；
  - 仅轨迹传播（无语义锚点）：在 StackCube unseen 上反而退化（20% vs. 40%），证明语义锚点不可缺；
  - 中心点 vs. 接触点：在 unseen 实例上接触点优势更明显（语义定位有效）；
- **姿态预测误差行为**：在 GT 历史下误差随预测步 k 近似线性增长（H=4 时约 1.89 mm / 0.25°）；在 episode 时间轴上误差近似平稳，旋转误差在接触事件附近出现瞬时尖峰但不累积漂移；
- **结论**：语义接触和位姿轨迹传播**互为必要、彼此不充分**，是同时保有"where"和"how"的最小完备组合。

## 7. 优点与亮点

- **问题诊断新颖**：明确指出静态可供性先验的失效模式与"半信号"瓶颈，并给出可证伪的诊断论断；
- **架构简洁**：检索 → 传播 → 条件化的三阶段流水线，组件职责清晰，可与现有 DP3 主干即插即用；
- **评估维度广**：仿真+真实、双机械臂平台、seen/unseen 实例、精度梯度任务、消融与误差分析齐备；
- **工程细致**：使用 DDIM 保证可供性轨迹生成稳定；以物体坐标系表达位姿提升跨实例泛化；静态 c 与动态 τ 分用 MLP 与 Transformer 编码；
- **诚实报告负面结果**：明确指出 DP3+Traj 在 StackCube unseen 上反而退化，USB Insertion 仍是 sub-mm 精度瓶颈，不掩盖局限。

## 8. 不足与局限

- **算力与可复现性信息缺失**：未报告 GPU 型号/数量/训练时长；
- **误差因果分析不充分**：per-episode-step 误差图为相关性的双曲线，未做受控噪声注入消泡，难以断言"不累积"是预测器特性还是跟踪误差主导；
- **未见实例与精度任务仍有缺口**：AdapterInsertion unseen 仅 6/30；USB Insertion 全任务仅 11/30；
- **依赖外部姿态跟踪器**：方法的有效性受 FoundationPose 跟踪误差制约，在遮挡/快速运动下可能失效；位姿质量上限未做严格测试；
- **可供性表示较为几何化**：仅编码接触点轨迹，未涉及力/触觉或多接触语义，对丰富接触类型（铰接、装配卡扣）外推性未知；
- **任务与物体多样性受限**：真实任务集中于桌面抓取/插孔，缺少杂乱场景、铰接体、可形变物体的验证；
- **检索范式假设**：依赖记忆库中存在"同任务、相似外观"的源实例，零样本全新类别能力受限；
- **基线覆盖**：未与 Equibot、3D Diffuser Actor、GenDP 等近期 3D 表征强化方法对比，"最强基线"的措辞略强；
- **安全与可靠性维度缺失**：未讨论失败模式分类、异常恢复、置信度估计等实际部署关键指标。
