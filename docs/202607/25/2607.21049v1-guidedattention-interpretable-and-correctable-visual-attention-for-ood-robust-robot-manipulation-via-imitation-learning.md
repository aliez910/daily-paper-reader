## 摘要
端到端的视觉运动策略几乎不提供让人类理解或纠正其视觉注意力的机会。我们提出了GuidedAttention，一种视觉运动模仿学习框架，将可解释且可纠正的视觉注意力作为一种显式的中间表示。任务相关的注意力关键点由相机图像预测得到，并作为条件输入到基于扩散模型的动作策略中。用户可在执行初始化时检查并可选地纠正所选关键点，随后由跟踪模块将纠正后的注意力自动传播至整个执行过程。仿真和真实世界中的实验表明，GuidedAttention能够持续提升机器人操控性能，尤其是在位置与外观分布外（OOD）条件下。

## Abstract
End-to-end visuomotor policies provide little opportunity for humans to understand or correct the policy's visual attention. We propose GuidedAttention, a visuomotor imitation learning framework that introduces interpretable and correctable visual attention as an explicit intermediate representation. Task-relevant attention keypoints are predicted from camera images and condition a diffusion-based action policy. Users can inspect and optionally correct selected keypoints once at rollout initialization, after which the corrected attention is automatically propagated throughout execution by a tracking module. Experiments in simulation and the real world demonstrate that GuidedAttention consistently improves robot manipulation performance, particularly under positional and appearance out-of-distribution (OOD) conditions.

# GuidedAttention 论文总结

## 1. 核心问题与研究背景

- **核心问题**：端到端视觉运动（visuomotor）模仿学习策略虽然在分布内（ID）条件下性能优异，但其视觉注意力机制对用户而言是"黑盒"，既**无法解释**（用户看不到策略在看哪里），也**无法纠正**（用户无法在运行时提供任务相关线索）。
- **痛点**：在分布外（OOD）条件下——特别是**位置 OOD**（目标物体位置超出训练分布）和**外观 OOD**（背景、纹理、色彩干扰）——策略容易"分心"，将注意力漂移到任务无关区域，导致操作失败。
- **研究意义**：为模仿学习策略引入一种"可解释 + 可纠正"的视觉注意力中间表示，弥合"端到端学习"与"人机协作"之间的鸿沟。

## 2. 方法论

### 2.1 整体架构（DP-GA）
- 将策略拆解为 **感知（关键点预测）→ 注意力特征 → 动作生成（扩散策略）** 三阶段。
- 输入：多视角 RGB 图像 + 关节本体感知（proprioception）。
- 输出：机器人动作（通过基于 U-Net 的 CNN 去噪扩散策略生成）。

### 2.2 视觉注意力编码器（AttnEnc）
- 采用 **DETR 风格的 Transformer encoder-decoder** 结构：
  - 骨干网络：ResNet-18 → patch features。
  - Transformer encoder：加入位置编码。
  - Decoder：使用一组**可学习 query**（数量 = 预设关键点数 $N_k$）。
  - 每个 query 输出一个 $d_f$ 维的注意力特征 $f_i$，再经线性映射 $h_\theta(\cdot)$ 得到 2D 关键点坐标：
    $$p_i = h_\theta(f_i) = A f_i + b$$
- 两种条件化变体：
  - **DP-GA (default)**：将注意力特征 $f_i$ 作为扩散策略条件输入；
  - **DP-GA (coord-as-feat)**：将 2D 坐标 $p_i$ 本身作为条件输入。

### 2.3 关键点损失与训练
- **关键点 MSE 损失**：
  $$L_{kp} = \frac{1}{N_k}\sum_i \| p_i - p_i^{gt} \|_2^2$$
- 关键点标注仅在每段示教的**首帧**进行，后续帧通过 **Co-Tracker** 自动跟踪传播。
- 静态关键点（如目标极点）在整段轨迹中保持固定。

### 2.4 关键点 Override 机制（关键创新）
- 用户可在**执行初始帧**对任意子集关键点进行点击纠正（支持部分纠正、部分视角纠正）。
- 纠正后的坐标 $p_i^{gt}$ 通过**解析逆映射**还原为特征空间：
  $$h_\theta^{-1}(p_i) = A^+(p_i - b)$$
  其中 $A^+$ 为 Moore-Penrose 伪逆，与正向映射共享参数。
- 为保证"预测路径"与"override 路径"特征对齐，引入三种技术：
  1. **前向-逆向权重共享**：复用同一线性映射；
  2. **特征空间对齐损失**：
     $$L_{feat} = \frac{1}{N_k}\sum_i \| f_i - h_\theta^{-1}(p_i^{gt}) \|_2$$
  3. **随机特征路由（Randomized feature routing）**：训练时随机选择每个关键点走"预测路径"或"override 路径"，避免扩散模型偏向单一通路。

### 2.5 执行时流程
1. 策略前向预测所有关键点；
2. 用户可选择在第一帧进行一次性纠正（可选）；
3. 通过 Co-Tracker 将关键点传播至整个回合；
4. 静态关键点保持固定，每帧将关键点特征送入扩散策略生成动作。

## 3. 实验设计

### 3.1 仿真环境（MuJoCo）
- **平台**：UR5e 机械臂 + 平行夹爪 + 单目 RGB 相机（固定对角俯视）。
- **3 个任务**（图 3）：
  - **Cable**：抓握柔性电缆并穿过两杆之间窄缝（2 个关键点）；
  - **Ring**：将柔性环套在杆上（2 个关键点）；
  - **Particle**：用勺子将颗粒物从源盒转移到目标盒（2 个关键点）。
- **数据集**：每个任务 30 条遥操作示教（每种 ID 目标位置 15 条）。
- **评估条件**：ID、位置 OOD、外观 OOD（桌面上叠加彩色方块干扰）、位置+外观复合 OOD。
- **基线方法**：
  - **DP**：基于 CNN 全局特征的 Diffusion Policy；
  - **ACT**：Action Chunking Transformer；
  - **DP-GA（default / coord-as-feat）**（本文方法）；
  - **MOP-Box / MOP-Point**：直接在图像上叠加边界框/点标记的视觉提示方法。

### 3.2 真实机器人实验

## 6. 主要结论与发现

- **自主执行**：DP-GA 在 ID 条件下较 DP 提升约 15 pp，在多数 OOD 条件下提升约 10 pp。
- **人类修正增益**：在执行初始帧一次性 override 后，DP-GA 在位置/外观 OOD 上较自主执行再提升 15–30 pp，较 DP 基线提升 20–30 pp（仿真）和 20–40 pp（实物）。
- **关键消融结论**：
  - **特征路由**对 override 路径的有效利用至关重要（去除后修正时性能暴跌 ~60 pp）；
  - **注意力监督**是分布内/外鲁棒性的必要条件（去除后性能下降 30–65 pp）。
- **行为特征**：
  - 在中度噪声（≤8 像素）下策略鲁棒；
  - 仅需 2 个任务相关关键点即可获得高性能；
  - 相机视角选择比相机数量更重要（遮挡严重的左侧视角反而降低性能）。

## 7. 优点 / 亮点

- **核心创新**：将"视觉注意力"从隐式特征提升为**显式、可解释、可交互**的中间表示，填补了端到端模仿学习与人机协作之间的接口空白。
- **极低交互成本**：用户仅需在执行初始帧点击几次（甚至可只纠正部分关键点或部分相机），无需持续遥操作或画草图。
- **鲁棒性显著**：在位置与外观双重 OOD 下表现优异，是少有的同时提升 ID 与 OOD 的方法。
- **工程友好**：
  - 训练标注仅需首帧单击；
  - 静态关键点策略降低跟踪负担；
  - 可与未来更优的跟踪模块即插即用；
- **实验体系完整**：仿真+实物、自主导航+修正、组件消融+参数敏感性分析齐全，并开放 RoboManipBaselines 框架。

## 8. 不足与局限

- **方法层面**：
  - **关键点预设依赖**：每任务需人工指定关键点数量与语义，复杂任务中"少量关键点 = 全部任务信息"的假设未必成立；
  - **2D 表示限制**：完全基于 2D 图像坐标，未显式建模深度与遮挡，关键点不可见时性能可能下降；
  - **跟踪模块依赖**：依赖 Co-Tracker 跟踪质量，**严重形变或长时间遮挡**场景下可能出现跟踪失败（作者已自承）；
  - **类别 OOD 未覆盖**：仅评估了位置与外观 OOD，**未见物体类别（category OOD）**未做实验；
  - **override 触发时机固定**：仅限"执行第一帧"，策略运行中无法动态纠错。
- **实验层面**：
  - 任务数量与多样性有限（仿真/实物各 3 任务），关键点数始终为 2；
  - 实物外观 OOD 仅在单一任务上评估；
  - 缺少对不同光照、动态干扰、密集遮挡等更复杂 OOD 的考察；
  - 未报告 GPU / 训练时长等算力信息，复现成本难以估计；
  - 用户研究缺失——所谓"易用性"仅为作者经验性陈述，未通过用户实验量化评估。
- **理论层面**：
  - override 仅作为运行时的"补丁"，未讨论用户持续提供反馈时的在线学习机制；
  - 随机特征路由虽缓解了路径偏差，但理论上对扩散去噪过程一致性影响尚不清晰。
