## 摘要
世界动作模型（World Action Models, WAMs）通过联合建模视觉状态转移与机器人动作，为机器人操控提供了一种极具前景的范式。然而，现有WAMs受限于有限的时间上下文、粗粒度的片段级语言监督以及以纯文本为主的条件输入，这些局限阻碍了任务进度跟踪与细粒度的语言-视频-动作对齐，同时也限制了视觉上下文推理与跨具身迁移能力。本文提出WorldScape Policy 2.0，一种配备推理增强型长短时记忆的可控WAM。其因果短时视觉记忆将近期观测作为DiT预填充输入，以保留局部交互动态；而长短时事件记忆则将历史VLM输出组织为全局历史、局部活跃和事件边界三种表示形式，以支持进度感知的检索。检索到的历史信息增强感知与自回归生成的规划令牌，为自主规划提供隐式的子目标条件；语义强制机制进一步将事件级指令语义注入这一潜在规划通路。为建立细粒度的多模态可控性，我们构建了ManipEvent-5M——一个以事件为锚点的具身预训练数据集，包含近500万个事件片段，配有对齐的动作轨迹、片段级任务指令、子片段级子任务描述、目标图像以及视频演示。上述设计提供了一个统一接口，既支持从高层指令进行自主规划，也支持依据细粒度文本、目标图像或视频上下文提示实现可控执行。仿真与真实平台上的实验表明，该方法在长时程自主规划、细粒度指令遵循以及上下文自适应方面均展现出卓越能力。

## Abstract
World Action Models (WAMs) offer a promising paradigm for robotic manipulation by jointly modeling visual state transitions and robot actions. However, existing WAMs are constrained by limited temporal context, coarse episode-level language supervision, and predominantly text-only conditioning, which hinder task-progress tracking and fine-grained language-video-action grounding while limiting visual-context reasoning and cross-embodiment transfer. In this paper, we introduce WorldScape Policy 2.0, a controllable WAM with reasoning-augmented long short-term memory. Its causal short-term visual memory supplies recent observations as DiT prefill to preserve local interaction dynamics, while its long short-term event memory organizes historical VLM outputs into global-history, local-active, and event-boundary representations for progress-aware retrieval. The retrieved history augments perception and autoregressively generated planning tokens, yielding an implicit subgoal condition for autonomous planning; semantic forcing further transfers event-level instruction semantics into this latent planning pathway. To establish fine-grained multimodal controllability, we construct ManipEvent-5M, an event-grounded embodied pretraining dataset containing nearly 5 million event segments with aligned action trajectories, episode-level task instructions, segment-level subtask captions, goal images, and video demonstrations. These designs provide a unified interface for autonomous planning from high-level instructions and controllable execution from fine-grained text, goal-image, or video-context prompts. Experiments in both simulation and real-world platforms demonstrate superior capabilities in long-horizon autonomous planning, fine-grained instruction following and in-context adaptation.

# WorldScape Policy 2.0 论文总结

## 一、核心问题与研究动机

- **总体定位**：针对机器人操控领域从任务专用策略向通用具身模型转变的趋势，世界动作模型（WAM）通过联合建模视觉状态转移与机器人动作，为可操控策略提供了"动力学中心"的新范式。
- **现有 WAM 的三大瓶颈**：
  - **进度感知记忆不足**：多数方法仅以当前观测或短窗口历史为条件，导致在长程任务中"看似相同"的中间状态下，模型难以判断已完成的子任务；已有 MemoryWAM 也未将历史组织为进度感知形式。
  - **语言—视频—动作对齐粗糙**：许多数据集整段共享同一片段级指令，模型易依赖视觉捷径，对原子动作的语义变化不敏感。
  - **交互接口受限**：现有 WAM 几乎只支持文本条件，难以利用目标图像、演示视频或跨具身示例进行灵活控制。
- **核心洞察**：长程可操控性需要两类互补的时间上下文——**语义级事件记忆**（用于推理任务进度）与**帧级视觉记忆**（用于保留局部交互动态），二者缺一不可。

## 二、方法论

### 2.1 整体框架
- **双分支架构**：以因果 DiT 为主干的视频—动作联合生成模型 + VLM 推理分支（Qwen3-VL-4B）。
- **统一接口**：支持三种交互模式——
  - **自主规划模式（auto）**：仅给定片段级高层指令，由 VLM 分支推理出当前子目标并据此生成动作；
  - **细粒度指令模式（fine）**：以 T5 编码的子任务描述作为跨注意力条件；
  - **视觉提示模式**：目标图像与/或演示视频以 VAE latent 形式作为持续性 DiT prefill。
- **动作表示**：以 chunk 起始帧为参考，每条机械臂输出 3D 增量位置 + 6D 连续相对旋转 + 1D 绝对夹爪命令，双臂共 20D；流匹配直接在原始动作空间进行。

### 2.2 推理增强型长短时记忆（LSTM）
- **短时视觉记忆**：最近 $S_v$ 个观测 chunk 的 VAE 潜码作为 DiT 因果预填充进入自注意力，保证局部动作连续性；可选的视觉提示则作为持续性上下文跨 chunk 保留。
- **长短时事件记忆（VLM 分支内）**：
  - **全局历史 latents** $m_{gh}$：通过任务嵌入与压缩历史池化并扩展为固定数量的全局槽位；
  - **局部活跃 latents** $m_{la}$：保留最近 $S_e$ 个完整 chunk 的感知与规划 token；
  - **事件边界 latents** $m_{eb}$：依据相邻 chunk 表示余弦距离变化量 $d_j$ 的 Top-K 选取（满足最小间隔 $\Delta$），稀疏保留任务阶段切换点。
- **检索与门控融合**：将三类记忆与压缩全历史 $H_t$ 拼接为 $B_t$，通过交叉注意力检索，并由 token 级 sigmoid 门控 $\gamma_t$ 控制注入强度 $\hat{q}_t = q_t + \alpha\,\gamma_t \odot \tilde{m}_t$。

### 2.3 隐式子目标潜规划与语义强制
- **VLM 推理路径**：单次 prefill 编码头视角图像与规划提示，再自回归生成 $K$ 个规划 token，拼接构成 $q_t=[u_t;r_{1:K}^t]$。
- **语义强制（Semantic Forcing）**：训练时利用子任务描述的 T5 池化表示 $\bar{s}_t$ 作为固定（stop-gradient）目标，并通过可训练投影 $\phi_q$ 将 $\hat{q}_t$ 池化后对齐到 T5 语义空间，损失为余弦相似度损失 $L_{sem}=1-\tilde{s}_t^\top\tilde{q}_t$；推理时仅靠高层指令和记忆推断子目标。

### 2.4 训练目标与三阶段课程
- **总损失**：$L = L_{act} + \lambda_w L_{world} + \lambda_s L_{sem}$（$\lambda_s=0.001$），其中 $L_{act},L_{world}$ 均为流匹配 MSE 损失。
- **三阶段**：
  - **阶段一（事件级多模态预训练）**：在 ManipEvent-5M 上学习细粒度文本/目标图/演示视频与视频—动作的对齐，启用短时视觉记忆；
  - **阶段二（记忆感知中训）**：引入 VLM 分支与事件记忆，仅输入高层指令，通过语义强制将显式事件语义迁移到潜规划路径；
  - **阶段三（下游交互后训）**：按任务需求选择交互模式（自主规划 / 细粒度 / 视觉提示），适配具体具身与动作分布。

### 2.5 ManipEvent-5M 数据集
- **规模**：5.12 亿帧、约 4 982 小时、74.4 万 episode、4.89 M 事件片段。
- **数据来源**：自采 PiPER 实机数据、AgiBot World、RoboMIND、RoboCOIN、DROID、自采 UMI、RoboTwin 2.0、LIBERO、EgoDex。
- **核心 schema**：每个事件片段 $\{(o_{b:e},a_{b:e},y,c,p^{goal},p^{video})\}$，即观测—动作—全局指令—子任务描述—目标图—演示视频六者对齐。
- **构造流程**：
  - **两阶段标注**：先用机器人状态信号切分运动/夹爪事件并赋 primitive 标签，再用 Qwen3-VL 给出语义；
  - **分层帧采样**：episode 级 ≤16 帧生成全局指令，event 级 ≤12 帧生成本地描述；
  - **具身 prompt 条件化**：限定描述维度（夹爪/对象/起止状态/接触/方向/失败恢复等）；
  - **多视角冲突消解**：以夹爪视角为先，头视角为辅；
  - **人手到机器人动作重定向**：将人手 3D 轨迹映射到夹爪位姿；
  - **目标图与演示视频**：第一视角目标图（事件末端观测）+ 第三视角目标图（人类演示）；视频 prompt 用于人—机器人与机器人—机器人迁移。

## 三、实验设计

- **仿真基准**：RoboTwin 2.0，50 个双臂任务，在 clean 与 randomized 两种设置下各 100 次试验平均；另设更严苛的 Clean-to-Randomized（C2R）评测。
- **真机平台**：AgileX 双臂 PiPER，覆盖 5 类能力（长程规划 / 记忆推理 / 跨具身 ICL / 顺序细粒度控制），每任务 20 次试验。
- **对比方法**：
  - VLA 系列：π0、π0.5、X-VLA、Abot-M0、LingBot-VLA、HoloBrain-0-QW；
  - WAM 系列：Motus、GigaWorld-Policy、LingBot-VA、Fast-WAM、Abot-M0.5、LingBot-VA 2.0、WorldScape 1.0、DreamZero。
- **评测指标**：任务成功率（subgoal / instruction / progress consistency / ICL 等附加维度）。

## 六、主要结论与发现

- **总体性能**：RoboTwin 2.0 平均成功率 94.3%（clean 94.3% / randomized 94.2%），超越 π0.5（+14.5%）、Fast-WAM（+2.4%）、LingBot-VA 2.0（+0.7%）等代表方法；C2R 设置下平均 47.9%，优于 π0、π0.5、Fast-WAM。
- **真机结果**：长程自主规划（叠衣/叠盒 75%）、顺序清理（80%）、壳球游戏（75%）、跨具身堆叠（60–70%）均显著优于 π0.5 与 DreamZero。
- **OOD 鲁棒性**：桌面清理 OOD 物体平均 60.0%，远高于 π0.5（43.3%）与 DreamZero（30.0%），表明事件级预训练显著提升组合泛化能力。
- **消融结论**：STM、LTM、LSR 三者单调提升，Stage-1 预训练贡献最大，Stage-2 与 SF 提供稳定增量，验证了课程设计合理性。
- **核心论断**：将 WAM 从"被动未来预测"推进到"基于记忆、可多模态操控的具身策略"。

## 七、方法与实验的亮点

- **双时间尺度记忆设计**：将语义级事件记忆与帧级视觉记忆解耦并协同，避免"全历史压缩丢细节"或"短窗口缺进度"的两难。
- **事件级多模态预训练**：以子任务描述、目标图、演示视频与视频—动作轨迹六者对齐，从根本上解决"整段共享指令"造成的监督粗糙问题。
- **语义强制机制**：以 stop-gradient 的 T5 目标稳定对齐潜规划空间，避免联合崩塌，使自主规划与可控执行共用同一语义表征。
- **统一交互接口**：同一模型支持文本/目标图/视频/高层指令四种条件，无需为不同任务切换策略头。
- **三阶段课程渐进式注入能力**：先建立可控性、再注入推理、最后适配下游具身，逻辑清晰且实验验证单调收益。
- **ManipEvent-5M 的工程贡献**：跨人/机器人/模拟多源、近 5M 事件片段、可用于多种 WAM/VLA 训练。

## 八、不足与局限

- **算力与可复现性披露不足**：GPU 型号、数量、训练总时长、显存峰值、推理延迟均未给出，给第三方复现带来障碍。
- **真机评测规模有限**：每任务仅 20 次试验，统计置信度与误差棒缺失，难以判断小幅差异是否显著。
- **基线公平性问题**：对 π0.5 在需要历史的任务上做了"时序扩展"，但未在所有任务上做等价扩展对比；C2R 设置下也缺少完整基线。
- **OOD 评估范围较窄**：仅在桌面清理 6 条指令下做 in/OOD 划分，缺乏更系统的长程 OOD 任务评测。
- **对 VLM 的依赖风险**：事件标注与子目标推理均重度依赖 Qwen3-VL，存在标注噪声传播与推理误差累积风险；不同 VLM 替换后的鲁棒性未评估。
- **应用场景受限**：仅在双臂 PiPER 与 RoboTwin 2.0 仿真上验证，未在移动机器人、灵巧手、户外非结构化环境等场景下测试。
- **安全与可解释性**：未讨论模型在长程失败时的恢复策略、潜在风险动作（碰撞、危险物体）等问题，离真实部署尚有距离。
