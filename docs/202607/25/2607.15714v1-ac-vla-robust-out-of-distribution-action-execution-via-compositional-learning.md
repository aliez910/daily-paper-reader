## Abstract
Vision-Language-Action (VLA) models excel at end-to-end robotic manipulation but struggle with out-of-distribution (OOD) generalization when familiar sub-tasks are recombined in unseen configurations. We identify two mutually reinforcing failure modes: \emph{trajectory overfitting}, where models overfit to holistic trajectory patterns rather than compositional sub-skill semantics; and \emph{perceptual shortcut}, where action tokens over-rely on wrist-view textures at the expense of global spatial grounding. To address both, we introduce \textbf{AC-VLA}, a plug-and-play Action Compositional learning framework comprising two architecture-agnostic components: \textbf{(i)} a compositional learning module that uses an LLM-driven instruction decomposer and a proprioceptive trajectory aligner to generate dense sub-task supervision, followed by mixed training on complete demonstrations and decomposed data to endow the model with compositional generalization; and \textbf{(ii)} a state-conditioned asymmetric masking strategy that suppresses wrist-view inputs during closed-gripper phases, enforcing global semantic grounding. All components are architectural modification-free and directly integrable into any VLA backbone. Instantiated on $π_{0.5}$ and evaluated on LIBERO and LIBERO-OOD benchmarks, AC-VLA achieves a ~28% absolute improvement on compositional OOD tasks while maintaining near-perfect in-distribution performance.

# AC-VLA 论文总结

## 1. 核心问题与研究动机

- **研究背景**：Vision-Language-Action (VLA) 模型凭借大规模预训练在端到端机器人操控中表现优异，但当面对将已熟悉的子任务以**未见配置**重新组合的指令时，泛化能力急剧下降。
- **关键现象**：例如训练时"抓 A 放到 A"、"抓 B 放到 B"，推理时要求"抓 A 放到 B"——模型会因 token 级视觉/语言冲突而行动混乱。
- **两种相互强化的失效模式**：
  - **轨迹过拟合（trajectory overfitting）**：模型记忆整体轨迹模式，而非真正的可组合子技能语义，导致无法灵活重组"抓"与"放"等原语。
  - **感知捷径（perceptual shortcut）**：模型过度依赖腕视角（wrist-view）的局部纹理作为强视觉线索，而忽视全局空间布局，导致放置阶段定位错误。
- **现有方法的不足**：
  - 分层规划（high-level planner + low-level policy）解耦阻碍联合优化；
  - 阶段化 VLA 方法引入刚性子任务边界，造成误差累积；
  - 单纯扩大训练数据无法根本解决组合泛化问题。

## 2. 方法论

### 2.1 整体框架

AC-VLA 是一个**即插即用、与架构无关**的 Action Compositional Learning 框架，包含两大组件：

- **组合学习模块（Compositional Learning Module）**
- **状态条件非对称掩码策略（State-Conditioned Asymmetric Masking）**

### 2.2 组合学习模块

- **协作分解**：
  - 给定一条完整演示 $(o_t, a_t)_{t=1}^T$，先用 LLM（具体为 Qwen-3.5-Flash）将整体指令 $\ell$ 分解为有序子任务描述 $\{\ell_1, \ell_2, \ldots, \ell_N\}$，子任务数 $N$ 由 LLM 根据语义复杂度动态决定。
  - 同时引入**本体感知驱动的轨迹对齐器（proprioceptive trajectory aligner）**，利用两类自然物理线索对轨迹进行切分：
    - 夹爪状态跃迁（open→close, close→open）；
    - 动作块平均末端位移 $D(A_t) = \frac{1}{H}\sum_{i=1}^{H-1}\|p_{t+i}-p_{t+i-1}\|_2$；
    - 子任务边界条件：$\text{seg}(t) = (g_t \neq g_{t-1}) \lor (D(A_t) < \epsilon)$，$\epsilon$ 通过对训练轨迹聚类得到。
- **离线密集子任务监督**：对齐后的 $(\ell^k, \xi^k)$ 对构成 $D_{\text{sub}}$，无需人工标注、完全离线构建。
- **混合训练（Mixed Training）**：构造 $D_{\text{mix}} = D_{\text{full}} \cup D_{\text{sub}}$，按固定比例从完整演示与子任务中采样 mini-batch，统一在基于 flow-matching 的 $\pi_{0.5}$ 骨干上进行训练，损失为：
  $$L(\theta) = \mathbb{E}_\tau\left\|V_\theta(\phi_t, A_t^{(\tau)}, q_t) - (A_t - \epsilon)\right\|^2$$
  其中 $A_t^{(\tau)} = \tau A_t + (1-\tau)\epsilon$，$\tau\in[0,1]$，$\epsilon\sim\mathcal{N}(0,I)$。推理时采用 $K$ 步 Euler 积分生成动作块。

### 2.3 状态条件非对称掩码

- **实证动机**：在 LIBERO 上的消融显示，去掉腕视角后成功率跌至接近 0（Goal: 1.5%、Spatial: 1.9%），而去掉第三人称视角只掉到中等水平；注意力图可视化也证实"放置"阶段注意力仍锚定训练时的旧目标。
- **核心策略**：复用协作分解模块定位"放置（place）"阶段（即夹爪闭合阶段），在训练时**遮蔽腕视角 token 的注意力**；在夹爪张开阶段（如接近、抓取）则保留腕视角，以维持精细操控所需反馈。
- **效果**：迫使模型依赖第三人称视角与语言指令推断空间关系，切断腕视角纹理与任务配置间的虚假相关性。
- **优势**：完全在线训练时执行，无需架构改动，不影响推理流程。

## 6. 主要结论与发现

- 在 $\pi_{0.5}$ 骨干上：
  - Spatial-OOD 从 35.5% → **64.2%**（+28.7），Goal-OOD 从 46.6% → **73.3%**（+26.7）；
  - In-D 平均仅小幅下降（98.8/98.5/99.3/92.9 → 98.0/97.7/98.4/92.4）；

- 在 GR00T-N1 骨干上：两个 OOD 子集分别获得 +18.5 与 +19.9 的绝对提升，证明方法**与具体骨干解耦**。
- 真实世界中：In-D 88.7% vs 93.7%（基线），OOD 82.5% vs 35.0%（+47.5），平均 85.6% vs 64.4%（+21.2）。
- **核心结论**：轨迹过拟合与感知捷径是两种**互补且必须同时解决**的失效模式；组合子任务监督 + 腕视角阶段化掩码构成有效对治手段，且无需改动模型架构。

## 7. 方法与实验设计的亮点

- **即插即用、架构无关**：无需修改任何 VLA 骨干，即可在 $\pi_{0.5}$ 与 GR00T-N1 上同时带来显著提升，便于落地。
- **自动离线子任务分解**：用 LLM + 本体感知信号（夹爪开闭 + 位移阈值）替代固定时序切分，避免阶段化方法常见的"刚性子任务边界"。
- **稳定性–可塑性平衡**：通过混合训练在完整演示与子任务之间显式调节，缓解"纯子任务训练导致 In-D 崩溃"的问题。
- **针对感知捷径的因果式修正**：以夹爪开闭为条件非对称掩码，比随机 dropout 更具语义针对性，并保留精细操控所需的腕视角反馈。
- **可视化与定量互证**：注意力图与 token 注意力分数统计共同支持"放置阶段过度关注腕视角旧目标"这一假设。
- **跨平台验证**：仿真 + 真实机器人双重验证，提升结论可信度。

## 8. 不足与局限

- **LLM 与本体感知对齐器的误差传播**：子任务描述依赖于 Qwen-3.5-Flash 的语义解析能力，对高度模糊或领域特定指令可能产生错误切分，进而影响后续轨迹对齐。
- **真实世界任务规模偏小**：仅 4 个 In-D + 2 个 OOD 任务、每任务 50 episodes×3 seeds，统计力度有限，难以排除偶然性。
- **阈值 $\epsilon$ 的依赖**：位移阈值通过聚类在训练轨迹上确定，对新场景/新硬件的迁移性未充分讨论。
- **超大规模数据下的边际收益递减**：作者自承在已覆盖绝大多数"对象–目标"组合的超大规模数据上，显式组合学习的收益可能减弱。
- **公平性争议**：未与需要两轮推理 + 手工调参的 $\pi$-TLI 在统一协议下严格对比；同时 SF-$\pi_{0.5}$ 在 OOD 上已具备一定竞争力，AC-VLA 的优势来源（空间对齐 vs 组合分解）尚未完全解耦分析。
- **注意力掩码仅作用于训练**：推理阶段仍使用双视角，若部署硬件缺少第三人称相机（如纯腕视角场景），方法可能失效——这是应用层面的潜在限制。
- **未给出训练时长、能耗、推理延迟等实用部署指标**，对实际工业部署参考价值有限。
