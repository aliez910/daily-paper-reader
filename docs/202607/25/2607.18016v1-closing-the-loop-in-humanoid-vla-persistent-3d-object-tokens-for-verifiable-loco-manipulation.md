## 摘要
视觉-语言-动作策略是通用机器人控制的有前景的基础，但长时序人形机器人运动-操作要求机器人将任务物体视为在运动、接触、遮挡与恢复过程中持续存在的物理实体。我们将这一问题刻画为物体状态发散：用于条件化全身动作的物体状态，可能与用于判断该动作是否达成预期物理关系的状态不一致。我们提出可持久化物体标记化（POT），该方法从 RGB-D 观测中维护按角色索引的三维物体记录，并将其转换为面向全身动作专家的物体标记。在实例化形式 POT-VLA 中，同一组物体记录既用于条件化动作生成，又支持几何谓词检查，由此构成一个物体状态既可执行又可验证的闭环执行系统。在 Unitree G1 上，POT-VLA 将一个匹配的 GR00T-N1.7 直接基线在八个真实任务族上的成功率从 39/80 提升到 71/80。在外部 Being-0 对齐参考评估中，POT-VLA 在对齐服务任务上达到 44/50 的成功率，而 Being-0 论文报告的成功率为 37/50。最大幅度的提升出现在需要维持三维关系的任务上，表明以物体为中心的持久化状态是可验证人形机器人 VLA 执行的一种有效抽象。

## Abstract
Vision-language-action policies are a promising foundation for general robot control, but long-horizon humanoid loco-manipulation requires the robot to treat task objects as persistent physical entities across movement, contact, occlusion, and recovery. We study this problem as object-state divergence: the object state used to condition a whole-body action can differ from the state used to decide whether the action achieved the intended physical relation. We propose \emph{Persistent Object Tokenization} (POT), which maintains role-indexed 3D object records from RGB-D observations and converts them into object tokens for a whole-body action expert. Instantiated as \emph{POT-VLA}, the same object records condition action generation and support geometric predicate checks, yielding a closed-loop execution system in which object state is both actionable and verifiable. On a Unitree G1, POT-VLA improves a matched direct GR00T-N1.7 baseline from 39/80 to 71/80 successes over eight real-world task families. In an external Being-0-aligned reference, POT-VLA achieves 44/50 successes on aligned service tasks, compared with the 37/50 success reported by the Being-0 paper. The largest gains occur on tasks requiring maintained 3D relations, suggesting that persistent object-centered state is a useful abstraction for verifiable humanoid VLA execution.

# 论文总结：POT-VLA — 持久化三维物体标记驱动的可验证人形机器人运动-操作

## 1. 核心问题与研究动机

- **长时序人形机器人运动-操作任务的核心难点**：自然语言指令（如"整理桌面""给我拿杯饮料"）要求人形机器人在行走、抓取、放置、遮挡、恢复等过程中，始终将同一物体（杯子、篮子、支撑面、交接伙伴）作为可寻址的物理实体，而不是仅作为视觉-语言特征中的隐含语义。
- **关键问题——"物体状态发散"（object-state divergence）**：当前主流视觉-语言-动作（VLA）策略以当前观测的视觉-语言特征隐式编码物体状态，而子任务完成性判断往往由独立的监控器、谓词层或语言级状态决定；二者状态不一致时，会导致过早早终止子任务、错误目标物体操作或低效恢复。
- **根本矛盾**：该问题是物理层面的，而非纯语义层面——物体在度量三维空间中运动、接触支撑面、进入容器、被遮挡，需要的是"持久化、可被动作生成使用、可被动作执行后验证"的三维物体级状态。
- **研究目标**：构建一个统一的物体级物理记忆，使动作专家与谓词验证器共享同一组随时间刷新的物体记录，从而形成可验证的闭环。

## 2. 方法论

### 2.1 核心思想
- 提出**持久化物体标记化（Persistent Object Tokenization, POT）**：在机器人基坐标系下，从 RGB-D 观测构建按角色索引（如 TARGET、DESTINATION、SUPPORT、HANDOVER_PARTNER）的三维物体记录，并将其序列化为**持久化三维物体标记**（Persistent 3D Object Tokens），同时供动作专家与谓词监管器使用。
- 实例化为 **POT-VLA**：在 GR00T-N1.7 全身动作专家上，插入物体标记到 DiT（Diffusion Transformer）动作头自注意序列中；执行 chunk 后用同一物体记忆的几何谓词进行验证，未通过则触发恢复。

### 2.2 关键技术细节
- **物体记录的构建**：
  - 由 VLM 规划器或人工提供"类型化子任务计划" Π，每个子任务 τᵢ 包含角色、接地查询、成功谓词、失败处理器、chunk 长度、超时与重试预算；
  - 使用 SAM3 提供角色/查询掩码，将有效深度像素经相机内参与相机-基座变换反投影到机器人基坐标系下，并按已标定的工作空间边界过滤；
  - 每条记录包含物体-容器距离、支撑高度、末端-物体偏移、目标-目的位移、对齐度、容纳关系、交接线索等。
- **物体标记结构**：
  - 固定 K=8 个槽位、每个 F=33 维特征，包含可见性、置信度、2D 框、3D 质心、3D 范围、可选朝向及关系特征；
  - 未使用槽位标记为 PADDING 并在注意力中被掩码；遮挡或低置信时角色槽位保留但字段标记为不确定。
- **动作头插入方式**：序列布局为 `[Z_state, Z_obj, Z_action]`，视觉-语言主干特征仅作为交叉注意的编码器隐状态；物体标记投影器为 LayerNorm → Linear → GELU → Dropout → Linear，并叠加学到的角色嵌入与上下文嵌入；可选的置信度门控按可见性与置信度缩放特征。
- **训练与适配**：使用与基线相同的动作 chunk 预测目标，不增加额外物体记忆或谓词损失；演示数据与部署时使用相同的角色感知 RGB-D schema 生成的"sidecar"配对，动作损失梯度同时更新物体-标记分支。
- **几何谓词验证**：每条谓词 p = ⟨κ, α, op, ν, n⟩（类型、接地参数、比较算子、阈值/目标、稳定窗口）；执行后基于刷新后的记忆 M_{t+} 评估前置条件 Pᵢ 与完成目标 Gᵢ，返回 in_progress / done / blocked / failed / uncertain，并附带定位失败模式的诊断；恢复动作包括 continue / retry / reobserve / reground / replan，可选调用 VLM 验证器处理语义歧义。
- **运行时**：每次仅执行一个经验证的短时域 chunk，期间执行命令平滑、关节与速度限幅、平衡检查、碰撞敏感工作空间约束与紧急停止。

### 2.3 整体流程
- 形成 **ground–act–refresh–verify–recover** 闭环：刷新角色索引物体记忆 → 序列化为物体标记供动作头预测整身 chunk → 运行校验与执行 → 用 RGB-D 刷新同一物体记忆 → 几何谓词验证 → 通过则继续子任务，否则触发恢复。

## 6. 主要结论与发现

- **闭环物体记忆带来显著提升**：在 Unitree G1 的 8 类真实任务上，POT-VLA 将成功率从 39/80 提升至 71/80，相对提升约 82%。
- **外部参考有效**：在 Being-0 对齐的 5 类服务任务上，POT-VLA 达到 44/50 成功率，优于 Being-0 论文报告的 37/50。
- **最大增益出现在需要维持三维关系的任务**：如三杯堆叠（1/10 → 8/10）、双球入篮（5/10 → 9/10）、衣物入篮（3/10 → 9/10）、抽屉/托盘放置（4/10 → 8/10），表明持久化物体中心状态对长时序几何关系维持尤为关键。
- **消融表明分工明确**：物体标记条件化（31/40）解决大部分接地失败；谓词验证（22/40 → 34/40）补足主要残余的误完成与部分失败。
- **对物体状态偏移鲁棒**：在新物体实例、位姿/布局偏移、执行中扰动下，POT-VLA 显著缩小与基线的差距（典型如 Mid-execution perturbations：4/10 → 8/10）。
- **失败主要源自度量物体状态错误**：基线失败常因抓取点不准、堆叠错位、漏抓小球、放错容器等，而非指令语义理解错误；POT-VLA 通过未达成谓词触发再观察、重接地、重试或重规划来避免静默错误推进。

## 7. 优点

- **共享物体记忆的耦合表示**：将动作生成和动作后验证建立在同一组可刷新的角色索引三维物体记录上，直击"物体状态发散"这一长时序人形机器人闭环的根本痛点。
- **轻量化系统改造**：不依赖仿真器、显式物理引擎或学得的动力学模型，仅在 GR00T-N1.7 动作头插入少量参数与一小组几何谓词，保留基础动作专家与运行时不变。
- **明确的成功判定与可恢复性**：以几何谓词在时间窗口内的持续满足为硬成功标准，并提供结构化恢复（reobserve/reground/retry/replan），减少了错误子任务切换与过早结束。
- **跨任务族与外部对齐双重证据**：8 类任务匹配对比与 Being-0 对齐参考同时给出，且最大增益集中于"维持三维关系"的任务，结论具有较强一致性。
- **可扩展 schema**：33 维 8 槽位的固定表示易于扩展到更多角色（如多目标搬运、多支撑面、双手分配），同时保留对遮挡/低置信的显式建模。

## 8. 不足与局限

- **实验规模与场景覆盖有限**：所有试验在单一杂乱办公环境、单一头戴相机与同一工作站上完成，缺少跨场景、跨光照、跨布局的真实世界复现，且每个变体的 trial 数仍较小（10/40 次），存在一定方差。
- **关键外部参考非本地复现**：Being-0 对齐结果来自原论文报告值而非本地同步复现，硬件、运行时与子任务定义差异可能影响公平性。
- **未报告算力与训练细节**：未说明 GPU 型号与数量、微调数据规模、训练时长、推理延迟等指标，复现成本难以评估。
- **依赖组件的鲁棒性受限于上游**：依赖 SAM3 的掩码质量、RGB-D 深度精度、相机-基座外参标定与 GR00T-N1.7 的整身动作覆盖范围，这些环节失效将直接传导至 POT。

- **方法被局限在单机器人单类型任务**：未来需扩展到主动多视角记忆、更丰富的接触/灵巧操作与人机交互等场景。
