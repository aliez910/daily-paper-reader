## 摘要
视觉-语言-动作（VLA）模型在机器人操作中取得了令人瞩目的泛化能力，近期一些引入记忆增强机制的VLA模型通过将过往图像或语言摘要作为条件，在一定程度上放宽了马尔可夫假设。基于视觉的记忆方法通过对过往采样图像帧进行条件建模来实现这一点，但其计算开销较高，且在时序事件存在视觉歧义时（例如以微小幅度多次按压按钮）存在根本性的局限。我们提出FM-VLA，一种具备基于力记忆的VLA模型，可针对非马尔可夫、接触丰富的操作任务进行时序上下文推理。我们利用在力时间序列重建任务上预训练的变分自编码器（VAE）将力的历史信息编码为紧凑的力记忆令牌。通过将力潜在表示与短期状态历史作为额外的条件令牌投影至动作专家模块，使VLA模型能够利用累积的接触事件历史来指导操作。我们在三个依赖记忆的任务上对FM-VLA进行了评估，包括寻找隐藏积木、按压按钮以及按规定次数擦洗碗碟。轻量化的力记忆机制以极低的推理开销实现了超过80%的成功率，显著优于基线方法。项目页面：https://qft-333.github.io/FM-VLA-Page/

## Abstract
Vision-language-action (VLA) models have achieved impressive generalization in robotic manipulation, and recent memory-augmented VLAs have relaxed the Markovian assumption by conditioning on past images or language summaries. Vision-based memory approaches address this by conditioning on sampled past image frames, but they are computationally expensive and fundamentally limited when temporal events are visually ambiguous, e.g., pushing a button multiple times with small movements. We propose FM-VLA, a VLA model with force-based memory, enabling temporal context reasoning for non-Markovian, contact-rich manipulation. We encode force histories into compact force memory tokens with a variational autoencoder (VAE) pretrained with force time series reconstruction. By projecting force latent representations and short state history as additional conditioning tokens to the action expert module, we enable VLAs to leverage accumulated contact event history to guide manipulation. We evaluate FM-VLA on three memory-dependent tasks, including finding a hidden block, pressing a button, and wiping a dish for a specific number of times. Our lightweight force memory achieves over 80% success rate with minimal inference overhead, significantly outperforming baseline approaches. Project page: https://qft-333.github.io/FM-VLA-Page/

# FM-VLA 论文详细总结

## 1. 核心问题与研究动机

- **核心问题**：现有的视觉-语言-动作（VLA）模型大多遵循 **马尔可夫假设**，即仅根据当前观测映射到未来动作，缺乏对**长时程历史信息**的显式记忆能力。
  - 这使得在需要"计数"、"进度跟踪"或"部分可观测状态推理"等**非马尔可夫任务**（如多次按按钮、反复擦拭）上表现严重不足。
- **现有方案的瓶颈**：近期引入记忆的工作（如 MemoryVLA、MEM 等）主要采用**视觉记忆**机制，即对历史图像帧进行条件建模。
  - **计算开销大**：历史帧输入显著增加 token 数量与推理时延。
  - **视觉歧义性**：当任务的关键事件在视觉上不可见或几乎无变化时（如按钮行程极小、反复按压），视觉记忆无法可靠区分事件次数。
- **关键洞察**：腕部六轴力/力矩传感器天然记录了**接触事件、力幅、作用次数**等交互信号，是对视觉信息的直接互补且低维、高频、噪声可处理。
- **现有力增强 VLA 的不足**：ForceVLA、TA-VLA 等工作仅将当前或短窗力信号用于**动作预测改进**，并未将力流作为**长时程事件记忆**使用，仍无法完成计数类任务。
- **整体含义**：论文探索了一条以"力"为记忆载体的新路径，弥补视觉记忆在接触丰富场景下的盲区，同时保持极低推理开销。

## 2. 方法论

### 2.1 总体思路
- 构建一个二阶段训练范式：
  1. **Stage 1**：用 VAE 在力时间序列重建任务上**预训练**任务无关的力编码器；
  2. **Stage 2**：冻结该力编码器，将其输出的力潜在表示加上短期状态窗口作为额外的条件 token 注入动作专家（action expert），从而在 VLA 中实现**长时程力记忆**与**短时程运动感知**的协同。

### 2.2 模型架构（基于 π0.5）
- **基座**：π0.5 = PaliGemma VLM（含 SigLIP 视觉编码器）+ Flow-Matching 动作专家。
- **两条记忆流**：
  1. **长程力历史 {fτ}**（全程，每帧 6 维 = 3 轴力 + 3 轴力矩）→ 力 VAE 编码器 → K 个力记忆 token。
  2. **短窗关节状态历史 {sτ}**（最近 ~0.9 s，W 帧 ds 维）→ 一个轻量线性层 → 1 个状态 token。
- **注入方式**：在动作专家的 suffix 中按 [noisy-action tokens ∥ K 个力记忆 token ∥ 1 个状态 token] 顺序拼接，保持 noisy-action tokens 的 RoPE 位置与基座预训练一致。
- **策略形式化**：π(aₜ | oₜ, l, hₜ)，其中 hₜ = [Enc_φ({fτ}) ; Proj_ψ({sτ})]。

### 2.3 关键技术与设计细节

- **一阶 EMA 平滑**：对原始力信号做因果指数移动平均（α=0.3），去噪同时保留脉冲起点与峰值。
- **随机噪声前缀（Training-only Augmentation）**：训练时在力历史前随机填充 ≤10 s 的低幅高斯噪声，**消除"序列长度泄露任务进度"这一捷径**，迫使编码器依赖信号内容；推理时关闭。
- **力 VAE（Perceiver-IO）**：
  - K=8 个可学习 latent query；
  - 输入：量化归一化后的 wrench 帧 → MLP + Fourier 位置编码（32 bands）；
  - 编码器：2 层 cross-attention + 10 层 latent self-attention；每 latent 投出 (μₖ, logσ²ₖ) ∈ R⁹⁶；
  - 解码器对称镜像；以重建 + free-bits 正则的 ELBO 训练（β=1e-3，λ=0.5 nats）。
  - 训练目标含掩码 ELBO，仅对有效帧计算重建损失。
- **短期状态投影器**：flatten 10×16 张量 → 单个零初始化线性层 → 1 个 token，端到端联合训练。
- **训练目标（Stage 2）**：沿用 rectified flow；冻力编码器，使用后验均值 μf；联合优化 VLM、动作专家、力投影器 Wf、状态投影器。
- **两点关键设计动机**：
  - 用 VAE 而非"端到端直接注入全长轨迹"，因为后者在长序列上难以学到有效表征；
  - 同时引入短状态窗口，以缓解"仅靠力记忆在接触前产生的重复动作伪影"。

### 2.4 两阶段训练范式
- **Stage 1（VAE 预训练）**：用反频率任务采样在所有任务数据上联合训练一个 VAE，100,000 步，AdamW，batch 512，bf16。
- **Stage 2（VLA 微调）**：冻结 VAE 编码器，整体在 π0.5 上微调 50,000 步，1k warm-up，peak LR 5e-5，batch 32，bf16，8×A100。

## 3. 实验设计

### 3.1 平台与数据
- **机器人平台**：AgiBot G1 双手机器人（双臂 7-DoF + 1-DoF 夹爪），腕部 6 轴 F/T 传感器，100 Hz；策略输入含头部 + 双腕 RGB 三路相机、关节/夹爪本体状态。
- **数据集规模**（自采 VR 遥操作）：
  - Task 1（找积木）：200 次演示；
  - Task 2（按按钮 N=1/2/3 次）：350 次演示；
  - Task 3（擦碗 N=1/2/3 圈）：200 次演示。
- **总规模有限**，属实验室级小规模数据，但覆盖了关键的非马尔可夫接触事件模式。

### 3.2 评测任务（三种"记忆依赖"任务）
1. **Find a Block Under Two Cups**：顺序掀开两个外观相同的倒扣杯以找到并取出隐藏积木，需记住已检查过哪只杯。
2. **Push Buttons**：按指令按按钮**恰好 N 次**（N∈{1,2,3}），按钮行程极小、视觉近乎不变。
3. **Wipe Dishes**：用海绵**完整擦拭碗 N 圈**，每圈需碗沿左→右连续接触。
- 每个任务每方法评估 **18 次**（Task 1 各 9 次积木位置；Task 2/3 各 6 次每个 N 值）。

### 3.3 对比方法
- **π0.5**：无任何历史条件的 memoryless 基线。
- **TA-VLA**（重实现于 π0.5）：短窗力 + 未来力预测辅助头，代表"短期力条件"路线。
- **π-MEM**（MEM 重实现于 π0.5）：在 SigLIP 中插入时空分离 attention，K=5 历史帧，代表"视觉记忆"路线。
- **消融**：Force-only、State-only、GRU / Q-Former / VAE（wrench encoder）三种架构、K∈{4,8,16,32} 令牌数。

## 6. 主要结论与发现

- **核心结果**：FM-VLA 三任务平均成功率 **83.3%**，显著优于 π0.5（27.8%）、TA-VLA（22.2%）、π-MEM（53.7%）。
  - Buttons：72.2% vs π-MEM 33.3%；
  - Wipe：77.8% vs π-MEM 50.0%；
  - Cups：100% vs π-MEM 77.8%。
- **关键发现**：
  - **力记忆对视觉不可见事件最为关键**（按按钮、计数擦碗），视觉记忆则更擅长空间依赖型任务（如掀杯子）。
  - **VAE 预训练显著优于 GRU/Q-Former**等端到端压缩器，说明"先做无监督力时间序列重建 → 再冻结注入"是有效归纳偏置。
  - **8 个力记忆 token 是甜点**：太少成瓶颈、太多破坏 π0.5 已有的 RoPE 位置假设。
  - **短状态窗口不可缺**：消除"接触前的重复动作"伪影。
- **效率优势**：相比 π-MEM（K=5 时 +39 ms，K=16 时 +129 ms），FM-VLA 仅 **+3.3 ms** 推理开销（64.0 vs 60.7 ms）。

## 7. 优点与亮点

- **问题切入角度新颖**：首次明确把"力流"作为**长时程事件记忆**而非仅限当前动作条件，突破了 ForceVLA/TA-VLA 的"局部力反馈"框架。
- **两阶段 VAE 预训练**提供了一种**任务无关、无文本标签**的可迁移力表征学习范式，对未来扩展到大规模数据具有潜力。
- **工程实现扎实**：
  - EMA + 随机噪声前缀消除长度泄漏，方法论细节到位；
  - 训练数据增广（per-view image dropout p=0.4）、逆频率任务采样、free-bits 等缓解了不平衡与后验坍缩；
  - Memory token 后置注入保证 RoPE 兼容、降低对基座破坏。
- **消融多维度**（模态 + 架构 + 容量 + 延时），证据链较完整。
- **推理侧优势突出**，提供了"高精度 + 实时部署可行"的组合，对实际应用友好。
- **任务设计紧扣假设**，Buttons/Wipe 的视觉不可见性是视觉记忆的天然反例，让对比结论颇具说服力。

## 8. 不足与局限

- **VAE 容量固定（K=8）**：对需要数百个接触事件的长程任务可能成为瓶颈，论文自己提出未来需要"分层/自适应压缩"。
- **训练数据规模与多样性有限**：
  - 三个任务总训练量仅 ~750 段遥操演示；
  - 仅 AgiBot G1 一种机器人形态、一种腕部 F/T 配置；
  - 未来扩展到跨平台、跨物体的"通用力记忆"仍需在大规模数据上验证。
- **统计充分性有限**：每方法每任务 18 次试验，无置信区间/多种子报告；对小差距比较（如 100% vs 100% 的 case）无法判断显著性。
- **基线公平性受重实现影响**：TA-VLA 与 π-MEM 均为再实现，细节差异可能影响对比；尽管附录给出了详细超参表，但缺少与原始论文结果的对照。
- **方法局限性**：
  - 力 VAE 在 Stage 1 仅在自有小数据集上训练，可能过拟合到该任务集的力模式；
  - 假设"接触事件可由腕部 F/T 清晰捕获"，在软接触、滑触、多指操作等场景下需要重新评估；
  - 仅使用右腕力信号，未充分利用双臂/触觉信息；
- **评测偏差风险**：任务结构较单一（计数类 + 1 个空间类），未覆盖遮挡处理、多物体交互、突发干扰等更具挑战的非马尔可夫场景。
- **应用与可推广性**：依赖稳定可用的 6 轴腕部力传感器，限制其在低装配成本机器人上的直接使用。
