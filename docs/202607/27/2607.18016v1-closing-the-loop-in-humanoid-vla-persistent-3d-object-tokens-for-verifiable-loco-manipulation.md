## 摘要
视觉-语言-动作策略是通用机器人控制的有前景的基础方法，但长时域的人形机器人运动-操作融合任务要求机器人将任务对象视为在运动、接触、遮挡与恢复过程中持续存在的物理实体。我们将该问题建模为物体状态发散：用于条件化全身动作的物体状态，可能与用于判定动作是否实现预期物理关系时所使用的状态存在差异。我们提出了持久物体令牌化（POT），该方法基于 RGB-D 观测维护角色索引的三维物体记录，并将其转化为物体令牌以供全身动作专家使用。POT-VLA 作为其具体实例，由同一套物体记录同时条件化动作生成并支撑几何谓词检验，由此构成一个物体状态既可执行又可验证的闭环执行系统。在宇树 G1 上，POT-VLA 将与之匹配的 GR00T-N1.7 直接基线在八类真实任务上的成功率从 39/80 提升至 71/80。在与 Being-0 对齐的外部参考基准上，POT-VLA 在对齐服务任务上取得 44/50 的成功率，而 Being-0 论文所报告的对应结果为 37/50。最大的性能增益出现在需要维持三维关系的任务上，这表明以物体为中心的持久状态是实现可验证人形机器人 VLA 执行的一种有效抽象。

## Abstract
Vision-language-action policies are a promising foundation for general robot control, but long-horizon humanoid loco-manipulation requires the robot to treat task objects as persistent physical entities across movement, contact, occlusion, and recovery. We study this problem as object-state divergence: the object state used to condition a whole-body action can differ from the state used to decide whether the action achieved the intended physical relation. We propose \emph{Persistent Object Tokenization} (POT), which maintains role-indexed 3D object records from RGB-D observations and converts them into object tokens for a whole-body action expert. Instantiated as \emph{POT-VLA}, the same object records condition action generation and support geometric predicate checks, yielding a closed-loop execution system in which object state is both actionable and verifiable. On a Unitree G1, POT-VLA improves a matched direct GR00T-N1.7 baseline from 39/80 to 71/80 successes over eight real-world task families. In an external Being-0-aligned reference, POT-VLA achieves 44/50 successes on aligned service tasks, compared with the 37/50 success reported by the Being-0 paper. The largest gains occur on tasks requiring maintained 3D relations, suggesting that persistent object-centered state is a useful abstraction for verifiable humanoid VLA execution.

## 1. 核心问题与研究动机

- **任务背景**：人形机器人的长程运动-操作融合任务（如"整理桌面"、"给我拿杯饮料"）要求机器人在行走、接触、遮挡与恢复过程中，将任务物体视为**持久存在的物理实体**，而非每帧重新识别的视觉特征。
- **关键失败模式——物体状态发散（object-state divergence）**：现有 VLA 策略通常用当前观测的视觉-语言特征来条件化动作生成，但任务进度的验证（如子任务切换、完成判断）往往由独立的监控器、谓词层或语言级状态机完成。当**用于决策动作的物体状态**与**用于验证动作是否成功的物体状态**不一致时，会导致：
  - 过早的子任务切换
  - 错误物体的操作
  - 低效或缺失的恢复行为
- **问题的物理本质**：物体在度量三维空间中运动、与手或支撑面接触、进入容器、被遮挡——这些都不是纯语义问题。因此需要一种**既可驱动动作生成、又可在执行后被验证**的、以物体为中心、可跨时间持久的状态表征。

## 2. 方法论

### 2.1 核心思想

提出**持久物体令牌化（Persistent Object Tokenization, POT）**，其核心思路是：
- 将 RGB-D 观测提升为**角色索引化的 3D 物体记录**（role-indexed 3D object records）；
- 将这些记录**序列化**为**持久 3D 物体令牌（Persistent 3D Object Tokens）**；
- 实例化为 **POT-VLA**：同一套物体记录同时条件化动作生成、并支撑几何谓词验证，形成"感知-动作-验证"闭环。

### 2.2 技术细节

- **物体记录结构**：每条记录 $m_e^t$ 存储实体的角色（TARGET/DESTINATION/SUPPORT/HANDOVER_PARTNER 等）、短语、2D 框、3D 质心与范围、置信度、可见性、关系特征。
- **记忆构建**：使用 SAM3 分割得到角色/查询掩码，将有效深度像素通过相机内参与相机-基座变换反投影到机器人基座坐标系中，过滤工作空间后生成记录。
- **令牌化**：$x_t^{obj} = \mathcal{T}(M_{\tau_i}^t)$，默认 **K=8 个槽位、F=33 个特征维度**；无效槽位为 PADDING 并被掩码。
- **动作专家集成**：在 GR00T-N1.7 的 DiT 动作头自注意序列中插入 `[Z_state, Z_obj, Z_action]`，视觉-语言特征仍作为编码器隐藏状态用于交叉注意；通过 `LayerNorm → Linear → GELU → Dropout → Linear` 投影，并叠加**角色嵌入**和**上下文嵌入**；训练时不增加额外的物体记忆或谓词损失，仅用与基础专家相同的动作块预测目标。
- **几何谓词验证器**：每个子任务有谓词集 $\Psi_i$，谓词形式为 $p = \langle \kappa, \alpha, \text{op}, \nu, n \rangle$（类型/参数/算子/阈值/稳定窗口）。验证后状态返回 $\{in\_progress, done, blocked, failed, uncertain\}$，并附带定位失败模式的诊断 $d_\xi$（如 missing visibility、failed grasp、unstable support、outside goal region 等）。基于状态选择 `continue / retry / reobserve / reground / replan`。
- **闭环执行流程**：每执行一个短时域动作块（horizon H），立即用新的 RGB-D 刷新同一套物体记忆 $M_{\tau_i}^{t+}$，再进行几何一致性检查。

## 6. 主要结论与发现

- POT-VLA 在 8 类真实任务上把匹配直接基线成功率从 **39/80 提升至 71/80**；
- 在 Being-0 对齐服务任务上取得 **44/50**，优于 Being-0 论文报告的 **37/50**（外部参考）；

- 泛化测试显示，POT-VLA 在新物体实例、布局偏移与执行中扰动下仍能保持明显优势，干扰物影响相对较小。

## 7. 方法与实验设计的亮点

- **闭环共享物体状态**：动作专家与谓词验证器读**同一套**刷新后的物体记忆，从根本上避免了"动作条件化状态"与"验证状态"不一致的系统性问题；
- **角色索引化抽象**：将任务语义（TARGET/DESTINATION/SUPPORT/HANDOVER_PARTNER）显式编码到物体令牌中，使动作专家不必从隐式视觉-语言特征中反推关键角色；
- **不依赖仿真器/物理引擎/学习动力学模型**：以 RGB-D 测量为依据的状态转换流即可支撑验证，可解释性较强；
- **细粒度诊断反馈**：谓词监督器返回失败定位（如 `object_not_grasped`、`outside_goal_region`），支撑结构化恢复（reobserve/reground/replan），避免过度依赖语言级整体重规划；
- **控制变量严格的匹配对比**：相同的 GR00T-N1.7、本体、运行时与提示，使性能差异可归因于"共享物体状态环路"本身；
- **跨任务泛化的实证证据**：在新物体、布局偏移、执行扰动下均观察到稳定增益。
