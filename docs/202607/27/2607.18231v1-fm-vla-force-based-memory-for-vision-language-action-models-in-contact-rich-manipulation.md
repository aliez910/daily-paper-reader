## 摘要
视觉-语言-动作（VLA）模型在机器人操作中取得了令人瞩目的泛化能力，而近期引入记忆增强的 VLA 通过以历史图像或语言摘要为条件，放宽了马尔可夫假设。基于视觉的记忆方法通过以采样的历史图像帧为条件来解决这一问题，但其计算开销大，且在时间事件具有视觉歧义时存在根本局限，例如多次小幅推动按钮。我们提出了 FM-VLA，一种基于力记忆的 VLA 模型，能够针对非马尔可夫、接触丰富的操作进行时序上下文推理。我们利用预训练于力时间序列重建任务的变分自编码器（VAE），将力历史编码为紧凑的力记忆令牌。通过将力的潜空间表征与短期状态历史作为额外的条件令牌投影至动作专家模块，使 VLA 能够利用累积的接触事件历史来引导操作。我们在三项依赖记忆的任务上对 FM-VLA 进行了评估，包括寻找隐藏积木、按压按钮以及按特定次数擦拭盘子。我们轻量级的力记忆方案以极低的推理开销实现了超过 80% 的成功率，显著优于基线方法。项目页面：https://qft-333.github.io/FM-VLA-Page/

## Abstract
Vision-language-action (VLA) models have achieved impressive generalization in robotic manipulation, and recent memory-augmented VLAs have relaxed the Markovian assumption by conditioning on past images or language summaries. Vision-based memory approaches address this by conditioning on sampled past image frames, but they are computationally expensive and fundamentally limited when temporal events are visually ambiguous, e.g., pushing a button multiple times with small movements. We propose FM-VLA, a VLA model with force-based memory, enabling temporal context reasoning for non-Markovian, contact-rich manipulation. We encode force histories into compact force memory tokens with a variational autoencoder (VAE) pretrained with force time series reconstruction. By projecting force latent representations and short state history as additional conditioning tokens to the action expert module, we enable VLAs to leverage accumulated contact event history to guide manipulation. We evaluate FM-VLA on three memory-dependent tasks, including finding a hidden block, pressing a button, and wiping a dish for a specific number of times. Our lightweight force memory achieves over 80% success rate with minimal inference overhead, significantly outperforming baseline approaches. Project page: https://qft-333.github.io/FM-VLA-Page/

# FM-VLA 论文总结

## 1. 核心问题与研究背景

- **马尔可夫假设的局限**：当前主流 VLA（Vision-Language-Action）模型普遍将策略建模为 π(aₜ | oₜ, l)，即仅依赖当前观测输出动作。这一假设在需要长期时间上下文的非马尔可夫任务中失效，例如：
  - 计数类任务（按钮按 N 次、擦盘 N 轮）；
  - 部分可观测状态推理（如在两个外观一致的杯子下寻找隐藏积木）。
- **视觉记忆方案的两大痛点**：以 MemoryVLA、MEM 等为代表的视觉记忆方法通过回溯历史图像帧实现上下文记忆，但存在两方面局限：
  1. 视觉变化模糊时无法提供可靠线索（如微小位移的按钮按压几乎无可观测变化）；
  2. 视觉编码与注意力开销巨大，显著增加推理延迟。
- **力觉信号的天然优势**：接触事件、力大小、重复次数等信息天然反映在腕部 F/T 传感器读数中，提供比视觉更直接、更明确的交互动态表示。
- **现有力增强 VLA 的不足**：ForceVLA、TA-VLA 等仅用短时窗力信号辅助当前动作预测，未将力信号作为长期事件计数器使用，无法支撑非马尔可夫决策。

## 2. 方法论

### 2.1 总体思路
- 提出 **FM-VLA**：在 π0.5（VLM = PaliGemma + SigLIP，Action Expert = Flow Matching）基础上，引入两类本体感知记忆：
  - **长期力觉历史** {fτ}：腕部 6 轴 F/T 读数，覆盖整段 episode；
  - **短期关节状态窗口** {sτ}：最近约 0.9 s 的关节位置+夹爪状态。
- 二者分别编码为 token 拼接到 Action Expert 噪声动作之后，形成 `[noisy actions ∥ Zf (K个) ∥ zs (1个)]` 的序列布局，保证 noisy-action token 在 base 模型预训练中的 RoPE 位置不变。

### 2.2 力觉历史处理管线
- **一阶 EMA 平滑**（α=0.3）去除高频噪声但保留起跳与峰值；
- **分位归一化**（q01/q99）使信号跨任务可比；
- **随机噪声预填充**（仅训练阶段）：在每段历史前随机拼接最多约 10 s 的低幅高斯噪声前缀，防止模型"作弊"通过序列长度推断 episode 进度，迫使编码器依赖信号内容本身。

### 2.3 阶段一：Force-VAE 预训练
- 编码器/解码器均采用 **Perceiver-IO** 结构，K = 8 个可学习 latent query；
- 单帧力信号经输入 MLP + Fourier 位置编码（32 频带，fmax=1500）转为 384 维 token；
- 编码器：2 层 cross-attn + 10 层 latent self-attn → 输出 (μₖ, log σ²ₖ) ∈ R^96；
- 训练目标：
  $$\mathcal{L}_{\text{VAE}} = \frac{1}{\sum_\tau m_\tau} \sum_\tau m_\tau \|f_\tau - \hat f_\tau\|^2 + \beta \cdot \frac{1}{K d_z} \sum_{k,j} \max\!\left(D^{(k,j)}_{\text{KL}}, \lambda\right)$$
- **Free-bits 正则化**（λ=0.5 nats）防止后验坍缩；
- 采用**逆频率任务采样**在所有任务数据上联合训练一个通用 VAE。

### 2.4 阶段二：VLA 微调
- 冻结 Force-VAE 编码器，仅取后验均值 μf，去掉重参数化噪声；
- 力记忆 token 经零初始化线性层 Wf 投影到 action expert 隐藏维度 dh；
- 短期状态历史窗口（10 帧，stride=3）经零初始化单层线性映射为单个 token zs；
- 训练目标（Rectified Flow）：
  $$\mathcal{L} = \mathbb{E}_{a^0, \epsilon, k}\big[\| v_\theta(a^k, k, c_t, Z_f, z_s) - (\epsilon - a^0)\|^2 \big]$$
- 端到端微调 VLM、Action Expert、Wf、Projψ。

## 3. 实验设计

### 3.1 数据与平台
- **机器人**：AgiBot G1 双手机器人，双 7-DoF 臂 + 1-DoF 夹爪，腕部 6 轴 F/T 传感器 @ 100 Hz，三路 RGB（头部 + 双腕）；
- **任务套件**（均需长期时间记忆）：
  | 任务 | 描述 | 演示数 |
  |---|---|---|
  | Find Block Under Cups | 在两个外观相同的倒扣杯下寻找隐藏积木 | 200 |
  | Push Buttons | 按蓝色按钮 N∈{1,2,3} 次（行程极小） | 350 |
  | Wipe Dishes | 用海绵擦拭碗内部 N∈{1,2,3} 轮 | 200 |
- **评测指标**：成功率（每个任务 18 次试验，Buttons/Wipe 按 N 平均分配）。

### 3.2 对比方法
- **π0.5**：base 记忆无关 VLA；
- **TA-VLA**：将约 0.9 s 短窗力序列注入 action expert，并加未来力预测头（依据 TA-VLA 论文最佳设计复现到 π0.5 上）；
- **π-MEM**：基于 MEM 的视觉记忆复现，在 SigLIP 每 4 层插入可分离时空 attention，使用 K=5 帧历史；
- **自身消融**：Force-only / State-only（模态消融）；GRU / Q-Former（架构消融）；K∈{4,8,16,32}（容量消融）。

## 4. 资源与算力

- 文中明确给出：
  - **Stage 1 VAE 预训练**：100,000 步，全局 batch size 64×8 = 512，硬件 bf16，AdamW（β=0.9, 0.95），peak LR 3×10⁻⁴；
  - **Stage 2 VLA 微调**：50,000 步，全局 batch size 32，1k warm-up，peak LR 5×10⁻⁵，无衰减；

## 5. 实验数量与充分性

- **主表**：7 种方法 × 3 任务 + 平均值，共 24 个成功率单元；
- **消融实验**：
  - 模态消融（Force-only / State-only）×3 任务；
  - 架构消融（GRU / Q-Former / VAE）×3 任务；
  - Token 数量消融 {4,8,16,32} 在 Wipe 任务上；
- **推理效率**：π0.5 / π-MEM (K=5,16) / FM-VLA 的 latency 多次测量并报告均值±标准差；
- **定性可视化**：每任务附图展示轨迹与单通道力曲线；
- **评估协议**：每任务 18 次试验、N 平均分配、对任务细节（按压是否触发咔嗒声、是否中途失接触等）严格定义成功标准；
- **充分性评价**：实验结构完整、消融维度（模态、架构、容量）齐备、对比公平（同数据/同归一化/同 schedule），但任务数量仅 3 个且均为单一机器人平台，泛化性证据仍有限。

## 6. 主要结论与发现

- **总体性能**：FM-VLA 平均成功率 **83.3%**，显著高于 π0.5（27.8%）、TA-VLA（22.2%）、π-MEM（53.7%）；
- **接触驱动任务收益最显著**：Buttons 72.2% vs π-MEM 33.3%；Wipe 77.8% vs π-MEM 50.0%；
- **模态互补**：Force-only 与 State-only 均显著退化（25.9% / 40.7%），证明长程力记忆与短程状态记忆必须组合使用；
- **架构选择**：VAE 显著优于 GRU（长序列梯度消失，5.6% on Wipe）和 Q-Former（易过拟合瞬时峰值，57.4%）；
- **Token 数量**：8 个为最佳，4 个形成信息瓶颈，16/32 个因超出 π0.5 action expert 预训练 token 上限而性能下降（分布漂移）；
- **推理效率**：仅增加 **+3.3 ms**（64.0 vs 60.7 ms），而 π-MEM (K=5) 增加 +39.1 ms、(K=16) 增加 +129.3 ms；
- **视觉记忆不足以替代力记忆**：在视觉变化不明显的任务上，视觉记忆方法无法替代接触事件计数。

## 7. 优点

- **首次将力觉信号作为长期记忆机制**：区别于 TA-VLA / ForceVLA 的"瞬时力条件"，FM-VLA 真正把力觉流当作 episode 级记忆使用；
- **轻量化设计**：仅 8 个紧凑 token，几乎零推理开销，可直接嵌入现有 π0.5；
- **VAE 预训练的合理性**：无需任务标签即可学到宏观时间结构（力幅、起跳、计数），避免 end-to-end 力注入基线难训练的问题；
- **关键工程细节**：
  - 噪声预填充防止长度泄漏；
  - EMA + 分位归一化提升稳定性；
  - 短状态窗口缓解纯力条件导致的接触前重复行为；
- **实验严谨**：18 次试验、N 值均衡分配、成功标准定义清晰、所有 baseline 在同一训练协议下复现；
- **附录信息丰富**：模型初始化（π0.5 + 智元挑战赛数据预训练）、各 baseline 实现细节、VAE/VLA 超参数表全部公开，可复现性强。

## 8. 不足与局限

- **固定 8 token 瓶颈**：对极长程（数百次接触事件）任务不友好，作者建议未来引入层次化或自适应压缩；
- **VAE 仅在演示数据上训练**：未在大规模多机器人多样化力/力矩数据集上预训练，可能限制跨任务泛化能力；
- **任务与平台单一**：仅在 AgiBot G1 双手机器人上验证 3 个任务，对单臂、其他本体（移动臂、人形）、不同夹爪/传感器的迁移性未知；
- **视觉记忆基线偏弱**：π-MEM 复现仅 K=5 帧，未与更长记忆或更新的视觉记忆方法（如 ReMemVLA、VPWEM 等）对比；
- **对比公平性细节**：TA-VLA 从 π0 重新实现到 π0.5，并加入了未来力预测头，与原始论文不完全一致，差异可能影响公平性；
- **缺少失败案例分析**：未深入讨论模型在何种条件下出错（如 Buttons 中 N=3 时的过/欠计数）；
- **未给出实时性压力测试**：仅平均 latency，未报告尾部延迟或长 episode 中的累积漂移；
- **奖励/行为可解释性有限**：力记忆 token 是否真正编码"已按次数"缺乏可视化或线性探针验证。
