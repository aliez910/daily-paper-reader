## 摘要
端到端的视觉运动策略几乎不提供让人类理解或纠正该策略视觉注意力的机会。我们提出了 GuidedAttention，一个视觉运动模仿学习框架，它将可解释且可校正的视觉注意力作为一种显式的中间表示引入。该框架从相机图像中预测与任务相关的注意力关键点，并以此作为基于扩散的动作策略的条件。用户可以在回合初始化时检查并可选地校正所选的关键点，随后由跟踪模块将校正后的注意力在整个执行过程中自动传播。仿真和真实世界中的实验表明，GuidedAttention 一致地提升了机器人操作性能，尤其是在位置和外观分布外（OOD）条件下。https://mmurooka.github.io/guided-attention-project-page

## Abstract
End-to-end visuomotor policies provide little opportunity for humans to understand or correct the policy's visual attention. We propose GuidedAttention, a visuomotor imitation learning framework that introduces interpretable and correctable visual attention as an explicit intermediate representation. Task-relevant attention keypoints are predicted from camera images and condition a diffusion-based action policy. Users can inspect and optionally correct selected keypoints once at rollout initialization, after which the corrected attention is automatically propagated throughout execution by a tracking module. Experiments in simulation and the real world demonstrate that GuidedAttention consistently improves robot manipulation performance, particularly under positional and appearance out-of-distribution (OOD) conditions. https://mmurooka.github.io/guided-attention-project-page

# GuidedAttention 论文总结

## 1. 核心问题与研究动机

- **端到端视觉运动策略的黑箱问题**：模仿学习得到的端到端策略直接从图像映射到动作，缺乏可解释性，人类既无法理解策略"在看哪里"，也无法在执行过程中给予及时纠正。
- **OOD 鲁棒性不足**：在分布外（如物体位置偏移、外观/纹理变化）场景下，策略的视觉注意力容易偏离任务相关结构，导致操作失败。
- **人机交互接口缺失**：现有视觉提示方法（语言指令、轨迹草图、语义标注、点提示等）要么交互成本高，要么直接将人类提示作为策略输入而非纠错接口。
- **本文目标**：在端到端视觉运动策略中引入一种**可解释、可纠正的视觉注意力**作为显式中间表示，在保留自主执行能力的同时，为人类提供低成本的纠错接口，从而提升 OOD 鲁棒性。

## 2. 方法论

### 2.1 整体框架（DP-GA）

- **架构流程**：多视角 RGB 图像 + 本体感知状态 → 视觉注意力编码器（AttnEnc）→ 注意力关键点 + 注意力特征 → 拼接本体特征 → 条件扩散策略（U-Net 去噪扩散）→ 动作生成。
- **关键思想**：将"任务相关的 2D 关键点"作为**显式、可视化、可人为修正**的中间表征，紧密耦合到动作生成过程中。

### 2.2 视觉注意力编码器（AttnEnc）

- **结构**：ResNet-18 骨干提取 patch 特征 → Transformer 编码器（含位置编码） → Transformer 解码器（接收可学习查询） → 线性坐标头。
- **预测输出**：每张图像输出 $N_k$ 个注意力关键点 $p_i \in \mathbb{R}^2$ 与对应特征 $f_i \in \mathbb{R}^{d_f}$。
- **坐标映射**：$p_i = h_\theta(f_i) = A f_i + b$（线性层）。
- **变体**：*coordinate-as-feature*——直接以坐标 $p_i$ 作为扩散策略的条件输入。
- **训练损失**：
  - 关键点 MSE 损失：$\mathcal{L}_{kp} = \frac{1}{N_k}\sum_i \|p_i - p_i^{gt}\|_2^2$
  - 特征空间对齐损失：$\mathcal{L}_{feat} = \frac{1}{N_k}\sum_i \|f_i - h_\theta^{-1}(p_i^{gt})\|_2^2$

### 2.3 关键点覆盖（Override）机制

- **原理**：回放时用户可对首帧部分关键点进行点击修正，修正坐标通过 $h_\theta^{-1}$ 恢复为特征，替换对应预测特征后输入扩散策略；跟踪模块自动将修正传播至后续帧。
- **三项关键技术**：
  1. **前向-反向权重共享**：利用 Moore-Penrose 伪逆定义解析逆映射 $h_\theta^{-1}(p_i) = A^+(p_i - b)$，无需新增参数。
  2. **特征空间对齐损失**：保证预测路径与覆盖路径产生一致特征。
  3. **随机特征路由**：训练时随机选择每个关键点走预测路径或覆盖路径，避免扩散模型对单一路径过拟合。

### 2.4 关键点标注与跟踪

- **训练**：仅在每个示范的首帧人工点击关键点，其余帧由 Co-Tracker 自动传播；静态关键点固定不变。
- **回放**：用户可在首帧选择性修正部分关键点（或部分相机视图），跟踪模块自动传播，实现"一次性修正"。

## 3. 实验设计

### 3.2 真实世界实验

- **DP-GA（default）**：扩散策略以注意力特征为条件。
- **DP-GA（coord-as-feat）**：扩散策略直接以关键点坐标为条件。
- **额外对比**：MOP-Box / MOP-Point（图像上叠加标记的视觉提示方法）。

## 6. 主要结论与发现

- **ID 性能**：DP-GA 较 DP 提升约 15 pp，较 ACT 提升 15–30 pp，验证了任务对齐注意力线索的价值。
- **OOD 鲁棒性**：
  - 全自主执行时，DP-GA 在多数 OOD 条件下较 DP 提升约 10 pp。
  - **一次性修正 + 自动跟踪**带来额外 15–30 pp 增益，在 Pos+App-OOD 下较 DP 高 20–30 pp（仿真），真实世界外观 OOD 下较自主执行提升约 80 pp、较 DP 高约 40 pp。
- **消融结论**：
  - 移除特征路由后开启修正时性能下降 ~59 pp，说明正确整合修正路径对训练至关重要。
  - 移除注意力监督后 ID 下降 ~31 pp、修正后下降 ~67 pp，表明显式空间监督不可或缺。
- **鲁棒性**：
  - 对中度跟踪/标注噪声（≤8 像素）容忍度良好；极端噪声下性能仍优于无注意力基线 20–40 pp。
  - 增加关键点数量（2→4→6）训练收益有限；但覆盖更多任务相关关键点（尤其是与目标物体相关的）效果更佳。
  - 相机数量增加未必更好——视角是否提供任务相关信息更关键（实验中 front+right 优于 front+left，因左视遮挡严重）。
- **与标记叠加提示对比**：DP-GA 较 MOP-Box / MOP-Point 在 ID 和 OOD 下均高 20 pp 以上，说明仅在输入图像上叠加标记不足以充分利用任务相关信息。

## 7. 优点与亮点

- **人机交互的轻量化设计**：用户仅需在首帧点击少量关键点（甚至部分关键点/部分相机），通过跟踪模块自动传播，大幅降低交互成本。
- **可解释性与纠错性统一**：以 2D 关键点作为显式中间表征，既可被人类实时观察，又可被人工修正，同时仍保持端到端训练。
- **严谨的技术组合**：前向-反向权重共享（解析伪逆）+ 特征对齐损失 + 随机特征路由三项技术协同保证修正路径与预测路径的一致性，避免过拟合。
- **仿真 + 真实世界双重验证**：覆盖 ID 与多种 OOD，且在外观 OOD 的 Towel Fold 任务上获得显著增益。
- **实验分析充分**：包含组件消融、噪声敏感性、关键点数量、相机数量、与视觉提示方法的对比，多维度验证设计选择的合理性。
- **工程友好**：基于统一的 RoboManipBaselines 框架，依赖开源的 Co-Tracker，易于复现与扩展。
