## 摘要
世界动作模型（World Action Models，WAMs）通过联合建模视觉状态转移与机器人动作，为机器人操作提供了一种颇具前景的范式。然而，现有 WAMs 受限于时间上下文长度不足、语言监督仅停留在片段（episode）级且粒度粗放，以及条件输入以纯文本为主，这不仅阻碍了任务进度跟踪与细粒度的语言-视频-动作对齐，也限制了视觉上下文推理与跨具身迁移能力。本文提出 WorldScape Policy 2.0，一种配备推理增强型长短期记忆的可控 WAM。其因果短期视觉记忆将近期观测作为 DiT 预填充（prefill）输入，以保留局部交互动态；其长短期事件记忆则将历史 VLM 输出组织为全局历史、局部活跃与事件边界三种表示，从而支持进度感知的检索。检索到的历史信息对感知模块进行增强，并联合自回归生成的计划标记（tokens），形成面向自主规划的隐式子目标条件；语义强制（semantic forcing）进一步将事件级指令语义迁移至该潜在规划通路。为建立细粒度的多模态可控性，我们构建了 ManipEvent-5M——一个事件级具身预训练数据集，包含近 500 万个事件片段，并配齐对齐的动作轨迹、片段级任务指令、子片段级子任务描述、目标图像以及视频演示。上述设计为基于高层指令的自主规划与基于细粒度文本、目标图像或视频上下文提示的可控执行提供了统一接口。在仿真平台与真实场景中的实验表明，该方法在长时序自主规划、细粒度指令跟随以及上下文自适应方面均展现出卓越能力。

## Abstract
World Action Models (WAMs) offer a promising paradigm for robotic manipulation by jointly modeling visual state transitions and robot actions. However, existing WAMs are constrained by limited temporal context, coarse episode-level language supervision, and predominantly text-only conditioning, which hinder task-progress tracking and fine-grained language-video-action grounding while limiting visual-context reasoning and cross-embodiment transfer. In this paper, we introduce WorldScape Policy 2.0, a controllable WAM with reasoning-augmented long short-term memory. Its causal short-term visual memory supplies recent observations as DiT prefill to preserve local interaction dynamics, while its long short-term event memory organizes historical VLM outputs into global-history, local-active, and event-boundary representations for progress-aware retrieval. The retrieved history augments perception and autoregressively generated planning tokens, yielding an implicit subgoal condition for autonomous planning; semantic forcing further transfers event-level instruction semantics into this latent planning pathway. To establish fine-grained multimodal controllability, we construct ManipEvent-5M, an event-grounded embodied pretraining dataset containing nearly 5 million event segments with aligned action trajectories, episode-level task instructions, segment-level subtask captions, goal images, and video demonstrations. These designs provide a unified interface for autonomous planning from high-level instructions and controllable execution from fine-grained text, goal-image, or video-context prompts. Experiments in both simulation and real-world platforms demonstrate superior capabilities in long-horizon autonomous planning, fine-grained instruction following and in-context adaptation.

# 论文总结：WorldScape Policy 2.0

## 1. 核心问题与研究动机

- **研究背景**：世界动作模型（World Action Models, WAMs）通过联合建模视觉状态转移与机器人动作，为机器人操作提供了一种颇具前景的范式。然而现有 WAMs 存在三大核心局限：
  - **记忆受限**：现有方法仅基于当前观测或短窗口历史，缺乏对任务进度的感知能力，导致不同子阶段外观相似时无法判断已完成动作。
  - **监督粒度粗放**：现有具身数据集的整段 episode 共享同一指令，细粒度的语言-视频-动作对齐薄弱，模型可能利用视觉捷径而对原子动作不敏感。
  - **交互接口单一**：现有 WAMs 主要依赖文本条件，无法利用目标图像、演示视频或跨具身示例，限制了视觉上下文推理与跨具身迁移。
- **整体目标**：将 WAM 从短时预测模型转变为可控的长时程策略，统一支持高层指令下的自主规划、细粒度文本控制、目标图像与视频演示的上下文学习。

## 2. 方法论

### 2.1 整体框架
WorldScape Policy 2.0 是一个可控的 WAM，由 **VLM 推理分支**（处理事件级语义记忆与高层规划）和 **因果 DiT 分支**（处理视频与动作生成）组成，二者共享事件记忆与视觉记忆。

### 2.2 关键技术细节

- **因果短期视觉记忆**：将最近 $S_v$ 个观测块的干净 VAE 潜变量作为 DiT 预填充（prefill），通过因果自注意力保留局部交互动态。
- **长短期事件记忆（VLM 分支）**：将历史 chunk 级 VLM 输出组织为三类视图：
  - **全局历史（Global-History）**：通过 Mean 池化与任务指令融合生成固定数量的全局槽。
  - **局部活跃（Local-Active）**：保留最近 $S_e$ 个完成 chunk 的完整 token。
  - **事件边界（Event-Boundary）**：通过相邻 chunk 潜变量余弦距离 $d_j = 1 - \cos(\bar{q}_j, \bar{q}_{j-1})$ 选取 TopK 变化最大且满足最小时间间隔 $\Delta$ 的 chunk，稀疏保存语义转折点。
- **检索与门控融合**：将三类记忆与压缩的完整历史 bank 拼接为 $B_t$，通过独立的 Q/K/V 投影进行 cross-attention，再用 sigmoid 门控 $\gamma_t = \sigma(W_g[q_t; \hat{m}_t] + b_g)$ 逐 token 注入，最终形成记忆增强的推理潜变量 $\hat{q}_t = q_t + \alpha \gamma_t \odot \hat{m}_t$。
- **隐式子目标规划与语义强制**：在自主规划模式下，仅输入高层指令 $y$，VLM 通过预填充联合编码头视图观测 $o_t^{head}$ 与规划模板 $T_{plan}(y)$，自回归生成 $K=4$ 个规划 token，得到感知 token $u_t$ 与规划 token $r_{1:K}^t$，拼接为 $q_t$。训练时通过语义强制 $\mathcal{L}_{sem} = 1 - \tilde{s}_t^\top \tilde{q}_t$（将 T5 嵌入作为停止梯度的语义目标，可训练投影器 $\phi_q$ 将 $\hat{q}_t$ 对齐到 T5 语义空间），将事件级语义迁移至潜在规划通路。
- **模式相关的语言接地**：在细粒度指令模式下使用 T5 嵌入 $s_t$ 作为 cross-attention 条件；在自主规划模式下使用记忆增强的 VLM token $\hat{q}_t$ 作为条件，二者由交互模式 $\mu \in \{\text{auto, fine}\}$ 切换。
- **统一动作表示**：每条动作 $a^{(e)}_{t,\tau} = [\Delta p^{(e)}_{t,\tau}; \phi_6(\Delta R^{(e)}_{t,\tau}); g^{(e)}_{t+\tau}] \in \mathbb{R}^{10}$，包含相对位移、6D 旋转与夹爪开合；双臂拼接为 $\mathbb{R}^{20}$。通过具身特定的 action encoder/decoder 对接共享 DiT。
- **视觉提示**：目标图像 $z_t^{goal}$ 与视频演示 $v_t$ 通过 VAE 编码后作为持久视觉预填充，在整个 rollout 中保持固定。

### 2.3 三阶段训练课程
- **Stage 1（事件级多模态预训练）**：在 ManipEvent-5M 上学习细粒度字幕、目标图像、视频演示与原子动作的对齐，建立因果视觉记忆。损失 $\mathcal{L}^{(1)} = \mathcal{L}_{act} + \lambda_w \mathcal{L}_{world}$。
- **Stage 2（记忆感知中期训练）**：引入 VLM 规划分支与长期事件记忆，通过语义强制 $\mathcal{L}^{(2)} = \mathcal{L}_{act} + \lambda_w \mathcal{L}_{world} + \lambda_s \mathcal{L}_{sem}$（$\lambda_s = 0.001$），将事件语义迁移到自主规划通路。
- **Stage 3（下游交互式后训练）**：根据任务需求激活不同交互模式（高层指令、细粒度字幕或视觉提示），适配具身。

### 2.4 ManipEvent-5M 数据集
- 数据来源：自采集 PiPER 真实数据、AgiBot World、RoboMIND、RoboCOIN、DROID、自采集 UMI 数据、RoboTwin 2.0 仿真数据、LIBERO、EgoDex 人类自我中心视频，共 5.12 亿帧 / 4982.8 小时 / 74.4 万 episodes / 488.6 万事件片段。

## 6. 主要结论与发现

- **RoboTwin 2.0 表现最佳**：平均成功率 94.3%（clean 94.3% / 随机化 94.2%），超越 π0.5 14.5%、Fast-WAM 2.4%、LingBot-VA 2.0 0.7%。

- **消融结论**：STM / LTM / LSR 三组件对性能均呈正向贡献；Stage-1 预训练带来最大提升，Stage-2 与 SF 提供稳定增量。

## 7. 优点

- **统一接口**：单一视频-动作模型同时支持高层自主规划、细粒度字幕控制、目标图像与视频演示提示，是首个在 WAM 范式下集成如此多模态控制的工作。
- **推理增强的长短期记忆设计**：将事件级语义记忆（全局/局部活跃/边界）与帧级视觉记忆解耦，事件边界基于潜变量余弦距离自动检测，无需人工标注。
- **语义强制机制**：通过固定 T5 目标 + 可训练投影器的对比损失，将细粒度语义有效迁移到无字幕的自主规划通路，避免联合崩溃。
- **大规模事件级数据集**：ManipEvent-5M 提供 488.6 万事件片段，覆盖异构数据源（人类自我中心、UMI、仿真、真实机器人），并配套目标图像与跨具身视频演示。
- **三阶段课程**：将可控性、记忆推理、下游适配解耦为独立训练阶段，每阶段均有清晰的监督信号。
- **跨具身能力**：通过统一的具身特定 action encoder/decoder 实现多具身联合训练，并通过视频提示实现人-机、机-机迁移。

- **基线公平性存疑**：在贝壳游戏与堆叠任务中，π0.5 采用了时序扩展输入，与原版不一致，可能造成对比偏差。
- **C2R 与主基准基线覆盖不均**：C2R 仅对比 4 个方法，未涵盖全部 WAM 基线。
- **消融不够细致**：未单独分析三种记忆视图（全局/局部活跃/边界）的贡献，也未对记忆长度 $S_e$、$S_v$、边界数量等超参数做敏感性分析。
- **依赖大型 VLM**：使用 Qwen3-VL-32B 进行标注、Qwen3-VL-4B 作为在线推理器，计算与延迟成本较高，对实时部署提出挑战。
- **领域覆盖偏窄**：ManipEvent-5M 以桌面操作为主，缺乏移动操作、长时序导航等场景的验证。
- **安全与可解释性**：作为大规模端到端模型，缺少失败案例的系统分析、对抗扰动鲁棒性评估与安全约束机制。
