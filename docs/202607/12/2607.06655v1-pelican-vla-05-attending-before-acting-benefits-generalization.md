## 摘要
在本报告中，我们提出了 Pelican-VLA 0.5，一个统一的 VLA 模型，在单一架构内集成了视觉—语言理解、未来帧生成与动作预测。Pelican-VLA 0.5 实现了注意力层面的泛化：在没有目标标注、分割掩码、注意力监督或任务特定微调的情况下，其动作通路已经能够聚焦于指令相关的物体及接触区域。该行为在未见过的场景和未见过的机器人本体上均持续存在，并且显著强于其他开源 VLA 基线。我们验证了这一能力源自于感知与动作之间插入的可学习推理槽（Reasoning Slots）：通过将任务相关的视觉信息经由一个紧凑瓶颈进行路由，该槽接口在预训练阶段诱导出以操作为中心的注意力，并在包括 MoT 风格架构在内的不同策略结构中保持有效。

## Abstract
In this report, we present Pelican-VLA 0.5, a unified VLA model that integrates vision-language understanding, future-frame generation, and action prediction within a single architecture. Pelican-VLA 0.5 achieves attention-level generalization: without object annotations, segmentation masks, attention supervision, or task-specific fine-tuning, its action pathway already focuses on the instruction-relevant object and contact region. This behavior persists across unseen scenes and unseen robot embodiments, and is substantially stronger than in other open-source VLA baselines. We verify that this ability originates from the learnable Reasoning Slots inserted between perception and action: by routing task-relevant visual information through a compact bottleneck, the slot interface induces manipulation-centric attention during pre-training and remains effective across different policy structures, including a MoT-style architecture.

# Pelican-VLA 0.5 论文总结

## 一、核心问题与研究动机

- **研究背景**：Vision-Language-Action (VLA) 模型的最终目标是构建能在不同物体、场景、任务和机器人本体（embodiment）间泛化的机器人策略，而非仅在特定基准上拟合动作。
- **关键观察与动机**：现有开源 VLA 模型（X-VLA、GR00T N1.6、Being-H0.5、ABot-M0、π0.5、LingBot-VLA 等）的动作通路（action pathway）注意力呈弥散状态，常分散在机械臂、背景或与任务无关的物体上，无法稳定聚焦于指令相关的目标区域或接触区，导致跨场景、跨本体泛化能力受限。
- **核心问题**：能否设计一种架构，使 VLA 在无需目标标注、分割掩码、注意力监督或任务级微调的前提下，自发形成"以操作为中心"的注意力，并将其转化为可执行的动作？

## 二、方法论

### 2.1 整体架构

- 基于 **Qwen3-VL 4B** 单一 Transformer 主干，将**视觉-语言理解、未来帧生成、动作预测**三者统一在一个前向过程中。
- 输入序列分为四段：
  - **Prefix**：当前观测的多视角图像 patch token 与语言指令 token；
  - **Middle**：由冻结的 Cosmos Tokenizer 编码的 t−15 与 t 帧连续 latents；
  - **Slots**：K=32 个可学习 **Reasoning Slots**（推理槽），从 N(0, 0.02²) 初始化；
  - **Suffix**：本体状态 token + H=50 个动作 chunk token（嵌入含流匹配时间 τ 的正弦编码）。
- 单一前向同时输出三件事：suffix 端的去噪速度、middle 端的未来帧 latents、slots 端的紧凑任务表征。

### 2.2 Reasoning-Slot 瓶颈机制（核心创新）

为防止动作 suffix 直接"绕过"slots，引入三项机制：

- **课程式瓶颈掩码**：以概率 $p_t = \min(1, t/T_{warm})$（$T_{warm}=10k$）随机将"动作 token → 上游感知 token"的注意力边切断，强制 suffix 必须经由 slots 读取感知信息。
- **正交正则**：在 ℓ2 归一化后的 slots 输出 $\hat{Z}_{slot} \in \mathbb{R}^{K\times D}$ 上施加 Gram 矩阵偏离单位阵的 Frobenius 范数惩罚 $\mathcal{L}_{reg}$，促使 K 个槽位编码互不冗余的因子。
- **生成门控**：将平均池化后的 slot 表征 $\bar{z}$ 经 $g=\sigma(W_g\bar{z})$ 调制 future-frame 生成的通道特征 $\tilde{F}_{gen}=F_{gen}\odot g$，让槽位同时承载"未来预测"信号。

### 2.3 训练目标

- **Flow-matching 动作损失** $\mathcal{L}_{action}$：采用条件流匹配构造 $x_\tau=\tau\varepsilon+(1-\tau)a$，目标速度 $u=\varepsilon-a$，由 decoder 头 $v_\theta$ 拟合。
- **未来帧生成损失** $\mathcal{L}_{gen}$：在 Cosmos 潜空间预测 $t+15$ 帧 latents，权重 $\lambda_{gen}=0.01$。
- **Slot-Language 对比损失** $\mathcal{L}_{task}$：轨迹表征与指令文本之间的对称 InfoNCE（温度可学习，dim=256，$\lambda_{task}=0.1$），同指令样本在分母中掩去。
- **正则损失** $\mathcal{L}_{reg}$，权重 $\lambda_{reg}=0.01$。
- 总损失：$\mathcal{L}=\mathcal{L}_{action}+\lambda_{gen}\mathcal{L}_{gen}+\lambda_{task}\mathcal{L}_{task}+\lambda_{reg}\mathcal{L}_{reg}$。

### 2.4 缓存式推理

- Prefix 与 middle 仅依赖视觉-语言上下文，可在 denoising loop 外预先计算并缓存；
- 仅保留 K=32 个 slot 的 KV 作为视觉上下文，丢弃大体积的 prefix/middle 缓存；
- 动作 chunk 从 $\mathcal{N}(0,I)$ 出发，用 N=10 步 Euler 积分流 ODE（$\Delta\tau=-1/N$）回推到 τ=0，使重复去噪成本只与 suffix 长度和 slot 数相关。

## 三、实验设计

### 3.1 数据集

- **预训练**：AgiBot-World Alpha、InternData-A1、Galaxea Open-World Dataset，约 1000 小时自采 TienKung/UR 遥操作数据，合计约 6000+ 小时异构、跨本体操作数据；
- 统一通过 LeRobot 接口读取，state/action 全部填充到 32 维以共享动作头；
- 使用 **joint-position** 动作表示。

### 3.2 基准与对比方法

- **RoboTwin Clean / Randomized**（已见任务，fine-tuned）：与 π0、π0.5、X-VLA、StarVLA-OFT、ABot-M0、LingBot-VLA、Qwen-VLA、JoyAI-RA、Hy-VLA 共 9 个开源 VLA 基线比较；

### 3.3 消融与归因实验

## 六、主要结论与发现

- **注意力级泛化**：无需任何像素级或 token 级监督，Pelican-VLA 0.5 的动作通路在零样本下就显著聚焦于指令相关目标与接触区，跨未见场景、跨本体保持稳定，且显著强于开源基线；
- **来源归因**：在数据/优化/参数一致的对照下，仅有插入 Reasoning Slots 的模型形成以目标为中心的注意力——**表征由架构诱导，而非由数据引发**；
- **训练动态**：预训练呈两阶段——先在空间上集中，再向语言指定物体对齐；目标物体 IoU 从 0.054 → 0.124（ρ=0.76, p=0.01），机械臂注意力维持稳定；
- **微调本质**：微调前后 slot 表征相似度 >0.9、注意力相似度 >0.92，目标注意力 IoU 几乎不变——**微调主要强化"表征到动作"的映射，而非从零生成表征**；
- **基准成绩**：RoboTwin Clean **91.4%**、Randomized **91.0%**（开源 VLA 平均最佳）；真实世界 TienKung 桌面清理 **80%**；
- **明确自我定位**：作者将模型定位为"中间阶段"，强调存在 *representation-to-action gap*（表征到动作的差距）。

## 七、优点与亮点

- **架构创新**：将"在感知与动作之间插入可学习紧凑瓶颈"的设计思想显式化、可视化（注意力图直接检查 slot 路由的信息），并配套课程式掩码保证优化稳定；
- **统一单主干**：放弃 dual-system / MoE 的多专家分立，采用 prefix/middle/slots/suffix 四段式单 Transformer 同时承载理解、生成与动作，便于共享表征与缓存推理；
- **跨架构可迁移**：将同一 slot 接口植入 MoT 风格架构仍能诱导出以操作为中心的注意力，证明设计是普遍机制而非特定架构的副作用；
- **训练效率**：通过 slot KV cache 显著压缩 denoising 期间的视觉上下文，提升高频控制推理效率；
- **方法论透明度**：除代码、权重外承诺发布**注意力可视化工具**，便于社区核查"注意力是否真的聚焦"；
- **诚实定位**：明确指出当前模型仅在 2400 小时欠训练状态、采用 joint-position 不利于跨本体泛化，并把后续 7000 小时扩展工作作为未来方向。

## 八、不足与局限

- **欠训练问题显著**：报告成绩来源于 0.4 epoch（≈2400h）欠训练 checkpoint，作者亦明确承认此点，意味着当前数字难以判定饱和性能；
- **动作表示局限**：统一使用 joint-position 动作，被作者承认为跨本体的关键瓶颈；end-effector 化路径未在此次报告中展开；
- **零样本定量证据不足**：zero-shot 仅描述"非零成功率""能靠近目标"，未给出与 World Action Models、GOAL-VLA、LAP 等零样本 VLA 的定量对比及完整成功率表格；
- **语言条件注意力的稳定性**：早期训练中观察到的"指令切换注意力迁移"在后期退化，归因于训练数据语言-动作不对齐；说明视觉显著性 bias 仍然较强；
- **机械臂注意力残留**：目标物体 IoU 仅 0.124，机械臂区域 IoU 维持在 0.35，说明注意力仍部分被本体自身吸引，pure object-centric 状态尚未完全达到；
- **公平性风险**：InternData-A1 与 RoboTwin 2.0 的"严格无重叠"经 TF-IDF + 人工核查，但完全排除语义相似任务的客观度量方法仍较粗略；
- **算力披露不充分**：GPU 类型/数量、总训练墙钟时间、数据混合比例、slot 数量 K=32 的消融均未给出，限制可复现性评估；
- **任务覆盖偏窄**：仿真任务集中在 RoboTwin 系列，缺少 Meta-World、RLBench、SimplerEnv 等更广泛基准的横向验证；真实世界仅 TienKung 单一平台、单一任务；
- **失败模式未被系统剖析**：作者指出失败多发生在稳定抓取与精确放置，但缺乏失败样本统计与可视化分类，难判瓶颈是否集中在接触感知而非策略能力。
