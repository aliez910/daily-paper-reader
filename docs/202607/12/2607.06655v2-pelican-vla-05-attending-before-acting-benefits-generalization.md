## 摘要
在本报告中，我们提出了 Pelican-VLA 0.5，一个统一的 VLA 模型，将视觉-语言理解、未来帧生成与动作预测集成于单一架构之中。Pelican-VLA 0.5 实现了注意力级别的泛化能力：在无需物体标注、分割掩码、注意力监督或任务特定微调的情况下，其动作通路已能自动聚焦于与操作相关的物体及接触区域。该行为在未见场景与未见机器人本体上均持续存在，且显著优于其他开源 VLA 基线方法。我们验证了该能力源自插入于感知与动作之间的可学习瓶颈标记（Bottleneck Token）：通过将任务相关视觉信息经由紧凑瓶颈进行路由，该标记接口在预训练阶段诱导出以操作为中心的注意力，并在包括 MoT 风格架构在内的不同策略结构中保持有效性。

## Abstract
In this report, we present Pelican-VLA 0.5, a unified VLA model that integrates vision-language understanding, future-frame generation, and action prediction within a single architecture. Pelican-VLA 0.5 achieves attention-level generalization: without object annotations, segmentation masks, attention supervision, or task-specific fine-tuning, its action pathway already focuses on the manipulation-relevant object and contact region. This behavior persists across unseen scenes and unseen robot embodiments, and is substantially stronger than in other open-source VLA baselines. We verify that this ability originates from the learnable Bottleneck Token inserted between perception and action: by routing task-relevant visual information through a compact bottleneck, the tokens interface induces manipulation-centric attention during pre-training and remains effective across different policy structures, including a MoT-style architecture.

# Pelican-VLA 0.5 论文总结

## 1. 核心问题与整体含义

- **研究背景**：Vision-Language-Action（VLA）模型是具身智能的主流范式，但当前的关键瓶颈在于**泛化能力**——即在新物体、新场景、新任务、新机器人本体上的零样本迁移能力。
- **核心观察**：论文通过分析现有 VLA 模型（如 X-VLA、GR00T N1.6、π0.5 等）的注意力图发现，它们的**动作通路注意力呈现"弥漫式"分布**，分散在机械臂、背景、任务无关物体上，而非聚焦于操作目标与接触区域。
- **研究动机**：现有 VLA 依赖任务特定数据收集与微调，泛化能力受限。一个关键问题是：**VLA 模型能否在预训练阶段就形成"与操作相关"的注意力表征**？这种表征能否成为零样本泛化的早期基础？
- **整体含义**：论文将"注意后再行动"（Attending Before Acting）作为提升泛化的设计哲学，并提出**注意力级泛化（attention-level generalization）**这一中间概念，作为迈向真正零样本操控的过渡阶段。

## 2. 方法论

### 2.1 整体架构
- 基于 **Qwen3-VL 4B** 作为共享 Transformer 主干，统一视觉-语言理解、未来帧预测、动作预测三种功能。
- 不采用 Dual-System 或 Mixture-of-Transformers（MoT）设计，所有功能共享 token 流。
- 单一前向传播同时输出三类结果：动作去噪速度、未来帧 latent、BotTokens 紧凑任务表征。

### 2.2 统一 Token 序列（四段式）
- **Prefix（视觉-语言）**：Qwen3-VL 视觉编码器处理三视角 224×224 图像，与语言指令嵌入拼接，采用双向注意力。
- **Middle（Cosmos latent）**：用冻结的 Cosmos-Tokenizer 编码 t−15 和 t 时刻的视觉历史，提供像素级动力学信号。
- **Bottleneck（K=32 个可学习 BotTokens）**：从 N(0, 0.02²) 初始化，dropout p=0.1，作为感知与动作间的瓶颈接口。
- **Suffix（状态 + 噪声动作）**：本体状态 token + H=50 个动作 token（32 维），使用 sinusoidal 嵌入融合 flow time τ。

### 2.3 三种约束机制（强制 BotTokens 成为有效瓶颈）
1. **课程瓶颈掩码（Curriculum Bottleneck Mask）**：在硬约束模式下，禁止 suffix 直接关注上游感知 token，必须经过 BotTokens 中转。训练初期以概率 pₜ = min(1, t/T_warm)（T_warm=10k 步）逐步启用，避免训练不稳定。
2. **正交正则化（Orthogonality Regularizer）**：惩罚 BotTokens 输出 Gram 矩阵偏离单位阵，鼓励不同 token 编码互补信息：
   $$\mathcal{L}_{reg} = \frac{1}{B}\sum_{b=1}^{B}\frac{1}{K^2}\|\hat{Z}_b\hat{Z}_b^\top - I_K\|_F^2$$
3. **BotTokens 门控生成**：将均值池化的 BotTokens 输出经 sigmoid 门控调制未来帧生成特征，使 BotTokens 承载前向预测相关的动作相关信息。

### 2.4 训练目标
- **Flow-Matching 动作损失** $\mathcal{L}_{action}$：基于条件流匹配，预测从噪声到干净动作的速度场。
- **未来帧生成损失** $\mathcal{L}_{gen}$（λ=0.01）：在 Cosmos latent 空间预测未来帧。
- **BotTokens-语言对比对齐损失** $\mathcal{L}_{task}$（λ=0.1）：对称 InfoNCE，对齐轨迹表征与语言指令。
- **正则化损失** $\mathcal{L}_{reg}$（λ=0.01）。
- **总目标**：$\mathcal{L} = \mathcal{L}_{action} + \lambda_{gen}\mathcal{L}_{gen} + \lambda_{task}\mathcal{L}_{task} + \lambda_{reg}\mathcal{L}_{reg}$。

### 2.5 缓存推理
- Prefix、Middle、BotTokens 的 KV 仅依赖当前视觉-语言上下文，与 flow time 无关，可一次性缓存。
- 反向 flow ODE 积分阶段（N=10 步 Euler）仅重新嵌入 suffix，复用 BotTokens cache。
- 大幅降低去噪循环成本，仅依赖 suffix 长度与 BotTokens 数量。

## 6. 主要结论与发现

- **注意力级泛化能力**：在零样本设置下，Pelican-VLA 0.5 的动作通路无需任何目标标注、分割掩码、注意力监督或任务微调，即可聚焦于操作相关物体与接触区域。
- **能力归因**：通过 MoT 风格密集架构对照 + 5 步消融实验，证实这种能力**专门源自 BotTokens 介导的感知-动作路由**，而非训练数据或辅助损失。
- **RoboTwin SOTA**：Clean 91.4%、Randomized 91.0%、平均 91.2%，为开源 VLA 中最佳，且 Clean 与 Randomized 仅差 0.4 点，表明对场景外观不敏感。
- **预训练中的注意力演化**：呈两阶段——先空间集中化，再语义对齐（目标 IoU 从 0.054 升至 0.124，ρ=0.76, p=0.01）。
- **微调的本质**：微调前后注意力模式高度相似（attention similarity >0.92），说明微调主要强化"注意力→动作"的映射，而非从头创建注意力。
- **表征-动作差距（representation-to-action gap）**：模型已能识别操作目标，但稳定抓取、精确放置等细粒度动作仍需任务特定监督。
- **跨架构迁移性**：BotTokens 机制在 MoT 风格架构中同样有效，是可迁移的设计范式。
