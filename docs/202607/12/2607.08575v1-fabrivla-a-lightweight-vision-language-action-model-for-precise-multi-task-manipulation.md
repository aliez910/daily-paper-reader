## 摘要
我们提出了 FabriVLA，一个用于精确多任务操作的轻量级视觉-语言-动作模型。FabriVLA 将 InternVL3.5 视觉-语言骨干网络与一个流匹配动作头相结合，该动作头在动作令牌之间采用门控自注意力机制，并通过浅层 VLM 层融合以增强空间上下文。该模型通过从预训练 VLM 和随机初始化的动作头进行单阶段联合优化训练。在涵盖 50 种多样化操作任务的 Meta-World MT50 基准测试上，FabriVLA 取得了 90.0% 的层级平均成功率，这表明基于 10 亿参数规模 VLM 构建的紧凑型 VLA 能够在不依赖数百亿参数 VLA 骨干网络的情况下实现出色的性能。

## Abstract
We present FabriVLA, a lightweight Vision-Language-Action model for Precise Multi-Task Manipulation. FabriVLA combines an InternVL3.5 vision-language backbone with a flow-matching action head featuring gated self-attention across action tokens and shallow VLM layer fusion for enriched spatial context. The model is trained via single stage joint optimization from a pretrained VLM and randomly initialized action head. On the Meta-World MT50 benchmark spanning 50 diverse manipulation tasks, FabriVLA achieves a tier-average success rate of 90.0%, demonstrating that a compact VLA built on a 1B scale VLM can achieve strong performance without relying on multi billion parameter VLA backbones.

# FabriVLA 论文总结

## 1. 核心问题与研究动机

- **背景**：视觉-语言-动作（VLA）模型已成为通用机器人操控的主流范式，通过预训练的视觉-语言模型将语言指令与视觉观察关联，输出可执行动作序列（典型代表包括 RT-2、OpenVLA、π0 等）。
- **痛点**：当前主流 VLA 模型参数量通常达到数十亿级别（如 π0 为 3.5B、RoboTron-Mani 为 4B），计算成本高、推理延迟大，难以满足实时机器人控制对效率的要求。
- **核心问题**：能否在 1B 量级的紧凑 VLA 模型上同时实现高精度的多任务操作能力，替代依赖大规模参数的大模型方案？
- **意义**：若可行，将显著降低 VLA 在边缘部署和实际机器人系统中的硬件门槛与运行成本。

## 2. 方法论

### 2.1 整体架构
FabriVLA 由三个核心组件构成：(1) InternVL3.5-1B 视觉-语言骨干；(2) 状态编码器与动作编码器；(3) 基于流匹配（Flow Matching）的动作头。

### 2.2 关键技术细节

- **视觉-语言骨干**：采用 InternVL3.5-1B，输入图像 resize 至 448×448，由视觉编码器生成视觉 token，与任务文本 token 拼接后输入多模态序列，保留骨干网络 14 层 transformer 层。
- **状态编码**：机器人状态 s ∈ R²⁴（包含末端位姿、夹爪状态、目标物体位置等）经过两层 MLP+ReLU 编码为状态 token z_s ∈ R¹⁰²⁴，并 prepend 到 VLM 上下文 token 序列。
- **动作编码**：采用 MultiEmbodimentActionEncoder，将噪声动作 x_t ∈ R⁵⁰ˣ²⁴ 通过共享 MLP（24→1024→1024→1024）逐步投影，再叠加水平位置编码，得到 R⁵⁰ˣ¹⁰²⁴ 的动作 token 序列。
- **门控自注意力（Gated Self-Attention）**：动作头由 8 个 FabriVLA TransformerBlock 堆叠组成。每个 block 内：
  - 动作 token 先经过多头自注意力，通过可学习门控参数 g 调节输出：`A' = A + g · SelfAttn(LayerNorm(A))`，其中 g 初始化为 0，因此初始化时 block 等价于纯 cross-attention 形式；训练过程中门控逐渐打开，使模型学习动作 token 之间的时序依赖。
  - 再进行 cross-attention 到 VLM 上下文：`A'' = A' + CrossAttn(LayerNorm(A'), C, C)`。
  - 最后叠加时序条件 FFN：`A''' = A'' + FFN(LayerNorm(A'') + TimeEmb(t))`，其中 TimeEmb(t) 为 sin/cos 位置编码，映射时间索引 p = ⌊1000t⌋。
- **浅层 VLM 层融合（Shallow Layer Fusion）**：将骨干网络的深层特征（第 14 层，提供高级语义信息）与浅层特征（第 6 层，提供更丰富的空间细节如目标边界和相对位置）通过 `concat_proj` 策略融合——将两层 token 沿特征维拼接后用一个 W ∈ R²⁰⁴⁸ˣ¹⁰²⁴ 的可学习线性层投影回原始维度，初始化为 [I|0]，从而保证初始化时与"仅深层"基线完全等价。
- **流匹配训练**：
  - 线性插值：`x_t = (1-t)ε + ta`，其中 ε ~ U([-1,1]⁵⁰ˣ²⁴) 为均匀噪声，a 为真实动作块。
  - 时间步采样：`t ~ Beta(2,2)`，集中采样中间区域以获得最有信息量的去噪任务。
  - 优化目标：`L(θ) = E[‖v_θ(x_t, t|·) − (a − ε)‖²]`，即预测从噪声到动作的直线速度场。
- **推理**：从均匀噪声出发，使用 50 步欧拉积分（Δt=1/N）逐步去噪，生成 50×24 维归一化动作块，反归一化后在闭环 receding horizon 模式下执行 4 维有效 Meta-World 动作。
- **训练策略**：单阶段联合优化，VLM 骨干从预训练 checkpoint 加载并全程解冻微调，动作头随机初始化；采用 AdamW 优化器，学习率 η=2.0×10⁻⁵，经 1000 步线性 warmup 后余弦衰减，weight decay=10⁻⁴，梯度裁剪范数 1.0。

## 6. 主要结论与发现

- **整体性能**：FabriVLA 在 Meta-World MT50 上取得 **90.0% 层级平均成功率**和 **92.0% 整体 episode 级成功率**，其中 easy 95.0%、medium 88.2%、hard 86.7%、very hard 90.0%。
- **参数量对比**：仅 0.89B 参数（无机器人预训练），层级平均成功率超越参数量更大的 LA4VLA（87.5%）和 Evo-Depth（84.4%）。
- **能力差异**：在平面滑移（95.7%）、铰接接触驱动（95.7%）、插入装配（93.3%）类任务上表现最强；在工具介导（83.3%）、粗略抓取运输（85.0%）、抓取放置（86.0%）类任务上相对较弱。
- **消融发现**：
  - 浅层 VLM 层融合相比仅深层基线，将 tier-average 从 82.9% 提升到 90.0%（+7.1 pp），整体成功率从 86.8% 提升到 92.0%（+5.2 pp）。
  - 门控自注意力是动作头中最关键的模块，单独加入即可将 tier-average 从 48.5% 提升到 57.7%；继续叠加 token 残差头和时序卷积反而损害性能。
- **训练动力学**：性能在 93k checkpoint 达到峰值，100k checkpoint 出现轻微退化，表明存在后期过拟合风险。

## 7. 优点

- **架构创新点明确**：门控自注意力通过零初始化门控提供平滑的优化路径，使模型从"无自注意力基线"逐步过渡到"全自注意力"，避免了直接训练自注意力的不稳定性。
- **浅深层融合设计优雅**：`concat_proj` 初始化为 [I|0]，保证初始化时完全退化为深层基线，使得融合策略的边际收益可被清晰度量。
- **极致轻量化**：仅 0.89B 参数实现 90% 层级平均成功率，相对 3.5B–4B 的大模型具有显著的实际部署优势。
- **单阶段联合训练策略简单实用**：避免了多阶段预训练/微调流程的复杂性，同时通过 DeepSpeed ZeRO-2 + FP32 master weights 解决了 BF16 训练中 VLM 小幅更新被量化噪声淹没的问题。
- **实验诊断充分**：除主表外，还给出任务级细粒度分析与训练动力学曲线。

## 8. 不足与局限

- **仿真单一性**：实验仅在 Meta-World MT50 仿真基准上完成，缺少真实机器人迁移实验与 sim-to-real gap 分析。
- **训练数据量较小**：每任务仅 50 条演示轨迹（共 2500 条），数据效率的泛化结论在更大规模数据集上是否成立有待验证。
- **传感器输入受限**：最终策略仅使用 corner RGB 单视角观察，未涉及多视角融合、深度信息或触觉/本体反馈的扩展实验。
- **评测公平性风险**：基线对比数据来自原论文而非统一重训，且评测 episode 数较少（每任务 10 个），统计稳定性有限。
- **训练时间未明确**：缺少总训练时长、收敛速度、推理延迟等效率指标的定量报告。
- **能力短板明显**：在工具介导与粗略运输任务上仍存在 14–17 pp 的差距，限制了在涉及工具使用、远距离搬运等场景的应用。
- **后期训练退化**：100k checkpoint 性能低于 93k 峰值，提示单阶段联合训练可能存在过拟合风险，缺乏早停准则或正则化方法的系统讨论。
- **设计空间探索有限**：仅在单卡 50k 步冻结 VLM 的弱化条件下对比动作头模块，绝对数值偏低，相对结论的鲁棒性需要更长训练的验证。
