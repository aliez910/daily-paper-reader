## 摘要
视觉-语言-动作（VLA）模型旨在将多模态输入映射为机器人动作。然而，现有方法大多因对所有视觉词元一视同仁，并仅依据人工挑选的因素进行推理，难以覆盖复杂动态场景，缺乏强调任务关键证据并忽略潜在因素的机制。为解决这一问题，我们提出 LEEVLA，一种在潜在环境演化中聚焦关键信息的 VLA 架构，能够显式引导模型关注信息区域，同时保持潜在世界表征的结构化演化过程。为了识别显著且与指令相关的区域，我们引入了漂移引导的动态优先级（DGDP），它结合了动态位置优先级（DPP）和语义漂移引导（SDG），用以指导 VLA 智能体在训练过程中的注意力分配。在此基础上，我们引入了结构化特征流生成（SFFG），通过原型到外围（P2P）预测建模这些被优先关注的特征在潜在空间中应如何演化，并提出互邻域对比（MC）损失以保持邻域间的拓扑一致性。DGDP 与 SFFG 共同构成了一个任务感知的"何处-如何"训练框架。在 VLA 基准上的大量实验表明，LEEVLA 始终优于先前方法，证实了显式的任务证据引导与结构化潜在推理对于可扩展的 VLA 均至关重要。代码已开源，地址为 https://github.com/LyuQi127/LEEVLA。

## Abstract
Vision-language-action (VLA) models aim to map multimodal inputs to robot actions. However, most existing approaches struggle to cover complex dynamic scenarios due to treating all visual tokens uniformly and reasoning with human-selected factors, which lack mechanisms to emphasize task-critical evidence and ignore underlying factors. To address this issue, we propose LEEVLA, a VLA architecture for seeing what matters in Latent Environment Evolution that explicitly guides the model toward informative regions while preserving the structured evolution of latent world representations. To identify salient and instruction-relevant regions, we introduce drift-guided dynamic prioritization (DGDP), which combines dynamic position prioritization (DPP) with semantic drift guidance (SDG) to guide the VLA agent where to attend during training. On top of this, we introduce structured feature flow generation (SFFG), which models how these prioritized features should evolve in latent space via prototype-to-periphery (P2P) prediction, and a mutual-neighborhood contrastive (MC) loss to maintain topological consistency among neighborhoods. Together, DGDP and SFFG form a task-aware "where-how" training framework. Extensive experiments on VLA benchmarks show that LEEVLA consistently outperforms prior methods, confirming that explicit task-evidence guidance and structured latent reasoning are both crucial for scalable VLA. Our code is available at https://github.com/LyuQi127/LEEVLA.

## 1. 核心问题与研究动机

**研究背景**：视觉-语言-动作（VLA）模型旨在将多模态输入（视觉、本体感知、语言指令）映射为机器人底层动作控制，是迈向开放环境具身智能的关键路径。

**两大现有问题**：
- **视觉 Token 一视同仁**：现有 VLA 在训练时对所有 patch 等同对待，导致梯度被静态背景和任务无关区域稀释，监督信号分散。
- **依赖人工先验的中间推理**：以 CoT-VLA、DreamVLA 为代表的方法依赖子目标图像、分割、深度等外部条件作为"上下文线索"，需要额外的辅助模型，引入额外计算开销，且过度强调**已知因素**而忽略**未知但任务相关**的潜在因素。当同一物体跨模态变化或不同物体在同一模态外观相似时，这类方法脆弱。

**核心主张**：作者主张直接在**潜空间**中进行结构化推理，避免人工构建的假设空间限制搜索范围；并通过显式的"何处关注"机制将监督信号聚焦于任务关键区域。

## 2. 方法论

LEEVLA 提出 **"where-how" 双模块训练框架**，两者**仅用于训练阶段，推理时不增加开销**。

### 2.1 Drift-Guided Dynamic Prioritization（DGDP）—— 决定"关注何处"

包含两个子模块：

**(a) Dynamic Position Prioritization（DPP）**：
- 用相邻时间步的 patch 特征余弦相似度变化定义"动态分数"：
$$\theta_i = 1 - \cos(v_{t,i}, v_{t+T,i})$$
- 动态分数高的 patch（机器人或任务相关物体）获得更高关注权重。

**(b) Semantic Drift Guidance（SDG）**：
- 计算每个 patch 与语言指令的相关性分数 $r_{t,i} = \max_j \langle \tilde{x}_{t,i}, \tilde{c}_j \rangle$
- 定义语义漂移 $\Delta_i = \text{clip}((r_{t+T,i} - r_{t,i})/\tau, -\delta, \delta)$，归一化后映射为权重因子 $\omega_i = \exp(\tilde{\Delta}_i / \tau)$
- **最终优先级权重**：$\beta_i = \sigma(\omega_i \cdot \theta_i)$，通过 sigmoid 函数耦合语义与动态性。

### 2.2 Structured Feature Flow Generation（SFFG）—— 决定"如何演化"

**(a) Prototype-to-Periphery（P2P）预测**：
- 对多视角未来时刻 patch 特征联合聚类得到 $L$ 个簇，每个簇以质心 $\mu_\ell$ 为原型
- 在每个簇内按到质心的欧氏距离由近到远排序
- 预测损失按排序加权：
$$L_{P2P} = \frac{1}{|C|}\sum_{\ell=1}^{|C|} \frac{1}{|\vec{c}_\ell|} \sum_{j \in \vec{c}_\ell} (\alpha + \beta_j) \cdot (1 - \cos(\hat{v}_{t+T,j}, v_{t+T,j}))$$
- 其中 $\alpha=1$ 为**全局调制因子**（防止过度聚焦于接触区域而忽略全局布局），$\beta_j$ 为 DGDP 的优先级权重。

**(b) Mutual-neighborhood Contrastive（MC）Loss**：
- 构建一阶（K=10）和二阶（M=5）k-NN 邻域
- 仅选**互为邻居**的样本作为正样本，过滤聚类噪声引入的非对称、虚假连接
- 使用 InfoNCE 形式：$L_{MC} = -\frac{1}{|I|}\sum_{i \in I} \frac{1}{|G_i^+|}\sum_{j \in G_i^+} \log \frac{\exp(S_{ij}/\tau_c)}{\sum_{\ell \neq i} \exp(S_{i\ell}/\tau_c)}$

### 2.3 总训练目标

$$L_{total} = \lambda_1 L_{action} + \lambda_2 L_{P2P} + \lambda_3 L_{MC}$$

其中 $L_{action}$ 为 L1 回归的动作损失（并行动作解码，类似 OpenVLA-OFT）。

## 6. 主要结论与发现

- **LIBERO 性能**：LEEVLA-large 平均成功率 98.2%（Spatial 98.8 / Object 99.0 / Goal 98.6 / Long 96.4），LEEVLA-mini 平均 97.5%，均超越同期 SOTA（含 π0.5 的 97.5% 和 OpenVLA-OFT 的 97.1%）

- **真实环境**：平均成功率 78.5%，相比 OpenVLA 的 40% 提升 38.5 个百分点
- **消融结论**：四组件均带来正增益；DPP 单独贡献最大（+1.5%），表明聚焦交互核心区域对策略学习最关键；SFFG 与 DGDP 互补

## 7. 优点

- **方法新颖性**：首次在 VLA 中显式分离"何处关注"与"如何演化"两个问题，DGDP + SFFG 框架思路清晰
