## 摘要
视觉—语言—动作（VLA）策略（如 π₀.₅ 和 OpenVLA）在许多操作任务中表现良好，但它们通常是反应式的：下一动作根据当前观测、指令和本体感受状态预测。该假设在阶段依赖型操作中失效，因为视觉上相似的状态可能由于潜在任务进度和先前交互结果的不同而需要不同的动作。我们认为此类任务不仅需要记忆，还需要具备动力学感知的信念更新：策略应在稳定或遮挡阶段保持任务进度，并在接近接触、释放或子目标转换时修正信念。我们提出了时间条件记忆融合策略（TFP），一种面向 VLA 主干网络的轻量级记忆—动作框架。TFP 利用液态时间常数（Liquid Time-Constant）动力学维持一个回合内的局部任务进度信念，并通过自适应调制将更新后的信念直接注入流匹配动作解码器。这使得时间累积的上下文能够塑造生成的动作块，而非仅仅作为被动的历史上下文。在一个 33 亿参数的模型上，TFP 将 LIBERO 上的平均成功率从 96.9% 提升至 98.75%，将 LIBERO-plus 上的平均成功率从 91.4% 提升至 93.77%。在面向记忆的 MIKASA ShellGameTouch 诊断任务上，TFP 的成功率高达 75.0%。机制分析表明，操作事件附近的写入增益变化约为远端非事件阶段的 6 倍；隐状态干预实验显示，信念对生成的动作块具有因果调制作用。这些结果表明，紧凑且对事件敏感的记忆动力学能够在遮挡、视觉扰动和阶段依赖型任务结构下提升 VLA 策略的性能。

## Abstract
Vision--Language--Action (VLA) policies such as $π_{0.5}$ and OpenVLA perform well on many manipulation tasks, but they are often reactive: the next action is predicted from the current observation, instruction, and proprioceptive state. This assumption breaks down in stage-dependent manipulation, where visually similar states may require different actions depending on latent task progress and previous interaction outcomes. We argue that such tasks require not only memory, but dynamics-aware belief updates: the policy should preserve task progress during stable or occluded phases and revise its belief near contact, release, or subgoal transitions. We introduce Temporally Conditioned Memory-Fusion Policies (TFP), a lightweight memory-action framework for VLA backbones. TFP maintains an episode-local task-progress belief with Liquid Time-Constant dynamics and injects the updated belief directly into the flow-matching action decoder through adaptive modulation. This lets temporally accumulated context shape the generated action chunk, rather than serving only as passive history context. With a 3.3B-parameter model, TFP improves the average success rate from \(96.9\%\) to \(98.75\%\) on LIBERO and from \(91.4\%\) to \(93.77\%\) on LIBERO-plus. On the memory-focused MIKASA ShellGameTouch diagnostic, TFP achieves success up to \(75.0\%\). Mechanistic analyses show that write-gain changes near manipulation events are about \(6\times\) larger than far non-event phases, and hidden-state interventions show that the belief causally modulates generated action chunks. These results suggest that compact, event-sensitive memory dynamics can improve VLA policies under occlusion, visual perturbation, and stage-dependent task structure.

# TFP 论文深度总结

## 一、核心问题与研究背景

现有主流的 **Vision–Language–Action（VLA）策略**（如 π₀.₅、OpenVLA、Octo、π₀ 等）虽然在大规模模仿学习下表现优异，但本质上属于**反应式（reactive）策略**：下一动作仅由当前视觉观测、语言指令和本体感受状态直接预测。

这一范式在**阶段依赖型操作（stage-dependent manipulation）**任务中存在结构性缺陷：
- **视觉歧义**：同一视觉状态在不同任务阶段可能对应不同动作（如物体交换任务中相同视觉状态可能对应"放置第一个物体"、"放置第二个物体"或"任务终止"）；
- **部分可观测**：遮挡、接触瞬间的视觉噪声使当前观测无法提供足够的决策依据；
- **缺乏动力学感知**：策略既不会"稳定地保留任务进度"，也不会"在关键事件（接触、释放、子目标完成）附近修正内部信念"。

因此，本文的核心论点是：**VLA 策略不仅需要记忆，更需要与物理时间耦合的、事件敏感的信念更新机制**。

## 二、方法论：TFP 框架

### 2.1 核心思想

TFP（Temporally Conditioned Memory-Fusion Policies）在冻结/微调的 VLA 主干（π₀.₅）基础上引入：
1. 一个**回合局部（episode-local）的隐式信念状态** h_t，由**液态时间常数网络（Liquid Time-Constant, LTC）**动力学维护；
2. 通过 **AdaLN 自适应调制**将该信念直接注入 **flow-matching 动作解码器**，使时序上下文直接塑造生成的动作块；
3. 训练时使用**Episode-Aware Temporal Batching（EATB）**保留回合内隐状态连续性；
4. 推理时使用**自适应滚动视界执行（Adaptive Receding-Horizon Execution）**应对不规则策略查询间隔。

### 2.2 关键技术细节

**（1）连续时间信念更新**
- 候选信念：$\hat{h}_t = \tanh(W_h [x_t; h_{t-1}] + b_h)$
- 输入依赖时间常数：$\tau_t = \text{softplus}(W_\tau [x_t; h_{t-1}] + b_\tau) + \epsilon$
- 保留门控：$k_t = \exp(-\Delta t_t / \tau_t)$，写入增益 $g_t = 1 - k_t$
- 更新规则：$h_t = k_t \odot h_{t-1} + (1 - k_t) \odot \hat{h}_t$

其中 $x_t = [\phi_{\text{vision}}(V_t); \phi_{\text{state}}(s_t)]$ 为紧凑观测表征；$\Delta t_t$ 为自上次查询以来的**实际物理时间间隔**。向量化的 $\tau_t$ 使不同隐通道具有不同的有效时间尺度。

**（2）信念条件动作生成**
- 信念投影：$m_t = W_m h_t + b_m$
- 时间步嵌入：$z_\tau = W_2 \sigma(W_1 \text{PE}(\tau) + b_1) + b_2$
- 加性融合：$c_t = z_\tau + m_t$
- AdaLN 调制：$\hat{x}^{(\ell)} = \text{AdaLN}(x^{(\ell)}, c_t)$，对解码器每一层的归一化激活施加特征维度的仿射调制
- 预测速度场：$v_\theta(a_\tau, \tau \mid I_t, s_t, \ell, h_t)$

这种设计避免了交叉注意力机制，使信念作为紧凑调制信号直接作用于解码器。

**（3）EATB 训练策略**
- 同时采样 B 条 episode，每条展开 K 个连续块；
- 起始时恢复存储的隐状态 $\tilde{h}^{(e_b)}_{\tau_b}$；
- 损失 = B·K 个块的 flow-matching 模仿损失均值；
- 训练步后用 $\text{stopgrad}(\cdot)$ 截断梯度写回 $\tilde{h}^{(e_b)}_{\tau_b+K}$，实现"前向记忆保留 + 反向梯度截断"。

**（4）自适应滚动视界执行**
- 策略始终预测 H 步动作块，但执行器根据块内**抖动、夹爪切换、动作连续性风险**决定执行前缀 $E_t \in [E_{\min}, H]$；
- 下一查询的实际间隔 $\Delta t_{t+1} = E_t \delta t_{\text{ctrl}}$，被传入 LTC 更新。

### 2.3 与相关方法的理论关系（见附录）
- **vs GRU**：GRU 的门控由离散步索引而非物理时间标定，无法保证"相同观测+不同间隔 → 不同保留"；LTC 通过指数保留门满足"历经时间一致性"。
- **vs 固定衰减记忆**：固定衰减是 τ_t = τ_0 的特例；TFP 让时间常数依赖输入。
- **vs SSM**：连续时间 SSM 亦可建模时间依赖，但 LTC 是**非线性、输入依赖、且直接驱动动作生成**的信念融合器。

## 六、主要结论与发现

1. **整体性能提升**：3.3B 参数的 TFP 在 LIBERO 平均成功率 **96.9% → 98.75%**，LIBERO-plus **91.4% → 93.77%**，ShellGameTouch **75%**；
2. **长视距提升最显著**：LIBERO-Long 从 92.4% → 97.0%（+4.6pp，95% CI [+1.8, +7.4]）；
3. **记忆写入具有事件敏感性**：事件 ±6 步内的写入增益变化是远端基线的 **~6 倍**（CI [4.6, 7.9]），且滞后 ≈ −1.6 至 −2.1 步，说明信念更新略**先于**仿真侧事件标签；
4. **信念对动作有因果调制**：固定观测仅替换隐状态，10 步动作块平均成对距离 0.0442（最大 0.1303），而时序相邻隐状态距离仅 0.0108；
5. **时间条件不可省略**：去掉实际 Δt 输入（TFP w/o Δt）后，Long 任务从 97.0% 降至 94.0%，LIBERO-plus 从 93.77% 降至 90.1%；
6. **记忆机制优于通用循环**：GRU 与 S4D 均弱于 TFP，表明**增益并非来自"加了记忆"，而是来自"连续时间 + 直接驱动动作生成"的耦合**；
7. **真实机器人**：Object Swap 3/20 → 15/20，Counting Pick-Place 8/20 → 18/20，主要消除了"重复已完成子任务 / 错入阶段"类失败。

## 七、优点

- **机制设计优雅**：LTC 不仅是连续时间 RNN，更与"信念滤波"在数学上对应——附录 C 证明了指数保留门是满足历经时间一致性的**唯一连续标量保留规则**；
- **轻量注入**：AdaLN 调制避免了交叉注意力带来的 token 序列复杂度，将信念压缩为单一调制向量；
- **训练效率**：EATB 在不进行全程反向传播的前提下保留了回合级前向记忆连续性；
- **评估体系完整**：仿真基准 + 真实机器人 + 机制可解释性 + 统计 CI，覆盖充分；
- **公平消融**：所有同骨架变体统一在相同自适应执行器下测试，隔离了"记忆机制"和"执行调度"两个变量；
- **错误模式分析细致**：在真实实验中区分了 Stage / Repeat / Target / Exec 四类失败，定位了 TFP 真正改进的维度；
- **理论严谨**：对 LTC 更新给出 ODE 解析解与历经时间一致性的唯一性证明，避免了"启发式设计"的口径。

## 八、不足与局限

- **训练成本高**：在 4×H200、>100GB 显存下训练 80 小时才达到饱和，对中小实验室门槛较高；
- **真实世界覆盖窄**：仅单臂桌面抓放，未涉及移动机械臂、双手、灵巧手；
- **ShellGameTouch 仍有差距**（75% vs MemoryVLA 88%）：作者承认这是 TFP 的设计盲区——其面向"连续时间事件敏感动力学"，而非"离散对象—位置绑定"，需补充对象中心化记忆模块（如 slot memory）；
- **基准饱和与对比口径**：LIBERO 多个 split >98%，改进空间受限；与文献基线不可直接比较；
- **真实实验样本量小**：20 trials/方法/任务，CI 区间宽；
- **消融维度仍可扩展**：未消融 AdaLN vs 交叉注意力、未消融向量 τ vs 标量 τ、未消融 EATB 长度 K、未分析不同动作视界 H 的影响；
- **自适应执行器带来的混杂**：所有受控消融均在同一自适应执行器下评测，虽然保证了公平，但也意味着 TFP w/o Δt 的"Δt 实际被使用但被替换为常数"这一变量与执行器耦合，难以完全分离；
- **可重复性细节**：附录未公开学习率、warm-up、scheduler 等关键超参数。
