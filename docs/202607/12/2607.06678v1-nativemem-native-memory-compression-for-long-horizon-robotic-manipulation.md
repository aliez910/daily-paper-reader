## 摘要
如何使预训练的视觉-语言-动作（VLA）模型在保留长时程视觉历史的同时支持高频更新，且不牺牲效率？现有方法依赖于外部记忆管理，这限制了记忆跨度或预训练策略的响应性。为此，我们提出了 NativeMEM，一种具有长期且实时更新记忆的 VLA 策略。其核心是一种高效的记忆编码方案——原生记忆压缩（Native Memory Compression），它复用了 VLA 自身的视觉编码器，将每个相机视角的每一历史帧压缩为单个标记。这些记忆标记被附加到输入序列中，使预训练的 VLA 能够以可忽略的延迟开销关注长期历史，既不需要外部规划器，也不需要新初始化的记忆模块。为了将记忆标记与预训练策略对齐，我们首先在需要记忆的数据上，利用冻结的 VLA 训练一个通用的记忆分词器，然后解冻 VLA 进行任务特定的微调。NativeMEM 一致优于先前方法，在仿真中将成功率从 32.4% 提升至 84.0%，在真实机器人上最高可达 98.7%，同时保持较低的推理延迟和 GPU 显存占用。值得注意的是，NativeMEM 展现出很高的数据效率，仅使用 20% 的训练数据即可取得与先前方法相当的竞争性结果。

## Abstract
How can pretrained Vision-Language-Action (VLA) models retain long-horizon visual histories with high-frequency updates without sacrificing efficiency? Existing approaches rely on external memory management, which restrains either the memory horizon or the reactiveness of pretrained policies. To this end, we present NativeMEM, a VLA policy that features long-term and real-time updated memory. At its core is an efficient memory encoding scheme, Native Memory Compression, which repurposes the VLA's own vision encoder to compress each historical frame from each camera view into a single token. Appended to the input sequence, these memory tokens enable the pretrained VLA to attend over long-term history with negligible latency overhead, requiring neither an external planner nor a freshly initialized memory module. To align the memory tokens with the pretrained policy, we first develop a generic memory tokenizer under the supervision of a frozen VLA on memory-demanding data, and then unfreeze the VLA for task-specific fine-tuning. NativeMEM consistently outperforms prior methods, boosting success rates from 32.4% to 84.0% in simulation and up to 98.7% on real robots, while maintaining low inference latency and GPU memory usage. Notably, NativeMEM exhibits high data efficiency by achieving competitive results with prior arts using only 20% of the training data.

# NativeMEM 论文总结

## 1. 核心问题与研究背景

- **研究对象**：预训练的视觉-语言-动作（Vision-Language-Action, VLA）模型在机器人操控任务中的长时程记忆能力。
- **关键瓶颈**：
  - 现有 VLA（如 π0.5、OpenVLA 等）多为**单帧反应式**策略，仅以当前观测和指令为条件，无法应对非马尔可夫的长时程任务（需要计数、识别遮挡物体、跟踪任务进度、避免重复失败等）。
  - 长时程操控任务中，相同当前观测在不同历史下可能要求不同动作（公式 (2) 所述）。
- **现有方案的不足**：
  - **VLM 驱动的外部记忆**：用高层 VLM 检索关键帧并生成文本子任务描述给低层 VLA 控制——子任务标注成本高、文本难以精确表达细微视觉信息。
  - **外部记忆模块**：在 VLA 内新增循环状态、压缩历史或检索式记忆库——未在预训练中见过的新模块会损害预训练先验，且面临**压缩困境**（不够压缩则历史过长，过度压缩则丢失关键细节）。

## 2. 方法论

### 2.1 核心思想：Native Memory Compression（原生记忆压缩）

- **极简压缩**：将每个相机视角的每一历史帧压缩为**单个 token**（M = 1），即 $|M_t| = V \cdot T \cdot N \cdot M$ 中的 M 取极限。
- **复用 VLA 自身视觉编码器**：从预训练 VLA 的视觉编码器派生一个 memory tokenizer $E_{mem}$，添加可学习的 memory query token $q_{mem}$，通过注意力聚合视觉 patch tokens：
  - $\hat{q}_{v\tau}, \hat{P}_{v\tau} = E_{mem}([q_{mem}, P_{v\tau}])$
  - $m_{v\tau} = W_{mem} \hat{q}_{v\tau}$
- **融入原始 token 序列**：在 BOS token 之后附加可学习的 memory BOS $b_{mem}$ 与各历史帧-视角的记忆 token，与当前观测、prompt tokens 拼接后送入 VLA，无需修改 VLA 架构。

### 2.2 两阶段训练流程

- **Stage 1 — 通用 Memory Tokenizer 学习（冻结 VLA）**：
  - 训练框架：用标准操控数据 + 需要记忆的任务数据混合训练；训练时 memory 序列 $I_t$ 由 episode 首帧 + 近期窗口组成（含当前帧）。
  - 优化目标：最小化 VLA 自身的 **动作预测损失** $\mathcal{L}_{act}$（公式 (9)），仅更新 memory 分支参数 $\{\phi_{mem}, q_{mem}, W_{mem}, b_{mem}\}$。
  - 意义：迫使 memory token 既包含动作相关信息，又与冻结 VLA 的 token 空间对齐，避免重建式监督带来的"无关注细节"问题。
- **Stage 2 — 任务特定微调**：
  - 离线缓存所有 frame-view 的 memory token（每帧一个 token，存储开销小）。
  - 冻结 memory tokenizer encoder，对 VLA 主干、action head 与 memory projection 在有限任务演示数据上进行微调（公式 (10)）。
- **实时记忆推理**：memory tokenizer 与 VLA 策略解耦——tokenizer 以指定频率独立更新 memory 队列，VLA 查询动作时直接拼接最新压缩记忆序列，实现高频更新 + 长时程保留。

## 6. 主要结论与发现

- 仿真平均成功率：32.4% → **84.0%**，全部 5 个任务均达到 SOTA。
- 真机平均累计成功率：34.7% → **98.7%**，且在 **Grocery Checkout Scanning（Stage 1 未训练）** 上仍达到 100%，表明 native memory token 表征具备良好的任务泛化能力。
- 长时程能力：支持分钟级历史（>160 frames，单视角），历史跨度为先前方法的 **9×~40×**。
- 推理高效：32GB 显存预算下可处理约 5000 帧，100 ms 实时约束下仍可关注约 200 帧。
- 数据高效：仅 10 条演示即达 60% 平均成功率（约为 Mem-0 的 3.5×）。
- 关键消融发现：
  - Stage 1 与冻结 VLA 训练必不可少（解冻 VLA 后性能降至 23.2%，表明会损害预训练先验）；
  - 高频更新（>0.5Hz）与长时窗（>6s）均显著影响性能，二者缺一不可。

## 7. 优点

- **架构兼容性强**：复用 VLA 自身视觉编码器，避免引入外部模块或文本化中间表征，最大限度保留预训练先验。
- **极致压缩**：M=1 的单 token/帧-视角设计，使分钟级高频记忆在算力预算内可行。
- **训练解耦**：memory 构造与 VLA 推理解耦，可高频独立更新；离线缓存亦降低 I/O 与存储成本。
- **动作监督而非重建监督**：使 memory token 直接面向动作相关性，避免通用视觉特征的"语义脱节"。
- **数据/算力效率突出**：仅 5 小时微调 + 20% 数据即达到可比性能，对实际部署友好。
- **可解释性**：通过 tokenizer 空间注意力和 action→memory 注意力可视化，展示出策略确实聚焦于任务相关历史时刻。

## 8. 不足与局限

- **超长时尺度不适用**：明确不针对小时/天级持续记忆，需额外的系统级记忆基础设施。
- **监督信号局限**：memory tokenizer 仅由动作损失监督，作者自陈可能在更复杂任务中暴露"低层动作损失 vs 高层抽象记忆需求"间的语义鸿沟。
- **真机任务数量与多样性有限**：仅 3 个真机任务、且部分使用相同演示数据，规模与场景多样性偏弱。
- **backbone 选择偏单一**：主实验基于 π0.5，未充分验证方法在其他 VLA（如 OpenVLA、π0）上的迁移性。
- **评测基线说明**：HAMLET、MEM-short 均为作者自行复现（非官方代码），可能与原工作存在实现差异，存在一定复现偏差风险。
- **算力信息缺失**：未报告 GPU 类型、数量与训练时长，限制了与其他方法在算力维度的可比性。
- **高频更新与高频推理的耦合未充分分析**：论文将 tokenizer 更新频率与 VLA 推理频率解耦，但对两者在不同步长组合下的鲁棒性探讨不深入。
