## 摘要
以语言为条件的操控任务既需要对富含接触环节的精细控制，也需要对语言、场景与长时程的稳健推理。端到端的视觉-语言-动作（VLA）模型具有强大的局部视觉运动技能，但其训练数据均为分布内的任务轨迹，在部署阶段的扰动下常常失效，例如语义目标重定向、目标重新绑定、空间布局变化以及局部接触的不稳定。大语言模型编码智能体能够提供互补的语义与组合推理能力，但纯解析式原语难以应对不规则抓取、受限放置以及铰接物体交互等场景。为此，我们提出 Harness VLA——一种记忆增强的智能体框架。该框架将冻结的 VLA 暴露为一个可重试的富含接触的原语，并将其与一个小型且固定的解析式原语库组合，用于对位、暂存、搬运、导航与释放等环节。框架并未扩张技能库，而是通过任务专属的执行轨迹、全局成功规则与失败模型，学习这些固定原语的适用区间。语义重新对位、非接触式执行与 VLA 重暂存等职责被上提至规划器，而冻结的 VLA 仅保留用于局部的富含接触阶段，从而使 Harness VLA 在无需微调的前提下，将预训练 VLA 的适用边界拓展至其原始轨迹分布之外。在扰动化的桌面、家庭厨房以及从规整到随机化的双手操控场景中，Harness VLA 在 LIBERO-Pro 与 RoboCasa365 上相较最强相关基线分别提升 38.6 与 25.4 个百分点，并在 RoboTwin C2R 上达到 58.4%。

## Abstract
Language-conditioned manipulation requires both precise contact-rich control and robust reasoning over language, scenes, and long horizons. End-to-end Vision-Language-Action (VLA) models provide strong local visuomotor skills, but they are trained on in-distribution task trajectories and often fail under deployment perturbations such as semantic retargeting, goal re-binding, spatial-layout shifts, and unstable local contacts. LLM coding agents provide complementary semantic and compositional reasoning, but purely analytic primitives struggle with irregular grasping, constrained placement, and articulated-object interaction. We present Harness VLA, a memory-augmented agentic framework that exposes a frozen VLA as a retryable contact-rich primitive and composes it with a small fixed library of analytic primitives for grounding, staging, transport, navigation, and release. Rather than expanding the skill library, the harness learns the operating range of these fixed primitives from task-specific execution traces, global success rules, and failure models. By lifting semantic re-grounding, non-contact execution, and VLA re-staging to the planner while reserving the frozen VLA for local contact-rich phases, Harness VLA extends pretrained VLAs beyond their original trajectory distribution without finetuning. Across perturbed tabletop, household kitchen, and clean-to-randomized bimanual manipulation, Harness VLA improves over the strongest relevant baselines by 38.6 and 25.4 percentage points on LIBERO-Pro and RoboCasa365, respectively, and reaches 58.4% on RoboTwin C2R.

## 1. 核心问题与研究动机

**核心问题**：语言条件下的机器人操控需要同时具备两类能力——精确的接触密集型控制（如不规则抓取、铰接物体操作）和长程语义推理（如目标重定向、布局变化适应）。然而现有的两大主流范式各自存在明显短板：

- **端到端 VLA 模型**（如 π0、π0.5、OpenVLA、RLinf）：在训练分布内的接触丰富视觉运动任务上表现强劲，但在语义目标重定向（Task-T）、位置互换（Pos-S）等部署扰动下，指令-场景绑定容易失效，表现为重复训练时行为而忽略新指令；同时单次接触失败会沿整个长程轨迹级联传播。
- **LLM 编码智能体**（如 Code-as-Policies、ProgPrompt、CaP-X）：擅长语义组合推理与程序合成，但纯解析式原语（IK 搬运、夹爪开闭等）在不规则抓取、约束放置、关节物体交互等任务上能力不足。

**整体含义**：论文指出，问题根源在于两个范式都把"错误的组件赋予了过多责任"——单块 VLA 同时承担语义解析、长程组合与底层控制；纯分析智能体则试图用脚本式原语实现物理上精细的接触行为。Harness VLA 提出一种"非对称分责"的折中：把冻结的 VLA 降级为一个**可重试的接触密集型原语**，由 LLM 规划器在外部负责语义重锚定、暂存调度与重试，使 VLA 的适用边界扩展到其原始轨迹分布之外，且全程无需微调。

## 2. 方法论

### 2.1 核心思想

构建一个**记忆增强的智能体框架**，把异构的视觉-语言-动作模型统一抽象为单一接触原语 `VLA_ACT`，并与一组小型且**固定的**解析式原语库组合，由 LLM 规划器在高层调度。原语库不是扩张的，而是**通过任务级执行轨迹、全局成功规则与失败模型学习其适用区间**。

### 2.2 系统架构与执行循环

- **观察输入**：RGB 图像 + 对齐深度图 + 机器人本体感知状态 $q_t$。
- **任务形式化**：任务由自然语言描述 $\ell$ 和仅在回合终止时返回的二值完成谓词 $G$ 定义。
- **执行循环**：规划器 $\Pi$ 在每个回合 $t$ 接收观察 $o_t$、任务 $\ell$、记忆上下文，输出一个 JSON 结构化的原语调用 $c_t \in \mathcal{P}$；物理引擎执行至原语内部后置条件满足后，返回下一观察 $o_{t+1}$。循环直到谓词满足或步数预算耗尽。

### 2.3 统一原语接口 $\mathcal{P}$

原语库是规划器唯一可调用的操作集合，分为两类：
- **分析原语**（无训练数据、模型无关）：
  - 复合型：`MOVE_TO`、`MOVE_POSE`、`NAVIGATE_TO`（RoboCasa365）
  - 原子型：`ROTATE_WRIST`、`ROTATE_PITCH`、`SET_GRIPPER`、`RELEASE`、`MOVE_BASE`（RoboCasa365）
- **VLA 原语**：`VLA_ACT` —— 输入 prompt + 实时相机观测，输出 action chunks；可配置早停谓词 $\tau$。

**关键约束**：原语词表在评估前固定，规划器不可在部署时发明新原语。

### 2.4 智能体生命周期

- **探索引导阶段**（Exploratory Bootstrapping）：在任务的参考实例上，允许使用 `RESET` 原语和宽裕时间预算；规划器自主发现最优的解析式与 VLA 原语编排。成功后，将执行轨迹序列化为参数化 JSONL（空间参数用符号感知查询代替绝对坐标）写入 **Task Specific Memory**，并将通用启发式（成功规则 + 失败模型）提炼到 **Global Memory**。
- **部署评估阶段**：禁用 `RESET`、压缩步数预算；规划器检索 Task Specific Memory 的 JSONL 轨迹作为结构先验，并依据实时 RGB-D 观测重新对位（re-grounding），再执行。

### 2.5 记忆机制

- **Task Specific Memory**：以参数化 JSONL 形式记录成功的原语调用序列 + JSON 审计（策略、避免项），用于 few-shot 重锚定。
- **Global Memory**：跨任务的可复用成功规则（如"使用完整任务指令作为 prompt"）与失败模型（如"空抓失败需重定位后重试"、"不可仅凭视觉近似判定成功"）。
- **Global Memory 示例**：
  - 成功规则：接触丰富阶段用 VLA，稳定抓取后长距离搬运用分析原语。
  - 失败模型：若夹爪闭合但物体未随末端移动，则视为空抓；必须查询基准完成信号而非仅靠视觉判断成功。

### 2.6 文件中介 REPL 协议

长期运行的环境 worker 拥有仿真器状态，规划器只能通过写入 `command.json` 与读取 `state_NN.json`、`log_NN.json` 等序列化文件交互，不访问特权仿真器状态或物体坐标。空间参数通过 RGB 选像素 → 索引世界图 → 取中位数的方式获得。

## 6. 主要结论与发现

1. **大幅领先 SOTA**：
   - LIBERO-Pro 总体 **82.4% (CC) / 72.1% (Codex)** vs RATS 43.8%（强基线 +38.6 个百分点）；
   - RoboCasa365 任务加权 **55.4% (Codex) / 48.6% (CC)** vs RLDX-1 30.0%（+25.4 个百分点）；
   - RoboTwin C2R **58.4% (CC) / 58.0% (Codex)** vs 直接 LingBot-VLA 50.4%；
   - 标准 LIBERO 维持 **96.0%**（vs RLinf 95.3%），证明未损失分布内性能。
2. **零样本同样有效**：在 LIBERO-Pro Goal 上禁用 Task Specific Memory 后 Harness VLA (CC) 仍达 79.0% (T) / 31.0% (S)，显著优于 Cap-X 的 16.8% / 25.6%。
3. **机制结论**：
   - 端到端 VLA 在扰动下行为弱依赖于任务描述与场景绑定（如图 3 所示 RLinf 在 OBJECT-Pro T 与 GOAL-Pro S 上的失败模式）；
   - 规划器阶段性调用 VLA 并支持重试显著提升成功率，且 VLA 调用稀疏（图 4 表明几次调用即可超过冻结基线，进一步调用趋于饱和）；
   - 分析原语承担非接触执行：LIBERO 84.2% 调用为分析原语、RoboCasa365 64.7%、RoboTwin C2R 52.6%，验证"分析原语组织任务、VLA 提供接触阶段"的不对称分工。
4. **核心论断**：预训练 VLA 的语言通道在扰动下基本失效（vestigial），将语义与空间绑定抽象到规划器层可避免单体部署的灾难性失败。

## 7. 优点 / 方法亮点

- **非对称分责的范式创新**：明确将"接触丰富局部控制"与"语义解析+长程组合"分配给不同组件，绕开了"端到端 VLA 必须同时做好一切"的隐含假设。
- **冻结 VLA 不微调**：所有 VLA 后端全程冻结，仅通过原语组合实现能力扩展，降低了对大规模机器人数据的依赖。
- **原语库固定但学习操作区间**：避免了在部署时膨胀技能库（与 ASPIRE 的可扩展库形成对比），通过 Task Specific + Global Memory 让规划器学会"何时调用哪个原语"。
- **稀疏、可重试的 VLA 调用**：将 VLA 当作"接触尝试"而非"全程控制"，配合规划器重暂存，显著提升鲁棒性；图 5 案例展示了失败的抓取可被重试覆盖而非级联终止。
- **感知隔离与文件中介 REPL**：规划器只能通过 RGB-D + 世界图感知空间，无特权坐标访问，部署更接近真实场景。
- **跨基准统一原语接口**：同一 `VLA_ACT` 接口适配 π0.5-SFT、RLDX-1、LingBot-VLA 三个异构 VLA，并支持桌面、单臂移动厨房、双臂三种 embodiment。
- **零样本同样有效**：Libero-Pro Goal 零样本结果证明规划器在线推理而非仅靠记忆回放。
- **详尽的附录**：包括文件协议、原语可用性矩阵、评估协议、prompt 设计、训练超参数与原语调用统计（附录 F 表 18-19），可复现性强。

## 8. 不足与局限

- **算力与训练细节不透明**：未披露 LLM 推理总成本、仿真环境 GPU 配置、rollout 总耗时；LingBot-VLA 后训练仅给出超参数而未给出 GPU 数量与 wall-clock 时长。
- **缺乏 RL / RLHF 联合微调**：作者明确指出高层规划器与底层 VLA 之间是**开放反馈回路**，且系统缺少基于环境奖励或人类偏好的联合微调（如 GRPO），限制了在样本高效策略改进上的潜力。
- **缺乏细粒度图像描述**：在高度杂乱或长程任务中，结构化推理受限于视觉-语言模型的描述粒度。
- **基准对比的口径不完全对齐**：
  - RATS、Cap-X 仅在部分 LIBERO-Pro 单元格报告数据，可能略高估其总体表现；
  - Harness VLA 使用 Task Specific Memory 进行 few-shot 重对位，而基线的协议细节未充分对齐，存在协议层面的不公平风险。
- **失败分析偏定性**：Key Findings 主要依赖成功率曲线与少量 rollout 可视化，缺少对失败类型的系统化分类（如空抓、错位抓取、空间推理错误等）的统计分布。
- **依赖闭源 LLM 规划器**：实验基于 Codex 与 Claude Code，缺乏对开源/本地模型（如 Qwen3-VL、Molmo）作为规划器的全面评估，限制了方法的复现性与成本透明度。
- **VLA 调用开销**：尽管稀疏，但每次 VLA 调用仍需完整的 action chunk 推理，且当前接口未提供对 VLA 内部状态的细粒度访问（例如中途暂停/继续），限制了在长程任务中的精细控制。
- **未探索自动技能发现**：作者在结论中将 ASPIRE 风格的自动技能增长列为未来方向，但当前框架严格保持原语词表固定，在新增 embodiment（如腿足/人形）或新接触模式时仍需人工扩展词表。
- **基准偏仿真**：所有评估均在 MuJoCo / Robosuite 类仿真器中完成，未涉及真实硬件部署的 sim-to-real gap。
