## 摘要
视觉-语言-动作（VLA）模型已成为通用机器人操作的一种有前景的范式，其中视觉-语言表征被用于条件化连续动作的生成。然而，这些表征并未针对动作条件化进行显式优化，使得动作专家模块需要弥合多模态理解与精确运动控制之间的差距。近期的动作推理方法引入额外的模块来生成显式的动作规划或动作空间推理信号，展现了动作级引导的益处，但通常需要独立的动作生成框架。我们提出CAC-VLA，一种上下文门控动作条件化框架，直接在VLM中学习一个轻量级的潜在动作接口。CAC-VLA并不生成可执行的轨迹，而是训练VLM预测由粗到细的潜在动作——这些是从未来动作片段编码而来的结构化表征——并通过上下文门控自适应地利用它们来条件化动作专家。这实现了VLM原生的动作条件化，同时校准潜在动作引导对专家动作生成的影响。在LIBERO和LIBERO-Plus上的实验证明了CAC-VLA的有效性，在LIBERO上达到了98.3%的平均成功率，在LIBERO-Plus上达到了89.5%，表明上下文门控的潜在动作条件化是面向连续专家控制的一种有效接口。

## Abstract
Vision-Language-Action (VLA) models have become a promising paradigm for generalist robot manipulation, where visual-language representations are used to condition continuous action generation. However, these representations are not explicitly optimized for action conditioning, leaving the action expert to bridge the gap between multimodal understanding and precise motor control. Recent action-reasoning methods introduce additional modules to generate explicit action plans or action-space reasoning signals, demonstrating the benefit of action-level guidance but often requiring separate action-generation frameworks. We propose CAC-VLA, a Context-Gated Action Conditioning framework that learns a lightweight latent-action interface directly within the VLM. Instead of generating executable trajectories, CAC-VLA trains the VLM to predict coarse-to-fine latent actions, which are structured representations encoded from future action segments, and adaptively leverages them to condition the action expert via a context gate. This enables VLM-native action conditioning while calibrating the influence of latent-action guidance on expert action generation. Experiments on LIBERO and LIBERO-Plus demonstrate the effectiveness of CAC-VLA, achieving 98.3% average success rate on LIBERO and 89.5% LIBERO-Plus, suggesting that context-gated latent-action conditioning is an effective interface for continuous expert control.

# CAC-VLA 论文总结：面向视觉-语言-动作模型的上下文门控动作条件化

## 1. 核心问题与研究背景

- **核心问题**：现有视觉-语言-动作（VLA）模型虽以视觉-语言表征作为多模态理解与连续动作生成之间的桥梁，但这些表征并非针对"动作条件化"进行显式优化，使得动作专家（action expert）需要自行弥合高层语义理解与底层精确控制之间的鸿沟。
- **现有方案的不足**：
  - 语言级方法（如子目标分解、文本计划）距动作空间过远；
  - 视觉级方法（如目标图像、未来观测）仍非动作结构化的表征；
  - 近期动作推理方法（如ACoT-VLA）虽引入显式动作规划或动作先验，但通常需要额外的独立动作生成/推理框架，且往往将动作引导作为**固定强度**的条件化信号，忽略了其在不同任务阶段、场景下的可靠性差异。
- **本文关注的关键问题**：能否在 VLM 内部嵌入一个**显式的潜在动作接口**，并由动作专家**自适应校准**该引导信号对连续控制的影响？

## 2. 方法论

### 2.1 整体框架
- **CAC-VLA（Context-Gated Action Conditioning for VLA）**：在 VLM 内部学习一个轻量级潜在动作接口，由 VLM 预测由粗到细的潜在动作（latent actions），并通过**上下文门控**自适应地将该引导注入到动作专家中。
- **核心思想**：不在 VLM 或辅助模块中生成可执行轨迹，而是预测"潜在动作"——由未来动作段编码得到的结构化表征。

### 2.2 关键技术细节

1. **有序动作分词器（OAT）监督**：
   - 利用冻结的 OAT（Ordered Action Tokenizer）将未来 $H_l$ 步动作段编码为原始 latent 向量 $\mathbf{z}^{oat}_t$。
   - OAT 提供由粗到细（coarse-to-fine）的有序潜变量结构。

2. **VLM 侧潜在动作预测**：
   - 在 VLM 输入中附加 $N_q=8$ 个可学习的 latent query tokens $\mathbf{q}$。
   - **专家感知注意力掩码**（expert-aware attention mask）阻断动作专家 token 直接关注 query tokens，确保 query tokens 仅通过预测出的潜在动作影响专家。
   - 预测头将 query 隐状态投影回 OAT 潜空间：$\hat{\mathbf{z}}_t = W_z \cdot \text{LN}(\mathbf{h}^q_t)$。
   - 监督损失为 token 级 Smooth-L1：$\mathcal{L}_{align} = \frac{1}{P}\sum_i m_i \cdot \text{SmoothL1}(\hat{z}_{t,i}, z^{oat}_{t,i})$。

3. **上下文门控动作条件化（Context-Gated Action Conditioning）**：
   - 训练时以 $\mathbf{z}^{oat}_t$ 作为条件化源，推理时切换为 VLM 预测的 $\hat{\mathbf{z}}_t$；
   - 经线性投影得到条件化 token $\mathbf{c}_t$，对专家动作隐状态 $\mathbf{x}_l$ 做交叉注意力检索：
     $$\mathbf{u}_l = \text{CrossAttn}(Q=\bar{\mathbf{x}}_l, K=\mathbf{c}_t, V=\mathbf{c}_t)$$
   - 上下文门控 $g_l = \sigma(W_g \tanh(W_x s^x_l + W_u s^u_l))$，其中 $s^x_l, s^u_l$ 分别为 $\bar{\mathbf{x}}_l$ 和 $\mathbf{u}_l$ 的 AvgPool。
   - 通过**门控残差**注入：$\mathbf{x}^+_l = \mathbf{x}_l + g_l \odot \mathbf{u}_l$。
   - 设计为：先检索，后按当前动作生成上下文校准注入强度，分离"取信息"与"注入量"。

4. **训练目标**：$\mathcal{L} = \mathcal{L}_{act} + \lambda_{align} \mathcal{L}_{align}$，其中 $\mathcal{L}_{act}$ 为原始 flow-matching 损失。

## 6. 主要结论

- **LIBERO**：平均成功率 98.3%，在 Object（99.8%）、Goal（99.6%）子套件表现突出，Spatial 与 Long 也保持高位。
- **LIBERO-Plus（SFT）**：平均成功率 89.5%，超过 ACoT-VLA（88.0%）与 π0.5（85.7%）基线；在灯光、背景、噪声、布局偏移下优势明显。
- **消融结论**：中等 horizon（$H_l=20$）最佳；门控机制（97.9%→98.3%）与潜在动作条件化（98.0%→98.3%）均带来提升。
- **真实世界**：pick-and-place Task Score 72%（+24pp）、Full SR 64%（+48pp，16/25）；block-stacking SR 52%（13/25），相对 π0.5 分别提升 16pp 与 16pp。
- **核心结论**：上下文门控的潜在动作条件化可作为 VLM 原生接口，为连续动作专家提供动作结构化引导，并按任务阶段与生成状态自适应校准。

## 7. 优点与方法亮点

- **VLM 原生的动作接口**：无需独立的动作推理器/生成器，潜在动作预测完全在 VLM 内由 query tokens 实现，降低系统复杂度。
- **检索-注入分离设计**：门控只在"取回多少"层面调节，而非固定融合，保留专家自身的连续动作建模容量。
- **由粗到细的有序监督**：利用 OAT 的有序潜变量，提供未来动作的多尺度结构信息，时间跨度灵活可配。
- **行为可解释性**：可视化显示门控值随 flow step、任务套件、操控阶段变化，佐证自适应校准的合理性。
- **兼容性强**：保持原 π0.5 架构与 flow-matching 专家，仅需新增少量参数与一次额外对齐损失。

## 8. 不足与局限

- **真实世界覆盖有限**：仅一台 UR7e 机械臂、两个桌面任务（pick-and-place 与 block-stacking），每任务仅 50 次演示与 25 次评估试验，难以全面反映真实场景的鲁棒性。
- **固定 latent horizon**：$H_l$ 为预设超参，未做任务自适应或分层化处理；当任务阶段或 horizon 跨度变化时，灵活性不足。
- **潜在动作的可靠性边界**：当 VLM 预测的 latent action 不准确时，可能会向专家注入噪声；论文未深入分析失败模式。
- **方法依赖性**：监督信号来源于冻结的 OAT tokenizer，方法性能上限与跨平台迁移能力受 OAT 表达能力的制约。
- **实证充分度**：尽管仿真端消融较系统，但真实世界消融与公平性比较维度有限（例如未对 latent horizon、门控在真实任务上的影响做消融）。
- **任务复杂度**：仿真任务相对"短时"，尚不能体现长程、复杂动作规划下门控动态的稳定性与价值。
