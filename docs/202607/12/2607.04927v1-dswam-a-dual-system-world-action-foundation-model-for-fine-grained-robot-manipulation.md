## 摘要
世界动作模型（World Action Models, WAMs）为机器人动作学习提供了一种有前景的替代方案，它利用基于视频的世界建模作为密集监督信号，取代视觉-语言-动作（Vision-Language-Action, VLA）策略。现有的WAMs擅长物理层面的执行，但通常缺乏基于VLM的VLA中所具备的显式语言级规划接口，难以将粗粒度指令进行分解。当家务任务涉及复杂的多步骤目标时，需要将粗粒度的用户指令转换为一系列细粒度的可执行子任务，这种分解能力变得尤为重要。同时，由于现有系统在数据、机器人本体形态和任务协议上往往存在差异，该领域仍然缺乏VLA与WAM执行能力之间公平的真实机器人比较。为同时解决分解能力不足以及开展受控的WAM-VLA对比的需求，我们提出了DSWAM，一种用于细粒度机器人操作的双系统世界动作基础模型。DSWAM将系统1的WAM执行器作为默认的控制路径，仅在任务分解有用时可选地激活系统2的视觉-语言子任务规划器。规划器根据短期视觉历史和全局任务提示预测可执行的子任务，而WAM执行器则为每条指令或子任务进行具有世界感知的动作生成。执行器通过动作预测和视频联合训练进行训练，但推理时直接预测动作块，无需显式生成未来视频。为了使该执行路径在实际机器人上切实可行，我们进一步集成了TensorRT加速、异步执行和实时分块（RTC）策略，以确保策略查询不会阻塞机器人控制。为与VLA策略进行公平的真实机器人对比，我们在DeMaVLA真实世界可形变物操作设定下构建并评估DSWAM，在机器人平台、预训练数据、后训练数据和评估标准方面进行了严格匹配。

## Abstract
World Action Models (WAMs) provide a promising alternative to Vision-Language-Action (VLA) policies by using video-based world modeling as dense supervision for robot action learning. Existing WAMs excel at physically grounded execution, but typically lack the explicit language-level planning interface in VLM-based VLAs for decomposing coarse instructions. Such decomposition becomes important when household tasks involve complex multi-step goals, where coarse user commands need to be converted into sequences of fine-grained executable subtasks. Meanwhile, the field still lacks a fair real-robot comparison between VLA and WAM execution capabilities, since existing systems often differ in data, robot embodiments, and task protocols. To address both the decomposition gap and the need for a controlled WAM-VLA comparison, we introduce DSWAM, a Dual-System World Action Foundation Model for fine-grained robot manipulation. DSWAM keeps a System 1 WAM executor as the default control path and optionally activates a System 2 vision-language subtask planner only when task decomposition is useful. The planner predicts executable subtasks from short-term visual history and a global task prompt, while the WAM executor performs world-aware action generation for each instruction or subtask. The executor is trained with action prediction and video co-training, but inference directly predicts action chunks without explicit future video generation. To make this execution path practical on real robots, we further integrate TensorRT acceleration, asynchronous execution, and real-time chunking (RTC) so that policy queries do not block robot control. To provide a fair real-robot comparison with VLA policies, we build and evaluate DSWAM under the DeMaVLA real-world deformable manipulation setting with matched robot platform, pretraining data, post-training data, and evaluation criteria.

# DSWAM 论文总结

## 1. 核心问题与研究动机

- **WAM 与 VLA 的能力错位**：现有世界动作模型（World Action Models, WAMs）以视频世界建模为密集监督，在接触丰富、物体可形变的物理执行上表现优异，但缺少类似 VLM-based VLA 那样的显式语言级规划接口，难以将粗粒度用户指令拆解为有序的可执行子任务。
- **复杂多步家务任务的现实需求**：当指令涉及"整理桌面"或"分拣衣物"等多步骤目标时，需要在执行前进行语义级别的任务分解，而 WAM 通常只作为底层执行策略，无法直接提供该能力。
- **公平对比的缺失**：以往 WAM 与 VLA 的对比常因数据规模、机器人本体（embodiment）、任务协议与评估标准的不同而产生混淆，难以判断性能差异究竟来自策略设计还是实验设置。
- **工程部署挑战**：基于视频的 WAM 在推理时若显式生成未来视频会带来较高延迟，不利于真实机器人的闭环控制。

## 2. 方法论

### 2.1 整体框架：双系统设计
- **System 1（WAM 执行器）**：默认控制路径，接收多视角 RGB、语言条件（原始指令或 System 2 子任务）与本体感知状态，输出连续动作块（action chunks），不进行显式的未来视频生成。
- **System 2（视觉-语言子任务规划器）**：可选高层模块，仅在粗指令需要分解时激活；基于类 Rynnbrain4B（4B 参数）的 VLM，输入 5 帧短期视觉历史（1 Hz 采样）与全局任务提示，输出下一条细粒度子任务。
- **协同机制**：部署时每 Δt = 2 s 由执行器向规划器发送最新 5 帧，规划器返回的子任务作为新的语言条件控制 System 1，直到下一次更新；WAM-only 模式下 System 2 不启动，直接以原始指令为条件。

### 2.2 System 2 规划器训练
- **子任务边界监督**：用预训练 VLM 标注器将轨迹视频切分为带时间边界 τ_k 的子任务段 s_k。
- **过渡感知标签**：滑窗 W_i 内若位于子任务 k 中间，则监督目标为 s_k；若为非终止子任务 k 的最后窗口，则监督为 s_{k+1}；若为终止子任务最后窗口，则输出 `done`。
- **损失函数**：标准自回归语言建模目标
$$
\mathcal{L}_{\text{plan}}(\phi) = -\mathbb{E}_{(X_t, p, y_t)}[\log P_\phi(y_t | X_t, p)]
$$

### 2.3 System 1 WAM 执行器
- **视觉骨干**：基于预训练视频模型 Wan2.2-TI2V-5B，编码当前多模态上下文到潜变量世界特征 $z_t = f_\theta(I_{1:3}^t, \ell_t, q_t)$。
- **动作预测**：直接从 $z_t$ 预测连续动作块 $p_\theta(A_t | O_t) = p_\theta(A_t | z_t)$，采用条件流匹配（conditional flow matching），适合双臂操作的连续动作分布。
- **训练目标**：动作损失 + 视频联合训练损失的统一流匹配形式
$$
\mathcal{L}_{\text{FM}}(y) = \mathbb{E}_{y,\epsilon,\tau}\left[\|v_\theta(y_\tau, \tau, O_t) - (\epsilon - y)\|_2^2\right]
$$
$$
\mathcal{L} = \mathcal{L}_{\text{act}} + \lambda_{\text{vid}}\mathcal{L}_{\text{vid}}
$$
- **关键设计**：训练时用未来视觉潜变量提供世界建模监督，但显式阻止动作 token 访问未来视觉信息，以保证推理时（仅有当前观测）的策略-训练一致性。

### 2.4 推理与部署优化
- **无未来视频生成**：推理时仅单次前向计算 $z_t$，无去噪、解码或未来帧采样。
- **实时分块（RTC）**：策略工作线程在后台预测新动作块时，控制器继续执行当前块，策略延迟不阻塞控制。
- **TensorRT 加速**：将计算拆分为两个引擎——视觉上下文引擎（构建 per-layer 缓存）与动作去噪引擎；采用 BF16 精度。
- **BF16 效果**：相较 PyTorch 198.2 ms，TensorRT BF16 仅 73.8 ms（2.69× 加速），最大相对误差 0.0106，余弦相似度 0.99977。

### 3.4 部署效率基准

## 6. 主要结论与发现

- **RoboTwin 2.0 仿真**：DSWAM 在 clean 与 randomized 条件下分别达到 92.38% 与 91.90% 平均成功率，均为最佳；相对 DeMaVLA 分别 +3.96% / +5.12%，相对 π0.5 分别 +9.64% / +15.14%，相对 Fast-WAM 分别 +0.50% / +0.12%。
- **真实世界折叠**：DSWAM 取得 96.3% SR 与 1′44″ 平均完成时间；相对 DeMaVLA：SR +3.8 pp、时间 −34 s；相对 π0：SR +20.0 pp、时间 −42 s。提升最显著的是裤子折叠（75%→90% SR，3′01″→2′19″）。
- **System 2 子任务监督**：在分拣任务上，原始粗指令平均 SR 75.7%、每次 3.53 次错误；子任务级指令平均 SR 100%、每次 0.65 次错误，证明当指令适合分解时显式子任务监督能显著提升稳定性。
- **部署效率**：TensorRT BF16 实现 2.69× 加速且与 PyTorch 输出一致；异步 TensorRT+RTC 在衬衫与裤子 easy 实例上保持或提升成功率（裤子 70%→100%），并缩短平均完成时间。

## 7. 优点与亮点

- **双系统解耦设计**：将语义级任务组织（System 2）与物理级世界感知执行（System 1）解耦，避免"规划必须"或"执行必须"的二选一，工程上更灵活。
- **训练-推理分离的世界建模**：训练时用视频联合训练提供密集物理监督，推理时不生成未来视频，兼顾表征质量与实时性。
- **真正公平的真实机器人对比**：在 DeMaVLA 设定下严格匹配机器人平台、数据、任务协议与评估标准，是目前少有的 WAM-VLA 受控实验。
- **工程化部署完善**：BF16 TensorRT 双引擎拆分 + 异步 RTC + 动作块机制，端到端延迟从 198.2 ms 降至 73.8 ms，验证了真实机器人上低延迟闭环的可行性。
- **可扩展基础模型设计**：使用 5000+ 小时真实世界数据 + 5B 视频骨干 + 4B VLM，模型规模与数据规模均达到当前 SOTA 水平。

## 8. 不足与局限

- **System 2 真实验证不足**：仅在桌面分拣 1 个任务上验证子任务监督的收益，未覆盖多类型复杂家务任务；System 2 在真实折叠任务中的表现未给出（折叠基准刻意关闭 System 2）。
- **训练成本不透明**：未报告训练所用 GPU 型号/数量、训练时长、λ_vid、batch size、训练步数等关键超参，复现门槛高。
- **数据封闭性**：5000+ 小时真实机器人数据与 5B/4B 预训练权重均为集团内部资源，限制了外部复现与公平比较。
- **方法外推风险**：双系统的协同节拍（Δt = 2 s）与 VLM/RTC 假设强绑定于家用任务节奏，迁移到工业级高动态或长视野任务时可能需要重新设计。

- **仿真指标与真实指标的口径差异**：RoboTwin 2.0 的 50 个任务与真实世界 4 个折叠任务间存在巨大分布跨度，论文未充分讨论两套结果之间的关系与一致性。
