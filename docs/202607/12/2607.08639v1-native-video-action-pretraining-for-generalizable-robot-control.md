## 摘要
视频-动作模型的出现为机器人控制提供了一条前景广阔的道路。然而，我们认为，将为数字内容创作设计的视频生成模型重新用于物理环境本质上是不合适的。为弥合这一差距，我们提出了 LingBot-VA 2.0，一个从零开始为具身智能构建的视频-动作基础模型。四大核心设计原则展示了其从 LingBot-VA 的演进。（1）我们摆脱了传统以重建为目标的 VAE 范式，引入了一种语义化的视觉-动作分词器，将视觉表征与语义和动作对齐，从而提升后续策略学习中的指令跟随能力和动作精度。（2）鉴于时序动态的严格因果性，我们采用因果预训练范式，从头开始训练以规避在适配双向架构时频繁出现的灾难性遗忘问题。（3）为满足高频推理的需求，我们的模型采用了稀疏 MoE 骨干网络，在不牺牲效率的前提下扩展了模型容量。（4）通过一种增强的异步推理方案实现了实时闭环控制，该方案在执行动作的同时并行预测未来潜变量，并通过学习到的前向动力学将每次展开重新锚定到最新观测。真实场景部署验证了 LingBot-VA 2.0 作为一种稳健的基础模型，其在复杂操作任务中的少样本泛化能力即是明证。

## Abstract
The advent of video-action models offers a promising path for robot control. Nevertheless, we argue that repurposing video generative models designed for digital content creation is inherently inadequate for physical environments. To bridge this gap, we present LingBot-VA 2.0, a video-action foundation model built from the ground up for embodiment. Four core design principles showcase its evolution from LingBot-VA. (1) Departing from traditional reconstruction-focused VAEs, we introduce a semantic visual-action tokenizer, which aligns visual representations with both semantics and actions, improving instruction following and action precision in subsequent policy learning. (2) Given the strictly causal nature of temporal dynamics, we adopt a causal pretraining paradigm, training from scratch to circumvent the catastrophic forgetting that frequently occurs when adapting bidirectional architectures. (3) To meet the demands of high-frequency inference, our model employs a sparse MoE backbone, expanding model capacity without compromising efficiency. (4) Real-time closed-loop control is realized through an enhanced asynchronous inference scheme, which predicts future latents in parallel with action execution while re-grounding each rollout on the latest observation via learned forward dynamics. Real-world deployment validates LingBot-VA 2.0 as a robust foundation model, as evidenced by its few-shot generalization across complex manipulation tasks.

# 论文总结：LingBot-VA 2.0 — 面向可泛化机器人控制的原生视频-动作预训练

## 1. 核心问题与整体含义（研究动机与背景）

- **问题背景**：视频-动作（Video-Action, VA）模型（如 LingBot-VA、DreamZero）通过联合预测场景演化与动作，为通用机器人操控提供了一条新路径。但当前工作普遍"嫁接"于通用视频生成模型之上，存在三重根本缺陷：
  - **表征错位**：像素重建型 VAE 的潜变量只服务于外观保真，缺乏语义与物理结构信息；动作模块又被单独附加，世界状态与动作处于不对齐的表征空间。
  - **推理过慢**：高维视频 token + 迭代去噪使首代 VA 模型难以达到真实机器人所需的控制频率。
  - **结构失配**：视频生成采用双向注意力，而闭环控制严格前向因果；将双向模型改造成因果模型会侵蚀 web-scale 预训练学到的广泛先验。
- **核心论点**：可泛化机器人控制既依赖下游策略，也依赖预训练底座；通用视频生成底座本质不适合物理环境，应当**从头构建（native）"为具身而生"的视频-动作栈**。
- **整体含义**：本文主张一种新的"原生视频-动作预训练"范式，从分词器、视频模型到推理调度器全部围绕具身控制的需求重塑，并以此获得少样本/零样本的跨任务泛化能力。

## 2. 方法论

### 2.1 总体框架（两阶段）
- **阶段一：语义视觉-动作分词器 (SemVAE)**：在重建型 VAE 基础上加入语义对齐与潜在动作学习，得到一个共享的"视觉-动作"潜空间。
- **阶段二：原生视频-动作模型**：在该潜空间上从零训练一个**因果扩散 Transformer (DiT)**，覆盖规划、视频流、多 chunk 预测、上下文学习、人机协同训练、异步推理六大组件。

### 2.2 四大核心设计
1. **语义视觉-动作分词器**：摆脱"只重建"的 VAE。
   - 视觉侧：ViT 编/解码器，结合 L1 + perceptual + GAN 重建损失，并额外加入与**冻结的 Perception Encoder 语义对齐**损失 L_align（公式 10）。
   - 动作侧：冻结视觉分词器，训练一个**逆动力学 (IDM) + 正向动力学 (FDM)** 配对的潜在动作模块，由"前向预测 + 反向一致性"自监督得到紧凑的潜在动作 token ℓ_t（公式 13-14）。这样一个视频片段最终输出 (z, ℓ) 配对，作为下游 VA 模型的训练目标。
2. **因果预训练范式**：完全摒弃双向注意力，自始至终采用**因果 mask**和"下一潜变量"预测目标（公式 4-5），保留 web 数据上学到的视觉动态先验，避免双向→因果适配导致的灾难性遗忘。
3. **稀疏 MoE 骨干**：沿用 Mixture-of-Transformers (MoT) 分离视频/动作专家，但把视觉专家的 FFN 替换为**稀疏 MoE 层**（Ne=128, top-k=8，1 shared expert，SwiGLU，group-limited routing）。采用 **auxiliary-loss-free load balancing**（公式 19）。MoE-13B-A1.9B 与 Dense-5B 在 wall-clock 损失上几乎重合。
4. **Foresight Reasoning 异步推理**：把推理-执行拆为两条并行流：执行流执行当前 chunk 的同时，预测流用视频专家自身做**前向动力学**（公式 29）预生成下一 chunk 的视觉潜变量与动作；每当真实观测到达即用真值覆盖并重置 KV 缓存，形成"draft-then-correct"的闭环。为训练此能力，额外加入 FDM grounding loss（公式 30）。

### 2.3 其余关键技术
- **多任务联合训练**：T2I / T2V / TI2VA / ICL / HCT 五类任务共享同一骨干，按 coarse-to-fine 调度 π(τ)（公式 28）。
- **多 chunk 预测 (MCP)**：3 个轻量级辅助模块预测第 1、2、3 块未来 chunk，权重 (0.5, 0.2, 0.1)，迫使表征编码"轨迹级动态"而非相邻帧外观复制。
- **视频 In-Context Learning**：把人类演示视频作为 z^icl 拼入条件，不破坏机器人侧因果掩码（公式 24）。
- **人机共训练 (HCT)**：通过手指关节→夹爪开度的映射 φ(q) 将 22 维手部姿态压成 scalar gripper aperture，与机器人动作共享世界模型 + 各自专属动作头（公式 25-27）。
- **层级规划器**：以 VLM (LoRA 微调) 在 ~2Hz 输出结构化 JSON 子任务上下文（done/instruction/generation_instruction/local_scene_description），与低层 VA 策略通过异步共享 buffer 解耦。
- **部署加速**：一致性蒸馏把视频/动作专家从 5+10 步降到各 2 步；再叠加 FP8 TensorRT 编译 + paged/ragged KV cache + FlashInfer attention + 系统级运行时开销削减。

## 4. 资源与算力

- **模型规模**：视频骨干 ≈13.0B 总参 / ≈1.9B 激活；动作专家 ≈0.6B；MCP 头 ≈1.7B；合计 ≈15.3B 训练参数、每 token ≈2.5B 激活。

- **训练步数**：MCP 消融展示 50k 步；主模型在 MoE-13B-A1.9B vs Dense-5B 对比中给出约 40–50 小时的 wall-clock 训练曲线。

- **未明确披露**：GPU 型号、单节点卡数、节点数、总训练 token 量、整体 wall-clock 与最终模型全量训练耗时——**论文未给出**，只能从 50k 步 ≈40–50h 这条对照曲线粗略推算。

- **主实验**：2 组（RoboTwin 2.0 仿真、真机 4 任务），与 4 类基线对比。
- **真机可视化**：4 个 ICL 零样本 demo（Calabash→Green plate 等组合任务）。
- **消融**：3 组（Tokenizer 跨 horizon 1/2/3、MCP 在 12 & 50 fps、推理加速逐项叠加），以及 MoE vs Dense 的优化轨迹对比。
- **演示**：4 个真实长尾场景（Desk Tidying / Conveyor Belt / Chip Picking / Air Hockey）覆盖长 horizon、动态对齐、精细抓取与高频反应。
- **充分性评估**：
  - **客观与公平**：基线覆盖 VA 与 VLA 两大主流路线；仿真/真机双线验证；RoboTwin 同时给 Easy/Hard，反映分布外泛化。
  - **相对不足**：

## 6. 主要结论与发现

- **RoboTwin 2.0**：Clean 93.8% / Randomized 93.4% / 平均 93.6%，超过 π0.5 (+14.0pp)、Motus (88.7/87.0)、LingBot-VA (92.2)，clean/randomized 差仅 0.6pp。
- **真机 4 任务**：在成功率与任务进度两项指标上系统性优于 LingBot-VA 与 π0.5，尤其在长 horizon 任务上更显著。
- **ICL 零样本**：仅在 4 个训练任务各 15 demos 上微调后，可零参数更新地执行未见过的物体-容器组合。
- **Tokenizer 消融**：SemVAE 相对 WAN2.2 VAE 在 horizon 1/2/3 均稳定提升，horizon 越长差距越大。
- **MCP 消融**：12 fps 与 50 fps 下均加快收敛、提高上限；50 fps 随机化设置下 5k 步 +29.7pp，20k 步匹配基线 45k 步 —— **2.3× 训练加速**。
- **部署加速**：一致性蒸馏 + FP8 TRT + paged KV + 系统级削减，把每 chunk 推理从 927ms→142ms，**异步控制频率由 35Hz 提升至 225Hz（6.5×）**。
- **核心结论**：从头构建的"视觉-动作共享语义潜空间 + 因果稀疏 MoE + 异步闭环重锚定"组合，使 web-scale 数据原生服务于具身控制，显著优于"先借用通用视频生成、再下游改造"范式。

## 7. 优点 / 亮点

- **全栈原生设计**：从分词器、对齐目标、骨干架构、训练范式到推理调度器，均围绕具身控制重塑，而非在通用视频生成上做修补。
- **语义动作共享表征**：将"世界状态"与"潜在动作"放入同一被视觉基础模型锚定的潜空间，无需昂贵机器人数据即可获得动作级监督，弱化数据稀缺瓶颈。
- **因果原生 + 多任务联合**：从零以因果 mask 训练，并联合 T2I/T2V/ICL/HCT，避免分阶段课程式学习导致的灾难性遗忘。
- **稀疏 MoE 与高效推理兼顾**：Ne=128 / top-8 仅激活小部分参数，仍能在 wall-clock 上逼近 Dense-5B 的损失。
- **异步推理 + 重锚定**：用视频专家自身做前向动力学预测下一 chunk，并在真实观测到达时硬重置 KV 缓存，把"想象-校正"做成闭环，避免 open-loop 漂移。
- **训练-推理协同**：MCP 模块仅训练时用、推理可丢弃；Few-step 蒸馏 + FP8 + paged KV + 系统级削减使 225Hz 部署可行。
- **真实部署验证**：覆盖长 horizon、动态对齐、精细抓取、高频反应四类典型任务，给出端到端真实部署频率证据。

## 8. 不足与局限

- **算力/训练透明度不足**：未披露 GPU 型号与规模、节点数、训练 token 量、最终模型全量训练时长，限制可复现性判断。
- **真实实验规模有限**：真机仅 4 任务 ×20 demos；ICL demo 缺少定量成功率、保持回合数、失败模式统计，证据强度有限。
- **评估偏差风险**：
  - 自我对照为主（与 LingBot-VA、Motus 同团队基线），且 π0.5 等基线可能存在微调协议差异；
  - 真实环境任务定义、数据收集、评估协议由作者自定，不易横向比较；
  - ICL 评估高度依赖作者挑选的"未见任务"组合，存在选择偏差。
- **方法局限**：
  - VLM 规划器与 VA 策略分开训练，靠固定 schema 耦合，规划-控制联合优化空间大；
  - 潜在动作来自被动视频，缺乏交互/强化信号，可能对精细动态事件（如柔性物体、接触丰富操作）刻画不足；
  - 30 维统一动作空间对非夹爪、非末端执行器形态的可扩展性尚未验证；
  - Asynchronous 推断虽提升频率，但异步吞吐与单步可靠性的边界条件依赖硬件栈，泛化到其他机器人平台尚未在论文中给出。
- **泛化边界**：数据集以桌面操作（厨房/餐桌/化妆台/办公桌/工具台）为主，对移动操作、长序列装配、双手机器人以外形态仍待论证。
