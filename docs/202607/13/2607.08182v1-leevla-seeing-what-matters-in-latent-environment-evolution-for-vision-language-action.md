## 摘要
视觉-语言-动作（VLA）模型旨在将多模态输入映射为机器人动作。然而，现有方法大多难以覆盖复杂的动态场景，原因在于其对所有视觉token一视同仁，并基于人为选择的因素进行推理，既缺乏强调任务关键证据的机制，又忽略了潜在的隐含因素。为解决这一问题，我们提出了LEEVLA，一种用于在潜在环境演化中关注关键信息的VLA架构，能够显式引导模型聚焦于信息丰富的区域，同时保持潜在世界表征的结构化演化。为了识别显著且与指令相关的区域，我们引入了漂移引导的动态优先级排序（DGDP），它将动态位置优先级排序（DPP）与语义漂移引导（SDG）相结合，以引导VLA智能体在训练过程中的注意力。在此基础上，我们引入了结构化特征流生成（SFFG），通过原型到外围（P2P）预测来建模这些被优先排序的特征在潜在空间中应如何演化，并提出互邻域对比（MC）损失以维持邻域间的拓扑一致性。综上，DGDP与SFFG共同构成了一个任务感知的"在何处—如何做"训练框架。在VLA基准测试上的大量实验表明，LEEVLA持续优于现有方法，证实了显式的任务证据引导与结构化潜在推理对于可扩展的VLA均至关重要。我们的代码已开源，地址为https://github.com/LyuQi127/LEEVLA。

## Abstract
Vision-language-action (VLA) models aim to map multimodal inputs to robot actions. However, most existing approaches struggle to cover complex dynamic scenarios due to treating all visual tokens uniformly and reasoning with human-selected factors, which lack mechanisms to emphasize task-critical evidence and ignore underlying factors. To address this issue, we propose LEEVLA, a VLA architecture for seeing what matters in Latent Environment Evolution that explicitly guides the model toward informative regions while preserving the structured evolution of latent world representations. To identify salient and instruction-relevant regions, we introduce drift-guided dynamic prioritization (DGDP), which combines dynamic position prioritization (DPP) with semantic drift guidance (SDG) to guide the VLA agent where to attend during training. On top of this, we introduce structured feature flow generation (SFFG), which models how these prioritized features should evolve in latent space via prototype-to-periphery (P2P) prediction, and a mutual-neighborhood contrastive (MC) loss to maintain topological consistency among neighborhoods. Together, DGDP and SFFG form a task-aware "where-how" training framework. Extensive experiments on VLA benchmarks show that LEEVLA consistently outperforms prior methods, confirming that explicit task-evidence guidance and structured latent reasoning are both crucial for scalable VLA. Our code is available at https://github.com/LyuQi127/LEEVLA.

## 1. 核心问题与研究动机

- **核心问题**：现有 VLA（Vision-Language-Action）模型在复杂动态场景中存在两大局限：
  - **视觉 token 均匀处理**：对所有 patch 一视同仁，导致梯度被静态背景和任务无关区域稀释，无法有效聚焦任务关键证据。

- **整体含义**：论文主张直接在潜在特征空间（latent feature space）进行推理，将动作视为驱动高维环境状态演化的因子，并通过"何处关注（where）"与"如何演化（how）"的双重机制，避免对辅助像素级重建或外部条件管道的依赖，从而提升 VLA 的可扩展性和长时序推理能力。

## 2. 方法论

### 2.1 整体框架

LEEVLA 提出"**Where–How 训练框架**"，由两大模块组成：
- **DGDP（Drift-Guided Dynamic Prioritization）**：回答"在何处关注"。
- **SFFG（Structured Feature Flow Generation）**：回答"如何演化"。

两者**仅在训练阶段使用**，不增加推理成本。

### 2.2 关键组件与公式细节

- **动态位置优先级排序（DPP）**：
  - 通过相邻时间步 patch 特征的余弦相似度变化计算 dynamism score：θ_i = 1 − cos(v_{t,i}, v_{t+T,i})。
  - 得分越高的区域（如机械臂末端、任务相关物体）获得更高关注权重。

- **语义漂移引导（SDG）**：
  - 对每个 patch 计算与语言 token 的指令相关分数：r_{t,i} = max_{1≤j≤M} ⟨x̃_{t,i}, c̃_j⟩。
  - 定义语义漂移：Δ_i = clip((r_{t+T,i} − r_{t,i})/τ, −δ, δ)，并通过指数函数映射为 SDG 因子 ω_i = exp(Δ̃_i / τ)。
  - 最终优先级权重：β_i = σ(ω_i · θ_i)（σ 为 sigmoid）。

- **原型到外围预测（P2P, Prototype-to-Periphery）**：
  - 对未来 t+T 时刻的多视图特征进行联合聚类得到 L 个簇及其质心 μ_ℓ。
  - 在每个簇内按到质心的欧氏距离排序（从最近到最远，即 prototype → periphery）。
  - P2P 损失：L_{P2P} = (1/|C|) Σ_ℓ (1/|→c_ℓ|) Σ_{j∈→c_ℓ} (α + β_j) · φ(v̂_{t+T,j}, v_{t+T,j})，其中 φ 为余弦嵌入损失，α 为全局调制因子（论文中取 1）。

- **互邻域对比损失（MC Loss）**：
  - 对每个锚点 i 构建一阶邻居 TopK 与二阶邻居集合（K=10, M=5）。
  - 仅保留**互为邻居**的样本作为正样本，使用 InfoNCE 损失拉近高置信度对称邻居，过滤聚类噪声与非对称关联。

- **训练目标**：L_total = λ₁ L_action + λ₂ L_{P2P} + λ₃ L_{MC}，其中动作预测采用 L1 回归与并行连续动作解码。

### 2.3 架构设计

- 视觉编码器：DINOv2 + SigLIP。
- 大语言模型骨干：OpenVLA-7B（大尺度版本）/ miniVLA（小尺度版本）。
- 未来特征解码器 D：将视觉嵌入映射到未来特征空间。
- 并行连续动作预测器（MLP head）。

## 6. 主要结论与发现

- **LIBERO 上**：
  - LEEVLA-mini（0.5B）平均 97.5%，超越 FLOWER（95.7%）等小尺度 SOTA。
  - LEEVLA-large（7B）平均 98.2%，在 Spatial/Long 等任务上取得最优，超越 π0.5（97.5%）、OpenVLA-OFT（97.1%）。
- **CALVIN 上**：LEEVLA-large 平均长度 4.34，显著优于 OpenVLA（3.80）、π0.5（4.02）、OpenVLA-OFT（4.10）等。
- **真实世界**：LEEVLA-large 在 Place/Press/Drawer/Long 四任务上平均 78.5%，远超 OpenVLA 的 40%。
- **消融结论**：四个组件均有正向贡献，DPP 贡献最大（+1.5），P2P+MC+DPP+SDG 累计带来 +2.2% 提升，验证了"where-how"框架的互补性。
- **设计洞察**：
  - 潜在空间中的结构化预测比人类选定的外部条件更具表达力。
  - 互邻域机制能有效抑制聚类噪声，提升对比监督稳定性。
  - 全局因子 α 与优先级权重 β 协同，能在聚焦关键区域的同时保持对场景整体布局的感知。

## 8. 不足与局限

- **真实世界实验规模偏小**：仅 3 个任务、每个任务 20 次试验，未提供标准差或多随机种子统计，泛化结论可能不够稳健。
- **缺乏失败案例分析**：未系统讨论模型在哪些场景下仍会失败（如严重遮挡、新型物体、长时序复合任务等）。
- **超参数依赖**：DGDP 中温度 τ、阈值 δ、簇数 L、邻居数 K/M、损失权重 λ₁/λ₂/λ₃ 均需调参，文中未充分讨论这些超参数对结果的敏感性。
- **任务相关分数的潜在偏差**：指令相关分数 r_{t,i} 由文本-视觉 token 内积计算，依赖语言编码器质量，对指令表述的鲁棒性可能受限。
- **数据集多样性**：训练数据混合主要来自 Open X-Embodiment 与 LIBERO，未涉及更复杂的真实世界噪声场景或新型机器人形态，跨平台迁移能力未验证。

- **因果性论证不足**：论文强调关注"unknown factors"，但缺少定量消融来验证相比 baseline，模型确实在发现未知因素方面有所提升，更多是定性的可视化主张。
