## 摘要
主流的视觉-语言-动作（VLA）模型在马尔可夫假设下主要基于当前观测预测动作，因此在长时序、时间依赖型任务中表现欠佳。现有的记忆增强型VLA方法要么扩展观测窗口，要么从记忆库中检索历史信息作为策略侧的辅助上下文。然而，这些方法将记忆置于VLA推理的原生潜在嵌入空间之外，导致历史经验无法与多模态推理及动作生成进行流畅的交织。为此，我们提出了LaMem-VLA，一个原生潜在记忆框架，它将历史经验重构为潜在记忆令牌，并将其与VLA推理直接交织。LaMem-VLA的核心包含四个协同组件：(i) 策展器，将历史经验组织为互补的短期与长期记忆库；(ii) 检索器，利用多模态认知查询两个记忆库，获取上下文相关的证据；(iii) 压缩器，将检索到的证据重构为紧凑的短期与长期潜在记忆令牌；(iv) 织合器，将这些记忆令牌与当前观测及指令注入到一条连续的嵌入序列中。通过在同一连续潜在空间中完整地表示、检索和利用历史经验，LaMem-VLA使记忆能够在有限上下文约束下直接参与VLA推理并引导动作生成。在SimplerEnv和LIBERO上的大量实验证明了LaMem-VLA的优越性。

## Abstract
Mainstream Vision-Language-Action (VLA) models predict actions primarily from the current observation under a Markovian assumption, thus struggling with long-horizon, temporally dependent tasks. Existing memory-augmented VLAs either expand the observation window or retrieve history from the memory bank as auxiliary policy-side context. However, they leave memory outside the native latent embedding space of VLA reasoning, preventing historical experience from being fluidly interleaved with multimodal reasoning and action formation. To this end, we introduce LaMem-VLA, a latent-memory-native framework that reconstructs historical experience into latent memory tokens and directly interweaves them with VLA reasoning. At its core, LaMem-VLA introduces four coordinated components: (i) a curator that organizes historical experience into two complementary short-term and long-term memory vaults; (ii) a seeker that queries both vaults using the multimodal cognition to retrieve context-relevant evidence; (iii) a condenser that reconstructs the retrieved evidence into compact short-term and long-term latent memory tokens; and (iv) a weaver that injects these memory tokens with the current observation and instruction into one continuous embedding sequence. By representing, retrieving, and consuming historical experience entirely in the same continuous latent space, LaMem-VLA enables memory to directly participate in VLA reasoning and guide action generation under a bounded context. Extensive experiments on SimplerEnv and LIBERO demonstrate the superiority of our LaMem-VLA.

# LaMem-VLA 论文总结

## 1. 核心问题与研究背景

- **马尔可夫假设的局限**：当前主流的视觉-语言-动作（VLA）模型（如 OpenVLA、CogACT、π0 等）在推理时主要基于**当前时刻的视觉观测**预测动作，忽略了历史状态变迁、已完成的子任务以及当前所处任务阶段。这种"时间短视偏差"使其在**长时序、强时序依赖**的机器人操作任务上表现欠佳。
- **现有记忆增强方案的两条路线及其不足**：
  - **时序上下文扩展**：将历史帧拼接或将输入扩展为视频序列。问题在于计算/显存开销随上下文长度线性增长，且固定窗口会"截断"窗口外的关键历史信息。
  - **外部记忆库检索**（如 MemoryVLA）：将历史观测与动作存储到外部记忆库，检索后作为**策略侧的辅助条件**输入到动作专家。其根本缺陷在于记忆始终处于 VLA 模型**原生 token 嵌入空间之外**，无法与多模态推理和动作意图生成深度交织。
- **核心研究问题**：能否将历史经验作为**上下文原生**的机器人记忆，在 VLA 模型已经"感知—推理—执行"的同一连续潜在空间中完成**存储、检索、消费**，从而真正参与多模态推理？

## 2. 方法论

### 2.1 整体架构与核心思想

- 提出 **LaMem-VLA**（Latent Memory VLA），一个**端到端的原生潜在记忆框架**。
- 关键理念：将机器人历史重构为**双尺度潜记忆令牌**（短期视觉 + 长期语义），并将其作为 VLA 输入序列的一部分，与当前观测、指令、动作查询一起通过自注意力机制进行联合推理。
- 四个协同模块：**策展人（Curator）→ 检索者（Seeker）→ 压缩者（Condenser）→ 编织者（Weaver）**。

### 2.2 关键技术细节

- **主干网络**：采用 7B 参数的 Prismatic VLM，在 Open-X Embodiment 大规模数据集上预训练；动作专家为约 300M 参数的扩散策略。
- **输入处理**：当前 RGB 图像 resize 到 224×224，经视觉编码器（DINOv2 / SigLIP）提取视觉 token $X_t$，与语言指令 token 拼接后送入 LLaMA-7B，并在序列末尾追加可学习的动作查询 $Q_{action}$。
- **双记忆库（Curator）**：
  - **短期记忆库** $M_{short}$：存储**视觉感知证据**，即每个时刻经 SE-bottleneck 压缩模块 $C_s$ 蒸馏出的视觉 token $v_s$，并以均值池化后的表示作为检索键 $k_s$。
  - **长期记忆库** $M_{long}$：存储**动作 hidden state** $H_{action}$，保留任务进度与动作连续性线索。
  - **更新策略**：当单元数超过容量 $L=16$ 时，计算相邻键的余弦相似度，合并最相似的相邻对以降低冗余。
- **记忆检索（Seeker）**：基于当前多模态认知状态构建上下文查询 $Q_{con}$，通过轻量 transformer 查询构建器 $B$ 生成 $K_q$ 个查询槽，并以均值池化向量 $q_t$ 在两个记忆库上执行 **Top-K 检索**（$K=8$）。检索采用 Top-K 操作，不参与梯度更新。
- **记忆压缩（Condenser）**：将检索得到的变长证据 $Z_{short}$、$Z_{long}$ 与可学习记忆槽 $T_s$、$T_l$ 一同输入轻量 transformer 形式的记忆塑形器 $F_v$、$F_c$，蒸馏为**固定长度**的潜在记忆令牌 $M_{short}$（$L_s=8$）和 $M_{long}$（$L_l=4$），与 VLA 嵌入空间对齐。
- **记忆编织（Weaver）**：将两类潜在记忆令牌与当前观测、指令、动作查询拼成一条**连续嵌入序列**：
  $$S_t = [M_{short}+1_{L_s}b_s^\top; M_{long}+1_{L_l}l_l^\top; X_t; I; Q_{action}]$$
  其中 $b_s$、$b_l$ 为可学习的源嵌入。动作 token 通过 VLM 自注意力直接"看见"记忆 token，从而形成**记忆驱动的动作表征** $Z_{action}$。
- **动作生成**：将 $Z_{action}$ 注入扩散动作专家，以 MSE 损失 $\mathcal{L}_{action}=\mathbb{E}_{n,\epsilon}\|\epsilon-\epsilon_\theta(a^n_{t:t+H-1}, n, Z_{action})\|^2$ 训练，推理时使用 DDIM 10 步采样生成 7-DoF 末端执行器动作块（动作块大小 16）。

## 3. 实验设计

### 3.1 基准与数据集

- **SimplerEnv-Bridge**（WidowX 机器人）：评估真实到仿真泛化能力，训练集为 Bridge v2，包含 4 个任务：Put Spoon on Towel、Put Carrot on Plate、Stack Cube、Put Eggplant in Basket。
- **LIBERO**（Franka 机器人）：包含 5 个套件——Spatial（空间感知）、Object（物体操作）、Goal（目标完成）、Long-10、Long-90（长时序推理），每任务 50 条演示。

### 3.2 对比方法

- **SimplerEnv 对比**：RT-1-X、OpenVLA、TraceVLA、SpatialVLA、Magma、CogACT、π0、DreamVLA、ThinkAct、CronusVLA、MemoryVLA、SemanticVLA 等 12 个方法。
- **LIBERO 对比**：Diffusion Policy、Octo、UniACT、SpatialVLA、OpenVLA、CoT-VLA、π0-FAST、CogACT、π0、ThinkAct、MemoryVLA、Fast-ThinkAct、SemanticVLA、LARA 等 14 个方法。

### 3.3 评测协议

- 每个任务 24 次（SimplerEnv）或 50 次（LIBERO）rollout 试验，报告平均成功率。
- 训练步数：SimplerEnv 50k 步，LIBERO Spatial/Object/Goal 各 20k 步，Long-10 与 Long-90 联合训练 40k 步；按 2.5k / 1k 步间隔在验证集上选最优 checkpoint。

## 4. 资源与算力

- **GPU**：8 张 NVIDIA H800，使用 PyTorch FSDP。
- **批大小**：单卡 32 样本，全局批大小 256。
- **学习率**：$2\times 10^{-5}$。
- **训练步数**：如上文所述。
- **超参数**：记忆库容量 $L=16$，检索 $K=8$，压缩 $L_s=8$、$L_l=4$，推理 DDIM 10 步。
- **论文未明确给出**：总训练时长（墙钟时间）、具体训练 epoch 数、推理延迟等指标。

## 5. 实验数量与充分性

- **主实验**：2 个 benchmark（SimplerEnv-Bridge、LIBERO），覆盖 4 + 5 = 9 个任务套件。
- **消融实验（至少 4 组）**：
  1. 双尺度记忆的贡献（去除短期 / 长期 / 全部）。
  2. 潜记忆原生 vs. 策略侧条件 vs. 原始检索直接条件化。
  3. 检索单元数 $K \in \{2,4,8,12\}$ 的影响。
  4. 压缩后记忆 token 数 $L_s$、$L_l$ 的影响（以曲线图呈现）。
- **充分性评价**：
  - **优点**：实验维度较为完整，涵盖主结果对比、双尺度消融、记忆路径消融、检索预算与压缩长度消融；与最近最强方法（MemoryVLA、SemanticVLA、π0）均做了直接比较。
  - **不足**：未在真实机器人上验证；消融缺少对各模块（策展人压缩策略、源嵌入 $b_s/b_l$、记忆塑形器深度等）的更细粒度拆解；缺少对推理效率、显存开销的定量分析。

## 6. 主要结论与发现

- **SimplerEnv-Bridge**：LaMem-VLA 平均成功率 **73.9%**，超过 CogACT 基线 16.6 个百分点，超过 π0 4.7 个百分点，超越 MemoryVLA 2.0 个百分点。
- **LIBERO**：平均成功率 **97.6%**，超过 MemoryVLA 1.1 点、CogACT 4.4 点、π0（前四套件）3.5 点；Long-10 与 Long-90 上分别比 MemoryVLA 高 2.4 / 1.4 点。
- **消融结论**：
  - 双记忆库互补：去掉任一库或同时去掉都会显著退化（SimplerEnv 由 73.9% 降至 57.3–65.6%）。
  - **潜原生优于策略侧条件化**：策略侧记忆条件 + 原始检索条件均显著弱于潜空间内压缩注入。
  - 检索预算 $K=8$ 最优，过多（$K=12$）反而因冗余证据引入干扰。
  - 压缩长度 $(L_s,L_l)=(8,4)$ 在性能与效率之间取得最佳平衡。
- **核心结论**：将历史经验作为**与 VLA 同空间的潜在记忆令牌**，通过自注意力直接参与推理，是提升长时序操控任务鲁棒性的有效方向。

## 7. 方法与实验设计的亮点

- **范式创新**：明确区分"原生潜记忆"与"外部策略侧条件"两种范式，提出在 VLA 嵌入空间内部完成"存储—检索—压缩—编织"全链路。
- **双尺度互补设计**：按"来源/功能"而非"表征形式"划分短期视觉与长期语义记忆，两者在压缩阶段都统一为同一嵌入空间的 token，接口统一。
- **变长→定长压缩**：检索结果数量可变，但通过可学习记忆槽注入后形成定长 token，控制上下文长度，规避长上下文计算膨胀。
- **实验较为系统**：同时验证了"双库互补""路径选择（原生 vs 外部）""检索量""压缩量"四个角度的消融。
- **与最强基线公平对比**：在未使用腕部相机与本体感受输入的情况下仍超越带额外输入的 π0-FAST 等方法，凸显了记忆机制本身的有效性。

## 8. 不足与局限

- **仅仿真验证**：作者明确指出当前结果全部来自 LIBERO 与 SimplerEnv 的仿真环境，未在真实机器人平台部署；真实环境的光照、噪声、相机抖动等因素对记忆检索与压缩的影响仍未验证。
- **基线实现公平性存疑**：对比方法中很多为已发表结果而非作者复现，且部分强基线（π0-FAST、π0）使用了腕部相机与本体感受等额外输入，starred 方法的"不公平优势"未被严格消融对齐。
- **架构依赖性强**：强依赖 7B 级 Prismatic VLM 作为主干并在大规模 Open-X Embodiment 上预训练；复现与训练成本较高，不利于低算力场景。
- **记忆容量与更新策略较为朴素**：仅基于相邻键余弦相似度合并，无法捕获跨步长程冗余；Top-K 检索不可微，存在检索误差的传递风险。
- **缺乏效率与可解释性分析**：未报告推理时延、显存占用、记忆 token 注意力可视化等指标；读者难以判断潜在收益与部署代价的权衡。
- **应用场景有限**：目前针对桌面级机械臂（WidowX / Franka）的 7-DoF 末端执行器控制；面向双臂、移动操作、灵巧手等更复杂形态的可扩展性未讨论。
- **缺少失败案例分析**：论文未对失败任务进行归因（如记忆检索错误、压缩失真、动作解码错误等），影响对方法边界的理解。
