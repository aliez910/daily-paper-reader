## 摘要
如何使预训练的视觉-语言-动作（VLA）模型在保持高频率更新的同时，保留长时序的视觉历史且不牺牲效率？现有方法依赖外部记忆管理，限制了记忆的时间跨度或预训练策略的实时响应能力。为此，我们提出了NativeMEM——一种具备长期且实时更新记忆能力的VLA策略。其核心是一种高效的记忆编码方案——本征记忆压缩（Native Memory Compression），它复用VLA自身的视觉编码器，将每个相机视角下的每一历史帧压缩为单个token。这些记忆token被附加到输入序列中，使预训练的VLA能够以可忽略的延迟开销关注长期历史，既不需要外部规划器，也无需重新初始化的记忆模块。为了将记忆token与预训练策略对齐，我们首先在需要大量记忆的数据上，在冻结的VLA监督下训练了一个通用的记忆分词器，然后解冻VLA进行任务特定的微调。NativeMEM持续优于先前方法，在仿真中将成功率从32.4%提升至84.0%，在真实机器人上最高达到98.7%，同时保持较低的推理延迟和GPU显存占用。值得注意的是，NativeMEM展现出很高的数据效率，仅使用20%的训练数据即可取得与先前方法相当的竞争性结果。

## Abstract
How can pretrained Vision-Language-Action (VLA) models retain long-horizon visual histories with high-frequency updates without sacrificing efficiency? Existing approaches rely on external memory management, which restrains either the memory horizon or the reactiveness of pretrained policies. To this end, we present NativeMEM, a VLA policy that features long-term and real-time updated memory. At its core is an efficient memory encoding scheme, Native Memory Compression, which repurposes the VLA's own vision encoder to compress each historical frame from each camera view into a single token. Appended to the input sequence, these memory tokens enable the pretrained VLA to attend over long-term history with negligible latency overhead, requiring neither an external planner nor a freshly initialized memory module. To align the memory tokens with the pretrained policy, we first develop a generic memory tokenizer under the supervision of a frozen VLA on memory-demanding data, and then unfreeze the VLA for task-specific fine-tuning. NativeMEM consistently outperforms prior methods, boosting success rates from 32.4% to 84.0% in simulation and up to 98.7% on real robots, while maintaining low inference latency and GPU memory usage. Notably, NativeMEM exhibits high data efficiency by achieving competitive results with prior arts using only 20% of the training data.

# NativeMEM 论文总结

## 1. 核心问题与研究动机

- **问题背景**：当前主流的预训练视觉-语言-动作（VLA）模型（如 OpenVLA、π0、π0.5 等）大多仅基于当前观测和语言指令做"反应式"动作预测，无法应对**长时序、记忆依赖型**操作任务（例如"按钮已按过的不能再按""方块原本在哪个 pad""已扫描过哪些商品"等）。
- **现有方案的局限**：
  - **VLM 驱动记忆**（如 MemER、MEM、Mem-0）：依赖高层 VLM 检索关键帧或生成子任务文本指令，存在标注成本高、细节难以语言化、引入额外参数与计算等问题。
  - **外部记忆模块**（如 MemoryVLA、HAMLET、ReMem-VLA 等）：新增循环状态、压缩记忆或检索记忆库模块，这些模块在 VLA 预训练阶段不存在，会损害预训练先验并带来结构复杂度。
- **核心矛盾（compression dilemma）**：保留更长时间、更高频率的历史与维持推理效率之间存在张力——压缩不足则上下文爆炸，压缩过度则丢失关键动作信息。
- **核心问题**：能否让 VLA 在不引入外部模块、保持预训练策略兼容性的前提下，保留长时序、细粒度且高效的视觉历史？

## 2. 方法论

### 2.1 整体思路

提出 **Native Memory Compression（本征记忆压缩）**：直接复用 VLA 自带的视觉编码器，把每一历史帧、每一相机视角压缩为 **单个 token**（M = 1），并以"原生视觉证据"的形式追加到 VLA 的原始 token 序列中，使策略通过其原本的注意力机制即可访问长期历史。

### 2.2 形式化建模

- 单帧 VLA：$a_t \sim \pi_\theta(\cdot | o_t, s_t, \ell)$
- 引入记忆后的 VLA：$a_t \sim \pi_{\theta'}(\cdot | o_t, s_t, \ell, M_t)$
- 记忆长度：$|M_t| = V \cdot T \cdot N \cdot M$，其中 $V$ 视角数、$T$ 时间跨度、$N$ 更新频率、$M$ 每帧 token 数；论文将 $M$ 压到 1。

### 2.3 记忆编码细节

- 从 VLA 自身的视觉编码器 $E_{\text{mem}}$ 初始化，加入可学习的查询 token $q_{\text{mem}}$：
  $$[\hat{q}_\tau^v, \hat{P}_\tau^v] = E_{\text{mem}}([q_{\text{mem}}, P_\tau^v])$$
- 线性投影映射到 VLA token 维度：$m_\tau^v = W_{\text{mem}} \hat{q}_\tau^v$
- 记忆序列拼接（带可学习 BOS token $b_{\text{mem}}$）：$M_t = [b_{\text{mem}}, \{m_\tau^v \mid \tau \in I_t, v=1..V\}]$
- 最终输入：$x_t = [x_t^{\text{obs}}, x^{\text{prompt}}(\ell, s_t), M_t]$——无需修改 VLA 架构。

### 2.4 两阶段训练流程

- **Stage 1（本征记忆压缩学习）**：冻结 VLA，仅训练 $E_{\text{mem}}$、$q_{\text{mem}}$、$W_{\text{mem}}$、$b_{\text{mem}}$；使用 VLA 原生的动作预测损失进行**动作监督**（非重构损失）；在标准操作 + 记忆依赖任务的混合数据上训练，形成可复用的通用记忆分词器；每步从片段首帧 + 近期窗口 + 当前帧采样训练索引。
- **Stage 2（任务特定微调）**：用 Stage 1 的分词器离线缓存所有历史帧的单个 summary token；冻结 tokenizer，对 VLA 主干、动作头、记忆投影进行任务微调；输入仍为当前观测 + 提示 + 记忆序列。

### 2.5 实时推理

- 记忆分词器独立于 VLA 主干运行，按指定频率生成单个 memory token 并维护紧凑队列；
- 动作预测时仅把最新记忆队列拼到原始 token 之后，实现**记忆构建与策略推理解耦**，支持高频率更新。

## 3. 实验设计

### 3.1 数据集与场景

- **真实机器人任务（3 个）**：
  1. Click Buttons（按指定顺序按钮、不重复）
  2. Put Back Block（记住方块原始 pad 后归位）
  3. Grocery Checkout Scanning（**Stage 1 未见过**，评估泛化性）

### 3.2 对比方法

- **基座 VLA**：π0.5、X-VLA
- **VLM 驱动记忆**：MemER、Mem-0
- **外部记忆模块**：HAMLET\*、MEM-short\*（在相同 π0.5 backbone 上复现）
- **时序动作连续性**：π0.5 + RTC
- 公平对比时所有方法使用相同 backbone 与训练数据

### 3.3 主要结果

- **仿真**：NativeMEM 5 个任务平均成功率 **84.0%**，远超前序最优（Mem-0 的 32.4%），每个任务均最优。

## 6. 主要结论与发现

- **方法有效**：将单帧 VLA 升级为记忆增强策略，仿真 +32.4pp、真实机器人 +84pp，且每个任务均最优。
- **效率优势**：每帧 1 token 的极简压缩可支持 **9× ~ 40× 长于前序方法** 的历史窗口，仍保持实时推理。
- **训练高效**：Stage 1 通用分词器可复用；Stage 2 仅需少量任务数据（100 demos / 5h）。
- **机制有效**：注意力可视化显示策略确实 attend 到任务关键历史时刻（如拾起方块瞬间、按钮按压时刻），而非简单使用最近帧。
- **数据高效**：仅 20% 数据即可匹配 SOTA。

## 7. 优点与亮点

- **架构兼容性强**：直接复用预训练 VLA 视觉编码器，不引入新结构，最大限度保留原策略先验；
- **压缩极致**：M = 1（每帧-视角单 token），解决了 memory length 与 fidelity 的根本矛盾；
- **动作监督训练**：用 VLA 原生 action loss 而非重构损失训练分词器，使记忆直接对齐动作相关性；
- **解耦设计**：记忆更新与策略推理解耦，可独立高频率更新；
- **训练流程清晰**：两阶段分离"如何压缩"与"如何使用"，避免 Stage 2 在小数据上坍塌；
- **可解释性**：提供 tokenizer 空间注意力与策略对记忆的时间注意力可视化，论证机制合理性；
- **跨任务、跨场景一致提升**：仿真、真实机器人、已见/未见任务均表现优异；
- **数据与算力高效**：仅 100 demos 即可完成转换，20% 数据即可比肩 SOTA。

## 8. 不足与局限

- **时间尺度有限**：作者明确指出不支持小时/天级持续记忆，需额外的系统级记忆基础设施；
- **监督信号单一**：记忆分词器仅用 action loss 训练，更复杂任务可能暴露语义鸿沟（作者已自行指出）；
- **Backbone 单一**：仅在 π0.5 上验证，对其他 VLA（如 OpenVLA、π0）的可移植性未知；
- **真实任务数量有限**：仅 3 类真实任务，"未见任务" Grocery Checkout Scanning 的真实环境与 Stage 1 真实训练数据可能存在一定分布重叠，泛化结论仍偏弱；
- **算力与统计细节缺失**：未公开 GPU 型号/数量、未报告多次随机种子均值±方差、可复现性受限；
