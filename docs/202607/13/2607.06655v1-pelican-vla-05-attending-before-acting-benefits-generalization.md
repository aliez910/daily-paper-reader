## 摘要
在本报告中，我们提出了 Pelican-VLA 0.5，一个将视觉语言理解、未来帧生成和动作预测集成于单一架构中的统一 VLA 模型。Pelican-VLA 0.5 实现了注意力层面的泛化：在没有物体标注、分割掩码、注意力监督或任务特定微调的情况下，其动作通路已能自发聚焦于指令相关物体及接触区域。这一行为在未见场景和未见机器人本体上依然保持，并且显著强于其他开源 VLA 基线。我们验证了该能力源自插入在感知与动作之间的可学习推理槽：通过将任务相关的视觉信息路由经过一个紧凑的瓶颈，该槽接口在预训练过程中诱导出以操作为中心的注意力，并在包括 MoT 风格架构在内的不同策略结构中持续有效。

## Abstract
In this report, we present Pelican-VLA 0.5, a unified VLA model that integrates vision-language understanding, future-frame generation, and action prediction within a single architecture. Pelican-VLA 0.5 achieves attention-level generalization: without object annotations, segmentation masks, attention supervision, or task-specific fine-tuning, its action pathway already focuses on the instruction-relevant object and contact region. This behavior persists across unseen scenes and unseen robot embodiments, and is substantially stronger than in other open-source VLA baselines. We verify that this ability originates from the learnable Reasoning Slots inserted between perception and action: by routing task-relevant visual information through a compact bottleneck, the slot interface induces manipulation-centric attention during pre-training and remains effective across different policy structures, including a MoT-style architecture.

# Pelican-VLA 0.5 论文总结

## 1. 核心问题与研究动机

- **核心问题**：当前 Vision-Language-Action (VLA) 模型在面对新物体、新场景、新任务乃至新机器人本体时，泛化能力仍然有限；它们高度依赖任务特定、环境特定的机器人数据，迁移时往往需要额外的数据采集与微调。
- **观察到的现象**：作者分析了多个开源 VLA 模型的注意力图，发现其动作通路（action pathway）的注意力呈弥散分布——覆盖机械臂、背景杂乱区域和与任务无关的物体，而未能稳定聚焦于指令相关的目标物体或潜在接触区域。
- **研究假设**：VLA 的泛化能力不仅取决于底层动作轨迹的拟合，还取决于"动作预测之前"任务相关信息的表征与路由方式。如果能在感知与动作之间强制构建一个紧凑的瓶颈接口，可能促使模型蒸馏出对操作更关键的视觉表征，从而提升跨场景/跨本体的泛化能力。
- **整体含义**：论文将研究目标定位在"注意力级泛化（attention-level generalization）"，即在零样本条件下，模型的注意力能否自发地集中到正确的目标与接触区域，而非追求完全的零样本执行成功率。

## 2. 方法论

### 2.1 整体架构

- **统一 Transformer**：基于共享的 **Qwen3-VL 4B** 主干，将视觉-语言理解、未来帧生成与动作预测统一于单一架构，不再采用双系统或 Mixture-of-Transformers 形式的"推理/行动"分离专家。
- **四段式 token 序列**：
  1. **Prefix**（视觉-语言 token）：当前多视角相机观测 + 语言指令，由 Qwen3-VL 视觉编码器插入到文本 token 序列中，采用双向注意力。
  2. **Middle**（Cosmos 潜空间 token）：由冻结的 Cosmos-Tokenizer 对 $t-15$ 与 $t$ 两个时刻的视觉进行编码，提供像素级、动力学感知的中间表征。
  3. **Slots**（K=32 个可学习推理槽）：初始化为 $\mathcal{N}(0, 0.02^2)$，并以 0.1 的概率进行 slot dropout，形成感知→动作的紧凑瓶颈。
  4. **Suffix**（本体状态 + 含噪动作 chunk）：本体状态投影为单个 token；动作 chunk 经线性嵌入并叠加 flow time $\tau$ 的正弦位置编码后融合为 H=50 个动作 token。

### 2.2 关键设计：Reasoning-Slot 瓶颈

为保证动作 suffix 无法绕过 slots，模型使用三种机制：

- **课程式瓶颈注意力掩码**：在 suffix → 上游感知 token ($C = \text{prefix} \cup \text{middle}$) 之间施加硬切断 $A_{i \to j}=0$。为缓解训练不稳定，采用课程策略：以概率 $p_t = \min(1, t/T_{\text{warm}})$（$T_{\text{warm}}=10k$ 步）施加硬瓶颈。
- **正交性正则化**：对 $\ell_2$ 归一化后的 slot 输出 $Z_{\text{slot}}$，惩罚其 Gram 矩阵偏离单位阵的程度
  $$\mathcal{L}_{\text{reg}} = \frac{1}{B}\sum_{b=1}^{B}\frac{1}{K^2}\|\hat{Z}_{\text{slot}}^{(b)}(\hat{Z}_{\text{slot}}^{(b)})^\top - I_K\|_F^2$$
  促使不同 slot 捕获互补信息。
- **Slot 门控的未来帧生成**：用 mean-pool 后的 slot 输出 $\bar{z}$ 计算通道门 $g=\sigma(W_g\bar{z})$，对生成特征 $F_{\text{gen}}$ 进行调制 $\tilde{F}_{\text{gen}} = F_{\text{gen}} \odot g$，将 slot 表征与"对未来预测"绑定。

### 2.3 训练目标

- **Flow-matching 动作损失** $\mathcal{L}_{\text{action}}$：构造插值 $x_\tau = \tau\epsilon + (1-\tau)a$、目标速度 $u=\epsilon - a$，对去噪速度 $v_\theta(\mathcal{Z})_{\text{act}}$ 与 $u$ 之间的 $\ell_2^2$ 损失。
- **未来帧生成损失** $\mathcal{L}_{\text{gen}}$：在 Cosmos 潜空间预测 $t+15$ 时刻的潜码，避免像素重建。
- **槽-语言对比对齐** $\mathcal{L}_{\text{task}}$：基于 InfoNCE 的对称对比损失，将轨迹表征与指令 token 表征对齐；权重 $\lambda_{\text{task}}=0.1$，嵌入维度 256。
- **总损失**：$\mathcal{L} = \mathcal{L}_{\text{action}} + \lambda_{\text{gen}}\mathcal{L}_{\text{gen}} + \lambda_{\text{task}}\mathcal{L}_{\text{task}} + \lambda_{\text{reg}}\mathcal{L}_{\text{reg}}$，其中 $\lambda_{\text{gen}}=\lambda_{\text{reg}}=0.01$。

### 2.4 缓存推理

推理分三步：(1) KV-cache 处理 prefix；(2) 扩展 middle 与 slots 缓存后，仅保留 K 个 slot 的 KV，丢弃大的 prefix/middle cache；(3) 初始化 $x_1 \sim \mathcal{N}(0,I)$，使用 Euler 法反向积分 N=10 步完成 flow ODE。每步只重嵌入 suffix，使去噪成本仅依赖于 suffix 长度与 slot 数，而非完整视觉上下文。

## 6. 主要结论与发现

- **注意力级泛化**：无需任何物体/分割/注意力监督，Pelican-VLA 0.5 的动作通路已自发聚焦指令相关目标与接触区域，并可迁移到未见场景与未见机器人本体，显著强于开源基线。
- **来源归因**：表征能力主要由 slot 瓶颈诱导——未来帧损失与对比损失单独施加于密集模型均无效，仅当"感知→动作"路由被强制经过紧凑 slot 通道时，目标对齐的注意力才显著出现。
- **slot 的可迁移性**：在 MoT 风格架构中插入相同 slot 接口，同样能诱导出物体中心的注意力，说明该机制并非 Pelican-VLA 专属。
- **预训练动态**：注意力先在空间上集中、再在语义上对齐目标；目标 IoU 从 0.054 升至 0.124（Spearman $\rho=0.76, p=0.01$）；机械臂区域注意力几乎不变（$\rho=-0.43, p=0.21$）。
- **零样本 vs 微调**：微调前后注意力 IoU 与相似度都保持高度一致（相似度 > 0.92），说明 fine-tuning 主要把"已形成的以操作为中心注意力"映射到可执行动作，而非从头建立表征。
- **RoboTwin 结果**：微调后在 Clean 与 Randomized 上分别达到 **91.4% 与 91.0%** 的平均成功率，为开源 VLA 中最佳；Clean 与 Randomized 之间差距仅 0.4 个百分点，提示策略对场景外观的依赖较小。
- **明确的"表征-动作"鸿沟**：在严格零样本下策略能接近正确目标，但精细抓取与放置仍是主要失败点，作者将其归因于数据规模与关节空间动作表示的局限，而非 slot 设计本身。

## 7. 优点

- **机制清晰、可解释性强**：以"紧凑瓶颈路由感知→动作"为核心机制，注意力可视化直接对应模型设计，便于分析归因。
- **无需额外监督**：物体/分割/注意力标注都不是必需的，与近期依赖监督式 grounding 的方法（如 GuidedVLA）形成对比。
- **统一架构**：在单一 Transformer 中同时支持视觉语言理解、未来帧预测与动作预测，避免双系统/双专家带来的工程复杂度。
- **可迁移性证据**：在 MoT 风格架构上验证同一 slot 接口仍能诱导操作中心注意力，说明这是一种较为通用的设计模式。
- **公平消融 + 量化分析**：使用控制变量的消融梯度和 IoU/Spearman 等指标，让"slot 才是原因"的结论有数据支撑。
- **推理效率优化**：通过 slot 缓存使去噪循环只重嵌入 suffix，对高频控制场景友好。
- **可复现性强**：开源代码、预训练/微调权重与注意力可视化工具同步发布。

## 8. 不足与局限

- **训练严重欠训练**：仅 0.4 epoch ≈ 2400 小时，作者自己承认处于"substantially under-trained regime"，可能高估或低估某些设计的边际收益。
