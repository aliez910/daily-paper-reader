## 摘要
我们提出了 FabriVLA，一个用于精确多任务操作的轻量级视觉-语言-动作模型。FabriVLA 将 InternVL3.5 视觉-语言骨干网络与一个流匹配动作头相结合，该动作头在动作 token 之间采用门控自注意力机制，并通过浅层 VLM 层融合以丰富空间上下文。该模型通过对预训练 VLM 和随机初始化动作头进行单阶段联合优化训练。在涵盖 50 个多样化操作任务的 Meta-World MT50 基准测试中，FabriVLA 达到了 90.0% 的层级平均成功率，表明基于 10 亿参数级 VLM 构建的紧凑型 VLA 模型无需依赖多十亿参数的 VLA 骨干网络即可实现强劲性能。

## Abstract
We present FabriVLA, a lightweight Vision-Language-Action model for Precise Multi-Task Manipulation. FabriVLA combines an InternVL3.5 vision-language backbone with a flow-matching action head featuring gated self-attention across action tokens and shallow VLM layer fusion for enriched spatial context. The model is trained via single stage joint optimization from a pretrained VLM and randomly initialized action head. On the Meta-World MT50 benchmark spanning 50 diverse manipulation tasks, FabriVLA achieves a tier-average success rate of 90.0%, demonstrating that a compact VLA built on a 1B scale VLM can achieve strong performance without relying on multi billion parameter VLA backbones.

# FabriVLA 论文总结

## 一、核心问题与研究动机

- **背景**：Vision-Language-Action (VLA) 模型已成为通用机器人操控的主流范式，典型代表（如 RT-2、OpenVLA、π0）参数规模动辄数十亿，依赖大规模机器人数据预训练。
- **痛点**：大规模 VLA 推理延迟高、算力开销大，难以满足实时机器人控制的需求；同时，许多模型还需额外的机器人数据预训练，进一步增加部署门槛。
- **核心问题**：能否在不依赖超大参数骨干的前提下，用紧凑型 VLA 在多任务精细操控任务中达到强性能？
- **本文立场**：以约 1B 参数的 VLM 骨干为底座，通过架构与训练策略创新实现"小模型、强性能"。

## 二、方法论

### 2.1 整体架构
FabriVLA 由三部分组成：
1. **视觉-语言骨干**：InternVL3.5-1B，保留 14 层 Transformer，输入图像 448×448。
2. **状态与动作编码器**：分别编码机器人状态和带噪动作。
3. **流匹配动作头**：8 层 FabriVLA TransformerBlock，输出 50×24 的动作块。

### 2.2 关键技术创新

- **门控自注意力 (Gated Self-Attention)**
  - 在动作头每个 Block 内，动作 token 序列先做多头自注意力，再与一个可学习的标量门控 `g` 相乘。
  - 公式：`A' = A + g · SelfAttn(LayerNorm(A))`。
  - 初始化时 `g = 0`，Block 退化为纯 cross-attention；训练中门控逐步打开，平稳引入动作 token 间的时序依赖。

- **浅层 VLM 层融合 (Shallow Layer Fusion)**
  - 同时抽取骨干的浅层（第 6 层，富含空间细节）与深层（第 14 层，富含语义信息）特征。
  - 采用 `concat_proj` 策略：将两层 token 在特征维度拼接后通过一个 `[I | 0]` 初始化的线性层投影回原维度。
  - 初始化的设计使融合模型在零时刻退化为仅深层基线，保证向后兼容；新增参数仅约 2.1M。

- **流匹配训练 (Flow Matching)**
  - 训练时：在归一化动作空间上做线性插值 `x_t = (1-t)·ε + t·a`，其中 `t ~ Beta(2,2)`，使样本集中在中等难度区间。
  - 优化目标：预测速度场 `v_θ`，最小化 `‖v_θ - (a - ε)‖²`。
  - 推理时：从均匀噪声出发，使用 Euler 法积分 50 步得到动作块，以闭环 receding horizon 方式执行。

### 2.3 训练策略
- **单阶段联合优化**：VLM 骨干全程解冻，与随机初始化的动作头一起从头联合训练。
- **精度与并行**：采用 BF16 混合精度 + DeepSpeed ZeRO-2 + FP32 master 权重，避免 BF16 量化噪声吞掉 VLM 的小幅梯度更新。

## 六、主要结论与发现

- **总体性能**：FabriVLA（0.89B）在 MT50 上取得 **90.0% 层级平均成功率**与 **92.0% 整体回合成功率**，在对比方法中位列第一，且**未使用任何机器人数据预训练**。
- **分难度表现**：easy 95.0% / medium 88.2% / hard 86.7% / very hard 90.0%，easy 档最强，其余三档为对比中的第二名（仅次于 LA4VLA）。
- **任务结构洞察**：
  - **强项**：平面滑移 (95.7%)、铰接触执行 (95.7%)、插入装配类 (93.3%)、精度子集 (94.0%)。
  - **弱项**：工具介导 (83.3%)、粗略运输 (85.0%)、抓取放置 (86.0%)。
- **架构组件贡献**：
  - 浅层 layer-6 融合使层级平均成功率 +7.1 pp、整体成功率 +5.2 pp。
  - 门控自注意力是动作头的决定性组件（基线 48.5% → 加 SA 57.7%）；token-residual head 与时序卷积在该设置下均带来性能下降。
- **总体结论**：1B 级别的紧凑型 VLA 通过精心的特征融合与动作头设计，可以摆脱对数十亿参数 VLA 骨干的依赖。

## 七、优点 / 亮点

- **极致轻量化**：约 0.89B 参数即可在 50 项任务上击败更大模型，适合实时部署。
- **零初始化门控机制**：保证训练起点退化为简单基线，平滑引入自注意力依赖，优化稳定。
- **向后兼容的层融合**：`[I | 0]` 初始化使浅层融合"无损可关闭"，实验设计干净。
- **Beta(2,2) 时间采样**：聚焦最有信息量的中等难度区间，提升训练效率。
- **训练细节扎实**：明确指出 BF16 + DeepSpeed + FP32 master 是 VLM 获得有意义梯度的关键，这一工程经验对社区有借鉴价值。
- **分析维度多元**：除 tier 平均外，按操控需求重新分组，给出可解释的强弱项分析。

## 八、不足与局限

- **仅仿真、单基准**：全部实验在 Meta-World MT50 仿真环境中完成，缺乏真实机器人部署验证；与现实世界的 sim-to-real 差距未讨论。
- **数据规模有限**：每任务仅 50 条轨迹（共 2500 条），难以判断方法在大规模数据下的扩展性。
- **基线复现缺失**：Table 1 中的对比数字直接取自各原论文，未在统一硬件/协议下重训，公平性存在疑问。
- **消融设置不一致**：模块消融使用 50k 步 + 冻结 VLM 的简化协议，与最终模型的全量联合训练不同，绝对数字无法直接比较。
- **训练动力学不稳定**：观察到 100k 步相对 93k 步出现轻微退化，提示当前设置可能尚未收敛或对训练步数敏感，缺乏进一步分析。
- **结构性弱点明确**：工具介导、粗略运输、抓取放置等任务成功率偏低，说明模型在长程规划与工具使用方面仍有显著不足。
- **未报告的内容**：单卡/总训练时长、显存占用、推理延迟与吞吐量、与其他轻量 VLA 的速度对比，这些对"轻量级"定位至关重要。
- **应用限制**：仅使用单一 corner RGB 视角，未探索多视角或深度输入；固定 50 步动作块与 4 维有效动作，针对 Meta-World 设定，未讨论在其他机器人本体（如机械臂灵巧手、夹爪/吸盘切换）上的迁移能力。
