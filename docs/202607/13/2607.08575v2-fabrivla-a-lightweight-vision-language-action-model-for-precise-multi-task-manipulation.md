## 摘要
我们提出了 FabriVLA，一种用于精确多任务操作的轻量级视觉-语言-动作模型。FabriVLA 将 InternVL3.5 视觉-语言骨干网络与流匹配动作头相结合，采用跨动作标记的门控自注意力机制以及浅层 VLM 层融合以丰富空间上下文。该模型通过从预训练 VLM 和随机初始化的动作头进行单阶段联合优化训练。在涵盖 50 种多样化操作任务的 Meta-World MT50 基准测试上，FabriVLA 达到了 90.0% 的分层平均成功率，表明基于 1B 规模 VLM 构建的紧凑型 VLA 能够在不依赖数十亿参数 VLA 骨干网络的情况下实现强劲性能。

## Abstract
We present FabriVLA, a lightweight Vision-Language-Action model for Precise Multi-Task Manipulation. FabriVLA combines an InternVL3.5 vision-language backbone with a flow-matching action head featuring gated self-attention across action tokens and shallow VLM layer fusion for enriched spatial context. The model is trained via single stage joint optimization from a pretrained VLM and randomly initialized action head. On the Meta-World MT50 benchmark spanning 50 diverse manipulation tasks, FabriVLA achieves a tier-average success rate of 90.0%, demonstrating that a compact VLA built on a 1B scale VLM can achieve strong performance without relying on multi billion parameter VLA backbones.

# FabriVLA 论文总结

## 1. 核心问题与整体含义

- **研究背景**：视觉-语言-动作（Vision-Language-Action, VLA）模型是通用机器人操作的热门范式，通过预训练的视觉-语言模型将语言指令与视觉观测对齐，生成可执行动作序列。
- **核心矛盾**：现有大规模 VLA 模型（如 π0、RT-2 等）参数规模达数十亿，计算开销大、推理延迟高，难以满足实时机器人控制的需求。
- **研究目标**：设计一种轻量级 VLA 模型，在保持较强多任务操作性能的同时，显著降低参数规模与部署成本。
- **核心论点**：证明基于 1B 规模 VLM 构建的紧凑型 VLA 同样能够胜任多任务精确操作，无需依赖数十亿参数的大型基座。

## 2. 方法论

### 2.1 整体架构
FabriVLA 由三个核心组件构成：
1. **InternVL3.5-1B 视觉-语言骨干**：仅保留 14 层 Transformer，输入图像缩放至 448×448。
2. **状态与动作编码器**：将 24 维机器人状态编码为 1024 维 token；将 50 步动作噪声编码为带位置编码的动作 token 序列。
3. **流匹配动作头**：8 层 Transformer 块，每层包含门控自注意力、跨注意力与时间条件 FFN。

### 2.2 关键技术细节

- **门控自注意力（Gated Self-Attention）**：
  - 公式：`A' = A + g · SelfAttn(LayerNorm(A))`
  - 关键设计：可学习门控参数 `g` 初始化为 **0**，训练初始阶段等效于纯跨注意力；训练过程中门控逐渐打开，让动作 token 学习跨步骤依赖。
  - 实现：先对 50 步动作 token 做自注意力，再与 VLM 上下文 token 做跨注意力，最后经 FFN + 时间嵌入输出。

- **浅层 VLM 层融合（Shallow Layer Fusion）**：
  - 提取第 6 层（保留空间细节）与第 14 层（高层语义）的特征；
  - 通过 `concat_proj` 方式拼接（`W ∈ R^{2048×1024}`）后投影回原始维度；
  - 投影矩阵初始化为 `[I | 0]`，确保初始化时与仅深层基线完全一致（向后兼容）。

- **流匹配训练**：
  - 公式：`x_t = (1-t)ε + t·a`，目标速度场：`v = a - ε`
  - 损失函数：期望预测速度与目标速度的均方误差
  - 时间采样：使用 **Beta(2,2)** 分布，集中于中间区域（t=0.5），避免过靠近纯噪声或纯净动作的退化区域。

- **单阶段联合训练**：VLM 骨干全部解冻，与随机初始化的动作头从训练开始就联合优化（区别于先微调 VLM 再训练动作头的多阶段方案）。

- **推理阶段**：从均匀噪声 `x_0 ~ U([-1,1]^{50×24})` 出发，采用 Euler 积分 50 步生成动作块，以闭环滚动时域方式执行。

- **架构简洁高效**：以 1B 规模 VLM 为骨干，无机器人预训练仍取得最优结果，证明"小而精"路线的可行性。
