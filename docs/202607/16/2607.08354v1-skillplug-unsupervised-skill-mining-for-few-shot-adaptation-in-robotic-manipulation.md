## 摘要
学习可迁移的视觉运动模仿策略，使其能够泛化到多种操作任务，并仅从少量演示中快速适应新任务，仍然是一项挑战。大多数现代策略采用端到端训练，将观测直接映射到底层动作，几乎没有显式结构来跨任务重用和重组行为，导致在监督有限的情况下迁移数据效率低下。我们提出了 SkillPlug，一个可插拔的框架，通过技能条件模块增强现有的视觉运动策略，并从原始多任务演示中挖掘一个共享的、可迁移的技能库。SkillPlug 通过自监督目标学习技能，这些目标促进行为级原语的紧凑性、可重用性和非冗余性，从而形成一个任务共享的先验，用于组合控制。在技能挖掘完成后，我们保持所学技能不变，仅通过微调轻量级的路由器和动作头来适应未见过的任务，从而无需完整的端到端重训练即可实现高效适应。我们在两个仿真基准和一个真实机器人上对 SkillPlug 进行了评估，观察到所挖掘的可迁移技能持续提升了多任务性能和少样本适应能力。总体而言，SkillPlug 提供了一种可扩展的方式来挖掘可重用技能，从而改善机器人操作中数据高效泛化的能力。

## Abstract
Learning transferable visuomotor imitation policies that generalize across diverse manipulation tasks and adapt rapidly to new tasks from only a handful of demonstrations remains challenging. Most modern policies are trained end-to-end to map observations directly to low-level actions, offering little explicit structure for reusing and recombining behaviors across tasks and making transfer data-inefficient under limited supervision. We propose SkillPlug, a plug-in framework that augments an existing visuomotor policy with a skill-conditioning module and mines a shared, transferable skill library from raw multi-task demonstrations. SkillPlug learns skills via self-supervised objectives that promote compact, reusable, and non-redundant behavior-level primitives, forming a task-shared prior for compositional control. After skill mining, we keep the learned skills fixed and specialize to unseen tasks by fine-tuning only lightweight router and action head, enabling efficient adaptation without full end-to-end retraining. We evaluate SkillPlug on two simulation benchmarks and on a real robot, and observe that the mined transferable skills consistently improve both multi-task performance and few-shot adaptation. Overall, SkillPlug offers a scalable way to mine reusable skills that improve data-efficient generalization in robotic manipulation.

# SkillPlug 论文总结

## 1. 核心问题与研究动机

- **核心问题**：在机器人模仿学习领域，当前的视觉运动（visuomotor）策略通常采用**端到端训练**，直接将观测映射到底层动作，缺乏显式的行为级结构。
- **由此带来的两个痛点**：
  - 难以**跨任务**发现并重用共享的行为模式；
  - 在仅有**少量演示（few-shot）** 的新任务上，数据效率低下，迁移成本高。
- **现有方案的不足**：
  - 人工标注或 VLM 分割定义技能（如 approach/grasp/place）的方式依赖大量手工设计与阶段切分；
  - 数据驱动学习技能（轨迹聚类、技能 embedding、MoE 路由）但缺乏对**可重用性、可分离性、与场景解耦**的显式约束，易出现技能坍塌或与视觉上下文纠缠。
- **本文目标**：提出一种**无监督的、可迁移技能挖掘**方案，使得一个共享的技能库能够跨任务复用，并支持新任务上的快速微调。

## 2. 方法论

### 2.1 整体框架（Plug-in 思路）
- 将任意已有的视觉运动策略视为**场景编码器 $f_{\text{enc}}$ + 动作头 $f_{\text{act}}$**，在二者之间插入**技能条件模块**，不改变原 backbone 的结构与张量形状。
- 关键组件包括：
  - **技能库（Skill Library）**：$K$ 个可学习的技能 embedding $\{s_k\}_{k=1}^{K}$，跨任务共享；
  - **轨迹-技能后验编码器（Trajectory-skill Posterior Encoder）**：仅以动作段 $\tau$ 为输入，经 MLP 投影得到 $f_\tau$，再与 $s_k$ 联合输出 VAE 风格的后验 $q_\phi(z_k \mid f_\tau, s_k)$，作为信息瓶颈，**仅在多任务训练阶段使用**，推理时丢弃；
  - **技能交互器（Interactor）**：以**交叉注意力**实现，将场景特征 $h_t$ 与每个技能 $s_k$ 结合，输出每个技能的调制特征 $u_{t,k}$；
  - **路由器（Router）**：在 chunk 级别预测权重 $r_\tau \in \mathbb{R}^K$，对所有 $u_{t,k}$ 加权求和后送入原动作头。

### 2.2 自监督学习目标（四项损失）
1. **重建损失** $\mathcal{L}_{\text{rec}}$：在 chunk 长度 $n$ 上做 L1 行为克隆，监督预测动作与真实动作。
2. **KL 正则** $\mathcal{L}_{\text{KL}}$：对后验 $q_\phi(z_k \mid f_\tau, s_k)$ 与先验 $p(z)$ 施加 KL 散度，**抑制技能过度拟合场景外观**，促使技能捕获跨轨迹稳定的结构。
3. **行为技能对齐损失** $\mathcal{L}_{\text{BSA}}$（InfoNCE 风格）：通过 soft-label 分类，将路由权重 $r_\tau$ 作为固定目标（stop-gradient），让技能 embedding 与轨迹行为互信息 $I(\tau; s)$ 最大化，从而把技能"绑定"到行为而非视觉。
4. **技能解耦损失** $\mathcal{L}_{\text{SD}}$：对同一观测下不同技能的调制特征做时间平均与 L2 归一化，最小化两两余弦相似度，避免**技能坍塌**和冗余。
- **总损失**：$\mathcal{L} = \mathcal{L}_{\text{rec}} + \lambda_{\text{KL}}\mathcal{L}_{\text{KL}} + \lambda_{\text{BSA}}\mathcal{L}_{\text{BSA}} + \lambda_{\text{SD}}\mathcal{L}_{\text{SD}}$。

### 2.3 训练-冻结-适配协议（Train-then-Freeze）
- 多任务训练阶段挖掘并固定技能库；
- **少样本适应阶段冻结** backbone 编码器与技能 embedding，**仅微调路由器与动作头**，从而把新任务的学习成本压低到"学会如何组合/重用已有技能"。

## 6. 主要结论与发现

- **多任务性能全面提升**：
  - DISCOVERSE：ACT+SkillPlug 在困难任务上大幅提升（如 jujube pick 6.7%→94.0%，drawer open 0%→100%，stack block 15.3%→80.7%），多任务平均提升 **+45.1 pp**；
  - LIBERO：在已接近饱和的基线上仍保持竞争力（Long/Object/Goal 小幅提升，Spatial 相当）。
- **少样本适应显著改善**：
  - DISCOVERSE 10 演示少样本平均提升 **+18.1 pp**；
  - LIBERO 跨 suite 5 演示平均提升 **+38.3 pp**；
  - 真机少样本平均成功率从 6/20 提升至 11.7/20。
- **挖掘出的技能具备四项关键性质**：
  1. **场景无关（scene-agnostic）**：同一技能在不同场景下稳定触发相同原语（如开爪、前进）；
  2. **可组合**：通过路由权重混合两个技能可生成"边前进边开爪"等组合行为；
  3. **可解释的阶段结构**：路由权重随时间呈现接近语义阶段（接近、抓取、运送）的模式；
  4. **存在合理冗余边界**：$K=4$ 后增大 $K$ 收益递减（DISCOVERSE 88% → 90%），余弦相似度显示 K=6 时已出现技能冗余。
- **额外收益——推理效率提升**：在 DISCOVERSE 所有任务上 ACT+SkillPlug 每个成功回合所需推理步数更少（如 block bridge place 181→119，stack block 126→86）。

## 7. 优点 / 亮点

- **Plug-in / 架构无关**：只需知道编码器与动作头的张量形状即可集成，无需修改 backbone，已验证在 ACT 与 OpenVLA-OFT 上均有效；
- **真正无监督**：不依赖人工阶段标注或 VLM 切分，从原始演示中自监督地学到可解释的、阶段结构化的技能；
- **多目标协同**：四项损失在功能上互补——重建保真、KL 促紧凑、BSA 绑行为、SD 防坍塌，消融表明四者缺一不可；
- **适配高效**：冻结 backbone 与技能，仅微调 router 与 action head，契合 few-shot 的真实需求；
- **分析维度多元**：除定量成功率外，还从场景无关性、可组合性、路由可解释性、技能冗余与推理效率多角度分析，强化结论可信度；
- **真机验证**：包含真实机器人多任务与少样本实验，而非仅停留在仿真。

## 8. 不足与局限

- **技能库固定**：作者明确指出，技能库在多任务训练结束后即冻结，**无法在适配阶段引入新原语**，因此当新任务需要训练集中不存在的行为模式时可能受限（论文将其列为未来工作：continual / cross-embodiment 下的可扩展技能库）；
- **资源信息缺失**：未报告 GPU 型号/数量、训练时长等算力信息，**可复现性受限**；
- **基准范围**：实验集中在 DISCOVERSE（7 任务）与 LIBERO（130 任务）两类桌面操作，**未覆盖移动操作、长任务链、双臂等更复杂场景**；
- **消融的统计严谨性**：消融项为 single-seed，主结果为 3-seed，**两者的可比性需谨慎解读**；
- **K 的选择依赖任务**：K 需手动设定，文中通过消融给出经验值（DISCOVERSE 用 4，LIBERO 用 8），**未给出自动确定 K 的机制**；
- **真机任务规模较小**：真机仅 6+3 任务，每任务 20 次试验，**统计强度低于仿真**，且未给出方差；
- **缺乏与已有技能学习方法的直接对比**：文中主要以"vanilla baseline + SkillPlug"作对比，**未与其它显式技能学习（人工分段、VLM 标注、MoE）方法做 head-to-head**，使得增益归因到"技能"本身的证据稍弱。
