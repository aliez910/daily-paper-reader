## 摘要
视觉-语言-动作（VLA）模型旨在将多模态输入映射为机器人动作。然而，现有方法由于对所有视觉 token 一视同仁，且仅基于人工选取的因素进行推理，缺乏突出任务关键证据的机制并忽略了潜在因素，因此难以覆盖复杂的动态场景。为解决这一问题，我们提出了 LEEVLA，一种面向潜在环境演化关键信息聚焦的 VLA 架构，能够显式引导模型关注信息丰富的区域，同时保持潜在世界表征的结构化演化。为了识别显著且与指令相关的区域，我们引入了漂移引导的动态优先级（DGDP），它将动态位置优先级（DPP）与语义漂移引导（SDG）相结合，以指导 VLA 智能体在训练过程中的注意力分配。在此基础上，我们进一步引入了结构化特征流生成（SFFG），通过原型到外围（P2P）预测建模这些被优先排序的特征在潜在空间中应如何演化，并采用互邻域对比（MC）损失以保持邻域间的拓扑一致性。DGDP 与 SFFG 共同构成了一个任务感知的"何处—如何"训练框架。在 VLA 基准上的大量实验表明，LEEVLA 始终优于先前方法，证实了显式的任务证据引导与结构化的潜在推理对于可扩展的 VLA 均至关重要。代码已开源，地址为 https://github.com/LyuQi127/LEEVLA。

## Abstract
Vision-language-action (VLA) models aim to map multimodal inputs to robot actions. However, most existing approaches struggle to cover complex dynamic scenarios due to treating all visual tokens uniformly and reasoning with human-selected factors, which lack mechanisms to emphasize task-critical evidence and ignore underlying factors. To address this issue, we propose LEEVLA, a VLA architecture for seeing what matters in Latent Environment Evolution that explicitly guides the model toward informative regions while preserving the structured evolution of latent world representations. To identify salient and instruction-relevant regions, we introduce drift-guided dynamic prioritization (DGDP), which combines dynamic position prioritization (DPP) with semantic drift guidance (SDG) to guide the VLA agent where to attend during training. On top of this, we introduce structured feature flow generation (SFFG), which models how these prioritized features should evolve in latent space via prototype-to-periphery (P2P) prediction, and a mutual-neighborhood contrastive (MC) loss to maintain topological consistency among neighborhoods. Together, DGDP and SFFG form a task-aware "where-how" training framework. Extensive experiments on VLA benchmarks show that LEEVLA consistently outperforms prior methods, confirming that explicit task-evidence guidance and structured latent reasoning are both crucial for scalable VLA. Our code is available at https://github.com/LyuQi127/LEEVLA.

# LEEVLA 论文总结

## 1. 核心问题与研究动机

视觉-语言-动作（VLA）模型旨在将多模态输入（视觉、本体感知、语言指令）映射为机器人连续动作。论文指出现有 VLA 方法存在两大核心痛点：

- **视觉 token 一视同仁**：现有方法对所有 patch 特征施加均匀监督，导致梯度被静态背景和与任务无关的区域稀释，无法突出任务关键证据。
- **推理依赖人工预设因素**：以 CoT-VLA、DreamVLA 等为代表的"显式推理"方法需要在外部条件（子目标图、分割图、深度图）下进行，而这些条件依赖辅助模型，开销大且受限于感知子任务的进展，导致"已知因素过度强调、未知任务相关因素探索不足"。
- **因果视角**：动作生成受已知与未知因素共同驱动，但现有方法过度依赖前者；本文倡导直接在潜在特征空间中进行推理。

整体含义：提出一种**训练阶段**的"where–how"框架，在不增加推理成本的前提下，让 VLA 自动聚焦任务关键区域，并以结构化方式建模特征在潜空间中的演化。

## 2. 方法论

LEEVLA 的核心由两大模块构成：**DGDP（何处关注）** + **SFFG（如何演化）**，均为**仅训练阶段**使用的辅助监督。

### 2.1 Drift-Guided Dynamic Prioritization（DGDP）

由两个子模块耦合得到每个 patch 的优先级权重 βᵢ = σ(ωᵢ · θᵢ)。

- **Dynamic Position Prioritization（DPP）**：通过相邻时间步 patch 特征的余弦相似度变化量化动态性。
  - 动态分数：**θᵢ = 1 − cos(vₜ,ᵢ, vₜ₊ₜ,ᵢ)**
  - 直观上，机器人交互区、目标物体区变化剧烈，背景变化小，故可用变化量区分关注区域。

- **Semantic Drift Guidance（SDG）**：在动态性基础上叠加指令相关性方向。
  - 指令相关性分数：**rₜ,ᵢ = max_{1≤j≤M} ⟨x̃ₜ,ᵢ, c̃ⱼ⟩**（patch 与语言 token 的最大内积）
  - 语义漂移：**Δᵢ = clip((rₜ₊ₜ,ᵢ − rₜ,ᵢ)/τ, −δ, δ)**，再归一化到 [−1, 1]
  - 漂移引导因子：**ωᵢ = exp(Δ̃ᵢ/τ)**

最终 βᵢ 经 sigmoid 调制，抑制漂向背景语义的 patch，强化漂向指令相关语义的动态 patch。

### 2.2 Structured Feature Flow Generation（SFFG）

解决"扁平化 token 预测破坏局部语义结构"问题，由 P2P + MC 组成。

- **Prototype-to-Periphery（P2P）预测**：
  1. 对多视图未来特征 [fₚᵗ⁺ᵀ; fʷᵗ⁺ᵀ] 做联合聚类得到簇 C = {cₗ}。
  2. 在每个簇内，按成员到质心 μₗ 的欧氏距离由近到远排序，形成"原型→外围"有序序列 −→cₗ。
  3. P2P 损失：**L_P2P = (1/|C|) Σ_ℓ (1/|−→cₗ|) Σ_{j∈−→cₗ} (α + βⱼ)·φ(v̂ₜ₊ₜ,ⱼ, vₜ₊ₜ,ⱼ)**，其中 α 为全局调制因子（设为 1），φ 为余弦嵌入损失。

- **Mutual-Neighborhood Contrastive（MC）Loss**：
  - 一阶邻域 G⁽¹⁾ᵢ：Top-K（K=10）相似 token；
  - 二阶邻域 G⁽²⁾ᵢ：一阶邻居各自的 Top-M（M=5）邻居并集；
  - 正样本集 G⁺ᵢ：仅保留**互为邻居**的 token，过滤不对称 / 噪声连接；
  - 采用 InfoNCE 形式的对比损失，温度 τ_c。

### 2.3 整体训练目标

- 动作回归损失（与 OpenVLA-OFT 一致的并行 L1 回归）：**L_action = (1/T) Σ |aₜ₊ᵢ − âₜ₊ᵢ|₁**
- 总损失：**L_total = λ₁L_action + λ₂L_P2P + λ₃L_MC**

### 2.4 架构与流程

- 视觉编码器：DinoV2 + SigLIP 组合，产生 patch 特征 → projector → LLM token。
- 语言经 tokenizer 编码，本体感知经 Es 嵌入。
- 引入 Future Feature Decoder D，将视觉 embedding 映射到未来特征空间，为 P2P/MC 提供监督目标。
- 动作策略：MLP 头从 LLM 最后一层 hidden state 并行回归连续动作块。
