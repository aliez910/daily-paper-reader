## 摘要
生成式视觉-语言-动作策略推动了机器人操作的进步，但在噪声、部分可观测性和随机初始条件下常常表现出不稳定性。在长时序展开过程中，微小的速度误差会累积，从而降低执行可靠性。现有的基于扩散和流的方法通常假设残差具有同方差性，且在动作生成过程中缺乏显式的不确定性建模，限制了在迭代展开过程中的鲁棒性。本文提出 SUREFlow，一个基于 Mamba 主干网络构建的状态空间不确定性感知残差流匹配框架。该方法联合预测动作速度与随输入变化的残差不确定性，无需环境反馈即可对不可靠的动作维度进行选择性细化，同时保持计算效率。在 LIBERO 上，SUREFlow 取得了 92.5% 的平均成功率（SR），比基于 Mamba 的 MaIL 高出 34.2%。在 LIBERO-PRO 上，它仅使用 179M 参数便取得了约 49% 的成功率，性能可与参数量为 3–7B 的大型 VLA 模型相媲美。SUREFlow 源代码可在以下网址获取：https://github.com/tanvirnwu/SUREFlow

## Abstract
Generative vision-language-action policies have advanced robot manipulation, but they often exhibit instability under noise, partial observability, and stochastic initial conditions. During extended rollouts, small velocity errors accumulate, degrading execution reliability. Existing diffusion and flow-based policies typically assume homoscedastic residuals and lack explicit uncertainty modeling within action generation, limiting robustness during iterative rollout. We propose SUREFlow, a state-space uncertainty-aware residual flow matching framework built on a Mamba backbone. The method jointly predicts action velocities and input-dependent residual uncertainty, enabling selective refinement of unreliable action dimensions without environment feedback while preserving computational efficiency. On LIBERO, SUREFlow achieves 92.5% average success rate (SR), outperforming the Mamba-based MaIL by 34.2%. On LIBERO-PRO, it attains around 49% SR using only 179M parameters, achieving performance comparable to large VLAs with 3-7B parameters. SUREFlow source code is available on: https://github.com/tanvirnwu/SUREFlow

# SUREFlow 论文总结

## 1. 核心问题与研究动机

- **问题背景**：生成式视觉-语言-动作（VLA）策略在机器人操控中虽显著提升了多模态行为表达能力，但在噪声环境、部分可观测场景及随机初始条件下表现出不稳定性。
- **关键挑战**：在长时序（long-horizon）开环执行过程中，速度场预测的微小误差会随时间累积，导致执行可靠性下降甚至任务失败。
- **现有方法的局限**：
  - 基于扩散（Diffusion Policy）和流匹配（Flow Matching）的方法通常假设残差具有同方差性（homoscedastic residuals），未对预测不确定性进行显式建模。
  - 大多数 VLA 模型依赖大规模 Transformer 主干（如 OpenVLA 7B、π0.5 3B），计算开销巨大。
  - 缺乏在推理阶段对不可靠动作维度进行选择性修正的机制。
- **研究目标**：提出一种轻量级、具备不确定性感知能力的生成式机器人操控策略，缓解长时序误差累积问题。

## 2. 方法论

### 2.1 整体框架（SUREFlow）

- 基于 **Mamba 状态空间模型**作为共享序列建模骨干，融合多模态输入（视觉、本体状态、语言）。
- 通过 **条件流匹配（Conditional Flow Matching）** 建模动作生成，将高斯噪声通过学习的速度场映射至专家动作分布。
- 联合预测动作速度与输入相关的残差不确定性，实现推理阶段无环境反馈的内部残差修正。

### 2.2 关键模块

- **Flow Conditioned Modulation (FCM)**：将连续流时间 $t \in [0,1]$ 通过正弦频率嵌入 + 两层 MLP 编码为 $\phi(t)$，再经两个线性投影生成调制参数 $\gamma, \beta$，对中间特征进行逐元素仿射变换：
  $$\text{FCM}(U, \phi(t)) = U \odot (1 + \gamma) + \beta$$
  初始化为恒等映射，保证训练稳定。

- **Memory-Guided Action Decoder (MGAD)**：将动作 token 作为可学习查询（10 个 queries），通过单层 4 头 cross-attention 与多模态记忆表征交互；后接 2 层 FFN（隐藏维度 512）和 LayerNorm，实现轻量级上下文聚合。

- **Uncertainty-aware Residual Flow (URFlow)**：
  - 概率路径：$x_t = (1-t)a + tz$，其中 $a \sim p_0$（专家动作），$z \sim \mathcal{N}(0,I)$。
  - 解析目标速度：$v_t(x_t) = z - a$。
  - 残差定义：$r_t = \hat{v}_t - v_t(x_t)$。
  - 异方差不确定性损失：
    $$L_u = \|r_t\|_2^2 / \exp(\hat{s}_t) + \hat{s}_t$$
  - 总损失：$L = L_{FM} + \lambda_u L_u$，其中 $\lambda_u = 0.001$。

### 2.3 推理阶段不确定性引导的残差修正

- 在 $t=0$ 时评估预测的对数方差 $\hat{s}_0$，构建不确定性掩码 $\mathcal{M} = \{i \mid \hat{s}_{0,i} > \tau\}$（阈值 $\tau=0.9$）。
- 仅对掩码内的动作维度进行残差更新：$a_i \leftarrow a_i - \eta \hat{v}_{0,i}$，迭代 $K=3$ 次。
- 整个过程完全在模型内部完成，无需在线环境反馈或动作校正。

## 6. 主要结论与发现

- **性能优势**：在 LIBERO 上平均 SR 达 **92.5%**，较 Mamba 基线 MaIL 提升 **34.2%**，较 Diffusion Policy 提升约 **78%**。
- **Meta-World**：平均 SR **88.32%**，超越 DP3（74.4%）、Diffusion Policy（37.6%）等。
- **分布偏移鲁棒性**：在 LIBERO-PRO 上以 **179M 参数**取得 **约 49% SR**，与 OpenVLA（7B, 52%）和 π0.5（3B, 53%）相当，优于 π0（3B, 44%）。
- **长时序稳定性**：开启 URFlow 后，随 rollout 长度增加，SR 衰减明显减缓。
- **不确定性校准**：MGAD 模块使训练过程中 $\hat{s}$ 范围更稳定，避免过度自信。
- **轻量化**：相比 3–7B 大模型，SUREFlow 降低超过一个数量级的参数规模，性能仍可比拟。

## 7. 优点与亮点

- **方法新颖性**：首次将不确定性感知残差流匹配与状态空间生成式流策略结合，填补了异方差不确定性建模在机器人流匹配中的空白。
- **计算高效**：基于 Mamba 的线性时间复杂度，配合 179M 轻量参数，适合实际部署。
- **选择性修正机制**：通过不确定性阈值引导的残差更新，仅修正不可靠动作维度，避免过修正。
- **MGAD 设计**：使用单层 cross-attention 而非完整 Transformer 解码器，在提升性能的同时保持轻量。
- **模块化与可解释性**：FCM、MGAD、URFlow 三模块可独立消融，便于分析贡献。
- **真实机器人验证**：在 Franka 机械臂上完成多步骤颜色匹配与插入任务，证明实际可用性。

## 8. 不足与局限

- **真实机器人实验有限**：仅测试单一桌面抓取插入任务（颜色匹配），未涵盖更复杂扰动（如强光遮挡、动态障碍、多物体堆叠）。
- **样本规模较小**：真实机器人每颜色仅 20 次 rollout（共 60 次），统计显著性有限。
- **未与其他流匹配 SOTA 方法直接对比**：除 Diffusion Policy 外，未与近期专门的 Flow Matching 操控策略（如 FlowMatching-based policy）做同等规模比较。
- **阈值与超参数敏感性**：$\tau=0.9$ 与 $\lambda_u=0.001$ 为经验调参，缺乏跨任务自适应机制。
- **语言编码器固定**：使用 CLIP ViT-B/32 冻结编码，未探索更大或更新的语言编码器对任务理解的提升。
- **数据集偏差风险**：LIBERO/Meta-World 均为仿真环境，存在 sim-to-real gap；真实实验未在扰动条件下系统测试。
- **训练算力信息不完整**：未报告训练总时长、单 epoch 时间，难以评估实际训练成本。
- **扰动鲁棒性提升有限**：在 LIBERO-PRO 的语义扰动（Sem）下，SUREFlow 仍为 0.00，说明对语义级分布偏移处理不足。
