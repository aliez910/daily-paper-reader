## 摘要
我们提出了 FabriVLA，一种用于精确多任务操作的轻量级视觉-语言-动作模型。FabriVLA 将 InternVL3.5 视觉-语言骨干网络与流匹配动作头相结合，该动作头在动作令牌间采用门控自注意力机制，并通过 VLM 浅层融合来丰富空间上下文。该模型以单阶段联合优化的方式进行训练，从预训练 VLM 和随机初始化的动作头出发。在涵盖 50 种多样化操作任务的 Meta-World MT50 基准上，FabriVLA 达到了 90.0% 的层级平均成功率，表明基于 1B 规模 VLM 构建的紧凑型 VLA 能够在不依赖数十亿参数级 VLA 骨干网络的情况下取得优异性能。

## Abstract
We present FabriVLA, a lightweight Vision-Language-Action model for Precise Multi-Task Manipulation. FabriVLA combines an InternVL3.5 vision-language backbone with a flow-matching action head featuring gated self-attention across action tokens and shallow VLM layer fusion for enriched spatial context. The model is trained via single stage joint optimization from a pretrained VLM and randomly initialized action head. On the Meta-World MT50 benchmark spanning 50 diverse manipulation tasks, FabriVLA achieves a tier-average success rate of 90.0%, demonstrating that a compact VLA built on a 1B scale VLM can achieve strong performance without relying on multi billion parameter VLA backbones.

# FabriVLA 论文总结

## 1. 核心问题与整体含义

- **研究背景**：视觉-语言-动作（VLA）模型已成为通用机器人操控的主流范式，通过预训练的视觉-语言模型将语言指令锚定于视觉观测，并输出可执行动作序列。
- **核心痛点**：以 RT-2、π0、OpenVLA 等为代表的 VLA 模型参数规模高达数十亿，带来高昂的计算成本与推理延迟，难以满足实时机器人控制的需求。
- **研究目标**：在不依赖超大规模 VLM 骨干的前提下，构建轻量级（1B 参数级）VLA，使其在多任务、精细操控场景下仍保持高精度，从而推动 VLA 的实际部署。

## 2. 方法论

### 2.1 整体框架
FabriVLA 由三部分组成：(1) InternVL3.5-1B 视觉-语言骨干；(2) 状态编码器与动作编码器；(3) 基于流匹配（Flow Matching）的动作头。整体采用**单阶段联合优化**方式，从预训练 VLM 与随机初始化动作头一同训练。

### 2.2 视觉-语言骨干
- 采用 InternVL3.5-1B，图像统一缩放至 448×448 经视觉编码器得到视觉 token；
- 任务文本（如 "Dunk the basketball into the basket"）经分词器与视觉 token 拼接，由 VLM 联合处理；
- 保留骨干的 **14 层 Transformer 层**，输出语境化的多模态 token。

### 2.3 状态与动作编码
- 24 维机器人状态 $s$（末端执行器位姿、夹爪状态、物体位置）经两层 MLP+ReLU 编码为 1024 维状态 token $z_s$，并前置拼接到 VLM context token；
- 噪声动作 $x_t \in \mathbb{R}^{50 \times 24}$（50 步预测视野、每步 24 维）由 `MultiEmbodimentActionEncoder` 共享 MLP 投影（24→1024→1024→1024），并叠加 horizon 位置编码，得到动作 token 序列 $Z_a \in \mathbb{R}^{50 \times 1024}$。

### 2.4 动作头关键设计

#### ① 门控自注意力（Gated Self-Attention）
- 在 8 层 FabriVLA TransformerBlock 内，动作 token $A \in \mathbb{R}^{50 \times 1024}$ 与 VLM context token $C \in \mathbb{R}^{N \times 1024}$ 依次经过：
  1. 多头自注意力 + **可学习门控 $g$**（初始化为 0）：
$$A' = A + g \cdot \text{SelfAttn}(\text{LayerNorm}(A))$$
  2. 跨注意力到 context：$A'' = A' + \text{CrossAttn}(\text{LayerNorm}(A'), C, C)$
  3. 注入 time embedding 的 FFN（1024→4096→1024，GELU）。
- **门控初始化为 0** ⇒ 训练初期块等价于"仅含跨注意力的 Transformer"，保障稳定优化起点；训练中门控逐渐打开，建模 50 步动作 token 的步间依赖。

#### ② 浅层 VLM 层融合（Shallow Layer Fusion）
- 同时提取 VLM 第 14 层（语义层）和第 6 层（空间细节层）的 token；
- 采用 `concat_proj` 融合策略：沿特征维拼接后由 $W \in \mathbb{R}^{2048 \times 1024}$ 线性投影回 1024 维；
- $W$ 初始化为 $[I\ |\ 0]$，确保**初始化时与 deep-only 基线完全一致**，仅在 2.1M 参数开销下引入低级空间细节。

#### ③ 流匹配训练与推理
- 时间 $t \in [0,1]$ 来自 $\text{Beta}(2,2)$ 分布（中间区域采样更密集）；
- 插值：$x_t = (1-t)\epsilon + t a$，其中 $\epsilon \sim U([-1,1]^{50\times 24})$；
- 目标速度 $a - \epsilon$，损失函数：
$$\mathcal{L}(\theta) = \mathbb{E}_{t,\epsilon,a}\left[\|v_\theta(x_t,t|\cdot) - (a-\epsilon)\|^2\right]$$
- time embedding 通过 $p = \lfloor 1000t \rfloor$ 取正弦位置编码；
- 推理时从均匀噪声出发，Euler 积分 50 步得动作 chunk，并以**闭式递推视野**（closed-loop receding horizon）执行。

## 6. 主要结论与发现

- 在 Meta-World MT50 上达成 **90.0% tier-average** 与 **92.0% overall episode-level**，**超过所有对比基线**（含 Evo-1、Evo-Depth、LA4VLA）；
- 1B 级紧凑 VLA 即可匹敌甚至超越多 B 级大模型，**挑战"VLA 必须靠规模堆性能"的假设**；
- 门控自注意力是动作头决定性组件：通过从 0 开始的门控先学"纯跨注意力基线"，再逐步纳入步间依赖，可获得稳定的优化路径；
- 浅层 VLM 层融合为精细操控提供空间定位线索，**对所有 4 档难度均有普适收益**；
- 在混合数据集、单一 corner RGB 视角下仍可稳定泛化。

## 7. 优点与亮点

- **极简但有效的先验设计**：门控 $g=0$ 初始化和 $[I|0]$ 浅层融合初始化，使任何新增模块在零增益时**完全等价于基线**，降低试错风险；
- **零成本接口**：浅层融合仅 +2.1M 参数（线性层），却带来 7.1/5.2 百分点提升，性价比极高；
- **闭环式 Euler 集成 + receding horizon 推理**，动作生成稳定且对噪声鲁棒；
- **流匹配 + 跨注意力**的组合充分发挥了 50 步视野内的时间结构与上下文化的语义对齐；
- 公开对齐的评测协议、可复现数据来源（Evo-1 数据集）以及系统化的累计消融设计。

## 8. 不足与局限

- **仿真局限**：仅在 Meta-World 仿真器验证，**未在真实机器人上展示**，对 sim-to-real gap 风险回避；
- **单视角输入**：仅用 corner RGB view，缺少多视角/深度信息（对比 Evo-Depth 时此点处于劣势）；
