## 摘要
视觉-语言-动作模型（VLA）继承了预训练 VLM 的语义能力，然而在大规模机器人数据上进行后训练以及架构修改可能会大幅重塑骨干网络，以至于难以隔离 VLM 对控制任务的贡献。以最小的架构改动直接将预训练 VLM 转换为 VLA，提供了一条更透明的路径来理解 VLM 能力如何在不同模型规模间迁移。其核心障碍在于输出分布的不匹配：将动作预测为裸露的数值标记序列会使生成过程偏离 VLM 预训练的语言分布，从而削弱我们希望保留的能力。为此，我们提出 CLAP（因果语言-动作预测），它在每个数值动作序列前添加一段自然语言动作描述，在不修改骨干架构的前提下，将精确的动作标记预测因果地建立在语言-动作规划之上。仅通过单个 epoch 的微调，2B 规模的 CLAP 在 LIBERO 上达到了 90.8%（较 VLA-0 提升 14.9 个百分点），并在 LIBERO-PRO 上面对语言、物体和空间扰动时展现出更强的鲁棒性。我们将开源 0.8B、2B 和 4B 三个规模的 CLAP，作为一个源自同一 VLM 谱系的开源权重、多尺度紧凑 VLA 家族，从而支持对 VLM 到 VLA 能力迁移的可控分析。

## Abstract
Vision-language-action models (VLAs) inherit semantic capabilities from pretrained VLMs, yet large-scale post-training on robot data and architectural modifications can reshape the backbone so extensively that it becomes difficult to isolate what the VLM contributes to control. Directly converting pretrained VLMs into VLAs with minimal architectural change offers a more transparent path to understanding how VLM capabilities transfer across model scales. The core obstacle is output-distribution mismatch: predicting actions as bare numeric token sequences moves generation away from the VLM's pretrained language distribution, degrading the capabilities we seek to preserve. To address this, we propose CLAP (Causal Language-Action Prediction), which prepends each numeric action sequence with a natural-language action description, causally conditioning precise action-token prediction on a language-action plan without modifying the backbone architecture. With single-epoch fine-tuning alone, 2B CLAP achieves 90.8% on LIBERO (+14.9 pt over VLA-0) and improves robustness on LIBERO-PRO under language, object, and spatial perturbations. We will release CLAP at 0.8B, 2B, and 4B as an open-weight, multi-scale compact VLA family from a single VLM lineage, enabling controlled analysis of VLM-to-VLA capability transfer.

# CLAP 论文总结：一种通过语言-动作接地实现 VLM 到 VLA 直接适配的轻量化方法

## 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：视觉-语言模型（VLM）在语义理解与推理上的能力不断增强，但将其迁移到机器人控制（即训练 VLA）仍非常困难。当前主流 VLA（如 π0、OpenVLA、SmolVLA 等）通过"添加独立的动作专家（action expert）、引入扩散/流匹配头、使用机器人大规模数据预训练"等手段，已经让 VLA 在架构和训练分布上都大幅偏离原始 VLM。
- **核心问题**：
  - **结构性黑箱化**：架构与数据复杂性使得难以孤立判断"预训练 VLM 本身到底为控制贡献了什么"，阻碍了系统化的能力归因分析。
  - **输出分布不匹配（output-distribution mismatch）**：标准 VLA 微调训练原本擅长生成语义化语言结构的 VLM 直接输出"4 12 98 3 0 0..."这样的裸露数值标记序列，迫使模型在数值化、少语义、缺乏空间与运动结构的目标分布上学习，这会损害模型原本的语义泛化能力。
  - **紧凑 VLA 的脆弱性**：使用轻量主干的紧凑 VLA 虽然便于部署，但因容量有限，对微调期间的分布偏移更敏感，因此"如何既最小改动又保住能力"是小模型 VLA 的关键挑战。
- **整体含义**：作者主张"如果能让 VLA 微调变得像 VLM 微调一样简单透明"，将更便于把 VLM 社区的能力进展快速引入机器人领域。CLAP 即是对该主张的具体实现。

## 2. 方法论：核心思想、关键技术与算法流程

### 2.1 核心思想
- **语言条件化的动作生成（Language-grounded Action Generation）**：CLAP 不预测裸数值 token，也不替换为纯语言描述，而是在**同一自回归序列**中先输出**自然语言动作描述前缀（language-action prefix）**，再输出精确的数值动作 token。
- 由于生成过程是因果自回归的，每个数值动作 token 自然地以之前的语言描述为条件，因此前缀不是辅助监督目标，而是**调节性中间量**。

### 2.2 关键技术细节
- **完整的 VLM 主干不变**：不做架构改动、不加 action expert、不扩充词表、不需额外人工标注。
- **动作离散化**：与 VLA-0 一致，每个动作维度离散为 K=1000 个 bin，使用 VLM 原生词表文本化表示；动作块长度为 h=8，每步为 7-DoF 末端执行器增量。
- **基于模板的语言前缀（Template-based Prefix）**：
  - 训练阶段：对每个真实动作块 ã 通过确定性模板 T 得到语言描述 d̃ = T(ã)。模板按各维度增量求和（平移以 cm、旋转以 10° 的最近整数离散），根据符号映射短语："move forward / back"、"tilt left / right"、"open / close gripper" 等。
  - 推理阶段：模型自回归生成 d，然后生成数值 token。
  - 整个目标序列被包裹在 `<think> d̃ </think> n1 n2 ... n56` 中，使用 Qwen3.5 的扩展思考模式。
- **形式化的联合生成概率**：

  $$\pi_\theta(d, a | o, l) = \prod_{j=1}^{|d|} \pi_\theta(d^{(j)} | d^{(<j)}, o, l) \cdot \prod_{i=1}^{7h} \pi_\theta(a^{(i)} | a^{(<i)}, d, o, l)$$

- **训练目标**：标准自回归交叉熵损失，同时作用于语言前缀与数值 token：

  $$\mathcal{L}_{\text{CLAP}} = -\mathbb{E}_{(o,l,a)\sim D}\left[\log \pi_\theta(\tilde{d} | o, l) + \log \pi_\theta(\tilde{a} | o, l, \tilde{d})\right]$$

- **可选的数据增强 — 动作掩码（Action Masking Augmentation）**：在数值 token 区段随机以 Uniform(0, p_max)（p_max=0.4）比例替换为 "?" 占位符，强制模型从图像-指令-语言前缀与剩余动作上下文中重建被掩码的数值 token。

### 2.3 算法流程（训练-推理概览）
1. **离线**：模板 T 把每个 h-step 动作块转换为简短自然语言摘要，作为监督目标的一部分。
2. **训练**：以图像-指令为输入，主干 VLM 端到端最大化"语言前缀 + 数值动作序列"的联合交叉熵。
3. **推理**：图像-指令输入下，模型自回归先输出 `<think>描述</think>`，再输出 56 个整数 bin；解析器丢掉 `<think>` 部分，仅将数值 token 解码为连续动作块并以开环执行（h=8）。

## 6. 主要结论与发现

- **学习效率大幅提升**：仅 1 个 epoch，CLAP 在所有尺寸上均稳定优于 VLA-0，平均提升 +13.5 / +14.9 / +20.7 pt（0.8B / 2B / 4B）。2B CLAP 取得 **90.8% LIBERO 平均成功率**，并已逼近完全训练（8 epoch）的 VLA-0。
- **OOD 鲁棒性改善**：在 LIBERO-PRO 上，未掩码 CLAP 平均 OOD 增益 +5.5 / +11.1 / +10.9 pt；尤其 Spatial-Obj 维度，4B 模型相对 VLA-0 提升 **+42.6 pt**，启用掩码后提升 **+54.4 pt**。
- **尺寸并非单调决定 VLM→VLA 迁移质量**：在 Qwen3.5 紧凑档内，2B 在多数 VLABench 维度上匹配或超过 4B，且下游 CLAP 2B 也优于 CLAP 4B，表明"主体能力"与"参数规模"不完全线性对齐。
- **CoT 并不一定有利于紧凑 VLA**：移除 CoT 在多数维度反而更好；4B 在 Spatial / Mesh & Texture 上 CoT 才有显著帮助。CLAP 用受模板约束的"结构化语言中间量"规避了自由推理带来的格式漂移。
- **可执行性与语义对齐兼得**：CLAP 同时满足"语义贴近预训练分布"、"无需外部动作生成器即可执行"、"token 高效适于实时控制"三条设计目标。
- **真实机器人验证**：120 段演示下，CLAP@2B 在 ID 与 OOD 上同为 60%，0.8B 为 35% / 10%，且 2B 对视觉干扰物的鲁棒性显著优于 0.8B——印证仿真观察到的容量-鲁棒性关系。

- **开源承诺**：以"同源 VLM 谱系"开源 0.8B / 2B / 4B 三档权重，便于社区复用与受控分析。

## 8. 不足与局限

- **VLM 谱系单一**：实验仅在 Qwen3.5 一个 VLM 家族上完成，结论是否对其它主干（如 LLaVA、PaliGemma、InternVL）依旧成立仍待验证。
- **基准覆盖有限**：仿真结果集中在 LIBERO / LIBERO-PRO / VLABench；缺少 CALVIN、RLBench、SimplerEnv、Meta-World 等更广泛基准的对照。
- **真实机器人数据与测试规模受限**：仅 120 段演示、20 trials/条件的小样本评估，统计稳定性有限，且部署平台单一（UR5e 桌面抓放）。
- **未与基于扩散/流匹配的动作头对比**：CLAP 选择自回归 token 路线，但其推理时延 +32%（约 +1.0 s/query）相较扩散头或流匹配头未必在速度上占优；未来需在延迟敏感场景下与并行解码方法做公平对照。
- **动作掩码作为可选项而非默认**：作者正确指出掩码不可一以贯之，但因此带来"默认设置选择"的问题——在小尺寸上启用掩码反而损害 long-horizon 性能，其根本原因尚未深究。
- **缺乏消融 → 结构化中间量的"必要性"实验**：模板化的语言前缀是手工启发式；关于"前缀信息量自由度"、"学习式 vs. 模板式前缀"、"不同时序深度"等更细粒度消融未给出。
- **类别与动作空间局限**：仅展示 7-DoF 末端执行器增量控制，未覆盖底座移动、长视野任务、或多模态末端配置（如关节空间、力控）等。
- **可推广性与安全部署**：未涉及真实世界的安全约束、错误恢复、或在非演示分布下的失败模式分析，离实际部署仍有一段距离。
