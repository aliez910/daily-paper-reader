## 摘要
语言条件操作需要精确的接触丰富控制以及对语言、场景和长视野的鲁棒推理。端到端的视觉-语言-动作（VLA）模型提供了强大的局部视觉运动技能，但它们在分布内的任务轨迹上进行训练，并且经常在部署扰动下失效，例如语义重定向、目标重新绑定、空间布局变化以及不稳定的局部接触。LLM 编码智能体提供了互补的语义和组合推理能力，但纯分析原语难以处理不规则抓取、受约束放置以及关节物体交互。我们提出了 Harness VLA，一个记忆增强的智能体框架，它将冻结的 VLA 暴露为可重试的接触丰富原语，并将其与一个小型固定的分析原语库组合，用于定位、分段、运输、导航和释放。该框架不扩展技能库，而是从任务特定的执行轨迹、全局成功规则和失败模型中学习这些固定原语的操作范围。通过将语义重新定位、非接触执行和 VLA 重新分段提升到规划器，同时将冻结的 VLA 保留用于局部接触丰富阶段，Harness VLA 在不进行微调的情况下将预训练 VLA 扩展到其原始轨迹分布之外。在扰动的桌面、家庭厨房以及从干净到随机的双手操作任务上，Harness VLA 在 LIBERO-Pro 和 RoboCasa365 上分别比最强的相关基线提高了 38.6 和 25.4 个百分点，并在 RoboTwin C2R 上达到 58.4%。

## Abstract
Language-conditioned manipulation requires both precise contact-rich control and robust reasoning over language, scenes, and long horizons. End-to-end Vision-Language-Action (VLA) models provide strong local visuomotor skills, but they are trained on in-distribution task trajectories and often fail under deployment perturbations such as semantic retargeting, goal re-binding, spatial-layout shifts, and unstable local contacts. LLM coding agents provide complementary semantic and compositional reasoning, but purely analytic primitives struggle with irregular grasping, constrained placement, and articulated-object interaction. We present Harness VLA, a memory-augmented agentic framework that exposes a frozen VLA as a retryable contact-rich primitive and composes it with a small fixed library of analytic primitives for grounding, staging, transport, navigation, and release. Rather than expanding the skill library, the harness learns the operating range of these fixed primitives from task-specific execution traces, global success rules, and failure models. By lifting semantic re-grounding, non-contact execution, and VLA re-staging to the planner while reserving the frozen VLA for local contact-rich phases, Harness VLA extends pretrained VLAs beyond their original trajectory distribution without finetuning. Across perturbed tabletop, household kitchen, and clean-to-randomized bimanual manipulation, Harness VLA improves over the strongest relevant baselines by 38.6 and 25.4 percentage points on LIBERO-Pro and RoboCasa365, respectively, and reaches 58.4% on RoboTwin C2R.

# Harness VLA 论文总结

## 1. 核心问题与研究动机

- **双重困境**：语言条件操控面临两类方法的固有缺陷：
  - **端到端 VLA 模型**（如 π0、π0.5、OpenVLA）虽然在分布内任务轨迹上训练良好，但在**部署扰动**下表现急剧退化，包括语义重定向（task redirection）、目标重新绑定（goal re-binding）、空间布局偏移（spatial-layout shifts）以及局部接触不稳定等场景。
  - **LLM 编码智能体**（如 Code as Policies、ProgPrompt、CaP-X、RATS）擅长高层语义组合推理，但纯分析原语难以处理不规则抓取、受约束放置、关节物体交互等需要细粒度视觉运动控制的接触丰富任务。
- **核心矛盾**：两类方法能力互补，但缺乏有效的组合机制——前者把语言理解、空间推理、长视野组合、低层控制全部压在一个策略中；后者试图用纯分析原语实现物理上脆弱的接触交互。
- **研究目标**：在不微调预训练 VLA 的前提下，将其从"单体轨迹策略"转化为"可重用的接触专家原语"，扩展其原始轨迹分布之外的鲁棒操控能力。

## 2. 方法论

### 2.1 核心思想：不对称的层次化分解

- 将冻结 VLA 封装为单一的**可重试接触丰富原语** `VLA ACT`；
- 与一个**小型固定的分析原语库**（`MOVE TO`、`ROTATE WRIST`、`SET GRIPPER`、`RELEASE` 等）组合；
- 由 LLM 智能体规划器 Π 统一调度，负责语义重定位、非接触执行、VLA 重新分段；
- **关键设计**：原语库在部署前固定，部署时不扩展新原语，而是通过记忆模块学习每个固定原语的**操作边界**（何时使用、如何使用）。

### 2.2 关键技术细节

- **执行循环（Agentic Execution Loop）**：基于 REPL 风格的文件中介协议，规划器通过读写 `command.json`、`state_NN.json`、`log_NN.json` 等文件与物理仿真器交互；每个回合发出一个 JSON 原语调用，等待执行完成后再做决策。
- **两阶段生命周期**：
  - **探索引导阶段（Bootstrapping）**：在参考种子 s0 上自主探索，将成功的原语序列参数化后存入**任务专属记忆（Task Specific Memory）**，并提炼通用启发式到**全局记忆（Global Memory）**。
  - **部署评估阶段（Deployment Evaluation）**：禁用 RESET 原语，缩短步数预算，从 Task Specific Memory 检索流程骨架，从当前 RGB-D 观测中重新绑定空间坐标。
- **记忆模块**：
  - **Task Specific Memory**：以 JSONL 格式存储参考回滚中的成功原语调用序列（含分析+VLA 混合），空间坐标被替换为符号感知查询；
  - **Global Memory**：跨任务的成功规则（如"VLA 用于接触丰富阶段，分析原语用于长距离运输和精确放置"）与失败模型（如空抓、视觉假成功、错误目标选择）。
- **`VLA ACT` 原语**：接受任务条件提示 `prompt`、最大块数 `max_chunks`、早停谓词 `stop`，调用冻结 VLA 输出一段动作块（action chunks），直到谓词满足或块预算耗尽。

### 2.3 算法流程（文字描述）

1. 读取当前观测 `o_t`、任务语言 ℓ、Task Specific Memory 与 Global Memory；
2. 规划器 Π 解析指令，从 RGB-D 中定位目标实体（避免使用仿真器内部坐标）；
3. 调用分析原语将机器人移动到 VLA 兼容的局部观测区域（预接触位姿）；
4. 调用 `VLA ACT` 执行局部接触丰富操作（如抓取、夹具操作）；
5. 观察接触结果，判断成功/失败/需重试；
6. 若失败，使用分析原语重新分段（re-stage），并可再次调用 `VLA ACT`；
7. 接触稳定后，使用分析原语完成运输、放置、释放、验证；
8. 任务谓词 G 满足或步数预算耗尽时终止。

## 6. 主要结论与发现

- **性能提升**：在 LIBERO-Pro 较最强基线 RATS 提升 **38.6 个百分点**（82.4% vs. 43.8%）；在 RoboCasa365 较 RLDX-1 提升 **25.4 个百分点**（55.4% vs. 30.0%）；在 RoboTwin C2R 达到 **58.4%**。
- **不损失标准分布性能**：在标准 LIBERO 上仍达 96.0%，与冻结 VLA（95.3%）和 π0（94.2%）持平或更高。
- **三大关键发现**：
  1. **规划器级语义重定位**可恢复任务条件行为——πRLinf 在扰动下反复执行训练时的行为，而 Harness VLA 通过分析原语重新绑定目标后调用 VLA 完成正确的局部接触。
  2. **规划器调度的 VLA 调用**提升冻结策略可靠性——少量（通常 2–5 次）规划器选定的 VLA 调用即可超过冻结策略基线；失败后可重试而非整个回滚失败。
  3. **分析原语隔离非接触执行与接触丰富控制**——LIBERO Pro 多数任务由分析原语最终触发完成谓词，而 RoboCasa365/RoboTwin C2R 因含更多接触丰富终态操作而 VLA 触发比例更高。
- **零样本泛化**：在禁用 Task Specific Memory 的 LIBERO-Pro Goal 零样本设置下，Harness VLA（CC）在指令重定向上仍达 79.0%，验证了在线规划器推理本身具备迁移能力。
- **核心论断**：预训练 VLA 最有效的使用方式是将其隔离到接触丰富阶段，把语义与空间绑定抽象到规划器，避免单体部署中常见的灾难性失败。

## 7. 优点

- **方法论新颖性**：明确区分了"扩展技能库"（如 ASPIRE）与"学习原语操作边界"（本文路线），提出固定原语库+记忆引导的折衷范式；
- **非对称设计清晰**：VLA 不被要求处理长视野组合或语言绑定，避免了端到端 VLA 在分布外失效的根本问题；
- **完整的 agentic harness 工程实现**：包括文件中介 REPL 协议、感知隔离（禁止访问仿真器内部坐标）、prompt 工程（共享核心 + 环境特化）、审计产物（JSON 审计 + JSONL 命令轨迹）；
- **跨多个 benchmark 的一致提升**：在桌面、厨房、双手操作三类不同 embodiment 上均验证有效；
- **机制分析深入**：通过原语调用归因、VLA 调用次数截断曲线、可视化 rollout 多维度解释增益来源；
- **可重试的接触设计**：将接触失败局部化到当前子任务，避免单体策略中一触即溃的问题。

## 8. 不足与局限

- **高层规划器与低层 VLA 之间的开放反馈回路**：缺乏紧耦合的端到端优化通道，错误传播仍可能跨回合积累；
- **无联合微调**：未通过环境奖励或人类偏好对系统进行联合训练（如 GRPO 等样本高效 RL 方法），性能上限可能受限于 LLM 骨干的零样本推理能力；
- **缺乏细粒度图像描述能力**：在高度杂乱的长视野任务中，结构化推理受限；
- **每 cell 种子数较少**：多数 cell 为 10 种子/任务，5–10 个随机失败的差异可能影响统计显著性；
- **不同 benchmark 使用不同冻结 VLA 后端**：无法严格分离"框架增益"与"VLA 骨干增益"——例如 LingBot-VLA 本身已是 RoboTwin 特化检查点，与直接 VLA 基线的对比并不完全公平；
- **依赖 LLM 骨干**：系统行为高度依赖 Codex / Claude Code 的指令遵循与代码生成能力，更换骨干时性能波动较大（Codex 在 RoboCasa365 优于 CC，CC 在 LIBERO-Pro 优于 Codex）；
- **基线公平性**：部分强基线（如 π0.5、Cap-X、RATS）的官方结果与本文复现结果存在协议差异（例如 seed 数、扰动定义），整体对比可能略偏向 Harness VLA；
- **应用范围受限**：当前主要在仿真环境中验证，迁移到真实机器人的感知噪声、延迟、硬件故障等问题尚未涉及；
- **未来方向**：作者提到可与 ASPIRE 等自动技能发现系统结合，但在原语扩展与固定之间如何保持可审计性仍是开放问题。
