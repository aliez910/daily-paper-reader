## 摘要
动作空间是机器人学习中的一个主要挑战，因为它通常是高维的，可以跨越长时间跨度，并且经常存在多模态的最优解。合理选择动作表示与损失函数有助于缓解这些问题，但往往需要做出权衡。我们提出了动作地图策略（AMP），将三维闭环操作策略学习建模为图像空间中的分类问题。尽管分类在生成式语言模型中已被证明是一种有效的建模方式，但将其应用于机器人动作学习却颇具难度，因为对高维连续动作进行朴素离散化会导致词表规模的爆炸式增长。我们的核心思想是将三维动作投影到相机图像平面上，并将每个像素位置视为一个离散类别，从而在控制维度的同时保留多模态特性。该方法无需庞大的词表即可为高维动作提供毫米级精度，同时保留细粒度的逐像素视觉信号。此外，它能够在单次前向传播中预测整个动作块，避免了复杂的噪声调度与迭代去噪过程，推理速度显著快于扩散策略。在多种操作任务上的实验表明，AMP 优于强基线方法，取得了更高的成功率、更快的推理速度以及更强的空间推理能力。

## Abstract
The action space poses a major challenge in robot learning, since it is often high-dimensional, can span long time horizons, and frequently admits multi-modal optimal solutions. A good choice of action representation and loss function can help to address these concerns, but there are often trade offs. We propose Action Map Policy (AMP), which casts 3D closed-loop manipulation policy learning as a classification problem in image space. While classification has been an effective formulation in generative language models, applying it to robot action learning is difficult because naively discretizing high-dimensional continuous actions explodes the token vocabulary. Our key idea is to project 3D actions onto the camera image planes and treat each pixel location as a discrete class, thus controlling dimensionality while retaining multi-modality. This method supports millimeter-level precision for high-dimensional actions without requiring a prohibitively large vocabulary, while preserving fine-grained pixel-wise visual signals. Furthermore, it can predict the entire action chunk in a single forward pass, avoiding complex noise scheduling and iterative denoising while achieving substantially faster inference than diffusion policies. Experiments on various manipulation tasks show that AMP outperforms strong baselines, achieving higher success rates, faster inference, and enhanced spatial reasoning.

# 论文总结：Action Map Policy（AMP）

## 1. 核心问题与整体含义

- **研究背景**：机器人操控（manipulation）策略学习中的一个根本性难题在于**动作空间的高维性、长时域性以及多模态性**。高维动作难以直接用分类范式建模，而长时序动作块（action chunk）的预测又涉及复杂的优化目标。
- **现有方法的痛点**：
  - 朴素的离散化方法（如将每个维度分桶）对高维连续动作离散化会导致**词表爆炸**，无法借鉴语言模型中成熟的分类范式。
  - 当前主流的扩散策略（Diffusion Policy）虽然能建模多模态，但依赖**迭代去噪**，推理延迟高，且涉及复杂的噪声调度设计。
- **核心动机**：能否找到一种动作表征，使分类范式天然适用于 3D 操控任务，同时兼顾**精度、多模态、推理效率**三者？

## 2. 方法论

### 2.1 核心思想

- 将**3D 末端执行器动作（位置 + 姿态/旋转）投影到相机图像平面**，把"动作预测"转化为"像素分类"任务。
- 图像中的每个像素位置即为一个离散类别（class），从而把高维动作空间压缩为二维的像素网格预测问题。

### 2.2 关键技术细节

- **像素即类别（Pixel-as-Class）**：
  - 利用相机内外参，将 3D 动作点（如末端位置）反投影到 RGB 图像像素坐标 `(u, v)`。
  - 姿态（orientation）则可编码为像素处的额外属性或在另一通道上做分类。
  - 这样既控制了输出维度（本质是 2D 像素网格），又保留了多模态分布（不同像素对应不同动作模式）。
- **毫米级精度**：
  - 通过亚像素（sub-pixel）插值/回归头，在离散像素分类结果之上做精细化偏移量回归，避免因像素离散化而损失精度。
  - 整个词表大小由图像分辨率决定（如 256×256 = 65536 类），远小于对 6D 动作各维度独立分桶的组合爆炸。
- **单次前向的动作块预测**：
  - 整段未来若干步的动作块（action chunk）通过一次前向传播输出，**不依赖迭代去噪**。
  - 训练时使用标准的交叉熵损失（分类）+ 偏移回归损失（精度细化）。
- **保留视觉-动作对齐信号**：
  - 像素级监督保留了细粒度的空间视觉信号，使得网络在执行动作预测的同时也能进行空间推理（spatial reasoning）。

### 2.3 算法流程（文字描述）

1. 输入：当前观测图像（多视角 RGB）+ 机器人状态（proprioception）。
2. 视觉编码器（通常是 ViT 或 CNN）提取特征。
3. 动作解码器以像素分类的方式预测未来 H 步动作的目标像素位置及亚像素偏移。
4. 将预测出的像素坐标通过相机投影的逆过程，恢复为 3D 末端位姿。
5. 机器人执行该动作块，每步重新观测并重复（闭环控制）。
