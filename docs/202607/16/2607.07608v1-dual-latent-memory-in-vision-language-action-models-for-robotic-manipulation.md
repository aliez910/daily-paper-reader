## 摘要
主流的视觉-语言-动作（VLA）模型在马尔可夫假设下主要基于当前观测来预测动作，因此在长时序、依赖时间信息的任务上表现欠佳。现有的记忆增强型VLA模型要么扩展观测窗口，要么从记忆库中检索历史信息作为策略侧的辅助上下文。然而，它们将记忆置于VLA推理的原生潜在嵌入空间之外，导致历史经验无法与多模态推理及动作生成流畅交织。为此，我们提出了LaMem-VLA，一个潜在记忆原生框架，它将历史经验重构为潜在记忆令牌，并将其直接与VLA推理交织融合。其核心包含四个协同组件：(i) 策展器：将历史经验组织为互补的短期与长期记忆库；(ii) 检索器：利用多模态认知查询两个记忆库，以检索与上下文相关的证据；(iii) 压缩器：将检索到的证据重构为紧凑的短期和长期潜在记忆令牌；(iv) 编织器：将这些记忆令牌与当前观测和指令注入到一条连续的嵌入序列中。通过在同一连续潜在空间中完整地表示、检索和消费历史经验，LaMem-VLA使记忆能够直接参与VLA推理，并在有界上下文下引导动作生成。在SimplerEnv和LIBERO上的大量实验证明了LaMem-VLA的优越性。

## Abstract
Mainstream Vision-Language-Action (VLA) models predict actions primarily from the current observation under a Markovian assumption, thus struggling with long-horizon, temporally dependent tasks. Existing memory-augmented VLAs either expand the observation window or retrieve history from the memory bank as auxiliary policy-side context. However, they leave memory outside the native latent embedding space of VLA reasoning, preventing historical experience from being fluidly interleaved with multimodal reasoning and action formation. To this end, we introduce LaMem-VLA, a latent-memory-native framework that reconstructs historical experience into latent memory tokens and directly interweaves them with VLA reasoning. At its core, LaMem-VLA introduces four coordinated components: (i) a curator that organizes historical experience into two complementary short-term and long-term memory vaults; (ii) a seeker that queries both vaults using the multimodal cognition to retrieve context-relevant evidence; (iii) a condenser that reconstructs the retrieved evidence into compact short-term and long-term latent memory tokens; and (iv) a weaver that injects these memory tokens with the current observation and instruction into one continuous embedding sequence. By representing, retrieving, and consuming historical experience entirely in the same continuous latent space, LaMem-VLA enables memory to directly participate in VLA reasoning and guide action generation under a bounded context. Extensive experiments on SimplerEnv and LIBERO demonstrate the superiority of our LaMem-VLA.

# LaMem-VLA 论文总结

## 1. 核心问题与研究动机

- **问题背景**：主流的视觉-语言-动作（VLA）模型普遍依赖马尔可夫假设，主要根据**当前观测**预测动作，导致其存在显著的**"时序短视偏差（temporal short-horizon bias）"**：能够对当前可见状态做出反应，但难以理解先前状态转移、已完成子任务以及多步骤任务所处阶段。
- **现有方案的局限**：
  - **时间上下文扩展**类方法（如拼接历史帧、扩展为视频序列）：随上下文长度增长带来计算与显存开销，且固定时间窗口会丢弃窗口外的关键证据。
  - **外部记忆库检索**类方法（如 MemoryVLA）：记忆存储在 VLA 原生 token 空间之外，作为**策略侧的辅助上下文**注入，难以与模型内部"感知—推理—动作"的统一流程深度融合。
- **核心研究问题**：能否将历史经验重构为**上下文原生（context-native）的潜在记忆令牌**，在 VLA 嵌入空间中完成存储、检索与消费，使其直接参与动作生成？

## 2. 方法论

### 2.1 整体框架（四个协同模块）

LaMem-VLA 采用 7B 参数的 **Prismatic VLM** 作为视觉-语言骨干 + 约 300M 参数的扩散式动作专家，整体流程：

1. 视觉-语言骨干将当前观测 $o_t$ 与指令 $I$ 编码为视觉 token $X_t$ 与指令 token $I$，并拼接可学习的动作查询 $Q_{\text{action}}$。
2. 通过四个模块将历史记忆编织进 VLA 推理序列。

### 2.2 各模块细节

- **潜在记忆策展器（Curator）**：将历史经验分解为两个互补的记忆库。
  - **短期记忆库 $M_{\text{short}}$**：以 key-value 形式存储视觉证据，通过 SE-bottleneck 压缩模块 $C_s$ 将当前视觉 token $X_t$ 蒸馏为 $v_s$，均值池化得到检索键 $k_s$。
  - **长期记忆库 $M_{\text{long}}$**：以时间步为单位存储动作隐藏态 $H_{\text{action}}$，用于追踪任务进度与动作连续性。
  - **库更新策略**：当容量超过 $L$ 时，通过余弦相似度选择最冗余的相邻单元，对 key 与 value 取均值后合并。

- **潜在记忆检索器（Seeker）**：
  - 由当前多模态认知状态 $Q_t^{\text{con}}$ 拼接可学习查询槽 $Q_{\text{init}}$，经轻量级 Transformer 查询构建器 $B$ 得到共享查询 $Q_t$。
  - 均值池化得到全局检索向量 $q_t$，分别对两个库按余弦相似度做 **Top-K 检索**，得到 $Z_{\text{short}} \in \mathbb{R}^{K N_s \times C}$ 与 $Z_{\text{long}} \in \mathbb{R}^{K N_l \times C}$。
  - Top-K 为离散操作，不参与梯度反传。

- **潜在记忆压缩器（Condenser）**：
  - 通过两个轻量 Transformer（$F_v$ 与 $F_c$），结合查询 $Q_t$、检索证据与可学习记忆槽 $T_s, T_l$，输出**固定长度**的紧凑记忆 token：
    $$M_{\text{short}} = F_v([Q_t; Z_{\text{short}}; T_s])[-L_s:], \quad M_{\text{long}} = F_c([Q_t; Z_{\text{long}}; T_l])[-L_l:]$$
  - 实现了检索规模与消费规模的解耦，记忆令牌数量与原始检索量无关。

- **潜在记忆编织器（Weaver）**：直接将记忆 token 拼入 VLA 输入序列：
  $$S_t = [M_{\text{short}} + \mathbf{1}_{L_s} b_s^\top; \; M_{\text{long}} + \mathbf{1}_{L_l} b_l^\top; \; X_t; \; I; \; Q_{\text{action}}]$$
  其中 $b_s, b_l$ 为可学习的源嵌入（标识记忆来源）。这使得记忆、当前观测、指令与动作查询在**同一潜在空间内通过自注意力联合推理**。

### 2.3 动作专家

- 采用基于扩散模型的动作专家 $\epsilon_\theta$，将 VLM 输出的"记忆接地"动作 token $Z_{\text{action}}$ 作为条件，通过 DDIM 采样（10 步）生成 7-DoF 末端执行器动作 chunk（长度 16）。
- 训练损失为标准 MSE 噪声预测损失。

## 6. 主要结论与发现

- **核心结论**：将历史经验重构为**潜在原生记忆 token**并直接编织进 VLA 输入序列，是缓解"时序短视偏差"的有效路径。
- **关键发现**：
  1. 双尺度记忆（短期视觉证据 + 长期语义/动作连续性证据）具有互补作用，缺一不可。
  2. 记忆必须在 VLA 嵌入空间内被消费（而非策略侧融合），才能带来最大收益。
  3. 检索量需适度：适度增加有助于提供充分上下文，过量则引入冗余与压缩负担。
  4. 固定长度压缩使记忆注入量与检索量解耦，避免上下文无限扩张。

## 7. 优点与亮点

- **范式创新**：首次提出"上下文原生潜在记忆"概念，使历史经验、视觉、语言、动作在同一连续嵌入空间中联合自注意力推理，而非作为外部条件。
- **架构解耦**：检索规模与消费规模解耦，通过 Condenser 实现"检索可变、消费固定"，避免上下文随历史线性膨胀。
- **双尺度设计**：视觉主导的短期记忆 + 语义/动作主导的长期记忆，针对长视野任务的关键时序依赖（物体状态变化、子任务完成信号）提供互补证据。
- **兼容性**：作为通用框架，可与不同 VLA 骨干与动作专家配合使用。
- **全面评测**：在两个仿真基准、约 130 个不同任务上验证，并配套多角度消融实验。

## 8. 不足与局限

- **缺乏真实世界验证**：论文明确指出目前**仅在仿真环境**评测，真实机器人实验留待下一版本。
- **输入模态限制**：仅使用单个第三人称 RGB 输入（224×224），未使用本体感知或腕部相机，与部分使用多模态输入的方法（带 ∗）相比，输入信息量较少。
- **计算开销**：增加记忆模块会带来额外前向计算（两个 Transformer 模块 + Top-K 检索），论文未给出具体的延迟与吞吐量数据。
- **超参数敏感性**：记忆库容量 $L$、检索数 $K$、token 数 $L_s/L_l$ 需手工调优，模型在不同任务上最优设置可能不同。
- **Top-K 离散操作**：检索过程不可微，限制了端到端优化，可能在分布外任务上出现检索偏差。
- **长期记忆粒度**：长期记忆以时间步为单位累积，episode 极长时仍可能存在压缩损失，且当前设计未考虑显式的子任务边界识别。
- **基准广度**：未涵盖 CALVIN、Meta-World 等其他长视野操控基准，泛化性证据有限。
