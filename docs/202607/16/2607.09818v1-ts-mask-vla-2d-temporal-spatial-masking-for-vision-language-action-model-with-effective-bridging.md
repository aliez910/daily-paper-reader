## 摘要
视觉-语言-动作（VLA）模型旨在理解自然语言指令与视觉观测，并生成并执行相应的动作，以作为具身智能体执行任务。近年来，基于自回归 token 的动作生成范式推动了众多代表性 VLA 模型的发展。然而，该范式往往将动作生成简化为下一 token 预测，缺乏对动作序列时空结构的显式建模，也未实现视觉-语言表征与动作之间的解耦，这可能在长时序和复杂场景中限制性能。本文提出 TS-Mask VLA，一个面向机器人操作的视觉-语言-动作框架。TS-Mask VLA 基于两项关键设计构建：（1）配备桥接注意力条件桥的离散扩散动作专家（Discrete Diffusion Action Expert），能够实现来自 VLM 的多层条件注入，从而实现更准确、更稳定的动作生成；（2）针对离散动作 token 的时-空二维掩码策略，可增强模型对跨时间依赖与维度间耦合的理解，进而生成结构一致性更高的动作序列。我们在仿真基准和真实世界任务上进行了大量实验。在 LIBERO 上，TS-Mask VLA 仅以 0.5B 参数即取得 95.7% 的平均成功率，超越了规模显著更大的模型。在 CALVIN 上，其平均序列长度达到 4.19，位列最优，并展现出强大的长时序性能。综合分析与消融实验进一步验证了所提设计的有效性。

## Abstract
Vision-language-action (VLA) models aim to understand natural-language instructions and visual observations, and to generate and execute corresponding actions as embodied agents. Recently, autoregressive token-based action generation has driven the development of many representative VLA models. However, this paradigm often reduces action generation to next-token prediction, thereby lacking explicit modeling of the spatiotemporal structure of action sequences and the disentanglement between vision-language representations and actions, which can limit performance in long-horizon and complex scenarios. In this paper, we propose TS-Mask VLA, a vision-language-action framework for robot manipulation. TS-Mask VLA is built upon two key designs: (1) a Discrete Diffusion Action Expert equipped with a Bridge Attention conditioning bridge, which enables multi-layer conditioning from the VLM and facilitates more accurate and stable action generation; and (2) a temporal-spatial 2D masking strategy for discrete action tokens that strengthens the model's understanding of cross-time dependencies and inter-dimensional coupling, leading to more structurally consistent action sequences. We conduct extensive experiments on simulation benchmarks and real-world tasks. On LIBERO, TS-Mask VLA achieves a 95.7 percent average success rate with only 0.5B parameters, outperforming significantly larger models. On CALVIN, it attains the best average sequence length of 4.19 and strong long-horizon performance. Comprehensive analyses and ablations further validate the effectiveness of our design.

# TS-Mask VLA 论文详细总结

## 一、核心问题与研究动机

- **研究背景**：视觉-语言-动作（VLA）模型通过将视觉感知、语言理解与动作生成统一在同一框架内，实现指令驱动的机器人操作，已成为具身智能的研究热点。
- **现有两大主流范式及其局限**：
  - **自回归式（AR）VLA**（如 OpenVLA、RT-2）：将动作序列视为 token 序列进行逐 token 预测，缺乏对动作时空结构的显式建模，且未实现视觉-语言表征与动作的解耦。
  - **连续扩散式 VLA**（如 π0、Diffusion Policy）：在长时序下容易出现不稳定，难以显式建模动作的时-空相关性。
- **作者的核心洞察**：VLA 模型需要在两方面取得突破——
  1. 将视觉-语言表征桥接到专门的"动作专家"，建立清晰的条件解耦；
  2. 将动作离散化以显式建模其结构化依赖，提升复杂场景中的泛化能力。
- **目标**：在仅 0.5B 参数的轻量级骨干下，在长时序、复杂操作任务上超越显著更大的 VLA 模型。

## 二、方法论

### 整体架构
TS-Mask VLA 包含三大核心组件：
1. **VLM 骨干**（Qwen2.5-0.5B）：编码第三视角相机图像、腕部相机图像与文本指令；
2. **离散扩散动作专家**：基于多层 VLM 隐藏状态条件，迭代去噪生成离散动作 token；
3. **时-空二维掩码模块**：在二维动作 token 网格上施加结构化扰动。

### 关键技术细节

**（1）多模态 VLM 编码**
- 视觉编码使用 DINOv2 + SigLIP 双编码器，并通过融合 MLP 投影到语言嵌入空间。
- 输入除图像与文本外，附加可学习的 **Action Query（AQ）** token 作为动作中心引导信号。
- **关键设计**：抽取 VLM 所有 L 层（而非仅最后一层）的隐藏状态 $\mathbf{H}=\{\mathbf{H}^{(l)}\}_{l=1}^{L}$，为动作专家提供从低层几何细节到高层语义的多层级条件信号。

**（2）桥接注意力（Bridge Attention）Block**
- 在一次注意力计算内融合三类信息流：
  - **Self tokens**：当前动作表示，建模动作内部时序依赖；
  - **AQ tokens**：来自 VLM 的 Action Query 特征，作为动作导向的条件信号；
  - **Task tokens**：视觉-语言特征，提供外部任务约束。
- 公式核心：
  $$\alpha = \mathrm{softmax}\left(\frac{[QK_{\text{self}}^{\top},\; QK_{\text{AQ}}^{\top},\; \tanh(g)\cdot QK_{\text{task}}^{\top}]}{\sqrt{d_h}}\right)$$
  其中 $g$ 为可学习门控标量，缓解训练早期过度任务条件化问题。
- 每个 key 分支独立使用 RoPE，保留序列内位置结构。

**（3）均匀量化动作 Token 化**
- 将每个归一化动作标量 $\hat{a}_i \in [-1,1]$ 独立均匀量化为 $V=256$ 个 bin；
- 离散序列 $\mathbf{q}\in\{0,\ldots,255\}^{M}$（$M=T\times D$）可重塑为 $T\times D$ 的二维网格；
- **有意不采用 VQ-VAE**，因其过强压缩会损失动作的时-空细粒度信息。

**（4）时-空二维掩码策略**
- 掩码比率由余弦调度 $r=\cos(\pi t/2)$ 决定；
- **两阶段掩码**：
  - **时间掩码**：随机选取 $\mathrm{round}(rT)$ 个时间帧，将帧内全部 $D$ 个动作维度同时掩码，强制建模跨时间依赖；
  - **空间掩码**：在未被时间掩码覆盖的帧内，随机掩码 $\mathrm{round}(rD)$ 个 token，引入细粒度结构扰动；
- 损失仅在两阶段掩码位置的并集上计算。

**（5）训练与推理**
- **训练损失**：
  - 主损失 $\mathcal{L}_{\text{mask}}$：在掩码位置上的交叉熵；
  - 步展开损失 $\mathcal{L}_{\text{unroll}}$：将高置信度预测回填后再次预测剩余掩码位置，缓解训练-推理不一致；
  - 总损失 $\mathcal{L}=\frac{\mathcal{L}_{\text{mask}}+\lambda\mathcal{L}_{\text{unroll}}}{1+\lambda}$。
- **推理流程**（粗到精）：
  - 从全掩码序列 $t_0$ 出发，经 $I$ 轮迭代；
  - 每轮预测 token 后，按置信度重掩码（ReMask）低置信度 token；
  - 重掩码数量由余弦调度 $\gamma(i/I)$ 控制，逐渐固定高置信度预测；
  - 最终将离散 token 解码为连续动作。

## 三、实验设计

### 数据集 / Benchmark
- **LIBERO**：四个子基准——Spatial、Object、Goal、Long，分别覆盖空间推理、物体理解、目标条件泛化、长时序操作。
- **CALVIN**：标准 ABC→D 评估协议，评估语言条件下的多步长时序任务。
- **真实世界**：基于 6-DoF UR5e + Robotiq-85 抓手的平台，配备两台 Intel RealSense D435i 相机（第三人称 + 腕部），共三类任务——放苹果、抽纸巾、翻平底锅，每类在不同位置摆放以增加难度。

### 对比基线（按参数量分组）
- **大规模（7–8.5B）**：FlowVLA、OpenVLA、CoT-VLA、ThinkAct、UniVLA、OpenVLA-OFT、RoboDual、OpenHelix、ReconVLA；
- **小规模（1.3–3B）**：π0、π0-FAST、SmolVLA、GR00T N1、DeeR、RoboFlamingo、SuSIE；
- **微型（≤0.5B 或非 VLM）**：Seer、VLA-OS、Diffusion Policy、VLA-Adapter-Pro、MoDE。

### 充分性评价

## 六、主要结论与发现

- **LIBERO**：仅 0.5B 参数即取得 95.7% 平均成功率，超越 8.5B 的 FlowVLA（88.1%）达 7.6 个百分点，也优于 π0（94.2%）；长时序任务上较 GR00T N1 提升 1 个百分点。
- **CALVIN ABC→D**：取得最佳平均序列长度 **4.19**，超越所有 7B 模型；5 任务完成率 66.9%，优于 OpenVLA-OFT（66.5%）；4 任务完成率从 OpenVLA 的 52.1% 提升至 77.0%。
- **消融结论**：2D 时-空掩码相对 1D 在 Long 任务上提升 6.6%，验证了对时序依赖显式建模的价值；中等步展开强度（$\lambda=0.5$）最佳，过强会过正则化。
- **真实世界**：三类任务均优于 OpenVLA-OFT 与 π0，验证了方法的实用性与跨场景泛化能力。

## 七、优点与亮点

- **结构化二维掩码**：将动作序列显式建模为 $T\times D$ 网格，相较传统 1D 掩码提供了清晰的时-空归纳偏置，理论与实证均证明有效。
- **桥接注意力机制**：在一次注意力计算内高效融合三类信息流，门控标量设计缓解早期过条件化问题；层级对齐的多层 VLM 条件注入兼顾低层几何与高层语义。
- **离散扩散替代自回归**：并行去噪避免误差累积，结构化离散建模天然契合动作的时空结构。
- **参数效率极高**：0.5B 骨干全面超越 7–8.5B 模型，部署成本低，实用价值突出。
- **真实世界验证**：在 UR5e 平台上证实迁移可行性，覆盖抓取、放置、翻转等典型操作。

## 八、不足与局限

- **算力与训练规模受限**：仅在单卡 RTX 4090 上验证，论文明确指出尚未在充足算力下探索模型潜力，大规模训练下的表现仍是开放问题。
- **消融不够全面**：缺少对量化 bin 数、Action Query 必要性、桥接注意力各分支贡献、推理迭代次数 $I$ 与重掩码调度 $\gamma$ 等关键超参数的独立消融。
- **真实世界实验规模有限**：仅 3 类任务、20 次/任务的试验规模，统计显著性较弱，且未涉及光照、遮挡、动态障碍等更具挑战性的场景。
- **依赖 LoRA 微调**：性能提升的一部分可能来自 VLM 预训练知识本身，分离"方法贡献"与"预训练优势"仍需更细粒度分析。
- **动作空间离散化的局限**：256 bin 的均匀量化在精细控制（如力控、接触丰富任务）下可能存在粒度损失，论文未与 VQ-VAE 之外的连续动作方案（如 flow matching）做直接对比。
- **应用范围**：当前评估集中在桌面操作类任务，对移动操作、双臂协作、长视频上下文等更广泛具身场景的适用性尚未验证。
