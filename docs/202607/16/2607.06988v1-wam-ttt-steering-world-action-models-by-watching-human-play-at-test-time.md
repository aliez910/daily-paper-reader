## 摘要
将机器人基础模型（RFM）引导至新的任务变体或用户偏好的行为仍然具有挑战性，通常需要额外的机器人演示、任务特定的微调或长上下文条件设定。我们提出了 WAM-TTT，一个通过原始人类视频来引导世界动作模型的测试时训练框架。WAM-TTT 并非将人类视频视为待模仿的轨迹，而是通过自监督视频预测将其吸收到冻结的 WAM 内部的一个轻量级自适应记忆中。为了使该记忆对控制有用，我们引入了一个元训练阶段，通过配对的人-机数据以及键-值记忆重建目标，将人类演示与机器人行为对齐。在测试时，仅需要未标注的人类视频来适应记忆，而预训练的 WAM 保持冻结状态。这使得无需机器人动作、人工标注或任务特定微调的高效且可重用的引导成为可能，同时保留了基础模型的泛化能力。大量实验表明，WAM-TTT 在多种操作任务和泛化设置中始终优于上下文人类视频条件设定的基线方法。

## Abstract
Steering robot foundation models (RFMs) toward new task variants or user-preferred behaviors remains challenging, often requiring additional robot demonstrations, task-specific fine-tuning, or long-context conditioning. We present WAM-TTT, a test-time training framework for steering world action models from raw human videos. Rather than treating human videos as trajectories to imitate, WAM-TTT absorbs them into a lightweight adaptive memory inside a frozen WAM through self-supervised video prediction. To make this memory useful for control, we introduce a meta-training stage that aligns human demonstrations with robot behaviors using paired human-robot data and a key--value memory reconstruction objective. At test time, only unlabeled human videos are required to adapt the memory, while the pretrained WAM remains frozen. This enables efficient and reusable steering without robot actions, human-side annotations, or task-specific fine-tuning, while preserving the generalization ability of the foundation model. Extensive experiments show that WAM-TTT consistently outperforms in-context human-video conditioning baselines across diverse manipulation tasks and generalization settings.

## 1. 核心问题与研究动机

随着机器人基础模型（Robot Foundation Models, RFM）的发展，如何将其灵活引导（steering）到新的任务变体或用户偏好的行为模式仍是一个关键难题。现有方法普遍存在以下局限：

- **依赖额外示教**：需要补充机器人演示数据，成本高昂且难以获取。
- **任务级微调破坏泛化**：针对特定任务进行微调往往损害基础模型原有的跨任务、跨场景泛化能力。

## 2. 方法论

WAM-TTT（World-Action Model with Test-Time Training）的核心思想是将人类视频作为"自监督信号"而非"模仿轨迹"，通过在冻结的世界-动作模型（WAM）内部嵌入**轻量级自适应记忆（Adaptive Memory）** 来吸收人类行为信息。

### 2.1 关键设计理念
- **冻结 WAM 主干**：预训练的世界-动作模型权重保持不变，仅更新其内部的小规模记忆模块。
- **自监督视频预测**：将人类视频帧作为预测目标，使记忆在重构未来帧的过程中捕获人类操作的行为模式。

### 2.2 元训练阶段（Meta-Training）
- 利用**配对的人-机器人数据**（同一任务的人类操作视频与对应的机器人执行数据），训练自适应记忆的对齐能力。
- 引入**键-值记忆重建目标（Key-Value Memory Reconstruction Objective）**：以键（key）检索相关记忆条目，以值（value）重建目标视频或动作，使记忆模块能够将人类演示与机器人行为空间进行语义对齐。
- 该阶段确保记忆在测试时能够将"人类行为意图"映射到机器人可执行的动作空间。

### 2.3 测试时训练阶段（Test-Time Training）
- 部署时无需任何机器人动作或人工标注，仅提供与目标任务相关的**未标注人类视频**。
- 模型通过自监督视频预测损失在线更新轻量记忆，主干网络保持冻结。
- 完成更新后，该记忆即可在控制阶段引导策略输出符合人类偏好的动作。

### 2.4 算法流程概览
1. 离线元训练：使用人-机器人配对数据 + 记忆重建损失 → 学习可对齐行为的记忆机制。
2. 部署时：给定少量人类视频 → 通过自监督损失更新记忆。
3. 控制执行：冻结 WAM + 更新后的记忆 → 输出动作。
