## 摘要
世界动作模型 (WAMs) 通过联合建模动作与未来视觉观测，以未来场景演化作为物理可落地动作生成的稠密监督，从而提升机器人策略学习。然而，现有 WAMs 的一个常见设计是在推理时显式生成未来视频，这会带来显著的计算开销，并阻碍实时闭环部署。GigaWorld-Policy 通过采用以动作为中心的建模方式来解决这一问题，即在训练阶段使用未来视觉动态，而在推理阶段仅解码动作。在此框架基础上，我们提出了 GigaWorld-Policy-0.5，一种面向更高效机器人控制的增强型以动作为中心的 WAM。在预训练阶段，GigaWorld-Policy-0.5 采用动作条件世界建模 (AC-WM) 与 WAM 混合训练策略。这增强了视觉动态与机器人动作之间的耦合，并提升了动作表征在下游策略学习中的可迁移性。为实现高效推理，GigaWorld-Policy-0.5 引入了 Transformer 混合架构，将视觉动态建模与动作生成分离到不同的专用专家模块中，从而在仅需动作的推理过程中降低有效计算量，并在本地 RTX 4090 部署下实现 85 毫秒的推理延迟。此外，我们采用基于智能体的 AutoResearch 流水线来系统化地搜索训练配置，从而更高效地识别最优实验设置，同时减少超参调优所需的时间和人工介入。实验与消融研究表明，GigaWorld-Policy-0.5 在保留未来视觉动态带来的训练优势的同时，提升了机器人控制的推理效率。

## Abstract
World Action Models (WAMs) improve robot policy learning by jointly modeling actions and future visual observations, using future scene evolution as dense supervision for physically grounded action generation. However, a common design in existing WAMs is to explicitly generate future videos at inference time, incurring substantial computational overhead and hindering real-time closed-loop deployment. GigaWorld-Policy addresses this issue with an action-centered formulation, where future visual dynamics are used during training while action-only decoding is used at inference time. Building upon this framework, we present GigaWorld-Policy-0.5, an enhanced action-centered WAM designed for more efficient robot control. During pretraining, GigaWorld-Policy-0.5 adopts a mixed Action-Conditioned World Modeling (AC-WM) and WAM training strategy. This strengthens the coupling between visual dynamics and robot actions and improves the transferability of action representations for downstream policy learning. For efficient inference, GigaWorld-Policy-0.5 introduces a Mixture-of-Transformers architecture that separates visual dynamics modeling and action generation into specialized experts, reducing active computation during action-only inference and achieving 85 ms inference latency on a local RTX 4090 setup. In addition, we employ an agent-based AutoResearch pipeline to systematically search training configurations, enabling more efficient identification of optimal experimental setups while reducing the time and manual intervention required for hyperparameter tuning. Experiments and ablations show that GigaWorld-Policy-0.5 preserves the training benefits of future visual dynamics while improving inference efficiency for robot control.

## 1. 核心问题与研究动机

- **研究背景**：世界动作模型 (World Action Models, WAMs) 通过联合建模机器人动作与未来视觉观测，将未来场景演化作为稠密监督信号，使动作生成具备物理合理性，已被广泛用于提升机器人策略学习。
- **核心问题**：现有 WAM 在推理时仍需显式生成未来视频或进行迭代去噪，导致：
  - 计算开销巨大（视频 token 远贵于动作 token）；
  - 难以满足边缘设备上的实时闭环控制需求；
  - 长时序下误差累积，反过来影响动作生成质量。
- **核心挑战**：如何在保留"动作—视觉动态耦合"带来的泛化收益的同时，避免推理阶段的未来视频生成开销。

## 2. 方法论

### 2.1 整体框架：以动作为中心的 WAM (Action-Centered WAM)

- **输入**：当前多视角观测 $o_t^{left}, o_t^{front}, o_t^{right}$、本体感知状态 $s_t$、语言指令 $l$。
- **输出**：长度为 $p$ 的动作块 $\hat{a}_{t:t+p-1}$，以及可选的未来视觉观测 $\hat{o}_{t+\Delta:t+K\Delta}$。
- **关键设计**：继承 GigaWorld-Policy 的 **因果掩码 (causal mask)**——动作 token 不可看到未来视觉 token，但未来视觉 token 可看到动作 token；因此推理时可彻底跳过未来视觉分支，仅解码动作。

### 2.2 训练策略：混合 AC-WM 与 WAM 预训练

- **AC-WM (Action-Conditioned World Modeling)**：在预训练阶段让模型基于动作条件预测未来视觉动态，强化动作与视觉变化的耦合关系。
- **WAM 训练**：联合建模动作与未来观测。
- **混合训练**：将两类目标结合，使模型同时学到：
  - 一般场景演化规律；
  - 动作诱导下的未来视觉变化；
  - 提升动作表征向下游任务的迁移性。

### 2.3 模型架构：Mixture-of-Transformers (MoT)

- **双专家结构**：
  - **Visual Expert**：处理当前/未来视觉 token，建模场景动态；hidden dim 3072，FFN dim 14336。
  - **Action Expert**：专注于动作去噪与动作块预测；hidden dim 1024，FFN dim 4096（轻量化）。
- **跨模态自注意力**：通过 multimodal self-attention 在统一 token 序列中实现信息交换，并保持 action-centered 因果掩码。
- **参数初始化**：
  - Visual Expert 由大规模预训练世界模型 **GigaWorld-1**（上万小时视频数据）初始化；
  - Action Expert 从 Visual Expert 权重复制，不对齐维度通过截取前 $n$ 维完成。
- **视觉编码**：使用 Wan 的 VAE 对组合观测（左+前+右拼接）进行编码。
- **语言编码**：使用 umT5 文本编码器。

### 2.4 优化目标：Flow Matching

- 对动作与未来视觉 token 分别采样流时间步，使用模态特定的 flow-shift 因子 $\gamma_a, \gamma_v$；
- 通过线性插值构造带噪联合 token $x_\tau$；
- 优化目标为预测速度场与真实流速度之间的均方误差 $\mathcal{L} = \mathbb{E}\|g_\theta(x_\tau, \tau) - v_\tau\|_2^2$。

### 2.5 训练流程

1. **初始化**：Visual Expert 由 GigaWorld-1 初始化。
2. **预训练**：使用 ~2K 小时过滤后的开源机器人数据 + 内部真实机器人数据，进行混合 AC-WM + WAM 训练。
3. **后训练**：在目标机器人的真实轨迹上微调，同时优化动作预测与未来视觉建模。

### 2.6 推理加速

- **KV 缓存**：复用视觉/语言上下文的注意力 KV 状态；
- **torch.compile**：图编译优化，降低 Python 开销；
- **C++ 运行时**：整合图像预处理、张量构建、模型执行、KV 管理与动作后处理，降低运行时开销。

### 2.7 AutoResearch 自动化流程

- 智能体驱动的训练配置自动搜索；
- 自动启动 pilot 训练、监控验证指标、对比候选配置、promising 配置进入长程训练；
- 显著减少人工超参调优成本。

## 7. 优点与亮点

- **架构创新**：MoT 架构将视觉建模与动作生成分离到专门专家，既保留 WAM 训练监督，又通过轻量级 Action Expert 实现低延迟推理。
- **训练策略创新**：混合 AC-WM + WAM 预训练有效强化了"动作 → 视觉变化"的因果链建模。
- **工程完整度**：提供从 KV cache、torch.compile 到 C++ 运行时的完整边缘部署方案，使 85 ms 的边缘推理成为现实。
- **方法论革新**：AutoResearch 智能体搜索管线为大型 WAM/VLA 模型的超参调优提供了自动化范式。
- **因果掩码设计**：动作 token 严格不接触未来视觉 token，从机制上保证推理时可丢弃未来视频生成而不会产生信息泄漏。
- **初始化策略**：将 Action Expert 从 Visual Expert 复制初始化，巧妙地迁移了大规模视频预训练知识。
