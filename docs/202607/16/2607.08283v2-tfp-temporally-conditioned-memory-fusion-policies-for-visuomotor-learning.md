## Abstract
Vision--Language--Action (VLA) policies such as $π_{0.5}$ and OpenVLA perform well on many manipulation tasks, but they are often reactive: the next action is predicted from the current observation, instruction, and proprioceptive state. This assumption breaks down in stage-dependent manipulation, where visually similar states may require different actions depending on latent task progress and previous interaction outcomes. We argue that such tasks require not only memory, but dynamics-aware belief updates: the policy should preserve task progress during stable or occluded phases and revise its belief near contact, release, or subgoal transitions. We introduce Temporally Conditioned Memory-Fusion Policies (TFP), a lightweight memory-action framework for VLA backbones. TFP maintains an episode-local task-progress belief with Liquid Time-Constant dynamics and injects the updated belief directly into the flow-matching action decoder through adaptive modulation. This lets temporally accumulated context shape the generated action chunk, rather than serving only as passive history context. With a 3.3B-parameter model, TFP improves the average success rate from \(96.9\%\) to \(98.75\%\) on LIBERO and from \(91.4\%\) to \(93.77\%\) on LIBERO-plus. On the memory-focused MIKASA ShellGameTouch diagnostic, TFP achieves success up to \(75.0\%\). Mechanistic analyses show that write-gain changes near manipulation events are about \(6\times\) larger than far non-event phases, and hidden-state interventions show that the belief causally modulates generated action chunks. These results suggest that compact, event-sensitive memory dynamics can improve VLA policies under occlusion, visual perturbation, and stage-dependent task structure.

# 论文总结：TFP — 时序条件记忆融合的视觉运动策略

## 1. 核心问题与整体含义

- **研究对象**：当前主流的 **Vision–Language–Action (VLA)** 策略（如 π0.5、OpenVLA、Octo、π0）通过当前观测、本体状态与语言指令直接预测动作，本质上是**反应式（reactive）**的。
- **核心问题**：在**阶段依赖型（stage-dependent）操作任务**中，视觉上几乎相同的当前状态，可能对应完全不同的正确动作。例如物体交换任务中，"把第一个物体放到缓冲区"、"把第二个物体放到原位"、"终止任务"等阶段可能呈现一致的外观。
- **关键洞察**：仅靠堆叠历史帧或通用循环网络并不足够，记忆更新需要**符合操作事件的物理时间结构**：
  - 在稳定抓持、遮挡阶段 → 应**保留**任务进度信念；
  - 在接触、释放、子目标切换阶段 → 应**快速修正**信念。
- **研究目标**：为 VLA 引入一个**动力学感知（dynamics-aware）的事件敏感任务进度信念**，使记忆直接塑形动作生成，而不仅是历史缓冲。

## 2. 方法论

### 2.1 整体框架

TFP 是面向分块（chunked）VLA 控制的轻量记忆-动作融合框架，主要由三部分构成：

1. **连续时间信念更新模块（LTC 动力学）**
2. **AdaLN 风格自适应调制接口**
3. **Episode-Aware Temporal Batching (EATB) 训练策略**

### 2.2 关键技术细节

- **观测编码**：将视觉 token 池化与本体状态嵌入拼接，得到紧凑表示 $x_t = [\phi_{\text{vision}}(V_t); \phi_{\text{state}}(s_t)]$。
- **LTC 信念更新**：
  - 候选信念：$\hat{h}_t = \tanh(W_h[x_t; h_{t-1}] + b_h)$
  - 输入相关时间常数：$\tau_t = \text{softplus}(W_\tau [x_t; h_{t-1}] + b_\tau) + \epsilon$
  - 滞留门：$k_t = \exp(-\Delta t_t / \tau_t)$，写入增益 $g_t = 1 - k_t$
  - 更新公式：$h_t = k_t \odot h_{t-1} + (1 - k_t) \odot \hat{h}_t$
- **关键性质**：作者在附录中证明：
  - 该更新是一阶连续时间信念松弛 ODE 的**精确离散解**；
  - 指数滞留是满足 elapsed-time 一致性（$k(\Delta_1+\Delta_2)=k(\Delta_1)k(\Delta_2)$）的**唯一标量连续保留函数**。
- **动作解码器注入**：将 $h_t$ 投影到解码器条件空间 $m_t = W_m h_t + b_m$，与 flow-matching 时间步嵌入 $z_\tau$ 相加得到 $c_t = z_\tau + m_t$，再通过 **AdaLN** 在每层动作解码器上施加特征级仿射调制 $v_\theta(a_\tau, \tau | I_t, s_t, \ell, h_t)$。
- **EATB 训练**：每个 episode 维护独立的隐藏状态 $h_t^{(e)}$；训练时采样 $B$ 个 episode，各展开 $K$ 个连续 chunk，按流匹配损失平均；段间用 `stop_grad` 写回末态以保留长期前向记忆，避免完整 episode 反向传播的高显存开销。
- **自适应执行**：推理时采用 **adaptive receding-horizon**，根据 jerk、夹爪过渡边界、与已执行动作的连续性等风险信号决定本次执行块长度 $E_t \in [E_{\min}, H]$，将真实物理时间 $\Delta t_{t+1} = E_t \delta_t^{\text{ctrl}}$ 反馈给下一次记忆更新。

## 3. 实验设计

### 3.1 数据集 / Benchmark

- **LIBERO**（Spatial / Object / Goal / Long-10）：通用操作与终身学习基准。
- **LIBERO-plus**：在 LIBERO 基础上加入 Noise / Lighting / Background 等视觉扰动。
- **MIKASA-Robo ShellGameTouch**：遮挡下的物体身份记忆诊断任务（仅触摸，不抓取）。
- **真实机器人 Galaxea A1**：单臂 + 平行夹爪 + 手腕鱼眼相机 + RealSense D435，包括 **物体交换**与**计数 pick-and-place** 两类阶段依赖型任务。

### 3.2 对比方法

- **反应式基线**：π0.5（3.3B）、π0（3.3B）。
- **已发表 VLA 基线**：OpenVLA (7B)、OpenVLA-OFT (7.3B)、HAMLET (3B)、AVA-VLA (7.3B)、MemoryVLA (7.3B)。
- **同骨干控制消融**：π0.5+GRU、π0.5+S4D (SSM)、TFP w/o Δt（用常数时间步替代真实 Δt）。

### 3.3 评估指标

- 成功率（Success Rate）；
- 写入门增益变化 $\Delta g_t$ 的事件/非事件对齐；
- 隐藏状态干预下的动作块差异；
- Wilson 95% 置信区间。

## 6. 主要结论与发现

- **总体性能**：3.3B 参数下，TFP 将 LIBERO 平均成功率从 96.9% 提至 **98.75%**，LIBERO-plus 从 91.4% 提至 **93.77%**，ShellGameTouch 达 **75.0%**；真机两任务分别由 3/20 → 15/20 与 8/20 → 18/20。
- **事件敏感记忆**：写入门增益 $\Delta g_t$ 在接触、释放等操作事件附近约为远端非事件阶段的 **6 倍**（最佳对齐 5.9–6.24×，滞后约 –1.6 至 –2.1 步），证明记忆更新并非步进式而是事件驱动。
- **信念因果性**：固定观测、指令与状态，仅替换 $h_t$ 即可使 10 步动作块发生显著变化（平均成对距离 0.0442，最大 0.1303，远大于相邻时间步的 0.0108）。
- **连续时间的必要性**：去掉真实 Δt（用常数步长）后 Long 切分与 LIBERO-plus 噪声/光照子项明显下降，说明**真实流逝时间**对不规则查询下的更新很重要。
- **失败归因**：TFP 主要将"阶段错误 / 子任务重复"类失败转化为"目标定位 / 低级执行"类失败，提示其优势集中在任务进度跟踪，而非底层控制。

## 7. 优点

- **结构化归纳偏置**：将 LTC 显式视为连续时间 POMDP 信念松弛的精确离散解，并用命题证明指数滞留是 elapsed-time 一致性的唯一连续保留函数，使设计选择具有理论支撑。
- **记忆-动作紧耦合**：通过 AdaLN 把 $h_t$ 注入流匹配解码器每一层，避免记忆 token 序列的二次解读负担；同一观测不同信念可产生显著不同的动作块。
- **训练高效性**：EATB 用 `stop_grad` 段间写回 + 多 episode 并行展开 K 段，兼顾长程前向记忆与显存友好。
- **机制可解释性强**：不仅报成功率，还提供写入门动态、同观测干预、真机失败标签等多层次分析。
- **通用即插即用**：主干预模块仅 256 维记忆，可无缝叠加到 π0.5 等流匹配 VLA 主干上。

## 8. 不足与局限

- **训练成本高**：完整 LIBERO 微调需 4×H200、80 小时、100 GB 显存，普通实验室复现门槛较高；EATB 仍需顺序展开 K 段。
- **基线公平性**：表 I 中多数数字来自各自文献，未在同一训练/rollout 协议下重新复现；同骨干对比仅覆盖 GRU 与 S4D，未与 HAMLET、AVA-VLA、MemoryVLA 在统一流水线中重训。
- **任务覆盖局限**：真机仅评估了桌面级单臂操作，**未涉及移动操作、人形、灵巧手**；ShellGameTouch 的 75% 距 MemoryVLA 的 88% 仍有差距，作者承认这是因为 TFP 的事件敏感连续时间信念并不擅长"离散对象身份-位置绑定"类任务。
- **推理时计算代价**：自适应执行器虽然不改变模型权重，但需要在线检测 jerk、夹爪过渡与连续性，部署时仍带来少量额外开销。
- **机制分析范围有限**：事件标签是事后从仿真特权信号中提取的，**未在真机上做对应干预**；隐藏状态干预只在 LIBERO 上做了 1 个 query 的 25 种条件，无法完全排除隐空间耦合。
- **可能偏差**：所有对照试验都共享相同的自适应执行器；反应式 π0.5 在该执行器下相对其原始固定步长设定的真实增益未被独立讨论，存在一定执行侧带来的"基线偏弱"风险。
