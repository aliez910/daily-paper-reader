## 摘要
生成式视觉-语言-动作策略推动了机器人操作的发展，但在噪声、部分可观测性以及随机初始条件下常常表现出不稳定性。在长时间滚动执行过程中，微小的速度误差会累积，降低执行的可靠性。现有的基于扩散和流的方法通常假设残差具有同方差性，并且在动作生成中缺乏显式的不确定性建模，限制了迭代滚动执行过程中的鲁棒性。我们提出了SUREFlow，一个基于Mamba骨干网络构建的状态空间不确定性感知残差流匹配框架。该方法联合预测动作速度以及与输入相关的残差不确定性，能够在无需环境反馈的情况下对不可靠的动作维度进行选择性细化，同时保持计算效率。在LIBERO数据集上，SUREFlow取得了92.5%的平均成功率（SR），优于基于Mamba的MaIL 34.2%。在LIBERO-PRO数据集上，SUREFlow仅使用1.79亿参数即达到约49%的成功率，性能可与参数量为30亿至70亿的大型VLA模型相媲美。SUREFlow源代码已开源：https://github.com/tanvirnwu/SUREFlow

## Abstract
Generative vision-language-action policies have advanced robot manipulation, but they often exhibit instability under noise, partial observability, and stochastic initial conditions. During extended rollouts, small velocity errors accumulate, degrading execution reliability. Existing diffusion and flow-based policies typically assume homoscedastic residuals and lack explicit uncertainty modeling within action generation, limiting robustness during iterative rollout. We propose SUREFlow, a state-space uncertainty-aware residual flow matching framework built on a Mamba backbone. The method jointly predicts action velocities and input-dependent residual uncertainty, enabling selective refinement of unreliable action dimensions without environment feedback while preserving computational efficiency. On LIBERO, SUREFlow achieves 92.5% average success rate (SR), outperforming the Mamba-based MaIL by 34.2%. On LIBERO-PRO, it attains around 49% SR using only 179M parameters, achieving performance comparable to large VLAs with 3-7B parameters. SUREFlow source code is available on: https://github.com/tanvirnwu/SUREFlow

# SUREFlow 论文总结

## 一、核心问题与研究动机

- **核心问题**：生成式视觉-语言-动作（VLA）策略在机器人操控任务中存在**长程执行不稳定性**的问题。具体表现为：
  - 扩散策略与流匹配策略通常假设残差是**同方差**（homoscedastic），缺乏对动作生成中输入相关不确定性的显式建模。
  - 在长时间开环滚动执行（open-loop rollout）中，速度场的微小误差会**逐步累积**，导致执行可靠性下降。
  - 多数现有方法依赖大参数 Transformer 自回归解码，计算开销大，难以满足实际部署需求。
  - 现有层次化/技能学习方法往往将技能学习与底层控制解耦，缺乏与端到端生成式策略的深度融合。
- **研究目标**：提出一种**轻量、鲁棒、可显式建模不确定性**的生成式流匹配操控框架，从而在长程、噪声、部分可观测条件下实现稳定执行。

## 二、方法论：核心思想与关键技术

### 1. 整体框架（SUREFlow）
- 以 **Mamba 状态空间模型**为骨干，将动作生成分解为**条件流匹配（conditional flow matching）**问题。
- 三大核心模块：
  1. **URFlow（Uncertainty-aware Residual Flow）**：不确定性感知残差流。
  2. **MGAD（Memory-Guided Action Decoder）**：记忆引导的动作解码器。
  3. **FCM（Flow Conditioned Modulation）**：流条件调制。

### 2. 条件流匹配（Flow Matching）
- 学习一个时间相关的速度场 $v_t$，将高斯先验 $p_1$ 映射至专家动作分布 $p_0$。
- 构造线性插值路径：$x_t = (1-t)a + t z$，其中 $a \sim p_0$ 为专家动作，$z \sim \mathcal{N}(0, I)$ 为噪声。
- 解析目标速度：$v_t(x_t) = z - a$。
- 学习得到的条件速度场记作 $\hat{v}_t = f_\theta(x_t, s, t)$，其中 $s = \psi(o_t, e)$ 为多模态融合表征。

### 3. URFlow（不确定性感知残差流）
- **核心思想**：显式建模残差 $r_t = \hat{v}_t - v_t(x_t)$ 的**异方差（heteroscedastic）不确定性**，而非假设所有残差同等可靠。
- 网络同时预测：
  - 速度 $\hat{v}_t = f_v(\tilde{h}_t^{(a)})$
  - 对数方差 $\hat{s}_t = f_s(\tilde{h}_t^{(a)})$（即 $\log \sigma^2$）
- **训练损失**：
  - 流匹配损失：$L_{FM} = \mathbb{E}_{a,z,t}[\|r_t\|_2^2]$
  - 不确定性损失：$L_u = \|r_t\|_2^2 / \exp(\hat{s}_t) + \hat{s}_t$
  - 总损失：$L = L_{FM} + \lambda_u L_u$，论文中 $\lambda_u = 0.001$
- **推理时的精炼机制（无环境反馈）**：
  - 在 $t=0$ 处计算预测不确定性。
  - 构造掩码 $M = \{i \mid \hat{s}_{0,i} > \tau\}$，阈值 $\tau = 0.9$。
  - 对高不确定性维度执行残差更新 $a_i \leftarrow a_i - \eta \hat{v}_{0,i}$，迭代 $K=3$ 次。
  - **关键特点**：完全在模型内部完成，无需在线环境反馈。

### 4. MGAD（记忆引导动作解码器）
- 将动作 token 视为可学习的 query，对 Mamba 输出隐藏序列 $H_t^{(L)}$ 执行**轻量级单层交叉注意力**。
- 使用 10 个可学习动作查询，4 头自/交叉注意力，head dim 64，后接 2 层 FFN（hidden 512）+ LayerNorm。
- 作用：让动作表征有选择地聚合多模态上下文信息，提升时间条件化与不确定性校准。

### 5. FCM（流条件调制）
- 对中间特征做基于时间的仿射调制：
  - 从时间嵌入 $\phi(t)$ 经两层 MLP 与两个线性层得到 $\gamma, \beta$。
  - 调制公式：$\mathrm{FCM}(U, \phi(t)) = U \odot (1 + \gamma) + \beta$。
  - 初始化为零（恒等映射），保证训练稳定。
- 应用位置：状态 token、动作 token、解码后动作特征，以及任务嵌入。

### 6. 网络结构与配置
- 视觉编码器：每个相机视角使用 **ResNet-18（带 GroupNorm）**，256 维潜空间投影。
- 语言编码器：**CLIP ViT-B/32** 预训练模型。
- 状态编码：可学习仿射映射 $f_{state}$。
- 动作嵌入：$\mathbb{R}^7 \to \mathbb{R}^{256}$ 的线性层。
- Mamba 主干：**5 层**，hidden dim 256，intermediate dim 256。
- 总体参数规模：**179M**。

## 六、主要结论与发现

- **LIBERO 表现**：SUREFlow 平均 SR 达 **92.5%**，较 Octo（75.1%）提升 17.4%，较 MaIL（58.3%）提升 **34.2%**。
- **Meta-World 表现**：平均 SR **88.32%**，超过 Diffusion Policy（37.6%）、DP3（74.4%）、Mamba Policy（76.8%）等。
- **LIBERO-PRO 表现**：仅 **179M 参数**即可取得约 **49% SR**，超过 π0（3B，44%），与 OpenVLA（7B，52%）、π0.5（3B，53%）相当。
- **长程稳定性**：URFlow 显著缓解 SR 随 rollout 步长增加而下降的趋势，验证了不确定性引导精炼对累积误差的抑制作用。
- **消融结论**：URFlow 单独贡献最大（+0.09 SR）；MGAD + URFlow 组合可获 0.91；完整 SUREFlow 达到 **0.92 SR**。
- **不确定性校准**：MGAD 加快不确定性统计量的收敛，并稳定 $\hat{s}_{min}$ 与 $\hat{s}_{max}$ 范围；移除 MGAD 会导致过度自信（$\hat{s}_{min}$ 偏低）。
- **超参数敏感性**：$\lambda_u = 0.001$ 与 $K = 3$ 为最佳；过大权重或过多精炼步数都会降低性能。
- **真实机器人**：颜色匹配插入任务 SR 达 **88.5%**（每色 20 次 rollout），验证方法的实用部署价值。

## 七、优点与亮点

- **方法创新性强**：
  - 首次将**异方差不确定性建模**显式融入条件流匹配框架，并结合**残差学习**思想。
  - 提出了**推理时无环境反馈的闭环精炼机制**，通过阈值与步数控制实现选择性维度更新。
- **架构高效**：仅 **179M 参数**即在多个基准上比肩 3B–7B 大模型，验证了 SSM + 轻量 MGAD 的高效性。
- **Mamba 骨干**带来线性时间复杂度，适合长程序列建模。
- **FCM 模块**以零初始化恒等映射开始训练，保证稳定性并允许时间信息贯穿网络。
- **实验较为系统**：涵盖基准、消融、敏感性、长程稳定性、不确定性校准与真实机器人实验。
- **代码开源**：GitHub 仓库已公开，便于复现。
