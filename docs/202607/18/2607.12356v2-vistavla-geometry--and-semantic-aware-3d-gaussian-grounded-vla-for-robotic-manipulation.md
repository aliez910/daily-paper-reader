## 摘要
视觉-语言-动作（VLA）模型通过将语言指令和二维视觉输入直接映射为动作，已成为机器人操作任务中一种强大的端到端范式。然而，这些模型缺乏显式的场景级三维表征，限制了其在空间布局和几何约束上的推理能力。尽管近期研究通过引入深度图或点云等显式三维线索来增强几何感知能力，但这些方法主要捕获低级结构，缺乏三维空间中的高级语义接地。在人类认知中，与物理世界的交互依赖于一种三维语义认知地图——一种将空间布局与语义上下文相整合的内部心智模型，以支持持久的、与视角无关的推理。受此启发，我们提出了VistaVLA，一种新颖的两阶段框架，它从三维高斯基元构建具有几何与语义感知能力的三维认知表征，并将其作为紧凑的上下文令牌用于VLA策略学习。具体而言，VistaVLA将多视角视觉-语言特征提升到三维高斯基元中，形成几何锚定的语义令牌，使其与视图一致的空间接地对齐于二维视觉特征空间。为使该三维表征在VLA控制中具有计算可行性，我们引入了合并-查询（Merge-then-Query，MtQ）令牌汇总机制。MtQ将密集的高斯基元压缩为一组高度紧凑且具有空间信息的令牌，在保留与动作相关的三维布局和语义上下文的同时，实现了99%的令牌压缩率。在仿真环境和真实环境中的大量实验验证了VistaVLA的有效性。值得注意的是，在真实场景中，VistaVLA在七项真实任务上将成功率提升了22.8%，并在具有挑战性的分布外任务上相较VLA-Adapter基线提升了30.0%。

## Abstract
Vision-Language-Action (VLA) models have emerged as a powerful end-to-end paradigm for robotic manipulation by mapping language instructions and 2D visual inputs directly to actions. However, these models lack an explicit, scene-level 3D representation, limiting their ability to reason over spatial layouts and geometric constraints. While recent efforts incorporate explicit 3D cues, such as depth maps or point clouds, to improve geometric awareness, they primarily capture low-level structures and lack high-level semantic grounding in 3D space. In human cognition, interaction with the physical world relies on a 3D semantic cognitive map - an internal mental model that integrates spatial layouts with semantic context to enable persistent, viewpoint-invariant reasoning. In light of this, we present VistaVLA, a novel two-stage framework that constructs a geometry- and semantics-aware 3D cognitive representation from 3D Gaussian primitives and grounds it as compact context tokens for VLA policy learning. Specifically, VistaVLA lifts multi-view vision-language features into 3D Gaussian primitives, forming geometry-anchored semantic tokens that align view-consistent spatial grounding with 2D visual feature spaces. To make this 3D representation computationally tractable for effective VLA control, we introduce Merge-then-Query (MtQ), a token summarization mechanism. MtQ compresses dense Gaussian primitives into a highly compact set of spatially informative tokens, achieving a 99% token reduction while preserving action-relevant 3D layouts and semantic context. Extensive evaluations in both simulated and real-world environments demonstrate the effectiveness of VistaVLA. Notably, in real-world scenarios, VistaVLA improves success rates by 22.8% across seven real-world tasks and by 30.0% over the VLA-Adapter baseline on challenging out-of-distribution tasks.

# VistaVLA 论文总结

## 1. 核心问题与研究动机

- **2D VLA 的瓶颈**：现有视觉-语言-动作（VLA）模型（如 OpenVLA、π0、RT-2、VLA-Adapter 等）仅依赖 2D 图像观测，缺乏显式的场景级 3D 表征，难以推理空间布局与几何约束，在精确抓取、堆叠、接触丰富等操作任务上容易失败。
- **3D 注入方法的不足**：近期通过深度图、点云、稀疏 3D 坐标等显式 3D 线索增强 VLA 的方法（SpatialVLA、PointVLA、3D-VLA、Q-Depth VLA 等），主要编码低级几何结构，缺少与开放词汇语义对齐的 3D 接地语义。
- **认知科学启发**：人类依赖"3D 语义认知地图"——将连续空间拓扑与功能语义融合的内部心智模型，实现持久、视角无关的推理；现有方法既不是场景级表示，也难以将丰富多模态语义绑定到物理空间结构上。
- **核心矛盾**：密集 3D 表示（如 10⁵ 量级的高斯基元）蕴含丰富空间-语义信息，但直接喂给 VLA 推理代价过高；需要一个紧凑的、可被 VLA 高效消费的 3D 接地语义接口。

## 2. 方法论

### 2.1 总体框架

VistaVLA 是两阶段框架：
- **Stage I**：构造语义高斯场，将多视角视觉-语言特征提升到 3D 高斯基元中，形成几何锚定的语义 token。
- **Stage II**：引入 Merge-then-Query（MtQ）模块，将密集高斯 token 压缩为固定长度的紧凑 3D 上下文 token，再注入 VLA 策略网络。

### 2.2 Stage I：3D 高斯接地认知表征

- **教师特征压缩**：提取每帧的 SigLIP2 与 DINOv2-Large 特征并拼接（2176 维），用轻量自编码器一次性训练，压缩到 128 维潜码作为后续高斯特征渲染的教师信号。
- **高斯基元定义**：每个基元 gi = (μi, Σi, αi, ci, zi)，其中 zi ∈ R¹²⁸ 为可学习的语义特征，其余为位置、协方差、不透明度、颜色。
- **两阶段渲染训练**：
  - 第一阶段损失 L_stage1 = λ_rgb·L_rgb + λ_dep·L_dep，先建立稳定的场景几何。
  - 第二阶段加入 L_feat，约束渲染特征图与教师特征一致：L_stage2 = λ_rgb·L_rgb + λ_dep·L_dep + λ_feat·L_feat。
  - 特征渲染遵循 3DGS 的 alpha-compositing 规则：F̂ᵥ(p) = Σᵢ Rᵢ(v,p)·zᵢ，其中 Rᵢ(v,p) 由投影、不透明度、深度排序与相机参数共同决定。
- **多视角一致性**：训练时使用两个标定 RGB-D 视角作上下文，渲染第三个视角作为新视图目标，强制跨视角一致性。
- **在线推理**：测试时不需深度输入或第三视角，仅用策略网络的实时 RGB 观测与标定相机位姿在线构建高斯场。

### 2.3 Stage II：MtQ 压缩与策略注入

- **问题**：高斯场约含 N₀ ∼ 10⁵ 个基元，无法实时送入 VLA。
- **参数化无关压缩**：
  1. 对稠密 GS token 重塑为逐视图网格并做 stride-4 平均池化，粗压缩到约 7K token。
  2. 按 3D 中心的 Morton 码排序，交替划分为锚点集 A 与非锚点集 B（避免 FPS 的迭代距离更新）。
  3. 每个非锚点 u ∈ B 通过语义相似度（余弦）匹配到最相似锚点 a*。
  4. 按相似度排名，仅合并前 50% 匹配，避免强制合并语义不一致 token。
  5. 对锚点进行 size-weighted 平均更新：z'ₐ、μ'ₐ、s'ₐ。
  6. 重复迭代直至 token 数 < N' = 1000。
- **基于查询的摘要**：用 Nq = 64 个可学习查询 token Q 通过 2 层 Transformer 解码器对压缩后 token Z' 做交叉注意力，再投影到 VLA 主干隐藏维度 d_llm，得到 X_gs ∈ R^(B×64×d_llm)。
- **动作生成**：遵循 VLA-Adapter 的因果序列建模范式，拼接 X = [X_vis, X_lang, X_gs, X_act]，使 GS 上下文在语言条件之后、动作解码之前被关注。动作头以 L1 回归损失训练；推理时执行前 K_exec = 4 个预测动作后重新规划。

## 6. 主要结论与发现

- **3D 语义接地显著提升空间推理**：将 2D 视觉语言特征提升到 3D 高斯场可同时获得几何结构与高级语义，比单纯注入深度/点云更有利于 VLA 策略学习。
- **MtQ 实现高效压缩**：99% token 缩减（10⁵ → 64 个查询 token）的同时保留动作相关 3D 布局与语义上下文。
- **小模型可胜大模型**：0.5B 主干的 VistaVLA 在空间需求强的真实任务上超过 π0.5-3B 等更大通用 VLA。
- **空间 OOD 鲁棒性**：相比基线，LIBERO-Pro-Swap 从 1.7% 提升到 12.2%，真实场景位置扰动从 0/10 提升到 3/10。
- **改进源于结构性 3D 表示而非更多图像**：相机/token 消融表明，即使使用 3 个相机视角的 2D token 仍逊于 VistaVLA 的紧凑 3D 摘要。

## 7. 方法与实验设计的亮点

- **认知科学驱动**：明确借鉴人类"3D 语义认知地图"，将 3D 几何与开放词汇语义在统一表示中耦合。
- **3DGS 作为策略级表示**：将高斯泼溅从渲染/重建场景拓展为 VLA 策略可消费的语言-视觉-动作接口。
- **在线高斯场构建**：测试时不依赖深度或第三视角，仅用 RGB + 标定姿态实时构造高斯场，适合实际部署。

- **完整消融链路**：从相机数量、压缩策略到查询数量逐项验证，证明每个组件的必要性。
