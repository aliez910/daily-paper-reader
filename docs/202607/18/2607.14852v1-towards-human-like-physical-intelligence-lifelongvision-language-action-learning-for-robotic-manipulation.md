## 摘要
与人类按顺序学习新任务的自然能力类似，配备视觉-语言-动作（VLA）模型的机器人在部署于开放世界环境时，应具备学习新任务的终身学习能力。然而，目前大多数最新提出的终身学习模型旨在有效学习当前任务（可塑性）或保持对先前任务的高准确率（稳定性），而可塑性-稳定性权衡问题在机器人操作模型中仍未得到有效解决。为应对这一根本性挑战，我们提出了一种面向机器人操作的缓存高效的终身视觉-语言-动作学习框架（即LifelongVLA），该框架通过双时间尺度自适应机制缓解可塑性-稳定性权衡问题，同时通过缓存高效的回放策略实现低成本的机器人部署。具体而言，我们提出了一种双时间尺度LoRA门控模块，将VLA自适应分解为两条轻量化路径：用于可塑性的短期适配器和用于稳定巩固的长期适配器。这些路径通过任务感知门控进行集成，从而实现对可塑性-稳定性权衡的显式控制。在技能回放阶段，我们提出了一种缓存高效的随机回放策略，无需完整轨迹存储即可保留更均衡的保留信号。最后，实验表明LifelongVLA优于现有基线方法，展示了高效的能力扩展、对已学操作行为的稳健保持，以及在xArm机器人上实际部署时减少对重训练的依赖。

## Abstract
Similar to the natural capabilities of humans to sequentially learn new tasks, robots with Vision-Language-Action (VLA) models should possess lifelong learning ability to learn a new task when deployed in open-world environments. However, most recently proposed lifelong learning models aim to effectively learn the current task (plasticity) or maintain high accuracy on previous tasks (stability), while the plasticity-stability trade-off remains largely unsolved in robotic manipulation models. To address this fundamental challenge, we propose a cache-efficient lifelong Vision-Language-Action learning framework for robotic manipulation (i.e., LifelongVLA), which alleviates the plasticity-stability trade-off with a dual-timescale adaptation mechanism while achieving low-cost robotic deployment with a cache-efficient replay strategy. More concretely, we propose a dual-timescale LoRA gating module to decompose VLA adaptation into two lightweight pathways: a short-term adapter for plasticity and a long-term adapter for stable consolidation. These pathways are integrated via a task-aware gate, enabling explicit control of the plasticity-stability trade-off. In the skill replay phase, a cache-efficient stochastic replay strategy is proposed to preserve more balanced retention signals without full-trajectory storage. Finally, experiments show that LifelongVLA outperforms existing baselines, demonstrating efficient skill expansion, robust retention of learned manipulation behaviors, and reduced reliance on retraining for real-world deployment on an xArm robot.

# 论文总结：LifelongVLA — 面向机器人操作的终身视觉-语言-动作学习

## 1. 核心问题与整体含义

### 1.1 研究背景
- **VLA 范式的兴起**：Vision-Language-Action（VLA）模型（如 RT 系列、Octo、π0/π0.5/π0.7）已成为语言条件机器人操作的主流范式，通过预训练视觉-语言表征连接机器人动作生成。
- **关键缺陷**：现有 VLA 模型普遍采用**静态离线训练**——在固定数据集上训练一次后即部署，无法在真实开放环境中持续学习新任务。
- **真实部署需求**：机器人需应对持续出现的新物体、新指令、新场景布局和特定于本体的动作分布。

### 1.2 核心挑战：塑性-稳定性权衡（Plasticity-Stability Trade-off）
- **塑性（Plasticity）**：快速学习新技能的能力。
- **稳定性（Stability）**：保持已学技能不遗忘的能力。
- **现有方法的不足**：
  - **直接顺序学习**：会导致灾难性遗忘。
  - **完整历史重训**：计算与存储开销过大。
  - **Replay Buffer / 架构扩展 / 参数隔离**：均未能充分解决权衡问题。
  - **完整轨迹回放**：图像丰富的 episode 需反复重新编码，计算成本高昂。

## 2. 方法论

### 2.1 整体框架：LifelongVLA
基于冻结的 VLA 主干（PaliGemma Gemma 2B + Gemma 300M 连续动作解码器），由两大核心模块构成：
- **Dual-Timescale LoRA Gating**（双时间尺度 LoRA 门控）
- **Cache-Efficient Stochastic Replay**（缓存高效随机回放）

### 2.2 Dual-Timescale LoRA Gating（双时间尺度 LoRA 门控）

**核心思想**：将 VLA 自适应过程分解为两条独立路径，以不同时间尺度分别建模"短期塑性"与"长期稳定"。

**关键设计**：
- **短期路径** $\Delta W_{\ell}^{sh,t} = A_{\ell}^{sh,t} B_{\ell}^{sh,t}$：仅由当前任务损失 $\mathcal{L}_{new}$ 更新，学习率 $\eta_{sh}$ 较大，负责快速吸收新任务。
- **长期路径** $\Delta W_{\ell}^{lg,t} = A_{\ell}^{lg,t} B_{\ell}^{lg,t}$：仅由回放损失 $\lambda \mathcal{L}_{rep}$ 与蒸馏损失 $\beta \mathcal{L}_{dist}$ 更新，学习率 $\eta_{lg} < \eta_{sh}$，负责巩固已学技能。

**任务感知门控（Task-Aware Gate）**：
- 门控上下文 $c$ 取自**冻结前缀特征**（避免循环依赖）：
  $$c = \text{Pool}(\text{stopgrad}(E_{pre}(u; \Theta_0)))$$
- 门控权重预测（每层）：
  $$\alpha_{\ell}^t(c) = \sigma(W_\ell^g \phi_\ell(c) + b_\ell^g), \quad \alpha \in [0,1]$$
- **权重级别组合**（单次前向推理）：
  $$\Delta_c W_\ell^t(c) = (1 - \alpha_\ell^t)\Delta W_\ell^{sh,t} + \alpha_\ell^t \Delta W_\ell^{lg,t}$$
  $$\tilde{W}_\ell^t(c) = W_\ell^0 + \gamma \Delta_c W_\ell^t(c)$$

### 2.3 Cache-Efficient Stochastic Replay（缓存高效随机回放）

**核心思想**：仅存储紧凑的 stop-gradient 前缀 token（不再存原始图像、语言 token、suffix、扩散时间/噪声），通过当前模型重算 suffix 实现高效回放。

**关键流程**：
- **技能级前缀缓存**：每任务仅采样 $c_t = 50$ 个样本，存储 $(\bar{h}_{pre}^{i,t}, s_i^t, y_i^t)$。
- **随机回放重采样**：对每个缓存样本，每次回放时**重新采样**扩散变量：
  $$\tau'_j \sim p(\tau), \quad \epsilon'_j \sim \mathcal{N}(0, I), \quad \tilde{y}_{\tau'}^{rep} = q_{\tau'_j}(y_j, \epsilon'_j)$$
- **Suffix 重算**：使用当前模型状态生成新的 suffix：
  $$h_{suf,rep}^{j,t} = E_{suf}(s_j, \tilde{y}_{\tau'}^{rep}, \tau'_j; \tilde{\Theta}_t(c_j^{rep}))$$
  $$\hat{\eta}_{rep}^j = D([\bar{h}_{pre}^j, h_{suf,rep}^{j,t}]; \tilde{\Theta}_t(c_j^{rep}))$$

**掩码损失函数**：
- 同一 mini-batch 内混合当前样本与回放样本，使用 replay mask 区分：
  $$\mathcal{L}_t = \mathcal{L}_{new} + \lambda \mathcal{L}_{rep} + \beta \mathcal{L}_{dist}$$
- $\mathcal{L}_{new}$ 与 $\mathcal{L}_{rep}$ 各自独立归一化，避免某一方主导梯度。
- 蒸馏损失 $\mathcal{L}_{dist}$ 使用任务 $t-1$ 的 detached 教师模型稳定旧技能预测。

## 7. 优点与亮点

- **架构设计清晰**：双时间尺度 LoRA 设计巧妙地将"快速塑性"与"长期稳定"显式解耦，类比人类记忆机制。
- **门控机制优雅**：权重级组合（而非输出级组合）使推理仍只需**单次前向传播**，不增加部署延迟。

- **实验对比充分**：覆盖 5 个有代表性的终身学习/VLA 基线，并提供过程级曲线与消融分析。
- **真实部署验证**：不止停留在仿真，也在 xArm 上做了实地验证。
