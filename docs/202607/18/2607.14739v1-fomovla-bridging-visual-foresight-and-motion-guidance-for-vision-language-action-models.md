## Abstract
Vision-Language-Action (VLA) models have achieved impressive results in visuomotor policy learning, yet remain fundamentally reactive, mapping current observations and language to actions without explicit forward prediction of world dynamics. Existing visual foresight methods predict future visual states but lack explicit motion guidance: they show where to go but not how to get there. We argue that future feature prediction and sparse point tracking are naturally complementary: the former provides the goal state, while the latter captures the continuous motion path toward it. We propose FoMoVLA, a framework that augments VLA representations with explicit spatio-temporal supervision by jointly learning future feature foresight and sparse 2D point tracking, enhancing the continuous action policy. FoMoVLA introduces compact foresight tokens to decode future feature states, decodes sparse temporal 2D point trajectories to model compact geometric motion, and couples both through a lightweight future-conditioned cross-attention module that enables consistent reasoning between anticipated states and point dynamics. Extensive experiments on LIBERO, RoboCasa GR-1 Tabletop, and LIBERO-Plus demonstrate state-of-the-art performance and strong zero-shot generalization. Project page is available at https://liauto-research.github.io/FoMoVLA.

# FoMoVLA 论文总结

## 1. 核心问题与研究动机

- **VLA 模型的反应式局限**：现有 Vision-Language-Action（VLA）模型（如 RT-2、OpenVLA、π0、GR00T 等）仅将当前视觉观测与语言指令直接映射为动作，本质上是"反应式"的，缺乏对世界动态的前向预测能力，难以胜任长时序、复杂动力学任务。
- **现有"视觉前瞻"方法的两类缺陷**：
  - **像素级密集预测**（如 DreamVLA、WorldVLA）：保留丰富场景信息但建模开销大，且包含大量与控制无关的静态背景，造成表征冗余。
  - **关键帧级紧凑预测**（如 HiF-VLA）：仅刻画目标终态，缺乏从当前到目标的**连续运动路径**，无法表达具体的动力学交互过程。
- **核心洞察**：未来特征预测（回答"目标在哪"）与稀疏点轨迹跟踪（回答"如何到达"）天然互补，二者联合可形成真正"可执行"的前瞻表征。
- **现有跟踪/光流方法**（FlowVLA、GeoPredict、JOPAT、Spatial Forcing）：仅单独使用视觉前瞻或点跟踪监督，未在统一框架内耦合两者，存在梯度干扰与表征分歧。

## 2. 方法论

### 2.1 总体框架
FoMoVLA 在 VLA 基座（StarVLA-GR00T）之上，**仅在训练时**引入三条辅助分支；推理时全部丢弃，零额外参数开销：

| 分支 | 作用 | 关键设计 |
|------|------|----------|
| 点跟踪分支（Point Tracking） | 编码"如何运动" | 用冻结 CoTracker-v3 作为教师，对 8×8=64 个稀疏网格点生成 T 帧位移/可见性监督 |
| 未来特征预测分支（Future Feature Prediction） | 编码"目标状态" | 引入 K=16 个可学习 `<Foresight>` Token，经 MAE 解码器重建 EMA 教师视觉编码器对终态帧的输出特征 |
| 未来条件跨注意力（FCCA） | 耦合二者 | 以零初始化的 8 头 MHA，把未来表征注入视觉 Token，使运动预测"锚定"于目标状态 |

### 2.2 关键公式与损失

- **Flow Matching 动作损失**（沿用 π0 思路）：
$$\mathcal{L}_{\text{action}} = \mathbb{E}_{\tau, x_0, x_1}\left[\|v_\theta(x_\tau, \tau, c) - (x_1 - x_0)\|^2\right]$$
其中 $x_\tau=(1-\tau)x_0+\tau x_1$，$\tau\sim U[0,1]$。

- **点跟踪损失**（位移 + 可见性 + 平滑）：
$$\mathcal{L}_{\text{track}} = \mathcal{L}_{\text{disp}} + \mathcal{L}_{\text{vis}} + \lambda_{\text{smooth}}\mathcal{L}_{\text{smooth}}$$
  - $\mathcal{L}_{\text{disp}}$：可见性加权的 L2 位移误差；
  - $\mathcal{L}_{\text{vis}}$：BCE 可见性分类；
  - $\mathcal{L}_{\text{smooth}}$：对预测轨迹二阶时间差分 $\Delta^2 \hat d_{n,t}$ 的 L2 正则，抑制突变。

- **前瞻特征损失**（余弦相似度重建 EMA 教师特征）：
$$\mathcal{L}_{\text{foresight}} = 1 - \frac{1}{M}\sum_{i=1}^M \frac{\hat z_i \cdot z_i^\star}{\|\hat z_i\|\|z_i^\star\|}$$

- **FCCA 模块**（残差形式，零初始化输出投影）：
$$\tilde H_{\text{vis}} = H_{\text{vis}} + \text{MHA}(\text{LN}(H_{\text{vis}}), \text{LN}(H_{\text{fut}}), \text{LN}(H_{\text{fut}}))$$
保证训练初期不影响预训练 VLM 特征。

- **总训练目标**：
$$\mathcal{L} = \mathcal{L}_{\text{action}} + \lambda_1 \mathcal{L}_{\text{foresight}} + \lambda_2 (\mathcal{L}_{\text{disp}} + \mathcal{L}_{\text{vis}} + \lambda_{\text{smooth}}\mathcal{L}_{\text{smooth}})$$

### 2.3 输入序列与注意力掩码设计
- **重排**：文本 Token 置于图像 Token **之前**，以保证图像 Token 隐藏态完全条件于语言指令（"目标感知"）。
- **掩码规则**：
  1. 指令 Token：严格因果；
  2. 当前图像 Token：因果 + 看到所有前置指令；
  3. Foresight Token：彼此双向 + 看到全部指令/图像；
  4. 动作 Token：可见所有前置模态（含 Foresight）。

### 2.4 推理
- 全部辅助分支（点跟踪头、FCCA、MAE 解码器、EMA 教师）丢弃；
- 仅额外保留 16 个 `<Foresight>` Token，中位延迟仅增加 9.4 ms、GPU 内存 +0.1 GB。

## 3. 实验设计

### 3.1 基准与场景
- **LIBERO**：4 个子集（Spatial / Object / Goal / Long），每集 10 任务 ×50 演示；评估每任务 20 rollout，动作块长 T=8。
- **RoboCasa GR-1 Tabletop**：24 个桌面 Pick-and-Place 任务，GR-1 人形机器人，1,000 演示/任务（共 24,000），50 rollout/任务，T=16。
- **LIBERO-Plus**：LIBERO 的 OOD 扰动扩展，7 个扰动维度（相机、机器人状态、语言、光照、背景、噪声、布局），共 10,030 实例；**零样本**评估。

### 3.2 对比基线（三组）
1. **通用 VLA/World-Action 模型**：GR00T-N1.5、π0、X-VLA、LangForce、Fast-WAM、LingBot-VA、Cosmos Policy、Spatial Forcing；
2. **未来预测方法**：WorldVLA、DreamVLA、UniVLA、LaRA-VLA、HiF-VLA；
3. **点跟踪/光流方法**：FlowVLA、GeoPredict、JOPAT。

### 3.3 实现细节
- 基座：StarVLA-GR00T；图像 224×224；ViT patch=16；空间合并至 8×8=64 Token；
- K=16 Foresight Token + 48 掩码 Token → 2 层 ViT MAE 解码器；
- EMA 动量 μ=0.999；损失权重 λ₁=0.1、λ₂=0.3、λ_smooth=0.1；
- 模块化学习率：VLM 1e-5，辅助头 1e-4；
- LIBERO 训练 30K 步、batch=12；RoboCasa 训练 100K 步、batch=8。

## 4. 资源与算力
- **硬件**：8×H20 GPU；
- **分布式框架**：DeepSpeed ZeRO-2；
- **优化器**：AdamW（β₁=0.9, β₂=0.95）；
- **训练量**：LIBERO 30K 步、RoboCasa 100K 步；
- **参数开销**（训练时）：VLM 4437.8 M + 动作模型 161.5 M + 前瞻解码器 30.5 M + FCCA 26.2 M + 跟踪投影器 2.6 M + 可见性头 1.3 M = 4660.0 M（比 Vanilla 多 60.7 M，约 +1.3%）；推理时回归 4599.3 M（与基线相同）；
- **推理延迟**：单 H20 + batch=1、1000 次平均：中位 94.3 → 103.7 ms（+9.4 ms），GPU 内存 9.3 → 9.4 GB。

## 5. 实验数量与充分性
- **消融实验**（LIBERO）：基线 / +Future / +Tracking / +Future+Tracking / +Future+Tracking+FCCA，5 列完整对照；
- **设计消融**：点网格密度（8×8 vs 16×16）、Foresight 架构（MAE vs Direct-64）、耦合方式（共享/分离 Token、Shared image、Image+Goal CrossAttn）共 3 组；
- **跨框架迁移**：在 StarVLA-π、StarVLA-OFT 上分别验证；
- **鲁棒性**：LIBERO-Plus 7 个扰动维度 × 多模型对比；
- **跟踪精度定量分析**：ATE-all / ATE-moving / Median TE / Survival@10px 四项指标（10,000 样本）；
- **定性分析**：LIBERO 与 RoboCasa 各自的未来特征、点轨迹、变化热力图可视化；
- **充分性评价**：实验较为系统，覆盖了组件消融、设计选择、跨基座迁移、鲁棒性、定量跟踪精度与定性可视化；**公平性**较好（同基座、同超参、同 rollout 数）；但 RoboCasa 24 任务的逐任务差异较大（如 PnPWineToCabinetClose +3%，PnPCupToDrawerClose 反而 -13%），个别任务呈现波动。

## 6. 主要结论与发现
- **主结果**：
  - LIBERO 平均 98.8%，4 子集（98.4 / 99.6 / 99.4 / 97.6）均高于所列 SOTA 基线（Cosmos Policy / Spatial Forcing / LingBot-VA 等 98.5%）；
  - RoboCasa GR-1 Tabletop 平均 **56.9%**，比 StarVLA-GR00T（47.8%）**+9.1%**，比 GR00T-N1.6（47.6%）高 9.3%；
  - LIBERO-Plus 零样本 80.5%，**与额外预训练的 Abot-M0 持平**，比 StarVLA（74.1%）+6.4%；语言扰动 +5.5%、背景 +0.5% 提升明显。
- **组件必要性**：
  - Future Prediction 与 Point Tracking 任一单独加入均提升基线；
  - 简单多任务合并提升有限，**必须经 FCCA 显式耦合**才能在 LIBERO-Long 上获得显著增益（+1.8%）；
  - 共享 Token 会因梯度冲突导致 Long 任务严重退化（85.8%），证明"分离 Token + CrossAttn"是关键设计。
- **跟踪精度提升**：加入 FCCA 后 ATE-moving 从 3.8 → 2.3 px（-39.5%），Survival@10px 从 78.0% → 95.3%（+17.3 pp）；
- **推理零额外参数**：因所有辅助分支在测试时被丢弃，仅增加 16 个 Foresight Token 的极小开销。

## 7. 优点与亮点
- **问题立意清晰**：精确指出"前瞻缺运动、跟踪缺目标"的对偶缺陷，提出"goal-state anchor + motion path"的统一视角；
- **训练-推理解耦**：辅助模块纯训练时使用，**推理零额外参数**，部署成本极低（+9.4 ms、+0.1 GB），工程友好；
- **稀疏监督高效**：仅 64 个网格点（比密集光流稀疏 4×），单点对单 Token 的几何关联设计简洁；
- **零初始化 FCCA**：保证训练初期不扰动预训练 VLM，缓解灾难性遗忘；
- **可迁移性强**：在 StarVLA-π（+2.2%）、StarVLA-OFT（+1.4%）两种不同动作头（Flow Matching / OFT）下均带来提升；
- **定性证据完整**：可视化同时给出未来特征、点轨迹与变化热力图，三者互为印证。

## 8. 不足与局限
- **2D 表征的根本限制**：跟踪与未来预测均在 2D 图像空间进行，**无法建模 3D 几何与深度**，因此在 LIBERO-Plus 的相机视角与机器人状态扰动上提升有限（Camera 64.0% 与 Cosmos Policy 69.6%、Qwen-RobotManip 70.4% 相比仍有差距）；
- **静态相机假设**：跟踪监督依赖于固定图像坐标，**对相机自身运动（egocentric）鲁棒性不足**（尽管 RoboCasa 定性显示可分离 ego-motion，但未定量验证鲁棒性）；
- **教师开销**：CoTracker-v3 训练时仍需前向计算 10K+ 样本以生成监督，论文未详细报告该部分训练时长与显存；
- **EMA 教师依赖**：未来特征预测的重建目标来自 EMA 视觉编码器，对底层 VLM 预训练质量敏感；
- **超参较多**：λ₁、λ₂、λ_smooth、K、Foresight Token 数、EMA 动量等共同影响性能，论文给出经验值但未做敏感性扫描；
- **任务泛化偏差**：在 LIBERO-Long（+1.4%）等长时任务上仍有 2.4% 以上的绝对差距；RoboCasa 24 任务中部分任务（如 PnPCupToDrawerClose、PnPMilkToMicrowaveClose）出现倒退，提示存在**任务敏感性**；
- **未来工作方向**：作者已指出将引入 **3D 运动预测**以补足几何推理能力。
