## 摘要
世界动作模型（World Action Models, WAMs）通过联合建模动作与未来视觉观测，利用未来场景演化作为物理合理动作生成的密集监督信号，从而改进机器人策略学习。然而，现有 WAMs 的一个常见设计是在推理时显式生成未来视频，这会带来巨大的计算开销，并阻碍实时闭环部署。GigaWorld-Policy 通过一种以动作为中心的范式解决了这一问题：在训练阶段使用未来视觉动态，而在推理阶段仅解码动作。在此框架基础上，我们提出了 GigaWorld-Policy-0.5，一种为更高效的机器人控制而设计的增强型以动作为中心的 WAM。在预训练阶段，GigaWorld-Policy-0.5 采用动作条件世界建模（Action-Conditioned World Modeling, AC-WM）与 WAM 混合训练策略。这加强了视觉动态与机器人动作之间的耦合，并提升了动作表示在下游策略学习中的迁移能力。为了实现高效推理，GigaWorld-Policy-0.5 引入了 Mixture-of-Transformers 架构，将视觉动态建模与动作生成分离到各自的专用专家模块中，从而在仅生成动作的推理过程中减少实际计算量，并在本地 RTX 4090 平台上实现了 85 ms 的推理延迟。此外，我们采用基于智能体的 AutoResearch 流水线来系统性地搜索训练配置，使最优实验方案的发现更加高效，同时减少了超参数调优所需的时间和人工干预。实验与消融研究表明，GigaWorld-Policy-0.5 在保留未来视觉动态训练收益的同时，提升了机器人控制的推理效率。

## Abstract
World Action Models (WAMs) improve robot policy learning by jointly modeling actions and future visual observations, using future scene evolution as dense supervision for physically grounded action generation. However, a common design in existing WAMs is to explicitly generate future videos at inference time, incurring substantial computational overhead and hindering real-time closed-loop deployment. GigaWorld-Policy addresses this issue with an action-centered formulation, where future visual dynamics are used during training while action-only decoding is used at inference time. Building upon this framework, we present GigaWorld-Policy-0.5, an enhanced action-centered WAM designed for more efficient robot control. During pretraining, GigaWorld-Policy-0.5 adopts a mixed Action-Conditioned World Modeling (AC-WM) and WAM training strategy. This strengthens the coupling between visual dynamics and robot actions and improves the transferability of action representations for downstream policy learning. For efficient inference, GigaWorld-Policy-0.5 introduces a Mixture-of-Transformers architecture that separates visual dynamics modeling and action generation into specialized experts, reducing active computation during action-only inference and achieving 85 ms inference latency on a local RTX 4090 setup. In addition, we employ an agent-based AutoResearch pipeline to systematically search training configurations, enabling more efficient identification of optimal experimental setups while reducing the time and manual intervention required for hyperparameter tuning. Experiments and ablations show that GigaWorld-Policy-0.5 preserves the training benefits of future visual dynamics while improving inference efficiency for robot control.

## 2. 方法论

### 2.1 整体框架：以动作为中心的 WAM
- **输入**：当前多视角观测（左/前/右）、本体状态 $s_t$、语言指令 $l$。
- **输出**：动作块 $\hat{a}_{t:t+p-1}$ 及可选的未来视觉观测 $\hat{o}^{comp}_{t+\Delta:t+K\Delta}$。
- **因果掩码**：采用 action-centered 因果掩码——动作 token 可以关注当前视觉、状态和语言，但**不能**关注未来视觉 token；未来视觉 token 可以关注动作 token。这一设计使推理时可完全跳过未来视觉 token，仅保留动作-only 通路。

### 2.2 训练目标：Flow Matching
- 对动作和未来视觉两种模态分别采样不同的 flow-shift 时间步 $\tau_a$、$\tau_v$，构建联合时序向量。
- 通过线性插值构造噪声混合 token $x_\tau$，对应速度场为 $v_\tau = x^1 - x^0$。
- 损失函数为对模型预测速度 $g_\theta(x_\tau, \tau|o^{comp}_t, s_t, l)$ 与 ground-truth velocity 的 L2 回归：
  $$\mathcal{L} = \mathbb{E}_{x^1,x^0,\tau}\|g_\theta - v_\tau\|_2^2$$

### 2.3 关键改进点

- **混合 Action-Conditioned World Modeling（AC-WM）+ WAM 训练**：预训练阶段同时训练"由动作生成未来视觉（AC-WM）"与"联合动作-未来视觉预测（WAM）"两类任务，使动作表征更紧密地耦合视觉动态变化，提升下游策略迁移性。
- **Mixture-of-Transformers（MoT）架构**：
  - **视觉专家**：处理当前及未来视觉 token，建模场景演化；隐藏维 3072、FFN 维 14336。
  - **动作专家**：专注于动作 token 去噪与动作块预测；隐藏维 1024、FFN 维 4096。
  - 通过多模态 self-attention 实现跨模态信息交换，沿用 action-centered 因果掩码。
  - 虽然总参数量增加，但动作-only 推理路径的计算显著降低。
- **参数初始化**：视觉专家用大规模预训练世界模型 GigaWorld-1 初始化，动作专家从视觉专家权重对应维度复制/截断而来。
- **训练流程**：先用超 1 万小时视频预训练的视觉专家 → 在 2K 小时开源+内部机器人数据上进行 robot-data pretraining（含 AC-WM + WAM）→ 在目标机器人轨迹上 post-training。
- **推理加速栈**：KV 缓存（视觉/语言上下文跨去噪步复用）+ `torch.compile` 图编译 + C++ 运行时集成图像预处理、模型执行、KV 管理与动作后处理。

### 2.4 AutoResearch 超参自动搜索
- 由智能体自动完成：候选配置生成 → 短程 1K-step pilot → 验证集评估 → 候选筛选 → 长程训练与最终选择。
