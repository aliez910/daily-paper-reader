## 摘要
机器人操作策略依赖于预训练视觉模型所提供的表征，这些表征要么给出全局场景嵌入，要么给出稠密块网格。两者都将任务相关特征与任务无关特征混在一起。对象中心槽位表征是一种结构化的替代方案：它们将特征分组为少量按对象划分的槽位。我们在 ManiSkill3 PickCube-v1 上测试了这种结构所带来的收益，采用冻结的编码器以及留出种子的评估方式。在固定策略、目标标记、渲染和标定，仅改变编码器的条件下，冻结的对象中心 SPOT 表征（DINO ViT-B/16 + 槽位注意力）达到了 55.0±2.9% 的成功率，比稠密 DINO 全局特征基线（32.6±1.5%）高出 22.4%，且策略的可训练参数量相同，无需对编码器进行微调。仅增加标记数量并无帮助：标记数量多出 16 倍的稠密块网格并未优于全局特征。加入显式的二维空间目标和原生分辨率渲染后，整个系统的成功率提升至 68.7±4.2%，略低于特权三维信息上界（71.7±4.1%）。随后，自动化运动学失败分类法将空间精度（Near-Miss）失败与目标跟踪（No-Grasp）失败区分开来：空间定位可减少 Near-Miss 失败，但对 No-Grasp 失败无影响。相同的分类法可迁移到更困难的 StackCube-v1，并指出遮挡是主要瓶颈所在。

## Abstract
Robotic manipulation policies rely on pre-trained vision models that give either a global scene embedding or a dense patch grid. Both mix task-relevant and task-irrelevant features. Object-centric slot representations are a structured alternative: they group features into a few per-object slots. We test what this structure buys on ManiSkill3 PickCube-v1, with a frozen encoder and a held-out-seed evaluation. Holding the policy, goal token, rendering, and calibration fixed and changing only the encoder, a frozen object-centric SPOT representation (DINO ViT-B/16 + Slot Attention) reaches 55.0$\pm$2.9% success, 22.4% above a dense DINO global-feature baseline (32.6 $\pm$ 1.5%), with the same trainable policy and no encoder fine-tuning. More tokens alone do not help: a dense patch grid with 16x the tokens performs no better than the global feature. Adding an explicit 2D spatial goal and native-resolution rendering raises the full system to 68.7$\pm$4.2%, just below a privileged 3D-oracle upper bound (71.7$\pm$4.1%). An automated kinematic failure taxonomy then separates spatial-precision (Near-Miss) failures from object-tracking (No-Grasp) failures: spatial grounding reduces Near-Miss while leaving No- Grasp unchanged. The same taxonomy transfers to the harder StackCube-v1 and points to occlusion as the main bottleneck.

# 论文总结：面向视觉运动模仿学习的对象中心表征

## 1. 核心问题与研究动机

- **核心问题**：机器人视觉运动模仿学习严重依赖预训练视觉编码器所产生的表征，但现有表征方式存在结构性缺陷：
  - **全局嵌入**（如 DINO 的 [CLS] token）：将整张图像压缩为单一向量，容易混入与任务无关的场景统计共现线索（如背景纹理），在训练分布内成立，遇到未见过的物体/目标位姿时即失效。
  - **密集 patch 网格**：保留空间细节，但缺乏对象级别的归纳偏置，token 之间相互纠缠，且 token 数增多并不必然带来泛化。
- **关键假设**：作者认为需要的是**表征结构（inductive bias）**的改进，而非参数容量的增加。沿用了近期基础模型研究的"捷径学习"观察（lazy aggregation、scan-pattern bias、gaze regression 等），将同样的现象迁移到视觉运动模仿领域。
- **总体含义**：通过受控对比实验，回答"在冻结编码器、固定策略的前提下，单纯改变视觉表征的结构能否显著提升对新位姿的泛化能力"。

## 2. 方法论

### 2.1 整体框架
- 两台 RGB 相机（base + side，224×224）独立编码 → 冻结 SPOT 编码器 → 14 个对象槽位（每相机 7 个）→ 与本体感知、目标、可学习 action token 拼接为 17 token 序列 → 8 层 8 头因果 Transformer（GPT/minGPT）→ 3 层 ReLU MLP 输出 10 步动作 chunk。
- 时间窗口 T = 5，连续 85 个 token。

### 2.2 冻结 SPOT 编码器
- **主干**：DINO ViT-B/16，冻结。
- **后接**：SPOT 的 Slot Attention 模块，将每视图 196 个 patch token 压缩为 K = 7 个对象槽位 S ∈ ℝ^(7×256)（K=7 来自 SPOT 公开 checkpoint，未调节）。
- **核心机制**：槽位维度上的 softmax 竞争，迫使每个 patch 强激活至多一个槽位，从公式 (1)-(2) 体现：

$$M_{i,j} = \frac{k(X_i) \cdot q(S_j)}{\sqrt{D}}, \quad W_{i,j} = \frac{\exp(M_{i,j})}{\sum_{l=1}^{K}\exp(M_{i,l})}$$

$$S^{(t)} = \mathrm{GRU}(S^{(t-1)}, W^\top v(X))$$

- **关键特性**：这是一个**容量受限的竞争型瓶颈**，使表征无法退化为全局统计，迫使容量分配给对象级区域。

### 2.3 Token 构造与目标条件
- 17 token/帧 = 14 视觉槽位 + 1 本体（7-DoF 关节位置经 MLP）+ 1 目标 + 1 learnable action。
- **三种目标条件**（用于消融）：
  - **Pure Visual**：无目标 token；
  - **2D Spatial Projection**：将 3D 目标经相机内外参投影到像素坐标 $g = [u_b, v_b, u_s, v_s]$，归一化后经 3 层 MLP 编码；
  - **3D Oracle**：来自仿真器的真值 3D 世界坐标（特权上界）。
- 注意 2D projection 使用仿真器真值目标位置，非自监督。

### 2.4 多视角融合策略
- 默认**直接 token 拼接**（将 14 个槽位 token 直接放入序列）。
- 消融对比 **双向交叉注意力**融合模块。

### 2.5 失败分类法（Kinematic Failure Taxonomy）
- 完全基于运动学量（不依赖视觉）：action variance、is_grasped flag、TCP-to-goal 距离。
- 互斥的 5 类，按优先级判定：**Idle → No Grasp → Drop → Near Miss（< 0.1 m）→ Unknown**。
- 编码器无关、可跨任务复用。

## 3. 实验设计

### 3.1 仿真器与任务
- **仿真器**：ManiSkill3（deterministic physx_cpu 后端）。
- **主任务**：**PickCube-v1**（Franka Panda 抓取红色立方体放到随机 3D 目标）。
- **跨任务验证**：**StackCube-v1**（红立方堆到绿立方上，遮挡更严重）。
- **示范数据**：1000 条来自仿真器 motion planner 的专家示范，100% 成功率回放。

### 3.2 评估协议（关键设计）
- **种子划分**：训练用 seed 0–9999，评估用 seed ≥ 10000（不重叠），衡量**对新位姿的泛化**而非记忆。
- **Checkpoint sweep**：每 50 epoch 保存一次，用 200 个留出 episode 扫一遍。
- **最终报告**：最佳 checkpoint 跑 3 次独立稳定性实验 × 300 episodes，报告 mean ± std。
- **过滤**：少于 10 步终止的 episode 视为平凡成功，丢弃。

### 3.3 对比方法（Representation Baselines，全部使用相同策略与目标 token）
| 配置 | Token 数 | 备注 |

| DINO Global [CLS] | 2 | 全局基线 |

## 6. 主要结论与发现

1. **结构 > 容量**：在所有条件受控的情况下，14 token 的对象中心 SPOT 比 32 token 的 DINO 4×4 patch 网格与 2 token 的 DINO Global 均显著更高（**55.0% vs 31.7% vs 32.6%**）。
2. **绝对差距**：冻结对象中心表征比全局密集基线**高 22.4 个百分点**。
3. **空间接地效果**：纯视觉 31.0% → +2D 目标近似标定 55.0% → 精确标定 58.7% → 原生 224² 渲染 68.7% → 3D Oracle 71.7%。
4. **融合与时间容量无效**：交叉注意力在训练时表现更好（≈60% vs ≈38.6%），但留出种子都只到 31.0%，**额外参数无法迁移**；时间窗口在 5–40 之间对成功率无影响。
5. **失败模式分离**：空间接地显著降低 Near-Miss（31% → 21% → 2.5%），但 No-Grasp 几乎不变（15/15/24 per 200），说明两类失败需不同修复方案。
6. **跨任务诊断**：StackCube-v1 上 No-Grasp 占 72%（vs PickCube 7.5%），主因是机械臂遮挡下 SPOT 无时序槽位记忆，**指出遮挡是关键瓶颈**而非空间精度。

## 7. 优点与亮点

- **问题定位精准**：在已有大量"换更大模型 / 更多数据"的工作中，明确提出"瓶颈在表征结构"，并给出可量化的反例（392 token 仍崩溃）。
- **实验设计严谨**：matched-condition + 留出种子 + 多次稳定性 run 的组合在同类工作中较为扎实。
- **跨任务可迁移的失败分类法**：仅靠运动学量就能区分两类瓶颈，是论文的工程亮点。
- **冻结编码器范式**：单 11 GB GPU、无端到端微调即可逼近 3D Oracle 上界，对资源受限的实践者非常友好。
- **连接基础模型捷径学习文献**：将视觉运动模仿放在与 ViT 分类、3D 感知、gaze estimation 一致的"低代价线索 + 结构性修复"叙事中。

## 8. 不足与局限

- **SPOT 无时序记忆**：直接导致 StackCube-v1 上的 72% No-Grasp 失败，作者承认这一架构局限是主因。
- **融合对比缺乏完整性**：交叉注意力 vs 拼接的实验**仅在无目标 token 下进行**，无法排除"在有空间锚点时交叉注意力可能重新发挥作用"。
- **2D 投影依赖仿真器真值**：并非自监督方案；论文承认"从槽位掩膜反推目标"留作未来工作。
- **标定精度敏感**：近似与精确内外参之间有 +3.7% 差距，实际部署仍需相机标定。
- **仿真单一**：仅 ManiSkill3 仿真，未涉及真实机器人、复杂背景、光照变化等（与 Chapin 等关于视觉分布偏移的工作形成互补而非替代）。
- **K=7 不可调**：来自 SPOT 公开 checkpoint，未对槽位数做消融。
- **token 数对比受限**：14×14 dense 因显存被迫 T=1, H=1，无法给出"纯 token 数量"的纯净对比。
- **训练数据量固定**：仅 1000 条示范，未考察数据规模对表征选择结论的影响。
- **训练成功率读数粗糙**：部分消融依赖训练日志近似值（"read off during training"），并非受控的指标。
