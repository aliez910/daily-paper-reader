## 摘要
视觉-语言-动作（VLA）模型旨在理解自然语言指令与视觉观测，并作为具身智能体生成并执行相应动作。近年来，基于自回归的token化动作生成推动了众多代表性VLA模型的发展。然而，该范式通常将动作生成简化为下一token预测，从而缺乏对动作序列时空结构的显式建模，以及视觉-语言表征与动作之间的解耦，这在长时序和复杂场景中会限制性能。本文提出TS-Mask VLA，一种面向机器人操作的视觉-语言-动作框架。TS-Mask VLA基于两个核心设计构建：（1）配备桥接注意力条件桥的离散扩散动作专家，可实现来自VLM的多层条件注入，从而生成更准确、更稳定的动作；（2）针对离散动作token的二维时空掩码策略，强化模型对跨时序依赖与维度间耦合的理解，生成结构更加一致的动作序列。我们在仿真基准与真实世界任务上进行了大量实验。在LIBERO上，TS-Mask VLA仅以0.5B参数即取得95.7%的平均成功率，显著优于参数量更大的模型。在CALVIN上，其取得了4.19的最佳平均序列长度和强大的长时序性能。综合分析与消融实验进一步验证了我们设计的有效性。

## Abstract
Vision-language-action (VLA) models aim to understand natural-language instructions and visual observations, and to generate and execute corresponding actions as embodied agents. Recently, autoregressive token-based action generation has driven the development of many representative VLA models. However, this paradigm often reduces action generation to next-token prediction, thereby lacking explicit modeling of the spatiotemporal structure of action sequences and the disentanglement between vision-language representations and actions, which can limit performance in long-horizon and complex scenarios. In this paper, we propose TS-Mask VLA, a vision-language-action framework for robot manipulation. TS-Mask VLA is built upon two key designs: (1) a Discrete Diffusion Action Expert equipped with a Bridge Attention conditioning bridge, which enables multi-layer conditioning from the VLM and facilitates more accurate and stable action generation; and (2) a temporal-spatial 2D masking strategy for discrete action tokens that strengthens the model's understanding of cross-time dependencies and inter-dimensional coupling, leading to more structurally consistent action sequences. We conduct extensive experiments on simulation benchmarks and real-world tasks. On LIBERO, TS-Mask VLA achieves a 95.7 percent average success rate with only 0.5B parameters, outperforming significantly larger models. On CALVIN, it attains the best average sequence length of 4.19 and strong long-horizon performance. Comprehensive analyses and ablations further validate the effectiveness of our design.

# TS-Mask VLA 论文总结

## 1. 核心问题与研究动机

- **研究背景**：视觉-语言-动作（VLA）模型将视觉感知、语言理解与动作生成统一在同一框架中，是实现指令驱动机器人操作的关键路径。目前主流 VLA 范式分为两类：
  - 自回归 Transformer（如 OpenVLA、RT-2）：将视觉、语言、动作统一为单一 token 序列，顺序预测下一 token；
  - 连续扩散（如 π0、Diffusion Policy）：在欧氏空间中迭代去噪生成连续轨迹。
- **核心痛点**：
  - 自回归范式缺乏对动作序列**时空结构的显式建模**，且表征学习与控制策略之间缺乏解耦；
  - 连续扩散在长时序任务中易出现不稳定，且难以显式建模动作的时-空相关性与维度间耦合；
  - 现有方法在**长时序复杂任务**上表现受限。
- **关键观点**：
  - 需将视觉-语言表征**桥接到专用动作专家**，实现清晰的解耦；
  - 需对动作**离散化并显式建模结构化依赖**，增强复杂环境下的鲁棒泛化。

## 2. 方法论

### 2.1 整体架构
由三大组件构成：
1. **VLM 主干**：Qwen2.5-0.5B，融合 SigLIP+DINOv2 视觉特征与文本指令，输出多层隐藏态 H = {H⁽ˡ⁾}ₗ₌₁ᴸ；
2. **离散扩散动作专家（Discrete Diffusion Action Expert）**：L 层与 VLM 对齐，通过 Bridge Attention 注入多层条件；
3. **时空二维掩码模块**：在 T × D 的离散动作网格上施加结构化掩码。

### 2.2 Bridge Attention 桥接块
单次注意力计算内融合三条信息流：
- **Self tokens**：当前动作表征，建模动作内部时序依赖；
- **AQ tokens**：来自 VLM 的 Action Query 特征，提供面向动作的条件信号；
- **Task tokens**：VLM 中的视觉-语言特征，提供外部任务约束。

具体计算：
- 共享 query Q 由当前动作特征经线性投影得到；
- 三条流各自生成 K、V，经独立 MLP 投影后拼接；
- 注意力权重 α = softmax([QK_selfᵀ, QK_AQᵀ, tanh(g)·QK_taskᵀ] / √dₕ)，其中 g 为可学习门控标量，缓解早期训练中任务条件过强的问题；
- 各分支独立施加 RoPE 以保留位置结构；
- 输出经线性投影与残差连接后送入 FFN。

### 2.3 动作离散化（Uniform Quantized Tokenization）
- 将每个归一化动作标量 âᵢ ∈ [-1, 1] **均匀量化为 V = 256 个 bin**（与 VQ-VAE 不同，避免过度压缩时空信息）；
- 量化后的 token 序列 q ∈ {0,...,255}^M 被重塑为 **T × D 二维网格**，T 为时间帧数，D 为动作维度；
- 解码时取 bin 中心恢复连续动作。

### 2.4 时空二维掩码策略（T×D 结构化扰动）
- 掩码比例由余弦调度 r = cos(πt/2) 控制；
- **两阶段掩码**：
  - **时间掩码阶段**：随机选中 round(r·T) 个时间帧，整帧所有 D 个维度同时掩码 → 强化跨时间依赖建模；
  - **空间掩码阶段**：对未被整帧覆盖的剩余帧，随机选 round(r·D) 个 token 掩码 → 增强帧内维度耦合；
- 损失仅在两阶段掩码位置的并集上计算。

### 2.5 训练与推理
- **训练损失**：L_mask 为标准交叉熵，仅计算在掩码位置上；引入 **Step Unroll Loss L_unroll**，在第一次前向后将高置信度预测回填，再次预测剩余掩码位置，缓解训练-推理偏差；总损失 L = (L_mask + λ·L_unroll)/(1+λ)。
- **推理流程**：
  - 从全掩码 token 序列 t₀ 开始；
  - 经 I 轮迭代，每轮采样 token 分布并计算置信度；
  - 通过 ReMask 策略对最低置信度的 mᵢ = ⌈γ(i/I)·|Ωᵢ|⌉ 个 token 重新掩码，其中 γ 为余弦调度；
  - 随 i 增大，γ 减小，实现**由粗到精的渐进细化**；
  - 最终 token 经动作 detokenizer 解码为连续动作。

## 6. 主要结论与发现

- **LIBERO**：以 0.5B 参数取得 **95.7% 平均成功率**，超越 FlowVLA（8.5B）7.6%、π0（3B）1.5%；长时序任务上较 GR00T N1 提升 1%；

## 7. 优点与亮点

- **方法创新性**：
  - 将离散扩散范式引入 VLA 动作生成，与传统自回归/连续扩散形成差异化定位；
  - Bridge Attention 在一次注意力内融合 Self/AQ/Task 三流，配合可学习门控 g，机制简洁；
  - **多层 VLM 隐藏态按层对齐注入**，兼顾低层几何特征与高层语义；
  - **T × D 二维掩码**提供显式的时空归纳偏置，弥补 1D 随机掩码的结构盲目性；
  - **均匀量化（256 bins）替代 VQ-VAE**，避免过度压缩，保留细粒度时空信息；
- **工程实用**：仅 0.5B 主干 + 单卡 4090 即可完成训练，部署门槛低；
- **多场景验证**：仿真（LIBERO+CALVIN）+ 真实世界（UR5e）三层验证链较为完整；
- **统一损失设计**：L_mask + L_unroll 直接缓解训练-推理不一致，无需额外辅助任务。

## 8. 不足与局限

- **算力与扩展性**：仅在 RTX 4090 单卡、资源受限场景下验证，未探索更大模型规模与更多训练资源下的性能上限；
- **消融不充分**：
  - 缺少 Bridge Attention 三流（Self/AQ/Task）独立贡献的消融；
  - 未对量化 bin 数 V、动作块长度 T、推理步数 I、γ 调度曲线等关键超参进行系统研究；
  - 未对比不同 VLM 主干（仅 Qwen2.5-0.5B）或不同视觉编码器组合的影响；
- **真实世界实验偏弱**：仅 3 类任务 × 20 次试验，任务多样性、扰动鲁棒性、跨物体泛化等评估不充分；

- **可复现性**：训练时长、超参完整配置（除 λ 外）未充分披露，可能影响复现；
- **泛化风险**：未在更多机器人本体（如双臂、移动操作平台）或更复杂场景（遮挡、动态干扰）下验证。
