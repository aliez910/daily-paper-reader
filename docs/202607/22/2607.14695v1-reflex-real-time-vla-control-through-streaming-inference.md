## 摘要
流匹配视觉-语言-动作（VLA）模型有望实现精确的连续控制，但其迭代去噪特性与实时机器人存在根本性的不兼容：全局时间步注入会破坏键值（KV）缓存机制，使得不得不在缓慢的 $O(N^2)$ 重计算与数学上不正确的缓存复用之间进行取舍。我们提出了 **Reflex**，一个通过利用**时间步不变性**（即感知编码器在功能上独立于去噪循环）来实现流匹配策略**实时流式推理**的框架。Reflex 将注意力上下文划分为静态区域、滑动区域和动态区域，从而能够在固定输入下进行 $O(1)$ 增量缓存更新，同时保持与全批次等效的注意力输出。为确保在连续高频推理下的稳定性，我们引入了 **AdaRMSNorm**——一种通过流相位门控来防止 BFloat16 数值崩溃的自适应归一化层。此外，我们通过一个**异步流水线**将视觉编码与动作生成解耦，并结合**算子融合**降低内核开销，从而最大化吞吐量。在 LIBERO 和 Kinetix 基准测试中，Reflex 实现了 2.58 倍的推理加速和 50Hz 的稳定流式输出，将反应延迟降低了最多 54%，且在不影响性能的前提下实现了高效部署。

## Abstract
Flow matching Vision-Language-Action (VLA) models promise precise continuous control, but their iterative denoising nature introduces fundamental incompatibilities with real-time robotics: global timestep injection invalidates KV-caching, forcing a choice between slow $O(N^2)$ re-computation or mathematically incorrect cache reuse. We present \textbf{Reflex}, a framework that enables \textit{real-time streaming inference} for flow matching policies by exploiting the \textit{Timestep-Invariance Property} -- that perception encoders are functionally independent of the denoising loop. Reflex partitions the attention context into static, sliding, and dynamic regions, enabling $O(1)$ incremental cache updates while preserving full-batch-equivalent attention outputs for fixed inputs. To ensure stability under continuous high-frequency inference, we introduce \textit{AdaRMSNorm}, an adaptive normalization layer that prevents BFloat16 numerical collapse by gating on flow phase. We further maximize throughput through an \textit{async pipeline} that decouples visual encoding from action generation, combined with \textit{operator fusion} that reduces kernel overhead. On LIBERO and Kinetix benchmarks, Reflex achieves a 2.58$\times$ inference speedup and 50Hz stable streaming, reducing reaction latency by up to 54\% and enabling efficient deployment without performance degradation.

# Reflex 论文总结：基于流式推理的实时 VLA 控制

## 1. 核心问题与研究动机

- **控制-推理频率鸿沟**：机器人操作需要 50–100 Hz 的控制频率，而当前最先进的 VLA（Vision-Language-Action）模型单次推理需 100–200 ms，存在一个数量级的频率差距。
- **流匹配模型的特殊矛盾**：基于流匹配（Flow Matching）的 VLA 模型虽然能生成更精确的连续动作，但其迭代去噪过程在每一步都注入全局时间步（timestep）条件，导致 KV 缓存中的键值对在每步去噪后即失效。
- **缓存两难困境**：要么放弃缓存进行 $O(N^2)$ 的全量重计算（过慢），要么复用数学上错误的旧缓存（结果崩塌）。现有方法如 VLA-Cache、VL-Cache、ActionFlow 等未能解决"时间步破坏缓存"这一根本问题。
- **同步阻塞的代价**：标准推理为"观察→推理→执行"的串行模式，机器人在推理期间必须冻结。在抓取移动目标等动态场景中，推理完成后目标已移位，造成反应延迟与任务失败。
- **核心洞察**：瓶颈不在于单次计算速度，而在于同步等待造成的系统空转。需采用异步流式架构让机器人"边想边动"。

## 2. 方法论

### 2.1 总体架构
Reflex 将 VLA 推理重构为两条并行执行的流水线：
- **Vision Stream（视觉流）**：在独立线程中以 10–30 Hz 连续编码观测，将 KV 对写入共享 Ring Buffer。
- **Policy Stream（策略流）**：在另一线程中以 50 Hz 通过动作专家 + 流匹配去噪器消费缓存，生成动作块。

### 2.2 关键技术

**（1）时间步不变性（Timestep-Invariance Property）**
- VLA 模型普遍采用"重型 VLM backbone + 轻量级动作专家"的两段式架构。VLM backbone 的感知编码器在功能上独立于去噪时间步 $t_k$（即 $\partial \text{Enc}/\partial t_k = 0$），而动作专家接收 $t_k$ 作为条件。这一性质是缓存分区的理论依据。

**（2）分区注意力（Partitioned Attention）**
- 将上下文划分为三个语义区域：
  - **静态前缀（Static Prefix）**：系统指令 token $\ell_{1:L}$，仅计算一次并永久固定。
  - **滑动历史（Sliding History）**：最近 $N$ 帧视觉观测 $o_{t-N:t}$，采用 FIFO 队列淘汰最旧帧（默认 $N=10$）。
  - **动态后缀（Dynamic Suffix）**：流状态 $x^{(k)}$ 与时间步嵌入，每个去噪周期重置。
- 注意力公式：

$$\text{Attn}(x^{(k)}) = \text{Softmax}\left(\frac{Q^{(k)}[K_{\text{pin}}; K_{\text{slide}}(t); K_{\text{dyn}}(k)]^T}{\sqrt{d}}\right)[V_{\text{pin}}; V_{\text{slide}}(t); V_{\text{dyn}}(k)]$$

- **理论保证**：在固定观测窗口与固定输入下，分区注意力与全批次注意力输出严格等价（MSE = 0.00），并支持 $O(1)$ 增量缓存更新。论文附录 A.1 给出形式化证明。
- **增量预填充（Incremental Prefill）**：每步仅编码最新一帧图像。
- **手动缓存合并（Manual Cache Merging）**：进入去噪循环前，将静态前缀与滑动历史预合并为连续缓冲区，动态后缀使用预分配张量，消除 `torch.cat` 开销。

**（3）AdaRMSNorm 自适应归一化**
- 公式：

$$\text{AdaRMSNorm}(x, c) = \frac{x}{\text{RMS}(x)} \odot \gamma(c), \quad \gamma(c) = 1 + \text{MLP}(c)$$

- 其中 $c = [\text{time-emb}(t_k), s_t]$ 拼接流时间步嵌入与本体感知状态。
- **数值稳定性保障**：RMS 统计量在 FP32 下计算以避免 BFloat16 下溢，门控 MLP 在 BFloat16 下执行以减少带宽。
- **鲁棒数据类型推断**：运行时探测 backbone 输出投影层（`o_proj`）的实际精度，避免类型不匹配。

**（4）异步流水线与未来状态预测**
- 双线程解耦视觉编码与动作生成，实现 $\tau_{\text{async}} < \tau_{\text{sync}}$。
- **Future-Conditional State Prediction**：将策略条件从过期传感读数 $s_t$ 替换为上一时刻已下达的目标动作 $a_t^{\text{cmd}}$，即 $\hat{s}_{t+\Delta} \approx a_t^{\text{cmd}}$，作为短时动力学的轻量级一阶近似。
- **自适应重叠调度（Adaptive Overlap Scheduling）**：根据实时推理延迟估计所需前探步数 $K$，保证下一个动作块在当前块耗尽时刚好就绪。

**（5）底层系统优化**
- **算子融合**：自定义 CUDA 内核将 Q/K/V 投影融合（WQKV），SwiGLU 中 Gate/Up 投影融合；FlashNorm 单遍计算归一化；FusedAdaLN 融合自适应层归一化与后续线性层。
- **环形缓冲区（Ring Buffer）**：系统初始化时预分配单一连续张量 $B \in \mathbb{R}^{L \times N_{\max} \times H \times D}$，通过指针算术实现 O(1) 访问，零动态分配。

## 6. 主要结论与发现

- **推理加速**：Pi0.5 在 LIBERO 上达 2.58×（135.2 ms → 52.4 ms）；Pi0 达 2.73×，呈规模不变甚至略增趋势。

- **反应延迟**：最多降低 54%（LIBERO-Long, Pi0），平均降低 47–51%。
- **任务性能**：
  - LIBERO 子套件基本与同步基线持平（±0.8%），Long 套件提升 +3.6~4.0%；
  - Kinetix 显著提升 +7.4%（Pi0.5）、+6.7%（Pi0）；
  - 真实机器人 Pick-Place +11pp、Articulated +14pp、Dynamic Recovery +17pp。
- **数值稳定性**：AdaRMSNorm 将稳定步数从 BF16 基线的 120–220 步提升至 >2000 步，无 NaN/Inf 事件。
- **分区注意力正确性**：与全批次注意力 MSE = 0.00，Naive Cache MSE > 1.0 几乎完全失败。
- **跨模型与跨硬件泛化**：SmolVLA（500M）仍获 2.29× 加速；RTX 3090 上仍保持 2.47× 加速比。

## 8. 不足与局限

- **架构适用性受限**：仅适用于感知编码器与时间步解耦的 VLA 架构（如 Pi0 系列）。对统一 DiT 风格（视觉编码器也接收时间步条件）的模型不适用，限制了推广范围。
- **未来状态预测器过于简化**：使用上一时刻指令动作作为未来状态估计的一阶近似（heuristic），非学习型动力学模型。在机器人低层跟踪误差较大时可能失效，论文自陈在 100 ms 前探内 <3 cm 偏差，更长前探下未验证。
- **真实机器人实验规模有限**：仅 3 个任务、每任务 20 回合，论文自陈"旨在验证部署可行性而非完整 sim-to-real 研究"，统计显著性受限。
- **缺乏多样化模型对比**：主要实验集中于 Pi0 家族（Pi0.5、Pi0），仅以 SmolVLA 作为补充。对 OpenVLA、GR00T 等其他主流 VLA 的泛化性未验证。
- **异步调度无形式保证**：论文明确指出异步管线与未来预测仅通过经验指标（延迟、失速率、成功率）评估，未提供与离线策略分布等价性的理论保证，可能存在分布偏移风险。
- **长程鲁棒性未充分压力测试**：AdaRMSNorm 验证 >2000 步稳定，但真实机器人多小时连续运行下的累计漂移问题仍待验证。
- **数据细节缺失**：训练侧数据集组成、是否使用额外数据微调、训练时长/算力均未披露，限制了结果的可复现性评估。
- **效率指标边界条件**：动作块大小 = 50 时有效控制频率仅 19.1 Hz（表 9），需配合块间插值才达到名义 50 Hz，这种"名义 vs 实际"频率差异在文中交代不够突出。
