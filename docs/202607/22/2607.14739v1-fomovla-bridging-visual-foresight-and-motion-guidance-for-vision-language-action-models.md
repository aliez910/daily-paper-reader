## 摘要
视觉-语言-动作（VLA）模型在视觉运动策略学习方面取得了显著成果，但本质上仍然是被动式的，仅将当前观测和语言映射为动作，缺乏对世界动态的显式前向预测。已有的视觉前瞻方法虽能预测未来视觉状态，却缺少显式的运动引导：它们能指明“要去哪里”，却无法说明“如何到达”。我们认为未来特征预测与稀疏点跟踪天然互补：前者提供目标状态，后者刻画通向目标的连续运动路径。为此，我们提出了 FoMoVLA，一个通过联合学习未来特征前瞻与稀疏二维点跟踪，对 VLA 表征施加显式时空监督，从而增强连续动作策略的框架。具体而言，FoMoVLA 引入紧凑的前瞻 token 用于解码未来特征状态，解码稀疏的时序二维点轨迹以建模紧凑的几何运动，并通过一个轻量级的、未来条件化的跨注意力模块将二者耦合，使模型能够在预期状态与点轨迹动态之间进行一致推理。在 LIBERO、RoboCasa GR-1 Tabletop 以及 LIBERO-Plus 上的大量实验表明，该方法取得了当前最优的性能，并展现出强大的零样本泛化能力。项目主页见 https://liauto-research.github.io/FoMoVLA。

## Abstract
Vision-Language-Action (VLA) models have achieved impressive results in visuomotor policy learning, yet remain fundamentally reactive, mapping current observations and language to actions without explicit forward prediction of world dynamics. Existing visual foresight methods predict future visual states but lack explicit motion guidance: they show where to go but not how to get there. We argue that future feature prediction and sparse point tracking are naturally complementary: the former provides the goal state, while the latter captures the continuous motion path toward it. We propose FoMoVLA, a framework that augments VLA representations with explicit spatio-temporal supervision by jointly learning future feature foresight and sparse 2D point tracking, enhancing the continuous action policy. FoMoVLA introduces compact foresight tokens to decode future feature states, decodes sparse temporal 2D point trajectories to model compact geometric motion, and couples both through a lightweight future-conditioned cross-attention module that enables consistent reasoning between anticipated states and point dynamics. Extensive experiments on LIBERO, RoboCasa GR-1 Tabletop, and LIBERO-Plus demonstrate state-of-the-art performance and strong zero-shot generalization. Project page is available at https://liauto-research.github.io/FoMoVLA.

## 一、核心问题与研究动机

- **VLA 模型的局限**：现有的视觉-语言-动作（VLA）模型（如 RT-2、OpenVLA、π0、GR00T 等）本质上是"反应式"的，仅将当前视觉观测和语言指令直接映射为动作，**缺乏对世界动态的显式前向预测能力**，难以建模长时序场景演化与物体交互。
- **现有前瞻方法的不足**：
  - **像素级未来预测**（如 WorldVLA、DreamVLA）保留丰富的场景信息，但包含大量与控制无关的静态内容，造成表征冗余与计算开销过大。
  - **关键帧级未来表示**（如 HiF-VLA、Spatial Forcing）虽更紧凑，但通常仅刻画"目标终态"，无法刻画到达该状态的**连续动态过程**。
- **核心洞察**：作者认为**未来特征预测**与**稀疏点轨迹追踪**天然互补——
  - 前者提供"**要去哪里**"（goal state）；
  - 后者提供"**如何到达**"（motion path）；
  - 二者联合可形成"可行动的前瞻"（actionable foresight），将未来想象真正转化为动作控制信号。

## 二、方法论

### 整体框架

FoMoVLA 在 StarVLA-GR00T 基础之上，新增三个**仅在训练阶段使用**的分支，在推理时全部丢弃，**零参数开销、零额外延迟**：

1. **稀疏点轨迹追踪分支**（Point Tracking）：将图像 token 与可追踪点对齐，预测 2D 点轨迹。
2. **未来特征预测分支**（Future Feature Prediction）：通过可学习的 `<Foresight>` token 解码未来帧的视觉特征。
3. **未来条件跨注意力模块**（FCCA）：将上述两者耦合，使运动预测锚定于未来视觉表征。

### 关键技术细节

#### 1. 输入序列重排与注意力掩码设计
- 将**文本 token 置于图像 token 之前**，确保图像 token 的隐藏状态可被完整语言指令条件化（goal-aware），从而可解码任务相关运动。
- 序列结构为：`Instruction → Current Image → Foresight → Action`。
- 注意力掩码规则：
  - 指令 token：严格因果；
  - 图像 token：对指令因果 + 自身双向；
  - Foresight token：自身双向 + 全程可关注指令/图像；
  - 动作 token：可关注所有前置模态。

#### 2. 点轨迹追踪分支（Section 3.2）
- **稀疏点选取**：ViT 编码 224×224 输入（patch=16）后经空间合并得到 8×8=64 个图像 token，每个 token 对应原图中一个网格查询点（one-to-one 对应）。
- **教师信号**：冻结的 CoTracker-v3 沿动作块（action chunk）跨度内的全部 T 帧追踪，提供归一化位移 $d^* \in \mathbb{R}^{N \times T \times 2}$ 与可见性标签 $v^* \in \{0,1\}^{N \times T}$。
- **对齐头**：从图像 token 隐藏状态 $h \in \mathbb{R}^{N \times d}$ 出发，两个轻量 MLP 分别预测位移 $\hat{d}$ 与可见性 $\hat{v}$。
- **运动损失**：
  $$\mathcal{L}_{track} = \mathcal{L}_{disp} + \mathcal{L}_{vis} + \lambda_{smooth}\mathcal{L}_{smooth}$$
  其中 $\mathcal{L}_{disp}$ 为 L2 位移回归、$\mathcal{L}_{vis}$ 为 BCE 可见性分类、$\mathcal{L}_{smooth}$ 为轨迹二阶差分正则；所有损失均按可见性掩码过滤，避免遮挡点引入噪声梯度。

#### 3. 未来特征预测分支（Section 3.3）
- 在图像/指令 token 后追加 $K=16$ 个可学习 `<Foresight>` token，训练其隐藏状态编码未来帧 $o_{t+T}$ 的视觉特征。
- **EMA 教师**：视觉编码器的影子副本（动量 $\mu=0.999$）为目标帧提供稳定特征目标 $z^* \in \mathbb{R}^{M \times d}$。
- **MAE 解码器**：将 $K=16$ 个 Foresight token 与 $M-K=48$ 个可学习 mask token 拼接后，经 2 层 ViT 解码器（含正弦位置编码）重建 $\hat{z} \in \mathbb{R}^{M \times d}$。
- **余弦相似度损失**：
  $$\mathcal{L}_{foresight} = 1 - \frac{1}{M}\sum_{i=1}^{M} \frac{\hat{z}_i \cdot z^*_i}{\|\hat{z}_i\| \|z^*_i\|}$$
- 推理时仅保留 $K$ 个 Foresight token 加入输入序列，使动作头可通过注意力获取目标视觉状态的显式先验。

#### 4. 未来条件跨注意力模块 FCCA（Section 3.4）
- 核心假设：**运动预测受益于对未来状态的先验认知**——知道未来长什么样，将点轨迹估计约束为"目标条件化的轨迹生成"问题。
- 在视觉特征 $H_{vis} \in \mathbb{R}^{N \times d}$ 提取与位移预测之间插入 FCCA：
  $$\tilde{H}_{vis} = H_{vis} + \text{MHA}(\text{LN}(H_{vis}),\, \text{LN}(H_{fut}),\, \text{LN}(H_{fut}))$$
  其中 MHA 使用 8 头注意力。
- **零初始化**：MHA 输出投影层零初始化，使模块训练初期表现为恒等映射，不扰动预训练 VLM 特征；训练过程中逐步学习注入未来信息。

#### 5. 总体训练目标与推理
$$\mathcal{L} = \mathcal{L}_{action} + \lambda_1 \mathcal{L}_{foresight} + \lambda_2 (\mathcal{L}_{disp} + \mathcal{L}_{vis} + \lambda_{smooth}\mathcal{L}_{smooth})$$
- $\mathcal{L}_{action}$：DiT 动作头的条件流匹配损失（flow matching），动作块长度 $T=8$（LIBERO）或 $T=16$（RoboCasa）。
- 损失权重：$\lambda_1=0.1,\ \lambda_2=0.3,\ \lambda_{smooth}=0.1$。
- **推理**：丢弃所有辅助分支，仅增加 16 个 Foresight token 输入，中位延迟仅 +9.4 ms，GPU 显存 +0.1 GB。

## 六、主要结论与发现

1. **未来特征预测 + 稀疏点轨迹追踪具有强互补性**：单独使用任一辅助目标均能超越 VLA 基线（LIBERO 平均 +1.0–1.3%），二者联合 +2.3%，加入 FCCA 后达 +2.3%。
2. **FCCA 是实现协同的关键**：仅简单相加两个损失（无跨注意力耦合）增益有限（+1.3% vs 单独的 +1.0%），而显式将运动预测条件化于未来表示后方可获得显著增益（+2.3%，尤其在 LIBERO-Long +5.6%）。
3. **稀疏设计优于密集设计**：8×8 网格（64 点，4 倍稀疏）优于 16×16（256 点）；MAE 瓶颈设计（16→64）优于 Direct-64。
4. **解耦 token 设计至关重要**：Foresight 与 Tracking 共享 token 会因梯度冲突导致 LIBERO-Long 下降至 85.8%；分离查询 + 跨注意力是最优耦合方式。
5. **跨框架可扩展性良好**：FoMoVLA 在 StarVLA-π、StarVLA-OFT 上均稳定提升。
6. **零样本 OOD 泛化突出**：LIBERO-Plus 80.5%，特别在语言、背景、噪声扰动上提升显著。

## 七、优点与亮点

- **问题洞察新颖**：明确指出"可行动的前瞻"需同时建模"目标态"与"运动路径"，并以最简洁方式（联合训练 + 跨注意力耦合）实现。
- **训练-推理解耦的工程优雅性**：所有辅助分支（EMA 教师、点追踪教师、FCCA、MAE 解码器、对齐头）仅训练时使用，**推理参数 / 显存零增长**，延迟增加可忽略（9.4 ms）。
- **零初始化 FCCA**：在不破坏 VLM 预训练表征的前提下渐进注入未来信息，是简洁且稳妥的设计。
- **稀疏 + 解耦设计**：8×8 网格 + 紧凑 16 个 Foresight token 兼顾效率与精度，对长时序任务尤为受益。
- **注意力掩码重排**：将文本 token 前置，使图像 token 天然 goal-aware，这一细节对运动解码至关重要。
- **全面的实验覆盖**：固定视角 + 自我中心、零样本 OOD 多维度评估、跨基座扩展性、定性 + 定量证据齐备。

## 八、不足与局限

- **仅 2D 视角相关运动**：作者明确指出当前追踪监督只能建模图像空间中的视图相关运动，**无法捕获动态场景下的 3D 几何**；这是 LIBERO-Plus 在相机 / 机器人状态扰动维度上提升有限（相机 64.0% vs Cosmos 69.6%、机器人状态 62.2% vs Cosmos 51.0% 互有胜负）的根本原因。
- **依赖外部点追踪教师**：使用冻结 CoTracker-v3 生成监督信号，意味着训练时引入额外的预处理开销（虽不计入参数 / 延迟）。
- **EMA 教师更新频率需谨慎**：$\mu=0.999$ 在大数据量下需较长 warm-up，但论文未深入讨论该超参数敏感性。
- **未报告 wall-clock 训练时长与统计显著性**：8×H20 上的实际训练小时数未给出，跨基准对比亦缺少多次种子方差报告。
- **动作块长度固定**：LIBERO $T=8$、RoboCasa $T=16$，未探讨不同动作块长度（如更长 horizon）对未来预测 + 追踪耦合策略的影响。
- **下游应用未验证**：实验限于仿真基准（LIBERO、RoboCasa），未在真实机器人平台部署验证；工业 / 移动操作等场景未涉及。
- **未来工作方向**（作者提及）：将 2D 点追踪拓展至 3D 运动预测，以增强对视角与深度变化的鲁棒性。
