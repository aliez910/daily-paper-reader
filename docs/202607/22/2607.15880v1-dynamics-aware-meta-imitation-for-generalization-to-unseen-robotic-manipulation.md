## 摘要
模仿学习旨在通过大量观察和示教数据为机器人学习技能，因而面临数据稀缺和环境泛化的难题。现有方法主要侧重于对同领域任务进行模仿，难以泛化到未见过的任务。为弥合这一泛化差距，我们提出了**动力学感知元模仿（Dynamics-Aware Meta-Imitation, DAMI）框架**。DAMI 通过集成元学习来构建共享技能空间，使智能体能够快速适应新任务。我们引入了视觉-运动轨迹（Visual-Motor Trajectory, VMT）模块来捕获任务潜在空间中的复杂时空动力学。此外，我们提出了无配对统一任务（Unpaired Unified Task, U2T）模块以融合非结构化的多模态观察。为协调这些表征，我们集成了一种任务条件特征调制（Task-Conditioned Feature Modulation, TCFM）机制，专门用于调制底层三维特征。通过从随机完整参考示教中捕获内在动力学，我们的框架学习的是底层任务逻辑，而非记忆静态线索，从而确保有效的泛化能力。在仿真环境和真实场景中的大量实验表明，相较于现有最优基线方法，我们的方法在已见任务的直接推理以及通过少量样本微调对未见任务的适应方面均表现更优。

## Abstract
Imitation Learning aims to learn skills from extensive observations and demonstrations for robots, so it suffers from data scarcity and environment generalization. The existing methods predominantly focus on imitation from in-domain tasks and consequently struggle with generalization to unseen tasks. To bridge this generalization gap, we propose the \textbf{D}ynamics-\textbf{A}ware \textbf{M}eta-\textbf{I}mitation (DAMI) framework. By integrating meta-learning to construct a shared skill space, DAMI equips agents for rapid adaptation to novel tasks. We introduce the Visual-Motor Trajectory (VMT) module to capture complex spatio-temporal dynamics within the task latent space. Furthermore, we propose the Unpaired Unified Task (U2T) block to fuse unstructured multimodal observations. To coordinate these representations, we integrate a Task-Conditioned Feature Modulation (TCFM) mechanism customized for modulating low-level 3D features. By capturing intrinsic dynamics from a random complete reference demonstration, our framework learns the underlying task logic rather than memorizing static cues, ensuring effective generalization. Extensive experiments in both simulation and real-world settings demonstrate that our approach outperforms state-of-the-art baselines regarding direct inference on seen tasks and adaptation to unseen tasks via few-shot fine-tuning.

# 论文总结：面向未见机器人操作任务泛化的动力学感知元模仿学习（DAMI）

## 1. 核心问题与研究动机

- **数据稀缺问题**：模仿学习（Imitation Learning, IL）依赖大量专家示教，但高质量演示数据采集成本高，限制了其在工厂与服务场景中的实际部署。
- **泛化能力不足**：现有方法主要面向**同域（in-domain）任务**进行训练，易过拟合静态视觉线索与训练任务模式，对**未见（unseen）任务**泛化能力差。
- **少样本适应难题**：传统元学习方法在大幅分布偏移下难以推断新任务动力学；上下文模仿学习（ICIL）又过度依赖视觉相似性，缺乏任务语义理解。
- **3D 扩散策略的困境**：扩散策略建模能力强但依赖密集示教，少样本下对 3D 扩散模型直接微调容易出现过拟合，难以学到可迁移的任务动力学。
- **核心洞察**：从**随机完整参考示教**中捕获**内在动力学**（即"在什么动作下场景如何变化"），而非记忆静态外观，才能实现有效跨任务泛化。

## 2. 方法论

### 2.1 整体框架：DAMI = MAML + 3D Diffusion Policy
- 策略输入：当前点云观测 $O_t$、文本指令 $\ell_i$、完整参考示教轨迹 $\tau_i$；
- 策略输出：$H$ 步动作轨迹 $A_0 = [a_t, \ldots, a_{t+H-1}]$；
- 元学习目标：学习一个**共享初始化**，使智能体能以少量示教快速适应新任务。

### 2.2 关键技术模块

**（1）Visual-Motor Trajectory (VMT) 模块**
- 输入：参考示教轨迹 $\tau = \{(f_{v,t}, a_t)\}_{t=1}^{T}$（视觉特征 + 动作）；
- 先通过可学习线性投影 $\phi_{proj}$ 将视觉特征与动作拼接映射到统一潜空间：
  $$e_t = \phi_{proj}([f_{v,t} \oplus a_t])$$
- 添加可学习时序位置编码，经 Transformer 编码器建模全局时序依赖：
  $$H_{demo} = \text{Transformer}(E + P)$$
- **作用**：联合编码"动作下视觉如何变化"，避免仅依赖静态外观。

**（2）Unpaired Unified Task (U2T) 块**
- 输入：演示 token $H_{demo}$（来自 VMT）、文本特征 $f_{text}$（冻结 CLIP 编码器）、观测-时间步条件 $h_k = \text{MLP}([e_k \oplus f_{obs}])$；
- 使用模态特定的仿射投影（LayerNorm + 线性层）对演示与文本进行对齐；
- 在 U-Net **第一个下采样块**进行 Transformer 融合：
  $$Z_{in} = [e_{demo} + P_{demo} \;\|\; e_{text} + P_{text} \;\|\; h_k]$$
  $$C_{Down_1} = \text{TransformerEncoder}(Z_{in})$$
- 其他 U-Net 块仅使用 $h_k$，降低计算开销；
- **"Unpaired"含义**：参考示教与当前观测无需帧级对齐，只共享任务语义。

**（3）Task-Conditioned Feature Modulation (TCFM)**
- 采用 FiLM（Feature-wise Linear Modulation）机制：
  $$\tilde{h}_j = \gamma_j(c_j) \odot h_j + \beta_j(c_j)$$
- 层级条件：$c_j = C_{Down_1}$（首个下采样块）或 $h_k$（其他块）；
- 保证每层都同时条件于观测与扩散时间步，但仅首块融合演示与文本。

**（4）扩散策略 + 完整 MAML 训练**
- 扩散损失：$\mathcal{L}_{diff} = \mathbb{E}_{k,A_0,\epsilon}\|A_0 - \hat{A}_{0,\theta}(A_k, k, f_{obs}, H_{demo}, f_{text})\|^2$；
- 内层（inner loop）：$\theta'_i = \theta - \alpha \nabla_\theta \mathcal{L}_{diff}(\theta, B^{sup}_i)$；
- 外层（outer loop）：使用 AdamW 对查询集平均梯度更新，包含**二阶导数**（完整 MAML）；
- 线性 warmup + 余弦退火学习率调度；维护 EMA 策略。

**（5）少样本适应流程**
- 新任务初始化自预训练 EMA 策略；
- 每个任务提供 10 条专家示教，迭代 N 步（仿真 200 步、真实 500 步）微调；
- 评估时 Meta-World 每回合随机选一条示教并固定；RLBench 选一条示教跨回合复用。

  - 未见：Push Cube、Stack Cube；
- 每任务 10 次示教（遥操作），10 次评估试验。

### 3.3 对比方法

## 6. 主要结论与发现

### 6.1 仿真结果
- **ML45 基础任务**：DAMI 平均成功率 **79.05%**，远超次优 Mamba 的 50.90%（提升 +28.15 pp）；
- **ML10 基础任务**：DAMI 达 **87.23%**，最优基线 82.13%（DP3）；

### 6.2 真实机器人结果

- DAMI 能避免**动作语义误判（Action Misinterpretation）**问题；

## 7. 优点与亮点

- **方法创新性**：
  - 首次将**完整 MAML** 与 **3D 扩散策略**深度融合，解决高容量模型少样本微调过拟合问题；

  - TCFM 的层级差异化融合策略既保证早期层几何感知，又控制计算开销。
- **实验完整性**：

- **实用价值**：
  - 真实场景适应 < 75 秒（500 步），接近在线部署需求；
  - 在 Object Place 任务上将 DP3 的 10% 提升至 50%，Sweep Cylinder 从 10% 提升至 100%，提升幅度大。

- **未来工作方向**（作者指出）：
