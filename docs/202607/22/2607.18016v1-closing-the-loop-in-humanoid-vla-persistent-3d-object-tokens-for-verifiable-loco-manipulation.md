## 摘要
视觉-语言-动作策略是通用机器人控制的有前景的基础，但长周期人形机器人的运动操控要求机器人将任务物体视为在运动、接触、遮挡和恢复过程中持续存在的物理实体。我们将这一问题研究为物体状态发散：用于调节全身动作的物体状态，可能与用于判定动作是否实现预期物理关系的状态之间存在差异。我们提出了持续物体标记化（Persistent Object Tokenization，POT），该方法通过RGB-D观测维护角色索引的三维物体记录，并将其转换为用于全身动作专家的物体标记。以POT-VLA形式实例化时，相同的物体记录既调节动作生成，又支持几何谓词检查，从而构成一个物体状态既可驱动动作又可验证的闭环执行系统。在宇树G1上，POT-VLA将一个匹配的GR00T-N1.7直接基线在八类真实任务上的成功率从39/80提升至71/80。在与Being-0对齐的外部参考中，POT-VLA在对齐服务任务上取得了44/50的成功率，而Being-0论文报告的成功率为37/50。最大的性能提升出现在需要保持三维空间关系的任务上，这表明以持续物体为中心的状态是实现可验证人形机器人VLA执行的一种有效抽象。

## Abstract
Vision-language-action policies are a promising foundation for general robot control, but long-horizon humanoid loco-manipulation requires the robot to treat task objects as persistent physical entities across movement, contact, occlusion, and recovery. We study this problem as object-state divergence: the object state used to condition a whole-body action can differ from the state used to decide whether the action achieved the intended physical relation. We propose \emph{Persistent Object Tokenization} (POT), which maintains role-indexed 3D object records from RGB-D observations and converts them into object tokens for a whole-body action expert. Instantiated as \emph{POT-VLA}, the same object records condition action generation and support geometric predicate checks, yielding a closed-loop execution system in which object state is both actionable and verifiable. On a Unitree G1, POT-VLA improves a matched direct GR00T-N1.7 baseline from 39/80 to 71/80 successes over eight real-world task families. In an external Being-0-aligned reference, POT-VLA achieves 44/50 successes on aligned service tasks, compared with the 37/50 success reported by the Being-0 paper. The largest gains occur on tasks requiring maintained 3D relations, suggesting that persistent object-centered state is a useful abstraction for verifiable humanoid VLA execution.

# 论文总结：人形机器人 VLA 闭环——用于可验证运动操控的持续三维物体标记

## 1. 核心问题与整体含义

- **研究背景**：视觉-语言-动作（VLA）策略被视为通用机器人控制的有前景基础，但对于长周期人形机器人**运动操控（loco-manipulation）**任务（如"收拾桌面"、"把饮料给我"），机器人必须在行走、抓取、放置、遮挡、失败恢复的全过程中，将任务物体作为持续的物理实体进行寻址。
- **核心问题定义——"物体状态发散（object-state divergence）"**：现代 VLA 策略通常基于当前观测的视觉-语言特征条件化动作，而任务完成度的检查由独立的监控器、谓词层或语言层状态完成。当**用于驱动动作生成的物体状态**与**用于验证动作效果的物体状态**不一致时，会引发过早的子任务切换、错误目标操作或无效恢复。
- **本质原因**：该问题是物理层面的而非纯语义层面——物体在度量化的三维空间中运动、与手或支撑面接触、被遮挡或部分进入容器，因此物体状态需具备**持久性、可操作性、可验证性**三大属性。

## 2. 方法论

### 2.1 核心思想
提出 **Persistent Object Tokenization（POT）**，将 RGB-D 观测提升为**角色索引的 3D 物体记录**，并序列化为一组"持续 3D 物体标记（Persistent 3D Object Tokens）"，同时驱动全身动作专家和几何谓词验证器，从而闭合**维护-动作-观测-验证-恢复**的闭环。

### 2.2 关键技术细节

- **角色索引物体记忆**：对当前活动的类型化子任务 τᵢ，构造 M^{t}_{τᵢ} = {m_e^t | e ∈ E_i}，每条记录包含实体角色（TARGET / DESTINATION / SUPPORT / HANDOVER_PARTNER 等）、图像框、3D 质心与范围、置信度、可见度及关系特征；坐标系为机器人基座坐标系。
- **持续化标记模式（schema）**：默认 K=8 个槽位、F=33 个特征维度；无效槽位用 PADDING 填充并掩码掉，可见度/置信度低时标记为不可靠以触发重新观测。
- **物体标记注入动作专家**：以 GR00T-N1.7 作为动作专家，将 x^t_obj 经 LayerNorm → Linear → GELU → Dropout → Linear 投影后，与学习到的角色嵌入、上下文嵌入结合，得到 Z^t_obj ∈ R^{K×d}。插入到 DiT 动作头自注意力序列 S_t = [Z^t_state, Z^t_obj, Z^t_action]，视觉-语言特征保持编码器隐状态，仅用于交叉注意力。
- **训练与适配**：使用与基础动作专家相同的动作块预测目标，**不增加额外的物体记忆/谓词损失**；训练时演示样本配以由同一角色感知 RGB-D 模式生成的"侧车"标记，梯度同时更新物体标记分支与启用的动作头参数。
- **几何谓词验证与恢复**：谓词定义为 p = ⟨κ, α, op, ν, n⟩（类型、参数、比较算子、阈值/目标值、稳定时间窗）；返回状态 ∈ {in_progress, done, blocked, failed, uncertain}，恢复策略 ∈ {continue, retry, reobserve, reground, replan}。几何谓词优先，可选地辅以 VLM 验证器。

## 3. 实验设计

- **平台与场景**：Unitree G1 人形机器人，搭载 Dex3-1 灵巧手与头部 RGB-D 摄像头，运行于**杂乱办公环境**；桌面工作站承担感知、类型化子任务执行、物体标记投影、谓词监督，机器人本机运行底层手臂与运动控制器。
- **基准任务**：8 类真实任务族、每类 10 次试验——推车运送与放置、薯片盒入灰色筐、两球入筐、三杯堆叠、衣物到洗衣篮、抽屉/托盘放置与关闭、台面分类、近距离饮料交接（合计 80 次试验）。
- **对照方法**：
  - **匹配直接基线**：使用同一 GR00T-N1.7 动作专家、同一躯体、同一运行时，仅禁用持续物体记录、物体标记与几何谓词监督。
  - **外部文献参考**：与 Being-0 论文中报告的对齐服务任务对比（5 类共 50 次试验，非本地复现）。
- **消融与泛化**：
  - 消融变体：直接基线（无 token 无验证器）、仅验证器、仅 POT token、完整 POT-VLA，4 类代表性任务上各 40 次试验。
  - 泛化测试：新颖物体实例、目标位移 20–50 cm/姿态 30°–90° 偏移、干扰物、执行中扰动。

## 5. 实验数量与充分性

- **数量**：主实验 80 次成功/试验（基线 vs POT-VLA）+ 外部参考 50 次 + 消融 4 任务 × 4 变体 × 10 = 160 次 + 泛化 4 场景 × 2 变体 × 10 = 80 次，总计**约 370+ 次真实试验**。
- **公平性**：
  - 主比较为"匹配直接基线"，控制变量严格——同一动作专家、同一躯体、同一运行时与等价任务-语言提示，避免了被新控制器或动作空间差异混淆。
  - 潜在**公平性局限**：外部 Being-0 对比并非本地复现，依赖原论文报告值，存在任务定义、试验协议与环境差异。
- **充分性评估**：
  - 优点：覆盖运输、放置、双手机操作、堆叠、分类、关节体交互、柔性体运输、交接等 8 类异构任务；消融隔离了 token 与验证器两个组件的贡献；泛化测试覆盖实例级、布局级、干扰级与扰动级。
  - 局限：每项仅 10 次（消融 40 次）试验规模有限；缺乏多机器人、多光照、多操作者的扩展验证；无统计显著性检验（如置信区间、p 值）。

## 6. 主要结论与发现

- **主结果**：8 类任务族总计 71/80 vs 39/80（基线），提升约 32 个百分点；Being-0 对齐服务任务 44/50 vs 37/50（论文报告值），提升 7 次。
- **最大增益出现在需维持三维关系的任务**：三杯堆叠（1/10 → 8/10）、双球入筐（5/10 → 9/10）、衣物入筐（3/10 → 9/10）、抽屉/托盘（4/10 → 8/10）。
- **消融发现**：仅 POT token（无验证器）将成功率从 15/40 提升至 31/40，是最大单一贡献；验证器单独作用提升至 22/40；完整 POT-VLA 达 34/40，表明验证器主要捕获 token 条件化未能消除的残余误完成。
- **泛化发现**：对新颖实例、布局偏移、执行中扰动的鲁棒性显著优于基线，干扰物对两者影响较小（8/10 vs 9/10）。
- **失败模式分析**：基线失败主要源于度量物体状态错误（抓取目标不准、堆叠错位、放置出界），而非语义误解；POT-VLA 通过重新观测、重新定位、重试与重规划抑制"无声任务推进"。
- **核心结论**：**持久化、以物体为中心的状态**是实现可验证人形机器人 VLA 闭环执行的有效抽象。

## 7. 优点

- **方法新颖性**：首次将"持续 3D 物体记忆"同时用作**动作生成的条件**与**谓词验证的证据**，真正闭合了感知-动作-验证循环，而非依赖分离的符号/语言层反馈。
- **可控性强的对照设计**：直接基线与 POT-VLA 共享同一动作专家、躯体与运行时，干净地隔离了"共享物体状态环"这一唯一变量。
- **角色索引语义**（TARGET / DESTINATION / SUPPORT / HANDOVER_PARTNER）显式暴露任务语义，比隐式视觉-语言特征更易检视、刷新与共享。
- **轻量验证层**：谓词基于真实测量（非学习动力学模型或模拟器），阈值与稳定窗口由任务类型与机器人标定给出。
- **任务覆盖广**：8 类异构任务族同时覆盖运输、堆叠、分拣、关节交互、柔性体与交接，验证了方法的通用性。
- **恢复动作分层**：从轻量（reobserve、reground）到重量级（replan）的级联响应，提供诊断信号 d_ξ（missing visibility / failed grasp / unstable support 等），便于定位失败。

## 8. 不足与局限

- **依赖外部模块质量**：POT 性能受限于 SAM3 分割、RGB-D 测距、相机标定与动作专家对当前躯体的覆盖度——论文自身亦明确承认这一点。
- **算力与训练披露缺失**：未给出 GPU 类型/数量、训练时长、演示样本量、推理延迟，难以评估工程可行性与资源成本。
- **样本规模偏小**：主实验与消融各任务仅 10–40 次试验，无置信区间或显著性检验，存在偶然性风险。
- **外部对比非本地复现**：与 Being-0 的对比依赖对方论文报告值，存在任务定义、协议与环境差异的混杂变量。
- **谓词仅适用几何关系**：物体类别歧义、交接"接收"等语义条件需借助 VLM 验证器辅助，几何谓词不能完全覆盖。
- **闭环节数与超时管理依赖人工调度**：子任务的超时、重试预算由"类型化子任务"文件预先指定，可能难以泛化到未预先建模的新任务。
- **缺乏与最新全身控制方法的系统对比**：未与 WholeBodyVLA、HumanoidVerse 等近期 3D 扩散策略或 latent VLA 在同一硬件下进行基准比较。
- **应用域限制**：当前框架仍假设已知任务角色集合（K=8）与结构化子任务规约，难以直接开箱处理长尾、未预定义的任务结构。
