## 摘要
类似于人类依次学习新任务的天然能力，具备视觉-语言-动作（VLA）模型的机器人应当拥有终身学习能力，以便在开放世界环境中部署时学习新任务。然而，近期提出的多数终身学习模型要么旨在有效学习当前任务（可塑性），要么旨在保持对先前任务的高准确率（稳定性），而可塑性-稳定性权衡在机器人操作模型中仍未得到很好的解决。为应对这一根本性挑战，我们提出了一种面向机器人操作的缓存高效的终身视觉-语言-动作学习框架（即LifelongVLA），该框架借助双时间尺度适应机制缓解可塑性-稳定性权衡，同时通过缓存高效的重放策略实现低成本的机器人部署。具体而言，我们提出了一个双时间尺度LoRA门控模块，将VLA适应分解为两条轻量化路径：一条用于可塑性的短期适配器和一条用于稳定巩固的长期适配器。这些路径通过任务感知门控进行集成，从而实现对可塑性-稳定性权衡的显式控制。在技能重放阶段，我们提出了一种缓存高效的随机重放策略，无需完整轨迹存储即可保留更为均衡的保留信号。最后，实验表明LifelongVLA优于现有基线，展现出高效的技能扩展、对所学操作行为的稳健保持，以及在xArm机器人上实际部署时对重新训练的更低依赖。

## Abstract
Similar to the natural capabilities of humans to sequentially learn new tasks, robots with Vision-Language-Action (VLA) models should possess lifelong learning ability to learn a new task when deployed in open-world environments. However, most recently proposed lifelong learning models aim to effectively learn the current task (plasticity) or maintain high accuracy on previous tasks (stability), while the plasticity-stability trade-off remains largely unsolved in robotic manipulation models. To address this fundamental challenge, we propose a cache-efficient lifelong Vision-Language-Action learning framework for robotic manipulation (i.e., LifelongVLA), which alleviates the plasticity-stability trade-off with a dual-timescale adaptation mechanism while achieving low-cost robotic deployment with a cache-efficient replay strategy. More concretely, we propose a dual-timescale LoRA gating module to decompose VLA adaptation into two lightweight pathways: a short-term adapter for plasticity and a long-term adapter for stable consolidation. These pathways are integrated via a task-aware gate, enabling explicit control of the plasticity-stability trade-off. In the skill replay phase, a cache-efficient stochastic replay strategy is proposed to preserve more balanced retention signals without full-trajectory storage. Finally, experiments show that LifelongVLA outperforms existing baselines, demonstrating efficient skill expansion, robust retention of learned manipulation behaviors, and reduced reliance on retraining for real-world deployment on an xArm robot.

## 1. 核心问题与整体含义

### 研究背景
- **VLA 模型的部署瓶颈**：现有视觉-语言-动作（VLA）模型（如 RT-2、π0、Octo、OpenVLA 等）大多采用**静态离线训练范式**——在固定技能集上训练一次后部署，无法在开放世界中持续学习新任务。
- **真实环境需求**：实际部署中，新的物体、指令、场景布局和动作分布不断涌现，要求机器人具备**类人的顺序学习能力**。
- **核心矛盾——塑性-稳定性权衡（Plasticity-Stability Trade-off）**：
  - 强可塑性 → 快速学习新技能，但可能覆盖旧行为（灾难性遗忘）
  - 强稳定性 → 保留旧技能，但限制新技能学习
  - 现有方法（SFT、LwF、ER、Info-VLA、AtomicVLA）均未很好解决该权衡
- **额外挑战——回放开销**：全轨迹回放需存储图像密集的回合并反复重新编码旧观测，对大 VLA 主干计算成本极高；扩展式架构则带来路由开销与推理延迟。

### 研究意义
使 VLA 策略能在**冻结大主干**下，以**显式且轻量**的方式平衡新技能学习与旧技能保持，并降低实际部署中的存储与计算成本。

## 2. 方法论

### 整体框架：LifelongVLA
基于冻结的 PaliGemma（Gemma 2B）+ Gemma 300M 连续动作扩散解码器（输出 7D 机器人动作）。提出两个核心模块：

### 模块一：双时间尺度 LoRA 门控（Dual-Timescale LoRA Gating）

**核心思想**：将单条 LoRA 适配路径拆分为"快变（短期）"与"慢变（长期）"两条低秩路径，并在权重空间通过任务感知门控进行组合，从而显式分离可塑性与稳定性。

**关键设计**：
- **短期 LoRA 路径** $\Delta W_{\ell}^{sh,t} = A_{\ell}^{sh,t} B_{\ell}^{sh,t}$：仅用当前任务损失 $\mathcal{L}_{new}$ 更新，学习率 $\eta_{sh}$ 较大，负责快速捕获新技能。
- **长期 LoRA 路径** $\Delta W_{\ell}^{lg,t} = A_{\ell}^{lg,t} B_{\ell}^{lg,t}$：仅用回放损失 $\mathcal{L}_{rep}$ 和蒸馏损失 $\mathcal{L}_{dist}$ 更新，学习率 $\eta_{lg} < \eta_{sh}$，负责巩固旧技能。
- **任务感知共享门控**：门控上下文 $c$ 由**冻结**的 prefix 特征经 stop-gradient 池化得到，避免"门控依赖自身权重"的循环依赖：
  $$\alpha_{\ell}^{t}(c) = \sigma(W_{\ell}^{g} \phi_{\ell}(c) + b_{\ell}^{g})$$
- **权重级组合**（非输出级融合，无需二次前向）：
  $$\Delta W_{\ell}^{t}(c) = (1-\alpha)\Delta W_{\ell}^{sh,t} + \alpha \Delta W_{\ell}^{lg,t}$$
- 门控参数跨当前与回放样本共享，$\alpha \to 0$ 强调塑性，$\alpha \to 1$ 强调稳定性。

### 模块二：缓存高效随机回放（Cache-Efficient Stochastic Replay）

**核心思想**：不存储完整轨迹，而是存储少量 stop-gradient 的 prefix token 作为"旧技能记忆锚点"，回放时用**当前模型**重新计算 suffix，并注入新鲜的扩散变量以生成多样化监督。

**关键设计**：
- **技能级 Prefix 缓存**：每任务最多保留 $c_t = 50$ 个样本，仅存储：
  - Prefix 隐表示 $\bar{h}_{i,t}^{pre} = \text{stopgrad}(h_{i,t}^{pre})$
  - 状态 $s_t^i$ 与动作 $y_t^i$
  - **不存储**：原始图像、语言 token、suffix token、扩散时间、噪声
- **随机回放 + 重算 Suffix**：
  $$\tau' \sim p(\tau),\ \epsilon' \sim \mathcal{N}(0, I),\ \tilde{y}^{rep}_{\tau'} = q_{\tau'}(y, \epsilon')$$
  $$h^{suf,rep}_{j,t} = E_{suf}(s_j, \tilde{y}^{rep}_{\tau'_j}, \tau'_j; \tilde{\Theta}_t(c^{rep}_j))$$
  每个缓存样本可在每步生成多个随机回放实例，提供多样化保留信号。
- **掩码联合目标**：
  $$\mathcal{L}_t = \mathcal{L}_{new} + \lambda \mathcal{L}_{rep} + \beta \mathcal{L}_{dist}$$
  - $\mathcal{L}_{new}$ 与 $\mathcal{L}_{rep}$ 分别按当前/回放样本数独立归一化，避免一方主导。
  - 蒸馏项用上一任务 detached 教师快照 $\bar{F}_{t-1}$ 稳定旧技能预测。

## 3. 实验设计

### 数据集与场景
- **主实验**：LIBERO 基准的 10 个连续技能学习任务（lifeslong manipulation），每个增量步骤引入一个新任务。
- **真实机器人**：5 个任务的 xArm 真实机器人数据流，每任务 50 条训练轨迹 + 50 条评估轨迹。

### 评估指标
- **平均成功率 SR**（Final Average Success Rate）：所有已见任务的最终平均成功率。
- **遗忘率 FOR**：$\text{FOR}_i = \max_{l \in \{i, \ldots, T-1\}} a_{l,i} - a_{T,i}$，取所有旧任务平均。
- **过程级增量准确率** $\text{ACC}_t$：第 $t$ 步时所有已见任务的成功率均值。
- 联合训练（Joint）作为性能上限，**测试时不提供任务标识**。

### 对比基线
| 方法 | 类别 | 年份 |
|------|------|------|
| SFT（sequential fine-tune all）| 朴素顺序微调 | - |
| LwF-LoRA | 输出蒸馏 + LoRA | 2017 |
| ER（Experience Replay）| 情景回放 | 2019 |
| Info-VLA | 信息论正则 | 2026 |
| AtomicVLA | 技能级专家特化 | 2026 |

### 关键超参
$r=16,\ \gamma=16,\ M=500,\ c_t=50,\ \lambda=1.0,\ \beta=0.1$；每任务训练 10,000 步，联合训练 40,000 步。

## 7. 优点与亮点

### 方法设计亮点
- **显式权衡接口**：通过门控 $\alpha$ 直接控制可塑性/稳定性贡献，无需两阶段或多前向传播。
- **权重级 LoRA 融合**：相比输出级融合（需要额外前向），保持单次前向推理。
- **缓存式回放**：仅存 stop-gradient prefix token，避免图像存储与重复重编码，存储与 I/O 开销显著降低。
- **随机重算 suffix + 新扩散变量**：解决"缓存特征陈旧化"问题，单个锚点可生成多样回放实例。
- **冻结主干 + 轻量 LoRA**：避免对大模型的灾难性破坏，便于实际部署。
- **任务标识无关**：符合真实开放世界场景。

### 实验设计亮点
- 涵盖仿真 + 真实机器人两类验证。
- 提供过程级分析（稳定性-可塑性散点图），可视化好。
- 消融清晰，能分别验证 latent replay 与 dual LoRA 的贡献。
- 跨方法在内存、参数量、SR、FOR 上做多维对比。

## 8. 不足与局限

### 作者自陈的局限（Limitations 章节）

### 隐含的局限

- **回放超参敏感性**：$c_t = 50$ 的选择缺乏消融，更小/更大缓存预算下的性能曲线未呈现。
