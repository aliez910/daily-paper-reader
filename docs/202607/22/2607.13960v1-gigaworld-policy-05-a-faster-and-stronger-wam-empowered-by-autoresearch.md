## 摘要
世界动作模型（World Action Models, WAMs）通过对动作与未来视觉观测进行联合建模，利用未来场景演化作为密集监督信号，从而实现基于物理的动作生成，提升机器人策略学习效果。然而，现有 WAM 的一个常见设计是在推理时显式生成未来视频，这带来了显著的计算开销，阻碍了实时闭环部署。GigaWorld-Policy 通过采用以动作为中心的建模方式解决了这一问题：在训练阶段利用未来视觉动态信息，而在推理阶段仅进行动作解码。在此框架基础上，我们提出了 GigaWorld-Policy-0.5，一种面向更高效机器人控制的增强型以动作为中心的 WAM。在预训练阶段，GigaWorld-Policy-0.5 采用动作条件世界建模（Action-Conditioned World Modeling, AC-WM）与 WAM 混合训练策略。该策略加强了视觉动态与机器人动作之间的耦合，并提升了动作表征在下游策略学习中的可迁移性。为了实现高效推理，GigaWorld-Policy-0.5 引入了混合 Transformer 架构，将视觉动态建模与动作生成分离到不同的专家模块中，从而在仅进行动作推理时降低有效计算量，并在本地 RTX 4090 环境下实现了 85 毫秒的推理延迟。此外，我们采用基于智能体的 AutoResearch 流程，系统性地搜索训练配置，从而能够更高效地找到最优实验方案，同时减少超参数调优所需的时间和人工干预。实验与消融研究结果表明，GigaWorld-Policy-0.5 在保留未来视觉动态带来的训练优势的同时，提升了机器人控制的推理效率。

## Abstract
World Action Models (WAMs) improve robot policy learning by jointly modeling actions and future visual observations, using future scene evolution as dense supervision for physically grounded action generation. However, a common design in existing WAMs is to explicitly generate future videos at inference time, incurring substantial computational overhead and hindering real-time closed-loop deployment. GigaWorld-Policy addresses this issue with an action-centered formulation, where future visual dynamics are used during training while action-only decoding is used at inference time. Building upon this framework, we present GigaWorld-Policy-0.5, an enhanced action-centered WAM designed for more efficient robot control. During pretraining, GigaWorld-Policy-0.5 adopts a mixed Action-Conditioned World Modeling (AC-WM) and WAM training strategy. This strengthens the coupling between visual dynamics and robot actions and improves the transferability of action representations for downstream policy learning. For efficient inference, GigaWorld-Policy-0.5 introduces a Mixture-of-Transformers architecture that separates visual dynamics modeling and action generation into specialized experts, reducing active computation during action-only inference and achieving 85 ms inference latency on a local RTX 4090 setup. In addition, we employ an agent-based AutoResearch pipeline to systematically search training configurations, enabling more efficient identification of optimal experimental setups while reducing the time and manual intervention required for hyperparameter tuning. Experiments and ablations show that GigaWorld-Policy-0.5 preserves the training benefits of future visual dynamics while improving inference efficiency for robot control.

## 一、核心问题与研究动机

- **研究背景**：World Action Models（WAMs）通过联合建模机器人动作与未来视觉观测，将未来场景演化作为密集监督信号，用于提升策略学习的物理一致性。然而，现有 WAM 的一个普遍设计是**在推理阶段也需要显式生成未来视频帧**，这带来了沉重的计算开销。
- **关键矛盾**：视频 token 的计算成本远高于动作 token，导致难以满足实时闭环控制（如边缘设备 100ms 量级延迟）的要求；同时，长时域想象生成的误差会逐步累积，反而削弱动作生成质量。
- **本文定位**：在已有 GigaWorld-Policy "动作中心化" 框架基础上，进一步推进"训练时利用未来视觉动态、推理时只解码动作"这一思路，解决动作建模效率与可部署性的进一步权衡问题。

## 二、方法论

### 1. 整体思路
- **动作中心化因果 token 结构**：保留 GigaWorld-Policy 的因果掩码机制——动作 token 仅依赖当前观测、本体状态与语言指令；未来视觉 token 在训练时由动作 token 条件生成；推理时可完全省略未来视觉 token，实现低延迟动作解码。
- **目标函数**：基于 flow matching 框架，对动作与未来视觉分别采样时间步并施加不同的 flow-shift 因子，联合回归速度场：
  - $L = E[\|g_\theta(x_\tau, \tau|o_t, s_t, l) - v_\tau\|^2]$。
- **多视图组合**：左/前/右三路相机按（前视图在上、左/右视图在下）方式拼接成复合观测，作为统一视觉输入（与 Motus 一致）。

### 2. Mixture-of-Transformers（MoT）架构
- **专家拆分**：
  - **Visual Expert**：处理当前与未来视觉 token，建模场景演化的潜空间表示（hidden dim 3072、FFN 14336）。
  - **Action Expert**：专注动作 token 去噪与动作块预测（hidden dim 1024、FFN 4096，更轻量）。
- **跨模态交互**：两个专家通过多模态自注意力互联，整体仍沿用动作中心化的因果掩码；推理时可仅激活动作专家，降低有效计算量。
- **参数初始化**：
  - 视觉专家继承自大规模预训练的世界模型 **GigaWorld-1**（万小时级视频数据预训练）。
  - 动作专家从视觉专家对应权重截取前 n 维进行初始化，对齐维度。

### 3. 训练流程
- **两阶段训练**：
  1. **机器人数据预训练**：使用 2K 小时开源机器人数据（AgiBot World、RDT-1B、RoboMind、AnyPos 等）+ 内部真实机器人数据，注入世界模型先验。
  2. **目标机器人后训练**：在目标真实机器人轨迹上联合优化动作预测与未来视觉动态。
- **混合 AC-WM + WAM 预训练**：在预训练阶段同时进行"动作条件世界建模"（以机器人动作条件预测未来视觉）与标准 WAM 训练，强化"动作→视觉变化"的耦合关系，提升下游策略学习的样本效率。

### 4. 推理加速
- **KV Cache**：自回归动作生成过程中视觉与语言上下文不变，缓存 KV 状态复用。
- **torch.compile**：图编译、算子融合，降低 Python 派发开销。
- **C++ 运行时**：整合图像预处理、模型执行、KV 管理与动作后处理到原生流水线，去除 Python 依赖。

### 5. AutoResearch 自动化超参搜索
- **基于智能体的自动化流程**：自动生成候选配置 → 启动短时试点训练（1K 步）→ 监控验证指标 → 筛选候选 → 扩展到长训练（30K 步）。
- **搜索空间**：学习率（3e-5、4.316e-5、6e-5、8e-5）与 batch size，最终选定 **lr=6e-5，batch size=16**。

## 六、主要结论与发现

- **性能领先**：在 Text Following 任务平均 SR 上达到 **0.85（水果）/ 0.89（物体放置）**，相较最强基线 Motus 分别提升 0.05 与 0.06。

- **AutoResearch 可行**：自动化流水线成功筛出 lr=6e-5、batch=16 的较优配置，并在 30K 步取得最佳验证性能。
