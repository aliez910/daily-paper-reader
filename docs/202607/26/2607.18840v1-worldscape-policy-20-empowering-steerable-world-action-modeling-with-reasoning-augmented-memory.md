## 摘要
世界动作模型（World Action Models，WAMs）通过联合建模视觉状态转移与机器人动作，为机器人操作提供了一种颇具前景的范式。然而，现有 WAMs 受到时间上下文有限、片段级语言监督粒度过粗以及以纯文本条件为主等限制，阻碍了任务进度跟踪与细粒度的语言-视频-动作对齐，同时制约了视觉上下文推理与跨具身迁移能力。本文提出 WorldScape Policy 2.0，一种具有推理增强长短期记忆的可控 WAM。其因果短期视觉记忆以 DiT 预填充的形式提供近期观测，以保留局部交互动态；其长短期事件记忆则将历史 VLM 输出组织为全局历史、局部活跃和事件边界表示，以支持面向进度的检索。检索得到的历史信息对感知进行增强，并与自回归生成的计划令牌相融合，形成用于自主规划的隐式子目标条件；语义强制机制进一步将事件级指令语义注入该潜在规划通路。为建立细粒度的多模态可控性，我们构建了 ManipEvent-5M，一个以事件为锚定的具身预训练数据集，包含近 500 万个事件片段，配齐了动作轨迹、片段级任务指令、子片段级子任务描述、目标图像以及视频演示。上述设计为高层指令的自主规划以及来自细粒度文本、目标图像或视频上下文提示的可控执行提供了统一接口。在仿真平台与真实机器人平台上的实验均表明，该方法在长时域自主规划、细粒度指令跟随以及上下文适应方面具有卓越能力。

## Abstract
World Action Models (WAMs) offer a promising paradigm for robotic manipulation by jointly modeling visual state transitions and robot actions. However, existing WAMs are constrained by limited temporal context, coarse episode-level language supervision, and predominantly text-only conditioning, which hinder task-progress tracking and fine-grained language-video-action grounding while limiting visual-context reasoning and cross-embodiment transfer. In this paper, we introduce WorldScape Policy 2.0, a controllable WAM with reasoning-augmented long short-term memory. Its causal short-term visual memory supplies recent observations as DiT prefill to preserve local interaction dynamics, while its long short-term event memory organizes historical VLM outputs into global-history, local-active, and event-boundary representations for progress-aware retrieval. The retrieved history augments perception and autoregressively generated planning tokens, yielding an implicit subgoal condition for autonomous planning; semantic forcing further transfers event-level instruction semantics into this latent planning pathway. To establish fine-grained multimodal controllability, we construct ManipEvent-5M, an event-grounded embodied pretraining dataset containing nearly 5 million event segments with aligned action trajectories, episode-level task instructions, segment-level subtask captions, goal images, and video demonstrations. These designs provide a unified interface for autonomous planning from high-level instructions and controllable execution from fine-grained text, goal-image, or video-context prompts. Experiments in both simulation and real-world platforms demonstrate superior capabilities in long-horizon autonomous planning, fine-grained instruction following and in-context adaptation.

## 1. 核心问题与整体含义

- **研究背景**：World Action Models（WAMs）通过联合建模视觉状态转移与机器人动作，成为机器人操作领域的重要范式，可作为 VLA 模型的互补方向，提供动作规划与上下文条件适应的天然基础。
- **现有 WAMs 的三大局限**：
  - **缺乏进度感知记忆**：多数方法仅以当前观测或短窗口历史为条件，无法在视觉相似但任务阶段不同的情形下正确推断后续动作；MemoryWAM 等虽扩展了视觉历史，但未显式围绕任务进度组织记忆，也未形成隐式子目标条件。
  - **语言-视频-动作对齐粒度过粗**：具身数据集中同一 episode 内不同片段往往共用同一高层指令，导致模型依赖视觉捷径而非事件级意图-状态-动作的细粒度对齐，对原子动作变化不敏感。
  - **交互接口受限**：现有 WAMs 主要以文本为条件，难以自然表达目标图像、演示视频或跨具身示例等意图，限制了视觉上下文推理与跨本体迁移。
- **整体含义**：论文从"短期视觉上下文 vs. 长期语义事件记忆"两条互补路径入手，旨在把 WAM 从"短时预测器"升级为"长时、可控、可推理"的可操控策略模型。

## 2. 方法论

### 2.1 核心思想

- 提出 **WorldScape Policy 2.0**：一种具备 **推理增强长短期记忆（Reasoning-Augmented Long Short-Term Memory, LSTM）** 的可控 WAM。
- 双分支结构：
  - **因果 DiT 分支**：维护 **短期视觉记忆**（最近若干 chunks 的干净 VAE 潜码）作为 causal prefill 保留局部交互动态；
  - **VLM 推理分支**：维护 **长期事件记忆**（全局历史、局部活跃、事件边界），做进度感知检索并生成隐式子目标条件。

### 2.2 关键技术细节

- **统一动作表示**：每臂动作由 chunk 内首帧相对的 3D 位置增量、连续 6D 相对旋转、绝对一维夹爪命令构成（10 维），双臂拼接为 20 维；flow matching 直接在原始动作空间进行，动作编码器/解码器只做 embodiment 接口。
- **事件级世界动作建模（Event-Grounded WAM）**：
  - 三类提示通过不同通路进入模型：细粒度子任务描述经 T5 编码后通过 cross-attention 控制 DiT；高层指令与当前头视图经 VLM 推理分支生成 memory-enhanced VLM tokens；目标图像与视频演示以 VAE 潜码形式作为持久视觉 prefill。
  - 视觉 prompt 按可用性切换：仅目标图像 / 仅视频 / 两者拼接 / 无。
- **推理增强长短期记忆**：
  - 推理分支输出 `q_t = [u_t; r_{1:K}^t]`，其中 `u_t` 为 VLM prefill 的感知 tokens，`r_{1:K}^t` 为同一 KV cache 续写的 K 个自回归规划 tokens。
  - 历史 chunks 感知 token 经 attention pooling 压缩为固定数量的 gist tokens 后，与规划 token 拼接形成紧凑 history bank。
  - 构造三类记忆视图：
    - **全局历史（Global-History）**：`m_gh` 通过任务嵌入 + 平均 history bank 经 Expand 投影获得；
    - **局部活跃（Local-Active）**：`m_la` 拼接最近 `S_e` 个完整 chunks；
    - **事件边界（Event-Boundary）**：`m_eb` 通过相邻 chunk 余弦距离 `d_j = 1 - cos(q̄_j, q̄_{j-1})` 并以最小时间间隔 Δ 贪心 TopK 选择 `S_b` 个变化最大处。
  - 检索融合：三类记忆与 history bank 拼接后经 cross-attention 检索，再用 token 级 sigmoid gating 调节注入强度 `γ_t`。
- **隐式子目标潜在规划（Implicit Subgoal Latent Planning）**：
  - 训练时通过 **语义强制（Semantic Forcing）** 对齐 latent 推理与子任务语义：`L_sem = 1 - ẽ_s^T ẽ_q`，其中 T5 编码器冻结并 stop-gradient，可训练投影器 φ_q 把 reasoning 投影到 T5 语义空间。
  - 推理阶段模型仅接收高层指令 `y`，通过 `q̂_t` 推断当前子目标。
- **三阶段训练课程**：
  - **Stage 1（事件级多模态 WAM 预训练）**：学习细粒度语言-视频-动作对齐与短期视觉动态，loss `L^(1) = L_act + λ_w L_world`。
  - **Stage 2（记忆感知中间训练）**：引入 VLM 规划分支与长短期事件记忆，加入 `λ_s L_sem`，实现从显式语义到潜在规划的迁移。
  - **Stage 3（下游交互式后训练）**：按任务需求切换自主规划 / 细粒度指令 / 视觉提示三种交互模式。

### 2.3 ManipEvent-5M 数据集构建

- 聚合异源数据：自采 PiPER（45%）、AgiBot World（32.53%）、RoboMIND、RoboCOIN、DROID、自采 UMI、RoboTwin 2.0、LIBERO、EgoDex 等，总计约 **5.12 亿帧、4 982 小时、74.4 万 episodes、约 489 万 event 段**。
- 事件级 schema：`τ = {(o_{t_b:t_e}, a_{t_b:t_e}, y, c_j, p_j^goal, p_j^video)}_j`，将全局任务意图与事件级子目标语义解耦，并保留与视觉-动作的对齐。
- 四阶段层次化标注（Qwen3-VL）：(1) 两阶段标注（机器人状态信号切分 + VLM 语义重新标注）；(2) 层次化帧采样（episode 级 16 帧 + event 级 12 帧）；(3) 具身提示条件（结构化模板约束，强制描述执行末端、目标对象、起止状态等）；(4) 多视角冲突消解（夹爪视角优先）。
- 目标图像 prompt：包括 **第一视角**（与动作同本体终端观测）与 **第三视角**（同任务人类演示终端观测）。
- 视频 prompt：用于人→机、机→机的演示对齐，按全局任务、有序事件序列与终端结果匹配。

- **真机能力显著提升**：在需要长时记忆与跨具身迁移的任务上（Shell Game、积木堆叠）相对 π0.5 与 DreamZero 取得大幅领先。

## 8. 不足与局限

- **资源披露不足**：未给出 GPU 型号/数量、训练总时长、显存占用等关键算力信息，难以复现与评估成本。
- **推理开销**：VLM 推理分支（即便为 4B 轻量模型）+ 视频-动作 DiT + 长短期记忆检索，推理时延与算力代价未量化，落地可行性存疑。
- **真机任务数与试验次数偏少**：仅 5 个真机任务、每任务 20 次试验，覆盖能力维度尚可，但统计显著性较弱；未提供方差/置信区间。
- **公平性细节**：真机任务对 π0.5 做了"时间扩展输入"以求公平，但 VLA 与 WAM 的条件接口本质不同，仍可能存在难以完全对齐的比较偏差；WorldScape Policy 1.0 与 2.0 的消融对比缺乏独立的隔离对比（仅在 RoboTwin 主表中出现）。
- **OOD 评测范围有限**：细粒度 OOD 仅基于桌面清理的物体类别替换，未覆盖指令结构、任务结构、视觉环境等更广义的 OOD 维度。
- **应用限制**：
  - 依赖高质量事件级标注（Qwen3-VL-32B + 多阶段 pipeline），数据构建成本高；
  - 长期记忆默认 8 chunks，更长任务可能需要扩展并重训 gating；
  - 跨具身视频演示依赖任务级对齐与终端结果一致性，对未见任务/不一致演示鲁棒性未深入讨论；
  - 真实部署涉及三阶段训练，工程复杂度较高。
- **偏差与风险**：训练数据中自采 PiPER 数据占比较高（45%），可能引入本体/场景偏好；行为克隆式的目标与流程对失败恢复、分布外纠错的处理有限。
- **安全性与伦理**：真机实验基于双手机械臂，未涉及与人协同、安全约束、故障停机等实际部署中必备的机制。
