## 摘要
视觉-语言-动作策略是通用机器人控制的有前景的基础，但长周期人形机器人运动操作要求机器人在运动、接触、遮挡与恢复过程中将任务物体视为持久的物理实体。我们将这一问题研究为物体状态发散：用于条件化全身动作的物体状态，可能与用于判断该动作是否达成预期物理关系的状态不同。我们提出了持久化物体标记化（POT），该方法从 RGB-D 观测中维护按角色索引的三维物体记录，并将其转化为面向全身动作专家的物体标记。作为 POT-VLA 实例化时，相同的物体记录既用于条件化动作生成，又支持几何谓词检查，从而构成一个物体状态既可操作又可验证的闭环执行系统。在宇树 G1 上，POT-VLA 在八类真实任务中将匹配的直接 GR00T-N1.7 基线从 39/80 次成功提升至 71/80 次成功。在外部 Being-0 对齐参照中，POT-VLA 在对齐的服务任务上取得了 44/50 次成功，而 Being-0 论文所报告的结果为 37/50 次成功。最大幅度的提升出现在需要维持三维关系的任务上，这表明以物体为中心的持久化状态是可验证人形机器人 VLA 执行的一种有效抽象。

## Abstract
Vision-language-action policies are a promising foundation for general robot control, but long-horizon humanoid loco-manipulation requires the robot to treat task objects as persistent physical entities across movement, contact, occlusion, and recovery. We study this problem as object-state divergence: the object state used to condition a whole-body action can differ from the state used to decide whether the action achieved the intended physical relation. We propose \emph{Persistent Object Tokenization} (POT), which maintains role-indexed 3D object records from RGB-D observations and converts them into object tokens for a whole-body action expert. Instantiated as \emph{POT-VLA}, the same object records condition action generation and support geometric predicate checks, yielding a closed-loop execution system in which object state is both actionable and verifiable. On a Unitree G1, POT-VLA improves a matched direct GR00T-N1.7 baseline from 39/80 to 71/80 successes over eight real-world task families. In an external Being-0-aligned reference, POT-VLA achieves 44/50 successes on aligned service tasks, compared with the 37/50 success reported by the Being-0 paper. The largest gains occur on tasks requiring maintained 3D relations, suggesting that persistent object-centered state is a useful abstraction for verifiable humanoid VLA execution.

# 论文总结：POT-VLA —— 面向可验证人形机器人运动操作的持久化三维物体标记

## 1. 核心问题与研究动机

- **研究对象**：长周期人形机器人运动-操作任务（loco-manipulation），即机器人在移动、接触、抓取、放置、遮挡、恢复等过程中持续对同一任务物体进行操作。
- **关键问题**：现有 VLA（视觉-语言-动作）策略中，**物体状态发散（object-state divergence）**——即"用于条件化全身动作的物体状态"与"用于判断动作是否达成预期物理关系的状态"不一致。
  - 动作专家通常基于当前观测的视觉-语言特征隐式地条件化动作；
  - 任务进度则由独立的监控器、谓词层或语言层状态进行检查；
  - 两者之间的不一致会导致：错误目标物体抓取、未完成的子任务提前过渡、错误的成功判定以及低效恢复。
- **核心动机**：物体的状态是**物理的**（在度量三维空间中运动、接触、被遮挡、进入容器），因此需要一种"既可执行、又可验证"的、以物体为中心、跨时间持续的状态表示。

## 2. 方法论

### 2.1 核心思想：Persistent Object Tokenization (POT)
- 在**机器人基坐标系**下维护一组**按角色索引的 3D 物体记录**（role-indexed object memory）；
- 将这些记录**序列化**为 Persistent 3D Object Tokens，作为全身动作专家的输入；
- 同一份物体记忆在动作执行前后被刷新（refresh），既驱动动作生成，又支撑几何谓词验证，形成 **ground–act–refresh–verify–recover** 的闭环。

### 2.2 关键技术细节
- **任务角色记录**：每个子任务 τᵢ 携带一组实体集合 Eᵢ，每条记录 m_e^t 包含角色（TARGET / DESTINATION / SUPPORT / HANDOVER_PARTNER / PADDING 等）、短语、2D 框、3D 质心与尺寸、置信度、可见性以及关系特征。
- **3D 感知流程**：使用 SAM3 给出角色/查询掩码 → RGB-D 反投影到机器人基坐标系 → 工作空间过滤 → 汇总为度量信息（含物体-容器距离、支撑高度、目标-终点位移、对齐、包含、交接线索等）。
- **Token Schema**：K=8 个 slot，每 slot F=33 维特征，padding slot 通过 mask 屏蔽。特征包括：可见性 vₖ、置信度 qₖ、2D 框 bₖ、3D 质心 cₖ、3D 尺寸 sₖ、可选朝向 oₖ、关系特征 ρₖ。
- **动作专家插入方式**：在 **DiT 动作头自注意力序列**中插入物体 token，而非改视觉-语言骨干：
  - 序列布局：Sₜ = [Z_state^t, Z_obj^t, Z_action^t]，视觉-语言特征仍作为 cross-attention 编码器隐藏状态 Z_vl^t。
  - 投影器 f_obj^θ：LayerNorm → Linear → GELU → Dropout → Linear，并加入可学习的角色嵌入与上下文嵌入，可选置信度门控。
- **训练方式**：保留原 GR00T-N1.7 的动作 chunk 预测损失；演示数据附带由同一角色感知 RGB-D schema 生成的物体 token 旁车（sidecar），对物体 token 分支与启用的动作头参数联合微调；不引入额外的物体记忆或谓词损失。
- **谓词监督器**：每个子任务有一组物理关系谓词 Ψᵢ，谓词形式为 p = ⟨κ, α, op, ν, n⟩（类型、参数、运算符、阈值/目标值、稳定性窗口）；监督器状态 ∈ {in_progress, done, blocked, failed, uncertain}；对不可见/低置信/不稳定记录输出 uncertain 并触发再观测。
- **恢复策略**：从 {continue, retry, reobserve, reground, replan} 中选择；本地恢复后再向任务级重规划返回紧凑反馈（如 `object_not_grasped`、`outside_goal_region`）。语义条件不充分时可调用 VLM 验证器，但**几何谓词优先**。

### 2.3 算法流程（文字版）
1. 由 VLM 规划器或人工任务文件给出类型化子任务计划 Π；
2. 在每个 chunk 开始前，POT 基于 RGB-D 与本体感知构造角色索引记忆 M_τᵢ^t，并将其编码为对象 token x_obj^t；
3. 全身动作专家 π_θ 生成候选 chunk ˆa_{t:t+H}，经运行时校验与平滑后执行；
4. 在 t⁺ = t + H 处，用新的 RGB-D 刷新同一记忆为 M_τᵢ^{t⁺}；
5. 几何谓词对 M_τᵢ^{t⁺} 检查子任务完成条件，决定是否继续、重试或触发本地/任务级恢复。

## 3. 实验设计

### 3.1 平台与场景

- **任务族（8 类真实任务，每类 10 次试验）**：

  4. 三个杯子堆叠；5. 衣物放入洗衣篮；6. 抽屉/托盘放置并关闭；

### 3.2 对比方法

- **外部参照**：5 个服务任务 × 10 次 = 50 次（POT-VLA 44/50，Being-0 论文报告 37/50）。

- **泛化测试**：4 种扰动（新物体实例、布局位移 20–60 cm/方向 30–90°、干扰物、执行中扰动）× 2 个系统 × 10 次 = 80 次。
- **客观性评估**：

## 6. 主要结论与发现

- **整体性能**：POT-VLA 在 80 次主试验中取得 71/80 成功，匹配直接基线为 39/80；在 Being-0 对齐的 50 次服务任务中取得 44/50，对照文献报告 37/50。
- **最大增益出现在需要维持 3D 关系的任务上**：杯堆叠（1/10 → 8/10）、两球入筐（5/10 → 9/10）、衣物到篮（3/10 → 9/10）、抽屉/托盘（4/10 → 8/10）、小车运输（3/10 → 8/10）。
- **基线失败模式多为度量级而非语义级**：抓取目标偏移、堆叠对齐错误、分类遗漏小球、放置在容器外等。
- **POT-VLA 的恢复机制**：抓取失败、放区偏移、错误交接等会被识别为 `done/uncertain/failed`，触发再观测、再接地、重试或重规划，而非静默推进。
- **消融结论**：对象 token 条件化是主要贡献（15/40 → 31/40），谓词验证带来进一步增益（→ 34/40）；二者分工是"token 解决大量接地前错误，验证捕获剩余的虚假完成"。
- **泛化结论**：在新物体实例、布局位移、执行中扰动下 POT-VLA 优势最明显（4/10–6/10 → 8/10–9/10），干扰物下两者差距较小。

## 7. 优点

- **问题定位精准**：把长周期 loco-manipulation 的核心瓶颈具象化为"物体状态发散"，并清晰区分语义级与度量级错误。
- **闭环耦合设计**：同一份角色索引 3D 物体记忆既驱动动作专家又支撑谓词监督，避免了"动作条件状态"与"验证状态"分叉带来的不一致。
- **可控的策略侧变量**：在 GR00T-N1.7 骨干与 G1 本体上做最小改动以隔离"共享物体状态环路"的因果贡献，便于归因分析。
- **轻量级接口**：物体 token 在 DiT 动作头自注意力序列中插入而非替换视觉-语言骨干，部署侵入小，schema 明确（K=8、F=33）。
- **谓词层形式化清晰**：以 ⟨κ, α, op, ν, n⟩ 形式显式建模物理关系，并配合诊断 dξ 与本地恢复策略，便于诊断与回溯。
- **真实机器人 8 类任务验证**：覆盖运输、放置、堆叠、分类、铰接体、柔性体与交接等典型场景，差异度较高。

## 8. 不足与局限

- **样本规模较小**：每任务仅 10 次试验，绝对成功率受随机性影响显著，缺乏置信区间或统计显著性检验。
- **外部比较非本地复现**：与 Being-0 的对比并非在同硬件、同协议下完成，存在不可控差异，仅可作为参考。
- **依赖外部感知模块**：SAM3 掩码质量、RGB-D 噪声、相机标定都会影响 POT 记录可靠性；遮挡/低置信度会被标为 `uncertain`，但可能放大误判。
- **算力与训练细节缺失**：未报告 GPU 型号、训练时长、数据规模、对象 token 微调所需样本量等关键信息，复现成本难以估计。
- **谓词与角色仍依赖人工/类型化子任务定义**：阈值、稳定性窗口、角色集合需手工或由 VLM 规划器给出，并非端到端可学习，存在工程化负担。
- **本体覆盖受限**：仅在 Unitree G1 + Dex3-1 上验证，未讨论跨本体迁移能力；G1 本体的动作表达空间亦限制了策略能力上限。
- **泛化测试扰动幅度有限**：布局位移最大仅 60 cm、方向 90°，缺少更大幅度的物体级或环境级扰动。
- **未能显式建模接触动力学**：方法仅记录"测量驱动的物体状态转移流"，不涉及物理引擎或接触力，建模物体形变/堆叠稳定性时存在根本局限。
- **没有学习代价-性能权衡分析**：对象 token 与谓词层带来的额外推理/工程成本与其带来的成功率提升之间的定量权衡未给出。
