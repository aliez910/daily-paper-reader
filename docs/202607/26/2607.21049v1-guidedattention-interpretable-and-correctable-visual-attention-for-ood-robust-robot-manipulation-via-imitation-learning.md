## 摘要
端到端的视觉运动策略几乎无法为人类提供理解或纠正策略视觉注意力的机会。我们提出了GuidedAttention，一个视觉运动模仿学习框架，它将可解释且可纠正的视觉注意力作为一种显式的中间表示。该方法从相机图像中预测与任务相关的注意力关键点，并以此作为条件驱动基于扩散模型的动作策略。用户可以在回滚初始化时检查并选择性地纠正部分关键点，随后由跟踪模块将纠正后的注意力在整个执行过程中自动传播。仿真和真实世界实验表明，GuidedAttention持续提升了机器人操作性能，尤其在位置和外观的分布外（OOD）条件下表现突出。

## Abstract
End-to-end visuomotor policies provide little opportunity for humans to understand or correct the policy's visual attention. We propose GuidedAttention, a visuomotor imitation learning framework that introduces interpretable and correctable visual attention as an explicit intermediate representation. Task-relevant attention keypoints are predicted from camera images and condition a diffusion-based action policy. Users can inspect and optionally correct selected keypoints once at rollout initialization, after which the corrected attention is automatically propagated throughout execution by a tracking module. Experiments in simulation and the real world demonstrate that GuidedAttention consistently improves robot manipulation performance, particularly under positional and appearance out-of-distribution (OOD) conditions.

# GuidedAttention 论文详细总结

## 一、核心问题与研究动机

- **端到端策略的"黑箱"问题**：现有视觉运动模仿学习策略（Diffusion Policy、ACT 等）直接从图像映射到动作，人类无法理解策略究竟在关注图像中的哪些区域，也难以在策略失败时进行干预修正。
- **任务相关视觉线索的缺失**：人类操作者一眼就能定位的关键物体或关键点，策略却必须自主从数据中学习。当任务相关的"简单提示"未被策略捕获时，即使对人类而言显而易见的线索也会导致任务失败。
- **分布外（OOD）泛化瓶颈**：模仿学习策略在训练分布内表现良好，但在物体位置或外观出现分布偏移时性能急剧下降；现有方法要么依赖数据增强（受限于训练时见过的变化），要么依赖鲁棒表示学习，但都缺乏让用户在关键时刻提供任务相关视觉引导的机制。
- **整体含义**：论文主张在"感知"与"动作生成"之间引入一个**显式、可解释、可由用户纠正的中间视觉注意力表征**，让人类可以零成本地在策略失效时"指一下"任务关键位置。

## 二、方法论

### 1. 整体框架 DP-GA（Diffusion Policy with GuidedAttention）
- **输入**：多视角 RGB 图像 + 本体感知关节状态
- **流程**：
  1. 每张图像经过**视觉注意力编码器 AttnEnc** 预测 N_k 个任务相关 2D 关键点及其注意力特征
  2. 注意力特征与本体特征拼接，作为条件送入基于 U-Net 的 CNN 去噪扩散策略
  3. 在回滚初始帧，用户可选择性纠正关键点；之后由 Co-Tracker 自动跟踪传播

### 2. 视觉注意力编码器（AttnEnc）
- **架构**：ResNet-18 骨干提取 patch 特征 → Transformer 编码器（带位置编码）→ Transformer 解码器（可学习查询）→ 线性层映射到 2D 坐标
- **关键公式**：
  - 关键点坐标预测：$p_i = h_\theta(f_i) = A f_i + b$
  - 关键点损失（MSE）：$\mathcal{L}_{kp} = \frac{1}{N_k}\sum_{i=1}^{N_k}\|p_i - p_i^{gt}\|_2^2$
- 注意力特征 $\{f_i\}_{i=1}^{N_k}$ 既用于条件扩散策略，也通过线性映射 $h_\theta$ 显式对应到 2D 坐标，从而可被人类直接观察和修正
- 提供两种变体：
  - **DP-GA (default)**：用注意力特征 $f_i$ 作为条件
  - **DP-GA (coord-as-feat)**：用预测坐标 $p_i$ 作为条件

### 3. 关键点修正机制（Keypoint Override）
- **修正流程**：用户点击图像修正关键点坐标 $\to$ 通过 $h_\theta$ 的逆映射恢复特征 $\to$ 替换预测路径的特征
- **关键技术一**：前向-逆向权重共享。利用线性映射的解析逆 $h_\theta^{-1}(p_i) = A^+(p_i - b)$（$A^+$ 为 Moore-Penrose 伪逆），无需额外参数即可保证前向预测与逆向恢复的一致性
- **关键技术二**：特征空间对齐损失 $\mathcal{L}_{feat} = \frac{1}{N_k}\sum_i \|f_i - h_\theta^{-1}(p_i^{gt})\|_2$，缓解 $d_f > 2$ 时逆映射欠定导致的特征不一致
- **关键技术三**：随机化特征路由（Randomized Feature Routing）。训练时随机选择每个关键点特征来自预测路径还是修正路径，避免扩散模型过度依赖单一通路，并稳定早期训练

### 4. 标注与跟踪
- **训练时**：仅在每条演示的初始帧人工点击 N_k 个关键点，之后由 **Co-Tracker** 自动传播；静态结构的关键点保持固定
- **回滚时**：策略前馈预测关键点，可全自主执行；当 OOD 情况下注意力漂移时，用户可在初始帧修正部分关键点或部分视角，跟踪模块持续传播

## 七、优点与亮点

- **方法层面**：
  - **人机交互的新范式**：在感知与动作之间插入"显式注意力接口"，既保留端到端自主执行能力，又允许 OOD 时一次点击纠偏
  - **三个稳定化技巧（前向-逆向权重共享 + 特征对齐损失 + 随机路由）**设计精巧，使"训练时假设的修正路径"与"推理时的实际修正"在特征空间对齐
  - **轻量标注**：仅在演示首帧点击，依赖 Co-Tracker 跟踪，极大降低人工标注成本
  - **通用性**：方法架构兼容任意数量关键点与任意相机数量，灵活可扩展
- **实验层面**：
  - 仿真 + 真实世界双验证，覆盖 ID 与多种 OOD
  - 提供均值与标准差，并做多角度消融与噪声鲁棒性分析
  - 与多种基线（DP、ACT、MOP-Box、MOP-Point）对比，且与粒度相似的 MOP 方法对比尤其有说服力
  - 定性可视化（图 7）直观展示了注意力漂移与修正前后的效果
- **工程层面**：基于统一的 RoboManipBaselines 框架实现，便于社区复现与对比

## 八、不足与局限

### 方法层面

## 八、不足与局限（续）

### 实验层面（续）

- **数据规模较小**：每任务仅 30–32 条演示，对扩散策略而言属于偏小规模，可能影响策略对分布内覆盖度的判断，进而使 ID 性能的对比存在一定噪声
- **OOD 范围有限**：Positional OOD 仅采样 10 个未见目标位置；Appearance OOD 仅通过桌面叠加彩色方块实现，扰动形式较为单一，未覆盖更剧烈的光照变化、视角变化、物体遮挡或复杂背景干扰
- **缺乏对未见物体类别（Category OOD）的评估**：现实部署中常遇到训练时从未出现过的物体；本文主要讨论位置与外观偏移，对语义级 OOD 的鲁棒性未做系统验证
- **真实世界任务时长较短**：三个任务均为短时程操作（数秒级），对长视野、强时序耦合任务的适用性未得到验证
- **人工修正的可行性假设较强**：要求用户在初始帧"看得出"关键点漂移并主动点击，但用户对何时该点击、何处该点的判断仍依赖经验；论文缺少对"非专家用户"的修正成功率与学习成本的分析

### 写作与披露层面

- **算力与训练成本未披露**：未给出 GPU 型号、训练时长、显存占用、训练 epoch 等关键复现信息
- **消融的可解释性有限**：仅给出最终成功率差异，未对"失败发生在哪一阶段（关键点预测 vs. 特征对齐 vs. 扩散去噪）"做诊断式分析

- **依赖外部跟踪器**：Co-Tracker 是第三方模块，其失败会传导到整套系统；缺少对跟踪失败时的退化策略

**整体评价**：GuidedAttention 提出了一个兼具**可解释性**与**可纠正性**的视觉注意力中间表征，方法设计精巧（特别是三个稳定化技巧）、实验覆盖较广（仿真 + 真实世界、ID 与多种 OOD、多角度消融与鲁棒性分析）。其核心贡献——"在策略中加入人类可读、可干预的 2D 关键点接口"——是一种有价值的人机协同范式，尤其在 OOD 恢复方面表现出色。然而，方法依赖预设关键点数量与位置、2D 表征无深度信息、Co-Tracker 成为隐性瓶颈，实验规模与 OOD 范围也相对有限，且缺少算力披露与失败模式分析。建议在更长时序任务、更复杂 OOD（如类别 OOD、严重遮挡）、不同跟踪器鲁棒性以及更细粒度的失败归因上做进一步研究。
