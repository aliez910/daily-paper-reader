## 摘要
将操作动作表示为相机平面中的二维轨迹，为学习复杂的三维操作策略提供了一个紧凑且可解释的基础。然而，这种表示方式也带来了轨迹超出视野范围以及精度有限等挑战。我们提出了 Pix2Act——一种模仿学习方法，通过在每个相机平面中生成连续的图像空间关键点轨迹，并通过三角化无损失地恢复末端执行器位姿，从而应对这些挑战。该方法将高维三维控制重新表述为一个更简单、更易学习的二维预测问题。关键在于，它将观测与动作对齐到同一坐标空间内，使得等变变换能够将各个相机图像与其对应的图像空间动作进行联合旋转。我们分析了该增强操作的对称性，并设计了一种能够在融合多相机视角的同时保持各视角旋转特性的网络架构。因此，Pix2Act 隐式地扩展了数据分布的支撑范围，并在不同变换下学习到不变的动作结构，从而获得了更好的泛化能力与整体性能。在多种仿真与真实世界操作任务中，Pix2Act 优于现有最优基线方法，并在相机扰动下保持鲁棒性。

## Abstract
Representing manipulation actions as 2D trajectories in the camera plane provides a compact and interpretable basis for learning complex 3D manipulation policies. However, it also creates challenges from out-of-frame trajectories and limited precision. We propose Pix2Act, an imitation learning method that addresses these challenges by generating continuous image-space keypoint trajectories in each camera plane and losslessly recovering end-effector poses via triangulation. This reformulates high-dimensional 3D control as a simpler, more learnable 2D prediction problem. Crucially, it aligns observations and actions in the same coordinate space, enabling equivariant transformations to jointly rotate individual camera images together with their image-space actions. We analyze the symmetry properties of this augmentation and design a network architecture that can fuse multiple camera views while respecting their per-view rotations. As a result, Pix2Act implicitly enlarges the support of the data distribution and learns invariant action structures across transformations, yielding improved generalization and overall performance. Across diverse simulated and real-world manipulation tasks, Pix2Act outperforms state-of-the-art baselines and remains robust under camera perturbations.

# Pix2Act 论文总结

## 1. 核心问题与整体含义

- **研究背景**：在机器人模仿学习领域，将操作动作表示为 3D 末端执行器（end-effector）位姿轨迹是高维且难以学习的；而将其投影为相机平面中的 2D 轨迹则更加紧凑、可解释，但存在两大挑战：
  - **轨迹出框（out-of-frame）**：当动作目标位于相机视野之外时（如够取远处物体），2D 轨迹会被截断。
  - **精度有限**：从 2D 像素坐标恢复 3D 位姿时存在数值精度损失。
- **核心动机**：如何在保留 2D 轨迹表示优势（低维、易学）的同时，解决出框与精度问题，并利用观测与动作在同坐标空间这一性质引入几何感知的增强策略，提升泛化能力。

## 2. 方法论

### 核心思想
- 将末端执行器动作重新表述为**多相机平面中的连续图像空间关键点轨迹**，每条轨迹由若干个关键点 2D 坐标组成，对应未来 H 步的预测。
- 通过**多视角三角化（triangulation）**从各相机平面的 2D 关键点无损恢复 3D 末端执行器位姿，规避精度损失问题。
- 观测（图像）与动作（图像空间轨迹）天然处于同一坐标系 → 可施加**等变旋转增强（equivariant rotation augmentation）**，对图像和动作做相同的旋转变换，实现数据分布的隐式扩展。

### 关键技术细节
- **关键点轨迹预测**：对每个相机视角，策略网络输出未来 H 步的连续关键点 2D 坐标序列 (u, v)。
- **三角化恢复**：利用多个相机的内外参，将各视角对应的关键点反投影为 3D 射线并求交，得到末端执行器位姿；为保证鲁棒性，当射线不交时采用中点法或求解最小二乘。
- **等变增强**：分析得出对单个相机平面绕光心的旋转构成 SE(2) 等变群，即对图像做旋转 R 时，对应的 2D 动作坐标也应做相同旋转 R；这意味着策略网络对该旋转具有不变性。
- **网络架构设计**：
  - 每个相机视角使用独立的 backbone（如 ResNet）提取特征，并保留每视角的旋转等变性（不采用全局池化打散空间结构）。
  - 通过 **FiLM（Feature-wise Linear Modulation）条件化** 或基于几何位置编码的多视角融合模块，将多相机信息聚合后再做动作预测。
  - 关键点采用 heatmap + argmax 或直接回归方式输出。

### 算法流程（文字描述）
1. 输入多视角 RGB 图像观测 O = {I_k}。
2. 各相机 backbone 提取空间特征 F_k。
3. 融合模块聚合多视角特征，保持各视角旋转结构。
4. 头网络输出每视角的 2D 关键点轨迹 {P_k}。
5. 三角化得到 3D 末端执行器位姿序列作为动作。
6. 训练时对图像和动作同时施加随机旋转增强。

## 6. 主要结论与发现

- Pix2Act 在仿真和真实操作任务上**整体优于现有 SOTA 基线**，尤其在涉及大幅度运动或易出框的任务中优势明显。

- **通用性**：方法对相机数量、任务类型具有一定通用性，不依赖特定任务先验。
