## 摘要
视觉-语言-动作（VLA）模型在视觉运动策略学习方面取得了令人瞩目的成果，但其本质上仍是被动反应式的，仅将当前观测和语言映射为动作，缺乏对未来世界动态的显式前瞻预测。现有的视觉前瞻方法能够预测未来视觉状态，但缺乏显式的运动引导：它们能展示应去往何处，却未说明如何到达。我们认为未来特征预测与稀疏点跟踪在本质上是互补的：前者提供目标状态，后者捕捉通向目标的连续运动路径。为此，我们提出了 FoMoVLA，一个通过联合学习未来特征前瞻与稀疏二维点跟踪来为 VLA 表征引入显式时空监督、从而增强连续动作策略的框架。FoMoVLA 引入紧凑的前瞻令牌用于解码未来特征状态，解码稀疏的时序二维点轨迹以建模紧凑的几何运动，并通过一个轻量级的未来条件交叉注意力模块将两者耦合，从而在预期状态与点动态之间实现一致的推理。在 LIBERO、RoboCasa GR-1 Tabletop 以及 LIBERO-Plus 上的大量实验表明，该方法取得了最先进的性能，并展现出优异的零样本泛化能力。项目主页参见 https://liauto-research.github.io/FoMoVLA。

## Abstract
Vision-Language-Action (VLA) models have achieved impressive results in visuomotor policy learning, yet remain fundamentally reactive, mapping current observations and language to actions without explicit forward prediction of world dynamics. Existing visual foresight methods predict future visual states but lack explicit motion guidance: they show where to go but not how to get there. We argue that future feature prediction and sparse point tracking are naturally complementary: the former provides the goal state, while the latter captures the continuous motion path toward it. We propose FoMoVLA, a framework that augments VLA representations with explicit spatio-temporal supervision by jointly learning future feature foresight and sparse 2D point tracking, enhancing the continuous action policy. FoMoVLA introduces compact foresight tokens to decode future feature states, decodes sparse temporal 2D point trajectories to model compact geometric motion, and couples both through a lightweight future-conditioned cross-attention module that enables consistent reasoning between anticipated states and point dynamics. Extensive experiments on LIBERO, RoboCasa GR-1 Tabletop, and LIBERO-Plus demonstrate state-of-the-art performance and strong zero-shot generalization. Project page is available at https://liauto-research.github.io/FoMoVLA.

# FoMoVLA 论文总结

## 1. 核心问题与研究动机

- **问题定义**：现有视觉-语言-动作（VLA）模型（如 RT-2、OpenVLA、π0、GR00T 等）本质上是被动反应式的，仅将当前观测与语言指令映射到动作，缺乏对未来场景演化和长时序物体动态的显式预测能力，制约了其在长视野、复杂操控任务中的表现。
- **两类现有方案的不足**：
  - **未来预测类**（如 WorldVLA、DreamVLA、UniVLA、LaRA-VLA、HiF-VLA）：要么以密集像素预测多帧未来状态，造成大量与控制无关的静态内容冗余与高计算开销；要么只预测紧凑的关键帧级目标状态，缺少到达该状态的连续动态过程。
  - **运动引导类**（如 FlowVLA、GeoPredict、JOPAT、Spatial Forcing）：通过光流或 2D 点轨迹建模运动，但通常只关注"如何移动"，不显式建模"应去往何处"的目标状态。
- **核心洞察**：未来特征预测与稀疏点轨迹跟踪天然互补——前者给出目标状态（where to end up），后者刻画到达目标的连续路径（how to move）。两者应联合学习并显式耦合，方可将"前瞻"真正落地为对动作生成有效的引导。
- **论文定位**：为 VLA 模型引入显式的时空监督信号，使视觉表征同时具备前瞻语义与几何运动一致性。

## 2. 方法论

### 2.1 整体框架

- **基础架构**：以 StarVLA-GR00T 为基座，VLM 主干 + Flow Matching DiT 动作头，按 action-chunking 范式一次性预测 T 步动作。
- **三条训练分支**（仅训练时使用，推理全部丢弃）：
  1. **点轨迹跟踪分支**（how to move）
  2. **未来特征预测分支**（where to end up）
  3. **未来条件交叉注意力模块 FCCA**（将前两者耦合）

### 2.2 点轨迹分支

- **输入序列重排**：将文本令牌置于图像令牌之前，使图像令牌隐状态可基于完整语言指令做条件化，避免自回归因果掩码下视觉表征无法感知目标语义。
- **稀疏查询点定义**：ViT patch=16、空间合并后得到 8×8 特征图，对应 64 个图像令牌；将每个压缩 patch 中心映射回原图坐标，形成 N=H′×W′=64 个查询点，与图像令牌一一对应。
- **教师信号**：冻结的 CoTracker-v3 在动作 chunk 的所有 T 帧上跟踪这些点，得到归一化位移 d⋆∈R^{N×T×2} 与可见性标签 v⋆∈{0,1}^{N×T}。
- **对齐头**：
  - 轨迹头 f_track：两层 MLP（LN→Linear→GELU→Linear），输出预测位移 d̂∈R^{N×T×2}。
  - 可见性头 f_vis：结构类似但隐层更小，输出 v̂∈R^{N×T}。
- **运动损失**（公式 (4)-(7)）：
  - L_disp：可见性掩码下的 MSE 位移损失。
  - L_vis：可见性 BCE 分类损失。
  - L_smooth：二阶时序差分正则，抑制突变。
  - 总运动损失：L_track = L_disp + L_vis + λ_smooth·L_smooth。
- **关键设计**：所有损失用真实可见性掩码，遮挡点不贡献梯度。

### 2.3 未来特征预测分支

- **前瞻令牌**：在图像与指令令牌之后追加 K=16 个可学习 \<Foresight\> 令牌。
- **教师**：视觉编码器的 EMA 影子（动量 μ=0.999），对目标帧 o_{t+T} 编码得到目标特征 z⋆∈R^{M×d}。
- **MAE 解码器**：K 个前瞻令牌拼接 M−K=48 个可学习 mask 令牌，经 2 层轻量 ViT 解码器（含正弦位置编码）重建 ẑ∈R^{M×d}。
- **损失**：余弦相似度损失 L_foresight = 1 − mean(cos(ẑ_i, z⋆_i))。
- **推理保留**：K 个前瞻令牌保留在输入序列中，供动作头交叉注意力使用。

### 2.4 未来条件交叉注意力（FCCA）

- **结构**：标准多头注意力（8 头），位于 VLM 视觉特征提取与位移预测之间。
- **作用**：以 H_fut∈R^{K×d}（前瞻令牌隐状态）作为 K/V，以 H_vis∈R^{N×d}（视觉网格特征）作为 Q：H̃_vis = H_vis + MHA(LN(H_vis), LN(H_fut), LN(H_fut))。
- **零初始化**：输出投影零初始化，训练初始等价于恒等映射，避免扰动预训练 VLM 特征，随训练逐步注入未来信息。
- **设计动机**：让运动预测在已知目标状态的前提下进行，问题约束更强，预测更一致。

### 2.5 总训练目标与推理

- **总损失**：L = L_action + λ_1·L_foresight + λ_2·(L_disp + L_vis + λ_smooth·L_smooth)，其中 λ_1=0.1，λ_2=0.3，λ_smooth=0.1。
- **推理**：所有辅助分支（MAE 解码器、FCCA、跟踪头、可见性头）全部丢弃，仅保留 K=16 个前瞻令牌，中位延迟仅增加 9.4 ms，GPU 显存增加 0.1 GB。

## 3. 实验设计

### 3.1 数据集 / 场景

- **LIBERO**：四个子套件（Spatial、Object、Goal、Long），每套件 10 个任务、每任务 50 条演示，每任务 20 次 rollout，chunk 长度 T=8。
- **RoboCasa GR-1 Tabletop**：24 个桌面 pick-and-place 任务，GR-1 人形机器人，每任务 1000 条演示（共 24000 条），每任务 50 次 rollout，T=16。
- **LIBERO-Plus**：LIBERO 的 OOD 鲁棒性扩展，7 个扰动维度（视角、机器人状态、语言、光照、背景、噪声、布局），10030 个实例，零样本评估。

### 3.2 对比基线

- **通用 VLA / 世界-动作模型**：GR00T-N1.5、π0、X-VLA、LangForce、Fast-WAM、LingBot-VA、Cosmos Policy、Spatial Forcing 等。
- **未来预测方法**：WorldVLA、DreamVLA、UniVLA、LaRA-VLA、HiF-VLA。
- **点跟踪方法**：FlowVLA、GeoPredict、JOPAT。
- **零样本基线**：OpenVLA、StarVLA、Qwen-RobotManip-scratch、VLA-JEPA、Abot-M0 等。

### 3.3 关键结果

- **LIBERO 平均成功率**：FoMoVLA 98.8%，高于 LingBot-VA / Cosmos Policy / Spatial Forcing 等 98.5%，略优于 LangForce 98.4%。在 LIBERO-Long 上 97.6%，相对最强对比方法有显著优势。
- **RoboCasa GR-1 Tabletop**：FoMoVLA 56.9%，相较 StarVLA-GR00T（47.8%）提升 +9.1%，相较 GR00T-N1.6（47.6%）提升 +9.3%。
- **LIBERO-Plus（零样本 OOD）**：FoMoVLA 80.5%，与需要大规模预训练的 Abot-M0 持平，显著优于 StarVLA 74.1%（+6.4%），在语言扰动上提升 +5.5%。

## 6. 主要结论与发现

- **互补性验证**：未来特征预测与稀疏 2D 点跟踪分别为 VLA 引入目标语义与几何运动先验，二者单独使用均能提升策略性能，但仅简单叠加收益有限（97.5→97.8），必须显式耦合。
- **FCCA 关键作用**：通过未来条件交叉注意力将运动预测锚定在目标状态上，LIBERO 平均 +1.0%、LIBERO-Long +1.8%、ATE-moving −39.5%、Survival@10px +17.3 pp。
- **设计选择**：稀疏 8×8 网格（64 点）优于更密集的 16×16 网格；MAE 瓶颈结构优于 Direct-64；图像令牌作为运动解码输入、目标令牌经 CrossAttn 注入为最优耦合方式。
- **跨框架可迁移**：FoMoVLA 对动作解码器不敏感，可同时提升 StarVLA-π（+2.2%）与 StarVLA-OFT（+1.4%）。
- **推理高效**：所有辅助分支在推理时丢弃，部署参数与基线一致，仅 K=16 个前瞻令牌引入 ~10 ms 延迟。
- **OOD 鲁棒性**：在未预训练的条件下达到与 Abot-M0 相当的零样本鲁棒性，尤其在语言与背景扰动维度表现突出。

## 7. 优点与亮点

- **问题洞察清晰**：将"前瞻"分解为"目标状态"与"运动路径"两个互补维度，并通过理论性论证与可视化共同支撑。
- **零推理开销设计**：辅助分支全部训练时使用，推理阶段部署成本与 Vanilla 基线完全相同，对实际部署友好。
- **轻量耦合模块**：FCCA 采用零初始化输出投影，保证训练起始不破坏预训练表征，训练过程稳定。
- **稀疏几何监督高效**：仅 64 个跟踪点即可提供有效运动监督，避免密集光流或像素重建的高昂开销。
- **MAE 瓶颈设计**：用 K=16 个令牌编码 M=64 个目标 patch，强迫模型捕获全局目标语义而非局部纹理细节。
- **跨基准、跨框架、跨相机视角验证**：在 LIBERO、RoboCasa（自我中心）、LIBERO-Plus 三类场景，及两种策略头下均显示一致增益。
- **量化与定性结合**：除任务成功率外，还对跟踪误差（FCCA 降低 ATE-moving 39.5%）、预测变化热图等进行细粒度分析。

## 8. 不足与局限

- **2D 运动的本质局限**：点跟踪仅在图像空间建模运动，无法捕捉 3D 几何与深度信息，对视角变化与遮挡的鲁棒性受限；论文亦承认这一点，并提出未来引入 3D 运动预测。
- **OOD 局限**：在 LIBERO-Plus 的 Camera 与 Robot State 扰动上提升有限，论文将其归因于训练数据固定视角与起始位姿。
- **教师依赖**：点跟踪信号完全依赖冻结的 CoTracker-v3；若跟踪器在遮挡、快速运动或极端视角下失效，监督噪声会直接传递到 VLM 主干。
