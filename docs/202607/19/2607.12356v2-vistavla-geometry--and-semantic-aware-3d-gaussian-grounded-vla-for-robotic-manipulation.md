## 摘要
视觉-语言-动作（VLA）模型作为一种强大的端到端范式，已被广泛应用于机器人操作任务，它能够将语言指令和二维视觉输入直接映射为动作。然而，这类模型缺乏显式的场景级三维表征，限制了其对空间布局和几何约束的推理能力。虽然近期一些研究工作尝试引入深度图或点云等显式三维线索以增强几何感知能力，但这些方法主要捕获的是低级结构信息，缺乏三维空间中的高级语义基础。在人类认知中，与物理世界的交互依赖于一种三维语义认知地图——一种将空间布局与语义上下文相融合的内部心理模型，从而实现持久的、与视角无关的推理。受此启发，我们提出了 VistaVLA，一个新颖的两阶段框架。该框架基于三维高斯基元构建几何与语义感知的三维认知表征，并将其作为紧凑的上下文标记用于 VLA 策略学习。具体而言，VistaVLA 将多视角视觉-语言特征提升至三维高斯基元空间中，形成几何锚定的语义标记，从而在二维视觉特征空间中实现视图一致的空间基础对齐。为了使该三维表征在计算上高效可控，我们引入了"合并后查询"（Merge-then-Query, MtQ）机制——一种标记摘要方法。MtQ 将密集的高斯基元压缩为空间信息高度紧凑的标记集合，在保留与动作相关的三维布局和语义上下文的同时，实现了 99% 的标记压缩率。在仿真环境和真实环境中的大量实验均验证了 VistaVLA 的有效性。值得注意的是，在真实场景中，VistaVLA 在七项真实任务上将成功率提升了 22.8%，并在具有挑战性的分布外任务上相较 VLA-Adapter 基线提升了 30.0%。

## Abstract
Vision-Language-Action (VLA) models have emerged as a powerful end-to-end paradigm for robotic manipulation by mapping language instructions and 2D visual inputs directly to actions. However, these models lack an explicit, scene-level 3D representation, limiting their ability to reason over spatial layouts and geometric constraints. While recent efforts incorporate explicit 3D cues, such as depth maps or point clouds, to improve geometric awareness, they primarily capture low-level structures and lack high-level semantic grounding in 3D space. In human cognition, interaction with the physical world relies on a 3D semantic cognitive map - an internal mental model that integrates spatial layouts with semantic context to enable persistent, viewpoint-invariant reasoning. In light of this, we present VistaVLA, a novel two-stage framework that constructs a geometry- and semantics-aware 3D cognitive representation from 3D Gaussian primitives and grounds it as compact context tokens for VLA policy learning. Specifically, VistaVLA lifts multi-view vision-language features into 3D Gaussian primitives, forming geometry-anchored semantic tokens that align view-consistent spatial grounding with 2D visual feature spaces. To make this 3D representation computationally tractable for effective VLA control, we introduce Merge-then-Query (MtQ), a token summarization mechanism. MtQ compresses dense Gaussian primitives into a highly compact set of spatially informative tokens, achieving a 99% token reduction while preserving action-relevant 3D layouts and semantic context. Extensive evaluations in both simulated and real-world environments demonstrate the effectiveness of VistaVLA. Notably, in real-world scenarios, VistaVLA improves success rates by 22.8% across seven real-world tasks and by 30.0% over the VLA-Adapter baseline on challenging out-of-distribution tasks.

- **空间推理能力不足**：在涉及精确空间布局、几何约束或接触丰富的任务中（如堆叠、放置、组织等），容易出现操作失败。
- **现有 3D 增强方法的缺陷**：
  - 引入深度图、点云或稀疏 3D 坐标的方法（如 SpatialVLA、PointVLA、DepthVLA 等）仅提供**低级几何结构**，缺乏 3D 空间中的**高层语义锚定**。

### 1.2 整体含义与动机
- 受**人类认知中"3D 语义认知地图"**启发——人类通过将空间拓扑与语义功能结合实现持久、视角无关的推理。
- 目标：构建一个**场景级、几何与语义联合感知**的 3D 认知表征，作为 VLA 策略学习的紧凑接口。

## 2. 方法论

### 2.1 整体框架：两阶段设计

**Stage I：3D 高斯认知表征构建**
- **基础设置**：基于 DepthSplat 构建 3D 高斯场，每个高斯基元参数化为 $g_i = (\mu_i, \Sigma_i, \alpha_i, c_i, z_i)$，其中 $z_i \in \mathbb{R}^{128}$ 为可学习的语义特征。
- **紧凑教师特征空间构建**：
  - 使用 SigLIP2（语言对齐语义）与 DINOv2-Large（稳健视觉描述子）提取 2176 维特征。
  - 训练轻量自编码器将其压缩至 128 维潜在编码作为教师特征。
- **两阶段高斯特征渲染**：
  - 第一阶段：仅 RGB-D 渲染损失 $\mathcal{L}_{\text{stage1}} = \lambda_{\text{rgb}}\mathcal{L}_{\text{rgb}} + \lambda_{\text{dep}}\mathcal{L}_{\text{dep}}$，稳定几何。
  - 第二阶段：在 RGB-D 基础上增加特征蒸馏损失 $\mathcal{L}_{\text{stage2}} = \mathcal{L}_{\text{stage1}} + \lambda_{\text{feat}}\mathcal{L}_{\text{feat}}$。
- **3D 锚定的 GS Token 化**：
  - 每个高斯基元的语义特征 $z_i$ 作为 Token 值，得到 $\mathcal{T}_{\text{gs}} = \{z_i\}_{i=1}^{N}$，$N \sim 10^5$。
  - 通过 $\alpha$-compositing 规则（公式 1）渲染特征图：$\hat{F}_v(p) = \sum_{i \in \mathcal{N}(p)} R_i(v,p) z_i$，其中 $R_i(v,p) = T_i^v(p) \alpha_i^v(p)$。
  - 跨视角监督确保每个 $z_i$ 在 3D 空间具有视角一致的语义描述能力。

**Stage II：Merge-then-Query (MtQ) Token 压缩与策略注入**

- **参数无关压缩（Morton-guided Merge）**：
  - 将稠密 GS Token 重塑为逐视角网格，采用 stride-4 平均池化粗降至约 7K Token。
  - 根据 3D 中心 $\mu \in \mathbb{R}^3$ 的 Morton 码排序，划分为锚点集 $A$ 与非锚点集 $B$。
  - 非锚点 Token 基于语义相似度（公式 3）匹配至最相似锚点 $a^*(u) = \arg\max_{a \in A} \langle z_u, z_a \rangle / \|z_u\|\|z_a\|$。
  - 仅合并相似度排名前 50% 的匹配，按大小加权聚合：$z'_a = (s_a z_a + \sum_{u \in M_a} s_u z_u) / S_a$，$\mu$ 与 $s$ 类似更新。
  - 迭代压缩直至 Token 数 $< N' = 1000$。
  - **实现约 99% 的 Token 减少**（从 $\sim 10^5$ 降至 $\sim 10^3$）。

- **基于查询的摘要（Query-based Summarization）**：
  - 使用 $N_q = 64$ 个可学习查询 Token $Q \in \mathbb{R}^{B \times N_q \times d}$，通过 2 层 Transformer Decoder 对压缩后的 Token $Z'$ 进行交叉注意力。
  - 投影至 VLA 骨干隐藏维度：$X_{\text{gs}} = \text{Proj}_{\text{llm}}(\text{Dec}_{\text{gs}}(Q, Z')) \in \mathbb{R}^{B \times N_q \times d_{\text{llm}}}$。

- **动作生成**：
  - 沿用 VLA-Adapter 的因果序列建模范式，将 Token 拼接为 $X = [X_{\text{vis}}, X_{\text{lang}}, X_{\text{gs}}, X_{\text{act}}]$。
  - 通过 LLM-0.5B + LoRA 训练，回归损失 $\mathcal{L}_{\text{act}} = \sum_{t=1}^{K} \|\hat{a}_t - a_t\|_1$。
  - 推理时执行前 $K_{\text{exec}} = 4$ 个预测动作后重新规划。

### 2.2 关键技术亮点
- **3D Gaussian 与 2D Foundation 特征的有机融合**：通过 RGB-D 渲染监督将 SigLIP2/DINOv2 特征蒸馏至 3D 高斯场。
- **Morton-order + 语义相似度的双引导合并**：兼顾空间分布与语义一致性。
- **极致的 Token 压缩率（99%）**：使高密度 3D 表征在 VLA 推理中可行。

## 6. 主要结论与发现

### 6.1 主要性能结果
- **真实世界（图 4）**：平均成功率显著优于 VLA-Adapter、VLA-Adapter+Depth、π0.5 与 SmolVLA。

  - 标准 LIBERO：96.05% 平均成功率（无大规模预训练方法中最佳）。

### 6.2 核心发现
1. **语义 3D 表征优于纯几何线索**：VLA-Adapter+Depth 提升有限，而语义高斯场带来大幅提升。
2. **增益来自结构化接口而非更多视角/Token**：消融表明，增加 2D patch Token 仅带来微弱改进，而 VistaVLA 用更少 Token 取得更好效果。
3. **Morton 合并 + 查询摘要缺一不可**：FPS、熵采样或仅线性投影均显著退化。
4. **查询 Token 数存在最优值**：64 为最佳，过多（256）反而损害性能。

## 7. 论文亮点与优点

- **认知科学启发的设计**：明确将"3D 语义认知地图"作为方法学基础，区别于纯工程导向的工作。

- **在小模型（0.5B）上达到超越大模型（π0.5-3B）的效果**：显示 3D 语义接口的边际效益显著。

## 8. 不足与局限

### 8.1 方法局限
- **依赖标定的多视角相机**：需要已标定的 RGB-D 相机位姿，限制了动态、杂乱场景的应用。
- **在线构建高斯场的开销**：每步控制需重新构建高斯场，引入额外计算延迟（未报告延迟数据）。
- **3D 高斯场仅支持静态场景**：对动态物体（如运动中的物体）建模能力未讨论。
- **依赖 Foundation 视觉特征**：教师特征质量直接影响 GS Token 质量。

### 8.2 实验局限
- **任务多样性不足**：仅 7 个真实任务，均为桌面级操作，未涉及移动机器人、人形机器人等。
- **统计置信度有限**：每任务仅 10 次试验，0/10 → 3/10 的对比可能受随机性影响。
- **扰动测试范围有限**：仅测试深度与位置扰动，未涉及光照变化、遮挡、背景杂乱等真实世界常见干扰。

- **未与所有最新 3D VLA 方法对比**（如 3D-VLA、GeoVLA、BridgeVLA 等）。

### 8.3 偏差与应用风险
- **评估平台单一**：仅在 Agile-Piper 上验证，不同机械臂本体可能带来性能差异。
- **演示数据规模未披露**：可能存在数据量差异带来的不公平。
- **应用限制**：当前仅适合受控桌面环境，难以泛化至家庭、户外等开放场景。
