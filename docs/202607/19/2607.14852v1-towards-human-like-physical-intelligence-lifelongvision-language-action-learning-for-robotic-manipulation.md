## 摘要
与人类能够顺序学习新任务的自然能力类似，具备视觉-语言-动作（VLA）模型的机器人应当拥有终身学习能力，以便在开放世界环境中部署时学习新任务。然而，近期大多数终身学习模型仅关注有效学习当前任务（可塑性）或保持在先前任务上的高准确率（稳定性），而可塑性-稳定性权衡问题在机器人操作模型中仍未得到妥善解决。为应对这一根本性挑战，我们提出了一种面向机器人操作的缓存高效终身视觉-语言-动作学习框架（即LifelongVLA），该框架通过双时间尺度自适应机制缓解可塑性-稳定性权衡问题，同时借助缓存高效回放策略实现低成本的机器人部署。具体而言，我们提出了一种双时间尺度LoRA门控模块，将VLA自适应分解为两条轻量化路径：用于可塑性的短期适配器和用于稳定巩固的长期适配器。这些路径通过任务感知门控进行集成，从而实现对可塑性-稳定性权衡的显式控制。在技能回放阶段，我们提出了一种缓存高效随机回放策略，无需存储完整轨迹即可保留更均衡的保留信号。实验结果表明，LifelongVLA优于现有基线，展现出高效的技能扩展、对已学操作行为的稳健保留，以及在xArm机器人上真实部署时对重新训练的依赖降低。

## Abstract
Similar to the natural capabilities of humans to sequentially learn new tasks, robots with Vision-Language-Action (VLA) models should possess lifelong learning ability to learn a new task when deployed in open-world environments. However, most recently proposed lifelong learning models aim to effectively learn the current task (plasticity) or maintain high accuracy on previous tasks (stability), while the plasticity-stability trade-off remains largely unsolved in robotic manipulation models. To address this fundamental challenge, we propose a cache-efficient lifelong Vision-Language-Action learning framework for robotic manipulation (i.e., LifelongVLA), which alleviates the plasticity-stability trade-off with a dual-timescale adaptation mechanism while achieving low-cost robotic deployment with a cache-efficient replay strategy. More concretely, we propose a dual-timescale LoRA gating module to decompose VLA adaptation into two lightweight pathways: a short-term adapter for plasticity and a long-term adapter for stable consolidation. These pathways are integrated via a task-aware gate, enabling explicit control of the plasticity-stability trade-off. In the skill replay phase, a cache-efficient stochastic replay strategy is proposed to preserve more balanced retention signals without full-trajectory storage. Finally, experiments show that LifelongVLA outperforms existing baselines, demonstrating efficient skill expansion, robust retention of learned manipulation behaviors, and reduced reliance on retraining for real-world deployment on an xArm robot.

# LifelongVLA 论文详细总结

## 1. 核心问题与研究动机

- **研究背景**：Vision-Language-Action（VLA）模型（如 RT-2、Octo、π0/π0.5/π0.7）已使语言条件下的机器人操作成为可能，但绝大多数现有 VLA 仍采用**静态离线训练**范式：在固定数据集上训练一次后即部署，缺乏持续学习能力。
- **现实需求**：机器人在开放世界部署中会持续遇到新物体、新指令、新场景和新动作分布，需要像人类一样**顺序学习新技能**。
- **关键瓶颈——可塑性-稳定性权衡（Plasticity-Stability Trade-off）**：
  - 直接顺序微调会导致**灾难性遗忘**；
  - 保留全部历史数据重训练成本过高（计算与内存随任务数线性增长）；
  - 现有持续学习方法（经验回放、参数扩展、参数隔离）多针对通用视觉/语言任务，**未充分适配 VLA 策略**；
  - 简单经验回放对 VLA 而言开销巨大（需反复重新编码历史图像观察）；
  - 架构扩展类方法（如专家路由）则带来推理延迟与路由开销。
- **本文目标**：在大型 VLA 主干网络上实现**显式的可塑性-稳定性平衡**，同时降低回放开销，以适配真实机器人低成本部署。

## 2. 方法论：核心思想与关键技术

### 2.1 整体框架
LifelongVLA 建立在**冻结的 PaliGemma（Gemma 2B）+ Gemma 300M 连续动作扩散解码器**之上，通过两个核心模块实现：
- **Dual-Timescale LoRA Gating（双时间尺度 LoRA 门控）**：在权重级别显式解耦可塑性与稳定性；
- **Cache-Efficient Stochastic Replay（缓存高效随机回放）**：用紧凑的潜空间记忆代替全轨迹回放。

### 2.2 双时间尺度 LoRA 门控
- **双路径设计**：每个适配层 ℓ 维护两个 LoRA 残差
  - 短期路径：$\Delta W_\ell^{sh,t} = A_\ell^{sh,t} B_\ell^{sh,t}$，仅由**当前任务损失** $\mathcal{L}_{new}$ 更新（学习率 $\eta_{sh}$ 较高）→ 高可塑性；
  - 长期路径：$\Delta W_\ell^{lg,t} = A_\ell^{lg,t} B_\ell^{lg,t}$，仅由**回放损失 + 蒸馏损失**（$\lambda\mathcal{L}_{rep}+\beta\mathcal{L}_{dist}$）更新（学习率 $\eta_{lg}<\eta_{sh}$）→ 高稳定性。
- **任务感知门控（Task-Aware Gate）**：
  - 门控上下文 $c = \text{Pool}(\text{stopgrad}(E_{pre}(u;\Theta_0)))$，从冻结前缀特征计算，避免循环依赖；
  - 门控输出 $\alpha_\ell^t(c) = \sigma(W_\ell^g \phi_\ell(c) + b_\ell^g) \in [0,1]$；
  - **权重级合成**：$\widetilde{\Delta W}_\ell^t(c) = (1-\alpha)\Delta W_\ell^{sh,t} + \alpha \Delta W_\ell^{lg,t}$；
  - 推理时只需**单次前向**，无额外开销。
- **意义**：$\alpha\to 0$ 强调近期可塑适应，$\alpha\to 1$ 强调稳定记忆；为可塑性-稳定性权衡提供**显式接口**。

### 2.3 缓存高效随机回放
- **技能级前缀缓存**：每个新任务仅随机选取 $c_t$ 个样本存入回放缓冲 $\mathcal{B}_t$：
  - 存储内容仅为 **stop-gradient 前缀 token** $\bar{h}_{pre}^{i,t}$ + 紧凑的 $(s_t^i, y_t^i)$；
  - **不存储**原始图像、文本 token、suffix token、扩散时间或噪声 → 大幅降低存储与 I/O。
- **随机回放与后缀重计算**：
  - 对缓存样本每步**重新采样**扩散变量 $(\tau', \epsilon')$；
  - 用**当前模型状态**重新计算 suffix token：$h_{suf,rep}^{j,t} = E_{suf}(s_j, \tilde{y}_{\tau'}^j, \tau'; \widetilde{\Theta}_t(c_{rep}^j))$；
  - 这样每个缓存前缀可在不同时间步生成多个随机回放实例，缓解缓存-当前模型失配问题。
- **遮蔽新-回放混合目标**：
  - 同一 mini-batch 内**拼接并打乱**当前样本与回放样本，通过 replay mask $m_i \in \{0,1\}$ 区分；
  - 损失函数 $\mathcal{L}_t = \mathcal{L}_{new} + \lambda\mathcal{L}_{rep} + \beta\mathcal{L}_{dist}$；
  - 蒸馏项使用上一任务的**解耦教师快照** $\bar{F}_{t-1}$ 稳定旧技能预测；
  - 分别按 $|M_{new}|$ 与 $|M_{rep}|$ 归一化，防止任一方主导。

## 3. 实验设计

### 3.1 数据集与场景
- **LIBERO 基准** [Liu et al., NeurIPS 2023]：选取 **10 个增量任务**用于仿真持续学习评估；
- **真实机器人**：使用 **xArm** 平台设计 **5 个顺序操作任务**（如 "Place the eggplant onto the plate"、"Pick up the black bowl in the top drawer..." 等）。

### 3.2 主干网络与超参
- 冻结 PaliGemma（Gemma 2B）+ Gemma 300M 连续动作解码器，输出 7D 机器人动作；
- LoRA rank $r=16$，缩放 $\gamma=16$，mini-batch $M=500$，缓存配额 $c_t=50$，$\lambda=1.0$，$\beta=0.1$；
- 每任务训练 10,000 步（联合训练上界为 40,000 步）；
- 推理时无任务身份（task identity unavailable）。

### 3.3 对比方法
- **SFT**（顺序微调基线）
- **LwF-LoRA** [Li & Hoiem, 2017]：基于输出蒸馏
- **ER** [Chaudhry et al., 2019]：情景经验回放
- **Info-VLA** [Zhao et al., 2026]：信息论正则化
- **AtomicVLA** [Zhang et al., 2026]：技能级专家特化
- **Joint（联合训练上界）**：所有任务数据同时训练

### 3.4 评估指标
- **SR**（Success Rate）：最终平均成功率；
- **FOR**（Forgetting Rate）：旧任务的最大性能下降；
- **ACC_t**：增量步骤上的过程级准确率。

## 6. 主要结论与发现

- **性能优势**：LifelongVLA 在 LIBERO 10 任务上取得 **83.2% 平均成功率**与 **11.4% 平均遗忘率**，分别比最强基线 ER 高 **13.0 个百分点**和低 **8.2 个百分点**（摘要称 SR 提升 >13%、FOR 降低 >8.2%）；
- **效率优势**：回放内存比 raw data replay 降低约 **72 MiB/task**（每任务节省 91.92 MiB，相较 ER），可训练参数远小于 AtomicVLA（99.97M vs 226.49M）；
- **过程稳定性**：在稳定性-可塑性散点图中 LifelongVLA 最接近左上"理想区域"，增量 ACC 曲线最稳定；
- **真实机器人有效性**：5 任务顺序学习后，所有任务成功率均**超过 80%**；
- **组件贡献**：潜空间回放（latent replay）将内存从 167.62→95.70 MiB/task 而保持竞争力；双 LoRA 在同等内存下进一步提升 SR、降低 FOR（74.6→83.2%，21.78→11.4%）。

## 7. 方法与实验亮点

- **显式可塑性-稳定性接口**：双时间尺度 LoRA + 任务感知门控在**权重级合成**，推理仍只需单次前向，无额外延迟；
- **缓存高效回放**：仅存 stop-gradient 前缀 token + 紧凑状态-动作监督，回放时按需重算 suffix 与扩散变量，大幅节省内存与 I/O；
- **训练目标平衡设计**：新/回放样本分母独立归一化，防止任一类样本主导梯度；
- **教师蒸馏稳定化**：使用任务 $t{-}1$ 的解耦模型快照作为蒸馏教师，缓解旧技能预测漂移；
- **从仿真到真实的闭环验证**：覆盖 LIBERO 基准与 xArm 真实机器人 5 任务顺序学习，并提供定性 rollout；
- **消融中分离 latent replay 与 dual LoRA 两个组件贡献**：思路清晰。

## 8. 不足与局限

- **任务规模有限**：仿真 10 任务、真实机器人 5 任务，远小于现实开放世界终生学习的任务规模与多样性；
- **任务顺序单一**：所有方法使用相同任务顺序，未报告多次随机顺序的均值与方差，**单序列结果可能存在顺序偏差**；
- **未做超参/组件敏感性分析**：缺少对缓存容量 $c_t$、$\lambda$、$\beta$、LoRA rank $r$ 以及门控动态行为的消融；
- **语言鲁棒性未评估**：实验使用清晰指令，未涉及歧义、对话、指代、省略等真实用户表达场景（作者在第 7 节明确承认）；
- **算力与训练成本未披露**：GPU 型号/数量、训练时长、能效比等关键信息缺失，难以评估实际部署成本；
- **回放样本随机选择可能受偏置影响**：从每个任务均匀采样 $c_t$ 个样本，未考虑类内多样性与样本难度；
- **未与更强基线对比**：未与基于 prompt tuning、MoE 适配器、或近期 VLA 持续学习方法（如 Remem-VLA、PixelVLA 等）充分比较；
- **应用范围限制**：评估局限于桌面级单臂 xArm 操作，未覆盖移动操作、长视野任务、双臂协同等场景。
