## 摘要
视觉-语言-动作（VLA）模型已成为通用机器人操作的一种有前景的范式，其中视觉-语言表示被用于条件化连续动作生成。然而，这些表示并未针对动作条件化进行显式优化，使得动作专家模块需要在多模态理解与精确运动控制之间架起桥梁。近期的一些动作推理方法引入额外的模块来生成显式的动作规划或动作空间推理信号，展现了动作级引导的益处，但通常需要独立的动作生成框架。我们提出了 CAC-VLA，一种上下文门控动作条件化框架，可在 VLM 内部直接学习一个轻量级的潜在动作接口。CAC-VLA 并非生成可执行的轨迹，而是训练 VLM 预测从粗到细的潜在动作，这些动作是从未来动作片段编码而来的结构化表示，并通过上下文门控机制自适应地利用它们来条件化动作专家。这使得 VLM 原生的动作条件化成为可能，同时可校准潜在动作引导对专家动作生成的影响。在 LIBERO 和 LIBERO-Plus 上的实验证明了 CAC-VLA 的有效性，在 LIBERO 上达到了 98.3% 的平均成功率，在 LIBERO-Plus 上达到了 89.5%，表明上下文门控的潜在动作条件化是用于连续专家控制的一种有效接口。

## Abstract
Vision-Language-Action (VLA) models have become a promising paradigm for generalist robot manipulation, where visual-language representations are used to condition continuous action generation. However, these representations are not explicitly optimized for action conditioning, leaving the action expert to bridge the gap between multimodal understanding and precise motor control. Recent action-reasoning methods introduce additional modules to generate explicit action plans or action-space reasoning signals, demonstrating the benefit of action-level guidance but often requiring separate action-generation frameworks. We propose CAC-VLA, a Context-Gated Action Conditioning framework that learns a lightweight latent-action interface directly within the VLM. Instead of generating executable trajectories, CAC-VLA trains the VLM to predict coarse-to-fine latent actions, which are structured representations encoded from future action segments, and adaptively leverages them to condition the action expert via a context gate. This enables VLM-native action conditioning while calibrating the influence of latent-action guidance on expert action generation. Experiments on LIBERO and LIBERO-Plus demonstrate the effectiveness of CAC-VLA, achieving 98.3% average success rate on LIBERO and 89.5% LIBERO-Plus, suggesting that context-gated latent-action conditioning is an effective interface for continuous expert control.

# CAC-VLA 论文总结

## 1. 核心问题与研究动机

- **VLA 范式的瓶颈**：当前视觉-语言-动作（VLA）模型使用预训练视觉-语言模型（VLM）作为多模态理解模块，并搭配"动作专家"（action expert）生成连续机器人动作。然而，VLM 的视觉-语言表征并非针对动作条件化显式优化，动作专家必须在多模态理解与精确运动控制之间自行架桥，转换过程是隐式的。
- **现有动作推理方法的局限**：近期一些方法（如 ACoT-VLA、CoT-VLA、WorldVLA 等）通过引入额外的子目标、目标图像、动作规划或参考轨迹等中间推理信号来辅助动作生成，虽然验证了动作级引导的价值，但通常需要独立的动作生成或推理模块，增加了框架复杂度。
- **核心问题**：能否在 VLM 内部构建一个轻量级的"潜在动作"接口，并由动作专家自适应地校准该接口对连续控制的影响？这就是本文要回答的技术问题。

## 2. 方法论

### 2.1 整体框架（CAC-VLA）

- 在 π0.5 架构基础上扩展，包含两个核心组件：
  1. **VLM 原生潜在动作预测**：在 VLM 输入中附加可学习的查询 token，训练其预测"潜在动作"（latent actions）。
  2. **上下文门控动作条件化（Context-Gated Action Conditioning）**：通过交叉注意力 + 门控残差连接，自适应地将潜在动作注入动作专家。

### 2.2 关键技术细节

- **潜在动作构造**：
  - 使用冻结的 OAT（Ordered Action Tokenization）分词器对未来动作段 $a_{t:t+H_l-1}$ 进行编码，得到原始潜在向量 $z^{oat}_t$，具备"从粗到细"的结构。
  - 潜在动作时长 $H_l$ 可与专家动作时长 $H_e$ 不同，提供了更灵活的时间范围引导。
- **VLM 查询 token**：
  - 在 VLM 输入中添加 $N_q = 8$ 个可学习的潜在查询 token $q$。
  - 使用"专家感知注意力掩码"（expert-aware attention mask），阻止动作专家 token 直接关注这些查询 token，保证潜在动作只能通过上下文门控模块影响专家。
  - 查询隐藏状态 $h^q_t = \text{VLM}(o_t, l, q)$ 经 LayerNorm + 线性层投影到原始 OAT 潜空间维度 $D_z = 4$，得到预测的潜在动作 $\hat{z}_t$。
- **潜在动作对齐损失**：使用 token 级的 Smooth-L1 损失对齐预测与目标，$\mathcal{L}_{align}$。
- **上下文门控动作条件化**（每层专家中）：
  1. 训练时使用 OAT 编码的 $z^{oat}_t$，推理时使用 VLM 预测的 $\hat{z}_t$，统一投影为条件 token $c_t$。
  2. 对动作隐藏状态做 Norm 后，通过 Cross-Attention 检索潜在动作更新 $u^l$。
  3. 通过平均池化提取状态与更新向量，经 Sigmoid 计算通道级门控 $g^l$。
  4. 通过门控残差连接注入专家：$x^l_+ = x^l + g^l \odot u^l$。
- **训练目标**：$\mathcal{L} = \mathcal{L}_{act} + \lambda_{align} \mathcal{L}_{align}$，其中 $\mathcal{L}_{act}$ 为原始 flow-matching 动作专家损失，$\lambda_{align} = 0.1$。

## 3. 实验设计

### 3.1 数据集与基准

- **LIBERO**：四个多任务操作子集（Spatial、Object、Goal、Long），使用官方评估协议。
- **LIBERO-Plus**：在 LIBERO 基础上加入相机视角、机器人形态、语言指令、光照、背景、噪声、场景布局等多种分布偏移。
- **真实世界实验**：桌面级 Pick-and-Place 与 Block Stacking，使用 UR7e 机械臂 + 两台 Intel RealSense D435i RGB-D 相机，每任务 50 条演示数据。

### 3.2 对比方法

- **LIBERO**：与 Diffusion Policy、Octo、CoT-VLA、WorldVLA、DreamVLA、UniVLA、F1、GE-Act、TraceVLA、OpenVLA、UniAct、SpatialVLA、ThinkAct、π0-FAST、FPC-VLA、SmolVLA、GR00T-N1、π0、GO-1、DD-VLA、MemoryVLA、π0.5、OpenVLA-OFT、VLA-Adapter、ACoT-VLA 等 20+ 方法对比。
- **LIBERO-Plus**：涵盖 WorldVLA、OpenVLA、NORA、UniVLA、π0-Fast、RIPT-VLA、OpenVLA-OFT、π0.5、ACoT-VLA 等。
- 对比方法按引导类型分类：视觉引导、语言引导、动作引导。

## 4. 资源与算力

- **硬件**：4 块 NVIDIA A100 GPU。
- **全局 batch size**：64。
- **优化器**：AdamW，梯度裁剪范数为 1.0，EMA 衰减 0.999。
- **学习率调度**：cosine schedule，10K warmup steps，峰值学习率 $1.25 \times 10^{-5}$，衰减步数 1M。
- **训练步数**：
  - LIBERO：40K 步。
  - LIBERO-Plus（SFT）：30K 步。
- **超参数关键值**：专家动作时长 $H_e = 10$；潜在动作时长 LIBERO $H_l = 20$，LIBERO-Plus $H_l = 10$；查询 token 数 $N_q = 8$；OAT 潜空间维度 $D_z = 4$；潜在动作条件 dropout = 0.1。

## 5. 实验数量与充分性

- **主实验**：在 LIBERO 与 LIBERO-Plus 两个基准下分别与大量最新方法对比，覆盖了 Spatial/Object/Goal/Long 四个子集。
- **消融实验**：
  - 潜在动作时长 $H_l \in \{10, 20, 30\}$ 三组对比。
  - 消融"潜在动作条件化"与"上下文门控"两个组件，提供 Full / w/o context gate / w/o latent-action conditioning 三组对比。
- **门控行为分析**：
  - 跨 flow step 与任务套件的原始门值可视化。
  - 有效潜在条件强度 $\frac{\|g \odot u\|_2}{\|x\|_2 + \epsilon}$ 在归一化回合进度上的曲线（Long vs Goal）。
  - 单任务阶段级（Approach / Grasp / Move / Drop）热力图。
- **真实世界实验**：2 个任务，每任务 25 次独立试验，方法间对比公平（同演示、同设置）。
- **充分性评价**：实验较为充分，涵盖仿真基准、零样本/监督微调、消融、可视化分析与真实机器人测试；但真实世界任务覆盖有限。

## 6. 主要结论与发现

- 在 LIBERO 上达到 **98.3% 平均成功率**（Spatial 98.4 / Object 99.8 / Goal 99.6 / Long 95.4），排名第二，仅次于 ACoT-VLA。
- 在 LIBERO-Plus（SFT）上达到 **89.5% 平均成功率**，超越 π0.5 与 ACoT-VLA。
- 潜在动作时长 $H_l = 20$ 为 LIBERO 上的最优权衡（更长未来上下文 vs. 当前动作块相关性）。
- 同时去掉潜在动作条件化和上下文门控都会导致性能下降（98.0% / 97.9% vs. 98.3%），验证了二者均为有效设计。
- 上下文门控在不同 flow step、不同任务套件、不同回合阶段表现出显著差异的激活模式，证实其为自适应而非固定强度的条件化。
- 真实世界 Pick-and-Place：Task Score 72%、Full SR 64%，相比 π0.5（48% / 16%）分别提升 24 与 48 个百分点；Block Stacking：Stacking SR 52% vs. 36%。

## 7. 优点

- **方法创新**：
  - 提出 VLM 原生的潜在动作预测接口，避免引入独立的动作生成或参考轨迹推理模块。
  - 上下文门控设计将"检索（cross-attention）"与"注入（gated residual）"解耦，更灵活地保留专家的连续动作建模能力。
  - 训练时使用真实潜在动作、推理时使用预测潜在动作的设计简洁且无需在部署时依赖 OAT。
- **实验完善**：
  - 多个基准、多种基线、细粒度消融与门控行为可视化分析结合。
  - 真实世界实验中两种方法使用完全相同的演示、超参与评估协议，对比公平。
- **可解释性**：通过阶段级与回合级可视化展示了门控的自适应行为，提升了模型透明度。

## 8. 不足与局限

- **真实世界验证范围有限**：仅在一个桌面级 Pick-and-Place 与一个 Block Stacking 任务上进行评估，且每任务仅 50 条演示数据、单一机器人平台（UR7e），不足以支撑广泛的现实推广性结论。
- **固定潜在动作时长的限制**：$H_l$ 在 LIBERO 与 LIBERO-Plus 上均被设置为常数，无法根据任务阶段自适应调整，可能不匹配更长或更多样化的操作场景。
- **潜在动作预测的可靠性问题**：当 VLM 预测的潜在动作不准确时，门控机制虽能部分缓解，但仍可能导致失败；论文未深入分析失败案例与潜在动作质量的关联。
- **依赖特定骨干**：实现基于 π0.5 架构，对其他 VLA 框架的通用性未充分验证。
- **超参选择与公平性**：真实世界任务中两个任务使用了不同的学习率（Pick-and-Place $1.25 \times 10^{-5}$，Block Stacking $5 \times 10^{-5}$），虽保持方法间一致，但可能掩盖任务级别的泛化结论。
- **可解释性边界**：门控可视化仅为描述性分析，作者也明确指出其不构成因果证据，因果贡献仍依赖消融实验。
