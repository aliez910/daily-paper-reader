## 摘要
类似于人类依次学习新任务的自然能力，具备视觉-语言-动作（VLA）模型的机器人应拥有终身学习能力，以便在开放世界环境中部署时学习新任务。然而，近期提出的多数终身学习模型侧重于有效学习当前任务（可塑性）或在先前任务上保持高精度（稳定性），而可塑性-稳定性权衡这一难题在机器人操作模型中尚未得到妥善解决。为应对这一根本性挑战，我们提出了一种面向机器人操作的高效缓存终身视觉-语言-动作学习框架（即LifelongVLA），该框架通过双时间尺度自适应机制缓解可塑性-稳定性权衡问题，同时借助高效缓存的回放策略实现低成本的机器人部署。具体而言，我们提出了一种双时间尺度LoRA门控模块，将VLA自适应过程分解为两条轻量化路径：用于可塑性的短期适配器与用于稳定巩固的长期适配器。这两条路径通过任务感知门控进行融合，实现对可塑性-稳定性权衡的显式调控。在技能回放阶段，我们提出了一种高效缓存的随机回放策略，无需存储完整轨迹即可保留更为均衡的记忆信号。最后，实验结果表明，LifelongVLA优于现有基线方法，展现出高效的技能扩展能力、对已学操作行为的鲁棒保持能力，并显著降低xArm机器人真实部署中对重新训练的依赖。

## Abstract
Similar to the natural capabilities of humans to sequentially learn new tasks, robots with Vision-Language-Action (VLA) models should possess lifelong learning ability to learn a new task when deployed in open-world environments. However, most recently proposed lifelong learning models aim to effectively learn the current task (plasticity) or maintain high accuracy on previous tasks (stability), while the plasticity-stability trade-off remains largely unsolved in robotic manipulation models. To address this fundamental challenge, we propose a cache-efficient lifelong Vision-Language-Action learning framework for robotic manipulation (i.e., LifelongVLA), which alleviates the plasticity-stability trade-off with a dual-timescale adaptation mechanism while achieving low-cost robotic deployment with a cache-efficient replay strategy. More concretely, we propose a dual-timescale LoRA gating module to decompose VLA adaptation into two lightweight pathways: a short-term adapter for plasticity and a long-term adapter for stable consolidation. These pathways are integrated via a task-aware gate, enabling explicit control of the plasticity-stability trade-off. In the skill replay phase, a cache-efficient stochastic replay strategy is proposed to preserve more balanced retention signals without full-trajectory storage. Finally, experiments show that LifelongVLA outperforms existing baselines, demonstrating efficient skill expansion, robust retention of learned manipulation behaviors, and reduced reliance on retraining for real-world deployment on an xArm robot.

# LifelongVLA 论文总结

## 1. 核心问题与研究动机

- **背景**：视觉-语言-动作（VLA）模型（如 RT-2、Octo、π0 等）已成为语言条件机器人操作的主流范式，但其当前主流训练范式为**静态离线训练**：在固定数据上训练一次后部署，不再更新，难以适应开放世界中新物体、新指令、新场景的连续涌现。
- **核心问题**：机器人需要像人类一样**终身学习（lifelong learning）**，即在部署后持续获取新技能的同时保持旧技能。但现有终身学习方法普遍难以解决 **可塑性-稳定性权衡（plasticity-stability trade-off）**：
  - 高可塑性 → 快速学习新技能，但易覆盖（catastrophic forgetting）旧技能；
  - 高稳定性 → 保留旧技能，但限制新技能学习。
- **现有方案的不足**：
  - 顺序微调（SFT）直接导致灾难性遗忘；
  - 保留全部历史数据重训练 → 内存与算力代价过大；
  - 经验回放（ER）类方法需要存储和重编码图像丰富的完整轨迹，对大 VLA 骨干而言开销巨大；
  - 架构扩展类方法（如 AtomicVLA）增加路由开销与推理延迟；
  - 信息论正则化（Info-VLA）等方法对权衡问题处理仍不充分。
- **本文关注**：在**有限重放预算**下，既要显式平衡可塑性-稳定性，又要降低重放开销。

## 2. 方法论

### 2.1 整体框架
- 名为 **LifelongVLA**，基于**冻结骨干网络**（PaliGemma + Gemma 2B + Gemma 300M 连续动作解码器），针对 7D 机器人动作。
- 包含两个核心模块：
  1. **双时间尺度 LoRA 门控（Dual-Timescale LoRA Gating）**：显式调控可塑性-稳定性；
  2. **缓存高效随机回放（Cache-Efficient Stochastic Replay）**：以紧凑前缀缓存代替完整轨迹存储。

### 2.2 双时间尺度 LoRA 门控

- **思想**：将单一的 LoRA 适配路径拆为**短期（plasticity）**与**长期（stability）**两条独立通路，分别针对新技能与旧技能。
- **公式层面**：
  - 在第 $\ell$ 层定义：$\Delta W^{sh,l}_t = A^{sh,l}_t B^{sh,l}_t$，$\Delta W^{lg,l}_t = A^{lg,l}_t B^{lg,l}_t$；
  - 短期 LoRA 用**当前任务去噪损失** $\mathcal{L}_{new}$ 更新，学习率 $\eta_{sh}$ 较高；
  - 长期 LoRA 仅用**回放损失** $\mathcal{L}_{rep}$ 与**蒸馏损失** $\mathcal{L}_{dist}$ 更新，学习率 $\eta_{lg}$ 较低（$\eta_{lg}<\eta_{sh}$），使其演化更慢、保持稳定。
- **任务感知门控（task-aware gate）**：
  - 为了避免"门控依赖自身权重"的循环依赖，**门控上下文 $c$ 从冻结的前缀特征**计算：$c = \text{Pool}(\text{stopgrad}(E_{pre}(u; \Theta_0)))$；
  - 每一层通过 $\alpha^l_t(c) = \sigma(W^l_g \phi^l(c) + b^l_g)$ 预测长期路径的权重；
  - **权重级融合**：$\widetilde{\Delta W}^l_t(c) = (1-\alpha)\Delta W^{sh,l}_t + \alpha \Delta W^{lg,l}_t$；
  - 因在权重空间融合，**推理仍只需单次前向**。
- **效果**：$\alpha \to 0$ 强调新技能塑性，$\alpha \to 1$ 强调旧技能稳定。

### 2.3 缓存高效随机回放

- **核心思路**：不存储完整图像轨迹，只存储**前缀 token（prefix cache）** + **紧凑状态-动作监督**，回放时用**当前模型**重计算后缀。
- **缓存内容**：对每个已完成任务，随机选 $c_t$ 个样本，仅保存 `stopgrad(prefix hidden state) + robot state + action`；不存原始图像、文本 token、后缀 token、扩散时间或噪声。
- **随机回放过程**：
  - 对缓存样本 $(\bar{h}^{pre}_j, s_j, y_j)$，每步**重新采样** $\tau'_j \sim p(\tau)$，$\epsilon'_j \sim \mathcal{N}(0, I)$，构造噪声动作 $\tilde{y}^{rep}_j = q_{\tau'}(y_j, \epsilon'_j)$；
  - 用当前模型重计算后缀：$h^{suf,rep}_{j,t} = E_{suf}(s_j, \tilde{y}^{rep}, \tau'; \widetilde{\Theta}_t(c^{rep}_j))$；
  - 这样**一个缓存前缀可生成多个随机回放实例**，既减少存储又提高回放信号多样性。
- **目标函数**（掩码混合）：
  - 当前样本与回放样本拼接打乱，按 replay mask $m_i$ 分别归一化 $\mathcal{L}_{new}$、$\mathcal{L}_{rep}$；
  - 蒸馏项：使用上一任务的**冻结教师模型快照** $\bar{F}_{t-1}$ 计算 $\mathcal{L}_{dist}$，稳定旧技能预测；
  - 总损失：$\mathcal{L}_t = \mathcal{L}_{new} + \lambda \mathcal{L}_{rep} + \beta \mathcal{L}_{dist}$。

## 3. 实验设计

### 3.1 数据集与基准
- **基准**：LIBERO 基准中选取 **10 个任务**进行增量技能学习；
