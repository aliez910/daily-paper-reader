## 摘要
视觉-语言-动作策略是通用机器人控制的有力基础，但长时序人形机器人运动-操作任务要求机器人将任务物体视为在运动、接触、遮挡与恢复过程中持续存在的物理实体。我们将该问题建模为物体状态发散：用于条件化全身动作的物体状态，可能与用于判定动作是否达成预期物理关系的状态之间存在差异。为此，我们提出了\emph{可持久化物体令牌化}（POT），该方法从 RGB-D 观测中维护按角色索引的三维物体记录，并将其转化为用于全身动作专家网络的物体令牌。在 \emph{POT-VLA} 的实例化中，相同的物体记录既用于条件化动作生成，也支持几何谓词检查，从而构成了一个物体状态既可驱动动作又可被验证的闭环执行系统。在 Unitree G1 机器人上，POT-VLA 将同等条件下的直接 GR00T-N1.7 基线在八类真实任务上的成功率从 39/80 提升至 71/80。在与 Being-0 对齐的外部参考评估中，POT-VLA 在对齐的服务类任务上取得了 44/50 的成功率，而 Being-0 论文报告的结果为 37/50。最大的性能提升出现在那些需要维持三维空间关系的任务上，这表明以可持久化的物体为中心的状态是实现可验证人形机器人视觉-语言-动作执行的一种有效抽象。

## Abstract
Vision-language-action policies are a promising foundation for general robot control, but long-horizon humanoid loco-manipulation requires the robot to treat task objects as persistent physical entities across movement, contact, occlusion, and recovery. We study this problem as object-state divergence: the object state used to condition a whole-body action can differ from the state used to decide whether the action achieved the intended physical relation. We propose \emph{Persistent Object Tokenization} (POT), which maintains role-indexed 3D object records from RGB-D observations and converts them into object tokens for a whole-body action expert. Instantiated as \emph{POT-VLA}, the same object records condition action generation and support geometric predicate checks, yielding a closed-loop execution system in which object state is both actionable and verifiable. On a Unitree G1, POT-VLA improves a matched direct GR00T-N1.7 baseline from 39/80 to 71/80 successes over eight real-world task families. In an external Being-0-aligned reference, POT-VLA achieves 44/50 successes on aligned service tasks, compared with the 37/50 success reported by the Being-0 paper. The largest gains occur on tasks requiring maintained 3D relations, suggesting that persistent object-centered state is a useful abstraction for verifiable humanoid VLA execution.

# 论文总结：闭环人形机器人视觉-语言-动作模型——用于可验证运动-操作的可持久化三维物体令牌

## 1. 核心问题与研究动机

- **研究背景**：视觉-语言-动作（VLA）策略已成为通用机器人控制的重要基础。然而，长时序的人形机器人"运动-操作"（loco-manipulation）任务（如"整理桌面""给我拿杯饮料"）要求机器人在行走、伸手、抓取、放置、观察失败、恢复的过程中，将任务涉及的同一物体（杯子、篮子、支撑面、交接伙伴等）作为**持续存在的物理实体**来寻址和操作。
- **核心问题——物体状态发散（Object-State Divergence）**：现代 VLA 策略通常基于当前观测的视觉-语言特征来条件化动作生成，而任务进度的检查则可能由独立的监控器、谓词层或语言级状态模块承担。当**驱动动作的物体状态**与**验证动作结果的物体状态**不一致时，即使指令被正确理解，小的抓取/放置误差也会导致子任务提前切换、错误物体被操作，或恢复失败。
- **根本原因**：物体在度量三维空间中运动、与手或支撑面发生接触、进入容器、被遮挡——这本质上是**物理性问题**，仅靠语义层面的视觉-语言特征难以解决。因此需要一种"以物体为中心的、跨时间持续的、可被动作策略使用、也可在执行后被验证"的物体状态表征。

## 2. 方法论

### 2.1 核心思想：Persistent Object Tokenization（POT）

- **核心思想**：将任务相关物体从 RGB-D 观测中"提升"为**按角色索引的 3D 物体记录**，并将这些记录序列化为一组 **Persistent 3D Object Tokens**，注入到全身动作专家网络的输入序列中。同一份物体记录在执行前被动作策略消费，在执行后被几何谓词验证器消费，从而构成 **ground–act–refresh–verify–recover** 的闭环。
- **关键模块**：
  - **任务角色物体记录（Task-role Object Records）**：从 VLM 规划器或人工编写的类型化子任务计划 Π = ⟨task_id, I, {τ_i}⟩ 出发，为当前活动子任务 τ_i 构建物体记忆 $M_t^{\tau_i} = \{m_e^t \mid e \in E_i\}$，每条记录包含：角色、文本短语、2D 框、3D 质心与范围、置信度、可见性、关系特征。实现中由 SAM3 提供按角色/查询的掩码，将有效深度像素反投影到机器人基坐标系。
  - **Persistent Token Schema**：将物体记忆映射为固定槽位的特征张量 $x_t^{obj} = T(M_t^{\tau_i}) \in \mathbb{R}^{K \times F}$，默认 **K=8 槽位，F=33 特征**。有效槽位对应 TARGET、DESTINATION、SUPPORT、HANDOVER_PARTNER 等角色 ID，无效槽位标记为 PADDING 并被掩码。
  - **角色感知物体投影（Role-aware Object Projection）**：每槽位包含 $[v_k, q_k, b_k, c_k, s_k, o_k, \rho_k]$，对应可见性、置信度、2D 框、3D 质心、3D 范围、可选朝向和关系特征。投影器结构为 LayerNorm → Linear → GELU → Dropout → Linear，将每个槽位嵌入到 DiT 隐藏维度 $Z_t^{obj} \in \mathbb{R}^{K \times d}$，并叠加可学习的角色嵌入与上下文嵌入。
  - **动作头插入（Action-head Insertion）**：将物体令牌插入到 DiT 动作头的自注意力序列中，序列布局为 $S_t = [Z_t^{state}, Z_t^{obj}, Z_t^{action}]$，视觉-语言骨干特征 $Z_t^{vl}$ 作为交叉注意力的编码器隐藏状态。动作专家预测 $\hat{a}_{t:t+H} = \pi_\theta(S_t, Z_t^{vl})$。
  - **训练**：沿用基础动作专家的动作块预测目标，**不引入额外的物体记忆或谓词损失**。在物体令牌微调阶段，演示数据附带同构的角色感知 RGB-D 侧车（sidecar），使动作头在训练时即观察对齐的语言-本体-视觉-物体负载。物体令牌分支梯度与启用的动作头参数一同更新。
- **几何谓词验证与恢复（Predicate-Level Verification & Recovery）**：在执行完一个块到达 $t^+ = t + H$ 后，RGB-D 刷新同一份物体记忆为 $M_{t^+}^{\tau_i}$。谓词集合 $\Psi_i$ 覆盖包含、支撑、末端-目标邻近度、目标-目的地位移、双手机分配、交接伙伴距离等。每个谓词表示为 $p = \langle \kappa, \alpha, op, \nu, n \rangle$，包括谓词类型、对象记录参数、比较算子、阈值和所需稳定窗口。监督器输出 {in_progress, done, blocked, failed, uncertain}，并返回定位失败模式的诊断 $d_\xi$。系统据此选择 {continue, retry, reobserve, reground, replan}；语义层面歧义可由 VLM 验证器补充判断，但可靠的几何谓词优先。

### 2.2 关键算法流程（文字描述）

1. 接收指令 I 与类型化子任务计划 Π；
2. 对当前活动子任务 τ_i，从 RGB-D 观测构造角色索引物体记忆 $M_t^{\tau_i}$；
3. 序列化为 Persistent 3D Object Tokens $x_t^{obj}$；
4. 投影到 $Z_t^{obj}$ 后与状态/动作令牌一起送入 DiT 动作头，预测候选动作块 $\hat{a}_{t:t+H}$；
5. 经运行时校验（命令平滑、关节/速度限制、平衡检查、工作空间约束、紧急停止）后执行 $a_{t:t+H}$；
6. 执行完毕用新观测刷新 $M_{t^+}^{\tau_i}$，几何谓词检查物理一致性；
7. 根据验证结果（done/blocked/failed/uncertain）决定继续、重试、重观察、重定位或重规划。

## 6. 主要结论与发现

- **总体性能**：POT-VLA 在 8 类任务上将直接 GR00T-N1.7 基线从 **39/80 提升至 71/80**；在 Being-0 对齐服务任务上以 **44/50** 超过 Being-0 论文报告的 **37/50**。
- **最大收益出现在需维持三维关系的任务**：堆叠三个杯子（1/10 → 8/10）、双球放置（5/10 → 9/10）、衣物入篮（3/10 → 9/10）、抽屉/托盘放置关闭（4/10 → 8/10）以及手推车运输放置（3/10 → 8/10）；交接等接近上限的任务增益较小。
- **失败模式分析**：直接基线的失败多为度量级物体状态错误（手柄/携带物抓取点不准、堆杯对位偏差、分拣漏检小球、放置越界等），并非语义层面的指令理解错误；POT-VLA 通过重新观察/重新定位/重试/重规划避免静默推进。
- **消融结论**：在 4 任务 × 40 次消融中，POT 令牌单独带来最大提升（15/40 → 31/40），几何谓词验证单独提升至 22/40，完整 POT-VLA 达到 34/40。表明"物体令牌"主要解决**动作生成前的定位问题**，"谓词验证"主要捕获**残留的虚假完成与部分失败**。
- **泛化结论**：在新物体实例、位姿/布局偏移、中途扰动下 POT-VLA 优势最大（4/10 → 8/10，6/10 → 9/10，5/10 → 9/10）；在干扰物场景下两者差距较小（8/10 → 9/10），说明自然办公室杂乱环境下干扰物已普遍存在。
- **核心论断**：以可持久化、角色索引、以物体为中心的三维状态是可验证人形机器人 VLA 执行的一种有用抽象。
