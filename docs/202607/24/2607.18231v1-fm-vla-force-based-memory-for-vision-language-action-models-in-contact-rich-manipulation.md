## 摘要
视觉-语言-动作（VLA）模型在机器人操作中已展现出卓越的泛化能力，而近期引入记忆机制的VLA通过将过去的图像或语言摘要作为条件输入，弱化了马尔可夫假设。基于视觉的记忆方法通过将采样的过去图像帧作为条件来解决这一问题，但这类方法计算开销大，且在时序事件存在视觉歧义时存在根本性局限，例如多次小幅推按按钮等场景。我们提出FM-VLA，一种具备基于力矩记忆的VLA模型，使其能够在非马尔可夫、接触丰富的操作任务中进行时序上下文推理。我们利用一个以力时间序列重构为训练目标预训练得到的变分自编码器（VAE），将力历史编码为紧凑的力矩记忆标记。通过将力矩的潜在表示与短时状态历史作为额外的条件标记投影至动作专家模块，使VLA能够利用累积的接触事件历史来引导操作。我们在三项依赖记忆的任务上对FM-VLA进行了评估，包括寻找隐藏方块、按按钮以及按指定次数擦拭盘子。我们的轻量化力矩记忆模块在极低的推理开销下取得了超过80%的成功率，显著优于基线方法。项目页面：https://qft-333.github.io/FM-VLA-Page/

## Abstract
Vision-language-action (VLA) models have achieved impressive generalization in robotic manipulation, and recent memory-augmented VLAs have relaxed the Markovian assumption by conditioning on past images or language summaries. Vision-based memory approaches address this by conditioning on sampled past image frames, but they are computationally expensive and fundamentally limited when temporal events are visually ambiguous, e.g., pushing a button multiple times with small movements. We propose FM-VLA, a VLA model with force-based memory, enabling temporal context reasoning for non-Markovian, contact-rich manipulation. We encode force histories into compact force memory tokens with a variational autoencoder (VAE) pretrained with force time series reconstruction. By projecting force latent representations and short state history as additional conditioning tokens to the action expert module, we enable VLAs to leverage accumulated contact event history to guide manipulation. We evaluate FM-VLA on three memory-dependent tasks, including finding a hidden block, pressing a button, and wiping a dish for a specific number of times. Our lightweight force memory achieves over 80% success rate with minimal inference overhead, significantly outperforming baseline approaches. Project page: https://qft-333.github.io/FM-VLA-Page/

# FM-VLA 论文总结

## 1. 核心问题与整体含义

**研究背景与动机**

- 视觉-语言-动作（VLA）模型（如 RT-2、OpenVLA、π0/π0.5）已在机器人操作中展现出强大的泛化能力，但绝大多数基于"马尔可夫假设"，仅以当前观测映射到下一步动作，无法处理需要长期时序上下文的非马尔可夫任务（如计数按按钮 N 次、找被杯子遮盖的隐藏积木、擦拭 N 个来回等）。
- 现有记忆增强方法（MemoryVLA、MEM 等）主要依赖**视觉记忆**：采样历史图像帧或视频特征加入条件输入，存在两个根本缺陷：
  1. **视觉歧义**：当接触动作位移极小（如按钮按压、擦拭）时，视觉信号几乎无变化，无法区分一次和多次接触；
  2. **算力开销大**：多帧图像 token 显著增加推理延迟（100–190 ms）。
- 力/力矩（wrench）信号天然包含接触事件、力大小、作用次数等"不可视见却真实存在"的交互信息，比视觉更适合作为记忆载体。但现有力增强 VLA（ForceVLA、TA-VLA）仅把力矩作为**短时即时条件**（用于当前动作的纠偏），未将其作为**长程历史记忆**。

**核心目标**：将力矩流改造为 VLA 的"长期记忆模块"，在视觉模糊的接触密集场景下实现非马尔可夫决策，同时保持极低推理开销。

---

## 2. 方法论

**整体思路**：在 π0.5（VLM 为 PaliGemma + SigLIP，动作专家为 flow-matching）的基础上，引入两条本征信号流，并通过 VAE 压缩 + token 注入的方式融合到动作专家。

**两条互补的本体感知流**

| 信号流 | 内容 | 角色 |
|---|---|---|
| 长期力矩历史 $\{f_\tau\}_{\tau=1}^{t}$（6 维，3 轴力+3 轴力矩） | 整个回合的接触事件累积 | 提供"记忆"：接触次数、时刻、幅值 |
| 短期状态窗口 $\{s_\tau\}_{\tau=t-W+1}^{t}$（关节位置+夹爪状态） | 最近约 1 秒的运动 | 提供"运动感知"：避免接触前的重复震荡 |

**两阶段训练框架**

**Stage 1：力矩 VAE 预训练（task-agnostic）**
- 架构：Perceiver-IO 编解码器，$K=8$ 个可学习潜变量 query token，潜变量维度 $d_z=96$。
- 预处理：
  - 一阶 EMA 平滑：$\tilde f_\tau = \alpha f_\tau + (1-\alpha)\tilde f_{\tau-1}$，$\alpha=0.3$，抑制高频噪声；
  - 分位数归一化（按数据集 q01/q99 统计）；
  - 训练时随机前缀填充低幅高斯噪声（最长 1000 帧 ≈10 s），消除"序列长度泄露回合进度"的捷径；推理时关闭。
- 目标函数（masked-ELBO + free-bits KL 正则）：
  
  $$\mathcal{L}_{\text{VAE}}=\frac{1}{\sum_\tau m_\tau}\sum_\tau m_\tau\|f_\tau-\hat f_\tau\|^2 + \beta\cdot\frac{1}{K d_z}\sum_{k,j}\max\!\big(D_{\text{KL}}^{(k,j)},\lambda\big)$$

- 所有任务联合训练 + 反频率任务采样，避免小数据集被淹没。

**Stage 2：VLA 微调**
- 冻结 VAE 编码器，推理时仅用后验均值 $\mu_f$（无重参数化噪声）；
- 通过零初始化线性层 $W_f$ 将 $\mu_f \in \mathbb{R}^{8\times d_z}$ 提升为 $K=8$ 个力矩记忆 token $Z_f \in \mathbb{R}^{8\times d_h}$；
- 短期状态窗口（10 帧，步长 3）经零初始化线性投影为单个 token $z_s$；
- **记忆 token 注入位置**：动作 expert 的 suffix 拼接顺序为
  
  $$[\text{noisy-action tokens}] \;\|\; [Z_f^{(1)},\dots,Z_f^{(K)}] \;\|\; [z_s]$$
  
  这样保证 noisy-action token 的 RoPE 位置与 π0.5 预训练一致，避免破坏 base policy；
- 微调目标遵循 π0.5 的 rectified flow 配方，但条件中加入 $Z_f, z_s$。

**为何用 VAE 而非端到端 GRU/Q-Former**：消融显示，长程 100 Hz 力序列上 GRU 出现梯度消失（擦盘仅 5.6%），Q-Former 过拟合瞬时峰值（55.6%），而 VAE 通过重构损失迫使潜空间编码宏观结构（幅值、起始、计数），更适合下游策略利用。

## 6. 主要结论与发现

**核心性能（平均成功率）**
| 方法 | Task 1 找积木 | Task 2 按按钮 | Task 3 擦盘 | 平均 |
|---|---|---|---|---|
| π0.5（无记忆） | 72.2 | 11.1 | 0.0 | 27.8 |
| TA-VLA | 50.0 | 11.1 | 5.6 | 22.2 |
| π-MEM（视觉记忆） | 77.8 | 33.3 | 50.0 | 53.7 |
| **FM-VLA（VAE）** | **100.0** | **72.2** | **77.8** | **83.3** |

**关键发现**
1. 视觉记忆在视觉歧义任务（按按钮）上严重失效（33.3% vs 72.2%），而力矩记忆天然区分接触次数；
2. 力矩与状态互补：仅力矩导致接触前动作震荡（25.9%），仅状态无法计数（40.7%），二者融合至关重要；
3. VAE 显著优于 GRU/Q-Former（83.3% vs 33.3% vs 57.4%），证明"预训练重构"对长程力序列表征学习的必要性；
4. Token 容量存在 sweet spot：$K=8$ 最优，$K=4$ 信息瓶颈，$K=16,32$ 超出 π0.5 base 训练的最大 50 token 预算，引起分布漂移；
5. 推理延迟 64 ms（vs π0.5 60.7 ms），仅 +3.3 ms 开销，远低于 π-MEM 的 +39.1 ms（K=5）/ +129.3 ms（K=16）。

## 7. 优点

1. **范式创新**：首次将腕部力矩流作为长期记忆而非即时条件，弥补了视觉记忆在接触密集任务上的根本缺陷；
2. **两阶段 VAE 预训练策略**：通过无标签的力时间序列重构任务得到通用结构化潜空间，避免了端到端难以学习长序列模式的难题；
3. **力矩+状态双流互补**：用短期本体感知抑制长期力记忆可能引发的"接触前重复震荡"伪影，设计精巧；
4. **注入位置精心**：记忆 token 放在 noisy-action 之后，保留 base policy 的 RoPE 位置，保护预训练表示；
5. **去捷径设计**：随机噪声前缀填充阻止模型通过序列长度作弊，体现对数据偏置的敏锐性；
6. **效率优势明显**：仅 +3.3 ms 延迟即可换来 +30 pp 平均成功率；
7. **实验充分**：模态、架构、容量、效率四维度消融齐全，基线复现与公平性处理规范。

5. **模态局限性**：力矩无法捕捉物体被遮挡后的纯视觉变化（如杯子位置），对完全非接触式记忆任务（如视觉搜索）天然不适用；
6. **未深入分析失败案例**：按按钮任务 27.8% 失败中，未区分"少按/多按"的具体错误模式；
7. **缺乏用户研究/视频证据**：附录仅给出"supplementary video"提示，但主文未呈现更多轨迹细节或可视化；
8. **数据规模偏小**：每个任务 200–350 条演示，远低于大规模 VLA 训练量，可能存在过拟合风险。
