## 摘要
扩散策略在机器人模仿学习领域展现出强大的潜力，近期的扩展工作通过引入额外的模态来提升操作性能。然而，这些模态不仅在信息内容上存在差异，在感知速率和推理延迟上也各不相同。现有的多模态扩散策略通常依赖同步融合或人工设计的多频率架构，这要么会降低高频反馈的响应速度，要么会限制其向新模态组合的可扩展性。为此，我们提出了 LAG-Fusion，一种面向异步多模态扩散策略组合的延迟感知引导融合框架。LAG-Fusion 允许各模态专属的策略以其原生推理速率运行，并在可用时提供去噪引导。为了使异步组合保持一致性，我们推导出在相对动作表征下扩散变量的参考系重基准规则，从而使得延迟的引导在融合前能够被对齐。我们在接触丰富的操作任务中实例化 LAG-Fusion，将低频视觉策略与高频力策略进行组合。在异构模态延迟下的实验表明，LAG-Fusion 在策略响应速度和任务性能方面均优于同步融合以及专门设计的力感知基线方法。

## Abstract
Diffusion policies have shown strong potential for robotic imitation learning, and recent extensions incorporate additional modalities to improve manipulation performance. However, these modalities often differ not only in information content but also in sensing rates and inference latencies. Existing multimodal diffusion policies typically rely on synchronous fusion or manually designed multi-frequency architectures, which either slow down high-frequency feedback or limit extensibility to new modality combinations. We propose LAG-Fusion, a latency-aware guidance fusion framework for asynchronous multimodal diffusion policy composition. LAG-Fusion allows modality-specific policies to operate at their native inference rates and contribute denoising guidance whenever available. To make asynchronous composition consistent, we derive a reference-frame rebasing rule for diffusion variables under relative action representations, enabling delayed guidance to be aligned before fusion. We instantiate LAG-Fusion in contact-rich manipulation by composing a low-frequency vision policy with a high-frequency force policy. Experiments under heterogeneous modality latencies show that LAG-Fusion improves policy responsiveness and task performance over synchronous fusion and specially designed force-aware baselines.

# LAG-Fusion 论文总结

## 1. 核心问题与研究背景

- **核心问题**：多模态扩散策略中，不同模态（视觉、力/力矩、触觉、音频等）在**采样频率**和**推理延迟**上存在显著异构性，但现有融合方法无法兼顾响应速度与可扩展性。
- **关键矛盾**：
  - **同步融合**（Joint Multimodal Fusion）：所有模态必须在同一时刻对齐后送入统一策略网络，整体控制频率受限于**最慢模态**，导致力觉等轻量级高频信号被迫降速，无法发挥原生控制能力。
  - **手工多频率架构**（Slow-Fast / 双系统设计）：如 RDP、FOAR 等需要从零设计专用架构与推理调度，**难以扩展到新模态组合**，且不具备模块化复用性。
- **实际痛点**：在接触丰富的操作（Contact-rich Manipulation）如插入、打磨、翻转任务中，力/力矩反馈变化剧烈、稳定物理交互需要**高频局部修正**，但视觉感知/推理管线较重，二者天然异速。
- **核心洞察**：应将模态专属推理与最终动作生成分离开，利用扩散模型的去噪引导（guidance）作为天然融合接口，使各模态按自身节奏产出引导信号。

## 2. 方法论：LAG-Fusion 框架

### 2.1 核心思想
- 借鉴 **diffusion composition** 的思路，将每个模态的去噪预测 $\varepsilon_k$ 视为引导项，允许模态专属的扩散策略以**原生推理速率**运行，并在需要融合时通过**参考帧重映射（Reference-Frame Rebase）**对齐后做加权组合。

### 2.2 关键技术与流程

**（1）同步扩散策略组合的回顾**
- 给定噪声动作 $a_k = \sqrt{\bar\alpha_k}a_0 + \sqrt{1-\bar\alpha_k}\varepsilon$，两模态分别预测 $\varepsilon^V_k = \pi_V(a_k,k;c^V)$ 与 $\varepsilon^F_k = \pi_F(a_k,k;c^F)$。
- 同步组合公式：

$$\varepsilon_k = \frac{w_V}{w_V+w_F}\varepsilon^V_k + \frac{w_F}{w_V+w_F}\varepsilon^F_k$$

- 随后执行 DDIM 更新 $a_{k-1}=\text{DDIMStep}(a_k,\varepsilon_k,k)$。

**（2）相对动作表征下的参考帧重映射（Rebase）**
- 采用 **relative action chunks**（动作以查询时刻的末端位姿为基准），便于局部反馈。
- 设 $T_1\to T_2$ 的变换为 $T_{2\leftarrow 1}=(R_{2\leftarrow 1}, p_{2\leftarrow 1})$。
- 动作表示为 $a=[x^\top, R^\top_{6d}, g]^\top\in\mathbb{R}^{10}$（3D 平移 + 6D 列式旋转 + 夹爪）。
- 重映射仿射变换：

$$a' = A_{2\leftarrow 1}a + b_{2\leftarrow 1}$$

- 其中 $A_{2\leftarrow 1}=\text{blockdiag}(R_{2\leftarrow 1},R_{2\leftarrow 1},R_{2\leftarrow 1},1)$ 为正交矩阵，$b_{2\leftarrow 1}$ 包含平移偏移（旋转和夹爪分量为零）。

**（3）扩散变量的差异化变换规则**（关键理论贡献）：
- 干净动作 $a_0$：全仿射变换；
- 噪声样本 $a_k$：$a'_k = A_{2\leftarrow 1}a_k + \sqrt{\bar\alpha_k}b_{2\leftarrow 1}$（偏移带 $\sqrt{\bar\alpha_k}$ 缩放因子）；
- 预测噪声 $\varepsilon_k$：**仅** $A_{2\leftarrow 1}\varepsilon_k$（正交线性变换，保持标准高斯协方差不变）。
- 这一区分保证了异步去噪预测在数学上的一致性。

**（4）异步策略组合流程（LAG-Fusion）**：
1. 低频视觉策略在 $t_1$ 时刻查询，预测全视界引导 $\varepsilon^V_k$（帧 $T_1$）。
2. 高频力策略在 $t_2>t_1$ 时刻查询，先将选定的重叠视界段 $S(a_k)$ 按 Eq.(7) 重映射到帧 $T_2$；
3. 力策略在 $T_2$ 帧去噪得到 $\varepsilon'^F_k$；视觉引导对应段也重映射为 $\varepsilon'^V_k = A_{2\leftarrow 1}S(\varepsilon^V_k)$；
4. 在 $T_2$ 帧加权融合，再映射回 $T_1$ 更新完整视界噪声，执行 DDIM 更新。

**（5）延迟感知权重（Latency-Aware Weights）**：
- 沿选定视界采用**线性调度**：视觉权重从 $w^V_{start}=0.8$ 递减至 $w^V_{end}=0.2$，力权重互补递增。
- 直观解释：早期动作依赖全局视觉（更新次数少），后期动作依赖高频力的局部修正（更新更及时）——以延迟作为置信度代理。

## 3. 实验设计

### 3.1 任务与平台
- **机器人**：Flexiv Rizon4 + FT03S 六维力/力矩传感器。
- **任务（2 个）**：
  - **Flip**：推送小盒与大盒建立接触并翻转。
  - **Polish Curve**：沿曲线轨迹打磨接触面，考核接触稳定性。
- **演示数据**：每任务 **50 条** arm-to-arm 遥操作示教（含力觉反馈）。
- **数据流**：RGB-D @20 Hz，力/力矩 @1000 Hz。

### 3.2 实例化构成
- **视觉策略**：RISE [Wang et al., 2024]，动作改为相对末端位姿坐标系。
- **力策略**：MLP 编码 1s/100步 力历史（6 维力/力矩通道）→ U-Net（[32,64] 通道）扩散去噪；动作块 50 步 @50 Hz。

### 3.3 对比基线（6 个）
| 类别 | 方法 | 关键特性 |
|------|------|----------|
| 视觉基线 | RISE | 纯视觉，2 Hz |
| 融合基线 | Training-Time Noise Fusion | 训练时融合，5 Hz |
| | Synchronous Composition | 同步推理融合，5 Hz |
| | Policy Consensus [Chen et al., 2026] | 同步+学习路由，5 Hz |
| 代表性多模态 | TA-VLA [Zhang et al., 2025] | VLA+触觉，1 Hz |
| | RDP [Xue et al., 2025] | Slow-Fast 设计，24 Hz |

### 3.4 评价指标
- **Flip**：Push（是否推到目标）+ Flip（完成翻转，翻一半计半成功），各 20 次试验。
- **Polish Curve**：Contact（接触建立）+ Score（按擦除完整度分 1.0/0.75/0.25/0）。

## 6. 主要结论与发现

### 6.1 核心性能结论
- **LAG-Fusion 总体最佳**（Table 1）：
  - Flip 成功率：**60.0%**（次优 RDP 35.0%，基线≤40%）；
  - Polish Curve Score：**55.0%**（次优 RDP 45.0%）；
  - Push / Contact 两个次指标接近最优（95-100%）。
- **异步融合优于同步融合**：同步组合将所有模态限制在 5 Hz，浪费了力觉的高频潜力；LAG-Fusion 通过异步组合 + 延迟感知权重全面胜出。

### 6.2 频率相关发现
- **独立力策略**：输入与推理频率越高，成功率越高——验证了"高频轻量模态在原生速率下才能充分发挥控制能力"。
- **LAG-Fusion 全框架**：保持高频推理亦能提升组合策略性能，频率红利跨模块生效。

### 6.3 理论发现
- 推导了**参考帧重映射下扩散变量的差异化变换规则**：干净动作为仿射、噪声样本带 $\sqrt{\bar\alpha_k}$ 缩放偏移、预测噪声仅正交线性变换——为异步多模态组合提供了数学一致性保证。

## 7. 优点与亮点

- **理论严密性**：显式推导出 reference-frame rebasing rule，并通过 $A_{2\leftarrow 1}$ 正交性保证噪声高斯分布不变，是少数从原理层解决异步融合一致性问题的论文。
- **模块化与可扩展性**：任何已训练的单模态扩散策略可直接接入，无需重新训练或重新设计架构，真正实现"组合而非重建"。
- **延迟感知权重的设计动机清晰**：将"时间新鲜度"作为置信度代理，沿视界线性衰减，简单可解释且有效。
- **真实机器人实验**：在 Flexiv + 力传感器上端到端验证，包含 50 条演示和 20 次重复试验，并设计了统一初始摆放以保证公平。
- **相对动作表征的选择合理**：与局部反馈场景天然契合，是异步对齐得以成立的物理基础。
- **报告推理时延与频率**：40 ms / 25 Hz 的实测数据增强了工程可复现性。

## 8. 不足与局限

### 8.1 方法局限
- **依赖相对动作表征**：要求策略输出 relative action chunks，若已有策略采用绝对动作则需重新训练或转换。
- **假设力视界包含于视觉视界**：当前实现限定了大小视界嵌套关系，限制了组合自由度。
- **延迟感知权重为线性手工调度**：未与策略联合学习，对复杂场景可能次优。
- **仅适用扩散模型**：作者明确指出扩展至 flow matching（π0、π0.5）等框架留作未来工作。

### 8.2 实验局限
- **任务数量偏少**（仅 2 个），且都在平行夹爪简单几何体上完成——接触动力学欠丰富。
- **试验次数偏少**（20 trials/task），统计显著性论证偏弱，未报告置信区间或方差。
- **未见对极端延迟、网络抖动的鲁棒性测试**，而这正是"延迟感知"宣称应当直接受益的场景。
- **基线 Policy Consensus 在评估中处于劣势**（需要路由器+微调），与 LAG-Fusion 的"无需额外训练"形成天然对比——这种对比虽合理但有失公允，文中已用 † 标注。

### 8.3 应用局限
- **两模态组合**：未探索 ≥3 模态（视觉 + 力 + 触觉 + 音频）的异步组合。
- **未涉及灵巧手与高维动作空间**：作者承认这是明确的方向。
- **未与控制先验结合**：作者提出未来可融入混合力/位控制等经典方法以增强稳定性。

### 8.4 偏差风险
- **演示者偏差**：单次遥操作者策略影响数据分布。
- **物体偏差**：仅 1 个训练见过 + 4 个未见物体，未覆盖材质/形状多样性（如可变形物体）。
- **平台偏差**：Flexiv Rizon4 + FT03S 的特定动力学环境难以直接推广到其他机器人。
