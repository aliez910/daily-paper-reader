## 摘要
模仿学习旨在通过大量观察与示教数据为机器人学习技能,因此面临数据稀缺与环境泛化的难题。现有方法主要侧重于域内任务的模仿,难以泛化至未见任务。为弥合这一泛化差距,我们提出**动力学感知元模仿**(Dynamics-Aware Meta-Imitation, DAMI)框架。通过引入元学习以构建共享技能空间,DAMI使智能体能够快速适应新任务。我们设计了视觉-运动轨迹(Visual-Motor Trajectory, VMT)模块,以在任务潜在空间中捕获复杂的时空动力学信息。此外,我们提出无配对统一任务(Unpaired Unified Task, U2T)模块,以融合非结构化的多模态观测。为协调这些表征,我们集成了面向低级三维特征调制而定制化的任务条件特征调制(Task-Conditioned Feature Modulation, TCFM)机制。通过从随机完整参考示教中捕获内在动力学,我们的框架学习的是任务背后的逻辑机理而非记忆静态线索,从而确保有效的泛化能力。在仿真与真实环境中的大量实验表明,我们的方法在已见任务的直接推理以及通过少样本微调适应未见任务方面均优于当前最先进的基线方法。

## Abstract
Imitation Learning aims to learn skills from extensive observations and demonstrations for robots, so it suffers from data scarcity and environment generalization. The existing methods predominantly focus on imitation from in-domain tasks and consequently struggle with generalization to unseen tasks. To bridge this generalization gap, we propose the \textbf{D}ynamics-\textbf{A}ware \textbf{M}eta-\textbf{I}mitation (DAMI) framework. By integrating meta-learning to construct a shared skill space, DAMI equips agents for rapid adaptation to novel tasks. We introduce the Visual-Motor Trajectory (VMT) module to capture complex spatio-temporal dynamics within the task latent space. Furthermore, we propose the Unpaired Unified Task (U2T) block to fuse unstructured multimodal observations. To coordinate these representations, we integrate a Task-Conditioned Feature Modulation (TCFM) mechanism customized for modulating low-level 3D features. By capturing intrinsic dynamics from a random complete reference demonstration, our framework learns the underlying task logic rather than memorizing static cues, ensuring effective generalization. Extensive experiments in both simulation and real-world settings demonstrate that our approach outperforms state-of-the-art baselines regarding direct inference on seen tasks and adaptation to unseen tasks via few-shot fine-tuning.

# DAMI 论文总结：面向未见机器人操作泛化的动力学感知元模仿学习

## 1. 核心问题与研究动机

- **核心问题**：机器人模仿学习（Imitation Learning, IL）通常需要大量专家示教数据，而数据采集成本高昂；同时现有方法多聚焦于"域内任务"训练，对未见任务（unseen tasks）的泛化能力不足，容易产生**动作误判（Action Misinterpretation）**问题（例如本应推圆柱却执行了"按按钮"动作）。
- **背景与挑战**：
  - 单任务 IL 策略在分布漂移下表现脆弱且误差累积；
  - 多任务模型容易记忆训练模式而无法迁移；
  - 大规模人类视频或合成数据训练成本高且存在域漂移；
  - 上下文模仿学习（ICIL）依赖视觉相似度而非任务动力学；
  - 3D 扩散策略（DP3 等）容量大但对稀疏示教数据敏感，倾向于过拟合支持轨迹而非学习可迁移的任务动力学。
- **研究目标**：弥合"已见任务 → 未见任务"的泛化差距，使智能体能够仅凭少量参考演示与少样本微调快速适应新任务。

## 2. 方法论：DAMI 框架

DAMI 将**元学习（MAML）**与**3D 扩散策略**深度融合，包含三大核心模块：

### 2.1 整体架构
- **输入**：当前观测（点云 + 机器人状态）、文本指令、完整参考示教轨迹；
- **主干**：1D 条件 U-Net（扩散策略），预测 H 步动作轨迹；
- **条件注入**：在第一个下采样块中通过 Transformer 融合多模态条件，其余块使用轻量级观测-时间步条件。

### 2.2 扩散-元模仿目标
- 扩散损失采用动作预测参数化：
  $$ L_{\text{diff}} = E_{k,A^0,\epsilon} \| A^0 - \hat{A}^0_\theta(A^k, k, f_{\text{obs}}, H_{\text{demo}}, f_{\text{text}}) \|^2 $$
- 内层循环：$\theta'_i = \theta - \alpha \nabla_\theta L_{\text{diff}}(\theta, B_i^{\text{sup}})$（SGD，1 步）
- 外层循环：使用 **完整二阶 MAML**，通过 AdamW 更新共享初始化，并配合线性 warmup + cosine decay 学习率策略；
- 训练中保留 EMA 策略用于评估。

### 2.3 VMT 模块（Visual-Motor Trajectory）
- **目的**：捕捉示教的时空动力学，避免纯视觉编码过度强调静态外观；
- **流程**：
  1. 将视觉特征 $f_{v,t}$ 与本体动作 $a_t$ 拼接，经可学习线性投影 $\phi_{\text{proj}}$ 映射至统一隐空间；
  2. 加入可学习位置编码 $P$ 保留时序；
  3. 通过 Transformer Encoder 编码得到 $H_{\text{demo}}$，作为"以运动为中心"的上下文；
- 关键点：联合建模"在什么动作下发生什么变化"，而非仅依赖静态视觉线索。

### 2.4 U2T 模块（Unpaired Unified Task）
- **"无配对"含义**：参考示教与当前观测不必逐帧对齐，只共享任务语义；
- **流程**：
  1. 文本特征由冻结 CLIP 编码，演示特征由 VMT 生成；
  2. 仅对这两个融合输入施加模态特定的仿射投影（带 LayerNorm）；
  3. 时间步嵌入 $e_k$ 与当前观测特征拼接，经 MLP 得 $h_k$；
  4. 三者拼接后送入 Transformer Encoder，得到首个下采样块的条件 $C_{\text{Down}_1}$。

### 2.5 TCFM 机制（Task-Conditioned Feature Modulation）
- 在每个 U-Net 块中使用 **FiLM** 调制：
  $$ \tilde{h}_j = \gamma_j(c_j) \odot h_j + \beta_j(c_j) $$
- 仅首个下采样块使用融合条件 $C_{\text{Down}_1}$，其余块使用 $h_k$（观测-时间步条件）。

### 2.6 算法流程
- **元训练（算法 1）**：每任务从 10 条完整示教中采样 16 帧窗口，按索引切分为支持集/查询集；随机选 200 帧完整参考演示；任务按 GPU worker 枚举而非随机采样。
- **新任务少样本适应（算法 2）**：复制 EMA 策略为初始化 → 拟合归一化器 → N 步 AdamW 微调（带梯度裁剪）→ EMA 平滑 → Meta-World 每次 rollout 固定参考演示，RLBench 跨回合复用。

- **泛化性**：在未见物体（异形圆柱、Rubik's 立方体）上仍保持稳健性能。
