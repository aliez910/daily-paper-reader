## 摘要
语言条件下的操作需要精确的接触丰富控制以及对语言、场景和长时段的鲁棒推理。端到端的视觉-语言-动作（VLA）模型提供了强大的局部视觉运动技能，但它们是在分布内任务轨迹上训练的，在部署扰动下（如语义重定向、目标重绑定、空间布局变化以及不稳定的局部接触）常常失败。LLM 编码智能体提供了互补的语义与组合推理能力，但纯分析性的原语在处理不规则抓取、受限放置和铰接物体交互时存在困难。我们提出 Harness VLA，一种记忆增强的智能体框架，它将一个冻结的 VLA 作为一种可重试的接触丰富原语暴露出来，并将其与一个小型的固定分析原语库（用于场景锚定、分段、运输、导航和释放）相组合。该框架并非扩展技能库，而是从任务特定的执行轨迹、全局成功规则和失败模型中学习这些固定原语的操作范围。通过将语义重新锚定、非接触执行以及 VLA 重分段提升至规划器层面，同时保留冻结的 VLA 用于局部接触丰富阶段，Harness VLA 在不进行微调的情况下，将预训练 VLA 的能力拓展到其原始轨迹分布之外。在扰动的桌面任务、家庭厨房以及从干净到随机的双臂操作任务中，Harness VLA 分别在 LIBERO-Pro 和 RoboCasa365 上超越最强相关基线 38.6 和 25.4 个百分点，并在 RoboTwin C2R 上达到 58.4%。

## Abstract
Language-conditioned manipulation requires both precise contact-rich control and robust reasoning over language, scenes, and long horizons. End-to-end Vision-Language-Action (VLA) models provide strong local visuomotor skills, but they are trained on in-distribution task trajectories and often fail under deployment perturbations such as semantic retargeting, goal re-binding, spatial-layout shifts, and unstable local contacts. LLM coding agents provide complementary semantic and compositional reasoning, but purely analytic primitives struggle with irregular grasping, constrained placement, and articulated-object interaction. We present Harness VLA, a memory-augmented agentic framework that exposes a frozen VLA as a retryable contact-rich primitive and composes it with a small fixed library of analytic primitives for grounding, staging, transport, navigation, and release. Rather than expanding the skill library, the harness learns the operating range of these fixed primitives from task-specific execution traces, global success rules, and failure models. By lifting semantic re-grounding, non-contact execution, and VLA re-staging to the planner while reserving the frozen VLA for local contact-rich phases, Harness VLA extends pretrained VLAs beyond their original trajectory distribution without finetuning. Across perturbed tabletop, household kitchen, and clean-to-randomized bimanual manipulation, Harness VLA improves over the strongest relevant baselines by 38.6 and 25.4 percentage points on LIBERO-Pro and RoboCasa365, respectively, and reaches 58.4% on RoboTwin C2R.

# Harness VLA 论文总结

## 1. 核心问题与研究动机

### 1.1 问题背景
- 语言条件下的机器人操控需要同时具备 **两类能力**：
  - **精确的接触密集型控制**（如不规则抓取、铰接物体操作、夹具启动）；
  - **鲁棒的语义与长时域推理**（如目标重绑定、空间布局变化、长流程组合）。

### 1.2 现有范式的局限
- **端到端 VLA 模型**（π0、π0.5、OpenVLA、RLDX-1、LingBot-VLA 等）：
  - 优势：局部接触丰富的视觉运动控制强；
  - 缺陷：在分布外扰动下（语义重定向、目标重绑定、布局变化、局部接触不稳定）易退化甚至失败；语言通道在分布外往往"形同虚设"。
- **LLM 编码智能体**（Code-as-Policies、ProgPrompt、RoboCodeX 等）：
  - 优势：组合推理、程序合成能力强；
  - 缺陷：纯分析原语难以处理不规则抓取、受限放置、铰接物交互；扩展技能库会引入"技能是否安全有效"的判断难题。

### 1.3 核心洞察
- 两种范式各自分担了错误的责任：VLA 把语言、组合与控制全压在单一策略；编码智能体把精细物理交互交给手工/生成的 API。
- **解决思路**：不扩充技能库，而是让智能体学会"如何编排"固定的小型原语库；VLA 仅作为可重试的接触密集型原语被调用。

## 2. 方法论

### 2.1 整体框架：Harness VLA
- **非对称层级化结构**：
  - 高层：**基于 LLM 的智能体规划器 Π**（如 Codex 或 Claude Code）；
  - 低层：**冻结的 VLA 策略 f_θ**（封装为单一接触原语 `VLA ACT`）；
  - 底层：**固定小型分析原语库 P**（运动学/模型驱动的确定性控制器）。

### 2.2 核心思想
- 规划器负责：**语义重锚定、非接触执行、VLA 重分段**；
- VLA 仅负责：**局部接触密集型阶段**（抓取、放置、铰接物交互、按钮/水龙头按下等）；
- 关键设计：VLA 不是一次性黑盒调用，而是**可重试、可重分段的接触尝试**。

### 2.3 关键技术细节

#### (1) 原语库 P（Table 1）
| 原语 | 类型 | 作用 |
|------|------|------|
| `MOVE TO` | 复合分析原语 | 末端执行器移至世界坐标系目标点 |
| `MOVE POSE` | 复合分析原语 | 同时变化位置与姿态（如 pitch） |
| `ROTATE WRIST` / `ROTATE PITCH` | 原子分析原语 | 腕部偏航/俯仰设定 |
| `SET GRIPPER` / `RELEASE` | 原子分析原语 | 夹爪开闭 |
| `VLA ACT` | VLA 原语 | 冻结 VLA 短脉冲执行 |
| `NAVIGATE TO` / `MOVE BASE` | 移动底盘原语（仅 RoboCasa365） | 大尺度厨房场景移动 |
| `arm` 参数 | 双臂绑定（仅 RoboTwin） | 区分左/右臂 |

#### (2) 智能体执行循环（REPL 风格）
- 规划器 Π 读取 `state_NN.json`、`command.json`、`log_NN.json` 等文件；
- 通过文件中介（file-mediated）发出 JSON 格式原语调用；
- 环境 worker 执行原语直到内部后置条件满足，返回新观测；
- 循环直到目标谓词 G 满足或预算耗尽。

#### (3) 双记忆模块
- **Task Specific Memory**（任务特定记忆）：
  - 在参考种子 s0 上探索成功后存储两类文件：
    - `{TASK}_s0.json`：语义摘要（策略、避免项、失败模式）；
    - `{TASK}_s0.jsonl`：参数化原语执行轨迹（空间坐标用符号感知查询替换，使结构可迁移）；
  - 评估阶段用于少样本重锚定。
- **Global Memory**（全局记忆）：
  - 跨任务可复用的成功规则（如"使用完整任务指令作为提示"）；
  - 失败模型（如"夹爪闭合但物体未随末端运动 → 空抓"；"不要仅凭视觉接近判定成功"）。

#### (4) 两阶段生命周期
- **探索引导阶段**（Bootstrapping）：
  - 可用 RESET 原语，时间预算宽松；
  - 重点：发现最优原语编排顺序、VLA 调用时机与早停阈值。
- **部署评估阶段**（Deployment）：
  - 禁用 RESET，预算大幅缩减；
  - 检索 Task Specific Memory + Global Memory，结合实时 RGB-D 观测动态重锚定。

#### (5) 闭包语义
- `VLA ACT` 输入：`prompt`（任务条件文本）、`max_chunks`（动作块预算）、`stop`（早停谓词 τ）；
- 输出：动作块序列直到 τ 满足或块预算耗尽；
- 智能体可在 VLA 调用后通过分析原语重分段（调整接近姿态/视角）后再次调用。

## 6. 主要结论与发现

### 6.1 性能结果
| 基准 | Harness VLA 最佳结果 | 对比最强基线提升 |
|------|---------------------|----------------|
| LIBERO（标准） | CC: 96.0% | 与 RLinf (95.3%) 持平，未退化 |
| **LIBERO-Pro** | CC: **82.4%** | 比 RATS (43.8%) 高 **+38.6 pp** |
| **RoboCasa365** | Codex: **55.4%** | 比 RLDX-1 (30.0%) 高 **+25.4 pp** |
| RoboTwin C2R | CC: **58.4%** | 比 LingBot-VLA (50.4%) 高 **+8.0 pp** |

### 6.2 零样本结果
- LIBERO-Pro GOAL 零样本（无 Task Specific Memory）：Harness VLA (CC) 在 Pos-S 上 31.0%（Cap-X 25.6%），在 Task-T 上 79.0%（Cap-X 16.8%）；
- 证明 LLM 规划器即使不依赖任务记忆，也能通过实时场景感知合成有效原语组合。

### 6.3 三大核心发现
1. **规划器层语义重锚定恢复任务条件行为**：RLinf 在 Obj-T/Goal-S 等扰动下重复训练时行为；Harness VLA 通过规划器解析指令、解析当前观测定位目标，仅在局部接触阶段调用 VLA。
2. **规划器分段调用 VLA 提升冻结策略可靠性**：图 4 显示前几次 VLA 调用就能大幅提升成功率并饱和；可重试机制将不稳定接触错误局部化，不会拖垮整条 rollout。
3. **分析原语隔离非接触执行与接触丰富控制**：分析原语处理自由空间运输、姿态调整、释放；VLA 仅在不可脚本化的接触阶段被调用。两类原语形成"非接触-接触-非接触"的责任分工。

## 7. 优点与亮点

### 7.1 方法层面
- **非对称设计原则**：明确将"语义推理 + 长程组合"与"接触控制"解耦，角色清晰；
- **固定小原语库**：避免技能库爆炸，原语定义在部署前固定（Table 1 + Table 8），杜绝智能体自创不可审计技能；
- **VLA 作为可重试接触专家**：改变 VLA 的使用范式——从端到端策略 → 可控的接触原语接口；
- **双记忆系统**：Task Specific Memory 捕获任务结构，Global Memory 捕获跨任务经验，两者分工明确；
- **JSON 原语接口 + 文件中介 REPL**：实现对 LLM 友好的低耦合、可审计执行循环。

### 7.2 实验层面
- **同骨干对比**：将同一冻结 VLA（RLinf/LingBot-VLA）既作为基线也作为内部原语，能精准归因框架收益；
- **场景多样性**：覆盖标准/扰动桌面、家庭厨房、双臂操作三类典型场景；
- **机制分析深入**：不仅报告数字，还给出原语使用统计、调用次数-成功率曲线、典型 rollout 案例；
- **零样本验证**：证明框架在缺少任务记忆时仍具备一定泛化能力。

### 7.3 工程实现
- 论文配套网站（harnessvla.github.io），附录详细列出原语 JSON 模式、prompt 模板、评测协议；
- 附录 A-F 提供从 REPL 文件协议、原语实现、评测细节、VLA 后端、prompt 设计到原语使用统计的完整工程说明。

## 8. 不足与局限

### 8.1 方法局限
- **开放反馈回路**：规划器与低层 VLA 之间缺乏紧耦合信号，依赖事后诊断而非在线感知；
- **无联合微调**：未结合环境奖励或人类偏好进行 RL 微调（如 GRPO），上限受限于冻结 VLA；
- **缺乏细粒度图像描述**：在高度杂乱的长程任务中，结构化推理能力受限；
- **依赖任务记忆**：在少样本协议下需要 s0 参考种子探索，部署成本不低（虽比大规模 RL 微调便宜）。

### 8.2 实验局限
- **全部基于仿真**：MuJoCo/Robosuite 仿真器，无真实机器人实验；
- **零样本评测面窄**：仅在 LIBERO-Pro GOAL 子集与 RoboTwin C2R 上验证，缺少更多零样本场景的鲁棒性证据；
- **LLM 规划器对比有限**：仅对比 Codex 与 Claude Code 两个商业 API，缺乏开源 LLM（如 Qwen3-VL、Molmo）的可复现性对比；
- **无技能库增长实验**：作者明确不扩展技能库，但未与 ASPIRE 等"动态技能发现"方法做直接对照。

### 8.3 偏差与应用风险
- **选择偏差**：评测基准多为已有基准，其分布外扰动是已知的，未必覆盖真实场景的全部扰动类型；
- **报告偏差**：所有 baseline 数字或直接来自原论文，或来自作者复现，未给出统一的复现协议统计置信区间；
- **Prompt 工程依赖**：Appendix E 显示 prompt 极为详细（11 模块），对 prompt 变化敏感性未做实验；
- **部署成本不透明**：未量化 LLM API 调用次数、Token 成本、VLA 推理 FLOPs，难以评估实际部署可行性；
- **域外迁移未验证**：仅在仿真操控任务上验证，迁移到移动操作、柔性物体、人机协作等更复杂场景的可行性未知。

### 8.4 作者自陈的未来方向
- 引入基于环境奖励的样本高效 RL（如 GRPO）；
- 融合细粒度图像描述以提升杂乱场景的结构推理；
- 与 ASPIRE 等自动技能发现系统结合，保留可审计原语接口的同时支持有限度的技能扩展。
