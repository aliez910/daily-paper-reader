## 摘要
世界动作模型（World Action Models, WAMs）通过将基于视频的世界建模作为机器人动作学习的密集监督，提供了一种有前景的视觉-语言-动作（Vision-Language-Action, VLA）策略替代方案。现有WAM在物理可执行性方面表现出色，但通常缺乏基于VLM的VLA中所具备的显式语言级规划接口，难以对粗粒度指令进行分解。当家务任务涉及复杂的多步目标时，这种分解尤为重要——此时需要将粗粒度的用户命令转换为一系列细粒度的可执行子任务。与此同时，由于现有系统在数据、机器人本体和任务协议方面往往存在差异，该领域仍然缺乏VLA与WAM执行能力之间公平的真实机器人对比。为了同时弥合分解能力差距并满足可控的WAM-VLA比较需求，我们提出了DSWAM，一个面向细粒度机器人操作的双系统世界动作基础模型。DSWAM将系统1的WAM执行器作为默认控制路径，并仅在任务分解有用时选择性地激活系统2的视觉-语言子任务规划器。规划器根据短期视觉历史和全局任务提示预测可执行的子任务，而WAM执行器则为每条指令或子任务执行具有世界感知能力的动作生成。执行器通过动作预测与视频协同训练进行训练，但推理时直接预测动作块，无需显式生成未来视频。为了使该执行路径在真实机器人上切实可行，我们进一步集成了TensorRT加速、异步执行与实时分块（real-time chunking, RTC），以确保策略查询不会阻塞机器人控制。为了提供与VLA策略公平的真实机器人对比，我们在DeMaVLA真实世界可形变操作设置下构建并评估了DSWAM，并在机器人平台、预训练数据、后训练数据和评估标准方面保持一致。

## Abstract
World Action Models (WAMs) provide a promising alternative to Vision-Language-Action (VLA) policies by using video-based world modeling as dense supervision for robot action learning. Existing WAMs excel at physically grounded execution, but typically lack the explicit language-level planning interface in VLM-based VLAs for decomposing coarse instructions. Such decomposition becomes important when household tasks involve complex multi-step goals, where coarse user commands need to be converted into sequences of fine-grained executable subtasks. Meanwhile, the field still lacks a fair real-robot comparison between VLA and WAM execution capabilities, since existing systems often differ in data, robot embodiments, and task protocols. To address both the decomposition gap and the need for a controlled WAM-VLA comparison, we introduce DSWAM, a Dual-System World Action Foundation Model for fine-grained robot manipulation. DSWAM keeps a System 1 WAM executor as the default control path and optionally activates a System 2 vision-language subtask planner only when task decomposition is useful. The planner predicts executable subtasks from short-term visual history and a global task prompt, while the WAM executor performs world-aware action generation for each instruction or subtask. The executor is trained with action prediction and video co-training, but inference directly predicts action chunks without explicit future video generation. To make this execution path practical on real robots, we further integrate TensorRT acceleration, asynchronous execution, and real-time chunking (RTC) so that policy queries do not block robot control. To provide a fair real-robot comparison with VLA policies, we build and evaluate DSWAM under the DeMaVLA real-world deformable manipulation setting with matched robot platform, pretraining data, post-training data, and evaluation criteria.

# DSWAM 论文总结

## 一、核心问题与研究动机

- **WAM 与 VLA 的能力不对称**：现有世界动作模型（World Action Models, WAMs）擅长基于视频建模的物理执行，但缺少视觉-语言-动作（VLA）模型中基于 VLM 的显式语言级规划接口，难以将粗粒度用户指令分解为可执行的细粒度子任务序列。
- **复杂家务任务的分解需求**：当任务涉及多步目标（如"整理桌面上的物体"）时，需要先做语义层面的任务组织，再进行接触丰富的物理执行，单一执行策略难以兼顾。
- **公平对比的缺失**：现有 WAM 与 VLA 的真实机器人对比往往在数据来源、机器人本体、任务协议上存在差异，导致性能差异难以归因于策略设计本身。
- **部署效率问题**：基于视频的世界建模监督虽有效，但推理时显式生成未来视频会带来延迟，难以满足真实机器人闭环控制需求。

## 二、方法论

### 2.1 整体框架：双系统设计

- **System 1（WAM 执行器，默认路径）**：基于预训练视频模型（Wan2.2-TI2V-5B）+ 动作专家（Action Expert），输入多视角图像、语言指令/子任务、本体感知状态，输出动作块（action chunk）。
- **System 2（视觉-语言子任务规划器，按需启用）**：基于 Rynnbrain4B 风格的 VLM，将粗粒度指令按短期视觉历史分解为有序的细粒度可执行子任务。
- **耦合机制**：System 2 每 2 秒接收来自 WAM 的 5 帧短期视觉历史，输出子任务作为 System 1 的语言条件；当不需要分解时，直接将原始指令作为语言条件。

### 2.2 System 2 子任务规划器

- 输入：全局任务提示 $p$ + 短期视觉历史 $X_t = \{x_{t-4}, x_{t-3}, ..., x_t\}$（1 Hz 采样的 5 帧）。
- 输出：下一子任务指令 $s_t = P_\phi(X_t, p)$。
- **转换感知监督**：训练数据来自机器人轨迹视频，由预训练 VLM 标注器进行子任务分段 $\{(s_k, \tau_k)\}$，监督目标 $y_i$ 在子任务内部为 $s_k$，在非终止子任务末窗为 $s_{k+1}$，在终止子任务末窗为 `done`。
- **优化目标**：自回归语言建模损失 $L_{plan}(\phi) = -\mathbb{E}[\log P_\phi(y_t | X_t, p)]$。

### 2.3 System 1 WAM 执行器

- **潜在世界特征编码**：$z_t = f_\theta(I_{1:3}^t, \ell_t, q_t)$，推理时仅需一次前向传播，无需未来帧采样/去噪/解码。
- **动作块预测**：$p_\theta(A_t | O_t)$，$A_t = [a_t, a_{t+1}, ..., a_{t+H-1}]$ 为连续双臂控制命令块。
- **流匹配（Flow Matching）损失**：对动作块 $A_t$ 与未来视觉 token $V_{t+1:t+T}$ 共享同一流匹配形式：
  - 构造 $y^\tau = (1-\tau)y + \tau \epsilon$
  - 损失 $L_{FM}(y) = \mathbb{E}[\|v_\theta(y^\tau, \tau, O_t) - (\epsilon - y)\|_2^2]$
- **联合训练目标**：$L = L_{act} + \lambda_{vid} L_{vid}$，训练时使用未来视觉 token 提供世界建模监督，但动作 token 不可访问未来视觉信息以保证与推理时一致。
- **关键设计**：训练时用视频协同训练，推理时直接预测动作块，不显式生成未来视频。

### 2.4 实时部署

- **实时分块（RTC）**：策略工作线程预测新块的同时，控制器继续执行当前块，策略延迟不阻塞底层控制。
- **TensorRT BF16 加速**：将重计算拆分为两个引擎——视觉上下文引擎（构建层级缓存）与动作去噪引擎（消费缓存预测去噪更新）；预处理、文本编码、VAE 等公共接口保持不变。
- **异步执行**：策略查询与机器人控制完全解耦。

## 六、主要结论与发现

- **RoboTwin 2.0 仿真**：DSWAM 平均成功率 clean 92.38%、randomized 91.90%，在 clean 与 randomized 设定下均为最佳；相比 DeMaVLA 分别提升 3.96% 与 5.12%。
- **真实机器人折叠**：在 WAM-only 模式下，平均成功率 96.3%（vs DeMaVLA 92.5%），平均完成时间 1′44″（vs 2′18″）；裤子任务提升最显著（75% → 90% SR，3′01″ → 2′19″）。

## 七、优点与亮点

- **双系统解耦设计**：将语义任务组织（System 2）与物理执行（System 1）解耦，对原子指令直接调用 WAM 执行器，对需分解的粗指令才启用规划器，避免了不必要的规划开销。
- **公平受控的对比协议**：在 DeMaVLA 基准上完全匹配机器人平台、数据、任务协议与评估标准，且折叠对比中禁用 System 2，使对比聚焦于策略设计本身。
- **训练-推理一致性**：训练时用视频协同监督，推理时不生成未来视频，规避了"想象-再执行"路径中的延迟与生成误差。
- **高效部署管线**：TensorRT 拆分双引擎 + 异步 RTC，使 WAM 执行器在真实机器人上满足低延迟控制需求。
- **覆盖广泛的评估**：仿真（50 任务）+ 真实机器人（4 类可形变物）+ System 2 消融 + 部署效率四个维度，证据链较完整。
- **使用大规模真实数据**：5000+ 小时真实机器人数据预训练，增强了一般操作能力。
