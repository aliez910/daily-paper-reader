## 摘要
我们提出了FabriVLA，一种用于精确多任务操作的轻量级视觉-语言-动作模型。FabriVLA将InternVL3.5视觉-语言主干网络与流匹配动作头相结合，其动作令牌之间采用门控自注意力机制，并通过浅层VLM层融合以丰富空间上下文。该模型通过从预训练VLM和随机初始化的动作头进行单阶段联合优化训练。在涵盖50项多样化操作任务的Meta-World MT50基准测试中，FabriVLA达到了90.0%的分层平均成功率，表明基于1B规模VLM构建的紧凑型VLA无需依赖数十亿参数的VLA主干网络即可实现强劲性能。

## Abstract
We present FabriVLA, a lightweight Vision-Language-Action model for Precise Multi-Task Manipulation. FabriVLA combines an InternVL3.5 vision-language backbone with a flow-matching action head featuring gated self-attention across action tokens and shallow VLM layer fusion for enriched spatial context. The model is trained via single stage joint optimization from a pretrained VLM and randomly initialized action head. On the Meta-World MT50 benchmark spanning 50 diverse manipulation tasks, FabriVLA achieves a tier-average success rate of 90.0%, demonstrating that a compact VLA built on a 1B scale VLM can achieve strong performance without relying on multi billion parameter VLA backbones.

# FabriVLA 论文总结

## 1. 核心问题与研究动机

- **背景**：Vision-Language-Action（VLA）模型已成为通用机器人操控的范式，但当前主流大模型（如 RT-2、π0、OpenVLA）依赖数百亿参数规模，在实时机器人控制中存在计算成本高、推理延迟大等部署瓶颈。
- **核心问题**：能否在 **不依赖多亿级参数基座** 的前提下，仅用约 1B 规模的紧凑 VLA 即可在多任务精确操控中实现强性能？
- **意义**：探索"轻量级 + 高精度"的设计路线，为 VLA 在真实机器人上的低成本部署提供可行性验证。

## 2. 方法论：核心思想与关键技术

### 整体架构（三大组件）
1. **VLM 主干**：InternVL3.5-1B（仅保留 14 层 Transformer），输入 448×448 RGB 图像与任务文本指令。
2. **状态/动作编码器**：
   - 机器人状态 $s \in \mathbb{R}^{24}$ 经两层 MLP 编码为状态 token $z_s \in \mathbb{R}^{1024}$。
   - 噪声动作 $x_t \in \mathbb{R}^{50 \times 24}$ 经 MultiEmbodimentActionEncoder（共享 MLP + 视野位置编码）映射为动作 token 序列 $Z_a \in \mathbb{R}^{50 \times 1024}$。
3. **流匹配动作头**：8 层 FabriVLA Transformer Block，每块包含门控自注意力、上下文交叉注意力、时间条件 FFN。

### 关键技术一：门控自注意力（Gated Self-Attention）
- 在动作 token 之间使用 **可学习门控参数 $g$**，初始化为 0：
  $$A' = A + g \cdot \text{SelfAttn}(\text{LayerNorm}(A))$$
- **优点**：训练初期等价于纯交叉注意力块，避免训练不稳定；随训练推进门控逐步打开，学习 50 步预测视野内动作间的时序依赖。

### 关键技术二：浅层 VLM 层融合（Shallow Layer Fusion）
- 同时抽取 VLM **第 6 层（空间细节）** 与 **第 14 层（语义信息）** 的特征。
- 通过 concat_proj 策略拼接后用线性投影 $W \in \mathbb{R}^{2048 \times 1024}$ 映射回原维度，初始化为 $[I|0]$，确保向后兼容。
- 仅为动作头增加约 **2.1M 参数**，代价极小。

### 关键技术三：流匹配训练
- 噪声 $\epsilon \sim U([-1,1])$ 与真实动作 $a$ 间线性插值：$x_t = (1-t)\epsilon + t\cdot a$。
- 时间 $t$ 采样自 **Beta(2,2)** 分布，集中于中间去噪区域。
- 速度场预测目标为 $a - \epsilon$，损失为 MSE。
- 推理时采用 **Euler 积分**，50 步从 $t=0$ 到 $t=1$。

### 训练策略
- **单阶段联合优化**：VLM 主干（从预训练加载）与动作头（随机初始化）从训练开始就全程解冻同时优化。
- 使用 **DeepSpeed ZeRO-2 + FP32 主权重 + BF16 混合精度**，避免小梯度更新在 BF16 量化中丢失。

## 6. 主要结论与发现

- **核心结果**：FabriVLA（0.89B 参数）在 MT50 上达到 **90.0% 分层平均成功率** 与 **92.0% 整体 episode 级成功率**，超过所有对比基线（含 LA4VLA 87.5%、Evo-Depth 84.4%）。
- **各难度档**：Easy 95.0%、Medium 88.2%、Hard 86.7%、Very Hard 90.0%。
- **任务维度发现**：平面滑移、铰接接触、插入装配类任务最强（93–96%）；工具使用、粗略运输与抓放任务相对较弱（83–86%）。
- **消融结论**：
  - 浅层融合使分层平均提升 7.1 个百分点（82.9 → 90.0），整体成功率提升 5.2 个百分点（86.8 → 92.0），证明空间细节对精确操控至关重要。

- **总体结论**：1B 规模的紧凑 VLA 无需依赖多亿级参数基座即可实现强多任务操控性能。

## 7. 优点与亮点

- **浅层+深层融合机制优雅**：初始化为 $[I|0]$ 保证向后兼容，工程细节扎实。
