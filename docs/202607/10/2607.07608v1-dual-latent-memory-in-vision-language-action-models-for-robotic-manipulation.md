## 摘要
主流的视觉-语言-动作（VLA）模型在马尔可夫假设下主要依据当前观测来预测动作，因此在长时程、时序依赖的任务中表现欠佳。现有引入记忆机制的 VLA 方法要么扩展观测窗口，要么从记忆库中检索历史作为策略端的辅助上下文。然而，这些方法将记忆置于 VLA 推理的原生潜在嵌入空间之外，阻碍了历史经验与多模态推理及动作生成的灵活交织。为此，我们提出了 LaMem-VLA，一种潜在记忆原生框架，将历史经验重构为潜在记忆令牌，并将其与 VLA 推理直接交织。其核心包含四个相互协作的组件：(i) 策展器，将历史经验组织为两个互补的短期与长期记忆库；(ii) 检索器，利用多模态认知查询两个记忆库，以检索与上下文相关的证据；(iii) 压缩器，将检索到的证据重构为紧凑的短期与长期潜在记忆令牌；(iv) 编织器，将这些记忆令牌与当前观测及指令注入到一个连续的嵌入序列中。通过在同一个连续潜在空间中完整地表示、检索和消费历史经验，LaMem-VLA 使记忆能够直接参与 VLA 推理，并在有界上下文条件下指导动作生成。在 SimplerEnv 和 LIBERO 上的大量实验证明了 LaMem-VLA 的优越性。

## Abstract
Mainstream Vision-Language-Action (VLA) models predict actions primarily from the current observation under a Markovian assumption, thus struggling with long-horizon, temporally dependent tasks. Existing memory-augmented VLAs either expand the observation window or retrieve history from the memory bank as auxiliary policy-side context. However, they leave memory outside the native latent embedding space of VLA reasoning, preventing historical experience from being fluidly interleaved with multimodal reasoning and action formation. To this end, we introduce LaMem-VLA, a latent-memory-native framework that reconstructs historical experience into latent memory tokens and directly interweaves them with VLA reasoning. At its core, LaMem-VLA introduces four coordinated components: (i) a curator that organizes historical experience into two complementary short-term and long-term memory vaults; (ii) a seeker that queries both vaults using the multimodal cognition to retrieve context-relevant evidence; (iii) a condenser that reconstructs the retrieved evidence into compact short-term and long-term latent memory tokens; and (iv) a weaver that injects these memory tokens with the current observation and instruction into one continuous embedding sequence. By representing, retrieving, and consuming historical experience entirely in the same continuous latent space, LaMem-VLA enables memory to directly participate in VLA reasoning and guide action generation under a bounded context. Extensive experiments on SimplerEnv and LIBERO demonstrate the superiority of our LaMem-VLA.

# 论文总结：LaMem-VLA——面向机器人操作的视觉-语言-动作模型双潜在记忆

## 1. 核心问题与研究背景

- **主流 VLA 模型的局限**：现有视觉-语言-动作（VLA）模型通常在**马尔可夫假设**下工作，仅依赖当前观测 $o_t$ 与指令 $I$ 预测动作，忽略了历史状态转移、已完成子任务与任务进度等时序依赖信号，因此存在"**时间短视偏差**（temporal short-horizon bias）"，在长时程、时序耦合任务上表现不佳。
- **现有记忆增强方法的不足**：
  - 路线一：扩展观测窗口（拼接历史帧 / 多帧视频），上下文代价随长度线性增长，且固定窗口会**丢弃窗外关键证据**。
  - 路线二：外部记忆库检索（如 MemoryVLA、MemeR），将记忆作为**策略端辅助上下文**拼接在 VLA 推理之外，使历史无法与视觉/语言/动作 token 在同一连续嵌入空间中深度交织。
- **核心研究问题**：能否将历史经验表示为**上下文原生（context-native）的机器人潜在记忆**，在 VLA 内部连续潜在空间中完成存储、检索与消费，使其直接参与多模态推理与动作生成？

## 2. 方法论

### 2.1 核心思想
将历史经验重构为**潜在记忆 token**，并以两类互补的"记忆库（vault）"——**短期视觉记忆**与**长期语义/动作记忆**——与当前观测、语言指令、可学习动作查询一起，按序拼接为统一的 VLA 输入嵌入序列 $S_t$，使记忆与视觉/语言/动作在同一自注意力上下文中联合推理。

### 2.2 整体架构与四个协同模块

| 模块 | 功能 |
| --- | --- |
| **Curator 策展器** | 将历史经验分解并写入两个记忆库：短期库 $M_{short}$ 以视觉 token 形式存储近期感知证据（容量 $L=16$），长期库 $M_{long}$ 以动作隐藏态形式存储任务进度与动作连续性证据 |
| **Seeker 检索器** | 基于当前多模态认知构造上下文查询 $q_t$，从两个库中通过余弦相似度 Top-K 检索相关证据 |
| **Condenser 压缩器** | 将检索到的可变长度证据压缩为**定长**潜在记忆 token（短期 $L_s=8$，长期 $L_l=4$），对齐到 VLA 嵌入空间 |
| **Weaver 编织器** | 将压缩后的记忆 token 注入 VLA 输入序列开头，形成 $S_t = [M_{short}; M_{long}; X_t; I; Q_{action}]$，再由扩散式动作专家生成动作 |

### 2.3 关键技术细节
- **骨干**：7B 参数 Prismatic VLM（在 Open-X Embodiment 上预训练），动作头为约 300M 参数的扩散式动作专家（DiT 风格）。
- **记忆库更新策略**：当库容量超限时，对相邻 key 取余弦相似度，合并最冗余的相邻 pair（键值均取平均），实现视觉与语义信息的无损聚合。
- **检索与压缩解耦**：检索规模 $K=8$（可调），压缩输出固定为 $(L_s, L_l)=(8,4)$，使输入上下文有界，避免随历史线性增长。
- **动作生成**：使用 DDIM（10 步采样）配合 MSE 噪声预测损失，输出 7-DoF 末端执行器动作块（chunk size = 16）。
- **记忆 token 标识**：在两类记忆 token 上分别添加可学习的源嵌入 $b_s, b_l$，防止短期 / 长期语义混淆。

## 3. 实验设计

### 3.1 数据集与基准
- **LIBERO**（Franka 机器人）：包含 Spatial、Object、Goal、Long-10、Long-90 共 5 个套件，按 OpenVLA 协议每任务 50 条示范，Long-10/Long-90 联合训练 40k 步，其他三个套件各训练 20k 步。
- **SimplerEnv-Bridge**（WidowX 机器人）：real-to-sim 评估协议，在 Bridge v2 数据集上训练 50k 步，每任务 24 次试验，每 2.5k 步验证。

### 3.2 对比方法
- **强基线**（含 * 的方法使用了额外的本体感知与腕部相机输入）：Diffusion Policy、Octo、UniACT、SpatialVLA、OpenVLA、CoT-VLA、π0-FAST*、CogACT、π0*、ThinkAct、MemoryVLA、Fast-ThinkAct、SemanticVLA、LARA。
- **SimplerEnv 上额外对比**：RT-1-X、OpenVLA、TraceVLA、SpatialVLA、Magma、CogACT、π0、DreamVLA、ThinkAct、CronusVLA、MemoryVLA、SemanticVLA。

### 3.3 评估方式
- 报告平均成功率（SR），每任务 50 次 rollout（LIBERO）/24 次试验（SimplerEnv）。
- 通过验证集挑选最佳 checkpoint。

## 6. 主要结论与发现

- **LIBERO 综合表现**：平均成功率 **97.6%**，超过 MemoryVLA（96.5%）1.1 点、CogACT（93.2%）4.4 点、π0*（94.2%）3.5 点（前四套件）。各套件分别 98.8%（Spatial）/99.0%（Object）/97.2%（Goal）/95.8%（Long-10）/97.0%（Long-90）。
- **SimplerEnv-Bridge**：平均 **73.9%**，超过 CogACT +16.6 点、π0 +4.7 点、MemoryVLA +2.0 点，在 4 个任务中有 2 个达到 SOTA。
- **关键消融发现**：
  - 双记忆缺失时 SimplerEnv 由 73.9% 降至 57.3%，LIBERO-90 由 97.0% 降至 92.1%，说明记忆机制本身贡献显著。
  - 相比"策略端条件"或"原始检索"，"潜在原生注入"在两个基准上均最优，表明增益来源于**整合路径**而非简单加入记忆。
  - $K=8$、$(L_s, L_l)=(8,4)$ 为性能-效率最佳折中，过大 $K$ 或 token 数反而拖性能。
- **长时程优势**：在 Long-10、Long-90 上对 MemoryVLA 分别 +2.4、+1.4 点，验证短期视觉与长期语义记忆在长时程任务上具有协同互补效应。

## 7. 方法与实验设计的亮点

- **范式创新**：将"记忆"从外置模块迁移至 VLA 内部**连续潜在空间**，使记忆真正参与多模态推理与动作意图形成，区别于传统外部记忆库方案。
- **双记忆库设计**：按"来源与功能"而非"表示形式"区分短期与长期记忆，但消费端保持统一的 token 接口，工程化干净。
- **检索-压缩解耦**：检索规模可变但消费定长，避免上下文随历史膨胀，具备实际部署意义。
- **零额外感知依赖**：仅使用第三人称 RGB 与语言指令，无需腕部相机或本体感知，即可达到甚至超过使用更多传感器的强基线，方法实用性高。
- **实验完备度较高**：横跨两个仿真平台、5 个 LIBERO 套件、4 组消融，并系统扫描了 $K$ 与 $(L_s, L_l)$ 超参。
- **工程实现透明**：给出 GPU 型号、batch、显存、FSDP 训练细节，配置可复现性较好。

## 8. 不足与局限

- **真实世界验证缺失**：论文明确指出当前实验**仅限仿真**，真实机器人平台的迁移性待验证，限制了对 sim-to-real gap 的判断。
- **基线公平性受限**：部分领先方法（如 π0*、π0-FAST*）使用了额外本体感知与腕部相机输入，与 LaMem-VLA 不完全可比，奖励了其性能收益；其他纯视觉-语言基线也存在版本与训练数据差异。
- **统计显著性未报告**：未给出多随机种子下的均值与方差，无法判断某些微小提升（如 Long-90 上 +1.4 点）的稳定性。
- **应用场景偏窄**：仅在仿真桌面操纵任务（Bridge / LIBERO）上验证，缺少移动操作、双手机器人、具身导航等场景。
- **记忆容量有限**：固定 $(L, L_s, L_l)=(16, 8, 4)$ 在超长任务（数百步）下可能依然不足，论文未讨论容量饱和与记忆淘汰策略的极限。
- **检索依赖即时多模态查询**：当当前观测被强干扰物（distractor）污染时，seeker 的查询构建可能受影响，论文未对鲁棒性极端情况进行分析。
- **算力披露有限**：未给出训练总时长（FSDP × 8×H800 上 50k 步的实际 wall-clock）、显存峰值或推理延迟，难以判断实际部署成本。
