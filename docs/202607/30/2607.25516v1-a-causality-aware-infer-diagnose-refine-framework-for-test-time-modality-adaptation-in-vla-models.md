## 摘要
视觉-语言-动作（VLA）模型以视觉观察和本体感知状态为条件，预测用于执行由语言指令指定任务的序列动作。然而，如何在VLA模型中融合模态仍是一个开放问题，因为机器人操作涉及动态阶段（如长距离运动和近距离交互），在这些阶段中视觉观察的重要性可能随时间变化。本文提出了一种推断-诊断-优化（IDR）框架，这是一个与模型无关的框架，可与多种VLA架构集成，在测试时优化动作预测。IDR首先在视觉观察的事实与反事实场景下推断动作，然后将视觉观察的因果效应诊断为估计的动态重要性，最后以无需训练的方式用于优化动作预测。我们进一步设计了一个因果感知的动作优化器来实现IDR框架，包括用于推断反事实动作的零填充干预、用于诊断因果效应的基于范数的量化，以及用于优化动作的门控残差融合。在仿真基准和真实世界任务上的大量实验表明，该方法在多种VLA骨干网络上均能带来整体性能的提升，证明了在测试时动态调整视觉重要性的有效性。

## Abstract
Vision-language-action (VLA) models predict sequential actions to execute tasks specified by language instructions, conditioned on visual observations and proprioceptive states. However, how to fuse modalities in VLA models remains an open problem, since robot manipulation involves dynamic phases, such as long-distance movements and close-range interactions, in which the importance of visual observations may vary over time. In this paper, we propose an infer-diagnose-refine (IDR) framework, a model-agnostic framework that can be integrated with diverse VLA architectures for refining action predictions at test time. IDR first infers actions under factual and counterfactual scenarios of visual observations, and then diagnoses the causal effects of visual observations as the estimated dynamic importance, which is finally used to refine the action predictions in a training-free manner. We further design a causality-aware action refiner to realize the IDR framework, including zero-padding interventions for inferring counterfactual actions, norm-based quantification for diagnosing causal effects, and gated residual fusion for refining actions. Extensive experiments on both simulation benchmarks and real-world tasks show improvements in overall performance across multiple VLA backbones, demonstrating the efficacy of dynamically adjusting visual importance at test time.

## 2. 方法论：Infer-Diagnose-Refine（IDR）框架

### 核心思想
将视觉重要性的动态变化建模为**因果效应**：通过比较"事实场景"（完整输入）与"反事实场景"（屏蔽某模态输入）下 VLA 模型的输出差异，估计当前时刻该模态对动作预测的因果贡献大小，并据此选择性修正动作。

### 关键技术细节（三阶段流水线）

#### 阶段一：Infer（零填充干预推断）
- 对冻结的 VLA 模型 πθ* 进行**三次前向推理**：
  1. 事实动作（factual）：`a_base = πθ*(v, s, l)`
  2. 视觉反事实动作：`a_no_img = πθ*(0_v, s, l)`（将视觉输入替换为同维度全零张量）
  3. 本体反事实动作：`a_no_prop = πθ*(v, 0_s, l)`
- **核心设计点**：选择零填充而非高斯噪声或均值填充，因为它能确定性、更彻底地消除模态信息（消融实验证实其效果最优）。

#### 阶段二：Diagnose（基于 L2 范数的因果效应量化）
- 计算两个方向的偏差向量：
  - Δ_img = a_base − a_no_img
  - Δ_prop = a_base − a_no_prop
- 用 L2 范数量化因果效应幅值：
  - E_img = ‖Δ_img‖₂（视觉因果效应）
  - E_prop = ‖Δ_prop‖₂（本体因果效应）
- **定义视觉重要性比**：R_img = E_img / (E_img + E_prop + ε)，用于诊断当前时步的视觉依赖程度。

#### 阶段三：Refine（门控残差融合）
- 设计**门控机制**避免盲目干预：
  - 门控阈值 τ 设为基线模型的视觉因果效应均值（约 0.7）。
  - 当 E_img < τ（视觉被忽视，如远距离运动阶段）→ 门 g_t = 1，触发修正；
  - 当 E_img ≥ τ（视觉已充分使用，如近距离交互）→ 门 g_t = 0，保持基线动作。
- **有界本体正则化器**：防止修正引入高频抖动
  - 动态权重：w_prop = β · min(1, E_prop/(E_img + ε))，β = 0.05
  - 截断项：u_prop = clip(Δ_prop, −λ, λ)，λ = 0.1
- **最终动作**：
  - `a_final = a_base + g_t · (α·Δ_img + w_prop·u_prop)`
  - 视觉修正强度 α = 0.08

### 算法流程概要
对每个时间步 t：
1. 同时进行三次 VLA 前向推理（factual + 两个 counterfactual）；
2. 计算 Δ_img、Δ_prop 与 E_img、E_prop；
3. 根据门控 g_t 决定是否融合修正项；
4. 输出最终动作 a_final。

## 6. 主要结论与发现

### 三大经验观察
1. **环境塑造视觉重要性**：同一模型在不同 benchmark 中可呈现完全相反的模态偏好（如 X-VLA 在 LIBERO 中本体主导，在 Google SIMPLER 中视觉主导）。
2. **架构决定模态偏好**：π0.5、VLA-Adapter、OpenVLA-OFT 视觉主导；X-VLA 本体主导，可能与早期是否注入本体/动作 token 有关。
3. **执行阶段改变视觉重要性**：基线模型的 R_img 在抓取开闭事件前后发生显著变化。

### 框架有效性
- **仿真**：在 LIBERO 上对所有 4 个骨干均带来提升（最大 +1.40% on VLA-Adapter）；SIMPLER 最大增益 +6.33%（VA 设置）；CALVIN 提升 5/5 完成率 70.5% → 77.3%。
- **真实世界**：平均成功率从 56.5% → 75.3%（+18.8%），平均完成时间从 53.6s → 41.5s；5 步 Organize Table 任务完整完成率从 0% → 33.3%。

## 7. 优点（亮点）

1. **模型无关、即插即用**：可无缝接入任何冻结 VLA，无需重训，部署成本低。
2. **理论性强**：将 Pearl 因果推断范式（factual vs. counterfactual）系统地引入 VLA 模态融合，给出清晰的形式化定义与因果图。
3. **三阶段设计清晰可解释**：Infer → Diagnose → Refine 流水线逻辑清楚，因果效应数值本身可作为可视化诊断工具。
4. **门控机制防过修**：避免在视觉已充分使用阶段盲目叠加修正，提升稳定性。
5. **跨规模、跨域验证充分**：从 <1B 到 7B+ 模型，从仿真到真实双臂机器人，从域内到域外 benchmark。
6. **发现反直觉现象**：揭示"本体主导模型仍需视觉引导修正"这一不对称性，具有分析价值。
7. **实证干预策略比较**：消融中验证零填充优于噪声与均值填充，给出明确的设计建议。
