## 摘要
视觉-语言-动作（VLA）模型通常采用以大语言模型为中心的 $V \to L \to A$ 路径，将视觉观测投影到大型语言模型的表示空间后再解码为机器人动作。尽管效果显著，该设计在每次策略调用时都会产生大量的计算与内存开销。在本文中，我们提出了 TurboVLA，一种全新的 VLA 范式，将传统的 $V \to L \to A$ 路径重构为直接的 $V + L \to A$ 映射。TurboVLA 不再以大型语言模型作为感知与动作之间的核心接口，而是对视觉观测和语言指令分别进行独立编码，通过轻量级的双向视觉-语言交互直接在二者之间交换信息，并使用紧凑的解码器预测连续的动作块。这种简洁的设计直接从视觉与语言特征构建任务条件化表示，显著降低了 VLA 推理的计算与内存成本。在 LIBERO 基准上，TurboVLA 仅使用 0.2B 参数即取得了 97.7% 的平均成功率，在消费级 RTX 4090 上实现了 31.2 ms 的推理延迟与 0.9 GB 的推理显存，性能可与参数量远大于它的 VLA 策略相媲美甚至更优。上述结果确立了 TurboVLA 作为主流 LLM 中心化 VLA 范式的一种简洁而有效的替代方案，为如何连接视觉、语言与动作以实现高效机器人操作提供了新的视角。代码开源于 https://github.com/H-EmbodVis/TurboVLA。

## Abstract
Vision-language-action (VLA) models commonly adopt an LLM-centric $V \to L \to A$ pathway, where visual observations are projected into the representation space of a large language model before being decoded into robot actions. Although effective, this design incurs substantial computation and memory overhead at every policy invocation. In this work, we introduce TurboVLA, a new VLA paradigm that reformulates the conventional $V \to L \to A$ pathway as a direct $V + L \to A$ mapping. Instead of using a large language model as the central interface between perception and action, TurboVLA independently encodes visual observations and language instructions, directly exchanges information between them through lightweight bidirectional vision-language interaction, and predicts continuous action chunks with a compact decoder. This simple design constructs task-conditioned representations directly from visual and linguistic features, significantly reducing the computational and memory costs of VLA inference. On LIBERO, TurboVLA achieves 97.7% average success with only 0.2B parameters, 31.2 ms inference latency, and 0.9 GB inference VRAM on a consumer-grade RTX 4090, matching or outperforming substantially larger VLA policies. These results establish TurboVLA as a simple and effective alternative to the prevailing LLM-centric VLA paradigm, offering a new perspective on how vision, language, and action can be connected for efficient robotic manipulation. Code is available at https://github.com/H-EmbodVis/TurboVLA.

# TurboVLA 论文总结

## 1. 核心问题与整体含义（研究动机与背景）

- **主流 VLA 模型的瓶颈**：现有视觉-语言-动作（VLA）模型普遍采用"以大语言模型为核心"的 **V→L→A** 路径，即先将视觉观测投影到 LLM 的表征空间，与指令共同经过 LLM 处理后再解码为动作。这种范式虽得益于大规模预训练，但在每一次策略调用中都带来巨额计算与显存开销。
- **部署痛点**：高延迟、高显存、依赖高端 GPU 与网络远程推理，难以满足实时闭环操控、资源受限平台部署的需求。
- **根本性反思**：作者指出——执行级控制（execution-level control）并不需要 LLM 这种通用生成与推理能力。语言只需提供"应当执行何种技能"的任务条件化信息，执行策略真正需要的是"基于当前视觉证据如何动作"。
- **研究目标**：提出一种无需以 LLM 为中心即可实现高效、强性能语言条件化操控的 VLA 新范式，使机器人策略可在消费级 GPU 上实时运行。

## 2. 方法论：核心思想与关键技术细节

### 2.1 总体范式：**V+L→A** 直接映射

- **核心思想**：去除 LLM 这一中央接口；分别编码视觉与语言，通过轻量双向交互直接交换信息，再用紧凑解码器并行预测连续动作块。
- **三阶段流程**：
  1. **多模态独立编码**：视觉用 DINOv3，文本用 BERT；分别投影到共享隐藏维度 d=256。
  2. **视觉-语言双向交互**：通过 N=6 层双向交叉注意力模块，让两条流互相更新。
  3. **连续动作块解码**：ACT 风格 Transformer 解码器，融合多模态特征 + 机器人本体状态，输出 H=12 步的 7-DoF 连续动作块。

### 2.2 模块细节

- **视觉编码**：每个摄像头视角独立提取空间特征，叠加位置嵌入与视角嵌入（区分多视角），再按视角拼接为 $Z_v^n \in \mathbb{R}^{N_v \times d}$。
- **文本编码**：保留 BERT 输出的完整 token 序列 $Z_l = P_l(f_{\text{text}}(x)) \in \mathbb{R}^{N_l \times d}$，不池化为单一向量，保留物体、属性、空间关系等细粒度信息。
- **机器人状态**：单独由轻量网络编码为 $Z_s^n \in \mathbb{R}^{N_s \times d}$，仅在动作解码阶段引入，避免污染跨模态对齐。
- **V-L 交互模块**：每层包含 LayerNorm + 双向交叉注意力 + 模态专属 FFN + 残差连接。视觉→指令注意力注入场景上下文；指令→视觉注意力让任务语义引导视觉特征。最终将更新后的两条流拼接为 $Z_{vl}^n = [V_n^N ; L_n^N]$。
- **动作解码**：所有 H 个可学习查询在单次前向传播中并行解码，无需动作 token 化或自回归生成；训练目标仅为行为克隆的 ℓ1 损失，不引入额外 LM 损失。

### 2.3 与 LLM-centric VLA 的对比

- **不再有**：将视觉投影到 LLM 词表空间、拼接指令 token、过 LLM、用其表征预测动作这一长链路。
- **保留**：语言条件化、连续动作块预测、并行解码等高效执行所需要素。

## 3. 实验设计

### 3.1 数据集与场景

- **LIBERO**（单臂仿真）：四个子套件 LIBERO-Object / Spatial / Goal / Long，各 10 个任务；使用 OpenVLA 提供的 no-noops RLDS 数据集；混合训练一个统一模型。
- **RoboTwin 2.0**（双臂仿真）：50 个语言条件化双臂任务；仅用官方 clean 演示训练，未加随机化场景数据。
- **真实世界**：AgileX Piper 6-DoF 单臂 + 腕部 RGB-D + 第三视角 RGB-D；4 个任务（抓滚轮、移动扑克牌、按订书机、堆叠三个碗）。

### 3.2 对比方法

- **非 VLA 基线**：Diffusion Policy（Chi et al., 2023）。
- **能力导向 VLA**：OpenVLA、π0、UniVLA、π0.5、CogVLA、Mantis、MM-ACT、VLA-JEPA、VEGA-3D 等。
- **加速导向 VLA**：OpenVLA-OFT、DDVLA（Discrete Diffusion VLA）。
- **轻量化 VLA**：SmolVLA、DreamVLA、VLA-Adapter、Evo-1。
- **真实世界**：与 π0.5 在相同平台、数据、协议下对比。

### 3.3 评测协议与指标

- 成功率（LIBERO 每任务 50 rollout，共 2000 次；RoboTwin 2.0 每任务 100 rollout；真实世界每任务 40 次）。

## 6. 主要结论与发现

- **性能-效率前沿显著前移**：
  - LIBERO 上 97.7% 平均成功率（持平/略优于 π0.5 的 96.9%、CogVLA 的 97.4%），参数量仅 0.2B（约 π0.5 的 6%），延迟 31.2 ms（π0.5 为 93.6 ms），推理显存 0.9 GB（π0.5 为 12.8 GB）。
  - RoboTwin 2.0 上 60.2% 成功率（优于 π0.5 的 57.0% 与 StarVLA-α 的 50.3%），延迟 43.4 ms。
- **架构效率可直接转化为部署能力**：单机 RTX 4090 上即可实现 32 Hz 在线策略推理，适合边缘部署。
- **架构设计有效**：
  - 视觉-语言双向交互显著优于无交互与单向交互（97.7% vs 95.2/96.1/96.5%）。
  - N=6 与 H=12 是性能-效率甜点。
  - 文本编码器选择不敏感（T5-Small 97.1%、BERT 97.7%、SigLIP-Base 95.5%）。
- **核心启示**：执行级语言条件化操控不必以 LLM 为中心，简单的双向跨模态交互 + 紧凑解码器即可达到或超过大模型 VLA。

## 7. 优点

- **范式创新**：明确指出 LLM-centric 路径的非必要性，提出 V+L→A 简洁替代范式，对 VLA 社区有方法论层面的启发意义。
- **极致效率-性能平衡**：仅 0.2B 参数、<1 GB 显存、32 Hz 推理，是当前 LIBERO 榜单上 Pareto 最优的小型 VLA。
- **架构简洁清晰**：独立编码 → 双向交互 → 并行动作解码，无复杂 token 化、无自回归动作生成、无 LM 辅助损失，易复现与部署。
- **多场景验证充分**：单臂 + 双臂 + 真实机器人三层验证；与 π0.5 在真实世界同条件对比。
- **消融系统化**：从语言必要性、文本编码器、交互方式、深度、时域等多维度验证设计选择的合理性。
- **双向交互借鉴视觉定位模型**：从 Grounding DINO 中获得结构灵感，将视觉-语言直接对齐机制迁移到控制表征构建，思路新颖。

## 8. 不足与局限

- **设计定位局限**：作者明确指出 TurboVLA 主要面向"执行级指令"，不擅长高层任务规划、开放词汇推理、长程语义分解。复杂高层语义理解仍需 LLM 配合。
- **benchmark 区分度不足**：LIBERO 上多数方法集中在 96–97%，成功率接近饱和，对细微差异的区分度有限。
- **真实世界任务规模偏小**：仅 4 个任务、每任务 40 次评估，且未提供大量真实世界失败案例分析。
- **RoboTwin 2.0 评估范围有限**：仅在 clean 设置评测，未在 domain randomization 下测试鲁棒性。
- **缺乏对极端场景与失败模式的深入分析**：如光照变化、遮挡、干扰物、对未见指令的泛化能力等讨论较少。
- **未涉及分层规划**：未来工作提到将高层 LLM 规划与 TurboVLA 高效执行结合，但当前工作并未给出完整分层系统的实现与验证。
- **依赖预训练权重**：双向交互层初始化自 Grounding DINO 特征增强权重，DINOv3 与 BERT 的选择虽实验证过，但对其他文本/视觉骨干的迁移效果未做系统研究。
- **算力透明度**：训练时长、单卡耗时、能耗等细节未给出，限制了复现成本估算。
