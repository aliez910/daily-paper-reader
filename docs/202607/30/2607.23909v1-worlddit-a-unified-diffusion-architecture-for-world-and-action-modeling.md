## 摘要
许多近期的机器人策略通过使用大规模预训练的视觉-语言模型（VLM）作为动作主干来追求更强的控制能力。我们提出了 WorldDiT，一种统一的扩散 Transformer 架构，它将动作生成与视觉世界建模相结合，且无需大规模预训练的 VLM 动作主干即可取得优异性能。在训练过程中，单个扩散 Transformer 同步生成连续动作块并从未来相机帧中预测归一化的 RGB patch 目标。在四个 LIBERO 仿真套件上，WorldDiT 在报告了全部四个套件的方法中，处于总模型参数量与平均成功率所构成的已报告帕累托前沿上。这些结果为未来的扩展性研究提供了一个强大的十亿参数以下基线。

## Abstract
Many recent robot policies pursue stronger control by using large pretrained vision-language models (VLMs) as the action backbone. We introduce WorldDiT, a unified diffusion transformer architecture that couples action generation with visual world modeling and achieves strong performance without a large pretrained VLM action backbone. During training, a single diffusion transformer generates continuous action chunks and predicts normalized RGB patch targets from future camera frames. Across four LIBERO simulation suites, WorldDiT lies on the reported Pareto frontier for total model parameters and mean success among methods reporting all four suites. These results provide a strong sub-billion-parameter baseline for future scaling studies.

## 2. 方法论

### 2.1 整体架构

- **统一扩散 Transformer（WorldDiT）**：由冻结的视觉编码器（MAE）、冻结的文本编码器（CLIP）、共享的 Perceiver Resampler、可训练的机器人状态编码器，以及一个可训练的 DiT 主干组成。
- **输入上下文**：语言指令 ℓ + 来自多视角（主相机 + 腕相机）的 C = 3 步观察序列 {oⱼ, sⱼ}。
- **输出**：在最后一个时间槽上同时预测 **H = 7 步动作块 Aᵢ ∈ ℝ^(7×7)** 与 **未来归一化 RGB patch 目标**（来自主相机与腕相机在 i+H 时刻的帧）。

### 2.2 RGB patch 目标构造

- 每帧经 CLIP 预处理为 224×224，按 16×16 patch 切分 → 每个 patch 为 768 维向量。
- 对每个 patch **按自身均值和方差归一化**（per-patch normalization）。
- 从每帧中**均匀采样 64 个 patch**，两个相机共 128 个 token。

### 2.3 训练：流匹配（Flow Matching）

- 干净目标为 y（动作或 RGB patch），采样噪声 ε ~ N(0, I)，τ ~ U[0,1]，构造中间状态：
  - x_τ = (1 − τ)ε + τy
- 流匹配损失（速度场回归）：
  - L_flow = E[‖v_θ(x_τ, τ, c) − (y − ε)‖²]
- 总损失为动作损失与 RGB patch 损失的加权和：
  - L_total = w_action · L_action + w_rgb · L_rgb
  - 论文实际取值：**w_action = 0.1，w_rgb = 0.001**

### 2.4 模型规格

- DiT 主干：depth = 4，hidden size = 1024，attention heads = 16，register tokens = 4。
- 完整训练窗口：N = 10 步（含 3 步上下文 + 7 步动作目标 + 1 步未来 RGB 目标）。
- 参数量：**总参数 399.084 M（含冻结模块），可训练参数 135.107 M**。

### 2.5 推理与部署

- 部署阶段**完全丢弃 RGB patch 路径**：仅使用上下文编码 G_t。
- 动作从高斯噪声 x₀ ~ N(0, I) 出发，通过 **20 步 Euler 积分**生成 7 步动作块：
  - x_{τ+Δτ} = x_τ + Δτ · v_θ(x_τ, τ, c)
- **执行前 3 个动作 → 滑动窗口 → 重规划**（receding horizon），并对重叠时段使用时间集成（temporal ensembling）。

## 6. 主要结论与发现

- **LIBERO 四套件成绩**：Spatial 98.0%、Object 97.0%、Goal 92.8%、Long 91.8%，**平均 94.9%**。
- **帕累托前沿位置**：WorldDiT 在"总参数 × 平均成功率"二维空间中处于已报告方法的帕累托前沿上。

- **核心结论**：无需将大型预训练 VLM 放在动作主干中，仅凭统一的扩散 Transformer 即可在 LIBERO 上取得当前最优级别的控制性能，验证了"统一世界建模 + 动作建模"作为紧凑可扩展基线的可行性。

## 7. 优点与亮点

- **架构简洁性**：单一 DiT 主干同时建模动作与未来视觉，**RGB patch 预测仅作为训练辅助目标**，推理路径纯净（action-only）。
- **轻量高效**：3.99 亿总参数 / 1.35 亿可训练参数即可对标数十亿级 VLA 模型的性能，**计算与部署成本显著降低**。
- **清晰的范式**：将"世界模型"目标与"动作生成"目标统一到同一流匹配框架下，方法学上具有可推广性。
- **坦诚的实验披露**：明确指出 300/500 回合未严格 held-out、无法复现对比方法、数据代码未完全公开等问题，**研究透明度较高**。
- **未来方向设想**：讨论了动作与视觉共享流匹配形式，便于**独立专家分解**（expert decomposition）、**异构硬件部署**与**边缘机器人平台**应用，与 Paris / Paris 2.0 路线相呼应。

## 8. 不足与局限

- **无消融实验**：未报告去除 RGB patch 损失、改变 w_rgb / w_action 比例、调整上下文长度 C 或动作块长度 H 的影响，难以判断世界建模目标对控制性能的**实际贡献量**。
- **无扩展性研究**：标题强调"scaling studies 的基线"，但论文本身**未提供任何规模扫描**（如参数、训练数据量、训练步数 vs 性能曲线）。
- **评测偏差风险**：
  - 每套件 500 回合中 300 回合被用于 checkpoint 选择，**94.9% 不构成严格无偏测试估计**。
  - 缺乏真实机器人验证，泛化到真实场景的能力未知。
- **公平比较局限**：24 个对比方法的分数均来自各自原始报告，**协议不统一**（回合数、动作集成、checkpoint 选择等可能不一致）；部分方法参数为重建估计（标注为"近似"）。
- **依赖冻结大型编码器**：尽管不使用"大型预训练 VLM 作为动作主干"，WorldDiT 仍依赖**冻结的 MAE 视觉编码器 + CLIP 文本编码器**，这些外部编码器本身参数量不小，是否真正"不依赖 VLM"在概念上仍有边界争议。
- **数据与代码公开度有限**：模型权重与训练代码**未完全公开**，限制复现与社区验证。
- **场景单一**：仅 LIBERO 仿真基准，未涉及更复杂的接触密集型任务、动态环境或多模态指令等场景。
