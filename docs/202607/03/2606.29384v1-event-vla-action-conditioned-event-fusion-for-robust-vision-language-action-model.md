## 摘要
视觉-语言-动作（VLA）模型已成为具身人工智能的重要范式。然而，现有的VLA模型通常假设照明良好且稳定的室内环境，而真实世界中的具身操作可能涉及因光照变化导致的退化RGB观测，这对鲁棒的机器人操作提出了严峻挑战。为了解决这一问题，我们提出了Event-VLA，一个事件增强的VLA框架，用于在不同光照条件下进行可泛化的操作。我们将退化可见度下的基于VLA的操作表述为以RGB为中心策略的一个实际鲁棒性问题，并引入事件流作为光照鲁棒、运动敏感的互补观测，以提升在各级可见度下的鲁棒性。具体来说，与直接将事件特征合并到全局语义令牌空间中的传统多模态融合不同，Event-VLA通过动作查询路由通路注入事件信息。它使用可学习的动作查询从VLA推理过程中提取任务相关语义，并通过门控交叉注意力选择性聚合事件令牌，构建事件感知的动作表示。这种设计保留了预训练的RGB-语言语义先验，同时有效利用事件信息进行鲁棒的动作预测。仿真和真实世界部署的实验表明，Event-VLA在正常光照下保持强劲的操作性能，并在低光照退化及近乎黑暗的真实场景中提高了成功率。

## Abstract
Vision-Language-Action (VLA) models have become an important paradigm of embodied AI. However, existing VLA models typically assume well-lit and stable indoor settings, while real-world embodied manipulation may involve degraded RGB observations caused by illumination shifts, posing critical challenges for robust robotic manipulation. To address this gap, we propose \textbf{Event-VLA}, an event-enhanced VLA framework for generalizable manipulation across varying illumination conditions. We formulate VLA-based manipulation under degraded visibility as a practical robustness problem for RGB-centric policies, and introduce event streams as an illumination-robust, motion-sensitive complementary observation to improve robustness across visibility levels. Specifically, unlike conventional multimodal fusion that directly merges event features into the global semantic token space, Event-VLA injects event information through an action-query routing pathway. It uses learnable action queries to extract task-relevant semantics from the VLA reasoning process, and selectively aggregates event tokens via gated cross-attention to construct event-aware action representations. This design preserves the pretrained RGB-language semantic priors while effectively leveraging event information for robust action prediction. Experiments in simulation and real-world deployment show that Event-VLA maintains strong manipulation performance under normal lighting and improves success rates under low-light degradation and near-dark real-world settings.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- 现有视觉-语言-动作（VLA）模型（如 OpenVLA、π0 等）通常假设室内环境照明良好、成像稳定，但真实机器人操作中常出现光照变化导致 RGB 观测显著退化（低光、近暗、噪声、运动模糊等）。
- 在此类退化条件下，传统 RGB 观测的纹理、颜色和边界信息大量丢失，导致 VLA 语义接地不稳、动作预测不可靠，这是一个亟待解决的鲁棒性问题。
- 事件相机（event camera）因其高动态范围、低延迟、对运动和光照变化敏感等特性，能在 RGB 退化时仍捕获运动轮廓和边缘线索，可作为理想的互补传感模态。
- 论文核心问题：**如何将异步高频事件流有效、可控地集成到预训练的 VLA 模型中**，既增强光照退化下的鲁棒性，又不破坏原有的 RGB-语言语义先验。

## 2. 论文提出的方法论

### 核心思想
- **避免将事件标记直接注入预训练 VLA 的全局语义自注意力空间**。事件信息仅通过后骨干（post-backbone）的**动作条件门控交叉注意力**和**查询引导路由**参与下游动作预测，从而保护预训练的 RGB-语言语义通路。

### 关键技术细节
1. **PREI（Physical Residual Event Integration）**：
   - 将异步事件流压缩为三通道物理残差图：瞬时通道（强调近期运动）、显著通道（局部突出活动）、持久通道（短时轮廓）。
   - 公式：以事件窗口内每个像素的衰减活性图为基础，经指数衰减、局部归一化等操作生成残差图。
2. **事件编码器与特征蒸馏**：
   - 使用 DINO 作为冻结视觉教师，通过全局和局部特征对比蒸馏，使事件标记与 VLA 隐藏空间更兼容。
3. **动作条件事件接口**：
   - 输入包含可学习的 common query、action query、event query，通过 VLA 骨干获得上下文化表示。
   - **门控交叉注意力**：VLA 隐藏标记与事件标记计算注意力，再由门控网络（基于多类查询特征）控制融合强度。
   - **查询引导路由**：common+action query 将融合后动作相关标记路由到动作头；common+event query 将事件相关标记路由到辅助事件头。
4. **训练目标**：
   - 主损失：动作预测的 ℓ1 损失（预测动作块与真值之间的误差）。
   - 辅助损失：未来 PREI 预测的 ℓ1 损失 + 梯度一致性损失，仅在训练时作为正则化，推理时不需要。

## 6. 论文的主要结论与发现

- 在正常光照下，Event-VLA 保持与 SOTA RGB 基线相当的成功率（平均 96.5% vs. 96.3%）。
- 在 LIBERO-Cross 三级退化下，RGB 基线成功率急剧下降（LL-Severe 平均低至 61.9%），而 Event-VLA 维持在 95.6%，提升显著。
- 事件-动作接口的消敛表明：**PREI 表示优于时间表面，查询路由优于简单拼接或适配器，完整查询设计和未来事件正则化均带来增益**。
- 真实世界部署验证了事件信息在近暗环境下的实际价值（Event-VLA 平均 65% vs. π0 48.3%）。

## 7. 优点

- **接口设计精巧**：通过查询路由和门控交叉注意力，在不上扰预训练语义的前提下有效利用事件信息，实现了“语义由 RGB 语言建模，事件仅注入动作通路”的设计原则。
- **系统鲁棒性提升**：在严重光照退化下（LL-Severe）仍保持 95%+ 成功率，远超直接使用 RGB 的基线。
- **轻量化**：事件编码和融合仅引入极小的推理延迟（+2.157ms），且事件头仅在训练时使用。
- **评估全面**：同时覆盖标准条件、受控渐进退化、真实部署，并提供详尽消融，验证了表示、接口、查询、正则化各自贡献。
- **与现有 VLA 兼容**：可基于任意预训练 VLA 骨干（如 OpenVLA）实现，无需重新训练整个模型。

## 8. 不足与局限

- **对模拟器的依赖**：LIBERO 实验依赖 RGB→Event 模拟器生成事件观测，可能无法完全反映真实事件相机的噪声、触发动态和校准误差。
- **真实世界实验规模有限**：仅 4 个任务，每光照条件 40 次试验，统计显著性有限，且任务类型相对简单，未验证长时间跨度或多物体场景。
- **硬件要求提高**：需要额外的事件相机硬件及精确的时间同步，增加了部署成本和复杂度。
- **适用范围有限**：目前框架专门针对光照退化设计，在其他退化类型（如遮挡、传感器故障）下效果未验证。事件辅助的有效性依赖于场景中存在足够的运动和对比度。
