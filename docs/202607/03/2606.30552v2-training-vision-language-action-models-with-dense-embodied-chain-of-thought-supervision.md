## 摘要
视觉-语言-动作（VLA）模型中的跨具身迁移仍然具有挑战性，因为不同机器人平台的低层状态和动作空间存在根本性差异。我们观察到，操作背后的高层认知过程，包括场景感知、物体识别、任务规划和子任务分解，在很大程度上是跨具身共享的。基于这一观察，我们提出了ZR-0，一个拥有26亿参数的端到端VLA模型，它使用密集的具身思维链（ECoT）监督来对齐视觉-语言模型（VLM）内的跨具身表示。ZR-0采用双流架构：一个预训练的VLM（系统2）在训练期间生成结构化的ECoT推理，而一个基于扩散Transformer的动作专家（系统1）通过流匹配产生连续的动作块。这两个组件通过交叉注意力耦合，并带有一个注意力掩码，该掩码限制动作专家仅关注输入提示特征，从而使得在推理时完全跳过ECoT生成而没有任何性能损失。ZR-0在ProcCorpus-60M上进行了预训练，这是一个包含约6000万帧（约1000小时）来自超过40万个轨迹的大规模数据集，密集的ECoT标注覆盖了96.8%的帧。我们在三个仿真基准上评估了ZR-0，涵盖单臂（LIBERO）、双臂（RoboTwin 2.0）和类人（RoboCasa GR-1 Tabletop）具身，以及在xArm平台上的真实世界实验，展示了在所有设置下的强大性能。代码和模型检查点可在https://github.com/RUCKBReasoning/ZR-0获取。

## Abstract
Cross-embodiment transfer in vision-language-action (VLA) models remains challenging because low-level state and action spaces differ fundamentally across robot platforms. We observe that the high-level cognitive process underlying manipulation, including scene perception, object identification, task planning, and sub-task decomposition, is largely shared across embodiments. Based on this observation, we present ZR-0, a 2.6 billion parameter end-to-end VLA model that uses dense Embodied Chain-of-Thought (ECoT) supervision to align cross-embodiment representations within the vision-language model (VLM). ZR-0 adopts a dual-stream architecture: a pre-trained VLM (System 2) generates structured ECoT reasoning during training, while a Diffusion Transformer-based action expert (System 1) produces continuous action chunks via flow matching. The two components are coupled through cross-attention, with an attention mask that restricts the action expert to input prompt features only, enabling ECoT generation to be entirely skipped at inference without any performance loss. ZR-0 is pre-trained on ProcCorpus-60M, a large-scale dataset comprising approximately 60 million frames (approximately 1,000 hours) from over 400K trajectories, with dense ECoT annotations covering 96.8% of all frames. We evaluate ZR-0 on three simulation benchmarks spanning single-arm (LIBERO), bimanual (RoboTwin 2.0), and humanoid (RoboCasa GR-1 Tabletop) embodiments, as well as real-world experiments on the xArm platform, demonstrating strong performance across all settings. Code and model checkpoints are available at https://github.com/RUCKBReasoning/ZR-0.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题**：视觉-语言-动作（VLA）模型在跨机器人本体（cross-embodiment）迁移时面临根本性挑战。不同机器人的低层级状态和动作空间（如自由度、控制接口、运动范围）差异巨大，导致模型难以共享和迁移知识。现有的格式层面对齐方法（如零填充、统一维度）无法解决语义对齐的深层难题。
- **动机**：本文观察到，尽管低层控制指令是本体特定的，但高层认知过程（如场景感知、物体识别、任务规划、子任务分解）在跨本体间是共通的。作者认为，利用这种“具身无关”的推理过程作为监督信号，可以有效对齐跨本体的表示，从而提高迁移能力。
- **核心思想**：提出一种名为**ZR-0**的26亿参数端到端VLA模型，通过在训练中引入密集的**具身思维链（ECoT）** 监督信号，迫使模型学习到可迁移的、高层语义对齐的表示，从而解决跨本体迁移难题。

## 2. 论文提出的方法论

- **核心架构**：采用双流（System 1 / System 2）架构：
    - **System 2（VLM）**：基于预训练VLM（Qwen3-VL-2B-Instruct），处理视觉和语言输入，并在**训练时**生成结构化的ECoT推理序列。
    - **System 1（动作专家）**：基于**扩散Transformer（DiT）**，通过**流匹配（Flow Matching）** 直接生成连续的**动作块（Action Chunks）**。
- **关键耦合机制**：两个系统通过**交叉注意力**连接。动作专家的DiT块（1:3的自注意力与交叉注意力比例）以VLM输出特征作为Key/Value进行跨模态交互。一个重要的**注意力掩码**限制了动作专家只能关注VLM的“输入提示特征”（即任务指令和图像），**完全忽略了ECoT令牌**。这保证了推理时无需生成ECoT，仅需一次VLM前向传播即可提供所有所需特征，实现高效推理（不损失性能）。
- **ECoT标注结构**：每个ECoT序列包含六个组件，旨在强化VLM的不同能力：
    1.  **场景描述**（Scene Description）：提升物体识别能力。
    2.  **进度评估**（Progress Assessment）：提升任务进度感知能力。
    3.  **未来计划**（Future Plan）：提升长时序规划和推理能力。
    4.  **待做动作**（To-Do Actions）：将计划分解为具身无关的原子子任务（e.g., “Grasp the blue plate”），是**跨本体对齐的核心**。
    5.  **目标物体**（Target Objects）：边界框形式的视觉定位信息，提升空间注意力。
    6.  **离散动作**（Discrete Actions）：FAST tokenizer生成的离散动作令牌，连接高层推理和低层连续动作。
- **训练目标**：联合优化两个损失函数：
    - **下一个令牌预测损失（$L_{ntp}$）**：用于ECoT序列生成，仅更新VLM参数。
    - **向量场预测损失（$L_{fm}$）**：用于连续动作块生成，通过流匹配学习去噪向量场 $\pi_\theta(l, o_t, s_t, A_t^\tau, \tau) \rightarrow (A_t - \epsilon)$。该损失**同时更新动作专家和VLM**（通过VLM特征 $f_t$）。
    - 总体损失 $L = L_{ntp} + \alpha L_{fm}$，其中 $\alpha$ 为平衡系数。
- **推理流程**：模型接收指令、图像和机器人状态，初始化噪声动作块，通过前向欧拉积分迭代去噪得到最终动作。自动跳过ECoT文本生成，单次前向推理约90ms（A6000 GPU），满足实时控制需求。

## 8. 不足与局限

- **预训练数据量不足**：论文指出其预训练数据仅为约1000小时，相比其他VLA模型（如π0的10000+小时，LingBot-VLA的20000小时）存在量级差距。这导致对预训练中缺失的行为（如关闭动作）表现不佳。
