## 摘要
视觉-语言-动作（VLA）模型在机器人操作任务中取得了令人瞩目的泛化性能。近期研究通过将过往图像或语言摘要作为条件，构建了具备记忆增强能力的VLA模型，从而放宽了马尔可夫性假设。基于视觉的记忆方法通过对采样的历史图像帧施加条件来实现这一点，但其计算开销较高，并且在时间事件在视觉上存在歧义时（例如以微小位移反复按压按钮）存在根本性的局限。本文提出FM-VLA——一种融合基于力的记忆机制的VLA模型，使其能够针对非马尔可夫、接触丰富的操作任务进行时间上下文推理。我们采用一个以力时间序列重建任务预训练的变分自编码器（VAE），将力的历史信息编码为紧凑的力记忆标记。通过将力的潜在表征与短期状态历史投影为额外的条件标记并输入至动作专家模块，使VLA模型能够有效利用累积的接触事件历史来引导操作行为。我们在三项依赖记忆的任务上对FM-VLA进行了评估，包括寻找隐藏方块、按压按钮以及擦拭餐盘特定次数。实验结果表明，我们所提出的轻量化力记忆方法在仅引入极小推理开销的情况下取得了超过80%的成功率，性能显著优于各类基线方法。项目主页：https://qft-333.github.io/FM-VLA-Page/

## Abstract
Vision-language-action (VLA) models have achieved impressive generalization in robotic manipulation, and recent memory-augmented VLAs have relaxed the Markovian assumption by conditioning on past images or language summaries. Vision-based memory approaches address this by conditioning on sampled past image frames, but they are computationally expensive and fundamentally limited when temporal events are visually ambiguous, e.g., pushing a button multiple times with small movements. We propose FM-VLA, a VLA model with force-based memory, enabling temporal context reasoning for non-Markovian, contact-rich manipulation. We encode force histories into compact force memory tokens with a variational autoencoder (VAE) pretrained with force time series reconstruction. By projecting force latent representations and short state history as additional conditioning tokens to the action expert module, we enable VLAs to leverage accumulated contact event history to guide manipulation. We evaluate FM-VLA on three memory-dependent tasks, including finding a hidden block, pressing a button, and wiping a dish for a specific number of times. Our lightweight force memory achieves over 80% success rate with minimal inference overhead, significantly outperforming baseline approaches. Project page: https://qft-333.github.io/FM-VLA-Page/

# FM-VLA：面向接触丰富型操作的视觉-语言-动作模型基于力的记忆方法 —— 论文总结

## 1. 核心问题与整体含义（研究动机与背景）

- **核心痛点**：现有 VLA 模型（如 RT-2、OpenVLA、π0、π0.5 等）通常采用"无记忆"策略，将决策建模为对当前观测的马尔可夫式映射。这对单步任务有效，但在依赖长时程历史的任务上失效，例如：需要"重复计数"的操作（按按钮 N 次、擦碗 N 轮）、进度跟踪、多步状态推理（已检查了哪个杯子）。
- **现有路径的局限**：近期 MemoryVLA、MEM 等视觉记忆方案通过对历史图像帧做条件来引入记忆，但有两个根本问题：
  1. **视觉歧义**：微小变化的接触事件（按钮按压、擦拭）几乎无视觉位移，视觉记忆无法识别；
  2. **计算开销**：增加输入 token 长度、推理延迟高（K=16 时 π-MEM 延迟近 190 ms）。
- **关键洞察**：力/力矩信号天然编码接触事件幅度与重复次数，是比视觉更直接、无歧义、更轻量的交互信号源。但之前的力增强 VLA（ForceVLA、TA-VLA）仅用"短期力窗口"作为即时修正信号，并未将力作为长时程记忆机制。
- **整体目标**：提出以力信号为主的长时程"记忆通道"，替代或补充视觉记忆，使 VLA 在视觉模糊、接触密集场景下具备非马尔可夫时序推理能力。

## 2. 方法论

### 2.1 核心思想

将 **腕部六轴力/力矩（wrench）长时间历史** 通过预训练 VAE 压缩为 K 个紧凑的"力记忆 token"，并叠加 **短窗口关节状态 token** 一并注入到流匹配动作专家（action expert）的 suffix 序列中，使策略能够利用累积的接触事件历史来决策。

### 2.2 关键技术细节

- **问题形式化**：策略 π(aₜ | oₜ, l, hₜ)，其中：
  - 长期 wrench 历史 {f_τ}_{τ=1}^{t}（f_τ ∈ R^6，3 轴力 + 3 轴力矩）；
  - 短期 state 窗口 {s_τ}_{τ=t−W+1}^{t}（关节位置 + 夹爪状态，ds=16）；
  - 编码为 hₜ = [Z_f ‖ z_s]，即 K 个 wrench latent token + 1 个 state token。
- **wrench 预处理**：
  - 因果一阶 EMA 平滑（α=0.3），去除高频噪声；
  - 训练时对历史前部随机填充低幅高斯噪声前缀（≤10 s），阻止模型"作弊"靠序列长度推断进度。
- **Force-VAE 编码器**：Perceiver-IO 架构，K=8 个可学习 latent 查询，2 层 cross-attn + 10 层 latent self-attn，输出每维后验 (μₖ, log σ²ₖ) ∈ R^96；预训练任务为掩码 ELBO 重建（含 free-bits 防后验坍缩）。
- **短状态投影**：无 VAE、零初始化线性层直接读取最近 ~0.9 s 的关节状态窗口，输出单个 token。
- **token 注入位置**：在 action expert 的 suffix 中，置于 **噪声动作 token 之后**（post-position），保留基础 π0.5 的 RoPE 位置。

### 2.3 两阶段训练流程

1. **Stage 1（任务无关 Force-VAE 预训练）**：以逆频率任务采样在所有任务的 wrench 历史联合训练，仅用重建损失，无需标签。
2. **Stage 2（VLA 微调）**：冻结 VAE 编码器，仅取后验均值 μ_f；用 π0.5 的 rectified flow 目标微调 VLM、action expert、力 latent 投影器 W_f 与短状态投影器。

## 3. 实验设计

### 3.1 数据集与机器人平台

- **平台**：AgiBot G1 仿人双臂机器人（2 × 7-DoF + 1-DoF 夹爪），腕部 100 Hz 六轴 F/T 传感器，头部 + 双腕 RGB；
- **数据集规模（自采 VR 遥操作演示）**：
  - Task 1 找隐藏方块：200 段；
  - Task 2 按按钮 N 次：350 段；
  - Task 3 擦碗 N 轮：200 段；
- 并在 Zhiyuan Challenge 数据集上做了额外预训练。

### 3.2 三项接触丰富型任务

| 任务 | 关键时序依赖 |
|---|---|
| **Find a Block Under Two Cups** | 必须记住哪个杯子已检查，不能重复检查 |
| **Press a Button N∈{1,2,3} 次** | 视觉几乎不变，靠 wrench 脉冲计数 |
| **Wipe a Bowl N∈{1,2,3} 轮** | 单次来回为 1 轮，需接触起止识别 |

每项任务 18 次试验（Task 1：前/后杯各 9 次；Task 2、3：N=1/2/3 各 6 次），依据终止条件判定成功/失败。

### 3.3 对比方法

- **π0.5**：无记忆马尔可夫基线；
- **TA-VLA**：短窗（≈0.9 s）+ 未来力预测的力增强基线（论文 π0.5 重实现）；
- **π-MEM**：基于 MEM 的视觉记忆在 π0.5 上的重实现（K=5 帧 / 相机，≈ 1.5 s 步长）。

## 6. 主要结论与发现

- **主结果**：FM-VLA 平均成功率 **83.3%**，远高于 π-MEM（53.7%）、π0.5（27.8%）、TA-VLA（22.2%）；
- **任务细分**（FM-VLA）：Cups 100%（18/18）、Buttons 72.2%（13/18）、Wipe 77.8%（14/18）；
- **关键洞察**：
  - 视觉记忆在视觉变化微小的"按钮"任务上彻底失败（33.3%）；
  - 短期力窗口（TA-VLA）同样无效（与 π0.5 相当），证明 **长时程历史压缩** 而非原始信号直送是关键；
  - 单一信号（仅力 或 仅状态）均不足以兼顾"接触计数"与"空间定位"；
  - VAE 重建预训练目标显著优于 GRU（33.3%）、Q-Former（57.4%）；
- **效率**：仅 +3.3 ms 推理延迟（64.0 ms vs π0.5 基线 60.7 ms），远低于 π-MEM 的 +39 ms（K=5）和 +129 ms（K=16）。

## 7. 优点

- **新颖视角**：把力/状态 proprioceptive 流当作"轻量记忆通道"，而非"即时观测"，开辟 VLA 记忆设计新维度；
- **两阶段范式**：任务无关 VAE 重建预训练，避免依赖文本/类别标签，与下游微调解耦；
- **工程细致**：EMA 平滑、随机噪声前缀防长度泄露、post-position 注入保护 π0.5 RoPE 位置、token 数与基础模型容量对齐；
- **强实证**：在视觉不可区分的计数任务上把基线差距从 ~30% 拉到 ~40 个百分点；
- **推理极轻**：几乎可忽略的延迟增量，便于实际部署。

---

## 8. 不足与局限

- **token 瓶颈固定**：当前 K=8 对超长时程任务（数百接触事件）不足，作者建议未来引入分层或自适应压缩；
- **数据规模有限**：VAE 仅在自采演示上预训练，未在大规模跨任务力数据集上训练，泛化性受限；
- **统计显著性弱**：每格 18 次试验，无多次随机种子或置信区间，绝对差异的统计意义未量化；
- **任务覆盖窄**：仅 3 类接触丰富任务，且均为双臂桌面操作，未覆盖移动操作、软体形变、人机交互等；
- **依赖特定硬件**：需要 100 Hz 腕部六轴 F/T 传感器，对无腕部传感或低采样平台的可迁移性存疑；
- **缺失与语言记忆的对比**：未将基于语言摘要的长期记忆方案（如纯文本 scratchpad、ReMem-VLA）纳入对比，仅与视觉记忆对比；
- **VAE 与 Q-Former/GRU 的对比粒度**：训练步数、数据规模是否完全一致需进一步确认；
- **应用限制**：当前评估仅在实验室结构化场景中完成，复杂光照、遮挡、传感噪声下的鲁棒性未验证。
