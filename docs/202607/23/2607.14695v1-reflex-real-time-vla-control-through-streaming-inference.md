## 摘要
流匹配视觉-语言-动作（VLA）模型有望实现精确的连续控制，但其迭代去噪特性与实时机器人控制存在根本性的不兼容：全局时间步的注入会使 KV 缓存失效，迫使用户在缓慢的 $O(N^2)$ 重计算与数学上不正确的缓存复用之间做出选择。我们提出了 \textbf{Reflex}，一个通过利用时间步不变性（即感知编码器在功能上独立于去噪循环）来为流匹配策略实现实时流式推理的框架。Reflex 将注意力上下文划分为静态、滑动和动态三个区域，实现 $O(1)$ 增量缓存更新，同时在固定输入下保持与全批次等价的注意力输出。为确保在连续高频推理下的稳定性，我们引入了 AdaRMSNorm——一种通过流相位门控来防止 BFloat16 数值崩溃的自适应归一化层。此外，我们通过将视觉编码与动作生成解耦的异步流水线，并结合降低内核开销的算子融合，进一步最大化吞吐量。在 LIBERO 和 Kinetix 基准测试上，Reflex 实现了 2.58 倍的推理加速和 50Hz 的稳定流式输出，将反应延迟最高降低 54%，并在不影响性能的前提下实现高效部署。

## Abstract
Flow matching Vision-Language-Action (VLA) models promise precise continuous control, but their iterative denoising nature introduces fundamental incompatibilities with real-time robotics: global timestep injection invalidates KV-caching, forcing a choice between slow $O(N^2)$ re-computation or mathematically incorrect cache reuse. We present \textbf{Reflex}, a framework that enables \textit{real-time streaming inference} for flow matching policies by exploiting the \textit{Timestep-Invariance Property} -- that perception encoders are functionally independent of the denoising loop. Reflex partitions the attention context into static, sliding, and dynamic regions, enabling $O(1)$ incremental cache updates while preserving full-batch-equivalent attention outputs for fixed inputs. To ensure stability under continuous high-frequency inference, we introduce \textit{AdaRMSNorm}, an adaptive normalization layer that prevents BFloat16 numerical collapse by gating on flow phase. We further maximize throughput through an \textit{async pipeline} that decouples visual encoding from action generation, combined with \textit{operator fusion} that reduces kernel overhead. On LIBERO and Kinetix benchmarks, Reflex achieves a 2.58$\times$ inference speedup and 50Hz stable streaming, reducing reaction latency by up to 54\% and enabling efficient deployment without performance degradation.

# Reflex：通过流式推理实现实时 VLA 控制

## 一、核心问题与研究背景

- **核心矛盾**：流匹配（Flow Matching）视觉-语言-动作（VLA）模型虽然能生成高精度连续动作，但其迭代去噪过程与实时机器人控制存在根本性冲突。机器人控制需要 50–100Hz 的频率，而当前 SOTA VLA 模型单次推理需 100–200ms，存在一个数量级的频率缺口。
- **关键瓶颈**：现有 Transformer 推理依赖 KV 缓存将复杂度从 O(N²) 降至 O(N)，但流匹配 VLA 在每一层注入全局时间步 t，使缓存键值随时步变化而失效，迫使系统在"缓慢的 O(N²) 重计算"与"数学上不正确的缓存复用"之间二选一。
- **推理-控制间隙**：即便采用动作分块（action chunking）延迟执行，长分块也会引入陈旧观测；异步推理虽能掩盖延迟，却无法降低计算本身的开销。
- **研究目标**：突破"停-思-动"同步循环，转向流式异步执行架构，从系统层面而非单纯加速单步推理的角度解决实时性问题。

## 二、方法论：核心思想与关键技术

### 2.1 核心洞察——时间步不变性（Timestep-Invariance Property）

- VLA 模型普遍采用两段式架构：重型 VLM 主干（处理视觉与语言嵌入，计算昂贵但与去噪时间步 t 无关）+ 轻量级动作专家（流匹配解码器，依赖 t 逐层变化）。
- 利用感知编码器 ∂Enc/∂tₖ = 0 的性质，将 KV 缓存按语义分区处理。

### 2.2 分区注意力（Partitioned Attention）

将上下文划分为三个语义区域：

- **静态前缀（Static Prefix）**：指令 token ℓ₁:L，仅计算一次并永久钉住。
- **滑动历史（Sliding History）**：最近 N 帧视觉观测 o_{t-N:t}，FIFO 队列管理，N=10（约 300ms）。
- **动态后缀（Dynamic Suffix）**：流状态 x⁽ᵏ⁾ 与时间步嵌入，每个去噪周期重置。

数学表达：Attn(x⁽ᵏ⁾) = Softmax(Q⁽ᵏ⁾[K_pin; K_slide(t); K_dyn(k)]ᵀ / √d) · [V_pin; V_slide(t); V_dyn(k)]

- 该方案在固定观测窗口与固定输入下，与全批次注意力输出完全等价（MSE = 0.00），但每步只需 O(1) 增量更新。
- 配合 **Manual Cache Merging**（预合并为连续 buffer）与 **Incremental Prefill**（仅编码最新帧），消除动态内存分配抖动。

### 2.3 AdaRMSNorm：流式稳定性保障

- 问题：50Hz 高频运行使模型接触高方差流初始化噪声（x ~ N(0,I)）的频率比训练时高 50 倍，导致 BFloat16 下激活值下溢，标准 RMSNorm 在 120–220 步后即崩溃。
- 方案：AdaRMSNorm(x, c) = (x / RMS(x)) ⊙ γ(c)，其中 γ(c) = 1 + MLP(c)，c = [tₖ, sₜ]（时间步嵌入 + 本体感受状态）。
- 关键细节：RMS 统计量强制 FP32，门控 MLP 保持 BFloat16；通过运行时探测 o_proj 层确定硬件精度，避免类型不匹配。可将稳定步数从 120–220 提升至 >2000 步，且无 NaN/Inf 事件。

### 2.4 异步流水线与系统级优化

- **双线程架构**：线程 A（视觉流，10–30Hz 编码 + KV 入队）、线程 B（策略流，50Hz 去噪消费），重叠视觉编码与动作执行。
- **未来状态预测器**：以最近一条命令 a_cmd 近似未来本体状态 ŝ_{t+Δ}，补偿异步延迟（而非学习型动力学模型）。
- **Adaptive Overlap Scheduling**：根据实时推理延迟 τ̂_inf 动态调整前瞻 K，使下一动作块刚好在当前块结束时就绪。
- **算子融合**：WQKV（Q/K/V 合并）、SwiGLU 的 Gate+Up 合并，使每层 kernel 启动数减半，单流推理墙钟提速 15–20%；FlashNorm 与 FusedAdaLN 进一步减 4.2ms。
- **环形缓冲区（Ring Buffer）**：系统启动时预分配 B ∈ ℝ^{L×N_max×H×D}，自定义指针算术实现零动态分配，确保确定性延迟。

### 2.5 算法骨架

主循环算法（Algorithm 1）：执行 chunk 中每条动作 → 在执行第 C−K 步时预测未来状态并异步启动下一推理 → 等待下一 chunk 就绪，构成连续闭环。

## 六、主要结论与发现

- **加速效果**：π0.5 在 LIBERO 上推理延迟从 135.2ms → 52.4ms（2.58× 加速）；π0 达 2.73×，呈现规模无关性。
- **控制频率**：稳定达成 50Hz 流式推理，反应延迟最高降低 54%（LIBERO-Long，π0），停滞率从 100% 降至 0%。
- **任务性能**：LIBERO 上与同步基线持平甚至略优（LIBERO-Long 提升 +3.6% ~ +4.0%）；Kinetix 上提升更明显（+6.7% ~ +7.4%），验证了低延迟对动态任务的关键作用。
- **注意力等价性**：固定输入下分区注意力与全批次注意力 MSE = 0.00。
- **稳定性**：AdaRMSNorm 支持 >2000 步无 NaN/Inf，远超典型回合长度。
- **可移植性**：RTX 3090 上仍保持 2.47× 加速；SmolVLA 上 2.29× 加速，验证架构无关性。
- **核心结论**："停-思-动"并非 VLA 模型固有局限，而是可通过算法与运行时协同设计解决的系统工程选择。

## 七、优点与亮点

- **理论-工程结合**：给出 Partitioned Attention 的形式化等价性证明，避免了"近似缓存"带来的隐性误差；Naive Cache MSE >1.0 的对比实验有力凸显了理论正确性的必要性。
- **系统层面创新**：从单纯优化单步推理转向"异步流式执行"思路，识别出根本瓶颈是同步等待而非计算时长本身——这一洞察对领域具有启发性。
- **多层次优化**：算法（分区注意力）、数值稳定性（AdaRMSNorm）、调度（异步流水线 + 前瞻补偿）、底层（算子融合 + 环形 buffer）四层协同。
- **数值稳定性贡献**：首次系统分析流匹配 VLA 长程部署的 BFloat16 数值崩溃问题，并提出轻量修复方案（仅 +0.4ms）。
- **验证充分**：不仅有仿真基准，还在 AgileX PiPer 实机上验证了可行性，三任务均获得 +11~+17pp 的成功率提升。
- **开源友好**：代码已开源（GitHub 链接），包含 StreamingInputManager、Ring Buffer 等实现细节。

## 八、不足与局限

- **架构适用性限制**：Reflex 依赖感知编码器"时间步不变性"，因此不适用于统一 DiT 风格、时间步条件进入视觉编码器的架构；适用范围存在结构性约束。
- **未来状态预测的简化**：采用 a^t_cmd ≈ ŝ_{t+Δ} 的一阶近似而非学习型动力学模型，在 100ms 前瞻下 <3cm 末端偏差，但当低层跟踪误差累积或任务时长更长时可能失效。
- **异步组件仅作经验验证**：异步调度、未来预测、混合精度行为均"通过实证评估而非等价性证明"覆盖，缺乏严格的稳定性/最优性理论保证。
- **数值稳定性分析范围**：AdaRMSNorm 解决了 RMS 路径主因，但作者明确指出这是"经验失效分析而非穷尽证明"；长程运行下的次级数值因素仍可能存在。
