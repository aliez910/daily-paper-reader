## 摘要
世界动作模型（World Action Models, WAMs）通过联合建模视觉状态转移与机器人动作，为机器人操作提供了一种颇具前景的范式。然而，现有 WAMs 受到有限的时间上下文、粗粒度的片段级语言监督以及主要以文本为条件的约束，阻碍了任务进度跟踪与细粒度的语言-视频-动作对齐，同时也限制了视觉上下文推理与跨具身迁移能力。本文提出 WorldScape Policy 2.0，一种具备推理增强长短期记忆的可控 WAM。其因果短期视觉记忆以 DiT 预填充形式提供近期观测，以保留局部交互动态；其长短期事件记忆将历史 VLM 输出组织为全局历史、局部活跃与事件边界表示，以支持具备进度感知能力的检索。检索到的历史信息对感知与自回归生成的计划标记进行增强，形成用于自主规划的隐式子目标条件；语义强制机制进一步将事件级指令语义迁移至该潜在规划通路中。为建立细粒度的多模态可控性，本文构建了 ManipEvent-5M——一个以事件为锚定的具身预训练数据集，包含近 500 万个事件片段，并配有对齐的动作轨迹、片段级任务指令、子片段级子任务描述、目标图像以及视频演示。上述设计为基于高层指令的自主规划以及基于细粒度文本、目标图像或视频上下文提示的可控执行提供了统一接口。在仿真与真实世界平台上的实验表明，该方法在长时程自主规划、细粒度指令跟随以及上下文自适应方面均表现出卓越能力。

## Abstract
World Action Models (WAMs) offer a promising paradigm for robotic manipulation by jointly modeling visual state transitions and robot actions. However, existing WAMs are constrained by limited temporal context, coarse episode-level language supervision, and predominantly text-only conditioning, which hinder task-progress tracking and fine-grained language-video-action grounding while limiting visual-context reasoning and cross-embodiment transfer. In this paper, we introduce WorldScape Policy 2.0, a controllable WAM with reasoning-augmented long short-term memory. Its causal short-term visual memory supplies recent observations as DiT prefill to preserve local interaction dynamics, while its long short-term event memory organizes historical VLM outputs into global-history, local-active, and event-boundary representations for progress-aware retrieval. The retrieved history augments perception and autoregressively generated planning tokens, yielding an implicit subgoal condition for autonomous planning; semantic forcing further transfers event-level instruction semantics into this latent planning pathway. To establish fine-grained multimodal controllability, we construct ManipEvent-5M, an event-grounded embodied pretraining dataset containing nearly 5 million event segments with aligned action trajectories, episode-level task instructions, segment-level subtask captions, goal images, and video demonstrations. These designs provide a unified interface for autonomous planning from high-level instructions and controllable execution from fine-grained text, goal-image, or video-context prompts. Experiments in both simulation and real-world platforms demonstrate superior capabilities in long-horizon autonomous planning, fine-grained instruction following and in-context adaptation.

# WorldScape Policy 2.0 论文总结

## 1. 核心问题与研究背景

### 1.1 研究动机
机器人学习正从任务特定策略向通用具身模型转变。然而现有世界动作模型（WAMs）在长时程可控操控方面存在三大瓶颈：

- **进度感知记忆缺失**：仅依赖当前观测或短窗口历史，无法在不同子任务阶段共享相似视觉场景时辨别"已完成什么、还需做什么"，导致子目标跟踪困难。
- **语言-视频-动作对齐粗糙**：具身数据集通常对整个 episode 使用同一条任务级指令，缺乏对原子动作的细粒度监督，模型易走视觉捷径，对原子动作变化不敏感。
- **交互接口受限**：现有 WAMs 主要由文本控制，无法自然接受目标图像、演示视频或跨具身示例，限制了视觉上下文推理与跨具身迁移。

### 1.2 整体目标
构建一个统一的、可控的 WAM，通过同时具备**短期视觉记忆**与**推理增强的长期事件记忆**，支持高层指令自主规划、细粒度文本指令、目标图像与视频演示的上下文自适应操控。

## 2. 方法论

### 2.1 整体框架
WorldScape Policy 2.0 采用 **VLM 分支 + 因果视频-动作 DiT 分支** 的双分支架构，共享训练目标与跨模态接口：
- **VLM 分支（推理 + 事件记忆）**：负责高层指令理解、事件级记忆检索和潜在子目标推理。
- **因果 DiT 分支（视觉 + 动作生成）**：以流匹配（flow matching）方式联合预测未来视觉潜变量与机器人动作。

### 2.2 关键技术细节

#### (1) 因果短期视觉记忆
- 维护最近 $S_v$ 个 chunk 的干净 VAE 潜变量 $Z_t^{vis}$，作为 DiT 的因果预填充。
- 通过 **causal self-attention** 让未来视频-动作 token 访问历史帧，保持局部交互动态。
- 可选的视觉提示（目标图像 / 视频演示）作为**持久预填充**贯穿整个 rollout。

#### (2) 推理增强的长期事件记忆（核心创新）
- **历史 VLM 输出结构**：每个历史 chunk 的 VLM 输出由感知 token $u_j$ 与自回归生成的计划 token $r_{1:K}^j$ 组成，构成 $q_j = [u_j; r_{1:K}^j]$，并保留全 token 作为锚点。
- **三种记忆视图**（显式构造）：
  - **全局历史 latents** $m_t^{gh}$：通过 attention pooling 压缩完整历史，加入任务指令后生成固定数量的全局槽位。
  - **局部活跃 latents** $m_t^{la}$：保留最近 $S_e$ 个 chunk 的全 token 锚点。
  - **事件边界 latents** $m_t^{eb}$：基于相邻 chunk 间的余弦距离 $d_j = 1 - \cos(\bar{q}_j, \bar{q}_{j-1})$ 通过 TopK$_{Δ}$ 选取语义变化最显著的 $S_b$ 个 chunk，同样保留全 token。
- **检索与门控融合**：通过独立 QKV 投影做 cross-attention，再以 token 级 sigmoid 门 $\gamma_t$ 控制注入量，得到记忆增强的推理潜变量 $\hat{q}_t$。
- **语义强制（Semantic Forcing）**：在训练阶段，将增强后的推理表示 $\hat{q}_t$ 通过投影器对齐到固定 T5 嵌入 $\bar{s}_t$ 的语义空间（$L_{sem} = 1 - \tilde{s}_t^\top \tilde{q}_t$），让自主规划通路继承 Stage-1 学到的细粒度语义。

#### (3) 双模式条件机制
- **细粒度指令模式**：$s_t = E_{T5}(c_t)$ 通过 cross-attention 直接注入 DiT。
- **自主规划模式**：高层指令 $y$ 配合 $o_t^{head}$ 由轻量 VLM（Qwen3-VL-4B）联合编码，自回归生成 K=4 个计划 token；记忆增强后的 $\hat{q}_t$ 作为条件。

#### (4) 动作表示与跨具身迁移
- 动作定义为每个 chunk 起始帧的相对位姿：3D 位置增量 $\Delta p$ + 连续 6D 旋转 $\phi_6(\Delta R)$ + 1D 夹爪指令，共 10D/臂。
- 各具身通过专用动作编码器 $E_a^{(e)}$ / 解码器 $D_a^{(e)}$ 接入共享 DiT，flow matching 在**原始动作空间**直接执行。

#### (5) 数据集 ManipEvent-5M
- 包含近 **500 万** 事件片段（约 512M 帧、4982 小时、744K episode）。
- 来源：自采 PiPER 数据、AgiBot World、RoboMIND、RoboCOIN、DROID、UMI、RoboTwin 2.0、LIBERO、EgoDex。
- 每条样本五元组：$(o_{t_b:t_e}, a_{t_b:t_e}, y, c_j, p_j^{goal}, p_j^{video})$。
- 通过四阶段层次化标注：**两阶段标注（边界检测 + 语义重标）→ 层次化帧采样 → 具身提示条件化 → 多视角冲突解决**（局部优先：左夹爪 → 右夹爪 → 头视角）。
- 提供第一/第三人称目标图像与跨具身视频演示对。

#### (6) 三阶段训练课程
- **Stage 1（事件级多模态预训练）**：仅使用 $L_{act} + \lambda_w L_{world}$，建立细粒度视频-动作对齐与短期视觉记忆。
- **Stage 2（记忆感知中训练）**：激活 VLM 事件记忆与语义强制，目标 $L^{(2)} = L_{act} + \lambda_w L_{world} + \lambda_s L_{sem}$（$\lambda_s = 0.001$），将事件级语义转移到自主规划通路。
- **Stage 3（下游交互式后训练）**：在目标机器人平台上对自主规划、细粒度指令跟随、视频上下文 ICL 三种模式分别适配。

## 6. 主要结论与发现

- WorldScape Policy 2.0 在 RoboTwin 2.0 上达到 **94.3% 平均成功率**（clean 94.3% / randomized 94.2%），clean 与 randomized 几乎无差距，表明强鲁棒性。

- 消融验证：短期视觉记忆、长期事件记忆、隐式子目标推理三者**互补单调提升**，Stage-1 事件级预训练贡献最大，Stage-2 + 语义强制进一步带来稳定增益。

## 7. 优点

- **统一接口设计**：单一模型支持自主规划、细粒度文本、目标图像、视频演示四种交互模式。
- **层次化记忆划分**：将"事件级语义记忆"与"帧级视觉动态记忆"显式解耦，使长期任务进度推理与局部交互动态各自各司其职。
- **语义强制机制**：通过 Stage-1 学到的 T5 嵌入作为冻结语义目标，使自主规划通路继承显式子任务语义，避免联合坍缩。
- **大规模数据工程**：ManipEvent-5M（5M 片段、跨多具身与人类数据）配合层次化标注、四阶段质量控制，是显著的工程贡献。
- **完备的实证**：仿真 + 真实 + 域内外 + 多类任务 + 多角度消融，证据链较扎实。
- **近乎无泛化差距**：clean 与 randomized 几乎一致，表明数据增强与预训练策略对扰动鲁棒性强。

## 8. 不足与局限

- **算力与训练成本不透明**：缺少 GPU 型号、数量、训练总时长、推理延迟等关键信息，难以评估方法的可复现性与部署门槛。
- **VLM 分支成为单点依赖**：推理增强记忆与子目标生成完全依赖 Qwen3-VL-4B，存在 VLM 偏置与失败传播风险。
- **数据来源集中**：底层覆盖虽然广（含 UMI、人类数据），但约 45% 的训练权重来自自采 PiPER 数据，存在系统性偏置。
- **仿真基准单一**：仅在 RoboTwin 2.0 上评估，未在 LIBERO、Meta-World 等其他仿真基准上验证迁移性。
- **真实世界平台单一**：仅 PiPER 双臂，缺乏其他具身（机械臂、人形等）的验证，"跨具身迁移" 主要体现在数据层面的视频演示对，而非真实异构平台的端到端验证。
- **基线对比边界**：对 π0.5 进行了时序扩展，可能夸大对比差距；且未与最近的开源 WAM（如 MemoryWAM、DSWAM 等）在真实任务上直接对比。
- **复杂组件带来超参数敏感**：语义强制权重 $\lambda_s = 0.001$、门控 scaling、记忆窗口长度等超参较多，论文未给出敏感度分析。
- **人类数据利用方式**：虽然纳入了 EgoDex 与 UMI，但实际训练权重较低（合计约 11%），人类知识贡献的潜力未完全释放。
- **应用边界**：模型依赖 20D 双臂相对位姿动作空间，对其他动作空间（如关节空间、速度场等）的扩展性需进一步验证。
