## 摘要
视觉-语言-动作（VLA）模型在视运动策略学习方面取得了令人瞩目的成果，但本质上仍是反应式的，仅将当前观测和语言映射到动作，缺乏对世界动态的显式前瞻预测。现有的视觉前瞻方法虽然能够预测未来的视觉状态，但缺乏显式的运动引导：它们指示了要去哪里，却没有说明如何到达。我们认为，未来特征预测与稀疏点跟踪天然互补：前者提供目标状态，后者捕捉通向目标的连续运动路径。我们提出 FoMoVLA，一个通过联合学习未来特征前瞻和稀疏 2D 点跟踪、以显式时空监督增强 VLA 表征的框架，从而提升连续动作策略。FoMoVLA 引入紧凑的前瞻 token 来解码未来特征状态，解码稀疏的时序 2D 点轨迹以建模紧凑的几何运动，并通过一个轻量级的未来条件交叉注意力模块将二者耦合，从而在预期状态与点动态之间实现一致的推理。在 LIBERO、RoboCasa GR-1 Tabletop 和 LIBERO-Plus 上的大量实验表明，FoMoVLA 达到了最先进的性能，并具有强大的零样本泛化能力。项目主页地址：https://liauto-research.github.io/FoMoVLA。

## Abstract
Vision-Language-Action (VLA) models have achieved impressive results in visuomotor policy learning, yet remain fundamentally reactive, mapping current observations and language to actions without explicit forward prediction of world dynamics. Existing visual foresight methods predict future visual states but lack explicit motion guidance: they show where to go but not how to get there. We argue that future feature prediction and sparse point tracking are naturally complementary: the former provides the goal state, while the latter captures the continuous motion path toward it. We propose FoMoVLA, a framework that augments VLA representations with explicit spatio-temporal supervision by jointly learning future feature foresight and sparse 2D point tracking, enhancing the continuous action policy. FoMoVLA introduces compact foresight tokens to decode future feature states, decodes sparse temporal 2D point trajectories to model compact geometric motion, and couples both through a lightweight future-conditioned cross-attention module that enables consistent reasoning between anticipated states and point dynamics. Extensive experiments on LIBERO, RoboCasa GR-1 Tabletop, and LIBERO-Plus demonstrate state-of-the-art performance and strong zero-shot generalization. Project page is available at https://liauto-research.github.io/FoMoVLA.

# FoMoVLA 论文总结

## 1. 核心问题与研究动机

- **VLA 模型的反应式局限**：现有视觉-语言-动作（VLA）模型本质上仍是反应式的（reactive），仅依靠当前观测和语言指令直接映射到动作，缺乏对世界动态的前向预测能力，难以建模长时序场景演化与物体交互动力学。
- **视觉前瞻方法的不足**：现有增强 VLA 前瞻能力的工作可大致分为两类，但都存在明显缺陷：
  - **密集像素级预测**（如 DreamVLA、WorldVLA）：保留丰富场景信息，但大量预测静态内容，产生表征冗余且计算开销大；
  - **关键帧级预测**（如 UniVLA、HiF-VLA）：效率更高，但只刻画"目标状态"，无法捕获到达目标所需的连续动态交互过程。
- **几何运动方法的局限**：基于光流或点轨迹的方法（FlowVLA、GeoPredict、JOPAT）虽然能建模运动路径，但通常单独优化，缺乏与未来视觉状态的显式交互。
- **核心洞见**：未来特征预测（提供"目标状态"）与稀疏点跟踪（提供"连续运动路径"）天然互补，**真正可执行的视觉前瞻应同时编码"未来是什么"和"如何到达"**。

## 2. 方法论

### 2.1 整体框架

FoMoVLA 在 VLA 基础模型上增加三个训练时分支，注入显式时空监督：

1. **点跟踪分支**（how to move）：预测稀疏 2D 点轨迹，赋予图像 token 显式运动信号；
2. **未来特征预测分支**（where to end up）：学习目标状态的紧凑表征；
3. **未来条件交叉注意力（FCCA）模块**：将前两者耦合，使运动预测受未来表征条件化。

所有辅助分支在推理时被丢弃，**零额外参数开销，仅引入 9.4ms 延迟和 0.1GB 显存**。

### 2.2 关键技术细节

- **点跟踪分支**：
  - 输入序列重排：文本 token 置于图像 token 之前，确保图像 token 隐藏状态被完整语言指令条件化（goal-aware）；
  - 稀疏点选择：N=64 个查询点（8×8 网格，与 patch cell 一一对应），将每个 patch 中心映射回原图坐标；
  - 教师信号：冻结的 CoTracker-v3 提供归一化位移目标 d⋆∈ℝ^(N×T×2) 和可见性标签 v⋆∈{0,1}^(N×T)；
  - 对齐头：轻量 MLP（LayerNorm→Linear→GELU→Linear）预测位移和可见性；
  - 损失函数：位移回归 L_disp + 可见性 BCE L_vis + 二阶差分平滑正则 L_smooth（公式 4–7），均用可见性 mask 过滤遮挡点。

- **未来特征预测分支**：
  - 在图像/指令 token 后附加 K=16 个可学习 `<Foresight>` token；
  - 目标：训练这些 token 编码动作 chunk 末帧 o_{t+T} 的视觉特征；
  - EMA 教师（动量 μ=0.999）提供稳定目标特征 z⋆∈ℝ^(M×d)；
  - MAE 解码器：K 个 Foresight token 拼接 M-K=48 个可学习 mask token，通过 2 层 ViT 解码器重建 64 个 patch 特征；
  - 损失：余弦相似度损失（公式 8）。

- **未来条件交叉注意力（FCCA）模块**：
  - 公式：H̃_vis = H_vis + MHA(LN(H_vis), LN(H_fut), LN(H_fut))，8 头多头注意力；
  - 输出投影**零初始化**：训练初期为恒等映射，保护预训练 VLM 特征不被扰动；
  - 作用：以未来表征为全局先验，约束局部轨迹估计，将两个目标耦合为协同优化。

### 2.3 注意力掩码设计（附录 A.2）

输入序列组织为：**Instruction → Current Image → Foresight → Action**，采用结构化不对称注意力掩码：
- 指令 token：严格因果自注意力；
- 图像 token：因果关注指令 token + 自身双向注意力；
- Foresight token：双向自注意力，同时关注指令和图像 token；
- Action token：关注所有前置模态（含 Foresight）。

### 2.4 训练目标

$$\mathcal{L} = \mathcal{L}_{action} + \lambda_1 \mathcal{L}_{foresight} + \lambda_2(\mathcal{L}_{disp} + \mathcal{L}_{vis} + \lambda_{smooth}\mathcal{L}_{smooth})$$

其中 λ₁=0.1，λ₂=0.3，λ_smooth=0.1；动作损失采用 flow matching 目标。

## 7. 优点与亮点

- **问题切分清晰**：明确区分"未来是什么"（目标状态）与"如何到达"（运动路径），二者通过互补设计联合监督；
- **训练-推理解耦**：所有辅助模块仅训练使用，推理时丢弃，实现"零参数增量、9.4ms 延迟"；
- **FCCA 设计的精妙**：零初始化保证训练初期不破坏预训练特征，渐进学习注入未来信息，避免了表征干扰；
- **多维度评估**：仿真基准 + 零样本 OOD + 跨策略头可扩展性 + 定性可视化，论证充分；
- **跟踪任务信号设计**：采用 patch 对齐的 8×8 网格点，与 ViT token 一一对应，避免冗余计算；
- **定量证据扎实**：FCCA 对跟踪精度的影响给出了 4 项具体指标提升；
- **可扩展性强**：在 StarVLA-π、StarVLA-OFT 等不同动作头框架上均带来稳定提升（最大 +8.2% in LIBERO-Long）。

## 8. 不足与局限

- **2D 表征局限**：点跟踪仅在图像空间建模，无法捕获 3D 几何，导致在视角变化（Camera）和机器人状态（Robot state）扰动上的泛化提升有限（LIBERO-Plus Camera 仅 64.0%，与最佳仍有差距）；
- **仿真为主**：所有实验基于仿真基准（LIBERO、RoboCasa），未在真实机器人硬件上验证；
- **训练数据视角固定**：模型在固定视角和初始位姿训练，难以泛化到全新配置；
- **教师依赖**：依赖冻结 CoTracker-v3 和 EMA 视觉编码器作为教师，跟踪与未来特征的监督信号质量受限于教师模型；
- **特征预测的紧凑性权衡**：MAE 瓶颈 K=16 虽高效，但可能丢失精细空间细节，未来若与更高分辨率 token 交互可能受限；
- **未明确讨论失败案例**：论文定性可视化集中于成功案例，缺乏对失败模式的系统分析；
- **未来工作方向**（论文自述）：将 2D 点跟踪扩展到 3D 运动预测，引入几何推理以增强视角鲁棒性。
