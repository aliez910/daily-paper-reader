## 摘要
类似于人类依次学习新任务的自然能力，搭载视觉-语言-动作（VLA）模型的机器人应当具备终身学习能力，以便在开放世界环境中部署时学习新任务。然而，目前大多数近期提出的终身学习模型侧重于有效学习当前任务（可塑性）或在先前任务上保持较高的准确率（稳定性），而可塑性-稳定性权衡问题在机器人操作模型中仍远未得到解决。为应对这一根本性挑战，我们提出了一种面向机器人操作的缓存高效的终身视觉-语言-动作学习框架（即LifelongVLA），该框架通过双时间尺度自适应机制缓解可塑性-稳定性权衡问题，并借助一种缓存高效的重放策略实现低成本的机器人部署。具体而言，我们提出了一种双时间尺度LoRA门控模块，将VLA自适应分解为两条轻量化路径：用于可塑性的短期适配器与用于稳定巩固的长期适配器。这些路径通过一个任务感知的门控进行集成，从而实现对可塑性-稳定性权衡的显式控制。在技能重放阶段，我们提出一种缓存高效的随机重放策略，在无需存储完整轨迹的情况下保留更加均衡的记忆信号。最后，实验表明LifelongVLA优于现有基线方法，展现了高效的技能扩展、对已学操作行为的稳健保持，并减少在xArm机器人上进行实际部署时对再训练的依赖。

## Abstract
Similar to the natural capabilities of humans to sequentially learn new tasks, robots with Vision-Language-Action (VLA) models should possess lifelong learning ability to learn a new task when deployed in open-world environments. However, most recently proposed lifelong learning models aim to effectively learn the current task (plasticity) or maintain high accuracy on previous tasks (stability), while the plasticity-stability trade-off remains largely unsolved in robotic manipulation models. To address this fundamental challenge, we propose a cache-efficient lifelong Vision-Language-Action learning framework for robotic manipulation (i.e., LifelongVLA), which alleviates the plasticity-stability trade-off with a dual-timescale adaptation mechanism while achieving low-cost robotic deployment with a cache-efficient replay strategy. More concretely, we propose a dual-timescale LoRA gating module to decompose VLA adaptation into two lightweight pathways: a short-term adapter for plasticity and a long-term adapter for stable consolidation. These pathways are integrated via a task-aware gate, enabling explicit control of the plasticity-stability trade-off. In the skill replay phase, a cache-efficient stochastic replay strategy is proposed to preserve more balanced retention signals without full-trajectory storage. Finally, experiments show that LifelongVLA outperforms existing baselines, demonstrating efficient skill expansion, robust retention of learned manipulation behaviors, and reduced reliance on retraining for real-world deployment on an xArm robot.

## 一、核心问题与研究动机

- **研究背景**：现有 VLA（Vision-Language-Action）模型（如 RT-2、π0、Octo、OpenVLA 等）大多采用**静态离线训练范式**：在固定的预收集技能集上训练一次后即部署，无法在开放世界环境中持续学习新任务。这与人能"依次学习新任务"的自然能力形成鲜明对比。
- **核心痛点**：机器人部署到真实环境后，会持续出现新物体、新指令、新场景布局及特定于本体的动作分布，需要**终身学习（lifelong / continual learning）** 能力，但 VLA 模型在该场景下面临严峻挑战：
  1. **可塑性-稳定性权衡（plasticity-stability trade-off）未解**：当前终身学习方法要么偏重新任务可塑性、要么偏向旧任务稳定性，两者难以兼得。
  2. **灾难性遗忘**：直接序列学习会覆盖已学行为。
  3. **重放成本高昂**：完整轨迹回放需存储并反复编码含图像的 episode，对大规模 VLA 骨干网络计算开销极大；架构扩展方法又会带来路由成本和推理延迟增加。
- **论文目标**：使 VLA 策略能在部署后**持续获取新操作技能**，同时**保留已学技能**，且具备**低开销、可部署**的特性。

## 二、方法论：核心思想与关键技术

LifelongVLA 构建在**冻结骨干网络**之上（frozen PaliGemma + Gemma 2B，配合 Gemma 300M 连续动作解码器，输出 7D 机器人动作），由两个核心模块组成：

### 1. Dual-Timescale LoRA Gating（双时间尺度 LoRA 门控）

- **核心思想**：将单一 LoRA 自适应路径拆分为**短期路径（plasticity）** 与**长期路径（stability）**，通过**任务感知门控**在权重层面合成，单次前向即可完成。
- **两条路径**：
  - **短期 LoRA** ΔW_sh = A_sh · B_sh：由当前任务损失 L_new 更新，学习率 η_sh 较高，专注快速获取新技能。
  - **长期 LoRA** ΔW_lg = A_lg · B_lg：仅由回放损失 L_rep 与蒸馏损失 L_dist 更新，学习率 η_lg < η_sh，负责巩固旧技能。
- **门控机制**：
  - 门控上下文 c 来自**冻结前缀特征**（避免循环依赖）：`c = Pool(stopgrad(E_pre(u; Θ₀)))`。
  - 门控权重 α ∈ [0, 1] 通过 `α = σ(W_g · φ(c) + b_g)` 预测，控制长期路径的贡献。
  - 合成公式：`W̃ = W₀ + γ·[(1−α)·ΔW_sh + α·ΔW_lg]`。
- **意义**：α→0 强调新技能可塑性，α→1 强调稳定性；提供对权衡的**显式控制接口**，且无需修改骨干或两次前向。

### 2. Cache-Efficient Stochastic Replay（缓存高效随机回放）

- **核心思想**：不存储完整轨迹，仅为每个技能**随机采样少量样本**，保存**stop-gradient 前缀 token** + 紧凑的状态-动作监督；回放时利用**当前模型**重新计算后缀 token 与扩散变量。
- **缓存结构**：
  - 每任务配额 c_t（论文设 c_t = 50），以蓄水池采样更新 `B_t = Reservoir(B_{t−1} ∪ {(h̄_pre, s, y)})`。
  - 不存储原始图像、语言 token、后缀 token、扩散时间/噪声。
- **随机回放过程**：
  1. 对缓存样本 (h̄_pre, s, y) **重新采样**扩散变量 τ′、ϵ′，生成加噪动作 ỹ_rep。
  2. 用**当前模型**重新计算后缀 token：`h_suf,rep = E_suf(s, ỹ_rep, τ′; Θ̃_t(c))`。
  3. 拼接到缓存前缀后由解码器 D 预测，得到 η̂_rep。
- **掩码混合目标**：
  - 将当前样本与回放样本拼接、洗牌，掩码 m∈{0,1} 区分来源。
  - 损失函数：`L_t = L_new + λ·L_rep + β·L_dist`，其中：
    - L_new、L_rep 各自归一化，避免任一来源主导。
    - L_dist 以任务 t−1 的**冻结教师模型** F̄_{t−1} 为目标，稳定旧技能预测。
- **收益**：以极小缓存提供多样且均衡的保留信号；每任务仅约 95.70 MiB，相比完整轨迹（167.62 MiB）节省约 43%，且比 AtomicVLA（452.98 MiB）节省约 79%。

### 3. 整体训练流程

1. 冻结骨干 Θ₀，仅训练 LoRA 通路与门控；
2. 每个新任务：用当前数据 + 缓存回放数据，以 L_t 更新短期 LoRA、长期 LoRA 与门控；
3. 推理：单次前向传播，根据门控自动平衡新旧技能。

## 三、实验设计

### 1. 数据集 / 场景

- **仿真基准**：**LIBERO** 基准 [Liu et al., NeurIPS 2023]，选 **10 个任务**进行增量技能学习评估。
- **真实机器人**：**xArm** 机器人上的 **5 任务流**，每任务采集 50 条训练轨迹，每任务 50 条评估轨迹。
- **任务设置**：每个增量步引入一个新任务；训练时只能访问当前任务数据与**有界回放缓存**；测试时**不提供任务身份**。

### 2. 评估指标

- **SR（Success Rate）**：所有见过任务的平均成功率。计算：`SR = (1/T)·Σ a_{T,i}`。
- **FOR（Forgetting Rate）**：旧任务遗忘率。`FOR_i = max_{l∈{i,…,T−1}} a_{l,i} − a_{T,i}`。
- **ACC_t**：过程级增量准确率。

### 3. 对比方法

- **SFT**（顺序全微调）：基线下界。
- **LwF-LoRA**（Li & Hoiem, 2017）：输出蒸馏型持续学习。
- **ER**（Chaudhry et al., 2019）：情景回放。
- **Info-VLA**（2026）：信息论正则化。
- **AtomicVLA**（2026）：技能级专家特化。
- **Joint**（所有任务联合训练）：作为**上界**，不参与排名。

### 4. 实现细节

- 骨干：冻结 PaliGemma（Gemma 2B）+ Gemma 300M 连续动作解码器，输出 7D 动作。
- 超参数：r = 16，γ = 16，批大小 M = 500，缓存配额 c_t = 50，λ = 1.0，β = 0.1。
- 训练步数：所有终身方法每任务 10,000 步；Joint 上界 40,000 步至收敛。

## 六、主要结论与发现

- **性能领先**：LifelongVLA 在 10 个 LIBERO 任务上取得 **平均 SR 83.2%、平均 FOR 11.4%**，相比最强基线 ER（70.2% / 19.6%）分别提升 **+13.0% 与 −8.2%**。
- **稳定性优势显著**：SFT 与 LwF-LoRA 仅 7.8% SR 且严重遗忘；Info-VLA、AtomicVLA 单独使用信息正则或专家特化无法解决权衡（均 28.6% SR）。
- **关键任务表现**：在 Task 5（96%）、Task 9（98%）、Task 10（96%）上达到高成功率；Task 9 的 FOR = 0，几乎无遗忘。
- **过程级行为**：在稳定性-可塑性散点图中最接近左上"理想区域"；增量准确率曲线随任务增加保持平稳。
- **效率优势**：
  - 缓存高效随机回放将内存从 167.62 MiB/task 降至 95.70 MiB/task（约 −43%）。
  - 双 LoRA 设计带来 99.97M 可训练参数，但仍显著少于 AtomicVLA（226.49M 参数 / 452.98 MiB 内存）。
- **真实部署可行**：在 xArm 5 任务流上，每任务成功率均超 80%，验证了方法从仿真到真实机器人的迁移能力。

## 七、优点与亮点

- **显式可塑性-稳定性权衡控制**：通过门控 α 在权重层面合成两通路，提供可解释、可调节的接口，且仅需**单次前向**，无额外推理延迟。
- **双时间尺度设计的生物学合理性**：借鉴记忆巩固理论（短期可塑 / 长期巩固），比单纯堆叠 LoRA 专家或单一正则更具动机支撑。
- **缓存高效**：仅存 stop-gradient 前缀 token + 紧凑监督，回放时再计算后缀与扩散变量，巧妙避免缓存陈旧与全轨迹重编码。
- **平衡的损失归一化**：L_new 与 L_rep 分别归一化，避免回放/新任务任一方主导梯度。
- **冻结骨干 + PEFT 范式**：与大规模 VLA 部署趋势高度契合，不破坏预训练知识。
- **教师蒸馏 + 缓存回放双保险**：以 F̄_{t−1} 作为冻结教师进一步稳定旧技能预测。
- **端到端真实机器人验证**：从仿真 LIBERO 走向 xArm 真实部署，论证实用价值。
