## 摘要
视觉-语言-动作（VLA）模型通过将语言指令和二维视觉输入直接映射为动作，已成为机器人操作的一种强大的端到端范式。然而，这些模型缺乏显式的场景级三维表征，限制了其对空间布局和几何约束进行推理的能力。虽然近期研究尝试引入显式的三维线索（如深度图或点云）来增强几何感知能力，但这些方法主要捕获低层结构，缺乏三维空间中的高层语义锚定。在人类认知中，与物理世界的交互依赖于三维语义认知地图——一种将空间布局与语义上下文相融合的内部心理模型，从而支持持久且视角不变的推理。有鉴于此，我们提出了 VistaVLA，一种新颖的两阶段框架，它从三维高斯基元构建几何与语义感知的三维认知表征，并将其锚定为紧凑的上下文标记，用于 VLA 策略学习。具体而言，VistaVLA 将多视角视觉-语言特征提升至三维高斯基元中，形成几何锚定的语义标记，使视图一致的空间锚定与二维视觉特征空间对齐。为了使该三维表征在 VLA 控制中具有计算可行性，我们引入了合并-查询（Merge-then-Query, MtQ）标记汇总机制。MtQ 将密集的高斯基元压缩为一组高度紧凑的、空间信息丰富的标记，在保留与动作相关的三维布局和语义上下文的同时，实现了 99% 的标记压缩率。在仿真环境和真实环境中的大量评估验证了 VistaVLA 的有效性。值得注意的是，在真实场景中，VistaVLA 在七项真实任务上将成功率提升了 22.8%，并在具有挑战性的分布外任务上较 VLA-Adapter 基线提升了 30.0%。

## Abstract
Vision-Language-Action (VLA) models have emerged as a powerful end-to-end paradigm for robotic manipulation by mapping language instructions and 2D visual inputs directly to actions. However, these models lack an explicit, scene-level 3D representation, limiting their ability to reason over spatial layouts and geometric constraints. While recent efforts incorporate explicit 3D cues, such as depth maps or point clouds, to improve geometric awareness, they primarily capture low-level structures and lack high-level semantic grounding in 3D space. In human cognition, interaction with the physical world relies on a 3D semantic cognitive map - an internal mental model that integrates spatial layouts with semantic context to enable persistent, viewpoint-invariant reasoning. In light of this, we present VistaVLA, a novel two-stage framework that constructs a geometry- and semantics-aware 3D cognitive representation from 3D Gaussian primitives and grounds it as compact context tokens for VLA policy learning. Specifically, VistaVLA lifts multi-view vision-language features into 3D Gaussian primitives, forming geometry-anchored semantic tokens that align view-consistent spatial grounding with 2D visual feature spaces. To make this 3D representation computationally tractable for effective VLA control, we introduce Merge-then-Query (MtQ), a token summarization mechanism. MtQ compresses dense Gaussian primitives into a highly compact set of spatially informative tokens, achieving a 99% token reduction while preserving action-relevant 3D layouts and semantic context. Extensive evaluations in both simulated and real-world environments demonstrate the effectiveness of VistaVLA. Notably, in real-world scenarios, VistaVLA improves success rates by 22.8% across seven real-world tasks and by 30.0% over the VLA-Adapter baseline on challenging out-of-distribution tasks.

# VistaVLA 论文总结

## 一、核心问题与研究背景

- **核心痛点**：现有 Vision-Language-Action (VLA) 模型主要基于 2D 图像观测直接映射到动作，缺乏显式的场景级 3D 表征，难以对空间布局和几何约束进行有效推理，导致在精确操作、接触丰富的任务上容易失败。
- **现有改进方案的局限**：近期研究尝试引入深度图、点云、稀疏 3D 坐标等显式 3D 线索，但这些方法：
  - 主要捕获低层几何结构，缺乏高层、开放词汇的语义特征在 3D 空间中的锚定；
  - 表示形式与 2D 预训练视觉语言模型的 patch token 空间难以匹配；
  - 大多为观测中心（observation-centric）而非场景级（scene-level）表示，无法将多模态语义绑定到物理空间结构。
- **生物学动机**：人类物理交互依赖于"3D 语义认知地图"——将连续空间拓扑与功能语义融合的内部心理模型，支持持久、视角不变的推理。本文旨在将该机制引入 VLA 框架。

## 二、方法论

### 2.1 总体框架
VistaVLA 是一个**两阶段框架**：
- **Stage I**：从多视角图像构建**语义高斯场**（Semantic Gaussian Field），每个高斯基元附带可学习的语义特征向量，形成几何-语义联合的 3D 表征。
- **Stage II**：通过 **Merge-then-Query (MtQ)** 机制将密集高斯基元压缩为紧凑的 3D 上下文 token，输入下游 VLA 策略网络。

### 2.2 关键技术细节

#### Stage I：3D 高斯锚定的认知表征
- **紧凑教师特征空间构建**：使用 SigLIP2 + DINOv2-Large 作为基础视觉编码器，提取每帧稠密特征（2176 维）。通过轻量自编码器训练一次，将特征压缩到 128 维共享瓶颈潜码，作为后续高斯特征渲染的教师信号。
- **两阶段高斯特征渲染**：
  - 基于 DepthSplat 框架，每个高斯表示为 $g_i = (\mu_i, \Sigma_i, \alpha_i, c_i, z_i)$，其中 $z_i \in \mathbb{R}^{128}$ 为可学习的语义特征；
  - 第一阶段损失：$\mathcal{L}_{stage1} = \lambda_{rgb}\mathcal{L}_{rgb} + \lambda_{dep}\mathcal{L}_{dep}$，用于建立稳定几何；
  - 第二阶段损失：$\mathcal{L}_{stage2} = \lambda_{rgb}\mathcal{L}_{rgb} + \lambda_{dep}\mathcal{L}_{dep} + \lambda_{feat}\mathcal{L}_{feat}$，通过多视角教师特征监督将语义蒸馏到高斯基元；
  - 特征渲染遵循 3DGS 的 alpha-compositing 规则：
  
    $$\hat{F}_v(p) = \sum_{i \in N(p)} R_i(v, p) z_i, \quad R_i(v, p) = T_i^v(p)\alpha_i^v(p)$$

  - 因此每个 $z_i$ 都是多视角语义描述符，受其对应 3D 基元的几何与可见性约束。
- **训练-推理差异**：训练时使用两路标定 RGB-D 视图作为上下文，渲染第三视角作为新视角目标；推理时在线基于 RGB 观测和标定相机位姿构建，无须深度输入。

#### Stage II：MtQ 压缩与策略注入
- **问题**：高斯场包含 $N_0 \sim 10^5$ 个基元，直接送入 VLA 计算不可行。
- **MtQ 机制流程**：
  1. **参数自由压缩**：
     - 将稠密 GS token reshape 为逐视角网格，应用 stride-4 平均池化（特征和 3D 中心），粗略降至约 7K；
     - 使用 **Morton 编码**对中心点排序并交替划分为锚点集 A 与非锚点集 B；
     - 对每个非锚点 token，按语义相似度匹配最优锚点：
       
       $$a^*(u) = \arg\max_{a \in A} \frac{\langle z_u, z_a \rangle}{\|z_u\|\|z_a\|}$$
       
     - 仅合并相似度排名前 50% 的匹配（避免语义不一致合并），按聚合尺寸加权平均更新锚点；重复迭代直到 $N' < 1000$。
  2. **基于查询的总结**：将压缩后的 token $Z' \in \mathbb{R}^{B \times N' \times d}$ 投影为 K/V，使用 64 个可学习 query token 通过两层 Transformer Decoder 进行交叉注意力总结，再线性投影到 VLA backbone 的隐藏维度 $d_{llm}$，得到 $X_{gs} \in \mathbb{R}^{B \times N_q \times d_{llm}}$。
- **动作生成**：沿用 VLA-Adapter 因果序列建模，将 2D 视觉 token、语言 token、GS 总结 token 与动作查询 token 拼接为 $X = [X_{vis}, X_{lang}, X_{gs}, X_{act}]$，预测未来 K 个连续动作；推理时执行前 $K_{exec} = 4$ 个动作再重规划。

## 六、主要结论与发现

- **真实世界**：VistaVLA 平均成功率较基线提升 **22.8 个百分点**，在 7 个任务上均取得最佳或并列最佳结果。
- **空间鲁棒性**：
  - PlaceSponge 深度扰动：基线 6/10 → VistaVLA **9/10**；
  - OrganizeSponge 位置扰动：所有基线均 0/10 → VistaVLA **3/10**（唯一非零方法）。
- **仿真标准 LIBERO**：平均成功率 **96.05%**，在无大规模动作数据预训练的方法中排名第一。
- **仿真 OOD (LIBERO-Pro-Swap)**：从基线 1.7% 提升到 **12.2%**，较 UniVLA（5.0%）、OpenVLA-SF（0.9%）、Q-Depth VLA（0.35%）等更优。
- **核心发现**：
  1. 单纯加入更多 2D 视角或深度只能带来有限提升；
  2. 语义高斯场为 VLA 提供"几何+语义"双重锚定，是关键增益来源；
  3. MtQ 在 99% token 压缩下仍能保留动作相关 3D 信息，64 个 query 是最佳摘要维度。

## 七、优点

- **生物学启发明确**：借鉴人类"3D 语义认知地图"概念，将空间拓扑与开放词汇语义融合到统一表征。
- **表征兼具几何与语义**：每个高斯基元既受 RGB-D 几何约束监督，又受语言对齐特征蒸馏监督，避免"纯几何"或"纯语义"任一极端。
- **多视角一致性**：通过多视角渲染损失 $\mathcal{L}_{feat}$ 自然保证语义特征在 3D 中的一致性。
- **高效压缩**：MtQ 通过 Morton 编码空间分桶 + 语义相似度匹配合并 + 查询式总结，实现了 99% 压缩（$\sim 10^5 \to 64$ token）。
- **推理友好**：推理时不依赖深度输入或第三视角，仅基于实时 RGB + 标定位姿即可在线构建高斯场。
- **公平对比设计**：在相同有效训练预算下与多个基线（含大模型 π0.5、SmolVLA）比较，结论更具说服力。
- **全面消融**：消融实验分别验证了相机视角、压缩策略、查询数量的贡献，能定位关键设计点。

## 八、不足与局限

- **平台与场景限制**：仅在 Agile-Piper 桌面机械臂上测试，未涉及更大工作空间、动态遮挡、相机位姿不可靠、不同机器人形态等现实复杂条件。
- **依赖标定相机位姿**：Stage I 训练需要两路标定 RGB-D 视图 + 已知相机内外参；在线推理也依赖标定，这限制了向消费级或非受控场景的迁移。
- **特征教师固定**：使用的 SigLIP2 + DINOv2 特征并非面向操作任务设计，可能并未充分利用操作特有的 affordance 信息。
- **3DGS 训练成本**：尽管 MtQ 解决了下游消费成本，但 Stage I 的高斯场训练本身仍涉及每场景优化或多视图前馈重建，计算开销与离线准备时间未在论文中充分披露。
- **仿真深度有限**：仅在 LIBERO / LIBERO-Pro 上验证，未覆盖如 RLBench、ManiSkill2、RoboCasa 等更丰富的仿真基准。
- **样本规模偏小**：真实世界每任务 10 次试验，对统计显著性而言略显单薄，缺少置信区间或方差报告。
- **OOD 仍具挑战**：OrganizeSponge 位置扰动下 VistaVLA 也仅 3/10，说明在大范围空间分布外场景仍有显著改进空间。
- **缺乏人类对照或失败分析**：未深入分析失败案例（如哪些场景下语义特征未能锚定到正确物体），不便后续改进定位。
- **基线深度集成方式有限**：VLA-Adapter+Depth 仅沿用 SpatialVLA 的策略，可能未充分代表 3D 输入方法的最强性能。
