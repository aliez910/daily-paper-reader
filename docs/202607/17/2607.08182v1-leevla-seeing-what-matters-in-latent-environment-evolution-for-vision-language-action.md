## 摘要
视觉-语言-动作（VLA）模型旨在将多模态输入映射为机器人动作。然而，现有方法大多难以应对复杂动态场景，原因在于它们对所有视觉令牌一视同仁，并以人工选定的因素进行推理，缺乏强调任务关键证据的机制，同时忽略了潜在因素。为解决这一问题，我们提出了LEEVLA，一种在潜在环境演化中聚焦关键信息的VLA架构，能够显式地将模型引导至具有丰富信息的区域，同时保持潜在世界表征的结构化演化。为识别显著且与指令相关的区域，我们引入了漂移引导的动态优先级排序（DGDP），它将动态位置优先级排序（DPP）与语义漂移引导（SDG）相结合，以指导VLA智能体在训练过程中应关注何处。在此基础上，我们引入了结构化特征流生成（SFFG），通过原型到外围（P2P）预测建模这些被优先排序的特征在潜在空间中应如何演化，并提出互邻域对比（MC）损失以保持邻域间的拓扑一致性。DGDP与SFFG共同构成了一个任务感知的"何处-如何"训练框架。在VLA基准上的大量实验表明，LEEVLA持续优于以往方法，证实了显式的任务证据引导与结构化的潜在推理对于可扩展的VLA均至关重要。代码已开源：https://github.com/LyuQi127/LEEVLA。

## Abstract
Vision-language-action (VLA) models aim to map multimodal inputs to robot actions. However, most existing approaches struggle to cover complex dynamic scenarios due to treating all visual tokens uniformly and reasoning with human-selected factors, which lack mechanisms to emphasize task-critical evidence and ignore underlying factors. To address this issue, we propose LEEVLA, a VLA architecture for seeing what matters in Latent Environment Evolution that explicitly guides the model toward informative regions while preserving the structured evolution of latent world representations. To identify salient and instruction-relevant regions, we introduce drift-guided dynamic prioritization (DGDP), which combines dynamic position prioritization (DPP) with semantic drift guidance (SDG) to guide the VLA agent where to attend during training. On top of this, we introduce structured feature flow generation (SFFG), which models how these prioritized features should evolve in latent space via prototype-to-periphery (P2P) prediction, and a mutual-neighborhood contrastive (MC) loss to maintain topological consistency among neighborhoods. Together, DGDP and SFFG form a task-aware "where-how" training framework. Extensive experiments on VLA benchmarks show that LEEVLA consistently outperforms prior methods, confirming that explicit task-evidence guidance and structured latent reasoning are both crucial for scalable VLA. Our code is available at https://github.com/LyuQi127/LEEVLA.

# LEEVLA 论文详细总结

## 一、核心问题与研究动机

- **VLA 模型的任务定位**：视觉-语言-动作模型需要将多模态感知（图像、本体感知、语言指令）映射到机器人底层动作，是开放环境下"感知-推理-动作"闭环的关键路径。
- **现有方法的两大瓶颈**：
  - **均匀处理视觉 token**：现有 VLA 在训练中对所有 patch 一视同仁，导致静态背景和无关物体的梯度稀释，任务关键证据得不到充分优化。
  - **依赖人工选择的外部条件**：CoT-VLA、DreamVLA 等借助子目标图像、分割、深度等辅助模态进行显式推理，过度强调"已知因素"，但忽略了对最终策略同样关键的"未知因素"，且需要额外辅助模型、开销大、依赖上游任务进展。
- **核心洞察**：动作应在高维潜在空间中驱动环境状态演化；通用视觉骨干（如 DINOv2、SigLIP）已编码了语义、外观、几何等多模态信息，直接在潜空间推理可同时利用"已知"和"未知"任务因子，且避免像素级重建。

## 二、方法论

### 2.1 整体框架

- **整体思路**：提出一个任务感知的 "where–how" 训练框架：
  - **DGDP（Drift-guided Dynamic Prioritization）**：回答"往哪里看"
  - **SFFG（Structured Feature Flow Generation）**：回答"怎么演化"
- **关键特性**：DGDP 与 SFFG 仅在训练时使用，推理阶段不引入额外开销（token 流不变）。

### 2.2 漂移引导的动态优先级排序（DGDP）

- **动态位置优先级（Dynamic Position Prioritization, DPP）**：
  - 用相邻 T 步之间 patch 特征的余弦相似度变化度量"动态度"：
    $$\theta_i = 1 - \cos(v_{t,i}, v_{t+T,i})$$
  - 动态度越大的区域（与任务执行相关的物体、机械臂）获得更高权重。
- **语义漂移引导（Semantic Drift Guidance, SDG）**：
  - 计算每个 patch 与语言指令的指令相关分数：
    $$r_{t,i} = \max_{1 \le j \le M} \langle \tilde{x}_{t,i}, \tilde{c}_j \rangle$$
  - 定义并裁剪语义漂移：
    $$\Delta_i = \mathrm{clip}((r_{t+T,i} - r_{t,i})/\tau, -\delta, \delta)$$
  - 再归一化映射为漂移因子 $\omega_i = \exp(\tilde\Delta_i / \tau)$。
- **组合权重**：
  $$\beta_i = \sigma(\omega_i \cdot \theta_i)$$
  - 使模型同时关注"动态变化大"且"语义朝指令相关方向漂移"的 patch，抑制漂向背景语义或静态区域的 token。

### 2.3 结构化特征流生成（SFFG）

- **原型到外围（Prototype-to-Periphery, P2P）预测**：
  - 对多视角未来特征做联合聚类 $\mathcal{C} = \{c_\ell\}_{\ell=1}^L$，计算每个簇的质心 $\mu_\ell$。
  - 按"到质心的欧氏距离"在簇内排序（近→远），形成 prototype→periphery 序列。
  - 用带全局调制因子 $\alpha$ 的 P2P 损失监督预测：
    $$L_{P2P} = \frac{1}{|\mathcal{C}|}\sum_{\ell} \frac{1}{|\vec{c}_\ell|}\sum_{j\in \vec{c}_\ell} (\alpha + \beta_j)\,\varphi(\hat{v}_{t+T,j}, v_{t+T,j})$$
  - 保证同一语义单元的特征被连续预测，避免扁平序列顺序破坏潜在空间局部结构。
- **互邻域对比（Mutual-neighborhood Contrastive, MC）损失**：
  - 为每个锚点构建一阶 (Top-K=10) 和二阶 (Top-M=5) 邻居集，仅保留互为邻居的 token 作为正样本，过滤聚类噪声和不对称关联。
  - 采用 InfoNCE 形式：
    $$L_{MC} = -\frac{1}{|\mathcal{I}|}\sum_{i\in \mathcal{I}} \frac{1}{|\mathcal{G}_i^+|} \sum_{j\in \mathcal{G}_i^+} \log \frac{\exp(S_{ij}/\tau_c)}{\sum_{\ell \ne i} \exp(S_{i\ell}/\tau_c)}$$
- **总训练目标**：
  $$L_{total} = \lambda_1 L_{action} + \lambda_2 L_{P2P} + \lambda_3 L_{MC}$$
  - 其中 $L_{action}$ 为并行连续动作解码下的 L1 回归损失。

## 六、主要结论与发现

- **性能 SOTA**：
  - **LIBERO**：LEEVLA-mini（0.5B）平均 97.5%，LEEVLA-large（7B）平均 98.2%，均超越同规模最强基线（FLOWER 95.7%、π0.5 97.5%）。
  - **CALVIN ABC-D**：LEEVLA-large 平均长度 4.34，超越 OpenVLA-OFT（4.10）和 π0.5（4.02）。
  - **真实世界**：平均成功率 78.5%，相对 OpenVLA 提升约 38.5 个百分点。
- **组件互补**：消融表明 SFFG（+0.8%）与 DGDP（+1.5%）分别独立增益且叠加后达到 96.6%→97.0%，其中 DPP 单独贡献最大。
- **设计选择有效**：特征重排 +0.5%，引入全局 $\alpha$ 因子再 +1.2%，验证了"既要重点关注又不丢弃全局上下文"的必要性。
- **训练 vs 推理成本**：训练增加若干模态预测与对比损失，但推理与 OpenVLA-OFT 持平（15.639 GB / ~124 ms），证明该方法不引入推理时负担。

## 七、优点 / 亮点

- **问题切入精准**：明确指出"均匀视觉 token + 人工因素"两大痛点，并将解决方案归结为 where（看哪） + how（怎么演化）。
- **方法与训练目标解耦良好**：DGDP/SFFG 仅作用于训练，对推理无影响，部署友好。
- **结构化潜在空间推理**：P2P 排序 + 互邻域对比的组合有理论支撑（原型分析、对称性约束），并通过可视化验证语义连通性。
- **覆盖双尺度与双基准**：在 0.5B 和 7B 上同时验证，并与 LIBERO、CALVIN 及真实场景保持一致结论。
- **解释性工具齐备**：特征聚类、注意力热图、因果图辅助读者理解模型行为。
