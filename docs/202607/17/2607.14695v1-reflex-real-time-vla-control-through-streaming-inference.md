## 摘要
流匹配视觉-语言-动作（VLA）模型有望实现精确的连续控制，但其迭代去噪特性与实时机器人存在根本性的不兼容：全局时间步注入使 KV 缓存失效，迫使我们在缓慢的 $O(N^2)$ 重计算与数学上不正确的缓存复用之间二选一。我们提出 **Reflex**，一个通过利用**时间步不变性**——即感知编码器在功能上独立于去噪循环——来实现流匹配策略**实时流式推理**的框架。Reflex 将注意力上下文划分为静态、滑动和动态区域，在保持对固定输入产生全批量等效注意力输出的同时，实现 $O(1)$ 的增量缓存更新。为确保高频连续推理下的数值稳定性，我们引入 **AdaRMSNorm**，一种通过对流相位进行门控以防止 BFloat16 数值崩溃的自适应归一化层。此外，我们通过将视觉编码与动作生成解耦的**异步流水线**，结合降低内核开销的**算子融合**，进一步提升吞吐量。在 LIBERO 和 Kinetix 基准测试上，Reflex 实现了 2.58 倍的推理加速和 50Hz 的稳定流式输出，将反应延迟降低高达 54%，在不损失性能的前提下实现高效部署。

## Abstract
Flow matching Vision-Language-Action (VLA) models promise precise continuous control, but their iterative denoising nature introduces fundamental incompatibilities with real-time robotics: global timestep injection invalidates KV-caching, forcing a choice between slow $O(N^2)$ re-computation or mathematically incorrect cache reuse. We present \textbf{Reflex}, a framework that enables \textit{real-time streaming inference} for flow matching policies by exploiting the \textit{Timestep-Invariance Property} -- that perception encoders are functionally independent of the denoising loop. Reflex partitions the attention context into static, sliding, and dynamic regions, enabling $O(1)$ incremental cache updates while preserving full-batch-equivalent attention outputs for fixed inputs. To ensure stability under continuous high-frequency inference, we introduce \textit{AdaRMSNorm}, an adaptive normalization layer that prevents BFloat16 numerical collapse by gating on flow phase. We further maximize throughput through an \textit{async pipeline} that decouples visual encoding from action generation, combined with \textit{operator fusion} that reduces kernel overhead. On LIBERO and Kinetix benchmarks, Reflex achieves a 2.58$\times$ inference speedup and 50Hz stable streaming, reducing reaction latency by up to 54\% and enabling efficient deployment without performance degradation.

# Reflex：通过流式推理实现 VLA 模型实时控制 — 论文总结

## 1. 核心问题与研究背景

- **现实瓶颈**：机器人在动态场景中需要 **50–100Hz** 的控制频率，但当前主流的基于流匹配（Flow Matching）的视觉-语言-动作（VLA）模型（如 π0、π0.5）单次推理需 **100–200ms**，存在一个数量级的频率鸿沟。
- **缓存困境**：标准 Transformer 的 **KV-Cache** 在每次去噪步中因全局时间步 $t$ 的注入而失效——任何一层都会因 $t$ 变化而重新计算 KV，使得缓存复用成为**数学上不正确的近似**。
- **同步等待**：传统阻塞式推理要求"感知—规划—执行"串行化，使机器人对过时观测作出反应，导致抓取移动目标失败。
- **动作分块的副作用**：通过动作分块（action chunking）延长单次推理输出可缓解频率差，但越靠后的动作越陈旧（staleness），形成新的张力。
- **数值稳定性**：50Hz 长时运行下，BFloat16 推理因高频接触高方差初始噪声出现数值崩溃，标准 RMSNorm 难以无限时域运行。
- **设计目标（G1–G3）**：正确性（Partitioned Attention 与全批量注意力输出一致）、稳定性（无限时域混合精度不崩溃）、吞吐量（通过异步流水线隐藏视觉编码开销）。

## 2. 方法论

### 2.1 核心思想
利用 **Timestep-Invariance Property**（$\partial \text{Enc}/\partial t_k = 0$）：VLA 的感知编码器在功能上与去噪时间步 $t$ 无关，可独立缓存；而只有动态去噪状态需要每步重算。该性质将"加速单步推理"的思路转向"重构整个服务回路"。

### 2.2 关键技术

- **三区上下文划分（Partitioned Attention）**：
  - **Static Prefix** $\ell_{1:L}$：语言指令 token，永久缓存。
  - **Sliding History** $o_{t-N:t}$：FIFO 滑动窗口的视觉观测（默认 $N=10$ 帧，约 300ms）。
  - **Dynamic Suffix** $x^{(k)}$：流状态与时间步嵌入，每个去噪步重算。
  - 形式化（公式 1）：
    $$\text{Attn}(x^{(k)}) = \text{Softmax}\!\left(\frac{Q^{(k)}[K_{\text{pin}}; K_{\text{slide}}(t); K_{\text{dyn}}(k)]^{\top}}{\sqrt{d}}\right)[V_{\text{pin}}; V_{\text{slide}}(t); V_{\text{dyn}}(k)]$$
  - 在固定观测窗口与固定输入下，输出**严格等价**于全批量注意力（MSE = 0），证明见附录 A.1。

- **Incremental Prefill**：仅编码最新帧而非整段历史。

- **Manual Cache Merging**：进入去噪循环前将 prefix + history 合并到连续内存，避免 `torch.cat` 碎片化。

- **AdaRMSNorm（公式 2）**：
  - $\text{AdaRMSNorm}(x, c) = \frac{x}{\text{RMS}(x)} \odot \gamma(c)$，其中 $\gamma(c) = 1 + \text{MLP}(c)$，$c = [t_k, s_t]$。
  - RMS 统计量强制 **FP32** 计算，门控 MLP 使用 **BFloat16**。
  - 通过探测 $o_{\text{proj}}$ 层实现 **Robust Dtype Inference**，防止类型不匹配。

- **异步流水线（Future-Conditional Overlap Scheduling）**：
  - **Thread A（Vision）**：10–30Hz 编码图像、推送 KV。
  - **Thread B（Policy）**：50Hz 消费最新 KV 生成动作分块。
  - **Future-State Predictor**：用上一周期指令 $a^{\text{cmd}}_t$ 近似未来状态 $\hat{s}_{t+\Delta}$（公式 3），用 Adaptive Overlap Scheduling 动态调整前瞻量 $K = \lceil \bar{\tau}_{\text{inf}} / \tau_{\text{step}} \rceil$。

- **系统级优化**：
  - **Operator Fusion**：合并 $W_Q/W_K/W_V$（WQKV）以及 SwiGLU 的 Gate+Up，kernel 启动数减半，单流推理提速 15–20%。
  - **Ring Buffer Architecture**：预分配 $B \in \mathbb{R}^{L \times N_{\max} \times H \times D}$，通过指针运算实现 O(1) 内存访问、零动态分配。
  - **FlashNorm + FusedAdaLN**：分别减少 2.7ms 和 1.5ms 的 action expert 延迟。

## 8. 不足与局限

- **架构适用性**：依赖感知编码器对时间步不变这一前提；**统一 DiT 风格 VLA**（时间步注入视觉编码器）不在适用范围内。
