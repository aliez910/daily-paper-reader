## 摘要
世界动作模型（WAMs）通过将基于视频的世界建模作为机器人动作学习的密集监督，为视觉-语言-动作（VLA）策略提供了一种有前景的替代方案。现有的WAMs在物理可执行性方面表现出色，但通常缺乏基于VLM的VLA中所具备的用于分解粗粒度指令的显式语言级规划接口。当家务任务涉及复杂的多步骤目标时，这种分解变得尤为重要，因为此时需要将粗粒度的用户指令转换为一系列细粒度的可执行子任务。与此同时，由于现有系统在数据、机器人本体和任务协议方面往往存在差异，该领域仍然缺乏VLA与WAM执行能力之间的公平真实机器人比较。为了同时解决分解缺口以及开展受控WAM-VLA比较的需求，我们提出了DSWAM，一个用于细粒度机器人操作的双系统世界动作基础模型。DSWAM将一个System 1 WAM执行器作为默认的控制路径，并仅在任务分解有用时可选地激活一个System 2视觉-语言子任务规划器。规划器根据短期视觉历史和全局任务提示预测可执行的子任务，而WAM执行器则针对每个指令或子任务执行具备世界感知能力的动作生成。执行器通过动作预测和视频协同训练进行训练，但推理时直接预测动作块而无需显式生成未来视频。为了使该执行路径在实际机器人上具有实用性，我们进一步集成了TensorRT加速、异步执行和实时分块（RTC），以确保策略查询不会阻塞机器人控制。为了与VLA策略进行公平的真实机器人比较，我们在DeMaVLA真实世界可形变操作设定下构建并评估了DSWAM，在机器人平台、预训练数据、后训练数据和评估标准方面保持一致。

## Abstract
World Action Models (WAMs) provide a promising alternative to Vision-Language-Action (VLA) policies by using video-based world modeling as dense supervision for robot action learning. Existing WAMs excel at physically grounded execution, but typically lack the explicit language-level planning interface in VLM-based VLAs for decomposing coarse instructions. Such decomposition becomes important when household tasks involve complex multi-step goals, where coarse user commands need to be converted into sequences of fine-grained executable subtasks. Meanwhile, the field still lacks a fair real-robot comparison between VLA and WAM execution capabilities, since existing systems often differ in data, robot embodiments, and task protocols. To address both the decomposition gap and the need for a controlled WAM-VLA comparison, we introduce DSWAM, a Dual-System World Action Foundation Model for fine-grained robot manipulation. DSWAM keeps a System 1 WAM executor as the default control path and optionally activates a System 2 vision-language subtask planner only when task decomposition is useful. The planner predicts executable subtasks from short-term visual history and a global task prompt, while the WAM executor performs world-aware action generation for each instruction or subtask. The executor is trained with action prediction and video co-training, but inference directly predicts action chunks without explicit future video generation. To make this execution path practical on real robots, we further integrate TensorRT acceleration, asynchronous execution, and real-time chunking (RTC) so that policy queries do not block robot control. To provide a fair real-robot comparison with VLA policies, we build and evaluate DSWAM under the DeMaVLA real-world deformable manipulation setting with matched robot platform, pretraining data, post-training data, and evaluation criteria.

## 1. 核心问题与研究动机

- **WAM 与 VLA 的能力缺口**：现有的世界动作模型（WAMs）通过基于视频的世界建模为机器人动作学习提供密集监督，在接触丰富、形变物体的物理执行上表现优异。但它们通常缺少 VLM-式 VLA 所具备的显式语言级规划接口，难以将粗粒度用户指令（如"整理桌上的物品"）拆解为有序的细粒度可执行子任务。
- **复杂多步任务的可分解性需求**：在家庭场景中，粗指令往往需要"搜索—接近—调整—执行"等多步子任务分解，单纯依靠 WAM 的执行能力不足以完成高层语义组织。
- **缺乏公平的 WAM-VLA 对比**：现有真实机器人对比常常因机器人本体、训练数据、任务协议和评估标准的不同而难以归因，无法判断差异究竟源自策略设计还是实验设置。
- **部署效率问题**：视频预测的 WAM 推理延迟较高，难以保证闭环低延迟控制，进一步限制其在真实机器人上的实用性。

## 2. 方法论

### 2.1 总体框架：双系统设计

- **System 1（默认路径）**：基于视频模型的 WAM 执行器，输入为多视角 RGB、当前语言条件及本体感知，输出动作块。
- **System 2（可选路径）**：视觉-语言子任务规划器，仅在粗指令需要分解时被激活，将高层指令转换为有序子任务后传给 System 1。
- 设计原则：原子化任务或 WAM 自身能可靠完成的任务直接走 System 1，避免冗余规划开销。

### 2.2 System 2 视觉-语言子任务规划器

- 基于 Rynnbrain4B-风格 VLM，以 1 Hz 采样最近 $T=5$ 帧的视觉历史 $X_t = \{x_{t-4},...,x_t\}$ 与全局任务提示 $p$，预测下一个子任务级指令 $s_t = P_\phi(X_t, p)$。
- **过渡感知监督（transition-aware supervision）**：将机器人轨迹视频切分为子任务区间 $\{\{s_k,\tau_k\}\}$，对滑动窗口 $W_i$ 设计标签
  $$y_i = \begin{cases} s_k, & W_i \text{ 位于子任务 } k \text{ 内部} \\ s_{k+1}, & W_i \text{ 为非终止子任务最后窗口} \\ \text{done}, & W_i \text{ 为终止子任务最后窗口} \end{cases}$$
  使规划器既能识别当前子任务，也能在边界处发出下一步指令。
- 训练目标为自回归语言建模损失 $L_{\text{plan}}(\phi) = -E[\log P_\phi(y_t|X_t,p)]$。
- 部署时每 $\Delta t = 2\text{s}$ 向 System 1 同步 5 帧，返回的子任务在两次更新之间作为 System 1 的语言条件。

### 2.3 System 1 WAM 执行器

- **编码与推理**：将多视角图像、语言 $\ell_t$、本体感知 $q_t$ 编码为潜在世界特征 $z_t = f_\theta(I_{1:3}^t, \ell_t, q_t)$，从中预测动作块 $A_t = [a_t,...,a_{t+H-1}]$，推理时仅做一次前向传播，**不显式采样、去噪或解码未来视频**。
- **训练：流匹配 + 视频协同训练**：对动作块 $A_t$ 与未来潜在视觉 token $V_{t+1:t+T}$ 共享流匹配公式 $y^\tau = (1-\tau)y + \tau\epsilon$，速度场损失为
  $$L_{\text{FM}}(y) = E[\|v_\theta(y^\tau, \tau, O_t) - (\epsilon - y)\|_2^2]$$
  总目标为 $L = L_{\text{act}} + \lambda_{\text{vid}} L_{\text{vid}}$。注意动作 token 在训练时不使用未来视觉 token，避免特权信息泄漏。
- **动作专家**：以条件流匹配建模双机械臂连续控制信号，适合多模动作分布与平滑轨迹生成。

### 2.4 部署优化

- **实时分块（RTC）+ 异步执行**：策略 worker 持续预测新块而控制器在另一线程执行当前块，使策略延迟不阻塞底层控制。
- **TensorRT 加速（BF16）**：将重计算拆为两个引擎——视觉上下文引擎（构建每层 cache）与动作去噪引擎（消费 cache 与动作潜变量进行单步去噪更新），保留对外预/后处理接口。
- **效果**：在 RTX 5090（CUDA 12.9 + TensorRT 10.16.1）上，预热后的端到端策略推理延迟由 PyTorch 的 198.2 ms 降至 TensorRT BF16 的 73.8 ms（2.69× 加速），最大相对误差 0.0106，余弦相似度 0.99977，与 PyTorch 参考保持高度一致。

## 6. 主要结论与发现

- **真实折叠**：在 DeMaVLA 匹配协议下，DSWAM 平均 SR 由 92.5% 升至 96.3%，平均完成时间由 2′18″ 缩短至 1′44″；相对 π0，SR 提高 20 个百分点，时间缩短 42 秒。证明 WAM-式策略执行在受控可形变操作对比中可优于强 VLA 参考。

- **System 2 价值**：分拣任务中子任务级监督显著提升稳定性与精度，SR 由均值 75.7% 提升至 100%，平均每回合错误由 3.53 降至 0.65。

## 7. 优点与亮点

- **架构创新**：将高层语义规划与底层世界感知执行解耦，使 System 1 保持纯执行器属性，仅在需要时调用 System 2，避免冗余规划开销。
- **过渡感知监督**：在子任务边界附近显式监督下一步指令与 "done" 信号，使规划器具备子任务切换能力，而不仅是当前子任务分类器。
- **视频监督与无视频推理的桥接**：训练阶段利用未来视觉 token 提供世界建模信号，推理阶段跳过显式视频生成，保留 WAM 表征优势同时消除延迟负担。
- **公平对比范式**：在 DeMaVLA 匹配协议下、关闭 System 2 进行 WAM-only 评估，给出可信的策略执行能力对比，避免"数据/平台/协议"混杂。
- **工程闭环完整**：RTC、异步执行、TensorRT 双引擎切分兼顾端到端延迟与服务接口稳定性，并提供与 PyTorch 参考的一致性度量。
- **可选的 System 2 设计哲学**：强调"按需规划"，避免对原子化任务过度工程化，对真实家庭场景中的混合任务粒度具有适配性。
