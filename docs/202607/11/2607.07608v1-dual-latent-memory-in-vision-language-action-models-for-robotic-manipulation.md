## 摘要
主流的视觉-语言-动作（VLA）模型在马尔可夫假设下主要根据当前观测预测动作，因而难以处理长时序、强时间依赖的任务。现有的记忆增强型 VLA 模型要么扩大观测窗口，要么从记忆库中检索历史信息作为策略侧的辅助上下文。然而，它们将记忆置于 VLA 推理的原生潜在嵌入空间之外，导致历史经验无法与多模态推理及动作生成过程进行流畅的融合。为此，我们提出了 LaMem-VLA，一种潜在记忆原生框架，将历史经验重构为潜在记忆令牌，并将其与 VLA 推理直接交织在一起。其核心包含四个协同组件：（i）策展器，负责将历史经验组织为互补的短期与长期两个记忆库；（ii）检索器，利用多模态认知查询两个记忆库，以检索与上下文相关的证据；（iii）凝练器，将检索到的证据重构为紧凑的短期与长期潜在记忆令牌；（iv）编织器，将这些记忆令牌与当前观测及指令一同注入到连续的嵌入序列中。通过在同一个连续潜在空间中完成历史经验的表示、检索与消费，LaMem-VLA 使记忆能够直接参与 VLA 推理，并在有界上下文条件下引导动作生成。在 SimplerEnv 和 LIBERO 上的大量实验验证了 LaMem-VLA 的优越性。

## Abstract
Mainstream Vision-Language-Action (VLA) models predict actions primarily from the current observation under a Markovian assumption, thus struggling with long-horizon, temporally dependent tasks. Existing memory-augmented VLAs either expand the observation window or retrieve history from the memory bank as auxiliary policy-side context. However, they leave memory outside the native latent embedding space of VLA reasoning, preventing historical experience from being fluidly interleaved with multimodal reasoning and action formation. To this end, we introduce LaMem-VLA, a latent-memory-native framework that reconstructs historical experience into latent memory tokens and directly interweaves them with VLA reasoning. At its core, LaMem-VLA introduces four coordinated components: (i) a curator that organizes historical experience into two complementary short-term and long-term memory vaults; (ii) a seeker that queries both vaults using the multimodal cognition to retrieve context-relevant evidence; (iii) a condenser that reconstructs the retrieved evidence into compact short-term and long-term latent memory tokens; and (iv) a weaver that injects these memory tokens with the current observation and instruction into one continuous embedding sequence. By representing, retrieving, and consuming historical experience entirely in the same continuous latent space, LaMem-VLA enables memory to directly participate in VLA reasoning and guide action generation under a bounded context. Extensive experiments on SimplerEnv and LIBERO demonstrate the superiority of our LaMem-VLA.

# LaMem-VLA 论文总结

## 1. 核心问题与研究动机

- **核心问题**：主流视觉-语言-动作（VLA）模型在推理时主要依赖当前单帧观测，隐含**马尔可夫假设**，无法访问历史状态变迁、已完成子任务步骤以及任务当前所处阶段等时序信息。这一局限被作者概括为 **"temporal short-horizon bias"（时序短视偏差）**，使得现有 VLA 模型在长视野、强时序依赖的操作任务中表现欠佳。
- **现有方案的不足**：当前对 VLA 引入记忆的两类主流做法均存在根本性缺陷：
  - **时序上下文扩展**：拼接历史帧或将输入拉长为视频序列，虽能暴露近期状态变化，但计算/显存成本随上下文长度线性增长，且固定时窗构成"记忆天花板"，窗外任务相关证据直接被丢弃。
  - **外部记忆条件化**：从外部记忆库中检索过去轨迹或历史 token 作为策略侧辅助上下文，但这些记忆存放在模型原生 token 空间之外，消费时仅作为推理完成后的策略端条件注入，无法与多模态推理/动作形成过程有机融合。
- **论文主张的核心问题**：历史经验能否被表示为**"上下文原生"**的机器记忆，与 VLA 模型的感知、推理、动作生成共享同一连续潜在空间？

## 2. 方法论

- **整体思路**：将机器人历史经验重构为**潜在记忆 token**，并在 VLA 嵌入空间内完成存储、检索、消费的全闭环，使记忆能参与自注意力推理而非仅作外部条件。历史被划分为**短期（视觉主导）**与**长期（语义/动作连续性主导）**两个互补记忆库，二者最终都以相同形式的潜在 token 接入模型。
- **总体架构（公式 (2)、(9)）**：每一步将当前视觉 token $X_t$、指令 token $\mathcal{I}$、可学习动作查询 $Q_{\text{action}}$ 与凝练后的短期/长期记忆 token $M^{\text{short}}、M^{\text{long}}$ 拼接为：
  $$S_t = [M^{\text{short}}; M^{\text{long}}; X_t; \mathcal{I}; Q_{\text{action}}]$$
  自此动作 token 在与图像、指令、记忆共处同一个嵌入空间中被解析，再交给扩散式动作专家生成 7-DoF 动作块（动作维度：3 平移 + 3 旋转 + 1 夹爪）。
- **四大模块**：
  - **潜在记忆策展人（Curator, §3.3）**：
    - 短期视觉金库 $\mathcal{M}^{\text{short}}$：通过 SE-bottleneck 压缩模块 $C_s$ 将当前视觉 token $X_t$ 蒸馏为 $v_s$，并取均值池化作检索键 $k_s$，单位为 $(k_s, v_s)$。
    - 长期语义金库 $\mathcal{M}^{\text{long}}$：直接将每步 VLA 主干输出的动作隐藏状态 $H_{\text{action}}$ 写入，不维护键值索引。
    - 超容量压缩（公式 (4)–(5)）：当金库超过容量 $L$ 时，对相邻键做余弦相似度选最冗余对，做键/值的均值合并以保留共享证据。
  - **潜在记忆检索者（Seeker, §3.4）**：
    - 由视觉/指令 token 经 VLA 主干得到上下文感知查询 $Q^{\text{con}}_t$，再拼接可学习槽 $Q^{\text{init}}$ 进入轻量 transformer 块 $B$（带掩码注意力，避免扰动主表征）更新得到共享查询 $Q_t$。
    - 检索采用 $q_t = \text{MeanPool}(Q_t)$，对两金库分别做 Top-K 余弦相似度检索，公式 (7)：$I^s = \text{Top-K}\{\cos(q_t, k^s_i)\}$，得到 $Z^{\text{short}}、Z^{\text{long}}$。Top-K 离散操作不可微。
  - **潜在记忆凝练器（Condenser, §3.4）**：
    - 引入可学习的短期槽 $T_s$ 与长期槽 $T_l$，以 $Q_t$ 引导并经 transformer 式"记忆成形器"$F_v、F_c$ 更新，得到固定长度的潜在记忆 token：
      $$M^{\text{short}} = F_v([Q_t; Z^{\text{short}}; T_s])[-L_s:], \quad M^{\text{long}} = F_c([Q_t; Z^{\text{long}}; T_l])[-L_l:]$$
    - 这一"检索大小可变化 / 消费大小固定"的设计解耦了存储与消费，避免上下文随检索数量膨胀。
  - **潜在记忆编织者（Weaver, §3.5）**：在动作查询被解析**之前**将两种记忆 token 与当前观测、指令、可学习动作查询一并送入自注意力；为两种来源分别加上可学习的源嵌入 $b_s、b_l$，得到 $S_t = [M^{\text{short}}+\mathbf{1}b_s^\top; M^{\text{long}}+\mathbf{1}b_l^\top; X_t; \mathcal{I}; Q_{\text{action}}]$，最终在自注意力阶段得到 $Z_{\text{action}}$。
- **动作专家**：基于扩散策略 [8]（DDIM 采样），对动作块加噪后用 MSE 损失训练噪声预测器：
  $$\mathcal{L}_{\text{action}} = \mathbb{E}_{n,\epsilon}\|\epsilon - \epsilon_\theta(\tilde{a}^{n}_{t:t+H-1}, n, Z_{\text{action}})\|_2^2$$

## 6. 主要结论与发现

- 在 SimplerEnv-Bridge 上达到 **73.9%** 平均成功率，较 CogACT 提升 16.6 点，超过 π0（+4.7）、MemoryVLA（71.9%）等强基线；在 LIBERO 五个套件上达到 **97.6%** 平均成功率，较 CogACT 提升 4.4、超过 MemoryVLA 1.1，在 Long-10 / Long-90 上较 MemoryVLA 进一步提升 2.4 与 1.4 点。
- 双尺度（视觉 + 语义）记忆与潜在原生融合均带来独立增益：去掉任一金库或任一融合路径都会明显退化（表 3、4）。
- 检索预算与凝练 token 数量存在明显"先增后降"效应，过多反而引入冗余证据、加重压缩负担（表 5、图 3），$(L_s, L_l)=(8,4)$ 与 $K=8$ 是兼顾性能与效率的默认配置。
- 文中强调：模型模拟以外的实验"是当前版本的局限"，团队正在将 LaMem-VLA 扩展到真实机器人平台，后续版本将补充真实世界结果。

## 7. 优点

- **范式革新**：明确提出"上下文原生潜在记忆"这一概念，把历史信息从"辅助上下文"提升为与感知、指令共享 embedding 的推理伙伴，相比 MemoryVLA 等"策略侧条件"路线更具一致性。
- **双尺度分工**：短期视觉记忆与长期语义记忆从来源和功能上互补，且都以统一 token 形式注入自注意力，体现了"表示形式一致、信息来源互补"的精巧设计。
- **有界上下文**：通过凝练器把可变大小的检索结果压缩为固定长度 token，避免上下文随检索长度增长而膨胀，兼顾时序感知与推理成本。
- **检索者设计**：用上下文感知查询 $Q_t$（基于多模态认知状态）而非单一当前观测特征做检索，缓解了在视觉迷惑场景下检索不可靠的问题。
- **实验闭环完整**：从主结果、消融、检索预算到凝练 token 数均有覆盖，特别是给出了"潜在原生 vs 策略侧 vs 原始检索"这一关键对比，对所提方法的核心贡献提供了直接验证。

## 8. 不足与局限

- **缺乏真实世界验证**：作者明确指出当前仅做了仿真实验，真实机器人部署仍是开放问题；这在当前的 VLA 论文中属于一个明显短板，可能限制其在真实系统中对扰动、光照、物体动力学差异等敏感性问题的可信度。
- **数据集/对比公平性**：不同基线所用训练数据与协议并不完全统一；特别是 SimplerEnv-Bridge 的对比中部分方法训练数据未公开，再现性与公平比较可能受影响。
