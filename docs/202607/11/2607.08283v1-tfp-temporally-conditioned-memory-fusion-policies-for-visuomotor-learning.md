## 摘要
视觉-语言-动作（VLA）策略（如 π₀.₅ 和 OpenVLA）在许多操作任务上表现良好，但它们通常是反应式的：基于当前观测、指令和本体感知状态预测下一步动作。这一假设在阶段依赖型操作中会失效，因为视觉上相似的状态可能由于潜在任务进度和先前交互结果的不同而需要不同的动作。我们认为，这类任务不仅需要记忆，还需要具备动力学感知的信念更新：策略应在稳定或遮挡阶段保持任务进度，并在接触、释放或子目标过渡等节点修正其信念。我们提出了时间条件化记忆融合策略（TFP），一种面向 VLA 主干网络的轻量级记忆-动作框架。TFP 通过液态时间常数动力学维护一个回合局部任务进度信念，并通过自适应调制将其直接注入到流匹配动作解码器中。这使得时间累积的上下文能够影响生成的动作块，而非仅作为被动历史上下文使用。在 33 亿参数规模下，TFP 将 LIBERO 上的平均成功率从 96.9% 提升至 98.75%，将 LIBERO-plus 上的平均成功率从 91.4% 提升至 93.77%。在聚焦记忆能力的 MIKASA ShellGameTouch 诊断任务上，TFP 的成功率最高可达 75.0%。机理分析表明，操作事件附近的写入增益变化约为远离事件的非事件阶段的 6 倍；隐状态干预实验显示，信念对生成的动作块具有因果调制作用。上述结果表明，紧凑且事件敏感的记忆动力学能够提升 VLA 策略在遮挡、视觉扰动以及阶段依赖型任务结构下的表现。

## Abstract
Vision--Language--Action (VLA) policies such as $π_{0.5}$ and OpenVLA perform well on many manipulation tasks, but they are often reactive: the next action is predicted from the current observation, instruction, and proprioceptive state. This assumption breaks down in stage-dependent manipulation, where visually similar states may require different actions depending on latent task progress and previous interaction outcomes. We argue that such tasks require not only memory, but dynamics-aware belief updates: the policy should preserve task progress during stable or occluded phases and revise its belief near contact, release, or subgoal transitions. We introduce Temporally Conditioned Memory-Fusion Policies (TFP), a lightweight memory-action framework for VLA backbones. TFP maintains an episode-local task-progress belief with Liquid Time-Constant dynamics and injects the updated belief directly into the flow-matching action decoder through adaptive modulation. This lets temporally accumulated context shape the generated action chunk, rather than serving only as passive history context. With a 3.3B-parameter model, TFP improves the average success rate from \(96.9\%\) to \(98.75\%\) on LIBERO and from \(91.4\%\) to \(93.77\%\) on LIBERO-plus. On the memory-focused MIKASA ShellGameTouch diagnostic, TFP achieves success up to \(75.0\%\). Mechanistic analyses show that write-gain changes near manipulation events are about \(6\times\) larger than far non-event phases, and hidden-state interventions show that the belief causally modulates generated action chunks. These results suggest that compact, event-sensitive memory dynamics can improve VLA policies under occlusion, visual perturbation, and stage-dependent task structure.

# TFP 论文总结

## 1. 核心问题与研究动机

- **问题定位**：现有主流 VLA 策略（如 π₀.₅、OpenVLA、Octo）多采用"反应式"决策范式——仅基于当前视觉观测、语言指令和本体感知状态预测下一步动作，**不显式维护任务进度记忆**。
- **失效场景**：在**阶段依赖型操作（stage-dependent manipulation）**中，视觉上相似的状态可能对应完全不同的子任务进度（如"交换物体"任务中相似画面可能对应搬第一个物体、搬第二个物体或终止），仅靠当前观测无法消歧。
- **核心论点**：任务不仅需要"记忆"，更需要**动力学感知的信念更新（dynamics-aware belief update）**——
  - 在**稳定/遮挡阶段**：应保留任务进度信息；
  - 在**接触、释放、子目标过渡等事件节点**：应快速吸收新证据。
- **关键空白**：现有记忆增强方法（HAMLET、MemoryVLA 等基于历史检索；AVA-VLA、ReMem-VLA 等基于循环潜状态）多以**帧/策略步**为索引更新记忆，未将**物理时间**作为显式条件，难以匹配分块控制中不规则查询间隔的实际动力学。

## 2. 方法论

### 2.1 核心思想
TFP 在 VLA 主干上外挂一个**回合局部潜信念状态** h_t，使用**液态时间常数（LTC）网络**进行连续时间更新，再通过 **AdaLN 风格自适应调制**直接注入到流匹配动作解码器，使记忆成为动作生成的因果条件。

### 2.2 关键技术细节

- **观测编码**：视觉 token V_t 经 ϕ_vision 池化/投影，与本体状态 s_t 嵌入拼成紧凑表征 x_t = [ϕ_vision(V_t); ϕ_state(s_t)]。
- **LTC 信念更新**（公式 2–4）：
  - 候选信念：ĥ_t = tanh(W_h[x_t; h_{t-1}] + b_h)
  - 输入相关时间常数：τ_t = softplus(W_τ[x_t; h_{t-1}] + b_τ) + ε
  - 保留门：k_t = exp(−Δt_t / τ_t)  （Δt_t 为距上次查询的物理时间）
  - 更新规则：h_t = k_t ⊙ h_{t-1} + (1 − k_t) ⊙ ĥ_t
  - 等价于：h_t − h_{t-1} = g_t ⊙ (ĥ_t − h_{t-1})，其中 g_t = 1 − k_t 为写入增益。
- **逐通道多时间尺度**：τ_t 为向量，不同潜通道可具有不同有效时间尺度，部分通道高保留（慢任务上下文），部分通道快速更新（局部感知证据）。
- **信念条件化动作生成**（公式 6–9）：
  - m_t = W_m h_t + b_m ∈ R^{d_c}
  - 流匹配时间步嵌入：e_τ = PE(τ)，z_τ = W₂σ(W₁e_τ + b₁) + b₂
  - 融合：c_t = z_τ + m_t，x̂^(ℓ) = AdaLN(x^(ℓ), c_t)
  - 速度场：v_θ(a_τ, τ | I_t, s_t, ℓ, h_t)
- **Episode-Aware Temporal Batching（EATB）训练**（公式 10–11）：每回合独立维护 h^(e)_t，仅在回合边界重置；每次采样 B 个回合各展开 K 个连续 chunk；参数更新后用 stopgrad 将末端 h 写回，保证跨段前向记忆连续性，避免全回合反传播的内存开销。
- **自适应滚动视域执行**：策略始终预测长度 H 的动作块，但执行器根据抓取过渡、抖动、与上一步连续性等风险指标 R_{t,r} 动态截取前缀 E_t ∈ [E_min, H]，使 Δt_{t+1} = E_t · δ_t^ctrl 反映真实物理时间。

### 2.3 与其他时间模型的对比（论文明确讨论）
- **GRU**：保留门由步数索引，相同观测在物理间隔不同时产生相同门，无法保证 Δt 一致性；
- **固定衰减**：τ₀ 不可调，是 LTC 的特例；
- **SSM/S4D**：可实现 Δt 相关转移，但 TFP 使用非线性、输入相关、且直接条件化动作解码器的 LTC。

## 3. 实验设计

### 3.1 基准与场景
- **LIBERO**（Spatial / Object / Goal / Long-10）：在线 rollout 通用操作质量；
- **LIBERO-plus**：在噪声、光照、背景扰动下的零样本鲁棒性；
- **MIKASA-Robo ShellGameTouch**：遮挡下隐藏位置推断的**记忆诊断任务**；
- **真实机器人**：Galaxea A1 单臂 + 平行夹爪 + 腕部鱼眼相机 + 静态 RealSense D435，两个任务——**物体交换**与**计数取放**（各 20 次试验）。

### 3.2 对比方法
- **反应式基线**：π₀.₅（3.3B）、π₀（3.3B）、OpenVLA（7B）、OpenVLA-OFT（7.3B）；
- **记忆/历史增强基线**：HAMLET（3B）、AVA-VLA（7.3B）、MemoryVLA（7.3B）；
- **同主干受控消融**（相同数据、动作视域、优化器、rollout 协议、自适应执行器）：
  - π₀.₅ + GRU
  - π₀.₅ + SSM（S4D）
  - TFP w/o Δt（用常数步长替代实测 Δt）
  - TFP（完整版本）

### 3.3 主要结果
- **LIBERO 平均**：96.85% → 98.75%；Long-10 提升最显著（92.4% → 97.0%）；
- **LIBERO-plus 平均**：91.4% → 93.77%；噪声 85.2% → 88.5%，光照 93.9% → 96.1%；
- **MIKASA ShellGameTouch**：75.0%，明显高于 OpenVLA-OFT 的 47% 报告值（MemoryVLA 报告 88%，作者将其视为诊断而非 SOTA 比较）；
- **真实 A1**：物体交换 3/20 → 15/20；计数取放 8/20 → 18/20；失败模式从"阶段错乱/重复子任务"转向"目标落地/低级执行"。

### 3.4 机理分析
- **事件敏感写入增益**：在 LIBERO "mug-in-microwave" 上，事件 ±6 查询内的写入增益变化幅度为远离事件基线的约 **5.9–6.24 倍**，最佳对齐存在约 −1.6 到 −2.1 步的轻微滞后；
- **同观测干预**：固定观测/指令/状态，仅替换 h_t，10 步动作块的平均成对 L2 距离 0.0442（最大 0.1303），而相邻时间步 h 的距离中位数仅 0.0108——证明 h 是动作的因果条件。

## 6. 主要结论与发现

- **TFP 在 3.3B 参数规模下**在 LIBERO、LIBERO-plus、真实机器人三处一致优于反应式 π₀.₅，且不牺牲通用任务能力；
- 增益**主要来自"连续时间 LTC 记忆 + 物理时间条件 + AdaLN 动作调制"三者协同**，而非单纯"加了循环"——GRU/S4D 同条件均不如 TFP，移除 Δt 后明显回落；
- **写入增益呈现事件敏感**行为：操作事件附近是远端非事件阶段的约 6 倍，且存在轻微预测性滞后（−1.6 ~ −2.1 步），暗示信念提前于事件标签进行修正；
- **记忆直接因果调制动作**：在固定观测/指令下，替换 h_t 即可显著改变动作块与末端轨迹；
- **失败模式分析**：TFP 真正消解的是"阶段错乱"类记忆错误，而非低级操作问题。

## 7. 优点与亮点

- **理论支撑扎实**：附录 C 用 ODE 闭式解证明 LTC 更新是连续时间一阶信念松弛的精确离散化；并用 Cauchy 方程证明指数保留是满足"Δt 合成一致性"的唯一连续解，为设计选择提供非平凡的理论基础；
- **架构简洁高效**：LTC + AdaLN 注入，接口固定、无需新增注意力通路，便于集成到现有流匹配 VLA；
- **EATB 训练策略**：在保留回合级记忆连续性的同时，避免全回合反传播的显存爆炸，工程可落地；
- **机理分析深入**：写入增益统计、滞后对齐、隐藏状态干预三类证据相互印证，而非仅靠性能数字；
- **公平消融设计**：在相同数据/视域/优化器/执行器下系统比较 GRU、S4D、消 Δt、完整版，结论可重复；
- **代码开源**：提供 GitHub 链接，便于复现。

## 8. 不足与局限

- **训练成本高昂**：H200 × 4、>100 GB 显存、80 小时仅完成 LIBERO 完整训练，研究门槛较高；
- **真实实验范围有限**：仅单臂桌面操作（Galaxea A1），未涉及移动机械臂、双臂、灵巧手、人形机器人；样本量仅 20 次/任务；
- **基准饱和问题**：LIBERO 部分子集接近天花板，绝对提升有限；多个对比基线为文献报告值，未在作者管线内复现，可能存在协议差异；
- **ShellGameTouch 表现仍逊于 MemoryVLA（75% vs 88%）**，作者承认其 LTC 记忆本质是"连续任务进度动力学"，对**离散物体-位置绑定**类任务匹配度不足；
- **动作分块长度 H 与自适应执行器是关键超参**，其敏感性未充分讨论；
- **缺少长时序扩展性验证**：单回合 ≥100 步的极长视野任务表现未知；
- **理论表达上的谨慎**：作者明确指出 LTC 并非在所有意义上"更优"于 SSM/GRU，区别在于"功能设计目标"——这虽诚实，但也意味着其理论优势是任务依赖的；
- **安全与鲁棒性**：未涉及分布外指令、对抗扰动、传感器失效等更现实场景的评估。
