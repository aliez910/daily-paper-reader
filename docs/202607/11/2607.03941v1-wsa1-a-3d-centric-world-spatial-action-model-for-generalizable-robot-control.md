## 摘要
具身智能领域的最新进展已使机器人基础模型（RFM）成为当前通用机器人系统的主流方法。通过在大规模机器人演示数据上进行模仿学习，RFM 在将视觉观察和语言指令映射到连续机器人动作方面取得了令人瞩目的能力。然而，现有 RFM 缺乏对物理动力学以及机器人行为在三维物理世界中因果效应的固有推理能力。这造成了以二维为中心的视觉感知与以三维为中心的具身交互之间的根本错配，严重限制了 RFM 在真实世界任务中的泛化能力。为弥补这一缺陷，我们提出了 WSA$_1$，一种基于所提出的“以三维为中心的世界-空间-动作”建模范式的新型 RFM。它不仅能学习面向未来机器人行为的三维世界感知视觉思维，还对三维世界状态转移与机器人动作之间的相互约束进行建模，以增强行为泛化能力。值得注意的是，WSA$_1$ 仅使用 6k 小时的专家演示数据（其中仅 1k 小时来自真实机器人）便实现了高数据效率的预训练，同时在 RoboTwin2.0 仿真基准上取得了具有竞争力的操作性能（93% 成功率），并在真实世界机器人控制任务上相较当前最先进的 RFM 平均提升 +20% 的性能。上述结果表明，当与以三维为中心的“世界-动作”联合建模相结合时，无需大规模真实机器人数据也能实现可泛化的 RFM，这为通用机器人系统提供了一条切实可行且经济高效的路径。

## Abstract
Recent advances in embodied AI have established robot foundation models (RFMs) as the dominant approach for generalist robotic systems to date. By leveraging imitation learning on extensive robot demonstrations, RFMs have achieved impressive capabilities in mapping visual observations and language instructions to continuous robotic actions. However, current RFMs lack an inherent ability to reason about physical dynamics and the causal effects of robot behaviors on the 3D physical world. This creates a fundamental mismatch between 2D-centric visual perception and 3D-centric embodied interaction, severely limiting the generalization ability of RFMs in real-world tasks.To address this gap, we present WSA$_1$, a novel RFM built upon proposed 3D-Centric World-Spatial-Action modeling paradigm. It not only learns 3D world-aware visual thought for future robot behaviors, but also models mutual constraints between 3D world state transitions and robotic actions to enhance behavior generalization. Notably, WSA$_1$ achieves highly data-efficient pre-training with 6k hours of expert demonstration data (only 1k hours from real robot), while delivering competitive manipulation performance (93% success rate) on RoboTwin2.0 simulation benchmark and achieving +20% average boosted performance over state-of-the-art RFMs on real-world robot control tasks. These results reveal that generalizable RFM can be attained without large-scale real robot data when paired with 3D-centric world-action joint modeling, which offers a practical and affordable pathway to generalist robotic systems.

# WSA$_1$ 论文总结：以三维为中心的世界-空间-动作建模

## 1. 核心问题与研究动机

- **范式局限**：现有机器人基础模型（RFM）主要沿两条路径发展——视觉-语言-动作（VLA）模型（如 RT-2、π0、π0.5、OpenVLA）以 2D 图像为感知核心，采用"理解→执行"范式；世界-动作模型（WAM，如 Motus、GeoPredict、Fast-WAM）以视频生成或 3D 几何预测为规划器，采用"想象→执行"范式。二者均未在共享潜空间中**显式联合建模 3D 世界动力学与动作之间的双向因果约束**。
- **2D–3D 错配**：物理交互本质发生在三维空间，而现有模型基于 2D 视觉语义或 2D 视频，缺乏对 3D 物理动力学、动作-世界因果性的内在推理能力，导致在涉及空间几何、接触、位姿等任务上泛化能力受限。
- **数据瓶颈**：模仿学习对大规模真实机器人数据依赖极强，但真实数据采集昂贵且存在安全约束，成为通用机器人落地的关键瓶颈。
- **研究问题**：能否构建一种**数据高效**的建模范式，使机器人能从演示中联合学习 3D 世界演化与物理行为之间的相互依赖，从而打破朴素模仿的泛化瓶颈？

## 2. 方法论

### 2.1 核心思想
提出"**3D-Centric World-Spatial-Action (WSA)**"联合建模范式，类比人类认知神经科学中的内部模型理论（Internal Model Theory），将机器人策略分解为三个层次的协同学习任务。

### 2.2 三个层次的学习目标
- **世界因果层（Action-Conditioned 3D World Modeling, 3D AC-WM）**：建模 $p(g_{t+1:t+K} \mid a_{t+1:t+H}, O_t)$，预测动作引起的 3D 世界演化，对应运动控制中的"前向内部模型"。
- **空间认知层（3D World-Aware Visual Thinking, 3D WA-VT）**：建模 $p(v_{t+1:t+N} \mid g_{t+1:t+K}, O_t)$，在 3D 几何约束下生成 2D 视觉子目标，对应人脑的"心理意象"能力。
- **动作执行层（3D Inverse Dynamics Modeling, 3D IDM）**：建模 $p(a_{t+1:t+H} \mid g_{t+1:t+K}, O_t)$，将 3D 状态转移映射到可执行动作，对应"逆向运动控制"。

### 2.3 架构设计
- 采用 **Mixture-of-Transformers（MoT）** 架构，集成三个专家模块：
  - **2D Spatial Expert (2D-SE)**：基于 Qwen3-VL-2B 或 Wan2.2-5B 初始化，预测子目标图像的潜 token（而非 RGB 像素），强化语义特征提取。
  - **3D Spatial Expert (3D-SE)**：与 2D-SE 同深度 Transformer，预测未来 3D 场景的潜表示。
  - **3D Action Expert (3D-AE)**：基于去噪扩散 Transformer（DiT），通过 flow matching 连续动作生成。
- **3D-Centric World-Action Causal Attention（双向因果注意力）**：
  - 所有预测 token（视觉、3D、动作）均可关注当前观测 token；
  - 2D 视觉 token 可关注 3D 场景 token（强制 2D-3D 视觉一致性）；
  - 3D 场景 token 与动作 token 之间**全双向注意力**（这是 WSA 范式建模世界-动作相互依赖的关键）。
- 提供两个版本：**WSA 1-B (3B)** 基于 Qwen3-VL-2B；**WSA 1-L (6B)** 基于 Wan2.2-5B。

### 2.4 损失函数
- $\mathcal{L}_{2D} = \|f_{2D}(O_t, G_t) - f_{enc}(V_t)\|_2^2$：视觉思维 MSE 损失；
- $\mathcal{L}_{3D} = \|f_{3D}(O_t, A_t) - f_g(G_t)\|_2^2$：3D 世界建模 MSE 损失；
- $\mathcal{L}_{ACT} = \|\omega - A_t - f_{act}(O_t, G_t, \hat{A}_t)\|_2^2$：flow matching 损失；
- **总损失**：$\mathcal{L}_{total} = \mathcal{L}_{2D} + \mathcal{L}_{3D} + \mathcal{L}_{ACT}$，在预训练与后训练两阶段**协同**优化。

### 2.5 训练策略
- **两阶段**：第一阶段在异构数据上预训练获取通用行为先验；第二阶段在具体任务/机器人本体上后训练适配。
- 区别于 Motus 等仅在某一阶段引入世界模型的方法，WSA 在**两个阶段均联合**优化三个目标。
