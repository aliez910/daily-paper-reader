## Abstract
Language-conditioned manipulation requires both precise contact-rich control and robust reasoning over language, scenes, and long horizons. End-to-end Vision-Language-Action (VLA) models provide strong local visuomotor skills, but they are trained on in-distribution task trajectories and often fail under deployment perturbations such as semantic retargeting, goal re-binding, spatial-layout shifts, and unstable local contacts. LLM coding agents provide complementary semantic and compositional reasoning, but purely analytic primitives struggle with irregular grasping, constrained placement, and articulated-object interaction. We present Harness VLA, a memory-augmented agentic framework that exposes a frozen VLA as a retryable contact-rich primitive and composes it with a small fixed library of analytic primitives for grounding, staging, transport, navigation, and release. Rather than expanding the skill library, the harness learns the operating range of these fixed primitives from task-specific execution traces, global success rules, and failure models. By lifting semantic re-grounding, non-contact execution, and VLA re-staging to the planner while reserving the frozen VLA for local contact-rich phases, Harness VLA extends pretrained VLAs beyond their original trajectory distribution without finetuning. Across perturbed tabletop, household kitchen, and clean-to-randomized bimanual manipulation, Harness VLA improves over the strongest relevant baselines by 38.6 and 25.4 percentage points on LIBERO-Pro and RoboCasa365, respectively, and reaches 58.4% on RoboTwin C2R.

# Harness VLA 论文总结

## 一、论文核心问题与整体含义

### 研究背景
- **任务定位**：语言条件下的机器人操作（language-conditioned manipulation）需要同时具备两类能力：精确的接触丰富型（contact-rich）运动控制，以及对语言、场景和长时序的鲁棒推理。
- **现有两大范式的不足**：
  - **端到端 VLA 模型**（如 π0、π0.5、OpenVLA）：擅长局部视觉运动控制（如不规则抓取、夹具操作），但在语义重定向（semantic retargeting）、目标重绑定（goal re-binding）、空间布局变化（spatial-layout shifts）等部署扰动下鲁棒性急剧下降；其语言通道在分布外几乎失效。
  - **LLM 编程智能体**（如 Code as Policies、ProgPrompt、CaP-X）：在语义组合与长时序规划上具有优势，但纯解析式基元难以处理不规则抓取、约束放置和铰接物体交互等精细接触操作。
- **核心症结**：两种范式都让错误的组件承担了过多责任——单块 VLA 把语言理解、长时序组合与底层控制塞入同一策略；纯代码智能体则试图用解析式 API 复现物理上精细的交互。
- **本文主张**：用解析式基元穿越部署扰动，仅在接触丰富阶段调用 VLA，使 VLA 成为可重试的"接触专家"。

## 二、方法论

### 核心思想
将**冻结的 VLA** 暴露为单一接触丰富型基元 `VLA ACT`，与一组**固定的分析式基元**组合，由**记忆引导的 LLM 规划器**统一调度。关键点不是扩大技能库，而是学习**如何编排固定基元**。

### 框架组成
- **统一的基元库 P**（固定、不可扩展）：
  - 解析式复合基元：`MOVE TO`、`MOVE POSE`、`NAVIGATE TO`（RoboCasa365）
  - 解析式原子基元：`ROTATE WRIST`、`ROTATE PITCH`、`SET GRIPPER`、`RELEASE`、`MOVE BASE`（RoboCasa365）
  - 单一 VLA 基元：`VLA ACT`（通过 JSON 调用，传入 prompt、max_chunks、stop 谓词）
  - 引导期专属：`RESET`
- **两层记忆模块**：
  - **Task Specific Memory**：在参考种子（seed 0）上成功探索得到的参数化 JSONL 命令轨迹 + 语义审计 JSON（策略、避免项）。空间坐标用符号化感知查询替换，便于跨布局重新 grounding。
  - **Global Memory**：跨任务的成功规则（如最优 prompt 策略）与失败模型（如空抓、虚假成功）。
- **两阶段生命周期**：
  1. **探索引导阶段（Exploratory Bootstrapping）**：在单个参考实例上自主探索，获得 RESET 权限和大预算，生成 Task Specific Memory 与 Global Memory。
  2. **部署评估阶段（Deployment Evaluation）**：禁用 RESET，缩短预算，从记忆检索 JSONL 轨迹，利用实时 RGB-D 观测重新 grounding。

### 关键执行机制
- **文件中介的 REPL 协议**：规划器通过写入 `command.json` 发出基元调用，工作进程（拥有仿真器状态）消费并执行；每个回合都伴随观察与诊断，绝不开放执行。
- **观测通道**：RGB 用于语义推理，深度图与本体感知用于度量定位；明确禁止访问真实物体位姿或仿真器内部状态。
- **可重试的接触尝试**：规划器将 `VLA ACT` 视为局部接触尝试，可重新摆放（re-stage）后再次调用，而非一次性黑盒调用。
- **VLA ACT 调用语义**：传入 prompt 与早停谓词 τ；冻结 VLA f_θ 输出动作块直到 τ 满足或块预算耗尽。规划器负责语义 grounding、空间重绑定、导航、再试与释放。

### 整体流程
1. 任务描述 + RGB-D 观测 + 机器人状态 → 智能体规划器 Π
2. Π 结合 Task Specific Memory、Global Memory 选取基元 c_t ∈ P
3. 物理引擎执行至基元内部后置条件满足，输出 o_{t+1}、q_{t+1}
4. 循环直至目标谓词 G 满足或预算耗尽

## 六、主要结论与发现

### 主要结论
- **核心结论**：通过智能体框架将冻结 VLA 与固定基元库组合，可将预训练 VLA 拓展至分布外的长时序扰动场景，而无需对 VLA 微调或扩展基元库。
- **不对称分层**：让 VLA 负责接触丰富的局部视觉运动控制，让 LLM 规划器承担语义 grounding、空间重绑定、运输、姿态调整、导航与释放。
- **记忆设计的重要性**：任务专属 JSONL 轨迹 + 跨任务 Global Memory 显著影响泛化能力与对历史失败的规避。

### 三大发现
1. 规划器级别的语义/场景重新 grounding 可恢复任务条件行为——无需修改 VLA 即可让冻结 VLA 跟随新指令。
2. 规划器分期调用与重试显著提高冻结策略可靠性；少量稀疏调用即超过冻结基线。
3. 解析式基元成功隔离了非接触执行与接触丰富控制；VLA 在 LIBERO 中仅占 15.8% 调用，在 RoboCasa365 占 35.3%，在 RoboTwin C2R 占 47.4%。

## 七、优点

- **方法论新颖性**：提出"不对称分层 + 固定基元库 + 冻结 VLA"的清晰分工，避免了基元库无限扩展与 VLA 微调两个常见路径。
- **即插即用**：通过统一 JSON 接口 `VLA ACT` 抽象掉 RLinf、RLDX-1、LingBot-VLA 三个不同 VLA 后端。
- **记忆设计细致**：将 Task Specific Memory 与 Global Memory 分离，JSONL 轨迹只作为结构骨架，空间坐标在部署时重新 grounding，避免了机械回放。
- **可重试机制**：将 VLA ACT 视为可重新摆位的接触尝试，规避了单次接触失败导致整条 rollout 崩溃的问题。
- **协议透明**：文件中介 REPL 协议、明确的感知隔离规则、附录给出完整 prompt 骨架与各基准实例化，提升可复现性。
- **实验覆盖广**：四大基准、跨扰动、跨实施机构（单臂 / 移动 / 双手），既保留 in-distribution 性能又显著提升 OOD 鲁棒性。
