## 摘要
视觉-语言-动作（VLA）模型在通用机器人操作方面展现出强大的潜力，但大多数现有模型依赖于二维视觉-语言骨干网络，缺乏对目标对象的细粒度三维理解，尤其在遮挡、姿态变化、尺度变化以及精确空间交互等场景下这一问题更为突出。我们提出了一种基于π₀构建的以对象为中心的三维表示对齐框架，采用SAM3D作为冻结的三维教师模型，在训练过程中为目标对象提供三维先验。具体而言，我们利用目标识别模型对任务相关对象进行定位，生成相应的目标掩码，并借助SAM3D提取密集的对象级三维表示，将其与π₀的中间视觉特征进行对齐。该方法使策略能够内化目标对象的三维信息，同时保留原始的RGB-语言-动作推理流程，在测试时无需深度图、点云、掩码、SAM3D或额外的三维模块。仿真实验表明该方法取得了稳定提升，在LIBERO基准上达到99.1%，在CALVIN基准上取得4.11的平均任务长度。真实世界实验进一步验证了我们的方法在长时序操作场景中的有效性——在这些场景中，机器人需要在多个子任务中聚焦于不同的目标对象。

## Abstract
Vision-Language-Action (VLA) models have shown strong potential for general robot manipulation, but most existing models rely on 2D visual-language backbones and lack fine-grained 3D understanding of target objects, especially under occlusion, pose variation, scale changes, and precise spatial interaction. We propose an object-centric 3D representation alignment framework built upon $π_0$, using SAM3D as a frozen 3D teacher to provide target-object 3D priors during training. Specifically, we localize task-relevant objects with object recognition models, generate corresponding object masks, and use SAM3D to extract dense object-level 3D representations, which are aligned with intermediate visual features of $π_0$. This enables the policy to internalize target-object 3D information while preserving the original RGB-language-to-action inference pipeline without requiring depth, point clouds, masks, SAM3D, or additional 3D modules at test time. Simulation experiments show consistent improvements, achieving 99.1\% on LIBERO and an average length of 4.11 on CALVIN. Real-world experiments further demonstrate that our method is particularly effective in long-horizon manipulation scenarios where the robot must focus on different target objects across multiple subtasks.

# SAM3D-VLA 论文详细总结

## 1. 核心问题与研究动机

- **问题背景**：现有的视觉-语言-动作（Vision-Language-Action, VLA）模型（如 π₀、OpenVLA、UniVLA 等）大多建立在 2D 视觉-语言骨干之上，仅依赖 RGB 图像与语言指令即可预测连续动作，已在通用机器人操作中展现强大潜力。
- **关键瓶颈**：这些 2D VLA 模型缺乏对**目标物体**的细粒度 3D 理解能力，难以建模目标对象的形状、姿态、尺度与空间布局。在遮挡、姿态变化、杂乱场景以及需要精确空间交互（如插花、放置、堆叠）的任务中表现受限。
- **现有方案的不足**：
  - **显式 3D 方法**（如 SpatialVLA、GeoVLA、3D-CAVLA、BridgeVLA、PointVLA）需要额外的深度图、点云或 RGB-D 输入，改变了原 π₀ 的输入输出接口；
  - **空间监督方法**（如 Spatial Forcing）多关注全局场景级空间结构，而非目标物体级 3D 先验；
  - **视觉接地方法**（如 ReconVLA、RoboGround）监督信号停留在 2D 图像空间，不能显式提供目标对象的 3D 形状/布局先验。
- **核心研究问题**：能否在**不改变 RGB-语言-动作推理流程**的前提下，将以对象为中心的 3D 知识注入到基于 RGB 的 VLA 策略中？

## 2. 方法论

### 2.1 核心思想

构建基于 π₀ 的**对象中心 3D 表征对齐框架**，在**训练阶段**使用冻结的 SAM3D 作为 3D 教师，为任务相关目标物体提供密集的 3D 形状与布局先验；将 SAM3D 特征与 π₀ 骨干的中间视觉特征进行对齐，从而让策略"内化"目标对象的 3D 结构信息。**推理阶段**完全保留原始 π₀ 的 RGB+语言→动作流程，无需深度、点云、掩码、SAM3D 或任何额外 3D 模块。

### 2.2 关键技术细节

- **骨干网络**：π₀ 架构 = SigLIP 视觉编码器 + Gemma 语言模型 + 连续动作专家（Continuous Action Expert），使用流匹配（Flow Matching）目标训练动作专家。
- **子任务分解（Subtask-aware Data Processing）**：
  - 高层长时序指令由 GPT-4o 等 LLM 分解为多个子任务；
  - 每个子任务对应一个目标对象，由 Grounding DINO / YOLO 进行开放词汇检测，再由 SAM2 生成分割掩码；
  - 每个子任务对应专属的图像-掩码对，提供阶段特定的 SAM3D 监督。
- **SAM3D 教师特征提取**：
  - 将多视角图像与对应子任务掩码展平，逐视角送入冻结的 SAM3D；
  - 取 SAM3D 最后一个 Transformer 块的稠密对象级 3D 特征 $T_t \in \mathbb{R}^{(BV)\times L_T \times D_T}$；
  - 将教师 token 序列重塑为 2D 特征网格，去掉全局 token 后用**双线性插值**重采样到学生视觉 token 的分辨率 $(H_S, W_S)$，保证空间对齐。
- **学生特征投影与对齐**：
  - 从 Gemma 选定层提取中间视觉特征 $S_t \in \mathbb{R}^{B\times(VL_S)\times D_S}$；
  - 通过投影器 $P_\phi$ 映射到 SAM3D 特征空间 $\hat{T}_t = P_\phi(S_t)$；
  - 仅对子任务对应目标对象的 token 做掩码对齐，其余 token 不参与监督；
  - 使用 ℓ2 归一化后计算 **Masked Normalized MSE** 作为对齐损失（公式 3）：
    $$L_{\text{align}} = \text{MSE}\big(\text{Norm}(\hat{T}_t)[M_t],\ \text{Norm}(\bar{T}_t)[M_t]\big)$$
- **总训练目标**（公式 4）：
  $$L = L_{\text{action}} + \alpha L_{\text{align}}$$
  其中 $L_{\text{action}}$ 为标准 π₀ 流匹配动作损失，$\alpha$ 控制 3D 监督强度。
- **冻结表征探测实验（Frozen-Representation Probing）**：
  - 训练结束后冻结整个 VLA 骨干，仅训练一个轻量两层 MLP 探测器 $P_\omega$；
  - 用相同的目标掩码与归一化 MSE 损失，从冻结的中间特征预测重采样后的 SAM3D 特征；
  - 若探测性能提升，说明 SAM3D 式对象级 3D 先验确实更容易从所学 VLA 特征中恢复，从而验证机制有效性。

## 3. 实验设计

### 3.1 数据集与基准

- **LIBERO 仿真基准**：包含 LIBERO-Spatial、LIBERO-Object、LIBERO-Goal、LIBERO-Long 四个子集，每个子集 10 个任务 × 500 条专家演示，评估空间布局、目标对象、目标变化与长时序泛化能力。
- **CALVIN 长时序基准**：包含 34 个任务、4 个环境（A/B/C/D），采用 ABC→D 划分；长时序挑战为 5 个连续子任务序列，500 次 rollout 评估。
- **真实世界平台**：AgileX Piper-X 移动双臂机器人，配置 3 个全向轮、2 条 6-DoF 机械臂、2 个腕部相机与 1 个头部相机。
- **真实世界任务**（3 类）：
  - 做饭（Cook）：将食材放置到绿盘并组装三明治；
  - 插花（Flower）：将桌面花朵依次插入花瓶；
  - 堆叠（Stack）：按指定颜色顺序堆叠方块。
- **测试协议**：每个任务设两种设置——
  - 标准设置（ST）：物体处于规范初始位置；
  - 遮挡/扰动设置（OC）：物体位置改变、加入干扰物、引入部分遮挡。

### 3.2 对比方法

- **2D VLA 基线**：Diffusion Policy、Octo、OpenVLA、Dita、CoT-VLA、π₀、UniVLA、OpenVLA-OFT、TraceVLA、FAST；
- **显式 3D VLA**：SpatialVLA、GeoVLA、3D-CAVLA；
- **隐式 3D / 空间监督**：Spatial Forcing；
- **对象中心方法**：ReconVLA（用于 CALVIN 对比）；
- **CALVIN 上的生成式方法**：UniPi、SuSIE、GR-1、VidMan、CLOVER；
- **CALVIN 上的大模型 VLA**：VLAS、RoboFlamingo、OpenVLA、UniVLA。

## 4. 资源与算力

- **真实世界训练**明确说明使用 **8 块 NVIDIA H100 GPU**；
- 仿真实验（LIBERO / CALVIN）的具体 GPU 型号、数量、训练时长在论文中**未明确披露**；
- 训练数据处理依赖多个外部模型：Grounding DINO / YOLO（检测）、SAM2（分割）、SAM3D（教师，冻结）、GPT-4o（子任务分解），均为推理调用，不涉及这些模型本身的训练。

## 5. 实验数量与充分性

- **仿真实验**：
  - LIBERO 上 4 个子集 × 多达 10 余个对比方法 × 2D/显式 3D/隐式 3D 三大类，全面报告 Spatial/Object/Goal/Long 与平均成功率；
  - CALVIN 上提供 1-5 步子任务成功率与平均长度，并对比 11 个 SOTA 方法；
  - 每个任务均使用标准成功率指标，且 CALVIN 上采用 500 次 rollout，结果统计较稳健。
- **消融与机制验证**：
  - 提供 **Frozen-Representation Probing** 实验，量化对象级 3D 先验是否被有效编码到 VLA 特征中；
  - 通过子任务分解 → 子任务专属 SAM3D 监督的设计，验证 LIBERO-Long 上 98.4% 的提升来自阶段特定对象级 3D 监督；
  - 但论文**未提供针对对齐层选取、α 权重、掩码噪声、子任务分解质量的系统消融**，机制层面仍偏描述性。
- **真实世界实验**：
  - 3 类任务 × 2 种设置 × 2 个方法（π₀ vs SAM3D-VLA），共 12 组成功率；
  - 真实世界任务覆盖目标选择、抓取、插入、放置等动作类型，场景较为多样，但仅基于单一机器人平台，统计显著性未做重复实验或多 seed 报告。
- **总体评价**：仿真基准全面、对比方法充足；但缺少 α/层数/掩码噪声等系统性消融，且真实世界实验的样本量与方法数量较少，结论的普遍性有一定限制。

## 6. 主要结论与发现

- 在 **LIBERO** 上达到 **99.1% 平均成功率**，其中 LIBERO-Long 达 **98.4%**，超越 Spatial Forcing（98.5%）、GeoVLA（97.7%）、OpenVLA-OFT（97.1%）等强基线；
- 在 **CALVIN ABC→D** 上达到 **平均长度 4.11** 与 **5 步成功率 71.6%**，全面优于 UniVLA、OpenVLA、ReconVLA 等；
- 在真实世界 Piper-X 上，将 π₀ 的平均成功率从 50.2%（ST）/21.3%（OC）提升至 **65.2%（ST）/44.3%（OC）**，长时序任务（做饭、插花、堆叠）提升尤为显著；
- 冻结探测实验表明，对齐训练后，SAM3D 对象级 3D 先验**更容易从所学 VLA 特征中恢复**，即 3D 知识确实被编码进骨干表征；
- 长时序子任务的对象切换需求与对象级 3D 先验天然契合，因此长 horizon 任务收益最大。

## 7. 优点与亮点

- **推理流程零改动**：在测试时不增加任何 3D 传感器、点云、掩码或额外模块，保留原 π₀ RGB+语言→动作的简洁部署形态，工程实用性高；
- **真正的对象中心视角**：区别于场景级空间对齐（如 Spatial Forcing），本文聚焦于任务相关目标对象的几何先验，与长时序多子任务切换的需求高度契合；
- **子任务级对象感知数据管线**：通过 LLM 子任务分解 + 检测 + SAM2 + SAM3D 构成端到端的"任务→对象→3D"监督链路，能为不同操作阶段提供针对性监督；
- **机制可验证**：通过冻结探测实验量化"3D 先验是否被内化"，比单纯报告成功率更具说服力；
- **跨域表现一致**：仿真（LIBERO/CALVIN）与真实世界（Piper-X）均取得稳定提升，方法泛化能力强。

## 8. 不足与局限

- **训练管线依赖多个外部模型**：子任务分解（LLM）、开放词汇检测（Grounding DINO/YOLO）、分割（SAM2）任一环节出错都会引入噪声监督，论文未分析这些噪声对最终性能的影响；
- **SAM3D 的固有局限**：SAM3D 仅处理单张图像，在严重遮挡、透明物体、不佳视角下可能给出不可靠的 3D 监督；多视角/时序 3D 教师未被探索；
- **消融实验不充分**：未报告对齐层选取、超参数 α、掩码质量、子任务分解误差、不同骨干（如 OpenVLA）等因素的消融结果；
- **真实世界评估有限**：仅在单一 Piper-X 平台、3 类桌面任务上验证，未涉及移动导航、双臂协调、人机交互等更复杂场景，且未给出多 seed 或显著性检验；
- **任务范围受限**：基准侧重桌面操作，未验证在 deformable object、tool-use、动态目标等更广泛操作场景中的表现；
- **方法不限于 π₀**：尽管作者声明该对齐框架可移植到其他 VLA 骨干，但本文**仅在 π₀ 上验证**，跨骨干泛化尚未证实；
- **算力披露不全**：仅给出真实世界训练使用 8×H100，仿真实验的算力与训练时长未透明化，难以复现成本评估。
