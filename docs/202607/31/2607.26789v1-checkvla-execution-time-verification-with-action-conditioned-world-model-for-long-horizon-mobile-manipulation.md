## 摘要
视觉-语言-动作（VLA）策略通常通过开环动作块执行长时程移动操作，在不接收新的高层视觉输入的情况下发出多个动作。已提交的动作块因此蕴含了观测应当如何演化的预期，但意外偏差可能违反该预期，而剩余动作会继续传播这一误差：提交时刻的策略置信度无法对分派后发生的偏差作出反应，而仅基于观测的异常分数缺乏动作条件参考，无法区分预期效应与未解释的变化。我们提出CheckVLA，它通过一个单独训练、冻结的动作条件世界模型来验证执行过程。经共形校准的风险阈值约束了不必要首次干预的回合级概率，并决定何时进行干预；其超出程度控制重写后缀保留被替代动作块的强度；感知延迟的硬前缀约束将替换限制在仍可部署的动作范围内；事件驱动的关键帧库在多次修复过程中保留先前进展的证据。在RoboCasa365上，在相同的训练方案和匹配的调用预算下，CheckVLA的平均成功率达到36.1%，而周期重规划为27.6%（+8.5个百分点）。在匹配的5%回合级误报目标下，动作条件将及时召回率提升至77.9%，而仅基于观测的对照组为48.6%，动作打乱的对照组为37.9%。这些仿真结果支持将动作条件验证作为一种在分块执行期间恢复反馈、同时使修复与推理延迟保持一致的方法。

## Abstract
Vision-language-action (VLA) policies commonly execute long-horizon mobile manipulation through open-loop action chunks, issuing multiple actions without receiving new high-level visual input. A committed chunk therefore implies how observations should evolve, but accidental deviations can violate this expectation while the remaining actions continue to propagate the error: commit-time policy confidence cannot react to a deviation that occurs after dispatch, and observation-only anomaly scores lack an action-conditioned reference for separating expected effects from unexplained changes. We propose CheckVLA, which verifies execution with a separately trained, frozen action-conditioned world model. A conformally calibrated risk threshold bounds the episode-level probability of an unnecessary first intervention and determines when to intervene, its exceedance controls how strongly the rewritten suffix retains the superseded chunk, latency-aware hard prefixing restricts replacement to actions that remain deployable, and an event-driven keyframe bank preserves evidence of prior progress across repairs. On RoboCasa365, under a common training recipe and a matched invocation budget, CheckVLA attains a 36.1% average success rate against 27.6% for periodic replanning (+8.5 points). At a matched 5% episode-level false-alarm target, action conditioning raises timely recall to 77.9%, against 48.6% for an observation-only control and 37.9% for an action-shuffled control. These simulation results support action-conditioned verification as a way to restore feedback during chunked execution while keeping the repair consistent with inference latency.

# CheckVLA 论文总结

## 1. 核心问题与研究动机

- **核心问题**：视觉-语言-动作（VLA）策略在执行长时程移动操作任务时，通常以**开环动作块（action chunk）**方式一次性发出多个动作，期间不再接收新的高层视觉输入，导致分派后的偏差无法被及时察觉并纠正。
- **问题的具体表现**：
  - 已提交的动作块隐含了观测应当如何演化的预期，但实际偏差（如物体滑落、基座偏移）会违反该预期，而剩余动作仍按错误前提继续执行，造成误差累积。
  - 提交时刻的策略置信度（commit-time confidence）无法对分派后发生的偏差做出反应。
  - 仅基于观测的异常分数缺乏**动作条件参考**，无法区分"预期效应"与"未解释的变化"。
- **现有方案的不足**：自适应分块、异步连续性方法（如 RTC、REMAC）只解决"何时刷新块"或"如何保持连续性"问题，未将**动作条件后果预测**转化为**带校准的干预**与**可部署的修复**。

## 2. 方法论

### 整体框架：四个耦合组件

1. **动作条件滚动预测**（Action-Conditioned Rolling Prediction）
2. **保角校准风险触发**（Calibrated Risk Triggering）
3. **延迟感知后缀重写**（Latency-Aware Suffix Rewriting）
4. **事件驱动情节上下文**（Event-Driven Episodic Context）

### 关键技术细节

- **问题形式化**：在块边界 $t$，策略 $\pi_\theta$ 编码指令 $L$、多视图观测 $o_t$、情节上下文 $\rho_t$，提交长度为 $H$ 的动作块 $A_t$。在块内高层策略不接收新视觉输入，但监控器（monitor）可接收。延迟 $d_{lat}$ 为推理分配的固定步数，$d_{eff}$ 为实际部署时刻；不可逆前缀为 $h < d_{eff}$，仅 $h \geq d_{eff}$ 可被替换。
- **动作条件世界模型**：使用**单独训练、冻结的 V-JEPA 2-AC 编码器**提取监控特征 $z_{t'} = \phi(o_{t'})$。世界模型 $\Psi$ 在特征空间中以块因果注意力预测未来 $k$ 步特征（$k \ll H$），条件包括当前特征、历史预测、剩余已提交动作及名义本体感受展开。
  - 训练流程：先以 teacher forcing + Huber 损失训练，再用自身自回归展开继续训练，使训练分布与在线推理分布一致。
  - 每个新观测重新锚定滚动，跨越块边界的预测需在下一块提交后生成。
- **保角校准风险触发**：
  - 计算预测-观测距离 $d_t = \text{dist}(\hat{z}_{t|t-\ell(t)}, z_t)$，并以保留学出成功统计量 $(\mu, \sigma)$ 做标准化：$\tilde{d}_t = (d_t - \mu_d(\ell))/\max(\sigma_d(\ell), \varepsilon)$。
  - 时序因果风险头 $R$ 聚合滑动窗口 $x_{t-w+1:t}$（含归一化距离、跨度比例、块内位置、最近块切换步数）与情节摘要，输出 $r_t \in [0,1]$。
  - 采用 **split functional conformal calibration**：在名义成功阴影轨迹上拟合 $(\mu_{r,t}, \sigma_{r,t})$，计算有限样本分位数 $\hat{q}_\alpha$，设定阈值 $\delta_t = \mu_{r,t} + \hat{q}_\alpha \tilde{\sigma}_{r,t}$，满足首次干预的回合级边界 $\Pr(\exists t: r_t > \delta_t \mid \text{nominal success}) \leq \alpha$。
  - 首次跨越时刻 $t^* = \min\{t: r_t > \delta_t\}$ 触发修复。
- **延迟感知后缀重写**：
  - 同一 VLA 在流积分（flow integration）过程中，对每个候选位置 $h < d_{lat}$ **硬钳位（hard clamp）**到正在执行的前缀动作；延迟溢出时部署起点为 $h = d_{eff}$，丢弃已流逝位置。
  - **保留强度**由触发时刻的标准化超出度 $e_{t^*}$ 控制：$w_0(e) = w_{\min} + (1 - w_{\min})e^{-\beta e}$，随 $e$ 单调递减；沿位置以通道特定速率 $\lambda_m$ 衰减为 $W_{h,m} = w_0(e_{t^*})e^{-\lambda_m(h-d_{lat})}$。
  - 流速度按权重混合参考与策略输出：$v = (1-W) \odot v_\theta + W \odot v_{\text{ref}}$。
- **事件驱动情节上下文**：
  - 维护关键帧银行 $B_t = \{(F_j, t_j)\}$，仅在关节空间位移局部极小且满足时间间隔与多样性准则时写入。
  - 策略通过门控交叉注意力读取完整银行；风险头仅读取紧凑摘要 $m(\rho_t) = (t - t_{\text{last}}, m_t, \bar{F}_{\text{last}})$。

### 算法流程

执行循环（伪代码见附录 B）：
1. 提交动作块并锚定当前观测；
2. 每收到新观测 → 检索最新有效预测 → 计算距离与风险 $r_t$；
3. 若 $r_t > \delta_t$ 且无抑制 → 计算 $e_{t^*}$，用同一 VLA 重写后缀（硬前缀钳位 + 风险自适应引导）；
4. 在调度时刻部署（$h = d_{lat}$ 或 $h = d_{eff}$），失效被替代的预测，抑制 $s_{\min}$ 步，重新锚定；
5. 否则以新观测为锚点继续滚动预测；块边界正常切换。

- **软件**：PyTorch 2.3.1 + CUDA 12.1；仿真器 RoboCasa365（robosuite 1.4.1、MuJoCo 3.1.4）。
- **监控器规模**：相对开环基线新增 **88.4M 参数**、每步 **16.9 GFLOPs**；监控器 p50/p95 延迟 **12.1 / 16.4 ms**（100 ms 控制周期内）；VLA 调用 p50/p95 **286 / 338 ms**（对应 $d_{lat}=3$）。
- **训练时长**：未在正文中明确给出端到端小时数；监控器训练为世界模型 60k teacher forcing + 20k 自展开步（AdamW lr=3e-4，batch=32），风险头 20k 步（lr=1e-4，batch=64）；保角校准使用 400 个名义阴影轨迹/种子。
- **随机种子**：3 个独立训练种子（Seed 1/2/3）。

## 6. 主要结论与发现

- **核心性能**：在 RoboCasa365 Human300 协议下，CheckVLA 取得 **36.1% 平均成功率**，较复现 π0.5（17.2%）提升约 18.9 个百分点，较调用匹配的周期重规划（27.6%）提升 **8.5 个百分点**；在公开结果中位列第一（高于 Qwen-RobotManip 35.9%、WorldDreamer 35.3%）。
- **动作条件的关键作用**：在 5% episode FWER 目标下，及时召回率 **77.9%** vs 纯观测对照 **48.6%** vs 动作打乱对照 **37.9%**；扰动成功率 **47.6%** vs 35.2% vs 31.0%。
- **组件贡献（顺序构建）**：解耦动作骨架 +1.5；调用匹配周期重规划 +4.5；验证触发 +3.9；风险自适应引导 +2.6；事件驱动记忆 +2.0。
- **"自信-错误"象限**：低策略不确定性 + 高世界模型风险象限占 25.0% 自然执行，但集中 **48.4% 的失败**，76.0% 仍可及时恢复，31.0% 可被修复——支持策略端与监控端信号的互补性。
- **记忆有效性**：完整设计将已完成子目标回归从 1.34/回合降至 **0.18/回合**，且效果随任务长度增加而扩大。
- **自然执行与良性偏移**：自然失败子集上救援率 21.6%、危害率 2.7%（vs 开环 61.4%）；良性偏移下首次干预率从 14.8% 降至 6.5%、危害率从 4.7% 降至 1.2%。
- **运行成本**：监控器在控制周期内完成（p95 < 100 ms），完整 CheckVLA 壁钟成本为开环的 **1.18×**。

## 7. 优点

- **问题视角新颖**：将已提交的动作块重新诠释为"对近期观测的可测试预测"，把开环执行的反馈缺失问题形式化为预测-观测一致性检测。
- **检测-修复-记忆三位一体设计**：监控器与策略路径解耦（冻结编码器 + 独立世界模型），避免干扰策略优化；保角校准提供统计意义上的首次干预边界；硬前缀钳位保证修复在延迟约束下可部署；事件驱动关键帧库解决重规划后子目标遗忘。
- **触发-修复配对机制**：超出度 $e_{t^*}$ 同时用于"何时干预"与"多大程度保留参考"，通过配对权重 $W(e)$ 而非仅调参提升救援-危害权衡。
- **实验极为充分**：构建性消融 + 跨族对照 + 多种规则对比 + 延迟扫描 + LOFO 训练 + 良性偏移 + 自然失败审计 + 绑定审计 + 失败归因；所有关键报告附 95% 区间。
- **资源效率**：监控器 88.4M 参数、p95 16.4 ms，控制周期内可完成；端到端 1.18× 开环壁钟成本。
- **数据隔离严谨**：策略训练、监控训练、验证、共形校准、目标套件、扰动测试六套数据严格隔离，外部 0 接触。

## 8. 不足与局限

- **仿真范围有限**：所有实验基于 RoboCasa365 仿真器，未进行硬件验证；传感器、控制器频率、硬件时序变化均需重新校准。
- **保角保证的范围狭窄**：功能性保角校准仅控制**名义成功回合上的首次不必要干预概率**，不保证扰动下的召回、修复后安全性、重复干预安全性或分布偏移下覆盖率。
- **扰动族有限**：仅注入冲量、瞬时关节偏移、被移动物体干预三类物理扰动；未涵盖感知噪声、动力学子任务失败等更复杂的真实失败模式。
- **修复能力受限于延迟与策略能力**：若剩余可部署后缀不足或无可行替代动作，警告即使正确也无法恢复回合——延迟扫描显示 $d_{lat}=10$ 时所有方法均显著退化。
- **硬前缀为经验投影**：硬钳位在中间积分时刻并不匹配训练时的噪声水平，因此是"经验性投影"而非严格的条件后缀采样。
- **修复规则依赖经验调参**：$w_{\min}$、$\beta$、$\lambda_m$、$s_{\min}$ 等超参数需在验证集上选择，$e_{t^*} \to W$ 的映射无保角保证。
- **公开系统比较的局限**：因公开方法在策略预训练数据之外差异较大，Table 2 的"最先进"定位仅为描述性；真正公平的比较来自 Table 3 的内部对照。
- **动作条件绑定的双通道混淆**：自回归展开中的动作信息既通过动作 token 又通过确定性本体感受展开传递，绑定审计未将两条通路分离。
- **可解释性与追溯**：风险头输出为标量且依赖复杂时间聚合，缺乏对失败原因的细粒度解释；附录 P 的失败归因为单标签分配。
