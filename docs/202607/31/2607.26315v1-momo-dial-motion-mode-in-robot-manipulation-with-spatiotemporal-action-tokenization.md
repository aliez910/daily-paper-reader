## 摘要
为了在多样化场景中有效运行，机器人不仅需要准确地完成操控任务，还需使其动作展开方式适应任务、物体以及交互环境。我们探讨这种执行层面的变化是否可以作为一种可复用的行为因素在任务间共享学习。我们提出了 **MoMo**，一个两阶段的模仿学习框架，包含一个时空动作标记器和一个以任务及连续运动模式条件作为输入的行为克隆 Transformer。在六项真实机器人操控任务中，改变该条件可产生稳定、动态以及介于两者之间的行为，人类评估者能够区分这些行为，且它们在关节速度、加速度和末端执行器接近俯仰角方面有所不同。在仅以单一模式示教的任务中，MoMo 能够在保持任务成功率的同时迁移到未见过的所请求模式。综上，这些结果为对未见过的任务-模式组合的组合泛化提供了证据，并表明运动模式可在任务间复用，以控制操控技能的执行方式。

## Abstract
To operate effectively across diverse contexts, robots must not only perform manipulation tasks accurately but also adapt how their actions unfold to the task, object, and interaction setting. We ask whether this execution-level variation can be learned as a reusable behavioral factor shared across tasks. We present \textbf{MoMo}, a two-stage imitation-learning framework consisting of a spatiotemporal action tokenizer and a behavior-cloning transformer that takes task and a continuous motion-mode condition as inputs. Across six real-robot manipulation tasks, varying this condition produces steady, dynamic, and intermediate behaviors that human raters can distinguish and that differ in joint speed, acceleration, and end-effector approach pitch. On tasks demonstrated in only one mode, MoMo transfers the unseen requested mode while largely preserving task success. Together, these results provide evidence of compositional generalization to unseen task--mode combinations and show that motion mode can be reused across tasks to control how a manipulation skill is performed.

# MoMo 论文详细总结

## 一、核心问题与研究动机

- **核心问题**：机器人操控策略目前通常将"行为执行风格"与"任务目标"绑定学习，导致风格难以跨任务复用。例如，将"稳健/慢速"或"动态/快速"的执行方式从拾取任务迁移到倒水或人机交互任务时，往往需要重新演示。
- **研究目标**：探索能否将**执行层面的差异**（how）作为**可复用的行为因子**（motion mode）从任务内容（what）中解耦出来，使其在任务间共享、组合。
- **研究背景**：
  - 现有行为/风格条件化操控策略将行为与任务共同学习，行为无法跨任务迁移；
  - 动作离散化（BeT、VQ-BeT、FAST）与动画领域残余矢量量化（VQ-Style）的工作已显示离散码本可作为任务与风格解耦的接口；
  - 机器人运动特性研究（可读性、可预测性、Elegnt、LLM 表达性运动等）均强调任务目标与轨迹风格应可分离寻址。
- **整体含义**：提出"motion mode"是一种**任务无关的行为调制因子**，可与具体任务组合，构成组合泛化（compositional generalization）的实证基础。

## 二、方法论

### 2.1 核心思想

- **两阶段模仿学习框架**：
  - **Stage 1**：时空动作分词器（Spatiotemporal Action Tokenizer），将动作块分解为**空间码流**与**时间码流**两条独立的残差矢量量化（RVQ）栈，再融合到共享解码器重建动作块。
  - **Stage 2**：行为克隆 Transformer，输入视觉观察、本体感知、任务标识符与**连续运动模式标量** $s\in[0,1]$，预测 Stage 1 的离散码索引；冻结 Stage 1。

### 2.2 关键技术细节

- **空间编码器**（Spatial Encoder）$E_{sp}$：
  - 直接作用于**原始关节空间波形** $a\in\mathbb{R}^{100\times 7}$；
  - 1D 卷积栈，下采样 5×，输出 $z_{sp}\in\mathbb{R}^{K\times D}$，$K=20$，$D=256$（每潜位置覆盖 0.4 秒）；
  - 捕获路径几何、接触与末端目标（任务相关结构）。
- **时间编码器**（Temporal Encoder）$E_{te}$：
  - 首先计算**关节增量** $\Delta q_t = q_{t+1}-q_t$；
  - 对时间轴做 **II 型离散余弦变换（DCT）**，保留前 $C=16$ 个低频系数 $\hat{\Delta q}(j)_c$（公式见论文 Eq.1）；
  - 经 2 层 MLP 投影到 $z_{te}\in\mathbb{R}^{K\times D}$；
  - 强调节奏、平滑度、犹豫等动态特性（运动模式相关）。
- **残差矢量量化（RVQ）**：
  - 空间栈：$L_{sp}=4$ 层，码本尺寸 $[64, 512, 512, 512]$（首层作为内容瓶颈）；
  - 时间栈：$L_{te}=4$ 层，尺寸 256；
  - EMA 更新；码本更新延后到优化器步骤之后，使对比梯度能经残差链回传至码本条目。
- **融合与解码**：两条量化流拼接后经 LayerNorm + GELU + $W_f\in\mathbb{R}^{D\times 2D}$ MLP 融合，再由 1D 上采样解码器 $\psi$ 重建动作块 $\hat{a}=\psi(z_q)$。
- **辅助 DCT 预测头** $h_{DCT}$：从 $z_q^{te}$ 预测 DCT 目标，确保时间码保留频域动态信息。
- **Stage 1 损失函数（7 项）**：
  $$L = L_{recon} + \lambda_{DCT}L_{DCT} + \lambda_{swap\text{-}task}L_{swap\text{-}task} + \lambda_{swap\text{-}mode}L_{swap\text{-}mode} + \lambda_{con}L_{con} + \lambda_{MI}L_{MI} + L_{commit}$$
  - $L_{recon}$：L1 重建损失；
  - $L_{DCT}$：DCT 重建辅助损失；
  - **交换损失（swap loss）**：解码时用基块的空间码 + 同任务反模式的供体的**时间码**，分别推向基路径与供体频域内容；
  - **解耦损失**：对比项（residual contrastive）+ 对抗互信息（MI）惩罚，迫使时间码携带模式信息、空间码携带任务信息。
- **Stage 2 行为克隆 Transformer**：
  - 编码器输入：双相机（俯视 + 腕部）ResNet-34 特征、当前本体感知、任务 ID 嵌入、连续运动模式标量嵌入；
  - 解码器：每个码本层一个分类头 + 连续偏移头（残差量化误差修正）；
  - 损失：交叉熵（码索引）+ L1（偏移头）；
- **推理**：任务 ID 选技能，$s$ 调制执行质量；使用 Zhao et al. 的时间聚合（temporal aggregation）策略对 50 Hz 执行稳定化。

## 三、实验设计

### 3.1 硬件与数据

- **硬件**：Interbotix X-Series 单臂 ALOHA leader-follower（WidowX-250 leader + ViperX-300 6-DOF follower），俯视固定相机 + 腕部相机（480×640），50 Hz；
- **动作块**：$T=100$（2 秒）；
- **任务集合（6 个）**：
  - **双模训练任务（4 个）**：pick、pour、look、avoid，每个任务 60 次示教（Mode A、Mode B 各 30 次）；
  - **单模迁移任务（2 个）**：push（仅 Mode B）、highfive（仅 Mode A），用于测试未示教模式的迁移能力；
  - 任务跨度涵盖精确操控（pick、pour、push）与非直接操控（look、avoid、highfive）；
- **初始条件**：物体位置固定在 ±5 cm 内；每条轨迹 16–20 s；
- **格式**：Robomimic HDF5 数据集，训练时 stride=10 子采样。

### 3.2 评估指标

- **客观动力学指标**：关节速度（rad/s）、关节加速度（rad/s²）、末端接近俯仰角（°，正向下）；
- **人类盲评**：3 名专家评估员对每个 rollout 视频独立打分（0–10）：
  - 风格贴合度（Mode B → Mode A）；
  - 任务完成度；
  - 盲评，评估者不知道请求的标量值，也不知道是否为迁移单元；
- **评估协议**：每个 (任务, 标量) 单元 $N=20$ 次 rollout；标量取 $s\in\{0.1, 0.5, 0.9\}$；
- **对比方法**：无明确 baseline 对比——核心为**自我消融/对比**（不同标量值、迁移 vs. 已训练），并辅以人类感知评估与潜在空间可视化；
- **潜在空间分析**：将 Stage 1 量化潜变量 $z_q^{sp}$、$z_q^{te}$ 经 PCA 投影，按任务与按标量着色可视化。

## 六、主要结论与发现

- **运动模式作为可复用行为因子**：调节连续标量 $s$ 在所有 6 个任务上产生稳定（Mode A）、动态（Mode B）及中间行为；
- **统计显著性**：所有 4 个已训练任务的动力学指标与 $s$ 呈强负相关（Spearman $\rho$ 在 $-0.88$ 到 $-0.94$ 之间，$p<10^{-6}$）；
- **迁移能力**：push（仅 Mode B）与 highfive（仅 Mode A）在未示教模式下能向请求方向移动动力学指标，且统计显著（$p<5\times 10^{-3}$）；任务完成度大体保持，仅 push 在 Mode A 接触阶段可靠性略降；
- **潜在空间结构**：$z_q^{sp}$ 主要按任务聚类、对模式不敏感；$z_q^{te}$ 形成清晰的 Mode B–Mode A 谱带、跨任务重叠；
- **OOD 模式组合的迁移机制**：空间码保持在任务聚类内，时间码移向请求模式区域；
- **人类感知**：所有任务上风格贴合度对 $s$ 单调，包括迁移任务；任务完成度近乎满分（除 push@Mode A）；
- **结论**：提供了**对未见任务-模式组合的有限但有意义的组合泛化证据**，表明运动模式可作为可复用的任务无关行为控制通道。

## 七、优点与亮点

- **架构创新**：双 RVQ 栈（空间/时间）+ DCT 输入的时间分支，构造性地将"几何"与"动态"分离到不同码本；
- **解耦目标设计精巧**：swap 损失（任务换模式）+ 对抗 MI + 对比损失联合推动潜空间解耦；
- **冻结 Stage 1 训练 Stage 2**：将策略学习问题降维为有限码空间的离散预测，降低优化难度并保留已学解耦；
- **运行时可控**：运动模式作为推理时输入，无需重训即可调节；
- **三重评估证据链**：客观动力学指标、潜在空间可视化、人类盲评三者互相印证；
- **真实机器人验证**：覆盖 6 个真实操控任务，包含 OOD 迁移场景；
- **可解释性**：潜在空间 PCA 直接展示任务与模式的分离结构，便于分析。

## 八、不足与局限

- **解耦不彻底（partially disentangled）**：运动模式仍有几何相关性（approach pitch 差异）被空间分支吸收；作者明确指出"motion mode does not live inside the temporal codebook alone"；
- **迁移幅度受限**：highfive 的短程空间几何限制了 Mode B 下能表达的速度上限；push 在未见 Mode A 下接触可靠性下降；
- **评估范围窄**：仅 1 个硬件平台、1 维标量、2 个原型模式、6 个任务；初始物体位置固定在 ±5 cm；
- **人类评估样本有限**：仅 3 名专家评估员，无普通用户；
- **统计规模**：$N=20$ rollout/单元在真实机器人中是常规但相对较小；
- **无 baseline 对比**：缺少与现有风格条件化操控方法（如 Neural Policy Style Transfer、constrained mode learning 等）的直接对比，削弱了对方法相对优势的论证；
- **行为因子维度受限**：1 维标量难以表达现实世界中丰富的运动模式；未来需要更高维度的行为因子与更强的交换监督；
- **任务-模式联合分布覆盖不足**：仅 4 个双模任务 + 2 个单模任务；更大任务分布才能更系统暴露组合泛化能力；
- **数据集规模小**：每任务 60 条轨迹，难以保证对真实世界复杂性的覆盖；
- **作者自我定位为"initial evidence"**，并不声称已实现完全解耦的表征。
