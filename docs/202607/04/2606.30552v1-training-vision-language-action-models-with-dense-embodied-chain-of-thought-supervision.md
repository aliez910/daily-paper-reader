## 摘要
视觉-语言-动作（VLA）模型中的跨实体迁移仍然具有挑战性，因为底层状态和动作空间在不同的机器人平台上存在根本性差异。我们观察到，操作背后的高层认知过程，包括场景感知、物体识别、任务规划和子任务分解，在不同实体之间很大程度上是共享的。基于这一观察，我们提出了ZR-0，一个26亿参数的端到端VLA模型，它使用密集的具身思维链（ECoT）监督来对齐视觉-语言模型（VLM）中的跨实体表示。ZR-0采用双流架构：一个预训练的VLM（系统2）在训练期间生成结构化的ECoT推理，而一个基于扩散Transformer的动作专家（系统1）通过流匹配产生连续的动作块。这两个组件通过交叉注意力耦合，注意力掩码将动作专家限制为仅输入提示特征，使得在推理时可以完全跳过ECoT生成而没有任何性能损失。ZR-0在ProcCorpus-60M上进行预训练，这是一个大规模数据集，包含来自超过40万条轨迹的约6000万帧（约1000小时），密集的ECoT注释覆盖了96.8%的所有帧。我们在三个仿真基准上评估了ZR-0，涵盖单臂（LIBERO）、双臂（RoboTwin 2.0）和人形机器人（RoboCasa GR-1 Tabletop）实体，以及在xArm平台上的真实世界实验，展示了在所有设置中的强劲性能。代码和模型检查点可在 https://github.com/RUCKBReasoning/ZR-0 获取。

## Abstract
Cross-embodiment transfer in vision-language-action (VLA) models remains challenging because low-level state and action spaces differ fundamentally across robot platforms. We observe that the high-level cognitive process underlying manipulation, including scene perception, object identification, task planning, and sub-task decomposition, is largely shared across embodiments. Based on this observation, we present ZR-0, a 2.6 billion parameter end-to-end VLA model that uses dense Embodied Chain-of-Thought (ECoT) supervision to align cross-embodiment representations within the vision-language model (VLM). ZR-0 adopts a dual-stream architecture: a pre-trained VLM (System 2) generates structured ECoT reasoning during training, while a Diffusion Transformer-based action expert (System 1) produces continuous action chunks via flow matching. The two components are coupled through cross-attention, with an attention mask that restricts the action expert to input prompt features only, enabling ECoT generation to be entirely skipped at inference without any performance loss. ZR-0 is pre-trained on ProcCorpus-60M, a large-scale dataset comprising approximately 60 million frames (approximately 1,000 hours) from over 400K trajectories, with dense ECoT annotations covering 96.8% of all frames. We evaluate ZR-0 on three simulation benchmarks spanning single-arm (LIBERO), bimanual (RoboTwin 2.0), and humanoid (RoboCasa GR-1 Tabletop) embodiments, as well as real-world experiments on the xArm platform, demonstrating strong performance across all settings. Code and model checkpoints are available at https://github.com/RUCKBReasoning/ZR-0.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：视觉-语言-动作（VLA）模型面临跨实体迁移的挑战——不同机器人平台的底层状态空间、动作维度、控制接口等差异巨大（如单臂与双臂、固定基座与移动基座、不同关节配置），使得直接在一个架构内训练多源数据时难以学到真正可迁移的表示。
- **观察与动机**：尽管底层状态/动作空间是实体特有的，但高层认知过程（场景感知、物体识别、任务规划、子任务分解等）在不同实体之间高度共享。因此，若能通过某种监督信号促使模型学习这种实体无关的推理能力，则有望实现有效的跨实体泛化。
- **整体含义**：该工作提出使用密集的具身思维链（Embodied Chain-of-Thought, ECoT）作为训练时的监督信号，以对齐不同机器人平台之间的表示，从而在不增加推理开销的前提下提升VLA模型的跨实体迁移能力。

## 2. 论文提出的方法论：核心思想、关键技术细节

- **模型架构**：ZR-0 是一个 2.6B 参数的端到端 VLA 模型，采用双流架构（System 1 / System 2 框架）：
  - **System 2（VLM）**：预训练的视觉-语言模型（基于 Qwen3-VL-2B-Instruct），输入任务指令和图像观测，在训练阶段生成结构化的 ECoT 推理序列（下一词预测）；其最后一层隐藏状态被提取，并通过交叉注意力传递给动作专家。
  - **System 1（动作专家）**：基于扩散 Transformer（DiT）的动作专家，接收 VLM 特征和机器人状态向量，通过流匹配（flow matching）直接输出连续动作块（动作序列 chunk）。
  - **耦合方式**：两者通过交叉注意力连接，且注意力掩码将动作专家限定为仅访问 VLM 对输入提示（任务指令与图像）的特征，禁止访问 ECoT 生成的 token。这使得推理时 VLM 只需一次前向传播即可提供动作专家所需的全部特征，完全跳过自回归的 ECoT 文本生成，无任何性能损失且不影响推理延迟（约 90ms 一个动作块）。
- **ECoT 组成**：每个帧的密集 ECoT 包含六个组件：
  1. **场景描述**（Scene Description）——提升物体识别能力。
  2. **进度评估**（Progress Assessment）——评估已完成的步骤与完成状态（Yes/No）。
  3. **未来规划**（Future Plan）——自由文本描述还需完成的事项。
  4. **To-Do 动作**（To-Do Actions）——将未来计划分解为原子式子任务列表（动词+宾语+介词短语），是跨实体对齐的关键组件。
  5. **目标物体**（Target Objects）——标注当前操作步骤相关物体的边界框。
  6. **离散动作**（Discrete Actions）——实体特定的离散动作令牌（FAST tokenizer 生成），作为高维推理与低维控制之间的桥梁。
- **训练目标**：同时对 VLM 进行下一词预测（ECoT）和整个模型进行流匹配动作损失（α=5 加权），其中 VLM 参数仅通过下一词预测损失更新，但动作损失也通过 VLM 特征反向传播。
- **推理流程**：从高斯噪声初始化动作块，通过 N 步欧拉迭代去噪得到预测动作块，执行后根据新观测重新规划。

- **评估基准**：

  - **RoboTwin 2.0**（双臂仿真，ALOHA 实体）：共 50 个任务，含清洁场景和域随机化场景（5 轴随机化）。
  - **RoboCasa GR-1 Tabletop**（人形机器人仿真，GR-1 实体）：共 24 个操作任务。
  - **真实世界 xArm**（单臂平台）：收集超过 2000 条遥操作轨迹，含 4 个任务（Push Blocks, Clean Table, Pick & Place, Hang Cups），>50 个物体。
- **对比方法**：

## 6. 论文的主要结论与发现

- 密集 ECoT 监督能有效对齐跨实体表示，训练后的 VLM 可以产生更有利于动作预测的特征。
- ZR-0 在三个仿真基准上均取得有竞争力甚至最优的结果：
  - LIBERO 平均 97.8%（超过 π0.5 的 96.9%、GR00T-N1.7 的 97.0%、MolmoAct2 的 97.2%）。
  - RoboCasa 平均 69.3%（超过 JoyAI-RA 的 63.2%，提升 6.1 分）。
  - RoboTwin 2.0 Clean 88.70% / Randomized 87.98%（与最好方法 Motus、LB-VLA 持平或略优，且随机化后性能下降最小）。
- 真实世界 xArm 平均任务评分 76.0，超过 π0.5 的 67.8；尤其在 Push Blocks 任务（需要 OCR 和精细操作）上提升显著（94.0 vs 66.1）。
- ECoT 在预训练数据中占比高的技能（如 pick-and-place）收益最大，而比例低的技能（如关闭柜门）泛化较弱。
- VL 数据共训练和 ECoT 监督有助于保持 VLM 的通用能力（如文本识别、场景理解），提升对新场景的鲁棒性。

## 7. 优点

- **创新性**：首次将密集具身思维链监督系统性地集成到 VLA 模型的双流架构中，在不增加推理代价的前提下实现跨实体表示对齐。
- **实用性**：ECoT 生成在训练时激活、推理时完全跳过，模型保持低延迟（~90-100ms/动作块），适合真实世界部署。
- **系统性实验**：涵盖单臂、双臂、人形仿真与真实平台，跨实体迁移效果得到全面验证；对比方法众多且结果具有统计意义（50-100 episodes/任务）。
- **开源贡献**：发布代码、模型权重和 ECoT 数据集 ProcCorpus-60M（部分数据标注方法来自 ProcVLM），有助于社区研究。
- **跨实体能力**：预训练后在多个不同实体（LIBERO、RoboTwin 2.0、RoboCasa、xArm）上仅需少量下游微调即可适应，验证了实体无关推理的有效性。

## 8. 不足与局限

- **实验局限**：
  - 消融实验仅针对 LIBERO 整体移除 ECoT，缺少对 ECoT 六个组件的独立贡献分析（如去掉 Target Objects 或 Progress Assessment 的影响）。
  - 未在真实多实体（如 bimanual 或 humanoid）上直接评估，只有单臂 xArm 真实实验，跨实体真实评估较弱。
- **数据规模与覆盖**：预训练数据仅约 1000 小时机器人数据，远小于领先工作（π0 >10k h, LingBot-VLA ~20k h）。在 RoboCasa 中，EcoT 不擅长的关闭类型任务（如关柜门）性能显著低于最好的 JoyAI-RA，反映出预训练数据技能覆盖不均。
- **精细控制局限**：在真实环境中 hang cups 任务上 ZR-0 不如 π0.5（70.0 vs 85.0），说明对需要高精度细粒度操作的任务，ECoT 推理带来的收益不如大规模动作数据。
- **算力报告不完整**：未给出完整训练 GPU 时数，不利于复现估算。
- **依赖外部批注管道**：ECoT 标注依赖专用 VLM 管道（ProcVLM），为其他团队应用该方法带来一定门槛和计算成本。作者也提到未来需探索更高效的标注策略（只标注关键帧）。
