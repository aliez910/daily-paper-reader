## 摘要
视觉-语言-动作（VLA）模型中的跨具身迁移仍然具有挑战性，因为低级状态和动作空间在不同机器人平台上根本不同。我们观察到操作背后的高级认知过程，包括场景感知、物体识别、任务规划和子任务分解，在很大程度上是跨具身共享的。基于这一观察，我们提出了ZR-0，一个26亿参数的端到端VLA模型，该模型使用密集具身思维链（ECoT）监督来对齐视觉-语言模型（VLM）中的跨具身表示。ZR-0采用双流架构：一个预训练的VLM（系统2）在训练期间生成结构化的ECoT推理，而一个基于扩散Transformer的动作专家（系统1）通过流匹配生成连续的动作块。这两个组件通过交叉注意力耦合，其中注意力掩码将动作专家限制为仅输入提示特征，从而可以在推理时完全跳过ECoT生成而不损失任何性能。ZR-0在ProcCorpus-60M上进行了预训练，这是一个大规模数据集，包含来自超过40万条轨迹的大约6000万帧（约1000小时），其中密集ECoT注释覆盖了96.8%的帧。我们在三个模拟基准上评估了ZR-0，涵盖了单臂（LIBERO）、双臂（RoboTwin 2.0）和类人（RoboCasa GR-1 Tabletop）具身，以及在xArm平台上的真实世界实验，展示了在所有设置中的强性能。代码和模型检查点可在https://github.com/RUCKBReasoning/ZR-0获取。

## Abstract
Cross-embodiment transfer in vision-language-action (VLA) models remains challenging because low-level state and action spaces differ fundamentally across robot platforms. We observe that the high-level cognitive process underlying manipulation, including scene perception, object identification, task planning, and sub-task decomposition, is largely shared across embodiments. Based on this observation, we present ZR-0, a 2.6 billion parameter end-to-end VLA model that uses dense Embodied Chain-of-Thought (ECoT) supervision to align cross-embodiment representations within the vision-language model (VLM). ZR-0 adopts a dual-stream architecture: a pre-trained VLM (System 2) generates structured ECoT reasoning during training, while a Diffusion Transformer-based action expert (System 1) produces continuous action chunks via flow matching. The two components are coupled through cross-attention, with an attention mask that restricts the action expert to input prompt features only, enabling ECoT generation to be entirely skipped at inference without any performance loss. ZR-0 is pre-trained on ProcCorpus-60M, a large-scale dataset comprising approximately 60 million frames (approximately 1,000 hours) from over 400K trajectories, with dense ECoT annotations covering 96.8% of all frames. We evaluate ZR-0 on three simulation benchmarks spanning single-arm (LIBERO), bimanual (RoboTwin 2.0), and humanoid (RoboCasa GR-1 Tabletop) embodiments, as well as real-world experiments on the xArm platform, demonstrating strong performance across all settings. Code and model checkpoints are available at https://github.com/RUCKBReasoning/ZR-0.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题**：视觉-语言-动作（VLA）模型在跨机器人平台迁移时面临根本性挑战——不同机器人的底层状态和动作空间（自由度、控制接口、传感器等）高度异构，现有方法主要靠零填充、逐本体归一化等格式层面对齐，但无法实现**语义对齐**，模型学到的大多是本体特定模式而非共享可迁移表示。
- **观察**：操作背后的**高层认知过程**（场景感知、物体识别、任务规划、子任务分解等）在不同本体之间是共享的。例如，拾取杯子这一动作无论机器人是6还是7自由度，其认知轨迹相似。
- **思想**：利用**密集的具身思维链（Embodied Chain-of-Thought, ECoT）监督**来强制VLM学习这种本体无关的高层推理，从而对齐跨本体表示，进而通过双流架构将表示映射到具体动作。
- **整体含义**：旨在构建跨本体通用机器人策略，通过结构化的推理监督打通异构动作空间的隔阂，实现更好的迁移和泛化。

## 2. 方法论

- **核心架构**：ZR-0（2.6B参数）采用**双流架构**，类似认知框架中的 System 1 / System 2：
  - **System 2**（VLM）：预训练自 Qwen3-VL-2B-Instruct，处理任务指令和图像，训练时生成结构化的ECoT序列（场景描述、进度评估、未来规划、子任务列表、目标物体边框、离散动作token）。
  - **System 1**（动作专家）：基于 Diffusion Transformer（DiT），接收VLM特征和机器人状态，通过流匹配（Flow Matching）直接预测连续动作块（chunk size H）。
- **耦合方式**：DiT块中采用**交叉注意力**，且**注意力掩码**限制动作专家仅关注VLM输入prompt（指令+图像）的特征，**屏蔽ECoT token**。这样一来，训练时ECoT提供丰富梯度信号，推理时可通过单次VLM前向传播获取所需特征，完全跳过ECoT自回归生成，不损失性能。
- **训练目标**：
  - ECoT生成：标准下一个token预测损失 \( \mathcal{L}_{\text{ntp}} \)（仅更新VLM参数）。
  - 连续动作预测：流匹配损失 \( \mathcal{L}_{\text{fm}} \)，模型学习从带噪动作去噪为真值动作向量场（联合更新VLM和动作专家）。
  - 总损失 \( \mathcal{L} = \mathcal{L}_{\text{ntp}} + \alpha \mathcal{L}_{\text{fm}} \)，权重α可调。
- **推理**：初始化高斯噪声，通过欧拉积分迭代去噪N步获取动作块。因注意力掩码设计，ECoT文本不生成，延迟低（约90-100ms）。
- **跨本体处理**：通过零填充将所有本体状态/动作维度统一到64维，损失掩码忽略填充维，并做分位数归一化。
