## 摘要
主流的视觉-语言-动作（VLA）模型主要基于当前观测在马尔可夫假设下预测动作，因此在处理长时序、依赖时间上下文的任务时表现欠佳。现有的记忆增强型 VLA 模型要么扩展观测窗口，要么从记忆库中检索历史信息作为策略侧的辅助上下文。然而，这些方法将记忆置于 VLA 推理的原生潜空间之外，导致历史经验无法与多模态推理及动作生成过程进行流畅的交织。为此，我们提出了 LaMem-VLA，一种潜记忆原生框架，将历史经验重构为潜记忆令牌，并将其与 VLA 推理直接交织在一起。LaMem-VLA 的核心包含四个协同的组件：（i）策展器，将历史经验组织为两个互补的短期与长期记忆库；（ii）寻访器，利用多模态认知查询两个记忆库，以检索与上下文相关的证据；（iii）凝缩器，将检索到的证据重构为紧凑的短期与长期潜记忆令牌；（iv）织合器，将这些记忆令牌与当前观测及指令融合为一个连续的嵌入序列。通过在同一个连续潜空间中完整地表征、检索和消费历史经验，LaMem-VLA 使记忆能够直接参与 VLA 推理，并在有界上下文条件下引导动作生成。在 SimplerEnv 和 LIBERO 上的大量实验验证了 LaMem-VLA 的优越性。

## Abstract
Mainstream Vision-Language-Action (VLA) models predict actions primarily from the current observation under a Markovian assumption, thus struggling with long-horizon, temporally dependent tasks. Existing memory-augmented VLAs either expand the observation window or retrieve history from the memory bank as auxiliary policy-side context. However, they leave memory outside the native latent embedding space of VLA reasoning, preventing historical experience from being fluidly interleaved with multimodal reasoning and action formation. To this end, we introduce LaMem-VLA, a latent-memory-native framework that reconstructs historical experience into latent memory tokens and directly interweaves them with VLA reasoning. At its core, LaMem-VLA introduces four coordinated components: (i) a curator that organizes historical experience into two complementary short-term and long-term memory vaults; (ii) a seeker that queries both vaults using the multimodal cognition to retrieve context-relevant evidence; (iii) a condenser that reconstructs the retrieved evidence into compact short-term and long-term latent memory tokens; and (iv) a weaver that injects these memory tokens with the current observation and instruction into one continuous embedding sequence. By representing, retrieving, and consuming historical experience entirely in the same continuous latent space, LaMem-VLA enables memory to directly participate in VLA reasoning and guide action generation under a bounded context. Extensive experiments on SimplerEnv and LIBERO demonstrate the superiority of our LaMem-VLA.

# LaMem-VLA 论文详细总结

## 一、核心问题与研究动机

- **马尔可夫假设的局限**：主流 VLA 模型（如 CogACT、π0、OpenVLA）仅基于当前观测 oₜ 与语言指令 I 预测动作，难以处理需要回顾历史状态、已完成子任务与任务进度的长时程操作任务，存在"时间短视偏差"（temporal short-horizon bias）。
- **现有记忆增强方法的不足**：
  - **时间上下文扩展路线**（如多帧拼接、视频扩展）：上下文长度固定，存在记忆上限，窗口外的关键证据被丢弃，计算开销随序列长度线性增长。
  - **稀疏历史抽象路线**（如循环隐状态、动作摘要）：过度抽象会丢失细粒度感知细节与高层语义。
  - **外部记忆库检索路线**（如 MemoryVLA、MemER）：历史记忆存储在 VLA 原生 token 空间之外，作为策略侧的辅助条件而非嵌入到 VLA 内部推理中，无法与多模态推理和动作生成流畅交织。
- **核心研究问题**：能否将机器人历史经验表示为"上下文原生"（context-native）的潜记忆令牌，使其存储、检索、消费全部发生在 VLA 同一连续嵌入空间中？

## 二、方法论

### 2.1 整体架构：四个协同模块

LaMem-VLA 基于 7B 参数 Prismatic VLM（DINOv2 + SigLIP + LLaMA-7B）+ ~300M 扩散动作专家构成，推理流程为：

```
当前观测 + 指令 → VLM 编码 → [策展 → 寻访 → 凝缩 → 织合] → 记忆增强序列 → 动作查询 → 扩散动作专家 → 动作块
```

### 2.2 四个核心组件

- **潜记忆策展器（Curator）**：将历史经验分解为两个互补的记忆库。
  - **短期记忆库 M_short**：存储当前回合的视觉感知证据。每个记忆单元 m^s = (k^s, v^s) 通过 SE-bottleneck 压缩模块 C_s 将视觉令牌 Xₜ 压缩为 N_s 个记忆令牌，均值池化作为检索键 k^s。
  - **长期记忆库 M_long**：存储每个时间步的动作隐藏状态 H^action，作为键-值对保存任务进度与动作连续性证据。
  - **更新策略**：当库容量超过 L=16 时，计算相邻键的余弦相似度，合并最相似的相邻对以减少冗余。

- **潜记忆寻访器（Seeker）**：基于多模态认知构建上下文查询 Q_t。
  - 在 VLM 输出中加入可学习查询槽 Q_init，通过轻量级查询构建器 B（带掩码注意力的两层 Transformer）得到查询令牌 Q_t ∈ ℝ^{K_q×C}。
  - 均值池化得到全局检索向量 q_t，使用 Top-K 余弦相似度从 M_short 和 M_long 中各检索 K=8 个相关单元，分别拼接为 Z_short 和 Z_long。

- **潜记忆凝缩器（Condenser）**：将检索到的证据压缩为固定长度令牌。
  - 引入可学习的短期视觉记忆槽 T_s ∈ ℝ^{L_s×C}（L_s=8）与长期语义记忆槽 T_l ∈ ℝ^{L_l×C}（L_l=4）。
  - 通过两个轻量级记忆形式器（memory former）F_v 和 F_c（类似 B 的两层 Transformer），结合 Q_t、检索证据与记忆槽，输出 M_short 与 M_long。
  - 关键属性：输出长度固定，与检索大小 K 无关，避免上下文无限膨胀。

- **潜记忆织合器（Weaver）**：将凝缩后的记忆令牌直接拼接到 VLA 输入序列中。

$$
S_t = [M^{short} + \mathbf{1}_{L_s}\mathbf{b}_s^\top;\, M^{long} + \mathbf{1}_{L_l}\mathbf{b}_l^\top;\, X_t;\, I;\, Q^{action}]
$$

  其中 b_s, b_l ∈ ℝ^C 为可学习的源嵌入（区分两种记忆流）。记忆令牌通过自注意力与当前观测、语言、动作查询交互，形成"记忆锚定的动作令牌" Z^action，而非外部拼接。

- **扩散动作专家**：将 Z^action 注入扩散条件，使用 DDIM 采样（10 步）生成 16 步长、7-DoF 末端执行器动作块，损失函数为噪声预测 MSE。

### 2.3 关键创新点

- 记忆完全在 VLA 原生嵌入空间中被表示、检索、消费；
- 短期视觉记忆 + 长期语义记忆互补，覆盖"看得见的细节"与"任务进度"；
- 固定长度接口使上下文预算可控，与检索量 K 解耦。

## 三、实验设计

### 3.1 数据集与 Benchmark

- **SimplerEnv-Bridge**（WidowX 机器人）：4 个任务（Spoon on Towel、Carrot on Plate、Stack Cube、Eggplant in Basket），使用 Bridge v2 数据集训练 50k 步。
- **LIBERO**（Franka 机器人）：5 个 suite — Spatial（10 任务）、Object（10 任务）、Goal（10 任务）、Long-10（10 任务）、Long-90（90 任务），按 OpenVLA 协议使用 50 个演示/任务。

### 3.2 对比方法（≥18 种）

- 通用策略：Diffusion Policy、Octo；
- VLA 模型：RT-1-X、OpenVLA、TraceVLA、SpatialVLA、Magma、CogACT、π0、π0-FAST、DreamVLA、ThinkAct、CronusVLA、SemanticVLA、CoT-VLA、UniACT、LARA、Fast-ThinkAct；
- 记忆增强 VLA：MemoryVLA。

### 3.3 主要实验结果

- **SimplerEnv-Bridge**：LaMem-VLA 平均成功率 73.9%，比 CogACT 高 16.6 点，比 π0 高 4.7 点，比 MemoryVLA 高 2.0 点；在 Spoon on Towel（83.3%）、Stack Cube（41.7%）单任务上最优。

## 六、主要结论

- LaMem-VLA 通过将历史经验重构为潜记忆令牌并直接编织进 VLA 推理序列，可显著缓解时间短视偏差；
- 短期视觉记忆与长期语义记忆具有互补性，移除任一流都会导致性能下降；
- 潜空间原生集成优于"外部条件"或"原始检索拼接"两种基线；
- 在两个主流 benchmark 上达到 SOTA，尤其在长时程任务上提升明显。

## 七、优点与亮点

- **范式新颖**：提出"context-native latent memory"概念，将机器人记忆从策略侧外挂转化为 VLA 内部原生上下文，思路具有范式意义；
- **双尺度记忆设计**：短/长期记忆在来源和功能上互补，统一用潜令牌形式表征，结构清晰；
- **固定长度接口**：凝缩器使记忆注入不随检索量增长，避免上下文爆炸；
- **强实证结果**：在 SimplerEnv 和 LIBERO 两个 benchmark 上均显著超越 MemoryVLA、CogACT、π0 等强基线；
- **消融充分**：四组消融从记忆内容、消费路径、检索预算、令牌数量多角度验证设计合理性；
- **可视化直观**：提供了框架总览图与范式对比图，便于理解。

## 八、不足与局限

- **仅仿真验证**：作者明确承认当前仅在 SimplerEnv 和 LIBERO 仿真环境中验证，**尚未提供真实机器人实验结果**（计划在下一版本补充）；
- **输入模态受限**：仅使用单张第三人称 RGB，相比 CogACT、π0-FAST 等带本体感知和腕部摄像头的基线，输入信息更少，跨方法比较可能不完全公平；
- **检索离散不可微**：Top-K 检索操作不可通过梯度优化，可能影响端到端训练的最优性；
- **长期记忆简单堆叠**：M_long 仅按时序追加动作隐藏状态，缺乏语义压缩或层级化结构，长 episode 时容量压力可能显现；
