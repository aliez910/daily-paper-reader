## 摘要
世界动作模型（WAMs）通过将基于视频的世界建模作为机器人动作学习的密集监督，提供了一种有前景的视觉-语言-动作（VLA）策略替代方案。现有的WAMs擅长物理层面的执行，但通常缺乏基于VLM的VLA中显式的语言级规划接口，无法对粗粒度指令进行分解。当家务任务涉及复杂的多步骤目标时，这种分解尤为重要，因为粗粒度的用户指令需要被转换为一系列细粒度的可执行子任务。同时，由于现有系统在数据、机器人本体和任务协议上往往存在差异，该领域仍缺乏VLA与WAM执行能力之间的公平真实机器人比较。为了同时解决分解缺口和实现受控的WAM-VLA比较的需求，我们提出了DSWAM，一种用于细粒度机器人操作的双系统世界动作基础模型。DSWAM将系统1的WAM执行器保留为默认控制路径，并在任务分解有用时选择性地激活系统2的视觉-语言子任务规划器。规划器根据短期视觉历史和全局任务提示预测可执行子任务，而WAM执行器为每条指令或子任务进行具备世界感知能力的动作生成。执行器通过动作预测和视频联合训练，但推理时直接预测动作块，无需显式的未来视频生成。为了使该执行路径在实际机器人上实用，我们进一步集成了TensorRT加速、异步执行和实时分块（RTC），以确保策略查询不会阻塞机器人控制。为了与VLA策略进行公平的真实机器人比较，我们在DeMaVLA真实世界可形变操作设定下构建并评估DSWAM，匹配了机器人平台、预训练数据、后训练数据和评估标准。

## Abstract
World Action Models (WAMs) provide a promising alternative to Vision-Language-Action (VLA) policies by using video-based world modeling as dense supervision for robot action learning. Existing WAMs excel at physically grounded execution, but typically lack the explicit language-level planning interface in VLM-based VLAs for decomposing coarse instructions. Such decomposition becomes important when household tasks involve complex multi-step goals, where coarse user commands need to be converted into sequences of fine-grained executable subtasks. Meanwhile, the field still lacks a fair real-robot comparison between VLA and WAM execution capabilities, since existing systems often differ in data, robot embodiments, and task protocols. To address both the decomposition gap and the need for a controlled WAM-VLA comparison, we introduce DSWAM, a Dual-System World Action Foundation Model for fine-grained robot manipulation. DSWAM keeps a System 1 WAM executor as the default control path and optionally activates a System 2 vision-language subtask planner only when task decomposition is useful. The planner predicts executable subtasks from short-term visual history and a global task prompt, while the WAM executor performs world-aware action generation for each instruction or subtask. The executor is trained with action prediction and video co-training, but inference directly predicts action chunks without explicit future video generation. To make this execution path practical on real robots, we further integrate TensorRT acceleration, asynchronous execution, and real-time chunking (RTC) so that policy queries do not block robot control. To provide a fair real-robot comparison with VLA policies, we build and evaluate DSWAM under the DeMaVLA real-world deformable manipulation setting with matched robot platform, pretraining data, post-training data, and evaluation criteria.

# 论文总结：DSWAM——用于细粒度机器人操作的双系统世界动作基础模型

## 1. 核心问题与研究动机

- **世界动作模型（WAMs）的局限性**：现有 WAM 通过视频世界建模获得物理执行能力，但缺乏视觉-语言模型（VLM）式 VLAs 显式的**语言级规划接口**，难以将粗粒度指令分解为可执行子任务。当家务任务涉及多步骤目标时，仅靠物理执行不够。
- **WAM 与 VLA 公平比较的缺失**：现有真实机器人对比常因数据来源、机器人本体（embodiment）和评估协议的差异而失公允，难以判断性能差异究竟来自策略设计还是实验设置。
- **部署效率问题**：基于视频的 WAM 推理常需显式生成未来帧，计算开销大，可能阻塞低延迟机器人控制回路。
- **核心目标**：同时解决"分解缺口"与"受控 WAM-VLA 对比"两大问题。

## 2. 方法论

### 2.1 整体架构：双系统设计
- **System 1（WAM 执行器，默认路径）**：基于多视角图像、语言指令与本体感知预测连续动作块（action chunks）。
- **System 2（可选视觉-语言子任务规划器）**：仅在粗指令需要分解时激活，基于短期视觉历史和全局任务提示生成有序子任务。

### 2.2 关键技术细节

- **观测输入定义**：
  - $O_t = [I^1_t, I^2_t, I^3_t, \ell_t, q_t]$，其中 $\ell_t$ 为原始指令或当前 System 2 子任务。
  - 输出动作块：$A_t = [a_t, a_{t+1}, ..., a_{t+H-1}]$，$H$ 为动作时域。

- **System 2 规划器（Rynnbrain4B 风格 VLM）**：
  - 输入：5 帧短期视觉历史 $X_t$（1 Hz 采样）+ 全局任务提示 $p$。
  - 输出下一条子任务：$s_t = P_\phi(X_t, p)$。
  - 训练监督使用**转换感知（transition-aware）标注**：每个窗口对应 $s_k$、$s_{k+1}$ 或 `done`，并在子任务边界处显式监督"切换至下一指令"。
  - 损失函数：自回归语言建模损失 $L_{plan}(\phi) = -\mathbb{E}[\log P_\phi(y_t | X_t, p)]$。
  - 部署时每 $\Delta t = 2s$ 向 System 1 推送一次更新的子任务。

- **System 1 WAM 执行器**：
  - 共享流匹配（flow matching）公式同时建模**动作**和**未来视频潜变量**：$y^\tau = (1-\tau)y + \tau\epsilon$，速度场损失 $L_{FM}(y)$。
  - 总损失：$L = L_{act} + \lambda_{vid} L_{vid}$。
  - **关键设计**：训练时使用视频潜变量提供世界建模监督，但**动作分支以当前观测为条件（不使用未来视觉作为特权信息）**，与推理时设定一致。
  - 推理直接预测动作块，不做显式未来视频生成。

- **推理部署加速**：
  - **实时分块（RTC）**：策略 worker 异步预测下一动作块，控制器继续执行当前块，策略延迟不阻塞机器人控制。
  - **TensorRT 加速（BF16）**：将执行路径拆为"视觉上下文引擎"和"动作去噪引擎"两个子图，预处理/VAE 等保留 PyTorch 处理以维持服务接口一致性。
  - 保持与 PyTorch 参考的近端端到端一致（最大相对误差 0.0106，余弦相似度 0.99977）。

## 3. 实验设计

- **System 2 消融任务**：真实桌面分拣，`Sort objects on the table` 粗指令，对比"原始指令训练"与"子任务级指令训练"。

## 6. 主要结论与发现

- **真实机器人折叠**（WAM-only 模式）：平均成功率从 DeMaVLA 的 92.5% 提升到 **96.3%**，平均完成时间从 2'18'' 缩短到 **1'44''**；相对 $\pi_0$ 提升 +20 pp，时间减少 42 秒。
- **RoboTwin 2.0**：clean **92.38%** 与 randomized **91.90%** 平均 SR，居全部比较方法首位；较 DeMaVLA 在两设置上分别提升 3.96 / 5.12 pp，较 Fast-WAM 仍提升 0.50 / 0.12 pp。
- **System 2 子任务监督**：分拣任务上 SR 从 75.7% 提升到 100%，每次 rollout 错误数从 3.53 降至 0.65，验证了"分解能带来稳定性增益"的前提。
- **部署效率**：TensorRT BF16 将策略推理延迟从 198.2 ms 降至 73.8 ms（**2.69× 加速**），异步 TensorRT+RTC 在裤子上将 SR 从 70% 提到 100%，且平均成功时间更短。

## 7. 优点

- **双系统设计理念清晰**：将"语义任务组织"与"世界感知物理执行"解耦，避免规划在原子任务上的强制开销。
- **公平真实机器人对比**：与 DeMaVLA 同基准、同数据、同协议的受控比较是该领域罕有且有价值的贡献。
- **训练-推理一致性**：动作分支不被未来帧作为特权信息，避免"训练捷径"。
- **不显式生成未来帧 + TensorRT + 异步 RTC**：在不牺牲世界建模训练监督前提下显著降低部署延迟。
- **同时报告多层结果**：仿真、真实机器人、消融、工程性能，较完整支撑了方法实用性主张。
