## 摘要
机器人操控的统一模型旨在为单一策略同时赋予预训练视觉语言模型的语义先验以及通过未来预测习得的物理动力学。然而在实际中，现有设计往往削弱预训练骨干网络的语义表征，遭受异质目标之间的相互干扰，并在像素空间中从零学习未来预测，导致预训练视频生成器的动力学先验未能得到利用。我们提出 InternVLA-A1.5，其以原生 VLM 骨干网络构建策略，持续在视觉问答（VQA）与子任务预测任务上训练，并附加一个轻量级统一专家用于连续动作生成。未来预测被重新表述为一个潜在查询问题：一小组可学习的预见 token 在冻结的预训练视频生成模型监督下，将任务相关的未来压缩为紧凑的潜在编码，从而使策略无需学习像素级生成即可继承世界模型的动力学先验。推理阶段舍弃视频分支，以保持实时控制。InternVLA-A1.5 在 1.2M 机器人轨迹与 3M 多模态样本上进行预训练，在全部六个仿真基准上取得了最佳综合成绩。在真实世界中，所保留的语义能力在未见指令绑定组合上展现出最强的组合泛化性能，而这两项设计共同支撑了长时序任务的稳定执行。

## Abstract
Unified models for robot manipulation aim to equip one policy with both the semantic priors of pretrained VLMs and the physical dynamics learned through future prediction. In practice, existing designs tend to erode the semantics of the pretrained backbone, suffer interference among heterogeneous objectives, and learn future prediction from scratch in pixel space, leaving the dynamics priors of pretrained video generators unexploited. We present InternVLA-A1.5, which builds the policy on a native VLM backbone that keeps training on VQA and subtask prediction, and attaches a lightweight unified expert for continuous action generation. Future prediction is recast as a latent-querying problem, where a small set of learnable foresight tokens condenses the task-relevant future into a compact latent code under the supervision of a frozen pretrained video generation model, so the policy inherits world-model dynamics priors without ever learning pixel-level generation. The video branch is discarded at inference, keeping real-time control. Pretrained on 1.2M robot episodes and 3M multimodal samples, InternVLA-A1.5 achieves the best overall results on all six simulation benchmarks. In the real world, the preserved semantics deliver the strongest compositional generalization on held-out instruction bindings, and the two designs together sustain long-horizon execution.

# InternVLA-A1.5 论文总结

## 1. 核心问题与整体含义（研究动机与背景）

- **研究目标**：为通用机器人操控构建一个**统一策略**，同时具备以下两类先验：
  - **语义先验**：来自预训练视觉语言模型（VLM）的物体、指令与空间理解能力。
  - **动力学先验**：来自世界/视频生成模型的物理演化能力（便于推理未来状态）。
- **现有方法的三大痛点**：
  - **语义侵蚀**：在策略训练中加入生成与动作目标后，VLM 的 VQA、指令跟随能力逐渐退化。
  - **目标异构相互干扰**：连续动作的 flow matching、未来视觉回归、离散语言建模等目标形式与尺度不同，joint training 时互相牵制。
  - **像素级未来预测从零学习**：未利用预训练视频生成模型中的时空动力学先验，重新从零学习像素重建。
- **整体含义**：在不牺牲语义能力、不付出像素级生成代价的前提下，把"动力学先验"以**紧凑潜在编码**的形式注入到策略中，使单一模型同时胜任理解、前瞻与动作生成。

## 2. 方法论：核心思想、关键技术细节与流程

### 2.1 整体架构（Mixture-of-Transformers, MoT）

- **VLM 骨干**：Qwen-3.5 2B，采用混合注意力（3 层 Gated DeltaNet 线性注意力 + 1 层 Full Attention）。
- **统一专家（Unified Expert）**：460M 参数，与 VLM 同构但隐藏维度更小，仅通过共享 Full Attention 层与 VLM 交互；Gated DeltaNet 层各自独立用于模态特化处理。
- **推理时丢弃视频分支**，仅保留 VLM + 统一专家，单步推理约 0.1s（RTX 5090）。

### 2.2 输入与输出设计

- **输入**：K 视角图像 $o_t$、语言指令 $l$、控制模式 $m \in \{\text{joint},\text{end\_effector},\text{vqa}\}$、离散化本体状态 $q_t$。
- **输出**（统一专家）：
  - **预见 token（Foresight tokens）**：$M=50$ 个可学习 latent queries。
  - **动作查询 token**：通过 flow matching 头解码连续动作块。

### 2.3 训练三阶段

- **Stage 1 — VLM Transfer**：
  - 在机器人轨迹 + VQA 数据上联合训练，统一用 next-token 交叉熵。
  - 关节态分桶（256 bins），动作通过 FAST tokenizer 编码为 2048 大小的动作词表，append 到原 VLM 词表。
  - 标签序列为 `<SubTask, FAST Action>` 或仅 `<Answer>`，共享同一交叉熵损失。
- **Stage 2 — 预见与动作生成**：
  - 引入统一专家与可学习预见 token。
  - 视频分支（WAN2.2-5B）冻结；用统一专家输出的条件 $C_f^t$ 替换 T5 文本编码器，作为 cross-attention 条件。
  - 视频监督采用 flow matching 损失（与 WAN 一致），梯度**仅回传至预见 token 和上游专家层**。
  - 动作采用 flow matching 头，$K$ 步 Euler 积分生成连续动作块。
- **Post-training**：同 Stage 2，可选启用视频分支微调预见 token。

### 2.4 核心公式

- **分解的联合分布**：
$$\pi_\theta(a_{t:t+H}, \hat{\ell} \mid o_t, \ell) = \pi_\theta(a_{t:t+H} \mid o_t, \hat{\ell})\, \pi_\theta(\hat{\ell} \mid o_t, \ell)$$

- **预见条件提取**：
$$Z_f^t = \Phi_\theta([H_t; Q_f])_F,\quad C_f^t = P_{\text{WAN}}(Z_f^t)$$

- **视频监督（flow matching）**：
$$L_{\text{video}} = \mathbb{E}\|u(x_s, C_f^t, s) - v_s\|^2$$
其中 $x_s = (1-s)x_0 + s x_1$，$v_s = x_1 - x_0$。

- **动作预测（flow matching）**：
$$L_{\text{action}} = \mathbb{E}\|v_\theta^{\text{act}}(a_\tau, H_t, Q_f) - (a_{t:t+H} - \epsilon)\|^2$$
其中 $a_\tau = (1-\tau)\epsilon + \tau\, a_{t:t+H}$，$\tau \sim \text{Beta}(1.5, 1.0)$。

- **Stage 2 总损失**：
$$L_{\text{stage2}} = L_{\text{stage1}} + \alpha L_{\text{video}} + \beta L_{\text{action}}, \quad \alpha=1,\ \beta=10$$

### 2.5 注意力掩码设计

- **VLM 部分**：保持 Qwen3.5 因果注意力。
- **统一专家部分**：分组因果（预见 token 看不到 FAST 动作 token；动作 token 可看到 VLM 上下文与预见 token），组内双向（适配 flow matching 的并行去噪）。
- 训练时显式屏蔽 expert 对 FAST token 的注意力，避免信息泄漏与梯度干扰；位置 id 在训练/推理时保持一致。

## 6. 主要结论与发现

- **仿真**：在全部 6 个 benchmark 上取得最佳或并列最佳：
  - SimplerEnv 80.8%（较 $\pi_{0.5}$ +23.7）；
  - LIBERO 98.9%；LIBERO-Plus 84.8%（零样本，鲁棒性最强）；
  - RoboTwin 93.2%（Clean 93.3 / Rand 93.0，几乎无退化）；
  - DOMINO 零样本 27.7 SR / 39.8 MS；
  - EBench Test 35.2% SR。
- **真实世界**：
  - Insert Tubes、Move Tubes、MOF 三项最佳；
  - Sort Tubes 仅略低于 $\pi_{0.5}$（75.9 vs 77.8），但 OOD 绑定上显著领先。
  - 长时序 MOF：76.4% vs $\pi_{0.5}$ 29.3% vs Motus 0%。
- **两条设计经验**：
  - **Prompt 设计重要**：把状态、控制模式、动作统一为 VLM 原生 chat template + 单一 next-token 损失，可显著稳定训练并迁移语义能力。
  - **未来预测不需要像素级生成**：少量 latent tokens 即可压缩未来信息，让"学到要想象什么"与"世界模型已知世界如何演化"解耦，成本远低于直接建模视频。
- **消融发现**：去掉视频监督或预见 token，在零样本与动态任务上下降最大（DOMINO、LIBERO-Plus），证明预见机制对分布外与动力学敏感场景尤为关键。
- **训练效率**：相同 SFT 设置下收敛更快、最终损失更低，预训练提供了更友好的下游优化 landscape。
- **世界模型利用**：冻结 WAN 即可在预见 token 条件下生成时序一致、物理合理的未来帧（含液体液面变化等因果效应），且在零样本下亦稳定。

## 7. 优点（方法与实验亮点）— 续

- **架构设计**：
  - 真正的 MoT 结构，仅通过共享的 Full Attention 层进行模态交互，避免了主流 VLA 在 VLM 末端"加 MLP/Adapter"导致的语义侵蚀。

  - 混合注意力（Gated DeltaNet + Full Attention）兼顾长上下文效率与跨模态对齐质量。

- **训练范式**：
  - 多阶段解耦使各目标在自己的优化区间内稳定收敛，避免异构目标直接对抗。
  - 视频梯度仅回传至预见 token，既保留了世界模型先验，又不会污染语言与动作能力。
  - FAST 离散动作 + flow matching 连续动作双轨并存，覆盖分类/回归两类下游需求。

- **数据与采样**：
  - 仿真与真实数据 46%:54% 配比，且通过 Re-Mix 重加权平衡多源分布，减少大源数据"淹没"小源数据。

  - 与十余个近期开源或商用 VLA 同台对比，包含 InternVLA-M1 / A1 自身消融版本，验证代际提升。

## 8. 局限性与未来工作

- **预见时间跨度受限**：
  - 当前前瞻只覆盖单个动作块（horizon=H 的短窗口），无法建模跨越多个动作块的远期后果；
  - 仅在动作 chunk 内部做"想象—动作"耦合，缺少对更长任务的显式 planning（如 sub-goal / option 级 rollout）。

- **视频生成器先验封顶**：
  - WAN2.2-5B 全程冻结，其内含的物理与物体动力学知识上限即模型的上限；
  - 论文承认对训练分布外或训练视频模型未充分见过的物理现象（如新型工具、特殊流体），预见分支难以补足。

- **潜在 token 设计空间未充分探索**：
  - 预见 token 数量 M=50、统一专家 460M 容量是经验性选择，未做系统消融；
  - 未探索更激进的 token 压缩（如 M=8/16）或更细粒度的 per-frame 条件。

- **视频分支不可用与未见模态未对齐**：
  - 推理时直接丢弃视频模型，但对未见过的相机视角、特殊光照、强反光/透明物体的零样本泛化仍依赖冻结视频模型的覆盖；
  - 长视频/高分辨率场景下 latent token 携带信息可能不够。

- **消融范围较窄**：
  - 仅消融了"视频损失有无"与"预见 token 有无"两个维度，未消融：
    - $\alpha, \beta$ 损失权重；
    - 统一专家容量与混合注意力比例；
    - 不同视频骨干对零样本动态任务的影响；
    - 多模态共训练比例（0.15:0.85）的敏感性。

- **数据规模与覆盖**：
  - 1.2M episodes / 861M 帧虽大，但 AgiBotWorld 等真实数据在任务多样性、物体多样性上仍偏单一实验室环境；
  - 移动操控（EBench）和动态操控（DOMINO）任务数相对较少，泛化结论尚需更大规模验证。

- **真实世界评测规模**：
  - 每个真实任务仅跑数十至上百次 trial，未报告标准差与置信区间；
  - 未做跨地点、跨硬件平台、跨天气的鲁棒性测试，对真实部署的可靠性论证偏弱。

- **失败案例分析不足**：
  - 缺少对失败模式（如动作卡死、物体跌落、语言误匹配）的系统化分类与归因；
  - 未分析"视频分支冻结但动作分支更新"之间可能产生的"想象与执行不一致"现象。

- **未来工作方向（论文暗示 + 自然延伸）**：
  - **扩大预见 horizon**：将单个动作块的预见扩展为可滚动的多 chunk 想象链；
  - **稀疏/选择性视频微调**：仅在罕见或新出现的场景下解冻视频模型子模块；
  - **更轻量的 latent 表达**：例如用 per-frame latent 而非单一 chunk latent，提升条件粒度；
  - **任务级规划与策略级控制的解耦**：在 VLM 内部生成 sub-task plan，外部由统一专家负责闭环控制；
  - **跨具身迁移**：将 MoT 架构与潜在预见机制迁移到不同本体（人形、四足、灵巧手）；
  - **安全性与可解释性**：将预见 token 解码为可读的未来语义（如"物体将下落至桌面"），用于人机协作时的意图沟通。
