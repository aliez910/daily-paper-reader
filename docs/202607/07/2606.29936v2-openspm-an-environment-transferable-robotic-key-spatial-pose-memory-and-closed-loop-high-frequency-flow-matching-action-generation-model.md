## 摘要
开放环境下的桌面机器人操控要求系统具备语义理解、精确的几何位姿估计和高频动作生成能力。虽然端到端的视觉-语言-动作（VLA）模型在语义泛化方面表现出色，但它们往往缺乏细粒度任务所需的显式几何约束，且训练成本高昂。为弥合高层语义与底层物理执行之间的鸿沟，我们提出了OpenSPM，一种开放环境空间持久记忆框架，由空间位姿记忆和流匹配动作生成模型组成。OpenSPM首先利用语义条件化的3D感知和卡尔曼滤波来跟踪连续的6D位姿。然后，它从人类示教中提取关键空间位姿，将其保存为可迁移的、以物体为中心的空间持久记忆条目。在推理阶段，OpenSPM根据自然语言指令检索相关的记忆条目，利用SE(3)变换将空间位姿迁移到新场景，并通过轻量级条件流匹配模型生成高频动作块。结合实时本体感受状态反馈和终端残差校正，该系统有效抑制了轨迹误差累积。在十个LIBERO-GOAL任务上的评估中，OpenSPM达到了85.6%的成功率和等效1033.3 Hz的控制频率，同时所需的推理AI计算能力极小。大量消融实验表明，结构化的空间持久记忆和闭环残差校正在可靠的高频机器人操控中起着关键作用。

## Abstract
Open-environment tabletop robotic manipulation requires systems to possess semantic understanding, precise geometric pose estimation, and high-frequency action generation. While end-to-end vision-language-action (VLA) models excel at semantic generalization, they often lack explicit geometric constraints for fine-grained tasks and require costly training. To bridge the gap between high-level semantics and low-level physical execution, we propose OpenSPM, an open environment spatial persistent memory framework consisting of spatial pose memory and flow-matching action generation model. OpenSPM first leverages semantically conditioned 3D perception and Kalman filtering to track continuous 6D poses. It then extracts key spatial poses from human demonstrations, keeping them as transferable, object-centric spatial persistent memory entries. During inference, OpenSPM retrieves relevant memory entries in terms of natural language instructions, transfers the spatial poses to new scenes using SE(3) transformations, and generates high-frequency action chunks via a lightweight conditional flow-matching model. Combined with real-time proprioceptive state feedback and terminal residual correction, the system effectively suppresses trajectory error accumulation. Evaluated on ten LIBERO-GOAL tasks, OpenSPM achieves an 85.6% success rate and an equivalent control frequency of 1033.3 Hz, while requiring minimal inference AI computing power. Extensive ablations illustrate that structured spatial persistent memory and closed-loop residual correction play a crucial role in reliable, high-frequency robotic manipulation.

- **整体含义**：为了桥接高层语义理解与低层物理执行之间的鸿沟，需要一种能够将语义信息与可迁移、以物体为中心的几何先验结合起来的框架。OpenSPM 提出通过关键空间位姿记忆作为中间表示，将长程示教压缩为阶段级别的相对位姿，再利用轻量级流匹配模型在线生成高频动作，从而在保证几何精度的同时实现高效的少样本操作。

## 2. 方法论：核心思想、关键技术细节与算法流程

- **核心思想**：
  - 将操作问题分解为四个阶段：语义 3D 感知 → 结构化关键位姿记忆构建 → 相对位姿迁移 → 局部动作生成与闭环执行。
  - 关键位姿（如接近、抓取、提升、放置前对齐、释放）以相对于目标物体的 SE(3) 相对位姿形式存储，利用 SE(3) 变换在不同场景间迁移，保持局部交互几何不变。
  - 使用条件流匹配模型仅在相邻关键位姿之间生成短时动作块（chunk），避免长程动作预测中的误差累积。
- **关键技术细节**：
  - **语义条件化 3D 感知**：
    - 级联结构：多视图 2D 语义分割（基于 SAM / Qwen3-VL）→ 3D 重建（SAM 3D）→ 卡尔曼状态估计。
    - 将目标物体的 6D 位姿视为状态空间问题，利用卡尔曼滤波进行预测和更新，减少观测抖动，输出连续、尺度一致的位姿。
    - 状态向量包含位置、线速度、局部朝向误差、角速度；观测协方差由分割置信度、掩码面积、多视图一致性等动态确定。
  - **关键空间位姿记忆库**：
    - 从示教轨迹中提取关键位姿，依据三类证据：夹爪状态变化、末端速度/朝向骤变、多模态模型（Qwen3-VL）对阶段语义的判断。
    - 每条记忆条目 `M_i` 包含检索键（操作类型、物体、阶段结构）、语义描述、一系列以物体为锚点的相对位姿 `ΔT_{o→e}`（即 `wT_o^{-1} * wT_e`）、阶段标签、置信度、质量评分等。
    - 在线检索时，结合语义匹配度、场景几何一致性、历史成功率来选取最合适的记忆。
  - **相对位姿迁移**：
    - 假设示教场景和测试场景下的目标物体位姿满足刚性变换关系 `G ∈ SE(3)`，则利用 `{\hat{w}T'}_{e,j} = {\hat{w}T'}_o * ΔT_{o→e,j}` 进行迁移，保持局部相对位姿不变（定理 1 证明一致性）。
    - 迁移后执行可达性、位姿突跳、最小距离检查。
  - **条件流匹配动作生成**：
    - 模型输入条件 `c_t` = (当前实际夹爪位姿, 下一个目标关键位姿, 相对误差, 进度指示)。
    - 训练：在相邻关键位姿之间的真实动作片段上，从噪声到数据构造线性插值路径，学习条件速度场 `v_θ`，损失为 MSE。
    - 推理：从高斯噪声开始，沿速度场 ODE 积分 H=5 步，输出动作块。
    - 模型参数仅 240K，轻量 MLP，适合高频调用。
  - **闭环执行与终端残差校正**：
    - **段间闭环**：每个动作块开始时，使用实时读取的夹爪位姿重新构建条件，而不是用规划的理想起点。
    - **终端残差校正**：在抓取、放置等关键节点附近，如果当前位置与目标关键位姿的偏差超过阈值，则基于当前状态重新生成校正动作块，直到收敛或达到最大迭代次数。
- **算法流程（文字描述）**：
  1. 离线阶段：从人类示教中，利用 3D 感知和语义分析提取多阶段关键位姿，计算相对于锚定物体的相对位姿，存入记忆库。
  2. 在线阶段：
     - 根据自然语言指令检索记忆库，获取匹配的记忆条目。
     - 通过当前场景的 3D 感知估计目标物体位姿，按 SE(3) 变换将关键位姿迁移至新场景。
     - 对于相邻关键位姿之间的段，使用条件流匹配模型生成动作块（H=5）。
     - 执行时，每块开始前读取实际状态更新条件；在关键节点处进行残差校正。重复直至任务完成。

## 6. 主要结论与发现

- OpenSPM 在 LIBERO-GOAL 上达到 **85.6% 的成功率**，同时实现 **等效 1033.3 Hz 的控制频率**，远超对比基线。
- 流匹配模型仅 240K 参数，推理延迟 4.8 ms，远低于其他 VLA 和扩散策略，适合高频实时控制。
- **关键结构化解耦有效**：将语义理解、几何记忆、局部动作生成分离，使每个子问题复杂度大幅降低。
- **验证了各个模块的不可或缺性**：
  - 移除结构化记忆库后，成功率从 85.6% 骤降至 23.8%，说明显式几何先验的不可替代性。

- 卡尔曼估计在 10 个任务上平均位置 MAE 5.8 mm，朝向 MAE 2.12°，能以低计算成本提供稳定的位姿。

## 7. 优点

- **显式几何记忆**：以物体为中心的相对位姿表示，天然具备场景可迁移性，且为关键物理交互提供刚性几何约束。
- **轻量且高频**：流匹配模型仅 240K 参数，动作块生成高效，无需 GPU 级算力即可维持千赫兹等效频率，适合实时控制。
- **模块化设计**：视觉感知、记忆检索、动作生成各模块可独立改进；无需端到端重训即可适应新任务或新场景。
- **有效的闭环机制**：段间状态反馈 + 终端残差校正，有效防止误差跨段累积，显著提高成功率。
- **充分的理论支撑**：定理 1 证明了相对位姿迁移的几何一致性；推导了误差传播模型，为设计闭环控制提供理论依据。

## 8. 不足与局限

- **感知依赖初值质量**：关键位姿提取和迁移依赖初始的 2D 分割与 3D 重建效果；对于严重遮挡、视觉相似物体、对称物体等场景，位姿估计可能失效，导致记忆检索或迁移偏离。
- **操作容差局限**：细长物体、支撑区域窄的物体等操作容差极小，即使经过残差校正，厘米级动作误差仍可能引发失败。
- **仿真环境局限**：实验仅在 LIBERO 模拟 benchmark 上进行，未在真实机器人上部署验证；模拟环境中物理引擎的简化可能导致实际迁移时的效果打折扣。
- **未建模力和接触**：当前方法仅依赖几何位姿，未结合力反馈、表面法向、障碍距离等信息，在处理约束运动（如推、插）时可能遇到环境几何冲突而无法恢复。
- **记忆库构建需要示教**：关键位姿从人类示教中提取，虽然示教数量需求少（少样本），但仍需要一定量的高质量示教数据，初次部署时需录制演示。
- **终端残差校正增加执行步数**：实验显示平均执行步数从 167 增加到 278.5，虽然动作模型本身快速，但环境步进时间增加，可能影响总任务耗时。
