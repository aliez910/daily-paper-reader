## 摘要
视觉-语言-动作（VLA）模型中的跨具身迁移仍然具有挑战性，因为底层状态和动作空间在不同机器人平台之间存在根本性差异。我们观察到，操控任务背后的高层认知过程，包括场景感知、物体识别、任务规划以及子任务分解，在不同具身之间大体上是共享的。基于这一观察，我们提出了 ZR-0，一个 26 亿参数的端到端 VLA 模型，采用密集的具身思维链（ECoT）监督来对齐视觉-语言模型（VLM）中的跨具身表征。ZR-0 采用双流架构：预训练的 VLM（系统 2）在训练过程中生成结构化的 ECoT 推理，而基于扩散 Transformer 的动作专家（系统 1）则通过流匹配生成连续动作块。这两个组件通过交叉注意力进行耦合，注意力掩码将动作专家限制为仅输入提示特征，从而使得推理时可以完全跳过 ECoT 生成而不会造成任何性能损失。ZR-0 在 ProcCorpus-60M 上进行了预训练，该大规模数据集包含来自超过 40 万条轨迹的大约 6000 万帧（约 1000 小时），并对其中 96.8% 的帧提供了密集的 ECoT 标注。我们在三个涵盖单臂（LIBERO）、双臂（RoboTwin 2.0）和人形（RoboCasa GR-1 Tabletop）具身的模拟基准测试以及 xArm 平台的真实世界实验上对 ZR-0 进行了评估，结果表明 ZR-0 在所有场景下均表现出色。代码和模型检查点可在 https://github.com/RUCKBReasoning/ZR-0 获取。

## Abstract
Cross-embodiment transfer in vision-language-action (VLA) models remains challenging because low-level state and action spaces differ fundamentally across robot platforms. We observe that the high-level cognitive process underlying manipulation, including scene perception, object identification, task planning, and sub-task decomposition, is largely shared across embodiments. Based on this observation, we present ZR-0, a 2.6 billion parameter end-to-end VLA model that uses dense Embodied Chain-of-Thought (ECoT) supervision to align cross-embodiment representations within the vision-language model (VLM). ZR-0 adopts a dual-stream architecture: a pre-trained VLM (System 2) generates structured ECoT reasoning during training, while a Diffusion Transformer-based action expert (System 1) produces continuous action chunks via flow matching. The two components are coupled through cross-attention, with an attention mask that restricts the action expert to input prompt features only, enabling ECoT generation to be entirely skipped at inference without any performance loss. ZR-0 is pre-trained on ProcCorpus-60M, a large-scale dataset comprising approximately 60 million frames (approximately 1,000 hours) from over 400K trajectories, with dense ECoT annotations covering 96.8% of all frames. We evaluate ZR-0 on three simulation benchmarks spanning single-arm (LIBERO), bimanual (RoboTwin 2.0), and humanoid (RoboCasa GR-1 Tabletop) embodiments, as well as real-world experiments on the xArm platform, demonstrating strong performance across all settings. Code and model checkpoints are available at https://github.com/RUCKBReasoning/ZR-0.

# ZR-0：基于密集具身思维链监督的视觉-语言-动作模型 论文总结

## 一、核心问题与研究动机

- **核心问题**：跨具身（cross-embodiment）迁移是构建通用机器人的关键，但 VLA 模型在不同机器人平台之间难以共享知识。
- **关键瓶颈**：不同机器人在运动学构型（6-DoF vs 7-DoF）、控制接口（关节位置 vs 末端位姿）、底座类型（固定 vs 移动）、传感器配置上差异显著，导致低层状态与动作空间存在根本性异构性。
- **现有方法的不足**：零填充、维度归一化、固定语义角色分配等"格式级"对齐手段仅解决表面问题，未触及**语义对齐**——即同维度的关节/动作在不同机器人上物理含义仍不相同。
- **核心洞察**：尽管低层控制是具身特定的，但高层认知过程——场景感知、目标识别、任务规划、子任务分解——在不同具身之间大体共享。这种"具身无关的推理"才是跨具身预训练应捕获的可迁移知识。

## 二、方法论

### 2.1 整体架构：双流 System 1 / System 2 框架

- **系统 2（VLM）**：基于 Qwen3-VL-2B-Instruct 初始化（约 2.1B 参数），处理任务指令与多视角图像观测，生成结构化 ECoT 推理序列。
- **系统 1（动作专家）**：基于扩散 Transformer（DiT）的 500M 参数模块，通过流匹配（flow matching）生成连续动作块。
- **耦合方式**：交叉注意力 + 交叉注意力掩码，将动作专家限制为**仅关注输入提示特征**（任务指令与图像），不关注 ECoT token。

### 2.2 ECoT 结构化推理的六大组件

| 组件 | 功能 |
|------|------|
| 场景描述 | 文本化当前视觉场景，提升物体识别 |
| 进度评估 | 二元完成标志（Yes/No），训练任务进度感知 |
| 未来计划 | 自然语言高层规划，训练时序推理 |
| 子任务动作 | "动词 + 宾语 [+ 介词短语]"的原子分解（如"Grasp the blue plate"），**实现跨具身对齐的关键载体** |
| 目标物体 | JSON 格式边界框，视觉定位监督 |
| 离散动作 | FAST tokenizer 编码的具身特定动作 token |

### 2.3 关键技术细节

- **1:3 交叉注意力比例**：自注意力层 1 个 + 交叉注意力层 3 个，区别于 GR00T N1 的 1:1，增强跨模态信息流动。
- **关键设计 —— 推理时可完全跳过 ECoT 生成**：因交叉注意力掩码将 ECoT 排除在外，仅需对输入提示做一次前向传播即可得到动作专家所需的全部特征，避免自回归文本生成的延迟开销。
- **训练目标**：联合优化两项损失
  - $L_{ntp}$：ECoT 下一 token 预测损失（仅更新 VLM 参数）
  - $L_{fm}$：动作块去噪向量场预测损失（同时更新 VLM 与动作专家）
  - 总损失：$L = L_{ntp} + \alpha L_{fm}$（预训练 $\alpha=5$，后训练 $\alpha=1$）
- **流匹配时间步采样**：$\tau \sim \text{Beta}(1.5, 1.0)$，强调较噪声较大的时间步。
- **通用 VL 数据协同训练**：混入 CapsFusion 与 Pixmo 数据集，缓解 VLM 灾难性遗忘。
- **跨具身动作对齐**：状态/动作填充到 64 维并对 padding 维损失掩码，使用 1st/99th 百分位数做 min-max 归一化。

### 2.4 推理流程

- 初始化噪声动作块 $A_0^t \sim \mathcal{N}(0, I)$
- 经 $N$ 步前向 Euler 积分：$A^{t+1/N} = A^t + \frac{1}{N} \pi_\theta(\cdot)$
- 单 A6000 GPU 单块生成延迟 ~90 ms

## 六、主要结论

- **LIBERO**：平均成功率 97.8%，LIBERO-10 长视野套件 96.4%（领先 π0.5 4 个百分点）

## 七、优点与亮点

- **架构设计精巧**：ECoT 仅作训练信号、推理可通过注意力掩码完全跳过，在效率（~90 ms/块）和表征质量间取得平衡
- **跨具身对齐机制明确**：将 To-Do Actions 的"动词+宾语"原子分解作为具身无关的语义桥梁，思路清晰
- **双流耦合比例优化**：1:3 的自/交叉注意力比例，强化跨模态信息流
- **数据策略完备**：通用 VL 数据 + 机器人轨迹 + 通用数据协同训练，缓解灾难性遗忘
- **覆盖广泛**：覆盖三种具身形态与真实机器人，附完整 50 子任务逐任务结果
- **可复现性**：代码与模型检查点开源（https://github.com/RUCKBReasoning/ZR-0）
- **数据效率显著**：用 ~1000 小时数据取得与 2 万小时级别模型相当的 RoboTwin 性能

## 八、不足与局限

- **数据规模有限**：仅 ~1000 小时预训练，远低于 π0（>1 万小时）、LingBot-VLA（~2 万小时）、Qwen-RoboManip（>3 万小时）；长尾动作（如关闭抽屉）表现明显下降
- **特定任务失败**：真实 Hang Cups 任务中 π0.5 反超 ZR-0（85 vs 70），表明 ECoT 推理对**精细运动控制**的贡献有限，更依赖动作监督规模
- **算力披露不充分**：GPU 数量、预训练总时长、ECoT 自动标注的具体算力开销均未明确
- **基准覆盖有限**：RoboCasa 仅有 24 个任务、xArm 仅 4 个任务；双臂实验主要在 ALOHA 形态，人形仅 GR-1 一种平台
- **ECoT 标注成本**：每帧经 VLM 自动标注的算力代价高，未给出具体节省策略（仅指出这是未来方向）
- **消融深度不足**：仅做了 ECoT vs 无 ECoT 的二值消融，未拆解六个 ECoT 组件的独立贡献，也未对 1:3 注意力比例、α 权重等超参做敏感性分析
- **细粒度运动精度受限于动作数据规模**：作者明确指出"增加动作监督规模"或可解决，但本文未验证
- **可解释性仅停留于训练侧**：ECoT 在推理时被完全跳过，因此最终模型丢失了"逐步推理"的可解释输出
