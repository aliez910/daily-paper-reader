## 摘要
语言条件操作既需要精确的富含接触的控制，也需要围绕语言、场景和长跨度时间范围的鲁棒推理。端到端的视觉-语言-动作（VLA）模型具备强大的局部视觉运动技能，但其训练数据来自分布内任务轨迹，在部署扰动（如语义重定向、目标重绑定、空间布局变化以及局部接触不稳定）下常常失效。大语言模型编码智能体提供了互补的语义与组合推理能力，但纯解析性基元难以应对不规则抓取、约束性放置以及铰接物体交互。我们提出了 Harness VLA——一个记忆增强的智能体框架，它将冻结的 VLA 暴露为一个可重试的富含接触的基元，并将其与一个固定的小型解析性基元库组合，用于接地、暂放、搬运、导航与释放等环节。该框架并不扩展技能库，而是从特定任务的执行轨迹、全局成功规则与失败模型中学习这些固定基元的适用区间。通过将语义再接地、非接触执行以及 VLA 再暂放上提至规划器层面，同时将冻结的 VLA 保留用于局部富含接触的阶段，Harness VLA 无需微调即可将预训练 VLA 的适用范围扩展到其原始轨迹分布之外。在受扰动的桌面任务、家庭厨房任务以及从规整到随机化的双手操作任务中，Harness VLA 在 LIBERO-Pro 与 RoboCasa365 上分别比最强的相关基线高出 38.6 与 25.4 个百分点，并在 RoboTwin C2R 上达到 58.4%。

## Abstract
Language-conditioned manipulation requires both precise contact-rich control and robust reasoning over language, scenes, and long horizons. End-to-end Vision-Language-Action (VLA) models provide strong local visuomotor skills, but they are trained on in-distribution task trajectories and often fail under deployment perturbations such as semantic retargeting, goal re-binding, spatial-layout shifts, and unstable local contacts. LLM coding agents provide complementary semantic and compositional reasoning, but purely analytic primitives struggle with irregular grasping, constrained placement, and articulated-object interaction. We present Harness VLA, a memory-augmented agentic framework that exposes a frozen VLA as a retryable contact-rich primitive and composes it with a small fixed library of analytic primitives for grounding, staging, transport, navigation, and release. Rather than expanding the skill library, the harness learns the operating range of these fixed primitives from task-specific execution traces, global success rules, and failure models. By lifting semantic re-grounding, non-contact execution, and VLA re-staging to the planner while reserving the frozen VLA for local contact-rich phases, Harness VLA extends pretrained VLAs beyond their original trajectory distribution without finetuning. Across perturbed tabletop, household kitchen, and clean-to-randomized bimanual manipulation, Harness VLA improves over the strongest relevant baselines by 38.6 and 25.4 percentage points on LIBERO-Pro and RoboCasa365, respectively, and reaches 58.4% on RoboTwin C2R.

# Harness VLA 论文总结

## 1. 核心问题与研究动机

- **核心矛盾**：语言条件操控任务同时需要**精确的接触密集控制**与**面向语言/场景/长视野的鲁棒推理**，但现有两大主流范式各执一端：
  - **端到端 VLA 模型**（如 π0、π0.5、OpenVLA、AtomVLA）擅长局部视觉-运动技能，但在部署分布外扰动——**语义重定向、目标重绑定、空间布局偏移、局部接触不稳定**——下泛化能力急剧退化，且单一不稳定接触即可摧毁整个长视野 rollout。
  - **LLM 编码代理**（Code-as-Policies、ProgPrompt、Cap-X 等）擅长语义/组合推理与程序合成，但纯解析式基元难以处理不规则抓取、约束放置、铰接物体操作等物理精细交互。
- **研究目标**：在不微调 VLA、不扩展技能库的前提下，让一个记忆增强的智能体把"冻结的 VLA"包装成一个可重试的接触密集基元，并将其与固定分析式基元组合，完成扰动下的语言条件操控。

## 2. 方法论

### 2.1 核心思想
- 采用**非对称分层**：冻结的 VLA 仅作为**接触密集专用原语** `VLA ACT` 调用（短 burst、附带停止谓词）；其余语义再接地、空移运输、姿态调整、移动底盘、释放验证均由 LLM 规划器 + 解析式基元完成。

### 2.2 统一基元接口（Primitive Library 𝒫）
- **复合解析式基元**：`MOVE TO`（笛卡尔目标）、`MOVE POSE`（位置+姿态）、`NAVIGATE TO`（移动底盘，仅 RoboCasa365）。
- **原子解析式基元**：`ROTATE WRIST`、`ROTATE PITCH`、`SET GRIPPER`、`RELEASE`、`MOVE BASE`。
- **学习式基元**：`VLA ACT`（统一包装 πRLinf / RLDX-1 / LingBot-VLA 等不同 VLA，输入 prompt + 最大 chunk 数 + 停止谓词 τ）。
- **辅助**：`RESET`（仅在 Bootstrapping 阶段）。
- 所有基元以 **JSON 序列化**调用，规划器永远不直接输出关节/动作 chunk。

### 2.3 三组件架构
1. **Agentic Planner Π**：接收 RGB-D 观测 + 任务描述 + 记忆，给出 JSON 基元调用。
2. **Harness（REPL 风格的执行回路）**：通过 `command.json`、`state_NN.json`、`log_NN.json`、`done_NN.flag` 等文件实现隔离、审计、同步；循环至 `G` 满足或预算耗尽。
3. **两套记忆模块**：
   - **Task Specific Memory**：在 seed 0 探索阶段保存"参考 primitive 序列"为 JSONL trace + 结构化 strategy/avoid 摘要（参数化的空间参数被替换为符号感知查询，以便重接地）。
   - **Global Memory**：跨任务积累 success rules（如完整 prompt 策略）与 failure models（空抓、假成功、误判完成等）。

### 2.4 两阶段使用流程
- **Exploratory Bootstrapping**：用单一参考实例在宽松预算 + RESET 可用下自探索；成功后抽象为 TSM，并蒸馏出 GM。
- **Deployment Evaluation**：禁用 RESET、压缩预算；规划器从 TSM 检索结构骨架，以当前 RGB-D 重接地所有空间参数；GM 提供启发式避坑。

### 2.5 核心算法逻辑（文字版）
1. 读取 `command.json`、观测、`state`、TSM 与 GM。
2. 从 RGB-D/世界图中**像素→世界坐标**感知定位（取多个稳定像素的稳健中位统计）。
3. 选择基元并发送 JSON；等待 worker 执行完毕。
4. 读取新状态做**闭环诊断**（是否目标对位、是否空抓、是否假成功）。
5. 决策：继续 / 重新 stage 后再调 `VLA ACT` / 调用解析式基元运输释放 / 终止。

### 2.6 提示工程
- 采用**共享 Prompt 核心 + 基准填充槽位**的模板：包含角色与成功信号、感知隔离、文件 REPL、基元词汇、VLA 职责分工、TSM 使用规则、闭环恢复、预算/复位/终止、输出审计等 11 个模块。

## 6. 主要结论与发现

- **结论 1**：预训练 VLA 最适合扮演"接触阶段专家"，而语义/空间重接地、长视野规划等任务交给 LLM 规划器可显著缓解 VLA 在扰动下的失效。
- **结论 2**：少量由规划器阶段性触发的 VLA 调用即可超过冻结 VLA 自身；额外调用带来边际收益并收敛。
- **结论 3**：检索 TSM 提供的"任务解法骨架"对位置换扰动（Goal-S）尤为关键（79.0% → 87.0%），对指令重定向作用有限——说明骨架贡献主要在几何时空布局而非语义。
- **结论 4**：解析式基元负责包围 VLA 的"非接触外壳"，使冻结 VLA 的有效作用范围被显著外推，且无需任何参数更新。
- **结论 5**：同一 Harness 可作为多种异构冻结 VLA 的统一调用外壳（πRLinf / RLDX-1 / LingBot-VLA），具备可复用的"代理即基元"特性。

## 7. 优点与亮点

- **架构创新**：将"agent harness 思路"系统迁移到机器人操控领域，把 VLA 视作"可重试基元"而非端到端策略，思路新颖且模块化。
- **零微调泛化**：在不改动 VLA 参数的前提下，把扰动鲁棒性大幅提升（+38.6 / +25.4 pp），具有较高实用价值。
- **可审计、可重放**：文件级 REPL + JSONL trace + 审计 JSON 提供全流程可追溯性，符合"代理可观测"工程原则。
- **记忆设计独特**：TSM 显式分离"骨架（JSONL）"与"语义摘要（JSON）"，并以感知参数化方式支持空间重接地；GM 收集跨任务避坑规则。
- **基元统计实证**：通过调用频率分布（Tables 18-19）直观展示 Harness 的"非对称分工"是真正在使用层面的特征，而非仅停留在概念。
- **多基准、多 VLA 后端**：跨 LIBERO / RoboCasa365 / RoboTwin C2R、跨 π0.5 / RLDX-1 / LingBot-VLA 的统一抽象 `VLA ACT`，增强了结论的普适性。
- **可视化详尽**：给出 Object / Goal / LIBERO-Pro / PRE SOAK PAN / STEAM IN MICROWAVE 等典型 rollout 帧，便于读者直观理解机制。

## 8. 不足与局限

- **缺乏算力与运行成本披露**：未给出推理 GPU 数、单 episode LLM/VLA 调用 token 等指标，难以评估实际部署门槛。
- **消融有限**：缺少对单一基元、TSM/GM 各子模块的逐一消融，"为何这样分工"的因果论证相对偏定性。
- **不同基准 VLA 不可直接比较**：三个基准使用的冻结 VLA 不同（πRLinf vs RLDX-1 vs LingBot-VLA），读者难以判断 Harness 增益中"基线 VLA 能力"与"Harness 增益"的耦合程度。
- **依赖闭源 LLM 与闭源 VLA**：Codex/Claude Code、π0.5/RLDX-1/LingBot-VLA 等均为外部依赖，复现门槛高；未明确提示工程令牌消耗与延迟代价。
- **回路"开环"问题**（作者承认）：规划器↔VLA 的反馈目前没有进入 VLA 本身的在线适应；缺乏基于环境奖励/人类偏好的 GRPO/RFT 式联合微调。
- **缺乏细粒度图像描述**：在高度杂乱、长视野任务中，对场景结构推理仍受限。
- **随机种子仅 10/任务（部分基准 5/任务）**：统计置信区间未做误差棒估计，结果的方差与显著性存在不确定性。
- **CM 风险**：TSM 在 seed 0 探索中可能发现"参考场景特定"启发式，若 GM 抽象不足，存在跨任务过度迁移风险；论文未给出 GM 的去污染或严格性验证流程。
- **应用边界**：当前仅在仿真器（MuJoCo via Robosuite 等）中验证；真实世界传感器噪声/延迟/接触不确定性下的鲁棒性尚未报告。
