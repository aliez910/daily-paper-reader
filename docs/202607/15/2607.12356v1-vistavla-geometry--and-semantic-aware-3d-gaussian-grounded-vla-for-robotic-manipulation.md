## 摘要
视觉-语言-动作（VLA）模型通过将语言指令与二维视觉输入直接映射为动作，已成为机器人操作中一种强大的端到端范式。然而，这类模型缺乏显式的场景级三维表征，限制了其对空间布局和几何约束的推理能力。尽管近期研究尝试引入深度图或点云等显式三维线索以增强几何感知，但这些方法主要捕捉低层次结构，缺乏三维空间中的高层次语义锚定。在人类认知中，与物理世界的交互依赖于一种三维语义认知地图——一种将空间布局与语义上下文相融合的内部心理模型，从而实现持久且视角不变的推理。有鉴于此，我们提出 VistaVLA，一种新颖的两阶段框架。该框架基于三维高斯基元构建几何与语义感知的三维认知表征，并将其作为紧凑的上下文标记用于 VLA 策略学习。具体而言，VistaVLA 将多视角视觉-语言特征提升至三维高斯基元中，形成几何锚定的语义标记，使其在二维视觉特征空间中实现一致的跨视角空间锚定。为了使该三维表征在计算上易于处理以实现有效的 VLA 控制，我们引入了先合并后查询（Merge-then-Query，MtQ）这一标记汇总机制。MtQ 将密集的高斯基元压缩为一组高度紧凑的、具有空间信息的标记，在保留与动作相关的三维布局和语义上下文的同时，实现了 99% 的标记压缩率。在仿真环境和真实环境中的大量实验评估证明了 VistaVLA 的有效性。值得注意的是，在真实场景中，VistaVLA 在七项真实任务上将成功率提升了 22.8%，并在具有挑战性的分布外任务上相较 VLA-Adapter 基线提升了 30.0%。

## Abstract
Vision-Language-Action (VLA) models have emerged as a powerful end-to-end paradigm for robotic manipulation by mapping language instructions and 2D visual inputs directly to actions. However, these models lack an explicit, scene-level 3D representation, limiting their ability to reason over spatial layouts and geometric constraints. While recent efforts incorporate explicit 3D cues, such as depth maps or point clouds, to improve geometric awareness, they primarily capture low-level structures and lack high-level semantic grounding in 3D space. In human cognition, interaction with the physical world relies on a 3D semantic cognitive map - an internal mental model that integrates spatial layouts with semantic context to enable persistent, viewpoint-invariant reasoning. In light of this, we present VistaVLA, a novel two-stage framework that constructs a geometry- and semantics-aware 3D cognitive representation from 3D Gaussian primitives and grounds it as compact context tokens for VLA policy learning. Specifically, VistaVLA lifts multi-view vision-language features into 3D Gaussian primitives, forming geometry-anchored semantic tokens that align view-consistent spatial grounding with 2D visual feature spaces. To make this 3D representation computationally tractable for effective VLA control, we introduce Merge-then-Query (MtQ), a token summarization mechanism. MtQ compresses dense Gaussian primitives into a highly compact set of spatially informative tokens, achieving a 99% token reduction while preserving action-relevant 3D layouts and semantic context. Extensive evaluations in both simulated and real-world environments demonstrate the effectiveness of VistaVLA. Notably, in real-world scenarios, VistaVLA improves success rates by 22.8% across seven real-world tasks and by 30.0% over the VLA-Adapter baseline on challenging out-of-distribution tasks.

## 1. 核心问题与研究动机

- **研究背景**：视觉-语言-动作（VLA）模型通过将语言指令与 2D 视觉输入直接映射为机器人动作，已成为端到端机器人操作的强大范式（如 OpenVLA、π0、RT-2、VLA-Adapter 等）。
- **核心问题**：
  - 现有 VLA 模型主要依赖 **2D 图像观测**，缺乏显式的场景级 3D 表征，难以进行视角无关的空间布局与几何约束推理。
  - 近期引入 3D 线索（深度图、点云、稀疏 3D 坐标）的方法虽增强了几何感知，但仅捕获**低层次几何结构**，缺乏 3D 空间中的**高层次开放词汇语义锚定**。
  - 现有 3D 表征多为**观测中心**而非**场景级**，无法将丰富多模态语义绑定到物理空间结构上，导致实时控制计算不可行。
- **认知启发**：借鉴人类"3D 语义认知地图"——一种融合连续空间拓扑与功能意义的内部心理模型，实现持久、视角不变的推理。
- **研究目标**：构建一个场景级、几何-语义联合感知的 3D 认知表征，作为 VLA 策略学习的紧凑空间接口。

## 2. 方法论

### 整体框架：两阶段结构

#### Stage I：3D 高斯接地认知表征学习
- **教师特征构建**：对每帧提取 SigLIP2（语言对齐语义）+ DINOv2-Large（鲁棒视觉描述符）特征（2176 维），通过轻量级自编码器压缩至 **128 维潜在代码**，作为渲染监督的教师特征。
- **3D 高斯场训练**：基于 DepthSplat 框架，将场景表示为高斯基元集合 $G = \{g_i\}_{i=1}^N$，每个基元扩展语义特征 $z_i \in \mathbb{R}^{128}$，即 $g_i = (\mu_i, \Sigma_i, \alpha_i, c_i, z_i)$。
  - **Stage 1**：使用 $\mathcal{L}_{stage1} = \lambda_{rgb}\mathcal{L}_{rgb} + \lambda_{dep}\mathcal{L}_{dep}$ 建立稳定场景几何。
  - **Stage 2**：加入教师特征监督 $\mathcal{L}_{stage2} = \lambda_{rgb}\mathcal{L}_{rgb} + \lambda_{dep}\mathcal{L}_{dep} + \lambda_{feat}\mathcal{L}_{feat}$，将紧凑语义特征蒸馏到高斯基元中。
- **渲染公式**（高斯泼溅 alpha-compositing 规则）：
  $$\hat{F}_v(p) = \sum_{i \in N(p)} R_i(v,p) z_i,\quad R_i(v,p) = T_i^v(p)\alpha_i^v(p)$$
  其中 $R_i$ 由高斯投影、不透明度、深度排序与相机参数决定；$\mathcal{L}_{feat} = \sum_{v \in V}\sum_{p \in \Omega}\|\hat{F}_v(p) - F_v^{teacher}(p)\|_2^2$。
- **3D 接地 Token 化**：每个高斯的潜在语义特征 $z_i$ 即为一个 GS Token，$T_{gs} = \{z_i\}_{i=1}^N$，$d=128$。每个 Token 是**多视角一致**的语义描述符，**锚定在 3D 空间**。
- **在线构建**：推理时从策略实时 RGB 观测和标定相机位姿在线构建高斯场，无需深度输入或第三视角。

#### Stage II：Merge-then-Query (MtQ) 紧凑 Token 汇总与策略注入
- **背景**：语义高斯场通常含 $N_0 \sim 10^5$ 基元，无法被 VLA 实时处理。MtQ 将密集 Token 压缩为固定长度表示。
- **步骤 1：无参数压缩（Parameter-free Compression）**
  - 对密集 GS Token 进行 stride-4 平均池化（语义特征 + 3D 中心），Token 数降至 ~7K。
  - 基于**Morton 编码**对 Token 排序，交替划分为锚点集 $A$ 和非锚点集 $B$。
  - 每个非锚点 Token $u \in B$ 按语义相似度匹配到最相似的锚点：$a^*(u) = \arg\max_{a \in A} \langle z_u, z_a \rangle / (\|z_u\|\|z_a\|)$。
  - 仅合并相似度排名前 50% 的匹配，避免强制合并语义不一致 Token；采用**尺寸加权平均**更新锚点（$z, \mu, s$）。
  - 迭代至 $N' = 1000$ 个 Token。
- **步骤 2：基于查询的汇总（Query-based Summarization）**
  - 使用 $N_q = 64$ 个可学习查询 Token $Q \in \mathbb{R}^{B \times N_q \times d}$，通过两层 Transformer Decoder 关注压缩后的 Token：
    $$X_{gs} = \text{Proj}_{llm}(\text{Dec}_{gs}(Q, Z')),\quad X_{gs} \in \mathbb{R}^{B \times N_q \times d_{llm}}$$
- **动作生成**：遵循 VLA-Adapter，将 2D 视觉 Token、语言指令 Token、GS 汇总 Token、动作查询 Token 拼接：$X = [X_{vis}, X_{lang}, X_{gs}, X_{act}]$；预测未来 $K=4$ 个连续动作（$K_{exec}=4$ 后重规划）。

## 6. 主要结论与发现

### 定量结果
- **真实世界**：VistaVLA 平均 SR **显著优于所有基线**，整体提升 **22.8%**（相对 VLA-Adapter）。
- **空间变体鲁棒性**：
  - 深度扰动（PlaceSponge）：基线 6/10 → VistaVLA **9/10**。
  - 位置扰动（OrganizeSponge）：所有基线 **0/10** → VistaVLA **3/10**（唯一非零结果）。
- **标准 LIBERO**：VistaVLA 平均 **96.05%** SR，在无大规模预训练方法中最佳，超过 VLA-Adapter（94.1%）。
- **LIBERO-Pro-Swap**：VistaVLA **12.2%**，远高于 VLA-Adapter（1.7%）和 OpenVLA-SF（0.9%）等 3D 输入方法。
- **3D 输入方法对比**：在所有 3D 输入基线（OpenVLA-SF、Q-Depth VLA）中 VistaVLA 表现最佳。

### 关键发现
- 注入**结构化 3D 语义高斯表征**比简单堆叠 2D 视觉 Token 或注入原始深度更有效。
- 增益并非来自更多相机视角或更多 2D Token，而是源于**语义 3D 空间接口**。
- Morton 引导的语义合并 + 查询式汇总的双层压缩机制对保留任务相关 3D 信息至关重要。
- 查询 Token 数量存在最优值（64 个），过多反而引入冗余。

## 7. 优点与亮点

- **方法创新**：
  - 首次将**语义 3D 高斯泼溅作为面向策略的表征**用于 VLA 控制，桥接了 3DGS 与机器人操作学习。
  - **MtQ 机制**实现 99% 的 Token 压缩（$10^5 \to 64$），同时保留动作相关的 3D 布局与语义信息。
  - 采用 Morton 编码实现**无参数空间感知合并**，避免 FPS 等方法的迭代距离更新。
- **表征优势**：
  - 每个 GS Token 同时具备**多视角一致性**、**3D 空间锚定**与**语言对齐语义**三重特性。
  - 高斯特征通过 alpha-compositing 规则渲染，与 2D 教师特征空间自然对齐。
- **工程实用性**：
  - 推理时无需深度输入，仅需 RGB + 标定相机位姿。
  - 在线构建 3D 高斯场，捕获场景布局的实时变化。
- **实验设计**：
  - 同时在真实环境与仿真中验证；包含标准与 OOD 任务；消融实验系统（相机、压缩、查询 Token 数）。
  - 在小模型（0.5B）下超越大模型通用 VLA（π0.5-3B），证明方法的高效性。

## 8. 不足与局限

### 方法局限
- **依赖相机标定**：构建语义高斯场仍需**标定好的相机位姿**，无法应对位姿噪声场景。
- **依赖深度训练信号**：训练阶段需要 RGB-D 输入与多视角监督，部署门槛较高。
- **多视角假设**：训练需 2 个标定 RGB-D 视角 + 1 个目标视图，限制了在单目或非标定环境中的应用。
- **固定平台**：仅在单一桌面操作平台（Agile-Piper）验证，未涉及移动机器人或类人机器人。

### 实验覆盖局限
- 真实任务样本量小（每任务仅 10 次试验），统计置信度有限。
- 任务类型集中在桌面操作，缺少动态障碍、铰接对象、长程导航等复杂场景。
- 未在更具挑战性的 OOD 场景（如光照变化、背景杂乱、新型物体类别）下系统评估。
- 未与最新 3D VLA 方法（如 GeoVLA、BridgeVLA、PointVLA、SpatialVLA 等）进行充分对比。

### 偏差与风险
- 评估主要作者所在机构完成，可能存在**确认偏差**。
- 缺乏失败案例的细粒度分析（如哪些操作失败、为何失败）。
- 高斯场构建的计算开销未明确报告，实时性保证存疑。
