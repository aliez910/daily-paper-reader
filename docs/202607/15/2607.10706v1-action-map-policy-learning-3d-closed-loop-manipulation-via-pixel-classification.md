## 摘要
动作空间是机器人学习中的一个主要挑战，因为它通常具有高维度、跨度较长的时间范围，并且常常存在多模态最优解。合理选择动作表示与损失函数有助于缓解这些问题，但往往需要在不同方案之间进行权衡。我们提出了动作地图策略（AMP），将三维闭环操作策略学习转化为图像空间中的分类问题。分类方法在生成式语言模型中已被证明是有效的，但其难以直接应用于机器人动作学习，因为对高维连续动作进行朴素离散化会导致词表规模急剧膨胀。我们的核心思想是将三维动作投影到相机图像平面上，并将每个像素位置视为一个离散类别，从而在控制维度的同时保留多模态特性。该方法能够在不依赖庞大词表的前提下，为高维动作提供毫米级精度，同时保留细粒度的逐像素视觉信号。此外，它可以在单次前向传播中预测完整的动作块，避免了复杂的噪声调度与迭代去噪过程，同时实现比扩散策略显著更快的推理速度。在多种操作任务上的实验表明，AMP 优于强基线方法，取得了更高的成功率、更快的推理速度以及更强的空间推理能力。

## Abstract
The action space poses a major challenge in robot learning, since it is often high-dimensional, can span long time horizons, and frequently admits multi-modal optimal solutions. A good choice of action representation and loss function can help to address these concerns, but there are often trade offs. We propose Action Map Policy (AMP), which casts 3D closed-loop manipulation policy learning as a classification problem in image space. While classification has been an effective formulation in generative language models, applying it to robot action learning is difficult because naively discretizing high-dimensional continuous actions explodes the token vocabulary. Our key idea is to project 3D actions onto the camera image planes and treat each pixel location as a discrete class, thus controlling dimensionality while retaining multi-modality. This method supports millimeter-level precision for high-dimensional actions without requiring a prohibitively large vocabulary, while preserving fine-grained pixel-wise visual signals. Furthermore, it can predict the entire action chunk in a single forward pass, avoiding complex noise scheduling and iterative denoising while achieving substantially faster inference than diffusion policies. Experiments on various manipulation tasks show that AMP outperforms strong baselines, achieving higher success rates, faster inference, and enhanced spatial reasoning.

## 2. 方法论：核心思想与关键技术

### 2.1 核心思想
- 将 **3D 闭环操控策略学习**重新建模为**图像空间中的像素分类问题**：
  - 把 3D 末端执行器目标位姿/动作投影到**相机像平面**；
  - 图像中的**每个像素位置**被视为一个**离散类别**；
  - 网络输出为图像分辨率大小的分类 logits。

### 2.2 关键技术细节
- **动作表示（Action Map）**：
  - 利用相机内参与外参，将世界坐标系下的 3D 动作投影到 2D 像素位置；
  - 像素位置即分类标签，因此**词表大小 = 图像像素数**，可控且与图像分辨率挂钩而非动作维度挂钩。
- **保留多模态**：
  - 像素分类的 softmax 分布天然支持多模态输出（多个像素位置可同时获得较高概率），无需引入额外混合模型。
- **毫米级精度**：
  - 通过亚像素解码（利用概率分布的期望/众数与像素邻域插值）实现 sub-pixel 定位，等效毫米级空间精度。
- **保留逐像素视觉信号**：
  - 图像平面与视觉特征共享同一空间，便于网络融合视觉特征与动作预测，提升空间推理。
- **单次前向预测完整 action chunk**：
  - 不需要迭代去噪，不依赖噪声调度器；
  - 在一次前向传播中并行输出整个动作序列块（action chunk）。
- **分类损失**：
  - 标准交叉熵损失（或带标签平滑），训练目标即"在动作发生的位置像素处打高概率"。

### 2.3 推理流程（文字描述）
1. 输入当前 RGB-D（多视角）观测；
2. 视觉编码器提取特征图；
3. 策略头在图像平面每个像素上输出 logits；
4. 取概率最大的像素位置（或期望位置）作为预测动作；
5. 利用相机投影参数将该像素反投影回 3D 空间，作为末端执行器目标位姿/动作；
6. 执行该动作（或动作块）并进入下一闭环步骤。

## 6. 主要结论与发现

- **像素分类范式有效**：将 3D 动作投影到图像平面再做分类，可以避免高维动作离散化导致的词表爆炸。
- **精度与速度兼顾**：在保持毫米级精度的同时，单次前向预测完整动作块，推理速度显著快于扩散策略。
- **多模态自然保留**：softmax 输出天然支持多模态动作分布，无需额外设计。
- **空间推理增强**：动作与视觉共享同一图像空间，使策略对空间关系更敏感，空间推理任务表现更佳。
- **整体效果**：在多种操控任务上，AMP 取得比强基线**更高的成功率、更快的推理速度与更强的空间推理能力**。

## 7. 方法与实验设计的亮点

- **概念简洁且迁移性强**：把 LLM 中的"分类即生成"范式巧妙映射到机器人动作领域，思路直观。
- **有效控制词表规模**：词表大小由图像像素数决定，与动作维度**解耦**，从根本上解决离散化爆炸问题。

- **效率优势显著**：无需迭代去噪，推理延迟低，对实时闭环控制尤为友好。
- **视觉-动作对齐**：动作预测空间与视觉特征空间一致，便于跨任务/跨视角迁移。
- **单次前向预测 action chunk**：与近年来的 action chunking 趋势契合，有利于长时域任务的稳定性。

## 8. 不足与局限

- **依赖相机标定与投影假设**：
  - 需要较为准确的相机内外参；若标定误差大或场景遮挡严重，像素分类精度可能受影响。
- **遮挡与视野限制**：
  - 当目标 3D 位置不在相机视野内或被遮挡时，像素分类无法直接给出有效动作，需额外处理。
- **末端执行器自由度受限**：
  - 像平面仅编码 2D 位置信息（深度与姿态可由额外通道编码），对高自由度任务（如复杂腕部姿态）的表示可能不如直接在高维动作空间学习灵活。
- **像素分辨率与精度的耦合**：
  - 像素分辨率限制了可达到的最小动作分辨率，需要借助亚像素插值等技巧来保证毫米级精度。
- **实验覆盖度的潜在不足**：
