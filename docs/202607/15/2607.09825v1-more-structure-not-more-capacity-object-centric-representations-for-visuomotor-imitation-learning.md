## 摘要
机器人操控策略依赖于预训练视觉模型，这类模型通常输出全局场景嵌入或密集patch网格。两者都会将任务相关特征与任务无关特征混在一起。以物体为中心的slot表征是一种更具结构性的替代方案：它将特征分组为少量按物体分配的slot。我们在ManiSkill3 PickCube-v1任务上测试该结构带来的增益，采用冻结编码器并使用留出种子进行评估。在固定策略、目标token、渲染与标定，仅改变编码器的条件下，冻结的以物体为中心的SPOT表征（DINO ViT-B/16 + Slot Attention）取得了55.0±2.9%的成功率，较密集DINO全局特征基线（32.6±1.5%）高出22.4个百分点，且使用相同的可训练策略，无需对编码器微调。单纯增加token数量并无帮助：token数扩大16倍的密集patch网格并未优于全局特征。引入显式的二维空间目标与原生分辨率渲染后，完整系统进一步达到68.7±4.2%，接近特权三维Oracle上界（71.7±4.1%）。随后通过自动化的运动学失败分类法，将空间精度类失败（Near-Miss）与物体跟踪类失败（No-Grasp）加以区分：空间定位有效降低了Near-Miss，但对No-Grasp无明显改善。同一分类法可迁移到更困难的StackCube-v1任务，并指出遮挡是主要瓶颈。

## Abstract
Robotic manipulation policies rely on pre-trained vision models that give either a global scene embedding or a dense patch grid. Both mix task-relevant and task-irrelevant features. Object-centric slot representations are a structured alternative: they group features into a few per-object slots. We test what this structure buys on ManiSkill3 PickCube-v1, with a frozen encoder and a held-out-seed evaluation. Holding the policy, goal token, rendering, and calibration fixed and changing only the encoder, a frozen object-centric SPOT representation (DINO ViT-B/16 + Slot Attention) reaches 55.0$\pm$2.9% success, 22.4% above a dense DINO global-feature baseline (32.6 $\pm$ 1.5%), with the same trainable policy and no encoder fine-tuning. More tokens alone do not help: a dense patch grid with 16x the tokens performs no better than the global feature. Adding an explicit 2D spatial goal and native-resolution rendering raises the full system to 68.7$\pm$4.2%, just below a privileged 3D-oracle upper bound (71.7$\pm$4.1%). An automated kinematic failure taxonomy then separates spatial-precision (Near-Miss) failures from object-tracking (No-Grasp) failures: spatial grounding reduces Near-Miss while leaving No- Grasp unchanged. The same taxonomy transfers to the harder StackCube-v1 and points to occlusion as the main bottleneck.

# 论文总结：More Structure, Not More Capacity

## 一、核心问题与研究动机

- **核心问题**：视觉运动模仿学习（visuomotor imitation learning）中，操控策略所依赖的预训练视觉表征如何影响其在未见过的物体/目标位姿上的泛化能力？
- **关键观察**：现有预训练视觉模型（DINO 等）通常输出两类表征——全局 [CLS] 嵌入 或 密集 patch 网格——两者都会将任务相关信息与场景级共现线索（背景纹理、上下文统计）混合，在训练与测试分布一致时通过"捷径学习"奏效，但在位姿重置（distribution shift）下失效。
- **研究假设**：作者认为捷径学习的修复手段应当是**结构层面的归纳偏置**（architectural inductive bias），而非增加参数量或数据量。论文以此假设为切入点，验证**以物体为中心的 slot 表征**能否在冻结编码器条件下显著提升视觉运动策略的泛化。
- **整体定位**：受控（controlled）、任务级（task-level）的表征消融研究，区别于以往对视觉分布偏移（如光照、纹理、杂乱）的研究，本文聚焦于训练集未见的物体与目标位置。

## 二、方法论

### 2.1 整体流水线
1. 两台固定 RGB 相机（base + diagonal-side，224×224）独立通过冻结的 **SPOT 编码器**；
2. Token 构造阶段将视觉、位姿、目标、动作 token 投影到统一 256 维空间；
3. 一个可训练的**自回归 Transformer 策略**输出 10 步动作 chunk。

### 2.2 冻结的 SPOT 编码器
- 骨干网络：DINO ViT-B/16（冻结）；
- 槽位模块：Slot Attention（[9]），将每张图像的 196 个 patch token 压缩为 **K=7 个物体 slot**（K 由公开 SPOT 权重固定，不做调参）；
- 两相机 slot 拼接成 `S_vis ∈ R^{14×256}`；
- 核心机制：softmax 归一化在 **slot 维度**而非 patch 维度，使得每个 patch 最多强烈激活一个 slot，形成竞争式绑定。
- 关键公式：
  - 注意力打分：`M_{i,j} = (k(X_i)·q(S_j))/√D`，`W_{i,j} = softmax_j(M_{i,j})`
  - 槽位更新：`S^{(t)} = GRU(S^{(t-1)}, W^T v(X))`

### 2.3 Token 构造（每帧 17 个 token）
- 14 个视觉 slot token；
- 1 个位姿 token（7-DoF 关节位置经 MLP）；
- 1 个目标 token（三种条件，见下）；
- 1 个可学习的 action token。

### 2.4 目标条件的三种变体（用于解耦空间信息的贡献）
- **Pure Visual**：无目标 token；
- **2D Spatial Projection**：3D 目标经相机内外参投影到像素坐标 `[u_b, v_b, u_s, v_s]`，3 层 MLP 编码（注：该目标由仿真器 ground-truth 提供，非自监督）；
- **3D Oracle**：直接使用仿真器真实 3D 坐标，作为不可部署的上界。

### 2.5 自回归策略
- 复用 LeRobot 中 VQ-BeT 的 minGPT 风格因果 Transformer；
- 8 层、8 头、隐藏维度 256；
- 时间窗口 T=5（共 85 token），下三角因果掩码；
- 动作 token 隐藏态经 3 层 ReLU MLP 输出 H=10 步、8 维动作 chunk；
- 7 维连续关节动作 Z-score 归一化，夹爪维度不归一化并由阶跃函数解码。

### 2.6 表征基线
- **DINO Global [CLS]**：每相机 1 token，共 2；
- **DINO 4×4 patches**：每相机 16 token，共 32；
- **DINO 14×14 dense**：每相机 196 token，共 392；显存压力迫使 T=1、H=1；
- **Object-Centric (SPOT)**：每相机 7 slot，共 14。

## 三、实验设计

### 3.1 仿真器与任务
- **仿真平台**：ManiSkill3（[15]），确定性 physx_cpu 后端；
- **主任务**：PickCube-v1，Franka Panda 抓取红方块并放置到随机 3D 目标；
- **次任务**：StackCube-v1，将红方块堆到绿方块上，用于验证失败分类法的迁移性。

### 3.2 数据与训练
- 专家示教：1000 条由运动规划器生成、100% 成功的演示；
- 训练种子：0–9,999；评估种子：≥10,000（不重叠，留出评估）；
- 每 50 个 epoch 保存检查点并扫描 200 个留出集 episode。

### 3.3 评估协议
- 最佳 checkpoint 进行 **3×300 episode 独立运行**，报告均值 ± 标准差；
- 剔除 <10 步结束的 trivial success；
- 评估本质是对冻结表征的非线性"解码器探针"（decoder probing），介于线性评估与端到端微调之间。

### 3.4 对比方法
- 表征对比：DINO Global [CLS]、DINO 4×4、DINO 14×14 dense、SPOT（Object-Centric）；
- 空间定位对比：Pure Visual → 2D approx cal 128² → 2D exact cal 128² → 2D exact cal 224² → 3D Oracle；
- 多视角融合对比：token 拼接 vs 双向 cross-attention；
- 时间窗口对比：T ∈ {5, 20, 40}（pure-visual 配置下）。

### 3.5 自动运动学失败分类法
按优先级（互斥）分为 5 类：
- **Idle**：平均动作方差低于阈值；
- **No-Grasp**：`is_grasped` 全程为假；
- **Drop**：曾抓取但中途释放；
- **Near-Miss**：最小 TCP-to-goal 距离 < 0.1 m，但最终未成功放置；
- **Unknown**。
仅依赖动作方差、抓取标志、TCP-to-goal 距离，**不使用视觉输入**，因此编码器无关（encoder-agnostic），可跨任务复用。

## 六、主要结论与发现

- **表征层面**：在完全匹配条件下，**以物体为中心的 SPOT（55.0±2.9%）比 DINO Global [CLS]（32.6±1.5%）提升 22.4 个百分点**；DINO 4×4 patches（31.7%）并未优于全局特征，表明 **token 数量本身不是决定因素**；14×14 dense 崩溃到 1.0% 是显存迫使 T=H=1 所致，不能解读为 token 数效应；
- **结构作用机制**：Slot Attention 的容量受限瓶颈强制每个 slot 绑定到一个连贯区域，使表征无法承载完整场景级统计，迫使容量分配给物体级特征；
- **空间定位贡献**：从 Pure Visual（31.0%）→ 2D 近似标定 128²（55.0%）→ 2D 精确标定 128²（58.7%）→ 2D 精确标定 224²（68.7%）→ 3D Oracle（71.7%），逐步逼近上界；
- **融合与时间窗口**：双向 cross-attention 在训练集表现远好（≈60% vs 38.6%），但留出集与简单 token 拼接完全相同（均 31.0%），表明**额外容量过拟合于已见配置而无法迁移**；时间窗口 T 在 {5,20,40} 间不改变成功率；
- **失败分布**：空间定位主要降低 Near-Miss（31% → 2.5%），但对 No-Grasp 无效（15/15/24 episode），揭示**两类瓶颈需要不同修复**；
- **跨任务迁移**：StackCube-v1 上 No-Grasp 占 72%（144/200），原因是接近阶段机械臂遮挡红方块且 SPOT 无时序记忆——与 PickCube 失败画像（以 Near-Miss 为主）形成镜像。

## 七、优点

- **严格的受控变量设计**：主表中只换编码器，策略、目标 token、渲染、标定全部固定，使 22.4% 的差距可归因于表征结构本身；
- **冻结编码器范式**：无需端到端微调，对应实际部署场景，避免"因微调带来的提升掩盖表征质量"的问题；
- **失败分类法的提出与迁移**：自动化的、编码器无关的运动学分类法，能区分空间精度与目标跟踪两类瓶颈，并跨任务复用，具备诊断价值；
- **结合 shortcut learning 文献脉络**：与 ViT 分类、3D 感知、gaze 估计等领域同模式呼应（lazy aggregation、域标识符、细节抑制），强化"结构修复 > 容量修复"的统一视角；
- **清晰的消融层级**：表征 → 空间定位 → 分辨率 → 融合 → 时间窗口 → 跨任务，层层递进；
- **实践建议明确**：偏好 slot 而非全局特征、token 拼接优于参数化融合模块、为策略提供显式空间目标锚点。

## 八、不足与局限

- **目标信息依赖 ground-truth**：2D 投影与 3D Oracle 都使用仿真器真实目标位置，并非自监督；如何从 slot mask 派生目标锚点仍是开放问题；
- **SPOT 无时序记忆**：slot 绑定不跨帧维持，遮挡恢复能力差，这是 StackCube 失败的直接原因，也限制了向更长时序任务的迁移；
- **融合对比范围有限**：仅在无目标 token 的 31% 性能区间测试；当空间锚点存在时，cross-attention 是否仍无收益未知；
- **主对比在近似标定下进行**：作者自承 +3.7% 来自精确标定，因此主结论"保守"而非"标定无关"；
- **单 GPU、单一仿真器**：未涉及 sim-to-real，未在其他仿真平台（RoboSuite、Isaac Sim 等）或真实机器人上验证；
- **统计区间不完全一致**：StackCube 与失败分类部分仅单次 200 episode，未使用 3×300 协议；
- **算力信息不足**：未给出 GPU 型号、训练时长、单次实验开销，难以评估可复现性；
- **K=7 来自预训练权重**：未探索 slot 数量对策略性能的影响；
- **示教规模较小**：仅 1000 条专家演示，未测试大规模数据下的结论是否依然成立。
