## 摘要
我们提出了 FabriVLA，一种用于精确多任务操作的轻量级视觉-语言-动作模型。FabriVLA 将 InternVL3.5 视觉-语言骨干网络与流匹配动作头相结合，动作头采用跨动作 token 的门控自注意力机制，并通过浅层 VLM 层融合以增强空间上下文。该模型通过单阶段联合优化进行训练，从预训练的 VLM 和随机初始化的动作头出发。在涵盖 50 种不同操作任务的 Meta-World MT50 基准测试上，FabriVLA 取得了 90.0% 的层级平均成功率，表明基于 1B 规模 VLM 构建的紧凑型 VLA 无需依赖数十亿参数的 VLA 骨干网络即可实现出色的性能。

## Abstract
We present FabriVLA, a lightweight Vision-Language-Action model for Precise Multi-Task Manipulation. FabriVLA combines an InternVL3.5 vision-language backbone with a flow-matching action head featuring gated self-attention across action tokens and shallow VLM layer fusion for enriched spatial context. The model is trained via single stage joint optimization from a pretrained VLM and randomly initialized action head. On the Meta-World MT50 benchmark spanning 50 diverse manipulation tasks, FabriVLA achieves a tier-average success rate of 90.0%, demonstrating that a compact VLA built on a 1B scale VLM can achieve strong performance without relying on multi billion parameter VLA backbones.

# FabriVLA 论文详细总结

## 1. 核心问题与研究动机

- **行业背景**：视觉-语言-动作（VLA）模型（如 RT-2、OpenVLA、π0）已成为通用机器人操作的代表性范式，通过预训练视觉-语言模型将语言指令与视觉观测对齐并生成动作序列。
- **核心矛盾**：现有高性能 VLA 模型参数量动辄数十亿，计算成本与推理延迟较高，难以满足实时机器人控制需求。
- **研究目标**：探索"轻量化 + 高性能"的 VLA 设计路径，证明基于 1B 级别 VLM 构建的紧凑型 VLA 无需依赖超大规模骨干网络即可实现强泛化能力。
- **关注焦点**：在保证多任务精度的同时，压缩模型规模、降低推理与训练开销。

## 2. 方法论

### 2.1 整体架构（三大组件）

- **视觉-语言骨干**：采用 InternVL3.5-1B，保留 14 层 Transformer；图像 resize 至 448×448，文本指令与视觉 token 拼接后输入。
- **状态/动作编码器**：24 维机器人状态经两层 ReLU MLP 编码为 1024 维 state token，拼接到 VLM context 前；50×24 的带噪动作经 MultiEmbodimentActionEncoder（共享 MLP + 水平位置编码）映射为 50×1024 的 action token。
- **流匹配动作头**：8 个 FabriVLA TransformerBlock 堆叠，输出经 LayerNorm、序列池化 MLP 后预测 50×24 的速度场。

### 2.2 关键技术创新

- **门控自注意力（Gated Self-Attention）**：
  - 公式：`A' = A + g · SelfAttn(LayerNorm(A))`，其中 `g ∈ R` 为可学习标量门，初始化为 0。
  - 效果：训练初期等价于"纯 cross-attention"，训练过程中门逐渐打开，平滑引入动作 token 之间的相互依赖建模，避免引入自注意力带来的优化不稳定。
- **浅层 VLM 层融合（Shallow Layer Fusion）**：
  - 同时抽取深层（layer 14，语义）与浅层（layer 6，空间）特征。
  - 采用 concat_proj 策略：`W ∈ R^{2048×1024}`，初始化为 `[I | 0]`，使得初始化时与"仅深层"基线完全等价，保证向后兼容。
  - 仅增加约 2.1M 参数。
- **流匹配训练**：
  - 插值公式：`x_t = (1-t)ε + t·a`，t 从 Beta(2,2) 分布采样（中间区域密度高）。
  - 目标速度：`v_θ ≈ a − ε`。
  - 损失函数：MSE（公式 6）。
  - 推理时从均匀噪声出发，50 步 Euler 积分生成动作块；闭环滚动执行。

### 2.3 训练策略

- **单阶段联合优化**：VLM 骨干与随机初始化的动作头从一开始就联合训练，所有参数全程解冻。
- **关键技术细节**：使用 DeepSpeed ZeRO-2 + FP32 master weights + BF16 混合精度（解决 BF16 量化噪声掩盖小梯度更新的问题）。
