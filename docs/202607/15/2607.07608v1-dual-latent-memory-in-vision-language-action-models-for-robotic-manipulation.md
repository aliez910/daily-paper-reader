## 摘要
主流的视觉-语言-动作（VLA）模型主要在马尔可夫假设下基于当前观测来预测动作，因此在长时序、时间依赖型任务中表现欠佳。现有的记忆增强型VLA方法要么扩展观测窗口，要么从记忆库中检索历史信息作为策略侧的辅助上下文。然而，它们将记忆置于VLA推理的原生潜在嵌入空间之外，导致历史经验无法与多模态推理及动作生成流畅地交织。为此，我们提出了LaMem-VLA，一个原生支持潜在记忆的框架，它将历史经验重构为潜在记忆标记，并将其直接交织到VLA推理过程中。其核心包含四个协同组件：（i）管理者，将历史经验组织为互补的短期与长期两个记忆库；（ii）检索者，利用多模态认知查询两个记忆库，以检索与上下文相关的证据；（iii）压缩者，将检索到的证据重构为紧凑的短期与长期潜在记忆标记；（iv）编织者，将这些记忆标记与当前观测及指令共同注入到一段连续的嵌入序列中。通过在同一连续潜在空间中完整地表示、检索和消费历史经验，LaMem-VLA使记忆能够直接参与VLA推理，并在有界上下文下引导动作生成。在SimplerEnv和LIBERO上的大量实验证明了LaMem-VLA的优越性。

## Abstract
Mainstream Vision-Language-Action (VLA) models predict actions primarily from the current observation under a Markovian assumption, thus struggling with long-horizon, temporally dependent tasks. Existing memory-augmented VLAs either expand the observation window or retrieve history from the memory bank as auxiliary policy-side context. However, they leave memory outside the native latent embedding space of VLA reasoning, preventing historical experience from being fluidly interleaved with multimodal reasoning and action formation. To this end, we introduce LaMem-VLA, a latent-memory-native framework that reconstructs historical experience into latent memory tokens and directly interweaves them with VLA reasoning. At its core, LaMem-VLA introduces four coordinated components: (i) a curator that organizes historical experience into two complementary short-term and long-term memory vaults; (ii) a seeker that queries both vaults using the multimodal cognition to retrieve context-relevant evidence; (iii) a condenser that reconstructs the retrieved evidence into compact short-term and long-term latent memory tokens; and (iv) a weaver that injects these memory tokens with the current observation and instruction into one continuous embedding sequence. By representing, retrieving, and consuming historical experience entirely in the same continuous latent space, LaMem-VLA enables memory to directly participate in VLA reasoning and guide action generation under a bounded context. Extensive experiments on SimplerEnv and LIBERO demonstrate the superiority of our LaMem-VLA.

# LaMem-VLA 论文总结

## 1. 核心问题与研究动机

- **根本问题**：主流视觉-语言-动作（VLA）模型在推理时隐式依赖**马尔可夫假设**，仅基于当前观测预测动作，导致出现"**时序短视偏差**（temporal short-horizon bias）"，在长时序、多步骤、时间强相关的操控任务中表现不佳。
- **现有方案的不足**：
  - **扩窗类方法**（如堆叠历史帧、视频序列扩展）：计算与显存开销随上下文线性增长，且固定窗口长度造成固有记忆上限，易丢弃任务相关证据。
  - **外部记忆库检索类方法**（如 MemoryVLA、MemER 等）：记忆存于模型原生 token 空间**之外**，仅作为"策略侧辅助上下文"在多模态推理完成后再注入，无法与 VLA 内部"感知—理解—动作意图形成"过程深度交织。
- **核心研究问题**：能否将历史经验表示为**与 VLA 同处同一连续潜在空间**的"上下文原生（context-native）"记忆，使其像视觉/语言 token 一样直接参与推理与动作生成？

## 2. 方法论

### 2.1 整体架构
LaMem-VLA 以 **7B 参数 Prismatic VLM** 为骨干 + 约 **300M 参数扩散动作专家**。给定当前观测 $o_t$ 与指令 $I$，输出未来 H 步的 7-DoF 末端动作序列。

### 2.2 四个核心组件
- **♣ 潜在记忆管理者（Curator）**：将历史经验分解到两个互补的记忆库中。
  - **短期记忆库** $\mathcal{M}_{\text{short}}$：存储视觉 token，使用 SE-bottleneck 压缩模块 $C_s$ 将 $X_t$ 压缩为 $v_s \in \mathbb{R}^{N_s \times C}$，均值池化得到检索键 $k_s$；每条记录为 $(k_s, v_s)$ 键值对。
  - **长期记忆库** $\mathcal{M}_{\text{long}}$：存储每个时间步的动作隐藏状态 $H_{\text{action}}$，无键值对结构，按时间累积。
  - **库容量更新策略**：超容量 $L$ 时，按相邻键余弦相似度合并最冗余的相邻单元（公式 4–5），兼顾去冗与保信息。
- **♦ 潜在记忆检索者（Seeker）**：以视觉 + 指令 token 构造多模态查询 $Q_t^{\text{con}}$，附加可学习槽位 $Q^{\text{init}}$，通过带掩码注意力的轻量 Transformer 构建器 $B$ 更新查询槽 $\hat{Q}_t \in \mathbb{R}^{K_q \times C}$；再以均值池化查询 $\bar{q}_t$ 对两个库做 **Top-K 余弦检索**（公式 7），得到 $\mathcal{Z}_{\text{short}}$ 与 $\mathcal{Z}_{\text{long}}$。Top-K 操作不可微。
- **♥ 潜在记忆压缩者（Condenser）**：引入可学习的短期槽 $T_s \in \mathbb{R}^{L_s \times C}$ 与长期槽 $T_l \in \mathbb{R}^{L_l \times C}$，与查询、检索证据共同送入记忆 Transformer $F_v / F_c$，输出**定长**的潜在记忆 token：
  $$M_{\text{short}} = F_v([\hat{Q}_t; \mathcal{Z}_{\text{short}}; T_s])[-L_s:],\quad M_{\text{long}} = F_c([\hat{Q}_t; \mathcal{Z}_{\text{long}}; T_l])[-L_l:]$$
  关键性质：与检索规模解耦，固定长度注入 VLA 推理。
- **♠ 潜在记忆编织者（Weaver）**：将 $M_{\text{short}}$、$M_{\text{long}}$（附加可学习源嵌入 $b_s, b_l$）与当前视觉、语言、可学习动作查询拼成一段**连续嵌入序列**：
  $$S_t = [M_{\text{short}}+1_{L_s}b_s^\top;\; M_{\text{long}}+1_{L_l}b_l^\top;\; X_t;\; I;\; Q_{\text{action}}]$$
  动作查询 $Q_{\text{action}}$ 输出隐藏态 $Z_{\text{action}}$ 在 VLA 内部**与记忆 token 做自注意力**，自然获得历史信息（公式 9）。

### 2.3 动作生成
- $Z_{\text{action}}$ 送入扩散动作专家，以 MSE 损失训练去噪网络（公式 10）。
- 推理时使用 **DDIM 10 步**采样，输出连续 7-DoF 动作块。

## 3. 实验设计

### 3.1 基准与场景
- **SimplerEnv-Bridge**（WidowX 机器人）：4 个任务，每个任务 24 次试验，使用 Bridge v2 真实数据训练，**真实到仿真**泛化评估。
- **LIBERO**（Franka 机器人）：5 个子套件（Spatial / Object / Goal / Long-10 / Long-90，合计约 120 任务），每个任务 50 次 rollouts。

### 3.2 对比方法（覆盖主流 VLA 与记忆增强 VLA）
- 经典方法：Diffusion Policy、Octo、RT-1-X、TraceVLA、UniACT、SpatialVLA、OpenVLA、CoT-VLA、CogACT、π0 / π0-FAST、Magma、DreamVLA、ThinkAct、CronusVLA、MemoryVLA、Fast-ThinkAct、SemanticVLA、LARA 等近 20 余种。

### 3.3 消融实验
- **双尺度记忆贡献**（去除短期、去除长期、去除双记忆）。
- **潜在原生 vs. 策略侧条件化**（Baseline、Policy-side Memory、Raw Retrieval Conditioning）。
- **检索预算 $K \in \{2,4,8,12\}$**。
- **记忆 token 数 $L_s$、$L_l$** 的影响。

## 6. 主要结论与发现

- **LIBERO**：LaMem-VLA 平均成功率 **97.6%**，各套件均 SOTA（98.8 / 99.0 / 97.2 / 95.8 / 97.0）；比 MemoryVLA 高 1.1 点，比 CogACT 高 4.4 点，比 π0（前四套件均值）高 3.5 点；长时序套件 Long-10 / Long-90 提升尤为显著（+2.4 / +1.4）。
- **SimplerEnv-Bridge**：平均 **73.9%**，超过 CogACT 16.6 点、π0 4.7 点，超过 MemoryVLA 2.0 点（73.9 vs 71.9）。
- **消融关键结论**：
  - 双尺度记忆缺一不可；同时移除短期 + 长期导致 SimplerEnv 暴跌 16.6 点（73.9→57.3）、LIBERO-90 下降 4.9 点。
  - **潜在原生编织显著优于外部条件化**：相比 Policy-side Memory 提升 +2.0 / +2.2 点；相比 Raw Retrieval 提升 +4.1 / +1.9 点，证明"嵌入空间内融合"是关键增益来源。
  - 检索数量与 token 数量存在最优值（$K=8$，$L_s=8, L_l=4$），过少信息不足，过多引入冗余与注意力负担。
- **总体结论**：将历史经验作为**上下文原生的潜在记忆 token**，使其直接参与 VLA 自注意力推理，是缓解长时序短视偏差的一种有效路径。

## 7. 优点与亮点

- **范式创新**：首次将"记忆"从"策略侧附加条件"提升为"上下文原生潜在 token"，与 VLM 内部嵌入空间完全同构，方法论上具有范式意义。
- **双尺度互补设计**：短期视觉证据 + 长期语义/动作连续性证据的形式化分工清晰，消融验证了二者互补而非冗余。
- **检索—压缩—编织三段式解耦**：检索规模与注入规模解耦，定长 token 保证上下文有界，工程友好。
- **与现有 SOTA 直接对比充分**：在 MemoryVLA、π0、SemanticVLA、CogACT 等强基线之上均取得提升，且在长时序套件上增益更显著，与论文方法定位高度一致。
- **超参数敏感性研究完整**：对 $K$、$L_s$、$L_l$ 三组关键超参均做了系统扫描，给出明确默认值与权衡讨论。

## 8. 不足与局限

- **仅仿真验证**：作者明确承认当前版本仅在 SimplerEnv 与 LIBERO 仿真环境评估，**真实机器人实验尚未完成**，且承诺在下一版本补充；这限制了对真实感知噪声、光照变化、硬件延迟等因素的鲁棒性结论。
- **未给出统计显著性**：所有成功率均为单次报告，**缺少多次种子方差与置信区间**，难以判断小幅提升（如 LIBERO 上 +1.1 点）的统计意义。
- **额外感知输入差异**：部分最强基线（如 π0-FAST）使用了本体感知 + 腕部相机，LaMem-VLA 仅使用第三人称 RGB + 指令；虽然论文标注星号说明差异，但公平性可能不完全对等。
- **算力与训练成本披露不全**：仅给出 H800×8 与优化步数，**未报告总训练小时数、能耗、数据吞吐**等，限制了可复现性与成本评估。
- **未与 MemoryVLA 等强记忆基线做逐任务细粒度对照分析**：仅给出平均成功率，未拆解"哪些任务类型上记忆机制最关键"。
- **检索的离散 Top-K 不可微**：检索阶段的硬选择与梯度脱钩，可能影响端到端优化空间，存在次优风险。
- **长期记忆的"语义—动作连续性"度量较隐式**：仅以动作隐藏状态累积，对跨回合/跨场景的更长期依赖处理能力仍待验证。
