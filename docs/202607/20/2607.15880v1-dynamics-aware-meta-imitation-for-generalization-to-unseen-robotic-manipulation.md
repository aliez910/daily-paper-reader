## 摘要
模仿学习旨在通过大量观察与示教为机器人学习技能，因而面临数据稀缺和环境泛化的难题。现有方法主要侧重于对同领域任务的模仿，难以泛化到未见过的任务。为弥合这一泛化差距，我们提出了**动力学感知元模仿**（Dynamics-Aware Meta-Imitation, DAMI）框架。通过融合元学习以构建共享技能空间，DAMI 使智能体能够快速适应新任务。我们引入了视觉-运动轨迹（Visual-Motor Trajectory, VMT）模块，以捕捉任务潜在空间中复杂的时空动力学。此外，我们提出了无配对统一任务（Unpaired Unified Task, U2T）模块，用于融合非结构化的多模态观测。为协调这些表征，我们整合了一种面向低级三维特征调制而设计的任务条件特征调制（Task-Conditioned Feature Modulation, TCFM）机制。通过从随机完整的参考示教中捕捉内在动力学，我们的框架学习的是任务背后的底层逻辑，而非记忆静态线索，从而确保有效的泛化性。在仿真和真实场景中的大量实验表明，我们的方法在已见任务的直接推理以及通过少样本微调适应未见任务方面均优于现有最先进的方法。

## Abstract
Imitation Learning aims to learn skills from extensive observations and demonstrations for robots, so it suffers from data scarcity and environment generalization. The existing methods predominantly focus on imitation from in-domain tasks and consequently struggle with generalization to unseen tasks. To bridge this generalization gap, we propose the \textbf{D}ynamics-\textbf{A}ware \textbf{M}eta-\textbf{I}mitation (DAMI) framework. By integrating meta-learning to construct a shared skill space, DAMI equips agents for rapid adaptation to novel tasks. We introduce the Visual-Motor Trajectory (VMT) module to capture complex spatio-temporal dynamics within the task latent space. Furthermore, we propose the Unpaired Unified Task (U2T) block to fuse unstructured multimodal observations. To coordinate these representations, we integrate a Task-Conditioned Feature Modulation (TCFM) mechanism customized for modulating low-level 3D features. By capturing intrinsic dynamics from a random complete reference demonstration, our framework learns the underlying task logic rather than memorizing static cues, ensuring effective generalization. Extensive experiments in both simulation and real-world settings demonstrate that our approach outperforms state-of-the-art baselines regarding direct inference on seen tasks and adaptation to unseen tasks via few-shot fine-tuning.

# 论文总结：面向未见过机器人操作任务泛化的动力学感知元模仿学习（DAMI）

## 1. 核心问题与研究背景

- **核心问题**：模仿学习（Imitation Learning, IL）依赖大量专家示教数据，且现有方法（无论是单任务策略还是多任务策略）大多在域内任务上训练，对**未见过的任务**（unseen tasks）和**分布外环境**泛化能力差，面临严重的"动作误判"（Action Misinterpretation）问题——即智能体记住静态视觉外观而非任务动态逻辑。
- **关键挑战**：
  - 示教数据采集成本高昂，无法为每个新任务都准备大量演示。
  - In-Context Imitation Learning（ICIL）虽无需梯度更新，但依赖视觉相似度而非任务动态与语义。
  - 3D Diffusion Policy（如 DP3）表达能力强，但模型容量大、依赖密集示教，在少样本条件下容易过拟合参考轨迹。
  - 现有元学习方法在大幅分布偏移下难以推断新任务动力学。
- **研究目标**：构建一个既能利用 3D 表征的强表达力，又能高效适配新任务的元模仿学习框架。

## 2. 方法论

### 2.1 整体框架：DAMI
- 以 **3D Diffusion Policy** 为基座，融合 **MAML（Model-Agnostic Meta-Learning）** 元学习目标，构建可在少样本下快速适配的共享技能初始化。
- 输入包括：当前观测（点云 + 机器人状态）、语言指令、完整的参考示教。
- 输出：长度为 H 的动作轨迹（预测时域为 16，作用步数为 8）。

### 2.2 三大核心模块

**(1) VMT（Visual-Motor Trajectory，视觉-运动轨迹）模块**
- 联合编码参考示教中的视觉特征与本体动作序列，捕捉"什么动作下场景如何变化"的时空动态，而非静态外观。
- 实现细节：
  - 将视觉特征 `fv,t` 与动作 `at` 拼接后经可学习线性投影 `ϕproj` 映射到统一潜在空间；
  - 叠加可学习位置编码后，通过 Transformer 编码器建模全局时序依赖；
  - 输入为完整 200 帧参考轨迹，输出为任务感知的时序 token 序列 `Hdemo`。

**(2) U2T（Unpaired Unified Task）模块**
- 解决多模态融合问题：参考示教（结构化序列）与当前观测（单帧）并非时间对齐（"unpaired"）。
- 流程：
  - 用冻结的 CLIP（ViT-B/32）编码文本指令 `ftext`；
  - VMT 编码参考示教 `Hdemo`；
  - 对 `Hdemo` 与 `ftext` 进行模态特定的仿射投影（LayerNorm + 线性变换）；
  - 当前观测 `fobs` 与扩散步嵌入 `ek` 拼接后经 MLP 形成 `hk`；
  - 在 U-Net 的**第一个下采样块**处，使用 Transformer 编码器将三者 token 融合生成 `CDown 1`；
  - 其余 U-Net 块仅使用更轻量的 `hk` 条件。

**(3) TCFM（Task-Conditioned Feature Modulation）**
- 基于 FiLM 机制对 U-Net 各块特征进行任务条件调制：
  - 第 j 个块的特征 `hj` 经 `γj(cj) ⊙ hj + βj(cj)` 调制；
  - 第一层 c_j = `CDown 1`（带 Transformer 融合），其余层 c_j = `hk`；
  - 早期下采样层负责几何 grounding 与接触推理，仅在第一层融合可降低计算开销。

### 2.3 元学习与训练流程
- **内循环**：在每个任务的 support batch 上做一次梯度更新，得到 θ′ᵢ = θ − α∇L_diff。
- **外循环**：保留计算图，使用全 MAML 二阶导数，在 query batch 上计算 meta-gradient，使用 AdamW（warmup + cosine 衰减）更新共享初始化；维护 EMA 副本。
- **新任务适配**：复制 EMA 策略作为初始化，用目标任务的少样本数据微调 200 步（仿真）或 500 步（真实）。
- **关键算法**：Algorithm 1（元训练）、Algorithm 2（新任务适配与评估）。

## 3. 实验设计

### 3.1 数据集 / Benchmark
- **Meta-World ML10**：10 训练 + 5 测试任务，测试快速适应能力。
- **Meta-World ML45**：45 训练 + 5 测试任务，测试大规模多任务泛化能力。
- **RLBench FS25**：25 训练 + 5 测试任务，测试 3D 操作跨任务适配能力。
- **真实场景**：UR10e + AG95 夹爪 + RealSense D435i 相机，5 个 base 任务（Close Drawer、Object Place、Press Button、Pull Ball、Sweep Cylinder）+ 2 个 novel 任务（Push Cube、Stack Cube），每任务 10 次示教。

### 3.2 基线方法
- **Meta-World RL**：标准强化学习基线。
- **DP3**：3D Diffusion Policy 经典基线。
- **Mamba Policy**：基于状态空间模型的 3D 扩散策略。
- **FreqPolicy**：频域一致性流策略。
- **FlowPolicy**：基于一致性流匹配的快速 3D 策略。
- 所有基线均扩展为多任务设置（联合训练）。

### 3.3 评估协议
- 所有仿真实验使用 3 个随机种子（0/1/2），每 200 个 epoch 评估一次，每任务 20 个 episode。
- Base 任务采用直接推理；Novel 任务采用 200 步少样本微调。
- 报告每个种子前 5 个 checkpoint 的平均值，再对 3 个种子取均值。

## 4. 资源与算力

- **软件框架**：PyTorch。

## 6. 主要结论与发现

- **ML10 base 任务**：DAMI 平均成功率 87.23%，超越所有基线（DP3 82.13% 等）。

## 7. 方法与实验设计的亮点

- **动力学感知而非外观匹配**：VMT 联合建模视觉与动作，捕捉"动作导致的变化"，是论文最具创新性的设计。

- **FiLM 风格的条件调制**：TCFM 将任务条件注入低层 3D 特征，避免在所有层都做重型 Transformer 融合。
- **元学习 + 扩散策略的有机结合**：在保留 3D Diffusion Policy 表达力的同时，借助 MAML 解决"模型容量 vs. 数据量"的不匹配问题。
- **充分的公平对比**：将多个单任务 SOTA 扩展为多任务版本并加 MAML 作为对照，避免"只是因为 MAML 所以赢"的质疑。
- **仿真 + 真实 + 定性 + 消融**：评估体系完整。
