## 摘要
世界动作模型 (WAM) 通过联合建模动作与未来视觉观察来提升机器人策略学习，利用未来场景演化作为密集监督信号，引导具有物理意义且合理动作的生成。然而，现有 WAM 普遍采用在推理时显式生成未来视频的设计，这会带来大量计算开销，阻碍实时闭环部署。GigaWorld-Policy 通过以动作为中心的建模方式解决这一问题：在训练阶段使用未来视觉动态信息，而在推理时仅进行动作解码。基于该框架，我们提出了 GigaWorld-Policy-0.5，一种面向更高效机器人控制而设计的增强型以动作为中心的 WAM。在预训练阶段，GigaWorld-Policy-0.5 采用动作条件世界建模 (AC-WM) 与 WAM 混合训练策略，强化了视觉动态与机器人动作之间的耦合，并提升了动作表示在下游策略学习中的迁移能力。为实现高效推理，GigaWorld-Policy-0.5 引入了混合 Transformer (Mixture-of-Transformers) 架构，将视觉动态建模与动作生成分离到不同的专用专家模块中，从而在仅进行动作推理时降低有效计算量，并在本地 RTX 4090 平台上实现 85 毫秒的推理延迟。此外，我们采用基于智能体的 AutoResearch 流水线来系统地搜索训练配置，从而更高效地识别最优实验方案，减少超参数调优所需的时间和人工干预。实验与消融研究表明，GigaWorld-Policy-0.5 在保留未来视觉动态训练收益的同时，提升了机器人控制的推理效率。

## Abstract
World Action Models (WAMs) improve robot policy learning by jointly modeling actions and future visual observations, using future scene evolution as dense supervision for physically grounded action generation. However, a common design in existing WAMs is to explicitly generate future videos at inference time, incurring substantial computational overhead and hindering real-time closed-loop deployment. GigaWorld-Policy addresses this issue with an action-centered formulation, where future visual dynamics are used during training while action-only decoding is used at inference time. Building upon this framework, we present GigaWorld-Policy-0.5, an enhanced action-centered WAM designed for more efficient robot control. During pretraining, GigaWorld-Policy-0.5 adopts a mixed Action-Conditioned World Modeling (AC-WM) and WAM training strategy. This strengthens the coupling between visual dynamics and robot actions and improves the transferability of action representations for downstream policy learning. For efficient inference, GigaWorld-Policy-0.5 introduces a Mixture-of-Transformers architecture that separates visual dynamics modeling and action generation into specialized experts, reducing active computation during action-only inference and achieving 85 ms inference latency on a local RTX 4090 setup. In addition, we employ an agent-based AutoResearch pipeline to systematically search training configurations, enabling more efficient identification of optimal experimental setups while reducing the time and manual intervention required for hyperparameter tuning. Experiments and ablations show that GigaWorld-Policy-0.5 preserves the training benefits of future visual dynamics while improving inference efficiency for robot control.

## 1. 核心问题与研究动机

- **背景**：世界动作模型（World Action Models, WAMs）通过**联合建模机器人动作与未来视觉观测**，利用未来场景演化作为密集监督信号，提升策略学习的物理一致性与泛化能力。
- **关键瓶颈**：现有 WAM 在推理时仍需**显式生成未来视频**（如迭代去噪、像素级 rollout），视频 token 的计算开销远高于动作 token，带来两方面问题：
  - **实时性差**：难以满足机器人闭环控制的低延迟需求；
  - **误差累积**：长时序想象中的视觉错误会反向影响动作生成质量。
- **核心矛盾**：如何在保留"动作–视觉动态耦合"带来的训练收益（更强物理监督）的同时，**避免推理时的视觉生成开销**。
- **本文定位**：在 GigaWorld-Policy 的"动作中心化"框架基础上进一步增强，引入 Mixture-of-Transformers 架构与自动化超参搜索，实现更快的推理与更强的策略表现。

## 2. 方法论

### 2.1 整体框架：动作中心化的因果 WAM

- 形式化定义：给定多视角观测 $\{o_t^{left}, o_t^{front}, o_t^{right}\}$、本体感知状态 $s_t$ 与语言指令 $l$，联合预测：
  - 长度为 $p$ 的动作 chunk：$\hat{a}_{t:t+p-1}$；
  - 步长为 $\Delta$ 的未来观测：$\hat{o}_{t+\Delta:t+K\Delta}$，其中 $K=\lfloor p/\Delta \rfloor$。
- **因果掩码策略**（继承自 GigaWorld-Policy）：
  - 动作 token 只能关注当前观测、状态、文本条件，**不可关注未来视觉 token**；
  - 未来视觉 token 可关注动作 token（实现动作条件化视频预测）；
  - 优势：训练时未来视觉提供密集监督，推理时可**完全跳过未来视觉 token** 直接解码动作。

### 2.2 训练目标：Flow Matching

- 采用 Flow Matching 框架，分别对动作与未来视觉施加模态专属的 flow-shift 因子 $\gamma_a, \gamma_v$ 与时间步 $\tau_a, \tau_v$；
- 通过线性插值构造噪声化的联合 token $x_\tau$，优化模型预测速度场 $g_\theta(x_\tau, \tau | \cdot)$ 与真值速度 $v_\tau$ 的 L2 损失。

### 2.3 Mixture-of-Transformers (MoT) 架构

- 将单一共享 Transformer 拆分为两个专家：
  - **视觉专家（Visual Expert）**：处理当前与未来视觉 token，建模场景演化；隐藏维度 3072，FFN 维度 14336；
  - **动作专家（Action Expert）**：专门处理动作 token 的去噪与生成；隐藏维度 1024，FFN 维度 4096（更轻量）。
- 两个专家通过**多模态自注意力**交互，沿用动作中心化的因果掩码。
- 关键设计：
  - 视觉专家由 **GigaWorld-1**（大规模预训练视频世界模型）权重初始化，继承视觉动力学先验；
  - 动作专家从视觉专家权重初始化，维度不匹配时取前 $n$ 维（截断兼容）；
  - 推理时仅激活动作专家路径，显著降低有效计算量。

### 2.4 混合 AC-WM + WAM 预训练策略

- **WAM 训练**：联合预测动作与未来视觉；
- **AC-WM（Action-Conditioned World Modeling）训练**：在动作条件下预测未来视觉演化；
- 二者混合训练的优势：
  - 强化"动作如何驱动视觉变化"的建模能力；
  - 提升动作表示的迁移性，使下游策略后训练更样本高效。

### 2.5 训练流程

- **预训练**：在 2K 小时筛选后的开源机器人数据 + 内部真实机器人数据上训练，注入 AC-WM 训练；
- **后训练**：在目标真实机器人轨迹上联合优化动作预测与未来视觉预测；
- **部署**：仅使用动作中心推理路径。

### 2.6 推理加速

- **KV 缓存**：自回归动作生成时缓存视觉/语言上下文键值，避免重复注意力计算；
- **torch.compile**：算子融合、减少 Python dispatch 开销；
- **C++ 运行时**：集成图像预处理、张量构造、模型执行、KV 缓存管理、动作后处理，去除 Python 依赖，便于与机器人中间件集成。

### 2.7 基于智能体的 AutoResearch 流程

- 自动完成候选配置生成 → 短程 Pilot 训练 → 验证指标采集 → 候选筛选 → 长程扩展训练的完整闭环；
- 在 pick-the-fruit 任务上：
  - 930 episodes（300 train / 30 val）；
  - 1K-step Pilot 扫描学习率与 batch size；
  - 选定 LR=$6\times10^{-5}$，batch size=16；
  - 最终扩展至 30K 步取得最佳验证动作 MSE。
