## 摘要
类似于人类依次学习新任务的天然能力，具备视觉-语言-动作（VLA）模型的机器人应拥有终身学习能力，以便在开放世界环境中部署时学习新任务。然而，大多数近期提出的终身学习模型仅聚焦于有效学习当前任务（可塑性）或在先前任务上保持高精度（稳定性），而可塑性-稳定性权衡问题在机器人操作模型中仍未得到很好解决。为应对这一根本性挑战，我们提出了一种面向机器人操作的可终身视觉-语言-动作学习框架（即 LifelongVLA），通过双时间尺度自适应机制缓解可塑性-稳定性权衡，同时借助缓存高效回放策略实现低成本机器人部署。具体而言，我们提出了一个双时间尺度 LoRA 门控模块，将 VLA 自适应分解为两条轻量化路径：用于可塑性的短期适配器与用于稳定巩固的长期适配器。这些路径通过一个任务感知门控进行集成，从而能够显式调控可塑性-稳定性权衡。在技能回放阶段，提出了一种缓存高效的随机回放策略，以在无需完整轨迹存储的条件下保留更加均衡的保留信号。最后，实验表明 LifelongVLA 优于现有基线方法，展现了高效的能力扩展、对已学操作行为的鲁棒保留，以及在 xArm 机器人上进行真实部署时对重新训练依赖的显著降低。

## Abstract
Similar to the natural capabilities of humans to sequentially learn new tasks, robots with Vision-Language-Action (VLA) models should possess lifelong learning ability to learn a new task when deployed in open-world environments. However, most recently proposed lifelong learning models aim to effectively learn the current task (plasticity) or maintain high accuracy on previous tasks (stability), while the plasticity-stability trade-off remains largely unsolved in robotic manipulation models. To address this fundamental challenge, we propose a cache-efficient lifelong Vision-Language-Action learning framework for robotic manipulation (i.e., LifelongVLA), which alleviates the plasticity-stability trade-off with a dual-timescale adaptation mechanism while achieving low-cost robotic deployment with a cache-efficient replay strategy. More concretely, we propose a dual-timescale LoRA gating module to decompose VLA adaptation into two lightweight pathways: a short-term adapter for plasticity and a long-term adapter for stable consolidation. These pathways are integrated via a task-aware gate, enabling explicit control of the plasticity-stability trade-off. In the skill replay phase, a cache-efficient stochastic replay strategy is proposed to preserve more balanced retention signals without full-trajectory storage. Finally, experiments show that LifelongVLA outperforms existing baselines, demonstrating efficient skill expansion, robust retention of learned manipulation behaviors, and reduced reliance on retraining for real-world deployment on an xArm robot.

# LifelongVLA 论文总结

## 1. 核心问题与研究动机

- **背景**：Vision-Language-Action（VLA）模型（如 RT-2、π0、Octo 等）已成为语言条件机器人操作的主流范式，但现有模型普遍采用"静态离线训练"——在固定技能集上训练一次后即部署，难以应对开放世界中不断涌现的新物体、新指令、新场景布局和新动作分布。
- **核心问题**：机器人需要像人类一样具备**终身学习（lifelong learning）**能力——能在部署后持续学习新技能，同时不遗忘已学技能。但机器人终身学习中存在**可塑性-稳定性权衡（plasticity-stability trade-off）**这一根本性挑战：
  - 高可塑性 → 快速学习新技能，但可能覆盖已学行为；
  - 高稳定性 → 保留旧技能，但可能限制未来学习。
- **现有方案的不足**：
  - 顺序微调（sequential fine-tuning）会导致灾难性遗忘；
  - 全数据重训练成本过高；
  - 回放缓冲（replay buffer）、架构扩展、参数隔离等方法仍未充分解决该权衡；
  - 全轨迹回放需要存储和重新编码图像密集的旧回合，计算开销巨大。

## 2. 方法论

LifelongVLA 是一个**基于冻结 VLA 主干**的缓存高效终身学习框架，包含两大核心模块：

### 2.1 双时间尺度 LoRA 门控（Dual-Timescale LoRA Gating）

- **核心思想**：将 LoRA 适配分解为**短期路径**和**长期路径**，分别负责可塑性与稳定性，通过任务感知门控显式调节。
- **两条路径**：
  - 短期路径 ΔW^sh = A^sh · B^sh：由当前任务损失 L_new 更新，负责快速学习新技能（高可塑性）。
  - 长期路径 ΔW^lg = A^lg · B^lg：仅由回放损失 L_rep 和蒸馏损失 L_dist 更新，且学习率 η_lg < η_sh，负责巩固旧技能（高稳定性）。
- **共享门控（Shared Gate）**：
  - 门控上下文 c 由冻结前缀特征池化得到（避免循环依赖）：c = Pool(stopgrad(E_pre(u; Θ₀)))。
  - 门控值 α_t(c) = σ(W_g · ϕ(c) + b_g) ∈ [0,1]，由样本决定，参数跨任务共享。
- **权重级组合**：
  - ΔW_t(c) = (1 − α) · ΔW^sh + α · ΔW^lg
  - 权重 W_t = W₀ + γ · ΔW_t(c)
  - α → 0 强调短期可塑性；α → 1 强调长期稳定性。
  - **单次前向推理**即可完成，门控在权重级而非输出级融合。

### 2.2 缓存高效随机回放（Cache-Efficient Stochastic Replay）

- **核心思想**：仅存储每个技能的少量随机样本的**停止梯度前缀 token**（不含图像、原始观测），回放时再用当前模型重新计算后缀特征。
- **技能级前缀缓存**：
  - 每个任务选取 c_t = 50 个样本，仅存储 stopgrad(h_pre) 与状态-动作监督 (s, y)；
  - 不存储原始图像、语言 token、后缀 token、扩散时间或噪声。
- **随机回放与重新计算的后缀**：
  - 对每个缓存样本，重新采样扩散变量 (τ', ε')，并用当前模型重新计算后缀：
    - h_suf,rep = E_suf(s, ỹ, τ'; Θ̂_t)
  - 每个缓存前缀可在每次回放时生成多个随机实例，提供多样化的保留信号。
- **遮蔽的新-回放目标函数**：
  - L_t = L_new + λ · L_rep + β · L_dist
  - L_new 和 L_rep 分别按新样本和回放样本数独立归一化，避免任一方主导；
  - L_dist 通过上一任务教师模型 F̄_{t−1} 的预测进行蒸馏，稳定旧技能预测。

## 3. 实验设计

### 3.1 数据集与场景

- **仿真基准**：LIBERO 基准中的 **10 个任务**，按增量学习设置（每个增量步引入一个新任务）。
- **真实机器人**：xArm 机器人上的 **5 个真实任务流**，每个任务收集 50 条训练回合，每个任务用 50 条评估回合评估。
- **VLA 主干**：冻结的 PaliGemma（Gemma 2B）+ Gemma 300M 连续动作解码器，输出 7D 机器人动作（扩散式动作预测）。

### 3.2 对比方法

| 方法 | 类型 |
|------|------|
| **SFT**（顺序微调） | 朴素基线 |

| **ER** [2019] | 情景回放 |

| **AtomicVLA** [2026] | 技能级专家特化 |

### 3.3 评估指标

- **SR**（Success Rate）：最终平均成功率；
- **FOR**（Forgetting Rate）：在已见任务上的遗忘率；
- **ACC_t**：增量步 t 的增量准确率；
- **稳定性-可塑性曲线**。

### 3.4 训练配置

- 终身方法每任务训练 **10,000 步**；联合训练 40,000 步；
- LoRA rank r = 16，缩放因子 γ = 16，batch size M = 500，缓存 c_t = 50，λ = 1.0，β = 0.1；
- 所有方法使用相同的任务顺序、动作空间、仿真协议；测试时不提供任务标识。

## 6. 主要结论与发现

- **整体性能**：LifelongVLA 平均 **SR = 83.2%**，平均 **FOR = 11.4%**，比最强基线 ER 分别提升 **13.0 个百分点**（SR）和 **8.2 个百分点**（FOR）。
- **任务级表现**：在任务 5、9、10 上分别达到 96%、98%、96% 的成功率；任务 9 的遗忘率降至 0。
- **效率**：相比 AtomicVLA（226.49M 参数、452.98 MiB/task），LifelongVLA 仅需 99.97M 参数和 95.70 MiB/task，参数减半以上。
- **消融结论**：
  - 潜在回放相比原始数据回放，内存从 167.62 MiB/task 降至 95.70 MiB/task，且 FOR 更低；
  - 双 LoRA 相比单 LoRA，SR 提升约 8.6 个百分点，FOR 降低约 10.4 个百分点，验证了双时间尺度设计的必要性。
- **真实部署**：xArm 上 5 任务最终 SR 均超 80%，定性回放展示成功执行。

## 7. 优点与亮点

- **问题定义精准**：明确聚焦 VLA 终身学习中的可塑性-稳定性权衡，而非泛泛而谈持续学习。
- **架构设计优雅**：
  - 双时间尺度 LoRA 在权重级融合，**单次前向推理**即可，无需两次前向或额外路由开销；
  - 门控上下文来自冻结前缀特征，避免循环依赖。
- **回放机制创新**：仅存储 stop-gradient 前缀 token + 紧凑状态-动作监督，大幅压缩内存；同时通过随机扩散变量重新计算后缀，缓解"缓存陈旧"问题。
- **损失平衡**：新任务损失与回放损失分别归一化，防止任一方主导训练。
- **部署友好**：内存成本低、可训练参数少、真实机器人验证可落地。
