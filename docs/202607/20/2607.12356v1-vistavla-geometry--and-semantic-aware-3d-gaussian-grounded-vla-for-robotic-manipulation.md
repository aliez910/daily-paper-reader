## 摘要
视觉-语言-动作（VLA）模型通过将语言指令和二维视觉输入直接映射为动作，已成为机器人操作领域中一种强大的端到端范式。然而，这些模型缺乏显式的场景级三维表示，限制了其对空间布局和几何约束进行推理的能力。虽然近期工作尝试引入显式的三维线索（如深度图或点云）以增强几何感知能力，但其主要捕获的是低级结构，缺乏三维空间中的高级语义基础。在人类认知中，与物理世界的交互依赖于一种三维语义认知地图——一种将空间布局与语义上下文相整合的内部心智模型，以实现持续的、与视角无关的推理。基于此，我们提出了VistaVLA，一种新颖的两阶段框架，该框架从三维高斯基元构建几何与语义感知的三维认知表示，并将其作为紧凑的上下文令牌用于VLA策略学习。具体而言，VistaVLA将多视角视觉-语言特征提升到三维高斯基元中，形成几何锚定的语义令牌，使视图一致的空间基础与二维视觉特征空间对齐。为了使该三维表示在计算上易于处理以实现有效的VLA控制，我们引入了"先合并再查询"（Merge-then-Query, MtQ）这一令牌汇总机制。MtQ将密集的高斯基元压缩为一组高度紧凑且具有空间信息性的令牌，在保留与动作相关的三维布局和语义上下文的同时，实现了99%的令牌压缩率。在仿真和真实环境中的大量评估证明了VistaVLA的有效性。值得注意的是，在真实场景中，VistaVLA在七项真实任务上将成功率提升了22.8%，并在具有挑战性的分布外任务上较VLA-Adapter基线提升了30.0%。

## Abstract
Vision-Language-Action (VLA) models have emerged as a powerful end-to-end paradigm for robotic manipulation by mapping language instructions and 2D visual inputs directly to actions. However, these models lack an explicit, scene-level 3D representation, limiting their ability to reason over spatial layouts and geometric constraints. While recent efforts incorporate explicit 3D cues, such as depth maps or point clouds, to improve geometric awareness, they primarily capture low-level structures and lack high-level semantic grounding in 3D space. In human cognition, interaction with the physical world relies on a 3D semantic cognitive map - an internal mental model that integrates spatial layouts with semantic context to enable persistent, viewpoint-invariant reasoning. In light of this, we present VistaVLA, a novel two-stage framework that constructs a geometry- and semantics-aware 3D cognitive representation from 3D Gaussian primitives and grounds it as compact context tokens for VLA policy learning. Specifically, VistaVLA lifts multi-view vision-language features into 3D Gaussian primitives, forming geometry-anchored semantic tokens that align view-consistent spatial grounding with 2D visual feature spaces. To make this 3D representation computationally tractable for effective VLA control, we introduce Merge-then-Query (MtQ), a token summarization mechanism. MtQ compresses dense Gaussian primitives into a highly compact set of spatially informative tokens, achieving a 99% token reduction while preserving action-relevant 3D layouts and semantic context. Extensive evaluations in both simulated and real-world environments demonstrate the effectiveness of VistaVLA. Notably, in real-world scenarios, VistaVLA improves success rates by 22.8% across seven real-world tasks and by 30.0% over the VLA-Adapter baseline on challenging out-of-distribution tasks.

# VistaVLA 论文总结

## 1. 核心问题与整体含义（研究动机与背景）

- **现有 VLA 范式的不足**：
  - 主流 Vision-Language-Action 模型（如 OpenVLA、π0、VLA-Adapter）依赖 2D 图像输入，**缺乏显式的场景级 3D 表示**，无法有效推理空间布局与几何约束，在精确或接触密集型操作任务中容易失败。
  - 近期引入 3D 线索的工作（如 SpatialVLA 的深度图、PointVLA 的点云、3D-VLA 等）虽能改善几何感知，但**只编码低级结构**，且难以与 2D 预训练 VLM/LLM 的 patch-token 空间对齐，**缺乏 3D 空间中的高层语义锚定**。
- **认知科学启发**：人类与物理世界交互依赖"3D 语义认知地图"——一种将连续空间拓扑与功能语义统一起来的内部心智模型，支持持久、视角无关的推理。
- **关键缺口**：当前 VLA 缺少一种**场景级、语义与几何联合、可作为策略接口**的 3D 表达，且要兼顾计算实时性。

## 2. 方法论：核心思想与关键技术细节

### 2.1 整体框架
VistaVLA 采用**两阶段**：
- **Stage I**：从多视角 RGB-D 离线构建一个**语义高斯场**（Semantic Gaussian Field），将开放词汇语义特征蒸馏到 3D 高斯基元中。
- **Stage II**：在线（每个控制步）从当前多视角 RGB + 标定相机位姿构建语义高斯场，并使用 **Merge-then-Query (MtQ)** 模块将 ~10⁵ 个高斯基元压缩为 64 个紧凑 3D 摘要令牌，经 cross-attention 注入 VLA 策略。

### 2.2 Stage I — 3D 高斯认知表征

- **紧凑教师特征空间**：先用 SigLIP2 + DINOv2-Large 提取多视角稠密特征（2176 维），通过轻量 auto-encoder 压缩到 **128 维瓶颈**，作为后续高斯特征渲染的 teacher。
- **两阶段训练（基于 DepthSplat）**：
  - 每个高斯基元 `g_i = (μ_i, Σ_i, α_i, c_i, z_i)`，其中 `z_i ∈ R^128` 为可学习语义特征。
  - 渲染器输出 RGB、深度、特征图：`(Î_v, D̂_v, F̂_v) = R(G, v)`，遵循与 3DGS 一致的 α-blending。
  - 阶段一损失：`L_stage1 = λ_rgb L_rgb + λ_dep L_dep`（仅几何）。
  - 阶段二损失：`L_stage2 = λ_rgb L_rgb + λ_dep L_dep + λ_feat L_feat`，其中  
    `L_feat = Σ_v Σ_p ||F̂_v(p) - F_v^teacher(p)||²`，通过多视角监督使 `z_i` 既保持 2D 语义对齐，又被底层 3D 几何与可见性约束。
- **训练时**：使用两视角 RGB-D 作为上下文，渲染第三视角作为新视角监督，强制跨视角一致性。**推理时无需深度输入或第三视角**，实时构建高斯场。

### 2.3 Stage II — Merge-then-Query (MtQ) 压缩

- **挑战**：高斯场含 ~10⁵ 个基元，直接送入 VLA 计算不可行。
- **参数无关压缩**：
  1. 按视角 reshape 后做 **stride-4 平均池化**（语义特征 + 3D 中心），token 数粗降至约 7K。
  2. 按 3D 中心的 **Morton 编码排序**，交替切分为 anchor 集合 A 和 non-anchor 集合 B。
  3. 每个 non-anchor token `u` 在语义空间寻找最相似 anchor `a*(u) = argmax⟨z_u, z_a⟩/‖z_u‖‖z_a‖`。
  4. 仅合并相似度排名前 50% 的匹配对，按聚合尺寸 `s` 做加权平均：  
     `z'_a = (s_a z_a + Σ s_u z_u) / S_a`，`μ'_a` 与 `s'_a` 同理。
  5. 重复至 token 数 `N' ≈ 1000`。
- **查询式 GS 汇总**：
  - 64 个可学习查询 `Q ∈ R^{B×64×d}` 通过 **2 层 Transformer Decoder**（cross-attention）对压缩后的 `Z'` 做注意力汇聚。
  - 投影至 VLA 隐藏维度 `d_llm`，输出 `X_gs ∈ R^{B×64×d_llm}`。
  - 整体压缩率约 **99%**。

### 2.4 动作生成（基于 VLA-Adapter）
- 序列拼接：`X = [X_vis, X_lang, X_gs, X_act]`，使 GS 上下文受语言条件化后再由 action query 关注。
- 动作头预测连续动作序列，训练目标 `L_act = Σ ||â_t - a_t||₁`。
- 真实机器人执行时取前 K_exec=4 个动作再重规划，降低开环误差积累。

## 6. 主要结论与发现

- **真实世界**：7 任务平均 SR 较 baseline 提升 **22.8 个百分点**，在空间敏感任务上提升尤为显著。
- **空间 OOD 鲁棒性**：PlaceSponge depth 扰动从 6/10 提升至 **9/10**；OrganizeSponge position 扰动从 0/10 提升至 **3/10**（所有 baseline 在该设置下全部失败）。
- **仿真**：标准 LIBERO 平均 SR **96.05%**（无大规模预训练方法中最高）；LIBERO-Pro-Swap 从 1.7% 提升至 **12.2%**。
- **消融结论**：
  - 增益主要来自 3D 语义高斯接口本身，而非单纯增加相机数或视觉 token 数。
  - Morton-guided 合并 + Query Decoder 均不可或缺。
  - 查询数 64 为最佳，过多（256）反而损害性能。

## 7. 优点与亮点

- **认知启发式 3D 语义接口**：模仿人类 3D 认知地图，将开放词汇语义与 3D 几何联合编码到高斯基元上。
- **极高压缩率**：99% 的 token 压缩（~10⁵ → 64），同时保留动作相关的空间布局与语义上下文。
- **端到端可在线构建**：每个控制步从当前 RGB + 标定位姿实时构建高斯场，无需持久预建地图。
- **几何保持 + 语义锚定**：通过 α-blending 的特征渲染损失，使每个 GS token 成为多视角一致的语义描述子。
- **跨方法兼容**：作为通用接口可替换不同 VLA backbone（实验基于 VLA-Adapter-0.5B 已验证）。
- **消融完整**：从相机、压缩策略、查询数三个维度均验证关键设计选择。
