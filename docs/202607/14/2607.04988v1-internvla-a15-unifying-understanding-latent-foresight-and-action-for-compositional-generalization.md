## 摘要
面向机器人操控的统一模型旨在使单一策略同时具备预训练视觉语言模型的语义先验以及通过未来预测习得的物理动力学。然而，现有设计在实际中往往会使预训练骨干网络的语义能力退化，遭受异构目标之间的相互干扰，并且从零开始在像素空间中学习未来预测，导致预训练视频生成器的动力学先验未能得到利用。本文提出 InternVLA-A1.5，它基于一个原生视觉语言模型骨干构建策略，持续在视觉问答和子任务预测任务上进行训练，并附加一个轻量级的统一专家模块以生成连续动作。未来预测被重新表述为一个潜在查询问题：少量可学习的预测令牌在冻结的预训练视频生成模型的监督下，将与任务相关的未来压缩为一个紧凑的潜在编码，使策略在不学习像素级生成的前提下继承世界模型的动力学先验。推理时视频分支被丢弃，从而保持实时控制能力。InternVLA-A1.5 在 120 万条机器人轨迹和 300 万条多模态样本上进行预训练，在全部六个仿真基准上取得了最佳的综合表现。在真实场景中，所保留的语义能力使其在未见过的指令组合绑定上展现出最强的组合泛化能力，这两项设计共同支撑了长时序任务的执行。

## Abstract
Unified models for robot manipulation aim to equip one policy with both the semantic priors of pretrained VLMs and the physical dynamics learned through future prediction. In practice, existing designs tend to erode the semantics of the pretrained backbone, suffer interference among heterogeneous objectives, and learn future prediction from scratch in pixel space, leaving the dynamics priors of pretrained video generators unexploited. We present InternVLA-A1.5, which builds the policy on a native VLM backbone that keeps training on VQA and subtask prediction, and attaches a lightweight unified expert for continuous action generation. Future prediction is recast as a latent-querying problem, where a small set of learnable foresight tokens condenses the task-relevant future into a compact latent code under the supervision of a frozen pretrained video generation model, so the policy inherits world-model dynamics priors without ever learning pixel-level generation. The video branch is discarded at inference, keeping real-time control. Pretrained on 1.2M robot episodes and 3M multimodal samples, InternVLA-A1.5 achieves the best overall results on all six simulation benchmarks. In the real world, the preserved semantics deliver the strongest compositional generalization on held-out instruction bindings, and the two designs together sustain long-horizon execution.

# InternVLA-A1.5 论文总结

## 1. 核心问题与研究动机

- **研究背景**：通用机器人操控需要同时具备预训练视觉语言模型（VLM）的语义先验与视频生成模型所蕴含的物理动力学先验，由此催生了 Vision-Language-Action（VLA）与 World Action 等统一模型路线。
- **现有方法的三大痛点**：
  - **语义退化**：一旦在 VLM 骨干上叠加重的生成与动作目标，便停止大规模 VQA / 语言训练，导致预训练语义知识漂移，指令跟随能力下降。
  - **目标异构干扰**：视觉潜变量回归、流匹配动作预测、下一词预测等目标在尺度与形式上差异大，联合训练时相互干扰。
  - **像素级未来预测浪费先验**：从零开始学习重建未来图像，未利用大规模预训练视频生成器已编码的时空动力学先验。
- **核心矛盾**：如何在统一模型中同时注入世界动力学先验，又不损害语义能力、避免像素级生成的巨大开销。

## 2. 方法论

### 2.1 整体架构（Mixture-of-Transformers）

- **VLM 骨干**：Qwen-3.5 2B，采用混合注意力（1 层 Full Attention + 3 层 Gated DeltaNet 线性注意力交替）。
- **统一专家（Unified Expert）**：与 VLM 同构的轻量模块（约 460M 参数，更小隐藏维度），仅通过共享的 Full Attention 层与 VLM 交互，Gated DeltaNet 层保持独立。
- **输入格式**：多视角图像块 + 语言指令 + 控制模式 token（`<joint>`/`<end_effector>`/`<vqa>`）+ 经 256 桶离散化的本体状态 token。动作通过 FAST tokenizer 离散化为 2048 词表，追加进 VLM 原生词表。

### 2.2 三阶段训练流程

- **阶段 1（VLM 迁移）**：在机器人数据 + VQA 数据上联合训练 VLM，监督目标包括子任务文本输出、FAST 离散动作 token、VQA 答案；统一交叉熵损失，单一损失函数。
- **阶段 2（前瞻 + 连续动作生成）**：
  - 引入统一专家与 50 个可学习 **foresight tokens**；
  - 冻结 WAN2.2-5B 视频生成器（去掉原 T5 文本编码器），用 foresight 输出作为条件，通过流匹配视频损失监督；
  - 同时训练统一专家用流匹配预测连续动作块（Euler 积分推理）。
- **后训练**：可选开启视频分支，下游演示数据微调 foresight tokens。
- **总损失**：$L_{stage2} = L_{stage1} + \alpha L_{video} + \beta L_{action}$，其中 $\alpha=1$，$\beta=10$。

### 2.3 关键设计：潜在前瞻（Latent Foresight）

- **核心思想**：未来预测被重新定义为"潜在查询问题"——少量 foresight tokens 通过统一专家关注多模态上下文，输出一个紧凑潜在编码 $C_t^f = P_{WAN}(Z_t^f)$，用于条件化冻结视频生成器。
- **视频损失**（沿用 WAN 的 flow-matching 目标）：$L_{video} = \mathbb{E}\|u(x_s, C_t^f, s) - v_s\|^2$，梯度仅经由条件通路回传到 foresight tokens 与上游专家层。
- **动作损失**：统一专家基于 $H_t$ 与 foresight tokens 预测速度场；推理时初始化为高斯噪声，Euler 积分得到连续动作块。
- **推理优势**：视频生成分支在部署时完全丢弃，不引入额外延迟，每步推理约 0.1s（RTX 5090 上）。

### 2.4 注意力掩码设计

- VLM token（图像、指令、状态、子任务、FAST）保持 Qwen3.5 因果注意力。
- 统一专家中：foresight tokens 与 action embeddings 跨组因果、组内双向（匹配流匹配的并行去噪特性）。
- 训练时统一专家对 FAST token 的注意力被显式屏蔽，避免信息泄漏与梯度干扰；位置 ID 在训练/推理间保持一致。

## 3. 实验设计

### 3.1 数据

- **机器人数据**：1.2M episodes、861M frames，包括 InternData-A1（合成）、AgiBotWorld、UMI、DROID、Galaxea、RoboMind 1.0，统一到 InternVLA-A1 的动作空间；sim 与 real 各约一半。
- **多模态数据**：~3M 样本（General QA 637K、Box QA 879K、Point QA 832K、Trajectory QA 684K），保证 VLM 语义与空间接地能力不退化。
- **采样策略**：两级分组采样，组内按帧数 $\gamma$ 比例（$\gamma=1$ 即帧比例），组间权重先用 Re-Mix 后手工微调；机器人与多模态按 0.15 : 0.85 比例混合。

### 3.2 仿真基准（6 个）

- LIBERO（4 套件 / 2000 demonstrations）
- LIBERO-Plus（零样本鲁棒性测试）
- RoboTwin 2.0（50 个双臂任务，clean + domain-randomized）
- DOMINO（动态操控，零样本 + 微调）
- EBench（移动操控，Val-Train / Val-Unseen / Test）
- SimplerEnv（WidowX，real-to-sim）

### 3.3 真实世界任务（4 个）

- **Sort Tubes / Insert Tubes / Move Tubes**：指令跟随任务，使用 hold-out 指令绑定设计（如 Sort Tubes 反转"臂-颜色"组合、Insert Tubes / Move Tubes 反转"颜色-目标孔位"组合），分别测试组合泛化能力。
- **MOF**：长程化学实验（金属有机框架合成），13 个子步骤，包含漏斗插入、液体倾倒、磁力搅拌器开关等。
- 对比基线：**π₀.5** 与 **Motus**；评估协议相同（随机化摆放，多次试验取成功率）。

### 3.4 主要对比方法

π₀、π₀.5、GR00T-N1.5/N1.7、OpenVLA-OFT、InternVLA-M1、InternVLA-A1、EO-1、Xiaomi-Robotics-0、StarVLA、Abot-M0、Cosmos-Policy、LingBot-VLA/VA、Fast-WAM、Being-H0.7、Qwen-VLA-Base/Instruct、XVLA 等。

## 4. 资源与算力

- **真实世界推理**：单卡 **NVIDIA RTX 5090**，启用静态图执行、SDPA 与 flash-linear-attention 库，每步推理约 **0.1s**。
- **预训练超参**：Stage1 300K steps、Stage2 600K steps，batch size 1024，常数学习率 5e-5，bfloat16；Stage1/2 后训练 60K steps，cosine 衰减（5e-5 → 5e-6），batch size 128。
- **RoboTwin 2.0 微调**：24 GPUs，batch size 16/GPU，训练 100K steps，最大学习率 1e-4，140K 步衰减；动作块 18，执行块大小 18。
- **EBench 微调**：batch size 128，仅训练 100K steps（比基线更快收敛）。
- **未明确披露**：总预训练算力（GPU 总数与时长）、视频生成分支的显存开销等。

## 5. 实验数量与充分性

- **仿真基准**：6 个，覆盖单臂、双臂、移动操控、零样本鲁棒性、动态操控、real-to-sim 等多种场景。
- **真实世界**：4 个任务，每个指令跟随任务还细分为 seen / held-out 两类绑定，MOF 设有 20 次随机化试验。
- **消融实验**：对视频损失与 foresight tokens 两项核心组件在 LIBERO / LIBERO-Plus / RoboTwin / DOMINO 上进行双因素消融。
- **分析维度**：训练效率曲线（SFT loss 对比）、视频生成器条件化预测可视化（覆盖标准与零样本设置）、seen vs. OOD 指令绑定分解。
- **充分性评估**：
  - 优点：基准覆盖广，消融与可视化证据齐全，seen/OOD 分离设计较严谨。
  - 不足：消融仅在 4 个基准上，缺少数值稳定性分析（多次种子）、未见对统一专家规模、foresight token 数量、损失权重 α/β 的敏感性消融；真实世界试验次数有限，每个绑定仅 15–16 次。

## 6. 主要结论与发现

- **仿真基准全面领先**：SimplerEnv 平均 80.8%（超 π₀.5 23.7 点）、LIBERO 98.9%、LIBERO-Plus 84.8%、RoboTwin 93.2%、DOMINO 零样本 27.7% → 微调 29.3%、EBench Test SR 35.2%。
- **真实世界组合泛化最强**：在 hold-out 指令绑定上 InternVLA-A1.5 在三个指令跟随任务中全部领先；MOF 任务达到 76.4%（π₀.5 仅 29.3%，Motus 0%）。
- **训练效率更高**：在 RoboTwin 微调上 SFT 损失收敛最快，最终损失最低。
- **世界模型先验有效**：可视化显示 foresight token 条件化下，冻结 WAN 可生成物理一致的预测（关节运动跟踪、液体液面变化等），即便在零样本设置下也保持时间连贯。
- **两条经验**：① 提示工程（prompt design）重要——将所有目标统一到 VLM 原生 chat 模板能稳定保留语义；② 统一模型不必从零学习像素生成，仅需少量潜 token 查询预训练生成器即可获得动力学先验。

## 7. 优点

- **保留 VLM 语义**：持续在 VQA、子任务预测上训练骨干，避免以往统一模型常见的语义漂移问题，组合泛化能力突出。
- **隐式前瞻机制新颖**：通过可学习 foresight tokens + 冻结视频生成器，以流匹配损失间接注入动力学先验，避免像素级生成开销；推理时视频分支完全丢弃，实现实时控制。
- **架构设计精巧**：MoT 架构 + 混合注意力 + 精心设计的注意力掩码（屏蔽 FAST token、组内双向），兼顾自回归语言建模与流匹配并行去噪。
- **数据规模与采样策略**：1.2M episodes + 3M 多模态样本，两级分组采样与 Re-Mix 权重微调有效缓解数据长尾问题。
- **任务设计严谨**：真实世界 hold-out 绑定设计能排除"动作记忆"的捷径，对组合泛化的评估更具说服力。

## 8. 不足与局限

- **前瞻仅限动作块尺度**：foresight 监督只覆盖单个动作块的时间跨度，缺乏长程想象与显式世界模型规划能力。
- **生成器冻结且通用**：视频模型保持冻结，其先验受限于预训练覆盖范围，对具身场景的覆盖不足。
- **实验细节不足**：缺少数值稳定性分析（如多次随机种子）、关键超参（foresight token 数量、损失权重 α/β、专家规模）的敏感性消融；真实世界试验次数较少（每个绑定 15–20 次）。
- **算力披露不充分**：总预训练算力未明确给出，仅说明 RoboTwin 微调用 24 GPU 与 RTX 5090 推理。
- **应用限制**：推理速度虽达 0.1s/step，但仍依赖单卡高端 GPU；不同 embodiment 需统一动作空间预处理，跨实体迁移仍有工程门槛。
- **作者声明局限**：作者在文末明确指出"foresight 监督时间跨度过短"与"视频生成器覆盖范围有限"两点。
