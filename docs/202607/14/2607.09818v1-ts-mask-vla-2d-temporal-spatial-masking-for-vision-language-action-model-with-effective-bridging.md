## 摘要
视觉-语言-动作（VLA）模型旨在理解自然语言指令与视觉观测，并生成和执行相应的动作以充当具身智能体。近年来，基于自回归的 token 化动作生成推动了众多代表性 VLA 模型的发展。然而，这种范式往往将动作生成简化为下一 token 预测，缺乏对动作序列时空结构的显式建模以及对视觉-语言表征与动作之间的解耦，从而在长时序、复杂场景下限制了性能。本文提出 TS-Mask VLA，一种面向机器人操作的视觉-语言-动作框架。该框架基于两项关键设计：（1）配备桥接注意力条件桥的离散扩散动作专家，可实现来自 VLM 的多层条件注入，从而促进更准确、更稳定的动作生成；（2）针对离散动作 token 的二维时空掩码策略，强化模型对跨时间依赖与维度间耦合的理解，生成结构一致性更强的动作序列。我们在仿真基准与真实任务上开展了大量实验。在 LIBERO 上，TS-Mask VLA 仅以 0.5B 参数即取得 95.7% 的平均成功率，优于参数量显著更大的模型。在 CALVIN 上，其取得了 4.19 的最优平均序列长度，并展现出强劲的长时序性能。综合分析与消融实验进一步验证了我们设计的有效性。

## Abstract
Vision-language-action (VLA) models aim to understand natural-language instructions and visual observations, and to generate and execute corresponding actions as embodied agents. Recently, autoregressive token-based action generation has driven the development of many representative VLA models. However, this paradigm often reduces action generation to next-token prediction, thereby lacking explicit modeling of the spatiotemporal structure of action sequences and the disentanglement between vision-language representations and actions, which can limit performance in long-horizon and complex scenarios. In this paper, we propose TS-Mask VLA, a vision-language-action framework for robot manipulation. TS-Mask VLA is built upon two key designs: (1) a Discrete Diffusion Action Expert equipped with a Bridge Attention conditioning bridge, which enables multi-layer conditioning from the VLM and facilitates more accurate and stable action generation; and (2) a temporal-spatial 2D masking strategy for discrete action tokens that strengthens the model's understanding of cross-time dependencies and inter-dimensional coupling, leading to more structurally consistent action sequences. We conduct extensive experiments on simulation benchmarks and real-world tasks. On LIBERO, TS-Mask VLA achieves a 95.7 percent average success rate with only 0.5B parameters, outperforming significantly larger models. On CALVIN, it attains the best average sequence length of 4.19 and strong long-horizon performance. Comprehensive analyses and ablations further validate the effectiveness of our design.

# TS-Mask VLA 论文总结

## 一、核心问题与研究动机

- **背景**：近年来，VLA（Vision-Language-Action）模型成为具身智能体领域的研究热点，旨在将视觉感知、语言理解与动作生成统一于同一框架。当前主流 VLA 模型主要遵循两种范式：
  - **自回归（Autoregressive）范式**：将视觉、语言、动作统一为单一 token 序列，以下一 token 预测的方式生成动作（代表工作：OpenVLA、RT-2 等）。
  - **连续扩散（Continuous Diffusion）范式**：通过迭代去噪生成连续动作轨迹（代表工作：π0、Diffusion Policy 等）。
- **现有局限**：
  1. 自回归范式将动作生成简化为序列预测，**缺乏对动作序列时空结构的显式建模**，且视觉-语言表征与动作之间未做有效解耦，限制了长时序、复杂操控场景下的性能。
  2. 连续扩散范式在长时序任务中稳定性不足，难以显式建模动作的时-空相关性。
- **核心论点**：作者认为关键在于两件事——（i）将视觉-语言表征桥接到专门的动作专家上，实现条件解耦；（ii）将动作离散化以显式建模其结构化依赖，从而在复杂环境中实现更鲁棒的泛化。

## 二、方法论

### 2.1 整体框架（TS-Mask VLA）
- 三大核心组件：
  1. **VLM 骨干网络**（Qwen2.5-0.5B）：编码视觉观测和文本指令，生成融合的多模态表征。
  2. **离散扩散动作专家（Discrete Diffusion Action Expert）**：在多模态条件下生成离散动作 token，并通过迭代去噪逐步优化。
  3. **时-空二维掩码模块**：在离散动作 token 上施加 2D 掩码，捕获时间依赖和维度间耦合。

### 2.2 多模态 VLM 编码
- **视觉编码器**：DINOv2 + SigLIP 分别提取第三视角图像和腕部图像特征，通过融合 MLP 投影到语言嵌入空间。
- **指令编码**：使用骨干 tokenizer 对指令 Lt 进行分词。
- **Action Query (AQ) token**：可学习的动作查询 token，附加到输入序列以提供面向动作的引导。
- **多层特征提取**：不仅使用最终层输出，而是**提取所有 L 个 Transformer 层的隐藏状态** $H = \{H^{(l)}\}_{l=1}^{L}$，提供从低层空间细节到高层语义的互补线索。

### 2.3 离散扩散动作专家
- **Bridge Attention 块**：将三类信息源在一次注意力计算中融合：
  - **Self tokens**：当前动作表征，捕捉动作内部的时间依赖。
  - **AQ tokens**：来自 VLM 隐藏状态的动作查询特征，作为面向动作的条件信号。
  - **Task tokens**：VLM 隐藏状态中的视觉-语言特征，提供外部任务约束。
  - 形式上，共享查询 $Q$ 来自当前动作特征，通过独立 MLP 投影得到三组 $(K, V)$。注意力权重计算为：
  
    $$\alpha = \text{softmax}\left(\frac{[QK_{\text{self}}^\top, QK_{AQ}^\top, \tanh(g) QK_{\text{task}}^\top]}{\sqrt{d_h}}\right)$$
    
    其中 $g$ 为可学习的门控标量，用于缓解早期训练中过强的任务条件影响。每个分支独立应用 RoPE 位置编码。
- **统一量化动作 token 化**：
  - 将归一化动作 $\hat{a}_i \in [-1, 1]$ 独立量化到 $V=256$ 个均匀分箱中。
  - 离散索引 $q_i \in \{0, \ldots, 255\}$，序列可重塑为 $T \times D$ 的二维时-空结构（$T$ 为时间步数，$D$ 为动作维度）。
  - **不使用 VQ-VAE**，避免对动作序列的强压缩而丢失细粒度时空信息。

### 2.4 时-空二维 Token 掩码
- **两阶段掩码策略**（区别于传统的 1D 随机掩码）：
  1. **时间掩码阶段**：随机选择 $\text{round}(rT)$ 个时间帧，对每个选中帧的**所有 D 个动作维度**全部掩码，强化跨时间步的依赖建模。
  2. **空间掩码阶段**：对未被时间掩码覆盖的剩余帧，每帧随机选择 $\text{round}(r \times D)$ 个 token 掩码，引入更细粒度的结构扰动。
- 掩码比率 $r$ 通过余弦调度 $r = \cos(\pi t / 2)$ 计算。

### 2.5 训练与推理
- **训练损失**：
  - 主损失 $L_{\text{mask}}$：在掩码位置上的交叉熵损失。
  - 展开损失 $L_{\text{unroll}}$：模拟推理时的逐步展开，缓解训练-推理差异。
  - 总损失 $L = \frac{L_{\text{mask}} + \lambda L_{\text{unroll}}}{1 + \lambda}$，$\lambda$ 控制展开损失的贡献。
- **推理流程**：
  - 从完全掩码的动作序列 $t_0$ 出发。
  - 迭代 $I$ 轮：每轮预测 token 概率分布 → 计算置信度 → **ReMask 策略**重新掩码低置信度 token（按余弦调度的重掩码率 $\gamma(i/I)$），保留高置信度预测。
  - 实现**从粗到精的渐进式优化**。

- 0.5B 参数下平均成功率 **95.7%**（Spatial: 95.4%, Object: 99.4%, Goal: 96.2%, Long: 91.6%）。
- 优于比其大 **19 倍**参数的 FlowVLA（88.1%）**7.6 个百分点**。

### 6.2 CALVIN
- 取得 **4.19 的最优平均序列长度**（Avg. len），超越所有 7B 级模型。

- 相比 OpenVLA，4 任务完成率从 52.1% 提升至 77.0%，5 任务完成率从 43.5% 提升至 66.9%。

## 七、优点与亮点

- **轻量高效**：仅 0.5B 参数，在多个基准上超越数倍甚至十几倍参数量的模型。
- **方法创新**：
  - **Bridge Attention** 实现 VLM 多层特征的对齐注入，将低层几何信息与高层语义信息同时利用。
  - **时-空二维掩码**是核心创新点，将动作序列的二维结构（时间步 × 动作维度）纳入掩码设计，提供结构化归纳偏置。
  - **ReMask + 余弦调度**的推理策略实现从粗到精的迭代优化。
- **显式解耦**：通过独立动作专家 + Bridge Attention 桥接，将视觉-语言表征与动作生成有效解耦，避免了自回归范式中表征学习与控制策略的混杂。
- **离散扩散优势**：相比 VQ-VAE 的强压缩，均匀量化保留细粒度时空信息；相比连续扩散，在离散空间中具有更明确的结构化归纳偏置。

## 八、不足与局限

- **算力与训练细节缺失**：未报告训练时长、数据规模、训练 epoch 等关键信息，限制了方法的可复现性评估。
- **消融不够全面**：
  - 缺少 Bridge Attention 单独消融（如仅使用最终层特征 vs 多层特征的对比）。
  - 缺少动作量化方案（均匀量化 vs 其他方法）的对比实验。
  - 缺少对不同 VLM 骨干规模的可扩展性分析。
- **超参数敏感**：展开损失 $\lambda$ 对性能影响较大（4.6% 波动），但未提供自动选择该参数的方法。
- **泛化能力存疑**：真实世界仅 3 个任务类别、每类 20 次试验，统计显著性有限；未在完全未见过的场景或物体上进行测试。
- **应用限制**：作者明确指出仅在资源受限场景下验证，未来需在更丰富资源下评估可扩展性。
- **对比公平性**：部分基线（如 VLA-Adapter-Pro）标注为"在相同设置下复现"，但其他基线的训练数据、计算资源未必一致，可能存在一定不公平性。
