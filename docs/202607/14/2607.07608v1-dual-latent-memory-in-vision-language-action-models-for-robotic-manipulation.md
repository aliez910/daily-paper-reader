## 摘要
主流的视觉-语言-动作（VLA）模型主要在马尔可夫假设下从当前观测预测动作，因此在长时域、时序依赖的任务中表现欠佳。现有的记忆增强型 VLA 模型要么扩展观测窗口，要么从记忆库中检索历史作为策略侧的辅助上下文。然而，它们将记忆置于 VLA 推理的原生潜在嵌入空间之外，阻碍了历史经验与多模态推理及动作生成之间的流畅交织。为此，我们提出了 LaMem-VLA，一个潜在记忆原生框架，将历史经验重构为潜在记忆标记，并直接将其与 VLA 推理相融合。LaMem-VLA 的核心包含四个协同组件：(i) 策展器，将历史经验组织为互补的短期与长期记忆库；(ii) 检索器，利用多模态认知查询两个记忆库以获取与上下文相关的证据；(iii) 压缩器，将检索到的证据重构为紧凑的短期与长期潜在记忆标记；(iv) 编织器，将这些记忆标记与当前观测和指令注入到一个连续的嵌入序列中。通过在相同的连续潜在空间中完整地表示、检索与使用历史经验，LaMem-VLA 使记忆能够直接参与 VLA 推理，并在有界上下文下引导动作生成。在 SimplerEnv 与 LIBERO 上的大量实验证明了 LaMem-VLA 的优越性。

## Abstract
Mainstream Vision-Language-Action (VLA) models predict actions primarily from the current observation under a Markovian assumption, thus struggling with long-horizon, temporally dependent tasks. Existing memory-augmented VLAs either expand the observation window or retrieve history from the memory bank as auxiliary policy-side context. However, they leave memory outside the native latent embedding space of VLA reasoning, preventing historical experience from being fluidly interleaved with multimodal reasoning and action formation. To this end, we introduce LaMem-VLA, a latent-memory-native framework that reconstructs historical experience into latent memory tokens and directly interweaves them with VLA reasoning. At its core, LaMem-VLA introduces four coordinated components: (i) a curator that organizes historical experience into two complementary short-term and long-term memory vaults; (ii) a seeker that queries both vaults using the multimodal cognition to retrieve context-relevant evidence; (iii) a condenser that reconstructs the retrieved evidence into compact short-term and long-term latent memory tokens; and (iv) a weaver that injects these memory tokens with the current observation and instruction into one continuous embedding sequence. By representing, retrieving, and consuming historical experience entirely in the same continuous latent space, LaMem-VLA enables memory to directly participate in VLA reasoning and guide action generation under a bounded context. Extensive experiments on SimplerEnv and LIBERO demonstrate the superiority of our LaMem-VLA.

# LaMem-VLA 论文总结

## 1. 核心问题与研究动机

- **主流 VLA 的局限**：现有视觉-语言-动作（VLA）模型（如 CogACT、π0、OpenVLA）大多在马尔可夫假设下运作，动作预测仅依赖当前观测 $o_t$ 与指令 $I$，导致**"时间短视偏差（temporal short-horizon bias）"**：模型可对当前可见状态作出反应，但无法感知历史状态变迁、已完成子任务及多步任务所处的阶段，难以处理长时序、强时序依赖的操作任务。
- **现有记忆增强方案的两条路径及其不足**：
  - **时序上下文扩展**：通过拼接历史帧或将输入扩展为视频序列。问题——计算与显存开销随上下文线性增长；固定时间窗口构成记忆上限，窗口外的关键证据被丢弃。
  - **外部记忆库检索**：从外部记忆库中检索历史轨迹或 token 作为策略侧辅助上下文。问题——历史存储在 VLA 原生 token 空间之外，消费发生在多模态推理之后，记忆无法与 VLA 内部的"感知—理解—动作意图形成"过程深度交织；当当前观测信号弱或存在视觉干扰时，检索不可靠。
- **核心研究问题**：能否将历史经验构建为**模型原生潜在记忆**，使其与视觉、指令、动作查询在同一个连续潜在空间中表示、检索与消费？

## 2. 方法论

### 2.1 整体框架
- LaMem-VLA 基于 7B 参数的 Prismatic VLM 主干（DINOv2/SigLIP 视觉编码器 + LLaMA-7B），与约 300M 参数的扩散式动作专家协同；输入为单张 224×224 第三人称 RGB 图像与语言指令，输出 7-DoF（3 平移 + 3 旋转 + 1 夹爪）的动作块（chunk size = 16）。
- 核心思想：**把历史经验重建为与 VLA 同维度的潜在记忆 token**，在动作查询求解之前直接拼入 VLA 输入序列，使记忆与当前观测、指令共享同一自注意力上下文。

### 2.2 四个协同模块
- **策展器（Curator）**：将历史经验分解为两个互补的"记忆库"。
  - **短期记忆库** $M_{\text{short}}$：保存当前 episode 的视觉证据。使用 SE-bottleneck 压缩模块 $C_s$ 将视觉 token $X_t$ 压缩为 $N_s$ 个短期记忆 token，并以其均值池化作为检索键。容量 $L$ 超限后，按相邻键余弦相似度合并最冗余的相邻对，保留共享视觉信息。
  - **长期记忆库** $M_{\text{long}}$：保存动作隐藏状态 $H_{\text{action}}$，用于追踪跨长时域的任务进度与动作连续性，采用与短期库相同的合并压缩策略。
- **检索器（Seeker）**：以视觉与指令 token 的多模态认知表示 $Q_t^{\text{con}}$ 拼接可学习的查询槽 $Q_{\text{init}}$，由轻量 transformer（带掩码注意力，仅查询槽读取 $Q_t^{\text{con}}$）更新为 $Q_t$；对 $Q_t$ 做均值池化得到全局检索向量 $q_t$，通过余弦相似度在两库中分别 Top-K 检索出 $Z_{\text{short}}, Z_{\text{long}}$。
- **压缩器（Condenser）**：以 $Q_t$、检索证据 $Z$ 和可学习的记忆槽 $T_s, T_l$ 为输入，经两个轻量 transformer 风格记忆生成器 $F_v, F_c$ 输出**固定长度**的潜在记忆 token $M_{\text{short}} \in \mathbb{R}^{L_s \times C}$ 与 $M_{\text{long}} \in \mathbb{R}^{L_l \times C}$，与 VLA 嵌入空间同维度、与检索规模解耦。
- **编织器（Weaver）**：构造记忆增强的 VLA 输入序列
  $$S_t = [M_{\text{short}} + \mathbf{1}b_s^\top; \; M_{\text{long}} + \mathbf{1}b_l^\top; \; X_t; \; I; \; Q_{\text{action}}]$$
  其中 $b_s, b_l$ 为可学习的源嵌入。$Z_{\text{action}} = \text{VLM}(S_t)[-N_a:]$ 即为"记忆根植的"动作 token，参与自注意力后送入扩散式动作专家。
- **扩散式动作专家**：按 DDPM/DDIM 范式，以 $Z_{\text{action}}$ 为条件、采用 MSE 噪声预测损失训练；推理时使用 10 步 DDIM 采样生成动作块。

## 3. 实验设计

- **基准与场景**：
  - **SimplerEnv-Bridge**：使用 WidowX 机器人评估真实到仿真泛化，在 Bridge v2 数据集上训练 50k 步，每任务 24 次试验，四个任务（Spoon on Towel、Carrot on Plate、Stack Cube、Eggplant in Basket）报告平均成功率。
  - **LIBERO**：Franka 机器人上五个套件——Spatial、Object、Goal、Long-10、Long-90（后两者为长时序基准），每任务 50 次回放，报告各套件与总体成功率。
- **对比方法**：覆盖单流/层级两大 VLA 范式以及多种记忆增强方法——
  - 通用基线：Diffusion Policy、Octo、OpenVLA、TraceVLA、SpatialVLA、π0、CogACT、CoT-VLA 等；
  - 记忆增强方法：MemoryVLA、Memer、CronusVLA、SemanticVLA、ThinkAct、Fast-ThinkAct、LARA 等；
  - 注意：带星号的方法（如 π0-FAST、π∗0）使用了额外的本体感知与腕部相机输入。

## 6. 主要结论与发现

- **SimplerEnv-Bridge**：LaMem-VLA 平均成功率 73.9%，比 CogACT 高 16.6 分、比 π0 高 4.7 分，并超过 MemoryVLA 等记忆增强方法；
- **LIBERO**：五个套件平均 97.6%，其中 Spatial 98.8%、Object 99.0%、Goal 97.2%、Long-10 95.8%、Long-90 97.0%；相对 MemoryVLA 提升 1.1 分、相对 CogACT 提升 4.4 分；前四套件相对 π0 提升 3.5 分；
- **双尺度互补**：移除任一记忆流均会导致性能显著下降，同时移除时退化最大；
- **潜在原生 > 策略侧条件**：将记忆直接织入 VLA 序列明显优于将其作为外部条件；
- **检索预算与压缩长度**：$K=8$、$L_s=8$、$L_l=4$ 在性能与效率间取得最佳平衡，过大的检索规模反而引入冗余。

## 7. 优点

- **范式创新**：明确提出"记忆应位于模型原生潜在空间内"的设计原则，区别于"外挂记忆库+策略侧条件"的传统做法；
- **架构清晰**：四模块（curator / seeker / condenser / weaver）职责分明、解耦合理，记忆"存储—检索—压缩—编织"形成闭环；
- **双尺度设计**：短期视觉证据与长期语义/动作连续性证据在来源与功能上互补，但在表示形式上统一为同维潜在 token，便于联合消费；
- **消融充分**：覆盖模块有效性、消费路径、超参敏感性三个维度，且与多个近期 SOTA 直接对比；
- **固定长度接口**：通过 condenser 将变长检索结果压缩为固定 token，避免 VLA 上下文随检索规模膨胀。

## 8. 不足与局限

- **仅仿真验证**：作者明确指出目前仅在 SimplerEnv 与 LIBERO 上验证，真实机器人实验留待下一版本，限制了结论的实用化外推；
- **任务多样性有限**：SimplerEnv-Bridge 仅 4 个任务，且集中于桌面拾放；更复杂场景（移动操作、双臂、长周期家务等）未涉及；
- **硬件假设较强**：依赖 8 张 H800 + 7B 主干，资源开销对中小实验室并不友好；论文也未讨论延迟与吞吐；
- **超参敏感性**：记忆库容量 $L=16$、检索数 $K=8$ 等均为手工设定，缺少自适应机制；不同任务 / 不同机器人形态下的最佳配置可能不同；
- **评估偏差风险**：对比的多个方法使用不同的输入模态（是否含腕部相机 / 本体感知），虽已用星号标注，但与 LaMem-VLA 的严格公平性仍受影响；
- **记忆机制本身局限**：合并策略基于相邻键相似度，可能在快速变化或周期性任务中错误合并关键差异帧；检索依赖单一均值池化向量，对高度多样化历史证据的表征能力有限；
- **可解释性不足**：潜在记忆 token 的物理含义、长期记忆何时"覆盖"短期记忆等机制，未提供可视化或诊断性分析。
