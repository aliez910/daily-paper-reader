## 摘要
动作空间是机器人学习中的一个主要挑战，因为它通常是高维的、跨越较长的时间范围，并且常常存在多模态的最优解。合理的动作表示与损失函数选择有助于应对这些问题，但也往往需要权衡取舍。我们提出动作地图策略（AMP），将三维闭环操控策略学习转化为图像空间中的分类问题。尽管分类在生成式语言模型中已被证明是有效的范式，但由于直接离散化高维连续动作会导致词表规模爆炸，将其应用于机器人动作学习仍然困难。我们的核心思想是将三维动作投影到相机图像平面上，并将每个像素位置视为一个离散类别，从而在保留多模态性的同时控制维度。该方法能够在不依赖庞大词表的前提下，对高维动作实现毫米级精度，同时保留细粒度的像素级视觉信号。此外，它可以在单次前向传播中预测完整的动作块，避免了复杂的噪声调度与迭代去噪，同时实现了显著快于扩散策略的推理速度。在多种操控任务上的实验表明，AMP 优于强基线方法，取得了更高的成功率、更快的推理速度以及更强的空间推理能力。

## Abstract
The action space poses a major challenge in robot learning, since it is often high-dimensional, can span long time horizons, and frequently admits multi-modal optimal solutions. A good choice of action representation and loss function can help to address these concerns, but there are often trade offs. We propose Action Map Policy (AMP), which casts 3D closed-loop manipulation policy learning as a classification problem in image space. While classification has been an effective formulation in generative language models, applying it to robot action learning is difficult because naively discretizing high-dimensional continuous actions explodes the token vocabulary. Our key idea is to project 3D actions onto the camera image planes and treat each pixel location as a discrete class, thus controlling dimensionality while retaining multi-modality. This method supports millimeter-level precision for high-dimensional actions without requiring a prohibitively large vocabulary, while preserving fine-grained pixel-wise visual signals. Furthermore, it can predict the entire action chunk in a single forward pass, avoiding complex noise scheduling and iterative denoising while achieving substantially faster inference than diffusion policies. Experiments on various manipulation tasks show that AMP outperforms strong baselines, achieving higher success rates, faster inference, and enhanced spatial reasoning.

## 1. 核心问题与研究动机

- **机器人动作空间的三大挑战**：
  - **高维**：连续动作维度通常较高（如末端6-DoF 位置+姿态+夹爪），难以直接离散化。
  - **长时域**：操控任务常需跨越较长时间跨度，单步动作决策需考虑未来多步。
  - **多模态最优解**：同一观察下可能存在多条等优的解轨迹，导致策略学习的平均化困境。
- **现有方案的权衡**：
  - **回归式策略**（如 MLP、Transformer 回归）输出灵活但难以处理多模态。
  - **扩散策略** 虽能处理多模态，但需多次迭代去噪，推理慢。
  - **直接离散化连续动作** 会导致词表爆炸，难以扩展到高维动作。
- **本文动机**：寻找一种兼具**表征紧凑性、多模态建模能力、推理效率与高精度**的统一动作表示与学习范式。

## 2. 方法论

### 核心思想
- 将 3D 闭环操控策略学习**重新建模为图像空间的像素分类问题**。
- 把三维末端动作（或关键空间位姿目标）投影到相机图像平面，**以像素位置作为离散类别**。
- 在图像平面学习"动作热力图/分类分布"，再反投影回 3D 空间生成动作。

### 关键技术细节
- **动作投影**：
  - 将 3D 动作（如末端目标位姿）的 x、y、z 坐标借助相机内参/外参投影到图像平面，得到像素坐标 (u, v)。
  - 像素位置即作为分类的离散类别标签。
- **词表控制**：
  - 离散类别数 = 图像像素总数（如 H×W），相比"对每一维连续动作分别离散化"（词表为 K^D，K 越大、维度 D 越大时指数爆炸）显著降低词表规模。
  - 保持像素级分辨率即可获得**毫米级**空间精度。
- **多模态建模**：
  - 分类分布天然支持多峰，规避回归式策略的"平均动作"问题。
- **动作块（action chunk）预测**：
  - 在单次前向传播中预测**整个动作块**（未来多步动作），而非逐步自回归。
- **推理效率**：
  - 一次前向即得结果，**无需复杂噪声调度或迭代去噪**。
  - 推理速度显著快于扩散策略。

### 算法流程（文字描述）
1. **输入**：当前相机图像观测（单目或多目）、本体感知状态（可选）。
2. **编码器**：视觉 backbone 提取图像特征。
3. **分类头**：在特征图上对每个像素位置预测动作分布（分类 logit/概率）。
4. **取像素动作**：选取得分最高的像素（或 Top-K 多模态采样）。
5. **反投影**：将像素坐标反投影回 3D 空间，得到末端动作；连续维度（如夹爪开合、旋转角）可额外回归或从类别中读取。
6. **执行动作块**：按 chunk 顺序逐步执行并闭环反馈。

## 7. 优点与亮点

- **范式创新**：将 LLM 中成功的"分类即生成"范式创造性地迁移到机器人 3D 动作空间。
- **多模态与精度兼得**：像素级类别既保留多峰分布，又支持毫米级空间精度，规避了词表爆炸。
- **闭环适配**：像素分类天然适合闭环重规划，可随观测变化实时更新动作分布。
- **效率优势**：一次前向预测整段动作块，无需噪声调度与迭代去噪，部署友好。
- **通用表征**：方法不依赖特定机器人本体，可拓展到多种夹爪与机械臂形态。

## 8. 不足与局限

- **像素分辨率—精度权衡**：图像分辨率受限于相机视野与计算资源，极端精细操控可能仍需额外机制。
