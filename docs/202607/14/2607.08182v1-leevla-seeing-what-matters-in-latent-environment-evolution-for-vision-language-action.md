## 摘要
视觉-语言-动作（VLA）模型旨在将多模态输入映射为机器人动作。然而，现有方法大多对所有视觉令牌一视同仁，并依据人工挑选的因素进行推理，缺乏突出任务关键证据以及考虑潜在因素的机制，因此难以覆盖复杂动态场景。为解决这一问题，我们提出了 LEEVLA——一种在潜在环境演化中聚焦关键信息的 VLA 架构，能够显式引导模型关注信息丰富的区域，同时保持潜在世界表征的结构化演化。为了识别显著且与指令相关的区域，我们引入了漂移引导的动态优先级机制（DGDP），结合动态位置优先级（DPP）与语义漂移引导（SDG），以指导 VLA 智能体在训练过程中应关注的区域。在此基础上，我们引入了结构化特征流生成（SFFG），通过原型到外围（P2P）预测建模这些被优先处理的特征在潜在空间中应如何演化，并提出互邻域对比（MC）损失以保持邻域间的拓扑一致性。DGDP 与 SFFG 共同构成了一个任务感知的"何处-如何"训练框架。在多个 VLA 基准上的大量实验表明，LEEVLA 持续优于先前方法，证实了显式的任务证据引导与结构化潜在推理对可扩展 VLA 均至关重要。代码已开源：https://github.com/LyuQi127/LEEVLA。

## Abstract
Vision-language-action (VLA) models aim to map multimodal inputs to robot actions. However, most existing approaches struggle to cover complex dynamic scenarios due to treating all visual tokens uniformly and reasoning with human-selected factors, which lack mechanisms to emphasize task-critical evidence and ignore underlying factors. To address this issue, we propose LEEVLA, a VLA architecture for seeing what matters in Latent Environment Evolution that explicitly guides the model toward informative regions while preserving the structured evolution of latent world representations. To identify salient and instruction-relevant regions, we introduce drift-guided dynamic prioritization (DGDP), which combines dynamic position prioritization (DPP) with semantic drift guidance (SDG) to guide the VLA agent where to attend during training. On top of this, we introduce structured feature flow generation (SFFG), which models how these prioritized features should evolve in latent space via prototype-to-periphery (P2P) prediction, and a mutual-neighborhood contrastive (MC) loss to maintain topological consistency among neighborhoods. Together, DGDP and SFFG form a task-aware "where-how" training framework. Extensive experiments on VLA benchmarks show that LEEVLA consistently outperforms prior methods, confirming that explicit task-evidence guidance and structured latent reasoning are both crucial for scalable VLA. Our code is available at https://github.com/LyuQi127/LEEVLA.

# LEEVLA 论文总结

## 1. 核心问题与研究动机

- **研究目标**：视觉-语言-动作（VLA）模型旨在将多模态输入（视觉、状态、语言指令）映射为机器人动作，使其能在开放环境中感知、推理与执行。
- **现有方法的局限**：
  - 对所有视觉 token 一视同仁，监督信号在静态背景和无关物体上被稀释；
  - 依赖人工挑选的"上下文线索"（subgoal 图像、分割、深度等）进行显式推理；
  - 需额外辅助模型生成这些模态，带来额外计算开销并依赖辅助任务的进展；
  - 过度强调"已知因素"，忽略"未知但任务相关"的潜在因素；
  - 在高维潜在空间中缺乏结构化引导，导致策略难以发现任务关键特征。
- **核心痛点**：当前 VLA 既缺乏"该看哪里"的自动机制，也缺乏"特征如何演化"的结构化建模，难以应对复杂动态场景。

## 2. 方法论

### 2.1 整体思路
- 提出 **LEEVLA（Latent Environment Evolution VLA）**，核心是"在哪看-怎么看"任务感知训练框架：
  - **DGDP** 解决"在哪看"——定位任务关键区域；
  - **SFFG** 解决"怎么看"——结构化建模潜在特征演化。
- 两个模块**仅用于训练阶段**，不增加推理成本。

### 2.2 DGDP（Drift-Guided Dynamic Prioritization）
- **DPP（Dynamic Position Prioritization）**：
  - 用相邻时间步 patch 特征的余弦相似度变化衡量"动态性"：$\theta_i = 1 - \cos(v_{t,i}, v_{t+T,i})$；
  - 动态区域（机器人本体、与目标交互的物体）得分高，静态背景得分低。
- **SDG（Semantic Drift Guidance）**：
  - 计算每个 patch 与语言 token 的内积，得到"指令相关分数" $r_{t,i} = \max_{j} \langle \tilde{x}_{t,i}, \tilde{c}_j \rangle$；
  - 定义语义漂移 $\Delta_i = \text{clip}((r_{t+T,i} - r_{t,i})/\tau, -\delta, \delta)$，并归一化；
  - 引导因子 $\omega_i = \exp(\tilde{\Delta}_i / \tau)$。
- **耦合权重**：$\beta_i = \sigma(\omega_i \cdot \theta_i)$，对"动态性强且语义向任务相关方向漂移"的 patch 分配更高权重。

### 2.3 SFFG（Structured Feature Flow Generation）
- **Prototype-to-Periphery (P2P) 预测**：
  - 对多视角 $t+T$ 时刻的 patch 特征做联合聚类，得到 $L$ 个 cluster；
  - 在每个 cluster 内，按成员到质心的欧氏距离从近到远排序（prototype → periphery）；
  - 损失函数：$L_{P2P} = \frac{1}{|C|} \sum_{\ell} \frac{1}{|\vec{c}_\ell|} \sum_{j \in \vec{c}_\ell} (\alpha + \beta_j) \cdot \phi(\hat{v}_{t+T,j}, v_{t+T,j})$
  - $\alpha$ 为全局调制因子（论文中设为 1），保证背景信息不被完全丢弃。
- **Mutual-Neighborhood Contrastive (MC) Loss**：
  - 构造二阶 KNN 互邻域图，K=10、M=5；
  - 仅当两 patch 互为邻居时选为正样本，过滤掉聚类噪声带来的不对称/虚假链接；
  - 采用 InfoNCE 形式：$L_{MC} = -\frac{1}{|I|} \sum_{i \in I} \frac{1}{|G_i^+|} \sum_{j \in G_i^+} \log \frac{\exp(S_{ij}/\tau_c)}{\sum_{\ell \neq i} \exp(S_{i\ell}/\tau_c)}$。
- **总训练目标**：$L_{total} = \lambda_1 L_{action} + \lambda_2 L_{P2P} + \lambda_3 L_{MC}$
  - 动作预测采用 L1 回归 + 并行解码，参考 OpenVLA-OFT 设计。

### 2.4 模型结构
- 视觉编码器：DINOv2 + SigLIP，预训练 patch 特征维度 $d_0$；
- Projector 把 patch 特征投影到 LLM 维度 $d$；
- LLM 隐藏状态经并行动作头（MLP）回归连续动作 chunk；
- 额外引入"Future Feature Decoder" $D$ 将 LLM 嵌入映射回原始特征空间，用于 P2P 与 MC 损失计算。

## 6. 主要结论与发现

- **性能领先**：
  - LEEVLA-mini (0.5B) 在 LIBERO 平均 97.5%，超过 FLOWER (95.7%)、DreamVLA (92.6%) 等；

  - CALVIN 平均完成长度 4.34，高于 π0.5 (4.02)、OpenVLA-OFT (4.10)；
  - 真实世界：LEEVLA-large 平均 78.5%，OpenVLA 40%（Place 70 vs 30、Press 80 vs 55、Drawer 65 vs 40、Long 60 vs 35）。
- **组件贡献（消融，LIBERO-Goal）**：
  - Baseline 94.8% → +P2P 95.2% → +MC 95.6% → +DPP 96.3% → +SDG 97.0%；
  - SFFG (P2P+MC) 和 DGDP (DPP+SDG) 互补。
- **设计意义**：
  - 在潜在空间推理比"人类选定的外部条件"更通用；
  - 视觉特征本身已隐含语义/几何/外观信息，结构化潜在预测能更好发掘这些信号；
  - 显式任务证据引导 + 结构化潜在推理对可扩展 VLA 至关重要。

- **代码开源**：可复现性强。
