## 摘要
视觉-语言-动作（VLA）模型已成为通用机器人操作的一种有前景的范式，其中视觉-语言表征被用于条件化连续动作的生成。然而，这些表征并未针对动作条件化进行显式优化，使得动作专家模块需要弥合多模态理解与精确运动控制之间的差距。近期的动作推理方法引入额外的模块来生成显式的动作规划或动作空间推理信号，证明了动作级引导的益处，但通常需要独立的动作生成框架。我们提出了 CAC-VLA，一个上下文门控动作条件化框架，能够在 VLM 内部直接学习一个轻量级的潜在动作接口。CAC-VLA 不生成可执行轨迹，而是训练 VLM 预测由粗到细的潜在动作——这些是从未来动作片段编码得到的结构化表征——并通过上下文门控自适应地利用这些表征来条件化动作专家。这实现了 VLM 原生的动作条件化，同时校准潜在动作引导对专家动作生成的影响。在 LIBERO 和 LIBERO-Plus 上的实验证明了 CAC-VLA 的有效性，在 LIBERO 上达到了 98.3% 的平均成功率，在 LIBERO-Plus 上达到了 89.5%，表明上下文门控的潜在动作条件化是面向连续专家控制的一种有效接口。

## Abstract
Vision-Language-Action (VLA) models have become a promising paradigm for generalist robot manipulation, where visual-language representations are used to condition continuous action generation. However, these representations are not explicitly optimized for action conditioning, leaving the action expert to bridge the gap between multimodal understanding and precise motor control. Recent action-reasoning methods introduce additional modules to generate explicit action plans or action-space reasoning signals, demonstrating the benefit of action-level guidance but often requiring separate action-generation frameworks. We propose CAC-VLA, a Context-Gated Action Conditioning framework that learns a lightweight latent-action interface directly within the VLM. Instead of generating executable trajectories, CAC-VLA trains the VLM to predict coarse-to-fine latent actions, which are structured representations encoded from future action segments, and adaptively leverages them to condition the action expert via a context gate. This enables VLM-native action conditioning while calibrating the influence of latent-action guidance on expert action generation. Experiments on LIBERO and LIBERO-Plus demonstrate the effectiveness of CAC-VLA, achieving 98.3% average success rate on LIBERO and 89.5% LIBERO-Plus, suggesting that context-gated latent-action conditioning is an effective interface for continuous expert control.

# CAC-VLA 论文总结

## 1. 核心问题与研究动机

- **核心问题**：在 Vision-Language-Action (VLA) 模型中，预训练视觉-语言模型（VLM）输出的多模态表征并未针对动作条件化做显式优化，导致动作专家（action expert）需要自行弥合"语义理解"与"精确运动控制"之间的鸿沟。
- **现有方案的不足**：
  - 多数 VLA 仍依赖 VLM 隐式表征作为动作专家的主要接口，缺乏面向动作的结构化引导。
  - 近期"动作推理"方法（如 ACoT-VLA）虽然引入了动作级引导（参考轨迹、动作先验等），但通常依赖**独立于 VLM 的额外动作生成/推理模块**，增加了系统复杂度和训练开销。
  - 现有方法往往将动作级引导以**固定强度**注入到动作专家，未考虑其在不同任务阶段、不同去噪/流匹配步骤下的可靠性差异。
- **本文关注的关键问题**：能否在 VLM 内部直接学习一个**轻量级的潜在动作（latent action）接口**，并让动作专家**自适应地校准**该动作结构化引导的注入强度？

## 2. 方法论

### 2.1 整体框架
- **核心思想**：CAC-VLA（Context-Gated Action Conditioning VLA）由两阶段组成：
  1. **VLM 原生潜在动作预测**：训练专用 VLM 查询 token（query token）从多模态上下文预测"潜在动作"。
  2. **上下文门控动作条件化**：动作专家通过 cross-attention + 上下文门控（context gate）自适应地利用这些潜在动作进行条件化。
- 关键设计选择：**潜在动作不作为可执行轨迹**，而是作为"动作结构化的中间表征"，最终连续动作仍由 action expert 产生。

### 2.2 关键技术细节

#### (1) 潜在动作的构造与监督
- 使用 **Ordered Action Tokenizer (OAT)** 将未来动作片段编码为原始潜在向量：
  - $z^{oat}_t = \text{OAT}(a_{t:t+H_l-1})$，其中 $H_l$ 为潜在动作视野（latent-action horizon）。
- 潜在表征具有 **coarse-to-fine（由粗到细）** 的结构。
- VLM 端使用 $N_q = 8$ 个可学习的 latent query tokens $q$；通过 expert-aware attention mask 防止 action expert 直接 attend 这些查询 token，确保信息流经潜在动作与门控模块。

#### (2) VLM 预测头
- VLM 输出查询隐藏态 $h^q_t = \text{VLM}(o_t, l, q)$；
- 通过轻量预测头 $W_z \cdot \text{LN}(\cdot)$ 映射到 OAT 的原始潜空间 $\hat{z}_t$；
- 训练时使用 token-wise **Smooth-L1 损失** $L_{align}$ 对齐预测与 OAT 编码目标。

#### (3) Context-Gated Action Conditioning 模块
- **条件源差异**：训练时使用 OAT 编码目标作为条件源（稳定）；推理时使用 VLM 预测的潜在动作。
- 投影 $c_t = \phi_c(z^c_t)$ 将其映射为 expert 隐藏空间的 conditioning tokens。
- 在每个 action expert 层中（self-attn 之后、FFN 之前）执行：
  1. 归一化 $x_l$ → $\bar{x}_l$
  2. Cross-attention 检索潜在动作更新：$u_l = \text{CrossAttn}(\bar{x}_l, c_t, c_t)$
  3. **门控计算**：
     - $s^x_l = \text{AvgPool}(\bar{x}_l)$，$s^u_l = \text{AvgPool}(u_l)$
     - $g_l = \sigma(W_g \tanh(W_x s^x_l + W_u s^u_l))$，产生 channel-wise 门 $g_l \in \mathbb{R}^{B \times 1 \times D}$
  4. **门控残差注入**：$x_l \leftarrow x_l + g_l \odot u_l$
- **设计哲学**："retrieval 与 injection 解耦"——cross-attention 负责按当前动作状态检索信息，门控决定注入多少。

#### (4) 训练与推理
- 总损失：$L = L_{act} + \lambda_{align} L_{align}$，其中 $L_{act}$ 为 flow-matching action expert 损失，$\lambda_{align} = 0.1$。
- 推理时移除 OAT tokenizer，expert 仅以 VLM 预测的潜在动作为条件，实现 VLM-native 部署。

## 6. 主要结论与发现

- **LIBERO**：CAC-VLA 取得 **98.3% 平均成功率**，在 Spatial/Object/Goal/Long 上分别为 98.4 / 99.8 / 99.6 / 95.4，排名平均第二（仅次于 ACoT-VLA 的 98.5%），Object 子任务并列最佳。
- **LIBERO-Plus (SFT)**：CAC-VLA 取得 **89.5% 平均成功率**，超过 ACoT-VLA (88.0%) 与 π0.5 (85.7%)，尤其在 Light (97.5)、Background (97.1)、Noise (95.4)、Layout (87.8) 上表现稳健。
- **消融发现**：
  - 移除 latent-action conditioning：98.3% → 98.0%。
  - 进一步移除 context gate：98.3% → 97.9%。
  - $H_l = 20$ 最优（98.3%），$H_l = 10$ 与 $H_l = 30$ 均为 98.1%，提示"中等潜在视野"在长上下文相关性与当前动作块相关性之间取得最佳折中。
- **门控行为发现**：门值与有效条件强度随去噪步骤、任务阶段动态变化（Long vs Goal 显著不同），说明 gate 确实在学而非退化为常数。
- **真实世界**：pick-and-place 任务 CAC-VLA Task Score 72%、Full SR 64%（π0.5 为 48% / 16%）；block stacking SR 52% vs π0.5 36%。完整成功率的提升幅度最大。

## 7. 优点与亮点

- **VLM 原生潜在动作接口**：避免引入独立动作生成/推理模块，使框架更简洁且与现有 VLA 范式高度兼容。
- **coarse-to-fine 潜动作 + context gate**：检索与注入解耦设计，使 latent action 不会以固定强度强制约束 expert，保留了 expert 的连续动作建模能力。
- **训练-推理一致性**：训练时用 OAT 目标提供稳定信号，推理时无缝切换到 VLM 预测的潜动作，部署无额外开销。
- **评估全面**：同时覆盖标准基准、分布偏移基准、消融、门控行为可视化和真实世界实验，分析维度较丰富。
- **公平对比**：在真实世界实验中严格控制变量（相同数据、相同训练超参）。

## 8. 不足与局限

- **真实世界覆盖不足**：仅 2 个桌面级任务（pick-and-place、block stacking）、单一机器人（UR7e）、单一传感配置（双 D435i）、每个任务仅 50 条演示，结论的泛化性受限。
- **潜在视野固定**：$H_l$ 对所有任务统一设置，无法根据任务阶段动态调整；论文承认在更长视野、更多样化的操作场景下可能失效。
- **潜在动作可靠性风险**：当 VLM 预测的 latent action 不准确或与即时控制需求不对齐时，gate 虽然可自适应降低注入强度，但本质仍是被动纠正，缺乏显式的纠错/校验机制。
- **依赖 OAT**：潜在动作的 coarse-to-fine 结构由 OAT 提供，方法的表达上限受限于 OAT 本身的编码能力。
- **作者承认的限制**：论文 Limitations 一节明确指出未来工作将扩展至更多真实任务与机器人平台，并探索任务自适应或层级化的潜在动作视野。
