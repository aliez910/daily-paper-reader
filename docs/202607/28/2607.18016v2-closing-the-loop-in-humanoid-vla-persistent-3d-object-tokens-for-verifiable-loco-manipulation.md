## 摘要
视觉-语言-动作策略是通用机器人控制中颇具前景的基础方法，但长时序的人形机器人运动操纵任务要求机器人将任务物体视为在运动、接触、遮挡与恢复过程中持续存在的物理实体。我们将这一问题建模为物体状态发散：用于调节全身动作的物体状态，可能与用于判断该动作是否达成预期物理关系的状态不一致。为此，我们提出了\emph{持久物体令牌化}（POT），该方法基于 RGB-D 观测维护按角色索引的三维物体记录，并将其转化为供全身动作专家使用的物体令牌。实例化为\emph{POT-VLA} 后，同一组物体记录既可作为动作生成的条件输入，又可支持几何谓词检查，从而构成一个物体状态既可驱动动作又可验证的闭环执行系统。在 Unitree G1 上的实验表明，POT-VLA 将同等条件下的 GR00T-N1.7 直接基线在八类真实任务中的成功率由 39/80 提升至 71/80。在与 Being-0 对齐的外部参考任务集上，POT-VLA 在对齐服务任务上取得了 44/50 的成功率，而 Being-0 论文报告的成功率为 37/50。最大提升出现在需要维持三维空间关系的任务上，表明以物体为中心的持久状态是可验证的人形机器人视觉-语言-动作执行中一种有效的抽象方式。

## Abstract
Vision-language-action policies are a promising foundation for general robot control, but long-horizon humanoid loco-manipulation requires the robot to treat task objects as persistent physical entities across movement, contact, occlusion, and recovery. We study this problem as object-state divergence: the object state used to condition a whole-body action can differ from the state used to decide whether the action achieved the intended physical relation. We propose \emph{Persistent Object Tokenization} (POT), which maintains role-indexed 3D object records from RGB-D observations and converts them into object tokens for a whole-body action expert. Instantiated as \emph{POT-VLA}, the same object records condition action generation and support geometric predicate checks, yielding a closed-loop execution system in which object state is both actionable and verifiable. On a Unitree G1, POT-VLA improves a matched direct GR00T-N1.7 baseline from 39/80 to 71/80 successes over eight real-world task families. In an external Being-0-aligned reference, POT-VLA achieves 44/50 successes on aligned service tasks, compared with the 37/50 success reported by the Being-0 paper. The largest gains occur on tasks requiring maintained 3D relations, suggesting that persistent object-centered state is a useful abstraction for verifiable humanoid VLA execution.

# 论文总结：人形机器人 VLA 闭环——持久三维物体令牌用于可验证的运动-操纵

## 1. 核心问题与研究背景

- **研究对象**：长时序人形机器人（humanoid）的"运动-操纵"任务（loco-manipulation），例如"整理桌面"、"递饮料"、"将衣物放入洗衣篮"等，需在行走、接近、抓取、放置、回收的多个阶段中保持同一物理实体的可寻址性。
- **核心问题——"物体状态发散"（object-state divergence）**：现有 VLA（Vision-Language-Action）策略一般以当前观测的视觉-语言特征隐式地编码物体状态，而任务完成度的判定往往依赖独立的监视器、谓词层或语言层状态。当**驱动动作的物体状态**与**验证动作是否成功的物体状态**不一致时，微小的抓取、对齐或放置误差就会引发：
  - 子任务过早切换；
  - 对错误物体进行操作；
  - 恢复策略失效；
- **物理层面的根源**：物体在度量空间（metric 3D）中移动、发生接触、被容器收纳、被部分遮挡，仅靠隐式的语义特征难以稳定跟踪。
- **核心需求**：需要一种物体中心（object-centered）的状态表示，既能**指导动作**（actionable），又能**事后验证**（verifiable），并且在多个动作 chunk 之间**持久**存在。

## 2. 方法论

### 2.1 整体框架：POT-VLA
- 提出 **Persistent Object Tokenization (POT)**，实例化为 **POT-VLA**，在感知-动作-验证之间共享一份按角色索引的物体记忆。
- 每个 chunk 周期内的循环为：*ground → act → observe → refresh → verify → recover*。

### 2.2 持久物体记忆（M^τ_i_t）
- 输入：高层 VLM 规划器或人工编写的 typed-subtask plan Π = ⟨task_id, I, {τ_i}⟩；
- 对当前活动子任务 τ_i 与其实体集合 E_i，从 RGB-D 观测 o_t 和本体感觉 s_t 构造记忆：
  - M^τ_i_t = {m_e^t | e ∈ E_i}；
  - 每条记录 m_e^t 包含：角色 ID（TARGET / DESTINATION / SUPPORT / HANDOVER_PARTNER 等）、文本短语、2D 包围盒、3D 质心与尺寸、置信度、可见性、关系特征；
- 3D 量通过相机内参与相机→基坐标外参反投影得到，统一在机器人基坐标系下表达，并经过工作空间边界过滤；
- 分割掩码来自 SAM3（在线或缓存）。

### 2.3 持久三维物体令牌（Persistent 3D Object Tokens）
- 将上述记忆通过映射 T(·) 序列化为固定槽位的特征张量 x^obj_t ∈ R^(K×F)，默认 K=8 槽、每槽 F=33 特征；
- 单槽特征向量 = [v_k, q_k, b_k, c_k, s_k, o_k, ρ_k]，分别对应：可见性、置信度、2D 包围盒、3D 质心、3D 尺寸、可选朝向、关系特征；
- 当物体被遮挡或低置信度时，槽位保留但相应字段标记为"不确定"，用于触发重新观测；
- 在动作头 DiT 中插入位置：动作序列 S_t = [Z^state_t, Z^obj_t, Z^action_t]，视觉-语言特征保留为 cross-attention 的编码器隐状态；
- 物体令牌不脚本化末端位姿，也不判定任务成功，仅作为统一的"状态接口"。

### 2.4 动作专家与训练
- 基础动作专家采用 **GR00T-N1.7**，保持相同的 Unitree G1 全身动作表示与运行时；
- 训练目标与基线一致（动作 chunk 预测损失），**不增加额外的物体记忆损失或谓词损失**；
- 在带物体令牌的微调阶段，演示数据附带相同 schema 的物体令牌 sidecar，保证训练-部署对齐；
- 物体令牌由 LayerNorm → Linear → GELU → Dropout → Linear 投影到 d 维，并叠加可学习的角色嵌入与上下文嵌入；padding 槽位被掩码。

### 2.5 几何谓词监督与恢复
- 在每个 chunk 执行完毕 t⁺ = t + H 后，使用同一份记忆 M^τ_i_t⁺ 进行物理一致性验证；
- 谓词形式 p = ⟨κ, α, op, ν, n⟩：类型、参数（来自物体记录）、比较算子、阈值、稳定性窗口；
- 谓词类别 Ψ_i 覆盖：containment、support、end-effector-target proximity、target-destination displacement、bimanual assignment、handover-partner distance；
- 监督器输出状态 ∈ {in_progress, done, blocked, failed, uncertain}，并附带诊断 d_ξ（失败类型定位）；
- 恢复策略集合：continue / retry / reobserve / reground / replan，对应不同的局部刷新或全局重规划反馈（如 object_not_grasped、outside_goal_region）。

## 6. 主要结论与发现

### 6.1 主对比
- 八类真实任务：**直接基线 39/80 → POT-VLA 71/80**；
- Being-0 对齐服务任务：**Being-0 37/50 → POT-VLA 44/50**；
- 最大增益出现在需要**跨多 chunk 维持 3D 关系**的任务，例如：
  - 叠杯子 1/10 → 8/10；
  - 双球放置 5/10 → 9/10；
  - 衣物搬运 3/10 → 9/10；
  - 抽屉/托盘 4/10 → 8/10。

### 6.2 失败模式分析
- 直接基线失败更多源于**度量级物体状态错误**（抓取目标不准、叠杯错位、小目标漏抓、放置越界）而非指令理解错误；
- POT-VLA 通过物体令牌解决"行动前"的大部分接驳错误，再通过几何谓词捕捉"行动后"的残余失败与错误完成；
- 谓词层带来的额外增益验证了"恢复-重观察-重接地"机制的有效性。

### 6.3 消融结论
- 物体令牌带来主要增益（15/40 → 31/40）；
- 几何谓词在此基础上提供边际改进（31/40 → 34/40）；
- 二者结合达到 34/40，符合"令牌负责行动前的接地、验证负责行动后兜底"的分工。

### 6.4 泛化结论
- 最大差距出现在**新物体实例、布局偏移、执行中扰动**三种条件下；
- 干扰物体对两个系统影响均较小，说明 POT 主要通过显式 3D 角色锚定抑制搜索振荡。

## 7. 优点

- **问题定义清晰**：将 VLA 闭环问题具象化为"物体状态发散"，并提出 actionable + verifiable 的双重要求；
- **结构简洁且通用**：POT 作为中间表示层，可在不更换动作专家的前提下接入现有 VLA；
- **共享状态回路**：同一份物体记忆同时驱动动作与谓词验证，避免"动作条件"与"完成判定"双轨不同步；
- **训练简洁**：不引入额外损失函数，复用基线动作损失，仅以 sidecar 方式对齐训练-部署；
- **谓词机制可解释**：恢复决策直接来自物理度量关系，失败模式可定位（failed_grasp、outside_goal_region 等）；
- **实验设计层次分明**：匹配对比、外部参考、消融、泛化四组，环环相扣。
