## 摘要
视觉-语言-动作（VLA）模型在机器人操作中取得了令人瞩目的泛化能力，而近期引入记忆机制的VLA通过以历史图像或语言摘要为条件，放宽了马尔可夫假设。基于视觉的记忆方法通过以采样的历史图像帧为条件来实现这一点，但其计算开销较大，并且在时序事件在视觉上难以区分时（例如多次按下按钮且每次动作幅度很小）存在根本性的局限。我们提出了FM-VLA，一种具备基于力觉的记忆的VLA模型，能够在非马尔可夫、接触密集型操作中进行时序上下文推理。我们利用以力时间序列重构为预训练目标的变分自编码器（VAE），将力历史编码为紧凑的力记忆标记。通过将力隐变量表征与短期状态历史一同作为额外的条件标记投影到动作专家模块，使VLA能够利用累积的接触事件历史来引导操作。我们在三个依赖记忆的任务上对FM-VLA进行了评估，包括寻找隐藏积木、按压按钮以及按指定次数擦拭餐盘。我们的轻量化力记忆机制仅带来极小的推理开销，便实现了超过80%的成功率，显著优于基线方法。项目页面：https://qft-333.github.io/FM-VLA-Page/

## Abstract
Vision-language-action (VLA) models have achieved impressive generalization in robotic manipulation, and recent memory-augmented VLAs have relaxed the Markovian assumption by conditioning on past images or language summaries. Vision-based memory approaches address this by conditioning on sampled past image frames, but they are computationally expensive and fundamentally limited when temporal events are visually ambiguous, e.g., pushing a button multiple times with small movements. We propose FM-VLA, a VLA model with force-based memory, enabling temporal context reasoning for non-Markovian, contact-rich manipulation. We encode force histories into compact force memory tokens with a variational autoencoder (VAE) pretrained with force time series reconstruction. By projecting force latent representations and short state history as additional conditioning tokens to the action expert module, we enable VLAs to leverage accumulated contact event history to guide manipulation. We evaluate FM-VLA on three memory-dependent tasks, including finding a hidden block, pressing a button, and wiping a dish for a specific number of times. Our lightweight force memory achieves over 80% success rate with minimal inference overhead, significantly outperforming baseline approaches. Project page: https://qft-333.github.io/FM-VLA-Page/

# FM-VLA 论文总结

## 1. 核心问题与研究动机

- **核心问题**：当前主流视觉-语言-动作（VLA）模型（如 RT-2、OpenVLA、π0、π0.5 等）普遍采用**马尔可夫假设**，即仅基于当前观测直接预测动作 chunk，缺乏对历史时序信息的记忆能力。
- **场景痛点**：在真实操作任务中，许多关键决策依赖**长期时序上下文**，例如反复按按钮需要计数、擦拭餐盘需要追踪进度、查找隐藏物体需要记忆已检查过的位置等。这类任务天然是**非马尔可夫**的。
- **现有方案的不足**：
  - 基于视觉的记忆方法（MemoryVLA、MEM 等）通过采样历史图像帧作为条件输入，但当**视觉变化微弱**（如按钮行程小）时无法可靠识别接触事件；
  - 视觉记忆机制计算开销大，多帧 RGB 输入显著增加 token 长度与推理延迟；
  - 现有基于力/力矩的 VLA（如 ForceVLA、TA-VLA）仅将力信号作为**短期即时条件**，用于改善当前动作生成，无法积累长时程交互历史。
- **本文洞察**：力/力矩信号天然编码接触事件、力幅值、动作重复次数等交互动态信息，比视觉更直接、无歧义，且**低维、高频、易压缩**，适合作为长时程记忆载体。

## 2. 方法论

### 2.1 总体思路

构建一个 **π0.5 基础上的 VLA 增强架构**，引入两条互补的本体感知记忆流：
1. **长期力历史** $\{f_\tau\}_{\tau=1}^{t}$（6 维腕部 F/T 传感器读数，覆盖整段 episode）；
2. **短期状态历史窗口** $\{s_\tau\}_{\tau=t-W+1}^{t}$（关节位置 + 夹爪状态，约 0.9 s）。

将二者编码后作为额外条件 token 拼接到 flow-matching 动作专家的 suffix 中。

### 2.2 关键技术细节

- **力信号预处理**：
  - 一阶 EMA 平滑（α=0.3）抑制高频噪声；
  - 训练时随机前缀低幅高斯噪声填充（最长约 10 s），避免模型通过序列长度捷径泄露 episode 进度。

- **力记忆编码器（Force-VAE）**：
  - 基于 **Perceiver-IO** 架构，K=8 个可学习 latent query tokens；
  - 训练目标为**掩码 ELBO**：重构项 + free-bits 正则化的 KL 散度；
  - 潜空间维度 $d_z=96$，注意力采用 cross-attention + self-attention 交替堆叠；
  - 任务是**任务无关**的，仅依靠力时间序列重构学习接触事件编码，无需文本或类别标签。

- **短期状态投影器**：
  - 简单线性层（零初始化），端到端学习；
  - 窗口大小 10、步长 3，覆盖约 0.9 s。

- **记忆 token 注入**：
  - 注入位置：**紧跟在 noisy-action token 之后**（不改变 RoPE 位置，保留 π0.5 预训练一致性）；
  - 顺序为 [noisy actions ∥ 8 个 force-memory tokens ∥ 1 个 state token]；
  - VAE 编码器在 Stage 2 冻结，仅推理时取后验均值 μ（不重参数化）。

### 2.3 两阶段训练

- **Stage 1**：Force-VAE 预训练
  - 所有任务的力历史联合训练，使用**逆频率任务采样**避免小数据集被淹没；
  - 优化器 AdamW，100K 步，batch size 512（64×8），peak LR 3×10⁻⁴，bf16；
  - KL 权重 β=1×10⁻³，free-bits λ=0.5 nats。

- **Stage 2**：VLA 微调
  - VAE 编码器冻结并切到 eval 模式；
  - 训练 VLM、action expert、状态投影器、力潜空间投影器；
  - Flow-matching 损失（rectified flow），预测 ε−a₀；
  - 50K 步，global batch size 32，peak LR 5×10⁻⁴，warm-up 1k 步；
  - 每视角图像 dropout p=0.4。

### 2.4 问题形式化

策略为 $\pi(a_t | o_t, l, h_t)$，其中 $h_t = \text{Enc}_\phi(\{f_\tau\}_{\tau=1}^t) \, \| \, \text{Proj}_\psi(\{s_\tau\}_{\tau=t-W+1}^t)$，即用 VAE 编码的长期力记忆与短期状态记忆共同增强策略。

  | Task 2: 按蓝色按钮 N 次 | 按按钮 N∈{1,2,3} 次后停止，视觉位移极小，依靠力脉冲计数 | 350 |

## 6. 主要结论与发现

- **FM-VLA 平均成功率 83.3%**，显著优于所有基线：
  | 方法 | Task 1 | Task 2 | Task 3 | Avg |
  |---|---|---|---|---|
  | π0.5 | 72.2 | 11.1 | 0.0 | 27.8 |
  | TA-VLA | 50.0 | 11.1 | 5.6 | 22.2 |
  | π-MEM | 77.8 | 33.3 | 50.0 | 53.7 |
  | **FM-VLA** | **100.0** | **72.2** | **77.8** | **83.3** |

- 在**视觉模糊任务**（按钮、擦拭）上优势尤为明显：π-MEM 在按按钮上仅 33.3%，FM-VLA 达 72.2%；
- **单独任一模态均不够**：Force-only 25.9%（缺短期空间感知）、State-only 40.7%（缺接触计数），二者互补必需；
- **VAE 显著优于 GRU 与 Q-Former**：GRU 受梯度消失影响丢失早期接触事件，Q-Former 过拟合瞬时峰值；
- **最优 token 数 K=8**：过少（K=4）形成瓶颈，过多（K=16,32）超过 π0.5 训练时的 token 上限造成分布偏移；
- **推理开销极小**：FM-VLA 64.0 ms vs π0.5 60.7 ms（+3.3 ms），而 π-MEM (K=5) 99.8 ms（+39 ms）。

## 7. 优点与亮点

- **物理直觉合理**：用腕部力矩直接编码接触事件，绕过视觉歧义性问题；
- **架构设计精妙**：VAE 预训练 + 冻结注入 + 位置选在 noisy-action 之后，**保护 π0.5 预训练的 RoPE 位置编码**；
- **轻量高效**：仅 K=8 个力记忆 token + 1 个状态 token，推理开销几乎可忽略；
- **消融充分**：从模态、架构、容量多个角度验证了 VAE 的必要性；
- **任务无关的 VAE 表示**：用重构目标而非任务标签学习力潜空间，避免过拟合特定任务；
- **训练技巧细致**：EMA 平滑、随机噪声前缀、free-bits KL 正则化、零初始化投影器等都体现了工程严谨性。

## 8. 不足与局限

- **任务数量有限**：仅 3 个真实世界任务，每任务 18 次试验，统计可靠性与泛化性尚待加强；
- **固定 token 瓶颈**：8 token 对数百次接触事件的极长时程任务可能不足，作者建议未来采用**分层或自适应压缩**；
- **VAE 训练数据受限**：仅基于演示数据集训练，未利用大规模多样化机器人数据集的力记录；
- **双手机器人单臂力信号**：仅使用右腕力矩，左腕力信号未利用，对双臂协作接触场景的适用性存疑；
- **无视觉记忆融合**：将视觉记忆与力记忆结合可能进一步提升，文中未探索；
- **本体单一**：仅 AgiBot G1，未验证在其他机器人（如单臂、灵巧手）上的可迁移性；
- **依赖精确力传感器**：方法有效前提是装配可靠的腕部 F/T 传感器，对低成本平台或柔性末端执行器的适用性未讨论；
- **论文未提供墙钟训练时间**，对算力需求评估不便；
- **评估协议人工化**：成功判据依赖"约 3 s 无运动"等启发式规则，存在主观性。
