## 摘要
我们研究从专家演示中端到端学习组合式机器人策略的问题，且不预设任何任务分解或层次结构。我们探究使用简化的混合专家（MoE）动作头训练的视觉-语言-动作模型能否涌现地学会将任务分解为可复用、可解释的基本单元。我们发现，学习到的专家在多个任务中被大量复用，并始终对应于定性上不同的低层行为，这表明路由器隐式地学会了执行高层排序，而专家则充当组合式的基本单元。我们的MoE在任务性能上与单体基线相当，同时展示了有意义的专家专业化，是迈向仅从数据中涌现的模块化、可解释机器人策略的一步。

## Abstract
We consider the problem of learning compositional robot policies end-to-end from expert demonstrations, without any pre-specified notion of task decomposition or hierarchy. We ask whether a VLA trained with a simplified Mixture-of-Experts (MoE) action head can emergently learn to decompose tasks into reusable, interpretable primitives. We find that learned experts are heavily reused across tasks and consistently correspond to qualitatively distinct low-level behaviors, suggesting that the router implicitly learns to perform high-level sequencing while experts serve as compositional primitives. Our MoE matches the task performance of a monolithic baseline while demonstrating meaningful expert specialization, a step toward modular, interpretable robot policies that emerge from data alone.

## 1. 核心问题与研究动机

- **核心问题**：能否在**端到端**地从专家演示中学习组合式机器人策略的过程中，**无需任何预定义的任务分解或层级结构**，让 VLA（Vision-Language-Action）模型自动涌现出可复用、可解释的行为原语（primitives）。
- **研究背景**：
  - 现有 VLA 模型（如 RT-2、OpenVLA、π₀、Octo、SmolVLA 等）通常作为**单体策略**部署，难以识别可复用技能、难做层级组合、修改局部行为需要调整整个模型。
  - 而机器人操作任务天然具有可分解的阶段特征（如 reach → grasp → place）。
  - 既有层级化 VLA 系统（如 HAMSTER、Fast-in-Slow 等）依赖**人工预设的规划器—控制器分工**，缺乏数据驱动的自动涌现能力。
- **整体含义**：探究一个最小化的 MoE 动作头结构能否在标准模仿学习目标下，自监督地生成"高层路由—低层专家"的层级结构，从而弥合模块化策略设计与端到端训练之间的鸿沟。

## 2. 方法论

### 2.1 核心思想
- 在两个预训练 VLA（π₀ 与 SmolVLA，均使用 flow-matching 进行动作生成）上附加一个**简化 MoE 动作头**，仅替换动作专家中每一层的 **FFN 子层**，自注意力和 VLM 主干共享。
- 路由器（router）在每次前向传播中**只做一次路由决策**，跨所有 L 层动作专家复用，从而让一个专家对应于**端到端一致的行为片段**（技能），而不是 L 个独立层级路由决策的拼凑。

### 2.2 关键技术细节

- **LoRA 化的 MoE 专家**（公式 1）：
  - 每个专家仅以 rank-r LoRA 增量（r=16）与基线 FFN 区分：ΔW = (α/r)·B·A；
  - B 矩阵零初始化，保证训练步 0 时策略与预训练主干完全一致，在强先验之上"涌现"分化。
- **全前向共享路由**（公式 2）：
  - 路由器输入 c = MeanPool(VLM(I, ℓ, s)) ‖ Wₛs，利用 VLM 上下文 + 关节状态；
  - 输出 E 个专家的 logit，取 top-k 并 softmax 归一化，对每个 FFN 应用相同权重 wₑ；
  - 推理时每个 action chunk 路由一次。
- **共享自注意力**：多头自注意保持跨专家共享；只有 FFN 被 base + 路由 LoRA 替代。
- **训练目标**（公式 3）：L = L_FM + λ_LB L_LB
  - L_FM：主干 flow-matching 速度预测损失（在加噪 action chunk 上）；
  - L_LB：经典 load-balancing 损失（Fedus et al., 2022），防止路由坍缩；
  - λ_LB = 0.01。

### 2.3 算法流程（文字描述）
1. 编码视觉 I、语言指令 ℓ、状态 s 得到 VLM 上下文；
2. 路由器 g_φ 基于上下文输出专家权重 w（top-k 归一化）；
3. 在每一层动作专家 FFN 处，应用 base FFN + 选中专家的 LoRA Δ；
4. 共享自注意力处理加噪 action 与 flow-matching 时间步 τ，迭代 K 步 flow-matching 生成动作 chunk â_{t:t+H}。

## 6. 主要结论与发现

- **结构性涌现**：MoE 自动将操作任务分解为可复用原语（如 final transport、release-and-retract、approach-grasp），无需任何任务层级标签或手工技能库。
- **路由器即隐式高层规划器**：路由器在同一轨迹内交替调用专家，把"接近→抓握→搬运→释放"自然缝合；超长视野任务中还能出现"重复尝试"式的恢复行为。
- **专家的两类角色**：
  - **可复用专家**（如 Expert A、B）：在 5 个不同任务中被 35–45% 频率选中，承担跨任务的阶段级技能；
  - **任务专属专家**（如 Expert C 67% 集中在 T5、Expert D 66% 集中在 T2）：吸收特定任务的"长尾"行为，让可复用专家保持简洁。
- **专家≠路由器派生产物**：手动替换路由指派后，专家在新上下文中仍能保持其原技能（如 Expert C 在 T4 也能完成抓握），并能通过手动重新路由恢复抓取失败 → 抓握成功，说明专家本身具有可独立调用的语义原语价值。
- **性能等价**：在 π₀ 与 SmolVLA 上，MoE 与 fine-tuned dense baseline 任务性能相当，但额外获得了模块化与可解释性。

## 7. 优点与亮点

- **设计简洁**：仅替换 FFN + LoRA + 单次路由，参数和训练开销接近 dense baseline，没有引入外部规划器、options、子任务标签或手工技能库。
- **初始化稳健**：B 矩阵零初始化 → 训练起点等价于预训练主干，确保在强先验之上分化而非从零学习。
- **端到端可解释**：专家—技能映射、任务级频率分布以及"manual routing"实验层层递进，提供了从行为视角定性可读的解释视角。
- **通用性强**：方法 backbone-agnostic，同一架构在 π₀ 与 SmolVLA 上都有效。
- **概念性贡献**：与 HAMSTER、Fast-in-Slow 等"强加层级"路线形成鲜明对比，论证了**层级结构本身可以从模仿学习中涌现**，为可解释机器人策略打开新方向。
- **失败可解释**：未完成任务表现为"重复调用已知原语"而非随机退行，便于调试。
