## 摘要
在机器人演示数据上通过行为克隆（BC）微调预训练的视觉-语言模型（VLM）已成为视觉-语言-动作（VLA）策略的标准方案。然而，BC微调会逐步覆盖那些支持视觉与语义泛化的预训练表示。在网络图文数据上进行协同训练是一种常见的补救办法，但它无法阻止这一覆盖过程：它将语言损失与动作损失分别施加在不同的观测上，导致VLA存在语言-动作错位问题，而标准的操作任务基准测试并未揭示该问题。本文提出Anchor-Align，通过两个目标对BC进行增强：视觉-语言锚定从一份冻结的VLM副本中分层蒸馏表示，以防止表示漂移；语言-动作对齐则将每个动作目标转换为离散的"运动方向"标签，并在同一机器人观测上联合训练语言预测与动作预测。在真实xArm7机器人平台上，针对两种广泛使用的VLA架构，Anchor-Align分别将真实机器人成功率从28%提升至54%，以及从37%提升至60%。在仿真的大规模实验中，我们分别在LIBERO-PRO、LIBERO-Plus和CALVIN上展示了对分布外扰动、感知鲁棒性以及长时序控制的一致改进，表明保留预训练表示与有效学习动作并非本质上相互对立。项目主页：anchoralignvla.github.io

## Abstract
Finetuning a pretrained vision-language model (VLM) on robot demonstrations via behavior cloning (BC) has become the standard recipe for vision-language-action (VLA) policies. However, BC finetuning progressively overwrites the pretrained representations that support visual and semantic generalization. Co-training on web image-text data, a common remedy, does not prevent this; it applies language and action losses to separate observations, leaving VLAs with language-action misalignment that standard manipulation benchmarks do not expose. We propose Anchor-Align, which augments BC with two objectives: Vision-Language Anchoring distills layer-wise representations from a frozen VLM copy to prevent this drift, while Language-Action Alignment converts each action target into a discrete motion-direction label and jointly trains language and action prediction on the same robot observation. On a physical xArm7 robot, across two widely used VLA architectures, Anchor-Align improves real-robot success on both (28% to 54% and 37% to 60%). At scale in simulation, we demonstrate consistent improvements on OOD perturbations, perceptual robustness, and long-horizon control across LIBERO-PRO, LIBERO-Plus, and CALVIN, respectively, suggesting that preserving pretrained representations and effective action learning are not fundamentally at odds. - **背景**：在预训练的视觉-语言模型（VLM）基础上，通过行为克隆（BC）在机器人示教数据上微调，已成为构建视觉-语言-动作（VLA）策略的主流范式（如 OpenVLA、π₀ 等）。
- **核心问题**：
  - **表征漂移/覆盖问题**：BC 微调会逐步"覆盖"预训练 VLM 中的视觉与语义表征，从而损害模型在新视觉场景、新指令或新物体组合上的泛化能力。
  - **语言-动作错位问题**：一种常见的补救手段是与网络图文数据联合训练，但这只是"补丁式"地外加一个语言损失；该语言损失与动作损失分别施加在两张不同的观测图像上（图文对来自互联网、动作标注来自机器人），导致 VLM 内部的语言语义空间与学到的动作空间出现错位，而标准操作基准测试（LIBERO、RTX 等）并未暴露这一问题。
- **整体含义**：论文指出，"保留预训练泛化能力"和"有效学习机器人动作"并非天然对立，需要针对性的、作用于表征层面的训练目标来同时保留二者。

## 2. 方法论：Anchor-Align

Anchor-Align 在标准 BC 损失之上增加两个辅助目标，构成"**锚定 + 对齐**"的训练框架。

### 2.1 视觉-语言锚定（Vision-Language Anchoring）
- 维护一份**冻结的预训练 VLM 副本**作为"教师"。
- 将学生 VLA 模型的**逐层（layer-wise）中间表征**与冻结教师在相同输入下的对应层表征进行**蒸馏**（如 MSE 或余弦距离损失）。
- 目的：阻止 BC 更新把视觉/语言表征推向"过拟合于机器人动作数据"的子空间，从而防止表示漂移（representation drift）。

### 2.2 语言-动作对齐（Language-Action Alignment）
- 将每个连续动作目标（例如末端位姿增量）**转换为一组离散的"运动方向"标签**（例如"上 / 下 / 左 / 右 / 前 / 后"等语义化类别）。
- 在**同一机器人观测**上同时预测：
  - 语言描述（如任务指令的下一 token）；
  - 动作对应的运动方向类别。
- 两个预测头共享 VLM 主干，使得语言语义和动作语义必须建立在**同一观测的同一表征**上，从而缓解语言-动作错位。

### 2.3 算法流程（文字描述）
1. 取一条机器人示教样本（观测图像 $o_t$、语言指令 $l$、动作 $a_t$）。
2. 计算主损失 $L_{\text{BC}}$（动作回归 / flow matching / 离散动作头等，与所选 VLA 架构一致）。
3. 计算锚定损失 $L_{\text{anchor}}$（学生 VLA 与冻结 VLM 教师的逐层表征蒸馏）。
4. 将 $a_t$ 离散化为运动方向标签 $d_t$，在 $o_t$ 上与 $l$ 联合做 next-token 预测，计算对齐损失 $L_{\text{align}}$。
5. 总损失 $L = L_{\text{BC}} + \lambda_{\text{anchor}} L_{\text{anchor}} + \lambda_{\text{align}} L_{\text{align}}$，整体微调学生 VLA。

### 2.4 适用性
- 该方法在论文中验证了**两种主流 VLA 架构**（从摘要与表中可推测为基于 OpenVLA 与基于 π₀/动作块结构的两种 VLA），具有架构无关性。

- **与"安全/在线学习"的联系弱**：论文关注的是离线 BC 微调，并未涉及在线 RLHF、扩散/flow 动作头下的兼容性，以及失败恢复等问题。
- **数据偏差风险**：实验均基于特定示教集合，未对数据集规模、多样性、采样偏差的影响进行系统分析；若示教本身覆盖度低，锚定再强也无法生成新行为。
- **应用限制**：离散化与锚定机制假设动作可由"方向语义"近似表达，对于高维连续控制（如多指灵巧手）与接触丰富任务的有效性尚需进一步验证。
