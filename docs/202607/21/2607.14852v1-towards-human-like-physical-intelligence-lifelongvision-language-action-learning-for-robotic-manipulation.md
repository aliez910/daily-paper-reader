## 摘要
类似于人类依次学习新任务的天然能力，具备视觉-语言-动作（VLA）模型的机器人应当拥有终身学习能力，以便在开放世界环境中部署时学习新任务。然而，近期提出的大多数终身学习模型旨在有效学习当前任务（可塑性）或在先前任务上保持高精度（稳定性），而可塑性-稳定性权衡问题在机器人操作模型中仍未得到很好的解决。为应对这一根本性挑战，我们提出了一种面向机器人操作的高缓存效率的终身视觉-语言-动作学习框架（即 LifelongVLA），该框架通过双时间尺度自适应机制缓解可塑性-稳定性权衡，并通过高缓存效率的回放策略实现低成本的机器人部署。具体而言，我们提出了一种双时间尺度 LoRA 门控模块，将 VLA 自适应分解为两条轻量化路径：用于可塑性的短期适配器和用于稳定巩固的长期适配器。这些路径通过任务感知门控进行集成，从而能够显式地控制可塑性-稳定性权衡。在技能回放阶段，我们提出了一种高缓存效率的随机回放策略，无需完整轨迹存储即可保留更加均衡的保留信号。最后，实验表明，LifelongVLA 优于现有基线方法，展示了高效技能扩展、对已学操作行为的稳健保留，并减少了对 xArm 机器人真实世界部署中重训练的依赖。

## Abstract
Similar to the natural capabilities of humans to sequentially learn new tasks, robots with Vision-Language-Action (VLA) models should possess lifelong learning ability to learn a new task when deployed in open-world environments. However, most recently proposed lifelong learning models aim to effectively learn the current task (plasticity) or maintain high accuracy on previous tasks (stability), while the plasticity-stability trade-off remains largely unsolved in robotic manipulation models. To address this fundamental challenge, we propose a cache-efficient lifelong Vision-Language-Action learning framework for robotic manipulation (i.e., LifelongVLA), which alleviates the plasticity-stability trade-off with a dual-timescale adaptation mechanism while achieving low-cost robotic deployment with a cache-efficient replay strategy. More concretely, we propose a dual-timescale LoRA gating module to decompose VLA adaptation into two lightweight pathways: a short-term adapter for plasticity and a long-term adapter for stable consolidation. These pathways are integrated via a task-aware gate, enabling explicit control of the plasticity-stability trade-off. In the skill replay phase, a cache-efficient stochastic replay strategy is proposed to preserve more balanced retention signals without full-trajectory storage. Finally, experiments show that LifelongVLA outperforms existing baselines, demonstrating efficient skill expansion, robust retention of learned manipulation behaviors, and reduced reliance on retraining for real-world deployment on an xArm robot.

# LifelongVLA 论文总结

## 1. 核心问题与研究背景

- **研究目标**：让机器人像人类一样，**在部署后能够持续学习新技能**，同时不遗忘已掌握的技能，即具备"终身学习"能力。
- **研究对象**：Vision-Language-Action (VLA) 模型——一类将预训练视觉-语言表征与机器人动作生成相结合的多模态策略（如 RT-2、Octo、π0 系列等）。
- **关键挑战**：**可塑性-稳定性权衡（plasticity-stability dilemma）**未得到有效解决：
  - 高可塑性 → 快速学习新技能，但可能覆盖已有行为；
  - 高稳定性 → 保留旧技能，但限制新技能学习。
- **现有方法的局限**：
  - 顺序微调（SFT）→ 灾难性遗忘严重；
  - 全数据回放 → 存储与计算代价过高，难以用于大规模 VLA 主干；
  - 架构扩展 / 参数隔离 → 路由开销与推理延迟增加。
- **核心动机**：在冻结大型 VLA 主干的前提下，引入**显式可调的可塑性-稳定性平衡机制**，同时**大幅降低回放开销**，以满足开放世界真实部署的需求。

## 2. 方法论

论文提出 **LifelongVLA** 框架，由两个核心模块组成。

### 2.1 Dual-Timescale LoRA Gating（双时间尺度 LoRA 门控）

- **核心思想**：将单一 LoRA 适配器**分解为两条低秩路径**，分别承担不同时间尺度的适配：
  - **短期路径（short-term adapter）**：由当前任务损失 $\mathcal{L}_{new}$ 更新，学习率 $\eta_{sh}$ 较大，负责"快速可塑性"；
  - **长期路径（long-term adapter）**：由回放损失与蒸馏损失 ($\lambda \mathcal{L}_{rep} + \beta \mathcal{L}_{dist}$) 更新，学习率 $\eta_{lg} < \eta_{sh}$，负责"稳定巩固"。
- **任务感知门控（task-aware gate）**：
  - 门控上下文 $c$ 来自**冻结前缀特征的池化**（避免循环依赖）；
  - 通过轻量级映射得到权重 $\alpha_\ell^t(c) = \sigma(W_g^\ell \phi(c) + b_g^\ell) \in [0,1]$；
  - 在**权重层面**组合两条路径：
    $$\Delta W_\ell^t(c) = (1 - \alpha_\ell^t)\Delta W_\ell^{sh} + \alpha_\ell^t \Delta W_\ell^{lg}$$
  - 推理仍只需**单次前向传播**，无需双路推理。
- **效果**：$\alpha \to 0$ 强调近期可塑适应，$\alpha \to 1$ 强调稳定记忆，提供显式可调的接口。

### 2.2 Cache-Efficient Stochastic Replay（缓存高效随机回放）

- **核心思想**：避免存储完整轨迹，仅保存**少量随机样本的"前缀记忆锚点"**。
- **存储内容**：每条缓存样本仅保留
  - stop-gradient 的**前缀 token** $\bar{h}_{i,t}^{pre}$；
  - 紧凑的**状态-动作监督** $(s_i^t, y_i^t)$；
  - **不存储**原始图像、语言 token、suffix token、扩散时间和噪声。
- **随机回放机制**：
  - 每个训练步重新采样扩散变量 $(\tau', \epsilon')$，基于当前模型重新编码 suffix；
  - 同一缓存前缀可生成多个"随机去噪实例"，提供多样化的保留信号。
- **混合训练目标**：
  - 当前样本与回放样本**拼接 + shuffle** 后同批训练；
  - 引入 **teacher distillation**：使用任务 $t-1$ 的模型快照 $\bar{F}_{t-1}$ 作为教师稳定旧技能预测；
  - 总损失：$\mathcal{L}_t = \mathcal{L}_{new} + \lambda \mathcal{L}_{rep} + \beta \mathcal{L}_{dist}$，对当前项与回放项分别归一化，避免任一方主导。

### 2.3 整体框架

- 冻结 **PaliGemma (Gemma 2B)** 作为视觉-语言主干；
- **Gemma 300M** 作为连续动作解码器，输出 7D 机器人动作；
- 所有 LoRA 适配、门控、回放均作用于 LoRA 层，主干参数 $\Theta_0$ 始终冻结。

## 3. 实验设计

### 3.1 数据集与场景

- **仿真基准**：LIBERO benchmark，选取 **10 个连续递增的操控任务**；
- **真实机器人**：在 **xArm** 上设置 5 个递增任务的真实部署；
- 每个任务 50 条训练轨迹、50 条评估轨迹，无任务身份提示。

### 3.2 对比方法

- **SFT（顺序微调）**：作为遗忘基线；
- **LwF-LoRA**：基于输出蒸馏的持续学习（Li & Hoiem, 2017）；
- **ER**：基于情节回放的持续学习（Chaudhry et al., 2019）；
- **Info-VLA**：信息论正则化约束（2026）；
- **AtomicVLA**：技能级专家特化方法（2026）；
- **Joint（联合训练上限）**：所有任务数据训练，不参与排名。

### 3.3 评估指标

- **SR（成功率）**：$SR = \frac{1}{T}\sum_{i=1}^T a_{T,i}$；
- **FOR（遗忘率）**：$\text{FOR}_i = \max_{l \in \{i,...,T-1\}} a_{l,i} - a_{T,i}$，平均遗忘率 $\text{FOR} = \frac{1}{T-1}\sum \text{FOR}_i$；
- **ACC_t（过程级增量精度）**：$\text{ACC}_t = \frac{1}{t}\sum_{i=1}^t a_{t,i}$。

## 6. 主要结论与发现

- **性能领先**：LifelongVLA 在平均 SR 上达到 **83.2%**，平均 FOR 仅为 **11.4%**；
- **相对提升**：相比最强基线 ER，SR 提升 **+13.0%**，FOR 降低 **−8.2%**；
- **极端基线失败**：SFT 与 LwF-LoRA 平均 SR 仅 7.8%，表明仅靠顺序微调或蒸馏不足以应对该任务；
- **复杂方法未必更优**：Info-VLA 与 AtomicVLA 平均 SR 仅 28.6%，信息论正则或技能特化未能完全解决权衡问题；
- **任务级亮点**：在任务 5、9、10 上分别取得 96%、98%、96% 的 SR，任务 9 的 FOR 为 0；
- **效率优势**：相比 AtomicVLA（226.49M 参数 / 452.98 MiB/任务），LifelongVLA 仅 99.97M 参数 / 95.70 MiB/任务，回放内存减少 **91.92 MiB/任务**；
- **真实部署有效性**：在 xArm 上 5 个任务全部学完后，每个任务的 SR 均 **超过 80%**。

## 7. 优点

- **问题定义清晰**：明确聚焦"可塑性-稳定性权衡"这一核心难题，并给出可量化的双指标（SR / FOR）评估；
