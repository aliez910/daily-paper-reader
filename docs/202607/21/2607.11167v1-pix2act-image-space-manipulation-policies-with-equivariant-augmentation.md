## 摘要
将操作动作表示为相机平面中的二维轨迹，为学习复杂的三维操作策略提供了一种紧凑且可解释的基础。然而，这也带来了轨迹超出视野和精度有限等挑战。我们提出了 Pix2Act，一种模仿学习方法，通过在每个相机平面中生成连续的图像空间关键点轨迹，并通过三角测量无损地恢复末端执行器位姿，从而应对这些挑战。该方法将高维三维控制重新表述为一个更简单、更易学习的二维预测问题。至关重要的是，它使观测与动作对齐于同一坐标空间，从而能够通过等变变换将各个相机图像与其图像空间动作联合旋转。我们分析了该增强的对称性属性，并设计了一种能够融合多相机视图同时尊重各视图旋转的网络架构。因此，Pix2Act 隐式地扩展了数据分布的支撑集，并学习跨变换的不变动作结构，从而获得更好的泛化能力与整体性能。在多样化的仿真与真实世界操作任务中，Pix2Act 优于最先进的基线方法，并在相机扰动下保持鲁棒性。

## Abstract
Representing manipulation actions as 2D trajectories in the camera plane provides a compact and interpretable basis for learning complex 3D manipulation policies. However, it also creates challenges from out-of-frame trajectories and limited precision. We propose Pix2Act, an imitation learning method that addresses these challenges by generating continuous image-space keypoint trajectories in each camera plane and losslessly recovering end-effector poses via triangulation. This reformulates high-dimensional 3D control as a simpler, more learnable 2D prediction problem. Crucially, it aligns observations and actions in the same coordinate space, enabling equivariant transformations to jointly rotate individual camera images together with their image-space actions. We analyze the symmetry properties of this augmentation and design a network architecture that can fuse multiple camera views while respecting their per-view rotations. As a result, Pix2Act implicitly enlarges the support of the data distribution and learns invariant action structures across transformations, yielding improved generalization and overall performance. Across diverse simulated and real-world manipulation tasks, Pix2Act outperforms state-of-the-art baselines and remains robust under camera perturbations.

# Pix2Act：基于等变增强的图像空间操作策略 —— 论文总结

## 1. 核心问题与研究动机

- **背景**：模仿学习（Imitation Learning）是机器人操作策略学习的主流范式之一。现有方法通常直接让策略网络从图像观测预测高维 3D 末端执行器位姿（如 6-DoF 动作），但在图像空间与动作空间之间缺乏统一表示，导致数据效率与泛化能力受限。
- **核心挑战**：
  - 高维 3D 控制信号难学，策略网络在小数据集下容易过拟合；
  - 相机视角发生扰动时，预测精度显著下降；
  - 部分已有方法尝试在图像空间预测 2D 轨迹，但存在两条主要问题——**轨迹出框（out-of-frame）**与**2D 精度有限**，难以恢复高质量的 3D 位姿。
- **整体目标**：将复杂的 3D 操作策略学习问题转化为更易学的 2D 预测问题，同时保持可恢复性、紧凑性与跨视角泛化能力。

## 2. 方法论

### 2.1 核心思想
- 将每个相机视角下的末端执行器动作表示为**相机平面上的连续 2D 关键点轨迹**；
- 利用多个相机的 2D 轨迹通过**三角化（triangulation）**无损恢复 3D 末端位姿；
- 由此实现"观测—动作同空间"对齐，使**等变数据增强**成为可能。

### 2.2 关键技术细节
1. **动作表示**
   - 每个相机产生一条 2D 关键点轨迹：$\{(u_i, v_i)\}_{i=1}^{T}$，表示末端执行器在图像平面上随时间的关键点位置；
   - 关键点是连续的（dense keypoints），而非离散点，以保留动作的细粒度信息。

2. **3D 位姿恢复**
   - 多相机视图下，已知相机内外参，对 2D 关键点进行三角化（multi-view triangulation），即可反推出每个时刻末端执行器的 3D 位置与姿态；
   - 该过程**无损**，因此 2D 预测的精度上限即 3D 控制的精度上限。

3. **等变增强（Equivariant Augmentation）**
   - 对每个相机图像及其对应 2D 关键点轨迹施加**同平面旋转**（in-plane rotation）变换；
   - 由于观测（图像）和动作（关键点）在同一图像坐标系内，该旋转对二者是**等变**的（同步旋转）；
   - 网络通过学习这种对称性，隐式扩大数据分布的支撑集（support set），提升泛化。

4. **多视图融合网络架构**
   - 每个相机分支采用保持**单视角旋转对称性**的网络结构（如 equivariant 卷积 / 旋转等变特征）；
   - 多相机特征在融合阶段聚合，使得最终策略对每个相机单独的旋转变换都保持不变性。

5. **训练流程**（文字概述）
   - 输入：多相机 RGB 图像；
   - 输出：每个相机的 2D 关键点轨迹；
   - 推理阶段：对 2D 轨迹三角化，得到 3D 末端执行器轨迹；
   - 监督信号来自专家演示的 3D 末端轨迹，反投影到各相机平面得到 2D 关键点真值。
