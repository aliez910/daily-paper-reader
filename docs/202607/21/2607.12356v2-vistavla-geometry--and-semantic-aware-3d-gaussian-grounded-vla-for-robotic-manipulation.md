## 摘要
视觉-语言-动作（VLA）模型通过将语言指令和二维视觉输入直接映射为动作，已成为机器人操作中一种强大的端到端范式。然而，这类模型缺乏显式的场景级三维表征，限制了其对空间布局和几何约束的推理能力。虽然近期有研究尝试引入深度图或点云等显式三维线索以增强几何感知能力，但这些方法主要捕获的是底层结构，缺乏三维空间中的高层语义锚定。在人类认知中，与物理世界的交互依赖于一种三维语义认知地图——一种将空间布局与语义上下文相融合的内部心理模型，从而实现持久且视角不变的推理。受此启发，我们提出了VistaVLA，一种新颖的两阶段框架。该框架从三维高斯基元构建几何与语义感知的三维认知表征，并将其作为紧凑的上下文标记用于VLA策略学习。具体而言，VistaVLA将多视图视觉-语言特征提升至三维高斯基元中，形成几何锚定的语义标记，使视图一致的空间锚定与二维视觉特征空间对齐。为使该三维表征在计算上对有效的VLA控制可行，我们引入了合并-查询（MtQ）这一标记摘要机制。MtQ将密集的高斯基元压缩为一组高度紧凑且具有空间信息的标记，在保留与动作相关的三维布局和语义上下文的同时，实现了99%的标记削减率。在仿真环境和真实环境中的大量评估验证了VistaVLA的有效性。值得注意的是，在真实场景中，VistaVLA在七项真实任务上将成功率提升了22.8%，并在具有挑战性的分布外任务上较VLA-Adapter基线提升了30.0%。

## Abstract
Vision-Language-Action (VLA) models have emerged as a powerful end-to-end paradigm for robotic manipulation by mapping language instructions and 2D visual inputs directly to actions. However, these models lack an explicit, scene-level 3D representation, limiting their ability to reason over spatial layouts and geometric constraints. While recent efforts incorporate explicit 3D cues, such as depth maps or point clouds, to improve geometric awareness, they primarily capture low-level structures and lack high-level semantic grounding in 3D space. In human cognition, interaction with the physical world relies on a 3D semantic cognitive map - an internal mental model that integrates spatial layouts with semantic context to enable persistent, viewpoint-invariant reasoning. In light of this, we present VistaVLA, a novel two-stage framework that constructs a geometry- and semantics-aware 3D cognitive representation from 3D Gaussian primitives and grounds it as compact context tokens for VLA policy learning. Specifically, VistaVLA lifts multi-view vision-language features into 3D Gaussian primitives, forming geometry-anchored semantic tokens that align view-consistent spatial grounding with 2D visual feature spaces. To make this 3D representation computationally tractable for effective VLA control, we introduce Merge-then-Query (MtQ), a token summarization mechanism. MtQ compresses dense Gaussian primitives into a highly compact set of spatially informative tokens, achieving a 99% token reduction while preserving action-relevant 3D layouts and semantic context. Extensive evaluations in both simulated and real-world environments demonstrate the effectiveness of VistaVLA. Notably, in real-world scenarios, VistaVLA improves success rates by 22.8% across seven real-world tasks and by 30.0% over the VLA-Adapter baseline on challenging out-of-distribution tasks.

# VistaVLA 论文总结

## 1. 核心问题与研究动机

- **VLA 模型的瓶颈**：现有 Vision-Language-Action（VLA）模型（如 OpenVLA、π0、VLA-Adapter 等）主要依赖 2D 图像观测，缺乏显式的场景级 3D 表示，难以对空间布局与几何约束进行可靠推理，在需要精确定位或接触丰富的操作任务中容易失败。
- **现有 3D VLA 方案的不足**：近期工作（PointVLA、SpatialVLA、3D-CAVLA 等）通过深度图、点云或稀疏 3D 坐标注入几何线索，但这些方法：
  - 仅提供低层结构信息，缺乏高层语义锚定；
  - 表示往往以观测为中心（observation-centric）而非场景级（scene-level），无法形成持久的多视角一致的 3D 语义认知地图。
- **认知科学启发**：人类与物理世界交互依赖的是"3D 语义认知地图"——一种将空间拓扑与功能语义融合的内部心理模型，能够实现视角不变的持续推理。这正是当前 VLA 体系所缺少的。

## 2. 方法论

VistaVLA 是两阶段框架，将 3D 高斯基元（3D Gaussian primitives）作为场景级 3D 认知表征，并将其压缩为紧凑 token 注入 VLA 策略。

### Stage I：几何–语义感知的 3D 高斯认知表征
- **紧凑教师特征空间**：为每帧训练图像提取 SigLIP2 与 DINOv2-Large 的拼接特征（共 2176 维），通过一个轻量自编码器压缩为 128 维潜码，作为 Gaussian 特征渲染的"教师"。
- **两阶段高斯特征渲染**（基于 DepthSplat 扩展）：
  - 每个 Gaussian 原语 $g_i = (\mu_i, \Sigma_i, \alpha_i, c_i, z_i)$，其中 $z_i \in \mathbb{R}^{128}$ 是学到的语义潜码；
  - 渲染器输出 RGB、深度和特征图 $(\hat{I}_v, \hat{D}_v, \hat{F}_v) = \mathcal{R}(G, v)$；
  - 第一阶段损失 $\mathcal{L}_{\text{stage1}} = \lambda_{\text{rgb}}\mathcal{L}_{\text{rgb}} + \lambda_{\text{dep}}\mathcal{L}_{\text{dep}}$ 稳定几何；
  - 第二阶段增加教师特征监督 $\mathcal{L}_{\text{feat}}$，在不松弛几何约束的前提下蒸馏语义特征。
- **3D-grounded GS Token 化**：每个 Gaussian 的潜码 $z_i$ 即为 GS token。由于渲染采用与 3DGS 一致的 alpha-compositing：

$$
\hat{F}_v(p) = \sum_{i \in \mathcal{N}(p)} R_i(v,p)\,z_i, \quad R_i(v,p) = T_i^v(p)\alpha_i^v(p)
$$

  其中 $R_i(v,p)$ 由投影、不透明度、深度排序与相机参数共同决定，因此每个 $z_i$ 同时对齐 2D 教师特征空间，又受到 3D 原语几何与可见性约束，得到**多视角一致、3D 锚定的语义描述子**。

### Stage II：Merge-then-Query（MtQ）紧凑化与策略注入
- **参数无关压缩（Parameter-free Compression）**：
  - 将密集 GS token 重塑为 per-view 网格后用 stride-4 平均池化粗降到约 7K；
  - 借助 Gaussian 中心的 **Morton 码**对 token 排序，交替划分为 anchor 集 $A$ 与 non-anchor 集 $B$；
  - 每个 non-anchor token 通过语义相似度匹配到最相似的 anchor：

$$
a^*(u) = \arg\max_{a \in A} \frac{\langle z_u, z_a \rangle}{\|z_u\|\|z_a\|}
$$

  - 仅合并相似度排名前 50% 的匹配，按"size-weighted averaging"更新 anchor 的语义特征、空间中心与聚合大小，直到 token 数 $N' \approx 1000$。
- **基于 Query 的 GS 摘要（Query-based Summarization）**：
  - 用 $N_q = 64$ 个可学习 query 通过两层 Transformer 解码器对压缩 token 做交叉注意力；
  - 投影到下游 LLM 的隐藏维度得到 $X_{\text{gs}} \in \mathbb{R}^{B \times 64 \times d_{\text{llm}}}$，作为紧凑的 3D 上下文 token。
- **动作生成**（沿用 VLA-Adapter 的因果序列建模）：
  - 拼接 token 顺序为 $X = [X_{\text{vis}}, X_{\text{lang}}, X_{\text{gs}}, X_{\text{act}}]$，使 GS 上下文在语言条件化后再被动作 query 关注；
  - 预测未来 $K$ 个连续动作并以 $\ell_1$ 损失回归；推理时执行前 $K_{\text{exec}} = 4$ 个动作后再基于最新观测重规划。
- **推理流程**：在线从策略的实时 RGB 观测与标定相机位姿构建 Gaussian 场（无需深度输入与第三视角），每步重新生成 GS token。

## 3. 实验设计

- **真实场景基准（Agile-Piper 机械臂）**：构建 7 个桌面操作任务，覆盖简单 pick-and-place、堆叠、整理、关节物体交互与多阶段长视程任务：
  1. PlaceSponge  2. StackBoxes  3. StackBowls  4. PlacePlate
  5. OrganizeSponge  6. ThrowTrash  7. Wand&Cup
- **空间鲁棒性测试**：在 PlaceSponge 上引入高度/深度扰动；在 OrganizeSponge 上引入 2D 位置扰动。
- **仿真基准**：标准 LIBERO 四个子集（Spatial / Object / Goal / Long）与零样本迁移到空间分布外场景的 LIBERO-Pro-Swap。
- **对比方法**：
  - 主要基线：VLA-Adapter-0.5B（同等训练预算、相同视角设置）；
  - 几何增强基线：VLA-Adapter+Depth（沿用 SpatialVLA 的深度注入策略）；
  - 通用大规模 VLA：π0.5-3B、SmolVLA-0.5B；
  - LIBERO 对比：OpenVLA、π0、UniVLA、OpenVLA-SF、Q-Depth VLA、MolmoAct、GR00T N1、CoT-VLA、WorldVLA 等。
- **评估协议**：每任务 10 次试验，初始位姿一致、试验间重置物体。

## 5. 实验数量与充分性

- **主对比实验**：7 个真实任务 + 标准 LIBERO 四子集 + LIBERO-Pro-Swap，覆盖范围较广。
- **消融实验（Table 3）**共三组：
  - **Camera/Token 消融**：Base-1Cam / Base-2Cam / Base-3Cam（256/512/768 2D token）与 VistaVLA-3Cam（仅 320 token），证明收益并非来自更多视角或更多图像 token；
  - **压缩策略消融**：FPS+Dec、Entropy+Dec、Merge+Linear 与完整 MtQ；
  - **Query token 数量消融**：16/32/64/128/256（最优 64）。
- **公平性设计**：
  - 所有方法在相同任务演示、相同评估协议、相同训练预算下进行；
  - 基线 VLA-Adapter 被显式扩充到与本方法相同数量的固定相机视角，避免"多视角"成为额外变量；
  - 提供 ±Depth 等强基线并报告通用大规模 VLA 的结果。
- **可能存在的局限**：每个真实任务仅 10 次试验，统计置信区间较宽；空间扰动只覆盖两个任务，对更广泛 OOD 的覆盖仍有限。

## 6. 主要结论与发现

- **真实场景**：VistaVLA 在 7 个任务上的平均成功率显著高于 VLA-Adapter 及其 +Depth 变体，并在多个任务上优于更强大的通用 π0.5；论文摘要给出整体提升 22.8 个百分点。
- **空间扰动鲁棒性**：在 PlaceSponge 深度扰动下从 6/10 提升到 9/10；在 OrganizeSponge 位置扰动下从 0/10 提升到 3/10（唯一非零方法），但绝对值仍偏低，说明大范围位置偏移仍是开放问题。
- **仿真结果**：
  - 标准 LIBERO 平均成功率 96.05%（无大规模动作数据预训练方法中最佳）；
  - LIBERO-Pro-Swap（空间分布外）平均成功率从基线 1.7% 提升到 12.2%，相对 VLA-Adapter 提升 30.0%。
- **关键洞察**：增益主要源于"将语义特征以结构化形式锚定到 3D 空间"这一接口设计，而非单纯引入额外 3D 线索或更多相机视角；2D token 增多对基线收益有限，而 VistaVLA 在更小 token 预算下取得更优性能。
- **MtQ 设计有效性**：Morton 引导的几何感知合并 + query 摘要都比 FPS、熵采样或纯线性投影更优；64 个 query token 是两层 Transformer 摘要器的较佳容量。

## 7. 优点

- **认知启发的清晰故事线**：以"3D 语义认知地图"为动机，方法设计与生物智能的空间认知相呼应，解释性强。
- **双重新颖性**：将语义特征提升到 3D Gaussian 形成 3D-grounded token，并设计 MtQ 在 99% 压缩率下保留动作相关 3D 布局与语义一致性，工程上兼顾表达力与效率。
- **多视角一致的 3D 语义锚定**：通过 alpha-compositing 的渲染监督，使每个 Gaussian 的潜码既对齐 2D 基础特征空间，又受几何与可见性约束，比单纯注入深度/点云更适合 2D 预训练 VLM/LLM backbone。
- **接口轻量、可插拔**：仅作为额外 3D 上下文 token 注入，无需改动主流 VLA backbone（VLA-Adapter-0.5B），便于迁移。
- **公平与全面的对比**：匹配训练预算与相机视角，提供 +Depth 与大规模通用 VLA 多重基线；消融三组（视角/token、压缩策略、query 数量）系统验证了设计选择的必要性。
- **零样本空间 OOD 改进显著**：LIBERO-Pro-Swap 上从 1.7% 到 12.2%，表明该接口具备一定的空间泛化能力。

## 8. 不足与局限

- **平台与场景限制**：评估仅基于桌面级 Agile-Piper 机械臂 + 标定多视角相机，工作空间、遮挡与机器人形态均较单一，未涉及移动操作、人形机器人等更复杂场景。
- **对位姿的依赖**：Gaussian 场的构建仍依赖已标定相机位姿，论文明确指出这是当前局限，未来需放宽标定假设。
- **统计显著性偏弱**：真实任务每任务仅 10 次试验，缺少置信区间或方差报告，结论的稳健性仍可加强。
- **扰动覆盖有限**：空间鲁棒性实验仅在 PlaceSponge、OrganizeSponge 两个任务上各引入一种扰动，未覆盖光照、物体外观、新物体等更广泛 OOD 维度。
- **高斯场训练细节披露有限**：未单独给出 Gaussian 自编码器与两阶段渲染训练所需的 GPU 时间、数据规模、收敛曲线等资源细节。
- **计算开销的实时性未充分量化**：虽然 MtQ 实现 99% 压缩，但未给出在线重建 + MtQ + VLA 推理的端到端延迟与频率指标，难以判断其在更高频率控制回路中的可用性。
- **方法泛化边界未知**：将语义高斯场推广到动态场景、关节物体或非刚体操作时，alpha-compositing 与 Morton 划分假设是否仍然成立尚未验证。
