## 摘要
视觉-语言-动作策略是通用机器人控制的有前景的基础，但长时序人形机器人运动操控要求机器人将任务物体视为在运动、接触、遮挡和恢复过程中持续存在的物理实体。我们将该问题建模为物体状态偏差：用于条件化全身动作的物体状态可能与用于判断动作是否达到预期物理关系的状态不同。我们提出了\emph{持久物体标记化}（POT），该方法从RGB-D观测中维护按角色索引的三维物体记录，并将其转换为用于全身动作专家的物体标记。具体实例化为\emph{POT-VLA}后，同一物体记录既用于条件化动作生成，又支持几何谓词检查，从而构成一个闭环执行系统，其中物体状态既可执行又可验证。在Unitree G1上，POT-VLA将匹配的直接GR00T-N1.7基线在八类真实任务上的成功率从39/80提升至71/80。在与Being-0对齐的外部参考测试中，POT-VLA在对齐的服务任务上达到44/50的成功率，而Being-0论文报告的成功率为37/50。最大改进出现在需要维持三维关系的任务上，这表明以物体为中心的持久状态是可验证人形机器人VLA执行的有用抽象。

## Abstract
Vision-language-action policies are a promising foundation for general robot control, but long-horizon humanoid loco-manipulation requires the robot to treat task objects as persistent physical entities across movement, contact, occlusion, and recovery. We study this problem as object-state divergence: the object state used to condition a whole-body action can differ from the state used to decide whether the action achieved the intended physical relation. We propose \emph{Persistent Object Tokenization} (POT), which maintains role-indexed 3D object records from RGB-D observations and converts them into object tokens for a whole-body action expert. Instantiated as \emph{POT-VLA}, the same object records condition action generation and support geometric predicate checks, yielding a closed-loop execution system in which object state is both actionable and verifiable. On a Unitree G1, POT-VLA improves a matched direct GR00T-N1.7 baseline from 39/80 to 71/80 successes over eight real-world task families. In an external Being-0-aligned reference, POT-VLA achieves 44/50 successes on aligned service tasks, compared with the 37/50 success reported by the Being-0 paper. The largest gains occur on tasks requiring maintained 3D relations, suggesting that persistent object-centered state is a useful abstraction for verifiable humanoid VLA execution.

# 论文总结：基于持久化 3D 物体标记的可验证人形机器人 VLA 闭环系统

## 1. 核心问题与研究动机

- **核心问题**：长时序人形机器人运动操控（loco-manipulation）中"**物体状态发散**（object-state divergence）"问题。即在 Vision-Language-Action（VLA）策略中，用于条件化全身动作的物体状态，与用于验证动作是否完成预期物理关系的物体状态之间存在不一致，导致误判、错误子任务切换、低效恢复等失败。
- **研究背景**：
  - 现有 VLA 策略（如 π0、RT-2、Octo、GR00T-N1.7）通常仅依靠视觉-语言特征的隐式编码来条件化动作，缺乏对任务对象的显式、持久、可验证的物理状态表示。
  - 长时序任务（如"整理桌面"、"递饮料"）要求机器人在行走、接触、抓取、放置、遮挡、恢复过程中持续锚定同一物体。
  - 现有执行验证机制（语言级监控、符号层、技能模块）往往与动作策略的状态空间分离，造成物理一致性缺失。
- **整体含义**：提出将物体作为"跨时间跨动作持续存在的物理实体"进行建模，使动作生成与执行验证共享同一份物体级物理记忆，从而形成可闭环的人形机器人 VLA 执行范式。

## 2. 方法论

### 2.1 核心思想：Persistent Object Tokenization（POT）

- 将任务相关的 RGB-D 观测提升为**角色索引的 3D 物体记录**（role-indexed 3D object records），并在动作专家与谓词验证器之间**共享**。
- 形成 **Ground → Act → Refresh → Verify → Recover** 的闭环循环：
  - **Ground**：从当前子任务 τᵢ 与 RGB-D 观测构建物体记忆 M_t^{τᵢ}
  - **Act**：将物体记忆序列化为 Persistent 3D Object Tokens，喂给全身动作头
  - **Refresh**：执行完动作块后用新 RGB-D 更新物体记忆至 M_{t+H}^{τᵢ}
  - **Verify**：几何谓词检查刷新后的物体状态是否满足预期物理关系
  - **Recover**：基于状态机 {continue, retry, reobserve, reground, replan} 触发局部恢复

### 2.2 关键技术细节

- **物体记录字段**（每条记录 met）：
  - 语义角色（TARGET / DESTINATION / SUPPORT / HANDOVER_PARTNER / REFERENCE / PADDING）
  - 实体短语、2D 框、可见性、置信度
  - 3D 质心、3D 范围（extent）、可选朝向
  - 关系特征：物体-容器距离、支撑高度、末端执行器-物体偏移、目标-目的地位移、对齐、容纳、交接线索
- **物体标记 Schema**：
  - 默认 K=8 个槽位，每槽 F=33 维特征
  - 标记张量 x_t^{obj} = T(M_t^{τᵢ}) ∈ ℝ^{K×F}
  - 填充槽位（padding）通过 token_mask 屏蔽
- **动作头集成**（基于 GR00T-N1.7）：
  - 在 DiT 自注意力序列中插入物体标记：S_t = [Z_t^{state}, Z_t^{obj}, Z_t^{action}]
  - 物体标记投影器：LayerNorm → Linear → GELU → Dropout → Linear，配以可学习的角色嵌入与上下文嵌入
  - 不改动视觉-语言骨干，仅修改动作头序列
  - 不增加辅助物体记忆或谓词损失，训练目标仍为动作块预测
- **谓词级验证**：
  - 谓词定义 p = ⟨κ, α, op, ν, n⟩（类型、参数、操作符、阈值、稳定性窗口）
  - 覆盖：容纳（containment）、支撑（support）、末端-目标接近度、目标-目的地位移、双手机分配、交接距离
  - 验证状态机返回：{in_progress, done, blocked, failed, uncertain}
  - 失败诊断 d_ξ 定位失败模式（未抓取、超出目标区域、支撑不稳、交接距离过远等）
- **执行与安全**：每次仅执行一个经过验证的短时域动作块，包含指令平滑、关节/速度限制、平衡检查、碰撞感知工作空间约束与紧急停止。

### 2.3 与基线的关键差异

- **保持不变**：GR00T-N1.7 骨干、Unitree-G1 全身动作表示、运行平台、机器人本体
- **唯一受控变量**：是否使用 POT 物体记忆 + 谓词验证（即"共享物体状态闭环"）

## 6. 主要结论与发现

- **核心结论**：在 Unitree G1 上，**持久化物体中心状态**是可验证人形 VLA 执行的有效抽象，共享物体状态闭环显著提升长时序运动操控成功率（71/80 vs 39/80，提升约 82%）。
- **分项结论**：
  - POT 物体标记为动作专家提供显式角色索引 3D 状态，是单一最大增益来源（Direct 15/40 → POT-tokens 31/40）
  - 谓词验证在物体标记基础上提供额外提升（POT-tokens 31/40 → POT-VLA 34/40），主要捕获残余的虚假完成与部分失败
  - 最大改善出现在需要**跨多动作块维持 3D 关系**的任务上：杯子堆叠（1/10 → 8/10）、双球放置（5/10 → 9/10）、衣物运送（3/10 → 9/10）、抽屉/托盘（4/10 → 8/10）
  - 在 Being-0 对齐服务任务上达到 44/50（vs Being-0 论文报告的 37/50），验证了泛化可行性
  - 泛化测试中，对新物体实例（6→9）、布局位移（5→9）、执行中扰动（4→8）提升最显著；干扰物影响最小
- **定性发现**：
  - 角色感知的 3D 物体标记减少了目标搜索震荡，并改善了把手、杯子、球、小桌面物体、衣物与容器区域的接触相关定位
  - 持久物体记录减少了逐块身份抖动
  - 几何监督器可在本地刷新当前子任务，避免强制完整语言级重规划

## 7. 优点与亮点

- **方法论创新**：
  - 提出"物体状态发散"作为 VLA 长时序失败的统一解释框架，概念上清晰、可推广
  - POT 设计将 3D Grounding 转化为**可执行且可验证的物理记忆**，桥梁作用于感知、动作、验证三层
  - 不依赖模拟器、物理引擎或学习动力学模型，仅依靠测量驱动的物体状态转移流
  - 角色索引（TARGET/DESTINATION/SUPPORT/HANDOVER）显式分离语义与几何，适合谓词验证
- **系统设计亮点**：
  - 单一受控变量的匹配基线（Matched Direct Baseline）使贡献归因清晰
  - 在 DiT 动作头插入而非在视觉-语言骨干插入，最大化兼容性、最小化对基础模型的扰动
  - 谓词系统返回结构化失败诊断（missing visibility / failed grasping / unstable support / outside_goal_region 等），便于人机协同
  - 状态机 {continue, retry, reobserve, reground, replan} 提供分层恢复机制，避免一次性全局重规划
- **实验亮点**：
  - 8 类任务横跨运输、放置、堆叠、分类、铰接、形变、交接——覆盖长时序操控关键挑战
  - 消融与泛化测试层次分明（隔离组件贡献、测试对分布偏移的鲁棒性）
  - 失败模式定性分析（直接基线的失败多为**度量物体状态错误而非语义误解**）具有启发意义
