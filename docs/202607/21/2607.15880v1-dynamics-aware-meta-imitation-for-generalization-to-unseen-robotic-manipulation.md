## 摘要
模仿学习旨在从大量观测与演示中为机器人习得技能，因此面临数据稀缺与环境泛化的挑战。现有方法主要侧重于对域内任务的模仿，导致在泛化到未见任务时表现不佳。为弥合这一泛化差距，我们提出了动力学感知元模仿（Dynamics-Aware Meta-Imitation, DAMI）框架。通过结合元学习以构建共享技能空间，DAMI使智能体能够快速适应新任务。我们引入了视觉-运动轨迹（Visual-Motor Trajectory, VMT）模块，以捕捉任务潜空间内的复杂时空动力学。此外，我们提出了非配对统一任务（Unpaired Unified Task, U2T）模块，用于融合非结构化的多模态观测。为协调这些表征，我们集成了任务条件特征调制（Task-Conditioned Feature Modulation, TCFM）机制，专门用于调制低级三维特征。通过从随机且完整的参考演示中捕捉内在动力学，我们的框架学习的是任务背后的逻辑而非记忆静态线索，从而确保有效的泛化能力。在仿真与真实环境中的大量实验表明，我们的方法在已见任务的直接推理以及通过少样本微调适应未见任务方面均优于当前最先进的基线方法。

## Abstract
Imitation Learning aims to learn skills from extensive observations and demonstrations for robots, so it suffers from data scarcity and environment generalization. The existing methods predominantly focus on imitation from in-domain tasks and consequently struggle with generalization to unseen tasks. To bridge this generalization gap, we propose the \textbf{D}ynamics-\textbf{A}ware \textbf{M}eta-\textbf{I}mitation (DAMI) framework. By integrating meta-learning to construct a shared skill space, DAMI equips agents for rapid adaptation to novel tasks. We introduce the Visual-Motor Trajectory (VMT) module to capture complex spatio-temporal dynamics within the task latent space. Furthermore, we propose the Unpaired Unified Task (U2T) block to fuse unstructured multimodal observations. To coordinate these representations, we integrate a Task-Conditioned Feature Modulation (TCFM) mechanism customized for modulating low-level 3D features. By capturing intrinsic dynamics from a random complete reference demonstration, our framework learns the underlying task logic rather than memorizing static cues, ensuring effective generalization. Extensive experiments in both simulation and real-world settings demonstrate that our approach outperforms state-of-the-art baselines regarding direct inference on seen tasks and adaptation to unseen tasks via few-shot fine-tuning.

## 2. 方法论

### 2.1 整体框架：DAMI（Dynamics-Aware Meta-Imitation）
- 核心思想：**元学习（MAML） + 3D 扩散策略** 的耦合。
- 策略输入包括三部分：**当前观测**（3D 点云 + 机器人状态）、**语言指令**、**完整参考演示**。
- 策略输出：H 步动作轨迹。
- 关键设计：在共享初始化基础上，仅需少量演示即可快速适应新任务。

### 2.2 关键模块

#### （1）视觉-运动轨迹模块（VMT, Visual-Motor Trajectory）
- 动机：纯视觉编码易过拟合静态外观，无法区分"推/拉/按"等动作意图。
- 实现：
  - **统一模态嵌入**：将视觉特征 $f_{v,t}$ 与本体动作 $a_t$ 拼接后，经可学习线性投影映射到共享潜空间：$e_t = \phi_{\text{proj}}([f_{v,t} \oplus a_t])$；
  - **时空表征学习**：加上位置编码后，输入 Transformer 编码器得到 $H_{\text{demo}} = \text{Transformer}(E+P)$，从而捕捉"在何种动作下场景如何变化"。

#### （2）非配对统一任务模块（U2T, Unpaired Unified Task）
- 动机：参考演示与当前观测无需时序对齐（同一任务不同阶段），但需共享任务语义。
- 实现：
  - 文本特征由**冻结的 CLIP 编码器**生成 $f_{\text{text}}$；
  - 演示 token $H_{\text{demo}}$ 与文本特征经模态专属仿射投影对齐；
  - 时间步嵌入 $e_k$ 与当前观测特征拼接后经 MLP 得到 $h_k$；
  - 仅在 **U-Net 第一个下采样块**使用 Transformer 编码器融合三者：$C_{\text{Down}_1} = \text{U2T}(Z_{\text{in}})$，其余块仅使用 $h_k$。

#### （3）任务条件特征调制机制（TCFM, Task-Conditioned Feature Modulation）
- 对每个 U-Net 块的特征 $h^j$ 使用 FiLM 风格调制：$\tilde{h}^j = \gamma^j(c_j) \odot h^j + \beta^j(c_j)$；
- 其中 $c_j$ 在 Down₁ 处为 U2T 输出，其余处为 $h_k$；
- 设计原因：早期下采样层执行几何定位与局部接触推理，最需要任务条件。

### 2.3 训练算法
- **损失函数**：扩散策略的 action-prediction 损失 $L_{\text{diff}} = \|A_0 - \hat{A}_{0,\theta}\|_2^2$；
- **MAML 二阶元梯度**：内环更新 $\theta'_i = \theta - \alpha \nabla_\theta L_{\text{diff}}(\theta, B^{\text{sup}}_i)$，外环基于查询集平均梯度并保留二阶导，使用 AdamW（warmup + cosine）更新共享初始化；
- **EMA 策略**：用于已见任务的直接推理；
- **未见任务适配**：从 EMA 初始化，经少样本微调后评估。

### 6.1 定量结果

### 6.2 关键发现

## 7. 优点

- **方法创新**：
  - VMT 模块首次在元模仿学习中将"视觉-动作"联合编码为运动中心上下文，避免静态外观过拟合；
  - U2T 仅在首个下采样块做 Transformer 融合，兼顾表达力与计算效率；
  - TCFM 通过 FiLM 实现细粒度任务条件调制。
- **架构设计合理**：将 MAML 的"共享初始化 + 快速适配"优势与扩散策略的"多模态动作建模"优势耦合。
- **实验较系统**：覆盖三大仿真基准 + 真实机器人 + 多角度消融，且报告了**适配时间**这一实用指标。
- **实际部署友好**：真实机器人适配在 75 秒内完成，少于 2 分钟。
- **明确指出现有方法的失败模式**（Action Misinterpretation）并给出针对性解决方案。
