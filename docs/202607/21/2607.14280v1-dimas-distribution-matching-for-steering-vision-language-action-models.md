## 摘要
基于流匹配的视觉-语言-动作（VLA）模型已成为机器人操作任务中强大的策略网络，然而一项关键能力尚未得到充分探索：细粒度行为控制，即通过干预模型的内部表征来调控机器人完成任务的方式。表征引导是语言模型和视觉-语言模型中一种成熟的解释性工具，其中行为特征通常被编码为线性方向，但我们证明这些经典方法在 VLA 中效果不佳。我们提出了 DiMaS，一种专为流匹配 VLA 设计的分布匹配引导策略，通过在表征分布之间进行迁移，而非沿固定方向移动，并证明该策略能够有效地在两个当前最先进的 VLA 上控制行为。我们进一步考察了该策略在任务差异不断增大时的泛化能力，即当学习任务与评估任务越来越不同时，刻画行为控制何时能够迁移、何时会失效。最后，通过对动作专家表征结构的分析，我们解释了为何经典的线性引导方法在视觉运动场景中效果不佳：行为特征是线性可解码的，但并非线性可引导的，这正是 DiMaS 采用分布匹配设计的动因。我们的代码已公开，地址为 https://github.com/pegah-kh/dimas，更多结果与视频请见 https://pegah-kh.github.io/dimas/

## Abstract
Flow-matching-based vision-language-action (VLA) models have emerged as powerful policies for robotic manipulation, yet a critical capability remains underexplored: fine-grained behavioral control, the ability to govern how a robot performs a task by intervening on its internal representations. Representation steering is a well-established interpretability tool for language and vision-language models, where behavioral features are typically encoded as linear directions, but we show that these classic methods fall short in VLAs. We propose DiMaS, a Distribution-Matching Steering strategy tailored to flow-matching VLAs, which transports between representation distributions rather than shifting along a fixed direction, and show that it effectively controls behavior across two state-of-the-art VLAs. We further examine the generalizability of this strategy as the tasks it is learned from and evaluated on grow increasingly dissimilar, characterizing where behavioral control transfers and where it weakens. Finally, through an analysis of the representation structure of the action expert, we explain why classical linear steering falls short in the visuomotor setting: behavioral features are linearly decodable but not linearly steerable, which motivates the distribution-matching design of DiMaS. Our code is publicly available at https://github.com/pegah-kh/dimas, with additional results and videos at https://pegah-kh.github.io/dimas/

# DiMaS 论文总结

## 1. 核心问题与整体含义

- **研究背景**：基于流匹配（flow-matching）的视觉-语言-动作（VLA）模型（如 SmolVLA、π0.5）已成为机器人操作任务的强有力策略，通过 VLM 表征条件化连续动作专家实现精细控制。
- **关键缺失能力**：这些模型在"做什么"（task success）上已很成熟，但在"怎么做"（细粒度行为控制，如运动速度、轨迹高度）上缺乏有效手段。
- **传统方法的局限**：表征引导（representation steering）在 LLM/VLM 中已被广泛验证有效，通常假设行为特征编码为激活空间中的**线性方向**（线性表征假设 LRH），通过加性偏移实现行为控制。
- **本文核心问题**：经典线性引导方法在 VLA 场景下表现不稳定、效果不一致，限制了其可解释性与可控性。**为什么线性方法在 VLA 中失效**？**如何设计针对流匹配 VLA 的有效引导策略**？

## 2. 方法论（DiMaS）

### 核心思想
- 不沿单一固定方向移动表征，而是学习一个**分布之间的传输映射 T**，将"特征缺失"的源分布 D⁻ 映射到"特征存在"的目标分布 D⁺。
- 利用**最优传输（Optimal Transport, OT）** 保留 D⁻ 与 D⁺ 的完整几何结构，而非压缩为单一方向。

### 关键技术细节

**Step 1：提取表征与配对行为特征**
- 从动作专家 f_A 的某一层 ℓ、某一去噪步 m 处提取残差流表征：h_{p,m}^ℓ(x_t) ∈ R^{d_A}
- 通过预测动作 a_i = (Δx, Δy, Δz, ..., gripper) 派生连续标量行为特征 ϕ(a_i)，如速度 = √(Δx² + Δy² + Δz²)，或累积 z 位移。

**Step 2：构造源/目标分布**
- 按经验分位数划分，避免中位数切分带来的样本重叠：
  - D⁻ = {h_i : ϕ_i ≤ q_τ}，τ = 0.25（下四分位）
  - D⁺ = {h_i : ϕ_i > q_{1-τ}}，1-τ = 0.75（上四分位）

**Step 3：学习传输映射 T**
- 求解 Kantorovich 最优传输问题（离散形式）：
  $$W_2^2(D^-, D^+) = \min_{\gamma \in \Pi(D^-, D^+)} \int \|z^- - z^+\|^2 d\gamma(z^-, z^+)$$
- 由于样本有限，采用**低秩 Sinkhorn 算法**（low-rank Sinkhorn）求解，复杂度 O((n+m)·r·K)，熵正则化 ε = 10⁻⁴，秩 r = min(n, m)。

**Step 4：测试时干预**
- 对测试表征 h，先通过**最近邻投影** P(h) = argmin_{z ∈ D⁻} ‖z - h‖ 映射到源分布
- 应用传输映射 T ◦ P(h)
- **特征过滤器（feature filter）**：使用线性 SVM 分类器 g(h) ∈ {0,1} 决定是否介入；g(h) = 1 表示特征缺失、需要干预
- **插值系数 α ∈ [0,1]**（核心"秘密武器"）：
  - α = 0：保持原始表征
  - α = 1：完全传输
  - 中间值：连续调节控制强度
  - h ← (1-α)h + α · (T ◦ P(h))，当 g(h) = 1

### 算法流程
1. 训练阶段：收集 rollout → 提取 action expert 中间层表征 → 计算对应行为特征 → 按分位数分组 → 训练 SVM 分类器 → 求解 OT 传输映射 T
2. 推理阶段：对每步表征 → SVM 判定 → 若需介入则 OT 映射 + 插值 → 输出修改后表征继续去噪

## 3. 实验设计

### 数据集与场景
- **LIBERO 基准**（终身机器人学习）：
  - **LIBERO-Object**：物体中心操作（10 任务）
  - **LIBERO-Spatial**：空间推理（10 任务）
  - **LIBERO-Goal**：目标条件任务，包含关节物体操作（10 任务）
  - **LIBERO-10 (Long)**：长视野复合任务（10 任务）
- 每个任务 50 个不同的初始状态分布

### 模型
- **SmolVLA**：基于 SmolVLM-256M 主干 + flow-matching 动作专家；预测 50 步动作块，每步仅执行第一步
- **π0.5**：基于 PaliGemma-3B 主干 + 300M 参数动作专家；预测并执行 10 步动作（更平滑）

### 目标行为特征
1. **末端执行器速度**（end-effector speed）
2. **末端执行器累积 z 位移**（垂直方向累积位移）

### 对比方法
1. **Mean-difference steering**（VLM Mean）：T(h) = h + (μ⁺ - μ⁻)
2. **Regression-based steering**（VLM Regression / FM Regression）：训练岭回归预测特征，沿回归方向最小范数扰动使预测值达到目标分位数
3. **Prompt injection**：通过指令重写（"go faster"、"do this slowly"）控制行为，无激活层干预

### 评估指标
- **成功率 SR**：任务完成率
- **特征值变化**：目标行为特征的均值变化 Δ
- **统计显著性**：配对 t 检验（p < 0.01）

## 6. 主要结论与发现

1. **DiMaS 显著优于线性引导和 prompt 引导**：能在两个不同规模 VLA 上同时调节速度与 z 位移，且能向高/低两个方向移动
2. **经典线性方法在 VLA 中失效**：VLM Mean、VLM/FM Regression、Prompt 引导的特征移动方向常不一致（增加和减少干预都偏向同一方向），且不显著
3. **行为特征线性可解码但不可线性引导**：
   - action expert 中后期层表征的 SVM 分类准确率接近 100%
   - 但沿分类方向平移只能移动分布的位置，**无法匹配其形状**（PCA 可视化证实）
   - 这与 LLMs/VLMs 中的线性表征假设不同，揭示 VLA 表示结构的独特性
4. **跨任务/跨 suite 迁移能力**：
   - Setting 2 > Setting 1（多任务聚合更稳定）
   - Setting 3（suite 内未见任务）仍显著
   - Setting 4（跨 suite）仍有方向正确的迁移，但 Goal suite 因任务异质性（推动物体 + 操作炉具）效果最弱
5. **可放大已有倾向的行为**：减少速度/降低高度方向效果更强，因为策略默认就倾向于减速、下放抓取；反向（加速、抬高）更难
6. **action expert 表征比 VLM 更具线性可分性**（90+% vs 87% max），故干预位置选在 action expert 而非 VLM
7. **长视野任务（LIBERO-10）仍有效**：速度降低 Δmean = -0.024，SR 从 96% 降至 90%（α = 0.5）

## 7. 优点（亮点）

- **方法新颖性**：首次将最优传输引入 VLA 表征引导，突破了"沿固定方向偏移"的范式约束
- **完整的表示结构分析**：通过线性可分性 + PCA 偏移可视化，系统解释线性引导失败原因（"可解码 ≠ 可引导"）
- **充分的消融与泛化研究**：4 个 Setting 严谨刻画了任务差异增大时行为控制的迁移规律
- **实用的工程设计**：
  - α 插值旋钮提供可控的强度-成功率 trade-off
  - 推理开销仅 0.62 ms，实时可部署
  - 离线一次性 OT 求解，与推理解耦
- **跨模型泛化**：在 256M (SmolVLA) 与 3B+300M (π0.5) 两个数量级不同的 VLA 上均有效
- **理论 insight**：揭示了 VLA 中 LRH 不成立的关键证据，对未来 VLA 解释性研究有指导意义

## 8. 不足与局限

- **成功率的代价**：z 位移引导会显著降低 SR（如 LIBERO-Object 上 SmolVLA 从 89% 降至 1-2%），因垂直位移与抓取-放置紧密耦合
- **仅仿真验证**：未在真实机器人上测试，sim-to-real 迁移性未知
- **特征范围有限**：仅测试连续标量行为特征（速度、z 位移），未涉及离散或高维行为模式（如抓取力、轨迹曲率）
- **OT 计算成本**：每个 suite ~85 分钟，离线成本不可忽视；低秩 Sinkhorn 虽已优化，但大规模特征空间仍受限
- **超参敏感性**：层选择依赖经验，对新 VLA 需重新校准；α 虽有默认值 0.5，但最优值因任务而异
- **动作块对应关系是近似的**：将每个表征与其对应动作的特征一一配对，忽略了同一动作块内多表征协同影响的复杂性
- **缺乏 VLM 内干预的深入比较**：线性方法在 VLM 上效果差，作者归因于可分性低，但未深入探究 VLM 表征是否也存在非线性的"形状差异"
- **干预时机未优化**：当前对所有时间步均匀干预，未实现"何时介入"的学习，可能导致不必要的扰动
- **baseline 公平性争议**：VLM Regression 在每层都干预，与 DiMaS 仅干预 action expert 单层相比，计算开销差异未被讨论
- **方向偏差风险**：仅 LIBERO-90 中部分任务与单一基准，可能存在 benchmark-specific overfitting
