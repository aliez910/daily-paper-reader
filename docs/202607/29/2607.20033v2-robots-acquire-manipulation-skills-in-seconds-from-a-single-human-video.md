## 摘要
快速且轻松地习得新技能并保留已掌握的技能对机器人而言至关重要。然而，当前方法仍然依赖笨重且耗时的训练循环，这一过程不仅成本高昂、速度缓慢，还会侵蚀已习得的技能。在本文中，我们提出了 HOST（Human-to-robot One-Shot Skill AcquisiTion，人到机器人一次性技能获取）框架，使机器人能够在数秒内从单个人类视频中习得技能，同时保留先前已掌握的技能。HOST 通过自基预测的级联来解决技能获取问题：它首先估计机器人在演示任务中的进度，然后将接下来的进展转化为机器人自身的未来观测，最后从这些预测的观测中推导出动作。该级联在耦合于视频演示的目标上进行训练，方法是将机器人轨迹与视频演示映射到一个共享的任务进度流形上，然后重新定义每个目标以使其与视频的未来进展对齐。HOST 从而使机器人能够主动跟随所演示的过程，并将其适配到机器人的本体结构。HOST 在推理阶段从单个人类视频获取新技能，平均耗时 29 秒，平均成功率达到 62%。它以 45% 的优势超越了零样本基线，同时保留了先前已掌握的技能。HOST 甚至超越了每任务使用 50 次机器人演示进行微调的基线，但所需的演示数量少 50 倍，且每个技能的获取速度快 507 倍。有关 HOST 的更多信息可在项目网站上获取。

## Abstract
The ability to acquire skills rapidly and effortlessly while retaining those already mastered is essential for robots. However, current methods still rely on a cumbersome training-time loop that is costly and slow, while eroding skills already mastered. In this paper, we introduce HOST (Human-to-robot One-Shot Skill AcquisiTion), a framework that enables a robot to acquire skills in seconds from a single human video while retaining previously mastered skills. HOST resolves skill acquisition through a cascade of self-grounded prediction. It first estimates the robot's progress within the demonstrated task, then translates the upcoming progression into the robot's own future observations, and finally derives actions from these predicted observations. This cascade is trained on targets coupled to the video demonstration, obtained by mapping the robot trajectory and the video demonstration onto a shared task progress manifold, then redefining each target to align with the future progression of the video. HOST thereby enables the robot to actively follow the demonstrated procedure and adapt it to the robot's embodiment. HOST acquires novel skills at inference time from a single human video in an average of 29 seconds and achieves a 62% average success rate. It exceeds the zero-shot baseline by 45% while retaining previously mastered skills. HOST even exceeds the baseline fine-tuned on 50 robot demonstrations per task while requiring 50 times fewer demonstrations and acquiring each skill 507 times faster. Additional information about HOST is available on the project website.

## 一、核心问题与研究背景

- **核心需求**：机器人需要具备**快速学习新技能**且**同时保留已学技能**的能力，这本质上是一种持续学习（Continual Learning）能力。
- **现有痛点**：当前主流方法（如基于大规模数据的行为克隆、扩散策略或视觉语言动作模型微调等）通常依赖**昂贵的训练循环**：
  - 每学习一个新任务都需要重新训练或微调模型；
  - 训练过程缓慢、资源开销大；
  - 极易引发**灾难性遗忘（catastrophic forgetting）**，旧技能在新任务训练后性能下降。
- **本文目标**：探索一种**推理时（inference-time）**即可从**单段人类视频**获取新操作技能、且无需耗时训练的方案。

## 二、方法论：HOST 框架

### 1. 核心思想
HOST（Human-to-robot One-Shot Skill AcquisiTion），即"人到机器人一次性技能获取"。它将"技能获取"重新定义为**自基预测级联（Cascade of Self-Grounded Prediction）**，而非端到端的动作回归。

### 2. 三级级联预测流程
- **第一步——任务进度估计**：根据机器人当前观测，估计其在所演示任务中所处的进度阶段（task progress）。
- **第二步——未来观测预测**：将"即将到达的进度"转化为机器人在未来某一时刻**自身视角下的未来观测**（future observation prediction）。
- **第三步——动作推导**：从预测出的未来观测中，反推出实现该过渡所需的动作（action derived from predicted observations）。
- 该级联耦合于人类视频演示，使得机器人能"主动跟随"演示过程，并适配到自身的本体结构（embodiment）。

### 3. 关键技术细节
- **任务进度流形对齐（Task Progress Manifold Alignment）**：
  - 将机器人执行轨迹与人类视频演示映射到**共享的任务进度流形**上；
  - 重新定义每个预测目标，使其与视频中"未来的进度推进"对齐，从而把异构数据（人类视频 vs. 机器人轨迹）统一到同一语义进度轴上。
- **跨本体适配**：通过预测"机器人自身的未来观测"而非直接模仿人类动作，使方法对机器人物理结构差异具有鲁棒性。

### 4. 算法流程（文字描述）
1. 给定一段人类演示视频与机器人当前观测；
2. 级联模块 1 输出任务进度标量/潜变量；
3. 级联模块 2 在机器人视角下预测未来观测帧/特征；
4. 级联模块 3 由预测观测反解当前步应执行的动作；
5. 整个过程在推理时完成，无需梯度更新。

## 七、优点 / 亮点

- **范式创新**：将传统"训练时学技能"转变为"推理时学技能"，大幅降低持续学习成本。
- **任务进度流形对齐**：以进度作为异构模态间的"对齐锚点"，相比直接像素级或动作级模仿更适合跨本体迁移。
- **三级级联分解**：把难以一次性预测的"动作"分解为相对容易的"进度→观测→动作"，增强了可学习性与可解释性。
- **数据高效**：仅需 1 段人类视频、29 秒推理即完成学习，相对微调基线大幅节省数据与时间。
- **抗遗忘**：保持已有技能的同时获得新技能，符合持续学习核心诉求。
