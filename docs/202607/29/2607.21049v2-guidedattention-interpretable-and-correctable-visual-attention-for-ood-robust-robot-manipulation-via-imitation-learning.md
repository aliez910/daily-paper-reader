## 摘要
端到端的视觉运动策略几乎不提供让人类理解或纠正其视觉注意力的机会。我们提出了GuidedAttention，一个视觉运动模仿学习框架，将可解释且可纠正的视觉注意力作为显式的中间表示。任务相关的注意力关键点从相机图像中预测出来，并作为基于扩散模型的动作策略的条件。用户可以在回放初始化时检查并选择性地纠正所选的关键点，随后纠正后的注意力通过跟踪模块在整个执行过程中自动传播。模拟和真实世界中的实验表明，GuidedAttention持续提升了机器人操作性能，尤其是在位置和外观分布外（OOD）条件下。https://mmurooka.github.io/guided-attention-project-page

## Abstract
End-to-end visuomotor policies provide little opportunity for humans to understand or correct the policy's visual attention. We propose GuidedAttention, a visuomotor imitation learning framework that introduces interpretable and correctable visual attention as an explicit intermediate representation. Task-relevant attention keypoints are predicted from camera images and condition a diffusion-based action policy. Users can inspect and optionally correct selected keypoints once at rollout initialization, after which the corrected attention is automatically propagated throughout execution by a tracking module. Experiments in simulation and the real world demonstrate that GuidedAttention consistently improves robot manipulation performance, particularly under positional and appearance out-of-distribution (OOD) conditions. https://mmurooka.github.io/guided-attention-project-page

# GuidedAttention 论文总结

## 一、论文核心问题与研究动机

- **核心问题**：端到端视觉运动策略（visuomotor policy）虽然具备强大的感知-动作映射能力，但其内部的"视觉注意力"对人类而言是不透明的黑箱——既难以理解策略关注了图像中的哪些区域，更难以在执行过程中对其进行干预和纠正。
- **关键痛点**：
  - 在 OOD 场景下（如物体位置变化、外观/纹理变化），策略容易"走神"，忽略任务相关的关键结构，导致性能急剧退化。
  - 即便人类能轻易识别任务目标，也难以将这一"简单提示"传达给端到端策略。
- **研究目标**：在保留端到端策略自主性的同时，提供一个**可解释且可纠正的视觉注意力接口**，让人类能在最少的交互下（如 rollout 初始时刻一次性修正关键点）引导策略回到正确的视觉焦点。

## 二、方法论

### 2.1 整体框架（DP-GA）
- 输入：多视角 RGB 图像 + 本体感知（proprioception）关节状态。
- 输出：基于 CNN-UNet 的去噪扩散动作策略（Diffusion Policy）。
- 核心改动：在感知与动作生成之间引入**显式的视觉注意力中间表示**（注意力关键点及其特征），以此作为扩散过程的条件。

### 2.2 视觉注意力编码器（AttnEnc）
- 采用类似 DETR 的 Transformer 编码器-解码器结构：
  - 图像经 ResNet-18 提取 patch 特征 → Transformer 编码器 → 与可学习 query 一起送入解码器。
  - 坐标头（线性层）将每个 attention feature 映射为 2D 关键点坐标：
    $$p_i = h_\theta(f_i) = A f_i + b \in \mathbb{R}^2$$
- 每个图像输出 Nₖ 个 attention feature ${f_i}$，这些 feature 条件化扩散策略。
- 备选变体（Coord-as-feat）：直接以坐标 $p_i$ 而非 feature 作为扩散条件的几何线索。
- 关键点损失（Keypoint Loss）：均方误差 $\mathcal{L}_{kp} = \frac{1}{N_k} \sum_i \|p_i - p_i^{gt}\|_2^2$，监督 attention feature 与任务相关物理结构对齐。

### 2.3 关键点覆盖机制（Keypoint Override）
在 rollout 初始帧，用户可选择性更正若干关键点坐标 $p_i^{gt}$；为保证覆盖路径与预测路径产生一致的策略行为，引入三项关键技术：

1. **前向-逆向权重共享**：线性映射 $h_\theta$ 的解析逆：
   $$h_\theta^{-1}(p) = A^+(p - b)$$
   其中 $A^+$ 为 Moore-Penrose 伪逆；保证参数零增量下正逆一致。
2. **特征空间对齐损失**：由于 $d_f > 2$ 时逆映射欠定，加入一致性损失促使预测路径与覆盖路径产生相近的特征：
   $$\mathcal{L}_{feat} = \frac{1}{N_k} \sum_i \| f_i - h_\theta^{-1}(p_i^{gt}) \|_2^2$$
3. **随机特征路由**：训练时，对每个关键点随机选择"预测路径"或"覆盖路径"作为扩散条件，缓解早期训练不稳定，并使两种 feature 产生一致的动作分布。

### 2.4 关键点标注与跟踪
- **训练阶段**：仅需在每条示教轨迹的**第一帧**手动点击标注关键点（轻量、直观），后续帧通过 Co-Tracker 自动传播：$p_i^{gt}[t] = G(p_i^{gt}[t-1], I[t], I[t-1])$；静态关键点（与固定结构绑定）始终保持不变。
- **推理阶段**：策略前向预测所有关键点，可视化为 ✕-marks；用户可在 rollout 初始帧选择性地点击修正部分关键点（仅一次），跟踪模块会在执行过程中持续传播已修正的关键点。

## 六、主要结论与发现

- **ID 性能提升**：DP-GA（default）在仿真中较 DP 提升约 15 pp（83.3% vs 67.8%）；真实世界中 DP-GA 较 ACT 提升 15–30 pp，较 DP 提升 5–15 pp。
- **OOD 鲁棒性显著增强**：
  - 仿真 OOD 条件下，DP-GA 全自主执行相较 DP 高出约 10 pp；引入人类一次性修正后，OOD 性能再提升 15–30 pp，并在 Pos+App-OOD 上相对 DP 高出 20–30 pp。
  - 真实世界 Positional OOD：修正模式较自主模式额外带来 +20–40 pp。
  - 真实世界 Appearance OOD（Towel Fold）：修正模式相对自主模式提高约 +80 pp，相对 DP 基线提高约 +40 pp。
- **消融关键发现**：
  - 关闭"特征路由"在允许修正时性能下降 ~58.9 pp，说明人类修正路径与预测路径在训练中的协同训练至关重要。
  - 移除"注意力监督"在 ID 条件下性能即下降 ~31.1 pp，说明 attention feature 必须对齐任务相关结构。
- **鲁棒性曲线**：方法对中等噪声较稳定；噪声达 8 px 时在 Pos+App-OOD 下仍领先无注意力基线 20+ pp。
- **关键点数量**：仅 2 个任务相关关键点即可获得高性能，无需大量增加标注负担；可仅修正子集关键点。
- **相机数量**：增加相机并不必然提升性能，**选择能提供任务相关观测的视点**比数量更重要。

## 八、不足与局限

- **关键点表示的固有局限**：
  - 假设少量（通常 2 个）手动定义的关键点足以代表所有任务相关结构，对更复杂任务可能不够。
  - 仅使用 2D 图像坐标，未显式建模深度与遮挡关系，关键点被遮挡时性能会下降。
- **对外部跟踪器的依赖**：依赖 Co-Tracker 自动传播关键点，遇到严重形变或长时间遮挡时可能失效；静态关键点策略只能部分缓解该问题。
- **算力与训练细节缺失**：未报告 GPU 型号、数量、训练时长等关键工程信息，难以评估复现成本。
- **任务与 OOD 范围有限**：
  - 任务相对简单（穿缆、套环、铲颗粒、插杯、放链、折毛巾），未涉及类别级 OOD、动态环境、多物体干扰等更复杂的真实场景。
  - 真实世界示教数据量（每任务 32 条）偏小，置信区间较大，泛化结论应谨慎。
- **缺乏人类因素评估**：未开展 user study 评估交互体验、修正成本或不同用户间的一致性。
- **细粒度对比不足**：未与若干 SOTA OOD 鲁棒模仿学习方法（如 BMIL/RoCoDA/ROSIE、Latent Policy Barrier、Adapting by Analogy）做直接对照实验，互补性仍需验证。
- **关键点 ID 化刚性**：关键点 ID 与顺序固定，不能自适应地随时间增减或重新分配，可能限制长时序多阶段任务的扩展性。
