## 摘要
视觉-语言-动作（VLA）模型在通用机器人操作方面展现出强大的潜力，但现有的大多数模型依赖于二维视觉-语言骨干网络，缺乏对目标物体的细粒度三维理解，尤其是在遮挡、姿态变化、尺度变化以及精确空间交互等情况下。本文提出了一种以物体为中心的三维表征对齐框架，构建于π_0之上，利用SAM3D作为冻结的三维教师，在训练期间提供目标物体的三维先验。具体而言，我们使用物体识别模型定位任务相关物体，生成相应的物体掩码，并利用SAM3D提取密集的物体级三维表征，将其与π_0的中间视觉特征进行对齐。这使得策略网络能够内化目标物体的三维信息，同时在测试时无需深度图、点云、掩码、SAM3D或额外的三维模块，即可保留原始的RGB-语言到动作的推理流程。仿真实验表明该方法取得了持续的性能提升，在LIBERO上达到99.1%，在CALVIN上平均轨迹长度为4.11。真实世界实验进一步证明，本文方法在机器人需要在多个子任务中关注不同目标物体的长时序操作场景中尤为有效。

## Abstract
Vision-Language-Action (VLA) models have shown strong potential for general robot manipulation, but most existing models rely on 2D visual-language backbones and lack fine-grained 3D understanding of target objects, especially under occlusion, pose variation, scale changes, and precise spatial interaction. We propose an object-centric 3D representation alignment framework built upon $π_0$, using SAM3D as a frozen 3D teacher to provide target-object 3D priors during training. Specifically, we localize task-relevant objects with object recognition models, generate corresponding object masks, and use SAM3D to extract dense object-level 3D representations, which are aligned with intermediate visual features of $π_0$. This enables the policy to internalize target-object 3D information while preserving the original RGB-language-to-action inference pipeline without requiring depth, point clouds, masks, SAM3D, or additional 3D modules at test time. Simulation experiments show consistent improvements, achieving 99.1\% on LIBERO and an average length of 4.11 on CALVIN. Real-world experiments further demonstrate that our method is particularly effective in long-horizon manipulation scenarios where the robot must focus on different target objects across multiple subtasks.

# 论文总结：SAM3D-VLA

## 1. 核心问题与研究动机

- **背景**：现有的视觉-语言-动作（VLA）模型（如 π₀、OpenVLA、UniVLA 等）大多基于二维 RGB 视觉-语言主干，仅通过动作预测进行训练。
- **核心问题**：二维视觉表征难以捕捉目标物体的三维几何结构（形状、姿态、尺度、空间布局），在以下场景下存在明显局限：
  - 物体遮挡
  - 姿态变化
  - 场景杂乱
  - 需要精确空间放置/抓取的操作
- **现有方案的不足**：
  - 显式 3D VLA（如 SpatialVLA、GeoVLA、3D-CAVLA）依赖深度图、点云或 RGB-D 输入，会改变原有输入输出接口。
  - 视觉接地区域方法（如 ReconVLA、RoboGround）监督信号仍停留在 2D 图像空间，没有提供目标物体的 3D 形状或布局先验。
  - 现有空间表示对齐方法（如 Spatial Forcing）主要关注全局场景级空间，缺乏以物体为中心的细粒度 3D 监督。
- **本文的核心问题**：能否在不改变 π₀ 原始 RGB-语言-动作推理流程的前提下，向策略中注入目标物体的 3D 先验？

## 2. 方法论

### 2.1 整体框架
- 基于 π₀ 架构（SigLIP 视觉编码器 + Gemma-4B 语言模型 + 连续动作专家）。
- 训练时引入**冻结的 SAM3D** 作为 3D 教师，提供物体级 3D 特征监督。
- 推理时完全沿用 π₀ 原始流程，无需任何额外 3D 模块。

### 2.2 关键技术细节

1. **目标物体定位与掩码生成**
   - 使用开放式物体识别模型（Grounding DINO / YOLO）定位任务相关物体。
   - 使用 SAM2 进行像素级分割，生成二值掩码。

2. **子任务感知的物体关联（针对长时序任务）**
   - 用 GPT-4o 将高层指令分解为多个子任务。
   - 每个子任务关联对应的目标物体，使不同阶段提供不同的对象级 3D 监督。

3. **SAM3D 物体级 3D 特征提取**
   - 对多视角图像进行展平处理：$\tilde{I}_t \in \mathbb{R}^{(BV)\times 3 \times H \times W}$。
   - 由冻结 SAM3D 教师提取密集物体级 3D 特征：$T_t \in \mathbb{R}^{(BV)\times L_T \times D_T}$。
   - 特征包含目标物体的形状、表面结构、空间布局等几何先验。

4. **特征空间对齐**
   - 对教师特征进行 2D 网格重塑并通过双线性插值将其对齐到 π₀ 视觉 token 的分辨率 $(H_S, W_S)$。
   - 提取 π₀ 中间 Gemma 层视觉特征 $S_t \in \mathbb{R}^{B\times(VL_S)\times D_S}$。
   - 通过可学习投影 $P_\phi$ 将学生特征映射到 SAM3D 特征空间：$\hat{T}_t = P_\phi(S_t)$。
   - 构造 token 级掩码 $m_t$ 只在目标物体 token 上计算对齐损失。

5. **对齐损失（Masked Normalized MSE）**

$$
\mathcal{L}_{\text{align}} = \text{MSE}\Big(\text{Norm}(\hat{T}_t)[M_t],\,\text{Norm}(\bar{T}_t)[M_t]\Big)
$$

- 对学生与教师特征均做 $L_2$ 归一化，强调方向性对齐，对尺度差异鲁棒。

6. **总训练目标**

$$
\mathcal{L} = \mathcal{L}_{\text{action}} + \alpha \mathcal{L}_{\text{align}}
$$

- 其中 $\mathcal{L}_{\text{action}}$ 为 π₀ 原本的 conditional flow matching 动作预测损失。

7. **冻结表征探针实验（Frozen-Representation Probing）**
   - 训练后冻结整个 VLA 主干，仅训练一个轻量两层 MLP 探针 $P_\omega$ 从中间视觉特征预测 SAM3D 目标特征。
   - 探针性能越好，说明 SAM3D 物体级 3D 先验越容易从已学 VLA 特征中恢复。

## 3. 实验设计

### 3.1 仿真基准
- **LIBERO**：包含 LIBERO-Spatial、LIBERO-Object、LIBERO-Goal、LIBERO-Long 四个子基准，每个含 10 个任务、500 条专家演示。
- **CALVIN**：基于 ABC→D 划分的 5 子任务长时序操作挑战，评估 500 次 rollout。

### 3.2 真实世界设置
- **机器人平台**：AgileX Piper-X 移动双臂平台（6-DoF 双臂 + 1-DoF 夹爪 + 头/腕相机）。
- **任务场景**：烹饪（assemble sandwich）、插花、积木堆叠。
- **评估设置**：
  - 标准（ST）：物体处于规范初始状态。
  - 遮挡（OC）：引入物体位置变化、干扰物、部分遮挡。

### 3.3 对比方法
- **2D VLA 基线**：Diffusion Policy、Octo、OpenVLA、Dita、CoT-VLA、π₀、UniVLA、OpenVLA-OFT。
- **显式 3D VLA**：SpatialVLA、GeoVLA、3D-CAVLA。
- **隐式 3D VLA**：Spatial Forcing。
- **物体中心方法**：ReconVLA。

### 3.4 关键实验结论
- **LIBERO**：SAM3D-VLA 平均成功率 **99.1%**，优于所有 2D 与 3D VLA 基线；LIBERO-Long 上达 **98.4%**。
- **CALVIN**：SAM3D-VLA 平均长度 **4.11**，5 步成功率 **71.6%**，较 ReconVLA、UniVLA 等取得领先。
- **真实世界**：6 个任务平均成功率从 50.2%（ST）/21.3%（OC）提升至 **65.2% / 44.3%**；长时序任务（烹饪、插花、堆叠）提升最显著。
- **探针实验**：SAM3D-VLA 的探针预测误差明显低于 π₀ 基线，验证物体级 3D 先验确实被内化到 VLA 特征中。

## 6. 主要结论与发现

- 物体级 3D 理解是当前 RGB-based VLA 策略的关键瓶颈，补充了现有工作主要关注的全局空间感知或动作空间空间化。
- 通过 SAM3D 教师在训练阶段对齐目标物体的 3D 特征，可显著提升 VLA 在长时序、多目标切换场景中的表现。
- 训练时注入 3D 先验、推理时保持 RGB-语言-动作接口不变的"对齐即蒸馏"框架是可行且有效的。
- 对齐损失的方向性归一化设计对跨模态表征对齐具有较好的鲁棒性。
- 真实世界实验表明该方法在遮挡与干扰场景下同样受益。

## 7. 优点

- **方法新颖性**：首次将 SAM3D 物体级 3D 特征作为教师信号，以表征对齐方式注入 VLA，比直接引入 3D 输入更轻量。

- **解释性强**：冻结表征探针实验为"3D 先验被学到了"提供了直接证据，而非仅靠最终成功率间接论证。

- **真实世界覆盖面有限**：仅在单一机器人平台（Piper-X）的桌面任务上验证，缺少移动、户外或非结构化环境测试。
