## 摘要
近期许多机器人策略通过将大规模预训练视觉-语言模型（VLMs）用作动作骨干网络来追求更强的控制能力。我们提出了 WorldDiT，一种统一的扩散 Transformer 架构，它将动作生成与视觉世界建模相耦合，并在不使用大规模预训练 VLM 动作骨干网络的情况下取得了强劲的性能。在训练过程中，单个扩散 Transformer 生成连续动作块，并从未来相机帧中预测归一化的 RGB patch 目标。在四个 LIBERO 仿真套件上，在报告了全部四个套件结果的方法中，WorldDiT 处于总模型参数量与平均成功率所构成的报告帕累托前沿上。这些结果为未来的可扩展性研究提供了一个强大的十亿参数以下的基线。

## Abstract
Many recent robot policies pursue stronger control by using large pretrained vision-language models (VLMs) as the action backbone. We introduce WorldDiT, a unified diffusion transformer architecture that couples action generation with visual world modeling and achieves strong performance without a large pretrained VLM action backbone. During training, a single diffusion transformer generates continuous action chunks and predicts normalized RGB patch targets from future camera frames. Across four LIBERO simulation suites, WorldDiT lies on the reported Pareto frontier for total model parameters and mean success among methods reporting all four suites. These results provide a strong sub-billion-parameter baseline for future scaling studies.

# WorldDiT 论文总结

## 1. 核心问题与整体含义（研究动机和背景）

- **研究动机**：当前许多机器人策略沿用语言建模的范式，将动作生成"挂载"在大规模预训练视觉-语言模型（VLM）之上（如 π₀、OpenVLA、π₀.5、VLA-Adapter 等），以期获得广泛的感知与语言能力。但这带来两个问题：
  - **难以分离贡献**：当策略参数达到数十亿级别时，强性能可能来自动作头设计、预训练主干，或两者结合，研究者难以判断真正的来源。
  - **部署成本高**：将数 B 参数的 VLM 作为动作主干，计算与部署开销对算力受限的机器人平台不友好。
- **研究问题**：一个统一的扩散 Transformer 架构能否同时完成连续动作生成与未来视觉预测的辅助任务，并在**不使用大型预训练 VLM 作为动作主干**的前提下仍保持强控制性能？
- **整体含义**：论文主张"世界-动作统一建模"可以作为机器人策略的紧凑基础，便于在模型容量、数据多样性、部署设置三个维度上进行后续规模化研究。

## 2. 方法论

### 2.1 核心思想

- 一个**共享的扩散 Transformer（DiT）** 主干同时建模两类目标：
  - **主任务**：连续动作块（continuous action chunk）生成；
  - **辅助任务**：未来相机帧的**归一化 RGB patch**预测。
- 部署时**仅走动作路径**，RGB patch 头与目标均不在推理图中——辅助视觉目标只用于训练时的正则化 / 监督。

### 2.2 关键技术细节

- **多模态编码**（全部为冻结 + 轻量投影）：
  - 视觉：冻结 **MAE 图像编码器** + **Perceiver Resampler**（多视图共享）；
  - 语言：冻结 **CLIP 文本编码器**；
  - 机器人状态：可训练的机器人状态编码器（手臂与夹爪分开编码后拼接为一个状态 token/时间步）。
- **Backbone 配置**：depth=4，hidden=1024，16 个注意力头，4 个 register token；输入是 **C=3** 步观察上下文 + H=7 步动作 + 1 步未来 RGB patch 的时间序列。
- **RGB patch 目标构造**：
  - 对每个 224×224 CLIP 预处理后的 RGB 帧划分为 16×16 patch；
  - 每个 768 维 patch 向量按自身均值/方差归一化；
  - 每个相机均匀采样 **64 个 patch**，两个相机（主视角 + 腕部视角）共 **128 个 token**；
  - patch 目标来自时间偏移 i+H 的未来帧，仅作用于**最后一个时间槽**。
- **训练目标（Flow Matching）**：
  - 从高斯噪声到干净目标沿直线插值：$x_\tau=(1-\tau)\epsilon+\tau y$；
  - 速度回归损失 $L_{\text{flow}}=E\|v_\theta(x_\tau,\tau,c)-(y-\epsilon)\|_2^2$；
  - 总损失：$L_{\text{total}}=w_{\text{action}} L_{\text{action}}^{\text{flow}} + w_{\text{rgb}} L_{\text{rgb}}^{\text{flow}}$，权重分别为 **0.1 与 0.001**。
- **推理**：动作 token 从 $N(0,I)$ 出发，用 **20 步 Euler 积分**得到 7 步动作块；执行**前 3 步**，滑动窗口 + 重规划，并使用**时间集成（temporal ensembling）**。

### 2.3 训练流程要点

- 预训练：libero_90 多任务数据，**30 epoch**，per-GPU batch=40，梯度累积=2，LR=1e-4（cosine + 1 epoch warmup），序列长度=10。
- 微调：四个下游 suite 各自独立微调，**有效 batch=512**（per-GPU 32 × 梯度累积 2 × 8 卡），bf16 混合精度，LR=1e-4。

## 6. 主要结论与发现

- **总体性能**：WorldDiT 在 4 个 LIBERO suite 上的成功率分别为 **Spatial 98.0% / Object 97.0% / Goal 92.8% / Long 91.8%**，均值 **94.9%**；
- **参数–性能帕累托前沿**：WorldDiT 总参数量 **399.084 M**（可训练 **135.107 M**，含冻结模块），落在报告的帕累托前沿上；
  - 所有报告更高均值成功率的方法，参数都比 WorldDiT 多；
  - 所有参数 ≤ WorldDiT 的方法，成功率均低于 WorldDiT；
- **设计含义**：
  - 强基准性能可在不使用大型预训练 VLM 作为动作主干的前提下达到；
  - 单一 DiT 可以同时承载连续动作生成与未来视觉预测，部署时仍保持动作-only 路径；
  - 为**亚十亿参数**机器人策略提供强基线，支持后续 scaling 研究。

## 7. 优点（亮点）

- **架构层面的统一性**：将动作生成与世界建模合并到**单一 DiT** 与**单一 Flow-Matching 损失**，相比"动作分支 + 独立世界模型"更紧凑；
- **训练/推理解耦**：RGB patch 预测仅作训练期监督，**不增加推理开销**，保持了部署图与标准扩散策略相同；
- **参数效率高**：~400 M 总参数 / ~135 M 可训练参数即达到 LIBERO 上的 SOTA 附近水平，与使用 ≥7B 参数 VLM 主干的方法（OpenVLA、π₀、VLA-Adapter 等）相比性价比显著；
- **输入表示设计合理**：按 patch 自身统计量归一化、按帧均匀采样 patch，避免了简单整帧回归的高方差；
- **评估视角清晰**：用参数–成功率帕累托前沿而非单点比较，避免被"最大模型永远最强"误导；
- **Action chunking + 时间集成 + receding horizon**：在控制层面是成熟的方案，与现有扩散策略对齐。
